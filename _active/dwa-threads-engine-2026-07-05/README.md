## What this test kit is actually verifying

1. **Threads link throttling on Farrice's own account.** The research anchor's claim that Threads doesn't throttle in-post outbound links is LIKELY/practitioner-confirmed, not dataset-proven. If link-posts underperform text-posts over ~5–10 posts, treat throttling as real and fall back to link-in-first-reply.
2. **Coach-frame resonance.** Whether the credentialed behavior-change coach framing (Frame 1) actually converts a money-motivated Threads audience, or whether the research's own counter-read holds — that it reads as therapy to someone scanning for a way to make money. Every piece in the kit is built to pair the behavioral insight with a concrete money mechanic in the same piece specifically to guard against this, but it's a design choice under test, not a settled fact.
