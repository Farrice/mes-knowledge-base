# Operator Autopilot Memory

## Active Patterns

- Default front door is `/autopilot` when Farrice has raw thoughts, messy context, or wants plan-to-execution without remembering the agent suite.
- Use Intent Lock first, then choose the operating mode.
- Prefer execution over menus unless the user asks for options or the work has a real strategic fork.
- Use `/orchestrate` as the menu backend and `/mission` as the governance backend.

## User Context

- Farrice wants lower cognitive load and less command memorization.
- The system should feel like: raw context -> intent verified -> plan chosen -> work starts.
- The operator suite should be hidden behind routing until a specific operator is useful.

## Past Work Reference

- The bottleneck is moment-of-work orchestration, not lack of extracted expertise.
- Real Codex subagents require explicit delegation permission.
- Quality gates should protect against AI slop without turning every small task into a ceremony.
