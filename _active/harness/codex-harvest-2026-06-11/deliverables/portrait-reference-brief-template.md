# Portrait Reference Brief Template

## Purpose

Create a reusable visual reference brief from Farrice's uploaded portraits so future marketing assets stay consistent.

This does not upload images to external tools or generate likeness-based assets without explicit approval.

## Portrait Intake

For each uploaded portrait, tag:

| Field | Notes |
|---|---|
| File name | Local path or attachment label |
| Expression | Calm, focused, warm, serious, amused, direct, reflective |
| Angle | Front, three-quarter, profile, candid, seated, standing |
| Lighting | Natural, studio, high contrast, soft, low light |
| Wardrobe | Casual, premium casual, professional, fitness, creative |
| Authority level | Approachable, expert, premium, editorial, founder |
| Best use | LinkedIn banner, Loom thumbnail, carousel cover, offer doc, Notion cover, proof asset |
| Avoid use | Any context where the image feels off-brand |

## Visual Direction

Default brand posture:

- calm authority
- strategic clarity
- human judgment
- premium restraint
- psychology plus systems

Avoid:

- AI robot tropes
- neon automation visuals
- generic tech founder imagery
- exaggerated guru posture
- overproduced luxury cosplay

## Asset Uses

### Loom thumbnail

Goal:

Make the video feel human, specific, and diagnostic.

Recommended composition:

- Farrice portrait on one side
- simple proof frame on the other
- short title: `Where AI Guessed`

### LinkedIn Featured image

Goal:

Make the AI Misfire Map feel like a serious diagnostic asset.

Recommended text:

```text
The AI Misfire Map
Where your AI output is being forced to guess
```

### Offer document cover

Goal:

Signal premium operator, not generic automation consultant.

Recommended text:

```text
AI Misfire Express
Diagnostic before the build
```

## Quality Gate

- Image feels like Farrice, not a stock consultant.
- Asset supports the offer without overexplaining it.
- Visual tone matches Oracle/Catalyst: direct, calm, observant, precise.
- No external upload or AI image generation happens without explicit approval.
