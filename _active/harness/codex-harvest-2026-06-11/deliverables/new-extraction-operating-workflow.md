# New Extraction Operating Workflow

## Core Rule

Do not start with `/extract-forge` every time anymore.

Start with:

```text
/extraction-governor-agent
```

The Extraction Governor decides the right extraction depth and deployment path.

The new operating pattern is:

```text
Govern -> Extract -> Deploy -> Gate -> Compile -> Evolve
```

## Best Default Sequence

```text
/knowledge-librarian extraction
/extraction-governor-agent [source]
/extract-vision [source]
/extract-forge [source]   # only if approved by the governor/vision
/orchestrate what should I do with this new capability?
/excellence-gate
/compile-knowledge
```

## The New Extraction Loop

### 1. Surface Existing Context First

Use this before extracting so you do not create redundant assets or miss obvious stacking opportunities.

```text
/knowledge-librarian [expert/topic/domain]
```

This checks:

- what already exists
- what overlaps
- what should be reused
- what sleeping assets may already solve the job
- where the new source could fill a real capability gap

### 2. Govern the Source Before Extracting

Use the Extraction Governor to decide what the source should become.

```text
/extraction-governor-agent [YouTube/book/transcript/article/expert]
```

The Governor decides whether the source should become:

- reference only
- light `/extract`
- full `/extract-forge`
- `/extract-amplify` on an existing skill
- companion skill
- workflow pack
- operator-agent capability
- client-facing offer asset
- content/media system

### 3. Run the Right Extraction Path

For source direction before building:

```text
/extract-vision [source/expert]
```

For normal useful sources:

```text
/extract [source]
```

For rich, high-leverage sources:

```text
/extract-forge [source]
```

For going deeper on something already extracted:

```text
/extract-amplify [expert/skill]
```

For multiple sources:

```text
/parallel-extract [sources]
```

### 4. Turn Extraction Into Deployment

After extraction, do not stop at the skill/workflow build.

Run:

```text
/orchestrate what are the highest leverage uses for this extraction?
```

This routes the new capability into:

- content
- offers
- client delivery
- copywriting
- positioning
- agent capability
- workflows
- productized service
- research asset

### 5. Quality Gate It

Before trusting the new asset:

```text
/excellence-gate
```

If it is client-facing, factual, revenue-critical, publishable, or strategic:

```text
/red-team-agent
/ground-truth-agent
```

This prevents the extraction from becoming polished but shallow.

### 6. Register and Compile

After building skill/workflow assets:

```text
/compile-knowledge
/knowledge-librarian extraction
```

This keeps the library usable instead of just bigger.

### 7. Evolve if It Underperforms

If the extraction creates useful but good-not-great workflows:

```text
/evolution-agent this extraction is useful but not producing remarkable outputs yet
```

Use this when:

- the workflow feels generic
- outputs plateau at "pretty good"
- the skill lacks deployment power
- the expert method is captured but not embodied
- the extraction is useful but not commercially or creatively sharp yet

## Quick Decision Guide

| Situation | Use |
|-----------|-----|
| You are unsure whether a source is worth extracting | `/extraction-governor-agent` |
| You want strategic direction before building | `/extract-vision` |
| The source is useful but not massive | `/extract` |
| The source is rich, central, and reusable | `/extract-forge` |
| You already extracted it but want more | `/extract-amplify` |
| You have several sources ready | `/parallel-extract` |
| You want to turn the extraction into business value | `/orchestrate` |
| You want to prevent shallow/generic output | `/excellence-gate` |
| It is client-facing or high stakes | `/red-team-agent` |
| It needs expert-standard calibration | `/ground-truth-agent` |
| It underperforms after use | `/evolution-agent` |

## Muscle Memory

When you find a source you want to extract, use:

```text
/knowledge-librarian extraction
/extraction-governor-agent [source]
```

When you finish an extraction, use:

```text
/orchestrate what should this become now?
/excellence-gate
/compile-knowledge
```

When it feels good but not remarkable, use:

```text
/evolution-agent
```

## Final Rule

Extraction is no longer the end product.

Extraction is how you manufacture new capability.

The capability only counts when it can be deployed into:

- better content
- better offers
- better client delivery
- better research
- better writing
- better copy
- better strategy
- better workflows
- better agents
- better proof
