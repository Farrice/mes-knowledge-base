# Strategy Anchor: Vibe Tax Brief Deployment OS

Created: 2026-05-11  
Mission: vibe-tax-brief-deployment-os

## Target Problem

The Vibe Tax package is strong, but deployment would degrade if the next session had to reconstruct the package, guess which expert lanes actually ran, or manually connect diagnosis, research, Farrice voice, LinkedIn drafting, and copy gates.

## Guiding Bet

Build a compact deployment wrapper, not a new system. `/vibe-tax-deploy` should extend `/vibe-tax-brief` and `/farrice-content-os` so Farrice can talk into one front door and receive daily deployment outputs without losing research proof, voice, or quality discipline.

## Audience

- Farrice as the daily operator.
- Future Codex sessions that need a clean startup packet.
- Prospects who encounter Vibe Tax posts, diagnostics, proof demos, or outreach.

## Key Proof Signals

- The command menu surfaces `/vibe-tax-deploy`.
- A fresh session can start from `BOOTSTRAP-PROMPT.md`.
- First LinkedIn draft includes voice evidence, research anchors, diagnostic mechanism, and Copy Gate Result.
- No external action happens without approval.

## Library Decision

Extend existing assets:

- `/vibe-tax-brief` remains the diagnostic spine.
- `/farrice-content-os` remains the content and voice engine.
- `/publishable-copy-gate` remains the final public-copy gate.

Do not create a second AI Content OS.

Relevant reusable solutions:

- `docs/solutions/routing-governor-self-compounding-workspace.md` - apply route-governor logic so the new wrapper prevents generic route selection.
- `docs/solutions/copy-gate-score-calibration.md` - apply score discipline for launch copy.
- `docs/solutions/high-taste-writing-os.md` - adapt as the quality layer before copy gate.
