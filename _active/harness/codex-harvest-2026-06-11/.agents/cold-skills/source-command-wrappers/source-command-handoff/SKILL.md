# source-command-handoff

Use this skill when the user invokes `/handoff`, asks for a handoff document,
wants to continue one slice of work in another session, or needs a fresh agent,
prototype branch, research lane, or tool to pick up focused context without
ending the parent session.

## Command Template

Read and execute the workflow at `.agent/workflows/handoff.md` - focused
transfer handoff with purpose, load-first paths, current state, suggested
skills/workflows, exact next prompt, acceptance criteria, and risk notes.
