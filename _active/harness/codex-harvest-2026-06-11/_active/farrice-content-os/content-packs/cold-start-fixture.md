# Cold-Start Fixture

This fixture proves the OS can start from one raw Farrice concept plus one brandjack seed without pretending research has already happened.

## Raw Farrice Concept

Generic AI content is not a writing problem first. It is usually a missing operating system: no voice context, no source material, no research, no taste gate, no hook room, and no one composer holding the final voice.

## Brandjack Seed

Entity/Event: current AI platform or product move.

Status: needs `research --brandjack` before any factual claim or named entity can be used.

## Required Next Moves

1. Run context lock from `context-index.md`.
2. Run brandjack research and update `research-ledger.md`.
3. Generate 10 hooks in `hook-lab.md`.
4. Draft body-first.
5. Run writers' room, high-taste, anti-slop, and publishable-copy gates.
