# Implementation Runbook

## Mission

Install a private 14-day Ready Buyer Engine pilot for Jen/Jiing without external publishing, CRM changes, paid ads, or live automation until approval.

## Day 0 Inputs

Collect:

- preferred market scope
- one listing or buyer scenario
- one seller proof story
- current lead sources
- current CRM or tracking method
- current weekly availability
- protected JJ/family windows
- lender partner
- title partner
- broker/compliance contact
- transaction/team support roles

## Days 1-2: Calibration

Outputs:

- confirm positioning
- confirm voice rules
- confirm deal math assumptions
- confirm protected calendar
- mark claims requiring lender/broker review

Do not:

- publish
- automate
- change profile
- contact leads through the new workflow

## Days 3-5: Cockpit Demo

Build:

- three sample lead cards
- one listing-to-leads transformation
- score routes
- next-best-action copy
- team handoff rules

Review with Jen:

- Does every card make sense?
- Would she trust the route?
- Does the reply sound like her?
- Which task should Jen never personally handle?

## Days 6-8: Content And DM System

Build:

- 12 priority content assets from the 30-day war room
- first lead magnet outline for `READY`
- DM keyword reply drafts
- manual intake sheet
- nurture paths

Priority assets:

1. Start Here Reel
2. $850K Reality Check carousel
3. Would I Let My Friend Buy This? Reel
4. Offer Room Reel
5. Valley Match Map carousel
6. Seller Trust File story stack

## Days 9-10: Review Gate

Review:

- finance examples with lender
- buyer-agreement language with broker
- program claims against current availability
- Fair Housing language
- AI/privacy boundaries

Any unresolved issue becomes "internal only" until fixed.

## Days 11-12: Rehearsal

Run one fake-safe end-to-end scenario:

```text
Instagram comment -> DM reply -> intake questions -> score -> route -> consult/nurture -> dashboard update -> proof note
```

Pass condition:

- Jen understands the flow
- team owner is clear
- no risky language appears
- no low-score lead gets high-touch treatment
- dashboard captures the result

## Days 13-14: Decision

Choose one:

| Decision | Meaning |
|---|---|
| Keep private | Continue refining before public launch. |
| Launch manually | Publish approved posts and run DM flow manually. |
| Automate lightly | Connect approved keyword delivery only. |
| Expand team | Package as MyHouseSellers proof case. |
| Narrow | Focus only on buyer, seller, or profile first. |

## Weekly Operating Rhythm After Pilot

| Day | Main Job |
|---|---|
| Monday | hot lead review and weekly conversion target |
| Tuesday | buyer/seller consult window |
| Wednesday | content/proof batch |
| Thursday | consult window and partner follow-up |
| Friday | dashboard and proof review |
| Saturday | A-leads or active clients only |
| Sunday | 20-minute family/calendar protection check |

## Launch Gates

Do not launch until:

- Jen approves voice
- lender approves payment/program examples
- broker approves buyer-agreement and compliance-sensitive language
- dashboard owner is assigned
- manual fallback exists for every automation
- proof capture is ready

## Expansion Gate

Only pitch this to MyHouseSellers or another agent after there is proof of:

- reduced manual chasing
- better lead scoring
- booked qualified consults
- content-to-DM path
- at least one seller proof asset
- Jen willingness to be the proof case
