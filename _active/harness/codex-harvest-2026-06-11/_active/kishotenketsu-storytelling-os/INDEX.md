# Kishotenketsu Storytelling OS

## Purpose

This package turns Lucas Alpay's video `The 3-Act Structure is Killing Your Novel` into a source-backed storytelling layer for fiction, social media, content, ads, media, creative strategy, branding, marketing, messaging, positioning, copywriting, ghostwriting, product/service/concept narrative work, and general writing.

It is intentionally both:

- a Lucas-specific companion expansion, so the source's nuance is not flattened into a generic story template
- a cross-domain writing OS, so contrast, texture, process, perspective shift, and integration can improve future Antigravity writing runs across concepts, products, brands, services, campaigns, posts, pages, scripts, pitches, and essays

## Use Now

Use `skills/lucas-alpay-storytelling/workflows/kishotenketsu-contrast-story-system.md` when a draft, strategy, campaign, ad, media script, positioning note, concept, brand page, service description, or product story feels like it is forcing a villain, fake stakes, rage-bait, or problem-agitation onto material that needs atmosphere, world, process, contrast, perspective shift, or lingering integration.

Use `/source-to-skill-system` when harvesting another source into a similar capability.

Use `docs/solutions/high-taste-writing-os.md` when the issue is a draft that is structurally correct but not alive, textured, or compelling.

Use `08-client-facing-service-package.md` when packaging this method for clients, paid diagnostic sprints, campaign/story audits, brand narrative work, positioning rewrites, ghostwriting upgrades, or product/service narrative offers.

## Completion Standard

This package is not complete because it explains Kishotenketsu. It is complete only when it can transform weak writing and show the behavior change: more specific texture, stronger contrast, process-as-plot, meaningful perspective shift, and integration that changes interpretation or action.
