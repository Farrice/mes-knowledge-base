# Sam Parr Copywriting Operating Model

## Core Thesis

Copy is not word polish. Copy is reader movement.

The system starts with the behavior the copy must create, then builds the sequence that moves the reader from attention to interest, desire, proof, objection relief, and action. The words are the visible surface. The real work is state change.

## The Five-Part Movement

| Stage | Reader State | Copy Job | Sam Mechanic |
|---|---|---|---|
| Attention | The reader notices something worth stopping for. | Create a punch, gap, proof object, or familiar turn. | Headline gravity, phrase twist, familiar energy. |
| Interest | The reader wants the next line. | Make continuation feel easier than leaving. | Curiosity gap, slippery slope, rhythm. |
| Desire | The reader wants the outcome before the offer is explained. | Use story, contrast, and stakes. | Story-led desire, long-is-not-bad, punch then pull. |
| Belief | The reader trusts the claim enough to keep going. | Make proof concrete and visible. | Proof-first ad, visual proof translation. |
| Action | The reader sees a believable next step. | Remove private doubt and make the action feel natural. | Objection by detail, price desire, CTA fit. |

## Behavior Before Words

Every Sam Parr pass starts with an Action Lock:

```text
The reader should [do action] because they now believe [belief] and feel [desire].
```

If that sentence is vague, the copy will drift into cleverness. If it is clear, the system can choose the right mechanic.

## The Copy Rescue Loop

1. **Name the desired action.**
2. **Mark the reader-state gap.**
3. **Pick one to three mechanics.**
4. **Rewrite the affected section only.**
5. **Show the before/after delta.**
6. **State what changed behaviorally.**
7. **Send public or revenue copy to `/publishable-copy-gate`.**

## Failure Classes

| Failure | Symptom | Repair |
|---|---|---|
| Label opener | First line names the topic but does not create pull. | Run headline gravity lab. |
| Empty curiosity | The hook withholds information without a real payoff. | Add proof-backed gap and payoff line. |
| Naked claim | The copy asks for belief without evidence nearby. | Build a proof object. |
| Product too early | The offer appears before the reader wants the result. | Run story desire pass. |
| Flat rhythm | Sentences are correct but inert. | Run rhythm and slippery-slope pass. |
| Defensive objection handling | The copy debates the reader. | Answer through detail, test, or anecdote. |
| Imported humor | The joke sounds like a costume. | Run humor fit check or remove it. |

## Composition Rule

Sam Parr Copywriting OS supplies direct-response mechanics. It does not own final voice, final conversion architecture, or final publishability.

| Function | Owner |
|---|---|
| Final conversion copy | `/copywriting-agent` |
| Direct-response mechanics | `/sam-parr-copywriting-mechanics` |
| Taste and composition | `/high-taste-writing-os` |
| Public/revenue gate | `/publishable-copy-gate` |
| Farrice content integration | `/farrice-content-os` |

## Definition Of Done

A run is complete only when it produces a changed section and explains the behavioral delta:

- stronger pull,
- clearer proof,
- more believable desire,
- lower objection pressure,
- better rhythm,
- or a concrete copywork practice loop.
