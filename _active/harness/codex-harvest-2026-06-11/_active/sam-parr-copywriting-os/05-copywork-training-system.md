# Sam Parr Copywork Training System

## Purpose

Copywork is the practice layer. It turns a source extraction from "interesting concepts" into better instincts.

The goal is not to copy style. The goal is to feel structure, pacing, proof placement, transitions, and payoff through manual repetition.

Evidence anchors: `00:27:40`, `00:29:05`, `00:31:20`, `00:45:15`.

## Copy-Hour Sprint

Use this when the writer keeps producing correct but flat copy.

| Minute | Action | Output |
|---|---|---|
| 0-5 | Choose one format and one exemplar. | Format lock and exemplar path. |
| 5-25 | Manually copy the exemplar. | Hand-copied texture pass. |
| 25-35 | Mark the mechanics. | Opener, gap, proof, story, rhythm, objection, action. |
| 35-45 | Extract five rules. | Rule bank. |
| 45-55 | Rewrite current asset using only those rules. | New draft section. |
| 55-60 | Write texture note. | What became visible through copying. |

## Daily Drill

Run one 15-minute rep:

1. Copy one strong opener by hand.
2. Mark the first proof object.
3. Rewrite a weak opener with the same structure.
4. Name one rule learned.

## Weekly Drill

Run one 60-minute rep:

1. Pick one target format.
2. Copy one full exemplar.
3. Extract mechanics.
4. Rewrite one real asset.
5. Compare before and after.
6. Add the best rule to the skill's rule bank.

## Quality Bar

Copywork passes only if it produces a rule and an applied rewrite. If the output only says the draft was "inspired by" the exemplar, it fails.
