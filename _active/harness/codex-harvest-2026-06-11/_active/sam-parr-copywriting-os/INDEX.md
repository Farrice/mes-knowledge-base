# Sam Parr Copywriting Companion OS

## Purpose

This is the canonical local Companion OS for Sam Parr's copywriting mechanics from the Sweat Equity video:

- Source URL: `https://www.youtube.com/watch?v=uf4fR3qcDkU&t=151s`
- Local evidence package: `extractions/video-context/uf4fR3qcDkU/`
- Evidence limit: transcript-backed spoken evidence only. Frame extraction and OCR were skipped.

Use this Companion OS when copy needs direct-response gravity: stronger headlines, sharper curiosity gaps, proof-first ads, better rhythm, more useful stories, objection handling, humor that fits the brand, or a copywork practice loop.

The first build created a valid doorway. This repair builds the room: source map, operating model, ad rescue protocols, copywork training, before/after proof lab, expert enhancement map, and a future-extraction regression guard.

## Invocation

Use the command-grade workflow:

```text
/sam-parr-copywriting-mechanics [draft, ad, script, post, page, offer, or copy goal]
```

For public, client-facing, or revenue copy, this layer never replaces the normal gates. Run it before:

```text
/high-taste-writing-os
/publishable-copy-gate
```

## Deployment Policy

- Cold deployment lives under `.agents/cold-skills/source-command-wrappers/`.
- Hot deployment is allowed only after the proof lab and live-surface validators pass.
- The hot command is bounded to direct-response mechanics. It is not a general Sam Parr persona.

## Integration Policy

- Keep the existing `sam-parr-taste-acquisition` skill intact.
- Use this as a project-local Companion OS layer, not a duplicate Sam mega-skill.
- Load this layer only when the copy needs headline, proof, curiosity, copywork, rhythm, or direct-response mechanics.
- Do not claim visual evidence from the video unless a future frame/OCR pass is completed.
- Do not let Sam Parr mechanics replace `/copywriting-agent`, `/high-taste-writing-os`, or `/publishable-copy-gate`.

## Quality Bar

A Sam Parr pass is only useful if it changes the copy in at least one observable way:

- the first line creates a stronger reader pull,
- the proof is more visible,
- the story carries more of the desire,
- objections are answered inside the copy,
- rhythm improves scan and momentum,
- or the next copywork practice step is concrete enough to run today.

## Acceptance Standard

The command is incomplete if it cannot take weak copy and return:

- named weak-link diagnosis,
- source-backed mechanics used,
- rewritten copy,
- before/after delta,
- proof object or proof-gap note,
- reader-behavior explanation,
- publishable-copy next gate,
- route and command verification.
