# Setup Checklist - AI Content Misfire Audit + 48-Hour Fix

> **Critical path**: checkout -> intake -> calendar -> sales page -> tracker -> first 10 asks.
> **External actions**: do not send, publish, charge, or modify live accounts without explicit approval.

## Phase 1 - Checkout

- [ ] Create product: **AI Content Misfire Audit + 48-Hour Fix**.
- [ ] Price: **$250 founding diagnostic**.
- [ ] Description: "Profile, offer, recent content, and AI-draft audit with a 48-hour workflow fix."
- [ ] Optional second product: **48-Hour Implementation Sprint** at **$750**.
- [ ] Redirect buyer to intake form after payment.
- [ ] Save checkout URLs in `links.md`.

## Phase 2 - Intake

- [ ] Build the 10 questions from `intake-form.md`.
- [ ] Require profile, offer, recent posts, and contact method.
- [ ] Make AI drafts and strong voice samples optional but strongly recommended.
- [ ] Test submission.
- [ ] Save form URL in `links.md`.

## Phase 3 - Booking

- [ ] Create 30-minute clarification call event if live review is needed.
- [ ] Keep async delivery as default when samples are complete.
- [ ] Add reminder: "Send one strong piece and one AI/content draft that did not work."
- [ ] Save booking URL in `links.md`.

## Phase 4 - Sales Page

- [ ] Publish `sales-page.md` as a simple viewable doc/page.
- [ ] Replace `[Stripe link]`.
- [ ] Test every link.
- [ ] Do not add screenshots, testimonials, or quantified claims until real proof exists.

## Phase 5 - Prospect Board

- [ ] Fill `prospect-shortlist.md` with 20 prospects.
- [ ] Score every prospect using `prospect-scorecard.md`.
- [ ] Contact only prospects scoring 13+.
- [ ] Prepare 3 mini-audit examples before broad outreach.

## Phase 6 - First 72 Hours

| Window | Action |
|---|---|
| Hour 0-2 | Checkout, intake, links, tracker ready |
| Hour 2-4 | Score first 20 prospects |
| Hour 4-8 | Build 3 mini-audit examples |
| Day 1 | Send first 10 direct asks |
| Day 2 | Follow up, publish one post, send second 10 |
| Day 3 | Push warm replies to checkout or call |

## Stop Conditions

- Do not send outreach until checkout/intake links work.
- Stop if 5 prospects ask "what is this?" and rewrite the opener.
- Stop if prospects think this is ghostwriting or a prompt pack.
- Stop if the first paid client needs a completely different deliverable.

## Success Signals

- 1 paid diagnostic
- 1 serious sales conversation
- 1 checkout request
- 3+ prospects repeat the pain in their own words
- 1 usable proof asset from a mini-audit or client delivery
