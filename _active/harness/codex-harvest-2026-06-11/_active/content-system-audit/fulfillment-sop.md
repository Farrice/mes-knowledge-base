# Fulfillment SOP - AI Content Misfire Audit + 48-Hour Fix

> **Delivery window**: 48 hours from complete intake.
> **Scope**: diagnostic + workflow fix, not ongoing ghostwriting or a full brand strategy.

## Inputs Required

- profile or main public page
- offer or service description
- 3-5 posts, drafts, or raw ideas
- 1-2 weak AI/content drafts if available
- 1-2 strong voice samples if available
- desired next action from readers

If inputs are incomplete, ask one clarification question before starting.

## 48-Hour Delivery Flow

### Hour 0-2 - Intake Triage

- Confirm buyer, offer, audience, and next action.
- Identify missing material.
- Decide whether this is content-to-client flow, AI voice flattening, or offer clarity.
- If the real issue is outside scope, state that before fulfilling.

### Hour 2-8 - Leak Diagnosis

Review:

- profile promise
- offer clarity
- recent content
- AI drafts or weak drafts
- strongest voice samples
- current CTA/reply path

Capture the top 3 leaks:

1. trust leak
2. voice/AI leak
3. buyer-pathway leak

### Hour 8-16 - Buyer-Pathway Map

Map:

- what the right reader already believes
- what they need to realize
- what proof would make the expert credible
- what question or ask should move them into conversation

### Hour 16-28 - Rewrites And Angles

Create:

- 3 post angles or rewrites
- 1 direct CTA/reply path
- optional "do not use" language list if AI is flattening the voice

### Hour 28-40 - Workflow Build

Build the simple repeatable process:

1. raw idea capture
2. buyer-pathway question
3. voice guardrails
4. AI drafting prompt
5. recognizability edit
6. CTA check

### Hour 40-48 - Handoff And Upsell Trigger

Deliver:

- diagnosis
- buyer-pathway map
- voice/AI notes
- 3 angles
- workflow
- next 7-day action

If they need deeper setup, offer the $750 implementation sprint:

```text
The audit shows the workflow clearly enough to fix. If you want me to install this into your ChatGPT/Claude/Notion setup and turn it into reusable templates, that is the 48-hour implementation sprint at $750. I can credit the diagnostic fee if you start within 7 days.
```

## Quality Bar

The client should leave with:

- one sentence describing the misfire
- three usable angles
- one workflow they can run without you
- a clearer CTA/reply path
- proof of what changed between before and after

## Scope Guard

If the client asks for full strategy, content calendar, profile rewrite, or ghostwriting, say:

```text
That is outside this diagnostic. The audit tells us what should be fixed first. If you want me to install the system or build the templates, that is the implementation sprint.
```
