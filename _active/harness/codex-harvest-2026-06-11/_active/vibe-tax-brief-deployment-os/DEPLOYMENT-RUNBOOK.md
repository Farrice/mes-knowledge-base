# Vibe Tax Deployment Runbook

## Daily Loop

Use when Farrice has 1-4 hours.

| Block | Time | Job | Output |
|---|---:|---|---|
| Market scan | 30 min | Look for buyer pain, proof gaps, AI/content distrust, weak positioning language | 3 raw signals |
| Deployment | 60 min | Draft one post, one diagnostic angle, or one manual ask | 1 public or direct asset |
| Proof block | 60-120 min | Build a sample brief, diagnostic, or teardown | 1 proof artifact |
| Closeout | 15 min | Record what shipped, what got replies, what needs revision | tracker entry |

## Command Order

For public content:

```text
/vibe-tax-deploy post -> Hook Room -> high-taste pass -> anti-slop audit -> /publishable-copy-gate
```

For a proof demo:

```text
/vibe-tax-deploy brief-demo -> /research-intelligence-agent -> /vibe-tax-brief -> proof gaps -> sales openers
```

For manual outreach:

```text
/vibe-tax-deploy outreach -> prospect scorecard -> give-first line -> soft ask -> copy gate
```

## What To Feed The System

Useful input:

- raw thought or voice memo
- prospect website or offer summary
- LinkedIn draft
- buyer niche
- competitor/content examples
- rough service idea
- proof sample
- objections or replies

Bad input:

- "make this viral" with no buyer or point of view
- vague AI consulting claims
- unsourced stats for public copy
- requests to automate DMs or engagement

## Done Definition

An output is deployment-ready only when it includes:

- reader and buyer state
- Vibe Tax mechanism
- Farrice voice evidence
- research anchors or unavailable-state notes
- clear CTA
- Copy Gate Result for public/revenue copy
- draft-only status unless Farrice approves external action
