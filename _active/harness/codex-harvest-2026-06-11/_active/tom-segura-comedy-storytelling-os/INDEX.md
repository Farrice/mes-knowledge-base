# Tom Segura Comedy Storytelling OS

## Purpose

This package turns the Tom Segura `How I Write` interview into a source-backed comedy and storytelling layer for social posts, marketing copy, general writing, and Antigravity writing workflows.

It is intentionally both:

- a Tom-specific deep extraction, so his nuance is not flattened into a generic humor checklist
- a companion expansion to the existing comedy lane, so it enriches Robert Mack, `/comedy`, Sam Parr copy mechanics, and publishable copy gates instead of competing with them

## Use Now

Use `skills/tom-segura-comedy-storytelling/SKILL.md` when a draft needs observational humor, story compression, a better reason for telling, stronger word choices, or a diagnosis of why a comedic attempt feels flat.

Use `/comedy` when the task is a fast humor pass and this Tom layer should be a supporting lens under the existing comedy front door.

Use `sam-parr-copywriting-mechanics` when the humor must serve proof, trust, buyer action, or conversion.

## Completion Standard

This package is not complete because it has notes. It is complete only when it can transform a weak draft and explain the behavior change with source mechanics, a proof gap, and the next gate.
