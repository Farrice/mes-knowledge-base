# Cold-Start Fixture

## Scenario

A solo founder runs a premium service business. They have real client outcomes but no consistent marketing operating system.

## Business Snapshot

| Field | Fixture Value |
|---|---|
| Business type | B2B operations consultant |
| Offer | 2-week workflow cleanup sprint for founder-led service businesses |
| Sales goal | 3 qualified calls in the next 30 days |
| Current lead sources | Warm referrals, occasional LinkedIn posts, past clients |
| Referral status | No formal referral ask, no timing, no incentive |
| Proof assets | 2 testimonials, 1 rough case study, scattered Slack/client notes |
| Email/CRM state | No nurture sequence, no follow-up templates, contacts in a spreadsheet |
| Public/supplied assets | Basic website, LinkedIn profile, one PDF overview |
| Available time | 25 hours per week for marketing |
| Budget | $500 for tools or contractors; no paid ads yet |
| AI/tool access | ChatGPT/Claude, Google Docs, simple CRM or spreadsheet |
| Delivery constraints | Founder still has client work; cannot add meetings or daily content production |

## Baseline Weaknesses

- Marketing depends on memory and mood.
- Referral ask is absent even though past clients are warm.
- Proof exists but is not converted into sales collateral.
- Website does not answer the real buyer objections.
- Email follow-up is manual and inconsistent.
- Organic content is not connected to offers or proof.

## Expected Template Output

The template should produce:

- fit verdict: good fit for solo AI service-business OS
- referral fix: ask past clients after outcome recap, with clear language and optional thank-you
- message board: 5-7 buyer questions from objections, proof, and service outcomes
- AI copy-machine brief: offer, buyer, proof, voice, objections, banned generic phrases
- compressed weekly calendar for 25 hours
- first 7-day sprint with no more than 3 measurable outcomes
- client-facing operating handoff
- proof/upsell path into a 48-72 hour diagnostic or implementation sprint
