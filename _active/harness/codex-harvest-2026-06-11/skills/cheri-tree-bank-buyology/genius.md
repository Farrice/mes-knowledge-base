# Cheri Tree B.A.N.K. Buyology - Genius Context

## Core Genius

Cheri Tree's method turns selling from a single-script guessing game into buyer-code translation. A prospect does not buy because the seller explained harder. The prospect buys when the offer is presented in the sequence, evidence, emotional frame, and risk profile that matches the prospect's dominant buying values.

The system is built on four buying codes:

- **Blueprint**: buys safety, order, proof, process, budget control, and risk reduction.
- **Action**: buys speed, status, opportunity, excitement, freedom, and winning.
- **Nurturing**: buys trust, care, purpose, belonging, ethics, and human connection.
- **Knowledge**: buys logic, data, accuracy, expertise, due diligence, and certainty.

## Genius Patterns

1. **Code Before Pitch**: Do not present until the buyer's dominant value order is known or strongly inferred.
2. **Values Beat Demographics**: Age, income, title, and industry are secondary. Buying behavior follows value hierarchy.
3. **One Offer, Four Doorways**: The same offer can be entered through risk reduction, status gain, mission fit, or logical certainty.
4. **Sequence Creates Meaning**: In Power Scripting, the same proof points feel different depending on whether credibility, emotion, or logic comes first.
5. **Objection as Code Mismatch**: Many objections signal that the seller used the wrong code language, not that the offer is weak.
6. **Ask When Possible, Infer When Necessary**: Direct card sorting or intake is strongest. Forensic coding is the backup when direct coding is impossible.
7. **Segment the Funnel, Not Just the List**: B.A.N.K. data should change landing pages, opt-ins, emails, calls, CRM tags, and proof assets.
8. **Weakest Code Becomes Blind Spot**: The seller's lowest code often causes the most lost sales because those buyers feel unseen.
9. **Closeable Sales Need Translation**: The method does not force bad fit. It improves odds when a sale is closeable and the buyer's values are honored.
10. **Human Motive Under Business Action**: Every B.A.N.K. asset must connect business outcomes to the buyer's deeper motive: safety, victory, love, or rightness.

## Signature Moves

- **Sort the Values**: Present the four value sets and have the person rank them from most to least like them.
- **Spot the First Clue**: Punctuality, flash, warmth, or data hunger often reveals the dominant code before the pitch begins.
- **Translate the Same Claim Four Ways**: Reframe one value proposition for B, A, N, and K before deploying it.
- **Pre-Load the Missing Proof**: Send documentation to K, risk safeguards to B, social proof/status cues to A, and mission/community proof to N.
- **BANKify the System**: Store code in the CRM and let it drive routing, emails, sales prep, and follow-up.

## Quality Rubric

| Criterion | Acceptable | Strong | Master-Level |
|---|---|---|---|
| Code accuracy | Names a likely code | Gives evidence and confidence | Separates dominant, secondary, and uncertainty with next test |
| Asset translation | Changes surface wording | Changes proof, CTA, and objections | Rebuilds the whole buyer path around code priorities |
| Practical output | Gives ideas | Produces deployable copy/assets | Produces a complete field-ready kit with tests and next actions |
| Ethical use | Avoids crude manipulation | Frames as service and fit | Protects buyer autonomy while increasing relevance |
| Multi-code handling | Picks one code | Handles primary and secondary | Creates segmented variants and routing rules |
| Evidence discipline | Makes broad claims | Grounds claims in observable cues | Shows cue, inference, counter-signal, and confidence |
| Entrepreneur fit | Generic sales advice | Maps to offer and audience | Maps to funnel, CRM, social, sales, and campaign calendar |

## Anti-Patterns

- Treating B.A.N.K. as a horoscope or fixed identity.
- Using one code label with no evidence.
- Writing four variants that only swap adjectives.
- Selling Action-style hype to Knowledge buyers.
- Selling Knowledge-style data dumps to Action buyers.
- Making Nurturing buyers feel manipulated or rushed.
- Making Blueprint buyers feel surprised, rushed, or exposed to risk.
- Using code diagnosis to pressure people instead of serving their decision criteria.

## Operating Standard

Every workflow must produce finished business assets. Do not explain B.A.N.K. unless the user asks for teaching. Ask for missing business context only when required; otherwise proceed with explicit assumptions and mark them.
