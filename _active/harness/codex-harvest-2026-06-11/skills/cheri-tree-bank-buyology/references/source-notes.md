# Source Notes

Source: *Why They Buy* by Cheri Tree, PDF supplied by Farrice Cain.

Extraction target: build a reusable B.A.N.K. OS for entrepreneur use, not a summary of the book.

Core captured areas:

- The four B.A.N.K. types: Blueprint, Action, Nurturing, Knowledge.
- Values, motives, clues, likes, dislikes, buying triggers, and sales behaviors for each code.
- Direct code collection through value-card ranking.
- Forensic coding through observable behavior, social profiles, written copy, and conversation signals.
- Power Scripting using credibility, emotion, and logic in a code-specific sequence.
- BANKification of funnels, websites, campaigns, email, CRM, events, networking, and sales calls.
- Exercises that turn the method into practice: memorizing values, identifying five communication moves per type, and altering scripts through code.

Use only short calibration excerpts if needed. Most outputs should be transformed methodology, original business assets, and operational prompts.
