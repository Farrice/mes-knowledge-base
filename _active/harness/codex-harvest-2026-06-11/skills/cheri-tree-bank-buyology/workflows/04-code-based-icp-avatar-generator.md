# Code-Based ICP and Avatar Generator

## Pre-Flight Gate

Load `../genius.md`, `../references/bank-code-field-guide.md`, and `../references/bank-deployment-map.md`. Build usable business profiles, not fictional character sketches.

## Input Required

- Offer, price point, promise, market, and current buyers
- Desired channel or campaign
- Known buyer data, testimonials, objections, or sales notes

## Execution

1. Identify which B.A.N.K. codes are most likely to buy and why.
2. Produce one ICP per relevant code.
3. Create avatars with buying motive, pain language, proof needs, objections, and conversion path.
4. Define what to say, what to show, and what to avoid for each code.
5. Recommend the first segment to target based on speed to revenue and fit.

## Output Requirements

- **Code Distribution Hypothesis**: likely buyer mix.
- **ICP Table**: code, buyer context, trigger, proof, offer fit.
- **Avatar Profiles**: four concise but useful avatars.
- **Message Angles**: 3 per code.
- **Objections and Counters**: code-specific.
- **Priority Segment**: where to start and why.

## Quality Gate

Reject generic avatars. Each avatar must change the offer framing, proof, CTA, and follow-up path.
