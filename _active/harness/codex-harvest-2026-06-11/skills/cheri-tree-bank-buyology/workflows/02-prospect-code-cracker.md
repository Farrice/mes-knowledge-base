# Prospect Code Cracker

## Pre-Flight Gate

Load `../genius.md` and `../references/bank-code-field-guide.md`. Separate evidence from inference. If confidence is below 70%, produce a test plan.

## Input Required

- Prospect name or segment
- Observable clues: punctuality, dress, pace, wording, questions, objections, content, buying behavior
- Offer being sold
- Sales context and desired next step

## Execution

1. Extract all code clues from the provided material.
2. Map each clue to B, A, N, or K.
3. Identify primary and secondary code with confidence.
4. Name the top risk if the code is wrong.
5. Produce the sales approach, proof stack, CTA, and next test.

## Output Requirements

- **Likely Code**: primary/secondary, confidence, uncertainty.
- **Evidence Map**: clue -> code -> interpretation.
- **How to Open**: first 90 seconds of conversation.
- **What to Emphasize**: proof, promise, risk, speed, mission, data.
- **What to Avoid**: code-specific turnoffs.
- **Next Test**: one question or asset that confirms the code.

## Quality Gate

Do not overclaim. If the evidence conflicts, show the conflict and create B/A/N/K-safe messaging.
