# Social Content Generator by Code

## Pre-Flight Gate

Load `../genius.md` and `../references/bank-deployment-map.md`. Social content should attract or reveal code, not merely mention code.

## Input Required

- Topic, offer, platform, audience
- Desired buyer code or all four codes
- Format: short post, carousel, thread, script, newsletter, ad, or content calendar

## Execution

1. Translate the topic into B/A/N/K buyer angles.
2. Generate hooks for each code.
3. Produce finished posts in the requested format.
4. Add CTA and comment/DM prompt that reveals code priority.
5. Recommend reuse into lead magnet, email, or landing page.

## Output Requirements

- **Angle Map**: B/A/N/K framing.
- **Hooks**: 5-10 code-aware hooks.
- **Finished Content**: ready-to-post copy.
- **CTA**: code-revealing or conversion-focused.
- **Repurpose Notes**: next asset to create.

## Quality Gate

Avoid shallow swaps like "safe" for Blueprint or "fast" for Action. Each post must change emotional logic and proof.
