# Satori Graphics — Design Mastery Genius File

> Load this file before executing any Satori Graphics workflow. It carries the decision engine behind the workflows.

## Expert Identity
Satori Graphics / Tom Satori is a graphic design educator focused on the professional thinking behind layout, composition, logo design, and AI-era visual communication. His methodology separates amateur work from professional work by asking whether the design actually communicates, guides attention, and leaves the intended emotional residue.

## Core Philosophy
Graphic design is visual communication. A design is not successful because it looks polished; it is successful when the viewer understands the message, feels the intended emotional state, remembers the concept, and can follow the composition without confusion.

## Central Thesis
AI can generate clean visual output. Human designers earn their value by adding intention: meaning before aesthetics, psychological eye control, controlled imperfection, predictive empathy, and memory-encoding concepts.

## The Satori Decision Stack
1. **Message**: What is this design trying to say?
2. **Reason**: Why does each element exist?
3. **Emotion**: What should the viewer feel after contact?
4. **Eye Path**: Where should the viewer look first, next, and last?
5. **Memory**: What visual idea will remain after the scroll?
6. **Transferability**: Does the visual language survive other formats?

## Genius Patterns

### Why Before What
Meaning comes before aesthetics. If a shape, texture, motif, color, or effect does not serve message, emotion, hierarchy, or memory, it gets removed.

### Controlled Human Imperfection
Perfectly aligned, symmetrical AI layouts often feel default. A professional adds purposeful overlap, asymmetry, tension, texture, or imbalance to make the layout feel crafted.

### Predictive Empathy
Do not design only for immediate attention. Design for the emotional state the viewer carries away: reassured, provoked, trusted, energized, calm, curious, or unsettled.

### Memory Encoding
Strong design gives the brain something to resolve: a metaphor, absence, substitution, contradiction, or slightly unresolved visual question.

### LIFT Layout System
- **Leverage Point**: The single dominant thing the viewer must see first.
- **Internal Rhythm**: The visual pacing from first point to secondary information.
- **Friction and Flow**: Purposeful tension balanced with navigable clarity.
- **Transferability**: The design remains recognizable and readable across formats.

### Logo As Memory Hook
A logo is one anchor in a larger brand system. It should not try to say everything. It should focus on one clear idea, be easy to recognize, and use shape psychology aligned with the target audience.

## Signature Moves
- Ask “What is this saying?” before judging polish.
- Evict every element that cannot justify its role.
- Start AI refinement from clean output, then add human-directed intent.
- Use grids to establish order, then break them deliberately for impact.
- Control visual rhythm with spacing, grouping, contrast, and purposeful disruption.
- Flip the design upside down to inspect structure without reading content.
- Compress a logo brief into one plain sentence before sketching.
- Use verbs such as protect, connect, accelerate, simplify, guide before nouns such as shield, arrow, mountain, or initials.
- Present every logo concept in the same structure to remove client presentation bias.

## Anti-Patterns
- Good-looking work that says nothing.
- Decoration used as a substitute for concept.
- AI outputs accepted as final because they look clean.
- More layers, effects, or details treated as better design.
- Multiple focal points competing without hierarchy.
- Grid breaking before grid discipline is established.
- Logo concepts trying to explain the entire business.
- Fast production used to avoid thinking.

## Quality Gate
Before any output is final, answer:
- Can the message be stated clearly?
- Does every element pay rent?
- Is there one dominant leverage point?
- Does the eye path have rhythm rather than chaos?
- Is friction intentional?
- Is the emotional after-state aligned with the brief?
- Is there a memory hook?
- Does it survive smaller, larger, dark, light, mobile, and print contexts?
