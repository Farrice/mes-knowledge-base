# Satori Graphics — Logo Client Presentation

## Pre-Flight Gate
Load `../genius.md`. Concepts must compete by idea strength, not presentation bias.

## Input Required
- Logo concepts
- Brand brief
- Research notes
- Color/type/context mockups

## Workflow
1. **Create Shared Structure**: Use the same section order for every concept.
2. **Show Thinking**: Present brief sentence, concept logic, iterations, and why decisions fit.
3. **Show Context**: Place each concept in equivalent applications.
4. **Neutralize Bias**: Keep layout, scale, mockup drama, and explanation depth consistent.
5. **Prepare Decision Criteria**: Give the client a comparison rubric.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Long vertical PDF | Use identical sections for each concept |
| Slide deck | One section per concept with matched pacing |
| Live presentation | Same explanation length per concept |
| Internal review | Add critique notes and risk flags |

## Output Requirements
- Presentation outline
- Reusable concept section template
- Concept comparison rubric
- Client decision language
- Bias controls

## Quality Gate
No concept gets a better stage than the others.
