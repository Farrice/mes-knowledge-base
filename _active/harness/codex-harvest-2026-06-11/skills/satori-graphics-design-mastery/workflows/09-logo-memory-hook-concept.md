# Satori Graphics — Logo Memory Hook Concept

## Pre-Flight Gate
Load `../genius.md`. The logo is a memory hook, not the whole brand.

## Input Required
- Brand brief
- Audience
- Competitors
- Desired brand feeling
- Practical constraints

## Workflow
1. **Brief Compression**: Reduce the brand to one clear sentence.
2. **Verb Extraction**: Identify how the brand acts: protects, connects, accelerates, simplifies, guides, strengthens, reveals.
3. **Shape Psychology**: Translate the selected verb into line, weight, angle, curve, proportion, or spatial behavior.
4. **Concept Routes**: Generate 3-5 logo concept directions without trying to say everything.
5. **Similarity Check Plan**: Specify Google Lens, Brand New, competitor, and market checks.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Startup logo | Balance distinctiveness with category trust |
| Premium brand | Reduce detail and increase restraint |
| Martial/fitness brand | Use strength, angle, and weight psychology |
| Tech brand | Avoid generic shields, nodes, and initials |

## Output Requirements
- One-sentence brief
- Verb-led concept map
- 3-5 logo routes
- Shape psychology notes
- Research/checklist

## Quality Gate
Reject any concept that needs a paragraph to explain why it works.
