# Satori Graphics — Memory Encoding Concept Builder

## Pre-Flight Gate
Load `../genius.md`. The goal is a concept the viewer remembers after the scroll.

## Input Required
- Message or topic
- Audience
- Required format
- Brand tone

## Workflow
1. **Compress the Message**: Reduce the idea to one sentence.
2. **Mine Metaphors**: Generate object relationships, absences, substitutions, reversals, and unresolved visual questions.
3. **Choose the Hook**: Select the concept with the strongest message fit and memory potential.
4. **Design the Pause**: Define the detail the viewer must resolve.
5. **Build the Direction**: Produce a visual concept ready for design or image generation.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Poster | One dominant metaphor |
| Social post | Thumbnail-readable visual twist |
| Brand campaign | Repeatable motif system |
| Editorial graphic | Concept plus explanatory caption structure |

## Output Requirements
- One-sentence message
- 5 concept candidates
- Selected memory hook
- Art direction spec
- Anti-generic warning list

## Quality Gate
The concept must be explainable in one sentence and visually stronger than a literal depiction.
