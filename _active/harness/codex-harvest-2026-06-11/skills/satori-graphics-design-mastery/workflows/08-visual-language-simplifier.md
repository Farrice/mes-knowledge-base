# Satori Graphics — Visual Language Simplifier

## Pre-Flight Gate
Load `../genius.md`. More layers do not equal better design.

## Input Required
- Current design or concept
- Core message
- Must-keep content
- Audience and format

## Workflow
1. **Identify the Core Idea**: State what the design must communicate.
2. **Inventory Excess**: List effects, layers, colors, fonts, icons, motifs, and competing focal points.
3. **Rank by Job**: Keep only elements that clarify message, eye path, emotion, or memory.
4. **Simplify the System**: Reduce to stronger contrast, clearer grouping, fewer marks, and cleaner whitespace.
5. **Produce Revision Brief**: Give concrete cuts and replacements.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Poster | One idea, one focal point, one hook |
| Logo | One mark idea, no brand encyclopedia |
| Social graphic | Strong thumbnail message |
| Presentation slide | One claim per slide |

## Output Requirements
- Core idea
- Remove/reduce/retain table
- Simplified visual hierarchy
- Revised direction
- Risks if over-simplified

## Quality Gate
Simplification must make the message louder, not merely make the design emptier.
