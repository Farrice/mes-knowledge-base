# Satori Graphics — Grid Composition System

## Pre-Flight Gate
Load `../genius.md`. Use the grid for order, then break it only with intent.

## Input Required
- Format and dimensions
- Content inventory
- Desired visual energy
- Required hierarchy

## Workflow
1. **Choose Grid Type**: Select column, modular, baseline, asymmetric, rule of thirds, compound, circular, triangular, or isometric.
2. **Assign Hierarchy**: Make important elements span more grid area or occupy stronger intersections.
3. **Plan Macro Whitespace**: Define empty zones and breathing room.
4. **Plan Micro Whitespace**: Define gaps between type, modules, and closely related elements.
5. **Break With Purpose**: Add one controlled grid violation for impact if needed.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Website | Column plus modular content grid |
| Poster | Asymmetric or rule-of-thirds grid |
| Logo | Circular, geometric, or proportion grid |
| Editorial | Baseline plus column grid |

## Output Requirements
- Recommended grid
- Column/row/module structure
- Spacing rules
- Hierarchy assignments
- Controlled-break rule

## Quality Gate
Do not cram content because a grid exists. The grid must create breathing room.
