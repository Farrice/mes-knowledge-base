# Satori Graphics — Anti-AI-Slop Refinement

## Pre-Flight Gate
Load `../genius.md`. Treat clean AI output as the starting point, not the final.

## Input Required
- AI-generated design or design description
- Brand/project context
- Desired emotion and audience
- Constraints

## Workflow
1. **Detect Defaults**: Identify symmetry, centered sameness, generic gradients, predictable cards, stock spacing, and unsupported decoration.
2. **Preserve What Works**: Keep useful clarity, hierarchy, or production quality.
3. **Add Human Decisions**: Introduce purposeful overlap, controlled imbalance, tactile detail, unusual crop, metaphor, or asymmetric rhythm.
4. **Anchor in Meaning**: Tie every refinement to message, emotion, eye path, or memory.
5. **Write the Build Brief**: Produce a designer-ready revision spec.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Hero section | Humanize product/image/type relationship |
| Poster | Replace generic motif with concept-led metaphor |
| Carousel | Create slide rhythm and visual surprises |
| Ad creative | Add one emotion-specific trust or tension cue |

## Output Requirements
- AI-slop diagnosis
- Keep/change/remove list
- Humanizing moves
- Revised visual direction
- Implementation-ready prompt or design brief

## Quality Gate
Do not add chaos. Every “human” change must improve communication.
