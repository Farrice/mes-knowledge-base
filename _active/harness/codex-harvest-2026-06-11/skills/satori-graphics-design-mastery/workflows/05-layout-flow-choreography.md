# Satori Graphics — Layout Flow Choreography

## Pre-Flight Gate
Load `../genius.md`. Control where the eye starts, travels, pauses, and exits.

## Input Required
- Asset type and dimensions
- Content blocks
- Primary message and CTA
- Audience scanning context

## Workflow
1. **Set Entry Point**: Define the first visual stop using scale, contrast, isolation, or placement.
2. **Create Main Route**: Sequence headline, image, supporting details, and CTA.
3. **Add Micro Routes**: Add secondary loops only where they reward extra attention.
4. **Control Motion**: Use implied direction, repetition, scaling, blur, gaze, diagonals, or texture.
5. **Set Temporal Rhythm**: Define impact, linger, pause, and release.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Poster | Strong entry point and short route |
| Landing page | Hero hit, benefit scan, CTA pause |
| Brochure | Slower route with grouped detail zones |
| Product graphic | Product first, proof second, CTA last |

## Output Requirements
- Eye-path map
- Focal hierarchy
- Movement devices
- Rhythm notes
- Layout wire direction

## Quality Gate
The viewer should never have to wonder where to look next.
