# Satori Graphics — Message-First Design Audit

## Pre-Flight Gate
Load `../genius.md`. Judge the design by communication first, polish second.

## Input Required
- Design, screenshot, description, or draft asset
- Intended audience
- Intended message
- Intended action or memory

## Workflow
1. **State the Message**: Write what the design appears to say before reading the user’s intent.
2. **Find the Gap**: Compare apparent message against intended message.
3. **Audit Element Purpose**: Classify each major element as message, hierarchy, emotion, memory, navigation, or decoration.
4. **Score Communication**: Rate message clarity, hierarchy, emotional fit, and memory strength from 1-10.
5. **Prescribe Fixes**: Remove, reduce, reposition, or replace anything that does not pay rent.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Poster | Prioritize instant message and one visual hook |
| Landing page | Prioritize headline, hero image, CTA sequence |
| Social graphic | Prioritize thumbnail clarity and memory |
| Logo | Prioritize recognition and one clear idea |

## Output Requirements
- Apparent message
- Intended-message gap
- Element-by-element purpose table
- 1-10 scores
- Top 5 fixes in execution order

## Quality Gate
The audit fails if it praises aesthetics without proving what the design communicates.
