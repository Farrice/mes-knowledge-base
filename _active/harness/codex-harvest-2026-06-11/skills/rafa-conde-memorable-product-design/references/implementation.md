# Implementation Guide

## Operating Sequence

1. **Name the feeling**: Choose one emotional target and one remembered sentence.
2. **Choose the carrier**: Product flow, prototype, video, onboarding, launch page, release note, or agent workflow.
3. **Map the beats**: Setup, need, reveal, tactile moment, payoff, memory hook.
4. **Protect the center**: Remove anything that weakens the one-sentence product promise.
5. **Add one signature detail**: Motion, sound, microcopy, visual object, unlock, default, or tiny ritual.
6. **Build the artifact**: Produce the brief, audit, script, launch kit, or workflow upgrade.
7. **Run the memory test**: Ask what people remember and what they felt after one day.

## Enrichment Anchors

- **IDEO / design thinking**: Desirability, feasibility, and viability keep memorable ideas grounded.
- **Stanford d.school**: Empathize, define, ideate, prototype, test; use the process as action, not ceremony.
- **Don Norman emotional design**: Design across visceral, behavioral, and reflective levels.
- **Laws of UX**: Use aesthetic-usability, peak-end, cognitive load, and flow as guardrails.
- **Brain Glue / Made to Stick**: Convert product feelings into repeatable language.
- **Eric Roth**: Add residue, subtext, and cinematic pacing.
- **Oren**: Calibrate taste and reject generic "nice."
- **David Placek**: Name moments and features with processing fluency and tension.
- **PJ Accetturo**: Build video ads and demo scripts that carry emotion.

## Output Standard

Every workflow must produce a concrete deliverable. Avoid instructor mode. The user should be able to hand the output to a designer, founder, editor, engineer, or agent and start building.
