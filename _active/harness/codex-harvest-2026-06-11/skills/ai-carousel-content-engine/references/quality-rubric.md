# Quality Rubric

| Criterion | Pass Standard |
|---|---|
| Source fidelity | The carousel preserves the source's actual point. |
| Swipe architecture | Slide 1 stops, slide 2 retains, core slides build, final slide directs action. |
| One idea per slide | No slide carries more than one major idea. |
| Visual direction | Each slide has a designable visual instruction. |
| GPT Image readiness | Prompt includes exact text, count, layout rules, style, and slide list. |
| Brand coherence | Style board gives palette, typography, and composition constraints. |
| Human review | Checklist catches copy, design, strategy, and claim issues before publishing. |

## Failure Conditions

- Hidden-prompt copying or implying access to private material.
- Generic "viral carousel" wording with no audience or mission.
- Long copy that cannot fit on a slide.
- No CTA or owned-content pathway.
- No review checklist.
