# EDAN Opener Builder

## Pre-Flight Gate

Use this before drafting when the user knows the topic, moment, scene, argument, or desired reader effect but needs an opening sequence.

## Skill Acquisition

Load:

- `skills/nicolas-cole-edan-writing-mechanics/genius.md`
- `skills/nicolas-cole-edan-writing-mechanics/references/genius-patterns.md`

## Execution

1. Define the target reader effect:
   - Clarity.
   - Curiosity.
   - Tension.
   - Trust.
   - Intimacy.
   - Authority.
   - Moral pressure.
   - Momentum.
2. Choose 2-4 EDAN blocks to sequence.
3. Pick the sequence pattern:
   - `E -> A`: clear setup into movement.
   - `A -> E`: hook action, delayed context.
   - `D -> N`: felt meaning, then worldview.
   - `E -> D -> A`: context, implication, consequence.
   - `A -> D -> N`: movement, texture, point of view.
4. Draft 3 opener variants.
5. Annotate each variant by block.
6. Recommend the strongest opener and explain why.
7. Save the reusable sequence as an "opener card."

## Content Type Adaptations

| Type | Opener Bias |
|---|---|
| Fiction | Start with action or description unless context is essential |
| Memoir | Use description/action before reflective narration |
| Newsletter | Lead with reader context or a concrete moment |
| LinkedIn | Use a compressed action/example, then POV |
| Sales story | Start with before-state action or proof detail |
| Script | Start visually: action or description first |

## Output Requirements

Return:

1. Target effect.
2. Candidate block sequences.
3. Three annotated openers.
4. Recommended opener.
5. Opener card: sequence, use case, warning sign.

## Quality Gate

The opener must be designed by block function, not just hookiness. If the sequence cannot explain the reader effect, revise it.
