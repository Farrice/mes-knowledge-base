# Description Upgrade

## Pre-Flight Gate

Use this when a passage explains emotion, conflict, status, tension, desire, trust, expertise, or transformation too directly.

## Skill Acquisition

Load:

- `skills/nicolas-cole-edan-writing-mechanics/genius.md`

## Execution

1. Identify the explanation to replace or strengthen.
2. State the intended inference: what should the reader conclude without being told?
3. Generate detail fields:
   - Object.
   - Gesture.
   - Spatial arrangement.
   - Timing.
   - Body language.
   - Setting.
   - Omission or avoidance.
   - Repeated behavior.
4. Choose the 2-4 details that imply the meaning most cleanly.
5. Rewrite the passage with description carrying the inference.
6. Keep only the explanation needed for clarity.
7. Check whether the reader can infer the intended meaning without the blunt claim.

## Content Type Adaptations

| Type | Description Upgrade |
|---|---|
| Fiction | Use sensory or physical detail to imply emotion/conflict |
| Memoir | Use remembered object/gesture instead of abstract reflection |
| Newsletter | Use concrete reader moment instead of broad advice |
| LinkedIn | Replace generic lesson with one observable scene |
| Case study | Use before/after behavior, artifact, or metric detail |
| Brand copy | Turn values into proof moments |

## Output Requirements

Return:

1. Original explanation.
2. Intended inference.
3. Detail bank.
4. Rewritten version.
5. Why the description works.
6. Any explanation that must remain.

## Quality Gate

Description must imply meaning. Reject decorative detail that does not change what the reader understands.
