# Deliberate Practice Loop

## Pre-Flight Gate

Use this when the user wants to actually improve a writing skill, not just fix one draft.

## Skill Acquisition

Load:

- `skills/nicolas-cole-edan-writing-mechanics/genius.md`
- `skills/nicolas-cole-edan-writing-mechanics/references/quality-rubric.md`

## Execution

1. Identify the plateau:
   - Too abstract.
   - Too much telling.
   - Weak action.
   - Generic POV.
   - Bad openings.
   - Poor scene movement.
2. Choose one EDAN focus:
   - Single block: E, D, A, or N.
   - Pair: E+D, D+A, A+N, E+A.
   - Trio: E+D+A, A+D+N, E+A+N.
3. Set a 5-10 rep drill.
4. Provide a model passage or model pattern if available.
5. Define feedback criteria.
6. Run one sample rep if the user supplied material.
7. Create a 7-day practice loop.

## Content Type Adaptations

| Type | Practice Loop |
|---|---|
| Fiction | Scene block reps, action consequence, implied meaning |
| Nonfiction | Concrete examples, reader moments, POV lines |
| Ghostwriting | Client worldview narration plus proof scenes |
| Brand writing | Values-to-action/description drills |
| Sales writing | Before/after proof moments and buyer POV |
| Daily writing habit | One block per day, one combination per week |

## Output Requirements

Return:

1. Plateau diagnosis.
2. Chosen EDAN focus.
3. Rep instructions.
4. Feedback checklist.
5. 7-day loop.
6. One example rep when possible.

## Quality Gate

Do not prescribe generic daily writing. The loop must isolate a specific block or combination.
