# Source Study Deconstruction

## Pre-Flight Gate

Use this when the user provides a passage, article, scene, newsletter, ad, or transcript segment they admire and wants to learn from it.

## Skill Acquisition

Load:

- `skills/nicolas-cole-edan-writing-mechanics/genius.md`
- `skills/nicolas-cole-edan-writing-mechanics/references/genius-patterns.md`

## Execution

1. Split the source into sentences or paragraph units.
2. Label each unit as E, D, A, N, or mixed.
3. Identify the block sequence.
4. Name the effect created by the sequence.
5. Extract reusable patterns:
   - Context setup.
   - Implied meaning detail.
   - Consequential action.
   - Worldview/narration line.
   - Delayed payoff.
6. Create 3 "opener cards" or "sequence cards" from the source.
7. Translate each card into a prompt the user can practice.

## Content Type Adaptations

| Type | Deconstruction Focus |
|---|---|
| Literature | Description/narration interaction and theme pressure |
| Newsletter | Explanation clarity and POV placement |
| LinkedIn | Hook/action/lesson sequence |
| Sales page | Proof action and belief narration |
| Case study | Before/after action architecture |
| Script | Visual action and explanatory timing |

## Output Requirements

Return:

1. Source EDAN map.
2. Sequence summary.
3. Reader effect diagnosis.
4. Reusable pattern cards.
5. Practice prompts.
6. One warning about what not to copy.

## Quality Gate

The output must teach transferable mechanics, not merely summarize why the passage is good.
