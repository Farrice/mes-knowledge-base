# Hidden Knowledge

## What Most Writers Miss

- "Show don't tell" is too vague to execute. EDAN translates it into a block trade: move from Explanation into Description when the reader should infer meaning.
- Description is not automatically literary. Description becomes powerful only when it replaces or intensifies meaning.
- Action scenes can be boring when nothing changes. Subtle action can be devastating when context and description have prepared the reader.
- Narration is not simply "voice." It is point of view about what is happening.
- Overusing narration drains it. The more important the worldview sentence, the more carefully it should be placed.
- A writer can improve without drafting a full piece. They can run reps on one EDAN block for days.
- A writer can reverse engineer taste by mapping block sequence, not merely by copying tone.

## Diagnostic Shortcuts

| Symptom | Likely EDAN Cause | First Repair |
|---|---|---|
| Draft feels like an essay outline | Too much Explanation | Convert one claim into Description or Action |
| Draft has scenes but no meaning | Action/Description without enough Explanation or Narration | Add context or a worldview line |
| Draft feels preachy | Too much Narration | Replace one claim with a scene/detail |
| Draft feels slow | Explanation is front-loaded | Move action earlier or delay context |
| Draft feels vague | Description lacks specificity | Add object, gesture, setting, body, timing, or measurable detail |
| Draft feels generic | Narration lacks a real belief | State the actual opinion the piece is afraid to own |
| Draft feels busy | Action lacks consequence | Cut motion that does not change anything |

## Practitioner Rule

Do not revise by making prose prettier first. Revise by changing block function, sequence, and payoff. Polish comes last.
