# Quality Rubric

Score each criterion from 1-5.

| Criterion | 1 | 3 | 5 |
|---|---|---|---|
| Classification accuracy | Blocks are guessed or mislabeled | Most blocks are usable | Each block label explains what the sentence does |
| Explanation timing | Context dump or missing context | Mostly useful context | Context is necessary, timed, and paid off |
| Description meaning | Decorative or generic detail | Some implication | Detail creates a clear inference |
| Action consequence | Motion without change | Some momentum | Action changes stakes, reveals, or proves something |
| Narration force | Generic moralizing | Some POV | Specific worldview line with thematic pressure |
| Block balance | One-note texture | Some variety | Mix matches target effect and format |
| Sequence design | Random order | Reasonable flow | Order deliberately creates feeling |
| Revision usefulness | Vague advice | Clear suggestions | Concrete block-level rewrites and cuts |
| Practice design | "Write more" | Some exercises | Isolated reps with target, model, and feedback |
| Reusability | One-off critique | Some patterns captured | New opener/block sequence added to reusable library |

## Pass Standard

- 40+ = keep and deploy.
- 32-39 = usable, but run one more EDAN revision pass.
- Below 32 = return to block classification before sentence polish.
