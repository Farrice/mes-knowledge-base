# E-Commerce Economics Reference

Use this for paid-scale audits, category selection, and brand validation.

## Core Metrics

| Metric | Why It Matters |
|--------|----------------|
| AOV | Determines how much paid traffic cost can be absorbed |
| Gross Margin | Sets the first ceiling on acquisition cost |
| Contribution Margin | More useful than ROAS alone because it includes variable costs |
| Break-Even ROAS | Minimum ROAS before fixed costs and growth goals |
| Scaling ROAS | Target ROAS that allows aggressive spend while preserving cash |
| CPA | Must be judged against first-order margin and LTV |
| LTV | Repeat purchase can make first-order acquisition viable |
| OPEX | Shrinks as a percentage at scale, but can kill small-volume brands |
| Inventory Cycle | Stock timing determines whether ads can keep running |
| Payment Terms | Better supplier terms free cash for acquisition |
| Platform Payout Delay | Shopify/payment delays can starve a fast-scaling brand |
| Shipping Weight | Heavy products punish paid-scale economics |

## Paid-Scale Gate

Score each from 1-10:

1. TAM size
2. Emotional outcome strength
3. Paid-ad explainability
4. Gross margin
5. Shipping profile
6. AOV expansion path
7. Repeat purchase or subscription path
8. Supply-chain simplicity
9. Defensibility
10. Brand trust potential

Verdict:

- **80-100**: strong candidate for aggressive paid validation
- **60-79**: promising, but needs a clear fix before heavy spend
- **40-59**: test only with constrained budget and strict kill criteria
- **Below 40**: poor paid-scale candidate

## Vince Standard

Do not stare at ROAS alone. A brand with lower ROAS can be healthier if AOV, LTV, contribution margin, OPEX, stock, and cash timing support it.
