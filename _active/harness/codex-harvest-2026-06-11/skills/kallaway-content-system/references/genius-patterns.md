# Kallaway Content System — Genius Patterns

This file exists for validator compatibility and cold-start loading. The full context lives in `../genius.md`.

## Pattern 1: Six-Stage Rep

Split content production into topic, format, substance, hook, script, and edit. Diagnose and improve each stage separately.

## Pattern 2: Signal Before Creativity

Use outlier data to validate topic and format before spending creative effort.

## Pattern 3: Specific Topic, Not Category

Turn broad categories into 3-5 word specific topics that a creator can react to.

## Pattern 4: Format As Creative Constraint

Lock the format before substance because the format changes what kind of take and proof can work.

## Pattern 5: Substance Is The Sauce

Originality lives in the contrarian take and the evidence stack, not in generic AI ideation.

## Pattern 6: AI As Evidence Partner

AI should support a human-owned take with proof options, not invent the creator's point of view.

## Pattern 7: Hook Triad Coordination

Design visual hook, text hook, and spoken hook as separate layers with separate jobs.

## Pattern 8: Script Profile Over Generic Drafting

Use 10-20 top transcripts from one voice to build a script profile before drafting.

## Pattern 9: Edit Path As Leverage Decision

Choose low-edit, DIY, AI-assisted, or outsourced editing based on creator leverage and quality bar.

## Pattern 10: 10x Batch Iteration

Treat ten posts as one learning unit. Carry 5x winners into three of the next ten and rerun 10x winners more directly.
