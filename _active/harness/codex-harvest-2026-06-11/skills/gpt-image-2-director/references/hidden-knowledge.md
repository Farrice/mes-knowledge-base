# GPT Image 2.0 Director - Hidden Knowledge

## Model Bias
GPT Image 2.0 is unusually strong at layout and rendered text. Treat typography, labels, UI regions, and information density as strengths, not risks.

## Failure Mode
For human realism, "photorealistic" can push outputs toward plastic faces. Film, editorial, flash, grain, lens, and camera-stock language usually performs better.

## Operating Rule
Default to structured JSON when the image has more than one meaningful region. The point of this skill is prompt-following precision.
