# Genius Patterns

## Pattern 1: Ledger Before Interpretation

Create the evidence ledger first, then summarize. This prevents early narrative from contaminating observed rows.

## Pattern 2: Channel Isolation

Keep transcript, frame, OCR, inference, and uncertainty as separate streams until the source map explicitly combines them.

## Pattern 3: Honest Adapter Fallback

If `yt-dlp`, captions, ffmpeg, OCR, or vision tooling fails, write a limitation row. Do not silently downgrade quality.

## Pattern 4: Visual Proof Requires a Visual Source

A visual proof note must cite a frame, OCR row, human visual note, or configured vision adapter output.

## Pattern 5: Extraction Handshake

The final report should make it easy to feed the video into `/extract`, `/extract-forge`, research, content, creative, or audit workflows.
