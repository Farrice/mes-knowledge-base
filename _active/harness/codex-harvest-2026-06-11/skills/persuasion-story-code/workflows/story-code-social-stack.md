# Story Code Social Stack

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/stacking-guide.md`
- Relevant partner skill only when needed: Kallaway, Shaan Puri, Story Compass, or `/social-narrative`.

Use when the user wants persuasive story content built for LinkedIn, X, Instagram, newsletters, carousels, or content series.

## Input Required

- Topic, offer, story, or content goal.
- Platform.
- Audience.
- Desired response.
- Existing story/proof if available.

## Execution

1. **Story Code layer**: Choose the persuasion story type and write the core story.
2. **Retention layer**: Add open loops, stakes, contrast, or curiosity if the platform needs it.
3. **Emotional layer**: Sharpen audience feeling and identity resonance.
4. **Platform layer**: Adapt length, pacing, line breaks, hook, CTA, and series potential.
5. **Variant layer**: Produce different versions by story job.

## Output

Produce a **Platform Story System**:

- **Core Persuasion Story**.
- **LinkedIn Version**.
- **X Thread Version**.
- **Instagram Caption/Reel Script**.
- **Newsletter Opener**.
- **Hook Bank**: 10 hooks.
- **Series Map**: 5 follow-up content ideas.
- **Stack Notes**: which expert lens shaped which part.

## Quality Gate

- Social mechanics do not distort the truth.
- The post still has a business job.
- Hooks do not overpromise.
