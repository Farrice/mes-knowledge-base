# Story Code Conversion Stack

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/stacking-guide.md`
- Relevant partner skill only when needed: Joanna Wiebe, Donald Miller, Jeremy Miner, or Rory Sutherland.

Use when the user needs story-led conversion assets: sales page, email, funnel, offer message, objections, pitch, or sales conversation.

## Input Required

- Offer.
- Audience and awareness level.
- Conversion goal.
- Existing copy or raw notes.
- Proof, objections, guarantees, and mechanism.

## Execution

1. **Story Code layer**: Create the persuasion story stack by barrier.
2. **Clarity layer**: Make the customer problem, offer, result, and CTA unmistakable.
3. **Conversion layer**: Add funnel-stage triggers, authority, skepticism handling, and proof.
4. **Sales psychology layer**: Convert objections into self-persuasion moments where appropriate.
5. **Perception layer**: Reframe value and alternatives when price or category comparison is the issue.

## Output

Produce a **Conversion Story System**:

- **Story Stack**: exact story blocks by funnel stage.
- **Finished Copy Sections**: lead, origin, mechanism, proof, objection, CTA bridge.
- **Objection Responses**: story-led answers.
- **Email Sequence Outline**: if relevant.
- **Sales Call Story Prompts**: if relevant.
- **Next Expert Handoff**: recommended next workflow and why.

## Quality Gate

- Conversion pressure does not create exaggeration.
- The offer remains clear.
- Every story section has a measurable business purpose.
