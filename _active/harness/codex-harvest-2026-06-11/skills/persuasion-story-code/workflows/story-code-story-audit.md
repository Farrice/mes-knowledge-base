# Story Code Story Audit

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/quality-rubric.md`
- `skills/persuasion-story-code/references/story-taxonomy.md`

Use when a story, post, email, page section, video script, or pitch feels flat, fake, bloated, confusing, or weak.

## Input Required

- Draft or asset.
- Audience.
- Desired action.
- Known proof and constraints.

## Execution

1. **Identify intended story job**: What should the story do?
2. **Score fit**: Does the current story match that job?
3. **Run four believability checks**: inconsistency, vagueness, exaggeration, non-conversational language.
4. **Run power checks**: word-pictures, simplicity, familiar language, relatability, research grounding.
5. **Rewrite**: Produce a corrected version that keeps truth and improves persuasion.
6. **Explain only the useful fixes**: Keep diagnosis concise and practical.

## Output

Produce a **Story Diagnosis + Rewrite**:

- **Current Story Job**: stated clearly.
- **Primary Failure**: the main reason it is weak.
- **Scorecard**: truth, specificity, compression, tone, placement, business usefulness.
- **Fixed Story**: ready to use.
- **Before/After Notes**: specific changes made.
- **Further Proof Needed**: if any.

## Quality Gate

- The rewrite preserves truth.
- The final version is shorter and clearer unless the channel requires detail.
- The diagnosis leads with the fix, not a lecture.
