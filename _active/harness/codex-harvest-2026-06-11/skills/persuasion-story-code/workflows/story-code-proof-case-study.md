# Story Code Proof Case Study

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/story-taxonomy.md`
- `skills/persuasion-story-code/references/quality-rubric.md`

Use when the user has a result, testimonial, customer note, proof point, or client win and needs persuasive proof.

## Input Required

- Customer/client context.
- Starting problem.
- What was done.
- Results and evidence.
- Permission status.
- Audience and asset type.

## Execution

1. **Choose proof form**: Case study, certification story, expert testimonial, results testimonial, or experience testimonial.
2. **Establish before state**: Specific starting condition, stakes, and doubt.
3. **Show intervention**: What changed, what was done, or what was used.
4. **Show result**: Concrete outcome, experience, or validation.
5. **Add credibility frame**: Proof, permission, caveat, context, and qualification.
6. **Create channel versions**: Sales page, short post, email, video, pitch, and testimonial block.

## Output

Produce a **Proof Story Package**:

- **Proof Strategy**: best proof type and why.
- **Full Case Study**: ready to publish if permission exists.
- **Short Proof Story**: 1-2 paragraphs.
- **Testimonial Rewrite**: conversational version preserving truth.
- **Social Proof Post**: ready to publish.
- **Video Proof Script**: 30-60 seconds.
- **Evidence Checklist**: permission, screenshots, metrics, disclaimers.

## Quality Gate

- No customer details are invented.
- Results are qualified when needed.
- The proof answers a real buyer doubt.
