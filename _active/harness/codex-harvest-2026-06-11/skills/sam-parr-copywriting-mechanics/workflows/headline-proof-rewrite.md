# Headline Proof Rewrite

## Use When

The opener is a label, claim, topic, or polite setup instead of a reason to keep reading.

## Inputs

- Current headline or first line.
- Audience.
- Desired action.
- Best available proof object.
- Biggest likely doubt.
- Platform.

## Steps

1. Name the desired reader action.
2. Identify the current opener type: label, claim, summary, shock, proof, story, or gap.
3. Create 10 headline candidates:
   - 3 curiosity-gap candidates,
   - 3 proof-first candidates,
   - 2 phrase-twist candidates,
   - 2 familiar-energy candidates.
4. Choose the strongest opener based on clarity, pull, proof, and voice fit.
5. Write the first body section so the headline pays off quickly.
6. Add the next line that moves the reader from attention to interest.

## Output

```markdown
## Headline Proof Rewrite
- Desired action:
- Weak link:
- Proof object:
- Selected headline:
- First payoff line:
- Why this is stronger:
- Remaining risk:
```

## Quality Gate

Fail if the selected headline is clever but unclear, creates curiosity without payoff, or cannot be supported by the proof object.
