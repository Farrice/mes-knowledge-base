# Copywork Hour Sprint

## Use When

The writer needs better instincts for a format before drafting or revising.

## Inputs

- Target format.
- Desired quality bar.
- Three to ten exemplar assets.
- Current draft or intended asset.

## Steps

1. Pick one exemplar that clearly performs the same job.
2. Copy it manually for 20 minutes.
3. Mark the mechanics:
   - opener,
   - curiosity gap,
   - proof,
   - story,
   - objection,
   - rhythm,
   - action.
4. Extract five rules from the exemplar.
5. Rewrite the current asset using only those rules.
6. Write a texture note: what became visible only through copying.

## Output

```markdown
## Copywork Hour Sprint
- Format:
- Exemplar copied:
- Five extracted rules:
- Texture note:
- Rewrite moves:
- Next practice rep:
```

## Quality Gate

Fail if the output only says "inspired by" and does not identify specific rules from the copywork.
