# Attention Hijack Hooks - Genius Patterns

## Pattern 1: Signal Before Sentence

Choose the attention anchor before writing the hook. The anchor can be a brand, news item, person, trend, claim, number, artifact, or strong body insight.

## Pattern 2: Payload Before Format

Lock the real argument before choosing Dense, Punchy plus Context, Single-Line Bomb, Stacked, or Hybrid. Format cannot rescue an empty payload.

## Pattern 3: Gap Before Polish

The hook must open expectation-versus-claim tension. If the reader can predict the body from the hook, the hook is not doing enough work.

## Pattern 4: First-Window Fit

Audit the first visible platform window. On LinkedIn this means first 40 to 50 words, mobile line breaks, and pixel-width pressure.

## Pattern 5: Judgment After Generation

Generate options, but ship a decision. Every run should name the winner, why it wins, what was rejected, and where the selected hook goes next.
