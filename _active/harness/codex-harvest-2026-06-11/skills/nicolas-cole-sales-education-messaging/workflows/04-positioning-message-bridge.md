# Positioning Message Bridge

## Pre-Flight Gate

Use this workflow when positioning is clear enough to name the category, buyer, and contrast, but sales messaging still sounds abstract or self-centered.

If positioning itself is unclear, use a positioning diagnostic first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-sales-education-messaging/genius.md`
- `skills/nicolas-cole-niche-positioning/genius.md` when buyer specificity is weak
- `skills/nicolas-cole-sales-education-messaging/references/quality-rubric.md`

## Execution

1. Capture the current positioning statement, buyer, category, alternative, and offer.
2. Translate the positioning into buyer language:
   - what problem this category solves
   - what old comparison is misleading
   - what the buyer must believe to care
   - what outcome the buyer actually wants
3. Build the problem-side message bridge.
4. Build the category-of-solution bridge.
5. Create talk tracks for:
   - sales call opening
   - sales page problem section
   - email angle
   - short DM
   - public post
6. Add contrast language against the old way without dunking on the buyer.
7. Define the next proof asset needed.

## Content Type Adaptations

| Type | Bridge Focus |
|---|---|
| New category | Explain why old categories mislead the buyer |
| Existing category | Explain why this mechanism is the right fit now |
| Premium service | Shift comparison from deliverables to business consequence |
| Digital product | Connect product vehicle to buyer transformation |
| Creator offer | Turn authority into useful buyer education |

## Output Requirements

Return:

1. Current positioning summary.
2. Buyer-language translation.
3. Problem-side bridge.
4. Category-side bridge.
5. Five medium-specific talk tracks.
6. Proof gap.

## Quality Gate

Pass only if the buyer can understand why the category matters before hearing why this seller is special.
