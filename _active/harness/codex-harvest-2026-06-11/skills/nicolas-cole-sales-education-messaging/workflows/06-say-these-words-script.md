# Say These Words Script

## Pre-Flight Gate

Use this workflow when the user needs actual language for sales education after the buyer, offer, and education gap are known.

If the education gap is not known, run `/buyer-belief-ladder` first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-sales-education-messaging/genius.md`
- `skills/nicolas-cole-sales-education-messaging/references/genius-patterns.md`
- `skills/phil-m-jones-conversational-influence/SKILL.md` only when phrase-level sales conversation control is explicitly needed

## Execution

1. Identify the medium: call, DM, email, page, post, proposal, or follow-up.
2. Identify the education moment:
   - problem awareness
   - reason why
   - consequence
   - emotional impact
   - category of solution
   - category power
   - benefit
   - positive outcome
3. Draft phrases in four families:
   - diagnostic question
   - educational reframe
   - proof bridge
   - clean next step
4. Keep each phrase honest, specific, and low-pressure.
5. Add softer and more direct variants.
6. Include a "do not say" version for manipulative or self-centered phrasing to avoid.

## Content Type Adaptations

| Type | Phrase Style |
|---|---|
| Sales call | Question-led, reflective, consultative |
| DM | Short, specific, curiosity-based |
| Email | One clear education beat with a proof bridge |
| Sales page | Plain-language section copy |
| Proposal | Buyer-specific recap and category rationale |
| Public post | Teach the market without naming one buyer |

## Output Requirements

Return:

1. Situation summary.
2. Education moment.
3. Phrase bank by family.
4. Soft/direct variants.
5. Do-not-say list.
6. Recommended phrase sequence.

## Quality Gate

Pass only if the phrases help the buyer understand. Reject lines that rely on false scarcity, shame, inflated certainty, or pressure.
