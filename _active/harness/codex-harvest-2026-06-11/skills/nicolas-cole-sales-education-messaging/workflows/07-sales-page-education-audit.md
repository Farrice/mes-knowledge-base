# Sales Page Education Audit

## Pre-Flight Gate

Use this workflow when the user provides a sales page, landing page, offer page, checkout page, proposal page, or draft copy and wants to know whether it educates buyers into readiness.

If no page exists yet, run `/sales-education-map` first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-sales-education-messaging/genius.md`
- `skills/nicolas-cole-sales-education-messaging/references/quality-rubric.md`
- `skills/nicolas-cole-nonfiction-value-architecture/genius.md` when the page is content-heavy

## Execution

1. Identify the buyer, offer, page goal, traffic source, and buyer awareness level.
2. Audit the page against the eight-part education arc.
3. Mark where the page talks about the seller before educating on the problem or category.
4. Identify missing objections, questions, wrong comparisons, and proof gaps.
5. Score each rubric criterion from 1-5.
6. Rewrite the page structure:
   - problem awareness
   - reasons why
   - consequence
   - emotional impact
   - category of solution
   - category power
   - benefits
   - ultimate positive outcome
   - seller/offer fit
   - next step
7. Provide section-level copy improvements.

## Content Type Adaptations

| Type | Audit Focus |
|---|---|
| High-ticket service page | Category education, trust, proof, application readiness |
| Course page | Transformation path, completion belief, objections, proof |
| Low-ticket product page | Fast clarity, specific use case, immediate benefit |
| Consulting page | Business case, category maturity, authority, next step |
| Waitlist page | Problem urgency and promise clarity before details |

## Output Requirements

Return:

1. Page readiness score.
2. Eight-part education coverage table.
3. Missing belief and objection map.
4. Proof gaps.
5. Revised page structure.
6. Priority copy fixes.

## Quality Gate

Pass only if a cold buyer can understand what problem matters, why now, why this category, and why this offer is a credible next step.
