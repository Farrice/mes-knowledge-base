# Choice Architecture Script

## Pre-Flight Gate

Use this when someone needs to choose among packages, next steps, strategies, scopes, or paths.

## Skill Acquisition

Load:
- `genius.md` - Three-Option Decision Design and Social Category Mirror
- `references/phrase-library.md` - sequence families 9, 10, 14, 20
- `references/stacking-guide.md` for Rory Sutherland pairing when needed

## Inputs

- Decision to be made
- Available options
- Preferred option, if there is one
- Buyer's/person's criteria
- Ethical constraints

## Execution

1. **Curate three options**: present three honest paths: conservative, best-fit, and ambitious or alternate.
2. **Name who each is for**: connect each option to a person, situation, or priority.
3. **Define enough**: clarify what is enough to solve the problem without overbuying.
4. **Ask the easiest choice question**: ask which option feels easiest, safest, or most aligned.
5. **Move to next step**: convert the selection into action.

## Content Type Adaptations

| Channel | Adaptation |
|---|---|
| Proposal | Use a three-option table and recommendation note. |
| Sales call | Explain options conversationally, then ask. |
| Landing page | Use package copy and fit language. |
| DM | Offer three brief paths. |
| Leadership | Present tradeoffs and decision owner. |

## Output Requirements

Produce:
- Three-option table
- Fit language for each option
- Recommended option with reason
- Choice question
- Next-step script

## Quality Gate

Reject fake decoy options. All three choices must be real, and the recommendation must serve the buyer.
