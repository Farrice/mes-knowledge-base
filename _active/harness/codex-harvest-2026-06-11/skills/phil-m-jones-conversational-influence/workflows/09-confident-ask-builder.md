# Confident Ask Builder

## Pre-Flight Gate

Use this when the speaker knows what they want but is avoiding the ask.

## Skill Acquisition

Load:
- `genius.md` - Columbo Add-On and Curiosity Recovery
- `references/phrase-library.md` - sequence families 21, 22, 23

## Inputs

- Desired ask
- Why it matters
- Size of ask
- Relationship
- What the other person gets or preserves

## Execution

1. **Shrink the ask to its honest size**: define the smallest useful action.
2. **Choose timing**: decide whether it belongs before, during, or after the main conversation.
3. **Use a favor frame only when true**: do not call a large request small.
4. **Add the Columbo moment**: include one optional extra ask after value has been delivered.
5. **Prepare curiosity recovery**: if they decline, learn why without argument.

## Content Type Adaptations

| Channel | Adaptation |
|---|---|
| Review ask | Make the action specific and easy. |
| Referral ask | Name who would be relevant and why. |
| Client ask | Tie the ask to project progress. |
| Personal ask | Keep warmth and directness. |
| Content CTA | Ask for one concrete reply or share. |

## Output Requirements

Produce:
- Clear ask
- Soft ask
- Direct ask
- Columbo add-on
- Decline recovery line

## Quality Gate

Reject any ask that hides the real effort required.
