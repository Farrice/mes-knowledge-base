# Traction-First Roadmap

## Pre-Flight Gate

Use when a founder needs a sequence from idea to paying customers. The roadmap should be evidence-gated, not feature-gated.

Load:
- `skills/ash-maurya-founder-systems/genius.md`
- `skills/ash-maurya-founder-systems/references/source-map.md`

## Execution

1. **Set The Goal**
   - Define the demand proof needed by day 90.
   - Choose commitment type: money, signed pilot, time, data access, referral, or implementation slot.

2. **Phase 1: Problem Discovery (Weeks 1-4)**
   - Week 1: research current alternatives and customer forces.
   - Week 2: run 10-15 behavioral interviews.
   - Week 3: map push, pull, inertia, friction.
   - Week 4: validate at least 30% high problem intensity.

3. **Phase 2: Solution Design (Weeks 5-8)**
   - Week 5: define outcome and 5P MVP decisions.
   - Week 6: test the value proposition with interviewed prospects.
   - Week 7: create the minimum demo.
   - Week 8: test demo engagement with fresh prospects.

4. **Phase 3: Offer Delivery (Weeks 9-12)**
   - Week 9: assemble the mafia offer.
   - Week 10: pitch qualified early adopters.
   - Week 11: optimize objections, price, and packaging.
   - Week 12: analyze demand proof and decide build scope.

5. **Define Gates**
   - Gate 1: problem intensity.
   - Gate 2: demo engagement.
   - Gate 3: resource commitment.
   - Gate 4: build-ready spec.

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| Startup | Optimize for paid pilots or preorders |
| Service | Optimize for paid audit/sprint commitments |
| AI tool | Optimize for demo engagement before automation build |
| Client engagement | Convert phases into a scoped validation sprint |

## Output Requirements

- 90-day roadmap
- Weekly actions
- Evidence gates
- Metrics and thresholds
- Build/no-build decision point

## Quality Gate

Pass only if each week has one evidence objective. Fail if the roadmap is a feature plan.
