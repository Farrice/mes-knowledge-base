# Core Message Forge

## Pre-Flight Gate

Use this when the user needs the central line, slogan, naming direction, positioning hook, or repeatable message for an idea, offer, business, product, or piece of content.

## Skill Acquisition

Load `../genius.md`, `../references/hidden-knowledge.md`, and `../references/implementation.md`.

## Execution

1. **Extract the plain truth**: State what the offer actually does in boring language.
2. **Find the one feature**: Choose the single most memorable buyer-relevant feature or transformation.
3. **Set the frame**: Decide what expectation the audience should have from the first sentence.
4. **Simplify**: Create a one-sentence version a non-expert can repeat.
5. **Make it sticky**: Generate candidate lines using metaphor, perspective, rhyme, alliteration, chiasmus, trigger words, and sensory cues.
6. **Choose the spine**: Select one campaign-grade core message.
7. **Create deployment variants**: Adapt the spine into tagline, headline, social hook, video open, and CTA.

## Content Type Adaptations

| Format | Output |
|---|---|
| Brand | Core promise, tagline, one-sentence positioning |
| Offer | Hero headline, subhead, CTA line |
| Social | First-line hook and repeatable phrase |
| Video | Spoken opening and closing line |
| Sales | Objection-aware core claim |

## Output Requirements

Produce:
- **Boring Truth**
- **Sticky Core**
- **10 Candidate Lines**
- **Winner + Why It Wins**
- **Deployment Variants**
- **Do-Not-Use Lines**

## Quality Gate

The winning line must be clear without explanation, specific enough to sell, and memorable enough to become a campaign spine.
