# Higgsfield Creative Studio - Hidden Knowledge

## Orchestration Bias
The still image and video prompt should share one strategy spine. A strong key visual can lock the product world before the motion prompt adds pacing and camera grammar.

## Failure Mode
The orchestrator can accidentally break source-skill output formats by over-explaining. Single-prompt requests must be passed through to the relevant source director.

## Operating Rule
Use stacking only when it improves the asset. For simple prompt requests, route directly and preserve the final format.
