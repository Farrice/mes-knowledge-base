# Oren Short-Form Revenue Map

## Pre-Flight Gate

Load `../genius.md`. Views are not the goal unless they connect to trust, brand deals, creator-for-brand work, offers, hiring, or another explicit outcome.

## Input Required

- Person or brand account
- Current niche, audience, and content examples
- Monetization goal: brand deals, service work, offer sales, job leverage, audience building, or all
- Current offer, if any
- Strengths: expertise, locality, access, personality, proof, production ability

## Execution

1. **Diagnose Current Level**

| Level | Meaning | Goal |
|---|---|---|
| Create To Escape | Build the skill and optionality | Prove you can get attention |
| Turn It On | Use content for leads, jobs, sales, or meetings | Add explicit CTAs and proof |
| Scale With Personality | Build affinity and trust beyond value | Add storylines, relationships, and audience connection |

2. **Choose Niche Wedge**
   - Expertise niche
   - Locality niche
   - Passion niche
   - Industry niche
   - Buyer-problem niche
   - If unclear, use locality plus taste or expertise as the starting wedge.

3. **Build Content Pillars**
   - Intellectual/graphic-yap depth
   - Personality/storyline
   - Versus comparisons
   - History/context
   - In-person review/proof
   - Future predictions
   - CTA/offer proof

4. **Pick Monetization Path**
   - Brand deals: requires brand-relevant organic content and ad-whitelistable assets.
   - Creator-for-brand work: show niche competence and ask for clients.
   - Offer sales: package expertise into a named offer.
   - Career leverage: make skills and judgment visible.

5. **Design The Offer**
   - Name the offer.
   - Choose speed, price, or skill as the competitive basis.
   - Add an entry offer if the core offer is expensive.
   - Write the CTA stack: profile, stories, newsletter, posts, comments, and direct outreach.

## Content Type Adaptations

| Goal | Adaptation |
|---|---|
| Brand deals | Make unpaid content about brands/products in the niche before asking for sponsorship |
| Service clients | Repeat proof, process, and direct "taking clients" asks |
| Job leverage | Show judgment, taste, execution, and business understanding |
| Local growth | Become a specific guide to a place through your domain lens |
| High-trust consulting | Balance intellectual depth with personal proof and personality |

## Output Requirements

Produce:

- **Current Level Diagnosis**
- **Niche Wedge**
- **3-5 Content Pillars**
- **30-Day Posting Sprint**
- **Monetization Path**
- **Offer Stack**
- **CTA Calendar**
- **Traps To Avoid**

## Quality Gate

The map fails if it can generate attention but no buyer behavior. It passes when the content, audience, offer, and CTA all point to the same commercial outcome.
