# Oren Pricing Psychology Map

## Pre-Flight Gate

Load `../genius.md`, especially Product Mix As Price Psychology and Persona Data To Message. Price is a signal, not only a number.

## Input Required

- Product/service list with prices
- Current offer or product strategy
- Target customer segments or available customer data
- Brand position: value, premium, luxury, specialist, mass, niche, service, or software
- Current conversion problem or strategic goal

## Execution

1. **Audit Price Signals**
   - Identify anchors, charm/rounded pricing, lost price points, underpricing risk, and quality-signal gaps.
   - Mark where price is helping trust and where it is undermining trust.

2. **Map Product/Offer Jobs**

| Job | Definition | Common Mistake |
|---|---|---|
| Entry | Low-risk way into the ecosystem | Discounting the core instead of creating a true entry point |
| Core | Main repeatable business | Treating it as the only product story |
| Aspirational | Higher-price item that anchors perception | Expecting it to sell like the core |
| Halo | Ceiling-setting proof of brand ambition | Making it disconnected from the brand world |

3. **Build The Ladder**
   - Place current offers into entry/core/aspirational/halo.
   - Identify missing jobs.
   - Propose additions, removals, bundles, or reframes.

4. **Connect Personas**
   - Use real customer segments where available: LTV, repeat, use case, influence, buyer context.
   - Identify which segment buys which job.
   - Decide whether separate landing pages, email/SMS, or ads are needed.

5. **Write The Messaging**
   - For each meaningful persona, write headline, subhead, proof bullet, CTA, and objection answer.
   - Keep personas separate only when the message truly changes.

## Content Type Adaptations

| Business Type | Adaptation |
|---|---|
| E-commerce | Build entry/core/aspirational/halo SKU map and persona landing pages |
| Service | Use entry audit/workshop, core retainer/project, aspirational intensive, halo case study or flagship engagement |
| Software | Use free/entry plan, core plan, pro/enterprise anchor, and future-facing halo feature/story |
| Premium brand | Favor rounded pricing, insider proof, and aspirational/halo anchors |
| Value brand | Use charm pricing selectively and make value explicit without cheapening trust |

## Output Requirements

Produce:

- **Price Signal Audit**
- **Current Product/Offer Job Map**
- **Missing Ladder Pieces**
- **Recommended Ladder**
- **Persona Segment Map**
- **Persona Messaging Table**
- **Landing Page/Email/SMS Recommendations**
- **Next Pricing Test**

## Quality Gate

The ladder fails if every item is expected to do the same job. It passes when each product or offer has a clear acquisition, revenue, perception, or proof function.
