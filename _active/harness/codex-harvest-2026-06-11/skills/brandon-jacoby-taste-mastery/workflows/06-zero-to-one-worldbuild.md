# Brandon Jacoby - Zero-to-One Worldbuild

## Pre-Flight Gate

Load `../genius.md`. Treat the blank canvas as a company, product, brand, and user world, not just screens.

## Input Required

- Founder idea, offer, product, or new system concept
- Target user or buyer
- Current known problem
- Existing references or anti-references

## Workflow

1. **Define the New Thing**: State what is being created and why now.
2. **Map the World**: Identify product promise, brand feeling, user transformation, and company behavior.
3. **Design the First Five Artifacts**: Specify hero screens, offer assets, proof pieces, workflows, or demos.
4. **Choose Pattern vs. Invention Zones**: Decide where to be familiar and where to create new ground.
5. **Write the MVP Craft Bar**: Define what cannot be sloppy even in version one.
6. **Create the Founder Brief**: Produce a concise working document the founder can react to.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Startup | Focus on company identity, MVP, founder story, and first product behavior |
| Service offer | Focus on buyer moment, delivery artifact, and proof path |
| Internal system | Focus on command surface, operating rhythm, and adoption |
| Content brand | Focus on format world, taste codes, and repeatable signature |

## Output Requirements

- New thing statement
- World map
- First five artifacts
- Pattern/invention zones
- MVP craft bar
- Founder reaction prompts

## Quality Gate

Fails if it only defines a brand voice or visual style without product/company behavior.
