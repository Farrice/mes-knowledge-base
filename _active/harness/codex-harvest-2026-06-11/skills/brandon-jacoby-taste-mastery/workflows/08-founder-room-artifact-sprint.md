# Brandon Jacoby - Founder Room Artifact Sprint

## Pre-Flight Gate

Load `../genius.md`. The goal is to help the founder think by making the idea visible.

## Input Required

- Founder/client idea
- Current ambiguity
- What decisions are blocked
- Available source material or constraints

## Workflow

1. **Capture the Fog**: Write what is still vague, contradictory, or assumed.
2. **Make Wrong Options Useful**: Create artifact directions that are allowed to be rejected.
3. **Attach Questions to Artifacts**: Each artifact should test a founder belief.
4. **Read the Rejections**: Convert "not this" into sharper principles.
5. **Synthesize the Direction**: Produce a clearer product, brand, or workflow direction.
6. **Set the Next Making Step**: Define what artifact comes next.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Product | Produce screen concepts, flow options, or feature boundaries |
| Brand | Produce positioning routes, tone samples, or visual codes |
| Offer | Produce promise, package, and proof variants |
| System | Produce command, workflow, and output shape options |

## Output Requirements

- Fog map
- Three wrong-useful artifacts
- Belief tested by each artifact
- Rejection interpretation guide
- Synthesized direction
- Next artifact

## Quality Gate

Fails if artifacts are too polished to invite honest rejection.
