# Brandon Jacoby - System Taste Elevation

## Pre-Flight Gate

Load `../genius.md`. The system should produce stronger judgment, not just more output.

## Input Required

- Skill, workflow, agent, content system, or operating process
- Current output examples
- Desired quality change
- Related Antigravity skills

## Workflow

1. **Map the Current System**: Identify input, process, output, review, and deployment steps.
2. **Find Average-Producing Defaults**: Locate prompts, steps, or routing choices that create generic output.
3. **Insert Taste Decisions**: Add pattern/invention, good-enough, craft/consequence, or Weird C checks where they change output quality.
4. **Upgrade Output Shape**: Require artifacts, directives, scorecards, or deployment-ready assets.
5. **Add Stacking Routes**: Pair with Oren, Nate, Satori, Design MD, or content experts where useful.
6. **Produce the Upgrade Plan**: Define exact file, workflow, or command changes.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Skill | Upgrade SKILL.md routing, genius context, and workflow quality gates |
| Agent | Upgrade persona standards and handoff rules |
| Workflow | Add decision pressure, artifact outputs, and anti-slop gates |
| Content system | Add signature standards, reference loops, and format tests |

## Output Requirements

- System map
- Average-producing defaults
- Taste decision inserts
- Output-shape upgrades
- Stacking routes
- Implementation checklist

## Quality Gate

Fails if it only says "make it more tasteful" without concrete changes to the system.
