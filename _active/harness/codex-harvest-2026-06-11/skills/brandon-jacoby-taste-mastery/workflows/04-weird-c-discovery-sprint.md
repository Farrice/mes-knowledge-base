# Brandon Jacoby - Weird-C Discovery Sprint

## Pre-Flight Gate

Load `../genius.md`. Discovery happens by making. Do not stay in abstract ideation.

## Input Required

- Current A/B options or stuck decision
- Desired outcome
- Constraints and non-negotiables
- Available tools

## Workflow

1. **Define A and B**: State the obvious options and what each protects.
2. **Make Three Bad Starts**: Create deliberately rough artifact directions that violate one assumption each.
3. **Search the In-Between**: Identify accidental combinations, tensions, or fragments that feel alive.
4. **Name Weird C Routes**: Produce three third-option directions with rationale.
5. **Pick the Sharpest Test**: Choose the fastest artifact that can validate the route.
6. **Write the Sprint Plan**: Define 24-hour or 48-hour making steps.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Product concept | Produce rough screen routes and interaction hypotheses |
| Content series | Produce three format hybrids and sample hooks |
| Brand direction | Produce visual/tonal route sketches and rejected codes |
| Agent workflow | Produce alternate command shapes and output formats |

## Output Requirements

- A/B diagnosis
- Three bad starts
- Three Weird C routes
- Recommended test artifact
- Sprint schedule
- Kill/keep criteria

## Quality Gate

Fails if the output is only ideas and no artifact plan.
