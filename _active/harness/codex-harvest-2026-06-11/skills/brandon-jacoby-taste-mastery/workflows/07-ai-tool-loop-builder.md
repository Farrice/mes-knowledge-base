# Brandon Jacoby - AI Tool Loop Builder

## Pre-Flight Gate

Load `../genius.md`. AI should remove constraints and create new design surfaces while human taste stays in charge.

## Input Required

- Creative or operational bottleneck
- Current tools
- Desired output
- Human judgment criteria

## Workflow

1. **Name the Missing Tool**: Define the tool, generator, helper, or loop that would unlock better work.
2. **Separate AI Work from Human Taste**: Assign AI to generation, transformation, search, or implementation; assign humans to judgment and final direction.
3. **Specify the Loop**: Define input, AI action, human review, refinement, and output.
4. **Add Taste Checks**: Embed pattern/invention, craft/consequence, and good-enough checks.
5. **Define Failure Modes**: Identify where AI may flatten, overfit, or fake quality.
6. **Produce the Tool Brief**: Create instructions that can be handed to Codex, Claude, or a builder.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Design | Build variant, component, reference, or motion helpers |
| Content | Build angle, hook, remix, or editorial judgment loops |
| Research | Build reference clustering and pattern extraction loops |
| Agent system | Build routing, review, or artifact generation loops |

## Output Requirements

- Missing tool definition
- AI/human responsibility split
- Loop diagram in text
- Taste checks
- Failure modes
- Build brief

## Quality Gate

Fails if AI is asked to make the taste decision instead of producing material for human judgment.
