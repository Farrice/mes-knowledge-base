# Tom Segura Observational Story Layer

## Use When

A comedy pass needs stronger lived observation, story stakes, or written timing after Robert Mack's structural comedy layer has identified the broad comedy opportunity.

## Inputs

- Draft or premise.
- Audience.
- Desired reader response.
- Comedy structure chosen by Mack or `/comedy`.
- Trust and publication context.

## Steps

1. Confirm the comedy structure: observation, story, commentary, bit, pure joke, or odd angle.
2. Find the charge: what bothers, delights, pressures, or embarrasses the speaker.
3. If there is a story, write the reason-for-telling line before the anecdote.
4. If there is no story, write the obvious recognition line.
5. Expand the live moment briefly, then cut.
6. Replace dull accurate words with vivid accurate words.
7. Add only one callback unless the piece genuinely needs more.
8. Hand off to Sam Parr or `/publishable-copy-gate` when public trust or conversion matters.

## Output

```markdown
## Tom Observational Story Layer
- **Comedy structure:**
- **Charge found:**
- **Recognition or way-in line:**
- **Rewrite:**
- **Word-choice swaps:**
- **Callback decision:**
- **Trust/proof risk:**
- **Next gate:**
```

## Quality Gate

Pass only if the rewrite feels more observed and more necessary, not merely more joke-dense.
