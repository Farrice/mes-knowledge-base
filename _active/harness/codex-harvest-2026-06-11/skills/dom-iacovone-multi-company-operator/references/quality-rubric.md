# Quality Rubric

| Criterion | Strong Output | Weak Output |
|---|---|---|
| Source grounding | Names evidence windows and preserves uncertainty limits | Sounds like generic founder advice |
| Operating diagnosis | Identifies one primary bottleneck and supporting symptoms | Lists many possible issues without ranking |
| Metrics | Uses finance, margin, channel, or timing checks | Uses vibes, motivation, or vanity metrics |
| Stage gates | Produces go/revise/park/kill decisions | Encourages launching everything |
| Delegation | Separates owner, meeting, and escalation design | Tells founder to "delegate more" vaguely |
| Channel strategy | Maps incentives and sequence | Chooses retail or TikTok because it is trendy |
| Leakage | Converts hidden costs into operating or valuation impact | Mentions costs without action |
| Boundary safety | Flags medical/legal/tax/investment limits | Gives professional advice without qualification |

## Minimum Acceptable Output

- Current stage.
- Bottleneck verdict.
- Evidence or assumptions.
- Recommended workflow.
- Operating map.
- First next move.
- Stop condition.
