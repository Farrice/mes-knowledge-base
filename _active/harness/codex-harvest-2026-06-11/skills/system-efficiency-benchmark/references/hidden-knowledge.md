# System Efficiency Benchmark - Hidden Knowledge

## Why This Exists

Antigravity has enough workflows that the obvious failure mode is not missing capability. It is choosing, loading, and proving the right capability without asking Farrice to rebuild the operating system every session.

## Practical Boundary

Plugin packaging is a distribution and reliability wrapper. It should wrap proven workflows; it should not become a new brain or a whole-library conversion project.

## Strong Default

When the benchmark is mixed, prefer:

1. router weighting
2. command metadata cleanup
3. skill description tightening
4. deterministic checks
5. workflow consolidation
6. plugin packaging

Packaging moves up the list only when fresh-thread behavior or portability is the real bottleneck.
