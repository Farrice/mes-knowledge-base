# Reader Value Audit

Use this when a draft feels smart but not useful, long but not valuable, or polished but forgettable.

## Pre-Flight Gate

Input should include a draft, outline, or excerpt. If the title exists, include it. If no title exists, infer the promise from the opening.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-nonfiction-value-architecture/references/quality-rubric.md`

## Execution

1. Identify the draft's apparent promise.
2. Identify the value mode the draft appears to use.
3. Audit whether the piece gives the reader a list of deliverables.
4. Mark meandering sections where the writer is expressing instead of giving.
5. Identify bundled terms and unsupported claims.
6. Rewrite the outline around a stronger spotlight mode.
7. Recommend cuts, upgrades, and value-stack additions.
8. Provide a revised skim path.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Preserve recurring voice while fixing the edition promise |
| LinkedIn post | Prioritize hook-to-bullet alignment |
| Article | Audit title, intro, H2s, and examples |
| Client draft | Separate voice preservation from value repair |
| Sales education content | Add reasons, mistakes, and examples to increase conviction |

## Output Requirements

Return:

- Promise diagnosis
- Reader-value score
- Value-mode mismatch notes
- Bundled-term audit
- Meandering-section cuts
- Revised outline
- Rewrite instructions

## Quality Gate

Do not simply copyedit. If the piece lacks clear value, repair the value architecture before sentence-level polish.
