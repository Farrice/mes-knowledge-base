# Ten Value Expander

Use this when the user has a topic or draft and needs richer expansion angles without drifting into filler.

## Pre-Flight Gate

The source idea must be stated in one sentence. If there is already a title, use it as the promise to expand.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-nonfiction-value-architecture/references/genius-patterns.md`

## Execution

1. Identify the current implied value mode.
2. Generate expansion angles for all ten modes:
   - Tips: what should the reader do?
   - Stats: what quantified proof changes their belief?
   - Steps: what sequence removes confusion?
   - Lessons: what should they learn before paying the cost?
   - Benefits: why should they care?
   - Reasons: why is this true or worth doing?
   - Mistakes: what should they avoid?
   - Examples: where can they see the pattern?
   - Questions: what should they ask themselves?
   - Story: what proof gives confidence?
3. Select the strongest primary mode and 2-3 supporting modes.
4. Convert the selected modes into outline candidates.
5. Remove expansion ideas that add content but not value.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Select one recurring value mode that fits the newsletter's tangible faucet |
| Blog/article | Use supporting modes as sections or subsections |
| LinkedIn post | Use one primary mode plus one supporting example or question |
| YouTube script | Use modes as retention beats across the script |
| Course lesson | Prefer steps, examples, mistakes, and questions |

## Output Requirements

Return:

- Ten-mode expansion grid
- Primary value recommendation
- Supporting value stack
- Outline angle options
- Discard list for low-value filler

## Quality Gate

Every expansion must give the reader something. Do not include abstract commentary unless it becomes a tip, stat, step, lesson, benefit, reason, mistake, example, question, or story.
