# Newsletter Value Draft

Use this when the user wants a draft, not just an outline, but the draft must be built from reader value rather than meandering opinion.

## Pre-Flight Gate

Input must include topic, audience, and desired outcome. If the value mode is not chosen, run a quick internal Value Spotlight Map first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-sentence-craft/genius.md` only after the value outline is complete

## Execution

1. Define the reader problem and desired outcome.
2. Choose the spotlight value mode.
3. Build the deliverable list.
4. Run Specificity Ladder on weak points.
5. Create title and subheads that pass the Subhead Skim Test.
6. Draft the piece section by section.
7. Add one supporting value mode where it increases usefulness.
8. Apply a light Cole sentence-craft pass:
   - Compress redundancy
   - Strengthen terminal words
   - Preserve clarity over cleverness
9. Run final quality gate.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Use intro promise, value sections, and closing action |
| Article | Use H2s and examples to make the skim path obvious |
| LinkedIn post | Convert sections into compressed bullets or short paragraphs |
| YouTube script | Add spoken transitions and retention questions |
| Client ghostwriting | Keep client voice markers intact during final polish |

## Output Requirements

Return:

- Value architecture summary
- Title options
- Final outline
- Draft
- Skim-path check
- Final quality notes

## Quality Gate

The final draft must make the promised value visible in title, subheads, and body. If the draft sounds good but the reader cannot name what they got, it fails.
