# Specificity Ladder

Use this when a draft or outline uses broad advice that sounds true but does not feel useful.

## Pre-Flight Gate

Input must include a list of claims, tips, subheads, or draft sections. If the user provides a full draft, extract the weakest broad claims first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-nonfiction-value-architecture/references/quality-rubric.md`

## Execution

1. Identify bundled terms: love, push, accountability, consistency, mindset, discipline, authenticity, trust, authority, confidence, value, quality, and similar broad words.
2. For each bundled term, ask: "What does this look like in a literal moment?"
3. Convert the broad advice into an observable action.
4. Add a measurable or judgeable standard where possible.
5. Rewrite the line at three levels:
   - Level 1: broad claim
   - Level 2: concrete action
   - Level 3: concrete action plus measurable standard
6. Keep the version that gives the reader the most immediate instruction without overexplaining.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Upgrade section subheads and bullets before drafting |
| LinkedIn post | Upgrade the hook promise and numbered points |
| Client thought leadership | Preserve client phrasing only if it remains specific |
| YouTube script | Translate broad beats into scenes, moments, or examples |
| Lead magnet | Turn each broad rule into a checklist item |

## Output Requirements

Return:

- Bundled-term audit
- Specificity ladder table
- Rewritten points
- Measurability notes
- Remaining claims that need evidence or examples

## Quality Gate

A line fails if the reader could nod but still not know what to do. A line passes when the reader can imagine, measure, or execute it.
