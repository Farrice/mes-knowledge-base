## Virtuoso Smoke Test

Ask:

> Show the Virtuoso Trace for a system audit that elevates agents, subagents, orchestration, and cross-pollination.

Pass means Codex uses `/virtuoso` as the front door, routes ownership to
`/system-audit`, surfaces the evidence-backed stack, names one owner, shows
composition slots, keeps subagents gated, separates considered gates from
executed surfaces, and lists the verification plan.
