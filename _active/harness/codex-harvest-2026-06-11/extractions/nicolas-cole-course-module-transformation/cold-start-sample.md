# Cold-Start Sample - Course Module Architect

Scenario: Build a course module for an AI consulting ICP that helps them turn a messy client process into a paid implementation offer.

## Course Module Blueprint

### Action Lock

| Decision | Answer |
|---|---|
| Buyer start state | AI consultant sees messy client operations but cannot package the problem into a paid implementation offer. |
| Buyer desired state after module | Consultant has a named client process map, pain-to-outcome bridge, and first paid implementation offer draft. |
| Main action | Convert one messy client process into a paid implementation offer. |
| Visible output | One-page Implementation Offer Map. |
| Why this action matters | Without a mapped process, the consultant sells vague AI help; with the map, they can sell a concrete business outcome. |

### 7-Section Module Stack

| Section | Module Content |
|---|---|
| Reasons Why | Vague AI consulting is hard to buy; messy processes reveal urgent operational pain; mapped workflows make ROI visible; a process map gives the consultant a delivery path; the offer becomes easier to price because the before/after is concrete. |
| Mistakes To Avoid | Selling tools instead of outcomes; mapping every department at once; using AI jargon in the offer; skipping the current-state workflow; promising automation before diagnosing bottlenecks; pricing by hours instead of value of the fixed process. |
| Micro-Steps | Pick one process; name the triggering event; list every handoff; mark delays, rework, duplicate entry, and decision waits; translate each pain into cost/time/risk; define the improved end state; write the offer promise; attach one implementation deliverable. |
| Questions And Uncertainties | What if the client has multiple problems? What if I do not know their tools yet? How do I estimate ROI? What if the process is too complex? How do I avoid sounding technical? What should the first deliverable be? What should I charge? |
| Walkthrough Or Proof | Show a before/after map: "manual lead intake across email, spreadsheet, and CRM" becomes "48-hour Lead Response Cleanup Sprint with one intake form, CRM routing, and follow-up dashboard." |
| Bonus Asset | The Messy Process To Paid Offer Worksheet: a fill-in template for current state, bottleneck, cost, improved state, deliverable, proof, and price anchor. |
| Assignment | Complete the worksheet for one real or hypothetical client process and write a 5-line offer draft. |

### Micro-Step Checklist

1. Choose one messy process with visible pain.
2. Write the current process in 5-9 handoffs.
3. Circle the top 3 bottlenecks.
4. Translate each bottleneck into money, time, risk, or frustration.
5. Define the improved workflow in one sentence.
6. Name the implementation sprint.
7. Write the offer: "I help [ICP] fix [process] so they can [outcome] without [pain]."

### Completion Evidence

Buyer submits or saves:

- One current-state process map.
- One bottleneck-to-value table.
- One named implementation offer.
- One 5-line offer draft.

### Vehicle-Fit Accountability

For a sub-$350 product, use a self-check rubric and example answer. For a cohort or higher-ticket offer, require submission in a shared channel and review the offer draft live.
