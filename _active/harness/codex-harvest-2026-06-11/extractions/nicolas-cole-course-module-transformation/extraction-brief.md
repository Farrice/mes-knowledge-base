## Build Decision

This is an expansion of `skills/nicolas-cole-digital-products`, not a standalone skill. The existing skill already owns vehicle selection, pricing, offer stacking, and product ecosystem strategy. The missing capability is course/module transformation: designing information products that create action, completion, visible results, and ICP-specific value.

## Extracted Operating Method

1. Start with the transformation, not the information.
2. Identify the buyer's current state, desired state, proficiency band, and questions.
3. Turn the path into actions; each module is one task.
4. Build each module with the 7-section stack: reasons why, mistakes, micro-steps, questions, proof, bonus asset, assignment.
5. Use bonuses to raise perceived value only when they directly help the buyer complete the action.
6. Use assignments to crystallize the main action into a visible output.
