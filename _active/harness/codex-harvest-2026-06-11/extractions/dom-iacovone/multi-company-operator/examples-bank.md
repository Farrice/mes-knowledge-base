# Examples Bank

## SGM Portfolio Planning

Pattern: A portfolio company sets annual initiative blocks, converts them into weekly finance and operating checks, and uses those checks to decide whether to keep pushing, correct course, or reallocate.

Antigravity use: when a future source-to-skill run has too many principles, force the extraction into four operating blocks and weekly proof surfaces.

## C-suite Operators As Internal Entrepreneurs

Pattern: Executives and brand managers are expected to solve problems proactively, not wait for the founder to dictate moves.

Antigravity use: when evaluating an AI employee, agent, or skill system, check whether each component owns a decision surface or only completes assigned tasks.

## Stage-Gated Product Innovation

Pattern: A product must make sense, improve the category, create margin, and fit the channel before it deserves launch energy.

Antigravity use: apply the same gate to new commands, skills, and workflows: distinct need, better mechanism, maintainable economics, and correct routing surface.

## TikTok To Amazon To Retail

Pattern: Demand is created through TikTok/influencer seeding, spills into Amazon, then supports retail expansion.

Antigravity use: for business/client work, map channels as a sequence rather than isolated tactics. For harness work, map source acquisition -> evidence package -> skill surface -> router discovery.

## Walmart Buyer Mistake

Pattern: A buyer request produced SKUs that fit shelf demands but drifted from brand/product truth.

Antigravity use: when a user request asks for a tempting artifact, preserve the underlying objective. Do not let the requested format override the system's truth.

## DSD Store Execution

Pattern: Direct retail can secure shelf presence, but distributor/store execution incentives may determine whether inventory actually moves.

Antigravity use: route commands based on execution incentives, not surface existence. A workflow existing in `.agent/workflows/` is not enough if it is not discoverable and used.

## Trade Spend And Logistics Leaks

Pattern: Deductions, freight, warehouse geography, and 3PL costs quietly reduce margin and valuation.

Antigravity use: add "leakage audits" to business systems and harness systems. In harness terms, leaks include dead wrappers, stale registries, duplicate routes, and unverified artifacts.

## Onside Target Exception

Pattern: A broad retail launch can be correct when partner strength, category setup, buyer support, end-cap visibility, and margin/velocity expectations align.

Antigravity use: allow exceptions, but only when the exception has stronger evidence than the default rule.
