# Cold-Start Route: StoryBrand Message Clarity System

## Use When

Use `/storybrand-message-clarity-system` when the user asks for:

- message clarity
- StoryBrand sound bites
- a one-liner that can be repeated everywhere
- a homepage or offer message that is too confusing
- a business message that customers should instantly understand
- soundbite strategy, PEACE sound bites, or cognitive-load reduction

## Start Command

```bash
/storybrand-message-clarity-system [business context, website, offer, or pasted copy]
```

## Cold-Start Reads

1. `extractions/donald-miller/storybrand-message-clarity-system/source-map.md`

## Minimum Inputs

- Business name
- What it sells
- Target customer
- One primary customer problem
- Optional existing copy, website, offer text, or active channels

## Default Output

Produce a Message Clarity Pack with:

1. One-hole problem lock
2. Cognitive-load diagnosis
3. Five locked PEACE sound bites
4. StoryBrand one-liner
5. BrandScript alignment notes
6. Deployment matrix
7. Monthly consistency audit

## Default Channels

If active channels are not supplied, use this default set:

- website hero
- social bio or profile headline
- pinned post
- email signature
- sales-call opener
- proposal cover
- newsletter subject line

## Stop Conditions

- Stop and ask when no business, customer, or offer can be identified.
- Stop and ask when the problem cannot be reduced to one specific customer pain.
- Do not claim visual evidence from the source videos unless a future full-mode ledger captures frames or OCR.
