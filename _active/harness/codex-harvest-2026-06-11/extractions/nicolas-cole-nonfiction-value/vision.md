## Extraction Decision

This is a distinct expansion of Nicolas Cole, not a replacement for existing sentence craft. The source sits one level above sentence mechanics: it defines how a nonfiction piece creates reader value before drafting begins.

The method adds a missing routing layer between:

- `nicolas-cole-sentence-craft`: how each sentence earns attention.
- `nicolas-cole-newsletter-flywheel`: how a recurring newsletter creates a tangible faucet.
- `nicolas-cole-nonfiction-value-architecture`: how one nonfiction piece decides what value it is giving, makes that value visible in the outline, and raises specificity until the reader can act.

## Leverage

This skill should be used before writing or editing any educational nonfiction asset: newsletters, LinkedIn posts, scripts, blog posts, playbooks, lead magnets, client ghostwriting drafts, and thought-leadership articles.

Core use case: turn a vague topic like "raise high agency kids" into an explicit reader-value promise, a list of deliverables, and subheads that pass the four-second skim test.

## Architecture

Build as eight practitioner workflows:

1. Value Spotlight Map
2. Ten Value Expander
3. Specificity Ladder
4. Subhead Skim Test
5. Nonfiction Outline Architect
6. Reader Value Audit
7. Value Stack Remix
8. Newsletter Value Draft

Each workflow should load the same genius context and enforce Cole's two core gates:

- What am I giving the reader?
- Did I unbundle the language enough that the reader can imagine, measure, or do it?
