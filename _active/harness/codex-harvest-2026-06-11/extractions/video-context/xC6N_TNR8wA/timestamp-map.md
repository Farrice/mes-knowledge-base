## Naming Notes

- The source uses `calibrate`, but Antigravity already has `/calibrate` as a monthly system scorecard. The daily learning command is therefore `/session-calibrate`.
- The third source skill name is not clearly recoverable from the captions. The behavior is clear, so Antigravity names it `/project-onboard`.
- `/project-coordinate` and `/project-onboard` are paired: one creates/updates the shared project context, the other loads it.
