# Niche Bending Examples

## Source-Backed Examples

| Example | Source Mechanic | Why It Matters |
|---|---|---|
| Sports title structure reused in gaming and spirituality | Same promise structure, different market | Shows that a format can travel when the psychological promise is portable. |
| Animal biology through gaming language | Borrowed fluency and visual language transfer | Shows that the bend must include vocabulary and visual grammar, not only a clever title. |
| "Every X explained in Y minutes" across markets | Empty square mapping | Shows how one long-lived format can be checked against many markets to find open cells. |
| POV NPC format moved across game-related markets | Same premise, different audience context | Shows that a format can become a repeatable series after one market proves it. |
| "Which one dies first" applied beyond casinos | Outlier skeleton extraction | Shows how a title premise can become a cross-market risk-ranking format. |

| Target Expertise | Borrowed Format | Possible Bend | Expertise Payload |

## Production Example Shape

Each final bend should include:

- **Bend**: `[Target Market] + [Borrowed Format]`
- **Title**: one concrete title
- **Hook**: first 1-3 lines or first 15 seconds
- **Skeleton**: the format beats to preserve
- **Payload**: the real expertise being delivered
- **Borrowed fluency**: terms and metaphors from the source format
- **Visual language**: thumbnail, layout, motion, or graphic cues
- **Validation**: pass, conditional, or reject

## Anti-Examples

- Generic educational content with a trendy title but no format skeleton.
- Borrowing slang without understanding the source culture.
- Ranking, roasting, or dramatizing a topic the user cannot explain deeply.
- Choosing a format because it is novel, not because it creates an audience bridge.
