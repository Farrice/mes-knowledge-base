# Niche Bending Operating Mechanics

## Core Equation

Niche = Market + Format.

The market is the audience vertical or expertise arena. The format is the delivery container: title structure, pacing, visual grammar, narrative arc, interaction pattern, or recurring premise.

Do not start by asking, "What topic should I post about?" Start by asking, "Which proven format has not yet been used in this market by someone with real expertise?"

## Command Sequence

1. **Expertise Constraint**
   - Name the domain expertise.
   - Identify what the user can credibly teach, diagnose, rank, review, narrate, or demonstrate.
   - Reject formats that require expertise the user does not have.

2. **Demand And Staleness Scan**
   - Confirm the market has existing demand.
   - Identify the dominant stale format in the market.
   - Treat saturation as a demand signal, not as a reason to avoid the market.

3. **Outlier Format Scout**
   - Find formats that outperform baseline in other markets.
   - Prefer smaller channels or smaller accounts with outsized performance.
   - Extract the format skeleton instead of copying the subject matter.

4. **Empty Square Grid**
   - Rows: the target market plus adjacent markets.
   - Columns: proven viral formats.
   - Mark occupied, emerging, empty, and incompatible cells.
   - Prioritize empty cells with strong expertise fit.

5. **Borrowed Fluency Map**
   - Capture native vocabulary from the source format.
   - Translate that vocabulary into the target expertise.
   - Require enough fluency that the bend feels native, not decorative.

6. **Visual Language Notes**
   - Specify thumbnail signals, UI patterns, overlays, pacing, camera behavior, props, and recurring visual motifs.
   - The visual language should match the borrowed format while the substance remains true to the target market.

7. **Production-Ready Bends**
   - Produce three concepts that can be made immediately.
   - Each concept needs a title, hook, format skeleton, expertise payload, visual language, and validation verdict.

## Handoff Shape

Each phase passes a compact handoff:

- **Input**: what the phase received.
- **Decision**: what was selected or rejected.
- **Evidence**: source timestamp, user context, or scout signal.
- **Output**: the object the next phase needs.
- **Risk**: the exact uncertainty or weak spot.

## Anti-Gimmick Rule

Format novelty is not enough. A bend is good only when the borrowed format helps the audience absorb valuable expertise they would otherwise skip.

Reject any idea that is entertaining but thin, visually clever but low-value, or linguistically borrowed without real domain insight.
