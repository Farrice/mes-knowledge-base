## Source Role

This video is the command spine for the Niche Bending Command OS. It explains how to treat a niche as the combination of a market and a format, then use proven formats from one market inside another market where that format has not yet been used well.

Use the existing `tim-danilov-niche-bending` skill as the expert core. Use `/niche-bending-system` when the user wants end-to-end execution: strategy, scouting, grid mapping, borrowed fluency, production concepts, and validation.
