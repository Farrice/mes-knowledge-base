# Niche Bending Quality Gates

## Gate 1: Expertise Constraint

Pass when the user can credibly deliver high-value knowledge inside the borrowed format.

Reject when the format requires expertise, taste, data, or cultural fluency the user does not have.

## Gate 2: Format Proof

Pass when the borrowed format has observable performance proof, preferably from smaller channels or accounts where distribution is not the main explanation.

Conditional when the format is interesting but not yet proven.

## Gate 3: Market Proof

Pass when the target market has visible demand, active competitors, buyer/search interest, community attention, or recurring audience pain.

Reject when the market is only personally interesting but has no demand signal.

## Gate 4: Empty Square

Pass when the target market and proven format have not been combined well by established players.

Conditional when the cell is emerging but not yet owned.

## Gate 5: Borrowed Fluency

Pass when the content uses the source format's native logic, vocabulary, pacing, and metaphors.

Reject when it only borrows a title template or a few trendy words.

## Gate 6: Visual Language

Pass when thumbnail, layout, graphics, motion, and on-screen signals clearly match the borrowed format.

Conditional when visual execution is not needed for the selected platform.

## Gate 7: Payload Value

Pass when the audience learns something specific and useful that could not be replaced by generic content.

Reject when the piece is entertaining but does not teach, clarify, prove, or change the audience's judgment.

## Gate 8: Production Readiness

Pass when the idea has a title, hook, structure, expertise payload, visual direction, and success metric.

Reject when it is only a strategic direction.

## Verdict Language

- **Pass**: make this first.
- **Conditional**: fix the named risk before production.
- **Reject**: do not make this version; choose another format or market.
