# Niche Bending Failure Modes

| Failure Mode | Early Signal | Prevention | Recovery |
|---|---|---|---|
| Duplicate skill bloat | A new standalone skill repeats `tim-danilov-niche-bending` | Use `/niche-bending-system` as an orchestrator over the existing skill | Move duplicate material into the extraction package or references |
| Topic thinking | The output says "make content about X" without naming the format | Force the `Market + Format` equation | Rewrite every idea as a bend |
| Gimmick wrapper | The concept is funny but the expertise is shallow | Run the expertise constraint before ideation | Reject or choose a format the user can fill |
| Source-market tourism | Borrowed language feels like random slang | Build a borrowed fluency map | Replace decorative terms with structural metaphors |
| Empty square fantasy | No proof the format or market has demand | Require format proof and market proof separately | Mark as speculative and run a scout pass |
| Big-channel bias | The format only worked because a huge creator posted it | Prefer small-channel outliers | Re-scout for lower-distribution proof |
| Visual claim overreach | The command describes on-screen details without frame/OCR evidence | Use only observed frame existence unless reviewed | Rerun OCR/vision or downgrade to transcript-backed |
| Platform mismatch | A YouTube format is pasted into LinkedIn without adaptation | Add platform-native translation | Rebuild hook, pacing, and surface for the target platform |
| Overbuilt grid | The grid is huge but produces no usable concept | Cap the grid at the smallest set that reveals a strong empty square | Move to three production-ready bends |
| No experiment | The pack ends with strategy but no test | Always produce a first experiment | Add title, hook, production notes, and decision metric |
