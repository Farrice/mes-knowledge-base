# Antigravity Semantic Library

This library makes recurring Codex Antigravity work legible to agents.

## Start Here

1. Read `authority-model.md`.
2. Read `primitive-map.md`.
3. Load the specific primitive in `primitives/`.
4. Use `validation-log.md` to record cold-start execution tests.

## First Primitives

| Primitive | File | Use |
|---|---|---|
| Agent Workflow Update | `primitives/agent-workflow-update.md` | Any edit that changes future agent or command behavior |
| Command Bridge Creation | `primitives/command-bridge-creation.md` | Any new or updated slash command that must work across workflow, Claude command, and Codex skill surfaces |
| Client Audit Delivery | `primitives/client-audit-delivery.md` | Fast paid diagnostic or proof-first delivery for a client |
| High-Floor Operator OS | `primitives/high-floor-operator-os.md` | Default Light / Standard / Deep / Parallel operating standard and No-Lazy-Path gate |
| Source-To-Skill Extraction | `primitives/source-to-skill-extraction.md` | Any source-to-capability build, including extract, forge, companion skill, workflow, reference, or business asset |
| Collaborative Steering Compass | `primitives/collaborative-steering-compass.md` | Operator Coach guidance at kickoff, major decision points, and closeout |
