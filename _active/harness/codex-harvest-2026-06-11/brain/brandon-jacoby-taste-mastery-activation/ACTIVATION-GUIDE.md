# Brandon Jacoby Taste Mastery - Activation Guide

## What This Adds

This package adds a taste deployment layer to Antigravity. Use it when the system already can produce work, but the work needs stronger judgment, a sharper signature, or a better decision about where to follow patterns and where to invent.

## Highest-Value Use Cases

| Use Case | Objective | First Command |
|---|---|---|
| Personal taste persona | Turn Farrice's standards into reusable operating rules | `/jacoby-taste-profile` |
| Anti-average revision | Push clean output past good enough | `/jacoby-good-enough` |
| Product or workflow decisions | Decide where to use convention vs. invention | `/jacoby-pattern-invention` |
| Content and offer quality | Align craft with business consequence | `/jacoby-craft-consequence` |
| New product or company shaping | Build the first product/company world brief | `/jacoby-worldbuild` |
| Founder/client ambiguity | Create useful wrong artifacts to sharpen direction | `/jacoby-founder-room` |
| AI-era creative work | Build a custom AI loop while preserving taste authority | `/jacoby-ai-tool-loop` |
| System-wide upgrade | Add taste checks to skills, workflows, agents, and content systems | `/jacoby-system-elevation` |

## Recommended Starter Sequence

### Day 1: Build Farrice's Taste Master Profile

Run:

```text
/jacoby-taste-profile
```

Input:

- 3 to 5 examples of your best work or favorite references.
- 3 examples of work that feels generic, too safe, or "not it."
- One current offer, workflow, content piece, or system you want upgraded.

Output to keep:

- Personal taste persona.
- Decision rules.
- Good-enough warning signs.
- Personal quality bar.

### Day 2: Upgrade One Live Asset

Run:

```text
/jacoby-good-enough
```

Use it on one draft that is already functional. The goal is not to rewrite everything. The goal is to find the few places where better taste changes the result.

### Day 3: Add the Taste Layer to a System

Run:

```text
/jacoby-system-elevation
```

Use it on one high-use workflow or skill. Best first targets:

- Content generation workflows.
- Offer creation workflows.
- Design or brand workflows.
- Agent/persona workflows that produce client-facing output.

### Day 4: Add Cross-Expert Quality Control

Recommended chain:

```text
/jacoby-pattern-invention
/design-taste-gate
/jacoby-craft-consequence
```

Use this when an asset needs both design quality and product/business consequence.

## Operating Rule

Do not run Brandon as a generic critic. Run him after there is a draft, artifact, workflow, or decision on the table. His highest value appears when there is something concrete to improve, reject, simplify, or push past good enough.
