## Reusable System Pattern

When Farrice brings in an inspiration transcript, video, creator, game, film, app, or artifact:

1. Save it in `ideation-bank/inspiration-sources/`.
2. Extract the remembered moments, feelings, mechanics, and Farrice translations.
3. Run the closest workflow, usually a source-specific skill if one exists.
4. Save workflow output in `ideation-bank/workflow-runs/`.
5. Push the strongest seeds into `content-seeds.md` and drafts into the appropriate content folder.
