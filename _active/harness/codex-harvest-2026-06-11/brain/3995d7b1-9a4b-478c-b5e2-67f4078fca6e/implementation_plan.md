# Kallaway Word Mastery Expansion: 7 → 13 Workflows

## The Problem

Current 7 workflows are **mechanics-focused** — they rewrite content FOR a specific quality (rhythm, tone, grip, believability). They're the technical layer. What's missing: **dynamic, creative deployment workflows** — HOW you deploy world-class expertise so it hits with maximum impact, entertainment, and resonance. The "final piece."

## The Gap

| Current 7 (Mechanics) | Missing (Dynamic Deployment) |
|----------------------|---------------------------|
| Rewrite for rhythm | Deploy expertise so it *radiates* through casual prose |
| Shift to a tone register | Architect *creative register shifts* within a piece for entertainment |
| Add proof + admissions | Engineer vulnerability *narrative arcs* that make expertise hit 3x harder |
| Audit for inauthenticity | Transmute *energy* from extraction to service mode |
| Apply full stack sequentially | Engineer the *gestalt* — the invisible charisma that emerges when all elements harmonize |
| Exercise for muscle-building | Forge the *single sentence* that determines whether anyone reads the rest |

---

## 6 New Workflows

### 1. Written Charisma Engineering (`charisma`)
**Slash**: `/word-charisma`

Not rhythm. Not tone. Not grip. The **gestalt** — the invisible "I can't explain why I love this writer" effect that emerges when all elements harmonize. This is the difference between technically-correct writing and writing that makes people follow you.

> **Deployment**: Diagnose which charisma elements are present/absent → engineer the missing ones → calibrate the harmony between all layers → produce content with the unnameable "it factor."

### 2. Energy Transmutation Engine (`energy`)
**Slash**: `/word-energy`

Content written to extract (views, followers, revenue) creates subtle pressure. Content written to serve creates magnetic pull. This workflow takes any content and **transmutes the underlying energy** — from asking-for-a-favor to doing-you-a-favor. The single biggest invisible difference between content that converts and content that repels.

> **Deployment**: Diagnose energy polarity → identify extraction markers → flip to service framing → inject HTBT energy markers → verify with the "favor test."

### 3. Code-Switch Architect (`code-switch`)
**Slash**: `/word-switch`

Creative register-shifting **within a single piece** for maximum texture and entertainment. The entertainment layer. Open casual → escalate to authoritative → punctuate with comedic → close intimate. The switch itself creates energy — monotone register is forgettable.

> **Deployment**: Map the emotional arc → assign registers to each section → engineer the switch points → create texture through juxtaposition → produce content that entertains while teaching.

### 4. Vulnerability Architecture (`vulnerability`)
**Slash**: `/word-vulnerable`

Not "add a vulnerability." Full **narrative architecture** around the admit → solve → compound arc. When done right, one genuine admission makes everything after it hit 3x harder. This is how world-class expertise FEELS earned instead of claimed.

> **Deployment**: Identify the authentic struggle → architect the narrative arc → engineer the payoff → position the expertise as EARNED by the failure → produce content where vulnerability IS the proof.

### 5. Opening Sentence Forge (`opener`)
**Slash**: `/word-opener`

The single most important sentence in any piece. A dedicated forge for engineering openers that use paradox, conflict, and specificity to make the reader PHYSICALLY unable to stop. Every other workflow assumes you have their attention. This one GETS it.

> **Deployment**: Generate 20+ opener candidates using paradox/conflict/specificity templates → stress-test each against skip-likelihood → select and refine → deliver the one sentence that determines everything.

### 6. Expertise Deployment Engine (`deploy`)
**Slash**: `/word-deploy`

The **pinnacle workflow**. Takes world-class expertise and determines the RIGHT vehicle to deploy it — story, hot take, proof stack, vulnerability arc, demonstration, analogy, or pattern interrupt. Then deploys it through casual, grip-engineered prose that RADIATES authority without lecturing.

> **Deployment**: Audit expertise depth → match to optimal deployment vehicle → apply the right combination of charisma, energy, code-switching, and grip → produce content where expertise feels RADIATED, not stated.
