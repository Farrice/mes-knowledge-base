# LinkedIn AI Consulting Cache Bank V1

## Active Entry Point

Use the source copies in `document-artifacts/` as the active persistence layer for the LinkedIn AI consulting and creative strategy cache bank.

This package is built around the current hybrid positioning:

> Creative Strategist + AI Operating Partner for founder-led experts turning customer language, founder judgment, and repeatable marketing work into agent-ready systems.

## Active Source Set

| Source Copy | Job |
|---|---|
| `00-control-room.md` | Mission charter, execution order, composition ledger, quality gates, and deployment sequence. |
| `01-market-research-icp-offer.md` | Market research, buyer thesis, ICP builds, customer language, and product offer. |
| `02-content-featured-post-cache.md` | Featured section copy, flagship posts, hooks, first comments, comment bank, and post cadence. |
| `03-outreach-feed-analysis-prompts.md` | Manual LinkedIn outreach system, browser-assistant prompts, feed analysis prompts, and DM/comment templates. |
| `04-visual-asset-briefs.md` | LinkedIn banner, featured cover, carousel, Loom thumbnail, and diagnostic visual prompts. |

Supporting file:

- `signal-tracker-template.csv` - lightweight tracking sheet for comments, DMs, artifacts, mini-diagnoses, and paid-bridge follow-up.

## Non-Negotiables

- No generic AI consultant positioning.
- No "I need clients" or runway language.
- No automated LinkedIn commenting, liking, DMs, scraping, or fake engagement.
- No `.docx`, HTML, Canva, Google Docs, Notion, or PDF export unless explicitly requested.
- All public copy must make the buyer feel the exact moment: "It looks finished, but I still have to rescue it."

## First Deployment Order

1. Update Featured section from `02-content-featured-post-cache.md`.
2. Publish the flagship post.
3. Comment manually on 10 relevant posts using `03-outreach-feed-analysis-prompts.md`.
4. Send contextual DMs only after engagement or obvious public-fit signal.
5. Use the visual asset briefs to create the first featured cover or diagnostic carousel.
