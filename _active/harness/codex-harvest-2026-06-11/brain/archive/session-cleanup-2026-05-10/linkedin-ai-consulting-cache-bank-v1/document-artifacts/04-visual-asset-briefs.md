# Visual Asset Briefs

## Visual System

The visual identity should feel diagnostic, not futuristic.

Use:

- annotated documents
- redline marks
- margin notes
- before/after frames
- proof screenshots with sensitive info removed
- simple maps from "guess" to "missing rule"
- clean typography
- restrained palette with one sharp accent

Avoid:

- robots
- glowing brains
- cyberpunk grids
- generic AI interface art
- gradient blobs
- stock-photo strategy rooms
- fake dashboards with no real work shown

## Asset 1: LinkedIn Featured Cover

| Field | Direction |
|---|---|
| Title | The Marketing System Misfire Map |

| Visual | A clean document page with 3 highlighted "guess points" and margin labels: customer language, proof standard, stopping rule. |
| CTA | DM `GUESS` with one output. |
| Size | LinkedIn document/featured cover safe area; keep headline readable on mobile. |

### Image Prompt

```text
Create a clean LinkedIn featured cover for a premium AI consulting diagnostic called "The Marketing System Misfire Map." Visual style: modern editorial document teardown, white/off-white background, black typography, one sharp red or electric blue accent, annotated margins, three highlighted lines labeled "customer language," "proof standard," and "stopping rule." No robots, no futuristic glow, no stock photos. The image should feel like a strategist marking up a real work artifact. Leave enough negative space for title text.
```

## Copy Gate Result

**Verdict:** PASS  
**Scope:** Visual system, featured cover, carousel, Loom thumbnail, banner, comment coverage card.  
**Expert deployment evidence:** Creative Design pass converted the offer mechanism into visual proof objects; Risk Gate removed generic AI aesthetics; Copy pass kept all text artifact-first and mobile-readable.  
**Prose/slop review:** Manual visual anti-slop pass: no robots, no glow, no vague futuristic dashboards, no decorative noise.  
**User-calibrated baseline:** User asked for complementary visuals that support featured agent coverage and posting; this creates asset-ready briefs without forcing unrequested external exports.  
**Failure addressed:** Visuals that look like generic AI consulting instead of diagnostic proof.  
**Score discipline:** Briefs are ready for image generation/design. Actual image performance still needs visual review after generation.
