# Coach Cooz LinkedIn Browser Cockpit

Purpose: compress the thinking work of LinkedIn engagement while keeping every account action human-approved.

This is for live profile review, visible-page analysis, comment drafting, connection-note drafting, warm DM drafting, and referral follow-up support. It is not for unattended automation.

## What The Browser Can Help With

- Review Cooz's live profile against the launch checklist.
- Compare headline, banner, About, Featured, Experience, and Services to the V5 profile copy.
- Read visible feed posts one at a time and draft thoughtful comments.
- Draft connection notes and warm DMs from context you approve.
- Identify which visible people/posts are worth engaging with today.
- Keep a manual outreach tracker for follow-up.

## What To Avoid

- Bulk scraping profiles, followers, comments, or feeds.
- Auto-sending comments, DMs, connection requests, likes, or follows.
- Copying profile data into a database without permission.
- Simulating a bot or bypassing platform limits.

LinkedIn's own guidance restricts automated activity and prohibited third-party tools:

- https://www.linkedin.com/help/linkedin/answer/a1341543
- https://www.linkedin.com/help/linkedin/answer/a1341387/prohibited-software-and-extensions%3Flang%3Den
- https://www.linkedin.com/legal/user-agreement

## 20-Minute Human-In-Loop Routine

### Minute 0-2: Choose The Surface

Open one surface:

- Cooz's profile
- LinkedIn home feed
- Notifications
- A known referral's profile
- A prospect's recent post

Stay on one surface long enough to make a useful decision.

### Minute 2-6: Read The Visible Context

For each visible post or profile, classify it:

- Comment now
- Save for later
- Connect with context
- Warm DM
- Skip

Skip anything where the only possible comment is generic encouragement.

### Minute 6-12: Draft Engagement

Ask for:

- 3 thoughtful comment options
- 1 short connection note
- 1 warm DM if there is real context
- 1 referral ask if the person already knows Cooz or Farrice

Do not send anything automatically. Choose the best option, edit it if needed, then send manually.

### Minute 12-18: Execute Manually

Recommended daily ceiling:

- 3-5 meaningful comments
- 2-3 connection notes
- 1-2 warm DMs or referral asks

Quality matters more than volume. A good comment should make the person feel understood, not targeted.

### Minute 18-20: Track Next Step

Track:

- Person
- Relationship/context
- Action taken
- Follow-up date
- Outcome

## Comment Standards

A useful comment should do at least one of these:

- Add a distinction.
- Name the hidden tension.
- Reflect the person's point in sharper language.
- Ask a precise question.
- Connect the post to Cooz's lane without pitching.

Avoid:

- "Great post."
- "Love this."
- "So true."
- Forced personal intimacy.
- Pitching the Triage Audit under someone else's post.

## DM Standards

A good DM should:

- Name the real context.
- Be short.
- Avoid pretending intimacy.
- Make one clear ask or offer one useful next step.
- Sound like Cooz, not a funnel.

Bad DM pattern:

"Hey, I help professionals over 40 rebuild strength and energy. Want to book a call?"

Better pattern:

"Saw your post about trying to keep training consistent while work keeps shifting. That is usually where the plan is not the real issue. It is the recovery, schedule, and accountability system around it. If you ever want a second set of eyes, I can point you toward the first 2-3 things I would check."

## Browser Limitation Note

If the in-app browser and the logged-in Chrome window are not showing the same LinkedIn page, use Chrome as the live surface. I can inspect the visible browser state only when the active tool can see that window or page.
