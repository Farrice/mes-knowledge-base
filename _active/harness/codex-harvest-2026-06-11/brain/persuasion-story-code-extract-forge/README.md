This artifact records the internal extraction and build package for the Persuasion Story Code system.

- OCR transcript: `extractions/persuasion-story-code/source/transcript.md`
- Coverage report: `extractions/persuasion-story-code/source/coverage-report.md`

## Build Summary

The system creates entrepreneur-facing persuasion stories for:

- Written content.
- Social media.
- Sales copy.
- Video scripts.
- Founder messaging.
- Case studies and proof.
- Objection handling.
- Story banks.

The extraction keeps the book as internal source material and does not republish long copyrighted passages.
