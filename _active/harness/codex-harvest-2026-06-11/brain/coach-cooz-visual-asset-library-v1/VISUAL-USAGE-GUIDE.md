# Coach Cooz Visual Usage Guide V1

## Visual Thesis

Coach Cooz should look like a serious private coach, not a fitness influencer.

The visual world should signal:

- strength
- diagnosis
- calm authority
- premium local presence
- real coaching relationship
- maturity after 40
- private support, not public performance

The strongest visual idea:

> The body has to carry the life.

## What It Should Feel Like

Use visuals that feel:

- grounded
- warm
- serious
- cinematic but not fake
- strong without shouting
- premium without looking luxury-coded
- local and human

Avoid visuals that feel:

- generic gym ad
- bro-fitness
- fake executive
- overdesigned wellness
- cheap quote card
- transformation challenge
- stock-photo personal trainer
- motivational speaker

## Visual Palette

Use:

- charcoal
- black
- bone
- warm gray
- deep brown
- brass/copper warmth
- muted cream
- controlled amber light

Avoid:

- bright blue fitness tech
- neon
- heavy purple gradients
- beige wellness minimalism
- loud red challenge graphics
- glossy fake luxury gold

## Typography Direction

Use clean, adult typography.

Recommended feel:

- strong sans for clarity
- restrained serif only for occasional authority
- high contrast between headline and body
- large text, few words
- no crowded paragraphs on graphics

Avoid:

- handwritten motivational fonts
- aggressive condensed gym fonts
- luxury fashion type if it makes the brand feel fake
- tiny text on mobile assets

## Asset Rules

### LinkedIn Banner

Job:

Make the profile feel clear, premium, and serious before someone reads the About section.

Best images:

- kettlebell still life
- gym teaching wide
- triage concept only if not implying real client proof

Copy should stay minimal:

```text
Your calendar is not going to calm down.
Your body still has to carry it.
```

### LinkedIn Profile Photo

Job:

Trust fast.

Best images:

- seated authority
- city black t-shirt
- blazer only if the audience context needs a more professional signal

Avoid:

- pointing images
- overtly corporate suit as default
- images that make him look like an executive coach instead of a strength coach

### Instagram Feed

Job:

Make Cooz feel real, premium, and useful.

Use:

- one strong image
- one useful caption
- no quote-card filler
- no cluttered text overlay

### Instagram Carousel

Job:

Make one insight saveable.

Slide 1 should name the pattern fast:

- "The 4 PM fog is usually traceable."
- "Monday is not a plan."
- "Do not buy another plan until you know what keeps breaking."

One thought per slide.

### YouTube Thumbnail

Job:

Make the topic clear in under 2 seconds.

Use:

- 3-5 words maximum
- one face or one symbolic object
- dark background with warm edge light
- strong contrast

Avoid:

- open-mouth influencer thumbnail
- exaggerated pointing unless intentionally testing a more direct-response style
- crowded text

## Image Gen 2 / Image Generation Rules

Start with one approved reference image.

Use image generation for:

- background extension
- platform-specific crops
- clean visual metaphors
- thumbnail backgrounds
- carousel cover concepts
- still-life assets
- gym environment variations

Do not use image generation to:

- invent client proof
- create before/after claims
- imply a real session happened
- create fake testimonials
- make Cooz look like a different person

Every generated asset must be saved in:

`generated-derivatives/`

Label it as generated or edited.

## Remotion / Video Rules

Use Remotion for:

- Reels
- YouTube Shorts
- captioned clips
- short proof explainers
- Triage Audit explainers
- carousel-to-video adaptations
- 16:9 YouTube intros or short openers

Video should feel:

- direct
- calm
- lightly cinematic
- useful fast
- built around one point

Avoid:

- overanimated text
- hype music
- fake trailer intensity
- flashy cuts that make Cooz feel less serious

## Proof Safety

Do not imply any AI-generated person is a real client.

Do not use:

- fake client scenes as testimonials
- unnamed second people as proof
- body transformation imagery without real permission/context
- Mari-style result claims without measurement validation

Safe language:

```text
Concept image for Triage Audit.
```

Unsafe language:

```text
Client audit session.
```

## Quality Gate Before Publishing

Ask:

1. Does this look like private strength and energy coaching after 40?
2. Would a serious professional trust this?
3. Is the message clear in under 3 seconds?
4. Is there any fake proof implication?
5. Does this avoid generic gym design?
6. Does this avoid fake luxury?
7. Does this sound and look like Cooz?

If any answer is weak, run `creative-review` and `design-taste-gate` before publishing.
