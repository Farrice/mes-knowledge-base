# /deploy-council

`/deploy-council` is the max-breadth preset of `/convene`: broad roster, diverse domains, wildcards, then a smaller inner council for deliberation.

Run:

```bash
python3 execution/convene.py plan "[mission]" --mode deploy --json
```

Use this when the problem is important enough to justify maximum perspective spread before synthesis. It does not bypass `/virtuoso`; it is a council owner behind the orchestration layer.
