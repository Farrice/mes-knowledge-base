# /insight-perception-sprint

> Rory Sutherland × Luke Iha — Perception-grounded insight vectors that exploit perceptual gaps.

## Quick Deploy
```
Load: skills/rory-sutherland-marketing/genius.md + skills/luke-iha-insight-vectors/genius.md
```

## When to Use
- Standard insight vectors feel informational but not perception-shifting
- The audience has strong beliefs that need dissolving through reframing, not arguing
- You need 15+ campaign angles that each change how the audience SEES the category

## Input
- Market/Niche + Product/Offer + Competitor Landscape + Content Goal
