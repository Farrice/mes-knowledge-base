# Slash Command Playbook — Quick Reference

> **Purpose**: You have 150+ workflows. This groups them by intent so you always know what to run.
> **When to read**: Session start, or whenever you're not sure which command fits.

---

## Daily Sequence (Every Session)

```
/daily-focus → [work] → finalize() auto-runs → /end-session
```

## Weekly Sequence (Monday)

```
/weekly-pulse → /maintenance → /daily-focus → [work]
```

## Monthly Sequence (1st of Month)

```
/calibrate → /gap-report → /skill-evolution → /ground-truth
```
