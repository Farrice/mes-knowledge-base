## Calibration Notes (For Evolution Engine)

### What Worked

1. **Behavioral mirror framing:** Scoring 50–60% higher than existing category-level concepts (4.3–4.9 vs. 2.9–3.2)
2. **Familiar/Twist ratio discipline:** All concepts 4.3+; zero sub-threshold (previous runs had 30–40% under-threshold)
3. **Emotion-first copy template:** Repeatable, voice-consistent, no AI-tell structural moves
4. **6-metric instrumentation:** Pre-committed kill/scale rules prevent indecision; weekly factory loop is sustainable
5. **Test-slate prioritization:** Scoring + visual translateability predicted, not arbitrarily chosen → reduces post-launch regret

### What to Watch

1. **Email baseline assumption:** If actual MyBPM baseline <20% or >28%, threshold recalibration needed mid-Week 1
2. **Price sensitivity:** $45 may pressure cold traffic conversion. Kill rule ($75 revenue min) catches this, but adjust for Wave 2 if needed
3. **POD quality variance:** Print-on-demand visual fidelity inconsistency is a known risk. Test order (Week 1) is critical QA gate.
4. **Seasonal moment risk:** "Post-Rave Tuesday" concept works June-forward (summer festival season). Autumn testing may show decline. Monthly factory loop should catch this.

### Evolution Recommendations

1. **Extend familiar bank work:** The 30+ signal inventory is MyBPM-specific. Build a "familiar bank generator" skill for future brands (structured prompt + user input = branded signal library)
2. **Copy template refinement:** The emotion-first template works for cold audience. A second variant is likely needed for "legacy" campaigns to existing buyers, where the emotion anchor shifts from recognition to belonging.
3. **Scorecard resolution:** The 1–5 scale clusters strong slates at 4.3–4.9, which makes sub-7 differentiation noisy. A 1–10 scale (or 1–5 with half-points) would sharpen the Tier 2 vs. Tier 3 call.
4. **Factory loop automation:** Weekly monitoring is currently manual. A Shopify → Google Sheets → Slack thread (Zapier or n8n) would remove the operational friction and catch threshold breaches the same day they happen.
