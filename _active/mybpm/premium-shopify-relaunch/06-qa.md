# Launch QA Contract

## Blocking checks

- [ ] Theme Check reports no errors
- [ ] Homepage, collection, product, cart, search, account, policy, 404, and contact surfaces render
- [ ] No `Product Name`, lorem ipsum, empty headings, broken images, or keyword-list alt text
- [ ] Color/size variants change the correct image and never request guessed files such as `black.png` or `white.png`
- [ ] No failed `thisnew.com`, `popcustoms.com`, or retired supplier storefront requests
- [ ] Every buy button adds the intended variant and quantity
- [ ] Cart drawer, discount entry, shipping estimate, and accelerated checkout behave as expected
- [ ] Test order completes through payment sandbox and produces the correct order, email, tax, and fulfillment route
- [ ] Shipping and return statements match policy pages and supplier reality
- [ ] Inventory and sold-out states are accurate
- [ ] GA4/Meta/Shopify purchase events fire once, not zero or twice
- [ ] Keyboard navigation, focus states, labels, and reduced-motion behavior pass
- [ ] No horizontal overflow at 320, 375, 768, 1024, and 1440 px widths
- [ ] Signal white is the dominant commerce canvas; no brown, cream, or beige background remains
- [ ] Mineral texture appears only on designated editorial surfaces and does not reduce text contrast
- [ ] Frequency acid is limited to one primary action or verified signal per viewport
- [ ] Core imagery is compressed and the hero does not lazy-load
- [ ] Domain, SSL, robots, sitemap, redirects, and canonical URLs are correct
- [ ] Email capture has consent language and reaches the intended list
- [ ] Current live theme has a tested rollback path
- [ ] Uploaded theme is `UNPUBLISHED`; `Updated copy of MyBPM Ira 4.3.0` remains `MAIN`

## Product proof checks

- [ ] Each launch product has an approved physical sample
- [ ] Material and care claims match supplier documentation and sample labels
- [ ] Size guide uses recorded garment measurements
- [ ] Model height and worn size are present where on-body photography appears
- [ ] Production and shipping windows are displayed before checkout

## Release decision

Any failed checkout, policy, inventory, supplier-script, analytics, or broken-asset item blocks publication. Cosmetic polish can be triaged only when it does not impair comprehension, trust, accessibility, or purchase behavior.
