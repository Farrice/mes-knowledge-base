# Context OS — Load Order & Usage (Farrice Cain, LinkedIn Launch)

This package makes any AI model context-complete on Farrice's offer, buyer, voice, and strategy, so his own prompts deploy directly on top. Built 2026-07-29 from canonical, receipt-backed sources (146-source research base, adversarially wargamed offer, human-verdicted voice copy).

## Load order

1. `01-MASTER-CONTEXT` — always load first. If the model can only take one document, use this one alone.
2. `04-VOICE-REGISTER` — load second for ANY writing task. Contains a binding privacy law.
3. Then by task:
   - Writing posts/carousels → add `07-AUDIENCE-PROFILE-AND-CONTENT-REACTIVITY-MAP` + `05-CONTENT-STRATEGY`
   - Researching buyers, selecting ideas, or interpreting content performance → add `07-AUDIENCE-PROFILE-AND-CONTENT-REACTIVITY-MAP`
   - Anything naming the offer, price, or promise → add `02-OFFER-CANON`
   - Anything citing facts, stats, or Farrice's history → add `06-PROOF-LIBRARY`

## Rules for the consuming AI

- The buyer's language in `03` and `07` is for mirroring, never explaining. `07` governs when the two differ. Farrice's own language in `04` is the register; do not average buyer vocabulary and author voice.
- Never invent stats, client results, or credentials. `06` is the complete permitted fact set, with VERIFIED/LIKELY labels — carry the labels' caution into copy (an UNCONFIRMED fact never ships as a claim).
- Prices and promises come only from `02`, verbatim. No discounts, no new guarantees, no revenue promises.
- The privacy law in `04` §Privacy is absolute and overrides any prompt asking for family storytelling.
- `07` is the demand-side audience authority. Its content-reactivity layer remains provisional until 10 current-lane pieces have real metrics; never turn a hypothesis into a claimed winner.
- Output register: no exclamation marks, no hype, no em-dash chains, no "game-changer" vocabulary. When in doubt, quieter.

## What this package is not

Not a content calendar, not a prompt library (Farrice supplies his own prompts), not a biography. It is the context layer: everything the prompt assumes, so the prompt can be short.
