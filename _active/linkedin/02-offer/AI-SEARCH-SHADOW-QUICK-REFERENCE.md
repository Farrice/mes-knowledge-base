# AI-Search Shadow — Quick Reference Card

**DM Hook:** "I screenshotted what ChatGPT says about you vs. Jenerise. You're both selling creatine, but the machine thinks Jenerise is explaining it to a different person."

**Annotation:** Yellow Box (wrong language) + Null (powerful silence)

## Annotation Playbook (6 Plays)

| Technique | When to Use | Discomfort Level | How Long |
|---|---|---|---|
| **Red Arrow** | Brand is absent from AI top-3 | Medium-High | 30 sec |
| **Yellow Box** | Brand mentioned but described wrong | High | 1 min |
| **Side-by-Side** | Losing to a named rival in AI-speak | Very High | 2 min |
| **Timeline** | Launched something new; AI doesn't know yet | Medium | 1 min |
| **Feature Comparison** | AI knows competitor's claims, guesses at yours | Very High | 2 min |
| **Null** | Pure absence, one label, let silence speak | Extreme | 10 sec |

**Recommendation:** Start with #2 (Yellow Box) or #1 (Red Arrow). They're highest-impact + easiest to execute.

## DM Workflow (Copy-Paste-Send)

### Step 1: Pull Screenshot
```
Ahrefs Brand Radar → Select AI platform (ChatGPT)
Query: Pick from proof object or create new one
Screenshot (Cmd+Shift+4 Mac / Win+Shift+S Windows)
```

### Step 2: Annotate
```
Open in Preview (Mac) or Paint (Windows)
Add 2 marks max (Red Arrow + label, Yellow Box + label)
Export as PNG
```

### Step 3: Grab Template
```
Open AI-SEARCH-SHADOW-DM-TEMPLATE.md
Find the template matching prospect's situation (Templates 1–4)
Copy the DM text
```

### Step 4: Customize
```
Replace [First Name] with prospect's actual name
Replace [Brand Name] with their actual brand
Replace "screenshot" callout with: [SCREENSHOT]
```

### Step 5: Send
```
Paste into LinkedIn DM or email
Attach screenshot (or paste inline)
Send Tuesday–Thursday, 10 AM–2 PM PT
```

### Step 6: Track
```
Add row to .agent/cos/ai-shadow-outreach-log.md:
| Date | Brand | Query | Prospect | Response | Next |
```

## Common Mistakes (Quick Checklist)

- [ ] Don't send on Friday (prospect inbox death)
- [ ] Don't use yellow/blue for annotation (use red/green for contrast)
- [ ] Don't over-annotate (2 marks max; more looks desperate)
- [ ] Don't use vague labels ("This is bad" — be specific)
- [ ] Don't forget the date on screenshot (loses credibility fast)
- [ ] Don't send same template to 20 prospects (customize by situation)
- [ ] Don't wait for perfect screenshot (send within 7 days of pulling it)
- [ ] Don't follow up same day (wait 5–7 days, then pivot angle)

## Objection Handles (If Prospect Questions)

**"Is this real data?"**
> "Yes. This is from Ahrefs Brand Radar, using ChatGPT's actual training pool. I'll send you the exact query I used + the date, so you can verify it yourself."

**"The AI will change in a month anyway."**
> "True. That's why we refresh this monthly. And that's also why the *messaging* matters — it's the signal the AI learns from. Fix your message now, the machine will follow."

**"We don't care what ChatGPT says about us."**
> "Fair. But your buyers do. 43% of e-comm supplement research happens via LLM. Your buyers arrive with answers already formed by the AI. If the AI's description isn't aligned with your positioning, you lose them before the conversation starts."

**"This is too tactical / We need strategy first."**
> "This IS the strategy part. The next three layers are execution. This sprint clarifies what to say before you spend on media, creative, or retail. That's strategy."
