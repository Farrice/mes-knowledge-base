## 2. THE CALIBRATION QUESTION

**Does the scorecard rank them the way the user does? No — it ties them, and the user does not.**

The user preferred the original overall (coherent ~8.3 base) and judged the Diandra *body* flat/degraded (the upgrade file's own banner: "Diandra-only body 6/10 — flat, lost the narrative"), keeping only the hook. The Diandra engine claimed ~9. The Kallaway novelty scorecard sides with **neither cleanly**: it scores both **10/10 Integrity PASS** and declares both "ship it."

What this exposes is a **scope boundary, not a calibration failure**. The novelty scorecard measures five things — reveal, outcome, contrast, urgency, proof rung — and the original/upgrade delta lives *outside all five*. The Diandra pass swapped one strong hook for another strong hook and **compressed the body** (360w → 290w), cutting connective narrative tissue ("Now watch where the money leaks out," the "did it backwards" inversion beat, the AG1 "budget be damned" payoff rhythm). Those are **coherence/loop/rhythm assets**, which the novelty rubric does not weigh. So the scorecard correctly says "both are novelty-ceiling" while being structurally incapable of seeing the flatness the user felt.

Two workflows partly recovered the user's verdict by reaching outside novelty: **novelty-forge** scored the original hand-pass slightly *ahead* (~9.5 vs the engine's 9, crediting "hook density + whisper close"), and **novelty-to-addictive** is the only workflow that diagnosed a real *body* defect in the upgrade (the dropped narrative loop). Everything else is calibration-silent on the original-vs-upgrade question.

Takeaway: the scorecard is **well-calibrated within its lane** (it does not inflate, it does not over-flag) but **lane-blind to body coherence** — which is precisely the axis the user's taste ruled on. It will never, on novelty grounds alone, tell you the original beats the upgrade. You need an addictive/loop or prose lens for that.

## 4. Agree-Strong vs. Genuine-Lift vs. Over-Engineer

**Agree the content is strong (would NOT touch):**
novelty-audit, novelty-reveal, novelty-contrast, novelty-urgency, novelty-protect, novelty-forge — all six, both specimens. Every one returns "ship it," names the matching anchor, and explicitly declines to invent a fix. novelty-protect is the cleanest: *"Scrubbed draft == source draft (no edits warranted)."*

**Genuine lift (real, specific, survives scrutiny):**
- **novelty-to-addictive (upgraded)** — the only body-level defect found anywhere. The upgrade opens a narrative loop on the friend ("That pause cost her the account") then pivots to "Most wellness founders haven't clocked the real problem" and **never closes it**. Proposed one-line add before the test: *"My friend didn't lose the account because she got lazy. She lost it because she got automated — and never noticed the day it happened."* Closes story + argument together. Zero fabrication. This is the single best fix in the 26 runs.
- **novelty-to-addictive (original)** — one dead-air stretch from the 5W study paragraph through "more suspicious by the time they reach you," rescued one beat late by "Now watch where the money leaks out." Proposed micro-rehook after the AG1 line: *"Win that half and you'd think you've won. You've actually just exposed the half that matters more."*
- **novelty-proof (both)** — frame the 5W stat AT the founder, not as a lab finding. "AG1 came in third" → *"if spend couldn't buy AG1 onto it, it can't buy you on either."* Same verified numbers, one rung closer. Honest and real.

**Would OVER-ENGINEER (the manufactured-novelty engine meeting refined prose — the key risk):**
- **novelty-meta** — both specimens. It would force a fourth-wall "I made that name up" confession onto a convert-asset that coined no name and runs on real facts. The workflow's own Guardrail bars it; it correctly self-rejected both times. The trap it would have set: deleting the killer close ("One of those numbers is too low. You already know which one") to make room for a writing-class flex.
- **novelty-hook** — its strict density lens scores the original's "Who actually wrote this?" a **5** (a category error for a long-form essay). It correctly flagged its own lens as wrong, but a naive operator following the raw density number would have swapped a dread-loaded whisper for a stat-bomb. This is the workflow most able to *mislead via its own score*.
- **novelty-contrast / novelty-reveal** — both surface "optional welded-line / coin-the-name" lifts that are genuinely lateral. Forcing the original's distributed contrast into a "You've been told X" billboard, or hard-naming "the Funnel Split," would trade earned interiority for generic marketer-voice. Correctly flagged as optional, not fixes.

## 5. Highest-Value Suggestions That Survived Both Versions

Honest answer: **the post is already strong, and most suggestions would degrade it.** Three survived scrutiny — and only one is unambiguous:

1. **Close the friend-loop (upgrade only).** The Diandra body's actual defect — the abandoned narrative thread — is real and the user already felt it as "flat." This is the highest-leverage edit and validates the user's own verdict. (Note: this fix belongs to the *upgrade*; the original never opens then drops the loop, which is part of why the user preferred it.)
2. **Aim the 5W stat at the reader (both).** Original line: *"AG1, reportedly the largest greens brand by revenue, landed third."* → add the self-implicating frame *"if it happened to the giant, it happens to you."* Facts untouched, one rung up the trust ladder. Low-risk, genuine.
3. **Swap the composite "friend" for a permissioned real anecdote (both, already self-flagged).** Both the package Sources note and the Diandra scorecard independently name this as the only path to the 10th point. It is a grounding/voice move, **not** a novelty fix — do not let any /novelty-* workflow "improve" it by inventing a sharper-sounding mimic (honesty-spine violation).

Everything beyond these three (coin-the-name, weld-the-contrast, front-load urgency, add a fifth component) was flagged by the workflows themselves as over-engineering on already-calibrated prose.

## 6. Skill-Calibration Takeaway

**Do the workflows over-flag good content? No — impressively restrained.** Across 26 runs on human-refined prose, not one workflow forced a component it didn't believe in. Six returned "ship it" cleanly; the diagnostic-but-inapplicable ones (meta, pattern) correctly *declined to run* rather than manufacture output. The honesty spine held everywhere: every workflow that touched the composite anecdote refused to fabricate a fix. This is the over-engineering failure mode the test was built to catch, and the skill **passed**.

**Is the scorecard well-calibrated vs. the user's taste?** Within its lane, yes; against the user's actual decision axis, no. It ties two pieces the user ranks differently because the deciding factor (body coherence/loop integrity) is outside the five novelty components. The scorecard does not lie — it is silent on the right question.

**Most useful here:** **novelty-to-addictive** — the only workflow that found a real, fixable body defect (the dropped loop) and the only one whose diagnosis tracks the user's "flat" verdict. **novelty-forge** second: its cold-build convergence test independently reproduced the user's hand-chosen frame and credited the original's whisper close, partially recovering the user's ranking from a direction the novelty score couldn't.

**Least useful / misleading:** **novelty-pattern** — genuinely inapplicable at N=1 (correctly so, but it returns no signal for this task). **novelty-hook is the one to watch**: its raw density score (5/10 on a 10/10 line) is an active misread for long-form, salvaged only because the workflow self-corrected in prose. An operator trusting the number over the narrative would degrade the post. **novelty-meta** correctly self-rejected both times — useful as a guardrail, zero lift as a generator here.

**Net:** the engine is honest and restrained, but it is a *novelty* instrument, not a *coherence* one. For the original-vs-upgrade question the user actually cares about, route to **novelty-to-addictive** (loop integrity) or a prose/writers-room lens — the novelty scorecard alone will tie them every time.
