# 05 — Automation + Launch + Scale  (`/suzuki-automate`, `/suzuki-flash-launch`, `/suzuki-scale`)

## Automation (`/suzuki-automate`) — create → schedule → opt-in convert
**Create (with the claim-edit gate):** batch-draft posts from the hook bank + swipe templates (`02-post-engine.md`) using the AI-gen pack. **Every draft passes a human edit against `06-compliance-ledger.md`** before it enters the queue — strip any income claim, keep the disclosure. AI drafts the shape; you own the claims.

**Schedule:** 1–2 posts/day, mixing the 18 hooks across the 5 angle types. Re-post the 3 flagship threads on a rotation (new proof/buyer each time). Tool: any compliant scheduler (Typefully, Hypefury, etc.).

**Convert (opt-in auto-DM):** map the keywords → free starter.
| Trigger (like/comment) | Auto-DM |
|---|---|
| HONEST / WORK / BURNED | DM 1 (delivery + one question) from `04-funnel-and-dms.md` |
Rules: fires **only** on the opt-in action; no cold/mass DM; opt-out honored; a human handles warm/ready/wrong-fit replies (don't automate the close).

## Launch — EVERGREEN (recommended), not flash
This buyer is scam-burned; **urgency repels them.** So the default is evergreen honest content, not a countdown. (`/suzuki-flash-launch` is available only if you later run a *real* cohort with a genuine cap — never fake scarcity.)

Run the **first-30-minute reply sprint** on every thread (the OS treats this as required work, not optional).

## Scale (`/suzuki-scale`) — once one account converts
The scaling unit is the account = **one buyer-niche × honest angle**. Don't clone copy across accounts (ToS + cringe).
| Account | Niche (specific buyer) | Angle |
|---|---|---|
| #1 (this one) | Burned-out parents / general beginners | Honest "what the work is" |
| #2 | Burned-out 9-5 / corporate quitters | "Dignity + exit, realistically" |
| #3 | A trade (nurses / teachers / ESL) | "Faceless digital skills for [trade]" |
**Distribution (cold start each account):** manufacture first views — your other accounts retweet the new one's first 1–3 posts; or a small boost. Treat first-distribution as required, per `scaling-mechanics.md`.

## Test instrumentation — did it TRULY work?
Log per thread (the OS judges by **qualified comments × price**, not views):
| Metric | What it tells you |
|---|---|
| Impressions | reach (least important) |
| Qualified comments (opt-ins) | the real lead count |
| Opt-in → LP click rate | DM/message strength |
| LP → checkout click rate | landing-page strength |
| Sales (from your affiliate dashboard) | the verdict |

**Kill/keep rule:** after ~5 threads, double down on the angle with the most opt-ins; cut the weakest. If opt-ins are healthy but sales are zero, the bottleneck is the LP or the offer/price — run `/suzuki-launch-debugger`. If opt-ins are zero, the hook/angle is the problem — back to `/suzuki-post-lab`.

## Honest expectation-set
This is a saturated category with a skeptical buyer. The wedge (honesty) is real but it's a *trust* play — it compounds over weeks, not hours. Evergreen reps + the reply sprint are the engine. No income is promised to you either.
