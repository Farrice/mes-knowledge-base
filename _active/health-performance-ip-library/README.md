# Health Performance Content IP Library

Purpose: compound daily health, performance, supplement, wellness, SEO, AEO, GEO, and AI-search signals into reusable content IP, productized audits, and premium service assets for Farrice Cain.

The operating prompt lives at:

`AUTOMATION_PROMPT.md`

The daily engine is now a ladder, not only a briefing:

1. Social listening and source truth
2. Claim and source-quality audit
3. SEO/AEO/GEO retrieval opportunity
4. Creative strategy angle
5. Productized audit or service asset
6. Personal anecdote prompt
7. Reusable IP ledger entry

## Daily Run

Each daily automation run saves a dated brief in `daily/` using:

`YYYY-MM-DD-health-performance-geo-brief.md`

Required sections:

- Executive Brief
- Source Quality And Claim Safety Audit
- AEO/GEO Retrieval Opportunity
- Creative Strategy Translation
- Productized Service Ladder
- Ready-To-Deploy Anti-Slop Content
- Creative Reaction And Anecdote Priming Loop
- IP Library Capture
- Daily 45-Minute Build Sprint

## Insight Ledger

Reusable insights are appended to:

`ledger/insights.jsonl`

Each JSONL row must include:

- date
- insight_title
- source_url
- source_lane
- evidence_grade
- audience_friction
- longtail_question
- retrieval_opportunity
- content_angle
- creative_angle
- productized_asset
- asset_type
- offer_bridge
- ladder_stage
- ladder_rung
- tags
- next_action

Evidence grades:

- VERIFIED
- LIKELY
- UNCONFIRMED

## Weekly Synthesis

Every Friday, the automation should also save:

`weekly/YYYY-WW-health-performance-synthesis.md`

The weekly synthesis should identify repeated buyer fears, strongest source-backed claims, weak claims to avoid, highest-value long-tail questions, the best 5 Percent Asset candidate, strongest productized service opportunity, content series ideas, and one next-week build sprint.

## Safety Boundary

No Google Drive export, Google Doc creation, publishing, outreach, login-gated scraping, medical advice, diagnosis, supplement dosing, or treatment recommendations without explicit approval.
