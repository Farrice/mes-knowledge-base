# Health Performance Client Acquisition IP Library

Purpose: compound daily health, performance, supplement, wellness, SEO, AEO, GEO, AI-search, creative strategy, copywriting, and ghostwriting signals into reusable content IP, productized audits, premium service assets, and a client-acquisition data moat for Farrice Cain.

The operating prompt lives at:

`AUTOMATION_PROMPT.md`

The daily engine is now a client-acquisition ladder, not only a briefing:

1. Social listening and source truth
2. Claim and source-quality audit
3. Zeitgeist and buyer-language read
4. SEO/AEO/GEO retrieval opportunity
5. Creative strategy and copy angle
6. Productized audit, ghostwriting, or creative strategy offer bridge
7. Multi-platform content package
8. Personal anecdote prompt
9. Reusable IP ledger entry

The named backend module for the offer is:

`Source-to-Search Trust Layer`

It turns claims, source receipts, buyer questions, founder judgment, brand rules, examples, counterexamples, quality tests, and update rules into assets humans can inspect and AI-search systems can retrieve more accurately. The first review packet lives at:

`review-packets/source-to-search-trust-layer-review-packet.md`

Client-facing assets created from the packet:

- `public-assets/source-to-search-trust-layer-one-page-offer-insert.md`
- `public-assets/glp-1-movement-receipt-public-demo.md`
- `review-packets/source-to-search-trust-layer-adversarial-review.md`

The unified project folder for this workstream is:

`projects/2026-06-23-revenue-source-to-search-trust-layer-glp1/`

Start there when reviewing, extending, or packaging this offer system.

## Daily Run

Each daily automation run saves a dated brief in `daily/` using (v4.0, 2026-07-31 — earlier briefs use `YYYY-MM-DD-health-performance-geo-brief.md`):

`YYYY-MM-DD-angle-map-listening-brief.md`

plus the ≤6-line exec cut at `daily/LATEST-EXEC-CUT.md` (inlined into the COS morning brief).

Required sections:

- Executive Brief
- Source Quality And Claim Safety Audit
- AEO/GEO Retrieval Opportunity
- Creative Strategy Translation
- Client Acquisition Opportunity Map
- Productized Service Ladder
- Ready-To-Deploy Anti-Slop Content
- Creative Reaction And Anecdote Priming Loop
- IP Library Capture
- Daily 45-Minute Build Sprint
- Acquisition Scorecard

Substantial offer updates should preserve the Source-to-Search Trust Layer as a backend module, not a first-touch technical pitch.

## Weekly Synthesis

Every Friday, the automation should also save:

`weekly/YYYY-WW-health-performance-synthesis.md`

The weekly synthesis should identify repeated buyer fears, strongest source-backed claims, weak claims to avoid, highest-value long-tail questions, the best 5 Percent Asset candidate, strongest productized service opportunity, strongest client-acquisition angle, best public teardown candidate, content series ideas, content data moat themes, and one next-week build sprint.

## Safety Boundary

No Google Drive export, Google Doc creation, publishing, outreach, login-gated scraping, medical advice, diagnosis, supplement dosing, or treatment recommendations without explicit approval.
