## How to Use This List in a Daily Brief

When Section 5 (Client-Acquisition Map) of a daily brief identifies an
opportunity, name the specific brand(s) from this list the signal is most
relevant to (e.g., a creatine-claim regulatory signal → Create Wellness /
Momentous), not a generic "DTC brand" placeholder. If a signal doesn't map
to anyone on this list, say so rather than forcing a fit.
