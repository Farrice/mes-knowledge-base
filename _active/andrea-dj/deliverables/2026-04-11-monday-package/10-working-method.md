# 10 — How We Work Together
## The Constitution, voice memos, and the flow that keeps momentum

*Andrea named this methodology on the April 21 call. She called the package of documents the "Constitution" — we don't rewrite, we iterate. This file makes that protocol explicit so we don't lose it.*

---

## The Constitution Principle

Every document in this package is the *Constitution* for Resonance.

- **We amend it. We don't rewrite it.** Once a doc reaches a "yes, this feels right" state, it stays that way. Revisions are targeted, tracked, and always downstream of a specific shift (new decision, new information, new Andrea insight).
- **Each document has a single source of truth.** If a decision changes (name, headcount, venue path), we update the one file where that decision lives, and cascade references through the others. No drift.
- **Finalization matters.** Once a section locks, we stop reopening it. Open-loop revisions kill clarity. A living Constitution is not the same as a document that's always in flux.

---

## The Voice Memo Flow

Andrea has insights that arrive in conversations, in the car, in the shower, mid-set. They can't wait for scheduled calls.

**Protocol**:

1. **Capture it raw.** When insight arrives, Andrea voice-memos it to Farrice — no pre-editing, no concern for polish. Raw is preferred; edited loses signal.
2. **Farrice processes within 24 hours.** The voice memo gets fed to Claude, synthesized into document updates or new content seeds. Farrice reviews before anything changes the Constitution.
3. **If it's a document change**: Farrice updates the Constitution file, flags the diff in chat (*"Updated 02-who.md based on your Tuesday voice memo — added X, removed Y, here's the new passage"*), and Andrea confirms.
4. **If it's a new idea**: Farrice captures it as a note in the right place (new section if it fits an existing doc, a new doc if it's a new category of thinking). Never let a voice memo die in a DM thread.

**Rule**: voice memos are never "too raw" or "too much." Send them. The AI infrastructure filters signal from noise; Andrea's job is to let the signal out when it arrives.

## The Weekly Rhythm

| Day | Activity |
|---|---|
| **Mon or Wed** | Co-work call with Farrice (60 min). Locks decisions, reviews doc changes, clears blockers. |
| **Tue–Fri** | Execution. Andrea: client work + any 10–30 min Resonance actions (invites, venue scouting, IG posts). Farrice: document updates, research, copy drafts. |
| **Any time** | Voice memos flow both directions as insights arise. |
| **Sunday** | Soft rest. Farrice may send a "here's what's coming this week" note Sunday evening so Monday opens clear. |

**No ceremony.** No status reports. No weekly decks. Voice memos in, doc updates out, one call per week to lock decisions. That's the whole system.

## What Andrea's Claude Pro Project Is For

Andrea has Claude Pro with the Resonance project loaded. Its job:

- **Ask it anything about the Constitution** — "what did we decide about alcohol?" / "who's the Darius archetype again?" / "what's the break-even at 50?" Claude can read all the docs and answer.
- **Draft in Andrea's voice** — captions, DMs to venues, reply to an invite request. Andrea pastes the context, Claude drafts, Andrea edits for voice.
- **Surface contradictions** — if Andrea feels torn between two directions, ask Claude to argue both sides. Much faster than waiting for a call.
- **NOT a replacement for Farrice** — Claude is the operational layer. Farrice is the strategic layer. If it's a decision about brand direction, staging, or a hard call, that's a Farrice conversation.
