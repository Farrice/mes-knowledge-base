## How each folder works

Inside every project folder you'll find:

- **★ SETUP - open me first** — open this first. Three steps.
- **CUSTOM-INSTRUCTIONS.md** — the text you paste into the project's instructions (also shown inside the SETUP sheet).
- **the rest of the `.md` files** — the project's knowledge. Upload all of them.
