# 07 - Quality Gates And Kill List

## Purpose

This keeps the content system sharp, honest, and commercially useful.

## Gate 1 - Audience Gate

Pass if the piece clearly speaks to:

- head of brand
- head of content
- VP growth
- founder
- formulator
- expert-led operator

Fail if it sounds like:

- generic creators
- fitness consumers only
- SEO peers only
- AI tool buyers only
- agency operators only

Question:

Would Dana or Marcus save this for a business reason?

## Gate 2 - Pressure Gate

Pass if the piece names a real pressure:

- AI names a competitor.
- proof exists but does not travel.
- claim sounds strong but lacks receipt.
- founder expertise is invisible.
- buyer trust is leaking.
- content volume has no edge.

Fail if the piece is only:

- trend summary
- list of tips
- platform update
- broad thought leadership

Question:

What private pressure does this public post resolve?

## Gate 3 - GET Gate

Pass if the reader receives one tangible thing:

- prompt to run
- claim check
- source question
- rewrite
- audit lens
- decision rule
- proof object

Fail if the reader only receives:

- motivation
- agreement
- clever phrasing
- vague education

Question:

What can the reader do tonight?

## Gate 4 - Proof Gate

Pass if factual claims are labeled or sourced.

Fail if the piece:

- names a citation without proof
- implies client results
- uses unverified stats as fact
- overstates a study
- makes health claims without boundary

Question:

Could this survive a skeptical buyer reading it line by line?

## Gate 5 - Voice Gate

Pass if the piece sounds like:

- a credentialed operator naming a real gap
- precise but alive
- useful before it sells
- strong enough to be remembered

Fail if it sounds like:

- growth-hacker LinkedIn
- generic agency copy
- clinical explainer with no stakes
- AI-average thought leadership
- fake contrarianism

Question:

Could a generalist ghostwriter write this without changing their work?

## Gate 6 - Offer Gate

Pass if the piece naturally points to:

- AI-Search Visibility Test
- Claim-Safe Citation Audit
- GEO Authority Ghostwriting
- Creative Strategy Intensive

Fail if it points to:

- vague marketing help
- personal brand coaching
- commodity SEO
- more content volume

Question:

Which rung does this asset strengthen?

## Gate 7 - Restraint Gate

Pass if the piece stops after the useful turn.

Fail if it adds:

- unnecessary CTA
- repeated punchlines
- over-explanation
- empty urgency
- extra frameworks

Question:

What can be cut without reducing the proof?

## Kill List

Cut these moves:

- "more content" as the solution
- "AI search hacks"
- "go viral"
- "thought leader"
- "10x your content"
- "personal brand" as the lead
- generic "content strategy"
- every-post "DM me AUDIT"
- fake scarcity
- unsourced AI citation claims
- cure, treat, prevent language
- wellness guru tone
- SEO jargon before buyer pain
- case-study posture before case-study proof

## Stale-Source Rule

Before using an older file, check whether it conflicts with:

- `CANONICAL-OFFER-BRIEF.md`
- `MARKET-ICP-DOSSIER-2026-06.md`
- `CONTENT-OS.md`

If it conflicts, demote it to source material.

Current stale-risk files include:

- older offer ladder docs
- coach-era ICP docs
- early content-engine docs that force every post into an audit CTA
- any file claiming results or case studies not yet documented

## Greenlight Checklist

Before publishing, confirm:

- Audience is specific.
- Pressure is real.
- One useful GET exists.
- Claims are sourced or softened.
- No fake proof.
- CTA is absent unless earned.
- The post strengthens one offer rung.
- The voice has a line a generalist could not write.

If two or more fail, hold the piece.

## Oren Anti-Overproduction Rule

The system should produce fewer, stronger assets.

Do not turn every idea into:

- a carousel
- a thread
- a PDF
- a lead magnet
- a new series
- a product

Ask first:

Does this asset make the offer easier to trust or easier to buy?

If not, archive the idea.

## Monthly Review Kill Questions

At the end of each month, cut or change anything where:

- the work is high effort but low learning
- the format is being maintained out of guilt
- the series has no proof object
- the audience is wrong
- the CTA is carrying more weight than the insight
- the content is respected but not commercially connected

The point is domination through remembered judgment, not content volume.
