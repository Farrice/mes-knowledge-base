# Voice Gate — Pass/Fail Checklist for All LinkedIn Drafts

> Thin checklist, NOT a copy of the rules (avoids drift). Sources of truth:
> `_active/farrice-brand/CLAUDE.md` §Voice Rules · `_active/farrice-brand/thought-bank/pov-anchors.md` ·
> `skills/diandra-escobar-linkedin-growth/references/hook-format-library.md`
> **Fail = REGENERATE the section. Never patch a failing draft word-by-word.**

## A. Banned structural moves (any hit = fail)

- [ ] No "Here's what/why/how..." or "Here is the part nobody..." openers
- [ ] No twin-sentence aphoristic endings ("Stop X. Start Y.")
- [ ] No "It's not X. It's Y." reveals
- [ ] No triple-beat anaphora
- [ ] No italicized mid-paragraph aphorisms
- [ ] No mic-drop + deflation endings
- [ ] ≤2 em dashes total (0 in hook)
- [ ] No generic question close — run the paste test (pov-anchors #4): would this question work pasted on another creator's post? Yes = banned
- [ ] Close is voice-true: image / declaration / bookend admission / concrete future / naming what they feel / litotes / earned silence

## B. Hook check (real ceilings — count characters, show the count)

- [ ] Declared format + within ceiling: **Dense 140-160, zero breaks** · **Punchy ≤50 + ≤50** · **Bomb ≤50** · **Stacked 2-3 lines ≤60 each** · 210 max total
- [ ] No questions (exception: Stacked 4C with data viz attached) · no emojis · no em dashes · no clichés ("game-changer," "let that sink in," "read that again," "here's the thing," "the truth is," "I'm excited to share")
- [ ] No filler: actually, basically, very, just, really, literally, honestly
- [ ] Works for a stranger who has never heard of Farrice
- [ ] Opens a real gap (provokes, doesn't summarize)
- [ ] Two failed rewrites = drop the angle, new hook on new angle

## C. Voice & substance

- [ ] Show > Tell at the sentence level; pull-through to the final line
- [ ] Private-language test (pov-anchors #5): ≥1 line only this audience's person would write; highlight any line any creator in the category could have written — rewrite those
- [ ] Persuasion Stack present: single truth (1 sentence) · mechanism (the WHY) · matched proof (one telling specific) · identity-resistance addressed where relevant
- [ ] 80/20 integration + Inclusion Insurance pass (non-sharers get full value)
- [ ] Would Farrice say this to a friend? (no forced jargon, no corporate hype)
- [ ] Empathy direction (pov-anchors #1-2): written to land for the reader, not to make the writer look good

## D. Factual grounding

- [ ] Every real-world claim labeled VERIFIED or LIKELY with a receipt in the briefing ledger
- [ ] Zero fabricated numbers, studies, or citations; no real data point → experiential proof instead
- [ ] Background NEVER attributed: clinical psychology, therapy, trauma treatment (FARRICE.md clarification)

## E. Ecosystem variance (check last 7 days of briefings + performance log)

- [ ] Hook format differs from yesterday's post
- [ ] Closing structure not used in any post this window
- [ ] No phrase/metaphor reused from another piece in the window (incl. corrective-exercise metaphor ≤1 per post, never the hook twice running)
- [ ] Angle not covered in last 7 days
