## (d) 30-SECOND SETUP CHECKLIST — how to wire this in LinkedIn

> Do these in order. The whole thing is ~20 minutes once the linked assets exist.

1. **Headline:** Profile → pencil-edit intro → paste **Option 1** (or 2 if founder-first week). Confirm it's under 220 chars (LinkedIn will truncate silently if over).
2. **About:** Same intro panel → "About" → paste the full rewrite. Check the first 2 lines read well *before* the "see more" fold on mobile.
3. **Turn Featured on** (if hidden): Profile → "Add profile section" → Recommended → **Add featured**.
4. **Add the 4 items** in order — for each: Featured → **+** → **Add a link** (for the Doc/post URL) → paste URL → **edit the auto-pulled title/description** to the exact card copy above (LinkedIn pre-fills from the page; overwrite it).
5. **Set Doc sharing to "Anyone with the link → Viewer"** for items [1], [2], [4] if they're Google Docs. A locked link kills the funnel silently. Make every Doc **pageless** (per the standing rule).
6. **Verify order:** [1] Visibility Test → [2] Teardown → [3] DM AUDIT post → [4] POV post. Drag to reorder if LinkedIn scrambles them.
7. **Test on mobile AND desktop:** tap every card, confirm each link opens for a logged-out viewer (use an incognito window — a buyer often isn't your 1st-degree connection).
8. **Confirm the DM verb is everywhere:** About ends on `DM me 'AUDIT'`, item [3]'s post first-comment ends on `DM me 'AUDIT' for a free teardown`. One verb, one inbox.

**Standing maintenance:** swap item [2] for your freshest teardown weekly (cadence = ≥1 named teardown/week). Everything else is set-and-forget until the first 3 case studies land — then raise pricing per the path in the offer docs.
