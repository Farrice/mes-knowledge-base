# The Source Registry (Institution — Parked)

## Status

🔒 **PARKED** — Not activated until 2+ case stories are documented and approved for publication.

**Trigger:** Two Founding Sources complete their Sprint, share results, and approve case-story sharing.

**Reason:** Send-before-build. The institution only makes sense when proof exists. Naming an institution before results is theater. After results, it's infrastructure.

---

## The Concept (When Activated)

### What it is

**The Source Registry** is a named proof institution that holds all documented Founding Source case studies and methodology updates.

- **In-world definition:** The record of how founders solved their messaging problems through the Proof-to-Market method
- **Structure:** Numbered case stories (Source Story № 1, № 2, № 3…) with brands, occasions, results, and approvals
- **Archives:** The registry also holds every version of the methodology, proof hierarchy templates, and angle-bank evolution

### Visual form (when built)

The Source Registry would appear as:

1. **A web page** (`/source-registry`) — searchable, filterable by occasion (Launch / Retail / Repositioning) or industry (Supplements / Recovery / Performance)
2. **PDF archive** — The documented cases and method versions, forwarded when new clients ask for proof
3. **Monthly update** — Founding Sources receive updates on new cases added to the registry
4. **Public attribution** (permission-based) — Named case stories become part of the offer story ("See how these founders solved positioning")

## What happens before activation

- Founding Sources are told: "Your case story will be added to the Source Registry when published (permission-based)"
- No website, no public registry — just internal documentation
- Case stories live in the client folder only
- The institution is not named in any marketing until 2+ stories are published

## Anti-cringe note

**The Source Registry is not:**
- A testimonials wall (no client headshots or clichéd quotes)
- A hype machine (no "successful founders" framing)
- A closed club (public-facing, permission-based, honest about results)

**It IS:**
- An archive of proof
- A record of how the method evolved
- A forwarding object (when a new prospect asks "do you have proof?")
- A Founding Source status symbol (membership in the practice's documented history)
