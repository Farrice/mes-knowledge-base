## The Daily Decision Filter

Before spending time on ANYTHING, run it through these 3 questions:

### 1. Does this put money in my account within 14 days?
- **YES** → Do it. Priority A.
- **NO, but it builds toward $20K/month** → Queue it for Phase 2. Priority B.
- **NO** → Don't do it. Not now.

### 2. Am I the only one who can do this part?
- **YES** (strategy calls, voice capture, psychology-informed decisions) → Do it yourself.
- **NO** (research, drafting, editing, scheduling) → Let Antigravity handle it.

### 3. Is this moving toward a PAYING client or building a system for FUTURE paying clients?
- **CLIENT NOW** → Priority A. This is Phase 1.
- **SYSTEM LATER** → Priority B. This is Phase 2-3.
- **NEITHER** → Stop. You're procrastinating elegantly.
