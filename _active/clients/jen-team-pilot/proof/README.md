# Listing Launch Kit Proof Bank

This folder starts empty by design. It records real evidence from the Listing
Launch Kit in the order it occurs. Do not add examples, rehearsals, projected
results, or drafted testimonials as proof.

The canonical event ledger is `PROOF-LEDGER.csv`. One row represents one agent
and listing proof cycle. No row means `NO EVENT`.

## Evidence Folders

| Folder | Put here only when it exists |
|---|---|
| `00-permissions/` | Jen and agent permission receipts, including separate internal, named, and public-use choices |
| `01-before/` | Permissioned baseline screenshots, post links, workflow notes, and the agent's sourced problem |
| `02-payment/` | Redacted payment receipt and the agreed price, scope, and date |
| `03-delivery/` | Delivered-package manifest, timestamps, production-time record, compliance result, and revisions |
| `04-use/` | What the agent actually filmed, posted, changed, declined, or ignored |
| `05-results-24h/` | Descriptive 24-hour platform screenshots and keyword-DM counts |
| `06-results-7d/` | Descriptive seven-day platform screenshots and qualified-conversation counts |
| `07-feedback/` | The agent's own specific feedback or testimonial plus its use permission |
| `08-repeat-referral/` | Repeat purchase, referral, team-interest, or explicit non-repeat receipt |

## Naming Rule

Use:

```text
YYYY-MM-DD_agent-id_listing-id_evidence-type.ext
```

Example format only: `YYYY-MM-DD_agent-01_listing-01_payment-receipt.pdf`.
Do not create placeholder evidence files from the example.

## Evidence Rules

- Keep raw evidence unchanged. Add a redacted copy when privacy requires it.
- Redact buyer, seller, payment, and private-message identifiers unless their
  use is explicitly authorized.
- A platform metric is descriptive. It does not prove that the kit caused the
  result.
- A compliment without a sourced before state, used component, and concrete
  change is feedback, not a transformation story.
- Internal capture permission does not grant named or public use.
- Fair-housing and claim-safety review remains mandatory before anything is
  published.
