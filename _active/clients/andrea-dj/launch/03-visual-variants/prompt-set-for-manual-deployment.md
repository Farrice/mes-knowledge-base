# Resonance — Visual Prompts for Manual Deployment

*Paste these directly into ChatGPT (GPT Image 2) or Gemini (Nano Banana Pro). MCP-pipeline image generation is paused. You drive the platform; we drive the prompt language.*

**Why this exists (one paragraph)**: v1 (Fal/fantastic-posters) produced museum-coded posed framing. v2 (Higgsfield Nano Banana 2) regressed in detail and drifted to same-sex pairings, age miscalibration, and AI-slop anatomy. Both runs failed Andrea's brief at the body-language layer. The fix is not another MCP attempt — it's tighter prompt grammar deployed on the strongest available consumer models (GPT Image 2, Nano Banana Pro) where you can iterate live.

---

## Hard rules (every prompt carries these — do not delete from any deploy)

1. **Heterosexual M/F partnership focus**. The brand exists for adults seeking committed partners; the visual language must show male-female recognition. No same-sex pairings in hero shots. Group shots may include mixed friendships, but the romantic recognition beat is always M/F.
2. **Age: 30 to 38**. Early 30s to mid-late 30s. No 20-somethings. No 45+. If the model drifts younger, add "early-to-mid 30s, mature faces, not in their 20s."
3. **Multicultural cast, real specificity**. Anchor to the ICP: a Latina woman (Costa Rican / Mexican / Colombian features, not generic "olive"); a Black woman (mixed-Caribbean or African-American, natural or styled hair, not flattened); a Black man (40s-adjacent, athletic, designer/creative posture — Marcus archetype); a white man with Polish/Italian features (architect posture — Daniel archetype); occasionally a Filipino or Korean adult to honor Chicago's actual demographic mix. Never default to "diverse" as a checkbox — name the specifics.
4. **Anti-AI-slop language (paste verbatim at the end of every prompt)**:
   `Anatomically correct human proportions. Five fingers per hand, no extra digits, no fused fingers, no merged limbs, no duplicate body parts. Real photography fidelity. Skin texture has pores, not airbrushed. Eyes focused, not glassy. No mutated faces. No extra arms or legs in the background. Reject any AI-painting feel; this is a photograph, not a render.`
5. **Body language: connection, not detachment**. From `photography-rules.md` §6.5 — connection cues: laughing, eye contact, hand-on-shoulder, mid-conversation pose, leaning in, dancing facing partner. Disconnection cues (BANNED): from-behind static groups, looking-away-at-DJ, single-isolated-body, posed-staring-at-camera, hands-in-air stadium pose.
6. **Daylight + sober + curated**. West-facing window light, 2-5pm hour, no bar, no glassware. A 40-50 person room, not a stadium.
7. **No type, no logos, no overlays**. These are photographs, not posters. If the model adds text, regenerate.

---

## How to deploy (3-line workflow)

1. Open ChatGPT (GPT-4o or GPT Image 2 endpoint) OR Gemini (Nano Banana Pro tier).
2. Paste the chosen prompt verbatim. If platform supports image upload, attach 1-2 references from the scout deck at the bottom.
3. Generate 4 variants per prompt. Pick the strongest. If anatomy fails, regenerate with the slop-rejection paragraph re-emphasized at the top.

## Iteration protocol (when the first generation is close but not there)

| Failure mode | Fix in the prompt |
|---|---|
| Models look too young | Replace "30 to 38" with "early-to-mid 30s, mature faces, eye crinkles when smiling, not in their 20s." Add "no Gen Z styling." |
| Same-sex pairing drift | Re-emphasize at the top: "Heterosexual male-female pair, romantic recognition register." Name the man's role first, then the woman, then their orientation toward each other. |
| AI-slop anatomy (extra fingers, fused limbs) | Move the slop-rejection paragraph to the TOP of the prompt, not the bottom. Increase weight by repeating "no extra fingers, no fused limbs, no duplicate body parts" twice. |
| Cast feels generic-diverse | Replace "multicultural" with specific named ethnicities: "Costa Rican woman, Black mixed-Caribbean man, Polish-Italian white man, Filipino woman, Korean man." |
| Same-set / posed for camera | Add: "Nobody is looking at the camera. The camera is a participant in the room, not an observer. 35mm film, handheld, not still." |
| Too festival-y / EDM-coded | Add: "This is NOT a music festival. NOT a stadium. NOT EDM stage lighting. This is a 50-person room, sober, daytime, considered." |
| Wrong palette dominance | Re-list the palette at the END after the slop-rejection paragraph. Specify which color goes on which surface (walls / clothing / textile / wood). |

## What success looks like (for Farrice's taste pass)

A v3 hero shot earns PASS only if it scores YES on every line:

- [ ] M/F partnership recognition is unmistakable in the foreground
- [ ] Ages read as 30-38 — not younger, not older
- [ ] Specific multicultural cast (not "ambiguously brown")
- [ ] Daylight is real — west-facing window, late afternoon, not golden-hour cliché
- [ ] Body language reads as recognition (laugh, lean-in, eye contact, hand-on-arm)
- [ ] No anatomical errors visible at standard zoom
- [ ] Palette matches the variant DESIGN.md spec
- [ ] No text, no logos, no overlays
- [ ] The image makes Andrea say "yes" — not "almost"

If 8/9 PASS → use it. If 7/9 → regenerate with the iteration fix. If <7/9 → re-read this doc and identify which line of the prompt drifted.
