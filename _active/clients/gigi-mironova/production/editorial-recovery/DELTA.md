# Creative delta

| Dimension | Good run | Failed run | Degradation |
|---|---|---|---|
| Type | Modern sans with sharp scale changes | Oversized display serif everywhere | Category cliché replaced Gigi's voice |
| Image | Image and information share one argument | Photograph is a generic top panel | Property became background decoration |
| Copy | Specific number or fact creates tension | Broad lifestyle phrases | Lower authority and less memorability |
| Layout | Content determines composition | One template controls all content | Mechanical repetition reads AI-made |
| Restraint | Few elements, each doing a job | Empty space plus ornamental hierarchy | Minimal-looking, but not meaningfully edited |
