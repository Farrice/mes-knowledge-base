# Local property-video capability

The user-approved vertical property-film workflow is installed privately at this directory. Enter through `.agent/workflows/jen-property-video.md`. The private SKILL.md, renderer, source references and approval manifests are restored from the private preservation bundle; they are intentionally excluded from this public repository.

A checkout alone is not a full media restore. Run the private verifier before generation and fail clearly if private assets are absent. Existing landscape and weekly social-content workflows remain separate.
