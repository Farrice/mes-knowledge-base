# Valley Editions in Claude Design — the handoff

Claude Design does the visual. This folder is everything it needs: the system (DESIGN.md), the geometry of the six Canva grammars (GRAMMAR.md), the final copy (COPY-DECK.md), her photos (photos/), and three reference sets. Read this page, then paste from PROMPTS.md in order.

## The references, and what each one is
- `reference/template-local-gem/1–5.png` — **the target.** The Canva template as exported, page by page. Match its type confidence, wash, doodles and composition; swap its yellow for the pale-blue accent and its stock for her photos.
- `reference/canva-native-attempt/` — the same template filled inside Canva (right fonts, wrong composition, stock placeholders). Useful only to see the real typeface on her words.
- `reference/our-take-2/` — the current code-rendered attempt (Instrument Serif). Not the target: it is the floor to beat. `01–05` are the edition; `S2–S6` are the five alternate grammars.

## Setup (five minutes)
1. claude.ai/design → new project, or the existing **Jen Santulan · Valley Native** project if you want the older navy line-icon system alongside. This edition is a different look; a fresh project called **Jen Santulan · Valley Editions** keeps them apart.
2. Attach DESIGN.md, COPY-DECK.md, GRAMMAR.md, the `photos` folder, and `reference/template-local-gem`.
3. Paste prompt 0, then prompt 1. Judge. Then 2 and 3 as needed.
4. Export PNGs. Send me the ones you like with one line each on what changed; I encode it into the generator so every future edition inherits it.

## The rules that don't move
- Palette: cream and white type, one accent #C9D4E2, no yellow, no orange, no navy blocks.
- One serif in every role on a Local Gem page: Instrument Serif (or Canva's own vintage serif if Claude Design has a closer match; name it back to me).
- Type never sits on a face. Her face only from her real photos.
- Copy is final. Numbers are verified. "buying or selling" in the ask, never "your first home", never "safe / family / schools / quiet".
- Photos only from `photos/`. Placeholders are named as placeholders.

## Judging a candidate (same three questions every time)
Does it still read as the template's cousin at thumbnail size? Is the copy untouched and legible? Would it survive as one screenshot with nothing around it?
