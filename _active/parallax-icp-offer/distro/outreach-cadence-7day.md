## SOLO-EXECUTION GUARDRAILS

- **No batching personalization**: screenshot each referenced post individually. No "I'll write 5 hooks then paste them." The moment personalization becomes a template, reply rate halves.
- **No weekend evening sends**: the brain gets tired, scripts drift, you send something that includes "creator" or "monetize" by mistake.
- **Tracker MUST update daily**: not "I'll catch up Sunday." Invisible data = invisible decisions.
- **One avatar per session**: context-switching between Avatar 01 and Avatar 02 in the same 45-min block degrades script quality. Block by avatar.
