- **Won't run paid ads pre-product-market-fit** (Oracle posture, §3)
- **Won't post-volume past quality threshold** (5-piece weekly cap, §1)
- **Won't compete on per-post pricing** (mechanism-led pricing, §3)
- **Won't allow brand handle to post hot takes** (Two-Account discipline, §2)
- **Won't lower Parallax tier price below $10/mo** (Oracle anti-positioning floor, §5)
- **Won't write for the demographic — only for Maya** (consumer posture discipline, §6)
