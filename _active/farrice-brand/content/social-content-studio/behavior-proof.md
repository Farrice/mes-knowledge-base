# Social Content Studio — Behavior Proof

## Input Tested

- Seed: `More creative cannot solve an unmade campaign decision.`
- Platform: LinkedIn
- Context: current Farrice audience, Voice Card, Angle Map LinkedIn system, winning-pattern profile, Premium Minimal design contract, and claim/proof contract

## Weakness Diagnosed

The pre-change signal-loop run produced grounded ideas and evidence labels, but future execution still required manual assembly across context, style, selection, voice, carousel, video, and approval surfaces. It did not carry a shared `Person → Tension → Path`, executable refusal file, format handoffs, or one package-level external-action gate.

## Source Mechanics Used

- Prepare durable context before production.
- Preserve operator judgment and publication authority.
- Generate surplus before committing a calendar.
- Use `Focus → Style → Plan → Create → Package` in dependency order.
- Begin with one week and one repeated workflow instead of a 20-skill build.

## Output Produced

- One source-cited Context Lock.
- One shared Content Spine.
- Six hard refusal constraints.
- Twelve materially different candidates, three selected and nine parked.
- One authority-post review draft, one carousel architecture/visual brief, and one short-video concept/brief.
- One evidence ledger and machine-readable approval manifest.

## Behavior Delta

| Dimension | Frozen pre-change behavior | Social Content Studio behavior | Result |
|---|---|---|---|
| Cited context | Present in the signal-loop assets | Preserved and compiled into one Context Lock | PRESERVED |
| Person → Tension → Path | Not an explicit shared contract | Explicit and reused across all three selected formats | IMPROVED |
| Refusal constraints | Audience anti-triggers existed as advisory context | Six hard, testable content and proof vetoes | IMPROVED |
| Surplus selection | Eight ideas; selection attached to a direct queue operation | Twelve differentiated executions; three selected with reasons; nine explicitly uncommitted | IMPROVED |
| Format handoffs | No post/carousel/video handoff in the run | Three native review artifacts with named downstream owners | IMPROVED |
| Human/evidence gates | Felt verdict and source gaps were recorded separately | One manifest controls context, selection, voice, visual, paid-tool, and publication states | IMPROVED |

The new workflow adds all six required dimensions, materially improves five, and preserves the existing source and proof boundaries.
