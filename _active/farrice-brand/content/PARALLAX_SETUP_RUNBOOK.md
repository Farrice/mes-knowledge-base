# The Parallax Setup Runbook

**Goal**: Convert your existing personal Substack into Parallax — configured, on-voice, and ready to post.
**Time**: 45-60 minutes, done once.
**Mode**: Free tier only (paid comes later).
**Status of UI references**: Substack moves settings around. I'll describe by function; if a menu name is slightly different, look for the closest match.

---

## PART 2 — Execution (the navigation walkthrough)

Substack's settings live under the **gear icon** (Settings) in your dashboard sidebar. All paths below start from the Substack dashboard after login.

### PHASE A — Core publication identity (10 min)

**A1. Rename the publication**
- Dashboard → **Settings** (gear icon)
- Find **Basics** (usually top of the settings list)
- Field: **Publication name** → paste `Parallax`
- Field: **Tagline / Short description** → paste the tagline from §1.1
- Save

**A2. Change the URL slug**
- Still in **Settings → Basics**
- Field: **Subdomain / URL** (may be labeled "Publication URL" or "Custom URL")
- Try `parallax` first. If taken, try `parallaxletter`, `readparallax`, `parallaxedition`
- **Warning**: Changing the URL breaks any existing links to your current Substack. Since you have one post with (presumably) low reach, this is fine — but decide about that post first (see Phase F).
- Save

**A3. Upload logo / avatar**
- Still in **Settings → Basics** (or a sub-tab labeled **Branding** / **Design**)
- Upload your profile picture as the publication logo
- If there's a separate "Publication image" or cover image field, upload the same one for now
- Save

**A4. Set the SEO description**
- In **Settings**, find **Publication details** or **SEO** (sometimes nested under "Basics" or "Advanced")
- Field: **Description / SEO description** → paste §1.2
- Save

`★ Insight — Why the tagline line matters more than you think ───────`
Substack's homepage, the Discover algorithm, and every "recommended publication" card all lead with your tagline. It's the single piece of copy a stranger uses to decide whether to click. "For people who were never meant to fit in one box" invites self-recognition — it's a filter, not a description. People who aren't your audience scroll past; people who are stop cold. That's the correct function of a tagline at this stage.

### PHASE C — Sections (5 min)

Sections let you separate Editions from Prompt Packs on your homepage and in subscriber email preferences.

**C1. Create the two sections**
- Settings → **Sections** (if you don't see Sections, it may be under **Publication setup** or **Advanced**)
- Click **Add section** / **New section**
- Section 1:
  - Name: `Editions`
  - Description: paste §1.8 Editions
  - Publishing settings: Email + web (default)
- Section 2:
  - Name: `Prompt Packs`
  - Description: paste §1.8 Prompt Packs
  - Publishing settings: Email + web (default)

**C2. (Optional) Set Editions as default**
Some Substack versions let you pick a default section new posts land in. If yours does, set default = `Editions`. You can always override per post.

### PHASE D — Discovery + Notes setup (5 min)

**D1. Discovery categories**
- Settings → **Discover** / **Publication categories** / **Topics**
- Select up to 3: **Culture**, **Philosophy**, **Technology**
- If those exact categories don't exist, closest matches are: Lifestyle, Self-Improvement, Tech/AI, Writing
- Save

**D2. Recommendations (partial setup now, expand later)**
- Settings → **Recommendations**
- Leave blank for now. This is a mutual-ask system — after you publish Edition 01, you'll reach out to 5-10 similar-angle writers (Jun Yuh, Lulu Cheng Meservey types) and recommend each other. Flag this as a post-launch task.

**D3. Start a Substack Note today — and commit to a real cadence**
- Dashboard → **Notes** tab (top nav, looks like a social feed)
- Post your first Note: a 2-3 line teaser of the manifesto. Draft:
  ```
  I paid a business coach $14K to tell me to niche down.
  Two years later I figured out he was wrong about everything.
  Edition 01 of Parallax drops Monday.
  ```
- **Cadence (this is the most under-weighted lever in your setup)**: 2026 Substack data shows Notes drives **70-90% of new subscribers** for growing publications, and creators posting 3-5 Notes/day grow 4-5x faster than newsletter-only publishers. The platform's algorithm shifted to sequential learning in late 2025 — it rewards narrative progression and conversion-predictive interactions over likes.
- **Weekly target**:
  - **10-5-1 weekly rule**: 10 thoughtful comments/replies on adjacent publications, 5 original value Notes, 1 promotional Note linking to your latest Edition
  - **3-2-1 daily formula** (when ramping): 3 value posts (frameworks, observations), 2 engagement posts (questions, polls), 1 soft promo
- **Use Notes scheduling** (launched March 2026) to batch a week of Notes in one sitting
- High-conversion Note formats to rotate through:
  - **Micro-story** (<400 chars): one specific moment + lesson
  - **Vulnerable admission**: a recent failure or pivot
  - **Quotable punchline**: a single resonant sentence designed to be restacked

### PHASE E — Navigation, pinning, visual check (5 min)

**E1. Pin the manifesto (after you publish Edition 01)**
- On your homepage view, click the **⋯** menu on Edition 01
- Select **Pin to top** / **Feature on homepage**
- This becomes your hero — the first thing every visitor sees

**E2. Remove clutter**
- Go to your homepage as a logged-out visitor would see it (open an incognito window → `parallax.substack.com`)
- Check: is there a Leaderboard, Chat tab, or other default element that dilutes focus?
- Back in Settings → look for **Homepage** / **Layout** / **Navigation** options and hide anything that isn't: Home, About, Subscribe button
- For now, keep it minimal. You can enable Chat, Podcast, etc. later if you use them.

**E3. Final visual sanity check**
Open three URLs in incognito and confirm:
- `parallax.substack.com` — pinned post visible, About link in nav, subscribe button prominent
- `parallax.substack.com/about` — the §1.4 copy renders, no broken images
- Subscribe flow — click Subscribe from the homepage, enter a test email you can access, check: welcome email arrives, subject and body match §1.6

### PHASE F — The existing post (decide now)

You have one post from your personal Substack phase. Three options:

| Option | When to pick | How |
|---|---|---|
| **Delete** | If the post doesn't reflect Parallax's voice or thesis | Post → ⋯ menu → Delete |
| **Unpublish & draft** | Keep it for personal reference, off public view | Post → ⋯ menu → Unpublish |
| **Keep as "Edition 00"** | If it's strong and on-theme — rename, re-tag, re-date | Edit post → update title, assign to `Editions` section, optionally backdate |

**Default recommendation**: Unpublish it. Start Parallax's public archive clean with Edition 01 as the first thing anyone sees. You can always republish later.

## Things I was less certain about (flag for verification)

- **Exact Substack menu labels**: Substack has shifted "Settings" sub-menus several times. If "Basics" is called something else, look for wherever publication name + tagline + logo live together.
- **Welcome email editor behavior**: Some Substack accounts edit the welcome email via Settings, others via a separate Emails section. Both paths work.
- **Character limit on tagline**: SEO best practice is ≤60 chars for the SEO title specifically; the display tagline may allow more but shorter performs better on Discover cards.
- **Sections default**: Whether you can set a default section for new posts depends on account age / tier. If the option isn't there, just tag each post manually on publish.
