# Display

The headline voice: sentence case, −0.025em tracking, close optical leading.

Sentence case is a rule, not a preference. Title case and all-caps headlines read as advertising and break the system.

One dominant idea per surface means **one level-1 Display per surface**. Levels 2 and 3 step down for supporting statements.

```jsx
<Display level={1}>Most supplement brands buy attention they already had.</Display>
<Display level={3} as="p">The proof was in the reorder rate the whole time.</Display>
```
