# FieldIndex

The numbering mark: `FIELD / 01`, `NOTE / 02`, or a bare two-digit page number.

At `label` scale it is Graphite and quiet. At `large` scale it is Stone and acts as structure — never as a headline. A large index must not compete with the dominant idea on the surface; that is what Stone is for.

```jsx
<FieldIndex label="FIELD" index="01" />
<FieldIndex index="02" scale="large" />
```
