# FunctionalLabel

Uppercase label type at +0.16em tracking — the system's only uppercase move.

Use it to name a field, a section, or a state. The stylesheet uppercases the content, so pass normal text.

Do not use it for headlines. A headline in tracked uppercase is the luxury theatre this system rejects.

`tone` is `graphite` (default), `ink`, `stone` for non-essential labels, or `on-ink` for dark surfaces.

```jsx
<FunctionalLabel>Field note</FunctionalLabel>
<FunctionalLabel tone="on-ink">Recommendation</FunctionalLabel>
```
