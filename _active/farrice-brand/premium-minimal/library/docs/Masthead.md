# Masthead

The small uppercase identity label at the top of a surface. A functional label, not a decorative logo — no mark, no badge, no seal, no container.

Two modes, one system:

- `master-brand` — mastheads `FARRICE CAIN` with the descriptor `CREATIVE STRATEGY FOR SUPPLEMENT + PERFORMANCE BRANDS`. Use for category point of view, lived observation, teardowns, frameworks.
- `offer` — mastheads `THE ANGLE MAP` and credits `FARRICE CAIN` as author. Use for the three campaign arguments and one recommendation.

```jsx
<Surface size="banner">
  <Masthead mode="master-brand" />
</Surface>
```

`identity` and `descriptor` override the defaults. Only use them for a genuinely different property — overriding them to say something clever breaks the identity the mode exists to hold.
