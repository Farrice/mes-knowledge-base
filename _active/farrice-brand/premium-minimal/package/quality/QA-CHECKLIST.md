# Production QA Checklist

An asset may move from draft to review only when every required check passes.

## 1. Authority and state

- [ ] Correct mode selected: Farrice Cain master brand or The Angle Map offer.
- [ ] Exact approved or Farrice-supplied copy identified.
- [ ] Closest approved template or recipe identified.
- [ ] Current asset state displayed correctly.
- [ ] No rejected branch, unconfirmed credential, or stale approval label entered the work.

## 2. Five-second comprehension

- [ ] The subject is obvious.
- [ ] The dominant thought is obvious.
- [ ] The intended buyer or context is apparent where required.
- [ ] An offer asset makes the object, output, decision, and action understandable.
- [ ] The page does not require internal strategy language to make sense.

## 3. Visual system

- [ ] Helvetica Neue is used for final production, or substitution is explicitly reported.
- [ ] Canonical palette used, except the named approved-banner legacy exception.
- [ ] Twelve-column logic is visible.
- [ ] At least one-third of the composition remains open.
- [ ] No more than three hierarchy levels.
- [ ] One dominant idea.
- [ ] Tracking and leading are optically calibrated.
- [ ] Secondary text is quieter but remains legible.
- [ ] Every visible element scores +1 or has a clear functional reason.
- [ ] No serif, gradients, shadows, pills, badges, icons, contour ornament, or luxury theater.

## 4. Functional components

- [ ] Functional masthead is consistent.
- [ ] Route grammar appears only when real choices are compared.
- [ ] Lead route is unmistakable without decorative color.
- [ ] Dark interruption appears no more than once per sequence.
- [ ] Proof boundary remains understandable when the asset is forwarded alone.
- [ ] Fictional demonstration label is visible when required.

## 5. Thumbnail and crop

- [ ] Dominant headline survives at 320 px width.
- [ ] Contact-sheet or 25–30% thumbnail inspection passes.
- [ ] Platform safe areas pass.
- [ ] LinkedIn profile-photo overlap does not obscure required banner content.
- [ ] No essential text sits against a crop edge.

## 6. Claim and identity

- [ ] No invented proof, client result, logo, testimonial, or performance implication.
- [ ] No legal, medical, scientific, regulatory, or compliance approval implied.
- [ ] Approved evidence ownership remains visible where relevant.
- [ ] Original portrait used only if the private add-on was authorized.
- [ ] Face pixels were not generated, reconstructed, reshaped, or AI-upscaled.

## 7. Export

- [ ] Editable source supplied.
- [ ] Native-size export supplied.
- [ ] PNG is sRGB PNG-24 when used for LinkedIn.
- [ ] PDF pages are consistent in size.
- [ ] Fonts are embedded in final PDF where applicable.
- [ ] Local linked images resolve after moving the asset folder.
- [ ] Alt text supplied when relevant.
- [ ] Filename includes surface, subject, state, and version.

## 8. Approval boundary

- [ ] Asset remains draft or review unless Farrice explicitly promoted it.
- [ ] No upload, publication, profile change, outreach, or deployment occurred.
- [ ] Delivery receipt records deliberate omissions and remaining decisions.
