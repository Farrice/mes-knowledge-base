# Private Identity Add-On

The original Farrice Cain portrait is intentionally excluded from the shareable core package.

When a portrait is genuinely required:

1. obtain the separately packaged Farrice-Cain-Private-Identity-Add-On-v0.9-review.zip;
2. read its rights and provenance record;
3. attach the original portrait only to the authorized collaborator or AI system performing that specific brand task;
4. preserve the original face pixels; and
5. remove the portrait from shared working folders when the task no longer requires it.

If the private add-on is unavailable, create a type-led asset. Never synthesize a replacement face.
