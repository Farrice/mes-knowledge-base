## The repeatable method

The reusable asset is the process, not this aesthetic:

1. Name the existing identity owner and proof boundaries.
2. Research multiple materially different reference angles in Refero.
3. Build three unmistakably different directions with one primary reference and bounded secondary borrowing for each.
4. Make every option locally visible and verify the preview files before asking for a decision.
5. Recommend one direction with an explicit tradeoff and keep the human taste checkpoint.
6. Write a reference lock before implementation.
7. Prove the lock on one or two representative surfaces before expanding.
8. Run visual, mechanical, brand-drift, and claim-boundary QA.
9. Preserve the approved example, the failed example, the rejects, and a replay prompt.
