# Performance Evidence Journal — reference lock

Status: `LOCKED FOR MOCKUP`

This direction is a Health Performance vertical mode inside Farrice Cain Premium Minimal. It does not create a second identity, token set, component library, or offer brand.

## Build target

Create a master-brand hero and an Angle Map decision page that feel like a premium evidence journal: calm enough to trust, structured enough to decide, and restrained enough to keep the argument—not decoration—in control.

## Canonical owner

- **Identity owner:** Premium Minimal.
- **Token owner:** [`../../tokens/design-tokens.css`](../../tokens/design-tokens.css).
- **Component grammar owner:** [`../../../library/src/premium-minimal.css`](../../../library/src/premium-minimal.css).
- **Offer mode:** The Angle Map remains a named offer inside the master brand.
- **Copy boundary:** Strategic decision support only. No health outcome, scientific authority, regulatory authority, or compliance result is implied.

## Traits that may not drift

1. Use only the existing Premium Minimal palette: canvas, paper, ink, graphite, line, stone, white.
2. Use Helvetica Neue only, with sentence-case display copy and uppercase functional labels.
3. Keep the twelve-column grid, open space, thin rules, sharp edges, and no more than three hierarchy levels.
4. Make one argument dominant per surface.
5. Use route grammar only for a real comparison.
6. Reserve the single dark interruption for the consequential Angle Map recommendation.
7. Keep proof boundaries visibly separate from recommendation language.

## Signature translation

The journal feeling comes from **evidence architecture**, not borrowed biotech decoration:

- editorial field numbers;
- ruled evidence records;
- compact source/status labels;
- a wide reading measure;
- disciplined light-to-dark cadence;
- one thick route line to mark the recommended decision.

## Media lock

The first mockup is intentionally type- and structure-led. It uses no image because none is needed to carry the idea. Future media may use approved source documents, material close-ups, real product evidence, or restrained portraiture. Generic supplement bottles, athletes in motion, molecule graphics, luminous biology, and fake scientific diagrams are rejected.

## Explicit rejects

- No new accent color.
- No serif or mono font.
- No gradients, shadows, pills, badges, seals, rounded cards, or ornamental icons.
- No black-and-gold premium theater.
- No oversized health promise.
- No visual claim of laboratory, medical, scientific, regulatory, or compliance authority.
- No second logo, second design system, or parallel brand package.

## Acceptance test

The mockup passes only if it is immediately recognizable as Premium Minimal when the Health Performance copy is removed, while the evidence-journal structure makes the vertical unmistakably more precise and decision-led.
