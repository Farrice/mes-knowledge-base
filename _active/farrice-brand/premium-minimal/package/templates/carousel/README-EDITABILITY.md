# Carousel Editability

The true editable sources are the four SVG page files in this folder.

The PPTX contains one flattened page image per slide. It is useful for sequencing, presentation, and PDF export, but its typography and page elements are not independently editable inside PowerPoint.

To revise the carousel:

1. edit the relevant SVG page;
2. export a replacement 1080 × 1350 PNG;
3. replace that page image in the PPTX;
4. export a new flattened PDF;
5. verify all pages remain the same size; and
6. rerun thumbnail and font-substitution checks.

Do not describe the supplied carousel PPTX as a fully editable text-and-shape master.
