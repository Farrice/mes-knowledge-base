# Asset State Ledger

## State definitions

| State | Meaning | External use |
|---|---|---|
| `approved` | Farrice explicitly approved the exact asset or protected primary | Still requires action-specific authorization before upload or publication |
| `review` | Production-ready enough for taste judgment; not promoted | No |
| `draft` | In progress or exploratory | No |
| `rejected` | Preserved only as regression evidence | Never reuse as a base |
