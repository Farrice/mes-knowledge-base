## Required Decision Logic

1. Compare available paths by:
   - first-dollar speed
   - proof required
   - audience dependency
   - delivery complexity
   - productization upside
   - long-term upside
2. Choose one primary path, one secondary path, and one deferred path.
3. Build the primary path around a paid service, audit, sprint, or implementation offer.
4. Treat digital products as proof-derived packaging, not the starting move, unless the user already has an audience and demand.
5. Define unlock criteria before any course, prompt pack, cohort, or product library is built.

## Output Contract

Produce or update an operating pack with:

- decision scorecard
- selected primary, secondary, and deferred paths
- buyer target
- price and offer promise
- first proof asset
- first deliverable
- 14-day action calendar
- outreach script
- stress test
- acceptance criteria
- productization unlock criteria
