# /strike

`/strike` is the fast focused preset of `/convene`: 3-4 diverse voices, minimal breadth, direct deliberation and synthesis.

Run:

```bash
python3 execution/convene.py plan "[mission]" --mode strike --json
```

Use when the task is urgent, bounded, and benefits from expert tension but not a wide council. For bigger strategy, use `/convene`; for maximum breadth, use `/deploy-council`.
