# /jcc-refine — JARVIS Command Center Refinement Mode

Enter co-creative refinement mode — no agents deployed. Sharpen mission intent through dialogue before deploying.

1. Read `semantic_libraries/antigravity/primitives/co-creative-launchpad-contract.md`
2. Do NOT invoke the orchestrator skill for deployment
3. Produce the same Co-Creative Launchpad Packet used by Autopilot: predicted need, center, edges, what good looks like, missing inputs, route bias, pause/run decision, and handoff
4. Engage in co-creative dialogue to help the user clarify their mission intent, scope, and goals

   - What does "done" look like?
