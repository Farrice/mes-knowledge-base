# /first-10k — First $10K Execution Workflow

Dual-use workflow for internal execution and client-facing work. Use this when the objective is to turn an idea, skill, service, client opportunity, or business asset into a focused path toward the first $5K-$10K in online revenue.

Default lane: **service-first revenue** through paid audits, implementation sprints, and client acquisition. Change lanes only when the objective clearly points to a digital product, app, content engine, or client-facing strategy package.

## Output Contract

Create an artifact folder:

```text
brain/[objective-or-client-slug]-first-10k-v1/
```

The folder must contain:

1. `README.md`
2. `BUYER-BELIEF-INTELLIGENCE.md`
3. `CONSUMER-POSTURE-ICP.md`
4. `POSITIONING-AND-CATEGORY.md`
5. `OFFER-ARCHITECTURE.md`
6. `ASSET-AUDIT.md`
7. `ACQUISITION-SPRINT.md`
8. `SALES-PROOF-KIT.md`
9. `DELIVERY-AND-OUTCOME-LOOP.md`

If the user requests a narrow pass, preserve the same sequence and produce a reduced artifact set. Never skip buyer reality, offer, acquisition, proof, or outcome logic entirely.

## Required Source Intake

Gather available source material before producing:

- objective, offer idea, client/project context, or business goal
- current audience, buyer, niche, ICP, or customer assumptions
- existing content, website, profile, landing page, proposal, or outreach copy
- existing client work, delivery process, testimonials, proof, or results
- current constraints: time, money, skills, team, tools, audience, geography, platform
- desired revenue target, timeline, and acceptable delivery intensity

If source files are named or discoverable in the workspace, read the relevant files. If the user gives no source material, infer only the minimum and mark assumptions clearly.

## Workflow Stack

Run the stack in order.

### 1. Objective And Revenue Lane

Load and apply:

- `skills/daniel-priestley-24-assets-os/SKILL.md`
- `skills/daniel-priestley-24-assets-os/genius.md`

Purpose:

- Classify the objective: audit, sprint, service, product, app, content engine, client-facing package, or hybrid.
- Identify the fastest credible path to first revenue.
- Default to service-first unless another lane is clearly stronger.
- Define the reusable asset this workflow must create.

Output in `README.md`:

- objective
- mode: internal, client-facing, or dual-use
- revenue lane decision
- fastest path to first paid commitment
- core assumptions and constraints
- artifact file map

Quality gate:

- If there is no buyer, paid pain, or plausible paid outcome, sharpen before moving forward.

### 2. Deep Buyer Reality Layer

Load and apply:

- `skills/david-mcraney-belief-change/SKILL.md`
- `skills/david-mcraney-belief-change/genius.md`
- `skills/david-mcraney-belief-change/workflows/belief-first-audience-intelligence.md`
- `skills/dai-media-consumer-posture/SKILL.md`
- `skills/dai-media-consumer-posture/genius.md`
- `skills/dai-media-consumer-posture/workflows/consumer-identity-discovery-blueprint.md`
- `skills/growth-ecosystems/SKILL.md`
- `skills/growth-ecosystems/genius.md`
- `skills/growth-ecosystems/workflows/01-ica-deep-intelligence.md`

Purpose:

- Map audience beliefs, resistance, processing routes, social risk, identity cost, and minimum viable belief shift.
- Build a vivid one-person consumer posture profile.
- Identify decision triggers, signal environments, validation questions, pain language, Point A -> Point B, Three-Yes blockers, and offer implications.

Output:

- `BUYER-BELIEF-INTELLIGENCE.md`
- `CONSUMER-POSTURE-ICP.md`

Hard gate:

- Do not begin offer construction until these are clear:
  - one specific buyer, not a demographic
  - belief and worldview map
  - decision trigger map
  - pain language in buyer words
  - Point A -> Point B transformation
  - belief blockers and proof implications

### 3. Positioning And Category

Load and apply:

- `skills/april-dunford-positioning/SKILL.md`
- `skills/april-dunford-positioning/genius.md`

Purpose:

- Choose the market category the buyer already understands.
- Name alternatives and status quo competitors.
- Define differentiated value against those alternatives.
- Translate Dai/McRaney buyer reality into clear positioning.

Output in `POSITIONING-AND-CATEGORY.md`:

- category
- target buyer
- alternatives
- differentiated value
- buyer risk
- proof needed to reduce risk
- plain-language positioning statement

Quality gate:

- A cold buyer should understand what this is, who it is for, and why it is different before any branded or poetic language appears.

## Category 1 Remarkable Standard

The workflow passes only if:

- A buyer would feel "this is for me" before seeing the offer.
- The offer is built from worldview, belief resistance, and pain language.
- The offer is economically and psychologically compelling.
- The first sale path is executable within 7 days.
- The delivery creates reusable assets, not one-off activity.
- The package can be used internally or shown to a client without exposing internal chain mechanics.
