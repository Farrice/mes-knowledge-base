## Runtime Inputs

Required:

- Brand, person, product, offer, or system being categorized
- Audience or buyer
- Current category box
- Proof or lived evidence behind the unfair intersection

Optional:

- Existing copy, website, profile, offer page, posts, product docs, client notes, or source package
- Desired output channel: content, offer, product, world-building, positioning, messaging, or internal harness design
- Naming constraints or phrases already approved

If required inputs are missing and cannot be inferred, ask only for the smallest missing field.

## Workflow

### Phase 1: Source Lock

State:

- source evidence used
- transcript/visual limits
- existing Erica assets loaded
- whether the output is a new category, category repair, or category proof layer

### Phase 2: Current Category Box

Name the category people currently use to judge the brand.

Produce:

- comparison set
- default criteria
- hidden rules around pricing, proof, tone, content, and opportunity
- where the brand is obeying the wrong rules

### Phase 3: Unconscious Decision Map

Map the assumptions created by the current category.

For each assumption:

- what people expect
- how they judge
- what behavior it creates
- what belief or proof can challenge it

### Phase 4: Open-Lane Diagnosis

Use Erica's Through-Line Discovery, Duo Differentiation, Physical Response as Data, and Open Lane Detection.

Produce:

- through-line
- unfair intersection
- 3 category candidates
- proof for each
- strongest candidate
- why the weaker candidates were rejected

### Phase 5: Anti-Gimmick Gate

Apply `category-building-deployment-contract.md`.

Return one verdict:

- `PASS`: category has language, proof, ritual, and adoption path
- `REVISE`: category is promising but needs clearer proof or plainer language
- `STOP`: category is just a gimmick, trend, or renamed normal service

Do not continue to deployment until a `REVISE` or `STOP` category has a repair plan.

### Phase 6: Category Language Ladder

Produce:

- internal category thesis
- buyer-readable phrase
- public category line
- category name candidates
- old-category phrases to stop using
- repeatable phrases the audience should start echoing

### Phase 7: Belief-To-Category Ladder

Connect Erica's existing Brand Magnetism system:

- 3 themes
- 9 beliefs
- enemy
- hero alternative
- permission statement
- tribal invitation

### Phase 8: World-Building And Proof Rituals

Produce:

- rituals
- recurring examples
- proof events
- content formats
- visual or verbal motifs
- demonstration assets
- audience participation points

### Phase 9: Category Adoption Signals

Define how to know it is working:

- inbound language matching
- unsolicited forwarding
- identity declaration
- buyer question change
- referral phrasing
- comparison-set shift
- proof requests
- magnetism decay signals

### Phase 10: 30-Day Deployment Sequence

Produce a plan with:

- weekly objective
- exact actions
- content prompts
- offer/audit hooks
- proof capture
- feedback loop
- quality bar

## Quality Gate

Reject or revise before final if:

- the category is not buyer-readable
- the output is only a naming exercise
- the unfair intersection lacks proof
- the category does not change judgment criteria
- the proof rituals are vague
- no adoption signal is defined
- the output ignores existing approved positioning when working on Farrice's service lane
- the source-video limits are not stated when citing `5TEMdTopdy8`
