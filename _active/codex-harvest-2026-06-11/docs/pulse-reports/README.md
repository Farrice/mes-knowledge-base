# Pulse Reports

Use this folder for concise post-ship, post-delivery, or post-experiment signal reports.

Pulse reports should stay short: headlines, usage or adoption, system or delivery performance, quality sample, and followups. They are working memory, not dashboards.

When a mission produces only an internal milestone pulse, keep it in that mission's `docs/mission-artifacts/<slug>/pulse.md`. Promote or mirror it here when the report should become part of the longer-term operating timeline.

## System Cohesion

Weekly system-cohesion platters live in `docs/pulse-reports/system-cohesion/`.
They are generated by `python3 execution/recurring_ops.py weekly-system-pulse`
and use the Silver Platter Pantry -> Prep -> Plate model to show route health,
activation blockers, dormant protocols, proof status, and the next repair move.

The matching machine-readable maps live under
`.agent/recurring-reports/system-cohesion/`.
