# Solutions

Use this folder for generalized learnings that future agents should reuse.

Promote a mission-local `solution-capture.md` here when the learning is likely to recur across missions, workflows, code paths, or client delivery. Keep one canonical doc per problem pattern when possible; update an existing doc instead of creating overlapping guidance.

Suggested shape:

- Problem or context
- Symptoms or trigger
- What did not work
- Working solution or durable guidance
- Why it works
- Prevention or reuse rule
- Source mission or evidence
