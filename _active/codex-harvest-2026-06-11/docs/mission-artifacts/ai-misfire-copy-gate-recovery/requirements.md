Created: 2026-05-10
Mission: ai-misfire-copy-gate-recovery

## Problem Frame
Analyze and revise the AI Misfire revenue-suite artifacts after user rejected inflated Copy Gate scores; log the failure, harden gates against ceremonial scoring, and produce amplified publishable copy grounded in the latest marketing-void intent.

## Requirements
- R1. Active AI Misfire public/revenue copy must be revised from the latest user intent: zero proof, no begging, brand/news/attention jacking, customer-language resonance, Creative Strategist + AI Operating Partner, and marketing-system void as the core demonstration.
- R2. Copy Gate Result sections must stop overclaiming. Any active current-intent gate must include user-calibrated baseline, failure addressed, score discipline, expert deployment evidence, and a prose/slop review that is not classifier-only.
- R3. The failure must be logged as routing/performance evidence so future generic/overconfident copy is treated as a system failure, not a one-off complaint.
- R4. The active suite must remain within the four-document rebuilt surface and must not revive stale pre-rebuild artifacts.

## Actors
- A1. Farrice as publisher and offer owner.
- A2. `/publishable-copy-gate`, `/copywriting-agent`, `/five-input-content-gate`, `/excellence-gate`, and Autopilot routing.

## Key Flows
- F1. User rejects inflated final copy -> mission logs failure -> active copy is rebuilt -> guards enforce calibration -> final rendered document can be used without pulling old drafts forward.
- F2. Future current-intent copy gate claims publishable status -> guard checks calibration and score discipline -> ceremonial pass fails before finalization.
