# Start Here

## Fast Use

Run `/productized-ai-service-os` when you have a service idea, source, or client context that needs to become a buyable AI-assisted service.

Best first prompt:

```text
/productized-ai-service-os "Turn [service idea] into a no-call productized service with intake, first artifact, delivery workflow, quality gate, proof sprint, and client-facing offer."
```

## Best First Application

Start with AI Slop Cleanup or an AI Workflow Integration Sprint. Both fit the source pattern because they can be:

- diagnosed from supplied assets
- delivered with a fast first artifact
- improved through AI-assisted production
- differentiated by human taste, strategy, and quality control
- packaged for internal use and for client work

For AI Slop Cleanup, use:

- `04-deliverables/ai-slop-cleanup-productized-service-os-brief.md`
- `04-deliverables/ai-slop-cleanup-offer-proof-sprint.md`

Default pricing is $99 for the first 3 founding beta spots, $249 for the standard cleanup, and $1,000 for the implementation sprint.

## Quality Bar

The system is good enough when a buyer can understand:

- what they buy
- what they submit
- what they receive first
- when they receive it
- how revisions work
- what is not included
- why this is better than DIY AI or a traditional agency
