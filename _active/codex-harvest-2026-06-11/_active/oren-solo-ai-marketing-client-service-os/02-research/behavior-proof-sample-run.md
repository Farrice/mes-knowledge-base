# Behavior Proof Sample Run

## Fixture Used

Source: `02-research/cold-start-fixture.md`

Scenario: a B2B operations consultant sells a 2-week workflow cleanup sprint and wants 3 qualified calls in 30 days.

## Baseline Plan Risk

A generic plan would say:

- ask for referrals,
- improve the website,
- post on LinkedIn,
- build case studies,
- start email follow-up.

That is direction, not an operating system.

## Template Output

### Fit Verdict

Good fit for the Oren solo AI marketing client/service OS.

Reason: the offer is specific, the buyer is clear, past proof exists, referral paths are warm, and the current bottleneck is not awareness volume. The bottleneck is unconverted proof plus no referral/follow-up system.

### Referral Fix

| Element | Output |
|---|---|
| Ask timing | After sending a short outcome recap to each happy past client. |
| Recipient list | 10 past clients or warm advocates with direct memory of the result. |
| Ask surface | Personal email or LinkedIn DM, not a newsletter. |
| Thank-you | Public thanks, small gift, or complimentary 30-minute workflow review. |
| Owner | Founder/operator. |

Ask draft:

```text
Quick note because the workflow cleanup we did together is still one of the clearest examples of the kind of work I want more of. If you know another founder-led service business buried in handoffs, client notes, or repeated admin, I would be grateful for an intro. Best fit is a founder with a real team, real clients, and one messy process costing them time each week.
```

### Message Board

| Message | Evidence | Buyer question answered | Surface to deploy | Test metric |
|---|---|---|---|---|
| Your team is not slow; the work disappears in handoffs. | Client notes mention missed Slack reminders and repeated status questions. | Why does this still feel chaotic with good people? | Landing page, LinkedIn, call opener | Replies and calls booked |
| Capture once, route once, reuse forever. | Prior cleanup reduced repeated client-status rewriting. | What actually changes after the sprint? | PDF one-pager, proposal insert | Proposal acceptance |
| The first win is a visible operating map, not an automation stack. | Client had scattered notes before system map. | What do we get first? | Sales page, intro email | Clicks/replies |
| This is for service businesses with real client work, not AI hobby projects. | Buyer has active delivery constraints. | Is this relevant to my business? | LinkedIn, page hero | Qualified inquiries |
| If the founder still remembers every exception, the system is not real yet. | Founder memory is the current bottleneck. | Why now? | Email follow-up, post | Booked calls |

### AI Copy-Machine Brief

AI may draft referral emails, landing page sections, case snippets, follow-up emails, LinkedIn posts, and FAQ answers.

Required context:

- buyer: founder-led service business with messy handoffs,
- offer: 2-week workflow cleanup sprint,
- proof: testimonials, rough case study, before/after notes,
- voice: direct, practical, specific, no hype,
- banned claims: guaranteed revenue, fully automated, effortless scale,
- review gate: every output must cite real proof or be marked as a hypothesis.

### 25-Hour Weekly Calendar

| Lane | Hours | Tradeoff |
|---|---:|---|
| Referral/proof | 5 | Highest leverage because warm relationships already exist. |
| Message/copy | 4 | Build proof-backed messages before content volume. |
| Funnel/follow-up | 5 | Fix page/PDF/email paths so demand can convert. |
| Sales collateral | 4 | One-pager and objection answers replace repeated explanation. |
| Organic validation | 3 | LinkedIn tests messages, not daily content volume. |
| Creator/vendor/paid | 0 | Deferred until referral/follow-up path works. |
| Logistics | 4 | Enough for replies, tracking, asset cleanup, and scheduling. |

### First 7-Day Sprint

| Day | Focus | Ship by end of day |
|---|---|---|
| 1 | Proof inventory | List of proof snippets, testimonials, and strongest outcome story. |
| 2 | Referral gate | Past-client list plus referral ask draft. |
| 3 | Message board | 5 proof-backed messages tied to buyer questions. |
| 4 | AI copy machine | Context pack and review checklist. |
| 5 | Follow-up surface | 2-email follow-up sequence and one proposal insert. |
| 6 | Organic validation | 2 LinkedIn posts testing the strongest messages. |
| 7 | Handoff | Client-facing operating template plus next sprint recommendation. |

### Client-Facing Handoff

Use `04-deliverables/client-facing-operating-template.md` with:

- fit verdict,
- referral system,
- message board,
- weekly rhythm,
- first 7-day sprint,
- next implementation path.

### Proof/Upsell Path

Natural next paid path: Implementation Sprint focused on referral packet, proof-backed landing page/PDF section, and follow-up email system.

## Behavior Delta

The template changed the output from "do more marketing" into a sequence of assets and operating decisions:

- exact referral ask,
- proof-backed message board,
- AI copy context with review gate,
- 25-hour calendar with paid/creator work deferred,
- first 7-day sprint,
- client-facing handoff,
- implementation upsell path.
