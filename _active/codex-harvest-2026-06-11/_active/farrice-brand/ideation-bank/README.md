# Farrice Ideation & Voice Bank

This folder is the source of truth for Farrice's raw thoughts, worldview notes, personal preferences, voice fingerprints, and workflow-ready content angles.

Use it when Farrice says things like:

- "store this"
- "capture this"
- "add this to the bank"
- "remember this for content"
- "this is how I think about..."
- or when he drops a raw thought, journal-style reflection, rant, story, hook, or personal belief.

## Operating Rule

This is private source material, not polished content. Preserve the raw thought, then add enough structure that future workflows can retrieve and transform it without flattening Farrice's voice.

## File Map

- `INDEX.md` - categorized map of every capture.
- `captures/` - dated raw entries with extracted themes, hooks, angles, and workflow routes.
- `inspiration-sources/` - outside creators, videos, games, apps, essays, and moments Farrice wants to farm for reusable taste and content mechanics.
- `workflow-runs/` - outputs from Antigravity workflows run against bank material.
- `voice-signals.md` - recurring language, beliefs, rhythms, emotional patterns, and "only Farrice would say this" markers.
- `content-seeds.md` - hooks, post angles, newsletter seeds, and workflow-ready ideas pulled from captures.

## Capture Protocol

For every new capture:

1. Create a dated Markdown file in `captures/` using `YYYY-MM-DD-short-slug.md`.
2. Preserve the raw thought in Farrice's language.
3. Categorize it into three layers:
   - Personal context: values, family, identity, growth edge.
   - Content potential: hooks, theses, audience problem, story angle.
   - Workflow routing: which Antigravity workflows should use it later.
4. Update `INDEX.md`, `voice-signals.md`, and `content-seeds.md` when the entry adds reusable material.

For every new inspiration source:

1. Create a dated Markdown file in `inspiration-sources/`.
2. Capture the source link, remembered moments, feeling, mechanic, Farrice translation, content hooks, and workflow routes.
3. Run the best-fit workflow if the system already has one.
4. Save outputs to `workflow-runs/`.
5. Move the strongest deployable ideas into `content-seeds.md`.

## Content Workflow Loading

Before creating content in Farrice's voice, load:

1. `FARRICE.md`
2. `_active/farrice-brand/ideation-bank/INDEX.md`
3. The most relevant capture files from `_active/farrice-brand/ideation-bank/captures/`
4. `voice-signals.md` when voice fidelity matters
5. `content-seeds.md` when selecting hooks or angles

## Default Workflow Routes

- `/daily-flywheel` - process a personal reflection into philosophy, framework, and content.
- `/voice-first-content` - turn raw voice input into LinkedIn-ready content.
- `/content-sprint` - create a publication-ready post from a topic, rant, or story.
- `/story-code-content-engine` - convert persuasion stories into content and offer messaging.
- `/find-context` - retrieve old captures by keyword, theme, or date.
