# Sam Parr Copy Quality Checklist

Use this checklist after applying the Sam Parr copywriting mechanics layer.

## Required Checks

| Check | Pass Standard |
|---|---|
| Desired action | The copy has one clear behavior it wants from the reader. |
| AIDA movement | The draft moves through attention, interest, desire, and action where appropriate. |
| Headline gravity | The opener creates a real reason to continue. |
| Curiosity gap | The copy creates and resolves tension honestly. |
| Interest over length | Any added length increases story, proof, desire, or clarity. |
| Proof object | At least one claim is supported by a quote, artifact, metric, before/after, comparison, or concrete example. |
| Visual translation | Abstract facts become concrete enough to picture. |
| Objection handling | The biggest likely doubt is addressed without sounding defensive. |
| Rhythm | Sentences vary enough to create motion. |
| Simple language | The core idea is understandable without expert decoding. |
| Story role | Story serves desire, proof, or belief movement. |
| Humor fit | Any humor fits the brand and does not weaken trust. |
| Voice fit | The copy still sounds like Farrice, the client, or the specified brand. |
| Behavior delta | The output explains how the rewritten section changes reader pull, belief, desire, objection pressure, rhythm, or action. |
| Before/after proof | The pass includes the original weak section and the rewritten section. |
| Downstream gate | Public or revenue copy is sent to `/publishable-copy-gate`. |

## Scoring

| Score | Meaning |
|---:|---|
| 1-4 | Sam mechanics were named but not integrated. |
| 5-6 | Some lines improved, but the reader path is still weak. |
| 7 | Useful draft pass; needs final taste/copy gate. |
| 8 | Strong enough to send into publishable-copy review. |
| 9+ | Only with market evidence, user-approved benchmark comparison, or live performance signal. |

## Fail Conditions

Revise before delivery if:

- the headline is clever but not clear,
- the story delays the offer without building desire,
- the proof is invented or too weak for the claim,
- the curiosity gap feels like a trick,
- the rhythm is just short-line theater,
- the output names Sam mechanics but does not show changed copy,
- the behavior delta is missing,
- or the copy sounds like Sam Parr cosplay instead of the intended voice.
