# Sam Parr Copywriting Use-Now Playbook

## Use This When

- The hook is accurate but does not pull.
- The ad explains the product before desire exists.
- The copy has claims but no proof object.
- The script is too long only because it is not interesting enough.
- The draft reads smoothly but has no tension.
- A writer needs a practice loop to get better at the format.

## Fast Pass: Sam Parr Copy Upgrade

Input:

- draft or goal,
- audience,
- desired action,
- proof assets,
- platform,
- offer or product,
- current concern.

Steps:

1. Write the desired action in one sentence.
2. Mark the draft by AIDA stage.
3. Replace the opener with a headline that creates a curiosity gap or proof promise.
4. Add one story or concrete image before the product pitch.
5. Convert one abstract fact into visible proof.
6. Add one objection-handling detail without using a defensive tone.
7. Tighten rhythm with sentence-length variation.
8. Run the copy quality checklist.

Output:

- revised hook/headline,
- revised body path,
- proof insertion,
- objection handling move,
- rhythm note,
- next gate.

## Ad Rewrite Pass

Best for paid social, landing sections, product ads, and offer cards.

1. Find the proof object first: quote, before/after, metric, screenshot, comparison, test, or customer phrase.
2. Write the headline from the proof, not the product category.
3. Build the desire story before introducing the product.
4. Translate any abstract number into a concrete image.
5. Handle the biggest objection through a short anecdote or detail.
6. End with one clear action.

## Script Hook Pass

Best for short-form video, YouTube intros, reels, and founder scripts.

1. Open with an unresolved situation.
2. Add a curiosity gap every 6-10 seconds only if each one pays off.
3. Use plain sentences.
4. Keep the story moving toward one action or realization.
5. Cut any line that repeats a point without increasing tension.

## Copywork Practice Loop

Use this when the writer needs better instincts, not just a better draft.

1. Pick one format: ad, headline, email, script, landing page, or LinkedIn post.
2. Collect 10 examples that already perform the job.
3. Manually copy 3 examples exactly.
4. Mark the mechanics: headline, proof, open loop, desire, objection, rhythm, action.
5. Write a rule list from what the examples do.
6. Rewrite the current asset using only those rules.
7. Keep a short texture note: what felt different when copied by hand.
