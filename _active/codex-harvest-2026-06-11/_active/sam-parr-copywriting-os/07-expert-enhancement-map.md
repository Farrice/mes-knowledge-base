# Sam Parr Copywriting OS Expert Enhancement Map

## Purpose

This map prevents expert soup. Sam Parr Copywriting OS is not another broad copywriting owner. It enhances specific weak links inside existing routes.

## Composition Ledger

| Slot | Asset | Accepted Contribution | Evidence Of Change | Skipped Or Bounded |
|---|---|---|---|---|
| Spine | `/source-to-skill-system` | Turns the video into a connected OS and command surface. | OS docs, skill workflows, command bridge, validation. | Does not create a duplicate mega-skill. |
| Gate | `/extraction-governor-agent` | Preserves source grounding and duplicate-system avoidance. | Transcript-only limits and existing route fit remain explicit. | No unsupported visual claims. |
| Differentiator | Sam Parr source | Adds headline, proof, curiosity, rhythm, story, objection, humor, and copywork mechanics. | Mechanics ledger and proof lab. | Does not own final voice. |
| Craft | `/high-taste-writing-os` | Keeps copy composed and non-sloppy. | Sam pass feeds craft pass when needed. | Does not let direct response flatten taste. |
| Risk Gate | `/publishable-copy-gate` | Scores public/revenue copy after the Sam pass. | Copy Gate Result remains final publishability proof. | Sam evidence is not treated as final proof. |

## Agent Enhancements

| Agent Or Workflow | Enhancement | Trigger | Boundary |
|---|---|---|---|
| `agents/copywriting-agent/AGENT.md` | Adds direct-response mechanics for weak headline, proof, curiosity, rhythm, and objections. | Public, revenue, ad, landing page, VSL, outreach, or offer copy with a weak opening or weak proof. | Copywriting Agent still owns final conversion copy. |
| `agents/sam-parr/AGENT.md` | Adds a bounded copywriting lens beside taste acquisition. | Explicit Sam copywriting, headline, ad, proof, or copywork task. | Does not mutate global `sam-parr-taste-acquisition`. |
| `.agent/workflows/copywriting-agent.md` | Routes to Sam before final copy gate when direct-response mechanics are the weak link. | Weak opener, proof gap, no curiosity, flat rhythm, early product pitch. | Sam is a scalpel pass, not the full copy path. |
| `.agent/workflows/publishable-copy-gate.md` | Requires Sam evidence only if Sam mechanics were used. | Final public/revenue scoring. | Publishable gate remains the final judge. |
| `.agent/workflows/high-taste-writing-os.md` | Uses Sam for reader pull and rhythm before composition polish. | Strong idea, weak continuation. | High-taste system owns final shape and taste. |
| `.agent/workflows/farrice-content-os.md` | Uses Sam in Hook Room and conversion content. | Hook lacks proof, curiosity, rhythm, or buyer recognition. | Farrice voice and strategy remain primary. |

## Enhanced Use Cases

| Use Case | Route |
|---|---|
| Improve a weak ad | `/sam-parr-copywriting-mechanics` -> `/publishable-copy-gate` |
| Improve a founder LinkedIn post | `/farrice-content-os` with Sam Hook Room pass |
| Rescue a generic offer page | `/copywriting-agent` -> Sam proof/rhythm pass -> `/publishable-copy-gate` |
| Train writing instincts | Sam Copywork Training System |
| Audit an opener | Headline Gravity Lab |

## Do Not Do

- Do not load Sam for every writing task.
- Do not use Sam as a personality costume.
- Do not let Sam replace proof, offer clarity, or publishability gates.
- Do not create additional Sam expert clones.
