# First Output Package Template

Use this when `/farrice-content-os sprint --count 20 --include-brandjacks` runs.

## Package Contract

| Asset | Required |
|---|---|
| 20 content cards | Yes |
| Bucket mix | 7 Growth, 7 Authority, 4 Conversion, 2 Personal |
| Brandjack/namejack/newsjack cards | At least 3 Growth cards when `--include-brandjacks` is active |
| Hook Lab | At least 10 hooks per serious post, top 3 ranked |
| Research ledger | Citation or unavailable-state note for every factual claim |
| Voice evidence | Farrice context loaded and referenced |
| Writers' room pass | Required for public drafts |
| Taste Evidence Ledger | Required before `taste_pass` |
| Visual briefs | Required before `visual_ready` |
| Engagement plan | Required before `weekly_ready` |
