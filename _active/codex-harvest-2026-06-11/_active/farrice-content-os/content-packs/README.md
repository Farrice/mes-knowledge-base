# Content Packs

Generated sprint, weekly, and remix packages live here.

Expected package types:

- `sprint-[date]/` for 20-post sprints.
- `week-[date]/` for weekly batches.
- `remix-[source]/` for cross-platform adaptations.

Each package should include content cards, Hook Lab output, research anchors, voice evidence, visual briefs, CTAs, engagement plan, and quality gate results.
