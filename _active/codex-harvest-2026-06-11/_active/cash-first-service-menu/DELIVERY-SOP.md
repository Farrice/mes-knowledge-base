# Delivery SOP - Cash-First Services

## Universal Delivery Boundary

Keep every first project small enough to complete within 48 hours and 1-4 hours/day.

If the buyer asks for a bigger build, sell the small diagnostic or first workflow first. Do not accept a broad custom implementation before trust, scope, and proof exist.

## Intake

Ask only for what the first version needs:

- desired outcome
- current process
- example input
- example output
- tools involved
- what breaks today
- what must be true for the first version to count as useful

Do not request sensitive account access unless the buyer has paid, the scope requires it, and a safer alternative is unavailable.

## Delivery Flow

### AI Workflow Integration Sprint

1. Map current process.
2. Identify the smallest repeated task.
3. Build before/after workflow map.
4. Draft prompt pack.
5. Draft SOP.
6. Run acceptance checklist.
7. Send handoff and optional walkthrough.

### Lead List + Outreach Starter Pack

1. Define buyer fit.
2. Define disqualifiers.
3. Build source map.
4. Manually qualify prospects.
5. Write first-message angles by segment.
6. Add follow-up prompts and objections.
7. Deliver tracker-ready table.

### The Vibe Tax Brief

1. Clarify offer and buyer.
2. Identify the decision the brief must protect.
3. Map false signals, alternatives, and substitutes.
4. Gather buyer language.
5. Map hidden objections, proof gaps, and pain.
6. Create offer-angle shortlist and sales openers.
7. Recommend keep, revise, stop, or test actions.
8. Deliver brief plus next action.

## Handoff Template

```text
- [fix 3]

1. [step]
2. [step]
3. [step]

What I would watch:
- [risk]

If you want the next layer installed:
- [small upsell option]
```

## Proof Capture

After delivery, ask:

```text
Was this useful enough to keep using? If yes, what specific part saved time, made the decision clearer, or made the next action easier?
```

Track:

- before state
- after state
- buyer quote
- implementation request
- paid upsell
- delivery hours
