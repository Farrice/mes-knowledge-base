# Magic Window Disneyland Locals Concept

## Project Home

This project is a lightweight concept-validation sprint for a third-party Anaheim theme-park crowd forecasting app aimed at locals and passholders.

## Surfaces

- `04-deliverables/magic-window-demo/index.html` - clickable local demo
- `05-assets/magic-window-concept.png` - image-generated concept direction
- `00-start-here/magic-window-concept-readout.md` - source-backed readout and monetization verdict

## Boundary

This is an unofficial product concept. It avoids Disney logos, characters, and official brand assets, and uses only generic theme-park visual cues.
