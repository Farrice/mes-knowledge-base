# /publishable-copy-gate

Mandatory copy and social quality gate for public, revenue-critical, client-facing, LinkedIn, outreach, offer, checkout, and marketplace copy.

Codex execution lives at `.agent/workflows/publishable-copy-gate.md`.

Use this before treating public copy as publishable. It must run `/copywriting-agent --deep`, `/excellence-gate --domain copy`, and platform-specific social gates. LinkedIn defaults to Lara Acosta, Josh Sanders, Kallaway, and Erica Mallet.
