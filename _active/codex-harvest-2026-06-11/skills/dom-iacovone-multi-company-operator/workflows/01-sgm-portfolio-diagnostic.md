# Workflow 01: SGM Portfolio Diagnostic

Use this when a founder has too many brands, offers, launches, or priorities.

## Inputs

- Business or portfolio description.
- Current revenue/channel mix if available.
- Active initiatives.
- Team owners.
- Current weekly metrics.

## Steps

1. Name the current stage: idea, validation, growth, retail expansion, portfolio, or exit-prep.
2. List all active initiatives and collapse them into four annual blocks.
3. Assign one owner and one weekly truth metric to each block.
4. Identify the finance signal that should be reviewed first.
5. Define continue, correct, or kill thresholds.
6. Produce the weekly meeting map.

## Output

- Four SGM blocks.
- Owner map.
- Weekly truth dashboard.
- Bottleneck verdict.
- First operating move.
- Stop condition.
