# Intent-First Creative Strategy

> **Expert**: Vince Nijhof | **Tier**: Foundation
> **Produces**: Creative strategy, concept pipeline, and testing plan

## Inputs Required

1. Product and offer
2. Current winning and losing ads
3. Customer-language bank or source material
4. Funnel destinations
5. Team capacity and production formats

## Skill Acquisition

Load:

- `genius.md`
- `references/data-bank-sources.md`
- `references/creative-pod-model.md`

## Execution

1. **Audit current volume**: Separate true concept diversity from repeated surface variations.
2. **Map awareness stages**: Top, middle, bottom, retargeting, retention.
3. **Define emotions**: Convert “angles” into buyer emotions and situations.
4. **Attach source evidence**: Each concept must trace back to data-bank items or prior winners.
5. **Assign funnel role**: What stage does the concept feed and where does it send traffic?
6. **Specify production path**: UGC, VSL, static, founder, authority, demo, comparison.
7. **Set testing plan**: Start with fewer stronger concepts, then increase output once winner quality is stable.

## Content Type Adaptations

| Format | Adaptation |
|--------|------------|
| Static | One emotion, one proof, one clean visual |
| 30-second video | Fast recognition, single mechanism, clear CTA |
| 3-5 minute VSL | Story arc, repeated resonance, proof sequence |
| Founder ad | Trust, mission, problem origin |
| Authority ad | Real authority makes claims the brand should not make directly |

## Quality Gate

- No concept without emotion.
- No concept without a funnel role.
- No “make more ads” recommendation unless input quality is already strong.
