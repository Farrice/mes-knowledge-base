# Action Weight Test

## Pre-Flight Gate

Use this when a scene, example, story, case study, or draft has things happening but still feels weak.

## Skill Acquisition

Load:

- `skills/nicolas-cole-edan-writing-mechanics/genius.md`
- `skills/nicolas-cole-edan-writing-mechanics/references/quality-rubric.md`

## Execution

1. List every action in the passage.
2. For each action, ask what it changes:
   - Plot/argument direction.
   - Stakes.
   - Reader understanding.
   - Character/client/protagonist intention.
   - Weakness, strength, or contradiction.
   - Proof of claim.
3. Mark each action:
   - `Weighted`: meaningful consequence.
   - `Setup`: will matter later.
   - `Decorative`: motion without payoff.
4. Cut, compress, or repurpose decorative actions.
5. Add context or description where an action should matter but lacks weight.
6. Upgrade one subtle action so it carries more meaning.

## Content Type Adaptations

| Type | Strong Action Means |
|---|---|
| Fiction | Choice, reveal, reversal, escalation |
| Memoir | Behavior that proves a change in self-understanding |
| Newsletter | Example/action that proves the advice |
| Sales story | Prospect/client behavior that proves pain or result |
| Case study | Observable before/after movement |
| Script/video | Visual beat that advances the promise |

## Output Requirements

Return:

1. Action inventory.
2. Weight classification.
3. Cut/compress list.
4. Context needed for weak actions.
5. Revised action sequence.
6. One stronger version of the key action.

## Quality Gate

Do not confuse "a lot happens" with momentum. A strong action must alter the reader's state of understanding.
