# Video Script System

## Pre-Flight Gate

Use this for Reels, TikToks, YouTube Shorts, webinar openings, long-form YouTube, VSL sections, founder videos, or educational scripts.

## Skill Acquisition

Load `../genius.md`, `../references/genius-patterns.md`, and `../references/implementation.md`. Stack with video-specific skills when production direction is needed.

## Execution

1. **Define the viewer action**: Watch, understand, believe, comment, click, book, buy, or share.
2. **Create the first-frame expectation**: Decide what the viewer should believe in the first 3 seconds.
3. **Design the sensory open**: Use a prop, visual metaphor, gesture, sound cue, pattern break, or demonstration.
4. **Write the spoken hook**: Make it easy to say, not just read.
5. **Build retention beats**: Alternate surprise, clarity, example, and payoff.
6. **Insert the sticky line**: Repeat one memory phrase at the right moment.
7. **Close with action**: CTA must connect to the sticky idea.

## Content Type Adaptations

| Format | Adaptation |
|---|---|
| Short-form | 3-second visual, 30-90 second arc, one repeatable line |
| YouTube | Curiosity open, proof/example blocks, recurring phrase |
| Webinar | Expectation frame, credibility anchor, promise of payoff |
| VSL | Problem scene, mechanism metaphor, proof cue, CTA |
| Founder video | Calm confidence, honest admission, tribal language |

## Output Requirements

Produce:
- **Video Concept**
- **Opening Visual**
- **Script**
- **On-Screen Text**
- **Shot / B-roll Notes**
- **Retention Beats**
- **CTA**

## Quality Gate

The opening must be visible, sayable, and specific. If the hook only works as written text, rewrite it for speech.
