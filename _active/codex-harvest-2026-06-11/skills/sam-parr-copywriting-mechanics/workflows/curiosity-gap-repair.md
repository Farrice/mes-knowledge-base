# Curiosity Gap Repair

## Use When

The reader has no reason to continue, or the existing open loop feels like clickbait.

## Inputs

- Current hook or section.
- Reader belief or doubt.
- Desired action.
- Proof available.
- Payoff the copy can honestly provide.

## Steps

1. Identify the current gap, if any.
2. Decide whether the gap is useful, vague, manipulative, or unsupported.
3. Rewrite the gap around a specific reader question.
4. Add a payoff line within the next few lines.
5. Check whether the reader is more curious and more trusting.

## Output

```markdown
## Curiosity Gap Repair
- **Original gap:**
- **Problem:**
- **Reader question:**
- **Rewritten gap:**
- **Payoff line:**
- **Behavior delta:**
- **Trust risk:**
```

## Quality Gate

Fail if the copy withholds obvious information or creates curiosity the piece cannot satisfy.
