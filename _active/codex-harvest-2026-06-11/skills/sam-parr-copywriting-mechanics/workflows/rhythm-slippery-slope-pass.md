# Rhythm And Slippery-Slope Pass

## Use When

The copy is accurate but flat, clotted, or easy to abandon.

## Inputs

- Draft section.
- Desired reader state after the section.
- Platform.
- Voice boundary.

## Steps

1. Mark the job of each line.
2. Remove lines that repeat without escalating.
3. Vary sentence length for momentum.
4. Make each line either answer, sharpen, or raise the previous line.
5. Read the section aloud and rewrite any line that stalls.
6. Keep natural voice; avoid fake dramatic spacing.

## Output

```markdown
## Rhythm And Slippery-Slope Pass
- **Original section:**
- **Stall points:**
- **Lines cut or moved:**
- **Rewritten section:**
- **Behavior delta:**
- **Voice risk:**
```

## Quality Gate

Fail if the pass only adds line breaks without improving continuation.
