# Copywork Rule Extraction

## Use When

The writer needs repeatable instincts for a format, not another framework list.

## Inputs

- Target format.
- One strong exemplar.
- Current draft or intended asset.
- Desired action.

## Steps

1. Manually copy or closely reconstruct the exemplar.
2. Mark opener, gap, proof, story, rhythm, objection, and action.
3. Extract five rules.
4. Rewrite the current asset using only those rules.
5. Write one texture note: what became visible through copying.

## Output

```markdown
## Copywork Rule Extraction
- **Format:**
- **Exemplar:**
- **Reader action:**
- **Five rules:**
- **Applied rewrite:**
- **Texture note:**
- **Next rep:**
```

## Quality Gate

Fail if the output says "inspired by" without extracting rules and applying them.
