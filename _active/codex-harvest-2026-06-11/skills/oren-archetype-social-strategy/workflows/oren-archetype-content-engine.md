# Oren Archetype Content Engine

## Pre-Flight Gate

Load `../genius.md`. If no archetype has been selected, run `oren-archetype-map` first. Do not produce generic content ideas; every idea must reinforce the selected archetype.

## Input Required

- Selected primary and secondary archetype
- Brand, offer, audience, and current channels
- Available creators, experts, designers, locations, products, proof
- Publishing capacity and approval constraints
- Target business outcome: reach, trust, leads, purchases, hiring, partnerships, or retention

## Execution

1. **Translate Archetype To Pillars**
   - Build 3-5 pillars where each pillar is topic plus format.
   - Assign funnel role: awareness, consideration, conversion, or retention.
   - Assign proof source: expert, product, customer, data, location, community, or culture.

2. **Build The Format Menu**
   - Oracle: history, category comparison, why-it-is-this-way, prediction.
   - Performer: recurring skit, cast moment, workplace scene, product-in-use story.
   - World Builder: short film, fictional series, trend essay, visual-cultural curation.
   - Catalyst: transformation proof, process breakdown, challenge, community highlight.
   - Helper: tutorial, buying guide, relatable anecdote, interview, practical comparison.

3. **Create The First 30 Days**
   - Produce 20-30 concepts.
   - Include format, hook, owner, funnel role, CTA, asset need, and effort score.
   - Keep the first two weeks low-friction enough to ship immediately.

4. **Add Measurement Rules**
   - Define what each pillar is supposed to prove.
   - Set a review cadence and one-change-at-a-time improvement rule.
   - Mark what gets killed, improved, or scaled.

5. **Connect To Commercial Surface**
   - Name which ideas support ads, landing pages, email/SMS, product education, or sales stories.
   - Add bottom-funnel asks where appropriate instead of leaving all content as awareness.

## Content Type Adaptations

| Content Type | Adaptation |
|---|---|
| Reels/TikTok | Use hooks that match the archetype and make the proof visible in the first 3 seconds |
| Carousel | Use for comparison, frameworks, buying guides, recap, or community curation |
| YouTube/Long Form | Use for Oracle depth, World Builder essays, and Catalyst transformation stories |
| Stories | Use for CTA repetition, proof, live updates, community participation, and offers |
| Email/SMS | Reuse best archetype claims and proof, then ask for action clearly |

## Output Requirements

Produce:

- **Archetype Content Thesis**
- **3-5 Pillars**
- **Format Menu**
- **30-Day Roadmap Table**
- **Asset/Owner List**
- **CTA Map**
- **Measurement Rules**
- **First Week Production Brief**

## Quality Gate

Every concept must pass the sentence: "This strengthens the brand's role as [archetype] by showing [specific proof]." Delete anything that fails.
