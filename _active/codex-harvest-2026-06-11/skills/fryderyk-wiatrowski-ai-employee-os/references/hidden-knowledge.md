# Hidden Knowledge

## Company Agents Are Permission Systems

The meaningful difference between a personal agent and a company agent is not the prompt. It is shared context, shared tools, and the risk of cross-boundary leakage.

## Connector Count Can Be A Trap

"Thousands of integrations" sounds powerful, but wrong ownership or personal/team ambiguity can make the agent worse. The real asset is a scoped integration map.

## Event Semantics Beat More Context

Adding more conversation history will not fix a system that does not understand edits, deletes, thread drift, reactions, or channel boundaries.

## Trust Is A Rollout Constraint

Broad activation is not just a growth decision. It is a security and user-comfort decision. An AI employee should earn workspace-wide behavior through visible proof.

## Model Benchmarks Miss Coworker Fit

A model can win tool-calling or codegen tests and still feel wrong as a teammate. Employee-grade systems need interaction canaries.

## Friendliness Is Infrastructure

"Make it friendly" is not decoration. Friendliness, restraint, and status clarity make long-running agent work feel acceptable.
