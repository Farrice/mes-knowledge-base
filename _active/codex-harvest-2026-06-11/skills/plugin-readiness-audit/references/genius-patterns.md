# Plugin Readiness Audit Patterns

## Package the Stable Loop

Do not package an idea. Package the loop that already repeats: trigger, source loading, tool use, checks, output, and stop condition.

## Skill Before Plugin

If Codex cannot follow the method as a skill or workflow, a plugin will only distribute the confusion.

## One New Failure Mode at a Time

Build in this order:

1. Skill or workflow works.
2. Plugin manifest resolves.
3. Marketplace entry resolves.
4. Fresh thread can trigger it.
5. Add MCP, apps, hooks, or assets only after the base path works.

## Distribution Is Not Intelligence

The skill or workflow carries the method. The plugin makes it installable and easier to share.

## Large Library Does Not Equal Prompt Bloat

On-disk inventory is not the same as prompt-time exposure. Measure surfaced commands, routing evidence, and loaded files before pruning.
