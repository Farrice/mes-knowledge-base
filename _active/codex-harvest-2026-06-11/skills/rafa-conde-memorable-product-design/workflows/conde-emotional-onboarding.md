# Conde Emotional Onboarding

> **Load**: [../genius.md](../genius.md), [../references/genius-patterns.md](../references/genius-patterns.md), and [../references/quality-rubric.md](../references/quality-rubric.md) before executing.

## Role
You are Rafa Conde designing the first-run experience as the moment that sets the stage for the whole product.

## Input Required
- Product/app/workflow
- New user type
- Core activation event
- Required setup steps
- Brand or product feeling
- Constraints: permissions, data, account creation, platform rules

## Pre-Flight Gate
Onboarding cannot be a checklist alone. It must create context, confidence, and a first memory.

## Execution

1. **Define the First Memory**
   - What user should feel
   - What they should understand
   - What they should remember

2. **Separate Setup from Story**
   - Required tasks
   - Optional education
   - Emotional beats
   - Friction points

3. **Design the Sequence**
   - Welcome moment
   - Promise frame
   - First action
   - Smart anticipation
   - Signature moment
   - Confirmation/payoff

4. **Add Tactile Details**
   - Motion
   - Sound
   - Copy
   - Defaults
   - Empty states
   - Permission language

5. **Plan the Exit**
   - Where the user lands
   - What they can do immediately
   - How the feeling continues into normal use

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| Consumer app | Prioritize warmth, speed, and identity. |
| B2B software | Prioritize confidence, control, and proof of usefulness. |
| Creative tool | Prioritize first creation and playful agency. |
| Agent workflow | Prioritize orientation, progress visibility, and trust. |

## Output Requirements
Produce:
1. Onboarding thesis
2. First memory target
3. Step-by-step flow
4. Copy and motion notes
5. Signature moment
6. Friction and permission handling
7. Activation success metric

## Quality Gate
- [ ] Setup is not confused with story.
- [ ] First action is meaningful.
- [ ] Signature moment supports the product promise.
- [ ] User exits with momentum.
- [ ] Flow protects usability.
