# Offer Education Sequence

## Pre-Flight Gate

Use this workflow when the user needs a sequence, launch arc, nurture path, call flow, or content series that prepares buyers for an offer.

If the buyer's objections are unknown, run `/buyer-belief-ladder` first.

## Skill Acquisition

Load:

## Execution

1. Define the audience, offer, medium, time horizon, and desired action.
2. Name the buyer's starting awareness level:
   - unaware
   - problem-aware
   - solution-aware
   - category-aware
   - offer-aware
3. Build the sequence around the eight education beats.
4. Assign each beat to one message, call section, page section, or content piece.
5. For each beat, define:
   - teaching point
   - buyer question answered
   - proof or example
   - CTA or next micro-step
6. Add follow-up branches for informed yes, informed no, and still-confused.
7. Remove any message that only repeats urgency without adding education.

## Content Type Adaptations

| Type | Sequence Shape |
|---|---|
| Product launch emails | Problem beats first, category education second, offer fit last |
| Sales call | Problem side, category side, buyer-self-sell close |
| DM nurture | One question or teaching point per touch |
| Content series | Public market education with repeated category proof |
| Webinar | Full education arc before offer invitation |
| Proposal follow-up | Recap education gaps and next decision point |

## Output Requirements

Return:

1. Sequence goal and buyer starting point.
2. Message-by-message education plan.
3. Proof asset list.
4. CTA ladder.
5. Follow-up branches.
6. Risks or missing inputs.

## Quality Gate

Pass only if every message teaches something new. If the sequence depends on repetition, pressure, or hype instead of cumulative understanding, revise.
