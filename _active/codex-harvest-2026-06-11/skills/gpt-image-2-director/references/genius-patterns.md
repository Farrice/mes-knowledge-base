# GPT Image 2.0 Director - Genius Patterns

## 1. Layout Precision Over Vibes
**Execute**: For anything with panels, UI, labels, typography, grids, diagrams, or hierarchy, use structured JSON with named regions, positions, counts, and labels.
**Deploy When**: Landing pages, infographics, editorial layouts, character sheets, posters with sections, social mockups.
**Success Metric**: The prompt describes where every major visible element goes.

## 2. Text Is a First-Class Asset
**Execute**: Preserve user-provided text exactly, including original language and punctuation. Put rendered text in quoted strings and specify typography where it matters.
**Deploy When**: Posters, UI mockups, document layouts, social graphics, anything with headlines or labels.
**Success Metric**: The output prompt can be pasted directly without text reconstruction.

## 3. Format Match Routing
**Execute**: Use JSON for layout, dense prose for one scene or subject, and meta-prompting for theme-only concept posters where the model should derive the composition.
**Deploy When**: Every GPT Image 2.0 prompt request.
**Success Metric**: The chosen format matches the visual task instead of defaulting to generic prose.

## 4. Cinematic Specificity
**Execute**: For single-frame prompts, specify subject, action, wardrobe, setting, props, lighting, palette, camera/film language, and mood in one dense paragraph.
**Deploy When**: Portraits, cinematic scenes, editorial photography, concept art.
**Success Metric**: The prompt contains concrete objects and camera language rather than abstract atmosphere.

## 5. Avoid Face-Realism Failure
**Execute**: For face-heavy prompts, avoid "photorealistic." Use film photograph, editorial portrait, 35mm, direct flash, grain, or cinematic language.
**Deploy When**: Human portraits, lifestyle scenes, character moments.
**Success Metric**: The prompt steers away from plastic skin while preserving realism intent.
