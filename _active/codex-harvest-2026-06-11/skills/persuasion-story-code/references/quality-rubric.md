# Quality Rubric

Use this before shipping any Story Code output.

| Test | Pass Standard |
|---|---|
| Story job | The story has one clear persuasion job. |
| Truth | No invented results, testimonials, credentials, client names, claims, or proof. |
| Believability | No inconsistency, vagueness, exaggeration, or stiff language. |
| Specificity | The story includes concrete people, moments, actions, objects, or outcomes. |
| Compression | The story is as short as possible while still complete. |
| Conversational tone | It can be read aloud without sounding like copy. |
| Placement | It sits where the prospect would naturally have the question it answers. |
| Asset fit | The version fits the channel: post, email, sales page, pitch, video, DM, or script. |
| Ethical claims | Results and regulated claims are qualified or flagged for legal review. |
| Next step | The output includes a clear CTA, prompt, bridge, or use instruction when needed. |

## Rejection Triggers

- Sounds like a hero's journey unless the user specifically asked for one.
- Depends on a fabricated story or proof point.
- Makes the prospect feel lectured.
- Uses the same adjective pile instead of one exact image.
- Turns into a lesson about storytelling rather than producing the asset.
- Hides the product behind too much cleverness.
