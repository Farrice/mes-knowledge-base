# Stacking Guide

## Social Content

- Use **Story Code** to select and write the persuasive story.
- Use `kallaway-addictive-storytelling` for loop density, stakes, and retention.
- Use `shaan-puri-storytelling` for emotional resonance and audience-friendly framing.
- Use `story-compass` for tension, rescue, series, and platform adaptation.
- Use `/social-narrative` when the post needs narrative physics for LinkedIn, X, or Instagram.

## Conversion Copy

- Use **Story Code** to build story blocks for credibility, desire, doubt, explanation, and proof.
- Use `joanna-wiebe-persuasion-mastery` for persuasion hierarchy, authority craft, triggers, and skepticism calibration.
- Use `donald-miller-storybrand` for clear customer-facing message structure.
- Use `jeremy-miner-identity-persuasion` for self-persuasion, objections, and sales conversation flow.
- Use `rory-sutherland-marketing` for perception change and value reframing.

## Video

- Use **Story Code** to choose the story job and draft the human script spine.
- Use `pj-accetturo-ai-video` for viral concept, production direction, and platform packaging.
- Use `tao-prompts-ai-video` for cinematic prompt and storyboard engineering.
- Use `remotion-video-creation` when the final asset needs programmatic production.
- Use `/create-video` after Story Code has produced the script and story board notes.
