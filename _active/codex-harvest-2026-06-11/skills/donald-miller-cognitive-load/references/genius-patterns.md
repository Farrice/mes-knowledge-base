# Donald Miller Cognitive Load Genius Patterns

## Source Package

Primary expansion source: `extractions/donald-miller/storybrand-message-clarity-system/`

## Patterns

| Pattern | Operating Rule | Apply It By |
|---|---|---|
| Weight scale | Words can be scored by how much thinking they require. | Assign a load score before rewriting copy. |
| One-hole ownership | A campaign should own one specific customer problem. | Reject multi-problem messages and comma-stuffed problem statements. |
| Bookend mirror | The End Result should resolve the exact pain named in the Problem. | Flip the problem into its positive future state. |
| Plain-language answer | The answer sound bite should be the simplest action or solution. | Avoid method names, feature bundles, and insider jargon. |
| Guide outside the hole | Empathy should validate the customer without making the brand the victim. | Write empathy from a capable guide position. |
| Identity change | The Change sound bite names who the customer becomes. | Make the shift personal and concrete. |
| Guitar-chord sound bites | Each sound bite must work alone and together. | Test standalone headline use and chained pitch use. |
| Decade repetition | Locked sound bites should repeat verbatim across channels. | Create a deployment matrix with exact copy, not variations. |
| Three-phase house | Curiosity, enlightenment, and commitment need distinct collateral. | Audit front steps, front porch, and front door before building campaigns. |
| Proof through load reduction | Zero-load rewrites should outperform clever or vague phrasing. | Preserve before/after scoring and recommend A/B tests when possible. |

## Quality Checks

- Problem sound bite names one felt pain.
- Every selected phrase is understandable without explanation.
- Problem and End Result mirror each other.
- Answer uses the simplest possible language.
- Deployment preserves exact sound bites.
