# Oren Content-Team Architecture — Genius Patterns

Load these patterns before running any `oren-content-team-architecture` workflow. They are the durable mechanics extracted from the Oren content-operations layer.

## Pattern Index

| # | Pattern | Practical Use |
|---|---|---|
| 1 | Pod Architecture Principle | Replace solo content-manager overload with strategist + creator division of labor |
| 2 | Marketing World Flywheel | Connect owned organic, owned paid, external brand world, conversion, and comms |
| 3 | Media Company Diagnostic | Gate transformation by POV, patience, editorial standards, process, and product-content integration |
| 4 | Signature Series Protocol | Pilot, test, iterate, lock, then scale repeatable formats |
| 5 | Pod Cadence System | Install weekly 1:1, creative review, analytics review, research, and recap rhythm |
| 6 | 10-Asset Weekly Standard | Set a velocity floor of 10 strong weekly concepts, not random post count |
| 7 | Tiered Brand Exemplar Matrix | Match team model to iPhone-tier, mid-tier, enterprise-tier, or agency/software-tier realities |
| 8 | External Creator Integration | Add paid micro-creators, influential customers, and collaborative partners without swamping the strategist |
| 9 | Founder-as-Character System | Treat founders as recurring characters in the brand world, not side-channel extras |
| 10 | Anchor Strategy Framework | Choose 1-2 defensible anchors from fame, influence, story, production elements, or events |
| 11 | Anti-Overproduction Mandate | Keep daily social production lean enough to publish quickly |
| 12 | Agency Integration Model | Evaluate partners by creator flywheel competence, not media-buying theater |
| 13 | Multi-Pod Scaling Architecture | Split pods only after one pod works; add shared editors, designers, producers, and leads at scale |

## Operating Rule
Every recommendation must tie back to pod ownership, publishing velocity, editorial standards, and how content moves through the flywheel. If the answer only names roles or channels, it is not yet an Oren-quality content-team architecture.
