# Satori Graphics Quality Rubric

| Dimension | Pass | Strong | Mastery |
|---|---|---|---|
| Message | Viewer can infer the topic | Viewer understands the point | Viewer understands the point instantly through visual language |
| Element Purpose | Most elements are relevant | Nearly every element has a role | Every element pays rent |
| Hierarchy | Focal point exists | Eye path is clear | Eye path is choreographed with rhythm |
| Emotion | General tone fits | Viewer after-feeling is deliberate | Emotion is predicted and engineered |
| Memory | One distinctive feature | Strong concept hook | Metaphor or unresolved idea sticks after viewing |
| Friction | Not chaotic | Tension supports emphasis | Friction and flow create energy without losing clarity |
| Simplicity | Not overloaded | Unnecessary details removed | Concept is reduced to its strongest visual language |
| Transferability | Works in one format | Works in common formats | Identity survives scale, platform, color modes, and layout rearrangement |
