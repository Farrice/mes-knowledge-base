# Satori Graphics — LIFT Layout Diagnostic

## Pre-Flight Gate
Load `../genius.md`. Diagnose the layout through LIFT.

## Input Required
- Design, screenshot, or layout description
- Intended primary message
- Required formats

## Workflow
1. **Leverage Point**: Identify what dominates first and whether anything competes.
2. **Internal Rhythm**: Trace the eye journey and pacing between zones.
3. **Friction and Flow**: Separate productive tension from clarity-destroying noise.
4. **Transferability**: Test whether hierarchy and identity survive scale, format, and background changes.
5. **Prescribe Fixes**: Give a prioritized revision plan.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Campaign key visual | Stress-test across campaign variants |
| Landing page | Test hero, proof, CTA, mobile rhythm |
| Poster | Test thumbnail survival |
| Brand identity | Test recurring elements and recognizability |

## Output Requirements
- LIFT scorecard
- Failure points
- Revision priorities
- Transferability test notes
- Final readiness score

## Quality Gate
The audit must distinguish good friction from bad friction.
