# Satori Graphics — Predictive Empathy Poster

## Pre-Flight Gate
Load `../genius.md`. Design for the emotion the viewer carries away.

## Input Required
- Campaign/topic
- Audience state before seeing it
- Desired after-feeling
- Message and CTA
- Format

## Workflow
1. **Map Emotional Before/After**: Name current viewer state and desired exit state.
2. **Set Tone Controls**: Calibrate headline force, color temperature, whitespace, imagery intensity, and trust cues.
3. **Build Visual Hierarchy**: Define what hits first, what reassures or provokes second, and where the CTA rests.
4. **Add One Empathy Cue**: Include a visual or textual cue that makes the viewer feel understood.
5. **Produce Direction**: Generate a complete poster concept and art direction spec.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Awareness poster | Emphasize recognition and reassurance |
| Event poster | Balance urgency with atmosphere |
| Cause campaign | Avoid shouting unless anger is the strategy |
| Product poster | Translate product benefit into emotional state |

## Output Requirements
- Emotional before/after map
- Poster concept
- Layout hierarchy
- Color/typography/imagery direction
- CTA treatment

## Quality Gate
The output fails if it only grabs attention and does not define the emotional residue.
