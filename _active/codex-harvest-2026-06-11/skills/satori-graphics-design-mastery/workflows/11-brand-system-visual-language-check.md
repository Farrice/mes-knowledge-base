# Satori Graphics — Brand System Visual Language Check

## Pre-Flight Gate
Load `../genius.md`. A design system must communicate consistently beyond one asset.

## Input Required
- Brand assets or DESIGN.md
- Sample applications
- Audience
- Desired recognition markers

## Workflow
1. **Identify Visual Language**: Extract recurring typography, color, layout, shape, imagery, and emotional cues.
2. **Test Logo Independence**: Ask whether the brand is recognizable without the logo.
3. **Check Transferability**: Test small, large, mobile, print, dark, and light contexts.
4. **Find Weak Links**: Identify elements that work only in perfect conditions.
5. **Prescribe System Rules**: Define rules that protect recognition across formats.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| DESIGN.md | Add missing psychology and transfer rules |
| Campaign system | Test motif repeatability |
| Social templates | Test thumbnail recognition |
| Brand refresh | Separate surface novelty from real system change |

## Output Requirements
- Visual language inventory
- Recognition test
- Transferability audit
- System-rule additions
- Risk list

## Quality Gate
The system fails if removing the logo removes all recognition.
