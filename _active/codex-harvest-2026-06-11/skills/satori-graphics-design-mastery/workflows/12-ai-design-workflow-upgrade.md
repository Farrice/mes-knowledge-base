# Satori Graphics — AI Design Workflow Upgrade

## Pre-Flight Gate
Load `../genius.md`. AI should create thinking space, not replace design thinking.

## Input Required
- Current workflow
- Repetitive tasks
- Tools available
- Output formats
- Quality bottlenecks

## Workflow
1. **Separate Thinking From Production**: Identify which steps require human judgment and which can be automated.
2. **Find Tool Gaps**: Map where AI can assist with references, variants, precision edits, layer iteration, or format export.
3. **Protect Concept Quality**: Require brief, message, emotion, and eye-path checks before generation.
4. **Create Iteration Loop**: Use AI for variants, then human refinement for meaning and control.
5. **Write Operating Workflow**: Produce a step-by-step AI-assisted process.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Poster workflow | AI for references/variants, human for concept |
| Logo workflow | AI for research and mockups, human for mark logic |
| Campaign workflow | AI for format expansion, human for system coherence |
| Client workflow | AI for repetitive production, human for presentation judgment |

## Output Requirements
- Current workflow diagnosis
- Human judgment checkpoints
- AI task map
- Revised step-by-step workflow
- Quality safeguards

## Quality Gate
The upgraded workflow fails if it makes weak thinking happen faster.
