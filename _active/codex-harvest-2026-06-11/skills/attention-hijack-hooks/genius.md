# Attention Hijack Hooks - Genius Context

## Core Genius

This system combines Diandra Escobar's attention-redirection philosophy with her 2026 hook-format study. The useful leap is that brandjacking, newsjacking, namejacking, trendjacking, and draft rehooking are all the same underlying operation:

1. Find the signal that already has attention.
2. Attach it to a real payload.
3. Open a gap between expectation and claim.
4. Package that gap inside the first platform-visible window.
5. Use human judgment to choose the hook that deserves amplification.

## Source-Backed Patterns

### Pattern 1: Dual Audience Hooking

Every hook serves two audiences: the human deciding whether to keep reading and the platform model deciding whether the post deserves distribution. A strong hook cannot only be emotional; it also needs semantic signal.

### Pattern 2: Attention Anchor First

Before generating hooks, identify the attention anchor: brand, person, news, trend, claim, number, belief, artifact, or body insight. If there is no anchor, the hook has to create all recognition from scratch.

### Pattern 3: Gap Before Format

Dense, Punchy plus Context, Single-Line Bomb, Stacked, and Hybrid are packaging options. The engine is the gap between what the reader expects and what the post will claim.

### Pattern 4: Pixel/Fold Reality

On LinkedIn, the practical first-screen budget is visual, not only character-based. Hooks need width, line-break, and first-50-word checks before they are trusted.

### Pattern 5: Context Creates Better Hooks

Do not ask for hooks from a thin topic label. Give the system the draft, source, offer, audience, and payload so it can identify hookable elements instead of inventing disconnected bait.

### Pattern 6: Judgment Over Automation

AI can generate stronger starting points, but the operator must choose, combine, cut, or rewrite based on audience, voice, and taste.

## Hidden Knowledge

- A brand or news item is not the idea. It is the doorway into the idea.
- A hook that can be used by any creator is usually not specific enough for one creator.
- Punchy plus Context is the default workhorse, but overuse turns it into wallpaper.
- Dense hooks work when context itself creates tension.
- Single-Line Bomb hooks should be rare because they spend all above-fold real estate on one sentence.
- Stacked hooks fail when the lines are not part of the same series.
- The safest universal workflow is body first, hook second, format third, platform check fourth.

## Quality Rubric

| Criterion | Score 4 | Score 7 | Score 10 |
|---|---|---|---|
| Signal Anchor | A recognizable source is named | The anchor has audience overlap and a clear reason to care | The anchor creates recognition, timeliness, and boomerang or debate potential |
| Payload Fit | The hook points to a general topic | The hook leads into a real argument or useful lesson | The hook makes the payload feel inevitable and worth reading now |
| Curiosity Gap | Mild intrigue | Clear expectation-versus-claim tension | Reader needs the next line because the gap hits a private belief |
| Format Choice | One format is used | Format matches the type of tension | Format, spacing, and rhythm make the hook feel native to the platform |
| Platform Fit | Roughly short enough | Survives first-screen constraints | Uses line breaks, width, first-50 signal, and mobile view deliberately |
| Judgment | Many options, no decision | Top choice with reason | Chosen hook plus rejected hooks teaches the operator how to improve future hooks |

## Anti-Patterns

1. Summary bait: naming a brand or event without a point of view.
2. Generic hook formulas: "Most people do X" without specific stakes.
3. Format cosplay: using line breaks or punchy spacing while the idea stays weak.
4. Disconnected bait: hook promises a fight the body cannot pay off.
5. AI option dump: many hooks with no scoring, no winner, and no taste call.
6. Platform denial: ignoring mobile fold, line breaks, first-50 signal, or channel norms.
