# Brandon Jacoby - Craft Meets Consequence Audit

## Pre-Flight Gate

Load `../genius.md`. Craft and consequence must be judged together.

## Input Required

- Work to audit
- Intended audience/user
- Intended business, product, or emotional result
- Current concerns

## Workflow

1. **Name the Consequence**: Define the work's real job.
2. **Score Craft**: Judge detail, clarity, emotional control, originality, and finish.
3. **Score Consequence**: Judge usefulness, conversion, adoption, user trust, product movement, or business value.
4. **Find Mismatches**: Identify polished parts with no consequence and useful parts with weak craft.
5. **Prescribe Harmonizing Moves**: Improve the places where craft and consequence can reinforce each other.
6. **Set Pass Bar**: Define what must be true before shipping.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Product | Focus on user behavior, trust, speed, and feeling |
| Brand | Focus on memorability, status, credibility, and distinction |
| Content | Focus on viewer action, emotional residue, and repeatable format |
| Skill/workflow | Focus on artifact quality, decision pressure, and execution clarity |

## Output Requirements

- Craft score
- Consequence score
- Mismatch table
- Top five revision moves
- Ship/no-ship verdict
- Post-revision test

## Quality Gate

Fails if craft is judged without consequence or consequence is used to excuse bland execution.
