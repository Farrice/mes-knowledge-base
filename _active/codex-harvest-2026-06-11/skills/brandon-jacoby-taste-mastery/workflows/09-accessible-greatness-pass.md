# Brandon Jacoby - Accessible Greatness Pass

## Pre-Flight Gate

Load `../genius.md`. Greatness is not the same as luxury. High craft should reduce friction where possible.

## Input Required

- Product, offer, content, workflow, or system
- Intended audience
- Current craft ambitions
- Constraints around cost, time, complexity, or adoption

## Workflow

1. **Define Greatness for This Audience**: Clarify what would make the work feel excellent to them.
2. **Remove Luxury Confusion**: Strip status-only details that do not improve use, trust, feeling, or desire.
3. **Simplify the Experience**: Identify the simplest path to the high-craft moment.
4. **Protect the Signature**: Keep the one or two details that make the work memorable.
5. **Increase Access**: Reduce price, time, cognitive effort, or tool friction where possible.
6. **Write the Revision Plan**: Produce specific changes and tradeoffs.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Software | Focus on speed, clarity, emotional polish, and default path |
| Service | Focus on delivery artifact, buyer confidence, and reduced complexity |
| Content | Focus on clear insight with a memorable angle |
| Internal workflow | Focus on fewer steps with higher output quality |

## Output Requirements

- Audience-specific greatness definition
- Status-only details to remove
- Simplification directives
- Signature details to protect
- Access improvements
- Tradeoff notes

## Quality Gate

Fails if it makes the work feel more premium by making it harder to use.
