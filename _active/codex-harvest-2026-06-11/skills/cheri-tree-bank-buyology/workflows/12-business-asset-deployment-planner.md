# Business Asset Deployment Planner

## Pre-Flight Gate

Load `../genius.md`, `../references/bank-code-field-guide.md`, and `../references/bank-deployment-map.md`. This workflow orchestrates the whole B.A.N.K. OS.

## Input Required

- Business, offer, audience, price, sales process
- Current assets and gaps
- Channels
- Timeline and campaign goal

## Execution

1. Diagnose the likely code distribution of the market.
2. Identify current asset gaps by code.
3. Build a campaign plan across content, lead magnet, funnel, email/DM, sales call, and CRM.
4. Create the first asset list in build order.
5. Define acceptance criteria and simple metrics.

## Output Requirements

- **Market Code Hypothesis**: likely B/A/N/K mix.
- **Asset Gap Audit**: missing code-specific pieces.
- **Deployment Plan**: ordered build plan.
- **Asset Specs**: each asset's code, purpose, input, and output.
- **Campaign Calendar**: practical launch sequence.
- **Metrics**: what to watch by code.
- **Next Commands**: which B.A.N.K. workflow to run next.

## Quality Gate

The plan must end with buildable assets, not strategy talk. Every recommended asset must have a code, purpose, and next action.
