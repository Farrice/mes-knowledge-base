# Email and DM Sequence Generator

## Pre-Flight Gate

Load `../genius.md` and `../references/bank-deployment-map.md`. Each sequence must change angle, proof, pacing, and CTA by code.

## Input Required

- Offer and audience
- Sequence type: cold, warm, nurture, launch, event, reactivation, post-call
- Known code or all-code segmentation
- Number of messages and channel

## Execution

1. Choose sequence arc and code-specific persuasion order.
2. Write subject lines or opening lines by code.
3. Produce each message with CTA.
4. Add segmentation logic and follow-up triggers.
5. Mark where to insert proof, testimonials, case studies, or documentation.

## Output Requirements

- **Sequence Strategy**: goal, segment, timing.
- **Messages**: finished email or DM copy.
- **Code Variants**: B/A/N/K if requested.
- **CTA Map**: what each code is asked to do.
- **Fallback Follow-Up**: if no response.
- **CRM Tags**: optional.

## Quality Gate

Do not produce vague nurture content. Every message must move the buyer toward a specific next step.
