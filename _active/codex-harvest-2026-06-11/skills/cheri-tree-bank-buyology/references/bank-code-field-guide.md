# B.A.N.K. Code Field Guide

## Blueprint

- **Motive**: safety and risk protection.
- **Values**: stability, structure, systems, planning, processes, predictability, responsibility, duty, rules, credentials, titles, tradition.
- **Clues**: professional dress, punctuality, formal tone, organization, budget awareness, conservative decisions, credentials, documented process.
- **Likes**: accountability, budgets, commitment, consistency, directions, due diligence, guarantees, lists, order, proven plans, references, track records.
- **Avoid**: chaos, delays, exaggeration, unclear instructions, surprises, missed deadlines, overspending, risk, rule breaking.
- **Buying triggers**: budget fit, written details, strong reputation, recommendations from known people, positive ratings.
- **Sales posture**: be organized, on time, precise, calm, budget-aware, and risk-reducing.

## Action

- **Motive**: winning and being the best.
- **Values**: freedom, flexibility, spontaneity, action, opportunity, excitement, attention, stimulation, competition, winning, fun, image.
- **Clues**: fast pace, status cues, designer labels, big energy, urgency, social buzz, VIP expectations, flashy or expensive taste.
- **Likes**: beauty, bottom line, celebrity endorsements, confidence, entertainment, fame, fortune, incentives, luxuries, prizes, recognition, speed, VIP treatment.
- **Avoid**: boredom, budgets, details, instructions, limits, paperwork, waiting, routine, over-planning.
- **Buying triggers**: celebrity endorsement, media/social buzz, automated recommendations, relevant publication reviews, gut feeling.
- **Sales posture**: be brief, exciting, high-status, fast, direct, and opportunity-led.

## Nurturing

- **Motive**: loving, being loved, and making a positive difference.
- **Values**: relationships, authenticity, personal growth, significance, teamwork, involvement, community, charity, ethics, harmony, morality, contribution.
- **Clues**: warmth, eye contact, encouragement, helpfulness, family or cause orientation, soft style, talkative friendliness, community language.
- **Likes**: faith, familiarity, family, flowers, friends, helping, inspiration, intimacy, love, nature, peace, referrals, support, touch when appropriate.
- **Avoid**: arguments, coldness, deceit, ego, greed, manipulation, rudeness, selling tactics, tension, unfairness.
- **Buying triggers**: contribution to a cause, best-quality goods or services, recommendations from known people, quality presentation, written details.
- **Sales posture**: be genuine, connected, ethical, warm, purpose-led, and relationship-first.

## Knowledge

- **Motive**: being right and avoiding a wrong decision.
- **Values**: learning, intelligence, logic, self-mastery, technology, research and development, science, universal truths, expertise, competence, accuracy, the big picture.
- **Clues**: reserved manner, technical reading, gadgets, analytical questions, desire for documentation, debates, data requests, expertise sharing.
- **Likes**: analysis, charts, documentation, experts, facts, formulas, innovation, logic, peer journals, proof, research, studies, technology, wit.
- **Avoid**: blanket statements, drama, excessive praise, incompetence, lack of documentation, speculation, shortcuts, unsubstantiated evidence.
- **Buying triggers**: budget fit, time for due diligence, complete information, strong written detail, best possible solution.
- **Sales posture**: be logical, documented, expert, accurate, patient, and prepared to defend the claim.

## Code Order

A person's full code is an ordered stack, not a single label. The first code opens the door. The second code often shapes proof. The third code may appear under stress or in complex decisions. The fourth code is often the blind spot. When confidence is low, create assets for the top two likely codes and test response.
