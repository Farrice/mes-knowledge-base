# Quality Rubric

| Criterion | Pass Standard |
|---|---|
| Value Mode | One primary mode is explicit |
| Reader Deliverable | The reader can name what they receive |
| List Strength | The outline lists the actual tips, steps, mistakes, reasons, or examples |
| Specificity | Broad terms are translated into literal moments or actions |
| Objectivity | At least one point can be observed, counted, or judged |
| Skim Strength | Title and subheads prove value in four seconds |
| Stack Discipline | Secondary modes support the primary mode |
| Draft Readiness | The piece can be drafted without discovering the argument from scratch |
