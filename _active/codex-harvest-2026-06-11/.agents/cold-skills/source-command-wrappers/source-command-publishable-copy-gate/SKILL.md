# source-command-publishable-copy-gate

Use this skill when the user invokes `/publishable-copy-gate`, asks for publishable copy, asks to improve LinkedIn/revenue/outreach/offer/marketplace copy, or complains that copy is strategically correct but flat.

## Workflow

1. Read `.agent/workflows/publishable-copy-gate.md`.
2. Read `.agent/workflows/copywriting-agent.md` and `agents/copywriting-agent/AGENT.md` when copy must be revised.
3. For LinkedIn, apply the required social gates named in the workflow: Lara Acosta, Josh Sanders, Kallaway, and Erica Mallet.
4. If the user rejected a prior draft as generic, flat, confusing, over-scored, or not deployable, start from that baseline and lower confidence before revising.
5. Return or save a real `Copy Gate Result` with scores, revisions applied, user-calibrated baseline, failure addressed, score discipline, and non-classifier prose/slop review.

Do not create `.docx`, HTML, Canva, Google Docs, or PDF exports unless explicitly requested.
