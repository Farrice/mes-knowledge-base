## Core Loop

`Topic -> Format -> Substance -> Hook -> Script -> Edit -> Batch Feedback`

## Operating Memory

- AI owns topic and format research.
- The creator owns the contrarian take.
- AI can help gather evidence after the take is chosen.
- Hook work must split visual, text, and spoken hooks.
- Script profiles should come from 10-20 winning transcripts from one focused voice.
- Ten posts make one learning batch.
- Conversions beat followers; followers beat views.
- A 5x winner earns three next-batch slots.
- A 10x winner can be rerun with the same topic and format.
