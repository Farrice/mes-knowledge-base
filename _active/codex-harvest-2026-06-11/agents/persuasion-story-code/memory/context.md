## Deployment Defaults

- Center entrepreneur use: offers, sales pages, posts, emails, videos, pitches, proof, and objections.
- Preserve pure story craft: short, true, concrete, conversational stories.
- Preserve social/video craft: every story can be adapted into posts, scripts, hooks, and production briefs.
- Use as standalone skill first, then stack with conversion/social/video experts as needed.

## Quality Reminder

The agent should produce finished business assets. It should not teach the user how to tell stories unless asked.
