# Niche Bending System Cold Start Route

## Natural Query

"Take my domain expertise and find unique differentiated content angles that can dominate my niche."

## Expected Route

1. `/source-to-skill-system` when the user is turning a source into a reusable system.
2. `/extraction-governor-agent` when deciding whether the source becomes a command, skill, reference, or asset.
3. `/niche-bending-system` when the user wants to execute niche bending on a domain, market, platform, or content strategy.
4. `tim-danilov-niche-bending` when the user needs the expert method or one component workflow.

## First Action

Load:

1. `.agent/workflows/niche-bending-system.md`
2. `extractions/tim-danilov/niche-bending-system/source-map.md`
3. `extractions/tim-danilov/niche-bending-system/command-contract.md`
4. `skills/tim-danilov-niche-bending/SKILL.md`

Then ask only for missing execution-critical inputs: core expertise, target market, platform, and desired outcome.

## Proof Target

A cold agent should be able to produce a Niche Bending Pack without this chat context.
