Pass type: chapter and scene-design pass from the video chapter map plus transcript descriptions of spaces, props, action, camera placement, and production roles. This is not a frame-by-frame raw video audit.

## Visual Heuristics Extracted

- Treat each place as a set with a cameraable action, not just a backdrop.
- Place prompts where guests already pass through.
- Use props to compress story: phone, cigar, ashtray, outfit, coffee, binoculars, DJ mixer.
- Add background actions that hold attention for another second or two.
- Use characters who already create energy instead of forcing scripted behavior.
- Build for fast repeated capture: record, stop, repeat, then hand off to the editor.
- Let prestige and tradition guide tone so the content does not fight the event.
