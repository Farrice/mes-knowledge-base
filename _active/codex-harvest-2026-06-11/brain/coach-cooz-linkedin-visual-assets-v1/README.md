# Coach Cooz LinkedIn Visual Assets V1

Purpose: give Cooz a simple set of LinkedIn-ready profile photo and banner options for the current profile launch.

This package uses the approved visual asset library as source material. These are production and marketing assets, not proof of a real client session or verified documentary event unless Cooz confirms the context and usage rights.

## File Map

- `profile-photos/` - three 800x800 profile photo options.
- `banners/` - three 1584x396 LinkedIn banner options.
- `previews/` - contact sheet for fast review.
- `source/` - copied source assets used for this pass.
- `SELECTION-GUIDE.md` - recommended default and tradeoffs.
- `LINKEDIN-BROWSER-COCKPIT.md` - safe human-in-loop browser workflow for LinkedIn review, commenting, and outreach drafting.

## Recommended Default

Use:

- Profile photo: `profile_a_serious_authority_800x800.png`
- Banner: `banner_a_kettlebell_symbolic_1584x396.png`

Why: this pair gives the clearest premium signal without making him look like a generic trainer, fake executive coach, or loud internet fitness personality.

## Guardrails

- Do not imply the Triage Audit image is a verified real session unless Cooz confirms it.
- Do not use any generated or edited likeness publicly until Cooz approves likeness comfort.
- Do not add performance claims, body transformation claims, or client proof to banners unless the claim has been validated.
- Keep LinkedIn actions human-approved: draft comments and DMs, then choose and send manually.
