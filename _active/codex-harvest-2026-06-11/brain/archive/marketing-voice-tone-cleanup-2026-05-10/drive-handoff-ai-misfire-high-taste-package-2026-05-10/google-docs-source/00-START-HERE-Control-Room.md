## Quality Stops

Stop and revise before publishing if any active asset:

- could be mistaken for a generic AI automation offer,
- asks for a call before proving the diagnostic lens,
- sounds like availability, desperation, or “quick cash,”
- names big companies as borrowed authority instead of public conversation context,
- fails to show the actual void: missing buyer language, proof, CTA timing, taste, or source-of-truth rules,
- claims 9/10 copy scores without live market response, buyer feedback, or explicit user-calibrated proof,
- treats `prose_classifier.py` as enough when the user has already rejected the work as generic.

## Copy Score Discipline

| Rule | Meaning |
|---|---|
| User baseline beats internal confidence | If the user says the copy feels 3-4/10, the next gate starts from that failure and must name what changed. |
| No ceremonial 9s | A 9+ requires live market/user proof, not expert-name routing or clean formatting. |
| Classifier pass is not enough | A static prose check can catch some generic structure, but the copy still needs manual buyer-language, tension, and scroll-stopping review. |
| Deployment proof decides | Replies, submitted artifacts, comments, and paid action are the real calibration signals. |
