# Quality Gate And Red Team

## Pre-Publish Gate

Every post, DM, marketplace listing, and proposal must pass these checks.

| Gate | Pass Standard |
|---|---|
| No begging | No mention of runway, urgent cash, bills, desperation, or needing help. |
| No generic audit | Does not say "business audit" as the main offer. |
| No commodity AI | Does not lead with automation, prompt packs, or AI transformation. |
| Buyer felt moment | Names "looks finished but still needs rescue" or equivalent. |
| Concrete CTA | Asks for one artifact, not a vague call. |
| Scope boundary | Does not promise implementation before diagnosis. |
| Proof posture | Uses controlled demo or real submitted artifact; no fake client proof. |
| Human judgment | Frames AI as support for judgment, not replacement. |

## Red-Team Questions

Before sending or publishing, ask:

1. Would a serious founder-led expert feel seen, or pitched?
2. Does this make Farrice look like a strategic operator, not a cheap prompt helper?
3. Is the next action obvious enough that someone knows exactly what to send?
4. Is there any false confidence before seeing the workflow?
5. Is the free value capped at three bullets?
6. Does the paid bridge feel earned by diagnosis, not pressure?
7. Would this still make sense as part of Creative Strategist + AI Operating Partner positioning in 90 days?

## Reply Handling

### If They Say "Interesting"

```text
The easiest way to test it is with the last AI output you had to rewrite manually.

If you send that, I can point out the first three places it was forced to guess.
```

### If They Ask "What Do You Need?"

```text
Just one artifact:

- prompt
- SOP
- workflow
- failed output
- content process
- proposal
- sales follow-up

And a short note on what AI was supposed to do and what a human had to correct.
```

### If They Ask Price Early

```text
The Founding Proof diagnostic is $300 for the first proof-building slots.

It covers one workflow or output, a written Misfire Map, a short Loom walkthrough, and the first agent-ready fix sketch.

If the issue is obviously just a tiny prompt tweak, I will say that before scoping anything deeper.
```

### If They Want Free Help

```text
I can give the first three observations for free if you send the artifact.

The full map, Loom, and agent-ready fix sketch are the paid diagnostic.
```

### If They Want Full Automation

```text
I would not build automation before diagnosing the misfire.

If the workflow is missing source of truth, rules, or examples, automation just makes unclear work move faster.

The diagnostic tells us what is actually worth building.
```

## 48-Hour Decision Rules

If LinkedIn gets engagement but no submissions:

- revise CTA to "send the last output you had to rewrite"
- publish the controlled teardown excerpt
- stop asking for `GUESS` if the keyword feels too abstract

If submissions happen but no payment happens:

- keep the free diagnosis to 3 bullets
- state the deliverable and price earlier
- show the Loom/demo before the bridge

If marketplaces produce no replies:

- apply to more active jobs
- narrow searches to AI workflow, SOP, output quality, prompt issue, content workflow
- shorten the proposal
- put the $300 diagnostic in the first five lines

If a buyer asks for implementation first:

- do not skip the diagnosis
- offer to credit the $300 toward implementation
- scope one workflow only

## Words To Avoid

- runway
- help me
- business audit
- 10x

- automate everything
