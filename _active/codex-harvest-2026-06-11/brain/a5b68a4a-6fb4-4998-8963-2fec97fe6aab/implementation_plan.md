## Proposed Skill Architecture

### Skill Name: `oren-content-team-architecture`

### Workflow Table (12 Workflows, 3 Tiers)

#### Tier 1 — Foundation Workflows (4)

| # | Slash Command | Workflow Name | Description |
|---|:-------------|:-------------|:------------|
| 1 | `/oren-media-org-diagnostic` | Media Org Readiness Diagnostic | Audit any brand's readiness to become a content-first organization. Scores across: point of view, editorial standards, product-content integration, existing talent, and production infrastructure. Outputs a transformation roadmap |
| 2 | `/oren-pod-architect` | Content Pod Architecture Builder | Design the pod structure for any org — from a 2-person minimum pod through multi-pod enterprise. Defines roles (Strategist, Creator, External), reporting lines, meeting cadence, and output standards |
| 3 | `/oren-content-flywheel` | Content Marketing Flywheel Engine | Map the complete owned organics → paid ads → brand world → conversion → communications flywheel for any brand. Identifies gaps in the circuit and prioritizes the first fix |
| 4 | `/oren-brand-media-blueprint` | Brand-as-Media-Company Blueprint | End-to-end transformation plan from traditional marketing to content-first media company. Includes phase gates, hiring sequences, and 90-day milestones |

#### Tier 2 — Practitioner Workflows (5)

| # | Slash Command | Workflow Name | Description |
|---|:-------------|:-------------|:------------|
| 5 | `/oren-signature-series` | Signature Series Architect | Design, pilot, test (4-6 episodes), and iterate on a brand's signature content series. Includes format selection, visual template design, cadence setting, and iteration protocol |
| 6 | `/oren-pod-cadence` | Pod Operating Rhythm Designer | Build the weekly operating rhythm — 1:1s, creative review, analytics review, research sessions, Friday recap. Calibrated to pod size and org maturity |
| 7 | `/oren-creator-network` | External Creator Network Builder | Design the external contributor layer — identification (Outer Signal / miniocial), briefing templates, retainer structures, content spark strategy. Scale from 3 external to 20+ |
| 8 | `/oren-founder-content` | Founder-as-Character System | Architect the founder's content identity as a brand character — separate from the core brand account. Personal brand + corporate brand + character-based storytelling integration |
| 9 | `/oren-anchor-strategy` | Content Anchor Strategy | Identify and deploy the 1-2 anchors (fame, influence, story, production elements, events) that make a brand's content uniquely defensible and unreplicable |

#### Tier 3 — Stacking Workflows (3)

| # | Slash Command | Workflow Name | Description |
|---|:-------------|:-------------|:------------|
| 10 | `/oren-content-team-audit` | Content Team 360° Audit | Full diagnostic on an existing content team — pod efficiency, output quality, cadence health, brand world coverage, creator network depth. Scores each dimension and prescribes specific fixes |
| 11 | `/oren-scale-media-machine` | Media Machine Scaling Protocol | Take a working 1-2 pod system and architect the expansion — shared resources (editors, designers, producers), channel leads, creative director hiring spec, and cross-pod coordination |
| 12 | `/oren-anti-production` | Anti-Overproduction Gate | Pre-production constraint check. Audit any production plan against Oren's "iPhone + Osmo + lights" standard. Kill bloated production before it drains budget. Speed-to-publish over production value |
