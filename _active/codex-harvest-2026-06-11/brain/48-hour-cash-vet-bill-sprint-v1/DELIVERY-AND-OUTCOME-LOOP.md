# Delivery And Outcome Loop

## Delivery Standard

Every paid audit must be:
- Specific enough to be useful without a call
- Honest about evidence limits
- Focused on visible trust, clarity, offer, content, and follow-up issues
- Delivered within 24 hours
- End with a small implementation option

## 60-Minute Audit Workflow

| Time | Action |
|---|---|
| 0-10 min | Review website/profile and write first impressions |
| 10-20 min | Score clarity, offer, proof, content, follow-up |
| 20-35 min | Identify 5 fixes |
| 35-45 min | Draft 3 content/outreach ideas |
| 45-55 min | Draft offer improvement |
| 55-60 min | Add next-step implementation option and send |

## Implementation Upsell

After delivery, recommend one next step only.

Good:

```text
The fastest fix is your homepage opening section. I can rewrite that plus the main CTA for $350 and deliver it tomorrow.
```

Weak:

```text
Let me know if you need anything else.
```
