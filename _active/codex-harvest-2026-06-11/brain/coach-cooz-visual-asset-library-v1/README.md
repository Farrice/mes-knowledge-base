# Coach Cooz Visual Asset Library V1

## Purpose

This library gives Coach Cooz and Farrice a clean production asset base for social media, marketing graphics, profile assets, video, thumbnails, carousels, and future image generation.

The files here are organized for practical use, not just storage.

## Folder Map

- `source-originals/`  
  All 20 provided images copied from Downloads with clean filenames. Originals in Downloads were not moved or changed.

- `approved-selects/`  
  Strongest brand-fit assets for near-term marketing use.

- `needs-review/`  
  Useful but restricted assets. Review before public use because of visual-fit, accessory, tattoo, realism, pointing, corporate, or second-person/client-impression risks.

- `platform-ready/`  
  Cropped outputs for LinkedIn, Instagram, YouTube, and carousel use.

- `generated-derivatives/`  
  Future Image Gen, edited, composited, or AI-derived outputs. Do not overwrite originals.

## Core Rule

Use these as production references and marketing assets.

Do not treat them as verified documentary proof, client proof, or real session evidence unless Cooz confirms likeness accuracy, usage rights, and context.

## Start Here

1. Read `VISUAL-USAGE-GUIDE.md`.
2. Use `ASSET-MANIFEST.md` to choose the right image.
3. Start with `approved-selects/` for public-facing assets.
4. Use `platform-ready/` when you need a fast crop.
5. Put all future generated or edited versions in `generated-derivatives/`.

## Safety

Before publishing major assets:

- Confirm Cooz is comfortable with the likeness.
- Do not imply an AI-generated second person is a real client.
- Do not use visible client-like scenes as proof without context.
- Do not use images with visible tattoo/accessory issues unless intentionally approved.
- Do not use corporate-suit imagery as the default brand signal.
- Do not let graphics drift into cheap gym, bro-fitness, fake luxury, or wellness design.
