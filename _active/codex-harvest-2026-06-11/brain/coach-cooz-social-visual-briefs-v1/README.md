# Coach Cooz Social Visual Briefs V1

## Purpose

This package is a handoff system for creating Coach Cooz social assets in stronger image/design-native AI tools.

It does not attempt to finish the visuals inside Codex. It gives Gemini Nano Banana 2, ChatGPT Image Gen 2, Claude Design, Canva, Figma, or another design AI the strategy, source references, prompts, layout rules, and QA gates needed to produce better assets.

## Use This Package In Order

1. Read `MASTER-VISUAL-DIRECTION-BRIEF.md`.
2. Choose the platform asset:
   - LinkedIn profile photo: `LINKEDIN-PROFILE-PHOTO-BRIEF.md`
   - LinkedIn banner: `LINKEDIN-BANNER-DESIGN.md`
   - Instagram suite: `INSTAGRAM-SOCIAL-SUITE-DESIGN.md`
   - YouTube thumbnails: `YOUTUBE-THUMBNAIL-BRIEF.md`
3. Copy the matching prompt from `AI-TOOL-PROMPTS.md`.
4. Upload the recommended source image to the design AI.
5. Generate 2-4 options.
6. Review with `DESIGN-QA-CHECKLIST.md`.

## Default Creative Direction

Coach Cooz should look like a serious private coach, not a fitness influencer.

The visual world should signal:

- strength
- diagnosis
- calm authority
- premium local presence
- maturity after 40
- private support, not public performance

The core visual idea:

> The body has to carry the life.

## Output Rules

- Keep copy minimal on graphics.
- Make text readable on mobile.
- Do not use fake client proof.
- Do not imply a generated scene is a real session.
- Do not use before/after transformation language.
- Do not make Cooz look like a different person.
- Get Cooz's approval before public use of edited/generated likeness assets.

## Recommended First Build

Build these first:

1. LinkedIn profile photo: Serious Authority
2. LinkedIn banner: Body Carries The Calendar
3. Instagram carousel cover: Monday Is Not A Plan
4. YouTube thumbnail: 4 PM Fog

This gives him a coherent public surface without trying to build the entire brand system at once.
