# Phase 4 — LAUNCH PLAN: Capsule 1 "THE RAVE BETWEEN RAVES"

**Doctrine**: smallest honest test first — "Find one shirt people actually want, not build a whole brand yet."

## The Test

| Decision | Call | Why |
|---|---|---|
| Channel | Shopify (existing store) — new capsule collection page | Store + fulfillment already live; capsule = identity claim, not product dump |
| SKUs | 3: Sunday/Monday · Still Synced 03:17 · Resting Heart Rate (1 PDP, 5 variants) | The scored slate; ≤3 per the smallest-honest-test rule |
| Window | 10-day featured drop (then capsule stays live) | Scarcity of ATTENTION, not artificial stock limits — store is permanent |
| Price | $38 per tee (capsule tier) | Above Defined ($35), below hoodies; premium-restrained positioning; room for "any 2 for $70" pair nudge (shipping arbitrage: 2nd item ships ~$1.99 — margin improves with pair) |
| Collection page | "THE RAVE BETWEEN RAVES — for the ones the set follows home" | The collection title IS a billboard statement (store-stack rule: collections = identity claims, not product types) |

## Sequence

1. **Founder approval gate (Farrice)** — approve per item: exact phrase/joke text · art direction (post-generation) · price + profit preview · PDP copy (04-listings.md) · IP self-check confirmation · launch posts. Nothing publishes before this gate.
2. **Mockups** — generate from 05-prompt-pack.md (cost-gated approval first). ONE mockup style per concept at launch — presentation/product separation: if CPC disappoints, swap the MOCKUP first, never the concept (pre-committed).
3. **Store build** — capsule collection page + 3 PDPs (copy from 04-listings.md); Frontline Raver tee added to the capsule page as catalog incumbent (its new lead line from 03-scorecard.md). Mobile pass: add-to-cart button position checked on a real phone before any traffic.
4. **Email announce** — existing list, 2-email sequence: (1) drop announce, subject "Your coworkers have no idea." (2) day-7 social-proof/last-feature nudge, subject "What does your heart actually rest at?" The list is pre-paid traffic — it goes first, before any ad dollar.
5. **Organic post pair** — IG captions from 04-listings.md; "tag the one who..." is the mechanic on every post (the involuntary forward is the ad).
6. **Paid test** — Meta, 48h-read protocol: 3 ad sets (one per concept), identical audience, $15/day each, 4-day initial window (two 48h reads). Creative = mockup + lead line, nothing else. Kill/scale rules pre-committed in 07-diagnostics.md.

## What this test answers

- Which WORLD wins: office double-life (#2) vs scene body-memory (#1) vs genre-as-biology (#5) — the winner directs Capsule 1 wave 2 (#4 Turn Signals, #3 Wristband, #12 Sunrise, revised #6/#7/#8).
- Whether the between-raves raver buys at $38 (price-band read for the premium redesign direction).
- First-ever bestseller data for the store (all 29 existing products currently treated equally — this run creates priority order).
