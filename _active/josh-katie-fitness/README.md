## Conventions
- **Programs are versioned, never overwritten** — v3 lands next to v2 in `programs/`; the client README always names which one is CURRENT.
- **Check-ins**: one file per week, named `YYYY-MM-DD.md`, from the template in each `check-ins/` folder.
- **Shared equipment gate (both clients)**: garage gym only — rack, barbell, DBs, bench, pull-up bar, bands, loop bands, stability ball, BOSU, mat, ab wheel. **No landmine, trap bar, specialty bars, cables, machines, or kettlebells — ever.**
- **Program shape (both)**: 5-day Mon–Fri, 3 full-body foundationals + 2 triggers. MAPS Anabolic hybrid. Trainerize-ready markdown (`[SS-]`, `[CIRCUIT]`, `PAUSED:`, `AUTOREG:`).
- Evidence-honest: claims carry VERIFIED / LIKELY / UNCONFIRMED labels; anything clinical routes to physician/prescriber.

## Tracker signal logic (shared)
- Weight ↓ + strength index holding = muscle defended / recomp working → **change nothing**.
- Weight ↓ + strength index falling 2 weeks = **muscle-loss flag** → raise protein/calories, cut a trigger, check sleep — BEFORE touching training.
- Katie: scale flat but thigh ↑ / waist ↓ = recomp working; scale is the lagging metric.
