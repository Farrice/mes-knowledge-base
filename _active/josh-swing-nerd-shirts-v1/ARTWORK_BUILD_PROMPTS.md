# Artwork Build Prompts

Use these prompts in a design tool, or hand them to a designer. The output should be vector or high-resolution transparent PNG artwork suitable for Bonfire upload.

## Global Art Direction

**Do:** minimal typography, adult casual apparel, restrained color, clean spacing, readable from 6-8 feet.

**Do not:** use dancer silhouettes, swing-era clip art, jukeboxes, musical notes, cartoon computers, fake GitHub UI, code editor screenshots, copyrighted logos, or copied meme layouts.

**Export target:** transparent PNG or SVG, 300 DPI equivalent, square canvas, design centered, one-color or two-color artwork.

**Placement default:** center chest, medium size. For No Drops In Prod, left chest label is acceptable.

## Candidate 1: Commit On Eight

**Primary prompt:**

```text
Create a minimalist typography-only t-shirt graphic for the phrase "COMMIT ON 8". The style should feel like an independent software tool crossed with a dance studio note, not novelty merch. Use a bold condensed sans-serif for the main phrase, all caps, tight but readable spacing. Under the phrase, add a small rhythm annotation: "[1 2 3&4 5 6 7&8]". Keep the layout centered, clean, and confident. One-color artwork only. No icons, no dancers, no computer screens, no logos.
```

**Recommended art treatment:**

- Main line: `COMMIT ON 8`
- Detail line: `[1 2 3&4 5 6 7&8]`
- Ink: warm off-white on black, charcoal on ivory, charcoal on heather gray
- Type feel: condensed, utilitarian, slightly editorial

**Bonfire upload check:**

- The bracket count must stay legible in the product preview.
- If the count line blurs, remove it or enlarge it.

## Candidate 2: No Drops In Prod

**Primary prompt:**

```text
Create a restrained t-shirt label graphic for the phrase "NO DROPS IN PROD". The style should feel like a small utilitarian studio rule or engineering operations label, not a construction warning sign. Use compact uppercase typography, subtle border or rule lines, and a tiny secondary line reading "test in rehearsal". The design should work as a small left-chest print or a centered front print. One-color artwork only. No hazard symbols, no dancers, no computers, no logos.
```

**Recommended art treatment:**

- Main line: `NO DROPS IN PROD`
- Detail line: `test in rehearsal`
- Ink: faded cream on pepper/washed black, cream on forest, soft white on navy
- Type feel: utilitarian label, but not aggressive

**Bonfire upload check:**

- If using left chest placement, confirm the mockup does not make it look too small.
- Avoid yellow/red safety colors. They make it feel like a costume.

## Candidate 3: Push / Pull Request

**Primary prompt:**

```text
Create a minimalist t-shirt graphic using the phrase "PUSH / PULL REQUEST". Make it feel like an abstract partner-connection protocol, not a software logo. Stack the words vertically with strong spacing: PUSH, slash divider, PULL REQUEST. Add one thin abstract connection line or bracket around the text. Keep it cool, clean, and wearable. One-color preferred, optional second muted accent. No GitHub references, no code editor UI, no arrows that look like a tech company logo, no dancer silhouette.
```

**Recommended art treatment:**

- Stacked text:

```text
PUSH
/
PULL REQUEST
```

- Optional tiny line: `connection is a protocol`
- Ink: black on bone, off-white on black, navy on muted blue
- Type feel: protocol label, precise but human

**Bonfire upload check:**

- Do not let the optional line crowd the main joke.
- If the abstract line makes it feel too technical, remove it.

## Mockup Review Checklist

For each uploaded design:

- Screenshot the mockup at normal size.
- Step back or zoom out to phone-thumbnail size.
- Confirm the shirt still reads as something someone would wear casually.
- Confirm the joke is visible but not screaming.
- Confirm no detail becomes fuzzy.
- Confirm the shirt color and ink contrast feel intentional.

## One-Design Fallback

If the three-shirt setup feels too much in Bonfire, launch only:

**Commit On Eight**

Why: It has the best balance of wearability, originality, and cross-audience comprehension.
