# Josh Swing-Nerd Shirt Launch V1

## First Drop Brief

**Working project name:** Social Dance Debug Club

**Brand premise:** Regular, wearable shirts for people who live in the tiny overlap between swing dance culture and nerd culture. The shirt should look like a cool tee from across the room and become an inside joke when the right person reads it.

**Audience:** Swing dancers, Lindy Hop people, West Coast Swing people, Balboa-adjacent dancers, software/engineering/game/tabletop/data nerds, and partners who like clever low-key apparel more than loud novelty shirts.

**Launch goal:** Validate whether Josh's creative direction has real audience pull before building a full store or agent team.

**V1 format:** One Bonfire limited batch campaign with 3 shirt candidates. The campaign tests cultural fit, joke clarity, wearability, and purchase intent.

**Target feeling:** "Oh, that's painfully specific. I need that."

**One-day memory line:** "It's dance merch that does not look like dance merch."

## Creative Rules

- Make the shirts wearable first, funny second.
- Avoid clip-art dancers, retro jukebox kitsch, loud swing typography, and big novelty slogans.
- Use original wording. No direct movie, TV, superhero, song lyric, event logo, school, or team references.
- The joke must survive without a paragraph of explanation.
- The design should work as 1-color or 2-color print.
- Josh gets final creative authority. AI can generate territories, but Josh decides what feels true.

## Research Snapshot

Bonfire is a strong V1 fit because it supports public campaigns, batch windows, direct buyer checkout, printing/shipping, and post-batch payouts. Batch campaigns are better for margin than print-on-demand because orders are grouped, and Bonfire states that batches can run 2-21 days. Bonfire also reviews content for trademark, copyright, hate, fraud, and other policy issues, so the launch should stay fully original.

Audience language to use carefully:

- Dance mechanics: lead/follow, connection, swingout, anchor, triple step, 8-count, social floor, phrase, break, drop, slot, compression, extension.
- Nerd mechanics: commit, merge, protocol, debug, prod, patch notes, pull request, latency, cache, runtime, signal, state machine.
- Shared emotional territory: connection, timing, recovery, graceful failure, private competence, "you had to be there" humor.

## Boring Default To Avoid

"Funny swing dance shirts" usually becomes one of four forgettable things:

1. A literal dancing silhouette.
2. A pun in a generic script font.
3. A loud novelty tee only wearable at a themed event.
4. A reference so broad that no insider feels seen.

This drop should feel like an indie software release got trapped at a late-night swing social.

## Final Candidate 1: Commit On Eight

**Campaign title:** Commit On Eight Tee

**Shirt text:** COMMIT ON 8

**Joke premise:** A developer-style command for dancers who know that half the battle is committing to the count instead of floating in uncertainty.

**Audience read:** Works for Lindy/WCS/swing people who know 8-count phrasing. Works for software people who hear "commit" as a code action. Still wearable if someone only gets one layer.

**Visual direction:** Minimal command-line meets dance studio. Large centered type, slightly condensed sans, with a small bracketed count mark underneath: `[1 2 3&4 5 6 7&8]`. No computer icon, no dancer silhouette.

**Recommended shirt colors:** Black with warm off-white print; ivory with dark ink; heather gray with charcoal ink.

**Print complexity:** 1-color. Very Bonfire-friendly.

**Bonfire listing description:**

For dancers who stop overthinking and commit on eight.

This one sits in the overlap between the social floor and the terminal window: timing, trust, and just enough nerve to send it. Clean enough for daily wear, specific enough that the right person will clock it immediately.

**Short description:** A clean swing-nerd tee about timing, trust, and committing to the count.

**Search tags:** swing dance, lindy hop, west coast swing, dancer gift, nerd shirt, developer shirt, social dance, dance humor

**Founder note for Josh:** Best first shirt if he wants the least risky, most wearable candidate.

## Final Candidate 2: No Drops In Prod

**Campaign title:** No Drops In Prod Tee

**Shirt text:** NO DROPS IN PROD

**Joke premise:** Dance drops and aerials are for practice/performance, not chaotic social-floor "production." Software people also know prod is where you do not test risky moves.

**Audience read:** Dancers get the floor-safety joke. Engineers get the production-environment joke. The attitude is funny but responsible.

**Visual direction:** Small utilitarian warning label on left chest or centered front. Use a restrained industrial label style, not a fake hazard sign. Optional tiny back-neck line: `test in rehearsal`.

**Recommended shirt colors:** Pepper/washed black with faded cream print; forest with cream print; navy with soft white print.

**Print complexity:** 1-color. Avoid red/yellow caution-sign visuals because that will make it feel like a gag shirt.

**Bonfire listing description:**

For the dancers who know the social floor is not your staging branch.

No panic aerials. No surprise drops. No "it worked once in rehearsal" energy. Just good connection, good timing, and a healthy respect for production.

**Short description:** A deadpan swing dance x software joke about saving the risky stuff for rehearsal.

**Search tags:** swing dance, social dance, dancer gift, software engineer, developer humor, dance safety, nerd shirt

**Founder note for Josh:** Best candidate if the community has enough software/product people to get "prod."

## Final Candidate 3: Push / Pull Request

**Campaign title:** Push / Pull Request Tee

**Shirt text:** PUSH / PULL REQUEST

**Joke premise:** Lead/follow connection uses push-pull energy; developers hear pull request. It feels like a tiny protocol for partner dance.

**Audience read:** Very strong overlap joke for dancers with software familiarity. Slightly more cryptic to non-technical dancers, but the visual can make it cool enough anyway.

**Visual direction:** Stacked typography:

```text
PUSH
/
PULL REQUEST
```

Add a thin connection line or bracket system around the words. Keep it abstract, like a protocol diagram, not a GitHub clone and not a flowchart.

**Recommended shirt colors:** Bone with black print; black with off-white print; muted blue with dark navy print.

**Print complexity:** 1-color or 2-color. Keep the second color optional.

**Bonfire listing description:**

Connection is a protocol.

Push, pull, wait, respond, adjust. This is for the dancers who can debug a bad connection without making it weird and the nerds who know every good merge starts with a clean request.

**Short description:** A low-key partner dance x code review tee about connection.

**Search tags:** swing dance, partner dance, lindy hop, west coast swing, developer shirt, code humor, nerd gift, dance humor

**Founder note for Josh:** Best candidate if he wants the most explicitly nerd-coded first drop.

## Recommended First Drop Structure

**Campaign name:** Social Dance Debug Club: First Drop

**Campaign format:** 3 shirts in one first-drop campaign if Bonfire allows the product/campaign layout Josh wants. If setup becomes clunky, publish only the strongest one first: Commit On Eight.

**Batch length:** 10 days.

**Smart Launch:** Turn off for a true limited test. Leave on only if Josh wants evergreen sales.

**Product range:** Start with unisex tee only. Add hoodie or long sleeve later if the first tee sells.

**Pricing rule:** Use Bonfire's live profit preview. Start around a normal premium tee price, then adjust until Josh has a meaningful profit per sale without making the shirt feel expensive. Do not finalize price from this document alone because Bonfire base costs and product options can vary.

**Success signal:** At least one shirt gets purchases or repeated unsolicited "I would wear that" comments from actual dancers, not just friends being nice.

## Josh Review Script

Ask Josh these five questions before publishing:

1. Which shirt would you personally wear when you are not at a dance event?
2. Which one would your swing friends understand fastest?
3. Which one feels most like your humor?
4. Which one is least likely to get old after two weeks?
5. Which one would make someone ask, "Where did you get that?"

If the same shirt wins 3 or more answers, make it the lead image and first campaign focus.
