# Josh Lindy Hop Apparel Visual Canvas

Open `index.html` to review the image-first concept package.

## What This Is

- A neutral visual canvas for Josh's Lindy Hop apparel direction.
- Eight AI-generated lookbook boards with blank garment zones for his actual graphics.
- Three creative lanes: Tailored Social Floor, Practice Utility, and Music-Rooted Craft.
- A research ledger connecting Lindy Hop roots and current apparel references to concrete design rules.

## What This Is Not

- Not a final name, logo, mark, monogram, or brand guide.
- Not a legal consult artifact.
- Not a finished apparel tech pack.
- Not the earlier SVG-style visual package.

## Best Review Path

1. Start with `index.html`.
2. Open `RESEARCH_LEDGER.md` if Josh asks why the clothes look this way.
3. Open `VERIFICATION_RECEIPT.md` if you need proof that the rejected visual direction was removed.
4. Ask Josh to choose the strongest lane, strongest silhouette, and first graphic placement zone.
