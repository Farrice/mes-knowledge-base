# No-Lazy-Path Gate

Before returning Standard or Deep steering, reject any option that fails one of
these tests:

- It could apply to almost any session.
- It does not name the concrete artifact, workflow, verifier, or decision.
- It tells Farrice to continue without teaching the move behind the continuation.
- It misses a material risk, hidden opportunity, or capability reveal.
- It does not have a clear skip condition.

Recovery: rewrite the option around the actual objective, current route, and
next useful artifact.
