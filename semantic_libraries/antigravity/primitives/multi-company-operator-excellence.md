# Multi-Company Operator Excellence

## Purpose

Use this primitive when a business, source, or client problem requires concrete entrepreneurial operating judgment across priorities, executives, product gates, channels, financial leakage, and launch/exit timing.

This primitive is grounded in the Dom Iacovone/Open Residency source package:

- `extractions/video-context/TUdTU1pwoZ4/`
- `extractions/dom-iacovone/multi-company-operator/`
- `skills/dom-iacovone-multi-company-operator/`

## When To Use

- A founder has too many initiatives and needs an operating model.
- A product, SKU, offer, or command needs stage-gate judgment.
- The founder is suppressing team ownership by staying too involved.
- Retail, TikTok, Amazon, DTC, DSD, or partner channels need sequencing.
- Growth is hiding financial leakage.
- A business is preparing for retail expansion, major launch, or exit optionality.
- A source-to-skill build needs a real business example corpus for "system, not summary" extraction.

## Core Operating Model

| Layer | Question | Output |
|---|---|---|
| SGM | What four initiatives deserve the year? | Four-block operating model |
| Finance | What numbers reveal truth first? | Weekly truth dashboard |
| Stage gate | Should this product or surface exist? | Go/revise/park/kill decision |
| Delegation | Where should the founder leave the room? | Owner and escalation map |
| Channel | Which route has the right incentives? | Channel sequence and lag map |
| Leakage | Where is margin quietly draining? | Gross-to-net and logistics audit |
| Optionality | What preserves future upside? | Launch/exit readiness map |

## Source-To-Skill Lesson

This source passed the build threshold because it contains many reusable mechanics across many chapters, not because it has an impressive title. Future source-to-system builds can use this as a comparison case:

- Evidence package first.
- Build shape second.
- New skill only if the method repeats across contexts.
- Harness primitive only if the source changes how the system should reason.
- Command surface only when users need a direct executable route.

## Quality Gate

Reject output if it:

- sounds like generic founder advice,
- ignores finance or channel incentives,
- recommends retail expansion without execution logic,
- treats buyer requests as automatically correct,
- gives medical/legal/tax/investment advice,
- or adds a new harness surface without route proof.

## Context Policy

Keep this primitive cold/on-demand. Load it when business/operator excellence is the target or when `/source-to-skill-system` needs a concrete source-to-skill example corpus. Do not make it a competing control-plane contract.
