# Antigravity Primitive Map

## Steering Primitives

- `primitives/high-floor-operator-os.md`: tier and high-floor routing standard.
- `primitives/collaborative-steering-compass.md`: Insightful Momentum closeout
  standard and 3 Next Prompts contract.
- `primitives/repeatability-spine-contract.md`: preservation lock, golden
  query, and regression guard standard for runs that worked once but cannot be
  reliably reproduced.
- `primitives/end-session-visible-closeout-benchmark.md`: lifecycle-truth
  benchmark for completed versus approval-blocked closeout answer surfaces.
- `references/no-lazy-path-gate.md`: quality gate that blocks generic steering.
- `references/frontier-followup-patterns.md`: researched frontier follow-up
  patterns for context, output families, information gaps, and anti-bait gates.
