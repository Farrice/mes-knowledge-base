# source-command-deep-research-os

Use this skill when the user asks to run the migrated source command
`deep-research-os`, asks for ultimate deep research, wide research, market
intelligence, social listening, PMF/OMF research, ICP deep canvassing, or
anti-hallucination research packaging. Also use it when the user wants
ChatGPT-like deep research inside Codex, live-world enrichment, native web
research, Tavily Search/Extract, or RSS-backed research without paid providers.

## Command Template

Read and execute the workflow at `.agent/workflows/deep-research-os.md` -
Ultimate research OS: deep research, wide decomposition, social listening,
market intelligence, source ledger, and anti-hallucination verification.

For current external research in Codex, also read
`semantic_libraries/antigravity/primitives/free-first-research-mission-contract.md`.
Default to its native-web-first path unless Farrice explicitly authorizes a
different provider or execution mode. Local context can shape questions and
analysis but cannot prove a current-world claim.

## Boundary

Prefer `/virtuoso --mode research` when the request needs orchestration before
research. Route directly into `/deep-research-os` when the objective is already
clearly research-heavy. Free-first mode never uses Apify, paid accelerators,
schedules, or real subagents.
