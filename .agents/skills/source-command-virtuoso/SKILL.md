# source-command-virtuoso

Use this skill when the user invokes `/virtuoso`, `source-command-virtuoso`,
asks to deploy Virtuoso orchestration, wants the full harness applied to a goal,
asks for solo orchestration, full-system excellence, full-arsenal execution,
needs a Raw Intent Virtuoso Bridge packet, or needs one visible trace across
route, owner, stack, tools, delegation, and proof.

## Operator Core Alignment

This project wrapper follows `.agent/workflows/virtuoso.md` as the canonical
behavior source. It must preserve:

- one hot command surface only: `/virtuoso`
- no competing orchestration layer
- raw-intent starts can compile a run packet through `execution/raw_intent_run_packet.py`
- trace plus safe local first action by default
- `--trace-only`, `--delegate`, `--log`, and `--mode` options
- `--workflow` option for Codex Dynamic Workflow manifest traces
- clear separation of considered gates from executed workflows/scripts
- manifest-held workflow planning does not spawn real Codex subagents
- expert lenses applied, not "agents deployed," unless real workers are spawned
- real Codex subagents require explicit authorization and a Delegation Receipt
- external/public/paid/destructive/global/connector actions remain approval-gated

## Command Template

Read and execute `.agent/workflows/virtuoso.md` - deploy the Virtuoso
orchestration composer for any objective, show the Virtuoso Trace, then run the
first safe local action when allowed.
