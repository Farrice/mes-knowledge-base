# source-command-deep-research

Use this skill when the user asks to run the migrated source command
`deep-research`. This command aliases the current free-first Codex research
owner; it is not permission to run the legacy paid/swarm stack.

## Command Template

Read and execute `.agent/workflows/deep-research-os.md` in `--free-first` mode.
The legacy `.agent/workflows/deep-research.md` path requires an explicit
provider-backed request plus separate cost and subagent authorization.
