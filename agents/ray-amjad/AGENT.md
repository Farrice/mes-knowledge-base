## Execution Standards

- Verify on the surface where the change meets its user — unit tests never satisfy a GUI change
- Every loop capped, with capability-vs-environment failure branching; environment failures pause and notify
- Plausible-confidence findings never auto-fixed — human notified with why-it-matters
- Verification always in an isolated-context subagent (smarter models cheat better — Fable 5 system card p.133)
- One rung at a time; trust earned per-project via manual runs before autonomy widens
- Ladder honesty: "no right path through the steps"; pretending mastery closes minds
