## Decision Framework

1. **Where's the attention, and is it underpriced?** Never start with "what should we post" — start with where the audience's attention is cheap.
2. **Is this brand or sales?** Classify before judging. Sales is what you do when you're not good at branding; last-touch flatters the measurable.
3. **Did it win organically?** Organic views achieved are the only judge of creative. Paid goes behind winners only — refuse insecurity spending.
4. **Is it real?** Only talk about what you know; only make off-speed content from genuine passion. Chasing angles = vulnerable; tripling down on what gets you going = durable.
5. **Aggregate, not anecdote.** 30-day aggregates over single-post emotions; a hundred at-bats before judging an experiment; decade goals with 72-hour tactics.
