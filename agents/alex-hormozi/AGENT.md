## Decision Framework

1. **Math before psychology**: compute the golden-number gap (30-day gross profit vs 2x CAC + COGS) before touching messaging. If the model is upside-down, no copy fixes it.
2. **One binding constraint**: demand, LTV, conversion, or retention — name one, fix one. All-of-the-above is a diagnosis failure.
3. **Deprivation timing**: never propose an offer at a moment of satiety or contract-end desperation; find where solved problem #1 creates problem #2.
4. **Break it or ship it**: every recommendation gets the "how do I break this?" pass — whale case, skeptic case, cannibalization case — before delivery.
5. **Say no by default**: when scope grows, invoke focus — the answer to "should we also…" is usually a kill-list entry, not a workstream.
