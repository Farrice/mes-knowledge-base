## Philosophy

### Consistency Is an Asset Discipline, Not a Model Feature
Move every load-bearing decision OUT of the prompt and INTO locked upstream artifacts — bibles (who), face locks and canonical sheets (what they look like), flat reference plates (what carries into the frame), block-structured video prompts (what happens on screen). Each generation becomes a cheap, disposable read of expensive, permanent context. Drift is never fully solved; hit rate scales with prep.

### Engineer References for the Model's Failure Modes, Not Human Eyes
18% gray beats white seamless because video models amplify mistakes at high-contrast edges. Garments get a headless panel so no facial data competes for attention. Faces go as large as the format allows because face size controls drift. Reference plates carry ZERO lighting information — baked shadows are inherited and amplified downstream. Lighting is applied exactly once, at the final render.

### References Carry Identity; Prompts Carry Framing
A 2,500-character prompt with strong references beats a 5,000-character one. If a sentence re-describes what an attached reference shows, cut it. Names, brands, and ages never appear in prompt output — names drift; visual descriptors survive.

### Write the Visible
km/h not "fast"; % haze plus meter visibility; scale via stacked humans; emotion in muscle ("knuckles blanch"). "If a word doesn't produce a visible pixel, cut it." Discrete anchors beat continuous suggestions: FOV in degrees not millimeters, timestamped beats, hex palettes — quantized instructions hold, analog ones decay.

### The Layers Never Do Each Other's Jobs
The bible refuses cinematography. Banana Pro refuses to bake lighting. The worldbuilder refuses to re-describe what a reference shows. An unbuilt character in a video request gets kicked back to stills; a multi-scene world with no bible gets canon first, or proceeds with the drift named out loud.

### Never Invent Canon
"[TBD] beats plausible" — invented canon becomes locked canon becomes prompt drift. Locks exclude as much as they include ("warm fair skin — never pale porcelain, never tan"); a lock without its "never" clauses won't hold over hundreds of renders.

## Execution Standards

- **Strict pipeline order.** CANON → STILLS → MOTION. Unbuilt character in a video ask → kick back to stills. No bible on a multi-scene world → build canon first or name the drift and proceed knowingly.
- **The Existence Question opens every session.** "Does this character/product already exist, or are we developing it?" — routes to lock vs. build.
- **Pre-prompt confirmation before every expensive prompt**, references listed FIRST — a missing ref is caught before the prompt ships. Minor iterations skip it; re-confirming on tiny deltas creates friction.
- **Cost before generate.** Every video prompt carries a declared duration; every shot plan carries a credit estimate before anything runs. All generation stays behind the workspace cost gates — the skill's job ends at the code block.
- **Silent structure, prose surface.** Checklists and coordinate grids stay internal; output is confident DP prose.
- **Quality gate**: anchor against the rubric in `skills/joey-cinema-os/genius.md` (identity persistence, reference discipline, anti-AI-render physics, write-the-visible, prompt economy, credit economy, story grip, world believability) before shipping.
