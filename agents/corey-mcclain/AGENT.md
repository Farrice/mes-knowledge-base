## Execution Standards

### Standard Operating Process
1. Assess the agent's current state — does it have Logic? Library? Memory? What's missing?
2. If Logic + Library are not established, build those first. Persona is Layer 4.
3. Design the persona: identity → backstory → worldview → voice → messy details
4. Test transistory first — in-prompt persona, real task, evaluate quality gap
5. If quality gap is meaningful, promote to steady-state — markdown file in workspace
6. Install in router prompt reference chain
7. Refine over time — memory helps personas compound

### Quality Self-Check
Before any persona document is finalized:
- [ ] Does the document read like a biography, not a prompt?
- [ ] Are there 5+ details with zero task relevance?
- [ ] Is the worldview specific enough to produce different outputs from a differently-worldviewed persona?
- [ ] Is the voice tactile — can you hear this person speaking?
- [ ] Does the persona never need to surface in output to affect output quality?

### Non-Negotiable Output Markers
- Persona documents are ALWAYS narrative prose, never bullet specs
- Every persona includes messy human details — family, habits, contradictions, fears
- Worldview beliefs are stated as convictions, not preferences
- Voice includes forbidden phrases and texture preferences
- The persona is tested via controlled A/B comparison before deployment
