# SubStack Launch — Zero to First Post

Complete launch sequence from blank SubStack to published first post with 2 more in the chamber.

## Prerequisites
- Load `nicolas-cole-newsletter-flywheel` skill
- Newsletter concept must PASS Two Rules Audit
- Tangible asset must be identified (`/tangible-faucet`)
- Business model chosen (`/newsletter-biz-model`)

## Process

### Step 1: Name & Positioning
1. **Name candidates (5+)**: Generate names that signal the tangible asset, not just the topic. Good: "The Prompt Vault," "Story Club." Bad: "Marketing Weekly."
2. **Tagline**: One sentence that completes "Subscribe and every [frequency] you'll get [tangible asset] that helps you [outcome]."
3. **Wine Club Pitch**: The 15-second elevator pitch using the wine club analog.

### Step 2: About Page Architecture
Write the SubStack "About" page using this structure:
1. **The Problem** — What the reader is struggling with (1-2 sentences)
2. **The Book They Wish Never Ended** — "If you loved [reference book/resource], this is the version that never stops" (1-2 sentences)
3. **What You Get** — The tangible asset, how often, in what format (2-3 bullets)
4. **Who This Is For** — Specific audience (not demographics — psychographics)
5. **Who Writes This** — 2-sentence credibility + why they care
6. **Subscribe CTA** — Clear, simple, specific

### Step 3: First 3 Posts Planned
Design the first 3 posts as a "proof sequence" — each one demonstrates the tangible asset so new subscribers immediately understand the value:

**Post 1 — The Manifesto**: Explain the philosophy (why this newsletter exists) AND deliver the first tangible asset. Reader should think: "This is exactly the kind of thing I wish never stopped."

**Post 2 — The Power Demo**: The best possible version of the tangible asset. This is the "if this is what free looks like..." post. Make it so good it's shareable.

**Post 3 — The Pattern Setter**: Normal cadence. This is what every future post will look like. Sets expectations for the subscription experience.

For each post, outline:
- Subject line (hook)
- Opening frame (why this edition matters)
- The tangible asset
- Commentary layer
- Close + tease next edition

### Step 4: Pre-Launch Checklist
- [ ] SubStack account created
- [ ] Profile photo + cover image uploaded
- [ ] About page written and published
- [ ] Frequency decided (weekly recommended for new newsletters)
- [ ] First post drafted and scheduled
- [ ] LinkedIn announcement post drafted (hand off to `/newsletter-social-proof`)
- [ ] Email signature updated with SubStack link
- [ ] 10 people from warm network personally invited

### Step 5: Output
Deliver:
- Newsletter name + tagline
- Complete About page copy
- 3 post outlines (subject lines, structure, tangible asset described)
- Pre-launch checklist (filled in)
- LinkedIn announcement draft

- [ ] The chosen name signals the tangible asset, not just the topic (fails the "Marketing Weekly" test)?
- [ ] The About page's "What You Get" section names a noun, not a theme?
