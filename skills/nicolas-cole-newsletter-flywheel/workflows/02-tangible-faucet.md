# Tangible Faucet — Asset Design Engine

Discovers and validates the specific tangible, repeatable asset that subscribers never want to stop receiving.

## Prerequisites
- Load `nicolas-cole-newsletter-flywheel` skill (SKILL.md + genius.md)
- User has a topic area or rough newsletter concept

## Process

### Step 1: Self-Consumption Audit
Ask the user (or run on their behalf):
1. "What do you consume obsessively that you wish never ended?"
2. "What tangible thing do you wish kept arriving — recipes, prompts, case studies, templates?"
3. "What would you pay to receive every week forever?"

Map answers to potential newsletter tangible assets.

### Step 2: Asset Type Identification
From the user's domain, generate 5-7 candidate tangible assets using this taxonomy:

| Asset Type | Examples | Best For |
|-----------|---------|---------|
| **Prompts** | AI prompts, coaching questions, journal prompts | Knowledge workers, coaches |
| **Templates** | Email templates, spreadsheets, scripts | B2B, service providers |
| **Recipes/Routines** | Workout plans, meal plans, daily routines | Health, lifestyle |
| **Case Studies** | Breakdowns of real examples with expert commentary | Strategy, marketing |
| **Cheat Sheets** | Quick-reference guides, frameworks on one page | Technical, skill-based |
| **Curated Collections** | Top 5 tools, best articles, playlist of resources | Curation-focused |
| **Step-by-Step Guides** | Walkthroughs with screenshots, action items | How-to, implementation |

### Step 3: Faucet Test (Per Candidate)
For each candidate asset, run three tests:

**Test 1 — The Noun Test**: Can the subscriber describe what they get with a noun? 
- ✅ "I get AI prompts" → passes
- ❌ "I get marketing insights" → fails (too abstract)

**Test 2 — The Save Test**: Can the subscriber save, bookmark, copy-paste, screenshot, or share it?
- ✅ Recipe card → saves to recipe folder
- ❌ "Reflections on leadership" → nothing to save

**Test 3 — The Wine Club Test**: "It's like a _____ club but for _____."
- ✅ "It's like a wine club but for AI prompts" → clicks
- ❌ "It's like a wine club but for business strategy" → broken analogy

### Step 4: Infinite Repeatability Check
For the candidates that pass all 3 tests:
1. Name 3+ external evolution engines that guarantee infinite fresh material
2. Project forward 2 years: will this asset still be relevant? Why?
3. Identify the "Write With AI problem": after 3 months of producing this, will you worry about running out? (If yes → the evolution engine isn't strong enough)

### Step 5: Output
Deliver:
- **Winner**: The tangible asset type with the highest faucet score
- **Runner-up**: The second-best option (pivot insurance)
- **Asset Description**: 2-sentence pitch: "Every [frequency], you get [specific tangible asset] that helps you [specific outcome]. It's like a [physical analog] club but for [your domain]."
- **First 5 Edition Concepts**: Quick titles showing the asset in action
