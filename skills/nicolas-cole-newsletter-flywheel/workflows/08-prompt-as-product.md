# Prompt as Product — Coaching Prompts as Tangible Assets

Creates actionable coaching prompts that extend the creator's ability, delivered as the newsletter's tangible faucet.

## Prerequisites
- Load `nicolas-cole-newsletter-flywheel` skill
- Newsletter audience defined (coaches, solopreneurs, multi-passionate entrepreneurs)
- Creator's area of expertise identified

## The Core Insight
The best newsletter tangible assets EXTEND the creator's coaching ability. Instead of the creator coaching 1:1, the prompts coach on their behalf. Each prompt is a "micro-coaching session in a box" — the reader runs the prompt and gets a personalized coaching output. This is the "Write With AI" model applied to ANY expertise domain.

## Process

### Step 1: Expertise Decomposition
Break the creator's expertise into coachable micro-units:
1. What are the 5-10 core decisions/actions their clients need to make?
2. What questions do they ask in 1:1 coaching that produce breakthroughs?
3. What frameworks do they use that can be templatized?
4. What diagnostics do they run that reveal hidden problems?

### Step 2: Prompt Architecture
For each micro-unit, design a coaching prompt with this structure:

```
PROMPT: [Name — Specific Outcome]

THE SITUATION
You're a [audience member] who [specific situation]. You have [context].

THE COACHING SESSION
Act as a [expertise domain] coach executing [specific methodology]. 
Walk me through:
1. [Diagnostic question that reveals the real problem]
2. [Framework application with my specific inputs]
3. [Action plan with timeline and accountability]

MY INPUTS
- [Input 1 the reader fills in]
- [Input 2]
- [Input 3 — optional context]

OUTPUT FORMAT
- [Specific deliverable the reader gets back]
- [Action items with deadlines]
- [Success metric to track]
```

### Step 3: Quality Gate for Prompts
Each prompt must pass:
1. **The Extension Test**: Does this prompt do what the creator would do in a 30-min coaching call?
2. **The Tangible Test**: Is the output a save-worthy, actionable deliverable?
3. **The Reuse Test**: Would the reader run this prompt again with different inputs?
4. **The Share Test**: Would the reader share this prompt with a colleague?

### Step 4: Newsletter Integration
Design how the prompt is delivered in the newsletter:
1. **Context intro** (2-3 paragraphs): Why this prompt matters this week, what it solves, story/case study of someone who needed it
2. **The Prompt** — formatted, copy-pasteable, immediately runnable
3. **Commentary layer**: Creator's perspective on what the prompt reveals, what to watch for, what most people get wrong
4. **Bonus**: One variation or advanced version for power users

### Step 5: Output
Deliver:
- **5 coaching prompts** ready for newsletter delivery
- **Newsletter format**: How each prompt would appear in an issue
- **Infinite repeatability plan**: The evolution engine that guarantees new prompts forever
- **Prompt library architecture**: How to organize past prompts for subscriber value
