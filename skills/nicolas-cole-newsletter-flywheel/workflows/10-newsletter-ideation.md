# Newsletter Ideation — Infinite Ideas Engine

Generates 10+ newsletter edition concepts using the tangible asset repetition model. Solves "what do I write about?" permanently.

## Prerequisites
- Load `nicolas-cole-newsletter-flywheel` skill
- Tangible asset defined (`/tangible-faucet`)
- At least 1 edition already published (understands the format)

## The Principle
Tangible things repeat infinitely because the domain evolves. New science, new tools, new trends, new case studies. The world generates the content for you. This workflow taps that infinite engine.

## Process

### Step 1: Evolution Engine Inventory
Identify 5+ external forces that generate infinite new material:
1. **Technology shifts**: What tools/platforms change in this space?
2. **Market movements**: What's happening in the industry?
3. **Audience evolution**: How are readers' problems changing?
4. **Seasonal patterns**: What recurs annually? (Tax season, Q4 planning, New Year)
5. **Cultural moments**: What cultural events/conversations intersect?
6. **Competitor gaps**: What are others in this space NOT covering?
7. **Reader questions**: What are subscribers asking in comments/replies?

### Step 2: Tangible Asset Multiplication
Take the defined tangible asset and generate 10+ variations:

**Variation Types**:
- **The Deep Dive**: One asset explored in extreme detail
- **The Collection**: 5-7 mini-assets bundled in one edition
- **The Challenge**: An asset + a 7-day challenge to implement it
- **The Breakdown**: Reverse-engineer a real-world example into an asset
- **The Template**: A reusable template the reader customizes
- **The Comparison**: Two approaches compared with asset for each
- **The Guest**: Expert contribution adding their twist to the asset format
- **The Reader Spotlight**: Reader-submitted use case + creator commentary
- **The Seasonal**: Asset tailored to a timely moment
- **The Advanced**: Next-level version for power subscribers

### Step 3: Cross-Matrix Generation
Cross the evolution engines (Step 1) with variation types (Step 2):

| Evolution Engine × | Deep Dive | Collection | Challenge | Breakdown | Template |
|---|---|---|---|---|---|
| Technology shift | | | | | |
| Market movement | | | | | |
| Audience question | | | | | |

Fill 10+ cells with specific edition concepts (title + 1-sentence pitch + tangible asset described).

### Step 4: Calendar Mapping
Organize the 10+ concepts into a content calendar:
- Mix variation types (don't do 3 deep dives in a row)
- Alternate between evergreen and timely
- Front-load the strongest concepts
- Save the "Guest" and "Reader Spotlight" for when you have traction

### Output
- **10+ edition concepts** with titles, pitches, and asset descriptions
- **Evolution engine inventory** (the infinite fuel sources)
- **4-week content calendar** filled with the best concepts
- **Backlog**: Remaining concepts saved for future months

## Output Schema

```markdown
# Newsletter Ideation — [Newsletter Name]

## Evolution Engine Inventory (5+)
1-5+. [technology/market/audience/seasonal/cultural/competitor/reader-question force]

## Cross-Matrix (filled)
[Evolution engines × variation types, 10+ cells populated]

## 10+ Edition Concepts
1-10+. [title + 1-sentence pitch + tangible asset]

## 4-Week Content Calendar
Week 1-4: [concept assigned per week, variation types mixed]

## Backlog
[Remaining concepts, unscheduled]
```

## Quality Gate

- [ ] At least 5 distinct evolution engines named (not variations on "trends change")?
- [ ] Every one of the 10+ concepts names a tangible asset noun, not just a topic?
- [ ] The 4-week calendar avoids 3+ consecutive editions of the same variation type?
- [ ] Backlog concepts are genuinely usable later, not filler generated to hit the count?
