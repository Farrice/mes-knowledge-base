# Paul Harding — Use Cases (Scenario → Workflow Map)

> Concrete deployment scenarios for the Paul Harding lyric-prose skill, each routed to the matching `harding-` workflow. Use this to pick the right instrument fast. The genius is in `genius.md`; the per-step procedures are in `workflows/`.
>
> **First, the lane.** This skill is for *perception-driven, lyric* writing — making a real thing land through precise attention and felt recognition. It is **not** the plotting engine, the SEO engine, or the hot-take engine. If the job is structure-first, argument-first, or volume-first, route elsewhere. If the job is to make a reader *feel* a true thing and recognize it, you're home.
>
> **Honesty spine.** In every commercial scenario below, the precisely-rendered detail must be a *real, true* particular. The craft makes a true thing land harder; it never fabricates texture. Run the honesty gate before the craft.

## The 10 workflows at a glance

| Workflow | One-line job | Layer |
|---|---|---|
| `/harding-improv-draft` | Generate a full first draft from one sensory seed, no outline | Drafting (front door) |
| `/harding-perception-engine` | Build luminous, precise description of any subject from raw observation up | Description (front door) |
| `/harding-then-what` | Build an extended image / set-piece link-by-true-link | Image construction |
| `/harding-two-things` | Render a loaded moment as literal thing + felt thing | Emotional scenes |
| `/harding-counterpoint` | Snap a habitual description awake via opposite-category verbs | Description rescue |
| `/harding-precision-wonder` | Replace slathered adjectives with precision + motion-over-time | Anti-slather rescue |
| `/harding-perceptual-copy` | Turn feature/benefit copy into the Two Things on an honesty spine | Copy (cross-domain) |
| `/harding-cadence` | Tune sentence music by ear — beats, tempo, accents | Line polish (final) |
| `/harding-distill` | Carve an overworked/sprawling draft to density (Systole & Diastole) | Revision |
| `/harding-recognition-audit` | Strip lessons/takeaways; re-engineer to persuade by recognition | QA / final pass |

## A. Drafting from scratch

### Scenario: "I have a topic/moment but no idea where the piece goes."
You have a seed — a remembered detail, an image, a single true moment — and the instinct to outline first. Don't. Improvise toward emergence.
→ **`/harding-improv-draft`** (Light Out Without a Map). Starts from one concrete sensory seed and follows the literal chain ("then what?") to an ending you *discover*. Includes permission to write the bad sentence first.

### Scenario: "Write the founder origin story without the hero template."
The arc keeps collapsing into "saw a problem, had the vision, never gave up."
→ **`/harding-improv-draft`** to generate from one real seed moment, not a template. Then **`/harding-then-what`** for any pivotal scene that needs to build link-by-true-link. (Cross-domain: see `cross-domain-patterns.md` §5.)

### Scenario: "Open a Substack/essay on a real moment instead of an abstract claim."
→ **`/harding-perception-engine`** to build the opening moment luminously, then **`/harding-recognition-audit`** to make sure it opens a door instead of promising takeaways.

## B. Building description

### Scenario: "Make this object/place/moment feel luminous and specific."
The core descriptive job — render the everyday so precisely it turns wondrous.
→ **`/harding-perception-engine`** (the front-door description workflow). Slow down beneath recognition → strip received language → render the literal thing with botanist's precision + motion → layer the felt experience.

### Scenario: "Build a big set-piece image that means something without stating a theme."
A dying man's vision, a long descent, an extended metaphor-that-isn't-a-metaphor.
→ **`/harding-then-what`** (the literal chain). Build the image one physically-true consequence at a time so meaning *accrues* — never reaching for the symbol. This is the cracked-ceiling move from *Tinkers*.

### Scenario: "This emotional scene keeps telling the reader how to feel."
You wrote "she felt devastated" or explained the emotion outright.
→ **`/harding-two-things`**. Produce the precise literal thing (neutrally true) + the character's charged experience of it, fused — so the *gap* between them does the characterizing. No explained feelings, no clanking gears.

---

## C. Rescuing prose that's gone wrong

### Scenario: "This description is flat / habitual / I've seen it a thousand times."
The line is correct but dead — generic, off-the-rack seeing.
→ **`/harding-counterpoint`**. Render the thing in the verb/noun repertoire of its *opposite* category (vapor in stone's verbs, silence in a roar's verbs). Stays purely literal; snaps the reader awake. Mine the verbs hardest.

### Scenario: "I'm slathering adjectives to make this feel beautiful/important."
"Ancient, gnarled, sorrowful willow…" — beauty applied to the thing instead of released from it.
→ **`/harding-precision-wonder`** (the anti-slather instrument). Replace stacked adjectives with botanist's precision *plus* motion-over-time ("add calculus so the light moves"). The wonder gets released, not installed. Run this the moment you catch yourself reaching for a "beautiful" word.

### Scenario: "This draft is bloated / cluttered / 1,000 words doing 200 words' work."
You overwrote (correctly) and now need to carve back.
→ **`/harding-distill`** (Systole & Diastole). Carve to maximum density with maximum readability via overwrite-then-chisel. Reframes revision as insurance, not punishment — depth, not width.

### Scenario: "The piece lands a lesson / takeaway / moral I want gone."
"Here's what I learned…", "It's not X, it's Y", "reminding us all that we must…"
→ **`/harding-recognition-audit`**. Locates every lesson/takeaway/explained-feeling in a diagnostic table, rewrites the worst offender to recognition, and renders a door-open verdict. A message means the reader never has to think about it again — kill it.

## D. Line-level finishing

### Scenario: "The sense is right but the sentence music is off — flat, sing-song, wrong rhythm for the feeling."
→ **`/harding-cadence`** (the final polish layer). Tune by ear like a drummer tunes a kit: scan beats → set tempo to mood (half-time for weight, double-time for momentum) → place accents where meaning wants them → match monosyllabic funk vs. polysyllabic tumble to the character → cut the stray eighth note → kill the sing-song. **Read-aloud verdict required.** This is the *last* layer — meaning and perception came first.

## E. Cross-domain commercial deployment

> All cross-domain scenarios run on the **honesty spine**: the rendered detail must be a real, checkable particular. See `cross-domain-patterns.md` for full before/after examples per domain.

### Scenario: "This converting copy reads as a feature/benefit list; the reader never FEELS the product."
The purpose-built cross-domain workflow.
→ **`/harding-perceptual-copy`**. Inventory the *real* particulars first (honesty gate) → render each as the literal thing + the felt experience (Two Things) → let the reader infer the benefit by recognition, never by stated claim.

### Scenario: "Write a brand's about-page / world so its character emerges from what it notices."
Kill the "bold, authentic, human-first" adjective list.
→ **`/harding-perception-engine`** to render the real brand-world precisely + in motion, so character refracts through what the brand notices. Run **`/harding-precision-wonder`** anytime brand copy starts slathering "premium/unforgettable."

### Scenario: "Ghostwrite in the client's voice — not mine, not a master's."
→ **`/harding-perception-engine`** to ground the client's claims in *their* real remembered moments, then **`/harding-cadence`** to tune the line-music to the client's ear. Surrender to the client's grain; never pastiche a master onto them.

### Scenario: "Make a familiar product category feel newly seen in an ad."
→ **`/harding-counterpoint`** to snap the habitual category description awake, inside **`/harding-perceptual-copy`**'s honesty + Two-Things frame.

### Scenario: "Write a LinkedIn/X post that resonates instead of instructing."
→ **`/harding-perception-engine`** (open on one precisely-seen real moment) → **`/harding-recognition-audit`** (strip the "here's what I learned" close, open a door). Depth, not width.

## F. Common chained sequences

Real work usually composes several workflows. Canonical chains:

| Goal | Chain |
|---|---|
| **Lyric essay, zero to ship** | `/harding-improv-draft` → `/harding-distill` → `/harding-cadence` → `/harding-recognition-audit` |
| **Single luminous description** | `/harding-perception-engine` → (`/harding-counterpoint` if habitual) → `/harding-precision-wonder` → `/harding-cadence` |
| **Extended set-piece image** | `/harding-then-what` → `/harding-precision-wonder` → `/harding-cadence` |
| **Emotional scene** | `/harding-two-things` → `/harding-cadence` → `/harding-recognition-audit` |
| **Converting copy** | `/harding-perceptual-copy` (honesty gate built in) → `/harding-counterpoint` (if category is stale) → `/harding-cadence` |
| **Rescue an overwritten draft** | `/harding-distill` → `/harding-precision-wonder` (carve slather) → `/harding-recognition-audit` (kill lessons) → `/harding-cadence` |
| **Ghostwriting a client piece** | `/harding-perception-engine` (ground in client's real moments) → `/harding-cadence` (client's ear) → `/harding-recognition-audit` |

> **Sequencing law:** meaning and perception first, music last. `/harding-cadence` is almost always the final step — never tune the rhythm of a sentence whose truth or perception isn't settled yet. And `/harding-recognition-audit` is the cheapest, highest-leverage final QA: if a lesson survived, the craft was wasted.

## G. When NOT to use this skill

Route elsewhere when:
- **The job is structure-first / plot-first.** Wright Thompson (architecture-first journalism) or Michael Connelly (surgical economy) own that lane. Harding refuses the map.
- **The job is argument / persuasion-by-logic.** Harding persuades by *recognition*, not argumentation. For claim-and-evidence work, route to a copy/argument expert.
- **The job is volume / SEO / quantity.** This is a depth engine, not a width engine. Route to the SEO or quantity-sprint experts.
- **The detail can't be real.** In any commercial scenario, if you can't ground the vivid particular in a true, checkable fact, do not deploy the craft to fake it. The honesty-spine breach is the most dangerous failure in the whole skill.
- **The voice should be plain and transparent on purpose** (legal, technical docs, terse UX). Lyric density is a feature here only when felt experience is the goal.
