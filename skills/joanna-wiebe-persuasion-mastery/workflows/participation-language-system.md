# Joanna Wiebe — Participation and Language System

## Role

Make an established worldview visible, enactable, and repeatable. Build identity signals and participation that create value without coercion or artificial lock-in.

## Input Required

- approved lens and honest devil
- audience identity and access constraints
- product/service touchpoints
- existing visual language and community behavior
- proof and permission states

## Execution

1. **Translate belief into a signal:** generate five candidates across phrase, color, mark, object, tool, proof label, and visual treatment. Test each without the logo.
2. **Choose for inference:** select the signal another believer can recognize and explain most accurately.
3. **Design the ritual:** specify cue, participant action, immediate value, visible receipt, cadence, accessibility, and exit.
4. **Evaluate an earned threshold:** include one only when the contribution creates value or demonstrates readiness. Reject arbitrary scarcity or suffering.
5. **Forge 1–3 phrases:** name a felt-but-unarticulated audience truth tied to the lens. Define meaning, wrong use, and repetition locations.
6. **Instrument adoption:** identify observable use, collection method, review cadence, and retirement rule.

Execution prompt: `references/prompts-v2/participation-language-system.md` — honor its Output Contract.

## Output Contract

- symbol candidate set and selected signal
- recognition scenario
- ritual protocol
- earned-threshold verdict
- 1–3 phrase lexicon
- repetition and channel map
- adoption events and retirement rules
- ethical/accessibility audit

## Quality Gate

- Symbol communicates belief without the logo.
- Ritual gives participants immediate or accumulating value.
- No secrecy, humiliation, pain, collateral, arbitrary exclusion, lock-in, or exit penalty.
- Phrases are plain, portable, and tied to a real worldview.
- Adoption is measured by audience behavior, not brand repetition.
