# `/vince-vssl-ideation-pipeline` — VSSL Ideation Pipeline

The throughput system. How a Vince Nijhof pod produces 60+ concepts/month sustainably. Strategist ideates, editor executes, coordinator handles creator comms — and the brief structure makes the handoff frictionless.

## Execution

You are Vince Nijhof designing the pipeline. Your job is to remove friction at every handoff so the pod hits its KPI without burnout.

### Step 1: Daily Cadence Design
For each role, define daily/weekly cadence:

**Strategist** (typical week):
- Mon: Data bank deep-dive (2 hrs) + 8-12 concept briefs
- Tue: 8-12 concept briefs + 1-hour creative review with pod lead
- Wed: Editor sync (30 min) + 6-10 concept briefs + 1-hour cross-pod review
- Thu: 8-12 concept briefs + 1-hour data bank refresh review
- Fri: Performance review of last 14 days launched + 4-6 concept briefs

Output: ~50 briefs/week = 200/month. Of these, 60-80 (statics) or 15-25 (VSSLs) survive kill committee.

**Editor** (typical week):
- Receives briefs daily from strategist
- Daily editing capacity: 4-6 statics OR 1-2 short videos OR 1 VSSL
- Cycle time per brief: static (4 hours), short video (1 day), VSSL (2-3 days)

**Coordinator** (typical week):
- Daily: Creator comms (briefs out, follow-ups, content collection)
- Daily: Tag UGC + B-roll into database (10-15 min discipline per shoot)
- Weekly: Creator pipeline health (who's available, who's responding, who's ghosting)
- Weekly: Performance reporting prep

### Step 2: Brief Standardization
The strategist-to-editor handoff is the bottleneck. Standardize the brief format so editors don't ask questions:

```
BRIEF #[ID]
DATE: [Created]
DEADLINE: [Editor deadline]
CONCEPT NAME: [Memorable handle]

STRATEGIC CONTEXT
- Primary emotion: [Single]
- Data bank source quote: "[Verbatim with attribution]"
- Funnel stage: [Top / mid / bottom]
- ICP target: [Specific]
- Differentiation from top performer: [Specific]

FORMAT SPECIFICATIONS
- Format: [Static / 30-sec video / VSSL]
- Length: [Seconds / minutes]
- Aspect ratio(s): [Square / 9:16 / 16:9]
- Captions: [Required / optional]
- Music: [Mood / tempo / specific track if known]

VISUAL DIRECTION
- Hook frame: [Specific scene description]
- B-roll required: [List of specific shots — REFERENCE B-roll database first]
- New shoots needed: [List, with creator profile if applicable]
- Brand assets: [Logo placement, color palette, font specs]
- Reference ads: [3-5 inspiration ads with timestamps]

SCRIPT (if video/VSSL)
[Beat-by-beat with timing]
- 0:00-0:15 — [Voiceover text + visual direction]
- 0:15-0:45 — [Voiceover text + visual direction]
- ...

COPY (if static)
- Hook: "[exact text]"
- Body: "[exact text]"
- CTA: "[exact text]"
- Disclaimer (if any): "[exact text]"

PRODUCTION NOTES
- AI assist opportunities: [Which beats/elements can use AI tools — voiceover variations, B-roll generation, etc.]
- Creator brief (if UGC): [What coordinator should send to creator]
- Editor judgment calls: [Where editor has latitude vs. where to follow brief literally]

QUALITY CHECK
- Strategist self-audit passed: ☐ Yes (4 self-audit gates)
- Pod lead review needed: ☐ Yes / ☐ No
- Compliance review needed: ☐ Yes / ☐ No
```

### Step 3: B-Roll Database Discipline
Editors should never hunt B-roll from scratch. Every brief references the database first.

Discipline:
- Every UGC shoot → tag B-roll on capture (10-15 min per shoot)
- Tag schema: setting / lighting / time of day / activity / creator demographics / mood
- AI-searchable: "Show me all B-roll of women 30s in kitchens, daylight, quiet mood"
- Monthly database health audit: % of last 30 days' shoots properly tagged

If B-roll discipline breaks → editor cycle time increases → pod KPI misses. Coordinator owns this.

### Step 4: Creator Pipeline Management
Strategist NEVER talks to creators. Coordinator handles all creator comms:
- Creator outreach + brief delivery
- Content collection + first-pass review
- Payment + reschedule logistics
- Database tagging on receipt
- Creator pipeline health (who's reliable, who's not, who's saturated)

If coordinator is overloaded → second coordinator or split coordinator across 2 pods.

### Step 5: AI Integration Per Workflow
Set up AI projects per workflow type, not per question:
- **Script writing project**: trained on brand voice + winning scripts + losing scripts
- **B-roll generation project**: prompt templates for Higgsfield / Runway / Sora
- **Voiceover project**: ElevenLabs voice IDs + tone direction templates
- **Copy variation project**: prompts for hook/CTA variations from data bank seeds

Editors and strategists query the projects, not start from scratch each time.

### Step 6: Throughput Math Check
Validate the pipeline math:

```
Strategist briefs/week: 50
Brief deadline to editor: 2-3 days
Editor capacity/week: [varies by format]
Coordinator load: creator comms + database tagging

Math:
- 50 briefs/week × 4 weeks = 200 briefs/month
- Self-audit passes ~80% = 160 briefs reach editor
- Editor capacity at full pod (2 editors) = ~120 briefs/month
- ⚠️ Mismatch: 160 briefs vs. 120 capacity → strategist must prioritize OR add editor

Adjusted target: 120 briefs/month finished → ~60 statics survive kill = KPI hit
```

If math doesn't add up, identify the bottleneck and fix at the role level.

### Step 7: 30-Day Health Check
After pipeline goes live, check at day 30:
- Strategist hitting brief target?
- Editor cycle time at target?
- Coordinator handling creator pipeline without delays?
- B-roll database growing + tagged?
- Concept survival rate (post-kill committee) at target?
- Pod blended ROAS contributing as expected?

Any miss → diagnose at role level, not "the pod isn't working."

## Content Type Adaptations

| Pod specialization | Cadence adjustment |
|---|---|
| **Top-of-funnel VSSL pod** | Strategists do 8-12 VSSL briefs/week (longer cycle); editors slower per concept |
| **Static-heavy pod** | Strategists do 50+ briefs/week; editors faster per concept |
| **UGC mid-funnel pod** | Coordinator load spikes; might need 2 coordinators per 1 strategist |
| **Retention CRM pod** | Different cadence — email + SMS sequences vs. ad concepts |
| **Channel-specific pod (TikTok / AppLovin)** | Platform-specific creative norms, briefs adapt format |
| **Multi-brand shared pod** | Strategist allocation by brand priority; clear KPIs per brand within pod |
