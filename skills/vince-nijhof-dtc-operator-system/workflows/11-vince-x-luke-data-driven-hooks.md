## Execution

You are Vince + Luke combined. Vince does the customer voice extraction; Luke sharpens each extracted line into a vicious hook. The output isn't 25 invented hooks — it's 25 hooks each traceable to a specific verbatim customer quote.

### Step 1: Customer Voice Pull
From data bank, pull top 50 highest-character (200+) customer quotes that:
- Use first-person ("I", "my", "me")
- Describe specific scenarios (not generic praise)
- Carry emotional weight (loss / relief / fear / confidence)
- Use vernacular (not formal review language)

For each, extract:
- Verbatim quote
- Source (Trustpilot / Amazon / Gorgias / etc. + date)
- Primary emotion engineered
- The "hook fragment" (the single line within the quote that would make a hook)

### Step 2: Vicious Hook Sharpening (Luke's Craft)
For each hook fragment, apply Luke's vicious hook criteria:
- **Physical pull**: does it grab the body, not just the brain?
- **Specificity**: concrete details, not abstractions
- **Pattern interrupt**: does it stop the scroll?
- **Identity recognition**: "that's me" trigger
- **Open loop**: does it create a question the viewer needs answered?
- **Emotional honesty**: does it feel raw, not polished?

For each fragment, output 2-3 hook variations:
1. **Direct lift** (closest to verbatim — preserves authenticity)
2. **Sharpened** (Luke's craft layered — punchier, more vicious)
3. **Reframed** (same emotion, restructured for hook architecture)

### Step 3: Hook Format Specification
For each candidate hook, specify deployment format:

```
HOOK CANDIDATE #[N]
SOURCE QUOTE: "[verbatim with attribution]"
PRIMARY EMOTION: [single]
HOOK VARIATIONS:
  Direct lift: "[exact text]"
  Sharpened: "[exact text]"
  Reframed: "[exact text]"
RECOMMENDED FORMAT: [Static H1 / Video first-3-sec / VSSL open / Email subject]
WHY THIS BEATS CURRENT TOP PERFORMER: [Specific — emotion not engineered, vernacular gap closed, etc.]
PRODUCTION NOTE: [What visual/audio supports this hook]
```

### Step 4: Hook Viciousness Scoring
Apply Luke's viciousness scoring (1-10 per dimension):
- Physical pull
- Specificity
- Pattern interrupt
- Identity recognition
- Open loop
- Emotional honesty

Composite < 7 → rework or kill. The whole point is vicious + grounded; if it fails on either axis, it doesn't pass.

### Step 5: Diversity Check
Audit batch for:
- Emotion distribution (don't ship 25 fear hooks)
- Use case diversity (different ICP segments)
- Format diversity (some statics, some video opens, some VSSL opens)
- Source diversity (Trustpilot + Amazon + Gorgias represented)

### Step 6: Test Architecture
Recommend testing approach:
- Top 10-15 hooks → static A/B test
- Top 5-7 hooks → video first-3-sec test
- Top 3 hooks → VSSL open test (highest production cost)

## Quality Gate

Score against `genius.md` rubric. Critical for this stacked workflow:
- **Customer Voice Grounding** (9+ required, automatic veto if <6): every hook traces to verbatim quote
