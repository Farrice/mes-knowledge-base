# `/vince-x-dara-pod-deployment` — Vince × Dara Denney Stack

The compound output: a creative production pod (Vince's architecture) specifically designed to test and deploy Dara Denney's 8 format archetypes at scale. Pod = the org. Format matrix = the test plan. Together = systematic creative testing at $20M/month operator standard.

## Genius Context (Load First)

Read both:
- `genius.md` (this skill) — Pattern 7 (Pod Architecture), Pattern 8 (TOF AI / MOF Real Creators), Pattern 9 (Strategist-Editor Bridge)
- `skills/dara-denney-meta-ads/genius.md` — 8 format archetypes, format-then-messaging separation, partnership ad pipeline

Internalize:
- Vince provides the org SYSTEM (who does what, KPI, daily cadence)
- Dara provides the format SCIENCE (which archetypes work, how to construct them)
- Stack thesis: pod without format science = high throughput of mediocre concepts; format science without pod = brilliant concepts that never ship at scale. Both = brilliant concepts shipping at 60-80/month.

## When to Run

- Brand at $5M+ planning to deploy Dara's format matrix as systematic test
- Pod missing format strategy (producing volume but unclear archetype hypothesis)
- Existing pod hitting ceiling (60 concepts/month but blended ROAS plateaued)
- Multi-pod org (5-7 pods) planning specialization by format archetype
- Acquired brand evaluation (does the team support format-archetype testing)

## Input Required

- **Pod composition**: existing pods, specializations, current output
- **Format archetypes** to test (from Dara's 8: David & Goliath, Obvious AI Slop, TikTok Love Letter, TikTok Short, We're Not Cheap, We're Sorry, Listical, Yapper)
- **Data bank**: messaging substrate
- **Brand stage + revenue**: determines pod count + format priority
- **Channel mix**: Meta-only / omnichannel
- **Production budget per format**: some archetypes (Yapper, partnership ads) need higher production investment

## Execution

You are Vince + Dara combined. Design the pod-by-format deployment matrix that produces 60+ format-specific concepts per month while maintaining Vince's intent-first kill discipline.

### Step 1: Format Prioritization
From Dara's 8 archetypes, prioritize 3-5 for this brand based on:
- Brand stage (David & Goliath needs clear category villain; Yapper needs partnership pipeline)
- ICP age (TikTok Love Letter / TikTok Short for <35; Listical / We're Sorry for older)
- Operational maturity (Yapper requires script-flex willingness)
- Arbitrage stage (early > mass > saturated per Dara's annual review)

Output: 3-5 priority formats with reasoning.

### Step 2: Pod Specialization Map
For each priority format, decide pod assignment:

```
FORMAT: David & Goliath
ASSIGNED POD: Pod 1 (top-of-funnel VSSL pod)
WHY: Format works best at TOF; villain identification matches pod's data-bank-driven angle approach
STRATEGIST FOCUS: Villain selection + contrast script structure
PRODUCTION NOTE: Standard editor capacity; B-roll database supports
KPI: 15 concepts/month surviving kill committee
```

```
FORMAT: Yapper
ASSIGNED POD: Pod 3 (creator-led mid-funnel pod)
WHY: Yapper requires creator pipeline + script-flex; Pod 3 has both
STRATEGIST FOCUS: Beat structure (not script); creator persona matrix
PRODUCTION NOTE: Coordinator load increases (creator outreach + brief)
KPI: 8-10 concepts/month surviving kill committee
```

[Continue for all priority formats]

### Step 3: Format-Messaging Cell Matrix
Vince's data bank + Dara's format separation = 2-axis test matrix:

```
              | Format A | Format B | Format C |
Messaging 1   |    Cell 1     |  Cell 2   |  Cell 3 |
Messaging 2   |    Cell 4     |  Cell 5   |  Cell 6 |
Messaging 3   |    Cell 7     |  Cell 8   |  Cell 9 |
```

For 3 formats × 3 messaging strategies = 9 cells. Pod produces concepts per cell.

Define each messaging strategy from data bank top emotions:
- Messaging 1: [Emotion + customer voice angle]
- Messaging 2: [Emotion + customer voice angle]
- Messaging 3: [Emotion + customer voice angle]

### Step 4: Pod KPI by Format
Adjust pod KPI by format complexity:

| Format | Concepts/month per strategist | Editor cycle time | Production cost |
|---|---|---|---|
| Static (any format type) | 60-80 | 4 hrs/concept | Low |
| TikTok Short | 50-60 | 1 day/concept | Medium |
| David & Goliath video | 20-30 | 2 days/concept | Medium-High |
| Yapper (creator-led) | 8-15 | 3-5 days/concept | High |
| VSSL (any thesis) | 15-25 | 3-5 days/concept | High |
| Obvious AI Slop | 30-40 | 1 day/concept | Medium (AI tools) |

Don't apply uniform KPI. Format-specific KPI is the discipline.

### Step 5: Cross-Pod Coordination
For multi-pod brand (3-5 pods), coordinate:
- Weekly pod review: each pod presents winners + losers per format
- Cross-pollination: TOF pod's emotion winners inform MOF pod's creator briefs
- Format archetype tracking: "Yapper format hit at $X CPA in pod 3 → consider expanding to pod 5"

### Step 6: Quarterly Format Review (Dara's discipline)
Schedule quarterly format scan:
- Which archetypes are decaying (move to maintenance)
- Which archetypes are emerging (allocate test budget)
- Which messaging strategies are MMF-aligned (per Vince's diagnostic)
- Which pods are over/under-performing per format

### Step 7: Decision Authority
Define who decides what:
- **Strategist**: format selection per concept (within pod's assigned formats)
- **Pod lead**: kill/launch decisions per concept
- **Cross-pod senior strategist**: format archetype strategy across pods
- **Vince/CEO equivalent**: quarterly format scan + matrix expansion decisions
