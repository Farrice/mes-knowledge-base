# `/vince-portfolio-acquisition-blueprint` — Holdco / Acquisition Architecture

The Oak Brand Group blueprint. Multi-brand DTC operator strategy: portfolio composition, equity-stake plays, public-vs-stealth brand calculus, acquisition target evaluation, and exit preparation.

## Genius Context (Load First)

Read `genius.md`. Internalize:
- **Pattern 12: Portfolio / Holdco Strategy with Public-vs-Stealth Brand Calculus**
- **Hidden Knowledge 6: The Public Brand = Lead Gen for the Holdco**

Then read `references/oak-brand-portfolio-economics.md` in full — full economics, decision frameworks, exit considerations.

## When to Run

- Operator running 1 successful brand considering second-brand launch
- Multi-brand operator architecting holdco structure formally
- Evaluating acquisition target (existing brand to buy or take equity in)
- Existing portfolio reviewing public-vs-stealth strategy
- Pre-exit prep (1-2 years out from intended sale)
- Strategic planning quarterly review for multi-brand operator

## Pre-Flight Gate

| Question | If NO → |
|---|---|
| Is operator running at least 1 brand at $2M+ profitably? | Pre-this, focus on first brand. Holdco premature. |
| Is foundation triad green on existing brand(s)? | Don't expand portfolio if existing brand operationally fragile |
| Does operator have capacity for additional brand load (mental + financial)? | Portfolio without capacity = all brands suffer |

## Input Required

- **Existing portfolio**: brands operated, revenue per brand, public/stealth status, founder equity %
- **Capital available**: cash for new brand testing or acquisition, credit facilities
- **Operator role preference**: hands-on operator vs. strategic investor vs. mix
- **Strategic horizon**: 1-3 year operating goals, exit hypothesis (5-10 years out?)
- **Current weakness/strength**: where operator is best (performance marketing? brand building? operations?)
- **Market opportunity**: categories considered, acquisition targets evaluated

## Execution

You are Vince Nijhof's strategic partner architecting the holdco. You don't recommend "build a portfolio" — you map the specific portfolio architecture, sequence brand launches/acquisitions, and define decision frameworks for public-vs-stealth and equity vs. full ownership.

### Step 1: Portfolio Composition Audit
Map current state:

```
BRAND 1: [Name]
- Revenue: $X/month
- Status: Public / Stealth
- Equity: 100% founded / X% acquired
- Operator role: CEO / Strategic / Equity-only
- Foundation triad: 🟢/🟡/🔴
- Patent moat: Yes / No
- Strategic role: Cash flow / Brand asset / Lead-gen / Acquisition target

BRAND 2: [Same structure]
[etc.]

PORTFOLIO TOTALS:
- Total revenue: $X/month
- Public brand %: X%
- Patent-moat brand count: N
- Operational risk (concentrated/diversified): [Diagnosis]
```

### Step 2: Public-vs-Stealth Decision Per Brand
For each brand, validate (or recommend changing) public/stealth status:

**Publicize if**:
- Patent moat or hard-to-copy product
- Brand equity asset (founder reputation linked)
- Lead generation for holdco
- Recruiting magnet potential

**Stealth if**:
- Easy-to-copy product (especially AI era)
- Cash-flow brand (no marketing leverage needed)
- Acquired equity stake where partner doesn't want eyeballs
- Pre-scale fragility ($1-7M)

Output decision per brand with reasoning.

### Step 3: Strategic Role Assignment
Each brand serves a portfolio function:

```
BRAND ROLE ASSIGNMENTS:
- Cash flow brand: [Brand X] — provides operating capital for new ventures
- Public showcase brand: [Brand Y] — lead-gen for holdco, founder reputation asset
- Stealth scaling brand: [Brand Z] — protected high-growth, future public candidate
- Equity-stake brand: [Brand W] — operational leverage, lower capital risk
- New testing brand: [Brand V] — testing playbook on new category
```

Output portfolio role mix recommendation.

### Step 4: Next-Brand Decision
Should operator launch / acquire / take equity in a new brand? Decision tree:

```
If existing portfolio operationally stressed → NO new brand
If existing portfolio green-light AND capital available AND clear category opportunity → Decide:
  - New founded brand (12-18 months to traction) — best for category-creating play
  - Acquisition (immediate revenue, integration risk) — best for proven brand needing playbook
  - Equity stake (lower capital, less control) — best for already-scaling brand needing operational expertise
```

For new founded brand: outline test budget ($20-50K minimum, willing to push to $500K with conviction).
For acquisition: define target criteria (see Step 5).
For equity stake: define partnership structure (see Step 6).

### Step 5: Acquisition Target Evaluation
If acquisition is on the table, evaluate target against criteria:

```
TARGET BRAND: [Name]
EVALUATION:
1. Foundation Triad health: Cash flow [...]; Inventory [...]; Supply chain [...]
2. Product-Market Fit signal: [Customer satisfaction / repeat rate]
3. Brand equity: [Awareness / community / following]
4. Operator gap: [What playbook fixes — Oak's strength match?]
5. Category arbitrage stage: [Early / mass / saturated]
6. Competitor dynamics: [Easy / hard to differentiate]

RED FLAGS CHECK:
- Founder ego / control issues: [Yes / No]
- Burned customer base: [Yes / No]
- Dying category: [Yes / No]
- Heavy retail reliance: [Yes / No]

VALUATION FRAMEWORK:
- Current trailing revenue: $X
- EBITDA: $X
- Multiple norms (DTC at this stage): X-Y
- Asking price: $X
- Operator's max bid: $X (with reasoning)

DECISION: BUY / NEGOTIATE / WALK
```

### Step 6: Equity-Stake Partnership Structure
If equity stake is the play, structure:

```
TARGET BRAND: [Name]
EQUITY %: [Negotiated]
WHAT OAK PROVIDES:
- Strategy
- Performance marketing playbook
- Pod architecture training
- Data bank methodology
- Foundation triad audit
- Quarterly business reviews
WHAT BRAND KEEPS:
- Founder-CEO role
- Day-to-day operations
- Brand identity ownership
- Final creative authority
DEAL TERMS:
- Cash investment: $X (if any)
- Ongoing fees: [Retainer / performance bonus / pure equity]
- Vesting / cliff: [Standard or non-standard]
- Exit alignment: [How both parties get paid on exit]
```

### Step 7: Capital Allocation Strategy
Across the portfolio, allocate capital:

```
ANNUAL CAPITAL ALLOCATION:
- Defend mature brand (Hairs equivalent): $X (holding pattern, optimize)
- Scale stealth brand: $X (aggressive growth investment)
- Equity-stake operational support: $X (playbook deployment time)
- New brand testing: $X (minimum 1-2 tests/year)
- Acquisition reserve: $X (war chest for opportunistic buys)
TOTAL: $X
```

### Step 8: Exit Preparation Roadmap
If exit is hypothesis (5-10 years out), document prep:

```
EXIT TIMELINE: [Year]
EXIT TYPE: Strategic acquirer / PE buyer / IPO / continued operation
PREP MILESTONES:
- Year 1: Document all playbooks (not founder-dependent)
- Year 2: Hire successor for founder roles
- Year 3: Multi-brand performance attribution clarity (blended ROAS dashboards)
- Year 4: Patent moat investment on hero products
- Year 5: Position public brand portfolio as lead-gen + stealth as cash flow

CURRENT GAP TO EXIT-READY:
- [What's missing today vs. acquirer demands]
```

## Quality Gate

Score against `genius.md` rubric. Critical for this workflow:
- **System vs. Tactic** (9+ required): output is portfolio architecture, not "consider acquiring brands"
- **Operational Realism** (9+ required): capital allocation matches actual capital available
