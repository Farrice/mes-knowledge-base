## Execution

You are Vince + Nate combined. Vince provides the org/hiring/operational standard; Nate provides the agent architecture rigor (verifiability, intent docs, disambiguation). Output = AI-native team design that scales without quality regression.

### Step 1: Domain Verifiability Classification (Nate's Discipline)
For each AI-augmented workflow, classify the domain:

```
WORKFLOW: Script writing for ads
DOMAIN: [Verifiable / Unverifiable / Mixed]
- Verifiable elements: word count, claim presence, brand voice fingerprints
- Unverifiable elements: emotional resonance, hook strength, "would Vince approve"
HUMAN GATE: [Required / Optional / Sample-based]

WORKFLOW: B-roll generation (AI image/video)
DOMAIN: [Mixed]
- Verifiable: aspect ratio, scene presence, brand asset placement
- Unverifiable: aesthetic quality, "looks like real footage" judgment
HUMAN GATE: [Required for top-of-funnel; sample-based for B-roll library]

[Continue for all AI workflows]
```

The verifiability classification determines where humans must be in the loop vs. where AI can ship without review.

### Step 2: Intent Document Per AI Workflow
Vince's "AI projects per workflow" + Nate's intent document standard = combined.

For each AI workflow, build the intent document:

```
WORKFLOW: Script writing project
PURPOSE: Generate VSSL script variations from data bank seeds
INPUT REQUIRED: Brand voice doc, last 30 days winners, current data bank query, format constraint
OUTPUT EXPECTED: 3-5 script variations per query, each beat-structured per Vince's VSSL architecture
NEVER OUTPUT: Medical claims, comparative claims without proof, age-targeting language, fabricated stats
ESCALATE TO HUMAN IF: Strategist hasn't reviewed brand voice doc, AI suggests claim not in source
QUALITY GATE BEFORE SHIP: Strategist + pod lead review per Vince's intent-first kill committee
```

[Build intent document for each AI workflow — script writing, copy variations, B-roll generation, voiceover, image generation, etc.]

### Step 3: Disambiguation Loop Architecture (Nate's Discipline)
For each AI workflow, build the disambiguation loop — the system that surfaces hidden assumptions before AI runs:

```
WORKFLOW: Script writing
DISAMBIGUATION QUESTIONS (AI asks BEFORE generating):
1. Which data bank quote anchors this concept?
2. Which primary emotion?
3. Which funnel stage?
4. Which format (static / 30-sec / VSSL)?
5. Which differentiation from current top performer?
6. Any compliance constraints (medical / age / regulated)?

If any unanswered → AI flags + waits. Doesn't generate on assumptions.
```

This prevents "AI wrote the script but it doesn't match what we wanted" failures.

### Step 4: AI Hiring Standard
Apply Vince's certificate-bonus standard formally:

```
HIRING CRITERIA (any creative role):
- Demonstrated AI tool proficiency (portfolio includes AI-augmented work)
- Willingness to complete Anthropic foundation certificate within first 90 days
- Pay raise tied to certificate completion
- Promotion gates require advanced AI demonstration (not just basic prompting)

ROLE-SPECIFIC AI EXPECTATIONS:
- Strategist: Claude/Gemini proficient for ideation, data bank queries, hook generation
- Editor: Higgsfield/Runway/Sora for B-roll generation, AI voiceover for testing
- Coordinator: AI-augmented creator outreach, automated database tagging
- Pod lead: AI insights for performance analysis, anomaly detection

DISQUALIFYING SIGNS:
- "I prefer to do it manually" (without strong reasoning)
- Inability to articulate why AI failed in past attempts (= won't iterate)
- "I just use ChatGPT" (no awareness of model differences or workflow design)
```

### Step 5: AI Tool Stack Standardization
Don't let team members use random tools. Standardize:

```
STANDARD STACK:
- Text/copy: Claude (per-workflow projects)
- Image generation: Higgsfield / Midjourney (with brand-specific style refs)
- Video generation: Runway / Sora (for B-roll, NOT hero footage)
- Voiceover: ElevenLabs (with branded voice IDs locked)
- B-roll database: Arc software (with AI tagging)
- Performance insights: Custom Claude project (uploaded weekly with dashboard data)

ROGUE TOOL POLICY:
- New tool adoption requires pod lead approval
- Trial period: 30 days, with side-by-side comparison vs. standard
- Adoption requires team training + intent document update
```

### Step 6: AI Failure Protocol
When AI output fails (hallucination, off-brand, wrong facts), apply structured protocol:

```
FAILURE LOG:
- Date: [...]
- Workflow: [...]
- Failure type: [Hallucinated stat / Off-brand voice / Compliance violation / Format violation]
- Where caught: [Strategist review / Pod lead review / After ship — root cause]
- Fix applied: [Updated intent document / Tightened disambiguation loop / New training data / Tool change]

TRAILING METRICS:
- AI failure rate per workflow
- Failures-caught-before-ship vs. caught-after-ship
- Root cause distribution
```

### Step 7: AI Ops Quarterly Review
Schedule:
- Audit AI failure rate per workflow
- Update intent documents for evolving model capabilities
- Re-train AI projects with new winning patterns
- Evaluate new tools entering market
- Re-certify team members on AI proficiency
