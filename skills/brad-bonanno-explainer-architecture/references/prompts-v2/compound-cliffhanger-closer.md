# Brad Bonanno — The Compound Cliffhanger Closer

## Role & Activation

You are scripting the closing 60-100 seconds of an explainer video using Brad Bonanno's Compound Cliffhanger Architecture (Pattern 6) — the structural move that turns a single tutorial into a channel-building artifact. The video must do two things without contradiction: CLOSE one loop (the viewer can ship and use the skill they just learned, standalone, no asterisks) AND OPEN a bigger promise (a system 5-10x more valuable that this skill plugs into) that only the NEXT video explains. Reference exemplar: Brad's Obsidian Tease (frame 75) — a dense, unannotated graph-view of his second-brain system shown alongside the just-taught skill, narrated with deliberate repetition ("more and more... better and better") that creates the FEELING of compounding without explaining the mechanics.

**Skip this workflow** if the video is a standalone evergreen piece with no channel-building intent — write a clean CTA close instead.

## Input Required

- **[VIDEO CENTRAL SKILL]**: 1 sentence — what the viewer just learned; must be genuinely ship-able as a standalone capability
- **[BIGGER SYSTEM]**: the larger system this skill plugs into — must be genuinely 5-10x more valuable, already documented or buildable (you're committing to make a video about it), and visually demonstrable (has a dashboard, graph, or interface)
- **[NEXT VIDEO STATUS]**: exists and is linkable now, OR on the roadmap (subscribe to be notified)
- **[CHANNEL POSITIONING]**: teach-by-systems creator or teach-by-tools creator (affects framing)
- **[VISUAL ASSET FOR THE TEASE]**: a real dashboard/graph/interface to film — if none exists, note that one needs to be built before this close can be shot
- **[SPECIFIC ANECDOTE]**: one concrete, real example from actual usage of the bigger system (load-bearing — the tease fails without it)

## Execution Protocol

**Phase 1 — The Closure Beat (15-20s).** The viewer must FEEL the skill is complete and ship-able BEFORE the pivot opens — otherwise the cliffhanger reads as bait-and-switch. Structure: "You can ship [skill] right now. Here's what you have." → quick recap of 2-3 things they can now do. Tone: confident, declarative. Anti-pattern: never say "but this is just the beginning" — that signals the skill itself is incomplete, which breaks trust in everything that follows.

**Phase 2 — The Pivot Beat (5-10s).** The transition from "skill is done" to "but here's what made me obsessed." Structure: personal hook → what changed when you combined this skill with the bigger system → name the system without explaining it. Tone: genuine surprise, vulnerability over salesmanship — "I wasn't planning this" beats "and that's why you need."

**Phase 3 — The Bigger Promise Tease (30-45s).** The longest, most important beat. Show without explaining.

Dashboard Tease Frame design: left pane = the bigger system's UI (dashboard, graph view, interface) showing RICH visual complexity — dense, many data points, intentionally intriguing; right pane = the current skill's UI shown feeding INTO the system (familiar, from earlier in the video); PIP = creator bottom-left, small (HK2). No labels, no annotations — visual complexity itself should produce "wait, what IS that?" Never explain the mechanics here; that's what the next video is for.

Narration structure: name the system → describe its scope without explaining mechanics → name the use cases that make it valuable → land ONE specific, real anecdote (the load-bearing concreteness — without it the tease is abstract and forgettable) → optionally use Brad's compounding-repetition device ("more and more... getting better and better... automatically") to create the feeling of compounding without requiring explanation.

**Phase 4 — The Explicit Handoff (10-15s).** State plainly that the bigger system is "a video on its own" (signals dedicated legitimate treatment, not an afterthought), frame the next step as viewer-controlled ("if that's where you want to take this"), and give an explicit pointer ("it's linked up here" + end-screen card).

**Phase 5 — The Subscribe Close (5-10s).** Standard end-screen mechanics: subscribe button, "Watch Next" thumbnail pointing to the specific next video, creator PIP in branded card. Keep it short — the cliffhanger did the conversion work; the outro is just the click target. Don't over-engineer it.

**Phase 6 — Total Length Audit.** Closure 15-20s + Pivot 5-10s + Tease 30-45s + Handoff 10-15s + Subscribe 5-10s = target 60-100s total. Over 100s: the tease is over-explaining — cut. Under 60s: closure or tease is rushed — expand, most often the tease (it's the beat doing the actual conversion work).

## Output Contract

One closing script covering all 5 beats, each with verbatim narration (not paraphrased placeholders), a fully specified Dashboard Tease Frame (left pane / right pane / PIP position / visual-complexity level / confirmation of zero annotations), and a completed audit-checks table. Total runtime must land in the 60-100 second range with each beat's duration stated.

## Quality Gate

- Does the closure beat treat the standalone skill as fully complete — zero "but this is just the beginning" language?
- Does the pivot read as a genuine personal hook rather than a sales transition?
- Does the tease SHOW the bigger system (dense visual, real UI) without any explanatory annotation or labeled callout?
- Does the tease include one concrete, real, specific anecdote — not a generic claim standing in for one?
- Is the handoff explicitly viewer-controlled, with a clear pointer to a specific named next video (not "more content coming")?
- Does total runtime land in the 60-100 second range with no single beat starved to fit?

## Creative Latitude

The floor is structural: closure-before-pivot ordering, unannotated tease visual, one real anecdote, viewer-controlled handoff framing. None of that constrains voice. Push on: (1) the pivot's emotional register — "I wasn't planning this" vs. "here's the part I held back" carry different vulnerability textures; pick whichever is true to the actual moment, don't default to Brad's exact phrasing; (2) the anecdote — the more specific and slightly odd it is (Brad's "reminded me about a follow-up from three months ago"), the harder it works; resist the instinct to generalize it into something more "impressive" but less concrete; (3) whether the compounding-repetition device ("more and more... better and better") fits this creator's voice at all — it's Brad's signature move, not a universal requirement; a flatter, plainer register can out-perform it if that's the creator's real voice.

## Deploy When

Given a just-taught skill, a genuinely bigger system it plugs into, and the next video's status, a creator needs a fully scripted 60-100 second close that converts standalone viewers into subscribers without feeling like a bait-and-switch.
