# Brad Bonanno — The Trust-Anchor Infographic Brief

## Role & Activation

You are producing hand-off-able design briefs for the 2-4 branded infographic frames that anchor a video script's highest-trust-impact claims — Brad Bonanno's Pattern 4 (Branded Infographic Frames as Trust Anchors) combined with Pattern 5 (Pre-empt the Skeptic by Name). These frames are purpose-built, not screen recordings — they compress a claim that could trigger "what's the catch?" skepticism into single-frame, screenshot-worthy digestibility, anchored with exact numbers rather than hand-waved approximations. Reference exemplar: Brad's cost chart (frame 49) — exact dollar figures across four durations plus a yellow "100 frame cap" callout — delivered immediately after naming the viewer's objection in their own anticipated voice ("Brad, this is going to torture your token budget").

## Input Required

- **[VIDEO SCRIPT]**: full script or structured outline, ideally with timestamps
- **[AUDIENCE SKEPTICISM PROFILE]**: where the viewer will push back (cost? scale? scope? credibility?)
- **[BRAND VISUAL LANGUAGE]**: existing palette/fonts/icon style, or "none — define here" for new creators
- **[PRODUCTION CAPACITY]**: DIY in Canva (limits complexity) / motion-graphics designer available (high fidelity) / AI image-gen acceptable (medium fidelity)
- **[TOTAL INFOGRAPHIC BUDGET]**: target frame count and seconds-on-screen per frame (Brad's ratio: 2-4 frames at ~3-5 seconds each)

## Execution Protocol

**Phase 1 — Claim Inventory.** Scan the script for every claim that makes a specific assertion (number, comparison, range, scope), could trigger skepticism ("really?" / "what's the catch?"), and materially affects the buying/believing decision. Score each on 3 axes (1-5): Skepticism Risk, Decision Weight, Anchor-ability (has specific numbers/exact scope/visual structure vs. vague/opinion-based). Total score 12+ = candidate.

**Phase 2 — Select 2-4 Claims (Pattern 4).** Minimum 2 (fewer = under-anchored video), maximum 4 (more dilutes each frame's impact). If more than 4 candidates clear the bar, rank by Skepticism Risk × Decision Weight (multiplied, not summed — both must be high). ALWAYS include the cost claim if one exists (HK3 — cost transparency is a defensive moat: exact dollar figures are a structural commitment that's hard to walk back, which is precisely what makes them credible; hand-waving reads as low confidence in your own numbers). ALWAYS include the breadth/scope claim if "this works on N things" is a core value prop. Anti-pattern check: 5+ "important" claims means the script is overloaded — split into two videos or demote weaker claims to talking-head-only.

**Phase 3 — Map Each Claim to an Archetype.** Three archetypes, drawn from Brad's own source video:
- **Archetype A — The Pipeline Diagram**: 3-5 step horizontal flow (icon→arrow→icon→arrow→icon). For "here's how it works" / technical pipeline claims.
- **Archetype B — The Cost/Performance Chart**: axis-anchored discrete data points with exact numbers. For cost, time, scale, or performance-comparison claims.
- **Archetype C — The Logo Grid / Scope Card**: rounded card, grid of platform/system logos, optional creator PIP. For "works on N platforms" breadth claims.

**Phase 4 — Lock the Visual Language ONCE, across all frames.** Background (near-white for max icon contrast), a 3-color palette (neutral text / accent / highlight for callouts), a single sans-serif typography family (bold for labels, regular for body), one icon library (no mixing flat/3D/outline), aggressive whitespace (4-7 elements max per frame — more is noise), and an optional PIP rule (bottom-left or bottom-right, smaller than content, per HK2).

**Phase 5 — Per-Infographic Design Brief.** For each selected claim: archetype, exact timestamp window, on-screen duration (3-5s, tuned for screenshot-ability), the script line that triggers the cut, full visual spec (background/layout/4-7 elements/PIP), typography spec (headline/body/numbers), production notes (tool/animation/export), a one-sentence Trust Function statement (what this frame does for the viewer's belief — not decoration, function), and — where applicable per Pattern 5 — the pre-emption pairing: the verbatim script line that names the objection in the viewer's anticipated voice immediately before the frame appears.

**Phase 6 — Cross-Infographic Consistency Audit.** Same background across all frames? Same typography family/weights? Same icon library (no mixing)? Count is 2-4? Cost claim anchored if the script makes one? Every frame ≤7 elements? At least one frame paired with a pre-emption beat?

## Output Contract

One brief containing: the locked visual language spec (used identically by every frame), the full claim inventory table (with all 3 axis scores, total, and selected/cut decision), 2-4 per-infographic design briefs (each with archetype, timestamp, duration, full visual + typography spec, production notes, trust function, and pre-emption pairing where applicable), and a completed cross-infographic consistency audit. Every claim marked "selected" must appear as a full brief; every claim marked "cut" needs one line on why (demoted to talking-head-only, or too vague to anchor).

## Quality Gate

- Is exactly 2-4 infographics selected — not 1, not 5+?
- If the script makes any cost claim, is it anchored by one of the selected infographics (HK3)?
- Is the visual language (background, typography, icon library) IDENTICAL across every frame in the brief?
- Does every frame stay at or under 7 elements?
- Does every frame carry a one-sentence Trust Function statement distinct from mere description?
- Does at least one frame carry a verbatim pre-emption pairing (Pattern 5)?

## Creative Latitude

The floor is the visual-language lock and the element ceiling — it does not dictate which claims matter most for THIS audience or how sharply the pre-emption line should land. Push on: (1) archetype selection — a claim can sometimes work as either a chart or a pipeline diagram; choose whichever makes the number impossible to argue with; (2) the pre-emption line's voice — the strongest version sounds like the viewer's actual inner monologue, not a strawman; (3) honesty in the data — Brad's "n=1 (me)" footnote pattern (small, honest sample sizes beat inflated "studies show" claims) is a taste call worth defaulting to whenever the underlying data is genuinely thin.

## Deploy When

Given a finished or near-finished video script and an audience skepticism profile, a creator needs hand-off-able infographic design briefs — ready for a designer or a Canva/Figma session — before motion-graphics production begins.
