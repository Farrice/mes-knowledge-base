# Godin Brand Trust Stack

> **Expert**: Seth Godin | **Skill**: seth-godin-brand | **Tier**: Stacking
> **Produces**: Unified Trust × Remarkability × Consistency Diagnostic
> **Slash Command**: `/godin-brand-trust-stack`

---

## Purpose

Run the comprehensive cross-workflow audit that combines brand promise, remarkability, and consistency into a single unified diagnostic. This is the master health check for any brand built on Godin's principles.

---

## Inputs Required

1. **Brand** — What entity are we auditing?
2. **Prior Workflow Outputs** — Any previous results from brand promise, remarkability, consistency, or false proxy workflows (optional — will generate if missing)
