## Template 4: Quality Validation Checklist

```markdown
# Output Quality Checklist
## [SYSTEM/USE CASE NAME]

Use before delivering any output from this system.

---

## Structural Validation
□ All required sections present
□ Logical flow maintained
□ Appropriate length achieved
□ Format specifications met

## Content Validation
□ Claims are supportable
□ Examples are concrete
□ Advice is actionable
□ No filler or padding

## Voice Validation
□ Matches target tone
□ No banned phrases used
□ Authentic to brand
□ Appropriate energy level

## Technical Validation
□ No hallucinated facts
□ No logical contradictions
□ Citations accurate (if applicable)
□ Technical terms correct

## User Value Validation
□ Answers the actual question
□ Provides clear next steps
□ Respects user's time
□ Would they pay for this?

---

## Scoring

- 5/5 sections pass: Ship it
- 4/5 sections pass: Minor revision
- 3/5 sections pass: Significant revision
- Below 3/5: Regenerate with adjustments
```
