# Workflow 01: Resistance Diagnosis & Breakthrough

> **Prerequisite**: Load [genius.md](../genius.md) before running this workflow.
> **Uses**: Patterns 1, 2, 3, 12, 14 + Tacit Knowledge 1, 4, 5

## When to Use
- You're stuck, procrastinating, or avoiding something you know matters
- You can't figure out why you won't start
- A project has stalled and "I'll get to it tomorrow" has been running for weeks

## Produces
1. Resistance Diagnosis (root cause identification)
2. Fear Chain Trace (the irrational cascade made visible)
3. Story Mode Check (architect vs victim)
4. Hiding Spot Audit (excuse structure analysis)
5. Breakthrough Action Protocol (specific next steps)

---

> **🔒 Pre-Flight Gate**: Before executing, run the **Decision Framework** in `genius.md` § Decision Framework. Confirm all diagnostic questions are answered.


## Phase 1: Name the Resistance

### Step 1: Identify the Stuck Point
Tell me what you're avoiding, procrastinating on, or can't seem to start. Be specific:
- What is the thing? (Not "be successful" — the actual deliverable)
- How long have you been avoiding it?
- What happens in your body/mind when you think about doing it right now?

### Step 2: Trace the Fear Chain (Pattern 14)
Complete the cascade:
```
I will [attempt the thing]
→ and then [what could go wrong?]
→ which means [what would that mean about me?]
→ so people would [how would others react?]
→ and I would be [end state]
```
Example: "I'll publish the article → someone might criticize it → which means I'm not good enough → so people would see I'm a fraud → and I would be humiliated and alone."

**Notice**: The chain almost always ends in some version of abandonment/death. That's not rational — that's the lizard brain running a 2-second fear cascade from lipstick to death. Name the absurdity: "I traced my fear of publishing a LinkedIn post all the way to dying alone. That's the resistance talking."

### Step 3: Story Mode Check (Tacit Knowledge 1)
Which story are you waking up in?
- **Architect Story**: "The circumstances aren't ideal AND I can change them." (This is the productive frame)
- **Victim Story**: "I can't control this. The world is happening TO me." (This needs to be exited before any strategy work)

If you're in Victim mode, the first breakthrough isn't tactical — it's narrative. Rewrite one sentence about your situation using "and" instead of "but."

## Phase 2: Diagnose the Root

### Step 4: Fear-Status-Affiliation Triad (Pattern 2)
Which of these three forces is driving the avoidance?

| Force | Sounds Like | Feels Like | Example |
|-------|------------|------------|---------|
| **Fear** | "What if I fail?" / "What if they judge me?" | Pit in stomach, physical avoidance | Won't publish because of criticism risk |
| **Status** | "They're ahead of me" / "I'm not at that level yet" | Comparison, competition, envy | Won't start because others are already doing it better |
| **Affiliation** | "People like me don't do that" / "My friends will think it's weird" | Need to belong, fear of standing out | Won't launch because your circle doesn't value entrepreneurship |

**CRITICAL**: The driver determines the intervention. A fear problem cannot be solved with status tools. Name the primary driver. If two are present, identify which is primary.

### Step 5: Problems vs Situations Triage (Pattern 3)
Classify the obstacles:
- **Problem**: Has a solution you might not like → ACTION PLAN
- **Situation**: Unchangeable like gravity → ACCEPT AND DESIGN AROUND

Common misclassifications:
- "I don't have time" — Usually a PROBLEM (you do have time, you're choosing to spend it elsewhere)
- "The market is saturated" — Sometimes a PROBLEM (niche down), sometimes a SITUATION (accept the competition)
- "I don't have credentials" — Usually a PROBLEM (pick yourself—Pattern 6)
- "I'm in my 40s" — SITUATION (accept it) AND a PROBLEM-solver (experience is leverage)

## Phase 3: Audit the Hiding Spots

### Step 6: Hiding Spot Audit (Tacit Knowledge 5)
The system wants you to hide (Tacit Knowledge 4). Check each item:

| Hiding Spot Pattern | Your Version? | Is It Real or Manufactured? |
|--------------------|--------------|-----------------------------|
| "I need more training/credentials first" | | |
| "I'm waiting for someone to notice me" | | |
| "I need X followers/subscribers/clients first" | | |
| "I tried and it didn't work (so I stopped)" | | |
| "The timing isn't right" | | |
| "I need to figure out the perfect version first" | | |

**Test**: If the hiding spot disappeared overnight, would you be forced to ship? If yes — it was a hiding spot, not a barrier.

## Phase 4: Build the Breakthrough

### Step 7: Design the Micro-Action (Pattern 6 + Tacit Knowledge 3)
Seeds don't bloom in bags. Your idea needs air.

Design one action that is:
- Completable in under 2 hours
- Ships something to at least 1 other human
- Cannot be "more research" or "planning" (that's hiding)
- Uncomfortable enough to trigger mild resistance (that's the signal it matters)

Format:
```
MICRO-ACTION: [What exactly you will do]
SHIPS TO: [Who will see it — by name if possible]
COMPLETION TIME: [Max 2 hours]
DEADLINE: [Today or tomorrow — no "next week"]
```

### Step 8: Name the Resistance Out Loud (Pattern 12)
Before executing, say this out loud (or write it down):
"I am avoiding [the thing] because I am afraid of [the named fear]. That fear traces to [the cascade end point]. I am naming it so it loses power. I'm doing it anyway."

### Step 9: Deploy the Cohort (Tacit Knowledge 7)
Send this to 1-3 people you trust:
"I just committed to [micro-action] by [deadline]. I need you to ask me if I did it. Hold me accountable."
