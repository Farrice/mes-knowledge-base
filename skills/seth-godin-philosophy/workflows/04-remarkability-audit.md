# Workflow 04: Remarkability Audit

> **Prerequisite**: Load [genius.md](../genius.md) before running this workflow.
> **Uses**: Patterns 5, 7, 8, 10, 12 + Tacit Knowledge 5, 8

## When to Use
- You have a product, service, post, or piece of content and want to know if people will care
- Something you made isn't getting traction and you don't know why
- You need to decide whether to iterate or pivot
- You want pre-launch validation on whether the work is worth shipping

## Produces
1. Remarkability Assessment (would someone remark about this to someone else?)
2. "Purple Cow" Diagnostic (what's unremarkable and why)
3. Generous Work Check (is it serving or performing?)
4. Improvement Plan (specific changes to make it remarkable)
5. Spread Potential Score (will it move without paid distribution?)

---

> **🔒 Pre-Flight Gate**: Before executing, run the **Decision Framework** in `genius.md` § Decision Framework. Confirm all diagnostic questions are answered.


## Phase 1: Define Remarkable

### Step 1: The Core Test
"Remarkable" literally means "worth making a remark about." That's it. Not impressive. Not perfect. Not viral. Just: would someone tell someone else about this?

State what you've made:
- What is it? (Be specific)
- Who is it for? (SVA — Pattern 5)
- What change does it create? (Pattern 7)

### Step 2: The Remark Test
Imagine your SVA person encounters this. Would they:

| Scenario | Yes/No | Evidence |
|----------|--------|----------|
| Tell a friend about it unprompted? | | |
| Screenshot it and send to someone? | | |
| Bookmark/save it for later? | | |
| Come back to it a second time? | | |
| Remember it a week later? | | |

**Scoring**:
- 4-5 Yes → Remarkable. Ship and amplify.
- 2-3 Yes → Almost. Needs specific sharpening (go to Phase 2).
- 0-1 Yes → Not remarkable yet. Needs fundamental redesign (go to Phase 3).

---

## Phase 2: Diagnose the Unremarkable

### Step 3: The Purple Cow Diagnostic
Why isn't it remarkable? Check each dimension:

| Dimension | Question | Status |
|-----------|----------|--------|
| **Specificity** | Is it for a specific person or "everyone"? | Too broad / Just right / Named person |
| **Tension** | Does it create a gap between where they are and where they want to be? | No tension / Some / Strong |
| **Newness** | Does it offer a perspective, angle, or approach they haven't seen? | Derivative / Fresh twist / Genuinely new |
| **Stakes** | Does something actually matter if they engage with this? | Low stakes / Moderate / High |
| **Generosity** | Would they feel genuinely served, not sold to? | Feels like marketing / Neutral / Feels like a gift |
| **Emotion** | Does it trigger an emotional response? (surprise, anger, delight, recognition) | Flat / Mild / Strong |

### Step 4: The "But" vs "And" Scan (Pattern 4)
Look at how you describe the work. Find every "but":
- "It's good BUT the market is crowded" → "It's good AND the market is crowded" (so differentiate)
- "People need this BUT they don't know it yet" → "People need this AND they don't know it yet" (so start with awareness)

Each "but" reveals a design constraint you're treating as a fatal flaw. Turn it into a design input.

### Step 5: The Hiding Check (Tacit Knowledge 5)
Is unremarkable-ness a feature, not a bug? Check:
- Did you intentionally make it safe to avoid criticism?
- Are you playing to not lose instead of playing to win?
- Is "good enough" your actual goal (hiding) or your minimum spec (shipping)?

---

## Phase 3: Build Remarkable

### Step 6: The Remarkability Lever Map
For each weak dimension from Step 3, design a specific intervention:

```
REMARKABILITY IMPROVEMENT PLAN
══════════════════════════════
Weakest dimension: [from Step 3]
Current state: [what it is now]
Remarkable state: [what it needs to become]
Specific change: [the actual edit/redesign]
Time required: [hours, not days]
```

Repeat for each weak dimension (max 3 — more than 3 means fundamental pivot).

### Step 7: The Generous Ruckus Redesign (Pattern 10)
Reframe the work as a generous act:
- Strip ego: "This exists to serve [SVA], not to make me look good"
- Add surprise: "What could I include that they aren't expecting?"
- Create indebtedness: "What would make them feel compelled to share?"

The best way to be remarkable: be genuinely generous in a world of transactional content.

### Step 8: The Dishwasher Test (Tacit Knowledge 8)
Do you already know what would make this remarkable?

Most of the time, the answer is yes — you know what the work needs. You're just avoiding the 10 minutes (or 2 hours) of uncomfortable work to make the change. Name the known fix. Execute it.

---

## Phase 4: Spread Assessment

### Step 9: Organic Spread Potential
Would this move without money behind it? Check:

| Factor | Present? |
|--------|----------|
| Easy to describe in one sentence | |
| Has a "you need to see this" quality | |
| Makes the sharer look smart/generous by sharing | |
| Works without context (standalone value) | |
| Creates conversation / debate / recognition | |

### Step 10: The 10-Person Test
If you showed this to 10 specific people in your SVA (name them if you can), how many would share it with at least one other person?

- 7-10 → Ship immediately. This spreads.
- 4-6 → Good but not remarkable. Apply Phase 3 improvements.
- 0-3 → Back to Phase 3. Fundamental improvement needed.
