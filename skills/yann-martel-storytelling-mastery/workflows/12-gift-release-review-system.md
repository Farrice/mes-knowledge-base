# Gift Release Review System

## Pre-Flight Gate
Inputs required:
- Work being released.
- Audience or market.
- Review channels or feedback sources.
- Creator's fears or desired outcomes.

Load `../genius.md`.

## Skill Acquisition
Use Martel's gift principle: make the work with full care, give it to the world, and do not demand that the world return the exact response you wanted.

## Execution
1. **Separate Craft From Reception**: List final craft checks that can still be controlled.
2. **Define Release Intent**: State what the work is giving.
3. **Classify Feedback Types**: Prepare for praise or criticism for right or wrong reasons.
4. **Set Response Rules**: Decide what will be used for promotion, learning, repair, or ignored.
5. **Create Release Protocol**: Produce a calm publishing and review-handling sequence.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Book | Separate editorial review from public review |
| Essay | Watch for genuine confusion, not taste mismatch |
| Launch | Use proof for promotion without identity dependence |
| Client Work | Convert feedback into scoped revision decisions |
| Personal Piece | Protect the gift from response addiction |

## Output Requirements
Produce:
- `Final Craft Checks`
- `Gift Statement`
- `Feedback Classification`
- `Response Rules`
- `Release Sequence`
- `Post-Release Boundary`

## Quality Gate
- The creator still improves the work before release.
- Reviews are not treated as identity verdicts.
- Useful feedback has a path.
- The work can leave the creator's hands.
