# Workflow 03: Oral/Written Culture Content Architect

## When to Use
You need a content strategy that goes beyond "post on these platforms." You want format selection driven by cultural mode physics, not guesswork. Content feels generic or cross-posted. Team is producing content that doesn't feel native to any platform.

## Input Required
- Brand/individual/organization being served
- Key messages, positions, or arguments
- Available platforms and team resources
- Content production capacity (weekly output)
- Primary audience and their platform habits

## Steps

### Step 1: Platform-Culture Matrix

Classify every available platform by cultural mode:

| Platform | Culture Mode | Characteristics |
|----------|-------------|----------------|
| X (tweets) | ORAL | Burst emotionality, interpersonal, tribal signaling, 12-hr spike lifecycle |
| X (threads) | HYBRID | Oral hook → written depth transition |
| TikTok / Reels / Shorts | ORAL | Visual burst, identity-triggering, campfire energy |
| Instagram Stories | ORAL | Ephemeral, interpersonal, raw |
| LinkedIn (posts) | HYBRID | Oral opening hook + written-mode depth below the fold |
| YouTube Long-form | WRITTEN | Despite being video — depth, abstraction, sustained engagement, analytical |
| Podcast | WRITTEN | Despite being spoken — long-form logic, evidence-based, highest trust |
| Substack / Blog | WRITTEN | Canonical depth, logical rigor, "change how you think" content |
| Email Newsletter | HYBRID | Written body + oral voice, direct relationship |

### Step 2: Content Library Classification

Sort the brand's key messages into cultural mode:

**Oral-Native Messages** (emotional spike content):
- Identity statements and belief declarations
- Hot takes and strong positions
- Personal stories that trigger emotion
- Tribal signals ("we believe X, they believe Y")
- Controversy-ready positions
- Reaction content to current events

**Written-Native Messages** (depth content):
- Systems thinking and frameworks
- Evidence-based arguments with data
- Multi-step methodologies
- "Change how you think" analytical pieces
- Historical or contextual deep dives
- Technical explanations

**Cross-Mode Messages** (two-stage deployment):
- Big ideas that need emotional hook (oral) + deep argument (written)
- Deploy oral teaser FIRST → drive audience to written deep dive
- Or: written anchor FIRST → extract oral highlights

### Step 3: Production Flow Design

**The Cardinal Rule: Written culture first, oral culture extracted.**

```
PRODUCTION FLOW:

Written Anchor (Day 1-2):
  → Record podcast / Write Substack / Film long-form YouTube
  → This establishes the FULL CONTEXT for all positions

Oral Extraction (Day 2-3):
  → Extract specific moments, quotes, takeaways
  → Produce platform-native short-form for each oral channel
  → Each piece is BORN on its platform, not reformatted

Hybrid Production (Day 3-4):
  → LinkedIn posts: oral hook from extraction + written depth from anchor
  → Email newsletter: written body + oral voice
```

**NEVER reverse this flow.** Complex or controversial positions must NEVER debut in oral-mode format. The long-form anchor is your context-length defense.

### Step 4: Staffing Recommendations

Each platform needs a person (or developed skill) matched to its culture mode:

- **Oral-mode creators**: High energy, reactive, emotionally tuned, trend-aware, comfortable with imperfection
- **Written-mode creators**: Analytical, evidence-oriented, long-form comfortable, depth over speed
- **Hybrid creators**: Can shift registers, good at hooks AND depth

Don't ask an essayist to make TikToks. Don't ask a TikToker to write Substacks.

### Step 5: Weekly Content Calendar

Design the full weekly production calendar organized by culture mode:

| Day | Activity | Culture Mode | Output |
|-----|----------|-------------|--------|
| Monday | Record podcast / long-form video | WRITTEN | Anchor content with full context |
| Tuesday | Publish Substack essay | WRITTEN | Canonical text position |
| Wednesday | Extract tweets + thread from anchor | ORAL extraction | 5 tweets + 1 thread |
| Thursday | Publish long-form YouTube | WRITTEN | Visual depth piece |
| Friday | Extract Shorts/Reels from long-form | ORAL extraction | 3 short-form videos |
| Daily | Reactive tweets on industry news | ORAL (native) | 2-3 reactive posts |
| 3x/week | LinkedIn posts from Substack/podcast | HYBRID | Adapted posts |
