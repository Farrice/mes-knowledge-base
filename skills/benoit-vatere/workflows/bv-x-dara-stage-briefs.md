# BV × Dara Stage Briefs — System Meets Production

## Role
Two seats, one deliverable, dissent preserved. **Benoit** sets the system: stage, one job per unit, buyer-state angle, consistency lock. **Dara Denney** produces inside it: formats, hooks, iteration logic from her ad-creative engine. One author per brief body (Dara); Benoit's constraints ride as the header and the gate — never blended into a consensus voice.

**Pre-Flight Gate**: Read both genius files. Run funnel-creative-map FIRST if no job map exists — this workflow consumes its output, it doesn't recreate it. Where the two experts genuinely disagree (e.g., Dara's volume-testing instinct vs Benoit's hand-picked consistency lock), surface the argument and let Farrice/client pick — consensus-blending is failure.

## Input Required
- **[JOB MAP]**: output of funnel-creative-map (unit jobs + buyer-state ladder)
- **[STAGE PRIORITY]**: which stage needs creative NOW
- **[BRAND LANE + ASSETS]**: the memorability lane, existing winners, brand constraints

## Execution
1. **Benoit's header per brief** (non-negotiable): funnel stage → the ONE job (REMEMBER-NAME / LINK-BENEFIT / RE-ANGLE / WIN-BACK) → buyer state → destination (PDP/retailer per pdp-chain-audit) → the metric the unit is accountable to (per stage: memorability proxy / cost-per-PDP-view / state conversion).
2. **Dara's body per brief**: format selection, hook directions, visual/message territory, iteration plan — from her methodology, in her voice, at her production standard.
3. **The dissent ledger**: where Dara's engine wants breadth (test many) and Benoit's lock wants curation (hand-pick per audience), record both positions + the recommended resolution per stage (typical: breadth WITHIN a stage's job, never across jobs; platform never picks cross-stage).
4. **Gate before handoff**: every brief re-checked against Benoit's one-job rule — a Dara-brilliant hook that smuggles a second job gets rewritten or moved to its right stage.

## Content Type Adaptations
| Context | Emphasis |
|---|---|
| Meta/paid-social consideration | Dara's home turf; Benoit constrains destination + metric |
| CTV/awareness | REMEMBER-NAME job dominant; comedy-lane-style memorability; no benefit content |
| Retargeting batches | RE-ANGLE per objection; each state's brief distinct by design |
| Client delivery | Production-sheet format (per-asset labeled cards, never prose blobs) |

## Output Requirements
Brief pack: per-brief Benoit header + Dara body → dissent ledger with resolutions → gate log (rewrites forced).
Execution prompt: references/prompts-v2/creative-message-ladder.md (headers) — Dara's own prompts drive the bodies.

## Quality Gate
- One author per brief body; headers and bodies never merge voices.
- Zero briefs with a smuggled second job; every brief names its accountable metric.
- Disagreements surfaced as decisions, not averaged away.
