# Preservation Lock — Performance Evidence Journal magic

## Failure classification

- **Primary:** code/workflow regression — the visual-choice surface depended on remote Refero hotlinks that did not render for Farrice.
- **Secondary:** user-facing evidence gap — a recommendation was accepted without inspectable option imagery.

## Preservation Lock

- **Keep:** multi-angle Refero research; unmistakably different territories; one primary source per direction; bounded borrowing; explicit rejects; Premium Minimal as identity owner; one recommended verdict; reference lock before implementation; small-surface build; visual and claim QA; controlled copy-only revision.
- **Change:** make every option locally visible and verified; persist the route and handoffs; add a contact sheet, receipt, cold-start proof, and replay prompt.
- **Do not disturb:** the approved Performance Evidence Journal artifacts, Premium Minimal tokens/components, the protected Angle Map offer facts, proof boundaries, and human promotion authority.
- **Risk:** turning one winning aesthetic into a universal house style, over-systematizing taste, or creating a new mega-skill that competes with Refero and existing brand systems.
- **Gate:** future runs reproduce the process while allowing radically different visual outcomes; no visual verdict is requested unless every option has a verified local preview.

## What the system must reproduce

1. Research breadth before aesthetic commitment.
2. Strong separation between directions.
3. One dominant reference plus narrow borrowed details.
4. A written lock that converts inspiration into decisions.
5. Translation through the existing brand/product context.
6. One or two inspectable production surfaces before expansion.
7. A QA receipt that separates taste, structure, proof, and external action.

## What the system must not reproduce automatically

- scientific-editorial styling;
- the Performance Evidence Journal name;
- monochrome evidence fields;
- Helvetica Neue;
- Premium Minimal tokens;
- Health Performance copy;
- The Angle Map;
- any aesthetic choice that belongs only to the golden example.

The magic is the controlled decision sequence, not a reusable visual costume.
