# Hidden Knowledge

- The most expensive failure in reference-led work happens before production: a reviewer chooses from labels because the actual visual evidence did not render.
- A named direction can feel persuasive enough to conceal that failure. The system therefore treats image visibility as an interlock, not presentation polish.
- The winning reference should govern relationships and roles, not force literal imitation. Copying visible decoration is usually less reusable than preserving hierarchy, pacing, density, and evidence behavior.
- Distinct options need distinct underlying models of attention. If every option asks the eye to move the same way, they are not genuinely different.
- A recommendation should explain strategic fit and system impact. “Looks premium” is not sufficient because it cannot guide later production decisions.
- Existing identity constraints are productive pressure. They force references to contribute craft moves instead of quietly becoming a replacement brand system.
- A good replay artifact includes negative controls: remote-only capture must fail when local evidence is required, and altered checksums must fail verification.
