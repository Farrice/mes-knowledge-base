# Addiction Loop Anatomy — Structural Reference

> Quick-reference for all workflows in the `kallaway-addictive-storytelling` skill domain.

---

## The Four-Step Addiction Loop

```
┌─────────┐    ┌──────────────┐    ┌───────────┐    ┌──────────┐
│  STAKES  │───→│ BIG QUESTION │───→│ HEAD FAKE │───→│  REHOOK  │──┐
│          │    │              │    │           │    │          │  │
│ Brain ON │    │ Dopamine     │    │ Dopamine  │    │ New Loop │  │
│          │    │ Drip         │    │ SPIKE     │    │ Opens    │  │
└─────────┘    └──────────────┘    └───────────┘    └──────────┘  │
     ↑                                                            │
     └────────────────────────────────────────────────────────────┘
                         REPEAT (never stop)
```

## Step 1: Stakes (The Housing)

**Function**: Activates the brain's prediction engine. Without stakes, no predictions fire.

**Three Components**:
| Component | What It Does | Example |
|-----------|-------------|---------|
| **Character** | Someone the viewer can root for | You, your client, "a creator I talked to" |
| **Risk** | Consequence if things go wrong | "About to lose my biggest client" |
| **Urgency** | Time compression multiplier | "Within 48 hours" / "the call was in 2 hours" |

**Critical Rule**: Stakes ≠ drama. Stakes = personally relevant for ideal viewer.

---

## Step 2: Big Question (The Drip)

**Function**: Loads a question the brain wants to solve. Triggers sustained, low-grade dopamine drip.

**Calibration Sweet Spot**:
- Too vague: "Something crazy happened" → brain can't predict → no dopamine
- Too specific: Brain guesses correctly → no prediction error → no spike
- **Just right**: Enough information to form a prediction, not enough to know the answer

**Timing Rule**: Load it as early as possible. Earlier question = longer dopamine drip before reveal.

---

## Step 3: Head Fake (The Spike)

**Function**: Breaks the prediction. Triggers the largest dopamine spike the brain can produce.

**Spike Size**: Proportional to surprise magnitude.
- Small surprise = small spike
- Large surprise = large spike
- No surprise = no spike

**Good vs. Bad**:
| Good Head Fake | Bad Head Fake |
|---------------|--------------|
| Unexpected but immediately logical | Random, comes from nowhere |
| "Oh!" (surprise + understanding) | "Huh?" (surprise + confusion) |
| Clues were embedded in setup | No connection to previous content |
| Magician-quality misdirection | Cheap shock value |

---

## Step 4: Rehook (The Restart)

**Function**: Closes one loop and opens another simultaneously. Zero dead air.

**Connective Phrases**:
- "Which would have been great, except..."
- "But here's the problem with that..."
- "And that's when I realized..."
- "Which is exactly why..."
- "But what I didn't know yet was..."

**Danger Zones**: Every point where one section ends and a new begins. Those are where viewers think "Okay, I'm done."

**The Relay Race Rule**: Both runners must be at full sprint at the point of baton transfer. Momentum never hits zero.

---

## The Casino Governing Metric: Time-Per-Hand

| Casino Metric | Content Equivalent |
|--------------|-------------------|
| Time per hand | Gap between dopamine hits |
| Goal: decrease time between bets | Goal: decrease gap between predictions |
| Result: 6-hour sessions at the table | Result: viewer watches all the way through |

**Benchmarks**:
| Format | Max Gap Without Prediction |
|--------|---------------------------|
| Long-form video | 20-25 seconds |
| Short-form video | 0 (one compressed loop) |
| Sales copy | 2 sentences |
| Email | 1 paragraph |
| Presentation | 1 slide |

---

## Vending Machine vs. Slot Machine Diagnostic

| Dimension | Vending Machine (BAD) | Slot Machine (GOOD) |
|-----------|----------------------|---------------------|
| Outcome | Predictable | Uncertain |
| Dopamine | Zero — brain already knows what happens | Sustained drip + periodic spikes |
| Viewer State | Passive consumption | Active prediction |
| Engagement | Can stop at any time | Chemically locked in |
| Content Signature | "Here's how X works..." → explains it → end | "Here's what happened when..." → prediction → surprise → new question |
| Variable | Nothing | Uncertainty |

## Loop Density by Format

| Format | Loop Cycles | Compression |
|--------|-------------|-------------|
| YouTube long-form (10-15 min) | 4-6 full cycles | Medium — each cycle gets 2-3 minutes |
| YouTube mid-form (5-8 min) | 2-3 full cycles | High — each cycle gets 2-3 minutes |
| Short-form (30-60s) | 1 compressed cycle | Maximum — all 4 steps in under 60 seconds |
| Email (single) | 1 full cycle | Medium — stakes in subject line, rehook drives next email open |
| Email sequence | 1 cycle per email, inter-email rehooks | Low — each email gets a full cycle with cliffhanger |
| Sales page | 3-5 cycles through the page | Medium — each section runs a mini-loop |
| Twitter thread | 1 micro-cycle per 2-3 tweets | High — each tweet transition is a rehook |
| Presentation | 1 cycle per major section | Medium — slides as loop boundaries |
