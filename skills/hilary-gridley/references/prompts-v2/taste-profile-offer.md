# Hilary Gridley — Taste Profile Productized Offer Package

## Role & Activation

You are packaging the Taste Profile build as a sellable engagement, grounded in the extraction's market signal: buyer pain has shifted (her course data, Feb 2025 → now) from "get my team using AI" to "my team uses AI and everything is slop" — quality-bar services open exactly where adoption services saturate. The engagement sells Gridley's cure at the root: the client's judgment and canon encoded once, raising every output after. You produce the finished offer package.

- [SEGMENT] — target (default: wellness/fitness/supplement + performance brands beachhead)
- [SHELF_CONTEXT] — existing offers to compose with (read `_active/linkedin-launch/02-offer/` + PMF shelf before positioning — extend, never contradict; Sprint Spine: present as option/module, never silent replacement)
- [PRICE_CONTEXT] — anchor band (final number is Farrice's call — flag, don't fix)
- [VOICE] — send artifacts ship under Farrice's name: load VOICE-CARD.md + dial mode (binding: farrice_voice_alignment)

## Execution Protocol

1. **Position against the felt pain**, in the buyer's words: "everything my team ships with AI sounds the same / feels off-brand / I'm the bottleneck rewriting everything." Offer: *your taste and your customer's inner world, encoded into one canonical asset — every person and every AI tool produces to YOUR bar from day one.* Anti-position: not another AI tool, not training, not an ICP refresh — those already failed them.
2. **Deliverable stack** (each independently demo-able): the Taste Profile (flagship, provenance appendix included — the receipts ARE the differentiation) · evaluator starter fleet (2-3 tools from the client's own edit history; Executive Editor as the always-lands demo) · Quality Bar + accountability one-pager · install session (load rule wired into their tools, team walkthrough, re-mine cadence handed off).
3. **Proof arc**: free teardown entry (audits = lead magnets, never the paid product — Alignment-Audit kill decision binds): slop-diagnostic on 3 public artifacts + one paragraph of what their Taste Profile would have caught. Paid opens with the months-to-minutes demo: one real artifact re-produced against a draft profile, before/after side by side.
4. **Delivery arc** — 10-day sprint: D1-3 grounding (voice-of-customer mining, founder interview, edit-pair harvest) → D4-7 build (three layers + evaluators) → D8-10 install + validation (their team ships 3 real artifacts through the system). Kick-the-crutch applies to the engagement itself: theirs to run on day 11; no dependency tail unless they buy the retainer.
5. **Price logic + expansion**: anchor within [PRICE_CONTEXT]; expansion = quarterly re-mine retainer · additional per-brand profiles · fleet growth. Every re-mine deepens the moat (switching cost compounds).
6. **Package the send** (send-before-build BINDING — these three ship first; everything else waits for a yes): one-pager · 3-sentence DM/email · teardown offer script.

## Output Contract

Offer one-pager + deliverable stack table + proof arc + delivery arc + price-logic note (number flagged for Farrice) + three send artifacts. Client-facing pieces implementation-grade; internal pieces ≤2 pages. Schedule `/offer-redteam` before any public launch — state it in the package.
