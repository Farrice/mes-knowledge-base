# hg-feedback-script — Break the Binary, Keep the Bar

What to actually say when slop lands on your desk. Her insight: bad/good binary feedback reads as a character verdict and kills iteration. The alternative is graduated language that names the state, matches effort to effort, and returns the work — installing shot → feedback → improve as the way things work.

## Execution

1. **Classify the moment**: first-take slop (effort mismatch) · repeat pattern (bar was never articulated — root problem) · method confusion ("I told them to use AI and now...") · quality dispute (they think it's good).
2. **Build the script from her grammar**:
   - **Name the state, not the person**: "This is a good first start, but it still feels too AI-generated — keep going." Never "this is bad."
   - **Reciprocity line** (effort mismatch): "It doesn't seem like you put a ton of thought into this, so I'm not going to put a ton of thought into it. Take another pass and put your spin on it — then I'll sit down and put mine."
   - **Accountability pivot** (method confusion): move the conversation from how they used AI to what they're accountable for and what good looks like. Include the third-party framing if useful.
   - **Bar gap** (repeat pattern): the honest move is admitting the bar was never stated — schedule `hg-quality-bar`; the script covers the interim.
3. **Add the forward mechanism.** Every script ends with the next concrete pass and who does what: their spin → your spin. If an evaluator tool exists for this artifact, route iteration through it so you stop being the gate.
4. **Calibrate register** to the relationship (direct report / peer / vendor / client) — the grammar holds; the warmth dial moves. Never sarcasm; the reciprocity line is stated plainly, not performed.
5. **Deliver**: the script (2-4 sentences, speakable), a one-line rationale, and the follow-up move if the next pass is still slop (escalates toward accountability contract, never toward tool bans).

## Content Type Adaptations

| Situation | Adaptation |
|---|---|
| Manager → report | Full grammar; pair with bar articulation |
| Peer → peer | Drop the reciprocity line (reads as status grab); keep state-naming + forward mechanism |
| Client → agency/vendor | Accountability language dominates; reference the contracted bar |
| Operator → own AI agents | Scripts become re-prompt patterns: name the failed criteria, demand another pass, never full-rewrite yourself (that's outsourcing your own judgment in reverse) |
