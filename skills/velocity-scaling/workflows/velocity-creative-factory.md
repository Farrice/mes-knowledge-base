# /velocity-creative-factory — Scale Creative Output to 1,500+ Ads

> Build the creative production machine that takes you from 50 to 1,500+ live ads across platforms — Danny Yeung's IM8 creative diversity playbook.

## When to Use
- Running fewer than 50 live ad creatives
- Creative fatigue is killing campaign performance
- Need to scale ad spend but creative production can't keep up
- Want to implement the 75/25 static-to-video ratio
- Setting up a creative testing and kill-rate protocol

## Inputs Required
1. Current number of live ad creatives
2. Current creative production capacity (per week)
3. Ad platforms in use and budget allocation
4. Current static vs. video ratio
5. Creative testing process (if any)
6. Team resources for creative production

## Execution Steps

### Step 1: Current State Audit
Map creative production bottlenecks:

| Metric | Current | Danny Yeung Benchmark |
|---|---|---|
| Live creatives | X | 1,500+ |
| New creatives/week | X | 10+ minimum |
| Static:Video ratio | X:X | 75:25 |
| Time from concept to live | X days | <48 hours |
| Kill rate | X% | Bottom 20% killed weekly |
| Platform coverage | X platforms | Meta, Google, TikTok, Amazon |

### Step 2: The Static-First Production Machine
Build the 75% static engine:

**AI-Accelerated Static Production**:
1. Create 5-10 "hero" creative concepts per week
2. Use AI tools to generate 10-20 variations of each concept (layout, color, copy)
3. Test all variations simultaneously — let data pick winners
4. Kill bottom performers within 72 hours
5. Scale budget on top 10% performers

**Static Creative Formula**:
- Bold product image (clean, well-lit, no clutter)
- Single benefit headline (not feature)
- Social proof element (testimonial, review count, celebrity association)
- Clear CTA with urgency element

**Volume target**: From 5 new statics/week → 50/week within 60 days

### Step 3: The 25% Video Strategy
Build the video moat that AI can't commoditize:

**Danny Yeung's insight**: "If everyone's going to a commodity [AI statics], how do you differentiate? Video and authenticity."

**Video categories**:
1. **Founder story** — Raw, authentic, explains why the product exists
2. **UGC testimonials** — Real customers, real results, unscripted
3. **Celebrity/partner content** — Leverage partnerships for produced content
4. **Behind-the-scenes** — Manufacturing, R&D, quality testing
5. **Results demonstrations** — Before/after, performance metrics

**Production cadence**: 2-3 new videos per week minimum

### Step 4: Testing Protocol
Danny Yeung's creative testing framework:

**Week 1: Launch**
- Deploy 10 new creatives across test audiences
- Budget: $50-100/creative for initial data

**Week 2: Evaluate**
- Metrics: CTR, CPC, CPM, ROAS (for conversion campaigns)
- Tier creatives: A (scale), B (keep), C (kill)

**Week 3: Scale or Kill**
- A-tier: 3-5x budget increase
- B-tier: Maintain, create variations
- C-tier: Kill immediately, replace with new concepts

**Ongoing**: Repeat cycle weekly. Never stop producing. Never stop killing.

### Step 5: Platform-Specific Adaptation
Adapt the creative factory for each platform:

| Platform | Budget % | Creative Notes |
|---|---|---|
| **Meta (IG/FB)** | 85% | All formats; carousel + story + feed |
| **Google** | 15% | Search + display; performance-focused |
| **TikTok** | Expanding | Native format; raw/authentic > produced |
| **Amazon** | Separate | Product images + A+ content |

### Step 6: The 50→500→1,500 Scaling Roadmap
Phase the scale-up over 13 months:

| Phase | Timeline | Live Creatives | Weekly Production |
|---|---|---|---|
| Foundation | Months 1-3 | 50→150 | 10-15/week |
| Scale | Months 4-6 | 150→500 | 25-30/week |
| Dominance | Months 7-13 | 500→1,500 | 50+/week |
