## Execution Steps

### Step 1: Angle Inventory Build (Iha's CASH → Yeung's Volume)
Generate the angle library that feeds the creative factory:

**Iha's 6 Angle Categories × Yeung's Volume Multiplier**:

| Angle Category | Framework | Volume Target |
|---|---|---|
| **Problem-Aware** | Surface pain the audience already feels | 250+ ads |
| **Mechanism** | Explain WHY the product works (not just THAT it works) | 250+ ads |
| **Social Proof** | Testimonials, numbers, celebrity partnerships | 300+ ads |
| **Identity** | "People like you use this" | 200+ ads |
| **Comparison** | vs. alternatives (direct or indirect) | 200+ ads |
| **Objection Killers** | Pre-empt the top 5 reasons people don't buy | 300+ ads |

**Output**: 50+ distinct angles across 6 categories → each generates 20-30 creative variants = 1,000-1,500 live ads with strategic diversity.

### Step 2: Hook Engineering for Static (75% of Factory)
Apply Iha's hook architecture to Yeung's static-first production model:

**Static Hook Formula** (one per creative):
```
[CURIOSITY GAP or UGLY NUMBER]
+ [SINGLE MECHANISM LINE]
+ [PROOF ELEMENT (number, name, or image)]
+ [CTA]
```

**Hook Bank Production** (target: 100+ hooks per sprint):
1. Write 20 hooks per angle category (120 minimum)
2. Score each hook: Curiosity (1-5) × Specificity (1-5) × Proof Density (1-5)
3. Top 20% → immediate production
4. Middle 50% → variant testing
5. Bottom 30% → kill

### Step 3: Script Architecture for Video (25% of Factory)
Apply Iha's proof-stacking to Yeung's video authenticity moat:

**Video Script Template (30-60 seconds)**:
```
HOOK (0-3s): [Ugly number or pattern interrupt — NOT "Hey guys"]
MECHANISM (3-15s): [WHY this works — the science/logic]
PROOF STACK (15-35s): [Layer 3+ proof types: data + testimonial + celebrity]
IDENTITY BRIDGE (35-45s): [Who this is FOR — consumer posture match]
CTA (45-60s): [Specific, urgent, value-framed]
```

**Video Categories × Iha Proof Types**:

| Yeung Video Category | Iha Proof Layer | Example |
|---|---|---|
| Founder story | Personal credibility proof | "I built 5 companies. This is the one I take myself." |
| UGC testimonials | Customer transformation proof | "30 days in, my sleep score went from 62 to 89." |
| Celebrity content | Authority proof | "Sabalenka's team tracked this for 90 days." |
| Behind-the-scenes | Process/quality proof | "Every batch tested 3x before it ships." |
| Results demos | Data proof | "14,000 customers. 91% reorder rate." |

### Step 4: Creative Diversity Scoring
Prevent the factory from producing 1,500 copies of the same ad:

**Diversity Matrix** (score weekly):

| Dimension | Minimum Coverage | Current % |
|---|---|---|
| Angle categories (6) | Each ≥10% of total | __ |
| Proof types (5+) | Each ≥15% of total | __ |
| Hook styles (curiosity, proof, identity, fear) | Each ≥20% of total | __ |
| Format (static/video/carousel) | 75/20/5 | __ |
| Funnel stage (TOF/MOF/BOF) | 50/30/20 | __ |

**Kill rule**: If any dimension falls below minimum → new creative sprint focused on that gap.

| Day | Action | Owner |
