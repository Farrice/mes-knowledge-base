# /velocity-audit — Business Velocity Diagnostic

> Diagnose the real constraints throttling business speed — then prescribe the Danny Yeung acceleration protocol.

## When to Use
- Starting or scaling a business and unsure where the bottleneck is
- Feeling "slow" but can't identify why
- Before deploying any other velocity-scaling workflow

## Inputs Required
1. Business description (what you sell, to whom, through what channels)
2. Current revenue and growth rate
3. Team size and structure
4. Decision-making process (who decides what, and how long does it take)
5. Current customer acquisition channels and CAC

## Execution Steps

### Step 1: Speed Infrastructure Scan
Score the business 1-10 on each Danny Yeung velocity factor:

| Factor | Question | Score |
|---|---|---|
| **Decision Velocity** | Can the founder make any non-regulatory decision within 24 hours? | |
| **Team Velocity** | Does every team member match the founder's urgency? Zero velocity blockers? | |
| **AI-Native Adoption** | Is every team member using AI tools daily? | |
| **Founder Context** | Does the decision-maker have direct operational knowledge across all departments? | |
| **Channel Control** | Is the business 100% DTC (or has full control of customer relationship)? | |
| **Infrastructure Leverage** | Are existing assets being reused vs rebuilt from scratch? | |
| **Launch Cadence** | Can the team go from idea to live product/campaign in <3 weeks? | |
| **Creative Volume** | Is the business running 50+ creative variants simultaneously? | |

### Step 2: Bottleneck Diagnosis
Identify the **single biggest constraint** using Danny Yeung's hierarchy:
1. **People problems** → Someone on the team is slowing everyone down
2. **Decision problems** → Too many approval layers or unclear authority
3. **Channel problems** → Retail or third-party dependencies killing speed
4. **Economic problems** → CAC/LTV ratio broken, no subscription model
5. **Infrastructure problems** → Building from scratch when assets already exist

### Step 3: Acceleration Prescription
For each constraint found, prescribe the specific Danny Yeung intervention:
- People → Team Velocity Filter (GP-3)
- Decisions → Founder-in-the-Weeds Integration (GP-2)
- Channels → DTC-Only Global Distribution (HK-3)
- Economics → 3-Month Subscription AOV Play (GP-7) + CAC/LTV targeting
- Infrastructure → Infrastructure Pivot methodology (GP-4)

### Step 4: 30-Day Sprint Plan
Design a 30-day velocity sprint that addresses the top 1-2 constraints:
- Week 1: Remove the bottleneck (fire, restructure, or pivot)
- Week 2-3: Deploy the replacement system
- Week 4: Measure decision cycle time, launch cadence, and creative output

## Output Format
```
## VELOCITY DIAGNOSTIC — [Business Name]

### Overall Velocity Score: X/80

### Top Constraint: [People/Decision/Channel/Economics/Infrastructure]
[Specific diagnosis with evidence]

### Acceleration Prescription
[Specific Danny Yeung intervention with deployment steps]

### 30-Day Sprint Plan
[Week-by-week action items]

### Recommended Next Workflow
[Which velocity workflow to deploy next]
```

## Quality Gate
- Must identify a SINGLE primary bottleneck, not a list of everything
- Prescription must cite specific genius patterns by number
- Sprint plan must have measurable outcomes (not "improve X")
- Must recommend the next velocity workflow to chain
