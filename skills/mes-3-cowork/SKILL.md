# MASTERY EXTRACTION SYSTEM 3.0 — COWORK EDITION
## Skill Factory: Expert Content → Deployable Skills + Documents

---

## WHAT THIS SKILL DOES

MES 3.0 Cowork transforms any expert content into two deliverables simultaneously:

1. **An installable Cowork skill** (SKILL.md + reference files) that becomes permanently available, auto-triggering, and stackable with other extracted skills
2. **Traditional markdown extraction documents** (analysis report + Crown Jewel prompts) for reference and manual deployment

This is a skill that creates other skills — a factory for turning expertise into executable capability.

---

## OPERATING MODE: PRACTITIONER WITH CREATIVE LATITUDE

Every output from this system EXECUTES methodology and PRODUCES finished deliverables. It never explains how to create something — it creates the thing itself.

The methodology is foundation, not ceiling. Apply full creative intelligence to producing exceptional outputs. Where adaptive brilliance can elevate beyond the formula, take it.

**The Test**: After running any extraction, can the user immediately deploy the skill or copy-paste the output? If yes → success. If they need to create something additional → failure.

## EXTRACTION METHODOLOGY

### 4-Layer Analysis

Read `references/extraction-methodology.md` for the complete protocol. In brief:

**Layer 1 — Surface Intelligence**: Explicit methods, stated achievements, observable patterns, direct knowledge.

**Layer 2 — Hidden Patterns**: Unconscious competence, automatic behaviors, decision shortcuts, executable mental models.

**Layer 4 — Strategic Architecture**: Market positioning, adaptive expertise, ecosystem understanding, competitive advantages.

### Deliverable 2: Crown Jewel Practitioner Prompts (7 Markdown Documents)

Save each to workspace. Every prompt follows practitioner architecture — read `references/crown-jewel-template.md` for the full template. Key requirements:

- 800-1000+ words each
- EXECUTES methodology (never teaches)
- Specific [BRACKETED] inputs
- Exact output deliverable specification
- Creative latitude provision
- Enhancement layer surpassing original expert
- Two example OUTPUTS (actual deliverables, 500+ words each — THE deliverable itself, not a description)

### Deliverable 3: Installable Cowork Skill

This is the Cowork-native upgrade. Structure:

```
[expert-name]-mastery/
├── SKILL.md          (YAML frontmatter + routing + execution protocol)
└── references/       (full prompts organized by domain)
    ├── [domain-1].md
    ├── [domain-2].md
    └── ...
```

Read `references/skill-output-template.md` for the exact SKILL.md format. The key architectural pattern (modeled after nichebend-mastery and robert-mac-comedy-intelligence):

**SKILL.md contains**:
- YAML frontmatter with name, aggressive trigger description
- Core philosophy / identity statement
- Command system (quick commands mapping to specific prompts)
- Capability summary table (what each prompt does, when it deploys)
- Prompt routing guide (user need → which reference file)
- Execution protocol (identify domain → load reference → execute → deliver)
- Force multiplier combinations (skill stacking patterns)
- Quality standards
- Reference file pointers

**Reference files contain**:
- Full Crown Jewel prompts with complete execution protocols
- Organized by domain/capability area
- Each self-contained and deployable

## CONVERSION PROTOCOL (/convert command)

When the user provides an existing prompt to convert into a Cowork skill:

1. **Diagnose** the prompt: Practitioner mode? Instructor mode? Rigid? Hybrid?
2. **Convert** to practitioner mode if needed (eliminate teaching language, add execution protocol)
3. **Package** as a Cowork skill directory (SKILL.md + references/)
4. **Add** aggressive trigger description, command system, routing guide
5. **Enhance** with creative latitude, enhancement layer, example outputs
6. **Save** to workspace folder

Read `references/conversion-protocol.md` for the diagnostic checklist and conversion steps.
