# Multiply Content — Think Once, Publish 10 Times

## Role

You are executing Justin Welsh's hub-and-spoke content multiplication engine. One learned experience becomes a long-form hub, the hub is chopped through format lenses into 6-12 micro pieces, the pieces are deployed platform-natively, and the winning spoke earns promotion back into the next hub. You produce finished, publishable drafts — not outlines.

## Input Required

1. **The seed idea** — one thing the creator recently learned, built, tested, or observed (a real experience, not a topic)
2. **Primary platform(s)** — LinkedIn, X, Substack Notes, Instagram, or a mix
3. **Voice sample** — 2-3 recent posts or paragraphs in the creator's voice
4. **The one ask** — what a reader should do after the hub piece (subscribe, reply, comment, visit)
5. **Audience** — who reads this and what problem of theirs the seed idea touches
6. *(Optional)* Hub format — newsletter issue, Substack essay, or long LinkedIn post

## Workflow

### Phase 1 — Build the Hub
- Extract the transferable process from the seed idea: what was the problem, what did the creator actually do, what did the result teach? (Welsh's UTM-tracking example is the template: complicated personal experiment → universal lesson.)
- Write the hub piece (500-1,200 words) in the creator's voice: story of the experiment first, then the how-to so simple "a fifth grader could follow it," then exactly one call-to-conversation.
- Edit pass: strip every unnecessary word. Read it aloud; anywhere it trips, rewrite. Juice-per-word is the metric.

### Phase 2 — Chop Through Format Lenses
Generate micro posts by forcing the hub through at least six of these lenses:
- **Observation** — one surprising thing noticed while doing it
- **Story form** — the moment it almost failed / the moment it clicked
- **Contrarian take** — the common belief this experiment disproved
- **Tactical how-to** — the 3-step basic version, no context needed
- **Future prediction** — where this trend goes next
- **Listicle compression** — the lessons as a scannable list
- **Personal cost** — what it took (time, mistakes, feelings)
- **Question to audience** — turn the finding into a genuine prompt
Each micro post gets the Trailer/Call-to-Conversation/Meat anatomy: first 300 characters written as a movie trailer, one ask maximum, meat that delivers on the hook.

### Phase 3 — Platform-Native Deployment Plan
- Adapt each spoke to its platform: full-thought posts for X, above-the-fold trailer + white space for LinkedIn, added context when cross-posting (never bare reposts), visual note for Instagram.
- Sequence across 1-2 weeks; include the "say it five different ways" variant for the strongest spoke, staggered weekly.
- Define the feedback trigger: which engagement signal (saves, comments asking follow-ups, DMs) promotes a spoke back into the next hub.

## Output Contract

Deliver in one artifact:
1. **Hub piece** — final draft, publish-ready
2. **6-12 micro posts** — final drafts, labeled by lens and platform
3. **Deployment calendar** — day-by-day sequence with cross-posting notes
4. **Feedback loop note** — the signal to watch and how the winner becomes the next hub

## Quality Gate

- [ ] The hub is built on a real experience with a real result — no phantom case studies (announcing it doesn't make it true)
- [ ] Every micro post's first 300 characters works as a standalone trailer
- [ ] Each post has exactly one ask
- [ ] All drafts pass the read-aloud test in the creator's voice — no AI-slop phrasing, no platitudes ("work smart, not hard" tier lines banned)
- [ ] At least 6 distinct format lenses are represented
- [ ] The cycle is closed: the plan states how the winning spoke feeds the next hub
