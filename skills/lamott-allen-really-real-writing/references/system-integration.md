# System Integration - Really Real Writing

## Role In The System
This package is an optional depth/truth layer. It should be invited when depth is the job, not applied to every writing request.

## Trigger Language
Use this package when the user asks for writing that is:
- real
- true
- soulful
- deep
- human
- relatable
- resonant
- less AI
- less generic
- more literary but not pretentious
- heartful
- voice-forward
- novel quality
- emotionally precise
- able to make people feel it

## Non-Triggers
Do not use by default for:
- speed edits
- pure structure
- formatting
- short tactical copy where depth is not requested
- factual research summaries
- system documentation unless the user asks for trust, voice, or reader care

## Integration Slots

| Existing Route | How This Package Plugs In |
|---|---|
| `lamott-craft` | Broader process stays owner. Add this package after the draft exists and needs compassion, realness, or reader trust. |
| `/writers-room` | Use as one depth/truth pass, not another named voice in a crowded room. |
| `/platform-adapt` | Use after platform structure to humanize without breaking platform fit. |
| `/content-sprint` | Use on selected high-value pieces, not every fast output. |
| `/copy-engine` | Add after market/offer logic to remove fake empathy and make conversion copy more trustworthy. |
| `/proof-copy-engine` | Use after proof is verified to make proof feel human, clear, and not inflated. |
| `/roth-*` | Roth handles cinematic structure, theme, and residue. This package keeps resonance human and unpretentious. |
| `/connelly-*` | Connelly handles vivid detail, momentum, and subtext. This package handles compassion, hard truth, and trust. |
| `/story-remix` | Use to protect the original human truth while changing format or domain. |
| `/book-atomize` | Use to keep extracts, excerpts, and derivative posts emotionally faithful to the book. |

## Composition Ledger
When stacked, record:
- Function owner: the workflow responsible for the main output.
- Depth slot: this package, only if depth/truth is required.
- Evidence of integration: changed line, cut overproof, hard thing named, reader-trust repair, or ending repair.

## Output Rule
Do not announce a parade of experts. The proof is in the revision. Name this layer only in the receipt or when the user asks how the work was deepened.
