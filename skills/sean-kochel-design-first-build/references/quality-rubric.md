| **Research Depth & Specificity** | Defines audience and competitors broadly. Some gaps in detail. | Identifies specific audience segments and 2-3 direct competitors. Provides basic competitive analysis. | Maps audience to specific psychographics, pain points, and desires. Identifies 2-3 direct AND 2-3 indirect competitors, detailing their positioning, messaging, and visual identity. Zero unanswered questions in the brief. |
| **Phase Gate Purity** | Research, Design, and Build phases blend, with some tools used across phases. | Phases are mostly distinct, but deliverables might overlap slightly or tools aren't strictly separated. | Clear, distinct deliverables for Research (intelligence doc), Design (approved visual mockup), and Build (working code). Each phase uses appropriate, segregated tools and requires independent sign-off. |
| **Visual Authority Signal** | Design is functional and aesthetically acceptable, but doesn't strongly convey trust or expertise. | Design is visually appealing and professional, hinting at quality and reliability. | Design instantly communicates strong authority, professionalism, and trustworthiness *before* any copy is processed. The visual quality itself is a conversion mechanism. |
| **Design-Copy Harmony** | Copy is inserted into the design, sometimes requiring compromises in layout or readability. | Design accommodates copy well, with minor adjustments. | Design provides an optimal visual scaffolding, and copy integrates seamlessly, enhancing the message without compromising aesthetic integrity or rhythm. |
| **Design System Coherence** | Visual elements are generally consistent but may have minor discrepancies or feel generic. | Visual elements (typography, color, spacing, components) are consistent and reflect a clear, intentional style. | The design exhibits a unified, sophisticated visual language, where every element contributes to a cohesive and intentional design system, often driven by a single powerful style keyword or reference image. |
| **MCP Integration Accuracy** | Built code requires manual adjustments to match the design, or some design tokens are missed. | Built code largely matches the design, with only minor, easily correctable discrepancies. | Built code is a pixel-perfect, lossless translation of the approved design system via MCP, requiring virtually no manual CSS or component adjustments. |
| **Positioning Distinctiveness** | Core message is clear but could be easily confused with direct competitors. | Core message is distinct from direct competitors, highlighting a key differentiator. | Core message is uniquely compelling, clearly differentiated from *both* direct and indirect competitors, and resonates deeply with the identified target audience, often derived from evaluating multiple competing hypotheses. |
