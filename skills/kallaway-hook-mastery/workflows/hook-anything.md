## Channel Mapping (the core move)

| Asset | "Spoken hook" analog | "Text hook" analog | "Visual hook" analog | "Lock-in zone" analog |
|---|---|---|---|---|
| LinkedIn post | Line 1 (pre-fold) | Formatting/line breaks/caps | Image/carousel cover | Lines 2–4 + receipt |
| Email | Subject line | Preview text | — | First paragraph + proof |
| Ad (static) | Headline | Overlay text design | The creative itself | Body copy proof block |
| VSL / video ad | First sentence | Overlay title text | First 3s footage | Next 2–4 sentences + trust anchor |
| YouTube long-form | Intro first line | Title + thumbnail text | Thumbnail image | Intro confirm + proof |
| Sales page | H1 | Subhead/eyebrow | Hero visual | Lead + proof above fold |
| Deck / proposal | Slide-1 title | Slide-1 sub | Slide-1 visual | Slide 2 = receipts |
| Cold DM / outreach | Sentence 1 | — | — | Sentence 2 = specific proof |

## Execution

1. **Map the channels** for [ASSET TYPE] (table above). Every asset has at least two.
2. **Two-question test + 4 S's** on the primary channel (subject + outcome in ≤12 words, one interpretation).
3. **Apply text-hook micro-rules** to the text analog (specificity, power words, no transition words; fold/line-break awareness replaces the 2-line rule where relevant).
4. **Align** all present channels (mutual predictability — an image that doesn't predict line 1 is a scroll-away on LinkedIn exactly as on Reels).
5. **Build the lock-in analog** with [PROOF ARTIFACT] (claim confirmed + trust anchor).
6. **Stack the specialist** for platform idiom polish: LinkedIn → diandra-hook-architect / ghostwrite · ads → luke-iha-vicious-hooks · shorts scripts → jenny-hoyos · curiosity copy → georgi-curiosity-loop · rhythm pass → sam-parr. One author per body (never stitch multi-expert prose).

## Output Requirements
Deliver 3 hook sets for the asset (channels filled per mapping) + lock-in analog + alignment verdict + which specialist (if any) polished idiom. State length held. Feedback Triad.
