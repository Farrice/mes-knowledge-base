# Hook Landscape Scan

> **🔒 Pre-Flight Gate**: genius.md Decision Framework. Real research only — this workflow gathers actual published hooks via available tools (Playwright for JS-rendered platforms per browser-automation-safety; research.py; provided exports e.g. Sandcastles CSV). Never generate a "landscape" from training memory.

## Skill Acquisition
`genius.md` Patterns 5, 7, 11 + `references/text-hook-rules-card.md`.

## Input Required
- **[NICHE]** and **[PLATFORM(S)]**
- **[CREATOR SEED LIST]** (optional): known top 15–20 accounts; else discover
- **[DATA SOURCE]**: Sandcastles export / analytics screenshots / URLs / manual list
- **[TIME WINDOW]**: default last 3–6 months (recency-weighted)

## Execution

1. **Build the channel list** (top 15–20 creators the audience actually watches).
2. **Curate outliers**: per creator, the top 2–3 performing pieces in [TIME WINDOW] by outlier score (performance vs. that account's baseline — not raw views). Target 30–50 total.
3. **Capture per item**: word-for-word text hook · spoken hook (first line) · visual-hook pattern (name it from the library) · design treatment (system vs premium, placement, line count) · performance metric.
4. **Design landscape report**: what typography/placement/aesthetic is winning; the fork Farrice should remix (never copy) for signature style.
5. **Substance pattern report**: recurring formats, recurring power phrases (with cross-creator validation counts), payload lane distribution (pain/outcome/state-change).
6. **Hand off**: corpus formatted as [HOOK LIST] input for `power-word-mine`; design conclusions as calibration for `text-hook-forge`.

## Content Type Adaptations
| Platform | Adaptation |
|---|---|
| Reels/TikTok/Shorts | Full protocol as above |
| LinkedIn | "Text hook" = line 1 + formatting; outlier = engagement vs follower base |
| YouTube long-form | Titles + thumbnails corpus; packaging patterns |
| Newsletters | Subject lines + opening sentences |
| Ads (Meta library) | Hooks + first-frame visuals; note compliance context |

## Output Requirements
Deliver: (1) corpus table (30–50 rows), (2) design landscape (≤1 page, remix recommendation), (3) substance patterns (formats + validated power phrases with counts), (4) handoff-ready [HOOK LIST]. All entries sourced with links/refs — factual grounding rules apply. State length held. Feedback Triad.

Execution prompt: references/prompts-v2/khm_landscape_scan.md

## Quality Gate
Every corpus row is a real, verifiable piece (no invented examples — hard fail). Outlier-scored, not raw-view-sorted. Report concludes with remix guidance, never "copy X."
