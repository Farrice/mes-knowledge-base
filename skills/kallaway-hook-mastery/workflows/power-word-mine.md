# Power Word Mine

> **🔒 Pre-Flight Gate**: genius.md Decision Framework. This workflow REQUIRES real performance-ranked hooks as input — own winners first, competitors second. No data = go run `hook-landscape-scan` or harvest from Farrice's analytics before mining. Never mine from imagination.

## Skill Acquisition
`genius.md` Patterns 6–7 + Hall of Fame exemplars (the worked examples of this exact protocol).

## Input Required
- **[HOOK LIST]**: word-for-word hooks ranked by performance (views/engagement), with source channel
- **[NICHE / TARGET TOPIC]**: where the remixes will be deployed
- **[VOICE CONSTRAINTS]** (optional): banned words, brand register

## Execution

### Phase 1 — Mine
Scan [HOOK LIST] top-down by performance. For each hook, extract:
- **Power phrases**: 1–3-word bundles that amplify pain/outcome atypically ("social media machine," "scientifically impossible to skip"). Test: does the phrase have "extra juice" vs. its plain paraphrase?
- **Formats**: the grammatical skeleton with variables stripped ("here's how to do [X bigger task] in [Y shorter time]"). A hook with no power word can still carry a winning format.

### Phase 2 — Validate
Flag any power phrase appearing in 2+ top performers as **double-validated** ("guaranteed banger" tier). Rank the bank: double-validated > single top-10% > single other.

### Phase 3 — Twist
For each ranked phrase: generate 4–6 remixes that keep the psychology and shift the words ("scientifically impossible to skip" → "neurochemically impossible to skip," "psychologically impossible to resist"). For each format: re-instantiate with [NICHE] variables. Never ship the original verbatim.

### Phase 4 — Recombine
Mash twisted power words × twisted formats into 5–10 new hooks. Each must still pass the 4 S's (Subject, Stakes, Speed ≤12 words, Super Clear).

## Content Type Adaptations
| Input corpus | Note |
|---|---|
| Own channel winners | Highest trust — your audience already voted |
| Competitor winners | Valid; adapt register to Farrice's voice card when in his voice |
| LinkedIn top posts | Mine first lines; formats transfer, watch platform idiom |
| Ad libraries | Mine headlines/openers; stack with `hook-trust-stack` on output |
| Sales pages / VSLs | Mine leads and cross-heads; long-form power words compress well |

## Output Requirements
Deliver: (1) power-word bank table (phrase · source hook · performance · validation tier), (2) format bank (skeleton · source · when to use), (3) remix matrix (original → twists), (4) 5–10 recombined hooks with lineage annotations (which phrase × which format). State length held. Feedback Triad.

## Quality Gate
Zero verbatim rips (the novelty ethic is binding). Every output hook traces to ≥1 real winner. Twists keep the psychology — if a twist changes the meaning, it's a new claim needing its own validation flag. 4 S's on every recombined hook.
