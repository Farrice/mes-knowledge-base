# Interrupt Hook Engine

> **🔒 Pre-Flight Gate**: Run the Decision Framework in `genius.md` — stakes type (education/entertainment), audience's actual wanted outcome, available data (own winners > competitor winners > cold start), channels in play, proof artifact for lock-in. Do not write a single hook line before all five are answered.

## Skill Acquisition
Load `genius.md` (full) + `references/text-hook-rules-card.md`. If visual channel is live, also `references/visual-hook-pattern-library.md`.

## Input Required
- **[TOPIC]**: what the piece is about
- **[AUDIENCE + WANTED OUTCOME]**: who's scrolling and what they actually want (views, skills, customers, money, time)
- **[FORMAT]**: short-form video / talking head / faceless / text post / other
- **[DATA]**: any winning hooks (own or competitors') to mine; if none, flag `cold-start`
- **[PROOF ARTIFACT]**: study, case study, screenshot, third-party reference available for the lock-in zone

## Execution

### Phase 1 — Two-Question Target
Write the two answers FIRST, as plain statements: (a) what is this about (subject)? (b) what does the viewer get if they stay (outcome)? These are the spec every hook variant must transmit in ≤3 seconds. If (b) is fuzzy, stop — resolve the audience's wanted outcome before proceeding.

### Phase 2 — 4 S's Assembly (spoken hook)
Draft 5 spoken-hook candidates. For each, enforce:
- **Subject** named unmistakably (proper noun preferred — attention magnet)
- **Stakes** = the wanted outcome (education) or curiosity scenario (entertainment)
- **Speed** = ≤12 words, 8 ideal. Compression, not fast talking — if a word doesn't transmit subject or stakes, cut it
- **Super Clear** = one interpretation only; kill wordplay and vague setups on sight

Amplify: swap flat phrases for power words (mine [DATA] via the level-2 protocol in `power-word-mine` if winners exist; else use proven-format carriage and flag untested).

### Phase 3 — Text Hook
Apply the substance formula (Subject Repeater + pain reminder / outcome teaser / state change) and all six micro-rules from `references/text-hook-rules-card.md`. Produce 3 title-text options per surviving spoken hook, with line-break markup shown (`line1 / line2`), font fork recommendation (system vs premium), placement note, and 3-second hold reminder.

### Phase 4 — Visual Hook
Select ONE pattern from the five categories (default to the 80/20: body move, visual move, or text move). Small beats gimmicky. Write a one-line direction ("lean into lens on word X"; "cut to screenshot at word Y").

### Phase 5 — Alignment Audit (kill gate)
For the top candidate set: cover each channel and predict the others. Visual alone → guessable text + spoken? Text alone → guessable topic? Any misprediction = revise until all three point at the same subject + outcome. Add a caption-hook line (first caption line, above the fold) consistent with all three.

### Phase 6 — Lock-In Handoff
Write a 2-sentence brief for the lock-in zone: which claim must be confirmed, which proof artifact anchors trust. (Full build: `lock-in-zone-architect`.)

## Content Type Adaptations
| Format | Adaptation |
|---|---|
| Talking-head short | Full triple hook as above |
| Faceless / B-roll | Visual = visual-selection or overlay category; text hook carries primacy even harder |
| Text platform (LinkedIn/X/email) | Route to `hook-anything` — spoken hook logic becomes line 1, text-hook rules become formatting |
| Long-form YouTube | Two-question test applies to title+thumbnail; lock-in zone = intro confirm |
| Ad | Stack with `hook-trust-stack`; proof artifact mandatory, not optional |

## Output Requirements
Deliver: (1) two-question target, (2) 3 finalist hook sets — each = spoken + text (with breaks/font/placement) + visual direction + caption line, (3) alignment audit table, (4) lock-in brief, (5) data lineage notes (which winner each format/power word traces to). State length held. Close with the Feedback Triad.

Score against the 10-dimension rubric in `genius.md`. Any 4 S missing = automatic fail, rework. No shipping a set whose alignment audit has an unresolved misprediction. Anti-patterns list is binding.
