# Spoken Hook Formats

> **🔒 Pre-Flight Gate**: genius.md Decision Framework. Know which format families already work for this channel (own analytics beat guesses). If performance data exists, weight toward the proven families; if not, spread across families and mark as test set.

## Skill Acquisition
`genius.md` Patterns 1, 7 + Hall of Fame exemplars.

## Input Required
- **[TOPIC]** and **[AUDIENCE WANTED OUTCOME]**
- **[PROVEN FORMAT FAMILIES]** (optional): e.g., "tutorial, secret reveal, breakdown, problem" from channel data
- **[COUNT]**: how many hooks (default 8)

## Execution

1. **Select format families.** From the outperforming dozen for short-form — tutorial, secret reveal, breakdown, problem/solution, question, list, case study/receipts, state change, challenge, comparison, contrarian take, time-compression ("do X bigger task in Y shorter time"). Prefer [PROVEN FORMAT FAMILIES].
2. **Instantiate per family.** Strip each format to its skeleton, plug [TOPIC] variables in. Two candidates per family.
3. **4 S's pass** on every candidate: subject named, stakes = wanted outcome, ≤12 words (8 ideal), one interpretation.
4. **Amplify**: where a flat phrase sits in the stakes slot, upgrade to a power word (pull from an existing bank if `power-word-mine` has run; else conservative amplification, flagged untested).
5. **Rank + label**: each hook tagged with family, word count, and data lineage (proven family / test).

## Content Type Adaptations
| Surface | Adaptation |
|---|---|
| Short-form spoken | As-is, written to be SAID (read aloud test) |
| LinkedIn line 1 | Same formats; written register; fold-aware |
| YouTube titles | Formats compress to ≤8 words; pair with `text-hook-forge` for thumbnail text |
| Email subjects | Question/secret-reveal/time-compression families dominate |
| Podcast cold-open | Tutorial + breakdown families; slightly longer allowance (≤15 words) |

## Output Requirements
Deliver [COUNT] hooks in a table: hook · family · words · lineage · note. Read-aloud friendly. State length held. Feedback Triad.

Execution prompt: references/prompts-v2/khm_power_word_mine.md (format lane)

## Quality Gate
4 S's on all. No family fatigue: max 2 per family in the final set. Level-1 is the floor, not the ceiling — recommend `power-word-mine` when real winner data exists.
