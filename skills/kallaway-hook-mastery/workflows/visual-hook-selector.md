# Visual Hook Selector

> **🔒 Pre-Flight Gate**: genius.md Decision Framework. Remember the priority order: visual is the LEAST important channel — if text + spoken aren't dialed, send the work to `text-hook-forge` / `interrupt-hook-engine` first.

## Skill Acquisition
`genius.md` Pattern 8 + `references/visual-hook-pattern-library.md` (the menu).

## Input Required
- **[TEXT + SPOKEN HOOKS]**: finalized (alignment target)
- **[PRODUCTION CONSTRAINTS]**: talking head / faceless / b-roll available / props / location / editing capacity
- **[CREATOR COMFORT]**: how much on-camera performance is realistic

## Execution

1. **Constraint triage.** Map [PRODUCTION CONSTRAINTS] to viable categories: talking head → subject motion + overlays; faceless → visual selection + overlays + effects; screen-recording → overlays + pattern interrupts.
2. **Default to the 80/20**: (a) move the body in frame, (b) move the visual in frame, (c) move text on/within the visual. Only go beyond when data or brief demands it.
3. **Pick ONE pattern** from the library menu (e.g., Point To Visual, Jump In, Holding Prop, A vs B Graphics). One. The anti-gimmick guard is binding: a lean-in beats a circus.
4. **Alignment check**: watching the visual alone, muted — is the subject/outcome guessable? The visual must support the text and spoken hooks, in principle carrying motion, color, contrast.
5. **Write the direction**: one-to-three lines of shot direction with word-level timing ("on 'machine', slam the prop down"), plus the 3-second text-hold interplay (visual must not fight the title-text read).

## Content Type Adaptations
| Setup | Adaptation |
|---|---|
| Yapper (bedroom talking head) | Micro-moves only: lean-in, arm gesture, hair up, set down phone |
| Product/e-com | Holding Prop, Many Of Same Prop, A vs B, unboxing motion |
| Educational screen-share | Overlay category; pattern interrupt to face for the trust beat |
| Client reels (real estate etc.) | Move-in-frame at the property; Point To Visual for listing data |
| AI/faceless | Visual selection: inherently freezing footage matched to subject |

## Output Requirements
Deliver: (1) chosen pattern + category with one-line why, (2) two rejected runners-up with reasons, (3) shot direction with timing, (4) alignment verdict. State length held. Feedback Triad.

Execution prompt: references/prompts-v2/khm_interrupt_hook_engine.md (visual phase)

## Quality Gate
One pattern, small, aligned. Fail if: gimmick stacking, misalignment with text/spoken, or visual chosen while text/spoken remain undialed.
