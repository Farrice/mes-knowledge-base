# Visual Hook Pattern Library

Named visual-hook and format patterns read directly from Kallaway's curated collections library shown on screen in "The Psychology of Killer Hooks" (2026-08-05, ~[24:46]–[25:20] section; his tool shows 105 collections, 47 of them visual hooks, 5–10 exemplar videos each). Organized here by his five categories (genius.md Pattern 8). Use as a menu when selecting a visual hook — pick ONE, keep it small (anti-gimmick guard).

## Selection heuristics (from the source)

- **Least-important channel**: dial in text + spoken first; yappers win with zero visual hooks.
- **80/20 starter set**: (1) move your body in the frame, (2) move the visual in the frame, (3) move text on top of / within the visual.
- **In principle**: some motion, some color, some contrast — and whatever you do visually must be ALIGNED with text + spoken hooks.
- **Anti-gimmick**: one small move (lean-in, arm movement, hair up) beats crazy engineering. Add more only if data demands it.
