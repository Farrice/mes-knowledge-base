# Workflow Productizer

Transform any automation workflow you've built for yourself into a sellable product. Based on Darrel Wilson's principle that every automation you use is also a product you can sell — the n8n lead scraper that finds you clients can be sold on Upwork for $500-$5K.

## Input Required

- **Workflow to Productize**: What automation have you built? (Lead scraper, content pipeline, data processor, reporting system)
- **Target Buyer**: Who would pay for this? (Agencies, freelancers, SaaS companies, local businesses)
- **Price Range**: Where does this fit? ($500 setup, $1K turnkey, $5K custom)
- **Delivery Model**: One-time sale, monthly subscription, or hybrid?

> **🔒 Pre-Flight Gate**: Before executing, run the **Decision Framework** in `genius.md` § Decision Framework. Confirm all diagnostic questions are answered.


## Execution

### Step 1: Value Audit

Every workflow has a measurable value. Calculate it:

| Metric | Formula | Example |
|--------|---------|---------|
| **Time Saved** | Hours saved/month × hourly rate | 20 hrs × $50 = $1,000/month value |
| **Revenue Generated** | Leads found × close rate × avg deal size | 50 leads × 10% × $2,000 = $10,000/month |
| **Cost Reduced** | Manual labor replaced × cost | 1 VA ($1,500/month) replaced = $1,500/month |
| **Risk Eliminated** | Cost of missed opportunities | 1 $30K contract found = $30K one-time |

**Pricing Rule**: Charge 10-30% of the annual value you deliver. If your workflow saves $12K/year, charge $1,200-$3,600.

### Step 2: Product Packaging

| Package | Price | Includes | Buyer |
|---------|-------|----------|-------|
| **Template** | $97-$297 | JSON export + setup guide + video walkthrough | DIY tech-savvy buyer |
| **Done-With-You** | $500-$1,500 | Template + 1 setup call + customization | Semi-technical buyer |
| **Done-For-You** | $2,000-$5,000 | Full build, deployment, testing, handoff | Agency/business buyer |
| **Retainer** | $297-$997/month | Ongoing maintenance + monthly optimizations | Recurring revenue |

### Step 3: Documentation Package

For each productized workflow, create:

1. **Architecture Diagram**: Visual flowchart showing what the workflow does
2. **Setup Guide**: Step-by-step installation (screenshots and video)
3. **Configuration Variables**: What the buyer needs to customize (API keys, keywords, etc.)
4. **Output Sample**: Show what the workflow produces (sample lead sheet, sample report)
5. **ROI Calculator**: Spreadsheet showing the buyer what they'll gain

### Step 4: Sales Channel Strategy

| Channel | Best For | Commission/Fee | Setup Time |
|---------|----------|---------------|------------|
| **Upwork** | Done-for-you projects | 10-20% fee | 1 day (profile + listing) |
| **Fiverr** | Templates and setup packages | 20% fee | 1 day |
| **Gumroad/Lemonsqueezy** | Self-serve template sales | 5-10% fee | 2 hours |
| **Direct Outreach** | High-ticket custom builds | $0 | Ongoing |
| **YouTube Description** | Passive sales from tutorial content | $0 | Embedded in content |

### Step 5: Productization Checklist

- [ ] Remove all personal API keys and credentials
- [ ] Add environment variable placeholders with instructions
- [ ] Create sample data for testing without live APIs
- [ ] Record 5-minute Loom walkthrough
- [ ] Write 1-page sales description highlighting ROI
- [ ] Set up payment processing (Stripe, Gumroad, or platform-native)
- [ ] Create support email or FAQ document

### Step 6: Scaling via Portfolio

Once you have 3+ productized workflows:
- Bundle complementary workflows (lead gen + CRM sync + email sequence = $3K bundle)
- Offer "automation audit" service → diagnose needs → sell relevant workflow
- Build a landing page showcasing your workflow portfolio
- Use existing client results as case studies for new sales

## Output

Complete workflow product package:
- Cleaned workflow export (JSON/Make blueprint)
- Architecture diagram
- Setup guide with screenshots
- ROI calculator spreadsheet
- Sales description for 3 channels
- Pricing recommendation
- Video walkthrough script
