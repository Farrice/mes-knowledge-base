# Affiliate Program Selector

Select the highest-ROI affiliate programs for any niche using Darrel Wilson's 10-year selection framework. Produces a ranked list with commission analysis, risk assessment, and step-by-step join instructions.

## Input Required

- **Niche/Industry**: What space are you operating in?
- **Content Format**: Long-form video, short-form, blog, parasite SEO?
- **Revenue Goal**: Monthly commission target
- **Experience Level**: First program or adding to existing portfolio?

> **🔒 Pre-Flight Gate**: Before executing, run the **Decision Framework** in `genius.md` § Decision Framework. Confirm all diagnostic questions are answered.


## Execution

### Phase 0: Editorial Integrity Architecture

Before scoring any affiliate program on commission metrics, run the Editorial Filter. Products must DESERVE recommendation before revenue math enters the picture. This is what separates curated authority from commercial aggregation.

**5-Dimension Editorial Filter:**

1. **Practitioner Verification** (pass/fail): Has someone in the target niche actually used this tool in their real workflow? Not "could they use it" — "does someone currently rely on it?" Source evidence from community forums, Reddit, niche Slack/Discord groups, practitioner interviews. No practitioner evidence = automatic fail regardless of commission.

2. **Switching Cost Honesty** (1-10): How locked-in does the user get? Score ecosystem dependency. Tools that hold data hostage score low. Tools with clean export/migration score high. Editorial trust requires recommending tools users can LEAVE — otherwise you're trapping them, not helping them.

3. **Alternative Transparency** (required output): For every recommended product, name 1-2 alternatives you considered and WHY you chose this one over them. Include at least one alternative that has NO affiliate program. This proves the recommendation isn't commission-gated. Showing your selection logic builds more trust than hiding it.

4. **Longevity Signal** (1-10): How stable is this company/product? Years in market, funding status, pricing history, user base trajectory. Recommending a tool that dies in 6 months destroys all accumulated trust in a single event.

5. **Value-to-Commission Ratio** (gut check): If the commission disappeared tomorrow, would you still recommend this product to a friend in the niche? If the answer is "no" for any product, it fails the editorial filter regardless of all other scores.

**Integration rule**: Products must pass Phase 0 BEFORE entering Step 2 (Program Scoring Matrix). High-commission products that fail editorial review get filtered out. Lower-commission products that are genuinely better get elevated.

**Output requirement**: Every final recommendation includes an **Editorial Note** — why this tool was selected on merit, what alternatives were considered, and what the switching cost looks like. This section is the compounding trust artifact.

### Step 1: Niche-to-Category Mapping

Classify the niche into one of three tiers:

| Tier | Best For | Commission Range | Key Consideration |
|------|----------|-----------------|-------------------|
| **Physical Products** | Tangible goods, impulse buys, Amazon inventory | 1-25% | High trust, low commission, high conversion |
| **Digital Products** | Software, courses, tools, subscriptions | 30-50% | High commission, freemium risk, payment risk |
| **Services** | Hosting, finance, crypto, insurance, SaaS | 2-300% | Highest ceiling, variable, recurring possible |

### Step 2: Program Scoring Matrix

For each candidate program, score across 5 dimensions:

1. **Commission Structure** (1-10): Rate × cookie duration × recurring potential
2. **Anti-Freemium Score** (pass/fail): Does the product require payment to function? If free tier exists → FAIL
3. **Marketplace Availability** (1-10): Available via Impact/Awin/PartnerStack = 10; Direct-only = 3
4. **Conversion Probability** (1-10): Brand recognition × product necessity × your audience alignment
5. **Payment Reliability** (1-10): Marketplace-backed = 10; Direct with track record = 7; Unknown = 2

### Step 3: Required Tool Analysis

For the user's content niche, identify products that viewers MUST purchase to follow tutorials/guides. These convert near 100%.

**Pattern**: "To follow this tutorial, you'll need [PRODUCT]" → affiliate link becomes prerequisite.

### Step 4: Produce Program Ranking

For each recommended program, output:
- Program name and URL
- Commission rate and structure (one-time vs recurring vs hybrid)
- Cookie duration
- How to join (marketplace or direct)
- Recommended promotion angle (direct review vs indirect mention vs required tool)
- Risk flags (freemium, payment history, competitive saturation)

### Step 5: Link Infrastructure Setup

Recommend link tracking setup:
- **PrettyLinks** (WordPress) or **ThirstyAffiliates** for clean URL formatting
- Custom redirect format: `yourdomain.com/go/[product-name]`
- Click tracking dashboard for performance monitoring

## Output

A ranked table of 5-10 recommended affiliate programs with:
- **Editorial Note per product**: Why this tool was selected on merit, alternatives considered (including non-affiliate options), switching cost assessment
- Commission analysis and projected monthly revenue at current traffic levels
- Risk assessment per program (including longevity signal)
- Join strategy (marketplace links)
- Promotion angle per program
- Link tracking setup instructions

## Creative Latitude

The scoring matrix is the foundation. Where niche-specific knowledge reveals overlooked programs, hidden commission structures, or unusual stacking opportunities — deploy them. The best affiliate programs are often the ones nobody talks about because they're not on "top 10" lists.
