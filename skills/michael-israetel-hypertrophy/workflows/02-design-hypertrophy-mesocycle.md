## Role

You are designing a periodized hypertrophy block the RP way: specificity → overload → progression, with volume set by frequency and effort, fatigue managed by a ramp toward MRV and a deload to clear it. The output is a plan a client can follow with no second-guessing — the app that just says "12 reps at 50 lb," not a science lecture.

## Input Required

1. The confirmed needs-analysis brief (goal, timeline, time budget, training age, equipment, constraints). Run `01-run-needs-analysis` first if you don't have it.
2. Target muscles / priority (from specificity — which muscles/adaptations actually serve the goal).
3. Sessions per week available and session length (drives split and frequency).
4. Equipment/loads available (determines rep ranges and exercise selection).
5. Recovery inputs — sleep, stress, and any prior signs of over-reaching.

## Workflow

### Phase 1 — Set the frame (specificity, split, frequency)
- From the brief, name the priority muscles; every exercise must trace to one of them (reject "good exercises" that serve nothing named).
- Choose the split to hit each target muscle **≥2×/week** (the floor); 2–4×/week is the sweet spot. For time-crunched clients default to **full-body 2–3×/week**. Add frequency only for higher training age — the 3→4 jump barely registers below advanced.
- Select exercises with clean technique lines (prime-mover mechanics), rep-to-rep consistency, and a full loaded stretch position. Use whatever loads the client owns.

### Phase 2 — Set starting volume and the ramp (MEV → MAV → MRV)
- Set **starting weekly sets per muscle near MEV** by training age: novice ≈ 2–3 sets/muscle/session (2 sessions → months of progress); intermediate/advanced start higher.
- Prescribe rep ranges anywhere in **~5–30 reps** — chosen by equipment/joints/preference, not a "magic" zone. Every working set ends near technical failure.
- Encode **overload/progression**: add ~1 set/muscle/week (or add reps/load) *while performance holds*, walking volume from MEV up toward **MRV**. Set **RIR progression** across the block — e.g. early weeks ~3–4 RIR, mid ~2, late ~0–1 RIR as fatigue accumulates. Distinguish warm-up sets from working sets explicitly.
- Attach the **warm-up ramp** (light 12 → medium 8 → near-weight 2–4, ~30–60s rest; one ramp set for subsequent same-muscle exercises). No cardio/stretch ritual required.

### Phase 3 — Schedule the deload and the recovery half
- Insert a **deload** at the point performance/reps start dropping and fatigue signs mount (typically end of week 4–6): ≈ half the volume, back off intensity, to shed accumulated fatigue so the next block starts fresh. Never program past MRV — that's junk volume (cost, no return).
- Specify the **out-of-gym growth requirements**: the workout is only the signal (~80% tension-driven); prescribe protein at each meal, adequate sleep, stress management, and session spacing so a muscle isn't re-hammered mid-growth (~0.5–4 day growth window).
- Deliver the plan as unambiguous per-session next-actions (exercise, sets, target reps, RIR), not a science essay.

## Output Contract

- The split and weekly schedule, with each target muscle trained ≥2×/week.
- Per-muscle starting weekly sets (near MEV) and the week-by-week ramp toward MRV.
- Rep ranges and RIR progression across the block.
- Warm-up ramp protocol.
- A scheduled deload (timing + reduced volume/intensity) before the next block.
- A recovery rider: protein cadence, sleep/stress notes, session spacing.
- Session sheets written as direct next-actions a client can execute without second-guessing.

## Quality Gate

- [ ] Every exercise traces to a named target muscle from the brief (specificity holds).
- [ ] Each target muscle is trained ≥2×/week; added frequency is justified by training age, not enthusiasm.
- [ ] Starting volume is near MEV (novices at the floor), with an explicit week-by-week ramp toward MRV — not a flat, maxed-out prescription.
- [ ] Working sets end near technical failure within a ~5–30 rep range; warm-up vs. working sets are clearly separated.
- [ ] A deload is scheduled before fatigue exceeds recovery; no week programs past MRV (no junk volume).
- [ ] The recovery half (protein, sleep, stress, spacing) is prescribed, not assumed — a stalled client would be checked for recovery before adding volume.
