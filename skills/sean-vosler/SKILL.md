# Sean Vosler — Skill Manifest

**Core thesis**: *"All sales messages are, at the most fundamental level, an argument for or against something."* Copy changes ONE belief via ethically-provoked, deliberately-resolved cognitive dissonance — built from mined language, never from a blank page. Benchmark receipt: his own page at 9.4% conversion on 5,687 cold visitors.

**Load first**: [genius.md](genius.md) (always) · [references/frameworks.md](references/frameworks.md) (skeleton library, cite by section number).

## Quick Reference

- Never freehand: the mining pass (workflow 02) precedes all drafting — Hard Veto 1.
- The two dissonance preconditions (perceived choice + meaningful stakes) gate every contrarian piece.
- Bias work is an accelerant, never the engine — delete-test the flourishes.
- Deepest benefit is triggered ("imagine what X could mean…"), never stated.
- One yellow line per section; the highlight layer alone must carry the argument.
- Farrice-voiced deliverables: VOICE-CARD.md + dial mode load as a LAYER on top of this skill.
