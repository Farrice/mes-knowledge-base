# Copy Argument Audit

Attention loss is a discrete failure event you can pinpoint, not gradual decay. So diagnose the gate; don't rewrite blind. A diagnosis that says "tighten it up" is not a diagnosis.

## Pre-Flight Gate

1. **The piece has an argument to audit.** State its contention in one sentence from the copy alone. If no contention exists, this is not a diagnostic job — the piece has no argument spine and routes to `01-contrarian-structure.md` for a rebuild.
2. **Both dissonance preconditions were satisfiable in the first place** (Pattern 3, hard gate). If the target audience sits behind a *factual belief lock* — contractually bound, physically unable — the copy was never the failure point. Say so and stop; "you're not going to host an intervention to make a sale."
3. **A mining pass exists or is flagged as the finding** (Hard Veto 1). If every headline and bullet is invented persona language, that IS the diagnosis: the piece fails at source, and the fix is `02-research-arbitrage.md`, not a line edit.
4. **Performance signal named.** Which metric failed and where — bounce at the fold, scroll depth, click-no-buy, reply-no-purchase. The failure location narrows which gate to interrogate first.

## Execution

**1. Function-tag the whole draft in place (Pattern 11).** His signature device, run as QA rather than teaching. Overlay a tag on every sentence against the active framework: `[defines the mistake]` `[raises the stakes]` `[Forgiveness]` `[illumination]` `[what's next?]` `{struggle enemy}` `{value}` `{boogie-man local tension}` `{boogie-man universal tension}` `{solution}` — or the 7 beat names for a Contrarian-structured piece.
Rule: **any sentence with no tag gets cut or rewritten.** Tagging forces every clause to justify its function; untaggable copy is filler.
Then read the tag *sequence* alone. Missing beats, out-of-order beats, and beat-starvation (Angst present as one clause where the argument needed a list) surface here before you've read a word of the prose.

**2. Run the 4 gates in order.** These are the reader's four sequential questions. Answer each with a yes/no from the copy as written — never from intent.

| Gate | Reader's question | Failure signature | Named fix |
|---|---|---|---|
| 1 · Stakes | *Does this matter enough to worry about?* | Benefits listed, no consequence; local stake only | **Raise the stakes.** Build the "problem of the problem" list; lift local → universal ("It's not called the wheel. It's called the carousel.") |
| 2 · Logic | *Does the argument make logical sense?* | Claim size exceeds evidence; assertion stacked on assertion | **More reasonable proof.** At least one convincing piece of logic or fact per claim; bigger claim → more evidence. Emotional examples count as Authority |
| 3 · Agency | *Do I feel I have control here?* | Reader agrees but sees no move available; "not the kind of person who…" | **Build a sub-argument dissolving the no-control belief** before continuing the main one |
| 4 · Counter-evidence | *Do I have "ah-ha, got you" counter-info?* | One unhandled objection sitting in the reader's head the whole read | **Find and address the unhandled objection**, staged: validate → answer → reframe |

Clear all four = belief internalized = trust. Stop at the FIRST gate that fails; later gates are downstream of it and their symptoms are usually artifacts.

**3. Map the resolution tree (p194).** Which branch did the actual reader take?
- **Changed belief → changed behavior** = the win; the piece isn't the problem, look upstream at traffic or offer.
- **Changed belief → didn't act** = the "you're right but I don't care" state.
- **Disputed the idea** = the argument's logic or emotion breaks somewhere findable — revise the argument, don't add volume.
- **Imported outside ideas** to rationalize against you = you failed to pre-refute. List the likely alternative ideas and refute them inside the copy ("admission of an alternative path").

**4. The "right but I don't care" pair of fixes.** This state has exactly two causes and two fixes.
- **Missing empathy.** The copy declared the reader's belief wrong without acknowledging the real difficulty behind it — quitting vaping IS hard, the cravings ARE real. Flat contradiction reads as not understanding them, and drives them off regardless of evidence quality. Fix: an empathy audit — for each claim, is the reader's version of it acknowledged as reasonable before it's displaced? "Never accuse the reader of being an idiot." Bring them to a conclusion; don't give them one.
- **Unstated stakes.** The reader doesn't know or hasn't accepted the real-world consequence of staying wrong. Fix: state the consequence explicitly, both immediate and long-term. Keep it real — manufactured or improbable risk is fear-mongering and fails the audit outright (Hard Veto 2).

**5. Secondary sweeps, only after a gate is named.**
- **A's checklist** — run the 15-term glossary across the piece (Attention, Appeal, Acknowledgement, Arousal, Angst, Aspirations, Attitude, Authority, Ambiguity, Ascension, Affirm, Associate, Aggravate, Animate, Action) to locate what's structurally absent. Not every A belongs in every piece — they culminate across a body of work.
- **Bias-deletion test (Hard Veto 3).** Strip every urgency, scarcity, social-proof, and anchoring flourish. If the close dies, the piece has no standalone message and the flourishes were carrying it.
- **Layer-3 audit (Hard Veto 5).** Any deepest benefit stated flat instead of triggered ("imagine what X could mean for you") is a conversion leak.
- **Intro re-read.** Always revisit the introduction after finishing a piece: does it state a clear claim of benefit up front, and does an "Even if…" line disarm the jugular objection?

**6. Write the diagnosis.** ONE failed gate. The specific named fix for that gate. The exact lines that must change. Not a rewrite plan for the whole page.

## Content Type Adaptations

| Type | Gate that usually fails | Diagnostic emphasis |
|---|---|---|
| Sales page | Gate 4 (counter-evidence) | Staged FAQ coverage against all 7 objection types; offer-close beat order |
| Email / sequence | Gate 1 (stakes) | Does the Even-If open answer the jugular objection? Is the CTA reachable at this reveal depth? |
| Social long-form | Gate 3 (agency) | Agreement without action — the "great post" that sells nothing; check for a named move |
| Ad / VSL | Gate 2 (logic) | Claim-to-evidence ratio at speed; run the 30-question emulation checklist on your own creative |
| Cornerstone content | Gate 1 → Gate 4 | Value given away without the argument spine — check for feature-tour drift |

## Quality Gate

1. **One gate, one fix (Pattern 4).** The diagnosis names a single failed gate with its specific fix. "Rewrite it tighter," a list of four gates, or a full-page rebuild = FAIL.
2. **Tag coverage (Pattern 11).** 100% of clauses carry a function tag; every untagged sentence is explicitly cut or rewritten, not left in place.
3. **Evidence from the copy.** Every gate verdict quotes the line that proves it. Verdicts asserted from intent or memory = FAIL (Hard Veto 6).
4. **Preconditions checked before blaming the copy (Pattern 3).** Perceived choice and meaningful stakes evaluated; factual-belief-lock audiences called out rather than written around.
5. **No fear-mongering fix (Hard Veto 2).** A stakes fix that manufactures risk fails the audit. Dig for the deeper real risk instead — "keep the monsters real."
6. **Bias-deletion test run (Hard Veto 3).** Documented result. If the close dies without the flourishes, that fact appears in the diagnosis.
