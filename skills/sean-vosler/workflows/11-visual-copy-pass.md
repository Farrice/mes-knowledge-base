# 11 — Visual Copy Pass (the page is copy)

> **Where this sits.** This supplies the *copy* layer of a designed deliverable — what gets highlighted, tagged, struck through, recapped, pull-quoted. It **stacks with** the design skills (`satori-graphics` for composition and contrast, the briefs/READOUT system for the shipping surface); it doesn't replace them. Design decides how the page looks; this pass decides what it *argues* when someone reads only its emphasis layer.

## Pre-Flight Gate

1. **The argument already stands** (Pattern 2): contention in one sentence, beats in order. Highlighting a spineless piece just marks a random line yellow.
2. **Format governs depth-of-reveal.** Email → straight to CTA · sales page → benefit outline then buy-CTA · content → tactical depth then soft-sell. Tune emphasis to that, not to page count.
3. **Skimmer assumption accepted** (Pattern 12). If the owner insists every reader reads every word, name the disagreement in one line and run the pass anyway.
4. **One honest self-undercut budgeted.** Showing the seams is the credibility strategy; zero visible imperfection reads as guru.

## Skill Acquisition

- `genius.md` — always. Patterns **11** (Annotate-in-Place) and **12** (One Yellow Line) are core; Pattern 6 governs annotation tone; Pattern 8 keeps flourish subordinate.
- `references/frameworks.md` — **the section whose framework the piece runs on** (§1 headlines · §3 A's of Influence · §4 Contrarian Copy Structure · §7 TTT/KLTCC); function-tagging is meaningless without a named framework. **§11** for A FOREST.
- Devices as printed: `extractions/sean-vosler-7fmc/harvest/pages-161-200.md` §7 and `pages-241-280.md` §7.
- **Voice layer**: shipping under Farrice's own name → load `_active/farrice-brand/voice/VOICE-CARD.md` as a LAYER. Borrowed voice shows worst in a highlighted line.

## Execution

**1 — One yellow line per section.** Exactly one highlighted takeaway per section or page. Emphasis works through restriction: two halve each other, five is none. The test: **read only the highlighted lines end to end — that sequence must deliver the complete argument alone.** If it reads as disconnected aphorisms, you highlighted lines you liked, not lines carrying the spine. Re-pick; never add.

**2 — Function-tag every clause.** Overlay tags on the draft against the active framework: `[defines the mistake]` `[raises the stakes]` `{struggle enemy}` `{boogie-man universal tension}` `{solution}`, or the beat labels in play (Acknowledgement / Aggravate / Authority / Angst / Ambiguity / Appeal). Two consequences: **any clause you cannot tag gets cut or rewritten** — untaggable copy is filler; and **the tag sequence must match the intended structure** — tags reading Attention → Authority → Authority → Appeal mean a proof pile with the Aggravate beat missing, and no design hides that. The Bed Bug Bomb paragraph proves the compression: struggle enemy, value language, local *and* universal tension, solution — forty words, all inline-tagged.

**3 — Translation / Implication annotation.** Under every headline, hook, or ad, write two lines: **Translation** (what it literally says) and **Implication** (what the reader concludes) — the Men's Health cover teardown and the six-ad paid-social gallery, the same pass at account scale. The gap between the two lines *is* the copy's work; identical lines mean the copy only describes.

**4 — No/Yes contrast graphic for every reframe.** Where a belief changes, render two columns: discarded frame beside replacement, both in the reader's language. Reframes in prose get skimmed; reframes as opposition get remembered. Keep the "No" column fair — a strawman reads as contempt and breaks the forgiving-tone rule.

**5 — Strikethrough-and-replace as rhetoric, not correction.** Revise in front of the reader: "change is ~~scary~~ **terrifying**"; "PART TWO: ~~KNOWLEDGE~~ INSIGHT IS POWER" — the second performs its own thesis in the title. One to three per deliverable; the device dies from repetition.

**6 — Visual metaphor paired with every abstract principle.** No abstraction ships naked. His practice is total: iceberg for depth calibration, compass/map/vessel for the ascension sequence, a five-icon vertical spine (handcuffs → broken chain → typewriter → crown → lightning) for a five-stage process, dung beetles for strategic asymmetry. The metaphor *is* the mnemonic structure — so write the caption mapping metaphor back to lesson; don't leave it to the designer.

**7 — Roman-numeral recap blocks.** Close every major section with a compressed I–IV recap, reworded each time. Spaced repetition built into page design; set it visually distinct (colored numerals) so it reads as the "if you read nothing else" block.

**8 — Worksheet beside worked example, two columns, same spread.** Reading the example and filling the worksheet in one eye-movement converts a reader into a practitioner; exiling the worksheet to an appendix guarantees it's never used.

**9 — Pull-quote architecture.** Pull-quotes are section-thesis statements: oversized, differently fonted, breaking mid-page, readable in isolation ("The Right Strategy Can Beat The Biggest Advantages"; "great marketing applied to a crappy product is just adding saffron to a turd"). One per major section, never adjacent to that section's yellow line — they'd compete.

**10 — Colour key, held throughout.** **Yellow** = load-bearing claim or pivot · **blue** = supporting emotional/sensory language · **red** = meta-commentary in the author's voice, visibly separated (bordered box, margin rule) from the material commented on — that border *is* the attribution mechanism when annotating someone else's copy. Sidebar vertical-rule callouts carry "Consider:" / "Remember:" so they read as director's notes, not skippable body.

**11 — Pacing furniture.** Full-bleed dividers between dense stretches: one image, one outside quote, zero body copy — act breaks. Running header bars naming the current part. Any literal tool (math table, checklist) set in monospace so it reads as a tool, not prose.

**12 — Final read as a skimmer.** Read only headline, subheads, yellow lines, pull-quotes, No/Yes columns, recaps. Score against the rubric row "Page layer = 10." Failing means fixing the emphasis layer — not the body copy.

## Content Type Adaptations

| Deliverable | Yellow-line unit | Devices that earn place | Drop |
|---|---|---|---|
| Long-form sales page | One per beat of the 7-beat structure | Function tags, No/Yes reframe, staged-FAQ block, pull-quote per zone | Worksheet columns, dividers |
| Lead magnet / guide / ebook | One per spread | Recaps, worksheet-beside-example, metaphor per principle, dividers | Heavy strikethrough |
| Research brief / client readout | One per section | Roman-numeral recap, monospace data tables, thesis pull-quote | Strikethrough, No/Yes |
| Carousel / slide deck | One per slide, non-negotiable | No/Yes contrast, visual metaphor, one pull-quote slide | Recaps — the deck *is* the recap |
| Email | One bolded line, max | Translation/Implication in review only, never shipped | Everything else |
| Ad creative set | One per asset | Translation/Implication across the whole set | Recaps, dividers, worksheets |

## Output Requirements

**(1)** Annotated draft — every clause function-tagged; untaggable clauses struck with a one-word reason (`filler`, `duplicate`, `no function`). **(2)** Highlight layer extracted — yellow lines as a standalone ordered list reading as a complete argument. **(3)** Translation/Implication table — one row per headline, hook, or ad. **(4)** Reframe spec — No/Yes column pairs in the reader's language. **(5)** Metaphor map — principle, visual metaphor, mapping caption. **(6)** Recap blocks — one per section, reworded not repeated. **(7)** Pull-quote set — one per section, each readable alone. **(8)** Design handoff — colour key, strikethrough instances, divider placements, and which blocks set as tools rather than prose.

## Quality Gate

- **Highlight-layer completeness** (rubric: Page layer = 10). Highlights alone deliver the argument. Fix by re-picking, not adding — fail otherwise.
- **Restriction held.** Exactly one highlighted takeaway per section. Two or more = fail.
- **Tag coverage.** 100% of clauses tagged, sequence matching the intended structure. Any untagged clause left in = fail (Pattern 11).
- **Ornament subordination.** Delete every highlight, strikethrough, and contrast graphic and the argument still closes — design form of **Hard Veto 3, No bias play without a standalone message** — fail otherwise.
- **Forgiving tone survives design.** No/Yes columns and struck words never make the reader the butt of the revision. Accusing the reader = fail (rubric: Tone).
- **One honest self-undercut present** — a flagged unsourced memory, an in-development note, a named limit. Sanded-out polish = fail.
- **Claim labels survive.** Statistics rendered as big-type pull-quotes still carry VERIFIED / LIKELY / UNCONFIRMED. Violation = **Hard Veto 6** — fail.
