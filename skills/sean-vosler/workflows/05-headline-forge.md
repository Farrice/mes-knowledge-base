# 05 — Headline Forge (The Imitation Game)

## Pre-Flight Gate

1. **Hard Veto 1 — no blank-page copy.** A mining pass exists before line one: aggregator captures, Amazon sub-titles, "most helpful" reviews, or long-running live ads — in a doc, with sources. The client's own raw language counts.
2. **Objective before tactics (Pattern 7).** SMART sentence first: *"In this [medium] I want to convince my reader that [specific feature] is better for accomplishing [specific task] than their current method. To do this I will show specific evidence, share specific case studies, and appeal to [xyz] emotions."* Free-write, throw it away, then write the objective.
3. **Format routed now** (format governs depth-of-reveal): email / sales page / content piece decides what the post-headline intro does.
4. **The ask is a family, not a line.** "Give me a headline" still ships the family.

## Execution

**1 — Brief.** Objective + desired action in one line. Name the audience identifier in the target's literal mined words, never from a persona doc.

**2 — Research the aggregators.** digg, reddit, news.google, medium, buzzfeed, cracked. **Mine STRUCTURE, not topic** — "focus less on what's being said, and more on how it's structured." 10-20 headlines verbatim with links. Mine through a ranking lens (front page, top-voted, best-seller rank, ad run-length); recency alone is not validation.

**3 — Formulate the skeleton.** Strip a capture to slot grammar: `"The [noun] Who Perfected The [topic]"`; sub-title variant `"A [adjective] Approach to [enticing promise]"`. Keep grammar, discard every original word — emulate FORM, never words and structure together.

**4 — Develop.** One sentence per skeleton: curiosity, belief-confirmation, open loop, powerful promise, questioned reality, provoked thought? Un-interrogated skeletons get discarded — you can't swap modifiers on a machine you can't explain.

**5 — Adapt.** Plug in audience + topic, then check the **master formula (p37): Attention Grabbing Headline = "Audience Identifier" + "Hook" + "Benefit"**. All three labelable, or it isn't finished.

**6 — Expand ("feed the need").** Apply **Modifier = End Result + Time Frame**, then bolt on a consequence clause answering "what's in it for them if they keep reading." Vosler's chain: *"A Counterintuitive Approach to Living a Good Life"* → `"A [adjective] Approach to [enticing promise]"` → *"A [Uniquely Powerful] Approach To [Making Millions Short Selling Homes]"* → *"…And Why Many Agents Are Missing Out Big Time."*

**7 — Mint the family (the modifier swap).** One skeleton, four keyed variants, lever named on each:
- **Base** — End Result + Time Frame, the clean promise.
- **Fear of Loss** — what they forfeit by not acting ("How to Avoid Easy-to-Miss Writing Mistakes That Are Costing You Sales").
- **Fear of Change** — disarms switching cost; the offer as an addition, not a replacement.
- **Fear of Unknown + Hope** — name the murk, point at the lit path.

**8 — Sub-title mining variant** (when the aggregator pass is thin). Amazon best-sellers in-niche → collect sub-titles, the promise carrier ("Don't judge a book by its cover… judge by its subtitle") → tag persuasion mode: Contrarian / Intriguing / Inspiring / Powerful Promise → abstract → repopulate → expand with the consequence clause. Tag mode per output so the family spans registers, not just modifiers.

**9 — Volume pass (optional).** Run the **32-prompt worksheet** against the niche: Ask a question / Reference current events / Create Your Own Terms / Reveal News / Command / Give Stats / Comparison / Promise Useful Info / Direct Offer / Quick Story / Recommendation / State Benefit / Testimonial / Arouse Curiosity / Reveal a Secret / Ultra Specific / Target Segment / Time Based / Urgency-Scarcity / Good News / Challenge Reader / Guarantee / Price-as-benefit / Contradiction / Address Objection / "As Crazy As It Sounds" / Promised Land / Demonstrate ROI / Reason Why / List-Answer Questions / Cost Saving / Cost of Mistakes / Reader's Goals. One line each; harvest survivors into step 7.

**10 — Sub-headline + Even-If opener.** Jobs split (p29): **Headline = Capture Attention + Frame Problem · Sub-headline = Hint at Solution + Address Main Objection.** Open the intro with the literal words **"Even if…"** answering the jugular objection — the one that loses the most audience — before the illusory-superiority reflex ("maybe for them, but not me") fires. Route after: Email → straight CTA · Sales page → benefit outline → buy CTA · Content → tactical depth → soft-sell CTA.

**11 — Function checklist.** Every shipped headline does ≥1 of Conjure Curiosity / Provoke Thought / Confirm Suspicion / Create Intrigue / Promise Powerfully / Question Reality — **and** pulls the reader down the page. Scoring without pulling makes it a slogan.

## Content Type Adaptations

| Content type | Skeleton source | Modifier emphasis | Routing after |
|---|---|---|---|
| Sales page | Sub-titles, long-running ads | Base → Fear of Loss | Even-If → benefits → buy CTA |
| Cold email / subject | Aggregator curiosity structures | Unknown + Hope; short | Even-If → straight CTA |
| Content / blog | 32-prompt secret / contradiction | Base + Fear of Change | Depth → soft-sell |
| Paid social ad | Live ads, engagement then longest-running | Fear of Loss, loss-framed | Hook + benefit + CTA |
| Webinar registration | Review-mined open-loop hooks | Base + Loss, unresolved | Bullets closing on registration |
| Lead magnet / opt-in | Review-mined self-talk | Fear of Change (addition) | Even-If → one soft CTA |

## Output Requirements

1. SMART objective + desired action.
2. Mining artifact: sources with links, skeleton(s), "why it works" sentence each.
3. **The headline family** — ≥4 variants off one skeleton, each with lever named, identifier/hook/benefit labeled inline, and the function-checklist item hit.
4. Sub-headline per shipping candidate.
5. The Even-If opener paragraph, jugular objection named.
6. Any 32-prompt run as appendix, never the deliverable.
7. Provenance line per headline.

## Quality Gate

- **Hard Veto 1:** every headline traces to a named mined artifact; zero invented persona language. One untraceable line fails the batch.
- **Family, not a line:** ≥4 modifier-keyed variants, levers named. A single "best" headline is a failed run.
- **Master formula (rubric: Language provenance):** identifier + hook + benefit labelable in every candidate.
- **Function checklist + pull:** ≥1 of six functions AND pulls down the page.
- **Hard Veto 2 (no fear-mongering):** loss and unknown variants name real, likely risks — the deeper one ("a lifetime of unfulfillment in a dead-end job"), not manufactured doom.
- **Hard Veto 6:** any number or timeframe inside a headline is VERIFIED or it comes out.
