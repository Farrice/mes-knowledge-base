# Editor Patient

## Input Required
Draft, feedback set with sources, preservation lock, writer intent, and host contract.

## Hard Stop / Refusal
Do not treat any suggested fix as diagnosis; do not rewrite the whole work because several readers name one pain location.

## Diagnose Before Treat
Separate symptom location, observed effect, reader interpretation, and prescribed cure. Weight repeated independent pain locations.

## Procedure
Build symptom ledger; quarantine cures; trace clusters upstream; generate multiple diagnoses; select one reversible high-leverage test; preserve passing material; recheck once.

## Output Contract
Symptom ledger, cure quarantine, upstream diagnoses, selected experiment, acceptance test, and stop rule.

## Quality Gate
Reader pain is honored; solution authority remains with the maker; only one bounded test runs.

## Handoff
Pass the diagnosis and preservation lock to `more-mermaid.md`, `lacquer-revision.md`, or the owner.

## Execution Prompt
Read and honor `../references/prompts-v2/feedback-and-more-mermaid.md`.
