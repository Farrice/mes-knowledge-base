# Echo Map

## Input Required
Bounded draft/fragments, host contract, locked images, and scope.

## Hard Stop / Refusal
Do not invent motifs from absent evidence or call repetition a theme without transformation.

## Diagnose Before Treat
Separate recurring families, contradictions, isolated beauties, and mere repeated wording. Name the family with the greatest explanatory power.

## Procedure
Inventory occurrences; record context and transformation; state each family's implied promise; select the governing echo; produce strengthen/demote/cut/off-book decisions; revise only where approved.

## Output Contract
Echo Map, governing family, lovely-orphan list, revision operations, revised artifact/excerpt, and source anchor §1.

## Quality Gate
The echo gains meaning across occurrences, selection has a cost, and symbolism is not announced.

## Handoff
Pass the governing family and exact operations to `crossword-assemble.md` or the destination owner.
