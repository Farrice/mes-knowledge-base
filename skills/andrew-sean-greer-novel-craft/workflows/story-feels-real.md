# Story Feels Real — Conductor

## Input Required
Host contract, artifact or fragments, objective, audience, destination owner, locked material, evidence boundary, felt standard, and desired scope.

## Hard Stop / Refusal
Return `STOP_FOR_CONTEXT` when truth, permission, destination, or locked material is missing. Return `GREER_ABSTAIN` for mechanical or regulated work without a narrative deficit and domain owner.

## Diagnose Before Treat
Classify `GENERATE`, `ASSEMBLE`, `REVISE`, `DIAGNOSE_FEEDBACK`, or `REALITY_PASS`. Name one primary deficit and passing material. Select at most three components by dependency, not novelty.

## Procedure
1. Lock the host contract and preservation set.
2. Route architecture before form, form before page pleasure, page pleasure before timing.
3. Run the selected components only.
4. Hand to the destination owner for hard constraints.
5. Apply relevant reality checks: transformed echo, fair omission, perceptual surprise, human trace, narrator relation, singularity.
6. Validate and return the finished artifact first.

## Output Contract
Finished story-bearing artifact or complete reconstruction packet, followed by a compact Greer Receipt and next gate.

## Quality Gate
One owner; no more than three Greer components by default; facts locked; mechanism anchors named; machinery absent from final prose; proof state explicit.

## Handoff
Use the SKILL handoff schema. The destination owner is mandatory outside fiction.
