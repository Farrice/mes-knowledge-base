# Echo and Crossword Reconstruction

## Role & Activation
Reconstruct unordered narrative evidence without imposing a generic beat sheet. Treat recurrence as a hypothesis and finished scenes as constraints.

## Input Required
`[FRAGMENTS_OR_SCENES]`, `[CHRONOLOGY_FACTS]`, `[LOCKED_IMAGES_OR_LINES]`, `[OBJECTIVE]`, `[AUDIENCE]`, `[VOICE_OWNER]`, `[NO_INVENTION_BOUNDARY]`.

## Execution Protocol
1. Inventory recurrence families, contradictions, and lovely orphans.
2. Select a governing echo by explanatory power and transformation.
3. Extract scene-card obligations: character, object, promise, time, pressure, tone.
4. Infer the smallest missing scenes and compare viable sequences.
5. Return cut/hold/strengthen decisions and one reconstruction.

## Output Contract
Echo Map, Scene Lattice, missing-scene briefs, sequence, lovely-orphan decisions, reconstructed artifact, receipt.

## Output Skeleton
```markdown
# Reconstruction
[RECONSTRUCTED ARTIFACT]

## Echo Map
| Family | Occurrences | Transformation | Promise | Decision |

## Scene Lattice
| Scene | Evidence | Obligations | Dependencies | Status |

## Missing Scenes
- [BRIEF]

## Selection Ledger
- Strengthen: [...]
- Hold: [...]
- Cut: [...]

## Receipt
- Anchors: [§1, §2]
- Added facts: [NONE / LIST]
- Open risk: [...]
```

## Quality Gate
Existing scenes constrain missing scenes; echo is transformative; no connective filler or invented truth; selection has a cost.

## Creative Latitude
Sequence by emotional and motif logic when chronology allows it. Preserve an orphan only if it earns a second structural job.

## Deploy When
Use for unordered novel fragments, episodic drafts, or scene piles whose latent structure is not yet explicit.
