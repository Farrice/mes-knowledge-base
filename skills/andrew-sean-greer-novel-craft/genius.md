# Andrew Sean Greer: Method Intelligence

Primary evidence is `references/source-ledger.md`, backed by `extractions/video-context/0kkAl04_0og/`. Mechanism names and cross-domain translations are `INFERRED`; they are not quotations or scientific laws.

## Eighteen Genius Patterns

1. **Abundance before allegiance.** When meaning has not appeared, collect fragments before choosing a thesis because selection needs evidence. `§§1–2`
2. **Echo architecture.** When a draft feels episodic, map recurrence and transformation because repeated images are the draft's early structural vote. `§1`
3. **Crossword drafting.** When chronology blocks work, write knowable scenes and infer obligations between them because completed nodes constrain the gaps. `§2`
4. **Form as pleasure engine.** When a required scene feels dead, test three forms before changing content because resistance may belong to viewpoint, distance, or report. `§3`
5. **Reader invention.** When explanation smothers attachment, withhold only inferable material because readers bond with what they help create. `§4`
6. **Difficulty dial.** When omission is tempting, name the clue and audience burden because obscurity is not depth. `§4`
7. **Source-pile voice laboratory.** When voice is generic, combine functionally distinct references because a voice is an ecology, not an imitation. `§§5,7`
8. **Narrator-character distance.** When pain and comedy collide, separate character-now from narrator-later because proportion can create safety without contempt. `§6`
9. **Project-specific consumption.** When inputs create noise, select them by the live craft problem because prestige is not usefulness. `§7`
10. **Literary permission mining.** When contemporary form feels narrow, study what older work permits because device memory expands available choices. `§§8,11`
11. **Surprise density.** When work is coherent but inert, create local perceptual turns because movement need not be plot escalation. `§9`
12. **Structural self-fit.** When transitions repeatedly fail, use the writer's reliable generative unit because structure should exploit native strength while preserving movement. `§10`
13. **Instant character capture.** When character is biography instead of life, record behavior under social pressure because resistance reveals personhood. `§12`
14. **Plot carries the contraband.** When literary value stalls the story, use movement to carry wisdom, beauty, or poetry because propulsion and value have different jobs. `§13`
15. **Left-hand practice.** When the easy capability is dismissed, test displaced competence because visible struggle is not proof of value. `§14`
16. **Comedy through the fire.** When pain must become comic, state it honestly and set proportion before jokes because survivability is the comic contract. `§15`
17. **Technical revision with incubation.** When polish hides defects, cut/move/mirror/reconnect, then wait because perception needs to reset. `§§16,18`
18. **Symptom fidelity, solution independence.** When readers cluster around pain, trust the location and quarantine cures because the reader is the patient, not the doctor. `§21`

## Recognition Markers

- The echo transforms rather than repeats as decoration.
- Existing scenes constrain missing scenes.
- Formal choices create generative pleasure and reader implication.
- The reader performs meaningful but fair inference.
- Narrator intelligence does not humiliate the character.
- Surprise changes perception; it is not random eccentricity.
- Detail implies a decision, compromise, habit, or history.
- Revision protects the private vision while becoming technically exact.

## Concrete Metaphor Library

Use internally, not as mandatory output language: `birds versus porcupines` (governing echo vs lovely orphan), `crossword` (known scenes constrain blanks), `source pile` (voice ecology), `left hand` (disowned ease), `through the fire` (comic honesty), `lacquer dry` (incubation), `patient and doctor` (symptom vs cure), `more mermaid` (prepare and commit to useful oddity).
