# Workflow 07: Commitment Incentive Designer

> **Produces**: 3+ commitment incentives (bonuses, trials, contests) with conversion mechanisms
> **Use When**: Designing "front door" conversion mechanisms — Phase 3 of the campaign
> **Genius Context**: Load `genius.md` before executing
> **Prerequisite**: PEACE sound bites + Enlightenment collateral should exist (Workflows 02 + 06)

## Pre-Flight

**Required Inputs:**
- Completed PEACE Sound Bite System
- Business name, product, price point, and target customer
- Current conversion mechanism (if any — what is the existing CTA?)
- Conversion blockers (what stops people from buying? — price, trust, complexity, timing)

> **🔒 Pre-Flight Gate**: Curiosity and Enlightenment phases must exist before Commitment is designed. You cannot pull someone through the front door if there are no steps or porch. If Phases 1-2 are missing, redirect to Workflows 02-06 first.

## Execution

You are Donald Miller designing the front door — Phase 3 commitment incentives that remove the last barrier to purchase. The customer has climbed the steps (curiosity), crossed the porch (enlightenment), and now needs a reason to walk through the door.

### Step 1: Barrier Diagnosis

Identify the specific barriers preventing conversion. Not guesses — the actual friction points:

| Barrier Type | Specific Barrier | Severity | Sound Bite Counter |
|-------------|-----------------|----------|-------------------|
| **Price** | [specific price concern] | High/Med/Low | [which PEACE bite addresses this?] |
| **Trust** | [specific trust gap] | High/Med/Low | [which PEACE bite addresses this?] |
| **Complexity** | [specific confusion point] | High/Med/Low | [which PEACE bite addresses this?] |
| **Timing** | [why not now?] | High/Med/Low | [which PEACE bite addresses this?] |
| **Risk** | [what could go wrong?] | High/Med/Low | [which PEACE bite addresses this?] |

For each barrier, identify which PEACE sound bite directly counters it. The commitment incentive is built ON TOP of the sound bite foundation — not separate from it.

**Output**: Barrier diagnosis with sound bite mapping.

### Step 2: Design 3+ Commitment Incentives

For each incentive, provide the complete design:

**Incentive 1: The Risk Eliminator**
- **Type**: Free trial / money-back guarantee / first-session-free / pay-after-results
- **Barrier it removes**: [specific barrier from Step 1]
- **Mechanism**: [exactly how it works]
- **CTA copy**: [derived from Answer sound bite — zero cognitive load]
- **Sound bites embedded**: [which PEACE bites appear in the offer copy]
- **Cognitive load score**: 0 lbs

**Incentive 2: The Impulse Accelerator**
- **Type**: Limited-time bonus / bundle deal / exclusive access / early-bird pricing
- **Barrier it removes**: [specific barrier]
- **Scarcity mechanism**: [REAL scarcity, not manufactured urgency]
- **CTA copy**: [zero cognitive load]
- **Sound bites embedded**: [which PEACE bites]
- **Cognitive load score**: 0 lbs

**Incentive 3: The Belonging Invitation**
- **Type**: Community membership / founding member status / VIP access / cohort enrollment
- **Barrier it removes**: [specific barrier]
- **Identity connection**: [how this ties to the Change sound bite]
- **CTA copy**: [zero cognitive load]
- **Sound bites embedded**: [which PEACE bites]
- **Cognitive load score**: 0 lbs

**Optional Incentive 4+**: Design additional incentives for different barrier types.

**Output**: 3+ fully designed commitment incentives.

## Quality Gate

- [ ] Minimum 3 commitment incentives designed
- [ ] Each incentive removes a SPECIFIC barrier (not generic "makes it easier")
- [ ] Every copy block scores 0 cognitive load
- [ ] PEACE sound bites appear verbatim in every incentive
- [ ] At least one risk eliminator is included
- [ ] Scarcity mechanisms are REAL, not manufactured
- [ ] Conversion pathway sequences incentives logically
- [ ] CTA copy derives from Answer sound bite

**ENFORCEMENT**: Fake urgency ("Only 3 left!" when unlimited) = anti-pattern. Sound bite modifications = FATAL (GP6). Commitment without preceding Curiosity + Enlightenment = structural failure.

> **🛡️ Anti-Pattern Check**: Verify sequence integrity — commitment is Phase 3, NEVER Phase 1. Check against GP7 (Haunted House) in `genius.md`.
