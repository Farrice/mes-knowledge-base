# Workflow 08: Friction-Proof Copy Chain

> **Produces**: Copy that is zero-friction AND persuasive AND proven
> **Use When**: Building conversion-optimized copy that stacks multiple expert methodologies
> **Genius Context**: Load `genius.md` before executing
> **Stacking Chain**: Miller (cognitive load) → Wiebe (persuasion) → Iha (proof)

## Pre-Flight

**Required Inputs:**
- Copy objective (landing page, email, ad, sales page, social post — what are we building?)
- Business name, product, price point, and target customer
- Existing PEACE sound bites (from Workflow 02) — optional but accelerates
- Available proof assets (testimonials, case studies, stats, credentials — what proof exists?)
- Target awareness level: Unaware | Problem-Aware | Solution-Aware | Product-Aware | Most Aware

> **🔒 Pre-Flight Gate**: This is a Tier 3 stacking workflow. It chains three expert methodologies in sequence. Each layer builds on the previous. Do NOT skip layers or reorder them.

## Execution

You are executing a three-expert chain. Each expert is invoked in sequence, building on the previous layer's output. The chain produces copy that is simultaneously frictionless (Miller), persuasive (Wiebe), and credible (Iha).

### Layer 1: Miller — Zero Cognitive Load Foundation

**Expert**: Donald Miller — Cognitive Load Messaging
**Mission**: Establish the zero-friction messaging foundation

**Step 1a**: If PEACE sound bites exist, load them. If not, generate them using the PEACE framework (Workflow 02 logic).

**Step 1b**: Draft the initial copy structure using ONLY zero-load language:
- Lead with the Problem sound bite
- Position the guide (Empathy)
- Present the Answer
- Promise the Change
- Close with the End Result

**Step 1c**: Score every phrase. Total must equal 0 lbs. Any phrase above 0 is rewritten before proceeding.

**Layer 1 Output**:
```
══════════════════════════════════════════
LAYER 1: ZERO-FRICTION FOUNDATION
Cognitive Load: 0 lbs
══════════════════════════════════════════
[Draft copy — zero-load, PEACE-structured]
══════════════════════════════════════════
```

**Gate**: Layer 1 must score 0 lbs before Layer 2 begins. Non-negotiable.

### Layer 2: Wiebe — Persuasion Architecture

**Expert**: Joanna Wiebe — 5-Level Persuasion Hierarchy
**Mission**: Layer persuasion mechanics INTO the zero-load foundation WITHOUT adding cognitive weight

**Step 2a**: Classify the target awareness level and select the appropriate persuasion tier:

| Awareness Level | Wiebe Persuasion Tier | Primary Technique |
|----------------|----------------------|-------------------|
| Unaware | Level 5 — Narrative | Story-led, indirect problem agitation |
| Problem-Aware | Level 4 — Emotional | Empathy-driven, internal problem focus |
| Solution-Aware | Level 3 — Logical | Mechanism + differentiation |
| Product-Aware | Level 2 — Social Proof | Testimonials + results |
| Most Aware | Level 1 — Direct | Offer + CTA — minimal copy |

**Step 2b**: Enhance the Layer 1 copy with persuasion mechanics:
- Add emotional amplification to the Problem section (without increasing load)
- Layer in a persuasion mechanism (the HOW — why this solution works differently)
- Strengthen the CTA with Wiebe's resolution formula
- Add urgency/scarcity (real, not manufactured) where appropriate

**Step 2c**: Re-score every phrase after persuasion layering. If any phrase now exceeds 0 lbs, rewrite the persuasion element in zero-load language. Persuasion must NOT add friction.

**Layer 2 Output**:
```
══════════════════════════════════════════
LAYER 2: PERSUASION-ENHANCED
Cognitive Load: 0 lbs (maintained)
Persuasion Tier: [Level X]
══════════════════════════════════════════
[Enhanced copy — zero-load + persuasive]
══════════════════════════════════════════
```

**Gate**: Layer 2 must STILL score 0 lbs. Persuasion that adds load is rewritten.

### Layer 3: Iha — Proof Integration

**Expert**: Luke Iha — Proof Ladder Architecture
**Mission**: Embed proof at multiple tiers WITHOUT adding cognitive weight

**Step 3a**: Inventory available proof assets:

| Proof Tier | Asset | Available? | Cognitive Load Risk |
|-----------|-------|-----------|-------------------|
| Tier 1 — Social | Testimonials, reviews | ✅/❌ | Low (if specific) |
| Tier 2 — Statistical | Numbers, percentages, results | ✅/❌ | Medium (if abstract) |
| Tier 3 — Authority | Credentials, media, endorsements | ✅/❌ | High (if jargon-heavy) |
| Tier 4 — Experiential | Demos, trials, samples | ✅/❌ | Low (action-based) |

**Step 3b**: Integrate proof into the copy at strategic points:
- After the Problem (proof the problem is real and widespread)
- After the Answer (proof the solution works)
- Before the CTA (proof the risk is low)

**Step 3c**: Score all proof elements for cognitive load. Proof that requires interpretation is rewritten:
- ❌ "We've helped over 2,400 companies achieve organizational excellence" (+25 lbs)
- ✅ "2,400 teams. 94% fewer missed deadlines in 60 days." (0 lbs)

