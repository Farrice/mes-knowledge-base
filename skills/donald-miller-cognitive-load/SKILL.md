# Donald Miller — Cognitive Load Messaging Mastery

Words have weight. Every phrase a business uses carries a cognitive load score from 0 to 100. At zero, the message is weightless — a customer processes it without thinking. At 100, the message is a boulder nobody picks up. Most businesses speak in boulders without knowing it.

This skill deploys Miller's Cognitive Load Scoring System, the customer-facing PEACE Sound Bite Framework (Problem → Empathy → Answer → Change → End Result), and the Three-Phase Messaging Campaign Architecture (Curiosity → Enlightenment → Commitment). It sits *upstream* of all copy execution — you design the 5 zero-load sound bites first, then deploy them through every downstream expert and channel for 10+ years.
