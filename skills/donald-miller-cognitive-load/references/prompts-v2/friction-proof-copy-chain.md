## Role & Activation

You are executing a three-expert stacking chain in strict sequence: Miller (cognitive load) → Wiebe (persuasion) → Iha (proof). Each layer builds on the previous layer's output, and each layer must independently verify it has not undone the previous one. The chain produces copy that is simultaneously frictionless, persuasive, and credible — not a compromise between the three, but all three at once.

This is a Tier 3 stacking workflow. Layers may not be skipped or reordered — Miller's zero-load foundation must be locked before Wiebe's persuasion mechanics are layered in, and Wiebe's layer must still score 0 lbs before Iha's proof is added. The constraint is absolute: 0 lbs cognitive load at every stage, from Layer 1 through final assembly.

## Input Required

- **[COPY_OBJECTIVE]** — what's being built: landing page, email, ad, sales page, social post
- **[BUSINESS_NAME_PRICE_CUSTOMER]** — business name, product, price point, target customer
- **[PEACE_SOUND_BITES]** — optional; if it exists, load it — if not, generate it inline using the PEACE framework (Problem/Empathy/Answer/Change/End Result) before Layer 1 proceeds
- **[PROOF_ASSETS]** — available proof: testimonials, case studies, stats, credentials
- **[AWARENESS_LEVEL]** — Unaware | Problem-Aware | Solution-Aware | Product-Aware | Most Aware

**Pre-Flight Gate**: This chains three expert methodologies in sequence. Do not skip layers or reorder them — starting with Wiebe's persuasion mechanics before Miller's zero-load foundation is locked is a chain-sequence violation.

## Execution Protocol

### Layer 1 — Miller: Zero Cognitive Load Foundation
Establish the zero-friction foundation. If [PEACE_SOUND_BITES] exists, load it; otherwise generate it (Problem excavation → End Result bookend → Empathy → Answer → Change). Draft the initial copy structure using only zero-load language, in this order: lead with the Problem sound bite, position the guide (Empathy), present the Answer, promise the Change, close with the End Result. Score every phrase — total must equal 0 lbs. Any phrase above 0 is rewritten before Layer 2 begins.

**Gate**: Layer 1 must score 0 lbs before Layer 2 begins. Non-negotiable.

### Layer 2 — Wiebe: Persuasion Architecture
Layer persuasion mechanics into the zero-load foundation WITHOUT adding cognitive weight. Classify [AWARENESS_LEVEL] and select the matching persuasion tier:

| Awareness Level | Persuasion Tier | Primary Technique |
|---|---|---|
| Unaware | Level 5 — Narrative | Story-led, indirect problem agitation |
| Problem-Aware | Level 4 — Emotional | Empathy-driven, internal problem focus |
| Solution-Aware | Level 3 — Logical | Mechanism + differentiation |
| Product-Aware | Level 2 — Social Proof | Testimonials + results |
| Most Aware | Level 1 — Direct | Offer + CTA — minimal copy |

Enhance the Layer 1 copy: add emotional amplification to the Problem section without increasing load; layer in a persuasion mechanism (the HOW — why this solution works differently); strengthen the CTA with a resolution formula; add urgency/scarcity only if real, never manufactured. Re-score every phrase after persuasion layering — if any phrase now exceeds 0 lbs, rewrite the persuasion element in zero-load language. Persuasion must NOT add friction.

**Gate**: Layer 2 must STILL score 0 lbs. Persuasion that adds load gets rewritten, not kept.

### Layer 3 — Iha: Proof Integration
Embed proof at multiple tiers WITHOUT adding cognitive weight. Inventory [PROOF_ASSETS] against four tiers: Social (testimonials/reviews, low risk if specific), Statistical (numbers/percentages/results, medium risk if abstract), Authority (credentials/media/endorsements, high risk if jargon-heavy), Experiential (demos/trials/samples, low risk, action-based). Integrate proof at strategic points: after the Problem (proof the problem is real and widespread), after the Answer (proof the solution works), before the CTA (proof the risk is low). Score all proof elements — proof requiring interpretation gets rewritten (e.g. "We've helped over 2,400 companies achieve organizational excellence" at +25 lbs becomes "2,400 teams. 94% fewer missed deadlines in 60 days." at 0 lbs). Never fabricate a stat or proof asset not present in [PROOF_ASSETS] — if proof is thin, use fewer tiers rather than invent one.

### Step 4 — Final Assembly
Present the complete friction-proof copy with layer annotations: total cognitive load (must be 0), the persuasion tier used, the proof tiers used, the final deploy-ready copy, and a layer breakdown summarizing what each expert layer contributed.

## Output Contract

One Friction-Proof Copy deliverable containing: (1) Layer 1 output (zero-load PEACE-structured draft, annotated 0 lbs), (2) Layer 2 output (persuasion-enhanced, annotated 0 lbs + persuasion tier), (3) Layer 3 output (proof-fortified, annotated 0 lbs + proof tiers used), (4) final assembly with the complete deploy-ready copy and a layer breakdown. Each layer must be shown separately (not collapsed into only the final copy) so the audit trail is visible. The final total cognitive load must be exactly 0 lbs.

## Quality Gate

- [ ] Layer 1 scores exactly 0 lbs before Layer 2 begins — no layer skipping or reordering
- [ ] Layer 2 does not increase cognitive load above 0; any persuasion element that added weight has been rewritten, not left in
- [ ] Layer 3 proof elements all score 0 lbs, and no proof claim appears that isn't grounded in [PROOF_ASSETS]
- [ ] The final assembled copy maintains 0 lbs total and shows all three layers separately, not collapsed
- [ ] The selected persuasion tier matches [AWARENESS_LEVEL] per the mapping table

## Creative Latitude

The layer sequence and the 0-lbs gate at every stage are fixed. The craft is in how persuasion and proof get woven in without adding weight — that's a genuine constraint-under-pressure problem, not a checklist. Push for proof placement and persuasion mechanics that feel native to the copy's flow rather than bolted on; a testimonial dropped in as an afterthought reads differently than one integrated at the exact point of doubt it resolves. If [PROOF_ASSETS] is thin, do not pad Layer 3 with weak or generic proof — use fewer, sharper proof points over more, softer ones.

## Deploy When

Building conversion-optimized copy where friction-elimination, persuasion, and proof all need to be present simultaneously — landing pages, sales pages, high-stakes ads. Not for simple sound bite generation or campaign architecture; this is the compounding-stack deliverable for a single piece of copy that needs to do the most work.
