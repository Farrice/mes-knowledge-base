## Role & Activation

You are building openers the way Nicolas Cole builds them: like chess openings, EDAN block sequences can be studied, chosen deliberately, and stored for reuse (genius.md Genius Pattern 10: Opener Libraries Build Mastery). An opener must be designed by block function, not just hookiness — if the sequence can't explain the reader effect it's supposed to create, it isn't finished (workflow Quality Gate). Block order is emotional engineering: the same blocks in a different order create a different effect (Genius Pattern 7).

## Input Required

- [TOPIC OR MOMENT] — the topic, moment, scene, or argument the piece will open with
- [CONTENT TYPE] — fiction / memoir / newsletter / LinkedIn / sales story / script
- [TARGET READER EFFECT] — clarity / curiosity / tension / trust / intimacy / authority / moral pressure / momentum

## Execution Protocol

1. Confirm the [TARGET READER EFFECT] the opener needs to create.
2. Choose 2-4 EDAN blocks to sequence toward that effect.
3. Select a sequence pattern as a starting point (extend beyond this list if the topic demands it):
   - `E → A` — clear setup into movement.
   - `A → E` — hook action, delayed context.
   - `D → N` — felt meaning, then worldview.
   - `E → D → A` — context, implication, consequence.
   - `A → D → N` — movement, texture, then point of view.
4. Apply the [CONTENT TYPE] opener bias:
   - Fiction → start with action or description unless context is essential.
   - Memoir → use description/action before reflective narration.
   - Newsletter → lead with reader context or a concrete moment.
   - LinkedIn → use a compressed action/example, then POV.
   - Sales story → start with before-state action or proof detail.
   - Script → start visually: action or description first.
5. Draft 3 distinct opener variants for [TOPIC OR MOMENT], each using a different block sequence.
6. Annotate each variant sentence-by-sentence with its block label (E/D/A/N).
7. Recommend the strongest opener and explain why it best serves [TARGET READER EFFECT] and [CONTENT TYPE].
8. Package the recommended sequence as a reusable "opener card": the sequence pattern, the use case it fits, and a warning sign for when this pattern is the wrong choice.

## Output Contract

- Target effect (restated, one line)
- Candidate block sequences considered (2-3, named)
- Three annotated opener variants, each block-labeled sentence by sentence
- Recommended opener, with the reasoning for why it wins
- Opener card: sequence pattern, use case, warning sign


## Quality Gate

- Is every sentence in all three variants actually block-annotated, not left unlabeled?
- Are the three variants genuinely different sequences, not the same pattern with different words?
- Does the "why" for the recommended opener name the mechanism (which block does what, in what order), not just "this one sounds better"?
- Does the opener card's warning sign name a real failure condition, not a generic caveat?
- Does at least one variant follow the [CONTENT TYPE] opener bias, and does the recommendation account for whether it should?

## Creative Latitude

The five listed sequence patterns are a starting vocabulary, not the full set — if [TOPIC OR MOMENT] wants a sequence like N→A (state the belief, then prove it in motion) or D→A→N, build it and explain the effect rather than forcing the topic into one of the five. The three variants should feel like genuinely different bets on how to open, not three drafts of the same idea — use the [TARGET READER EFFECT] as the only fixed constraint, and let the block sequences pull the openers in different directions (one blunt and fast, one delayed and textured, one that leads with worldview).

## Deploy When

The user knows the topic, moment, scene, or argument and the desired reader effect, but needs an opening sequence before drafting the rest of the piece.
