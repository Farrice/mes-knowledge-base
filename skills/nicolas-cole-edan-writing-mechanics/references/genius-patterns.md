# Genius Patterns

## 1. Unbundle Writing Before Improving It
Treat "writing" as a bundled term. The useful coaching question is not "how do I write better?" but "which writing function am I practicing or failing to use?"

## 2. EDAN Classification Before Taste Judgment
Classify the passage first. A passage that feels boring may be all Explanation. A passage that feels busy may be all Action. A passage that feels vague may lack Description. A passage that feels generic may lack Narration.

## 3. Explanation As Context Timing
Explanation can appear before, after, or long before the moment it activates. The craft decision is timing: does the reader need this context now, later, or not at all?

## 4. Description As Implied Meaning
Description is strongest when it carries meaning the writer could have explained directly. The test: what will the reader infer from this detail?

## 5. Action As Consequence
Action is not motion. Action is a change-maker. It should move plot, reveal motive, prove behavior, escalate stakes, or create a before/after.

## 6. Narration As Worldview
Narration is where the narrator or author peeks through with a belief. It is the power source for theme and voice, so it should be sharp and protected.

## 7. Block Order As Emotional Engineering
The same blocks in a different order create different effects:

| Sequence | Likely Effect |
|---|---|
| E -> A | Clear stakes, direct momentum |
| A -> E | Curiosity, delayed understanding |
| D -> N | Felt implication followed by worldview |
| E -> D -> A | Context, felt scene, then consequence |
| A -> D -> N | Motion, texture, then meaning |

## 8. Deliberate Practice As Skill Isolation
Volume helps only until the writer plateaus. The upgrade path is isolate one block, study better models, practice reps, then integrate the block back into live work.

## 9. Opener Library Thinking
Writers can collect EDAN combinations the way chess players collect openers. Each saved sequence should include target effect, block order, example use, and warning signs.

## 10. Cross-Format Adaptation
EDAN applies across formats, but the block mix changes:

| Format | Likely Bias | EDAN Risk |
|---|---|---|
| Newsletter | Explanation + Narration | Too much telling, not enough scene or action |
| LinkedIn post | Action + Explanation | Generic lesson with no description or POV |
| Fiction scene | Action + Description | Beautiful motion without enough context |
| Case study | Explanation + Action | No implied meaning or human point of view |
| Sales story | Explanation + Narration | Claim-heavy without proof moments |
