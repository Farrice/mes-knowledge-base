# Genius Patterns

## 1. Unbundle Writing Before Improving It
Treat "writing" as a bundled term. Cole names the standard version of this failure directly: "write what you feel, write what you love, be honest on the page" is a set of "bundled instructions" that require "a lot of subjective interpretation" (`gAVbSZHwzNU`, 00:06:26-00:06:41). The useful coaching question is not "how do I write better?" but "which writing function am I practicing or failing to use?"

## 2. EDAN Classification Before Taste Judgment
Classify the passage first. A passage that feels boring may be all Explanation. A passage that feels busy may be all Action — Cole's own counter-example is a character narrating four flat steps in a row (00:16:12-00:16:23). A passage that feels vague may lack Description. A passage that feels generic may lack Narration.

## 3. Explanation As Context Timing
Explanation can appear before, after, or long before the moment it activates. Cole's chess parallel: "moving a bishop into place and that bishop not actually activating its position for 10 moves into the future" (00:11:06-00:11:30). The craft decision is timing: does the reader need this context now, later, or not at all?

## 4. Description As Implied Meaning
Description is strongest when it carries meaning the writer could have explained directly. Cole's benchmark authors for this move are Nikolai Gogol and Anton Chekhov, whose Russian-literature style "doesn't explain anything" and instead forces the reader to "extract the meaning" from specific description (00:11:54-00:12:22). The test: what will the reader infer from this detail?

## 5. Action As Consequence
Action is not motion. Cole's illustration spans a genre spectrum — from *Mission: Impossible*-style "explosions happening" to a single "very subtle thing" in "an Academy Award-winning film" that lands harder because of everything staged around it (00:17:04-00:18:33). Action should move plot, reveal motive, prove behavior, escalate stakes, or create a before/after.

## 6. Narration As Worldview
Narration is where the narrator or author peeks through with a belief. Cole's fully worked passage: "We hadn't talked all summer, not since his mom died and my parents got divorced. And that's the thing about divorce is it's selfish because it hurts the people around you more than it hurts the people getting divorced" (00:19:57-00:20:12) — the first clause is Explanation, the second is Narration voicing an opinion. It is the power source for theme and voice, so it should be sharp and protected.

## 7. Block Order As Emotional Engineering
The same blocks in a different order create different effects:

| Sequence | Likely Effect |
|---|---|
| E -> A | Clear stakes, direct momentum |
| A -> E | Curiosity, delayed understanding |
| D -> N | Felt implication followed by worldview |
| E -> D -> A | Context, felt scene, then consequence |
| A -> D -> N | Motion, texture, then meaning |

Cole's own version of this idea: writers "start you start to realize why certain pieces of writing elicit the feelings that they do in you" once the block order is visible (00:04:53-00:05:04).

## 8. Deliberate Practice As Skill Isolation
Volume helps only until the writer plateaus. Cole cites the book *Peak* by name and its recreational-golfer example: someone who plays "once a month or twice a month" for years stays "roughly the same," because the jump requires "upgrading your mental model," then isolating and drilling one piece "over and over and over again" (00:24:38-00:24:46, 00:26:32-00:26:48, 00:27:23-00:27:27). The upgrade path is isolate one block, study better models, practice reps, then integrate the block back into live work.

## 9. Opener Library Thinking
Writers can collect EDAN combinations the way chess players collect openers — Cole references buying "a bunch of chess books" and describes a chess-opener book "the size of a dictionary that is nothing but openers" (00:07:22-00:07:34). He keeps a running doc logging each new combination as "opener number one," "opener number two," "opener number three" (00:31:57-00:32:24). Each saved sequence should include target effect, block order, example use, and warning signs.

## 10. Cross-Format Adaptation
EDAN applies across formats, but the block mix changes. Cole's own claim about hierarchy: "explanation and action are the two pieces that get used the most," description is "the next most advanced piece," and narration is "the most advanced piece" (00:22:54-00:23:15) — and he notes that Pulitzer- and Nobel-tier literature is distinguished less by story quality than by the density of narration moments (00:23:25-00:24:08).

| Format | Likely Bias | EDAN Risk |
|---|---|---|
| Newsletter | Explanation + Narration | Too much telling, not enough scene or action |
| LinkedIn post | Action + Explanation | Generic lesson with no description or POV |
| Fiction scene | Action + Description | Beautiful motion without enough context |
| Case study | Explanation + Action | No implied meaning or human point of view |
| Sales story | Explanation + Narration | Claim-heavy without proof moments |
