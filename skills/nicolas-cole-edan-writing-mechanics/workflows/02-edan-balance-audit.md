# EDAN Balance Audit

## Pre-Flight Gate

Use this when a piece feels flat, slow, preachy, vague, busy, overly abstract, or hard to revise.

## Skill Acquisition

Load:

- `skills/nicolas-cole-edan-writing-mechanics/genius.md`
- `skills/nicolas-cole-edan-writing-mechanics/references/hidden-knowledge.md`
- `skills/nicolas-cole-edan-writing-mechanics/references/quality-rubric.md`

## Execution

1. Run a quick EDAN classification on the draft or sample.
2. Name the dominant block and the missing block.
3. Diagnose the likely reader experience:
   - Too much Explanation: clear but lifeless, lecture-like, or slow.
   - Too much Description: pretty but unclear, indulgent, or low momentum.
   - Too much Action: busy but shallow, motion without meaning.
   - Too much Narration: preachy, abstract, or over-thematic.
4. Identify three places where a block swap would improve the piece.
5. Prescribe exact repair moves:
   - Cut.
   - Move earlier/later.
   - Replace E with D.
   - Add E before A.
   - Add N after D/A.
   - Turn vague N into concrete D.
6. Provide before/after micro-rewrites for the highest-leverage 2-3 spots.
7. Score the draft against the EDAN quality rubric.

## Content Type Adaptations

| Type | Audit Bias |
|---|---|
| Fiction | Preserve mystery; avoid overexplaining motives |
| Nonfiction | Keep reader value clear; add examples/actions where claims float |
| Thought leadership | Balance POV with proof moments |
| Brand story | Turn abstract values into scenes/actions |
| Sales copy | Add proof action before broad narration |
| Script | Ensure action and description create visual momentum |

## Output Requirements

Return:

1. One-sentence diagnosis.
2. EDAN ratio.
3. Imbalance table.
4. Repair sequence.
5. 2-3 rewrites.
6. Rubric score.
7. Next workflow to run.

## Quality Gate

Do not recommend "make it more vivid" or "show more." Specify which block changes and why.
