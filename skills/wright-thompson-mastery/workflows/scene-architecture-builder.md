# Scene Architecture Builder

Scenes are the fundamental unit of narrative. Not paragraphs, not arguments, not sections — scenes. Thompson: "Every single section, every scene needs to hit a different note so it's not repetitive." This workflow constructs a scene sequence that has the structural integrity of a screenplay and the emotional depth of a novel.

## Execution

### Requirements

The user provides **raw material for a multi-scene piece** — reporting notes, an outline, a rough draft that needs structural overhaul, or a set of scenes that feel disconnected. This workflow produces a scene map with structural logic for every transition.

### Step 1: Inventory the Raw Material

List every potential scene — every distinct moment, setting, or dramatic unit — in the raw material. For each scene, note:

- **Setting**: Where and when does this happen?
- **Action**: What is observably happening?
- **Emotional Note**: What does this scene make the reader feel? (Name the specific emotion, not the topic.)
- **Thematic Load**: What idea or question does this scene carry? (If it carries no thematic weight, flag it as potentially decorative.)

Don't evaluate yet. Just inventory.

### Step 2: The Note Map

Now arrange the scenes by emotional note. Thompson's rule: "Every single section, every scene needs to hit a different note so it's not repetitive."

Create a Note Map:
- Assign each scene a one-word emotional note (e.g., Intimacy, Tension, Loss, Defiance, Stillness, Violence, Joy, Revelation)
- Flag any scenes that hit the same note as another scene
- Mark which notes are missing from the overall sequence

**The Repetition Kill**: If two scenes hit the same note, one of them is redundant. You must either cut one, find a way to shift its note, or merge them. Repetition of effect is death (Anti-Pattern 3, genius.md).

### Step 3: The Structural Spine

Now build the spine — the sequence in which scenes should appear. Thompson's method is cinematic: "A section is the equivalent of a chapter."

For each position in the sequence, answer:

1. **Opening Scene**: What concrete moment drops the reader into the world? (Never start with context. Start with a human being doing something.)
2. **Second-Section Verb**: Which scene expands from micro to macro? (Pattern 7 — this is the structural hinge.)
3. **Interior Sections**: What note does each section need to hit to vary the emotional texture? How does each scene provide a different piece of the answer to the thematic question?
4. **Pre-Hammer Scene**: What scene creates the maximum runway for the hammer without telegraphing it?
5. **Hammer**: What scene lands the emotional payload? (Pattern 1.)

### Step 4: Transition Logic

For every scene-to-scene transition, define:

- **The Bridge Element**: What concrete detail, character, or image carries the reader from one scene to the next? (A name, a place, an object, a line of dialogue.)
- **The Pressure Direction**: Does the pressure increase, decrease, or shift direction? (Thompson on books: "Push a ball downhill and clear out all the obstacles so it rolls.")
- **The Time Move**: How does time shift? (Forward? Backward? Different scale?) Is the shift smooth or does it "depressurize the cabin"? (Anti-Pattern 4, genius.md.)

### Step 5: The Feel-In-The-Seat Test

Thompson on outlining vs. feeling: "I'm going to have a better idea in the seat of what works than whatever theory I had standing in front of my wall."

Read the scene sequence as if you're experiencing it for the first time:

- **Does every scene feel necessary?** If a scene could be removed without the reader missing it → cut.
- **Does the sequence build?** Not necessarily in intensity — but in cumulative understanding. Each scene should add a layer the reader didn't have.
- **Does the sequence feel like it was made or found?** Thompson: "I'm not trying to make the path. I'm trying to see the path that was there before I got there." If the architecture feels imposed, loosen it. Leave room for discovery.

## Output Requirements

**Deliver**:
1. **Scene Inventory** — every potential scene with setting, action, emotional note, thematic load
2. **Note Map** — scenes arranged by emotional note, duplicates flagged, missing notes identified
3. **Structural Spine** — the full sequence with structural role of each scene
4. **Transition Map** — bridge element, pressure direction, and time move for each transition
5. **Cut List** — scenes removed from the final architecture with reasons
6. **Architecture Score** — 1-10 on whether the sequence feels discovered (good) or assembled (bad)

## Content Type Adaptations

| Content Type | Scene Architecture Adaptation |
|-------------|-------------------------------|
| **Magazine Profile** | Full workflow applies. 5-8 scenes typical. Each scene is a chapter. |
| **Book Chapter** | Multiple scene layers — the chapter has its own spine, but each scene must also serve the book's macro architecture. Map both. |
| **Newsletter** | 2-3 scenes maximum. The opening scene, the pivot, the close. Step 2 (Note Map) is critical even at this scale. |
| **Video Script** | Scenes = visual sequences. Bridge elements become visual motifs. Time moves become cuts. |
| **Personal Essay** | Fewer scenes (3-5), but each must carry more thematic weight. The essay's power comes from density, not breadth. |
| **Podcast Episode** | Scenes = segments. Transition logic becomes the host's connective tissue. Cold open = opening scene. |
