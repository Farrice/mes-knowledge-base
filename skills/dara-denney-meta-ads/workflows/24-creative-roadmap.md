# `/dara-creative-roadmap` — Quarterly Plan → Monthly Roadmap → Testing Sheet

The planning gap is the other big strategist gap: "they'll get on a weekly sprint schedule and never be able to get out of it… never able to see the bigger picture or take much bigger swings." The fix is an altitude ladder: **quarterly planning** (launches, seasonal persona pushes, big swings in format/content-type/creators) → **monthly roadmap** (strategic sequencing) → the **Creative Testing Roadmap sheet** that the weekly sprint executes from. "You can actually just add strategy to your overall creative approach if you implement this thinking."

## Genius Context (Load First)

- **Pattern 17**: every roadmap row traces to a gap
- **Pattern 16**: Winner × Persona Replication rows are the cheapest tests on the sheet

## Input Required

- Mission doc + gap audit (`/dara-mission-doc`, `/dara-gap-analysis`)
- Business calendar: product launches, seasonal moments, retail/press events (from the reputation analysis press scan)
- Production reality: creator pipeline status, design capacity, budget rhythm

## Execution

1. **Quarterly plan** — per quarter: the 1-2 big swings (new persona push, new platform trend adoption, partnership-ad pipeline build, creator-program diversification), anchored to the business calendar (launch windows, seasonal personas — "attack certain personas in this time of year").
2. **Monthly roadmap** — sequence the gap-closing concept directions into months: which gap, which persona, which pillar angle, which format, expected learning. Balance: every month carries ≥1 TOF/ecosystem play alongside BOF winners, ≥1 low-cost replication row when winners exist, and no more than one bounded C/D challenger unless live evidence changes the source prior.
3. **Creative Testing Roadmap sheet** — the exact artifact from her Oats Overnight build. Columns:
   | Test # | Concept Name | Nº Variations (3-6) | Winning Element (Hook / Angle / Format / Storyline) | Creative Type (UGC / Video / Image / Carousels) |
   Concept names carry their research trace in the name where possible ("DEAR DIY'ers…" ← DIY objection; "FULLNESS CHASER STATICS" ← satiety gap). 8-12 rows per month is the working density.
4. **Winning-element hypothesis discipline** — each row names WHICH element it's testing (a row that tests everything learns nothing).
5. **Wire the loop** — Day-30 readout feeds next month's roadmap; quarterly review re-tags arbitrage stages and re-ranks personas.

## Output Schema

Template: `references/templates/creative-testing-roadmap.md`. Three blocks: Quarterly Plan (per-Q big swings + calendar anchors) · Monthly Roadmap (month → gap → persona → angle → format → expected learning) · Testing Roadmap sheet (the 5-column table, ready to paste into Sheets/Notion). Handoff: rows execute through the Tier-1 production workflows (01-17) and `/dara-test-plan` for matrix months.

## Context Adaptations

| Context | Adaptation |
|---|---|
| Brand client | The engagement's operating rhythm; review monthly with the client |
| Personal brand | Quarterly content swings + monthly pillar sequencing + a testing sheet for hooks/formats on your own posts |
| Agency/multi-brand | One sheet per brand; the quarterly layer is where cross-brand arbitrage patterns transfer |

## Quality Gate

- All three altitudes present — a testing sheet alone = still the sprint trap.
- Every row: gap-traced concept name + ONE winning-element hypothesis + variation count 3-6 + creative type.
- Calendar anchors real (from press/business scan), not decorative.
- TOF presence every month unless the awareness audit says otherwise.
- STOP CONDITION: no mission doc/gap audit yet → run those first; a roadmap without named gaps is churn-and-burn with better formatting.

## When to Return

- Monthly (rolling) · quarterly (big swings + arbitrage re-tag) · after any launch/press event that changes the calendar.
