# `/dara-mission-doc` — The Creative Strategy Mission Doc

The fourth artifact of her SOP ("Fourth: Create the Mission Doc"). Everything upstream was evidence; this is the strategy. One document that answers, for the next quarter: who we're targeting and why (personas + receipts), what we're saying to them (pillar angles), where the gaps are and which we're closing first, which platform trends we're riding, and how we'll know the strategy is right. It is the anti-"copy the competitors" and the anti-"just test more formats" document.

## Genius Context (Load First)

Read `genius.md` — Creative Strategy OS layer, especially:
- The Core Thesis: real strategy = the layer before format selection (personas · pillar angles · platform trends)
- **Pattern 17**: Three-Gap Diagnosis Before Any Concept
- **Pattern 20**: Organic-Echo Validation — a strategy is validated when it shows up in organic too
- **Pattern 12**: the Mission Doc is ALSO an LLM context doc — it governs every future ad prompt

## Input Required

The three upstream artifacts: reputation analysis · review-mining/AI-analysis doc · persona deck (+ gap audit if run). Plus: business context — what does the business actually want to achieve next (launches, seasons, AOV goals, retail moves from the press scan)?

## Execution

1. **The single truth** — one paragraph: what the evidence says is really going on with this brand's growth (THE friction point, the hottest underserved segment, the honest state of the account).
2. **Strategy pillars** — the layer before formats:
   - **Personas**: the 2-4 activation segments + the net-new injection, each with receipts and its role (scale / efficiency / net-new).
   - **Pillar angles**: 2-3 per persona — big pillar pain-point ideas (angles, NOT concepts).
   - **Platform trends**: the macro plays being ridden (EGC, partnership ads, whatever is current) and why.
3. **Gap-closing priorities** — from `/dara-gap-analysis`, ranked; each with its closing move.
4. **Why-this logic** — for the top 5 planned creative directions, the one-line answer to "why this creative / this persona / this angle?" (traceability standard).
5. **Validation criteria** — what tells us the STRATEGY is right (not just an ad): organic echo, multi-cell pattern across the test matrix, persona-level CAC/AOV movement — a single creative test cannot validate a strategy.
6. **Merchandising notes** — bundle/AOV proposals if Step 1 triggered them.
7. **Cadence commitment** — quarterly plan anchors + monthly roadmap rhythm (hand to `/dara-creative-roadmap`).

## Output Schema

Template: `references/templates/mission-doc-template.md`. 2-4 pages, client-readable, promptable. Header note: "Attach this doc to any AI session producing creative for this brand — it is the governing context."

## Context Adaptations

| Context | Adaptation |
|---|---|
| Brand client | The engagement's north-star doc; review with the team like Dara reviews the persona deck |
| Personal brand | Personal content mission doc: segments, pillar angles, platform trends, gaps in your own calendar |
| Agency/multi-brand | One per brand; the portfolio view lives in the roadmap layer |

## Quality Gate

- Could a new strategist (or an LLM) produce on-strategy creative from this doc ALONE? If not, it's incomplete.
- Personas carry receipts; angles are pillar-level; every direction has its why-this line.
- Validation criteria present — strategy-level, not ad-level.
- No competitor-copying as strategy; no format list masquerading as strategy.
- 2-4 pages. Density > completeness — this is a governing doc, not an archive.

## When to Return

- Quarterly rewrite · after major press/product events · when the team starts asking "what should we test next?" (the doc should already answer it).
