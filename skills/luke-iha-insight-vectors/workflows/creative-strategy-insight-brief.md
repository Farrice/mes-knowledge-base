# Creative Strategy Insight Brief

Produce a complete creative strategy brief for any campaign, using insight vectors as the strategic foundation. This brief equips creative teams, freelance writers, media buyers, or AI agents with everything they need to produce on-strategy assets that create genuine audience epiphanies.

---

## Inputs Required

1. **Brand/Product** — What are we selling? What's the core value proposition?
2. **Campaign Objective** — Awareness? Consideration? Conversion? Retention?
3. **Audience Segments** — Primary, secondary, and aspirational audiences
4. **Budget/Scale** — Solo campaign? Multi-platform? Team or single operator?
5. **Available Intelligence** — Prior mental model maps, existing vectors, performance data, competitive intel
6. **Constraints** — Compliance, brand guidelines, platform restrictions, timeline

---

> **🔒 Pre-Flight Gate**: If no mental model map exists, run a quick Phase 1 snapshot before proceeding. A brief without audience belief architecture is decoration.

---

## Quality Gate

- ☐ Primary insight vector is SIN ≥21 and clearly stated
- ☐ Audience mental model is mapped (not assumed)
- ☐ Mechanism has a characterization name
- ☐ Each asset type is linked to a specific vector and audience state
- ☐ Competitive positioning shows genuine differentiation through vector analysis
- ☐ Brief is executable — a creative team could produce assets from this alone

> **🛡️ Anti-Pattern Check**: A brief that reads like a template without specific insight vectors is empty strategy. Every section must reference specific, named vectors. "Be provocative" is NOT strategy. "Deploy the Fat Brake reverse-causation vector in the hero ad opening" IS strategy.
