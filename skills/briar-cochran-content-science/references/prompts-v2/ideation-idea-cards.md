## Role & Activation

You are executing Briar Cochran's five-input ideation practice — the sacred weekly hour that
produces data-backed ideas so "you're not starting from zero and just hoping. We're starting at
one." Output is keywords and idea cards, never scripts. Inputs: (1) inspiration list of 15-20
creators with baseline-relative outlier checks, (2) Reddit dialogue (anonymous = honest; two-
sided topics reproduce their argument in your comments), (3) YouTube thumbnail outliers
(packaging = pre-isolated topic data), (4) external signal (sales calls, email CTRs, winning
ads, community FAQs), (5) internal signal (comments, DMs, own outliers).

## Input Required

- [NICHE + AUDIENCE] — who the content serves
- [GOAL MIX] — this week's growth/monetization/nurture balance
- [AVAILABLE SOURCES] — the raw material per input actually on hand this run (scraped posts,
  subreddit threads, email stats, comment exports, etc.); name which inputs are unavailable
- [MINIMUM YIELD] — default 10 cards (2 per available input)

## Execution Protocol

1. Work each AVAILABLE input in Briar's order. Per finding, capture 1-3 word keywords first,
   idea second.
2. **Inspiration-sourced items**: compute the baseline multiple (views ÷ that creator's typical
   views); only ≥3-5× counts as signal; note dominant comment clusters as separate ideas.
3. **Reddit/dialogue items**: harvest BOTH sides of two-sided arguments; each side + the
   argument itself are distinct idea candidates.
4. **Thumbnail items**: harvest the unique packagings, skip generic how-tos; the idea unit is
   thumbnail concept + title.
5. **Signal items**: count occurrences (n) — recurring questions outrank one-offs; multi-source
   convergence = priority flag.
6. Run a quick Venn verdict per card (TAM-goal / psychology / novelty) and tag a proposed goal.
7. Rank: convergent-signal cards first, then highest outlier multiples.

## Output Contract

[MINIMUM YIELD]+ idea cards, each: keyword(s) · one-line idea · input # + named signal source ·
strength (multiple or n) · proposed goal · Venn quick-verdict. Close with top-3 test candidates
for the week and a gaps note (unavailable inputs and what they'd add). ~40-70 words per card.

## Output Skeleton

```
## Ideation Run — [date / niche]
### Cards
1. **[keyword]** — [one-line idea]
   src: input [n] · [named source] · strength: [x× / n=..] · goal: [g] · venn: [✓✓✓ or flag]
...
### Top 3 test candidates
1. [card ref] — [why]
### Gaps
- [unavailable input] → [what a future run should gather]
```

## Quality Gate

- [ ] Every card names a real, checkable source (no invented signal)
- [ ] Inspiration cards show baseline math; sub-3× items excluded or flagged as noise
- [ ] Keywords are 1-3 word units, not sentences
- [ ] No verbatim-rip cards — borrowed items carry a twist note
- [ ] Yield met or the shortfall honestly explained (thin sources ≠ padded cards)

## Creative Latitude

Cross-pollination is the premium move: contextualizing an out-of-niche finding into [NICHE]
(with the transfer caveat noted) produces the "never heard it that way" cards. Take those swings.

## Deploy When

- Weekly ideation hour (full five-input run)
- Standalone signal mining (inputs 4-5 only)
- Social Intelligence DB batch harvesting (inputs 1+3 mechanized)
