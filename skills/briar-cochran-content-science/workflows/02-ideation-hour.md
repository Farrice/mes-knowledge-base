# The Ideation Hour (Five Inputs)

The sacred weekly hour. Output is keywords and idea cards, never scripts. "We're not starting
from zero and just hoping. We're starting at one."

## Pre-Flight Gate

Load `../genius.md` → Five-Input table. Confirm: niche + audience definition, the week's goals
mix (growth/monetization/nurture), and which inputs have live sources available this session
(Social Intelligence DB batches count as Input 1/3 — see /bc-intel-bridge).

## Skill Acquisition

- `../genius.md` (five inputs, Venn, signal doctrine)
- `../references/frameworks.md` §2, §4
- Optional stack: `skills/alex-content-science/` Detail Stack for any outlier worth forensics

## Execution

Work the five inputs in order; jot 1-3 word keywords + idea seeds as you go:

1. **Inspiration list** — sweep the 15-20 tracked creators (burner account / Social Intelligence
   DB). For every candidate: run the Baseline Click (views ÷ creator's baseline; only ≥3-5×
   counts). Note comment clusters under nuclear videos — each cluster is an idea.
2. **Reddit** — 15-20 niche subreddits (≥50-100K members), sorted top of week/month. Dump the
   biggest threads into analysis: "what are people talking about here?" Harvest both sides of
   two-sided arguments (they reproduce their argument in your comments).
3. **YouTube thumbnails** — scan 5-10 niche keywords through an outlier finder. Packaging =
   pre-isolated topic data; harvest the unique thumbnails, skip the generic how-tos.
4. **External signal** — sales-call FAQs, top email subject CTRs, winning paid ads, community
   call questions. Each recurring question = one video.
5. **Internal signal** — own comments, DMs, view outliers vs own baseline.

Then: minimum 2 ideas per input → 10+ idea cards. Pass the strongest through the Venn (Workflow
01 logic) inline; tag each card with its signal source and a proposed goal.

## Content Type Adaptations

| Type | Adaptation |
|------|-----------|
| Personal brand (Farrice) | Input 4 = client calls, Substack replies, LinkedIn DMs; thought-bank inbox counts as internal signal |
| Client engine | Inputs 1-3 scoped to client's niche list; goals from client funnel |
| B2B/LinkedIn | Reddit → also niche Slack/Discord/LinkedIn comments as dialogue source |
| E-commerce (MyBPM) | Input 4 = reviews, support tickets; Input 3 includes TikTok Shop outliers |

## Output Requirements

10+ idea cards: keyword(s) · one-line idea · signal source (named) · outlier math if applicable
· proposed goal · Venn quick-verdict. Flag the top 3 as this week's test candidates.
Execution prompt: references/prompts-v2/ideation-idea-cards.md — honor its Output Contract.

## Quality Gate

Every card has a NAMED signal source (no guess-from-zero). Baseline math shown for any
inspiration-sourced card. No card is a verbatim rip — twist noted where borrowed. Keywords pass
the insider read-aloud.
