# Idea Venn Gate

Score ideas BEFORE production. A great idea sits in all three circles; the center is
psychological alignment — the audience's ears perk up.

## Pre-Flight Gate

Load `../genius.md` → Decision Framework. Confirm you have: the idea(s), the account's niche,
and the DECLARED GOAL per idea (growth / monetization / nurture). No declared goal = stop and
get one — TAM cannot be judged without it.

## Skill Acquisition

- `../genius.md` (Venn, insider test, anti-patterns)
- `../references/frameworks.md` §2
- If wording matters: `../references/source-quotes.md` (wrestler calibration, keyword examples)

## Execution

1. **TAM sizing**: Estimate who this idea can be FOR (order of magnitude). Verdict: matched /
   too broad / too narrow **relative to the declared goal** — a 10K-view idea can be the win
   (media-team receipt). Flag too-high-TAM stunts that would poison follower quality.
2. **Specific psychology**: Extract the idea's core keyword(s). Run the insider read-aloud —
   would a practitioner at the target level actually say this, or does it out you ("teach you a
   takedown")? Is the keyword alive in the niche right now ("yapping") or burned ("viral")?
3. **Unique/Novel**: Would the target audience say "I've never heard it that way"? Identify the
   twist; if none exists, propose one (angle, mechanism, contrast, extension of a borrowed model
   where it breaks — Briar's own Chris Rock move).
4. **Signal check**: Name the data source backing the idea (subreddit, outlier, DM cluster,
   sales-call FAQ). None = mark GUESS and route to /bc-ideation-hour or /bc-signal-mine.
5. **Verdict**: PASS (all three + signal) / REWORK (name the failing circle + the fix) / KILL.

## Content Type Adaptations

| Type | Adaptation |
|------|-----------|
| Short-form video | Keyword must survive as spoken first line (non-hook) |
| LinkedIn/Substack post | TAM maps to reader identity; insider test on the headline |
| YouTube long-form | TAM judged against packaging (thumbnail+title carry attribution) |
| Client content | Goal comes from the client's funnel stage, not from reach |

## Output Requirements

Per idea: three-circle verdict table, signal source, goal-TAM statement, the failing circle +
concrete fix (reworded keyword, twist, or resize), final PASS/REWORK/KILL.
Execution prompt: references/prompts-v2/idea-gate-scorecard.md — honor its Output Contract.

## Quality Gate

Check against `../genius.md` anti-patterns: no raw-view worship, no guess-from-zero, no
too-high-TAM stunt, no verbatim rip. Any ≥8/10 idea must name which exemplar-standard it matches.
