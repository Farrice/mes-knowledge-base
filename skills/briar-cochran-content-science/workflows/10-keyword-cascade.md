# Keyword Cascade (Belonging Piece)

The purest demonstration of ideation-as-content: "all this video is is just him doing great
ideation and then just saying the keywords in a linear fashion." Zero narrative, zero hook
craft — the keywords ARE the video.

## Pre-Flight Gate

Load `../genius.md` → Kolby exemplar. Required: a validated keyword ledger for the niche
(/bc-keyword-snipe output — 10+ HOT/STABLE insider keywords). Without a ledger, run the snipe
first; cascades built from guessed keywords are dead on arrival.

## Skill Acquisition

- `../genius.md` (exemplar verbatim, specific psychology)
- `../references/source-quotes.md` (Kolby cascade full text)
- Voice: if shipping under Farrice's name, load `_active/farrice-brand/voice/VOICE-CARD.md` +
  dial mode (binding farrice_voice_alignment)

## Execution

1. **Select 10-15 keywords** from the ledger — order for emotional build: recognition →
   identity → aspiration (Kolby's arc: "human nature" → "genius maxing" → "speaking your truth").
2. **Opening move**: a guess-frame ("Let me guess...") or equivalent direct-address opener that
   frames the list as reading the viewer's mind.
3. **Cascade**: keywords delivered linearly, 1-3 words each, no connective tissue, no
   explanation — explanation kills the perk-up effect.
4. **Belonging close**: the found-your-people move ("If you see this video and you like all
   these topics, welcome. You found your people.") — adapted, never copied verbatim
   (/bc-contextualize the close itself).
5. **Visual layer** (video): one image/scene per keyword (Kolby's collage pattern — Jung book,
   da Vinci portrait). For text platforms: line breaks as the rhythm.

## Content Type Adaptations

| Type | Adaptation |

| Substack Note | Compressed cascade (7-10 keywords); close links the letter |
| Client | Ledger must be the CLIENT niche's; creator-layer check on delivery style |
