# Arsenal Install (Account OS)

The productized deliverable: everything Briar's system needs to run weekly on one account —
yours or a client's — installed in one pass.

## Pre-Flight Gate

Load `../genius.md` in full. Required: account context (platform(s), niche, current baseline
views, follower count, business model, funnel), the operator's available cadence (posts/week,
time budget), and the declared strategy mix (growth/monetization/nurture ratio). This is a
multi-deliverable install — confirm scope before producing.

## Skill Acquisition

- `../genius.md` (all frameworks)
- `../references/frameworks.md` (all diagrams)
- Component workflows: 02 (ideation hour), 03 (arsenal week), 04 (win audit), 06 (keyword
  snipe), 11 (intel bridge)

## Execution

1. **Account read**: baseline views, follower-view ratio if available, through-line statement
   (or draft one), CCN sketch (what serves core/casual/new today).
2. **Keyword ledger** (seed): run workflow 06 logic → 10-20 entries.
3. **Five-input source map**: name the actual 15-20 creators (+ propose Social Intelligence DB
   scrapes), 15-20 subreddits, 5-10 YT scan keywords, external surfaces, internal surfaces.
4. **Arsenal ledger** (instantiate): empty bank + week-1 slate (test-heavy is correct at
   install), the 4:3 target ratio and 3-6 attempt rule written into the ledger header.
5. **Cadence contract**: the sacred hour (when), posting slots, win-audit trigger (any post ≥2×
   baseline), weekly slate ritual.
6. **Follower-quality dashboard**: which metrics this account tracks ($/follower where revenue
   exists, first-3h follower-view ratio, returning-viewer %, story views, inbound DMs) with
   current values as baseline.
7. **Anti-pattern contract**: the account's specific temptations (paid-ads shortcut? niche
   drift? all-winners coasting?) named with the rule that blocks each.

## Content Type Adaptations

| Type | Adaptation |
|------|-----------|
| Farrice personal brand | Wire to farrice-engine cadence; thought-bank = internal signal; voice-os layered on production |
| Client install | Deliver as client-runnable production sheet (per client-content format standard: labeled cards, ≤2 pages per doc) |
| Multi-platform | One arsenal per platform; keywords shared, baselines separate |
| Cold-start account (<1K) | Weeks 1-4 all-test; ratio phases in once 3+ winners banked |

## Output Requirements

The install pack: through-line + CCN sketch · seed keyword ledger · five-input source map ·
instantiated arsenal ledger with week-1 slate · cadence contract · follower-quality baseline
dashboard · anti-pattern contract.
Execution prompt: references/prompts-v2/arsenal-week-plan.md (ledger) + idea-gate-scorecard.md
(seed ideas) — honor their Output Contracts.

## Quality Gate

Every source in the map is REAL and named (no placeholder creators/subreddits). Week-1 slate
matches account stage. Metrics dashboard has current baselines, not blanks. Client versions are
production-sheet format, ≤2 pages per doc.
