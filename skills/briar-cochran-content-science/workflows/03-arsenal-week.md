# Arsenal Week Planner

The infinite testing loop. "Content is a game of putting out tests, keeping the winners,
discarding the bad" — with no Madison Square Garden, so the arsenal must loop forever.

## Pre-Flight Gate

Load `../genius.md` → Arsenal Loop. Confirm: current arsenal state (banked winners with attempt
counts; empty is fine for week 1), posting cadence (slots/week), account stage and goal mix.
If there is no arsenal ledger yet, this run creates it.

## Skill Acquisition

- `../genius.md` (arsenal rules, fatigue rationing)
- `../references/frameworks.md` §4
- Test candidates come from /bc-ideation-hour output or the Venn gate

## Execution

1. **Ledger read**: List banked winners (topic, attempts, last-run date, verdict), active tests
   (attempts used of 3-6), and discards.
2. **Ratio set**: Default ≈4 proven : 3 tests. Weeks 1-3 of a fresh install skew test-heavy
   (all-test week 1 is correct). NEVER an all-winners week; never below the 70/30 floor.
3. **Bench call**: If winners exceed slots, deliberately bench the surplus (use 4 of 6). Check
   lifecycle: any winner last run >4-6 weeks ago may rotate back as near-fresh.
4. **Test selection**: Fill test slots from the top Venn-passed idea cards. Each test slot notes
   its signal source and attempt count (n of 3-6).
5. **Fatigue scan**: Any topic/format appearing ≥3 consecutive weeks → flag and rotate. Any
   audience-fatigue symptoms reported (falling follower-view ratio, auto-scroll pattern) →
   reduce winner reuse this week.
6. **Write the week**: Slot-by-slot slate + updated ledger (arsenal bank, benched list, active
   tests with counts, discards with reason).

## Content Type Adaptations

| Type | Adaptation |
|------|-----------|
| Daily short-form | 7 slots, full 4:3 |
| LinkedIn (3-5 posts/wk) | Scale ratio: 2-3 proven : 1-2 tests |
| Substack (weekly) | Ratio applies across a month: 2-3 proven : 1-2 test editions |
| Client accounts | Ledger is per-account; never share arsenals across niches |

## Output Requirements

Weekly slate (slot → idea → proven/test → signal source → attempt count) + updated arsenal
ledger + benched winners + fatigue flags.
Execution prompt: references/prompts-v2/arsenal-week-plan.md — honor its Output Contract.

## Quality Gate

Ratio within 4:3 ± account-stage tolerance and ≥70/30 floor. No discarded idea under 3 attempts
without a named reason. Bench list non-empty whenever winners > winner-slots. No all-winners
week under any argument.
