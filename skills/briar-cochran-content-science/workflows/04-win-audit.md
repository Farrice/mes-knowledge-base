# Four-Question Win Audit

Postmortem winners (and instructive flops) in strict order, isolating the variable like an
experimenter. Every audited video feeds the four arsenals.

## Pre-Flight Gate

Load `../genius.md` → Win Audit. Confirm: the video/post + its performance vs the account's own
baseline (outlier multiple), plus any qualitative signal (comment themes, DMs, shares). Judging
by raw views alone = stop; compute baseline first.

## Skill Acquisition

- `../genius.md` (audit order, four arsenals, his worked ledger)
- `../references/frameworks.md` §5
- Deep forensics on a single piece: stack `skills/alex-content-science/` Detail Stack afterward

## Execution

Ask in strict order — earlier answers constrain later ones:

1. **Topic**: Was the IDEA what resonated? Evidence: have you run this topic before (hit or
   flop)? Have others? Is the comment section about the idea itself?
2. **Format**: Was the visual vehicle the variable (green screen, whiteboard, reaction, talking
   head)? Compare: same topic in another format; same format on other topics. Propose the
   isolating test if the data doesn't exist yet.
3. **Hook**: First 3-5 seconds, plus location, wardrobe, color, nonverbals. Usually interacts
   with topic+format — note the relationship rather than forcing a single cause.
4. **Body**: Did a mid-video story/statistic/reference drive the comments and DMs (the
   30-second-weave candidates)? Mine comment timestamps.

Then: write ONE primary verdict + confidence, plus secondary contributors; bank each finding
into its arsenal (topics / formats / hook principles / body principles); if the variable can't
be isolated, output the comparison test to run next (the isolating experiment).

## Content Type Adaptations

| Type | Adaptation |
|------|-----------|
| Short-form | Hook = first line + first frame; body = mid-video comment spikes |
| LinkedIn | Format = post structure (listicle, story, contrarian take); hook = first 2 lines |
| Newsletter | Body audit weighs reply-driving sections; hook = subject line CTR |
| YouTube long-form | Packaging (thumbnail+title) IS the hook layer — audit it first after topic |

## Output Requirements

Audit report: baseline math → four-question verdicts with evidence → primary variable +
confidence → arsenal entries written → next isolating test (if needed).
Execution prompt: references/prompts-v2/win-audit-report.md — honor its Output Contract.

## Quality Gate

Baseline multiple computed, never raw views. One primary variable named (no "everything worked").
Every verdict lands in exactly one arsenal. Unresolvable audits output an isolating test, not a
shrug.
