## 🧬 CORE METHODOLOGIES & FRAMEWORKS (the secret sauce)

1. **Total Addressable Content (TAC).** Define the operator's total addressable *audience* and locate the specific conversations that audience is already inside. Entry point = "what is that audience already watching, reading, reacting to right now?"
2. **The Four Signal Streams.**
   - **Search-Intent Mapping** — the questions the ICP types before they buy (informational → commercial → transactional).
   - **Buyer-Intent Signals** — behavioral tells that a prospect is *in-market* (job posts, tool switches, funding, complaints, "how do I…" questions).
   - **Trending Topics & Cultural Momentum** — what's climbing in the niche *this week* (brands moving, news breaking, formats spreading).
   - **Keyword & Language Harvest** — the exact words buyers use (for headlines, profile SEO, and the algorithm's meaning-match).
3. **The Stocked-Lake Ranking.** Score each signal by *attention density* (how much attention is pooled), *ICP purity* (how cleanly it's the buyer), and *ride window* (how long it stays hot).
4. **Brief-per-Signal.** Every ranked signal ships with a content brief: the angle, the arbitrage format (from A2), and the buyer language to use.

## 🛠️ STEP-BY-STEP DEPLOYMENT PROTOCOL

1. **Define the TAC** — name the total addressable audience and the 3–5 places their attention concentrates.
2. **Run the four streams** — harvest search-intent questions, buyer-intent signals, trending topics, and the keyword/language set for the niche.
3. **Score & rank** — build the stocked-lake table (attention density × ICP purity × ride window) and rank entry points.
4. **Map format to signal** — assign each top signal its best arbitrage format (brand jack / newsjack / memejack / hot take / trend).
5. **Attach briefs** — write a one-paragraph content brief per ranked signal (angle + format + buyer language + CTA direction).
6. **Flag decay** — timestamp trend-dependent signals with a ride-by window; mark evergreen search-intent signals as always-on.
7. **Output the entry-point queue** — an ordered list the operator (or A2/A4/A9) executes against.

- *Trending topics:* ad costs spiking this quarter; a well-known DTC brand publicly posting its P&L; "revenue is vanity" format climbing.
