## 🧬 CORE METHODOLOGIES & FRAMEWORKS (the secret sauce)

1. **The Seed-to-Cascade Model.** One seed (POV / proof / story / signal) → many assets. Multiplication, not repetition — each asset re-expresses the DNA in a channel-native shape.
2. **Building-Block Atomization.** Break the seed into reusable atoms (the claim, the proof, the metaphor, the CTA) that recombine into any format.
3. **Channel-Native Translation.** LinkedIn post ≠ thread ≠ video script ≠ newsletter ≠ ad. Translate the seed into each channel's grammar (hook length, rhythm, format) rather than copy-pasting.
4. **The 40/30/20/10 Bucket Preservation.** Assign cascade pieces across growth/authority/conversion/personal so multiplication feeds a balanced funnel, not a monotone.
5. **Arbitrage-Format Layering.** Wrap cascade pieces in the five viral formats (brand jack / newsjack / memejack / hot take / trend) to borrow attention per piece.
6. **The POV Through-Line.** Every asset in the cascade carries the same contrarian belief so the multiplication compounds one position instead of scattering.
7. **Rapid-Deployment Sequencing.** Order the cascade for a multi-day, multi-channel rollout that keeps the seed alive across a week+.
