# Nate B Jones Manager Loop

> "The longer the agent run gets, the more the pieces depend on one another, the more the management of the work becomes the work." (08:19)

Nate B Jones's post-prompt layer: for work bigger than a prompt, you don't write a better prompt — you hand a **recipe card** to a **manager loop**. The card names the job, sketches its lanes, says what to ask for, what the agent handles alone, when it comes back, which actions need approval, and what to do when work breaks. The manager interviews once, keeps every unblocked lane moving, brings back **decision packets** instead of status, and closes on four questions: done? aligned? nothing unauthorized? approvals surfaced?

**Core insight**: the failure to catch is the hand-back — an agent that stops after every answer and returns the job. In this harness that rule is physical: `python3 execution/job_board.py next <slug>` must print MAY END before a job turn ends.

| forge | [Recipe Card Forge](workflows/recipe-card-forge.md) | `recipes/<slug>.md` per the standard | No recipe matches, or a card is being ratcheted |
| run | [Manager Loop Run](workflows/manager-loop-run.md) | Lanes driven to done/blocked, packets, receipts, checkpoint | The card is confirmed; every turn until MAY END |
| packet | [Decision Packet](workflows/decision-packet.md) | One DECISION PACKET answerable in a line | A lane hits its ask-when threshold or an approval is next |
| closeout | [Job Closeout](workflows/job-closeout.md) | Four answers with receipts + recipe ratchet + verdict ask | All lanes terminal |

## Front door and machinery

- `/job "<raw ask>"` — `.agent/workflows/job.md` (triage → interview → run → closeout), both harnesses.
- `execution/job_board.py` — the board (open · lanes · lane · next · packet · checkpoint · handoff · resume · status · close · lint). `execution/recipe_cards.py` — the library. Standard: `directives/recipe-card-standard.md`.
- Hook: `MODE JOB-HANDOFF` fires from `execution/hooks/steering_loop_hook.py` on job-shaped asks (Claude and Codex variants); Stop-hook observer logs a turn that ended with runnable lanes and no packet.
- Harness independence: job state lives on disk; `job_board.py handoff --to codex|claude|chat` writes a portable packet so either harness runs a job alone or together.
