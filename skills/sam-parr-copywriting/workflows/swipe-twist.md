# /parr-swipe-twist — The Steal-and-Twist Engine

Never face a blank page. Sam Parr's signature ethos: merciless copying of classics, twisted ~3% to make them yours. The Hustle's Trends ripped off WSJ's "Tale of Two Boys" → made a lot of money. And source where competitors aren't looking — Thrasher, Japanese Popeye, JFK Jr.'s *George*. "Tech people don't read these, so the ideas are fresh."

## Pre-Flight Gate
Load `genius.md` (Pattern 13; cross-pollination hidden knowledge). Confirm:
- The brand/product and the piece to create (ad, headline, hook, structure).
- Whether this is a sourcing run (build a swipe file) or a twist run (transform a specific classic).
- **This is the bridge to the taste skill.** If the user wants the disciplined copy-work *drill* (transcribe by hand to internalize texture), route to `/taste-copy` — don't rebuild it here. This workflow is the *deploy* layer: steal a proven skeleton and ship a twisted original.

## Execution
1. **Source (if sourcing run).** Pull 5-10 proven examples — from the swipe file AND from outside the industry (fiction, magazines, classic ads). For each, name the MECHANIC (the curiosity gap, the parallel-hero story, the visceral comparison) — not the surface.
2. **Select the skeleton.** Match the mechanic to the brief. WSJ "Tale of Two Boys" for a transformation sell; Rolls-Royce specific-detail for a quality claim; piano ad for a curiosity hook.
3. **Twist 3%.** Keep the structure and physics; change the skin: subject, voice, era, specifics → the brand's. Resist pattern-lock — extract WHY it works, discard the original scenario.
4. **Pressure-test the twist.** Is it twisted enough to be the brand's own, not a recognizable knockoff? Is it twisted *little* enough to keep the proven mechanic? 3%, not 50%.
5. **Trace the lineage (optional).** Run `/taste-lineage` to show the ancestry — removes the intimidation of "originality" and reveals further moves to steal.
6. **Output** the twisted original + a note on the source mechanic and what changed.

## Output Requirements
- The twisted original deliverable.
- The source mechanic named + "what I twisted" (proving it's 3%, not 50%).
- For sourcing runs: a tagged swipe-file list (mechanic + source + in/out-of-industry).

## Quality Gate (from genius.md)
- The MECHANIC is preserved (proven physics intact); the SKIN is the brand's own.
- Not a recognizable knockoff; not so changed the mechanic broke.
- Auto-fail: pattern-locked copy that reuses the original's scenario/voice; "inspired by" with no actual structural steal.
