# /parr-ad-rewrite — The Ad-Rewrite Gym

Take any weak ad and rewrite it on the spot, the way Sam Parr did live with AG1, Caraway, and Harley. Diagnose what's broken, then deploy the full toolkit. Highest instant utility in the skill.

## Pre-Flight Gate
Load `genius.md` (all patterns; the guardrail + anti-exemplar). Confirm:
- The original ad copy (paste it in).
- The product, the reader, and the desired action.
- **Any stat in the original or the rewrite → verification queue. Structure from Sam; facts verified.**

## Skill Acquisition
- `genius.md` — full pattern set; the Product-First **anti-exemplar**; the AG1 + Caraway **exemplars** (calibration ceiling).
- `references/swipe-file-and-frameworks.md`.

## Execution
1. **Diagnose against the anti-exemplar.** Score the original on the 9-criterion rubric. Name the specific failures — almost always: product-first (no buried Trojan horse), no story, no open loop, abstract claims, uniform rhythm. Quote the weakest line.
2. **Pick the rewrite mode** based on the product:
   - **Proof mode** (supplements, results-based): lead with before/after; "the best ad is just proof — don't even show the product."
   - **Educational-story mode** (AIDA): punch stat-hook → relatable problem → absolve guilt → mechanism → social proof (the AG1 template).
   - **Tangibility mode** (anything abstract/hygiene/health): make the claim a physical image (the Caraway "toilet bowl" template — use `/parr-tangible`).
   - **Desire mode** (lifestyle/aspirational, e.g. Harley): sell the experience/identity, price as a bonus, not the lead.
3. **Write 2 distinct rewrites** in different modes so the user can compare mechanics.
4. **Insert the early YES** and bury the product past the desire build.
5. **Rhythm + cut a third** (`/parr-rhythm-edit`).
6. **Show your work**: a one-paragraph "what I changed and why" tying each move to a pattern.

## Content Type Adaptations
| Original format | Rewrite focus |
|---|---|
| Meta/IG static ad | Headline punch + one tangible image + early yes; keep it scroll-stopping |
| Product-page copy | Bury the product; add a micro-story + proof block |
| Email blast | Add open loop in subject; one story; objection in the P.S. |
| Short-form video script | Switch to `/parr-shortform` — retention engineering, not static copy |
| Bottom-of-funnel/price ad | Don't over-fix — high-intent price ads can be fine; add desire framing only |

## Output Requirements
- **Diagnosis**: rubric scores + named failures + quoted weakest line.
- **2 rewrites** in different modes, each mapped to AIDA beats.
- **"What I changed and why"** — moves tied to patterns.
- **Verification Queue**: every stat labeled VERIFIED / LIKELY / UNCONFIRMED; unverified flagged.

## Quality Gate (from genius.md)
- Rewrites beat the original on ≥5 of 9 rubric criteria.
- **Desire-before-offer** ≥8, **Tangibility** ≥7 (where applicable).
- Auto-fail: rewrite still leads with the product; any unverified stat presented as fact.
