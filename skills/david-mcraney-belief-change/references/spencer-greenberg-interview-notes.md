## Key Concepts Extracted (Net-New Intelligence)

### 1. Elaboration Likelihood Model (ELM)
- **Central Route**: Deep, effortful processing. Active when motivation + ability are both high. Produces durable attitude change.
- **Peripheral Route**: Surface-cue processing (authority, likability, social proof). Active when either motivation or ability is low. Produces fragile attitude change.
- **McRaney's application**: Before choosing ANY persuasion strategy, diagnose which route is active. Most marketers default to central-route arguments for peripheral-route audiences — structural messaging mismatch.
- **→ Deployed as**: Genius Pattern #24 (ELM Route Selection)

### 2. Technique Rebuttal vs Topic Rebuttal
- **Technique rebuttal**: Attacking the *method* of persuasion ("you're trying to manipulate me")
- **Topic rebuttal**: Attacking the *content* of the argument ("your facts are wrong")
- **Critical insight**: These require opposite responses. Transparency fixes technique rebuttals but looks desperate on topic rebuttals. Evidence fixes topic rebuttals but confirms suspicion on technique rebuttals.
- **→ Deployed as**: Genius Pattern #25 (Rebuttal Type Detection)

### 3. Metacognition as Master Mechanism
- McRaney positions metacognition (thinking about one's own thinking) as the mechanism that enables all other change mechanisms
- Process questions ("how did you arrive at this?") vs content questions ("why do you believe this?") — the former activates metacognition, the latter triggers defensive justification
- Deep canvassing, street epistemology, and MI all independently discovered this: guided self-reflection creates change from within
- **→ Deployed as**: Genius Pattern #26 (Metacognitive Unlock)

### 4. The 30% Tipping Point
- Research synthesis: ~30% counter-evidence (relative to belief strength) triggers genuine re-evaluation in *neutral* conditions
- Social costs inflate this multiplicatively — tribal/identity contexts push threshold to 70-80%+
- **Operational implication**: If you've hit 30% evidence and nothing's changing, STOP adding evidence. The barrier is social/identity cost, not information deficit.
- **→ Deployed as**: Pattern #13 update + Hidden Knowledge #13 (30% Empirical Calibration)

### 5. Accommodation Trigger Conditions (Deeper Treatment)
- Assimilation = default processing mode (absorb without changing)
- Accommodation = exception, requires three simultaneous conditions:
  1. **Surprise** — cognitive, not emotional; "my model can't explain this"
  2. **Relevance** — personal stake, not abstract importance
  3. **Safety** — social/identity cost low enough to permit updating
- **Design implication**: If your message can be comfortably absorbed into existing worldview, it WILL be. Designing for change = designing for surprise.
- **→ Deployed as**: Pattern #2 update + Hidden Knowledge #12 (Accommodation Requires Surprise)
