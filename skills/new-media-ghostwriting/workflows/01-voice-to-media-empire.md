# Workflow 01: Voice to Media Empire — Premium Ghostwriting Service

## Purpose
Transform any founder/leader from "I need someone to write my LinkedIn posts" into a full media presence with authentic voice, platform-native content, strategic positioning, and crisis protection. This is the complete premium ghostwriting engagement.

## Input Required
- Client: founder name, company, industry
- Existing content samples (previous posts, interviews, podcasts, presentations)
- Business goals (hiring, sales, fundraising, authority)
- Available engagement time (hours per week for interviews, review, recording)
- Current platforms and desired platforms
- Competitors they want to outposition

## Phase 1: Voice Intelligence (Week 1)

### Step 1: Nicolas Cole Voice Capture
**Load**: `skills/nicolas-cole-ghostwriting/SKILL.md`
**Load**: `skills/nicolas-cole-ghostwriting/workflows/voice-document.md` (or equivalent voice workflow)

Execute the full voice capture:
- Interview Protocol: 2-3 deep interview sessions extracting:
  - Speaking rhythm (long sentences vs. short punches)
  - Vocabulary patterns (technical jargon comfort level, colloquialisms)
  - Story structures (do they lead with data or narrative?)
  - Humor style (dry, self-deprecating, none)
  - Conviction words (what phrases do they lean into?)
- Content Analysis: Read 10+ pieces of their existing content. Document patterns.
- Voice Document: Create the comprehensive voice reference document

### Step 2: Joe Rogan Test Diagnosis
**Load**: `skills/andreessen-horowitz-new-media/workflows/04-founder-go-direct.md`

Score the client on the Joe Rogan CEO Test (1-10):
- Can they hold a 3-hour unscripted conversation and be genuinely interesting?
- Do they have original ideas (not recycled industry wisdom)?
- Are they comfortable with controversy (calibrated, not reckless)?
- Is their personality magnetic or managed?

### Step 3: Unscripting Protocol
Based on Joe Rogan score, run the unscripting protocol:
- **Kill List**: Identify old-media conditioning to remove
  - PR-approved talking points they default to
  - Corporate-speak ("leverage," "synergize," "at the end of the day")
  - Safety hedges ("some might say," "it's complicated")
- **Liberation List**: Find suppressed opinions and beliefs
  - "What do you believe about your industry that you've never said publicly?"
  - "What's the biggest lie your industry tells itself?"
  - "What's the thing you're most afraid to say to your audience?"
- **Controversy Calibration**: Map each liberated opinion on the consensus → third rail spectrum
  - Green zone: Safe but authentic takes
  - Orange zone: Interesting contrarian positions (THIS IS THE SWEET SPOT)
  - Red zone: Third rail — publish with full context in long-form only

**Output**: Enriched voice document with unscripted authentic positions + controversy map

For each platform, create a **platform voice card**: how the client's voice adapts to this culture mode WITHOUT losing authenticity. This is the key ghostwriting skill — same person, different registers.

### Step 5: Content City Blueprint (with Culture Layer)
**Load**: `skills/grace-andrews-media-company/SKILL.md` + `genius.md`
**Load**: `skills/grace-andrews-media-company/workflows/01-city-map-architect.md`

**Critical rule**: Enforce WRITTEN-FIRST pipeline:

## Phase 3: Production Pipeline (Ongoing)

### Step 7: Long-Form Anchor Production
Monthly:
- 2-4 long-form pieces (Substack essays, YouTube scripts, or both)
- Each piece establishes ONE position from the controversy map
- Full proof loading using Luke Iha methodology
- These are the WRITTEN CULTURE anchors everything else extracts from

Process:
1. Client records 30-min voice memo on the topic (raw, unscripted)
2. Ghostwriter extracts the argument structure
3. Enrich with proof (research, data, examples)
4. Write in client's voice using voice document
5. Client reviews ONE draft (not three rounds)
6. Publish

### Step 8: Platform-Native Extraction
From each long-form anchor piece, create platform-native content:
- 2-3 X threads (oral-culture extraction of key provocations)
- 1 LinkedIn post (hybrid narrative version)
- 1-2 Shorts/Reels scripts (single "whoa" moment)
- Email edition to subscribers (bridge to long-form)

**Each piece is NATIVELY designed for its platform's culture mode.**
Not reformatted. Not truncated. Natively redesigned.

### Step 9: Real-Time OODA Content
Beyond the planned content:
- When industry events happen, produce rapid-response content in the client's voice
- Use pre-built orientation templates from narrative warfare framework
- Target: react within hours, not days
- The client approves via text/voice memo, not email chains

## Phase 4: Protection (Setup in Month 1, Ongoing)

### Step 10: Context-Length Defense
For every controversial position in the client's pipeline:
- Ensure the full argument exists in long-form somewhere (podcast, Substack)
- Create a "canonical reference" for each position — the link you share when someone takes it out of context
- Never let a controversial position exist ONLY in short-form

### Step 11: Flood-Zone Preparation
Pre-build the crisis arsenal:
- 5 "in the can" interesting pieces ready for emergency publication
- Written in the client's voice, on topics unrelated to any controversy
- Ally activation list: Who can amplify for this client in a crisis?
- 48-hour assessment protocol

## Output Schema

This workflow produces a **client-specific engagement package**, delivered in stages, not
one monolithic document. Each stage has a required artifact:

| Stage | Required Artifact | Format |
|---|---|---|
| Phase 1 (Voice Intelligence) | Voice Reference Document + Joe Rogan CEO Test score (1-10) + Controversy Map (green/orange/red zones) | Markdown doc, 3 sections minimum |
| Phase 2 (Content Architecture) | Platform Voice Cards (1 per active platform) + City Map (Grand Central/Destinations/Lines/Passengers) + LinkedIn profile spec | Markdown doc or table per platform |
| Phase 3 (Production, ongoing) | Long-form anchor piece(s) + platform-native extraction set matching the Monthly Deliverables table above — no piece ships without its culture-mode tag (Oral/Written/Hybrid) | Per-platform drafts, tagged |
| Phase 4 (Protection) | Context-length defense index (one canonical link per controversial position) + Flood-Zone arsenal (5 pre-built pieces) + 48-hour assessment protocol doc | Reference index + content bank |
| Engagement summary | Service tier selected (Foundation/Full Media/Kingmaker) + monthly deliverable count committed + pricing confirmed against the table above | 1-page brief |

A deliverable that skips the Voice Reference Document or ships platform content without a
culture-mode tag has not satisfied this workflow's contract, regardless of how polished the
individual pieces read — the whole point of the compound service is that every asset traces
back to a specific phase artifact above.

## Quality Gates

- [ ] Voice fidelity: Would a close colleague believe the client wrote this? (score 8+/10)
- [ ] Culture-mode match: Does oral-platform content FEEL oral? Does written FEEL written?
- [ ] No cross-posting: Every piece is natively designed, not reformatted
- [ ] Controversy calibration: Bold positions have long-form context available
- [ ] Trust pathway coherence: Every piece serves a specific trust stage
