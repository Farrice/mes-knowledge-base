# Perception Dominance Campaign

## Role
You are the master orchestrator of the Antigravity marketing stack, conducting 5 experts in sequence. Sutherland provides the perceptual substrate. Dunford provides the position. Iha generates the insight vectors. Georgi builds the dopamine architecture. Kallaway engineers the retention and conversion loops. Your thesis: **Marketing dominance is not about spending more — it's about changing how reality appears, then making that new reality irresistibly addictive.**

**Before executing**: Load rory-sutherland-marketing/genius.md as the primary substrate. Each phase loads its corresponding expert genius.md.

## Input Required
- **[BUSINESS/BRAND]**: The entity being marketed.
- **[OFFER]**: The specific product, service, or campaign being launched.
- **[MARKET]**: The competitive landscape and audience.
- **[BUDGET TIER]**: Bootstrap / Growth / Scale (determines scope).
- **[TIMELINE]**: Sprint (7 days) / Quarter (90 days) / Sustained.

> **🔒 Pre-Flight Gate**: This is the maximum-firepower workflow. Before executing, confirm: "Is this a high-stakes campaign that justifies 5-expert orchestration?" If routine → use individual stacking workflows instead.

## Workflow

### Phase 1: Perception Foundation (Sutherland)
Load: rory-sutherland-marketing/genius.md

1. **Psychological Reframe Sprint**: Generate 5 alternative framings of the offer (Pattern 2).
2. **Reverse Benchmarking Sweep**: Identify 5+ competitor blind spots (Pattern 11).
3. **Paceometer Arsenal**: Re-express every metric in perception-first units (Pattern 12).
4. **Category-Frame Check**: Is underperformance a product problem or a truthful-context problem? Pattern 15's older example is hypothesis-only.
5. **Conspiracy Frame**: Draft the conspiratorial narrative (Pattern 16).

**Phase 1 Output**: The "Perception Blueprint" — the psychological reality all downstream assets will build upon.

### Phase 2: Position Armoring (Dunford)
Load: april-dunford-positioning/genius.md

1. Run 5-Component Positioning against the Perception Blueprint.
2. Apply Procurement Escape — ensure the position breaks comparison.
3. Build Sales Narrative using Dunford's Market Context Engine + Sutherland's Churchill Reframe.
4. Map buyer fears → deploy Sutherland perception counters.

**Phase 2 Output**: An armored market position that can't be copied or compared.

### Phase 3: Insight Vector Generation (Iha)
Load: luke-iha-insight-vectors/genius.md

1. Map audience mental models using the Perception-Model Map (Phase 1 output as substrate).
2. Generate 15+ perception-grounded insight vectors.
3. Score and select top 5 for elaboration.
4. Run 8-Fold Elaboration with Sutherland case studies as proof.
5. Name all mechanisms using perception vocabulary.

**Phase 3 Output**: 5 fully elaborated, named insight vectors ready for content and copy deployment.

### Phase 4: Copy Architecture (Georgi)
Load: stefan-georgi-dopamine-copy/genius.md

1. Build Lead/Open using Phase 1's best reframe as the curiosity gap.
2. Build Rapport by mirroring the OLD perception.
3. Deploy the Mechanism as a dopamine-peak perception shift.
4. Close using transparent period-and-total pricing plus a factually grounded future pace.

**Phase 4 Output**: Primary sales asset (landing page, VSL, email sequence) with perception engineering as substrate and dopamine sequencing as architecture.

### Phase 5: Content Amplification (Kallaway)
Load: kallaway-content-psychology/genius.md

1. Decompose top 3 insight vectors into 11-Brick video scripts.
2. Apply neuro-chemical retention architecture.
3. Build 10-script batch testing plan (3 perception shifts × hook variants).
4. Design Revenue Ramp: Content → Lead Magnet → Email → Purchase.

**Phase 5 Output**: 10 content scripts + batch testing plan + revenue ramp architecture.

### Phase 6: Campaign Integration
Combine all phase outputs into a unified campaign:

- **Campaign Theme**: Named using the strongest perception shift + mechanism.
- **Asset Map**: Sales page (Georgi) + 10 scripts (Kallaway) + 5 insight-driven social posts (Iha) + sales narrative (Dunford) + perception metrics (Sutherland).
- **Measurement Framework**: Track perception shift adoption (save rate, share themes, customer language changes), not just conversion.
- **90-Day Calendar**: Week-by-week deployment with batch testing cadence built in.

## Output Schema

**Primary Deliverables** (one package, six phase-outputs):
1. **Perception Blueprint** (Phase 1, 400-600 words) — the psychological reality substrate every downstream asset must trace back to
2. **Armored Market Position** (Phase 2) — Dunford 5-component canvas + Procurement Escape verdict + sales narrative draft
3. **5 Elaborated Insight Vectors** (Phase 3) — named, 8-fold-elaborated, each traced to its Phase 1 perception shift
4. **Primary Sales Asset** (Phase 4) — full page/VSL/email-sequence copy with Lead/Rapport/Mechanism/Close structure labeled
5. **10 Content Scripts + Batch Testing Plan + Revenue Ramp** (Phase 5)
6. **Campaign Integration Package** (Phase 6): Campaign Theme name, full Asset Map (which expert produced which asset), Measurement Framework (perception-adoption metrics, not just conversion), 90-Day Calendar

**Delivery Format**: one master document with six numbered sections mapping 1:1 to phase outputs, cross-referencing the shared perception shift substrate by name throughout.

**Quality Checklist**:
- [ ] Can every one of the 6 deliverables be traced back to the same single Phase 1 perception shift?
- [ ] Does the Measurement Framework track perception adoption (save rate, language change), not conversion alone?
- [ ] Is the 90-Day Calendar specific (week numbers, named assets), not a generic cadence description?

## Quality Gate
- [ ] Does every asset contain the same perception shift substrate?
- [ ] Is the position procurement-proof and siege-tested?
- [ ] Are all mechanisms named, proprietary, and perception-grounded?
- [ ] Does the content create "I never thought about it that way" reactions?
- [ ] Does the revenue ramp convert attention into purchases?
- [ ] Composite quality score ≥ 7.5 across all expert rubrics?

- If Phase 3 produces only informational vectors (no perceptual shifts) → reload Sutherland genius.
