# Michael Connelly — Use Cases (Deployment Scenarios → Workflow Map)

> Specific situations where this skill is the right call, each mapped to the matching workflow and the genius pattern it deploys. Use this to route fast: find the scenario closest to your task, run the named workflow. Always load `genius.md` first and clear the Decision Framework pre-flight gate before executing any workflow.

## How to Read This File

Each use case gives you:
- **Scenario** — the concrete situation you're in
- **Workflow** — the file under `workflows/` to run
- **Genius pattern** — the underlying move (from genius.md) so you understand *why* it fits
- **Tell that you're in this scenario** — the symptom that should trigger the route

## 1. Telling Detail Engine → `workflows/telling-detail-engine.md`

**Deploy when:** You need to describe a character, scene, product, or emotional state and the draft is bloating into a descriptive paragraph.

| Scenario | Tell |
|---|---|
| A LinkedIn/X hook opens on an abstract claim instead of a concrete image | "After years of..." / "The truth about..." openers with no particular |
| Landing-page section is a list of benefits or features | 3+ bullet points doing the work one image could do |
| Character or founder introduced via résumé of traits | "passionate, driven, detail-oriented" stacking |
| A scene description runs 3+ sentences before anything happens | Reader's attention drifting before the action |

**Genius pattern:** The Telling Detail > The Descriptive Paragraph + Narrative Load Ranking (rank candidate details by how many vectors they fire across; behaviors beat objects).

---

## 2. Momentum Writing Audit → `workflows/momentum-audit.md`

**Deploy when:** A draft is complete-ish but feels slow, skimmable, or easy to put down.

| Scenario | Tell |
|---|---|
| Newsletter/blog post that readers open but don't finish | High open rate, low scroll-depth / read-time |
| Email sequence with drop-off mid-message | People archive before the CTA |
| Long-form essay that "loses energy" in the middle | You yourself skim your own draft on re-read |
| Any prose where a reader could comfortably stop | A clean paragraph ending that doesn't pull forward |

**Genius pattern:** Momentum Is Sacred — the Reading Test, the "Good Place to Stop" Test, the Density Threshold. Spare prose = momentum; dense prose = speed bumps.

---

## 3. Character Through Place → `workflows/character-through-place.md`

**Deploy when:** Writing a scene set in a specific location and you need character depth to come *from* the geography.

| Scenario | Tell |
|---|---|
| Brand narrative tied to a city, office, or origin location | Setting is described but doesn't reveal anyone |
| Founder story where "where it happened" matters | A place is named but used as backdrop, not trigger |
| Fiction scene where setting is currently inert | Geography present, character flat |
| Case study that needs grounding in a real environment | Location adds texture but not meaning |

**Genius pattern:** Character Is the Organizing Principle — geography triggers memory that reveals character. "Location, location, location" becomes "character, character, character."

---

## 4. Subtext Dialogue Builder → `workflows/subtext-dialogue-builder.md`

**Deploy when:** You need dialogue (or persuasive lines) with hidden conflict, not a surface-level exchange.

| Scenario | Tell |
|---|---|
| Fiction/script dialogue that's on-the-nose | Characters say exactly what they mean |
| Sales copy that sounds like it's trying to convince | Surface message = the literal sell, no undertow |
| Testimonial or conversation reading flat | "Literally about" and "actually about" are identical |
| A scene that needs tension without naming it | Conflict stated outright instead of felt |

**Genius pattern:** Subtext Over Surface — the Two-Layer Test. If "what is this literally about?" equals "what is this ACTUALLY about?", the writing lacks depth.

---

## 5. Outsider Lens Filter → `workflows/outsider-lens-filter.md`

**Deploy when:** A character, brand voice, personal voice, or ghostwriting client needs edge, critical distance, and automatic tension.

| Scenario | Tell |
|---|---|
| Brand voice reads "comfortable insider," no friction | Voice has authority but no point of view |
| Ghostwriting client sounds generic / safe | Credential-leading, hedged, no stance |
| Personal brand needs a recognizable angle | Expertise present, perspective absent |
| Fictional character feels too at-home in their world | No conflict between their access and their belonging |

**Genius pattern:** The Outsider Looking In — the Access/Belonging Gap. Define what they have access to and why they feel they don't belong. The gap IS the voice.

---

## 6. Vonnegut Conflict Audit → `workflows/conflict-audit.md`

**Deploy when:** A scene, chapter, or content section feels flat and you need micro-tension on every page.

| Scenario | Tell |
|---|---|
| A chapter/section where "nothing's at stake" | Pleasant prose, no pull |
| Content piece that's informative but inert | Reader has no reason to keep going |
| A draft where characters/voices want nothing | No want = no tension on the page |
| Middle stretch of any long piece sagging | Energy present at start and end, dead in the middle |

**Genius pattern:** Character-as-organizing-principle applied page-by-page — every character (or section) must *want* something on every page, or the page is a speed bump.

---

## 7. Connelly Rewrite Protocol → `workflows/connelly-rewrite-protocol.md`

**Deploy when:** A complete draft is ready for revision and needs the full dual-pass treatment.

| Scenario | Tell |
|---|---|
| First draft done, needs tightening + sharpening | Draft is "there" but overwritten |
| A piece that's good but not yet shippable | Composite quality 6–7, needs to hit 8+ |
| Retroactive foreshadowing needed | You now know the ending; the opening doesn't earn it |
| Any prose needing both word-level and structure-level cuts | Both bad words AND good words in wrong places |

**Genius pattern:** The Dual-Pass Erosion System — Pass 1 Micro-Erosion (sentence level, cut bad words) + Pass 2 Macro-Erosion (structural level, cut good words in the wrong place). "You don't revise. You erode."

## 8. Newspaper Dialogue Economy → `workflows/newspaper-dialogue-economy.md`

**Deploy when:** Dialogue or quoted material is flabby, over-explained, or people talk too much for their character.

| Scenario | Tell |
|---|---|
| Dialogue runs long, every character over-explains | Lines that repeat what action already showed |
| Ghostwriting client's copy is bloated | Hedged, padded, lowest-trust because longest |
| A character who should be terse is verbose | Voice and word-count mismatch |
| Quotes/testimonials that bury the point | The signal is in there somewhere, drowned |

**Genius pattern:** 14 years at the LA Times — "give me six inches." How much a character says IS characterization; a nod replaces "yes"; the question you cut is the one the reader asks themselves.

---

## 9. Slingshot Opener → `workflows/slingshot-opener.md`

**Deploy when:** You need an opening that converts a passive reader into a committed one — the moment the car "drops into drive."

| Scenario | Tell |
|---|---|
| Social post / thread with a weak first line | Scroll-stop failing; no trigger moment |
| Newsletter or blog with a meta-intro throat-clear | "In today's edition I want to talk about..." |
| Email where the reader bails before the hook lands | Setup too long for the audience's trust level |
| Any content where the reader hasn't committed yet | No moment of no-return early enough |

**Genius pattern:** The trigger point — empathic strike, then the moment that drops the story into drive. New audience = slingshot early; established audience = you can extend the setup.

## 10. Real-World Anchor → `workflows/real-world-anchor.md`

**Deploy when:** A narrative needs instant believability through environmental authenticity — fiction, brand story, founder narrative, or case study.

| Scenario | Tell |
|---|---|
| A founder/brand origin story reading as mythology | Vague "I saw a problem and built a solution" |
| Fiction character not yet believable to a smart reader | World is generic; character floats |
| A case study that needs to feel verifiably true | Claims present, texture absent |
| Any narrative where "is this real?" is the risk | Reader could doubt the whole thing |

**Genius pattern:** "Plant the character's feet in as real a world as possible." Real streets, real procedures, Google-able texture — the reality of the world sells the character for free. **Honesty spine: in non-fiction the anchor must be a true particular.**

## 11. Character Design Blueprint → `workflows/character-design-blueprint.md`

**Deploy when:** Building a character (or brand persona / ghostwriting voice) from scratch who needs to feel alive on first appearance.

| Scenario | Tell |
|---|---|
| New fictional character, blank page | Need depth, not a trait list |
| Brand persona being defined for the first time | Need a character, not a positioning doc |
| Ghostwriting a voice you've never written before | Need the load-bearing voice DNA |
| A recurring content "character" (founder-as-protagonist) | Need consistency across many pieces |

**Genius pattern:** The 6 Connelly layers — from name (Bosch = Hieronymus Bosch) through geography trigger — each layer revealing who the person IS. Name serves character; everything serves character.

---

## 12. Chandler Calibration → `workflows/chandler-calibration.md`

**Deploy when:** About to start a major writing session and you need to calibrate quality standards before drafting.

| Scenario | Tell |
|---|---|
| Starting a high-stakes piece cold | No taste anchor set for the session |
| Quality has been drifting across recent outputs | Recent work feels "fine," not excellent |
| Beginning a long-form or flagship deliverable | Need a ceiling-setting passage to write toward |
| Resetting after a run of mechanical/slop output | Craft moves need re-loading into working memory |

**Genius pattern:** Pre-writing taste reset — read a ceiling-setting passage, extract carry-forward craft moves, set the quality standard *before* the first sentence rather than auditing after.

## Composite Scenarios (Workflow Sequences)

Some jobs want more than one workflow, in order:

| Job | Sequence |
|---|---|
| **Ship a flagship LinkedIn post** | `slingshot-opener` → `telling-detail-engine` → `momentum-audit` |
| **Write a brand origin narrative** | `character-design-blueprint` → `real-world-anchor` → `character-through-place` → `momentum-audit` |
| **Tighten a converting landing page** | `telling-detail-engine` → `subtext-dialogue-builder` → `momentum-audit` |
| **Ghostwrite a client's first post in a new voice** | `character-design-blueprint` → `outsider-lens-filter` → `newspaper-dialogue-economy` |
| **Full revision of a complete draft** | `momentum-audit` → `connelly-rewrite-protocol` (rewrite folds in micro + macro erosion) |
| **Calibrate then draft a major piece** | `chandler-calibration` → (draft) → relevant production workflow → `connelly-rewrite-protocol` |

## Routing Guardrails

- **Load `genius.md` first, every time.** The patterns are intuition primitives, not a checklist. An output that mechanically runs all 12 workflows has failed.
- **Clear the Decision Framework pre-flight gate** (genius.md § Decision Framework) before executing any workflow. If you can't answer Q1–Q3, fix the underlying material first.
- **Non-fiction domains: honor the honesty spine (Q7).** Telling details, anchors, and outsider-lens beats must be *true* particulars in copy, brand, and ghostwriting. Craft makes a true detail land harder; it never manufactures one.
- **Subtraction over addition.** Most tasks need ONE workflow (usually telling-detail or momentum). Reach for more only when the symptom genuinely calls for it.
- **Stacking:** for structure/theme pair with Eric Roth or Pressfield; for platform-native social pair with Lara Acosta; for proof-driven copy pair with Luke Iha; for a depth/truth pass pair with Lamott + Allen Really Real Writing (see SKILL.md Stacking Guide).
