# Problem Articulation Script

## Pre-Flight Gate

Use this workflow when a sales call, landing page, email, post, DM, or proposal needs to make the buyer feel understood before the offer is introduced.

If the problem is still broad, run `/sales-education-map` first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-sales-education-messaging/genius.md`
- `skills/nicolas-cole-sales-education-messaging/references/genius-patterns.md`
- `skills/nicolas-cole-nonfiction-value-architecture/genius.md` when the output is long-form content

## Execution

1. Capture the buyer, situation, current workaround, and desired outcome.
2. State the surface problem in the buyer's words.
3. Identify the deeper mechanism: why the problem keeps happening.
4. Name the consequence in concrete business, money, time, status, or momentum terms.
5. Name the second-order emotional impact without exaggerating.
6. Write a problem-articulation script in this order:
   - "You are trying to..."
   - "But what keeps happening is..."
   - "The real reason is..."
   - "That is costing you..."
   - "And the part people miss is..."
7. Add 3 alternate versions by tone:
   - direct
   - consultative
   - public content
8. Mark which lines require proof before use.

## Content Type Adaptations

| Type | Script Shape |
|---|---|
| Sales call | Question-led diagnosis, then reflective summary |
| Landing page | Headline, subhead, problem section, consequence bullets |
| Cold DM | One precise observation plus one question |
| Launch email | Story or situation, then problem mechanism |
| LinkedIn post | Public pattern, specific example, buyer mirror |
| Proposal | Recap of the buyer's own problem in sharper language |

## Output Requirements

Return:

1. Surface problem.
2. Root mechanism.
3. Consequence stack.
4. Emotional impact.
5. Primary script.
6. Three tonal variants.
7. Proof-needed notes.

## Quality Gate

Pass only if the buyer would feel recognized rather than diagnosed from a distance. Avoid vague pain language, hype, or invented stakes.
