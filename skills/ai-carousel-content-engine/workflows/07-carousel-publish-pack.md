# Carousel Publish Pack

Use `publish-pack.md` to prepare:

- caption
- CTA
- platform notes
- client handoff bundle
- link back to article or offer

## Output Schema

A publish pack containing: a caption draft (opens on/echoes the carousel's cover line, names the gap it closes, closes with a specific save/engage prompt), platform notes written per delivery target (Instagram / LinkedIn / client delivery / weekly pipeline — not one generic note reused across all), a CTA options list (2-3 options, each tied to a real owned-content or offer pathway), and an explicit audience line. Full contract: `references/prompts-v2/publish-pack.md`.

## Quality Gate

- The caption draft actually references the carousel's own cover line rather than reading as a generic template caption.
- Every requested delivery target gets its own distinct platform note.
- Every CTA option resolves to a real, named pathway — none is a dead-end "follow for more."
- If client delivery is a target, the pack names the full handoff bundle (`carousel-script.md` + `gpt-image-2-prompt.json` + `review-checklist.md`), not just the caption.
- If no owned-content link was supplied, the pack flags that gap rather than inventing one.
