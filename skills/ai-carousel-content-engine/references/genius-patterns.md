# Genius Patterns

## Pattern 1: Article As Source Of Truth

Start from a durable article or insight bank, then use the carousel as distribution. This creates a content engine instead of a posting habit.

## Pattern 2: Structured GPT Image Prompt

The carousel prompt should be a JSON layout spec with slide count, exact text, visual direction, style, and rules. GPT Image 2 is strongest when given discrete regions.

## Pattern 3: Reference-Matched Style

Choose a visual style once, then reuse it across carousels. Reference images or a style board reduce drift.

## Pattern 4: Human-In-The-Loop Taste

Automate draft and design. Keep human selection, copy tightening, and final publish review.

## Pattern 5: Owned-Content Loop

Every carousel should point back to an article, guide, offer, lead magnet, or client conversation. Distribution should feed the source ecosystem.
