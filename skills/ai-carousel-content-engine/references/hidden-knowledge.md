# Hidden Knowledge

## The Prompt Is Not The Moat

The hidden community prompt is less valuable than the system: source selection, slide sequencing, style references, GPT Image layout prompting, and human review.

## Style Matching Is A Taste Shortcut

A single strong reference image or style board communicates more design intent than a vague style paragraph. Build references once and reuse them.

## Carousels Need Editorial Compression

The hard part is not making slides. It is deciding which idea deserves each slide, which line gets visual dominance, and what the reader should do at the end.

## Prompt-First Beats Generation-First

The durable asset is the prompt package. Generated images are useful, but the reusable system is what compounds.
