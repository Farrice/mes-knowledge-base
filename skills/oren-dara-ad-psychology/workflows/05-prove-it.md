# `/adpsy-prove-it` — Prove It In-Frame

> Oren: "how do I within a 60-second prove the value proposition?" Anchor: Shot on iPhone — "you're proving how good the iPhone camera is."

Claims are stated; proof is staged. The three forms from the source: **straight demonstration** (24-hour-hold vlog), **extreme circumstance** ("sharpest chef knife… We have 400 tomatoes here and we're just going to run through"), and **trend carrier** ("we went through all the viral food in LA… you get that visual hook of the amazing food. You're proving the makeup doesn't crease").

## Pre-Flight Gate

- Is the claim physically demonstrable on camera? If the value prop is intangible (status, identity), route tactics 1/2/6 instead.
- Only claim what the frame shows — the demonstration IS the claim ceiling.

## Skill Acquisition

Read `genius.md` (Tactic 4, Proof-in-Frame Compression, Anchor-to-Iconic) + `references/source-quotes.md` Tactic 4 block. Real-case calibration: the Laura Geller ad built from one review — a chef in Arizona whose makeup survived heat + kitchen — "did really really well for that audience."

## Input Required

- **[CLAIM]**: the specific value prop (hold, durability, capacity, speed, taste)
- **[PRODUCT]** + category
- **[REVIEW EVIDENCE]** (optional but gold): a customer who already proved it in their life — the Laura Geller move
- **[LIVE TRENDS]** (optional): current organic hype objects that could carry the demo

## Execution

1. **Compress the claim.** Restate it as one sentence that a 60-second demonstration can settle. If it can't be settled in-frame, narrow the claim.
2. **Build the straight demo.** The honest version: continuous or time-stamped demonstration (vlog-through-the-day for "24-hour hold").
3. **Build the extreme-circumstance variant.** Scale the test past reasonable: 400 tomatoes, the bigger burger. The organic "hype factor" comes from the excess, not the product shot.
4. **Build the trend-carrier variant.** Attach the demo to something the audience already watches (viral food, current challenge) so the visual hook is borrowed: the carrier draws the eye, the product survives the carrier.
5. **Mine reviews for lived proof.** If a customer already ran the extreme test in real life (Arizona chef), that review IS the script — dramatize their circumstance, credit their words.
6. **Write the exec anchor.** One line: which iconic ad is this the principle of (Shot on iPhone / Patek / etc.)? Use it when selling the concept upward.
7. **Vessel handoff**: hooks via `/dara-winning-hooks` (visual layer moves performance most); static version via `/dara-transformation-static` if before/after shaped.

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| Cosmetics/personal care | Hold/wear tests through meals, workouts, weather |
| Tools/durables | Extreme-volume or abuse tests; artisan hands close-ups |
| Food/bev | Blind taste tests (opinion-framed), visual side-by-side |
| Software/services | Timed head-to-head on a real task; screen is the frame |

## Output Requirements

2-3 Prove-It Concepts (straight / extreme / trend-carrier), each: demonstration spec (what the frame literally shows) · claim ceiling note · hook line · exec anchor line. Plus the review-mined variant if evidence exists.

Execution prompt: `references/prompts-v2/05-prove-it-concepts.md`

## Quality Gate

Rubric: proof-in-frame ≥7 (claim demonstrated, not narrated); trend-carrier variant must borrow a REAL current trend, not an invented one. Automatic fail: any claim the demonstration doesn't literally show; a demo that needs the voiceover to be believed.
