# Use Cases — Henry Shukman Contemplative Writing → Workflow Map

> Specific deployment scenarios mapped to the matching `shukman-` workflow. Find the scenario that matches your task, fire the named workflow. When a scenario chains workflows, run them in the order given. When in doubt about whether to deploy wonder *at all*, run `/shukman-mythos-logos` first — it is the gate that decides whether any of the contemplative engine should fire.
>
> **Front door:** `/shukman-let-it-through` (generate a surrendered first draft). **Register gate:** `/shukman-mythos-logos` (decide logos vs. mythos before writing). **Honesty spine, every workflow:** the concrete detail must be true; a faked one is worse than none.

---

## The 11 Workflows at a Glance

| Workflow | One-line job | Pattern |
|---|---|---|
| `/shukman-let-it-through` | Generate a contemplative/poetic/personal **first draft by surrender** — find the live thread, cross the fear barrier, transcribe fast, judgment off | P1, P5, P9 |
| `/shukman-concrete-doorway` | Rebuild any passage reaching for awe so the largest feeling rides **one exact, true particular**; delete abstractions of vastness | P2, P7, P3 |
| `/shukman-embodied-word` | Word-level pass: replace mind-words with **body-words** felt as physical events (*crackles* over *burned*), read-aloud tested | P3 |
| `/shukman-distance-digestion` | **Readiness gate** for high-charge material (grief/trauma/joy/loaded place): READY → draft from recovered ground + find durable motif; HOLD → return the recalibration condition | P4, P12, P11 |
| `/shukman-fear-barrier` | Diagnose a **stuck/careful/sanitized** draft: locate the flinch, name the fear, write the avoided sentence | P5 |
| `/shukman-one-thread` | Find the **single true thread** of a memoir/personal essay in one sentence; strip what doesn't feed it | P11, P12, P10 |
| `/shukman-mythos-logos` | **Register chooser**: logos (inform, be clear) vs. mythos (transmit an experience); rewrite muddied sections into their true register | P6, P7 |
| `/shukman-dont-cut-live-flesh` | **Spirit-preserving revision**: re-enter the original spirit before changing a word; cut only what's dead, protect what's alive | P8, P1 |
| `/shukman-wonder-content` | Produce **finished awe-driven content** (post/essay/newsletter beat) on one true doorway, mythos register, embodied verbs | P2, P7, P6 |

## Scenarios → Workflow

### Drafting & Generation

**"I want to write a poem / contemplative piece but I don't know what to say."**
→ `/shukman-let-it-through`. Don't choose a subject. The workflow finds what's already pulling at you and transcribes it fast. The deliverable includes a one-line note of the *surprise* — the proof it was let through, not assembled.

**"I'm blocked — I've been staring at the page for an hour."**
→ `/shukman-let-it-through` (blocked = the controlling mind refusing to release; the workflow runs the warm-up tap and crosses the fear barrier). If the block is recurring/structural rather than this-session, → `/shukman-daily-tap` (build the faucet so blocks stop happening).

**"I have a 'good idea for a poem/essay' and want to execute it well."**
→ Caution: a fully-pre-planned subject is the forced-poem failure (AN-2). Run `/shukman-let-it-through` and let the workflow test whether you're composing from the surface or genuinely letting through — go smaller and more honest until you can't predict the ending.

**"Write me a meditation / contemplative reflection on [ordinary thing]."**
→ `/shukman-wonder-content` (finished piece) — *but* it forces the honesty check: there must be a *real* moment to mine. If there's none, the workflow stops; a faked one is worse than none.

---

### Awe, Wonder & the Sublime

**"This passage reaches for the sublime but feels purple / hollow / performed."**
→ `/shukman-concrete-doorway`. It rebuilds the passage so the entire feeling rides one concrete, true particular and deletes every standalone abstraction of vastness (*infinite, eternal, profound, the universe*). Delivered as before/after with the doorway-detail named. This is the direct cure for performed wonder (AN-1).

**"My ending doesn't land / the line meant to be the climax falls flat."**
→ `/shukman-concrete-doorway`. Endings and "landing" lines are exactly where drafts reach for the cosmic and announce instead of locate. Find the smallest real detail that carries the largest feeling.

**"I need a finished social post / newsletter beat / essay section that makes the reader feel alive — not just informed."**
→ `/shukman-wonder-content`. The anti-hype post, the section that makes the feed go quiet. Built on one true doorway + mythos register + embodied verbs. Target reader-reaction: "I've seen this a trillion times and never *actually* seen it."

**"Is this piece even supposed to be wondrous, or should it just be clear?"**
→ `/shukman-mythos-logos` FIRST. It forces the honest register call. If the real job is to inform/instruct/sell-on-features, it tells you to stop deploying wonder — "Darwin's journals are fine." This is the guardrail against faking mystery onto a how-to.

---

### Word-Level & Sensory Revision

**"This sentence is true and accurate but reads flat / dead."**
→ `/shukman-embodied-word`. Almost always the load-bearing words are mind-words reporting information (*the wood burned*, *the snow fell*) where they should be body-words felt as physical events (*crackles*, *sifts*). Read-aloud tested; marked-up swaps with the body-response noted.

**"Help me choose between two near-synonyms."**
→ `/shukman-embodied-word`. Test both in the body — does *sifts* feel different in the throat and hands than *falls*? Choose the one you can feel.

---

### High-Charge / Personal Material

**"I want to write about a grief / trauma / loss I'm going through."**
→ `/shukman-distance-digestion` — it runs a HARD readiness gate (Q5 is a veto). If you can't inhabit the experience without being swamped, it returns a **HOLD** with the exact recalibration condition to wait for. It will not write the wound while it bleeds (AN-3). If READY, it drafts from recovered ground and finds the durable motif.

**"I want to write about a place — a city, a landscape — that matters to me."**
→ `/shukman-distance-digestion` (geographic-distance key: Hemingway wrote America best from Paris). For the structural role of place in a longer narrative → `/shukman-one-thread` (which audits place-as-third-character, P10).

**"I want a milestone / anniversary / memorial piece that outlasts its moment."**
→ `/shukman-distance-digestion`. The deliverable includes the **durable motif** (the frozen lake, the candle, the rain) — the portable vessel a reader can carry into their own future dark night.

**"My personal piece feels careful, safe, weirdly correct, and dead."**
→ `/shukman-fear-barrier`. It locates the flinch (the "not that" you steered around), names the fear underneath, and writes the one sentence you were scared to write. **Safety interlock:** if the material is still bleeding (a distance flinch, not a fear-of-exposure flinch), it honors the flinch and routes you to wait — `/shukman-distance-digestion`.

### Structure & Subject

**"My memoir / personal essay sprawls and loses the reader."**
→ `/shukman-one-thread`. It finds the single true thread — not "my life" but *this* trajectory through it — states it in one sentence the reader could repeat, then strips everything that doesn't feed it. Yields a spine + a strip-list of what got cut.

**"I'm about to write a 'my journey' piece and want it tight from the start."**
→ `/shukman-one-thread` first (name the thread before drafting), then `/shukman-let-it-through` (draft it), then `/shukman-distance-digestion` if it's high-charge.

---

### Revision (without killing it)

**"I have a draft with real spark and I'm scared revising will flatten it."**
→ `/shukman-dont-cut-live-flesh`. Re-enter the original spirit (re-feel, don't re-think) BEFORE changing a word; cut only what's dead/stilted/right-angled; protect what's alive even when you can't justify it. Ships with a Protection Log. Finished by the MacCaig "wet ink" test.

**"My draft came out clean but deadened / over-edited / stilted."**
→ `/shukman-dont-cut-live-flesh`. This is the exact cure for the over-edited draft. Default verdict on every line is PROTECT; the burden of proof is on the *cut*.

**"I want to rebuild this already-good piece properly from a cleaner angle."**
→ STOP. That urge is the failure mode (AN-4 + the always-on law: rebuilding already-elevated work degrades it). Run `/shukman-dont-cut-live-flesh` for small surgical passes — do not rebuild. (If the piece genuinely never had spark, that's a generation problem → `/shukman-let-it-through`, not a revision problem.)

### Cross-Domain Deployment (Shukman's technique → business writing)

**"Build a brand voice for a wellness / mindfulness / contemplative / calm-tech brand."**
→ `/shukman-contemplative-brand`. Chooses the mythos/logos mix honestly, sets the sincerity register (no irony shield), applies the concrete doorway to product and experience, installs the no-faked-mystery guardrail (the manufactured-serenity trap), and ships a deployable voice card with do/never lines a copywriter can run. **Note:** it tunes *how the brand sounds when it tells the truth* — it sits inside oren-brand / build-bos positioning, it does not decide what the brand *is*. If you can't name one true concrete thing the brand offers, do positioning first.

**"My wellness copy reads like manufactured serenity — serene, sacred, sanctuary, journey stacked up."**
→ `/shukman-contemplative-brand` (for the voice system) or `/shukman-concrete-doorway` (for a single passage). Both replace the abstraction-stacking with one real particular.

**"I need scroll-stopping social content that isn't hype."**
→ `/shukman-wonder-content`. The sincere pause in a feed built on performance.

**"I'm ghostwriting and the client's drafts sound like generic brand-speak."**
→ `/shukman-let-it-through` (capture the unguarded true line, not the composed positioning) → `/shukman-one-thread` (find the trajectory of *this* piece). If the client sanitized the real thing → `/shukman-fear-barrier`.

**"Write a founder failure story / origin story that lands."**
→ `/shukman-distance-digestion` (READY/HOLD gate — failure told from recovered ground, not the wound) → `/shukman-one-thread` (name the single trajectory, root it in its real place). Then `/shukman-let-it-through` to draft.

**"My product copy is all claims (durable, premium, ergonomic) and converts poorly."**
→ `/shukman-concrete-doorway` (replace the claim with one real felt moment that *demonstrates* it) → `/shukman-embodied-word` (verb-level pass). Honesty check mandatory.

---

### Practice & Cadence

**"Help me build a sustainable daily writing / content practice."**
→ `/shukman-daily-tap`. A 5–6 day/week cadence, a warm-up that opens the channel without forcing the poem, and a two-timescale tracking frame (clearing *this month* AND *across the year*). Metric = did the tap RUN, not did today's output perform.

**"I'm setting a content cadence but my voice hasn't settled yet."**
→ `/shukman-daily-tap`. Consistency is how the water runs clear — over a lifetime, not a launch. The early dirty-water posts are the price of the later clear ones.

**"Force me to produce great work every day."**
→ Caution: that's not a practice, it's a slow way to kill the channel. `/shukman-daily-tap` builds the *faucet* (show up, let the channel stay open); quality is a lifetime statistic, not a daily one.

## When NOT to Use This Skill

- **The job is genuinely logos** (a how-to, a spec, an FAQ, a clear instruction). Run `/shukman-mythos-logos`; if it returns logos, *stop deploying wonder* — faking mystery onto a how-to is the same failure as performed awe, inverted.
- **The material is still bleeding.** `/shukman-distance-digestion` will return HOLD; honor it. Distance makes material inhabitable, not safe — but writing the open wound (AN-3) drowns the reader.
- **There's no real detail to mine.** The honesty spine is absolute across every workflow: if there's no true thing actually perceived/remembered/honestly imagined, there's no honest piece. A faked detail is worse than none.
- **The piece was already elevated and you want to "redo it properly."** That urge is the failure mode (AN-4). Use `/shukman-dont-cut-live-flesh` for small surgical passes; never rebuild.
