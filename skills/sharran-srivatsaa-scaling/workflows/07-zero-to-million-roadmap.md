# Zero to $1M Roadmap

> Load `skills/sharran-srivatsaa-scaling/genius.md` before executing.

## Inputs Required
- **Business idea or existing business** (What do you sell or plan to sell?)
- **Current revenue** ($0 / under $10K/mo / $10-25K/mo / $25-85K/mo)
- **Available resources** (Capital, time per week, existing skills, existing network)
- **Target timeline** (12 months / 18 months / 24 months — be realistic)
- **Why $1M?** (What specifically changes in your life at $1M? This is the fuel.)

> **🔒 Pre-Flight Gate**: This roadmap is for business builders who want a systematic path, not a "get rich quick" scheme. The honest timeline from zero to $1M annual is typically 18-36 months with full commitment. If the user needs cash in 7 days, route to Emergency Revenue protocols.

## The Roadmap

### Phase 1 — STANDARDIZE ($0 → $10K/month)
**Timeline**: Months 1-6 | **Primary Job**: Make the machine work once

#### The Constraint at This Phase
You don't have a business. You have an idea, a skill, or a service. The constraint is **converting that into something someone will pay for, repeatedly**.

#### Critical Actions

**1. The Napkin Test**
Write the business on a napkin. If it takes more than a napkin, simplify.

```
I help [specific person] achieve [specific outcome] through [specific method].
They pay me $[price] per [unit].
I can deliver [number] per [time period].
Maximum revenue at capacity: $[amount]/month.
```

If maximum capacity < $10K/month → the model won't work. Redesign before proceeding.

**2. The First 5 Clients**
Do not build systems. Do not build a website. Do not make a logo. GET CLIENTS.

| Method | Action | Target |
|--------|--------|--------|
| Direct outreach | Message 10 people per day who fit the ICP | 5 conversations/week |
| Free work / proof runs | Deliver for 2-3 people for free or discount to build proof | 3 case studies |
| Referral request | Ask every happy client for 2 referrals | 2 referrals per client |
| Content signal | Post 3x/week showing your work and thinking | Authority building |

**3. The Simple Spreadsheet**
Build the financial model:

| Line Item | Number |
|-----------|--------|
| Price per client/project | $ |
| Cost to deliver (your time valued at $50/hr) | $ |
| Gross margin | $ |
| Clients needed for $10K/month | |
| Leads needed (at current close rate) | |
| Current lead generation capacity | |

**4. First Artifact of Success**
Write down: (a) exactly how you deliver the service, step by step, (b) what the client experiences in their first 7 days, (c) the 3 metrics that tell you the business is healthy.

#### Exit Criteria for Phase 1
- [ ] 3+ paying clients at full price
- [ ] Service delivered with documented, repeatable process
- [ ] Revenue trend: growing or stable for 2+ consecutive months
- [ ] Can explain the business in one sentence
- [ ] Financial model shows path to $25K/month at capacity

### Phase 2 — OPTIMIZE ($10K → $25K/month)
**Timeline**: Months 6-12 | **Primary Job**: Make the machine efficient

#### The Constraint at This Phase
You're working. The business is working. But YOU are the business. The constraint is **yourself as the bottleneck** — in delivery, sales, and decision-making.

#### Critical Actions

**1. CEO Time Audit**
Track one week honestly:

| Activity Category | Hours/Week | % of Total | Leverage Level |
|-------------------|-----------|------------|----------------|
| Client delivery (doing the work) | | | Low |
| Sales / business development | | | High |
| Admin / operations | | | Low |
| Strategy / planning | | | High |
| Content / marketing | | | Medium |
| Meetings (internal) | | | Variable |
| Meetings (external) | | | Variable |

**Target**: >50% of time in High Leverage activities. If you're spending >50% in Low Leverage → that's the constraint.

**2. The First Hire (or Automation)**
Answer: "What is the ONE task that, if removed from my plate, would unlock the most growth?"

| Option | Cost | Time Freed | Revenue Potential of Freed Time | ROI |
|--------|------|-----------|-------------------------------|-----|
| Hire VA for admin | $/mo | hrs/wk | $ | x |
| Hire contractor for delivery | $/mo | hrs/wk | $ | x |
| Automate [process] | $/setup | hrs/wk | $ | x |

**3. Sales Process Documentation**
Write the sales playbook:
- Lead qualification criteria (who is and isn't a fit)
- Discovery call script (questions, not pitch)
- Proposal template
- Follow-up sequence (48-hour rule: contact within 48 hours or lose them)
- Objection handling (top 5 objections + responses)

**4. KPI Dashboard**
Build and review weekly:

| Metric | Week 1 | Week 2 | Week 3 | Week 4 | Target |
|--------|--------|--------|--------|--------|--------|
| Leads generated | | | | | |
| Discovery calls booked | | | | | |
| Proposals sent | | | | | |
| Deals closed | | | | | |
| Revenue collected | | | | | |
| Client satisfaction (NPS/feedback) | | | | | |

#### Exit Criteria for Phase 2
- [ ] Revenue consistently $20K+/month for 3 consecutive months
- [ ] CEO spending <30% of time on delivery
- [ ] At least 1 person (hire or contractor) handling repeatable tasks
- [ ] Sales process documented and followed consistently
- [ ] KPI dashboard reviewed weekly with trend data

### Phase 3 — GROW ($25K → $85K/month)
**Timeline**: Months 12-24 | **Primary Job**: Add fuel to the working machine

#### The Constraint at This Phase
The machine works. The machine is documented. The constraint is now **people and channels**. You need humans who can execute the systems you've built, and you need more ways to generate demand.

#### Critical Actions

**1. The Leadership Hire**
The single most transformative action at this phase. Identify the role:

| Role Type | When It's Right | Impact |
|-----------|----------------|--------|
| Operations Manager | You're drowning in delivery logistics | Frees CEO for sales + strategy |
| Sales Person | You have more leads than you can handle | Scales revenue without CEO |
| Marketing Lead | Your acquisition is CEO-dependent | Creates independent demand generation |
| Senior Practitioner | Quality drops when you're not involved | Scales delivery capacity |

**2. Second Channel Development**
If >80% of revenue comes from one acquisition channel → build a second:

| Channel | Current Revenue % | Growth Potential | Investment Required |
|---------|------------------|-----------------|-------------------|
| Referrals | | | |
| Content / organic | | | |
| Paid ads | | | |
| Partnerships | | | |
| Outbound | | | |

**3. Offer Architecture**
Evaluate whether the current offer can reach $85K/month, or if you need to:

| Option | Path to $85K/mo |
|--------|-----------------|
| Raise prices | [current price] → [new price] × [clients needed] |
| Add a premium tier | Base offer + premium offer at [2-3x price] |
| Add recurring revenue | Monthly retainer / subscription component |
| Productize knowledge | Course, template, or tool alongside service |

**4. Meeting Cadence**
Install the operational rhythm:
- **Daily**: 15-min standup (team alignment)
- **Weekly**: 60-min team meeting (KPI review, constraint discussion)
- **Monthly**: 90-min strategic review (are we on track for the quarter?)
- **Quarterly**: Half-day planning (set next quarter's constraint + priorities)

#### Exit Criteria for Phase 3
- [ ] Revenue consistently $70K+/month for 3 consecutive months
- [ ] Team of 3+ people executing without daily CEO involvement
- [ ] 2+ acquisition channels generating leads independently
- [ ] Offer architecture can mathematically reach $85K/month target
- [ ] Meeting cadence running consistently for 8+ weeks

### Phase 4 — SCALE ($85K → $1M/year run rate)
**Timeline**: Months 18-30 | **Primary Job**: Multiply the machine

#### The Constraint at This Phase
The people are hired. The systems are built. The constraint is **strategic clarity** — knowing what to build next, what to say no to, and how to make decisions at scale.

#### Critical Actions

**1. Decision Mapping Deployment**
The CEO's primary job is now making decisions, not doing work.
- Run `/decision-map` on every strategic choice (>$5K impact)
- Install the Decision Log as a standing artifact
- Train team leads to run their own decision maps for their domains

**2. The "Stop" Audit**
What got you here won't get you there. Identify what to kill:

| Activity/Product/Client | Revenue/Value | Time/Energy Cost | Keep / Kill / Delegate |
|------------------------|---------------|-----------------|----------------------|
| | | | |
| | | | |
| | | | |

**3. Culture Architecture**
At this stage, culture becomes a constraint or an accelerator:
- Define the 3-5 non-negotiable values (not aspirational — actual behaviors)
- Install the "remind of past, focus on bigger future" culture cadence
- Build the Results Economy (judge output, not face time)

**4. Daisy Chain Protection**
Run `/daisy-chain-audit`. At $1M trajectory, the founder's health and relationships are under maximum strain. This is where most founders break.

**5. The Coach/Mentor Gate**
Sharran's lesson: "Transformations don't happen in isolation."

| Resource | Status | Action |
|----------|--------|--------|
| Business coach/mentor | ☐ Have / ☐ Need | [Action] |
| Peer group / mastermind | ☐ Have / ☐ Need | [Action] |
| Advisory board (even informal) | ☐ Have / ☐ Need | [Action] |
| Accountability partner | ☐ Have / ☐ Need | [Action] |

#### Exit Criteria for Phase 4
- [ ] Revenue run rate at $1M+/year ($83K+/month) for 3 consecutive months
- [ ] Business can operate for 2 weeks without CEO daily involvement
- [ ] Decision-making distributed — team leads making decisions within their domains
- [ ] Daisy chain audit score ≥30/50 (not sacrificing life for business)
- [ ] Coach/mentor relationship active

## Quality Gate
- [ ] Current phase correctly identified with evidence (not aspiration)
- [ ] Actions are specific to the CURRENT phase (not mixing phase activities)
- [ ] Financial model included showing mathematical path to next milestone
- [ ] Exit criteria are specific and measurable
- [ ] 90-day plan has weekly granularity
- [ ] Daisy chain mentioned (business growth is not the only metric)
- [ ] Coach/mentor need assessed

> **🛡️ Anti-Pattern Check**: The most dangerous pattern is trying to execute Phase 3 or 4 activities while still in Phase 1 or 2. Building a team before you have a repeatable process → wasted money. Running paid ads before you can close leads → wasted budget. Respect the sequence.
