# Artifacts of Success Builder

> Load `skills/sharran-srivatsaa-scaling/genius.md` before executing.

## Inputs Required
- **Business stage** (Standardize / Optimize / Grow / Scale)
- **Current artifacts** (What is already documented? Plans, SOPs, dashboards, playbooks?)
- **Team size** (Solo / 2-5 / 6-20 / 20+)
- **The constraint** (Output from `/constraint-audit` or `/10x-diagnostic`)

> **🔒 Pre-Flight Gate**: "Big Goal / No Plan = plague of high achievers." If the business has ambitious goals but nothing written down, this is likely the FIRST workflow to run.

## The Process

### Step 1 — Artifact Audit

Sharran's principle: **"If it isn't written down, it doesn't exist."**

Score each artifact category:

| Artifact Category | Status | Quality (1-5) | Notes |
|-------------------|--------|--------------|-------|
| **Business Plan** (1-page: vision, mission, 90-day priorities) | ☐ Exists / ☐ Missing | | |
| **Financial Dashboard** (revenue, expenses, cash flow, runway) | ☐ Exists / ☐ Missing | | |
| **Sales Process** (pipeline stages, scripts, follow-up sequences) | ☐ Exists / ☐ Missing | | |
| **Delivery SOPs** (step-by-step for how the product/service is delivered) | ☐ Exists / ☐ Missing | | |
| **Hiring Playbook** (job descriptions, interview process, onboarding) | ☐ Exists / ☐ Missing | | |
| **Client Onboarding** (first 7 days experience for new customers) | ☐ Exists / ☐ Missing | | |
| **Meeting Cadence** (weekly/monthly/quarterly rhythm with agendas) | ☐ Exists / ☐ Missing | | |
| **KPI Scorecard** (the 5-7 numbers that tell you if the business is healthy) | ☐ Exists / ☐ Missing | | |
| **Decision Log** (record of major decisions, rationale, outcomes) | ☐ Exists / ☐ Missing | | |
| **Coach Memo** (strategic reflection document for CEO growth) | ☐ Exists / ☐ Missing | | |

**Artifact Score**: ___/50

| Score Range | Diagnosis |
|-------------|-----------|
| 0-15 | **Critical**: Business is running on hope and memory. Start here. |
| 16-25 | **Developing**: Foundation exists but major gaps. Prioritize the missing ones. |
| 26-35 | **Functional**: Good base. Focus on quality improvements and consistency. |
| 36-50 | **Mature**: Strong artifact infrastructure. Move to optimization and team alignment. |

### Step 2 — Priority Triage

Not all artifacts matter equally at every stage. Map to the business phase:

**STANDARDIZE Phase Priorities:**
1. One-Page Business Plan (napkin-level clarity)
2. Delivery SOP (make it repeatable)
3. Basic Financial Dashboard (know your numbers)

**OPTIMIZE Phase Priorities:**
1. KPI Scorecard (measure what matters)
2. Sales Process Documentation (make selling repeatable)
3. Meeting Cadence (weekly rhythm)

**GROW Phase Priorities:**
1. Hiring Playbook (scaling people)
2. Client Onboarding (scaling experience)
3. Decision Log (institutional memory)

**SCALE Phase Priorities:**
1. Coach Memo System (CEO self-coaching)
2. Strategic Planning Documents (quarterly OKRs)
3. Team Decision-Making Frameworks (distribute decision capacity)

### Step 3 — Artifact Templates

For each priority artifact, build the template:

#### One-Page Business Plan
```
VISION: [Where are we going in 3-5 years?]
MISSION: [What do we do, for whom, and why it matters?]

90-DAY PRIORITIES:
1. [Priority 1 — the constraint to solve]
2. [Priority 2 — supporting action]
3. [Priority 3 — preparation for next phase]

KEY NUMBERS:
- Revenue Target: $___
- Lead Target: ___/week
- Close Rate Target: ___%
- Client Capacity: ___

THE ONE THING:
If we could only accomplish ONE thing this quarter, it is:
> [Single sentence]
```

#### KPI Scorecard
```
WEEKLY SCORECARD — Week of [date]

| Metric | Target | Actual | Status |
|--------|--------|--------|--------|
| Revenue | | | 🟢🟡🔴 |
| New Leads | | | 🟢🟡🔴 |
| Qualified Leads | | | 🟢🟡🔴 |
| Close Rate | | | 🟢🟡🔴 |
| Client Satisfaction | | | 🟢🟡🔴 |
| Cash Collected | | | 🟢🟡🔴 |
| CEO Hours in Zone of Genius | | | 🟢🟡🔴 |

CONSTRAINT STATUS:
> [Current constraint + progress toward solving it]

```

#### Coach Memo
```
COACH MEMO — [Date]

WHAT HAPPENED:
[Factual summary of the week/month — decisions made, results achieved, problems encountered]

WHAT I LEARNED:
[Insights — not just what happened, but what it MEANS]

WHAT I'D DO DIFFERENTLY:
[Honest reflection — no defensiveness]

WHAT I NEED HELP WITH:
[Where I'm stuck — specific enough that a coach/advisor could act on it]

MY ENERGY LEVEL (1-10): ___
THE CONSTRAINT RIGHT NOW:
> [One sentence]
```

#### Decision Log
```

| Date | Decision | Context | Rationale | Owner | Review Date | Outcome |
|------|----------|---------|-----------|-------|-------------|---------|
| | | | | | | |
```

### Step 4 — Implementation Plan

The artifacts are only useful if they're USED. Build the operating rhythm:

| Artifact | Frequency | Owner | Time Required | Day/Time |
|----------|-----------|-------|---------------|----------|
| KPI Scorecard | Weekly | CEO | 30 min | Monday AM |
| Team Meeting | Weekly | CEO | 60 min | Monday AM |
| Coach Memo | Bi-weekly | CEO | 45 min | Friday PM |
| Financial Review | Monthly | CEO + Finance | 90 min | 1st of month |
| Decision Log Update | As needed | CEO | 10 min | After each decision |
| Business Plan Review | Quarterly | Leadership | 3 hours | Quarter start |

---

## Quality Gate
- [ ] Artifact audit scored all 10 categories with specific evidence
- [ ] Priorities matched to actual business phase (not aspirational phase)
- [ ] Templates are specific to THIS business (not generic)
- [ ] Operating rhythm has specific days, times, and owners
- [ ] Coach Memo template included (this is Sharran's secret weapon)
- [ ] Implementation plan is realistic given team size and capacity

> **🛡️ Anti-Pattern Check**: If someone wants to build all 10 artifacts at once, STOP. That's the "Big Goal / No Plan" trap applied to the artifacts themselves. Build the top 3 for your phase first.
