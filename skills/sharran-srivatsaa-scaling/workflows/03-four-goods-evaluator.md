# Four Goods Evaluator

> Load `skills/sharran-srivatsaa-scaling/genius.md` before executing.

## Inputs Required
- **Deal description** (What is the investment/partnership/opportunity?)
- **The other party** (Who are you evaluating? Background, reputation, history)
- **Terms proposed** (What is being offered? Equity splits, roles, financial terms)
- **Your position** (What resources are you committing? Capital, time, reputation)

> **🔒 Pre-Flight Gate**: This framework is for investments/partnerships where you are committing capital, equity, or significant time. For hiring decisions, route to genius.md § Turning Points = People Decisions. For strategic decisions, use `/decision-map`.

## The Process

### ⚠️ SEQUENTIAL GATE SYSTEM
The order is the protection. You CANNOT evaluate Good Contract before Good People, Good Intentions, and Good Rationale pass. Each Good is a gate — if it fails, the deal stops. No exceptions.

---

### Good 1 — Good People

Referrals are not enough. You need working relationship and history.

| Criterion | Score (1-5) | Evidence |
|-----------|------------|----------|
| **Track record**: Have they built something before? What was the outcome? | | |
| **Reputation check**: What do people who've WORKED WITH them (not just know them) say? | | |
| **Working relationship**: Have YOU worked with them on anything, even small? | | |
| **Consistency**: Does their story remain consistent across multiple conversations? | | |
| **Character under pressure**: How do they behave when things go wrong? (Ask their past partners) | | |

**Minimum Score**: 15/25 to proceed. Below 15 = STOP. No deal.

**Red Flags:**
- Can't provide references from people who've WORKED with them (not just friends)
- Story changes between conversations
- Past partnerships ended badly and they blame the other party every time
- No verifiable track record of execution

---

### Good 2 — Good Intentions

Is this person friendly, helpful, and collaborative? Or are they the dangerous "person in the middle"?

| Criterion | Score (1-5) | Evidence |
|-----------|------------|----------|
| **Collaborative spirit**: Do they share information openly or hoard it? | | |
| **Direct connections**: Are they willing to connect you directly with relevant parties? | | |
| **Value creation**: Do they create value independent of being the gatekeeper? | | |
| **Alignment of interests**: Are their goals genuinely aligned with yours, or are they extractive? | | |
| **Communication style**: Transparent about challenges and risks, or only positive? | | |

**Minimum Score**: 15/25 to proceed. Below 15 = STOP. No deal.

**🚨 The Dangerous Middle Person Test:**
- Do they ALWAYS need to be in the room?
- Do they resist direct connections between principals?
- Is their primary value "access" rather than execution?
- Would removing them from the deal make it simpler or impossible?

If 2+ of these are YES → this is the dangerous middle person. STOP.

---

### Good 3 — Good Rationale

The deal has to work on a simple spreadsheet. No spreadsheet, no deal.

| Criterion | Score (1-5) | Evidence |
|-----------|------------|----------|
| **Simple math**: Can the business model be explained on a napkin? | | |
| **Unit economics**: Revenue per unit, cost per unit, margin — does it work? | | |
| **Market validation**: Is there evidence of demand, or is this theoretical? | | |
| **Downside protection**: If the worst happens, what do I lose? Can I survive it? | | |
| **Return thesis**: What is the specific mechanism through which I make money? | | |

**Minimum Score**: 15/25 to proceed. Below 15 = STOP. No deal.

**The Spreadsheet Test:**
Build a simple model with these inputs:
- Revenue assumptions (conservative, moderate, aggressive)
- Cost structure (fixed + variable)
- Timeline to breakeven
- Capital required vs. capital at risk
- Return scenarios (1X, 3X, 5X, 10X — what has to be true for each?)

If the partner can't produce or collaborate on this spreadsheet → NO DEAL.

---

### Good 4 — Good Contract

Memorialize the agreement. But NEVER proceed here without the first three being satisfied.

| Criterion | Score (1-5) | Evidence |
|-----------|------------|----------|
| **Clarity**: Are roles, responsibilities, and expectations unambiguous? | | |
| **Exit provisions**: How does each party exit if things go wrong? | | |
| **Decision rights**: Who has authority over what? Is that clear? | | |
| **Financial terms**: Capital calls, distributions, waterfall — crystal clear? | | |
| **Dispute resolution**: What happens when there's a disagreement? | | |

**Sharran's Contract Philosophy:**
> "We don't look at contracts as a way to enforce something. We look at contracts as a way to memorialize our agreement."

The contract protects the RELATIONSHIP, not just the transaction. If the contract feels adversarial, Good Intentions hasn't truly passed.

## Quality Gate
- [ ] All four Goods evaluated with specific evidence (not gut feelings)
- [ ] Sequential gate respected — stopped if any Good scored below 15
- [ ] Middle Person Test applied in Good Intentions
- [ ] Spreadsheet Test completed (or failure to produce one documented)
- [ ] Contract section only evaluated AFTER first three passed
- [ ] Clear VERDICT with rationale
- [ ] Risks accepted are named specifically

> **🛡️ Anti-Pattern Check**: The most common failure mode is evaluating Good Contract first because "the terms look great." Terms that look great with bad people = guaranteed loss. Enforce the sequence.
