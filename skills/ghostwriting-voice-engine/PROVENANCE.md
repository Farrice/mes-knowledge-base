## Methodology Governance

**Sourcing Standard**: Every anti-pattern and framework is sourced to a named expert's extraction transcript with:
- Direct file path (e.g., `extractions/lara-acosta/transcript.txt`)
- Extraction date (e.g., 2026-01-20)
- Confidence level (VERIFIED / LIKELY / UNCONFIRMED)
- Verbatim quote or documented practice reference

**Deployment Model**: Patterns are classified by load tier:
- **Tier 1** (core)**: Always load when producing expert-domain output
- **Tier 1.5** (verification layer): Load when validating voice profiles or quality gates
- **Tier 2** (specialized): Load only for premium work or when depth score is 3+
- **Tier 0** (orientation): Load before any workflow execution

**Preservation Rule**: Constraints adopted by experts (Albom's sentence length, Cole's compression obsession) are treated as signatures, never "corrected." Limitations become differentiation.
