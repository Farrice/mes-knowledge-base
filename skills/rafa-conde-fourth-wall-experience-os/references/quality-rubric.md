# Quality Rubric

| Criterion | Score 4 - Acceptable | Score 7 - Good | Score 10 - Savant |
|---|---|---|---|
| Frame Clarity | Names a general surprise | Identifies the specific frame being broken | Makes the frame break obvious, elegant, and tied to the idea |
| Truthfulness | Uses generic personalization | Uses real context or user behavior | Uses a context only this medium/audience could provide |
| Surprise | Adds novelty | Creates a clear "wait" moment | Creates surprise that becomes insight |
| Taste | Clever but risky | Controlled and appropriate | Feels inevitable, human, and high-quality |
| Utility | Does not block the task | Improves engagement | Makes the core idea easier to understand and remember |
| Fallback | Assumes everyone gets it | Provides normal path | Users who miss it still get a strong experience |
| Transferability | Works in one format | Adapts to adjacent formats | Transfers cleanly across product, content, launch, client, agent, and live domains |
| Safety | Avoids obvious harm | Respects user trust | Names boundaries, consent, accessibility, and creepiness risks explicitly |

## Fail Conditions

- It is just storytelling with a clever line.
- It references the user in a way that feels fake, creepy, or manipulative.
- It adds friction without a meaningful payoff.
- It distracts from the product or argument.
- It has no fallback.
- It is copied from games or films without translating the underlying mechanic.
- It uses "surprise and delight" as decoration.
