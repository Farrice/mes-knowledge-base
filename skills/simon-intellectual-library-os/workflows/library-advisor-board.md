# Library Advisor Board

"Alex Hormozi and Obama on your board of advisors" — done honestly: each seat is grounded in a curated corpus, gated, and confidence-labeled. Stacks with `/convene` (Collective Genius Council).

## Pre-Flight Gate
- Load `genius.md` §Mandatory Grounding Gate + §Context Stack Loading.
- Every proposed seat needs an existing grounded KB (library lane, advisor, or extraction bridged via `/library-extraction-bridge`). A seat without a corpus is a persona, not an advisor — either bridge it first or label it explicitly as ungrounded color.
- 3-5 seats max; more dilutes deliberation.

## Skill Acquisition
Read `genius.md` + each seat's KB/genius context + the user's context layer (who-am-I/context map) — board answers must be framework × THEIR situation.

## Execution
1. **Cast the board**: pick seats for productive DISAGREEMENT on this question (different lanes, different confidence profiles), not topical overlap.
2. **Seat briefs**: per advisor — its KB scope, its gate ("answer ONLY from your corpus; flag when your KB is silent"), its known biases (from the extraction's anti-patterns).
3. **Round 1 — Grounded takes**: each seat answers independently, citing its entries (entry names/sources inline). A seat whose KB is silent SAYS SO — that's the system working, not failing.
4. **Round 2 — Cross-examination**: each seat challenges one other seat's take using its own corpus ("Godin's 'everyone is not your customer' cuts against your volume play"). Real citations only.
5. **Synthesis**: convergences (multiple corpora agree = high confidence) · live disagreements (present BOTH sides with sources — don't average dissent away) · gaps (no seat's corpus covers it → flagged as board blind spot + research candidate).
6. **Compound**: the synthesis is saved back into the library (Type=Case Study, the question as context) and session memory — boards make the library smarter.

## Content Type Adaptations
| Question type | Adaptation |
|---|---|
| Positioning/strategy | Seats from different GTM philosophies; disagreement is the product |
| Creative direction | Add one craft seat (taste) + one audience-psychology seat |
| Antigravity /convene runs | This workflow = grounding layer: each council member loads genius.md + bridged entries; cite-or-flag rule enforced |
| Client deliverable | Synthesis reformatted ≤2 pages (density rule); citations as endnotes |

## Output Requirements
Board roster with corpus per seat + grounded takes with citations + cross-examination + synthesis (convergence/dissent/blind spots) + the save-back entry. Ungrounded seats labeled in every appearance.

## Quality Gate
`genius.md` §Rubric Groundedness — ≥8 = every claim traceable to a seat's corpus; silent-KB moments visible. §Anti-Patterns: persona cosplay (un-gated seats), averaged-away dissent, board output not compounded back.
