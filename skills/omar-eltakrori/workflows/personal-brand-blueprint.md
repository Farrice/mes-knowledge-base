# Personal Brand Blueprint Workflow

## Overview
End-to-end pipeline for building a personal brand business that generates revenue. Three phases executed sequentially with checkpoints.

## Pre-Work
1. Define the niche/expertise area
2. Identify the target audience (who you help and what transformation you provide)
3. Inventory existing content assets, stories, and proof points

## Phase 1: Unlock Infinite Content

### Step 1: Activate Student's Identity
- List 5 books, podcasts, or courses you're currently consuming
- For each: extract 3 principles you can teach or riff on
- Output: 15+ content seeds

### Step 2: Build Your Content Engine
Map content to cadence:
- **1 long-form per week** — YouTube video, podcast episode, blog post, or live stream
- **5 feed posts per week** — LinkedIn, Instagram, Twitter/X
- **3-5 stories per day** — Instagram/Facebook stories, behind-the-scenes

### Step 3: Content Type Mix
For each week, plan content using these types:
- [ ] **Cutless content** — 1 raw, unedited piece (live stream, voice memo riff, sneeze-and-keep-going video)
- [ ] **Classified content** — 1 phone album photo + copy overlay post
- [ ] **Two-at-once content** — 1 piece where you share a tip in a lifestyle context (gym, cooking, driving)
- [ ] **PPP content** — 1 Picture → Parable → Principle post (personal story → lesson)
- [ ] **Framework content** — 1 piece introducing or teaching a coined framework

### Step 4: Apply the Five F's
Review your content calendar. Are you sharing across all five:
- [ ] Faith (belief system, values)
- [ ] Family (relationships, personal life)
- [ ] Food (culinary, dining, cooking)
- [ ] Fashion (style, aesthetics, gear)
- [ ] Fitness (physical pursuits, health)

**Checkpoint:** You should have 30 days of content planned before moving to Phase 2.

## Phase 2: Usher Into an Intimate Conversion Event

### Step 5: Choose Your Conversion Vehicle
Select ONE:
- [ ] **Web class / Master class** (free, 60-90 min, kills limiting beliefs, teaches through a lens like "5 mistakes")
- [ ] **5-Day Challenge** (paid, $197-$400, daily Zoom sessions + Q&A, culminates in offer)
- [ ] **Workshop** (paid, single session, intensive)
- [ ] **Discovery/Sales call** (1-on-1, for high-ticket)
- [ ] **In-person event** (highest conversion, highest cost)

### Step 6: Script the Conversion Event
If web class:
1. Open with your story (Picture → Parable → Principle)
2. Teach through the lens of mistakes/myths (belief shifting, not information dumping)
3. Present the offer as the next step for those who want acceleration
4. Use urgency + scarcity (limited spots, time-bound pricing)

If challenge:
1. Day 1-4: Teach one pillar per day. Q&A each session.
2. Day 5: Present the core offer. Application-based. Limited spots.
3. Follow up with attendees who didn't purchase (fortune is in the follow-up).

### Step 7: Build the Lead Pipeline
- [ ] Organic: CTA in content → free web class registration
- [ ] Paid: Facebook/Instagram ads → free web class → paid challenge ticket
- [ ] Ad budget guidance: $30K-$50K per challenge cycle (for established businesses)

**Checkpoint:** Conversion event scripted and lead pipeline mapped before Phase 3.

## Phase 3: Uncover Your Core Irresistible Offer

### Step 8: Define What They're Actually Buying
Map your offer to the 7 value types:
- [ ] **Acceleration** — How does this speed up their result?
- [ ] **Transformation** — What identity shift happens?
- [ ] **Organization** — How does this structure scattered knowledge?
- [ ] **Proximation** — What access do they get to you?
- [ ] **Identification** — What new identity do they embody?
- [ ] **Community** — Who else is in the room?
- [ ] **Consolidation** — How is everything in one place?

### Step 9: Price the Offer
- Start math from the goal: $1M ÷ price = number of clients needed
- Price should make buyers pay attention (Price = Attention principle)
- Consider founders pricing for first cohort (identity + locked-in rate)
- Focus articulation on PAYOFF, not features

### Step 10: Structure One-to-Many Delivery
- Weekly group coaching call (not 1-on-1 unless ultra-premium)
- Community platform (Skool, Circle, Slack)
- Optional: quarterly in-person events
- Renewal/ascension path for existing members

### Step 11: Launch
Use the Challenge Model:
1. Run ads to free master class
2. Master class → paid challenge ticket
3. Challenge → present offer on final day
4. Follow up with non-buyers
5. Measure: revenue, conversion rate, cost per lead, cost per acquisition
6. Iterate for data, not perfection ("do it for the data")

## Post-Launch
- Run the play again. Same format, improved execution.
- Raise price as demand grows (Omar: $2K → $25K, same core offer)
- Renewals become passive income stream
- "I am boring. I just run the play."
