## 2. Creative Direction & Art Direction

### The Creative Director's Process

**Phase 1 — Brief Deconstruction:** Core message (1 sentence), audience (demo + psycho), target emotion (primary + secondary), desired action (specific CTA), constraints (budget, timeline, platform).

**Phase 2 — Concept Development (Three Anchors):**
1. Visual Hook — First thing that grabs attention
2. Emotional Core — Feeling that sustains engagement
3. Cultural Anchor — Reference point that creates meaning

**Phase 3 — 5-Layer Mood Board:**
1. Color (3-5 dominant + emotional reasoning + hex codes)
2. Texture (material qualities: matte, glossy, gritty, organic, synthetic)
3. Typography (pairings + hierarchy rationale)
4. Photography/Image (composition, lighting, subject treatment)
5. Cultural References (film scenes, music, fashion, architecture, art)

### Brand Identity System Checklist

1. Logo System (primary, secondary, icon, wordmark, monogram)
2. Color Palette (primary 1-2, secondary 2-3, neutral 2-3, accent 1)
3. Typography (display, heading, body, accent/mono)
4. Photography Direction (subject, lighting, color treatment, composition)
5. Illustration Style (if applicable)
6. Pattern/Texture Library
7. Iconography (style, weight, corner radius)
8. Voice & Tone
9. Layout Grid (columns, margins, gutters, spacing)
10. Motion Principles (animation style, timing, easing)

### Campaign Architecture — 3-Tier Content System

1. **Hero** — Centerpiece, high production, 1 per campaign
2. **Hub** — Supporting, expands story, 3-5 per campaign
3. **Hygiene** — Daily/weekly presence, ongoing

**Campaign Narrative Arc:** Tease (cryptic) > Reveal (hero drops) > Deep Dive (details) > Social Proof (UGC) > Urgency (final push)

### Universal Design Principles

1. **Hierarchy** — Guide the eye through size, weight, color, position
2. **Contrast** — Opposition creates interest (large/small, light/dark)
3. **Repetition** — Consistency builds cohesion
4. **Alignment** — Intentional order (even breaking alignment should be intentional)
5. **Proximity** — Group related, separate unrelated
6. **White Space** — Active design element, not leftover
7. **Unity** — Every element belongs to the same family

### Kittl AI Platform

**Image Board Formula:**
```
[SUBJECT] + [STYLE] + [COMPOSITION] + [COLOR] + [TEXTURE] + [TYPOGRAPHY] + [BACKGROUND]
```
- "Define the Allowed" — exactly what to see
- "Define the Locked" — what must NOT change
- "vector illustration" / "flat design" for clean graphics
- "photorealistic" / "studio photography" for product shots

**Video Board (Modular):**
```
CAMERA: [movement and framing]
ACTION: [what happens]
AUDIO: [sound design]
TEXT: [overlay text/titles]
```
Design carries subject/context/style; prompt controls camera, movement, and readability.

### Midjourney v6

**Structure:** `[SUBJECT], [ENVIRONMENT], [LIGHTING], [CAMERA/LENS], [STYLE], [MOOD], [QUALITY] --ar [RATIO] --v 6 --s [STYLIZE]`

| Parameter | Range | Effect |
|---|---|---|
| --s (stylize) | 0-1000 | 0=literal, 1000=max artistic |
| --c (chaos) | 0-100 | Variation between outputs |
| --w (weird) | 0-3000 | Unconventional aesthetic |
| --no | text | Negative prompt |

**Stylize ranges:** 0-100 (literal/technical) > 100-300 (balanced/commercial) > 300-600 (artistic/editorial) > 600-1000 (abstract/experimental)

### Flux Pro

**Structure:** `[DETAILED SUBJECT], [PRECISE ENVIRONMENT], [LIGHTING: direction, quality, color temp], [CAMERA: lens, aperture, ISO], [COLOR TEMP in Kelvin], [MOOD]`

**Strengths:** Best photorealism, excellent text rendering, strong prompt adherence, natural skin tones, precise lighting control.

**Best practices:** Specify light direction ("upper left at 45 degrees"), use real camera specs ("Canon EOS R5, 85mm f/1.4, ISO 200"), include materials ("matte cotton," "brushed aluminum"), describe exact environments ("white cyclorama studio with infinity curve").

### Universal Prompting Rules

1. **Specificity > length.** "85mm f/1.4" > "beautiful blurry background"
2. **Front-load the subject.** Most important element first
3. **Real-world references.** "Shot on Arri Alexa" signals quality
4. **Describe light, not mood.** "Warm golden backlight at 45°" > "beautiful lighting"
5. **Think in layers.** Subject > Environment > Light > Camera > Style > Mood
6. **Test cheap first.** Popcorn/Kling before Veo 3.1

## 4. Streetwear Design & Universal Design Mastery

### The Virgil Abloh Method

**3% Rule:** Change 3% of something existing. Genius = knowing WHICH 3%.
- Typography: Helvetica + quotation marks > "DESIGN"
- Silhouettes: Classic Blazer + deconstructed swoosh
- Graphics: Caravaggio painting + industrial zip ties

**Readymade Principle:** Selection IS the creative act (Duchamp approach).

**DJ Philosophy:** Selection (intentional references) > Sequencing (order changes perception) > Mixing (high + low, luxury + street).

**Quotation Mark Technique:** "SHOELACES" on a shoelace = ironic, meta, self-aware. Transform labels into commentary.

### Taste Architecture

**Development:** Volume (100 refs before opinion) > Articulation (name WHY it works) > Curation (collect with POV) > Contrast (study what you hate) > Cross-Pollination (outside design).

**Taste Test:** Clear POV? Can articulate WHY in one sentence? Subtraction test? Specific reference? Would you stop scrolling? Tension or resolution?

### Color Palette Construction (Streetwear)

1. Start with black (foundation)
2. Add one signature color (Supreme=red, Off-White=orange)
3. Include a neutral (white, cream, grey, earth)
4. Optional accent for seasonal variation
5. Test on black garments first

### Mockup Hierarchy (weakest to strongest)

Flat lay solid BG < Flat lay with props < Ghost mannequin < On-model studio < On-model environmental < Editorial/campaign (elite)

## 5. Trailer Storytelling & Narrative Architecture

### Why Trailers Work (3 Cognitive Mechanisms)

1. **Curiosity Gap** — Show enough to question, never enough to answer
2. **Emotional Priming** — Transfer an emotional state resolvable only by full experience
3. **Pattern Interruption** — Break viewer's current mental state

### 4-Act Trailer Structure

| Act | Timing | Purpose | Shots | Emotion | Pacing |
|---|---|---|---|---|---|
| 1: The World | 0-30s | Establish setting, "normal" | Wide, slow | Curiosity | 4-6s cuts |
| 2: Disruption | 30-60s | Conflict, stakes, change | Medium, reactions | Tension | 2-4s, accelerating |
| 3: Escalation | 60-90s | Maximum intensity, peak | Close-ups, rapid montage | Awe, overwhelm | 0.5-2s, rapid-fire |
| 4: Resolve | 90-120s | Final hook, open loop | One powerful image + title | Anticipation | Sudden deceleration |

### 7 Trailer Archetypes

1. **Cold Open** — Most arresting image/line, no context (Inception). Best: mystery, thriller, sci-fi.
2. **Slow Burn** — Atmosphere gradually building (Blade Runner 2049). Best: drama, horror, luxury.
3. **Spectacle** — Biggest visual moments first (Avatar). Best: action, product launches.
4. **Character Study** — One character's journey (Joker). Best: drama, personal brand.
5. **Mystery Box** — Fragments that don't connect, irresistible puzzle (The Matrix). Best: teasers.
6. **Emotional Gut Punch** — Feel before understand (Up montage). Best: cause marketing, emotional brands.
7. **Hype Machine** — Pure energy, rapid cuts (Fast & Furious). Best: sports, streetwear drops.

### 10 Signature Trailer Sound Elements

1. **Braaam** — Deep sustained brass/synth (Inception)
2. **Riser** — Ascending pitch before drop
3. **Hit** — Single percussive impact at transitions
4. **Whoosh** — Transitional sweep between scenes
5. **Silence** — Sudden absence (most powerful tool)
6. **Heartbeat** — Rhythmic pulse, primal tension
7. **Vocal Chop** — Fragmented voice as rhythm
8. **Reverse** — Sound backward, creates unease
9. **Stinger** — Post-title surprise
10. **Needle Drop** — Recognizable song recontextualizing footage

### Applying Trailer Logic to Content

**Social (Short-Form):** Cold open hook (0-1s) > Context (1-3s) > "Wait, what?" (3-5s) > Value delivery (5-12s) > Open loop/CTA (final 2-3s)

**Brand Campaigns:** World (brand universe) > Disruption (problem solved) > Escalation (product in action) > Resolve (tagline + CTA)

**Product Launches:** Teaser (cryptic hints) > Full Reveal (hero video) > TV Spots (specific features) > BTS (sustained)

### Emotional Frequency Mapping

| Emotion | Visual | Sound | Pacing |
|---|---|---|---|
| Awe | Wide, slow-mo, vast | Orchestral swell, silence | Slow, deliberate |
| Tension | Close-ups, dutch angles | Riser, heartbeat | Accelerating |
| Joy | Bright, warm, movement | Upbeat, laughter | Quick, bouncy |
| Dread | Darkness, slow zoom | Low drone, silence | Painfully slow |
| Excitement | Fast cuts, saturated | Driving beat, bass | Rapid-fire |
| Nostalgia | Warm grade, soft focus | Familiar melody, vinyl | Measured, gentle |
| Power | Low angle, symmetry | Braaam, percussion | Commanding |

## 6. Node Workflows & Production Pipelines

### Kittl Flows (2026)

Core pattern: **Design > AI Image Board > Mockup > AI Video Board > Export**

- AI Image Boards and Video Boards are interconnected nodes on infinite canvas
- Each board can use a different model (Nano Banana, Flux Pro, Seedream 4)
- Output of one feeds into next
- Strict one-line prompts at each node for precision
- Key insight: Flows turns one starting point into multiple variations in seconds

**Available video models:** Veo 3.1 (highest quality, audio), Veo 3.1 Fast, King 2.5 Turbo Pro, PixVerse v5, Seedance 1.5 Pro, Grok Imagine Video, Kling Video 3.0

**Video prompt structure:** CAMERA / ACTION / AUDIO / TEXT blocks. Design carries subject+context+style; prompt controls camera behavior and motion.

### Higgsfield Cinema Studio 3.0 Pipeline

**Full sequence:** Sketch-to-Video > Reference World Building (9 images) > Core Generation > Preset + Camera Direction > Sora 2 Enhancer > Higgsfield Upscale > SoulID > Sora 2 Trends > Photodump Studio

**Genre presets** (General, Action, Horror, Comedy, Noir, Drama, Epic) influence pacing, motion energy, lighting, and camera logic.

**Speed Ramp Presets:** Linear, Auto, Flash In, Flash Out, Slow-mo, Bullet Time, Impact, Ramp Up

### Universal Pipeline Principles

1. Every node = one task done well
2. Chain: Concept > Generation > Refinement > Output
3. Reference images + style presets for consistency
4. Iterate at each node BEFORE passing to next
5. Save successful workflows as templates
6. Keep prompts specific and minimal per node
7. Plan distribution format BEFORE starting pipeline
