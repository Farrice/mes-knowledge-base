# JIMMY CONOVER INSTAGRAM MASTERY (v2)

**Core Philosophy:** Instagram is an open house, not a broadcast channel. Content manufactures hand-raisers; the DM system converts them. Identity first: "I'm a content creator who happens to sell [service]." Nobody relates to vague — people relate to specific. Do epic, document it, reach out. Three-headed monster: attention / DM strategy / consult strategy — every request serves one.

## Trigger

Any Instagram growth, content, or lead-conversion request for real estate or a local/relationship business. Route: "what do I post" → 1-2; listing → 3; lead magnet → 4; "comments but no leads" → 5; live DM thread → 6; push an asset → 7; "who has attention in my market" → 8; "audit my account" → 9; "make AI sound like me" → 10; "give me hook variants" → 11; automation/email → 12; giveaway → 13; client wins or saturated trend → 14. For Jen's LA business, stack with jen-shortform-carousel-engine per the JEN STACK section.

## Steps

**Always:** produce the finished deliverable, never instructions. Specificity doctrine: replace every vague word with a named, lived detail; if missing, ask for the 3-5 that matter. Every deliverable ends with its conversion link (lever + follow-up DM).

**1. Three-Pillar Content Engine** — LOCAL / CORE OFFER / CONNECTION pillars, classified by CTA not topic; formats short (1 clip + text hook) / medium (multi-clip B-roll, currently strongest) / long (talking, 1-2×/month max). 30-day calendar: per post — hook, shot list, format, CTA/lever, caption directive. Monthly: contrarian yin-yang post per pillar; repost winner (flip camera, 5% zoom, new hook). Handle uses "official"/"real", never "realestate".

**2. Connection Content Producer** — Mine the story inventory into 5 finished reels: hook + shots + 2,000-2,200-char caption ending in guide CTA. Include one lifestyle-hype reel (fun clips + nostalgic song + tribal-memory hook) and one pain-point list ("5 things we stopped worrying about since leaving [X]").

**3. Listing Multiplier** — One visit → 10+ videos via four capture types: straight tour, POV living, feature isolations, neighborhood context. Walking-order shot list (<1 hr), per-video hook selling the life not sqft, comment-word CTA, 2-3 week posting order. First-timers start with 3 (overwhelm kills action). UGC beats cinematic. No cringe clickbait.

**4. Hyperlocal Guide Builder** — Lead-magnet law: solve a small problem that INTRODUCES a bigger problem you solve. Only area/suburb and new-build guides qualify. Structure: intro (reader's fear + your arrival story) → one lean page per suburb (median price, key data points chosen by what THIS audience self-locates on, cited school rating, "who this fits" verdict, one opinion line) → next steps + testimonials. Ship with caption plug, story plug, commenter DM. The comment is the hand-raise; the guide is the pretext — send the DM whether or not they download.

**5. Five-Lever DM Operating System** — Levers: guide commenter, listing commenter, new follower, story poll answerer, inbound DM — lead OPPORTUNITIES, not leads. Manual, name-first, this-or-that openers ("Hey [Name], thanks for the follow — here for the content or thinking about moving to [Area]?"). Daily: same-day outreach → active convos → exactly ONE follow-up to ghosts, then move on. 5-10 followers/day = 5-10 min/day; work the 20% who reply. Output the day's queue: name, lever, exact message, stage.

**6. Connect→Qualify→Convert Executor** — Diagnose stage; produce the exact next message (short, one question). Qualify order: current location → its pain → area familiarity → dream → timeline → budget. Hunt the GAP and insert yourself in it. Convert: summarize back → "Here's what we typically do next — a quick call so we're only showing you homes in areas you actually want." Close: "Do you think that would be helpful?"

**7. FOMO Story Broadcast** — Create-mode: slide 1 = one accent word ("read"); slide 2 = concrete promise + real proof (round, never invent) + exclusivity ("not posting it anywhere else") + urgency + one DM keyword. 3 variants (proof/FOMO/urgency-first), reply script feeding capability 6, 48h "lots of new followers lately" flex story. Benchmark: 500 DMs from one story.

**8. Local Attention Arbitrage** — Map the 5-10 accounts holding local attention (followers, format, cadence, monetization); find proven attention formats no agent runs (the empty square); produce the claim plan (adopt 3 formats + conversion layer they lack) and collab targets. Origin: "if she just talked about houses she'd get attention — she already has the audience."

**9. Sorted-Account Audit** — Sort top posts by views; table: hook | visual hook | pillar | CTA/lever. Extract the winning pattern, pillar imbalance, CTA leakage; prescribe: repost which winner, feed which pillar, retrofit which CTA. Diagnose which monster head is missing.

**10. Story Context File Builder** — Run the structured story interview (origins, every move and why, season of life, near-misses, hates about where clients come from, hyper-specific loves, generational touchstones). Compile the living context file of named details tagged by pillar — required input to 1-2. The moat is the context file, not the model.

**11. Hook Rewording Engine** — All hooks are one framework reworded. Identify the frame (hidden-cost / insider / delayed-realization / contrarian-warning); generate 10 rewordings across families ("Nobody tells you…", "You don't find out until…", "POV: you just…", "5 things we stopped…", "If you know, you know"), each specificity-checked, tagged pillar + format, with visual-hook pairing note.

**12. Automation Split + Email Engine** — Automate the fulfillment (ManyChat delivers the asset, transactional), humanize the conversation (human sends the name-first DM same day). Never let the bot ask relationship questions. Weekly one-strategy email: specific-promise subject, 150-300 words, one tactic, DM-keyword CTA; each week's open rate is next broadcast's proof line.

**13. Watch-to-End Audit Giveaway** — End-of-content gate: "If you're still here, comment [WORD] — I'll personally reach out" + a personal-service reward (an audit = a sales conversation in disguise). Deliver the outreach DM and the audit-to-offer bridge ending in the permission close.

**14. Win Flywheel + Anti-Trend Positioning** — Post client wins (their before → the move → the number, tagged) 1-2×/week: proof, retention, and belief network in one. Anti-trend: when a format saturates ("everyone's yapping"), its opposite differentiates — track the niche's current herd format and deliberately hold the visual opposite. Micro-pattern: sequential text-lead storytelling — each overlay leads into the next clip.
