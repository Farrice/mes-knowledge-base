# Creative Strategist Launcher

## Purpose
Take someone from zero to job-ready as a paid creative strategist in 30 days. Covers role clarity, skill gap assessment, positioning, and launch sequence.

## When to Use
- When transitioning from copywriting, media buying, or marketing to creative strategy
- When starting from scratch in the DTC advertising space
- When someone asks "how do I become a creative strategist?"

## Step 1: Role Clarity — Paid vs Organic

### Completion Target
User can clearly define the paid creative strategist role and differentiate it from organic creative strategy.

### Process

**Organic Creative Strategist** (NOT this workflow):
- Manages IG, TikTok, YouTube content
- Focuses on branding, positioning, entertainment, attention
- Channel: organic social

**Paid Creative Strategist** (THIS workflow):
- Writes ads for DTC ecom brands and info/coaching brands
- Focused on performance — belief shifting that gets people to BUY
- Blends direct response copywriting + cultural attention skills
- Primary client: DTC Shopify brands, anything not sending you to Amazon
- "Takes raw attention and alchemizes it into belief shifting that gets people to buy"

**The key distinction**: Organic = attention mastery. Paid = attention + conversion mastery. "People who do organic really well are amazing at getting attention. Where they start to fall weaker is how do you take that raw attention and convert it into belief shifting."

## Step 2: Skill Assessment & Gap Analysis

### Completion Target
User knows exactly which skills they already have and which gaps to close.

### Process

**Skill Inventory** — Rate yourself 1-10 on each:

| Skill | Description | Minimum for Launch |
|-------|-------------|-------------------|
| Copy Block Fluency | Can you identify Pain, Promise, Proof, Constraints, Curiosity, Conditions? | 6/10 |
| Headline Sensitivity | Can you feel the difference between good and great headlines? | 5/10 |
| Audience Awareness | Can you map Schwartz's 5 awareness levels? | 5/10 |
| DTC Industry Knowledge | Do you know what brands like Rosabella, VS Shred operate? | 4/10 |
| AI Tool Proficiency | Can you direct Claude/ChatGPT to produce ad variations? | 6/10 |
| Direct Response Basics | Do you understand hooks, leads, fascinations, CTAs? | 5/10 |
| Facebook Ad Library Navigation | Can you research competitors' ads? | 4/10 |

**Gap Closure Plan**: For any skill below minimum:
- 6/10+ gap: Buy Copy Blocks training ($27) + complete certification
- 5/10 gap: Watch 5 Luke Iha YouTube videos on the topic + practice
- 4/10 gap: Spend 2 hours researching + browsing Ad Library

## Step 3: Positioning Statement

### Completion Target
User has a clear one-line positioning statement for LinkedIn and Upwork.

### Template
"I help [specific type of DTC brand] get [specific outcome] through [your unique angle] — specifically through [ad types you specialize in]."

### Examples
- "I help supplement DTC brands scale ad spend profitably through AI-orchestrated ad creative — specifically static ads and advertorials."
- "I help info/coaching brands convert cold traffic through mechanism-driven VSL leads and proof-stacked ads."
- "I help DTC ecom brands test 3x more creative variations using AI production + human judgment curation."

### Rules
1. Name the client type (not "businesses" — which DTC brands?)
2. Name the outcome (not "better ads" — what business result?)
3. Name your edge (not "creative strategy" — what specifically?)
4. Make it sound like you've done this before (even if you're starting)

## Step 4: The 30-Day Launch Sequence

### Completion Target
User has a day-by-day action plan for their first month.

### Week 1: Foundation (Days 1-7)
- **Day 1-2**: Complete Proof Ladder rungs 1-3 (resume, samples, certifications)
- **Day 3-4**: Set up LinkedIn profile with creative strategist positioning
- **Day 5**: Set up Upwork profile with DTC-focused portfolio
- **Day 6-7**: Begin testimonial collection from any past work (even non-CS work)

### Week 2: Volume (Days 8-14)
- **Daily**: 5-10 outreach actions (Upwork proposals + LinkedIn connections)
- **Ongoing**: Continue testimonial follow-ups (bump 2-3 times)
- **Build**: Create 2-3 spec ads for recognizable brands using AI tools
- **Study**: Break down 3 winning ads daily from Facebook Ad Library

### Week 3: Proof Acceleration (Days 15-21)
- **Daily**: Maintain 5-10 outreach volume
- **Focus**: Land first client — even free or deeply discounted
- **Build**: If no client yet, approach an agency for overflow work
- **Create**: First "How I" case study using spec work or pro-bono results

### Week 4: Momentum (Days 22-30)
- **Daily**: Maintain outreach + track conversion rates
- **Optimize**: Review what's working in outreach — double down
- **Document**: Get testimonial from first client immediately
- **Plan**: Map next 60 days based on which proof rungs are still incomplete
