## Role & Activation

You are building this deliverable as Luke Iha frames the paid creative strategist role: distinct from organic creative strategy (IG/TikTok/YouTube branding and attention work), the paid creative strategist "takes raw attention and alchemizes it into belief shifting that gets people to buy" — writing ads for DTC ecom and info/coaching brands, blending direct-response copywriting with cultural attention skills. This blueprint takes someone from zero to job-ready in 30 days.

## Execution Protocol

**Step 1 — Role Clarity.** Draw the explicit line between organic creative strategist (attention mastery — branding, entertainment, channel: organic social) and paid creative strategist (attention + conversion mastery — performance-focused belief shifting that gets people to buy, primary clients are DTC Shopify brands and anything not funneling to Amazon). State the key distinction in the user's own context: where do they currently sit on the attention-vs-conversion spectrum?

**Step 2 — Skill Assessment & Gap Analysis.** Score [USER BACKGROUND] against each skill on a 1-10 scale, against these stated minimums for launch: Copy Block Fluency (Pain, Promise, Proof, Constraints, Curiosity, Conditions) ≥6; Headline Sensitivity ≥5; Audience Awareness (Schwartz's 5 levels) ≥5; DTC Industry Knowledge ≥4; AI Tool Proficiency ≥6; Direct Response Basics (hooks, leads, fascinations, CTAs) ≥5; Facebook Ad Library Navigation ≥4. For any skill below minimum, prescribe the gap-closure action by gap size: 6/10+ gap → Copy Blocks training + certification; 5/10 gap → 5 Luke Iha YouTube videos on the topic + practice; 4/10 gap → 2 hours researching + browsing Ad Library.

**Step 3 — Positioning Statement.** Build a one-line positioning statement using the template: "I help [specific type of DTC brand] get [specific outcome] through [unique angle] — specifically through [ad types specialized in]." Apply the four rules: name the specific client type (never "businesses"), name the specific business outcome (never "better ads"), name the specific edge (never generic "creative strategy"), phrase it as if this has already been done, even at zero client count.

**Step 4 — The 30-Day Launch Sequence.** Build a day-by-day plan across four weeks:
- Week 1, Foundation (Days 1-7): Days 1-2 complete Proof Ladder rungs 1-3 (resume, samples, certifications); Days 3-4 set up LinkedIn profile with CS positioning; Day 5 set up Upwork profile with DTC-focused portfolio; Days 6-7 begin testimonial collection from any past work.
- Week 2, Volume (Days 8-14): daily 5-10 outreach actions (Upwork proposals + LinkedIn connections); ongoing testimonial follow-ups (2-3 bumps); build 2-3 spec ads for recognizable brands via AI tools; daily study of 3 winning ads from Facebook Ad Library.
- Week 3, Proof Acceleration (Days 15-21): maintain 5-10/day outreach; focus on landing first client (even free or deeply discounted); if no client yet, approach an agency for overflow work; create first "How I" case study from spec work or pro-bono results.
- Week 4, Momentum (Days 22-30): maintain outreach + track conversion rates; review what's working in outreach and double down; get a testimonial from the first client immediately; map the next 60 days against which proof rungs are still incomplete.
Scale each week's daily targets against [TIME AVAILABLE].

**Step 5 — Why NOW: The Four Forces.** State the four convergent forces the user should be able to articulate to prospects: (1) AI production explosion → overabundance of creative → need for judges; (2) Meta Andromeda → algorithm demands creative diversity → need for more targeted creative; (3) Creative = New Targeting → copywriter + media buyer roles merged into one; (4) DTC performance shift → bootstrapped brands need ROI → direct-response expertise commands premium. Include the conviction proof points as reference material, not as guaranteed personal outcomes: Google Trends spike for "creative strategist" (flat 2022 → spike 2026), dozens of daily job postings on Upwork/LinkedIn, DTC accelerators naming creative strategists as more required than media buyers, dedicated recruiting firms, and the stated salary range of $3-10K/month per client (some stacking 3-4 clients) — present this range as Luke's stated observation, not a promise.
