# heyDominik Instagram Growth OS

## The decision this system owns

Diagnose an Instagram revenue leak backwards, then repair it forwards.

- **Inspection order:** Offer clarity → Attraction evidence → Profile conversion → Trust transfer → Offer visibility.
- **Repair order:** Offer → Trust → Profile → Attraction.
- **One job per layer:** Offer creates buying desire; Trust reduces warranted skepticism; Profile creates relevant binge behavior; Attraction reaches the right non-followers.
- **Algorithm translation:** algorithm work is audience-match work. Never recommend reach divorced from the intended buyer.

## Start here

Run `workflows/00-instagram-growth-os.md`. It creates an evidence packet, invokes Compliance Guard when needed, runs the diagnostic, and loads only the next component required by the leak.

Canonical machine-readable definitions: `references/instagram-growth-os.skills.json`.

The component numbers preserve the user's requested blueprint. The conductor does not execute them numerically; it activates repairs in dependency order: Offer → Trust → Profile → Attraction, with Compliance as a transversal hold and Monetization as the offer-visibility handoff.

## Execution modes

- `FULL`: run the complete evidence-led system.
- `AUDIT`: run intake, Compliance Guard, Profile Auditor, and Funnel Diagnostician; stop with the first broken layer and evidence gaps.
- `COMPONENT`: run one numbered skill when its required upstream artifact already exists.
- `MONITOR`: ingest a new Insights window and compare against the declared baseline and target.

## Access states

Every component reports one of:

- `LIVE`: an authorized connector or local tool returned a receipt.
- `PROVIDED_DATA`: the user supplied exports, screenshots, URLs, or files.
- `BLOCKED`: evidence or permission required for the requested action is missing.

Never convert `BLOCKED` into a simulated result.

## Hard truth boundaries

1. No native Instagram Insights access is assumed.
2. No public/private scraping is claimed without an authorized connector receipt and platform-compliant method.
3. No "shadowban" diagnosis from view count alone.
4. No voice clone or face synthesis without explicit consent and rights.
5. No external page, ManyChat flow, DM, post, or publication without approval.
6. No medical, financial, legal, housing, or regulated-goods copy is cleared solely by this general guard.
7. No view, follower, lead, sale, or `$20k+` result is promised.
