# Genius Patterns — heyDominik Instagram Growth OS

## 1. Reverse-funnel debugging

Start with whether the offer is coherent, then read downstream telemetry. The visible symptom is not automatically the first repair.

## 2. One layer, one job

- Offer: create desire in the right buyer.
- Trust: reduce warranted skepticism.
- Profile: create relevant binge behavior.
- Attraction: reach the right non-followers.

## 3. Inspection/repair asymmetry

Inspect `Offer → Attraction → Profile → Trust → offer visibility`; repair `Offer → Trust → Profile → Attraction`.

## 4. Algorithm equals audience

Translate algorithm language into audience-match decisions. A large wrong audience is a failed Attraction layer.

## 5. Evidence handoffs

Use non-follower share, profile visits, follows, DMs, link clicks, calls, sales, and collected revenue as a chain of handoffs, with visible denominators.

## 6. Cold-profile scan

Test whether a new visitor can identify buyer, outcome, proof, binge path, and one next action within two to five seconds.

## 7. Embodied trust

Trust needs attributable voice, opinion, demonstration, and bounded proof. Face time without judgment is not enough; silent B-roll is not automatically a failure.

## 8. Clarity-curiosity hook

Use the first 0.5 seconds for visual orientation and the next three seconds for a specific open loop that the body closes.

## 9. Context before face

Lead with B-roll when it makes the subject legible faster, then use the face where identity, conviction, or proof adds value.

## 10. Beginner repetitions

Quantity creates learning throughput only when tests are controlled, sustainable, and reviewed. Volume is not evidence of quality.

## 11. Native trust repurposing

Reform owned source material with voiceover, face, high-contrast selective captions, and separate Trial/feed versions; remove watermarks.

## 12. One-link economics

Carry one promise to one destination and measure the resulting event. Use calculators only when inputs, math, and claims can be audited.
