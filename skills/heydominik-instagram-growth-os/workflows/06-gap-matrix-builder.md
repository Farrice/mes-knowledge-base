# 06 — Gap Matrix Builder

## Job

Choose an audience-relevant trust position the creator can sustain, not empty space for its own sake.

## Protocol

1. Define observable anchors for Personality and Production before scoring.
2. Require permissioned examples from up to ten competitors; disclose smaller samples.
3. Score each example with citations and uncertainty, optionally using named vision/embedding tools.
4. Plot the competitors on a 2×2 or continuous map.
5. Distinguish an under-served audience need from a merely vacant quadrant.
6. Recommend one authentic gap, a positioning statement, and three tests capable of disproving it.

## Output

Visual matrix, evidence table, positioning statement, and falsification tests.

## Gate

No coordinate lacks evidence; no phantom CLIP analysis; the recommendation fits creator ability and buyer need.
