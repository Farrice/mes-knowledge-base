## Role & Activation

The Multi-Page Option: extending a single design-philosophy piece into a small sequence — treated,
in the skill's own framing, as a coffee-table book waiting to be filled, not a batch of repeated
posters.

## Input Required

- `[DESIGN PHILOSOPHY .MD]` — the philosophy governing the whole set
- `[FIRST / ORIGINAL PAGE]` — if a page already exists, the foundation the rest builds from
- `[REQUESTED PAGE COUNT]`
- `[OUTPUT FORMAT]` — bundled into a single .pdf, or delivered as multiple numbered .png files

## Execution Protocol

1. **Reframe the mental model.** Treat the first page as just one page in a whole coffee-table book
   waiting to be filled — not a finished, singular artifact that additional pages merely echo.
2. **Create additional pages along the same design-philosophy lines, but distinctly different from
   one another.** Same worldview, different compositions — never a repeat with the palette swapped.
3. **Let the sequence almost tell a story, tastefully.** Treat later pages as unique twists and
   memories of the original — variations that reference or echo page one without duplicating it.
4. **Exercise full creative freedom across the set.** This option is explicitly where the source
   material grants the widest latitude.
5. **Bundle appropriately.** Package all pages into a single .pdf, or output as multiple .png files,
   per the requested format.
6. **Every page still inherits the full Canvas Expression protocol.** Museum-quality bar, the
   boundary/margin non-negotiables, fonts sourced from `./canvas-fonts`, the subtle-reference
   embedding, and the ~90/10 visual-to-text ratio all apply per page — this deliverable extends
   canvas expression, it does not relax its rules.

## Output Contract

A bundled `.pdf` (multi-page) or a set of numbered `.png` files, `[N]` pages total, all sharing one
design philosophy, each page visually distinct from every other, together suggesting a loose narrative
arc. Every page meets the same craftsmanship bar as a standalone single-page piece — no page is a
lesser or filler page.

## Output Skeleton

```
[MULTI-PAGE SET: <movement name> — <N> pages]

Page 1: [foundation page — composition summary]
Page 2: [distinct twist — what changes from page 1, what echoes it]
Page 3: [distinct twist — what changes, what echoes prior pages]
...
Page N: [closing page — how the sequence resolves or lands]

Narrative thread across pages: [the loose story the sequence tells]
Bundling: [single .pdf | numbered .png files]
```

## Quality Gate

- Does every page share one design philosophy while being visually distinct from every other page
  (not a repeat with a color or crop changed)?
- Is there a loose narrative or progression across the sequence, rather than an arbitrary page order?
- Does each individual page still meet the single-page craftsmanship and boundary bar (no overlaps,
  margins held, museum quality)?
- Is the output bundled correctly per the requested format (single multi-page .pdf vs. numbered .png
  set)?

## Creative Latitude

This is the deliverable the source material is most explicit about granting "full creative freedom."
What the twists and echoes between pages are, how literal or abstract the narrative thread reads, and
how far a later page can depart from the first while still belonging to the same movement — all of
this is a taste call. Treat pages 2 through N as genuine new compositions in conversation with page 1,
never as template variations run off the same layout.

## Deploy When

The user asks for more than one page or piece, a series, a book, or multiple pieces "along the same
lines" as an already-established design philosophy and first page.
