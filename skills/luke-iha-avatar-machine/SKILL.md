# Luke Iha: The AI Avatar Machine (Manifold) v1.0

## What This Skill Does

Most ICP work is one-dimensional ("busy moms who want convenience"). This skill plots a market across **10+ orthogonal dimensions on 1–10 spectrums** — Big-Five-for-markets instead of a single adjective — and turns that plot into the single document the rest of your copy system runs on.

It operationalizes Luke Iha + Mario Castelli's **"AI Avatar Machine (Manifold)"** workshop: a teachable, repeatable method that closes the "Great Curtain of Direct Response" — the gap between what elite copywriters *do* (factor enormous nuance) and what they *teach* ("just use intuition"). The thesis: **anything explainable can be explained.**

**Why it matters to the system:** your 11 existing Luke skills (hooks, proof, VSL, mechanisms, copy blocks, vicious hooks, proof ladders, etc.) all *start* at "you already understand your market." None of them build that understanding. This is the missing upstream keystone. Its signature deliverable — the **Avatar Manifold** — is exactly the "in-depth package / creative brief" product for ICP/avatar work.

## The Core Method

| Concept | One line |
|---|---|
| **Multi-Dimensional Plot** | Orthogonal dimensions × 1–10 spectrums; the score's *consequence* is the output |
| **Core Wound** | Every market refracts one fear (annihilation/abandonment/death) through its Ontological Resources |
| **Resonance Hierarchy** | Experiences→Beliefs→Values→Identity; built bottom-up, sold top-down; never clash with Identity in the lead |
| **Epiphany Threshold** | Hooks land in the Goldilocks Zone (7–9): surprising but believable; thesis→antithesis→synthesis |
| **Splitting the Atom / AWE** | Reframe = a distinction inside a bundled assumption; Agree→Wedge→Elaborate |
| **Anti-Hero's Journey** | Substitute the product for the epiphany ("Energetic Changeling"), calibrated to consciousness level |
| **The Manifold** | Run every framework for one market, concatenate → reusable market-intelligence asset |
