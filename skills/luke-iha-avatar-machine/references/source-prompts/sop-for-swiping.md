## How to swipe

Steps:

1. Pick a product/file to swipe  
2. Check if it’s already in the \#\#\#LIST OF SWIPES\#\#\#  
   1. If it already is, add the newly swiped items within that entry  
   2. If it isn’t:  
      1. Create a new product folder in the corresponding product type folder  
      2. Add an entry to the Master List spreadsheet and paste the link to the folder there  
         1. Right-click on the folder \-\> Get link \-\> Change from Restricted to Anyone with link (Viewer) \-\> Copy link  
3. Check if they have a newsletter to sign up to  
   1. If they do, check if we already have an entry in the “Newsletter List” sheet.  
      1. If we do, disregard. Otherwise, create a new entry.  
   2. If they don’t, disregard.  
4. Emails, social ads, display ads, headlines:   
   1. Add to an existing Doc or create one if there isn’t one already.  
   2. When swiping emails, create one Google Doc per type of email   
      1. Clicker Email  
      2. Consumption Sequence (how to use a bought offer)  
      3. Abandon Cart Sequence   
      4. Welcome Email/Sequence  
      5. Launch Sequence (launching/selling a new offer)  
      6. Sale Sequence (Black Friday, Christmas, Valentines, etc)  
      7. Order Confirmation  
      8. Reactivation Sequence  
      9. Affiliate Emails (other lists promoting this offer)  
      10. Reply Emails (short email asking for a reply)  
      11. etc  
5. Advertorials, landers, upsells, downsells, TSLs:   
   1. Create a new Doc for each  
   2. Copy and paste with/without formatting (Ctrl/Cmd+Shift+V)  
   3. Capture the PDF  
   4. Save the PDF in the same folder as the Doc  
   5. Link the PDF to the top of the Doc  
6. VSLs, webinars  
   1. Download the VSL  
   2. Upload on [otter.ai](https://otter.ai/my-notes)  
   3. Download the transcript  
   4. Create a Doc and paste the transcript  
7. Note about TSLs & VSLs:  
   1. Every TSL and VSL should be in the “Data Format” folder  
   2. And if they’re formatted correctly (and not just a rev.com transcript for example), they should also be in the “Script Format” folder, along with the PDF  
   3. If a VSL for a high ticket offer was swiped, add an “x” in the last column “High Ticket VSL”  
8. Add Advertorials/TSL/VSL headlines to a Doc named Headlines  
9. Update any new folder links to the Master List

## Places to check when swiping a whole offer

This list is non-exhaustive:

1. [Facebook ad library](https://www.facebook.com/ads/library/)   
   1. Besides swiping the ads themselves, click on them to be forwarded to the sales pages  
2. Check the offer’s main website  
3. Google “site:example.com” to find subdomains/sales pages/upsells/VSLs  
4. Google “example.com vsl” or “offer name vsl”  
5. Youtube channel and [Vidtao](https://dashboard.vidtao.com/) for unlisted ads  
6. Twitter/Pinterest/Tiktok  
7. Sign up to email newsletter  
8. Go through checkout but don’t buy to get abandon cart emails

## Where to continually find new pieces of copy to swipe

Once we’ve gone through swipe files, top 100 Clickbank, etc, we need to continually find the newest and best performing pieces of copy to swipe. Offers that are trending, new VSLs, etc. Below is a non-exhaustive list of sources for new swipes.

1. Check native ads in the following websites and swipe the whole offer (ad, advertorial, sales letter, etc):  
   1. [https://weather.com/](https://weather.com/)  
   2. [https://www.yahoo.com/](https://www.yahoo.com/)  
   3. [https://www.msn.com/](https://www.msn.com/)  
   4. [https://www.marketwatch.com/](https://www.marketwatch.com/)  
   5. [https://finance.yahoo.com/](https://finance.yahoo.com/)  
2. Once a month, check Clickbank/Digistore24/BuyGoods Top 100 for new offers  
   1. [https://accounts.clickbank.com/marketplace.htm\#/results](https://accounts.clickbank.com/marketplace.htm#/results)  
   2. [https://backoffice.buygoods.com/campaigns](https://backoffice.buygoods.com/campaigns)  
   3. [https://www.digistore24.com/en/home/marketplace](https://www.digistore24.com/en/home/marketplace)  
3. Check incoming email subscriptions for new swipes/offers  
   1. Any entry in the “Email List” that is not yet “Full”  
   2. Swipe the emails and offers linked from the email  
4. Check Vidtao’s website and email newsletter  
   1. [https://vidtao.com/](https://vidtao.com/)  
5. New inputs into To Process [folder](https://drive.google.com/drive/folders/1nsgZHdM4h0vAcsvkCeY1EjhSikeWaDi9) and [spreadsheet](https://docs.google.com/spreadsheets/d/1zVaXdxFRzSufTujTkwjZVQINJvgaK-Iyp3yDSQUsWCw/edit#gid=0)

Videos hosted on Vidalytics {#videos-hosted-on-vidalytics}

[Loom video](https://www.loom.com/share/55ca359e28f144b9aa0dbd3aa84cdb08)

Steps:

1. Inspect (Ctrl/Cmd+Shift+c)  
2. Sources  
3. Refresh page (F5)  
4. fast/quick.vidalytics.com \-\> embeds \-\> loader.min.js  
5. Right click and open file in new tab  
6. Change URL ending from /loader.min.js to /player-dash-mse.min.js  
7. Search for “mp4” and grab the very last link, at the bottom of the page.  
8. Paste in a new tab  
9. Download

**Note**: If you get the error “Error 503 Response object too large” when opening in a new tab, this is an alternative way to download it:

[Loom video](https://www.loom.com/share/ab4cb39fa16d43b7ab535bfe86d8a85d)

Steps:

1. Follow the steps above until 7  
2. Instead of grabbing the “.mp4” link, copy the “.m3u8” link  
3. Open [VLC](https://www.videolan.org/vlc/) \-\> Media \-\> Open Network Stream  
4. Paste the “.m3u8” link  
5. Go to Settings, choose download location, file ending (.mp4) and file format (mp4)  
6. Click Start and download

[Link to VLC Windows instructions](https://www.leawo.org/entips/download-m3u8-with-vlc-1398.html)

4. Open in a new tab and download the video

How to copy text from a website when you can’t click on it or select the text {#how-to-copy-text-from-a-website-when-you-can’t-click-on-it-or-select-the-text}

[Loom video](https://www.loom.com/share/d00e5cd0293c4acb9d88df86ebfc544a)

Steps:

1. Ctrl/Cmd+P to print to PDF  
2. Open PDF, select all and copy  
3. Paste in the Doc without formatting (Ctrl/Cmd+Shift+V)  
4. Edit the Doc so it’s readable

If there’s copy in the page it didn’t print to PDF, like FAQs that don’t all open at once, you can get the text through the console window.

1. Open the console  
   1. Through Ctrl/Cmd+Shift+C  
   2. Through View \-\> Developer \-\> Inspect elements/Developer tools  
   3. Through right click on the page \-\> Inspect  
2. Find and open the piece of copy  
3. Copy and paste in the Doc

Signing up to newsletters {#signing-up-to-newsletters}

[Loom video](https://www.loom.com/share/b4a971b4de8044f5b74daae32837b61b)

Steps:

1. Go to the offer’s website and sign up for the newsletter  
   1. Note: Sometimes it’s not out in the open, and it’s necessary to create an account, order something for free, find it on google, or abandon cart  
   2. Don’t use “Renee” as first name when asked, use “Anna”  
2. Create an entry in the Email List sheet  
   1. Note: Company and List Name are often the same  
   2. Update status to “Signed up”  
3. Open Gmail and create a filter once the first email arrived (might arrive in the spam folder)  
   1. Open an email and copy the address starting from the “@”  
   2. Settings  
   3. See all settings  
   4. Filters and Blocked Addresses  
   5. Create a new filter  
   6. Paste the address in the “From” field  
   7. Create filter  
   8. Check these boxes  
      1. Skip the Inbox (Archive it)  
      2. Apply the label:  
         1. “New Label” if necessary  
      3. Also “Apply filter to X matching conversations”.  
      4. Never send to spam  
   9. Create filter  
4. Update the status on the Email List  
   1. Signed up: Subscribed to newsletter  
   2. Filtered: Filter created for automatic labeling and archiving  
   3. Full: \~40 emails have been swiped

Note: The goal is to have the inbox empty, all incoming emails should be automatically labeled and archived
