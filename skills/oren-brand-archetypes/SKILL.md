# Oren — Brand Social Media Archetypes

The strategic selection layer that answers "what should this brand DO on social?" — before team structure, before taste evaluation, before production. Five archetypes (Oracle, Performer, World Builder, Catalyst, Helper), selected through resource-reality audits, each producing a different content ecosystem and funnel mechanic.

This is the FRONT DOOR to all other Oren skill domains. Select archetype first → then route to content-team-architecture, taste-development, repositioning, etc.
