# Power Script Generator

## Pre-Flight Gate

Load `../genius.md`, `../references/bank-code-field-guide.md`, and `../references/bank-deployment-map.md`. Power Scripting is words in a sequence that matters to a particular code.

## Input Required

- Audience or prospect code
- Offer or ask
- Medium: DM, email, pitch, sales call, webinar, video, ad, or presentation
- Desired action
- Proof and constraints

## Execution

1. Select the persuasion order by code: ethos, pathos, logos.
2. Translate the offer into code-specific value language.
3. Write the script in the requested medium.
4. Add alternate openings for primary and secondary code.
5. Include a close and one objection response.

## Output Requirements

- **Code and Sequence**: chosen order and why.
- **Core Script**: ready to use.
- **Alternate Opening**: for secondary code.
- **Proof Inserts**: credibility, emotion, logic blocks.
- **Close**: clear next action.
- **Objection Response**: code-aware response.

## Quality Gate

The script must sound natural in the selected medium. Avoid code jargon in buyer-facing copy unless the buyer has opted into B.A.N.K. language.
