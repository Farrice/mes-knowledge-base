# Forensic Profile from Social and Copy

## Pre-Flight Gate

Load `../genius.md`, `../references/bank-code-field-guide.md`, and `../references/bank-deployment-map.md`. This is forensic coding, so evidence discipline matters more than certainty.

## Input Required

- Social profile text, website copy, bio, emails, posts, or call transcript
- Prospect role and company
- Objective: outreach, sales call, partnership, hiring, content, or funnel

## Execution

1. Mine language for values, proof preferences, pacing, identity cues, and decision signals.
2. Score code evidence across B/A/N/K.
3. Detect possible performative signals that may reflect brand voice rather than buyer values.
4. Produce a forensic profile and outreach guidance.
5. Create a message variant for the top likely code and a fallback for the runner-up code.

## Output Requirements

- **Forensic Code Read**: primary, secondary, confidence.
- **Signal Inventory**: exact source clue summarized in your own words.
- **Counter-Signals**: what could make the diagnosis wrong.
- **Outreach Angle**: one code-specific opening.
- **Message Variant A**: primary-code version.
- **Message Variant B**: runner-up-code version.
- **Confirmation Question**: polite question that reveals code priority.

## Quality Gate

Never treat public brand copy as perfect proof of personal code. Mark all forensic conclusions as provisional.
