# B.A.N.K. Lead Magnet Generator

## Pre-Flight Gate

Load `../genius.md`, `../references/bank-code-field-guide.md`, and `../references/bank-deployment-map.md`. The lead magnet must either attract a code or reveal a code.

## Input Required

- Offer and audience
- Funnel goal
- Channel
- Desired lead data
- Any existing lead magnets or assets

## Execution

1. Decide whether the lead magnet should attract one code, segment all four codes, or diagnose code.
2. Generate lead magnet concepts for B, A, N, and K.
3. Pick the best concept for the campaign goal.
4. Produce the finished outline, title, opt-in promise, landing copy, and follow-up route.
5. Add a code-revealing intake question set when useful.

## Output Requirements

- **Lead Magnet Strategy**: attract, segment, or diagnose.
- **Four Concepts**: one for each code.
- **Winner**: selected concept with rationale.
- **Finished Asset Outline**: sections, prompts, scoring, or checklist.
- **Opt-In Copy**: headline, bullets, CTA.
- **Segmentation Questions**: optional code capture.
- **Follow-Up Routing**: what sequence each code enters.

## Quality Gate

The asset must be valuable even if the prospect never buys. Do not make a disguised sales pitch.
