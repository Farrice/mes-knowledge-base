# Segmented Funnel and Landing Page Generator

## Pre-Flight Gate

Load `../genius.md` and `../references/bank-deployment-map.md`. One offer can have four entry paths; keep the offer constant and adapt the route.

## Input Required

- Offer, audience, price, proof, guarantee, CTA
- Traffic source
- Lead magnet or opt-in
- Known code or target segments

## Execution

1. Map the funnel stages: traffic, opt-in/page, nurture, sales page/call, close, follow-up.
2. Define code-aware page variants for B, A, N, and K.
3. Write landing page sections for the selected primary code or all four if requested.
4. Create redirect/routing logic if code is captured.
5. Add test hypotheses for copy, CTA, and proof.

## Output Requirements

- **Funnel Map**: stages and code routing.
- **Landing Page Copy**: headline, subhead, proof, body, CTA, FAQ.
- **Code Variants**: B/A/N/K angle changes.
- **Proof Requirements**: what each code must see.
- **Routing Rules**: code capture and follow-up.
- **Test Plan**: first 3 tests.

## Quality Gate

Do not create four unrelated offers. Keep the offer stable and translate the decision path.
