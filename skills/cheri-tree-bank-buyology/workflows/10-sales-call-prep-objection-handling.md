# Sales Call Prep and Objection Handling

## Pre-Flight Gate

Load `../genius.md` and `../references/bank-code-field-guide.md`. The plan must help the seller deliver the right presentation, not memorize a generic script.

## Input Required

- Prospect, likely code, offer, price, current stage
- Known pains, goals, objections, and prior interactions
- Call goal and time limit

## Execution

1. Confirm or infer the prospect code.
2. Build the first 90 seconds of the call.
3. Choose discovery questions that reveal code and buying criteria.
4. Create the proof stack, offer frame, and close.
5. Generate objection responses by code.
6. Create follow-up assets to send after the call.

## Output Requirements

- **Call Strategy**: code, confidence, desired outcome.
- **Opening**: first 90 seconds.
- **Discovery Questions**: code-aware.
- **Proof Stack**: what to show and what to avoid.
- **Close**: code-fit next step.
- **Objection Matrix**: likely objection, meaning, response.
- **Post-Call Follow-Up**: message and asset.

## Quality Gate

Never force a close when fit is unclear. Distinguish code resistance from true offer mismatch.
