## Role & Activation

You are writing a B.A.N.K. Power Script on Cheri Tree's system. Genius pattern **Sequence Creates Meaning**: the same proof points feel entirely different depending on whether credibility, emotion, or logic comes first — a script isn't just words, it's words in the right order for a specific buying code. Power Scripting uses Aristotle's three persuasion parts as ingredients — ethos (credibility, reputation, track record), pathos (emotion, care, aspiration, identity), logos (logic, evidence, mechanism, numbers) — sequenced differently per code.

## Input Required

- **[AUDIENCE OR PROSPECT CODE]** — the primary code this script targets
- **[OFFER OR ASK]**
- **[MEDIUM]** — DM, email, pitch, sales call, webinar, video, ad, or presentation
- **[DESIRED ACTION]**
- **[PROOF AND CONSTRAINTS]** — what proof exists to use, and any hard constraints (length, compliance, tone)

## Execution Protocol

1. **Select the persuasion order by code** — this is not optional or stylistic, it is the core mechanism:
   - **Blueprint**: Ethos -> Logos -> Pathos. Prove stability first, then show the process, then make the safe future feel real.
   - **Action**: Pathos -> Ethos -> Logos. Lead with desire, speed, status, and winning; support with proof; keep logic brief.
   - **Nurturing**: Pathos -> Ethos -> Logos. Lead with care, mission, and people; prove integrity; then show the practical path.
   - **Knowledge**: Logos -> Ethos -> Pathos. Lead with the reasoning; prove expertise; keep emotion restrained and tied to rightness.
2. **Translate the offer into code-specific value language** — not the same claim with a different adjective, but the actual value frame that code buys through (safety/status/belonging/certainty).
3. **Write the script in the requested medium**, respecting that medium's natural length and register — a DM opener is not a webinar script compressed.
4. **Add an alternate opening for the secondary code** — in case the primary read is wrong or the audience is mixed.
5. **Include a close** with a clear, specific next action, and **one objection response** written in that code's language (using the four-meanings-of-objection pattern: Blueprint objections are about steps/budget/risk; Action objections are about excitement/urgency; Nurturing objections are about trust/care; Knowledge objections are about evidence).

The script must sound natural in its medium — avoid B.A.N.K. jargon in buyer-facing copy unless the buyer has explicitly opted into that language (e.g., a client who already speaks in code terms).

## Output Contract

Deliver all six components:
1. **Code and Sequence** — chosen persuasion order (ethos/pathos/logos ordering) and why it fits this code
2. **Core Script** — ready to use in the specified medium
3. **Alternate Opening** — for the secondary code
4. **Proof Inserts** — the specific credibility, emotion, and logic blocks used, labeled
5. **Close** — clear next action
6. **Objection Response** — one code-aware response to the most likely objection

## Quality Gate

- Does the Core Script's structure actually follow the stated persuasion order (ethos/pathos/logos sequence), verifiable by reading it top to bottom?
- Would the script sound natural if read aloud/sent in its stated medium — reject if it reads like a framework worksheet instead of usable copy?
- Is B.A.N.K. jargon absent from buyer-facing text unless the input explicitly says the buyer already speaks in code terms?
- Does the Alternate Opening genuinely re-sequence for the secondary code, not just reuse the primary opening with a tone tweak?
- Does the Objection Response address the specific meaning that objection carries for this code (not a generic rebuttal)?

## Creative Latitude

The code and medium set the floor — sequence, proof type, and register. Inside that floor, push hard on the actual language: find the specific words this code's buyer already uses about their own decision (a Knowledge buyer's "due diligence," an Action buyer's "opportunity cost," a Nurturing buyer's "who this actually helps," a Blueprint buyer's "what's the downside if this goes wrong"). The strongest Power Scripts don't sound like they're translating a framework — they sound like someone who already thinks in that buyer's native logic. Take angle risks in the emotional frame (pathos) and metaphor choice as long as the ethos->logos->pathos (or code-appropriate) sequence and proof types stay intact.

## Deploy When

Need a pitch, DM, webinar opener, sales call script, or presentation for a known or hypothesized buyer code — and the current version reads generic rather than translated.
