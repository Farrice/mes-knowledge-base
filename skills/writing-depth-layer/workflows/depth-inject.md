# Depth Inject (Surgical Single-Move)

Some drafts don't need surgery. They need one touch. The spine holds, the scene is there, the function works — and yet a line lands flat where it should land hard, or a conclusion is told where one image would let the reader see it, or a paragraph reads competent but anonymous because no sentence ever snaps it shut. The mistake is to "deepen" the whole thing: a full rewrite on a draft that's already 90% there trades a working piece for a different one and buries the single move that would have closed the gap. This workflow refuses the teardown. It finds the *one* highest-leverage move, applies it and only it, and hands back the before→after of that move with a one-line receipt.

This is the layer's scalpel, not its operating room. It owns exactly one job: a single, invisible, confirmed-deficit move on a near-finished draft. It re-teaches no craft — the move loads its owner skill and applies *their* technique into the prose. It does not re-architect, it does not run the full stack, it does not touch what works. If diagnosis turns up two or more real deficits, this is the wrong workflow — route to `/deepen`. If the user wants a score and no prose change, route to `/depth-audit`. The only thing this file owns is the discipline to do one thing well and stop.

## Pre-Flight
Read these files before executing:
1. `skills/writing-depth-layer/genius.md` (the composition brain — § The 8 Depth Deficits, § The Ordering Law, § The Deepen Loop, § Per-Vertical Dosing, § Anti-Patterns)
2. `skills/writing-depth-layer/references/depth-deficit-taxonomy.md` (the 0/1/2 severity rubric + detection signals — score against this, then isolate the single weakest link)
3. `skills/writing-depth-layer/references/routing-map.md` (the deficit → owner table; the REAL skill paths and commands — never reference a path not in this map)
4. `skills/writing-depth-layer/references/vertical-dosing.md` (the PRESERVE column for the confirmed vertical — the one function the inject is forbidden to break)
5. Then, and ONLY for the single confirmed deficit, that one owner's `genius.md` + the single named command from the routing map. One owner, one command — never the roster. An inject loads less than any other workflow in the layer.

> **🔒 Pre-Flight Gate**: Before touching the prose, run the **Decision Framework** in `genius.md § Decision Framework` — all five questions, with question 2 (scope) as the hard gate. STOP condition: a surgical inject is valid ONLY when the diagnosis returns a draft that is already 90% there — one deficit at 1 (Present), nothing at 2 (Severe). If two or more deficits score 1, or anything scores 2, an inject is the wrong tool: route to `/deepen`. If the user asked for diagnosis only, route to `/depth-audit`. Refining a misdiagnosed draft — or injecting a move a clean dimension didn't ask for — is the one unrecoverable error.

## Input Required
- **The draft** — the near-finished prose, pasted in full. The inject works on what's on the page; it assumes the piece already mostly works.
- **The vertical** — social / copy / marketing / book-long-form / client-personal. This sets the PRESERVE list (the function the single move may not break) and the truth slot, should the move be a truth-slot move. If ambiguous, ask.
- **The function to protect** *(infer if unstated, confirm if risky)* — the one thing this draft must keep doing: stop the scroll, convert, hold authority, carry the spine. One move is small, but a misplaced one can still blunt a hook or bury a CTA.
- **The target move** *(Optional — diagnose if unstated)* — if the user already knows the touch they want (one telling detail, one recognition beat, one hard-truth line, one vivid-verb swap, one rhythm break), confirm it maps to a real deficit, then apply it. If unstated, the DIAGNOSE pass names the single highest-leverage move.
- **The spot** *(Optional)* — the specific line, paragraph, or beat the move should land on. If unstated, the diagnosis names the spot.

## Workflow

The DEEPEN LOOP, run at minimum amplitude: **DIAGNOSE → SELECT + ORDER → APPLY → RECEIPT** — but ORDER collapses (one move has no sequence) and APPLY touches exactly one spot. The whole pass is one move, surgically placed.

### Step 1: DIAGNOSE (confirm it's a one-move draft, then isolate the single move)
Diagnose before treating — even here, even for one touch. Read the draft once for what it's *about*, then score all eight deficits on the 0/1/2 rubric in `references/depth-deficit-taxonomy.md`. The score does two jobs: it confirms this is an inject-shaped draft, and it names the one move.

| Check | What confirms it | What it disqualifies |
|---|---|---|
| **Is it 90% there?** | Exactly one deficit at 1 (Present); everything else at 0. The draft already works — one touch will close the gap. | Two+ deficits at 1, or anything at 2 → STOP. This is a `/deepen` job, not an inject. |
| **What is the one move?** | The single 1-scoring deficit maps to one of the five inject types below. | A deficit at 1 that needs a structural pass (e.g. a real #1 architecture gap) is not an inject — route to `/deepen`. |
| **Where does it land?** | One identifiable spot — a line, a beat, a verb. | A fix that has to touch the whole draft is not surgical → not an inject. |

The five inject types — each is one deficit, one move, one spot:

| Inject type | Deficit it treats | Owner + command (load `genius.md` + this one) | The move, in one line |
|---|---|---|---|
| **One telling detail** | #7 Missing telling detail | Michael Connelly — `skills/michael-connelly-vivid-writing` → `/telling-detail-engine` | Replace one told conclusion with one concrete image the reader concludes from. |
| **One vivid-verb swap** | #7 detail / #2 hollow (line-level) | Eric Roth — `skills/eric-roth-writing-mastery` → `/visual-prose-for-copy` | Swap one flat verb/abstraction for one specific, picturable one. |
| **One rhythm break** | #6 Weak rhythm | Nicolas Cole — `skills/nicolas-cole-sentence-craft` → `/terminal-power-rhythm-engineering` | Insert one short beat or re-end one sentence so the passage snaps shut. |
| **One hard-truth line** | #3 Emotionally unearned | Lamott-Allen → the vertical's `/really-real-*` truth slot | Add or sharpen one earned line that says the true thing plainly — never manufactured. |
| **One recognition beat** | #3 earned emotion / #8 reader trust | Lamott-Allen → vertical `/really-real-*` truth slot (`/really-real-reader-trust` for #8) | Land one "yes, that's me" moment the draft already earned but didn't name. |

Name the single deficit (1-scoring), the inject type, and the spot. If no deficit scores 1 — the draft is already clean — say so and inject nothing. Manufacturing a move on a clean draft is over-deepening.

### Step 2: SELECT + ORDER (one owner, no sequence — set the PRESERVE constraint)
ORDER collapses to nothing here: a single move needs no Ordering-Law sequence. SELECT is exactly one owner. The real work of this step is constraint, not selection.

1. **Confirm the dose ceiling.** This is the lightest dose in the layer regardless of vertical — one move. Even a book/long-form draft, which `/deepen` would treat full-stack, gets exactly one touch here. If the vertical demands more than one move, you are in the wrong workflow.
2. **Load exactly one owner.** From `references/routing-map.md` and the table above, load only the owner for the single confirmed deficit — its `genius.md` + the one named command. Nothing else. An inject that loads two owners has stopped being an inject.
3. **Lock the PRESERVE list.** Open `references/vertical-dosing.md` to the confirmed vertical's row and read the PRESERVE column. One move is small, but it can still break a function: a "better" verb that softens a CTA, a rhythm break that fractures a scannable social shape, a hard-truth line that overclaims on a client piece. The protected function is the hard boundary the single move lives inside.

### Step 3: APPLY (one move, one spot, invisible)
Apply the single move into the one spot, and nothing else. Load the owner's `genius.md` + the named command and use *their* technique — never re-implement it here. The rest of the draft is left exactly as it was; the discipline of this workflow is what it does *not* touch.

- **Touch one spot.** A telling detail replaces one told conclusion. A rhythm break re-ends one sentence. A hard-truth line lands in one place. If the move starts spreading across the draft, stop — it was never an inject.
- **Hold the PRESERVE list as a hard boundary.** If the one move touches the hook, the CTA, the offer, the proof, the position, or the spine, it must *strengthen* that function or it doesn't go in.
- **Call the truth slot — never duplicate it.** A hard-truth line or recognition beat (#3 / #8) runs the vertical's `/really-real-*` pass (`/really-real-social` / `-marketing` / `-book` / `-client`; `/really-real-reader-trust` for trust). Do not re-teach really-real craft inside this workflow.
- **Earn it or skip it.** A hard-truth or recognition move that the draft has not already earned is manufactured sentiment — the layer would never. If the truth isn't on the page already, find the real specific detail that earns it, or leave the line out and inject a different move.
- **Deepen ≠ lengthen.** A single move rarely adds length; a vivid-verb swap or rhythm break often keeps the word count flat or *cuts* it. If the inject grew the draft, check it was a move and not a paragraph.
- **Integrate invisibly.** No expert name, no technique label on the page. The reader feels the touch, never the hand. The expert is named only in the one-line Receipt.

### Step 4: RECEIPT (show the before→after of just the move)
Show the isolated before→after — only the spot that changed, not the whole draft — then the one-line Depth Receipt. This is where, and the only where, the expert and move are named. The before→after is what makes a single move auditable at a glance: the reader sees exactly what changed and why it lands harder.

## Content-Type Adaptations
| Vertical | How this workflow adapts (dose / order / truth slot) |
|---|---|
| **Social** (LinkedIn / X / IG / newsletter short) | The most natural home for an inject — a working post that needs *one* touch. Favor a #6 rhythm break (one short beat that snaps a line shut) or a #7 telling detail swapped for one abstraction. PRESERVE the hook, brevity, scannability, the platform-native shape — a single move must live *inside* the existing shape. Truth slot (recognition beat): `/really-real-social`. Often the move is a cut, not an addition; never let one inject grow a 150-word post. |
| **Copy** (ads / VSL / landing / email / offers) | One move that adds conviction without touching the funnel — a #7 vivid-verb swap on a flat benefit, or one earned proof-detail. PRESERVE the offer logic, CTA, proof, clarity-to-action; the move may not blur the next action. Truth slot (hard-truth line): `/really-real-marketing`. Literary flourish never beats clarity-to-action — if the one move softens the CTA, revert it. |
| **Marketing / Brand** | One move toward humanity — a #7 specific detail that makes the brand sound like a person, or one #3 earned line of belief. PRESERVE the belief/position and the strategic frame; specificity serves belief, not decoration. Truth slot: `/really-real-marketing`. One concrete detail beats one nicer adjective — never manufacture warmth the brand hasn't earned. |
| **Book / long-form / novel** | Exactly one touch even here — this is NOT the full-stack vertical for an inject. Use it for a single beat in an otherwise-set chapter: one telling detail (#7) or one hard-truth line (#3) the scene already earned. Do NOT inject architecture — a real #1 spine gap is a `/deepen` job, never a single move. PRESERVE the spine/theme, narrative continuity. Truth slot: `/really-real-book`. |
| **Client / personal-brand** | The most restrained inject — one move that reads as authority, not ornament. A #7 credible detail or one #8 trust repair (a confusing leap clarified, a throat-clearing line cut). PRESERVE the claim→evidence→so-what architecture, credibility (no overreach), the trusted-advisor restraint. Truth slot: `/really-real-client`; `/really-real-reader-trust` for a #8 move. Never manufacture vulnerability for "relatability." |

## Output Format
```
## INJECT DIAGNOSIS
Vertical: [social / copy / marketing / book-long-form / client-personal]
Function to protect (PRESERVE): [the one thing this draft must keep doing]
One-move check: [confirmed — exactly one deficit at 1, nothing at 2] OR [STOP — route to /deepen or /depth-audit, with reason]
The single move: [inject type] — treats Deficit [#] ([name])
The spot: [the one line / beat / verb the move lands on]

## THE MOVE (before → after)
BEFORE: [only the spot that changes — the single line/beat/verb, verbatim from the draft]
AFTER:  [the same spot after the one move — invisible craft, no labels, the rest of the draft untouched]

DEPTH RECEIPT
- Weakest link found: [the single deficit, scored 1]
- Move applied: [deficit fixed] -> [the one move in plain craft terms] -> [expected reader effect] -> [source principle]
- Dose / vertical fit: [why a single inject, not a deepen, was the right call for this near-finished draft; what was deliberately left untouched]
- Remaining risk: [what still could fail — including any second deficit you chose NOT to treat because it didn't reach the bar]
```

## Quality Gate
> **🛡️ Anti-Pattern Check**: review the output against `genius.md § Anti-Patterns` and `genius.md § Anti-Duplication Contract` before delivering. Flag and fix any violation.
- **Diagnosis confirmed the inject before the move.** All eight scored; the draft is 90% there (one deficit at 1, nothing at 2). If two+ deficits scored 1 or anything scored 2 and you injected anyway, return it — that draft was a `/deepen` job.
- **Exactly one move.** One deficit, one owner, one spot. If the output changed two beats or ran a second owner, it stopped being an inject — rebuild as a single move or route to `/deepen`.
- **Only a confirmed deficit treated.** The move maps to a deficit scored 1. If the draft scored clean and you injected anyway, you over-deepened a working piece — return the original untouched and say so.
- **Ordering Law honored by collapse.** A single move needs no sequence, but it must still be a *line/scene/truth* move on an already-architected draft — never an architecture inject. If the spine was the gap, this was the wrong tool.
- **Function preserved.** The PRESERVE item (hook / CTA / offer / proof / position / spine) is intact or stronger after the one move. If the touch softened the CTA, fractured the social shape, or overclaimed on a client piece, revert it.
- **Deepen, not lengthen.** The move did not balloon the draft. A vivid-verb swap or rhythm break should hold or cut the word count. If a paragraph appeared, it wasn't a single move.
- **No machinery on the page.** No expert name, no technique label, no manufactured trauma or false vulnerability in the prose or the AFTER. The expert appears ONLY in the Depth Receipt. If a reader can feel the technique, integrate harder.
- **Composed, never duplicated.** The move ran through its owner's real command; a hard-truth/recognition move *called* the `/really-real-*` truth slot, it did not re-implement it. If craft got re-taught inside this file, route to the owner.

## Common Pitfalls
- **Inject on a draft that needed a deepen.** Treated one move when the diagnosis actually showed two deficits at 1 or a 2 somewhere, leaving the real problems unaddressed. Recovery: re-read the score — if it isn't 90%-there (one 1, no 2s), stop and route to `/deepen`.
- **Move spread into a rewrite.** "One telling detail" became three, or the rhythm fix rippled through the paragraph. Recovery: revert to the single spot; a move that has to touch the whole draft is by definition not an inject.
- **Manufactured a move on a clean draft.** Nothing scored 1, but a move went in anyway "to deepen." Recovery: a clean dimension is left alone — return the original and report that no inject was warranted.
- **Architecture injected as a single move.** Tried to fix a #1 spine gap with one line. Recovery: architecture is never a single move — route to `/deepen` for the structural pass; this workflow only touches line/scene/truth on a draft whose spine already holds.
- **Function sacrificed for feel.** A "better" verb softened the CTA, or a rhythm break broke the scannable shape. Recovery: hold the PRESERVE column as a hard boundary — any move touching the protected function must strengthen it or be reverted.
- **Manufactured sentiment.** Added a hard-truth line or recognition beat the draft had not earned, chasing "heart." Recovery: depth is earned, never faked — find the real specific detail already on the page that earns the line, or inject a different move and leave the truth alone.
- **Truth slot re-implemented.** Re-taught really-real craft inside this workflow instead of calling the matching `/really-real-*` pass for a #3 or #8 move. Recovery: enforce the Anti-Duplication Contract — compose the truth-slot owner, never duplicate it.
- **Whole-draft dump in the Receipt.** Pasted the full deepened draft instead of just the before→after of the one spot. Recovery: the inject's deliverable is the isolated BEFORE → AFTER plus the one-line Receipt — show only what changed.
