# Depth Line (Writing Depth Layer)

Most depth failures are upstream — no spine, no scene, no earned feeling — and you do not fix those at the line. But there is a real, narrow job that lives only at the sentence: a draft whose architecture is sound and whose scene is concrete can still plod, over-prove, and reach for the 25-cent word where the nickel word would land harder. That is the work this pass owns. `/depth-line` assumes the structure is already right (if it isn't, this is the wrong tool — go back up the Ordering Law) and treats the two bottom-rung deficits that live purely at the line: **#5 Over-explained / bloated** and **#6 Weak rhythm**, plus the line-level half of voice — vivid verbs and word-stream choice.

It does not re-teach craft. The sentence-craft *knowledge* lives in two owners: the expanded technical module `skills/lamott-allen-really-real-writing/references/technical-craft-36-rules.md` (the 25–30% economy dial, the Anglo-Saxon vs. Latinate two-stream model, vivid verbs, read-aloud cadence, mastery-as-invisible-effort) and Nicolas Cole's sentence-craft skill (compression density, terminal power, vocabulary calibration). This pass *consumes* and *orchestrates* those — it reaches for their commands, applies the moves into the prose, and reports them in the Receipt. It never copies their content into this file, and it never reaches above the line: no theme work, no scene-building, no truth pass. If the draft needs those, `/depth-line` is the last stage of the ladder, not the whole climb.

## Input Required
- **The draft** — the prose to tune at the line. Whole or a marked section; the line pass works locally, so a flagged passage is acceptable here (unlike the architecture stages, which need the whole).
- **Confirmation that the structure is sound** — either a prior `/depth-audit` showing Deficits 1/2/7 at 0, or the user's explicit "architecture and scene are fine, just tighten the lines." If neither is given, run the gate-quick check in Step 1 before proceeding.
- **The vertical** — social / copy / marketing / book-long-form / client-personal. Sets the dose and what must be PRESERVED. If ambiguous, ask; the cut depth differs sharply by vertical.
- **The function to PRESERVE** — the one thing the line pass is forbidden to break (the CTA/offer for copy, the scroll-stopping shape for social, the argument/credibility for client, the spine for book).
- *(Optional)* A voice reference — 1–2 samples that sound like the intended author — to ground vivid-verb and word-stream choices to *their* register rather than a generic "tighter."
- *(Optional)* Hard limits — word ceiling, banned words, platform line-break conventions — carried as constraints through the pass.

## Workflow

This is the DEEPEN LOOP narrowed to the line: **DIAGNOSE (lines only) → SELECT+ORDER (within the line tier) → APPLY (into the prose) → RECEIPT.** Architecture and scene are out of scope by definition — this pass refuses to climb above the bottom rung.

### Step 1 — Diagnose the line tier (and gate the structure)
First, confirm the structure is sound enough to justify a line pass. Then score the two line deficits with the shared 0/1/2 rubric from `references/depth-deficit-taxonomy.md`.

| Diagnose action | What good looks like |
|---|---|
| **Gate-check structure** | Quick read for Deficit 1 (nameable spine), 2 (concrete subject/stakes), 7 (rendered image). If any reads ≥1, STOP and route up — do not line-polish a spineless or hollow draft. |
| **Score Deficit 5 (Over-explained)** | Estimate the cuttable percentage: where is a point re-made, a caveat defending an objection no one raised, throat-clearing before the real first line? If ~25–30%+ lifts with no loss, it's a 2. |
| **Score Deficit 6 (Weak rhythm)** | Read it aloud. Do sentence lengths cluster? Does any short sentence ever snap a passage shut? Do key sentences land on a weak terminal word? Stumbling or breathlessness = a 2. |
| **Flag the line-level voice gap** | Even with strong overall voice, the line can leak: Latinate abstractions where the Anglo-Saxon word would hit, laboring verbs ("was walking" vs. "trudged"), the showpiece sentence where the writer's effort still shows. |

Output of Step 1 is a short **line-diagnosis block** (the two scores + the voice-leak note + confirmation the structure passed the gate). If both deficits score 0 and no voice leak fires, say so and stop — there is nothing to deepen at the line, and inventing changes over-deepens.

### Step 2 — Select and order the line moves (within the bottom rung)
Within the line tier the order is fixed: **cut first, then set cadence, then sharpen word-choice.** You compress before you tune rhythm because cutting changes the cadence; you set cadence before swapping words because the terminal word's job depends on where the sentence breaks. Load only the owner for each confirmed move.

| Confirmed deficit / gap | Move (in order) | Owner + REAL command |
|---|---|---|
| **#5 Over-explained / bloated** | **Cut to the 25–30% target.** First pass lifts whole sentences/beats (the second explanation, the defensive caveat, the wind-up). Second pass removes the little words (*just*, *really*, *very*, *actually*, *thing*, *in order to*, *the fact that*). | `skills/nicolas-cole-sentence-craft/genius.md` → `/atomic-compression-density-audit`; `skills/lamott-allen-really-real-writing/references/technical-craft-36-rules.md` → Mechanic 1 (the 25–30% dial). |
| **#6 Weak rhythm** | **Set the cadence.** Vary sentence length; let one short sentence snap each long passage shut; give the load-bearing sentences terminal power (the last word carries the weight). Pass the read-aloud test. | `skills/nicolas-cole-sentence-craft/genius.md` → `/terminal-power-rhythm-engineering`; technical-craft module read-aloud note. |
| **Line-level voice leak** (word-stream / verbs) | **Sharpen word-choice.** Circle the multisyllabic words; swap Latinate abstractions for the Anglo-Saxon word that gets the reader "right into the scene." Replace laboring verbs with vivid ones. Kill the darling sentence where the writer's effort still shows. | `skills/nicolas-cole-sentence-craft/genius.md` → `/audience-calibration-vocabulary-control`; technical-craft module Rule 6 (two-stream model) + Mechanic 3 (effort going invisible). |

### Step 3 — Apply into the prose (read-aloud loop)
Load each selected owner's `genius.md` + module section, then apply the move *into the lines* — preserving the user's meaning and voice. Work the three moves in the Step 2 order. After each pass, **read the changed lines aloud**: the test is not "is it shorter?" but "does the mouth ride it, and is the meaning closer?" If a cut removed meaning, you cut too late — restore, clarify the line, then cut again (silence requires prior clarity). Integrate every move invisibly: no expert name, no rule number, no technique label survives in the prose.

### Step 4 — Receipt
Show the changed lines (before → after, only the lines you touched — this is a surgical pass, not a full rewrite) and end with the Depth Receipt. Experts and rule numbers are named **only** in the Receipt, never in the prose.

## Content-Type Adaptations
| Vertical | How this workflow adapts (dose / order / truth slot) |
|---|---|
| **Social** (LinkedIn / X / IG / newsletter short) | Lightest dose. The line pass here is almost always the CUT (Deficit 5) — the deepest line move on a 150-word post is subtraction, not addition. Preserve the hook line untouched unless it itself is bloated, plus brevity, scannability, and the platform-native line breaks. Never let the cadence pass turn a scannable post into dense paragraphs. No truth slot — `/depth-line` is line-only; if the post needs earned feeling, route to `/depth-social`. |
| **Copy** (ads / VSL / landing / email / offers) | Tune inside the conversion skeleton. Compress and sharpen verbs WITHOUT touching the offer logic, CTA, or proof. Terminal power serves the line that drives the click — give the CTA-adjacent sentences the strong terminal word. Bright line: a leaner, punchier sentence that blurs the next action doesn't ship. No truth slot here; if conviction is missing, that's `/depth-copy`. |
| **Marketing / brand** | Word-choice carries most of the weight: swap category-Latinate ("solutions," "leverage," "optimize") for the concrete Anglo-Saxon word a human would actually say. Cadence makes the brand sound like a person, not a press release. Preserve the positioning/reframe — don't let a prettier sentence dissolve the belief the line is staking. |
| **Book / long-form** | This is the legitimate full-strength line pass — but it runs LAST, after the spine and scene are set elsewhere. Apply the full module: 25–30% economy dial, two-stream verb work, terminal power, read-aloud throughout. Guard the spine: a line edit must never drift the throughline set upstream. Deepening a chapter at the line usually means cutting, not adding. |
| **Client / personal** | Measured. The line pass shows as authority and clarity, never ornament. Compress the over-explaining that proves what a trusted reader already grants (Deficit 5 is the dominant move here); set a calm, confident cadence. Never sharpen a verb into hype the credibility can't carry. Preserve accuracy — no word swap that overstates. |

## Quality Gate
> **🛡️ Anti-Pattern Check**: review the output against `genius.md § Anti-Patterns` and the § Decision Framework before delivering. Flag and fix any violation first.
- **No lengthening-as-deepening.** This is a line pass — confirm it CUT or held even, never bloated. If the treated passage is materially longer, the pass added instead of deepened — re-run the compression move and return.
- **Stayed on the bottom rung.** Confirm the pass treated only Deficits 5 and 6 (plus line-level voice) — it did NOT do theme, scene, or truth work. If a structural change crept in, that's out of scope: revert it and route up the ladder. Line-craft on a draft that needed architecture is the cardinal error.
- **Machinery invisible.** No expert name, no rule number, no technique label survives in the deepened lines. Experts and rules live only in the Receipt. If a reader could feel the technique, integrate harder and return.
- **Function preserved.** The PRESERVE line is intact — the CTA/offer (copy), the hook/shape (social), the argument/credibility (client), the spine (book) still does its job. A punchier sentence that breaks the function does not ship.
- **No manufactured sentiment.** A line pass adds zero feeling the draft hadn't earned — sharpening a verb is not the same as injecting warmth. If a "tuned" line reaches for emotion the structure didn't build, that's truth-slot work this pass doesn't own; strip it and route to the matching `/depth-*`.
- **Ordering Law respected.** This pass is the line/rhythm tier — the lowest rung. It ran only after (or on the assumption of) sound architecture and scene, and within the tier it cut → cadence → word-choice in order. Confirm only confirmed deficits were treated; a deficit scored 0 reads as an explicit no-op, not invented work.
- **Composed, never duplicated.** Every move ran through Cole's real command or the technical-craft module — no sentence-craft knowledge was re-taught locally (Anti-Duplication Contract).

## Common Pitfalls
- **Polished a spineless draft.** You tuned sentences on a piece with no architecture, producing well-crafted nothing. Recovery: enforce the Step 1 gate — if Deficit 1/2/7 scores ≥1, this was the wrong tool; route to `/deepen` or `/depth-stack` and set the spine before any line work.
- **Cut into meaning.** The compression pass removed not bloat but substance, leaving the line thinner instead of closer. Recovery: you cut too late — restore the line, clarify it first, then omit (silence requires prior clarity per Mechanic 1's failure mode); re-read aloud to confirm the survivors feel closer, not thinner.
- **Made fog shorter.** You cut to the 25–30% number on a draft that was vague to begin with, so now it's briefly unclear. Recovery: economy is not a fix for vagueness — clarify the line first, then economize; if the vagueness is structural, route up.
- **Cadence flattened the platform shape.** A rhythm pass turned a scannable social post into dense paragraphs. Recovery: on social, deepen *inside* the existing line-break shape — re-impose the platform's white space and re-cut for the scroll, not the page.
- **Verb sharpened into hype.** On client/marketing copy a vivid-verb swap overstated and dented credibility. Recovery: choose the strong Anglo-Saxon verb that's still *true* — the river guide works hard but never shows off; pull the swap that announces itself and pick the accurate punchier word instead.
- **Receipt skipped or experts named in prose.** You delivered tuned lines with no Depth Receipt, or left a rule number in the prose. Recovery: this is a rewrite-tier workflow — it MUST end with the Depth Receipt, and every expert/rule citation lives there only; scrub the prose and append the block.
