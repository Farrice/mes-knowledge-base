# Depth — Marketing / Brand Media (Writing Depth Layer)

Most brand prose dies the same way: it is *accurate* and *empty*. It describes the company, lists the values, asserts that it cares — and could be pasted onto any competitor without a word changing. The failure is rarely the writing; it is that nothing underneath it is *staked*. There is no belief, no specific thing seen, no reason this brand and not the next one. This workflow's single job is to deepen marketing and brand media until a reader feels a person who believes something — by reframing the choice (Rory Sutherland), grounding the belief in a concrete image (Roth), and earning the warmth instead of asserting it (the truth slot) — without ever dissolving the position or burying the next action.

It is a full-stack orchestrator dosed for one vertical. It does not re-teach reframing, visual prose, or really-real craft. It diagnoses what depth the brand piece is missing, composes the confirmed owners in the ordering law, and hands back a deepened draft plus a change-map. The bright line for this vertical: **specificity serves belief, not decoration.** A prettier adjective that loses the position is a failure, not a flourish.

## Input Required
- **The draft** — the brand narrative, manifesto, campaign copy, about page, positioning statement, or hero/section copy to deepen. Paste it in full.
- **The belief / positioning** — the one thing this brand stakes that a competitor would not say. If the user can't state it, that *is* the diagnosis (no architecture / hollow) — surface it before deepening.
- **The brand voice / coherence constraints** — voice bible, existing brand lines, words it owns, words it forbids, the register it lives in. The deepened draft must read as *the same brand*, deeper — never a new one.
- **The strategic frame** — what the reframe is meant to make obvious (why choose this over the default), so a deepening move strengthens the frame rather than blurring it.
- **The scope asked for** — diagnosis only, a surgical inject (one section/line), or a full rewrite. Never full-rewrite when an inject would do.
- *(Optional)* The medium inside the vertical — manifesto vs. about page vs. campaign headline vs. landing hero — which narrows the PRESERVE list.
- *(Optional)* Any stakes already known — what the brand is fighting, who it is for, the cost of the status quo it is reframing.

## Workflow
Run the **DEEPEN LOOP** (diagnose → select+order → apply → receipt), specialized for marketing/brand. The dose is MEDIUM-HEAVY on humanity + belief; the moves run *inside* the existing position and voice, never replacing them.

1. **DIAGNOSE — score the 8 deficits, name the 1–3 weakest links (this vertical's usual suspects first).** Score the draft against all eight deficits in `genius.md § The 8 Depth Deficits`, but look hardest where brand prose fails: **#2 Hollow / generic** (could-be-any-brand, no image you could photograph), **#3 Emotionally unearned** (manufactured warmth, "we care" asserted not shown), and **#4 No signature voice** (sounds like a category, not a believer). Then check **#1 No architecture** — does the piece have a spine, a belief it is built to deliver, or is it a list of true-and-empty claims? Name the confirmed deficits explicitly. Diagnose before treating; never refine a brand piece on a misdiagnosed draft.

2. **SELECT + ORDER — pick only the owners for confirmed deficits, sequence by the Ordering Law.** Load *only* the routing-map rows for the confirmed set (Load Discipline: one `genius.md` per owner, Tier 2, plus the single named command). Sequence by `genius.md § The Ordering Law`, not by deficit number:
   - **(spine first, if #1)** `skills/noah-hawley-storytelling-mastery` → `/hawley-theme-engine` — establish the belief as a spine the whole piece delivers, before any line work. For a manifesto specifically, `skills/steven-pressfield-narrative-mastery` → `/manifesto-engine` (13) is the available architecture owner.
   - **(belief / reframe — the marketing layer)** `skills/rory-sutherland-marketing` → `/conspiratorial-reframe-engine` — reframe the choice so the brand's position becomes the obvious one, and the reader feels let in on something rather than sold to. This is the move that turns a category description into a stance.
   - **(scene + telling detail, if #2 / #7)** `skills/eric-roth-writing-mastery` → `/visual-prose-for-copy` and `skills/michael-connelly-vivid-writing` → `/telling-detail-engine` — replace the abstract claim with the one concrete image that *proves* the belief is lived, not stated.
   - **(line / rhythm, if #5 / #6)** `skills/nicolas-cole-sentence-craft` → `/atomic-compression-density-audit`, `/terminal-power-rhythm-engineering` — cut what the reader already grants, set the cadence so the belief lands on a strong terminal beat. For brand copy, deepening is often *subtraction*.
   - **(truth + voice, LAST)** the truth slot below + the brand's voice fingerprint — earned warmth and signature voice go last, onto a draft that is already staked, scened, and clean.

3. **APPLY — run each owner's move INTO the prose, invisibly, inside the position and voice.** Load each confirmed owner's `genius.md` + the single named command and apply the move directly into the draft. Preserve the brand's core meaning, position, and voice coherence — the output is *this brand, deeper*, not a new brand. Integrate every move invisibly: no expert names, no technique labels, no "reframe:" scaffolding in the prose. Hold the PRESERVE constraint as hard: every move must *strengthen* the belief / positioning, the specificity that makes it credible, and the strategic frame — or it does not ship, no matter how good the sentence sounds.

4. **TRUTH SLOT — CALL `/really-real-marketing` (do not re-implement it).** As the final earned-emotion pass, **run `/really-real-marketing`** (`skills/lamott-allen-really-real-writing`) on the deepened draft. This is the truth slot for the marketing/brand vertical: it earns the heart and humanity that brand prose usually fakes. Pass it the staked belief and the concrete detail you grounded in Step 3 so the warmth attaches to something real. Do NOT re-teach really-real craft here; orchestrate the pass and take its output back. (Per the Anti-Duplication Contract, this workflow composes the truth slot owner; it never duplicates it.)

5. **RECEIPT — end with the Depth Receipt.** Emit the verbatim Depth Receipt block (Output Format below). Name the experts ONLY here, never in the prose. State which dose you used and why, and the remaining risk — for brand work, usually: does the warmth still attach to a real belief, or did a deepening pass drift it into generic "authentic voice"?

## Quality Gate
> **🛡️ Anti-Pattern Check**: review the output against `genius.md § Anti-Patterns` and `references/vertical-dosing.md` (Marketing / Brand row + Common Pitfalls) by name. Flag and fix any violation before delivering.
- **No lengthening-as-deepening.** Comprehensive = failure. Confirm the deepened piece is more honest/specific/staked, not merely longer — for brand prose, a strong pass often *cuts* (#5). If it grew without earning the growth, rebuild from the cut.
- **No expert name-drops or technique labels in the prose.** Experts and moves live in the Depth Receipt ONLY. If "reframe," "telling detail," or any name appears in the deepened draft, strip it.
- **Function not sacrificed — the belief survived.** The PRESERVE constraint held: the position/positioning is sharper, the specificity stayed credible, the strategic frame got stronger. If a deepening move produced a gorgeous sentence that dissolved the position or blurred a next action, return it — flourish never beats the belief.
- **No manufactured sentiment.** The warmth is earned from a real, specific thing on the page — not confession or false intimacy bolted onto a beliefless brand. If the heart isn't earned, find the real detail that earns it or leave the restraint.
- **Ordering law respected, only confirmed deficits treated.** Architecture → reframe/scene → line/rhythm → truth/voice, in that sequence. Confirm you treated *only* the diagnosed weakest links and did not crowd a clean draft with moves it didn't need.
- **Truth slot CALLED, not re-implemented.** `/really-real-marketing` was actually run as the truth pass; this file did not re-teach really-real craft. If you re-implemented it, you violated the Anti-Duplication Contract — route to the real command and re-run.

## Common Pitfalls
- **Generic "authentic brand voice" that believes nothing.** The deepened draft sounds warmer but is still paste-able onto any competitor. Recovery: you treated #3 (warmth) before securing #1/#2 (a staked belief, made concrete). Re-sequence — establish and ground the belief first, then earn the warmth onto it.
- **The reframe lost to a nicer adjective.** A line-craft or truth pass smoothed the prose and quietly dissolved the Rory reframe that made the choice obvious. Recovery: hold the strategic frame as a PRESERVE constraint; restore the reframe and re-run the line pass *around* it, not over it.
- **Manufactured vulnerability for "relatability."** You injected confession or false intimacy a brand piece had not earned, chasing heart. Recovery: depth is earned, never faked — find the real specific detail that earns the feeling, or leave the restraint intact. (This is the #1 fail mode the marketing/client dose exists to prevent.)
- **Wrong vertical, full stack run.** You ran the marketing stack on a converting landing page and buried the CTA, or on a 150-word brand post and drowned it. Recovery: re-confirm the vertical and the function to protect — route to `/depth-copy` (conversion) or `/depth-social` (post) when those are the real verticals.
- **Truth slot re-implemented instead of called.** You re-taught really-real craft inline instead of running `/really-real-marketing`. Recovery: delete the inline craft, invoke the real command, take its output back into the draft.
- **Over-scoped the ask.** The user asked for a diagnosis and got a full rewrite. Recovery: match the scope — diagnosis-only returns the scored deficits and the route, and stops before any prose.
