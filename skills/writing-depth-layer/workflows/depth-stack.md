# Depth Stack

`/deepen` fixes the one or two places a draft is hollow and gets out of the way. That is the right move for most work. But some pieces cannot afford "good enough" — a keystone essay, a launch manifesto, a chapter the book turns on, the page a client's reputation rides. For those, you do not want a surgical inject. You want the whole ladder climbed deliberately, in order, with the machinery visible to *you* (never to the reader) so you can see exactly what each layer of depth bought.

That is this workflow. `/depth-stack` runs the full Ordering Law as four named stages — architecture first, truth and voice last — and after each stage it shows the delta: what changed, why, and what the change was supposed to do to the reader. It is the heavy instrument. It still obeys every law of the layer: it diagnoses before it treats, it loads only the owners the draft actually needs, it composes the craft roster instead of re-teaching it, and it can still decide a stage is a no-op when the draft already holds. The reward for the extra weight is a piece you can stand behind line by line, plus a consolidated receipt that proves the depth was earned, not asserted.

If a single surgical fix would do, this is the wrong tool; route to `/deepen`. Over-scoping into the full stack on a draft that needed one cut is an anti-pattern, not thoroughness.

## Input Required
- **The draft** — the full piece to deepen, in the form it will ship. Whole, not an excerpt; the stack works on architecture, which only the whole reveals.
- **The vertical** — social / copy / marketing / book-long-form / client-personal. This sets the dose and the truth slot. If ambiguous, ask; a wrong vertical wrongs every stage.
- **The stakes / why this one is exceptional** — what this piece must do that justifies the heavy pass (launch hinge, reputation, the chapter the book turns on). Names the bar each stage is held to.
- **The function to PRESERVE** — the one thing the deepening is forbidden to break (the CTA and offer logic for copy; the scroll-stopping shape for social; the argument/credibility for client; the spine once set for book). The hard constraint every stage bows to.
- *(Optional)* A voice reference — 2–3 samples that unmistakably sound like the intended author/brand — to ground Stage 4's voice pass. Without it, voice is set conservatively to "recognizably human, not AI."
- *(Optional)* Hard limits — word ceiling, banned claims, platform constraints — carried as constraints through every stage.

## Workflow

This is the DEEPEN LOOP run at full depth: **DIAGNOSE → SELECT+ORDER → APPLY (as four staged passes) → consolidated RECEIPT.** The difference from `/deepen` is that APPLY is broken into the four Ordering-Law stages and each stage emits its own visible delta before the next begins.

### Step 0: Diagnose first (never skip — even on the heavy pass)
Score the draft on all 8 deficits using the shared 0/1/2 rubric in `references/depth-deficit-taxonomy.md`. Heavy does NOT mean "treat all eight." It means treat the confirmed weak links *thoroughly and in order*. A deficit scored 0 is left alone — routing an owner at a 0 over-deepens.

| Diagnose action | What good looks like |
|---|---|
| **Score 8 deficits (0/1/2)** | One integer per deficit, in Ordering-Law order (1→8), each justified by a named detection signal from the taxonomy — not a vibe. |
| **Name the weakest links** | The 1–3 highest-scoring deficits become the treatment target. On a high-stakes piece the confirmed set is often broader than `/deepen`'s — but every routed deficit must score ≥1. |
| **Map deficits to stages** | Sort the confirmed deficits into the four stages below (Architecture / Scene+Detail / Line+Rhythm / Truth+Voice). A stage with no confirmed deficit becomes an explicit **no-op** — state that it ran clean; do not invent work. |
| **Lock the dose + PRESERVE line** | From `references/vertical-dosing.md`: set the dose for the vertical and write the PRESERVE function as a one-line hard constraint carried through all four stages. |

> Output of Step 0 is the **diagnosis block** (the 8 scores + weakest links + which stage owns each). Show it before touching the prose. If the user asked for diagnosis only, STOP here — that is `/depth-audit`'s job; do not climb the stack.

### Stage 1 — Architecture (spine first)
**Owner:** Noah Hawley — theme / ending-first. `skills/noah-hawley-storytelling-mastery` (`genius.md`) → `/hawley-theme-engine`, `/hawley-ending-first`.
**Treats:** Deficit 1 (No architecture). For book/long-form this is the heaviest stage; for social the spine is usually already in the hook, so this is often a no-op — do not manufacture architecture a 150-word post doesn't need.

| Conductor action | The question this stage answers |
|---|---|
| **Find or set the spine** | What is this *about*, underneath the topic, in one sentence? If a reader can't name it, install it. |
| **Make the ending pay off the opening** | Does the last beat land what the first set up? Build the through-line before any sentence work. |
| **Re-sequence if paragraphs float** | If sections are freely reorderable with no loss, the spine isn't load-bearing — fix the order so each beat depends on the last. |

Load Hawley's `genius.md` + the named command, apply the move INTO the prose, then emit the **Stage 1 delta**: what changed, why, expected reader effect, source principle. If Deficit 1 scored 0, write *"Stage 1 — clean: spine already nameable and ending pays off the open; no change."* and proceed.

### Stage 2 — Scene + telling detail
**Owners:** Eric Roth (visual prose) + Michael Connelly (telling detail). `skills/eric-roth-writing-mastery` (`genius.md`) → `/visual-prose-for-copy`; `skills/michael-connelly-vivid-writing` (`genius.md`) → `/telling-detail-engine`.
**Treats:** Deficit 2 (Hollow/generic — abstraction at the level of stake and subject) and Deficit 7 (Missing telling detail — the absent rendered image). Built ON TOP of the spine from Stage 1 — scene without a spine is decoration.

| Conductor action | The question this stage answers |
|---|---|
| **Ground the abstraction** | Swap could-be-anyone claims for the one concrete stake/subject only this piece could carry (Deficit 2). |
| **Show, don't tell** | Replace conclusions and adjectives ("she was nervous") with the load-bearing image that produces them (Deficit 7). |
| **One image carries the meaning** | Find the single concrete object/gesture/moment the spine can hang on — quotable, picture-able. |

Apply the owners' moves, then emit the **Stage 2 delta**. No-op if both deficits scored 0.

### Stage 3 — Line + rhythm
**Owners:** Nicolas Cole (sentence craft) + Lamott-Allen technical-craft (read-aloud / economy). `skills/nicolas-cole-sentence-craft` (`genius.md`) → `/atomic-compression-density-audit`, `/terminal-power-rhythm-engineering`; `skills/lamott-allen-really-real-writing` (`genius.md`) → `/really-real-silence`, `/really-real-attention`.
**Treats:** Deficit 5 (Over-explained/bloated) and Deficit 6 (Weak rhythm). Runs only now that the scene exists to carry the rhythm. **Remember: deepen ≠ lengthen — this stage usually CUTS.** On most high-stakes drafts ~25–30% lifts with no loss.

| Conductor action | The question this stage answers |
|---|---|
| **Cut the over-proof** | Where is a point made twice, or a caveat defending an objection the reader won't raise? Lift it (Deficit 5). |
| **Set the cadence** | Vary sentence length; let a short sentence snap a passage shut; give key sentences terminal power (Deficit 6). |
| **Pass the read-aloud test** | Read it out loud. Where you stumble or run out of breath, re-cut until the mouth rides it. |

Apply, then emit the **Stage 3 delta** — and report the cut percentage explicitly, since on the heavy pass the cut IS the depth. No-op if both scored 0.

### Stage 4 — Truth + voice (last, always)
**Owners:** Lamott-Allen really-real (the vertical's truth slot — **CALL it, do not re-implement**) + the voice-as-music model. Truth slot by vertical: SOCIAL → `/really-real-social` · COPY & MARKETING → `/really-real-marketing` · BOOK/LONG-FORM → `/really-real-book` · CLIENT/PERSONAL-BRAND → `/really-real-client`. Voice owners (Deficit 4): `skills/ghostwriting-voice-engine` (`genius.md`) → `/voice-capture` (01); `skills/nicolas-cole-sentence-craft` (`genius.md`) → `/terminal-power-rhythm-engineering`; voice-as-music model lives in `skills/lamott-allen-really-real-writing/references/genius-patterns.md` Pattern 7 Music Diagnostic.
**Treats:** Deficit 3 (Emotionally unearned), Deficit 8 (No reader trust), Deficit 4 (No signature voice). Last because truth lands hardest on a draft that already has spine, scene, and clean rhythm — sentiment dropped on a shapeless draft reads as melodrama.

| Conductor action | The question this stage answers |
|---|---|
| **Earn the emotion** | Run the matched `/really-real-*` truth slot. Is each feeling built through scene/cost, or asserted? Erode overclaim to the earned core; never manufacture warmth (Deficit 3). |
| **Repair reader trust** | Cut throat-clearing, fix the unfollowable leap, replace fake closure with an earned ending (Deficit 8). |
| **Set the fingerprint** | Apply the voice-as-music model + voice owners against the reference samples so the piece is recognizably this author's, not AI's (Deficit 4). |

Apply, then emit the **Stage 4 delta**. No-op any of the three deficits that scored 0. **Do not name any expert in the prose itself** — integrate every move invisibly; experts appear only in the consolidated Receipt.

### Step 5: Consolidate and pressure-test
Re-read the fully deepened draft once, end to end, as a reader who has never seen the stages. Confirm: the machinery is invisible, the PRESERVE function is intact, the dose matched the vertical, and the piece reads *more honest, clearer, warmer, more specific, less defended* — not merely longer or more impressive. If a reader could feel the technique stack, return to the offending stage and integrate harder before delivering. Then assemble the consolidated Depth Receipt.

## Content-Type Adaptations
| Vertical | How this workflow adapts (dose / order / truth slot) |
|---|---|
| **Social** (LinkedIn / X / IG / newsletter short) | Heaviest restraint of any vertical even on the "heavy" pass. Stage 1 is usually a no-op (spine lives in the hook); Stage 3 is often the whole game (cut, don't add). Preserve hook, brevity, scannability, platform shape. Truth slot: `/really-real-social`. If the stack starts turning a 150-word post into an essay, you've mis-tooled — drop to `/deepen`. |
| **Copy** (ads / VSL / landing / email / offers) | Run all four stages INSIDE the conversion skeleton — never re-architect the funnel. Stage 1 = the argument/spine of the offer, not a new structure. Stage 4 adds conviction + voice but the CTA, offer logic, and proof stay intact. Truth slot: `/really-real-marketing`. Literary feel never beats clarity-to-action — if a move blurs the next step, it doesn't ship. |
| **Marketing / brand** | Medium-heavy on humanity + belief. Stage 1 protects the positioning/reframe (Rory Sutherland reframe via `skills/rory-sutherland-marketing` → `/conspiratorial-reframe-engine` available as the belief layer); Stage 2 makes it credible; Stage 4 makes the brand sound like a human who believes something. Truth slot: `/really-real-marketing`. Specificity serves belief, not decoration. |
| **Book / long-form** | The home vertical for this workflow — the full stack is the default and Stage 1 (architecture) is the heaviest, most load-bearing pass. Argument architecture for non-fiction via `skills/fareed-zakaria-writing-mastery` → `/high-stakes-argument-architecture` where the spine is an argument. Truth slot: `/really-real-book`. Guard: don't let Stages 3–4 drift the spine set in Stage 1; deepening a chapter often means cutting a scene. |
| **Client / personal** | Measured, trusted-advisory restraint. Stage 1 = argument architecture (Fareed → `/high-stakes-argument-architecture`); Stage 4's truth slot is `/really-real-client` and shows as authority + clarity, never confession. Preserve credibility (no overreach, no manufactured stat). Never manufacture vulnerability for "relatability." |

## Quality Gate
> **🛡️ Anti-Pattern Check**: review the output against `genius.md § Anti-Patterns` and the § Decision Framework before delivering. Flag and fix any violation first.
- **No lengthening-as-deepening.** Confirm Stage 3 actually cut. If the deepened draft is materially longer with no clear reason, the stack added instead of deepened — re-run Stage 3 and return.
- **Machinery invisible.** No expert name, no technique label, no stage marker survives in the deepened prose. Experts and stages live only in the Receipt and the staged deltas. If a reader could feel the stack, integrate harder and return.
- **Function preserved.** The PRESERVE line is intact — the CTA/offer (copy), the hook/shape (social), the argument/credibility (client), the spine (book) still does its job. A gorgeous sentence that breaks the function does not ship.
- **No manufactured sentiment.** Stage 4 earned every feeling through scene/cost; nothing confesses or claims warmth the draft hadn't already earned. Manufactured vulnerability = rebuild Stage 4.
- **Ordering Law respected.** Architecture → scene → line/rhythm → truth/voice, in that sequence, with only confirmed deficits treated. A stage that scored 0 reads as an explicit no-op, not as invented work.
- **Truth slot CALLED, not re-implemented.** Stage 4 ran the matching `/really-real-*` pass; it did not re-teach really-real craft locally (Anti-Duplication Contract).

## Common Pitfalls
- **Heavy mistaken for thorough.** You ran all four stages on a draft that needed one cut, crowding clean prose with technique. Recovery: re-read the Step 0 diagnosis — every routed deficit must score ≥1; if only one weak link exists, this was the wrong tool, drop to `/deepen`.
- **Stages run out of order.** You polished sentences (Stage 3) or dropped in truth (Stage 4) before the spine existed, producing beautiful prose with no center. Recovery: obey the Ordering Law — return to Stage 1, set the spine, then re-climb.
- **Added instead of cut.** Stage 3 made the piece longer instead of leaner. Recovery: re-run `/atomic-compression-density-audit`; on a high-stakes draft, ~25–30% should lift — find it and report the cut percentage.
- **Voice set to no one.** Stage 4 left a competent-but-anyone cadence because no reference samples grounded it. Recovery: pull 2–3 real samples and re-run the voice owners against them; absent samples, set voice conservatively and flag it as Remaining Risk.
- **Truth slot re-implemented.** Stage 4 tried to re-teach really-real craft instead of calling the matching `/really-real-*` pass. Recovery: enforce the Anti-Duplication Contract — CALL `/really-real-social` / `/really-real-marketing` / `/really-real-book` / `/really-real-client` per the vertical; the stack composes the truth owner, never duplicates it.
- **Deltas faked on a no-op stage.** A stage that scored 0 got invented "changes" to look complete. Recovery: a 0 is left alone — write the explicit no-op line; manufactured work over-deepens and is itself an anti-pattern.
