# Deficit → Owner Routing Map

The conductor does not play the instruments. This map is the seating chart: it tells the depth layer, for each of the 8 depth deficits, which existing craft expert owns the fix, the real skill path to load, and the real command to run. Every path and command below was verified on disk against the verified expert roster — if a path is not in this file, the layer does not reference it. The layer composes these owners; it never re-implements what they already do.

Read order is the law. A deficit map without an ordering law is a pile of fixes that produces well-crafted sentences with no spine. Diagnose first, route only the confirmed deficits, and apply them in the order below — architecture before line, truth last.

## The Ordering Law (non-negotiable)

Apply confirmed deficits in this fixed sequence. Inverting it — line-craft before architecture — yields well-crafted sentences with no spine. Architecture first, always; truth and voice last.

1. **Architecture (spine first).** Hawley — Deficit 1. Establish theme/ending/reason-this-exists before any line work. `skills/noah-hawley-storytelling-mastery` → `/hawley-theme-engine`, `/hawley-ending-first`.
2. **Structure / scene + telling detail.** Roth + Connelly — Deficits 2, 7. Build the concrete scene and the showing image on top of the spine. `skills/eric-roth-writing-mastery` → `/visual-prose-for-copy`; `skills/michael-connelly-vivid-writing` → `/telling-detail-engine`.
3. **Line / rhythm.** Cole + Lamott-Allen technical-craft — Deficits 5, 6. Compress, set cadence, pass read-aloud — only once the scene exists to carry the rhythm. `skills/nicolas-cole-sentence-craft` → `/atomic-compression-density-audit`, `/terminal-power-rhythm-engineering`; `skills/lamott-allen-really-real-writing` → `/really-real-silence`, `/really-real-attention`.
4. **Truth + voice (last).** Lamott-Allen really-real (the vertical's truth slot) + the voice-as-music model — Deficits 3, 4. Earn the emotion and set the signature fingerprint as the final pass, never before the spine and scene hold. `skills/lamott-allen-really-real-writing` → `/really-real-*` (vertical-matched truth slot); voice owners per Deficit 4 row.

## Load Discipline

Loading an owner you don't need is a tax on the prose and a tax on the context window — and it tempts the layer to "fix" a deficit the draft doesn't have, which is how a clean draft gets crowded with technique.

- **Load only owners for confirmed deficits.** The diagnosis names 1–3 weakest links. Load exactly those rows' owners — nothing more. A draft scored clean on Deficit 1 does not load Hawley, no matter how tempting the spine work looks.
- **One genius.md per owner, Tier 2.** Read each owner's `genius.md` plus the single specific command/workflow for the confirmed deficit. Do not bulk-load a skill's full workflow set.
- **Sequence by the Ordering Law, not by deficit number.** If the confirmed set is Deficits 4 and 1, you still run architecture (1) before voice (4). The table numbers are an index, not an apply order.
- **Dose by vertical** (see `genius.md § Per-Vertical Dosing`). SOCIAL: fix 1–2 deficits max, light and fast, preserve hook/brevity/platform shape. COPY: depth without losing conversion — offer logic, CTA, proof, clarity-to-action stay intact. BOOK/LONG-FORM: full stack, architecture-heavy. Over-deepening a 150-word post into an essay is a routing failure, not a thoroughness win.
- **Compose, never duplicate.** Every fix runs through the owner's real command above. The depth layer's `genius.md` is routing intelligence only — zero craft re-teaching. Technical sentence-craft knowledge lives only in `skills/lamott-allen-really-real-writing`; this map points at it, it does not copy it.
- **Diagnose-only means route nothing.** If the user asked for an audit, run the diagnosis and stop. Do not load owners or apply moves on a diagnosis-only request.
