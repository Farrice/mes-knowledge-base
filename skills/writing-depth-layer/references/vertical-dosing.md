# Vertical Dosing

The same deepening move kills a LinkedIn post and saves a novel chapter. Depth is not a constant — it is a *dose*, and the dose is set by the vertical, not by the draft's ambition. A 150-word post does not want the full stack; it wants one weak link fixed and its hook left alone. A book chapter wants the whole architecture-to-truth ladder, slow and layered. The conductor's job is to read which room it's playing in before choosing how loud to deepen. Over-deepen social and you drown the scroll-stopping shape in essay; under-deepen a book and you ship competent sentences with no spine.

This file is the dial. For each of the five verticals it fixes five things: **the dose** (how light or heavy), **which deficits matter most** (so DIAGNOSE knows where to look first), **the truth slot** (which `/really-real-*` pass the full-stack `/depth-*` orchestrator calls — never re-implements), **what must be PRESERVED** (the function the deepening is forbidden to break), and **the failure mode** the dose exists to prevent. Deficit numbers refer to the 8 Depth Deficits taxonomy in `genius.md`; owners refer to the Verified Expert Roster in `genius.md § Routing Map`.

## Pre-Flight
Read these files before dosing any draft:
1. `skills/writing-depth-layer/genius.md` (the 8 Depth Deficits taxonomy + the Ordering Law + the Anti-Duplication Contract)
2. `skills/writing-depth-layer/references/routing-map.md` (which owner fixes which deficit — never reference a path not on the Verified Expert Roster)
3. The matching truth-slot pass for the vertical you're dosing — e.g. `skills/lamott-allen-really-real-writing` (commands `/really-real-social`, `/really-real-marketing`, `/really-real-book`, `/really-real-client`) — so the `/depth-*` orchestrator *calls* it rather than re-teaching it.

> **🔒 Pre-Flight Gate**: Before applying a dose, run the **Diagnose-Before-Treating** check in `genius.md § Decision Framework` — confirm you have actually scored the draft on the 8 deficits and named the 1–3 weakest links. STOP condition: if you cannot name the confirmed deficits, you are about to refine slop on a misdiagnosed draft. Diagnose first. A dose applied to the wrong deficit is wasted depth and may break the function the vertical needs preserved.

## Input Required
- **The vertical** — social / copy / marketing / book-long-form / client-personal. If ambiguous, ask which one; the dose is wrong if the vertical is wrong.
- **The diagnosis** — the 1–3 confirmed weakest deficits from the DEEPEN loop's DIAGNOSE pass. The dosing table tells you *which deficits to suspect first*; it does not replace scoring.
- **The function to protect** — the one thing this draft must keep doing (convert, stop the scroll, hold authority). This is the PRESERVE column made concrete for this specific piece.
- *(Optional)* The platform / channel inside the vertical (X vs. LinkedIn vs. newsletter short; VSL vs. landing vs. cold email) — narrows the preserve list further.
- *(Optional)* Whether the user asked for diagnosis only, a surgical inject, or a full rewrite — never full-rewrite when an inject would do.

## Reading the Dose: Light → Heavy

Picture the dial as one continuous line, not five separate settings:

```
LIGHT ──────────────────────────────────────── HEAVY
social        copy / marketing         client        book
(1–2 fixes)   (deepen-in-skeleton)     (restraint)   (full stack)
```

- **The lighter the vertical, the more depth = subtraction.** Social's most common deepening move is a cut (#5 over-explained) or one telling detail swapped for an abstraction (#2 hollow). Resist adding.
- **The middle verticals deepen *inside an existing structure* you must not break** — the conversion skeleton (copy) or the position/reframe (marketing). You are adding conviction and specificity to a frame, never replacing the frame.
- **The heavier the vertical, the more the Ordering Law runs in full** — but "heavy" still bows to restraint at the client end (authority is quiet) and to architecture-first at the book end (spine before sentence, every time).

## Common Pitfalls

- **Wrong vertical, right moves.** You dosed a piece of converting copy as if it were a Substack essay and buried the CTA under earned interiority. Recovery: re-confirm the vertical *and the function to protect* before selecting moves; the dose is set by the vertical, not the draft's literary ambition.
- **Deepen read as lengthen.** You added paragraphs to "deepen" a 150-word post and killed its scroll-stopping shape. Recovery: for social and any over-explained draft, try the cut first — deepening is often subtraction; re-run DIAGNOSE for deficit #5 before adding a single word.
- **Function sacrificed for feel.** A copy or marketing deepening pass produced a gorgeous sentence that blurred the next action or dissolved the position. Recovery: hold the PRESERVE column as a hard constraint — if a move touches the CTA, the offer, the proof, or the belief, it must *strengthen* that function or it doesn't ship.
- **Architecture polished last.** On a book/long-form draft you ran line-craft and truth passes before the spine existed, so you have beautiful sentences with no throughline. Recovery: obey the Ordering Law — architecture (Hawley) first, always; return to the spine and re-sequence before any line work.
- **Truth slot re-implemented.** The `/depth-*` orchestrator tried to re-teach really-real craft instead of *calling* the matching `/really-real-*` pass. Recovery: enforce the Anti-Duplication Contract in `genius.md` — the depth layer composes the truth slot owner; it never duplicates it. Route to `/really-real-social` / `/really-real-marketing` / `/really-real-book` / `/really-real-client` as the table dictates.
- **Manufactured vulnerability.** On a client or marketing piece you injected confession or false intimacy the draft had not earned, chasing "heart." Recovery: depth is earned, never faked — if the warmth or stakes aren't on the page already, find the real specific detail that earns them or leave the restraint intact.
