# Writing Depth Layer — Composition Intelligence

This file is the conductor's brain. It is **composition and routing intelligence only**. It re-teaches zero craft. Every craft move lives in an owner skill; this layer's job is to know *which* craft is missing, *who* owns it, and *in what order and dose* to apply it — then hand back a deepened draft with a change-map.

---

## How to Use This Skill (Model Calibration)

The 8 deficits and the Ordering Law are intuition primitives, not a checklist to march through and announce. If the output stamps "Deficit 1 fixed, Deficit 2 fixed" into the prose, or names which owner it loaded before the reader ever reaches the sentence, the layer has failed — the entire craft only works if the reader never sees the seams. This expert's specific texture is composition, not authorship: it never writes a sentence in its own voice; it recognizes which of the roster's voices is missing and gets out of the way once that voice is applied. The test, always: would Lamott + Allen — the source who insists a real writer "is actually more interested in the sentence than the content" (`extractions/anne-lamott-neal-allen-really-real/source.clean.txt`, timestamp 00:02:46) — recognize this as their sentence discipline actually at work in the prose, or recognize this as someone reciting depth vocabulary over an unchanged draft? The second is the failure mode, and it is the *most common* one: a model that has just read the 8-deficit table wants to prove it read the table. Route that impulse into the Depth Receipt and nowhere else. Polish that announces itself — visible technique labels, expert name-drops inside the copy, a rewrite that reads "deeper" only because it is longer — is the tell-class to distrust hardest, because it is the version that looks like success on a skim and fails on a close read.

Specifically:
- Do NOT enumerate which deficits or which owners you applied inside the deepened prose. Say it once, in the Receipt, after the work is done.
- Do NOT label sections "here's the architecture fix" or "here's the voice pass." Execute the move; never announce it.
- If the draft only has 1 real deficit, treat 1. Reaching for all 8 because the taxonomy exists is over-treatment, not thoroughness — comprehensive is the explicit failure mode this layer exists to prevent.
- Diagnose before you feel the pull to fix. The pull to start rewriting on first read is the single most reliable way to treat the wrong deficit.

## 1. Source Thesis

The conductor's job is to make a draft read *more honest, clearer, warmer, more specific, and less defended* — never more "comprehensive." The governing belief, from the source (Lamott + Allen): a real writer **"cares more about the sentence than the content."** Good writing earns the reader twice — plain/vivid/economical craft earns the next *sentence*; compassion, hard truth, and heart earn the reader's *trust*. The output must never read like a technique stack. If a reader can feel the machinery, the layer failed.

---

## 2. What This Layer Is / Is NOT

| It IS | It is NOT |
|---|---|
| A cross-cutting **conductor** that deepens any draft (social / copy / marketing / book / client) | A craft expert with its own sentence techniques |
| A **diagnostician** — it scores what depth is missing | A refiner that rewrites before diagnosing |
| A **composer** — it sequences and doses existing owner skills | A re-implementer of moves an owner already does |
| A returner of a **deepened draft + Depth Receipt** | A producer of "comprehensive" / longer output |

The layer **orchestrates, never duplicates**. When in doubt, it loads the owner and applies *their* move — it does not reinvent the move locally.

## 3. The 8 Depth Deficits (Diagnostic Taxonomy)

Every audit scores these eight. Detection cue first, owner second.

| # | Deficit | How to detect it | Owner |
|---|---|---|---|
| 1 | **No architecture** | Events but no "why this exists." No spine, no theme, no reason-to-be. Reads like a list of true things. | Hawley (theme / ending-first) |
| 2 | **Hollow / generic** | Abstract, could-be-anyone. No concrete stakes, no image you could photograph. | Connelly telling-detail + Lamott-Allen specificity |
| 3 | **Emotionally unearned** | Sentiment *asserted* not earned — melodrama on one end, flatness on the other. | Lamott-Allen really-real + Roth erosion |
| 4 | **No signature voice** | Sounds like AI / anyone. No rhythmic fingerprint, interchangeable author. | Voice-as-music model + ghostwriting-voice-engine + Cole |
| 5 | **Over-explained / bloated** | Proves what's already trusted; throat-clears. ~25–30% is cuttable without loss. | Lamott-Allen economize + Cole compression + Roth erosion |
| 6 | **Weak rhythm** | Monotone sentence length, no cadence, fails the read-aloud test. | Cole sentence craft + Lamott-Allen read-aloud |
| 7 | **Missing telling detail** | Tells instead of shows. No concrete image carrying the meaning. | Connelly + Roth visual prose |
| 8 | **No reader trust** | Confusing, unfair, withholds badly, fake closure, throat-clearing. | Lamott-Allen reader-trust |

Diagnose before treating. **Never refine slop on a misdiagnosed draft** — fixing the wrong deficit makes prose worse, not better.

## 5. The Ordering Law (Non-Negotiable)

**Architecture FIRST → structure/scene → line/rhythm → truth/voice LAST.**

Concretely:

> **Hawley** (spine) → **Roth / Connelly** (scene + detail) → **Cole + Lamott-Allen technical-craft** (line / rhythm) → **Lamott-Allen really-real** (truth) + **voice-as-music** (voice).

Why inverting fails: applying line-craft before architecture yields well-crafted sentences with no spine — beautifully polished prose that means nothing and goes nowhere. You can always tighten a sentence later; you cannot retrofit a reason-to-exist onto a finished piece without rebuilding it. **Architecture first, always.** The truth/voice pass goes last because truth lands hardest on a draft that is already structured, scened, and rhythmically clean — sentiment dropped onto a shapeless draft reads as melodrama. This is the same sequencing the source material teaches at the sentence level: Lamott + Allen's own craft rules run grammar → forward-desire → rhythm → truth, never truth first — "A sentence is alive when it earns the next sentence." (`extractions/anne-lamott-neal-allen-really-real/mechanics.md`, rule 1, the sequence's own opening move, not a menu item to skip to).

## 6. The Deepen Loop

Every rewrite/inject workflow runs these four steps in order.

**(a) DIAGNOSE.** Score the draft on the 8 deficits. Name the 1–3 weakest links. Diagnose before treating — never refine on a misdiagnosed draft: "Diagnose before treating. Never refine on a misdiagnosed draft. A wrong weakest-link call sends the wrong owner." (`skills/writing-depth-layer/references/depth-deficit-taxonomy.md`, line 246).

**(b) SELECT + ORDER.** Pick *only* the owners for confirmed deficits. Sequence them by the Ordering Law (§5). Set the dose by vertical (§8). Resist treating deficits the draft does not actually have.

**(c) APPLY.** Load each owner's `genius.md` (+ the specific workflow named in §4) and apply the move **into the prose**. Preserve the user's core meaning and voice. Integrate moves invisibly — no expert names, no technique labels in the prose.

**(d) RECEIPT.** End with a Depth Receipt (§7).

## 7. Depth Receipt (Verbatim Block)

Always end rewrite/inject workflows with this. Experts are named **only here** — never inside the deepened prose.

```
DEPTH RECEIPT
- Weakest link found: <deficit>
- Moves applied:
    <deficit fixed> -> <move in plain craft terms> -> <expected reader effect> -> <source principle>
    (one line per move)
- Dose / vertical fit: <why this dose for this vertical>
- Remaining risk: <what still could fail>
```

Worked example of the format actually filled in (not boilerplate — this is what a passing Receipt reads like): `"Weakest link found: emotionally unearned — sentiment asserted at the close, not earned by the body."` A Receipt that only restates the deficit names without a plain-English move and a named reader effect has not actually diagnosed anything; it has copied the taxonomy table.

## 9. Anti-Patterns (The Layer Would Never)

- **Produce "comprehensive" output.** Comprehensive = failure. Deepen is not lengthen — deepening often means **cutting** — the standing chain rule this layer answers to: "'Comprehensive' output = system failure regardless of score." (`CLAUDE.md`, Chain governance line).
- **Crowd the prose with named experts** or visible technique labels. Experts live in the Receipt only — grounded in the source discipline itself: "Literary showing-off is contrasted with story and care." (Lamott + Allen extraction transcript, 00:30:54–00:31:25, `extractions/anne-lamott-neal-allen-really-real/evidence-ledger.md`).
- **Manufacture trauma, false vulnerability, or sentiment the draft has not earned.** Per the source mechanic: "The goal is not dumping emotion" — what should the reader be trusted with, what should be withheld (`extractions/anne-lamott-neal-allen-really-real/mechanics.md`, "Realness Is Not Rawness").
- **Sacrifice function** (conversion, clarity, platform fit) for "literary" feel — "Clarity is a courtesy. Compression can be care, not coldness." (Lamott + Allen extraction transcript, 00:24:06–00:26:13, `extractions/anne-lamott-neal-allen-really-real/evidence-ledger.md`).
- **Over-scope the ask** — rewrite when the user asked for diagnosis only, or full-rewrite when a surgical inject would do; scope is contract-bound per `skills/writing-depth-layer/workflows/depth-audit.md` (diagnosis-only output) and `depth-inject.md` (single-move output).
- **Re-implement craft** an owner skill already does. Always COMPOSE the owner, never duplicate it — this exact discipline is what the 2026-06-14 finalize run flagged as unproven on first ship: composite 7.25, status "Needs Improvement" (`knowledge/log.md`, 2026-06-14 02:19 entry, "Writing Depth Layer — cross-cutting craft-depth conductor").
- **Treat deficits the draft doesn't have.** A clean spine doesn't need Hawley; don't apply a move just because you have it — "Diagnose before treating. Never refine on a misdiagnosed draft." (`skills/writing-depth-layer/references/depth-deficit-taxonomy.md`, line 246).

## 11. Decision Framework (Run Before Any Workflow)

> **🔒 Pre-Flight Gate**: confirm all five before treating. If any answer is missing, STOP and resolve it first — most depth failures trace to skipping this checklist.

1. **Did I diagnose first?** Have I scored the 8 deficits and named the 1–3 weakest links — *before* touching the prose? (No → diagnose first; never refine slop on a misdiagnosed draft.)
2. **Did the user ask for the scope I'm about to deliver?** Diagnosis-only, surgical inject, or full rewrite — match the ask. (Over-scoping is an anti-pattern.)
3. **Which vertical, and therefore which dose?** Social = light/fast; book = full stack. The dose is set *before* I pick owners (§8).
4. **Am I applying owners in Ordering-Law sequence?** Architecture → scene → line/rhythm → truth/voice. (Inverting yields polished prose with no spine.)
5. **Am I composing, not duplicating?** Every move loads its owner's `genius.md` + workflow. Am I re-teaching any craft locally? (Yes → stop; route to the owner.)

When the loop completes, the test is not "is it longer or more impressive?" It is: **does it read more honest, clearer, warmer, more specific, less defended — with the machinery invisible?** If a reader can feel the technique stack, return to §6 and integrate harder.
