# /lynch-drtv-copy — DRTV-Powered Copy Architecture (Lynch × David Deutsch)

> Stack Ron Lynch's DRTV methodology with David Deutsch's A-list copy architecture. Write copy that demonstrates like an infomercial AND persuades like a world-class sales letter.

## When to Use
- Writing long-form sales copy (VSLs, sales pages, advertorials)
- When the product benefits from demonstration AND deep persuasion
- When short-form creative isn't converting and you need long-form architecture
- Bridging the gap between "show it working" and "make them believe"

## Inputs Required
1. Product/service with demonstrable transformation
2. Target audience and awareness level
3. Available proof (testimonials, data, demonstrations)
4. Price point and offer structure
5. Identity word (if available from `/lynch-identity-campaign`)

## Execution Steps

### Step 1: Demonstration Assets (Lynch)
Inventory what can be SHOWN:
- Before/after transformations
- Live usage demonstrations
- Customer results documentation
- Process transparency (how it works, visually)

### Step 2: Persuasion Architecture (Deutsch)
Build the copy structure using David Deutsch's framework:
- **Big idea**: The one insight that makes everything click
- **Mechanism**: How and WHY this works (not just THAT it works)
- **Proof cascade**: Logical → statistical → testimonial → demonstration
- **Emotional driver**: The deeper motivation beneath the surface want

### Step 3: DRTV-Copy Fusion
Merge demonstration with persuasion at each stage:

| Copy Section | Deutsch Element | Lynch Enhancement |
|---|---|---|
| Lead/Hook | Big idea + curiosity | Transformation result shot |
| Problem | Pain agitation | Visual depiction of the problem |
| Mechanism | How it works | Live demonstration of the mechanism |
| Proof | Testimonials + data | Video testimonials + before/after |
| Offer | Price anchoring + stack | DRTV offer structure ("but wait") |
| Close | Urgency + guarantee | Call-to-action with demonstration callback |

### Step 4: Voice Layer (Lynch GP-6)
Write from inside the customer's head:
- Deutsch provides the STRUCTURE of persuasion
- Lynch provides the VOICE of the customer
- The copy should read as the customer's internal realization, not a pitch

### Step 5: Full Copy Execution
Write the complete piece:
- VSL script with visual direction notes for demonstration moments
- Sales page with embedded demonstration sections
- Or advertorial with editorial voice and proof integration

## Quality Gate
- Must include at least 3 demonstration moments in the copy
- Deutsch persuasion architecture must be complete (big idea, mechanism, proof, emotion)
- Voice must be customer-internal (not brand-external)
- Visual direction notes must be specific enough for a producer to execute
- Both expert contributions explicitly documented
- Score ≥7 on both Transformation-First AND Copy Architecture
