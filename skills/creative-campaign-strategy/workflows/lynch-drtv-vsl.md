# /lynch-drtv-vsl — DRTV-to-VSL Conversion Engine (Lynch × David Deutsch)

> Translate infomercial methodology to modern VSLs. 30-minute DRTV structure → modular VSL with demonstration-first architecture + David Deutsch copy principles. Copy that SHOWS and PERSUADES simultaneously.

## When to Use
- Writing long-form sales copy (VSLs, sales pages, advertorials)
- Converting DRTV methodology into digital-native creative formats
- When digital creative lacks demonstration, proof density, or urgency
- When the product benefits from live demonstration AND deep persuasion
- When short-form creative isn't converting and you need long-form architecture

## Inputs Required
1. Product/service with demonstrable transformation
2. Target audience and awareness level
3. Available demonstration footage or capability
4. Available proof (testimonials, data, before/after)
5. Price point and offer structure
6. Identity word (if available from `/lynch-identity-campaign`)

## Execution Steps

### Step 1: DRTV Principle Extraction (Lynch)
Identify which infomercial principles apply to this product:
- **Demonstration supremacy**: Can you SHOW the transformation happening?
- **Problem agitation → solution reveal**: Can you make the pain vivid?
- **Compressed proof**: Can you stack 3-5 testimonials in rapid sequence?
- **Price anchoring**: Can you anchor against a higher perceived value?
- **Urgency mechanics**: What legitimate scarcity or time pressure exists?
- **The Reverse Sell**: Lead with the FOOD, not the appliance

### Step 2: Copy Architecture (David Deutsch)
Build the persuasion structure using Deutsch's A-list framework:
- **Big idea**: The one insight that makes everything click — the thought the reader has never had before
- **Mechanism**: HOW and WHY this works (not just THAT it works) — the proprietary explanation
- **Proof cascade**: Logical → statistical → testimonial → demonstration (each layer building on the last)
- **Emotional driver**: The deeper motivation beneath the surface want — what the customer REALLY fears or desires

### Step 3: DRTV-to-VSL Structure Translation
Translate the 30-minute infomercial into a modern VSL:

| DRTV Element | Time (30 min) | VSL Translation | Time (8-15 min) |
|---|---|---|---|
| Cold open/hook | 0:00-2:00 | Transformation result shot (the "food") | 0:00-0:30 |
| Problem world | 2:00-5:00 | Pain agitation with Deutsch emotional driver | 0:30-2:00 |
| Discovery moment | 5:00-8:00 | Big idea reveal | 2:00-3:00 |
| Live demonstration | 8:00-15:00 | Mechanism + demo (compressed) | 3:00-5:00 |
| Testimonial montage | 15:00-20:00 | Proof cascade (video + text) | 5:00-7:00 |
| CTA #1 (mid-roll) | 20:00-21:00 | **Remove** (VSL = single CTA) | — |
| Deep dive/features | 21:00-25:00 | Mechanism deepening + objection handling | 7:00-9:00 |
| CTA #2 (mid-roll) | 25:00-26:00 | **Remove** | — |
| Offer stack | 26:00-28:00 | Value stack with Deutsch price anchor | 9:00-11:00 |
| Final close | 28:00-30:00 | Urgency + guarantee + identity CTA | 11:00-12:00 |

Key translation rule: Remove middle CTAs. A VSL has ONE close. An infomercial has three.

### Step 4: Two-Column Script (Lynch GP-10)
Write the VSL in Ron Lynch's two-column format:

| VISUAL (what they see) | COPY (what they hear/read) |
|---|---|
| [Transformation result shot — the food, not the appliance] | [Voiceover: customer's aspirational internal monologue] |
| [Cut to: real person experiencing the problem] | [Agitation copy using Deutsch emotional driver] |
| [Cut to: discovery moment — the "wouldn't it be cool if"] | [Big idea revelation — Deutsch's one insight] |
| [Demonstration: product creating the transformation in real time] | [Mechanism copy — HOW this works, not THAT it works] |
| [Testimonial montage — real people, real results] | [Proof cascade — each one building credibility] |
| [Offer architecture — value stack revealed] | [Price anchor → reveal → guarantee] |
| [Identity reinforcement — customer BEING the identity] | [CTA framed as joining the identity, not buying the product] |

### Step 5: Voice Layer (Lynch GP-6)
Merge Deutsch's persuasion structure with Lynch's voice methodology:
- Deutsch provides the STRUCTURE of persuasion (what to say, in what order)
- Lynch provides the VOICE (from inside the customer's head, not the expert's)
- The copy should read as the customer's internal realization:
  - ❌ "Our patented technology increases absorption by 300%"
  - ✅ "Wait — so THAT'S why nothing else ever worked?"

### Step 6: Platform Adaptation
Adapt the master VSL for digital platforms:
- **Full VSL (8-15 min)**: YouTube, landing page embed, webinar
- **Compressed (3-5 min)**: YouTube pre-roll, Facebook video ad
- **Modular cuts (15-60 sec)**: Instagram Reels, TikTok, Stories
- Apply `/lynch-modular-script` methodology: "Take the staple out"

## Quality Gate
- Must include at least 3 DRTV principles actively deployed
- Deutsch persuasion architecture must be complete (big idea, mechanism, proof, emotion)
- Script MUST use two-column format (visual + copy) — not copy-only
- Middle CTAs must be REMOVED (VSL = single close)
- Voice must be customer-internal (not brand-external) in every section
- At least one platform adaptation beyond the master VSL
- Both expert contributions explicitly documented
- Score ≥7 on both Transformation-First AND Voice Accuracy in the Ron Lynch Quality Rubric
