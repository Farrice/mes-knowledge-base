# /lynch-modular-script — Modular Script Architecture

> Write one comprehensive long-form script, then "take the staple out" to produce 5-12 standalone spots, social clips, email sequences, and VSL sections. One creative effort → maximum asset yield.

## When to Use
- Producing a campaign with multiple deliverables across platforms
- When budget demands maximum asset output from minimum production
- After `/lynch-identity-campaign` and `/lynch-media-match` when you need execution-level scripts
- Converting a VSL or long-form video into modular social content
- When a client needs "a campaign" but the budget says "one shoot"

## Inputs Required
1. Identity word (from `/lynch-identity-campaign`)
2. Campaign brief or media-matched creative strategy (from `/lynch-media-match`)
3. Target platforms and their format constraints (length, aspect ratio, tone)
4. Number of deliverables needed
5. Production constraints (budget, shoot days, talent availability)

## Execution Steps

### Step 1: Long-Form Master Script (GP-10 — Two Columns)
Write the comprehensive master script using Ron Lynch's two-column format:

| VISUAL (Right Column) | COPY (Left Column) |
|---|---|
| What the viewer SEES | What the viewer HEARS/READS |
| Camera direction, setting, action | Voiceover, dialogue, text overlay |
| Demonstration moments | Narration during demonstration |
| Transition cues | Emotional beats |

The master script should be 20-30 pages (equivalent to a 30-minute infomercial structure):
1. **Cold open** (2 pages): Identity hook — show the transformation, not the product
2. **Problem world** (3 pages): The before-state in vivid sensory detail
3. **Discovery** (3 pages): The "wouldn't it be cool if" moment
4. **Demonstration** (5 pages): Show the product creating the transformation
5. **Proof montage** (4 pages): Multiple customer stories, each self-contained
6. **Deep dive** (5 pages): Mechanism, features-through-transformation lens
7. **Offer architecture** (3 pages): Value stack with transformation framing
8. **Close** (2 pages): Identity reinforcement + CTA
9. **Reprise** (3 pages): Condensed recap of best moments

### Step 2: Staple Removal — Module Identification
Mark every natural breakpoint in the master script:
- Each section that can stand ALONE as a complete story
- Each demonstration that makes sense without context
- Each testimonial/proof that delivers value independently
- Each emotional beat that resolves within itself

Label each module:
```
[MODULE A — Cold Open] 0:00-2:00 | Standalone: YES | Platform: YouTube pre-roll, TikTok
[MODULE B — Problem World] 2:00-5:00 | Standalone: YES | Platform: Facebook, Instagram
[MODULE C — Discovery] 5:00-8:00 | Standalone: PARTIAL | Platform: YouTube mid-roll
...
```

### Step 3: Platform-Native Adaptation
For each standalone module, adapt to platform constraints:

| Platform | Length | Format | Module Adaptation |
|---|---|---|---|
| TikTok/Reels | 15-60 sec | Vertical, fast | Strip to single demonstration + hook |
| YouTube Pre-roll | 15-30 sec | Skip-worthy | Identity hook + immediate transformation |
| YouTube Long-form | 3-8 min | Horizontal | 2-3 modules stitched with transitions |
| Meta Feed | 15-45 sec | Square/vertical | Problem → demo → CTA compressed |
| Email | N/A | Copy only | Left column extracted + link to video |
| Landing page | N/A | Scroll | Full script as page sections with embedded video |
| VSL | 5-15 min | Horizontal | Modules 1-7 with single CTA |

### Step 4: Voice Consistency Audit (GP-6)
Verify every module maintains the customer's internal voice:
- Does each standalone piece sound like the CUSTOMER, not the brand?
- Would someone encountering Module D first still hear the right voice?
- Is the identity word woven into each module (even if the viewer never sees the master)?

### Step 5: Production Sheet
Create the production-ready breakdown:
- Shot list organized by LOCATION (not by module — shoot efficiency)
- Talent needs per module
- Asset dependencies (what must be shot vs. sourced vs. customer-generated)
- Edit plan: master cut first, then module extraction

## Output Format
```
## MODULAR SCRIPT ARCHITECTURE — [Product/Brand]

### Master Script (Two-Column Format)
[Full 20-30 page script with VISUAL | COPY columns]

### Module Map
[Each module labeled with timestamps, standalone rating, platform assignment]

### Platform Adaptation Guide
[How each module transforms for each target platform]

### Voice Consistency Checklist
[Verification that customer voice persists across all modules]

### Production Sheet
- Shot list by location: [organized for shoot efficiency]
- Talent requirements: [per module]
- Asset dependencies: [shoot vs. source vs. UGC]
- Edit sequence: [master → modules → platform cuts]

### Asset Inventory
- Total deliverables: [number]
- From one shoot: [what's produced]
- From one script: [what's extracted]
- Cost per deliverable: [total production ÷ deliverable count]
```

## Quality Gate
- Master script MUST use two-column format (visual + copy) — not copy-only
- Minimum 5 standalone modules identified from the master script
- Each module must function independently (no orphaned references)
- Platform adaptations must be genuinely native (not the same video resized)
- Voice must be from inside the customer's head in every module
- Production sheet must optimize for shoot efficiency, not script order
- Score ≥7 on both Media-Creative Match AND Voice Accuracy in the Ron Lynch Quality Rubric
