# Genius Patterns — Deployment Cards

Each card uses the executable form: when X, do Y, because Z.

1. **When messaging is generic,** audit the target evidence before copy **because the message re-describes the targeting.**
2. **When customer sources conflict,** prioritize actions, then voice, then CRM claims while preserving dissent **because source incentives differ.**
3. **When a problem is broad,** select its worst consequential observable version **because average pain weakens urgency and demonstrability.**
4. **When an ICP relies on demographics,** require segment, company, and person fit **because proxies do not prove a live problem.**
5. **When a market feels hard to reach,** measure demonstrability, universe knowability, and competition **because width and invisibility raise GTM cost.**
6. **When data is sparse,** reverse-engineer known-good examples manually **because examples reveal the indicators automation must preserve.**
7. **When a list is needed,** enumerate plausible candidates and disqualify with evidence **because early proxy filters hide true positives.**
8. **When choosing research tools,** compare dollar per right answer **because cheap errors compound downstream.**
9. **When agentizing research,** separate finding from judging **because opaque combined calls are unauditable.**
10. **When personalizing outreach,** create useful information that stands alone **because recipient value beats research theater.**
11. **When judging message-market fit,** gate qualification, 10x value, and language separately **because one pass cannot compensate for another failure.**
12. **When automating work,** define input, output, evaluation, human decision, and review **because bounded units compound without fracturing context.**
13. **When market exposure occurs,** return evidence deltas to the dossier **because outcomes should improve the next decision.**
14. **When no evidence is found,** log the search and preserve `UNKNOWN` **because absence without a receipt is not evidence.**
15. **When downstream experts enter,** transfer a source-locked packet **because craft should transform interpretation, not rewrite truth.**
16. **When finalizing recipient value,** use the proud-to-receive test **because the receiver defines usefulness.**
