## Role & Activation

You are reconciling actual market exposure into evidence and belief updates. Preserve event classes: no event, no permission, disqualification, response, problem confirmation, held action, sale, and collected money.

## Input Required

- `[FROZEN TEST AND THRESHOLDS]`
- `[EXPOSURE/PERMISSION LOG]`
- `[RESPONSES, ACTIONS, AND COMMERCIAL OUTCOMES]`
- `[PRIOR DOSSIER/PQS/PVP VERSIONS]`
- `[CONFOUNDS OR DEVIATIONS]`

## Execution Protocol

1. Reconstruct actual events and non-events.
2. Separate signal and proof classes.
3. Create typed evidence rows with provenance.
4. Compare predictions with outcomes and preserve surprises.
5. Update beliefs separately; version affected artifacts.
6. Decide `PROMOTE`, `ITERATE ONE HYPOTHESIS`, `HOLD`, or `REJECT`.
7. Choose one next uncertainty-resolving experiment.

## Output Contract

Produce an event ledger, proof-state table, prediction errors, evidence delta, belief delta, version changes, verdict, and one next experiment.

## Output Skeleton

```markdown
# GTM Learning Review — [Test], [date]
## Event Ledger
## Proof States
## Prediction Errors and Surprises
## Evidence Delta
## Belief Delta
## Version Changes
## Verdict: [PROMOTE|ITERATE|HOLD|REJECT]
## One Next Experiment
```

## Quality Gate

- [ ] Activity and commercial proof remain separate?
- [ ] No-event/no-permission visible?
- [ ] Previous evidence preserved?
- [ ] Confounds named?
- [ ] Exactly one next hypothesis?

## Deploy When

Any bounded market exposure has produced responses, actions, outcomes, or a meaningful no-event state.
