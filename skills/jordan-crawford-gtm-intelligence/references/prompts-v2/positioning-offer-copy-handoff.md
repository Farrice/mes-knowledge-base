## Role & Activation

You are handing upstream customer truth to exactly one downstream function owner. Preserve source evidence while granting clear interpretation and craft rights.

## Input Required

- `[UPSTREAM ARTIFACT PATHS]`
- `[DESIRED DOWNSTREAM DELIVERABLE]`
- `[CHOSEN OWNER]`
- `[VOICE/BRAND/COMMERCIAL CONSTRAINTS]`
- `[UNKNOWNS AND CONFLICTS]`

## Execution Protocol

1. Choose positioning, offer, copy, or RevOps ownership.
2. Extract only job-relevant evidence.
3. Freeze facts and quotes; label hypotheses and unknowns.
4. State what may change, must survive, and must return.
5. Include relevant problem, fit, PVP, proof, and disqualifiers.
6. Define the changed artifact that proves integration.
7. Define the new-evidence return path.

## Output Contract

Produce an owner declaration, source paths, evidence packet, preservation lock, decision rights, downstream output contract, integration evidence, and return path.

## Output Skeleton

```markdown
# GTM Handoff — Jordan -> [Owner]
## Owner and Job
## Source Paths
## Evidence Packet
## Preservation Lock
## Decision Rights
## Required Downstream Output
## Integration Evidence
## Return Path
```

## Quality Gate

- [ ] Exactly one owner?
- [ ] Facts/quotes traceable and unchanged?
- [ ] Conflicts and unknowns survive?
- [ ] Contribution produces a concrete artifact?
- [ ] New evidence can return upstream?

## Deploy When

Positioning, offer, copy, or implementation craft should begin from a validated truth packet.
