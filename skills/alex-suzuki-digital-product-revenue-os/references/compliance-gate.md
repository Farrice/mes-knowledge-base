# Compliance & Ethics Gate

Cross-cutting guardrail for the Suzuki OS. **Load before any scaling, automation, partnership, affiliate, or claims-bearing output.** The OS extracts Suzuki's *mechanics*; it does not adopt his unverified claims or platform-risky tactics uncritically. Non-negotiable. Aligns with the system Factual Grounding Standard and the deterministic ethics-gate philosophy.

## 1. Claim Safety
- Every revenue/income figure from the source is a **creator claim** — label it; never repeat as a promise or as a result the buyer will get.
- Client/user outputs use **verified internal proof** only, or explicitly labeled assumptions.
- Banned: guaranteed-income language, "you will make $X", earnings implied as typical.
- Required when selling a money/business outcome: a plain earnings/results disclaimer.

## 2. Truthful Attribution (partnership / affiliate)
- Borrowed proof must be the partner's **real, documented** proof — never invented, never restated as yours.
- Disclose the partnership/affiliate relationship to the audience.
- Affiliate links carry clear **FTC-style disclosure** ("affiliate", "I earn a commission").
- Never impersonate the partner; post *with* attribution, not *as* a fabricated identity.

## 3. Platform ToS (automation + multi-account)
- Auto-DM only on an explicit opt-in trigger (the user liked/commented to ask for it). **Never** mass-DM cold or unsolicited users.
- Respect each platform's automation rules and rate limits; tools and limits change — verify current ToS before scaling.
- Multi-account carries platform risk: do not duplicate identical copy across accounts, do not manufacture fake engagement, keep accounts genuinely distinct.
- Always provide and honor an opt-out.

## 4. Niche / Offer Integrity
- "Teach people how to make money" content must deliver real, usable value — not a hollow loop selling the dream of selling the dream.
- Avoid regulated-claim landmines (financial / health / earnings) without proper disclaimers and, where needed, professional review.
- Decline or flag: get-rich-quick framing, fabricated scarcity, predatory targeting of the desperate.

## Gate Output (every risk-bearing run appends)
- **Claims ledger**: each figure → source / verified / assumption.
- **Disclosure block**: partnership / affiliate / earnings disclaimers as applicable.
- **Platform-risk note**: automation / multi-account exposure + the safer alternative.
- **Verdict**: SHIP / SHIP-WITH-DISCLOSURE / REVISE.

## Quick Reference — when this gate fires
| Tactic | Required disclosure / guard |
|---|---|
| Income/revenue figure | Creator-claim label + earnings disclaimer |
| Partner's proof | Real proof + partnership disclosure |
| Affiliate product | FTC affiliate disclosure |
| Auto-DM | Opt-in trigger only; opt-out honored |
| Multi-account | Distinct copy/identity; no fake engagement |
| Make-money niche | Real value delivered; no guarantees |
