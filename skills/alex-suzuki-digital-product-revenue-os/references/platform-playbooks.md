# Platform Playbooks — Native Revenue Funnels

Companion to `04-cross-platform-launch-adapter` (quick translate) and `/suzuki-platform-engine` (build native funnel from scratch). The X mechanism transfers as **structure, not wording**: `qualified hook → proof body → opt-in free asset → DM/auto-DM → trust → checkout or application`. Each platform changes the native asset, the opt-in trigger, and the automation surface. Load `compliance-gate.md` — automation rules differ per platform.

## Transfer Principle
Carries everywhere: buyer-quality over reach, opt-in free asset, two-lane CTA (curiosity vs. purchase), first-use path, claim safety.
Changes per platform: asset format, how the opt-in fires, how the DM is delivered (manual vs. native automation), and how proof is shown.

## X / Twitter (home base — reference)
- **Asset:** post or thread. **Opt-in:** like/comment keyword. **Automation:** scheduler + auto-DM on like/comment (`scaling-mechanics.md`). **Funnel:** comment → DM (free asset) → checkout (low-ticket) or community → application → call (high-ticket). **Edge:** low views, elite buyers, high $/post. **Risk:** mass-DM ToS — opt-in only.

## Instagram (flagship cross-platform)
- **Native assets:** carousel (teach the method in 6-10 slides), Reel (hook in 1s, value, CTA), Story (poll/question → DM).
- **Hook:** slide 1 / first second = buyer + result; carousel cover does the job the X first line does.
- **Free-asset delivery:** comment keyword → DM automation (e.g. ManyChat-class tool) sends the asset + link; or Story link sticker; or "DM me [WORD]".
- **Conversion trigger:** comment keyword (auto-DM), Story reply, link-in-bio, link sticker.
- **Funnel:** Reel/carousel → comment keyword → auto-DM free asset → nurture in DM → checkout (low) or application/call (high).
- **Replay:** repost winning carousel as Reel; Story-tease the case study; pin the offer highlight.
- **Risk:** automation tool ToS + link friction (bio/sticker). Disclose affiliate/partner. Keep DM opt-in.

## LinkedIn
- **Asset:** credibility-first text post or document (PDF carousel). **Hook:** authority + specific outcome, less hype. **Opt-in:** comment keyword or "DM me"; profile-featured link. **Funnel:** post → comment → DM/connection → resource → call/application. **Best for:** higher-ticket B2B, services, cohorts. **Risk:** over-promotion penalised; lead with proof and usefulness.

## YouTube (long + Shorts) — the proof engine
- **Asset:** long-form teardown / student interviews (his model: 20-30 min student journeys as social proof) + Shorts as hooks. **Opt-in:** description link, pinned comment, end-screen. **Funnel:** Short → long video → free community/lead magnet → application. **Edge:** long-form builds the trust that closes high-ticket; interviews = durable proof (claim-labeled). **Risk:** disclosure on income content; YT policy on get-rich-quick.

## TikTok / Reels
- **Asset:** 7-30s script + caption; hook in frame 1. **Opt-in:** comment keyword → DM; link in bio. **Funnel:** clip → comment/DM → free asset → low-ticket or community. **Edge:** reach volume (opposite of X — many views, lower buyer density) → use for top-of-funnel + low-ticket; route serious buyers off-platform. **Risk:** automation limits; claims policy.

## Threads
- **Asset:** short stack of posts (X-like, softer tone). **Opt-in:** reply keyword, profile link. **Funnel:** mirror X but expect lighter automation. **Use:** cheap replay surface for X winners.

## Substack
- **Asset:** essay + offer box / button. **Opt-in:** subscribe, reply, inline checkout link. **Funnel:** essay (proof + method) → free subscriber → paid product / paid tier. **Edge:** long-form trust + owned list. **Best for:** ebook/course/community where teaching sells.

## Email
- **Asset:** short sales email or mini case. **Opt-in:** reply keyword or checkout link. **Funnel:** the email IS the warm list — `scaling-mechanics.md`: a list is pre-paid traffic. **Use:** launch + replay; sequence the proof → objection → offer arc.

## Platform Selection Guide
| Goal | Lead platform | Why |
|---|---|---|
| Elite buyers, high $/post, low effort | **X** | Buyer density + auto-DM |
| Visual niche, broad + DM automation | **Instagram** | Carousel/Reel + comment-to-DM |
| B2B / services / high-ticket | **LinkedIn / YouTube** | Credibility + trust depth |
| Top-of-funnel volume, low-ticket | **TikTok / Reels** | Reach |
| Owned audience, teaching-sells | **Substack / Email** | List = pre-paid traffic |

## Per-Platform Output (what `/suzuki-platform-engine` must produce)
Source mechanism carried over · native asset (finished) · opt-in trigger in native form · DM/automation path + compliance note · two-lane intent routing · first-use + replay · proof/risk ledger.
