## Execution Protocol

Run all steps in sequence. This is a system build, not a single asset — do not stop at the first finished piece.

1. **Intent lock**: state product (or "none"), buyer, price target, proof available, platform(s), goal, timeline, launch style.
2. **Product/proof gate**: if `[PRODUCT]` is "none" or `[PROOF AVAILABLE]` is "none," run the sourcing decision rule — **no product + no proof → Partnership** (borrow a proven operator's real, disclosed proof, 30-50% split); **want a ready offer fast → Affiliate** (sell an already-validated product, disclose the relationship); **have expertise/proof → Build** (scope a fast digital product, page/module count, sample, price). Produce a concrete offer, not "ideas."
3. **Offer ladder + funnel**: choose low-ticket direct checkout (~$30-$500, trust from proof alone) vs. high-ticket free→application→call (typically $3K-$10K — free community/course → application → founder call → close, no closers). Match to price and buyer risk.
4. **Post engine**: build the finished sales post using the watch-grounded skeleton — transformation headline (two hard numbers, line 1) → enemy line (name the lazy default) → before→strip→after (bulleted) → invented proprietary named mechanism → payload freebie (3-5 named deliverables, each with a number/scale/duration/sample) → mechanical CTA (`Comment "KEYWORD" (must follow + RT so I can DM)`).
5. **Voice Edge Calibration Gate** (mandatory before proceeding — do not skip): run the post through three checks.
   - **Hedge Strip** — remove softening language ("might," "could," "I think maybe," stacked qualifiers before a claim). A cold-start post makes a claim and stands behind it.
   - **One Blunt Line Rule** — the post must contain at least one line an average reader would call opinionated, polarizing, or uncomfortably direct — the line most likely to be screenshotted or quote-tweeted. If every line is agreeable, rewrite one line to take a side.
   - **Screenshot Test** — "would a stranger who disagrees with part of this still repost it to argue?" If no, cut the most polite sentence and replace it with the sharpest true thing you'd say to a friend.
   This does not loosen claim-safety — bluntness and compliance are independent and both must pass.
6. **Platform funnel(s)**: build native funnel(s) for the chosen platform(s) (Instagram is flagship cross-platform; also LinkedIn, YouTube, TikTok, Threads, Substack, Email as needed). Transfer principle: `qualified hook → proof body → opt-in free asset → DM/auto-DM → trust → checkout or application` — only the native asset, opt-in trigger, and automation surface change per platform.
7. **Automation backbone**: separate create (batch-generate + mandatory human claim-edit gate) → schedule (cadence, queue, autopilot windows) → convert (auto-DM ONLY on an opt-in like/comment trigger — never cold mass-DM).
8. **Distribution**: manufacture first views for a cold account — a retweet/boost network or paid boost for the first 1-3 posts. Treat first-distribution as a required input, not luck.
9. **Launch mode**: evergreen automation (default per source) or a 24-72hr flash with honest scarcity only (real bonus expiry, real cohort cap, real price step — never fake countdowns or invented stock).
10. **Scale plan**: once one funnel works, plan additional accounts — the account (niche × proof source × offer) is the scaling unit, not the post.
11. **High-ticket asset** (if application-based): outline the 6-section mirrorboard — story/origin, case studies + proof, how it works, technical/tools, student results, the offer.
12. **Compliance pass** (whole system, mandatory): claims ledger (each figure → source/verified/assumption), disclosure block (partnership/affiliate/earnings as applicable), platform-risk note (automation/multi-account exposure + safer alternative), verdict (SHIP / SHIP-WITH-DISCLOSURE / REVISE).
13. **7-day action plan + one concrete action today.**

## Quality Gate

- Works with no starting product, proof, or following — the sourcing path is concrete, not "ideas."
- Every layer is present: offer → post → funnel → automation → distribution → launch → scale.
- The Sales Post passed all three Voice Edge Calibration checks (hedge strip, one blunt line, screenshot test) — a post that is purely agreeable has failed.
- No guaranteed-income language anywhere; every figure is claim-labeled or is the operator's own verified fact.
- Exactly one concrete action the operator can take today (not a list).
- If any section is a plan-with-no-finished-asset (post, funnel copy, DM scripts), it fails — go back and finish it before delivery.

## Creative Latitude

The mechanics (skeleton, gate, funnel shape) are the floor, not the ceiling. Push hard on: the **invented proprietary mechanism** — this is the single most-missed move in generic output; coin something that reads as owned IP, not generic advice ("the Faceless Skill Stack," not "a content system"). Find the **enemy line** that actually lands for this specific buyer's world, not a generic villain. Choose the **Blunt Line** so it is genuinely uncomfortable to the target buyer's self-image, not just mildly assertive. If the niche is claims-sensitive (affiliate, make-money-online), apply the compliant-grip swap — move all specificity off money and onto skills/outputs/time (see the "Faceless Skill Stack" exemplar: "went from a blank page to a published 6-piece content system in 9 days" instead of an income figure) — the grip must survive the swap.
