# Flash Launch (24-72hr)

## Use When
Run a time-boxed urgency launch for a digital product. This is the urgency complement to the evergreen default — for an always-on automated funnel, use `/suzuki-automate` instead.

> Source note: Suzuki's video-3 default is *evergreen automation*, not flash launches. The 24-hr window here is drawn from his general practice, videos 1-2, and standard launch craft — applied through the OS's claim-safety and honest-scarcity rules.

## Pre-Flight Gate
Scarcity must be honest. Allowed: a real time-boxed bonus, a genuine cohort cap, a real price step. Banned: fake countdowns, invented stock, fabricated "spots left." If the only urgency is fake, stop.

## Steps
1. **Pre-launch**: offer, proof, free asset, and distribution lined up (retweet boost if cold — `/suzuki-scale`). Auto-DM armed (`/suzuki-automate`).
2. **Hour 0 — launch post**: anatomy-built post (`/suzuki-post-lab`) + opt-in auto-DM live.
3. **Urgency mechanic**: pick ONE honest scarcity lever (bonus expiry, cap, price step). State it plainly.
4. **Reply sprint + proof drops**: work the window — deliver, answer objections, stack claim-labeled proof.
5. **Reminders**: mid-window and final-call replay frames (objection post, proof post, last-call post).
6. **Close + post-launch**: stop on time, deliver, map first-use, collect proof for the next launch.

## Content Type Adaptations
| Mode | Shape |
|---|---|
| Low-ticket flash | Direct checkout; bonus-expiry urgency; fast reply sprint |
| High-ticket sprint | Application window cap; founder calls; mirrorboard as the asset |
| Cohort open | Real seat cap + start date; close on fill or deadline |

## Output Format
```markdown
## Pre-Launch Checklist (offer, proof, distribution, auto-DM)
## Launch Calendar (Hour 0 / +6 / +24 / final)
## Hour-0 Launch Post
## Honest Urgency Mechanic
## Reply Sprint + Proof Drops
## Reminder Frames (mid / final)
## Close + First-Use + Proof Collection
## Claim / Risk Ledger
```

## Quality Gate
- Scarcity is real and stated plainly; no fabricated urgency.
- Opt-in DM; ready buyers have a purchase/application lane.
- Replay frames included (not a single post).
- First-use path + claim labeling present.
