# Proof And Authority Bank

## Use When
The offer needs credible proof before the sales post or funnel can work.

## Load First
- `../references/source-ledger.md`
- `../references/hidden-knowledge.md`

## Proof Types
| Proof Type | Examples |
|---|---|
| Product proof | Page count, modules, sample page, table of contents, demo |
| Process proof | How it was built, time saved, method steps |
| Buyer proof | Testimonials, beta notes, screenshots, call quotes |
| Outcome proof | Revenue, time saved, leads, conversion, before/after |
| Authority proof | Experience, client work, teardown skill, public artifacts |
| Risk proof | Refund rule, guarantee, support, fit criteria |

## Steps
1. Inventory existing proof.
2. Mark each proof item as verified, owned, assumed, or missing.
3. Pick the safest proof cue for the post.
4. Pick the proof cue for checkout.
5. Define the fastest proof collection action.

## Output Format
```markdown
## Proof Inventory
| Proof | Type | Status | Use |
|---|---|---|---|

## Best Post Proof
[One proof cue]

## Best Checkout Proof
[One proof cue]

## Missing Proof
[Gaps]

## Collection Action
[What to collect today]
```
