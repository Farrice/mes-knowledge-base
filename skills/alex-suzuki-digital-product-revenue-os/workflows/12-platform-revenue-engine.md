# Platform Revenue Engine

## Use When
You need a from-scratch, platform-native revenue funnel — Instagram (flagship), LinkedIn, YouTube, TikTok/Reels, Threads, Substack, or Email — not a copy-translate of an X post. For a quick translation of an existing X asset, use `/suzuki-cross-platform-launch` instead.

## Pre-Flight Gate
Confirm the target platform and the offer (buyer, price, proof, free asset). The transfer principle holds: `qualified hook → proof body → opt-in free asset → DM/auto-DM → trust → checkout or application`. Only the native asset, opt-in trigger, and automation surface change.

## Steps
1. **Select platform**; load its row in `platform-playbooks.md`.
2. **Lock offer**: buyer, price, proof, free asset, low- vs high-ticket path.
3. **Build the native asset**: carousel / Reel / document / essay / email / script — hook in native form (cover slide, first second, subject line).
4. **Opt-in + automation**: native opt-in trigger (comment keyword, Story reply, link sticker, reply) + DM/automation path, with the platform's compliance note.
5. **Funnel**: route to checkout (low-ticket) or community → application → call (high-ticket) per `funnel-map.md`.
6. **Two-lane routing** in native form (curiosity vs. purchase intent).
7. **First-use + native replay** templates for the platform.
8. **Proof / risk ledger** (what changed, what to verify, disclosures).

## Content Type Adaptations
| Platform | Native asset | Opt-in trigger | Automation note |
|---|---|---|---|
| Instagram | Carousel / Reel / Story | Comment keyword, Story reply, link sticker | Comment-to-DM tool; opt-in only |
| LinkedIn | Credibility post / PDF | Comment keyword, "DM me", featured link | Manual or compliant tool; lead with proof |
| YouTube | Long teardown + Shorts | Description link, pinned comment | Long-form builds high-ticket trust |
| TikTok / Reels | 7-30s script + caption | Comment keyword, link in bio | High reach, lower buyer density |
| Threads | Short stack | Reply keyword, profile link | Lighter automation |
| Substack | Essay + offer box | Subscribe, reply, checkout | List = pre-paid traffic |
| Email | Short sales email | Reply keyword, checkout | The email IS the warm list |

## Output Format


## Quality Gate
- The asset is native, not pasted X copy.
- Automation is opt-in and within the platform's ToS.
- Funnel after the click/comment stays intact; ready buyers have a paid lane.
- Decision asset and first-use path survive the platform change.
- Claims labeled; affiliate/partner disclosures present.
