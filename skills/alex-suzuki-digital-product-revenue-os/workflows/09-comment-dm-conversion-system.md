# Comment DM Conversion System

## Use When
The user needs the comment keyword, public replies, DM handoff, and follow-up sequence behind a post.

## Load First
- `../references/post-mechanics.md`
- `../references/funnel-map.md`
- `../references/revenue-mechanics.md`

## Steps
1. Pick the keyword: short, relevant, easy to type.
2. Pick a purchase-intent keyword or permission phrase for ready buyers.
3. Write public reply scripts for delivery, objection, proof, ready buyer, wrong fit, and urgency.
4. Write DM delivery scripts for cold, warm, ready, and wrong-fit buyers.
5. Write follow-up DM or email prompts for days 1, 3, and 7.
6. Add link disclosure and permission step before sending affiliate, checkout, or application links.
7. Add a compliance/risk note: do not spam, respect platform rules, and keep opt-outs clear.

## Quality Gate
- DM includes the promised asset.
- Next step is clear.
- Ready buyers have a permission-based path to link, checkout, application, or conversation.
- Wrong-fit buyers are protected from an over-eager sale.
- Follow-ups ask for score/context or next-step permission, not random nudges.
- Follow-up is useful, not pushy.
