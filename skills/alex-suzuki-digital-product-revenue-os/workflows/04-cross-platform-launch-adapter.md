# Cross-Platform Launch Adapter

## Use When
The X post mechanism needs to move to Instagram, LinkedIn, Substack, email, Threads, TikTok, or another selected platform. This is the *quick translator* of an existing X asset. To build a from-scratch native revenue funnel (deeper, per-platform mechanics), use `/suzuki-platform-engine` with `../references/platform-playbooks.md`.

## Platform Translation Rules
| Platform | Native Asset | Conversion Trigger |
|---|---|---|
| X | Post or thread | Comment keyword or DM |
| LinkedIn | Credibility post, document, or comment-to-DM | Comment keyword or profile link |
| Instagram | Carousel, Reel, Story, or DM automation | Comment keyword, Story reply, link sticker |
| Substack | Essay, note, offer box | Reply, subscribe, checkout link |
| Email | Short sales email or mini case | Reply keyword or checkout link |
| Threads | Short stack of posts | Reply keyword or profile link |
| TikTok/Reels | Script plus caption | Comment keyword, link in bio, DM |

## Steps
1. Identify the source X mechanism: hook, proof, free asset, CTA, funnel.
2. Select the native asset type for the platform.
3. Rewrite the hook in platform-native form.
4. Adapt proof display.
5. Adapt the value lane and purchase-intent lane to platform behavior.
6. Preserve the same decision asset, intent routing, and first-use path after the action.
7. Add native replay templates for the platform.
8. Add a platform-specific risk note.

## Output Format
```markdown
## Source Mechanism
[What carries over]

## Platform Choice
[Selected platform and native asset]

## Adapted Asset
[Finished platform-native post, carousel, email, note, or script]

## CTA And Follow-Up
[How the value lane and purchase lane move to DM/email/checkout/application]

## Intent Routing
[Cold, warm, ready, wrong-fit paths in platform-native form]

## First-Use And Replay
[First-use path plus replay posts/frames/scripts]

## Proof/Risk Notes
[What changed and what must be checked]
```

## Quality Gate
- The adapted asset should not sound like copied X copy.
- CTA should match platform behavior.
- Funnel after the click/comment/reply stays intact.
- Purchase-intent buyers still have a path to link, checkout, application, or conversation.
- The decision asset and first-use path survive the platform change.
