# Derive Shorts — long-form cutlist → 60-90s verticals

Beats make this cheap: shorts are re-cuts of the long-form cutlist, not new edits.
Load `skills/jenny-hoyos-shorts/` for the shorts grammar before picking beats.

1. **Pick the spike**: scan the long-form beats for the sharpest self-contained claim/payoff (hook skill judgment). A short leads with the claim — context dies.
2. **New cutlist**: `cutlist-shorts-NN.json`, preset `vert-916`, shots referencing the SAME sources with tighter in/outs. Hook ≤3s. Target 45-90s total.
3. **Re-frame**: v1 transcode is center-crop — for talking-head it holds; for screen recordings, prefer rebuilding those beats as vertical graphics instead of cropping.
4. **Captions**: `shorts-bold` style, ALWAYS burned. Wordlist applied.
5. Render → qa-probe → one QA-loop pass (shorts get 1 iteration, not 3) → export.
6. 3-5 shorts per long-form is the cadence target; log each as its own render chain.
