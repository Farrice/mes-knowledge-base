## Typography & graphics
- Graphics are front-end design: every graphic passes the house design bar (no default HTML styling, no unstyled `<div>` energy). Load the design stack before building any comp.
- One display face + one text face per video, declared in the brand file. Never introduce a third mid-video.
- Graphic types are NAMED (title-card, stat-card, lower-third, diagram, quote-card) — a beat asks for a type, not a vibe.
- Safe margins: nothing text-bearing inside 4% of any edge; lower-thirds sit at 72% height.
- One idea per graphic. A graphic needing a paragraph is a diagram beat, not a card.

## Pacing (cite skills/remotion-video-creation/rules/high-retention-editing.md)
- Hook lands inside 5s. No shot overstays: talking-head segments ≤8s without a visual change (cut, punch-in, graphic, B-roll).
- Cut on word boundaries, on motion where possible. Silence >0.7s dies in the rough cut unless marked `[beat: hold]`.
- Cut rhythm is uneven on purpose — staccato for hooks/montage, measured for explanation, legato for story beats.

## Captions
- Platform presets in `caption-styles.json` — never freestyle ASS styles.
- LinkedIn: ALWAYS burned. Shorts: burned by default. YouTube long-form: sidecar SRT unless the brand file says burn.
- Captions never cover a face or a graphic's text zone. Brand wordlist corrections applied to the SRT before burning.

## Audio
- Final mix −14 LUFS integrated, true peak ≤ −1.5 dBTP. Music beds ducked under VO (sidechain), default −18 dB bed gain.
- No audible level jumps between shots; crossfade audio at every xfade.
- SFX are cues, not decoration — only where the annotation asks.

## B-roll
- Ladder order is law (broll-ladder.md). 2-6s inserts, cut on motion, never lip-sync generated plates.
- Grade/energy must match the main track; a mismatched insert is a blocker.
