# The Content Sprint — Weekly Content Production Engine

> One command → one week of platform-native content. Mine, map, draft, test, gate, distribute.

---

## When to Use

- Your brand is built and you need a repeatable weekly production system
- You want to stop "figuring out what to post" every week
- You need content that's strategically mapped to customer pain, not random inspiration
- You want to make sure every piece passes quality tests before publishing
- Run this weekly, ideally on the same day (e.g., "Content Sprint Monday")

## What You'll Produce

1. **5-7 content concepts** mapped to customer pain problems
2. **Platform-native drafts** for each piece (YouTube, short-form, Instagram, newsletter)
3. **4C intros** for any video content
4. **Short-form test versions** (Accordion method) for untested concepts
5. **Quality gate scorecard** for every piece before publishing
6. **Distribution map** — which piece goes where and when

## Workflow

### Step 1: Mine Wrapping Paper (10 min)

Pull from your wrapping paper library + this week's scroll.

**Quick scroll protocol:**
1. Spend 10 minutes scrolling 3-5 niches OUTSIDE your space
2. Save anything that stops your scroll (thumbnail, hook, format, transition)
3. Tag with: What specifically stopped me? Hook structure? Visual? Format?

**Select 2-3 wrapping paper assets for this week's content:**
- A hook structure to adapt
- A visual/format to try
- A delivery style to experiment with

### Step 2: Map Customer Pain → This Week's Content (15 min)

**From your 5 customer pain problems, select this week's focus:**

| # | Content Concept | Pain Problem # | Platform | Format | Wrapping Paper |
|---|----------------|---------------|----------|--------|----------------|
| 1 | [specific concept] | [1-5] | [primary] | [type] | [from Step 1] |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

**Rules:**
- At least 2 pieces must address different pain problems (no single-pillar weeks)
- At least 1 piece must use a fresh wrapping paper format from Step 1
- At least 1 piece must be designed for cold audience (Pattern 8)
- Rotate contrarian positions — don't hammer the same take every week

### Step 3: Draft Content with 4C Intros

**For each content piece, write:**

**A. The 4C Intro (for video content):**
1. **Credibility**: "[Specific result/credential]"
2. **Connection**: "[Human detail that makes you relatable]"
3. **Contrarian**: "[What you believe differently]"
4. **CTA**: "[What to do if this resonates]"

**B. The Content Body:**
1. State the painful problem (name it specifically)
2. Explain why the common solution fails (contrarian angle)
3. Share your unique approach with a specific example
4. Give one actionable takeaway they can use TODAY
5. Close with trust-building CTA (not salesy — DM-oriented)

**C. The Wrapping Paper Layer:**
- For video: What B-roll, environment, or visual context?
- For written: What structural format (list, story, breakdown)?
- For carousel: What slide-by-slide hook flow?

### Step 4: Accordion Test (for untested concepts)

**For any concept you haven't validated before:**
1. Create a 30-60 second short-form version FIRST
2. Post as a Reel/Short/TikTok
3. Track: saves, shares, DMs, comments with specific questions
4. **Signal threshold:** 2.5x your average engagement = green light for long-form
5. **No signal:** Don't invest in long-form. Try different wrapping paper for the same concept, or shelve it.

**For validated concepts (previously tested via accordion):**
- Skip directly to long-form production
- Reference which short-form piece validated it

### Step 5: Quality Gate (Every Piece, No Exceptions)

**Run each content piece through all 9 quality tests:**

| Test | Question | Pass/Fail |
|------|----------|-----------|
| **Text Test** | Would I text this to friends whose opinions I respect? | |
| **Cold Viewer Test** | Can someone with zero context understand this completely? | |
| **Buyer Signal Test** | Am I tracking DMs, not just likes? | |
| **Prison Test** | Will I still believe this contrarian position in 5 years? | |
| **Pluribus Test** | Could this have been written by any of the last 50 posts in my niche? | |
| **Big Cola Test** | Does this feel like a grocery store knockoff of a major influencer? | |
| **Champagne Problems Test** | Am I showing human frustration, not lifestyle signal? | |
| **4C Completeness** | Does the intro hit all 4 C's within 30 seconds? | |
| **Accordion Test** | Did I validate this concept before investing in long-form? | |

**Scoring:**
- 9/9 passes → publish immediately
- 7-8/9 → fix the failing tests, then publish
- 6 or fewer → rewrite or shelve. Something fundamental is off.

### Step 6: Platform Distribution Map

**Assign each final piece to its purpose platform:**

| Piece | Platform | Purpose | Publish Day | CTA Type |
|-------|----------|---------|-------------|----------|
| [Concept 1] | YouTube | Trust | [day] | Subscribe + DM |
| [Concept 1 short] | Reels/TikTok | Discovery | [day-1] | Bio link |
| [Concept 2] | LinkedIn | Authority | [day] | Comment engagement |
| [Concept 3] | Instagram feed | Conversion | [day] | DM keyword |
| [Week recap] | Newsletter | Depth | Friday | Hit reply |

**Distribution timing rules:**
- Post short-form versions 1-2 days BEFORE long-form (build anticipation)
- YouTube on a consistent day each week (algorithm consistency)
- Instagram stories: daily wrapping paper content (B-roll of real life)
- Newsletter: end of week when audience has seen your content

## Post-Sprint Review (Run Friday)

Spend 15 minutes reviewing the week:
1. Which piece got the most DMs? → That's your strongest pillar this week
2. Which wrapping paper format performed? → Add to your proven formats
3. Any 2.5x+ outlier? → Accordion-expand for next week
4. Any piece that flopped? → Why? Wrong pain? Wrong wrapping? Wrong platform?
5. Update your wrapping paper library with this week's findings

Feed insights into next week's sprint.
