## Step 1: Show Format Discovery

Find the format by working backward from what your audience wants to RETURN TO:

### The Return Engine Test
> "What would make someone set a reminder to consume your content at the same time every week? What creates that 'new episode of my favorite show' feeling?"

**Prompt the user through three format archetypes:**

| Archetype | Structure | Example | Best For |
|----------|-----------|---------|----------|
| **The Investigation** | Each episode investigates a question, person, or phenomenon | "How [Brand X] actually makes money" — each episode deconstructs one company | Trust district — builds authority through analysis |
| **The Conversation** | Each episode features a different guest/perspective on a recurring theme | "Founder Confessions" — unscripted conversations about what founders really think | Connection district — builds resonance through human stories |
| **The Laboratory** | Each episode tests, experiments, or builds something live | "30 days of running ads for $0" — each episode shows one day/attempt | Trust + Attention — builds credibility through demonstration |
| **The Anthology** | Each episode is self-contained but follows a recurring format/structure | "In 5 Minutes" — each episode explains one complex topic in exactly 5 minutes | Discoverability — consistent format makes discovery easy |
| **The Documentary** | Multi-episode deep dive into a single topic/story | "The Complete Story of [Topic]" — serialized documentary | Trust — high production value, high investment reward |

### Format Selection

Choose ONE primary format and define:
- **Show name**: [Memorable, brandable, searchable]
- **Format archetype**: [From above]
- **Episode length**: [Consistent — same duration every episode builds expectation]
- **Release cadence**: [Weekly is the minimum for show momentum]
- **Infinite well test**: Can this format sustain 100+ episodes without running dry? If not, it's a series, not a show.

## Step 2: Series Bible Construction

Create the reference document that keeps every episode consistent:

### Show Identity
```
SHOW NAME: [Name]
TAGLINE: [One sentence — the show's promise]
GRAND CENTRAL CONNECTION: [How this show routes through your city's core mission]
FORMAT: [Archetype + specific structure]
PLATFORM: [Primary + distribution]
CADENCE: [Day + time of release]
TARGET EPISODE COUNT: [First season commitment — minimum 12 episodes]
```

### Tone & Personality
- **Show voice**: [How does the show "sound"? Distinct from your brand voice — a show CAN have its own personality]
- **Visual identity**: [Thumbnail style, colors, fonts — must be instantly recognizable]
- **Audio identity**: [Intro music, sound design, voice treatment]
- **Energy arc**: [How does energy flow within each episode? Start high → go deep → end on a high? Start quiet → build?]

### Recurring Elements
Every show needs "Pavlovian triggers" — elements that create recognition and anticipation:

| Element | Description | Purpose |
|---------|------------|---------|
| **Cold open** | [How every episode opens — the signature first 30 seconds] | Creates the "oh, a new episode!" feeling |
| **Intro sequence** | [The consistent intro — music, title card, voiceover] | Recognition signal |
| **Signature segment** | [A recurring segment within episodes] | Creates within-episode anticipation |
| **Running gag/reference** | [An in-joke or reference that rewards loyal viewers] | Community-building |
| **Closing ritual** | [How every episode ends — consistent sign-off] | Emotional closure + habit |
| **Preview tease** | [End-of-episode hint at next episode] | Creates inter-episode anticipation |

### Episode Structure Template
Define the minute-by-minute (or section-by-section) structure:

```
[0:00 - 0:30] COLD OPEN — [Most compelling moment from this episode, pulled forward]
[0:30 - 1:00] INTRO — [Title sequence + episode context]
[1:00 - X:00] ACT 1 — [Setup: introduce this episode's topic/guest/experiment]
[X:00 - Y:00] ACT 2 — [Core content: the meat of the episode]
[Y:00 - Z:00] SIGNATURE SEGMENT — [The recurring element]
[Z:00 - end-2:00] ACT 3 — [Resolution/key takeaway/results]
[end-2:00 - end] CLOSE — [Closing ritual + preview tease + CTA]
```

## Step 4: Pilot Episode Design

Design the pilot episode in full — this sets the quality ceiling:

### Pilot Objectives
1. **Prove the format works** — is the structure engaging from minute 1 to the end?
2. **Set the quality bar** — every future episode is measured against the pilot
3. **Create viral potential** — the pilot should be the easiest episode to share
4. **Establish recurring elements** — introduce the Pavlovian triggers from the Series Bible

### Pilot Episode Blueprint
```
EPISODE: Pilot — [Title]
TOPIC/GUEST: [The strongest possible first topic/guest]
COLD OPEN: [Write the exact first 30 seconds]
KEY INSIGHT: [What's the one thing the audience MUST remember?]
HOOK: [The hook that sells this episode before they press play]
MEMORABLE MOMENT: [The one scene designed to be clipped/shared]
CLOSING TEASE: [How you set up Episode 2 — "Next week, we..."]
```

**Quality gate**: The pilot must pass the "tell a friend" test. After consuming the pilot, would someone TEXT a friend "you have to check this out"? If not, revise.

## Step 5: Season Architecture

Plan the first 12 episodes as a "season":

| Episode | Topic/Guest | Key Insight | Callback (from previous episodes) |
|---------|------------|-------------|----------------------------------|
| 1 (Pilot) | [Strongest possible] | [Foundational insight] | N/A |
| 2 | [Topic] | [Insight] | [References Pilot] |
| 3 | [Topic] | [Insight] | [References Ep 1-2] |
| ... | | | |
| 6 (Mid-season) | [SPECIAL — bigger guest, bolder topic, or format twist] | [Major insight] | [Pulls threads from 1-5] |
| ... | | | |
| 12 (Season finale) | [Biggest/boldest] | [Synthesis insight] | [All threads converge] |

**Pacing rules**:
- Episodes 1-3: Establish the format — audience should know exactly what this show IS
- Episode 6: Mid-season escalation — something unexpected to re-energize
- Episode 12: Season payoff — reward loyal viewers with synthesis/revelation/celebration
