# Workflow 15: Emotional Residue Engineer

> **Genius Pattern**: GP-9 (Emotional Residue Engineering)
> **Purpose**: Most content informs. Some content entertains. The content that builds trust does neither — it creates emotional residue: the sentence, story, or insight that "stays in your soul" after the audience closes the tab. This workflow designs that moment deliberately, then builds the content architecture around it.

## Pre-Flight Check

Before starting:
- [ ] You have a content concept or draft to apply this to
- [ ] The content piece has a trust pathway tag (from Workflow 02)
- [ ] genius.md has been read this session

---

## Step 1: The 48-Hour Memory Test (Signature Move)

Before designing the residue moment, test whether one already exists:

> **"If someone consumes this content, will they remember a specific moment 48 hours later?"**
> **"Will they tell someone about that moment?"**

| Answer | Classification | Action |
|--------|---------------|--------|
| Both "yes" | **Memorable Minutes** — residue already exists | Go to Step 3 (identify and amplify) |
| One "yes" | **Almost Memorable** — residue is latent | Go to Step 2 (design the moment) |
| Both "no" | **Forgettable Seconds** — no residue potential | Either redesign the concept or accept it as an entry-point piece and reduce production investment |

## Step 2: Residue Moment Design

Every piece of content gets ONE sticking moment. Here's how to find it:

### 2A: The Residue Candidates

Generate 5 potential residue moments by completing each frame:

1. **The Reversal**: "The thing everyone believes about [topic] is actually backwards because ___"
2. **The Confession**: "What I've never admitted about [topic] is ___"
3. **The Crystallization**: "The simplest way to explain [complex thing] is ___"
4. **The Gut Punch**: "The real cost of [common behavior] is ___ and here's exactly what that looks like"
5. **The Permission Slip**: "The thing you're secretly wondering about [topic] is ___. The answer is ___"

### 2B: The Residue Selection Filter

Score each candidate on three criteria (1-10):

| Candidate | Emotional Charge (does it CREATE a feeling?) | Specificity (vivid enough to remember?) | Tell-Worthiness (would someone repeat this?) | TOTAL |
|-----------|----------------------------------------------|----------------------------------------|----------------------------------------------|-------|
| Reversal | | | | |
| Confession | | | | |
| Crystallization | | | | |
| Gut Punch | | | | |
| Permission Slip | | | | |

**Winner** = highest total score. If no candidate scores >21/30 total, your concept may be too generic — return to ideation.

## Step 3: Content Architecture Around the Moment

The entire content piece serves the residue moment. Build the architecture:

```
RESIDUE ARCHITECTURE
The Moment: [One sentence — the residue moment itself]
Placement: [Where in the piece does it land? Beginning / middle / end?]
  - Beginning: Confession openers, reversal hooks. Use when the residue moment IS the hook.
  - Middle: After context-setting. Use when the audience needs context to feel the weight.
  - End: Crystallizations, permission slips. Use when the moment needs emotional buildup.

Buildup: [What comes before the moment that makes it land harder?]
  - What context, story, data, or tension builds toward this moment?
  
Afterglow: [What comes after the moment to let it breathe?]
  - Short paragraph? Silence? A pause? A question that lets the moment echo?
  - RULE: Never rush past the residue moment. Let it land.

Supporting Material: [Everything else in the piece that supports but doesn't compete with the moment]
  - RULE: The rest of the piece should be good, but the residue moment should be the BEST part.
  - If a supporting section is more memorable than the planned residue moment, swap them.
```

## Step 4: Residue Type Classification

Which type of emotional residue are you engineering?

| Residue Type | What It Does | Best For | Trust Stage |
|-------------|-------------|----------|-------------|
| **Identity Mirror** | "This person gets me" | Connection | Connection / Trust |
| **Possibility Expansion** | "I never thought of it that way" | Discoverability / Attention | Attention / Discoverability |
| **Competence Trust** | "This person clearly knows what they're talking about" | Trust | Trust |
| **Emotional Solidarity** | "Someone finally said what I was thinking" | Connection | Connection |
| **Action Ignition** | "I need to change something right now" | Conversion (soft) | Trust / Conversion |

**Tag the piece**: Your residue moment is type ___ and serves trust stage ___. Cross-reference with Workflow 02 to verify alignment.

## Step 5: Relief-Seeking Compliance Check (HK-4)

> People don't go to social media to be sold to. They seek relief and entertainment.

Before publishing, verify your content satisfies the relief/entertainment need BEFORE deploying the residue moment:

- [ ] **Relief Check**: Does the first 20% of this content provide some form of relief (entertainment, validation, curiosity satisfaction)? If no → add a relief element before the residue moment
- [ ] **Selling Guard**: Does anything in this piece feel like selling BEFORE the residue moment lands? If yes → remove or reposition
- [ ] **Energy Test**: If I'm the audience, do I feel BETTER after consuming this, or do I feel like I was used? → If "used," the piece fails regardless of how good the residue moment is

---

## Quality Gate

The piece is ready only when:
- ✅ Passes the 48-Hour Memory Test (both questions = "yes")
- ✅ ONE residue moment identified and scored ≥21/30
- ✅ Content architecture built around the moment (buildup + placement + afterglow)
- ✅ Residue typed and trust-stage aligned
- ✅ Relief-seeking compliance verified
