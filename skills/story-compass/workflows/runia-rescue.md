# /runia-rescue — The Mid-Creation Rescue Protocol

When you're lost in the middle of creating something — the draft is meandering, the video has no direction, the copy is going nowhere — use the compass to diagnose what's wrong and get back on track.

## Pre-Flight Gate

Load `skills/story-compass/genius.md` — Pattern 7 (Compass Return), Pattern 1 (Topic-to-Story Binary), Anti-Patterns.

## Input Required

- **The stalled content**: The draft, script, outline, or description of what you're working on
- **Where you're stuck**: What specifically feels wrong (optional — the diagnostic will find it)

## Execution

### Step 1: Reverse-Engineer the Compass

From the existing content, attempt to extract:
- **Want**: What was this piece supposed to deliver?
- **Tension**: What resistance was supposed to build engagement?
- **Change**: What was supposed to be different at the end?

Write the implied compass sentence: "I wanted ___, but ___, until ___."

### Step 2: Diagnose the Failure

Most mid-creation stalls fall into one of these patterns:

| Diagnosis | Signal | The Problem |
|-----------|--------|------------|
| **No Compass** | You never had one | You started creating without a story — you have a topic tour |
| **Lost the Compass** | You had direction but drifted | The piece has accumulated content that doesn't serve the compass |
| **Weak Want** | Direction is unclear | The audience doesn't know what they're rooting for |
| **Missing Tension** | Everything is smooth | Nothing is unresolved — there's no reason to keep reading/watching |
| **No Change** | Building toward nothing | The ending will be the same energy as the beginning |
| **Tension Without Resolution** | All conflict, no payoff | You piled on problems but never designed the mechanism of change |
| **Circular Content** | Going in circles | Every new section/scene restates the same point without advancing |
| **Scope Creep** | Too many stories | Multiple compass sentences competing — the piece tries to do too much |

### Step 3: Prescribe the Fix

For each diagnosis, apply the specific remedy:

**No Compass** → Stop. Write the compass sentence before touching the content again. Then restructure.

**Lost the Compass** → Pin the compass at the top. Read every paragraph/scene. Mark anything that doesn't serve the want, tension, or change. Cut it.

**Weak Want** → Rewrite the opening to make the want visceral and specific.

**Missing Tension** → Run `/runia-tension-dig` on the existing content. Find the buried tension.

**No Change** → Run `/runia-change-engineer`. Design the ending before continuing the middle.

**Tension Without Resolution** → Jump to the ending. Write the change FIRST. Then revise the buildup to earn it.

**Circular Content** → Number every section. Each must advance ONE element (deepen tension OR move toward change). If it repeats → merge or cut.

**Scope Creep** → Write separate compass sentences for each story you've accidentally included. Choose ONE. Kill the rest or save them for separate pieces.

### Step 4: Restructure

With the diagnosis and fix applied, restructure the content:

1. Pin the compass sentence
2. Map every existing section to: serves Want / serves Tension / serves Change / serves nothing
3. Cut everything that serves nothing
4. Identify gaps: Where does tension need to build more? Where does change need to land harder?
5. Fill the gaps, guided by the compass

### Step 5: Restart with Clarity

Produce a brief action plan for completing the piece:
- What to keep
- What to cut
- What to add
- Where the compass should be most visible

## Output Requirements

```
REVERSE-ENGINEERED COMPASS:
"I wanted ___, but ___, until ___."
Compass Strength: [1-10]

DIAGNOSIS:
[Primary failure pattern] — [specific evidence from the content]

PRESCRIPTION:
[Specific fix with action steps]

TRIAGE MAP:
✓ KEEP: [sections/beats that serve the compass]
✗ CUT: [sections/beats that don't serve anything]
+ ADD: [what's missing]

ACTION PLAN:
[Step-by-step to complete the piece]
```

## Quality Gate

- [ ] Diagnosis is specific (not just "it's not working")
- [ ] Prescription is actionable (not just "make it better")
- [ ] The compass sentence is now clear and strong
- [ ] Every remaining section serves the compass
- [ ] The path to completion is visible
