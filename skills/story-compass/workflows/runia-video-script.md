# /runia-video-script — Compass to Video Script

Take a completed compass sentence and expand it into a full video script structure with scene breakdowns, beat timings, and shot direction. Optimized for YouTube, Reels, and TikTok.

## Pre-Flight Gate

Load `skills/story-compass/genius.md` — Pattern 7 (Compass Return), Pattern 11 (Specificity Escalator), Quality Rubric.

**Prerequisite**: A compass sentence must exist. If not, run `/runia-compass` first.

## Input Required

- **Compass sentence**: The completed "I wanted ___, but ___, until ___"
- **Platform**: YouTube (long-form), Reels/TikTok (short-form), or both
- **Duration target** (optional): 3 min, 8 min, 15 min, 60 sec, etc.

## Execution

### Step 1: Decompose the Compass

Break the compass sentence into structural beats:

| Beat | Compass Element | Purpose |
|------|----------------|---------|
| **Opening** | The Want (set up desire) | Why should the audience care? |
| **Escalation** | The Tension (introduce resistance) | What's stopping this from being easy? |
| **Deepening** | Tension intensified | The moment it gets real |
| **Turn** | The shift begins | What started to change? |
| **Resolution** | The Change (mechanism revealed) | How was the tension resolved? |
| **Resonance** | The meaning | What does this mean for the viewer? |

### Step 2: Build the Script Structure

**For YouTube (Long-form 5-20 min):**

```
HOOK (0:00-0:30):
[Open with the tension — not the want. Drop the viewer INTO the problem.]

SETUP (0:30-2:00):
[Establish the want. Make the audience align their desire with yours.]

TENSION BUILD (2:00-[midpoint]):
[Show the resistance. Internal + external. Specific details. The audience needs to FEEL the obstacle.]

THE TURN ([midpoint]):
[The dig moment — what started to shift? The first crack in the pattern.]

RESOLUTION ([midpoint]-[near-end]):
[The change. The mechanism. Show, don't tell.]

CLOSE ([last 30-60 sec]):
[The compass sentence restated through the lens of someone who's been through it. What does the viewer take away?]
```

**For Reels/TikTok (Short-form 30-90 sec):**

```
HOOK (0:00-0:03): [Tension first — drop into the problem]
WANT (0:03-0:08): [One line — what you wanted]
TENSION (0:08-0:25): [The obstacle — fast, specific, visual]
CHANGE (0:25-0:45): [The mechanism — the realization or action]
PAYOFF (0:45-0:60): [The result + the compass sentence as voiceover]
```

### Step 3: Script the Key Beats

For each beat, write:
- **Visual direction**: What the viewer SEES
- **Audio/voiceover**: What the viewer HEARS
- **Emotional target**: What the viewer FEELS

### Step 4: Compass Check

Pin the compass sentence and verify every beat serves it:
- Does the opening make the audience invest in the WANT?
- Does the middle build unresolved TENSION?
- Does the ending deliver satisfying CHANGE?
- Is anything in the script that doesn't serve the compass? → Cut it.

## Content Type Adaptations

| Platform | Hook Style | Pacing | Key Difference |
|----------|-----------|--------|---------------|
| **YouTube** | Start with tension, not want | Slow build, earned payoff | Time for depth — show the full dig |
| **Reels** | Tension as first frame/word | Compressed — every second counts | Change must be instant and visual |
| **TikTok** | Pattern interrupt + tension | Fastest possible — hook in 1 sec | Use text overlays for speed |
| **Documentary** | Cold open on the tension moment | Patient, atmospheric | Visual storytelling carries the weight |

## Output Requirements

```
COMPASS SENTENCE: [restated for reference]

SCRIPT STRUCTURE:
[Beat-by-beat breakdown with timecodes]

KEY SCENES:
[2-3 most important moments with visual + audio direction]

COMPASS CHECK:
✓ Every beat serves the compass
✓ Nothing extraneous
✓ Emotional arc tracks Want → Tension → Change
```

## Quality Gate

- [ ] Every beat traces back to the compass sentence
- [ ] Tension is visual and specific, not narrated abstractly
- [ ] Change has a clear mechanism, not just a result
- [ ] Script would work even without the voiceover (visual storytelling)
