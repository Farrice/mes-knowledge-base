# /runia-series-compass — The Series Arc Architect

Design multi-part content series (video series, newsletter arcs, LinkedIn series, podcast seasons) where each episode has its own compass AND the overall series has a master compass. The audience feels each piece is complete while being pulled through the full arc.

## Pre-Flight Gate

Load `skills/story-compass/genius.md` — Pattern 6 (Compass Sentence), Pattern 8 (Positive Tension Recognition), Pattern 9 (Progressive Refinement).

## Input Required

- **Series topic/theme**: What the series is about
- **Episode count**: How many parts (3-12 typical)
- **Platform**: Where this lives (YouTube, newsletter, LinkedIn, podcast)
- **Audience journey**: Where the audience starts → where they should end up

## Execution

### Step 1: Build the Master Compass

The entire series needs ONE overarching compass sentence that spans all episodes:

> **"We set out to [SERIES WANT], but [SERIES TENSION — the ongoing resistance], until [SERIES CHANGE — the cumulative transformation]."**

This is the compass for the ARC. Individual episodes are chapters within it.

### Step 2: Design the Tension Escalation

The series-level tension should ESCALATE across episodes. Not repeat — escalate.

```
Episode 1: Tension introduced (surface level)
Episode 2-3: Tension deepens (internal dimensions revealed)
Episode 4-5: Tension compounds (new layers, higher stakes)
Episode 6-7: Tension peaks (maximum resistance, darkest moment)
Episode 8+: Tension begins to resolve (change emerges)
Final Episode: Resolution (full change achieved)
```

### Step 3: Design Per-Episode Compasses

Each episode gets its own compass sentence that:
- Is complete on its own (the episode is satisfying alone)
- Advances the master compass (moves the series arc forward)
- Ends with a tension handoff (something unresolved that pulls into the next episode)

| Episode | Episode Compass | Advances Master By | Tension Handoff |
|---------|----------------|-------------------|----------------|
| 1 | "I wanted ___, but ___, until ___" | [how it moves the arc] | [what's unresolved] |
| 2 | "I wanted ___, but ___, until ___" | [how it moves the arc] | [what's unresolved] |
| ... | | | |
| Final | "I wanted ___, but ___, until ___" | [resolves the master compass] | None — full resolution |

### Step 4: Design the Between-Episode Pull

What makes someone come back for the next episode?

**Cliffhanger Model**: End each episode at the moment of maximum tension before the change
**Progress Model**: Each episode resolves its own compass but reveals a deeper layer of the master tension
**Anticipation Model**: Each episode builds toward a known event — the audience is counting down
**Mystery Model**: Each episode answers one question but raises a bigger one

### Step 5: Validate the Arc

Test the complete series:
- [ ] Master compass is clear and compelling
- [ ] Each episode compass is self-contained
- [ ] Tension escalates (not flat, not repetitive)
- [ ] Each episode advances the master arc
- [ ] The final episode resolves the master compass satisfyingly
- [ ] The between-episode pull is designed (not accidental)

## Content Type Adaptations

| Series Type | Master Compass Style | Episode Compass Style | Pull Mechanism |
|------------|---------------------|----------------------|---------------|
| **YouTube series** | Big transformation journey | Individual challenges/experiments | Cliffhanger + progress |
| **Newsletter arc** | Intellectual journey of discovery | Each issue = one insight building on the last | Mystery + progress |
| **LinkedIn series** | Professional transformation | Each post = one lesson/story | Progress + anticipation |
| **Podcast season** | Deep investigation | Each episode = new angle on the same question | Mystery |
| **Course/educational** | Skill acquisition journey | Each module = one capability unlocked | Progress + anticipation |

## Quality Gate

- [ ] Master compass sentence is one line
- [ ] Each episode compass is one line
- [ ] Tension escalates (not flattens or repeats)
- [ ] Each episode is satisfying alone AND advances the arc
- [ ] The final episode earns its resolution
