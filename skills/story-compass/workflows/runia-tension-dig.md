# /runia-tension-dig — The Tension Excavation Engine

When an idea feels interesting but has no obvious tension, this workflow systematically digs for the hidden story. Every interesting idea has tension hiding inside it — you just have to find it.

## Pre-Flight Gate

Load `skills/story-compass/genius.md` — Pattern 3 (Tension Excavation), Pattern 4 (Internal/External Split), Pattern 8 (Positive Tension Recognition).

## Input Required

- **The flat idea**: The topic that feels interesting but has no obvious conflict, obstacle, or tension
- **The want** (if known): What the person/audience desires

## Execution

### Step 1: Confirm the Flatness

Verify this idea currently fails the story test — it has a want but no tension. If tension is already present, redirect to `/runia-compass`.

### Step 2: Run the Dig Protocol (6 Questions)

Ask each question about the idea/experience/topic:

1. **What didn't go as planned?** — Surface-level friction, unexpected turns
2. **What was uncomfortable or unfamiliar?** — Fish-out-of-water moments, vulnerability
3. **What was worth remembering?** — The moments that stuck — often tension in disguise
4. **What almost didn't happen?** — Near-misses, close calls, last-minute saves
5. **What made you (or the subject) want to quit?** — The breaking point, the threshold
6. **What assumption turned out to be wrong?** — The gap between expectation and reality

### Step 3: Classify Tension Candidates

For each tension surfaced, classify:

| Tension Candidate | Type | Strength (1-10) | Causal Link |
|-------------------|------|-----------------|-------------|
| [description] | Internal / External / Anticipation | | Does this cause another tension? |

### Step 4: Select the Primary Tension

Choose the tension that:
- Is most visceral and picturable
- Creates the strongest "need to see how it ends" force
- Connects most naturally to the want
- Has the most potential for meaningful change

If dual tension exists (external triggers internal or vice versa), note the causal chain — this creates depth.

### Step 5: Test the Dig

With the newly excavated tension, run a quick Story Test:
- Want: [original want]
- Tension: [excavated tension]
- Change: [does a change now suggest itself?]

If all three are present → produce the compass sentence.
If change is still missing → hand off to `/runia-change-engineer`.

## Content Type Adaptations

| Content Type | Best Dig Approach | Tension Sweet Spot |
|-------------|------------------|-------------------|
| **Personal story** | Questions 2, 5 (vulnerability, breaking point) | Internal tension — what you FELT |
| **Tutorial/how-to** | Questions 1, 6 (things that went wrong, wrong assumptions) | External tension — what BLOCKED progress |
| **Review/comparison** | Question 6 (assumptions that were wrong) | Expectation vs. reality gap |
| **Trend/culture piece** | Questions 3, 6 (worth remembering, wrong assumptions) | Intellectual tension — what everyone's missing |
| **Client case study** | Questions 1, 4 (problems, near-misses) | External tension with internal doubt |

## Output Requirements

```
DIG RESULTS:
[List of tension candidates with classification and strength scores]

PRIMARY TENSION SELECTED:
[Description] — [Internal/External/Anticipation]
Why this one: [rationale]

UPDATED STORY TEST:
Want: [✓/✗]
Tension: [✓ — newly excavated]
Change: [✓/✗ — does one suggest itself?]

COMPASS SENTENCE (if all three present):
"I wanted ___, but ___, until ___."

NEXT STEP: [/runia-compass or /runia-change-engineer]
```

## Quality Gate

- [ ] At least 3 dig questions produced usable tension
- [ ] Primary tension is specific, not abstract ("I couldn't read a single sign" not "it was challenging")
- [ ] Tension type correctly classified
- [ ] If dual tension exists, causal relationship identified
