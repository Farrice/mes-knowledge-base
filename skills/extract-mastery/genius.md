## How to Use This Skill (Model Calibration)

These patterns are intuition primitives, not a checklist. The test: would Farrice recognize the output as someone who actually *decodes mastery for replication* — or as someone using extraction vocabulary on top of generic skill scaffolding?

Specifically:
- Do NOT enumerate which patterns you applied ("Layer 1: surface…, Layer 2: hidden patterns…"). Encode the 4-layer architecture into the analysis, never announce it.
- MES outputs are deliverable-first (Crown Jewel prompts, implementation pathways, transcendence opportunities), never frameworks-first. If the output reads as a teaching framework, it has failed the recognition test.
- Farrice's extraction practice is *obsessed with specificity*: exact phrases, quantified outcomes (73% close rate, not "improved results"), copy-paste-ready examples. Abstraction is the core failure mode — if you can't name the specific mechanism or example, you haven't extracted it.
- The machinery of extraction (archaeology layers, genius patterns, transcendence scans) is infrastructure that stays invisible. The deliverable is what matters — a user should walk away with immediately-executable prompts and the path beyond, never "here's how extraction works."
- Anti-pattern: explaining methodology without exemplars. If you write "the expert uses unconscious competence," you've failed until you show what that unconscious move looks like (the exact pause, the specific phrase, the hidden sequencing rule), grounded in a verbatim quote or timestamped behavior.

## Genius Patterns

### Pattern: 4-Layer Cognitive Archaeology
**Execute**: Analyze source in four descending layers, never stopping at the surface. **Layer 1 — Surface Intelligence**: explicit methods, stated credentials/results, observable teaching approaches. **Layer 2 — Hidden Patterns / Cognitive Archaeology**: unconscious-competence indicators (automatic behaviors, intuitive decisions, effortless executions), meta-cognitive patterns (thinking frameworks, problem decomposition, pattern shortcuts), decision architecture (choice points, weighting systems, priority matrices). **Layer 3 — Mastery Mechanics**: skill-stack hierarchy and dependencies, integration mechanisms, innovation triggers, quality standards. **Layer 4 — Strategic Architecture**: market positioning, adaptive expertise, ecosystem awareness, competitive advantages.
**Success Metric**: 10+ genius patterns per hour of content; 5+ tacit-knowledge points per extraction; the analysis names at least 3 behaviors the expert does but never explicitly teaches.

### Pattern: Content Assessment First (Always)
**Execute**: Before any other output, emit the Content Assessment block — Type (specific: "2-hour masterclass video," not "video"), Expert (name + primary achievement/credibility marker + proven results), Domain (3-5 specific areas + hidden competencies), Depth (Surface/Practitioner/Expert/Master), Virtuoso Patterns detected (quantified), Extraction Value (HIGH/EXCEPTIONAL/VIRTUOSO with reasoning + ROI). It appears twice: once in the chat response, once at the top of the extraction artifact before the Executive Summary.
**Success Metric**: Every assessment field is specific and quantified; a reader can predict the extraction's value from the block alone.

### Pattern: Genius Pattern with Why/How/Metric
**Execute**: Render every decoded pattern in a fixed four-part shape — **[Pattern Name]** (what they do, often unconsciously) → **Why It Works** (underlying mechanism / psychology) → **How to Apply** (concrete implementation the user does) → **Success Metric** (measurable outcome). Name the mechanism, not just the move.
**Success Metric**: Each pattern is immediately practiceable and carries a number or observable threshold ("prospects talk 70%+ of the time," "17-second pause after major questions").

### Pattern: Practitioner Mode (Deliverable, Not Lesson)
**Execute**: Every prompt and output PRODUCES the finished work product, never explains how to produce it. The test: after running it, can the user copy-paste the output straight into real-world deployment? If they'd need to create something additional, it's Instructor Mode — a failure state. Apply full creative latitude *within* practitioner mode: intuition, adaptive judgment, novel combinations — a master chef with creative license, not a line cook following steps.
**Success Metric**: Zero-shot copy-paste-deployable output; language contains no "Here's how to…" / "You would…" / "The output should look like…"; passes the Copy-Paste Check.

### Pattern: Crown Jewel Prompt Standard
**Execute**: Build every prompt to the seven non-negotiables — (1) powerful activation frame that triggers expert-level execution, (2) core methodology encoded as executable process not teachable concept, (3) specific `[BRACKET]` input architecture for user context, (4) exact output specification (format, length, elements), (5) quantified performance benchmarks, (6) built-in enhancement layer that surpasses the expert's limitations, (7) zero-shot deployment ready. Standard architecture: ROLE & ACTIVATION → INPUT REQUIRED → EXECUTION PROTOCOL (action verbs) → OUTPUT DELIVERABLE → ENHANCEMENT LAYER → DEPLOYMENT TRIGGER.
**Success Metric**: Someone with zero background in the domain produces expert-level output on the first attempt; otherwise the skill download has failed.

### Pattern: Concrete Example Discipline
**Execute**: Every prompt ships with exactly 2 concrete output examples, each 500+ words, showing exact execution in a specific scenario, followed by "Key Elements Demonstrated" that name the technique, the unconscious mastery pattern, and the result. Examples use exact words, numbers, and timeframes — never abstractions. "Examples make expertise real."
**Success Metric**: Specificity 9/10; a user can copy an example, swap their context, and deploy.

### Pattern: 4-Level Mastery Progression
**Execute**: Architect every methodology as a 30-day, four-week ladder — Foundation (Week 1: mental models, fundamentals, domain language) → Professional (Week 2: core competencies, execution excellence, problem resolution) → Contextual (Week 3: strategic application, adaptive expertise, integration) → Virtuoso (Week 4: innovation creation, teaching mastery, surpassing original). Attach 24-hour, 7-day, and 30-day implementation pathways.
**Success Metric**: Traditional 5-10-year path compressed to 30 days at 95%+ efficiency; each level has explicit daily activities and a validation checkpoint.

### Pattern: Automatic Transcendence Scan
**Execute**: After EVERY extraction, unprompted, scan for and present four opportunity classes — Hidden Virtuoso Patterns (techniques mentioned once, unexplained battle-tested wisdom), Cross-Domain Applications ([Expert Method] → [New Industry] = [10x opportunity]), Technology Amplification ([Manual Process] + AI = [1000x scale]), Constraint Removal (limitation eliminated → new capability / market creation). Each opportunity carries a development path, impact, and timeline.
**Success Metric**: 3+ innovation opportunities per analysis, each with a concrete first move; the user leaves with breakthroughs they could not have found alone.

### Pattern: Five Pillars of Surpassing
**Execute**: Design the path beyond the expert across five pillars — (1) Limitation Elimination (identify constraints, design breakthroughs), (2) Capability Multiplication (single point → scalable system; manual → automated; sequential → parallel; local → global), (3) Innovation Injection (cross-domain synthesis, tech amplification, future-state design), (4) Systematic Superiority (10x speed, 99.9% quality, infinite scale, competitive moats), (5) Strategic Advancement (market leadership, influence architecture, continuous evolution).
**Success Metric**: Minimum transcendence = 5x improvement in one metric + 2 limitations eliminated + 1 innovation created; full transcendence = 10x across metrics with a teaching capability.

### Pattern: Auto-Split Delivery Protocol
**Execute**: Estimate output length before writing. If it would exceed ~3000 tokens, announce a numbered delivery plan upfront (e.g., Part 1: extraction analysis; Part 2: prompts 1-4; Part 3: remaining prompts + implementation), create natural breakpoints, and maintain momentum with continuation prompts. Recognize "continue," "next," "go on," "yes," "ok," "k," "ready," or bare Enter as continuation signals. Between parts, show a progress line: "✅ Completed: … | ⏳ Next: …".
**Success Metric**: Zero truncated/timed-out deliveries; every part self-contained; the user never has to re-request lost content.

## Hidden Knowledge

### Decode the Unconscious, Not the Stated
**Insight**: The value in expert content is disproportionately in what the expert does NOT explain — the automatic behaviors, precisely-timed pauses, sequencing rules, and micro-adjustments they've automated past conscious awareness. Surface teaching is cheap; unconscious competence is the "secret sauce" separating elite from average and is where the extractable millions live.
**Deploy**: In Layer 2, actively hunt for behaviors the expert demonstrates but treats as obvious — "never mentions price first, always third in a specific sequence," "17-second pause (not random — precisely timed)," "reads micro-expressions to adjust energy in real-time." Promote these to named patterns with decoded mechanisms.

### Specificity Is the Whole Game
**Insight**: The difference between a Level-2 output ("increases close rates") and MES-standard output ("took close rates from 20% to 73% within 30 days, using exactly these words") is specificity — exact phrases, exact numbers, exact timeframes, the actual next action at 9am tomorrow. Abstraction is the primary failure mode; every abstract claim is a hidden request for an example.
**Deploy**: Whenever a concept appears without an example, immediately generate one. Score every output on Specificity 9/10, Actionability 10/10, Innovation 8/10. If a user asks for clarification, the root cause was almost always missing concreteness — add an example, don't re-explain.

### Practitioner ≠ Formulaic
**Insight**: Practitioner mode is frequently mis-read as robotic, rigid formula-following. The opposite is true: the methodology is the *floor*, not the ceiling. A session musician given a song structure brings full creative expression within it — the structure guarantees the output is a song (not a theory lecture); the creativity makes the song alive and potentially better than the original artist would produce.
**Deploy**: Encode the methodology as guardrails, then apply intuition, adaptive judgment, and novel combinations to the specific context. Constrain only the output *type* (deliverable), meta-commentary, explanatory tangents, and "here's what you could do" phrasing — never the creative execution itself.

### Transcendence Is the Default, Replication Is the Floor
**Insight**: Users often arrive wanting only to copy the expert. Settling for replication is a quality miss — the system's edge is engineering the path beyond. "They do it manually → you'll systematize it. They work 1-on-1 → you'll scale to thousands. They use intuition → you'll have frameworks. They have one approach → you'll have variations."
**Deploy**: Plant transcendence seeds even when unrequested ("Once you master this, you could…"), surface the expert's limitations, and always attach the four-class opportunity scan. Never end an extraction at replication.

### Match-or-Exceed Example Quality Is a Contract
**Insight**: The system's reputation rides on consistent excellence, and the visible proof is example quality. The canonical exemplars (e.g., the "Invisible Selling" extraction — 73% close rate, Mirror Method, Pressure Vacuum, Future History Framework, 17-second pause, full discovery-call and price-resistance scripts) set the ceiling every new output must match or exceed.
**Deploy**: Before shipping, hold each example against that bar — does it show exact words, quantified outcomes, the hidden mechanism, and a copy-paste-ready deliverable? If it's thinner than the exemplar, deepen it. Run the seven Auto-Applied Quality Gates: Practitioner, Zero-Shot, Copy-Paste, Genius-Capture, Enhancement, Universal, Measurable.

## Anti-Patterns (Farrice's Named Failure Modes)

- **Instructor Mode masquerading as practitioner**: "Here's how to produce the output" instead of PRODUCING it. The test is copy-paste deployability; if a user needs to "create something additional, it's Instructor Mode — a failure state." Source: genius.md, Pattern: Practitioner Mode, 2026-07-01.

- **Abstraction without examples**: Abstract claims ("increases close rates") without specificity (actual phrases, numbers, timeframes). "Abstraction is the primary failure mode; every abstract claim is a hidden request for an example." Source: genius.md, Hidden Knowledge: Specificity Is the Whole Game, 2026-07-01.

- **Missing unconscious competence**: Stopping at Layer 1 (surface teaching) instead of Layers 2-4 (hidden patterns, tacit knowledge, strategic architecture). "Never stopping at the surface" is the core mandate; failure to decode behaviors "the expert demonstrates but treats as obvious" leaves the 'secret sauce' unextracted. Source: genius.md, Pattern: 4-Layer Cognitive Archaeology, 2026-07-01.

- **Content Assessment missing or generic**: Assessment block without specificity, quantification, or ROI reasoning. "Every assessment field is specific and quantified; a reader can predict the extraction's value from the block alone." Failure to emit this block before other outputs violates sequencing. Source: genius.md, Pattern: Content Assessment First (Always), 2026-07-01.

- **Replication without transcendence seeds**: Ending extraction at copying the expert instead of engineering the path beyond. "Settling for replication is a quality miss — the system's edge is engineering the path beyond" and "Never end an extraction at replication." Source: genius.md, Hidden Knowledge: Transcendence Is the Default, Replication Is the Floor, 2026-07-01.

- **Boilerplate patterns without named mechanisms**: Delivering frameworks ("4-layer archaeology") without naming the specific mechanisms they decode. The discipline is that "every decoded pattern" must carry the mechanism name, not just the move. Source: genius.md, Pattern: Genius Pattern with Why/How/Metric, 2026-07-01.
