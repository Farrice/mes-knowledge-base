# Search Content Mastery OS

One local conductor for source-grounded search work across traditional SEO, answer engines, retrieval surfaces, local search, ecommerce, social/video discovery, and conversion handoff.

This is a non-persona companion OS. It coordinates existing expert and production capabilities; it does not replace or restate them.

## What It Produces

| Mode | Primary record or handoff | Use when |
|---|---|---|
| `foundation` | `SearchProjectManifest` plus portable project pack | Starting a project or moving it into a clean context container |
| `audit` | Source-referenced baseline audit | Establishing eligibility, intent, coverage, citation, channel, and measurement gaps |
| `plan` | `SearchBrief` | Turning one opportunity into a production-ready, measurable decision |
| `create` | Approved production handoff | Sending a brief to existing written, image, carousel, audio, or video workflows |
| `score` | `ContentScoreReceipt` | Rating an asset without confusing readiness, expert judgment, taste, or outcomes |
| `measure` | Normalized import receipt, `SearchEvent`, or proposed learning | Recording what happened from local exports and manual observations |
| `service` | `ServiceReceipt` | Validating a bounded delivery pack without activating an offer |

## Core Operating Rule

Keep five truths separate:

1. What the source or import actually shows.
2. What the system infers or predicts.
3. What expert judgment recommends.
4. What Farrice overrides through taste or commercial judgment.
5. What a dated external event later proves.

Never overwrite an earlier truth with a later one. Link them through receipts.

## Command Surface


## When NOT to Use

- Use `nathan-gotch-ai-seo` directly for one bounded Nathan-method execution that needs no project pack or measurement spine.
- Use `ethan-smith-aeo` directly for a focused AEO experiment or citation-landscape analysis.
- Use `/create` directly when the approved strategy and brief already exist and no search scoring or measurement is needed.
- Use `/health-check` for read-only harness status. A search-system build is not a health-check request.
- Do not use this command to guarantee rankings, citations, traffic, leads, conversions, or revenue.

## Proof Boundary

Structural validation and cold-start execution may promote the local capability to `RUNTIME_OBSERVED`. Every market-effect state stays `UNTESTED` until a dated, source-referenced `SearchEvent` exists.
