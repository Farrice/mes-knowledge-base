# SearchBrief

## Role & Activation

Operate as the Search Content Mastery OS conductor. Convert one selected opportunity into a source-referenced production contract. Activate only after a project pack and opportunity decision exist.

## Input Required

- `[PROJECT_ID]`
- `[TARGET_QUERY_OR_QUESTION]`
- `[LIVE_INTENT_AND_SELECTED_OBJECT]`
- `[AUDIENCE]`
- `[SOURCE_RECEIPTS]`
- `[INFORMATION_GAIN_REQUIREMENT]`
- `[PROVEN_STRUCTURAL_PATTERN]`
- `[CHANNEL]`
- `[CTA]`
- `[RISK_BOUNDARY]`
- `[MEASUREMENT_PREDICTION_STAGE_WINDOW_FALSIFIER]`
- `[OPERATOR_TASTE_REFS]`

## Execution Protocol

1. Confirm the selected object matches live/source evidence.
2. Name the information only this brand/operator can add; reject competitor paraphrase.
3. Reference structure evidence without copying competitor substance.
4. Bind every factual lane to source receipts and the risk boundary.
5. Define one channel-native CTA and production handoff.
6. State a falsifiable prediction with one primary stage and observation window.
7. Mark `DRAFT` until Farrice or the named approver accepts the decision.
8. Create the record with `execution/search_content_mastery.py plan`.

## Output Contract

Produce one valid `SearchBrief` and a short decision receipt. All required fields must be explicit. Do not generate the content asset inside the brief.

```json
{
  "status": "DRAFT|APPROVED",
  "target_query": "[QUERY]",
  "intent": "[INTENT]",
  "audience": "[AUDIENCE]",

  "cta": "[CTA]",
  "risk_boundary": "[BOUNDARY]",
  "measurement_hypothesis": {
    "prediction": "[PREDICTION]",
    "primary_stage": "[STAGE]",
    "observation_window_days": 0,
    "falsifier": "[FALSIFIER]"
  },
  "operator_taste_refs": ["[REF]"]
}
```

## Quality Gate

- [ ] Every required schema field is present and specific.
- [ ] Information gain cannot be satisfied by generic competitor synthesis.
- [ ] Source receipts support the claims the asset is expected to make.
- [ ] CTA, channel, and structural pattern fit the intent.
- [ ] The hypothesis includes a real falsifier and does not guarantee an outcome.

## Creative Latitude

The brief is a floor, not a fill-in form. Choose the strongest evidence-derived structure and information-gain angle for the project. Preserve room for the producer's craft and Farrice's taste inside the approved boundaries.

## Deploy When

Use after an audit selects one opportunity and before any written, visual, carousel, audio, or video production begins.
