# Search Content Mastery OS — Contract Reference

Canonical build contract:

`extractions/nathan-gotch-search-content-mastery/skill-system-contract.md`

## Mandatory Handoff

- **Source evidence:** exact package, import receipt, or source row.
- **Component used:** one owner plus bounded support.
- **Output produced:** versioned record ID and file path.
- **Next input:** exact downstream record, not hidden chat context.
- **Validation:** command and result.
- **Open risk:** exact proof gap or `none`.

## Hot/Cold Rule

Keep the manifest, current brief, current asset/receipt, and exact evidence rows hot. Keep transcripts, raw imports, other verticals, and unrelated expert files cold until requested by the current handoff.
