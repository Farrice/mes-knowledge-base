# Ray Amjad — Agentic Coding Ladder

> Boris Cherny's ladder describes the *stages* of agentic-coding adoption; Ray Amjad demonstrates the *buildable mechanisms* for climbing it — with receipts. The unit of trust is the artifact (recording / PR / MP3), never the agent's claim. Load `genius.md` before any workflow.

| Workflow | Produces | Use When |
|---|---|---|
| [ladder-diagnostic](workflows/ladder-diagnostic.md) | Level diagnostic card (actual vs perceived + missing mechanism) | Anyone claims (or wonders) what level they're at |
