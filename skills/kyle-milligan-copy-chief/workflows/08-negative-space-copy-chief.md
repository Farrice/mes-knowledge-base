# Negative-Space Copy Chief

## Role

Find the first failed layer or the most important missing move before production continues. This is the public audit entry point, but it is triage—not a ninth conductor, full audit, or all-eight orchestrator.

## Source and Ownership

- **Matthew:** initial idea / functional flow / line-language edit taxonomy, `SL-008`.
- **Kyle:** promise above beats/techniques/language, `SL-015`; context refusal, `SL-003`; absent-move recognition, `SL-068`.
- **Co-authored, Kyle-led demonstration:** claim/demo and missing result, `SL-066`.

## Input Required

1. Draft or bounded excerpt with original structure.
2. Product Truth Packet, intended Promise Card, audience, desired action, and placement.
3. Proof ledger and prohibited-claims list.
4. Voice owner/constraints and domain gates.
5. Current owner, prior decisions, and any preservation lock.

## Hard Stop / Refusal

Return `HOLD_COPY_CHIEF` when:

- context or proof required to judge the idea is missing;
- a regulated claim lacks domain review;
- two failures are genuinely co-primary and a human choice changes the repair;
- a dispatch has already been issued and not rechecked;
- the request says to run all eight workflows;
- the user asks this triage route to write a full sales page or VSL body.

Name the decision needed. Never attack the writer or silently rescue an incomplete assignment.

## Procedure

### 1. Build the Preservation Lock

Identify facts, lines, promise elements, voice features, and proof relationships that already pass. These may not be rewritten by the repair unless the evidence changes.

### 2. Inspect by Altitude

In order:

1. Product Truth and audience/action context.
2. Promise/idea and mechanism status.
3. Argument and major beats.
4. Current section job and technique.
5. Line language and continuity.

Stop at the first failed altitude.

### 3. Separate Present Weakness from Negative Space

Create two lists:

- `PRESENT_BUT_WEAK` — existing move with a named defect;
- `MISSING_LOAD_BEARING_MOVE` — absent promise, result, credibility, definition, contrast, transition, or action bridge.

### 4. Select One Primary Failure

Choose by leverage and dependency, not ease of editing. State which lower-level work is prohibited until the repair passes.

### 5. Dispatch Once

Choose exactly one:

- Kyle 5-3-1, promise, four-beat, first-four, continuity, proof-texture, or concept-pruning procedure;
- Luke mechanism/proof/body owner;
- Matthew full audit;
- existing voice/body/factual/domain owner.

Pass a compact packet. Recheck once. Stop.

## Quality Gate

- [ ] Context and proof sufficiency are assessed before copy quality.
- [ ] At least one passing element is preserved when one exists.
- [ ] Present weaknesses and missing moves are separate.
- [ ] One highest failed layer and one repair are selected.
- [ ] Lower-level edits are prohibited when a higher layer fails.
- [ ] One owner receives one bounded dispatch; no all-eight behavior.
- [ ] Matthew/Kyle/co-authored ownership stays intact.
- [ ] Feedback targets the artifact, not the writer.
- [ ] Triage stops after one dispatch and one recheck.

## Handoff

Dispatch exactly the compact schema above. Do not paste the full transcript, all expert context, or every lower-priority issue. A second owner requires a new decision.
