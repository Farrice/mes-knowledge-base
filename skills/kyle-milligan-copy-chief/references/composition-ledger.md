## Integration Test

Expert names are not integration proof. A composed run must show:

1. one named owner;
2. a distinct intermediate artifact;
3. a decision that changes the next output;
4. a compact handoff rather than pasted context;
5. one verifier or human gate;
6. an explicit stop before another owner loads.

If two experts are writing the same copy body simultaneously, composition has failed.
