# Web Design Taste Sprint

Domain-specific deployment of the 4-step process for web design. Produces a Figma-ready collection of reproductions, named design rules, and a web-specific lineage from Gutenberg through Swiss Design to modern interfaces.

## Pre-Flight Gate

- Read `genius.md` — focus on Pattern 4 (Blind Copy), Pattern 9 (History-as-Constraints), Hidden Knowledge: Gutenberg Typography Lineage, Hidden Knowledge: Swiss Neutrality Design Philosophy
- User must provide: What kind of web presence they're building (SaaS, portfolio, agency, editorial, e-commerce)
- Optional: 3-5 sites they already admire

## Execution

### Step 1: Web Identity Declaration (Compressed)
Run an abbreviated `/taste-declare` for web specifically:
- "What should someone FEEL when they land on your site?"
- "What sites do you visit repeatedly — not for content but because they feel right?"
- "Name 3 sites you consider beautiful and 3 you consider ugly. Don't overthink."
- Synthesize into a web-specific identity statement

### Step 2: 30-Site Collection
Build a curated collection of 30 websites:
- 10 from the user's specific industry/type
- 10 from adjacent or respected domains (editorial, luxury, tech)
- 10 "wildcard" sites — personal favorites, foreign language, experimental
- For each, screenshot the homepage and write ONE sentence: what makes this noteworthy

### Step 3: Pixel-Perfect Copy Sprint
From the 30, select 5 for exact reproduction in Figma:
- Selection criteria: Range of styles within identity, varying complexity, at least 1 "aspirational" (stretch choice)
- For EACH: reproduce the homepage — every typeface, color value, spacing unit, image placement
- No shortcuts. Measure everything. Match exactly.
- Time: 2-4 hours per site (10-20 hours total)

### Step 4: Design Rule Extraction
After copying all 5, analyze patterns:
- **Typography rules**: What typeface pairings? What size ratios? What line-height patterns?
- **Grid rules**: How many columns? What max-width? How does content breathe?
- **Color rules**: How many colors per site? What's the ratio of neutrals to accent? Dark mode patterns?
- **Spacing rules**: What's the base unit? How does vertical rhythm work? Section padding patterns?
- **Interaction rules**: What moves? What's static? What happens on hover?
- Name each rule. Source it to the exemplars.

### Step 5: Web Design Lineage
Trace web design conventions backward:
- Current conventions → Web 2.0 (2005-2015) → Early web/Flash era → Print design → Swiss International Style → Bauhaus → Gutenberg's moveable type
- Identify which "era" your identity aligns with most closely
- Understand WHY the conventions exist (accessibility? screen constraints? cultural values?)

### Step 6: Taste-Applied Wireframe
Using collected rules and identity, produce a wireframe for the user's actual project:
- Apply the rules you've extracted (not copied layouts, but the RULES from them)
- Break one rule intentionally — document which one and why
- Annotate every design decision with the rule it follows

## Content Type Adaptations

| Web Type | Sprint Focus |
|----------|-------------|
| SaaS product | Prioritize conversion layouts, pricing page conventions, dashboard design |
| Portfolio/agency | Prioritize case study presentation, hero sections, brand expression |
| Editorial/blog | Prioritize readability, long-form layouts, typography hierarchy |
| E-commerce | Prioritize product photography, cart UX, browsing flow |
| Personal brand | Prioritize personality expression, About page architecture, social proof |

## Output Requirements

1. **Web Identity Statement** — one sentence defining the feeling and intention
2. **30-Site Collection** — curated library with screenshots and annotations
3. **5 Pixel-Perfect Reproductions** — Figma files (or equivalent)
4. **Named Design Rules** — 15-20 rules from typography, grid, color, spacing, interaction
5. **Web Design Lineage** — traced from current back through 5+ historical periods
6. **Taste-Applied Wireframe** — first original work using the extracted rules

## Quality Gate

- Do the 5 reproductions match the originals within 95% fidelity?
- Can the user name 10+ design rules with evidence and historical origin?
- Does the wireframe follow the rules with one intentional, justified rule break?
- Would the user defend their design decisions against a critic by referencing specific rules?
