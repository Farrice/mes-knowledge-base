# Brand Aesthetic Language

Your brand's visual and verbal language should descend from your identity values and cultural lineage — not from trends. This workflow produces a living brand language document rooted in Sam Parr's taste methodology: identity-driven, history-informed, rule-articulated.

## Pre-Flight Gate

- Read `genius.md` — focus on Pattern 2 (Identity-Before-Aesthetics), Pattern 8 (Values-Behind-Attraction), Pattern 9 (History-as-Constraints)
- User should ideally have completed `/taste-declare` (or provide equivalent identity context)
- User must provide: Brand name + what it does + who it's for

## Execution

### Step 1: Identity Values Audit
Pull from `/taste-declare` or construct:
- 3-5 identity values that the brand embodies (not aspirational — lived)
- For each value, the cultural tradition it connects to
- The emotional response the brand wants to trigger in first contact

### Step 2: Visual Language Extraction
For each identity value, define:
- **Color**: What colors carry this value? (Not "blue" — "deep navy: authority without corporate coldness")
- **Typography**: What typefaces express this value? (Serif vs. sans, geometric vs. humanist, weight)
- **Space**: How does whitespace express this value? (Generous = confidence, tight = energy, asymmetric = rebellion)
- **Imagery**: What photographic/illustration style? (Documentary vs. polished, warm vs. cool, people vs. objects)
- **Texture**: Matte vs. gloss, grain vs. smooth, analog vs. digital signals

### Step 3: Verbal Language Extraction
For each identity value, define:
- **Vocabulary register**: Technical vs. conversational, short vs. long words, jargon or plain language
- **Sentence structure**: Short declaratives, long explorations, fragments, lists
- **Tone**: Warm/cool, direct/oblique, serious/playful, certain/exploratory
- **Rhythm**: Punchy (copywriting), flowing (editorial), staccato (urgent)
- **Forbidden words**: What language DOESN'T belong? (This is as important as what does)

### Step 4: Historical Grounding
For the visual AND verbal language, source the tradition:
- "Our type choices descend from the Swiss International Style because we value clarity above expression"
- "Our tone descends from New Journalism because we believe brands should be human, not institutional"
- This prevents drift — when in doubt, return to the lineage

### Step 5: Rule Codification
Produce explicit brand language rules:
- 5-7 visual rules (color ratios, type hierarchy, spacing units)
- 5-7 verbal rules (sentence length, vocabulary register, tone markers)
- 3-5 "never do this" rules (what breaks the language)
- 1-2 "breakable rules" for creative moments

### Step 6: Coherence Test
Test the language system against 3 real outputs:
- Write a social post in this language — does it feel right?
- Design a mock landing page section — does it feel right?
- Read both aloud — do they feel like the SAME brand?
- If not, which element is misaligned? Adjust.

## Content Type Adaptations

| Brand Type | Language Emphasis |
|-----------|-----------------|
| Personal brand | Heavier verbal weight — voice IS the brand, visuals serve it |
| Product brand | Heavier visual weight — design IS the product experience |
| Service brand | Balance visual and verbal — trust requires both consistency |
| Media brand | Verbal dominates but visual establishes credibility tier |

## Output Requirements

1. **Identity Values Map** — 3-5 values with cultural lineage connections
2. **Visual Language Guide** — color, type, space, imagery, texture per value
3. **Verbal Language Guide** — vocabulary, structure, tone, rhythm, forbidden words
4. **Historical Grounding** — which traditions your language descends from
5. **Rule Codex** — 15-20 explicit rules (visual + verbal + prohibitions)
6. **Coherence Test Results** — 3 sample outputs evaluated for alignment

## Quality Gate

Reference genius.md quality rubric — Aesthetic World Cohesion:
- **Score 4**: Elements are pleasant but lack unified theme
- **Score 7**: Visuals and verbal are generally consistent
- **Score 10**: Every element contributes to a meticulously crafted, immersive world
- **Minimum to pass**: Score 7. If visual and verbal feel like different brands, iterate.
