# Taste × CEV Diagnostic

The full pipeline stacking Sam Parr (taste acquisition) with Oren (taste evaluation). Sam Parr teaches you HOW to develop taste. Oren teaches you HOW to evaluate and deploy it. Together: build → evaluate → curate → deploy.

- Read `skills/sam-parr-taste-acquisition/genius.md` — the full taste acquisition system
- Read `skills/oren-taste-development/SKILL.md` — the CEV evaluation framework
- User must provide: Domain + where they are in their taste journey (new? some foundation? advanced?)

## Execution

### Step 1: Phase Detection
Where is the user in the combined pipeline?

| Phase | Sam Parr Stage | Oren Stage | Action |
|-------|---------------|------------|--------|
| **1 — Raw** | Pre-identity, no copying | No evaluation framework | Start with `/taste-declare` |
| **2 — Foundation** | Has identity, copying | Beginning evaluation | Continue copy sprint, introduce CEV vocabulary |
| **3 — Integration** | Rules extracted, history known | CEV framework learned | Merge: evaluate YOUR work using CEV on YOUR rules |
| **4 — Deployment** | Good taste demonstrated | CEV audit ready | Apply combined framework to real projects |
| **5 — Mastery** | Breaking rules intentionally | Spotting insider codes | Full taste-as-moat deployment |

### Step 2: Sequential Deployment
Based on phase, deploy the right combination:

**Phase 1-2 (Acquisition Focus)**:
- Deploy Sam Parr workflows: `/taste-declare` → `/taste-copy` → `/taste-rules`
- Introduce Oren CEV vocabulary alongside but don't evaluate yet
- The user needs to BUILD before they can EVALUATE

**Phase 3 (Integration)**:
- Deploy `/taste-rules` output INTO Oren's CEV matrix
- For each extracted rule: Is this a Craft axis marker? Experience axis? Value axis?
- Map rule mastery to CEV evaluation: "I follow this Craft rule at Score 7, this Experience rule at Score 5"

**Phase 4 (Deployment)**:
- Run Oren's full taste audit on the user's original work
- Score against Sam Parr's quality rubric AND Oren's CEV matrix simultaneously
- Identify: Where does acquisition weakness show up as evaluation gaps?

**Phase 5 (Mastery)**:
- The user can now do both: build taste in new domains (Sam Parr) AND evaluate with precision (Oren)
- Deploy for others: use combined framework to audit brands, evaluate creative work, consult

### Step 3: Gap Diagnostic
Identify where acquisition vs. evaluation gaps exist:
- "You can IDENTIFY quality (Oren strong) but can't PRODUCE it (Sam Parr weak)" → More copying needed
- "You can PRODUCE quality (Sam Parr strong) but can't ARTICULATE why (Oren weak)" → CEV training needed
- "Both strong" → Deploy as competitive advantage

### Step 4: Combined Scorecard
Produce a unified taste assessment using both expert frameworks:

| Dimension | Sam Parr Score (1-10) | Oren Score (1-10) | Gap | Action |
|-----------|----------------------|-------------------|-----|--------|
| Identity clarity | [identity/values/lineage] | [personal aesthetic] | | |
| Execution quality | [rule following] | [Craft axis] | | |
| Historical depth | [lineage knowledge] | [Canon knowledge] | | |
| Innovation capacity | [rule breaking] | [Insider codes] | | |
| Economic deployment | [moat building] | [Value axis] | | |

## Output Requirements

1. **Phase Diagnosis** — where in the 5-phase pipeline the user sits
2. **Sequential Deployment Plan** — which workflows to run in which order
3. **Gap Diagnostic** — acquisition vs. evaluation strengths and weaknesses
4. **Combined Scorecard** — unified assessment across both frameworks
5. **Next Actions** — the specific 3 things to do THIS WEEK

## Quality Gate

- Does the diagnostic distinguish between HAVING taste and ARTICULATING taste?
- Is the deployment plan sequential (not everything at once)?
- Does the combined scorecard show where the frameworks complement vs. overlap?
