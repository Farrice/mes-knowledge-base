# Taste Identity Declaration

The foundation of Sam Parr's taste system. Before you copy, study, or build ANYTHING, you answer: **What do I want to say?**

Most people skip this step and jump straight to mimicking what looks cool. The result is scattered aesthetics with no coherence. This workflow forces the identity-first gate.

## Pre-Flight Gate

- Read `genius.md` — focus on Pattern 2 (Identity-Before-Aesthetics), Pattern 8 (Values-Behind-Attraction), and Hidden Knowledge: The Emotional Root Discovery
- User must provide: The DOMAIN they want to develop taste in (fashion, web design, writing, naming, brand, music, interior, etc.)
- Optional: Examples of work/people/brands they already admire in this domain (if they have them)

## Execution

### Step 1: Domain Declaration
Have the user name their domain explicitly. One domain per execution.

### Step 2: Attraction Mining
Collect raw inputs — things the user is drawn to in this domain. Ask:
- List 5-10 things you genuinely like in this domain (specific examples, not categories)
- For each: "What specifically draws you to this?"
- "If you had to explain to a stranger why this is good, what would you say? Don't worry about being right."

### Step 3: Values Trace
For each attraction cluster, trace backward using the WHY x3 method from genius Pattern 8:
- Surface attraction → Emotional resonance → Identity value
- Example: "I like leather jackets" → "I like adventure" → "I want to be perceived as someone who acts"
- Name the 3-5 identity values that keep appearing

### Step 4: Cultural Lineage Mapping
For the values identified, map to cultural movements, historical periods, or creative traditions:
- "Midwestern stoicism" → workwear heritage → agricultural utility → function-over-fashion ideology
- "Adventure and action" → military heritage → exploration equipment → purpose-built design
- This is the lineage that will inform the copying phase

### Step 5: Identity Statement
Synthesize into one declaration:
> "I want my [domain] to say [identity statement] because [values]. This connects to the [cultural lineage] tradition."

### Step 6: Test the Declaration
Run the coherence check:
- Does it explain ALL the things you listed as attractions? If something doesn't fit, either the statement needs adjusting or that attraction is noise.
- Would someone who understands this statement be able to predict your preferences? If not, sharpen.
- Do you feel a gut-level "yes" when you read it? If intellectual but not visceral, dig deeper.

## Content Type Adaptations

| Content Type | Adaptation |
|-------------|-----------|
| Fashion | Mine wardrobe attractions, lifestyle aspirations, body-comfort values |
| Web design | Mine sites you visit repeatedly, UX frustrations, brand alignment goals |
| Writing | Mine authors/voices you re-read, topics that won't bore you, what you want readers to feel |
| Music | Mine songs you replay, emotional states you seek, live vs. recorded preferences |
| Brand | Mine brands you'd defend in arguments, purchase patterns, aesthetic environments you linger in |
| Naming | Mine names you remember, sounds you're drawn to, etymology interests |

## Output Requirements

1. **Raw Attraction Inventory** — 5-10 specific things with gut-level reasons
2. **Values Map** — 3-5 identity values traced backward from attractions
3. **Cultural Lineage** — The tradition(s) your taste connects to
4. **Identity Statement** — One declaration that you would stake your aesthetic reputation on
5. **Coherence Score** — How many of your raw attractions the statement explains (aim for 80%+)

## Quality Gate

Reference genius.md quality rubric:
- **Score 4**: Vague preferences ("I like clean stuff")
- **Score 7**: Specific identity with some values reasoning
- **Score 10**: Precise declaration with 3+ traced values and cultural lineage
- **Minimum to pass**: Score 7 — clear identity with values. Score 4 = re-execute Step 3.
