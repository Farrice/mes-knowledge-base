# Niche Constellation Map

**Execution prompt:** `../references/prompts-v2/niche-constellation-map.md`

## Purpose

Create one legible umbrella while preserving adjacent expertise that strengthens rather than fragments it.

## Protocol

1. Name the tip of spear: the clearest category the audience should remember.
2. Map adjacent audiences, problems, outcomes, methods, stories, and offers.
3. For every adjacent node, state how it reinforces the umbrella.
4. Classify nodes: `CORE`, `ADJACENT`, `EXPERIMENT`, or `OUT OF BOUNDS`.
5. Set a content or capacity allocation and a rule for promoting/demoting nodes.

## Output

Umbrella statement, constellation map, node logic, boundaries, allocation, and expansion triggers.

## Quality Gate

If the tip of spear disappears when the adjacent nodes are listed, the map is a collection of interests—not a constellation.
## Output Schema

Umbrella statement, classified nodes, reinforcement logic, boundaries, allocation, promotion triggers.

## Quality Gate

The result must preserve source-versus-derived boundaries, label uncertainty, name one executable next test, and avoid treating clarity or engagement as payment proof.
