# /alyssa-stalker-content-mix-planner — Mostly For Them, A Little About You

Coffee & Contracts' mix: "mostly local content, listing content because you got to show what it is that you sell, and then a little bit of authority building content and that's the smallest percentage" [25:59–26:10]. Goal decides ratio: grow → local, "the fastest way to attract new followers" [26:47–26:51]; convert → listing [26:53–26:57]; nurture → authority, about monthly [26:59–27:01], [28:04–28:06]. "Every post has a different goal... you're not going to get a ton of likes on authority-building nurture style content" [27:04–27:10]. And never five experiments at once [38:29–38:39].

## Pre-Flight Gate

Load `genius.md` Patterns 1, 11 and heuristics 6–7. Required: the agent's primary goal for the month (grow / convert / nurture), posting capacity (real posts per week), and — if it exists — the Outlier Audit Card's hypothesis. Never prescribe daily posting when capacity is three.

## Skill Acquisition

- `genius.md` — Patterns 1, 11; anti-patterns 1, 7, 8
- `01-outlier-audit` output if available; `02-one-person-niche` card for the who on every slot
- `enrico-incarnati-instagram-realestate` workflow 08 weekly sprint and Content Expansion Pack for format fill
- For Jen: `jen-engine` Stage 2 (4-week, 20-video calendar) — this planner sets the goal tags and ratio that Stage 2 fills

## Diagnose Before Treat

Read the current grid against the ratio. Count the last 20 posts by tag. A grid that is 60% listing and 30% authority is the billboard [34:30–34:39]; the plan's first job is to invert it, not add to it.

## Execution

1. **Set the goal** — one primary goal for the month. Grow / convert / nurture.
2. **Set the ratio** — starting points: grow ≈ 60% local / 30% listing / 10% authority; convert ≈ 40% local / 50% listing / 10% authority; nurture ≈ 50% local / 30% listing / 20% authority (still ~monthly authority at most cadences). Adjust to capacity. Ratios are this skill's translation of "mostly / some / smallest"; the source gives the order, not percentages.
3. **Tag every slot** — local / listing / authority, plus the who from the niche card and one message per slot [25:40–25:49].
4. **Pre-declare expectations** — next to each authority slot: "fewer likes; memory." Next to each local slot: "reach/follows." Next to listing: "saves/DMs."
5. **Place the experiment** — exactly one, from the Outlier Audit hypothesis, repeated across 3–4 slots, with a data window and a pivot/double-down rule [35:52–36:03].
6. **Thread the personal lens** — one Pattern 6 signal per week, usually in stories.
7. **Lo-fi by default** — carousels, single images, create-mode text posts, phone B-roll with a text hook [10:37–11:04], [13:10–13:17]. Reserve production for listing showcases.
8. **A/B where cheap** — "I would AB test both" B-roll and carousel for local content [10:37–10:41].
9. **Human review checkpoint** — the agent confirms capacity and voice before the plan is "ready."

## Content Type Adaptations

| Agent goal | Ratio lean | Default formats |
|---|---|---|
| Grow (new followers) | Local heavy | B-roll + text hook, local carousels, text posts |
| Convert (leads) | Listing heavy | Listing carousels, showcase reels, keyword CTAs |
| Nurture (trust, referrals) | Authority up to ~20% | Story carousels, green-screen news, testimonial clips |
| Jen FTHB month | Local + comfort heavy | Comfort carousels, Valley local, one listing showcase per active listing |

## Quality Gate

- Does every slot carry a tag, a who, one message, and an expectation?
- Is authority at or under ~monthly and pre-declared as low-engagement?
- Is there exactly one experiment with a data window?
- Does the plan fit the agent's stated capacity?
- Is the grid moving away from billboard, not adding to it?
- Anti-pattern check: no five simultaneous experiments, no just-sold/just-listed filler.
