# Mark Kashef — Visual Blueprint Methodology

A universal visual planning protocol that uses ASCII art wireframes as the "contract" between human creative intent and AI production execution. Instead of prompting blindly and iterating expensively at the code/design layer, this system forces visual alignment at the wireframe layer first — reducing iteration cycles by 60-80%, eliminating assumption-based failures, and positioning the human as creative director over the AI production team.

| 01 | [ASCII Wireframe Generator](workflows/01-ascii-wireframe-generator.md) | Production-ready ASCII wireframe for any visual asset type | You need a quick wireframe to plan layout before building anything visual |
| 02 | [Visual Blueprint-to-Build Pipeline](workflows/02-visual-blueprint-to-build.md) | Complete built asset from concept → wireframe → annotation → production | Full end-to-end visual project: websites, dashboards, marketing pages, PDFs |

| 05 | [Visual Taste Gate](workflows/05-visual-taste-gate.md) | Critiqued/refined wireframe ready for production | Quality-checking wireframes before committing to production, or reviewing existing designs |

## Evolution Log

### 2026-04-09 — Add Conversion Traceability Matrix to Blueprint-to-Build Pipeline
- **Hypothesis**: Adding a Conversion Traceability Matrix (CTM) to Phase 1 of workflow 02 — where every wireframe element must declare its conversion role, the viewer decision it influences, and a testability statement — will make visual hierarchy decisions conversion-traceable rather than purely structural.
- **What changed**: New step 3 in Phase 1 of `workflows/02-visual-blueprint-to-build.md`. Four conversion roles (Attention Capture, Desire Building, Friction Removal, Action Triggering). Elements that can't fill the matrix get cut or merged. Element order must follow the natural conversion decision sequence.
- **Benchmark task**: "Design the visual hierarchy for an Authority Flywheel landing page — every element justified by conversion impact"
- **Baseline score**: Intent 7 / Expert 7 / Adversarial 5 / Composite 6.3
- **Variant score**: Intent 9 / Expert 8 / Adversarial 8 / Composite 8.3 (+2.0)
- **Result**: KEPT — strictly additive. Biggest gain in adversarial resilience (+3): every element now has a testable conversion justification. Original wireframe methodology untouched.
