# David Placek — Implementation Reference

## The Placek Naming System (4 Phases)

### Phase 1 — Landscape Intelligence (Days 1-3)
1. Map competitive naming landscape — bucket every existing name.
2. Declare the first hypothesis: "We're not going there."
3. Study the product with fresh eyes — what is this thing ACTUALLY?
4. Study the consumer — ladder up: features → benefits → ultimate benefit.
5. Run the Strategic Question Sequence:
   - How do you define winning?
   - What do you have to win?
   - What do you need to win?
   - What do you need to say?
6. Articulate the creative framework (a window to walk through, not a box to conform to).

### Phase 2 — Treasure Hunting (Days 3-10)
1. Deploy three two-person teams with divergent briefs.
2. Each team hunts across: Greek/Latin roots, mythology, periodic table, sounds/phonemes, unrelated domains.
3. Free-associate in 20-minute sprints — pad + pen → AI queries → pursue threads.
4. Generate 2,000+ candidates. No judgment during this phase.
5. Run two creative cycles (~2.5 weeks total, interleaved with other projects).

### Phase 3 — Convergence (Days 10-15)
1. Evaluate candidates against the creative framework.
2. Surprisingly Familiar test: Original? Processing fluent? Unexpected?
3. Sound symbolism analysis.
4. Ship shortlist (10-15) to trademark/legal review.
5. Ship to global linguists for cross-language viability.
6. Create proof-of-concept mockups.

### Phase 4 — Presentation & Decision (Days 15-20)
1. Present names in context — headlines, endorsements, product mockups.
2. Believability test: is this believable in less than one second?
3. Navigate the comfort trap: consensus = warning sign.
4. Polarization-as-energy frame for strong candidates.
5. Develop supporting copy.
6. Finalize nomenclature, positioning line, short story.

## Implementation Pathway

### 24-Hour Quickstart
Run the comfort trap audit on your own brand names. Score them:
- Originality in category (1-10)
- Processing fluency (1-10)
- Unexpectedness (1-10)
- Which zone: tension or invisible?

### 7-Day Sprint
Execute a full naming sprint on one real project:
1. Landscape intelligence (Day 1)
2. Treasure hunting with divergent briefs (Days 2-4)
3. Generate 500+ candidates minimum
4. Convergence + shortlist 10-15 (Day 5)
5. Proof-of-concept mockups for top 3 (Day 6)
6. Internal presentation using context (Day 7)

### 30-Day Integration
- Deploy three-team divergent-brief architecture on all creative projects
- Train team on approximate thinking
- Build personal sound symbolism reference
- Establish "speculate, don't evaluate" phase gate in creative reviews
