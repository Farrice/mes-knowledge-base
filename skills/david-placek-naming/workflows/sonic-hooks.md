# Sonic Hooks Workflow

## Prerequisites
- Load `skills/david-placek-naming/SKILL.md` (Tier 1)

## Steps

### 1. Intake
Gather from the user:
- Topic or theme
- Platform (LinkedIn, Twitter/X, Instagram, YouTube, email)
- Target emotion (punch, intrigue, authority, warmth, urgency, curiosity)
- Audience

### 2. Sound-Emotion Mapping
Deploy `sonic-hook-engineer` prompt → Step 2:
- Map target emotion to optimal phonemes
- Establish the sonic palette for this content

### 3. Hook Generation
Deploy `sonic-hook-engineer` prompt → Steps 3-5:
- Generate 10+ hooks with phonemically intentional opening words
- Score each with sonic analysis (opening phoneme, processing fluency, rhythm, mood signal)
- Run CVCV amplifier on top 5

### 4. Deliverable
Present ranked hooks with:
- Sonic score
- Processing fluency
- Platform fit
- Before/after comparison (standard vs sonically engineered)
