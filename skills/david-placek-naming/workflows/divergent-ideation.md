# Divergent Ideation Workflow

## Prerequisites
- Load `skills/david-placek-naming/SKILL.md` (Tier 1)
- For creative/complex ideation: also load `genius.md` (Tier 2)

## Steps

> **🔒 Pre-Flight Gate**: Before executing, run the **Decision Framework** in `genius.md` § Decision Framework. Confirm all diagnostic questions are answered.


### 1. Intake
Gather from the user:
- Topic or theme
- Platform(s) and format(s)
- Audience
- What they've already said on this topic

### 2. Frame Construction
Deploy `divergent-content-sprint` prompt → Step 2:
- Build Frame 1 (Direct), Frame 2 (Transplant), Frame 3 (Inversion)
- Ensure Frame 2 uses a genuinely unrelated domain
- Ensure Frame 3 feels uncomfortable (real inversion, not soft contrarianism)

### 3. Divergent Generation
Deploy `divergent-content-sprint` prompt → Step 3:
- Generate 5 concepts per frame (15 total)
- Score each on Surprisingly Familiar (1-10)
- No evaluation during generation

### 4. Cross-Pollination
Deploy `divergent-content-sprint` prompt → Step 4:
- Identify frame collisions (two frames producing related insights from different directions)
- Import transplant metaphors into direct frame
- Insert inversion tension into direct frame

### 5. Convergence
Deploy `divergent-content-sprint` prompt → Steps 5-6:
- Select top 5, score on 5 criteria
- Present with opening lines, sonic scores, and recommended downstream workflows

## Downstream Routing
- → `/ip-flywheel` for short-form LinkedIn execution
- → `/yt-flywheel` for long-form YouTube execution
- → `/serial-arc` for series content
- → `/roth-content` for cinematic long-form

## Quality Gate
- [ ] Three genuinely distinct frames used (not variations of the same angle)
- [ ] 15 concepts minimum generated before convergence
- [ ] At least one frame collision identified
- [ ] Top 5 concepts include elements from 2+ frames
- [ ] Sonic opening scored for each finalist


> **🛡️ Anti-Pattern Check**: Before delivering, review output against the **Anti-Patterns** in `genius.md` § Anti-Patterns. Flag and fix any violations. Cross-reference **Voice DNA** for tonal accuracy.
