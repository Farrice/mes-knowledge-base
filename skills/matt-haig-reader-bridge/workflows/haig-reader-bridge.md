# Reader Bridge

## Pre-Flight Gate

- Require an actual premise, passage, or scene plus its intended feeling.
- Preserve the original verbatim.
- Reject Matt Haig voice imitation and guaranteed-readership requests.
- Read `../genius.md` sections “Seven-Part Reader Bridge” and “Diagnose-Before-Treat.”

## Skill Acquisition

Load `../references/source-ledger.md`, `../references/rubric_v1.md`, and the matching execution prompt below.

## Execution

1. **Recover the private signal:** state what appears necessary before audience approval enters.
2. **Name the current carrier:** identify the concrete story, image, choice, or consequence doing the transport work.
3. **Locate friction:** classify it as guarded truth, abstract language, weak story motion, false hope, structural cause, or approval contamination.
4. **Pull upward:** test line → scene → motive → sequence → premise and select the highest supported cause.
5. **Choose one intervention:** rewrite only the load-bearing unit first.
6. **Protect life:** name the oddity, rhythm, exposure, or image that must survive.
7. **Compare:** explain the reader consequence of the change and issue a continue/hold/revert decision.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Fiction | Diagnose premise, character pressure, scene action, and ending residue |
| Memoir | Test whether protective distance would increase honesty |
| Essay/newsletter | Give the governing feeling a concrete event or image |
| Brand/founder story | Keep lived specificity; remove manufactured relatability |
| Short-form post | Repair one carrier and one ending, not the whole worldview |

## Output Requirements

- Private signal
- Current bridge and failure
- Causal ladder
- Highest-leverage repair
- Finished revised unit
- Protected element
- Reader consequence
- Stop decision

Execution prompt: `references/prompts-v2/reader-bridge-diagnostic.md` — honor its Output Contract.

## Quality Gate

- Is the diagnosis causal rather than adjectival?
- Did the revision change the reader experience, not just explain it?
- Did a strange particular survive?
- Is every claimed consequence labeled as predicted unless observed?
- Is there a stop decision?
