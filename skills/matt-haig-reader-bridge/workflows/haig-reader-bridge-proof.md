# Reader Bridge Proof

## Pre-Flight Gate

Require the original input, generated output, workflow name, source-anchor trace, and claimed result. A self-authored artifact cannot prove reader response, sales, expert endorsement, or human acceptance.

## Skill Acquisition

Load `../references/source-ledger.md`, `../references/rubric_v1.md`, `../references/exemplars.md`, and `../genius.md` Recognition Test.

## Execution

1. Verify file and source-anchor integrity.
2. Reconstruct the selected workflow decision from the input alone.
3. Compare the output against the protected original.
4. Run the ten rubric criteria with evidence per score.
5. Run negative controls: missing source, voice imitation, reach guarantee, already-live draft, sterilizing edit, false hope, prestige performance, unsupported proper noun.
6. Separate STRUCTURAL_VERIFIED, RUNTIME_OBSERVED, MODEL_JUDGED, HUMAN_APPROVED, and MARKET_OBSERVED.
7. Prepare the blind-pass packet or record why it cannot be completed.
8. Issue one verdict: PASS COLD, HOLD, FAIL, or READY FOR HUMAN PROMOTION REVIEW.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Diagnostic | Verify causal classification and restraint |
| Rewrite | Compare access and charge against original |
| Story generation | Check story carrier and source-independent originality |
| Claim-sensitive work | Factual and legal owners retain veto power |
| Promotion review | Human blind verdict is mandatory for A-tier |

## Output Requirements

Evidence inventory; rubric table; negative-control table; recognition verdict; proof-state ladder; remaining gaps; final verdict; next gate.

Execution prompt: `references/prompts-v2/reader-bridge-diagnostic.md` — honor its proof branch and Output Contract.

## Quality Gate

- Is runtime observation distinguished from file existence?
- Is human acceptance distinguished from model judgment?
- Does every score cite an artifact or source anchor?
- Did all eight negative controls run?
- Is promotion blocked unless the human gate is satisfied?
