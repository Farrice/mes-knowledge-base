# Implementation and Handoff Rules

## Standard Run

1. Preserve the input unchanged.
2. Select one workflow from `SKILL.md`.
3. Diagnose the highest causal layer before rewriting.
4. Load the matching born-v2 prompt.
5. Produce the complete deliverable.
6. Compare against the protected original for reader access and charge.
7. Run `rubric_v1.md`; state continue, hold, or revert.

## Handoffs

| Need | Owner | Transfer |
|---|---|---|
| Theme-first restraint | Mitch Albom | Private signal, target feeling, protected oddity |
| Rough-draft permission | Lamott/Allen | Live premise, exposure point, do-not-polish constraint |
| Idea/title compression | David Perell | Emotional proposition, story object, mystery to preserve |
| Revision sequencing | Michael Connelly | Root cause, protected original, stop rule |
| Farrice’s public voice | Fresh Voice + Voice Card | Revised substance, never a Haig-style surface |

## Evidence States

- **VERIFIED:** mechanically checked file, source anchor, or observed runtime behavior.
- **LIKELY:** coherent inference from repeated source behavior.
- **UNCONFIRMED:** needs wider corpus or named external verification.
- **UNTESTED:** built but not observed with real readers, clients, or market behavior.
- **NO EVENT:** no publication, sale, reply, or human promotion decision occurred.

## Stop Conditions

Stop and hold when source material is missing, voice imitation is requested, a bestseller result is promised, a protected original is absent, or revision lowers charge without a named reader benefit.
