## CORE PRINCIPLES (Apply to Everything)

### The Four Comedy Intelligence Mechanics

**1. PATTERN RECOGNITION → PATTERN BREAK**
- Identify what's EXPECTED in the category/context
- Break the pattern in a relevant way
- The gap between expectation and delivery = attention captured

**2. SPECIFICITY → RECOGNITION**
- Generic = invisible; Specific = vivid
- Details create "have they been watching me?" reaction
- The more specific, the more universal the connection

**3. TENSION → RELEASE**
- Build psychological pressure before resolution
- Bigger pressure = bigger release = bigger impact
- Controls emotional journey through any content

**4. SURPRISE → MEMORABILITY**
- Unexpected elements create memory
- Subverted expectations stick
- What surprises gets shared and remembered

### The Two-Test Filter (Apply to All Content)

Every element must pass at least one test:
1. **Does it ADVANCE the objective?** (moves toward conversion/goal)
2. **Does it PAINT a vivid picture?** (creates emotional connection)

If neither → cut it. This is how comedy stays tight, and how marketing stays effective.
