- Premise-seed done? Trenches drafting REQUIRES a premise with all its food (run `/baldacci-premise-seed` first if not).

## Execution
1. **No outline.** Decisions get made in-scene at full stakes — "Tom Brady in practice" doesn't sharpen anyone. If an outline exists, mine it for the premise and discard the rest.
2. **Start linear, page 1 forward.** No writing the ending first. The first chapters are the joy ("everything is new") — ride that.
3. **Shrink the unit.** You are not writing a book; you are writing "a series of short stories with connectivity." Write 2 chapters → assess → write 2 more. Firm the puzzle edges, work inward. Never hold the whole thing at once ("multiplication tables to physics" is how people drown).
4. **Watch the speed signal.** Writing fast = crystallized = keep going. Slowing down = upstream defect — stop and fix premise/character, don't push quotas ("what if they all suck?"). No word counts, no page counts.
5. **Let the computer come online.** Mid-build, the mind starts holding page 20 / page 120 / page 315 simultaneously. When a future peak scene becomes visible and electrifying, note it and keep building toward it.
6. **Pen the ending when close.** If the finale isn't settled: write the plausible placeholder, mark it PEN, disassociate (walk/shower/other project). Generate 4-5 plausible endings; return and amalgamate the strongest pieces.
7. **Edit deletion-first.** "First drafts are usually overwritten." Pass order: cut → reorder for micro-timing → add only what the two-purpose rule demands. Then run `/baldacci-scene-audit` and `/baldacci-dialogue-economy`.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Novel | Full protocol |
| Nonfiction ebook | Chapters = connected short stories answering one premise question each |
| Course | Modules drafted linearly against the promise; no curriculum-outline paralysis |
| Long-form essay/newsletter | Single-sitting trenches run; pen the ending if the close won't land |
| New writer ramp | Prescribe 5-page short stories first — "would you do an 800-lb squat on your first day in the gym?" |

## Output Requirements
- The drafted unit (chapters/sections) — real prose, decisions made, nothing deferred
- Status ledger: edges firmed, computer-state (what's now known: pages/beats ahead), speed signal read
- PEN markers on any placeholder endings + the 4-5 scenario slate when applicable
