# /baldacci-scene-audit — Two-Purpose Scene Audit

## Pre-Flight Gate (genius.md Decision Framework)
- A complete draft (or complete section) exists — this is an edit-pass tool, not a drafting tool.
- Author accepts deletion-first editing: the default verdict is cut.

## Skill Acquisition
- Load `genius.md` (patterns 8, 9; hidden knowledge: Deletion-First Editing; anti-patterns)
- Load `references/source-quotes.md` § Dialogue & Scenes

## Execution
1. **Inventory scenes/sections.** One line each: what happens, what it's for.
2. **Apply the two-purpose test.** Each scene must do ≥2 of: (a) advance the plot/argument, (b) flesh out a character/brand, (c) give the reader information they need to follow. One purpose = merge or cut. Zero = cut. "Why does it have to be in the film?" — "I don't know" is not an answer.
3. **Hunt ego writing.** Research display ("you did a lot of research and you're loathed to cut it"), beautiful-but-inert passages, atmosphere runs > 3-4 sentences (the page-flip threshold). Verdict: cut, or compress to the one mechanical-cowboy detail that does the paragraph's work.
4. **Check the rollercoaster.** Map tension across the piece: climbs, drops, and the finite go-for-it peaks. Flag flat stretches and back-to-back peaks.
5. **Micro-time the reveals.** For each key piece of information: is it released beats too soon or too late? Propose reorders — "a page difference can have enormous impact." Test moving C before A.
6. **Deliver verdicts, then apply.** Per scene: KEEP (purposes named) / COMPRESS / MOVE (to where, why) / CUT. Apply on approval or in-place when authorized.

## Content Type Adaptations
| Type | Adaptation |
|---|---|
| Novel/ebook | Full scene-level pass |
| Sales page | Sections = scenes; purpose (b) = deepen belief in mechanism/guide |
| Course | Modules/lessons; purpose (c) = arm the student for the next step |
| Newsletter/essay | Paragraph-level; page-flip threshold tightens to 2 sentences |
| Deck/webinar | Slides = scenes; two-purpose or delete |

## Output Requirements
- Scene ledger with verdict + named purposes per scene
- Cut list (with the one salvageable detail from each cut, if any)
- Reorder map for micro-timing moves
- Tension curve note: where the peaks sit, what's flat

Execution prompt: references/prompts-v2/scene-audit-report.md — honor its Output Contract.

## Quality Gate
- [ ] Every surviving scene has ≥2 named purposes
- [ ] No atmosphere run exceeds 3-4 sentences (adapted threshold by type)
- [ ] At least one micro-timing improvement evaluated (even if rejected)
- [ ] Research survives only as planted eyewitness details (99% invisible)
- [ ] Verdicts are decisive — no "maybe keep" hedging
