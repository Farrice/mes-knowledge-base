# /baldacci-game-film — Post-Release Breakdown

## Pre-Flight Gate (genius.md Decision Framework)
- The work has actually shipped and reception data exists (sales, replies, reviews, analytics, reader emails). No data = premature; schedule instead.
- Author ego parked: "If enough people say this is not how they saw it, that's MY problem."

## Skill Acquisition
- Load `genius.md` (signature move: Game-Film the Book; quality rubric)
- Load the shipped asset + its original intent notes (premise, bet sheet, peak map if they exist)

## Execution
1. **Restate intent.** What was each major element SUPPOSED to do — the planted assumptions, the peaks, the character arc, the premise promise?
2. **Collect reception.** Reader reactions verbatim where possible (emails, reviews, comments, replies), plus the numbers (sales curve, completion, opens, saves). Baldacci reads reader emails and debriefs friends deliberately — reception is sourced, not imagined.
3. **Compare intent vs. received.** Where did readers see what was intended? Where did they see something else? "This is how I intended it, but if enough people say otherwise — that's my problem, something wasn't working."
4. **Diagnose honestly.** Baldacci's own categories: nailed it ("that was a game, Dave") / telegraphed ("people figured it out before I wanted") / whiffed ("my mindset was not where it needed to be") / miscast ("maybe the character wasn't right for that plot"). Not every miss has a crystal-clear answer — say so.
5. **Bank the corrections.** Specific, forward-looking: what gets done differently in the next work. Feed craft misses to the relevant workflow (weak opening → big-pop; flab → scene-audit) and business misses to `/baldacci-author-economics` / `/baldacci-find-your-readers`.
6. **Log the standard raised.** "It gets harder because I know how good it can be if you try a little bit harder." Name the one dimension the next work must beat.

## Content Type Adaptations
| Type | Adaptation |

| Book/ebook | Full protocol; reviews + sales curve + reader mail |
| Content (posts/newsletter) | Analytics + replies; per-piece intent vs. received |
| Launch | Funnel numbers vs. designed peaks; where anticipation leaked |

## Output Requirements
- Intent vs. received table per major element
- Verbatim reception evidence (quoted, sourced)
- Honest verdicts using Baldacci's categories (including "no clear answer" where true)
- Banked corrections routed to named workflows
- The raised-standard line for the next work
