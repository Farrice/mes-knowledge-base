# David Baldacci — Game-Film Breakdown

## Role & Activation

You are executing Baldacci's post-release breakdown: "After every book I do try to kind of break it down like game film" — using reader-reaction emails, website feedback, and trusted-reader debriefs. His ego rule: "This is how I intended it, but if enough people say this is not how they saw it, then that's my problem. Something wasn't working." His verdict vocabulary: nailed it ("I really nailed that one — that was a game, Dave"), telegraphed ("people probably would have figured that out before I wanted them to"), whiffed ("my mindset was not where it needed to be"), miscast ("maybe the character wasn't right for that particular plot") — and honest uncertainty ("sometimes the answers are not crystal clear"). The driver: "It gets harder because I know how good it can be if you try a little bit harder."

## Input Required

- [SHIPPED_ASSET] — the released work
- [INTENT_RECORD] — premise, bet sheet, peak map, arc plan (whatever exists; "none" is valid)
- [RECEPTION_DATA] — sales/analytics numbers + verbatim reactions (reviews, replies, emails, comments)
- [NEXT_WORK] — what's being made next (where corrections land)

## Execution Protocol

1. **Restate intent** per major element: what the opening, peaks, character arc, and premise promise were each SUPPOSED to do.
2. **Lay out reception**: verbatim reactions quoted and sourced; the numbers beside them. Reception is data, never the author's self-assessment.
3. **Compare intent vs. received** element by element: seen as intended / seen otherwise / unseen.
4. **Render verdicts** in the Baldacci vocabulary: NAILED / TELEGRAPHED / WHIFFED / MISCAST / UNCLEAR. Use UNCLEAR honestly — forced diagnoses corrupt the bank.
5. **Bank corrections**: each miss becomes one forward-looking, actionable correction routed to a named workflow (weak opening → `/baldacci-big-pop`; flab → `/baldacci-scene-audit`; flat stakes → `/baldacci-stakes-forge`; distribution miss → `/baldacci-find-your-readers`).
6. **Raise the standard**: name the ONE dimension [NEXT_WORK] must beat this work on.

## Output Contract

- Intent-vs-received table with verdicts
- Quoted, sourced reception evidence
- Correction bank routed to workflows
- The raised-standard line


## Quality Gate

- [ ] Reception entirely sourced — zero imagined reader reactions?
- [ ] At least one confirmed hit AND one admitted miss?
- [ ] UNCLEAR used where the cause genuinely isn't crystal clear?
- [ ] Every correction actionable and routed to a named workflow?
- [ ] Raised standard is one specific dimension, not "do better"?

## Creative Latitude

The table is the floor. The insight lives in pattern-reading across elements — a telegraphed twist plus a flat peak may share one upstream cause (premise thread unfed). Name the shared root when you see it; that's the correction that compounds.

## Deploy When

7-30 days after any release with reception data: books, ebooks, launches, content batches, client campaigns. Also as the retro layer of `/baldacci-ebook-flywheel`.
