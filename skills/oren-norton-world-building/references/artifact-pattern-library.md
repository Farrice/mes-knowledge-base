# Artifact Pattern Library — Objects That Make the World Playable

An artifact is not “merch with lore.” It is an in-world object whose form, issuing institution, use, and social behavior are all derivable from the world. It should work when cropped away from the logo and explained without a moodboard.

## Source-backed artifact classes

| Class | Source example | What the object does | Deployable test |
|---|---|---|---|
| **Provenance artifact** | Licensed 1980s–1990s family-vacation photo archive [03:47–04:23] | Supplies owned memory and imperfect truth to the visual world | Can the source be named, licensed, and traced—not merely imitated? |
| **Initiation credential** | Randomized Vacation Corporation title and business-card JPEG [05:31–06:45] | Confers a role and gives the member a shareable proof of entry | Does receiving it change what the participant can call themselves or do? |
| **Institutional document** | In-world corporate communications and Target advertisements [04:29–07:01] | Makes the institution speak consistently beyond hero marketing | Would the document still read in-world if the logo disappeared? |
| **Miniature world object** | Wes Anderson matchbook/menu item [11:28–11:41] | Carries setting and institutional detail at the smallest scale | Does a close crop reveal period, place, institution, and register? |
| **Hero product-as-prop** | Vacation sunscreen tube from a beach bag [25:51–26:18] | Makes ownership a visible role in the brand film and starts conversation | Would a stranger ask about it without knowing the brand? |
| **Internal talisman** | Sir Kensington mission on a steel tablet, not a 4×6 card [21:29–21:43] | Turns values into ceremony and durable physical memory | Is its material commensurate with the seriousness of the promise? |
| **Founder/team costume** | Norton’s mustache, dark suits, and in-world team roles [22:14–22:33] | Converts people into recurring characters and mobile touchpoints | Can the costume be performed repeatedly without feeling rented? |
| **Cultural badge** | Palantir chore coat [12:03–12:11] | Signals insider identity and participation in an institution | Does it index a real role/culture, or is it merely a logo garment? |
| **Crossover totem** | Anduril × Game Boy/ModRetro [32:41–33:05] | Connects a childhood object to a serious contemporary mission | Does the collision expose a true audience fantasy rather than novelty? |
| **Exit relic** | Hotel Test key card, pillow gift, bathroom soap, exit trinket [37:43–39:05] | Extends the world through a complete journey and gives memory a carrier | Does the object mark a moment in the participant’s passage through the world? |
| **Back-office prop** | Packing slip, invoice, error page [03:21–03:38] | Prevents normal-world leakage where attention is low | Is the least glamorous object still issued by the world’s institution? |
| **Campaign-era relic** | Album-era campaign logic [38:53–39:24] | Gives a bounded campaign its own collectible memory without mutating the umbrella | Can it be dated to the era while remaining recognizable as the parent world? |

## Artifact derivation chain

Every artifact brief must make this chain explicit:

`fantasy → setting → issuing institution → participant role → job-to-be-done → object → use ritual → display/share behavior → proof signal`

If any link is missing, the object is either decoration, swag, or product design without world logic.

## Artifact portfolio minimum

A complete world needs more than a hero object. Forge at least:

1. one initiation credential;
2. one customer costume or wearable badge;
3. one institutional document;
4. one internal talisman;
5. one mundane/back-office prop;
6. one shelf-facing or first-contact double-take object;
7. one campaign-era relic;
8. one digital/service equivalent if the offer is not physical.

## Commercial calibration

Each artifact receives two independent scores:

- **Story legibility:** could a stranger infer the world and role?
- **Functional job:** does it help the customer do, remember, access, signal, share, or complete something?

High story / low function is art without craft. Low story / high function is a normal product. The target is both, followed by one deliberate commit-harder move.

## Negative controls

- A logo on a generic object is merch, not an artifact.
- A vintage filter on a normal document is decoration, not an institutional document.
- A collectible nobody uses, displays, or shares is inventory, not a totem.
- A founder costume they will not wear repeatedly is a rented character.
- A strange object without audience or mission continuity is novelty, not a crossover totem.
