## CORE PHILOSOPHY

**The algorithm distributes to INTEREST CLUSTERS, not followers.** Every content decision, positioning choice, and brand element should be judged by one question: *which interest clusters does this signal to, and how does it create tribal recognition?*

**The 7 Genius Mechanics:**
1. **Interest Cluster Targeting** — Algorithms respond to interest signals, not demographics
2. **Inclusive Addition** — Add depth without excluding non-sharers
3. **Jeep Wave Engineering** — Create instant "one of us" recognition moments
4. **Deep vs. Surface Diagnostics** — Identity-level interests create exponential connection
5. **Hybrid Format Innovation** — Fuse unrelated domains for unreplicable positioning
6. **Friend-Energy Dynamics** — "Hang out while I learn" beats "let me teach you"
7. **Unreplicable Combination Moat** — The STACK is defensible, not individual elements

**The thread through everything:** your authentic interest stack is your moat. It cannot be copied without someone becoming you.
