# /satori-composition-brief — Composition Intelligence Conductor

Use this after the communication problem and concept are clear but before layout styling, image generation, mockups, or code. It composes existing Satori mechanics into one compact handoff; it does not create a second design system.

## Activate / Skip

Activate for layout-bearing posters, ads, slides, social assets, editorial spreads, web surfaces, and multi-format identities. Skip logo-only, palette-only, pure-type selection, non-layout images, and exact-pixel repairs with locked hierarchy. Follow `semantic_libraries/antigravity/primitives/layout-composition-intelligence-contract.md`.

## Inputs

- One-sentence communication problem and audience action
- Required content ranked by importance
- Format(s), dimensions, dwell expectation, and viewing context
- Approved concept/reference/preservation constraints, if any
- Target feeling and explicit anti-targets

## Protocol

### 1. Lock Leverage

Name the single element that must win in under two seconds. Choose its dominance mechanism: scale, contrast, position, or isolation. Refuse competing primaries.

### 2. Choreograph Internal Rhythm

Write the first, second, and final eye stops. Add zero to two micro-routes only when dwell is useful; each must be lighter than and reconnect to the primary route. Define the spacing/alignment rhythm that creates trust.

### 3. Commit The Grid

Select one grid family by its job, not its prestige. State what it organizes. Budget one intentional break or choose none; a break without established order is noise.

### 4. Choose Movement And Time

Select one primary movement level from 1–6. Use literal cues only for clarity-first contexts. For Level 6 or any scroll/motion experience, map `Punch → Slow → Pull → Release`.

### 5. Budget Friction

Name one purposeful pause, what meaning or action it serves, and where flow resumes. Distinguish friction from random texture, rotation, or decoration.

### 6. Design Transfer

For every required format, state what stays invariant and how leverage, path, grid, and friction adapt. Do not specify “crop to fit.”

### 7. Compile The Handoff

Translate the decisions into three `must preserve`, three `must avoid`, and one thumbnail test. Hand the packet to the native executor; do not perform its typography, generation, or code job here.

## Quality Gate

- One leverage point, not a committee.
- Eye path names ordered stops; micro-routes never outrank the main route.
- Grid selection states a job and at most one break.
- Temporal work includes all four beats.
- Friction has a purpose and a release.
- Multi-format work adapts hierarchy instead of cropping.
- Native executor and human taste owner remain explicit.
