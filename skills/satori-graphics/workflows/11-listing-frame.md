## Execution

### Step 1: Establish Frame Brief

Document:
- **Property type**: condo / townhome / SFR / fixer / new build
- **Price**: [...]
- **Neighborhood**: [SFV-specific area]
- **Hero feature**: the ONE thing that makes this listing exciting (kitchen, view, lot, layout, character)
- **Buyer state at scroll**: distracted, scrolling, half-skeptical, slightly tired (cold reality)
- **Target next-emotion**: "I could see myself there" / "we should look at this" / "save this for tonight"

### Step 2: Apply LIFT — Frame-Specific

#### L — Leverage Point
The leverage on a listing frame is the **hero feature** — defined by what most uniquely sells *this specific property* to *this specific buyer state*.

Three leverage modes, ordered by frequency:
- **Mode 1 — Visual moment** (view, kitchen, light, character feature): the photo IS the leverage. Type overlay is small, anchored, qualifier-only. Use this when the property has a stand-out visual feature.
- **Mode 2 — Comparative anchor** (e.g., "$X less than your rent" / "lowest $/sqft on the block this year"): the *number paired with comparison* is the leverage. The photo supports. Use this when the property's compelling angle is the math, not the visuals — common for fixers, condos, and inventory in tight markets where spec-comparison breaks the scroll.
- **Mode 3 — Spec pairing** (beds + price + neighborhood): hierarchy-driven, no single leverage. Use this only when you have a carousel and the opening frame is a navigational landing, not a scroll-stopper.

**Pick ONE mode per frame.** Frames that try to be both Mode 1 and Mode 2 fail — the photo and the comparison number compete for leverage, and the eye lands on neither. If the property has *both* a visual hero AND a strong comparison, run two frames (Mode 1 hero frame + Mode 2 comparison frame in the carousel) instead of fighting them in one.

#### I — Eye Choreography
Mobile-first scan path:
1. Hero photo (or hero number) hits first
2. Eye drops to qualifier (price + neighborhood)
3. Eye lands on action cue (handle, save indicator, "more")

Test: trace the path in <2 seconds with a non-buyer. Path should be obvious.

#### F — Friction & Flow
- **Good friction**: A subtle text overlay that *implies* without yelling ("walk to coffee" / "$3K below comps" / "first time on market")
- **Bad friction**: Loud "JUST LISTED!" stamps, price flag with "REDUCED" decoration
- **Flow zones**: pure-photo zones with no text — these are the "imagine yourself here" beats

#### T — Transferability
Listing frames must hold across:
- Reel (1080×1920 vertical)
- Square post (1080×1080)
- Instagram story
- Substack thumbnail (typically 16:9 or 4:3)
- Email preview thumbnail (small)

Engineer leverage to survive crop. Most frames lose at thumbnail because the hero photo gets cropped.

### Step 3: Apply Predictive Empathy — Jen's ICP

**Buyer state map** (Jen's first-time SFV buyers):
- **Pre-state**: Tired from rent ($2.5K-3.5K/mo for nothing), priced-out feeling, half-believing they'll never own
- **Awareness level**: Problem-aware, sometimes solution-aware, rarely product-aware (this listing specifically)
- **Trust level**: Cool to mildly warm (Jen's content is recognizable, but buyer is wary of agents in general)
- **Time window**: Skim (<3 seconds before scroll continues)

**Loud-default to avoid**:
- "DREAM HOME!" / "PRICED TO SELL!" → triggers "I've seen 1,000 of these" filter
- Stark contrast with luxury-poster aesthetic → wrong tier
- Dramatic photo crops with HDR push → screams "agent shot"

**Empathy shifts to apply**:
- **Tone**: Conversational text overlays (Jen's voice — "let's check it out!" energy at lower volume in static)
- **Visual energy**: Soft contrast, breathable crop, palette warm-but-grounded (avoid blue-cast luxury palette)
- **Trust cue**: ONE — neighborhood marker that grounds reality ("Encino, CA"), or square footage reality-check, or honest day-on-market (if recent listing)
- **Palette**: warm whites, terracotta accent, ink black; or cool dusty blue + cream + warm gray. AVOID: hard luxury black + gold; AVOID corporate brokerage red
- **Pacing**: For carousel: opening frame breathes, second frame qualifies, third frame previews interior

### Step 4: Apply Memory Encoding

Pick ONE encoding move (resists scrolling past):

#### Move A — Specific Detail Anchor
Lead with the ONE specific detail that lodges (not "great kitchen" → "south-facing kitchen window over the sink"). The detail does the encoding.

#### Move B — Honest Constraint Reframe
Lead with what's "imperfect" but earns rent (small backyard / no garage / older fixtures) framed as the *reason* it's affordable. Reframe lodges because it's culturally rare for listings.

#### Move C — Imagined-Future Vignette
Lead with an implied future moment ("morning coffee on this patio") rather than the property feature alone. The viewer pre-experiences ownership.

#### Move D — Comparative Anchor
Lead with the explicit comparison ("$X less than your rent") that makes buying *legible*. Anchors the buy-vs-rent math in one second.

**Compatibility note**: Move D is most powerful when paired with Mode 2 leverage from Step 2 (the comparison number IS the leverage). Do NOT combine Move D with Mode 1 (visual-hero leverage) in a single frame — the comparison number will compete with the photo for attention. Either commit to comparison-as-leverage and shrink the photo to support, or commit to photo-as-leverage and use Move A/B/C for memory encoding.

### Step 5: Apply Anti-AI-Slop (3-4 imperfections)

Listing frames default to AI-template look (HDR push, perfect crop, stat-blast overlay). Inject:
1. **Asymmetric crop** — hero photo cropped off-center; subject takes 60% of frame, breathing on one side
2. **Type-size variance** — neighborhood marker smaller than expected; hero number larger than expected (creates rhythm)
3. **Color punctuation** — one accent color used in ONE place only (e.g., a "save" indicator or year-built marker)
4. **Subtle texture** — barely-there grain or paper texture (only on backgrounds, not on photos)

## Content Type Adaptations

| Listing format | Special considerations |
|---|---|
| **Reel opening frame** | First 1.5 sec scroll-stop — leverage on visual; minimal text overlay |
| **Reel mid-frame** | Specifications-heavy; Hierarchy grid + clear leverage on the spec |
| **Square post** | Aspect ratio compromise — engineer leverage to survive crop both ways |
| **Story** | Vertical, low text density — leverage + one trust cue, nothing else |
| **Carousel slide 1** | Hook frame — memory encoding is mandatory |
| **Carousel slide 2-3** | Continuation — flow zones, reduced contrast, specs |
| **Carousel last slide** | Return to leverage with CTA ("DM for showing") |
| **Substack thumbnail** | 16:9 — lower urgency than reel; can lean editorial; one detail anchor |
| **Email preview** | Survives at small size — must read at 200×140 |
