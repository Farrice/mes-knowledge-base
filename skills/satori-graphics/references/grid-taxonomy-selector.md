# Grid Taxonomy Selector

Pick the right grid for the brief. Default-grid syndrome (everything goes on a 12-column) is amateur thinking.

---

## Decision Tree

**Step 1: What's the dominant content type?**
- Long-form text → see "Text-First Grids"
- Mixed content (text + product / text + image) → see "Hybrid Grids"
- Visual-first (photo / image-driven) → see "Visual-First Grids"
- Logo / mark → see "Logo Grids"

**Step 2: What's the format?**
- Magazine / newspaper / editorial → Column grid
- Book / long article → Manuscript grid
- E-commerce / product → Modular grid
- Social / gallery → Square grid
- Hero web / poster → Asymmetric or Hierarchy grid
- Infographic / 3D illustration → Isometric
- Round logo / mark → Circular
- Geometric packaging → Triangular

**Step 3: How will you break the grid?**
- For impact → one element disrupts (oversize, cross-column, off-grid)
- For hierarchy → top-tier content spans more cells
- For tension → element rotated / partially outside grid

## The 12 Grid Types

### Text-First Grids

#### Baseline Grid
**Use for**: Aligning body text, headlines, captions across columns
**Operating rule**: Multiples of base leading
- Body text 14pt → headline 28pt (2×) or 42pt (3×)
- Spacing between sections also follows the multiple
**Pairs with**: Any other grid (baseline is foundational)

#### Manuscript Grid
**Use for**: Books, long articles, single-content pages
**Operating rule**: Single column with wide margins
- Margins reserve space for notes, images, drop caps
- Comfortable measure: 50–75 characters per line
**Pairs with**: Baseline grid

---

### Hybrid Grids

#### Column Grid
**Use for**: Magazines, newspapers, multi-content websites
**Operating rule**: 4–12 columns with consistent gutters
- Span content across multiple columns to create hierarchy
- Featured image: 3 columns; supporting text: 1 column
- For detailed work, split a 3-column to 6-column for finer control
**Common moves**:
- Headline spans 3 columns; deck spans 2; body fills 1
- Image bleeds across full width; caption sits in 1 column

#### Compound Grid
**Use for**: Multi-content layouts that need both listing and detail
**Operating rule**: Combine column (for listings) + modular (for details)
- E-commerce category page: column for product titles + modular for product cards
- Don't cramp — keep breathing space between the two grids

#### Hierarchy Grid
**Use for**: Headline-driven layouts, content-heavy navigation pages
**Operating rule**: Different module sizes encode different priority levels
- Primary content: large, bold, high contrast
- Secondary content: medium, muted tone
- Tertiary content: small, low contrast
**Common move**: Large hero block + 2-3 medium feature blocks + small detail row

---

### Visual-First Grids

#### Modular Grid
**Use for**: E-commerce, product showcases, dashboards
**Operating rule**: Each module gets its own cell (image, title, description, price)
- Vary module size by product importance — best-sellers larger
- Span featured items across 2 cells horizontally
- Maintain consistent inner-module proportions

#### Asymmetric Grid
**Use for**: Hero sections, dynamic layouts, energetic posters
**Operating rule**: Hero image / headline takes more space; supporting columns provide secondary flow
- Lets you naturally direct attention to the most important element
- Allows layering: text overlapping image, diagonal lines breaking columns
**Risk**: Easy to overdo — anchor with one strong leverage point

#### Square Grid
**Use for**: Instagram feeds, photo galleries, uniform collections
**Operating rule**: Equal-size square cells in a grid
- Add color/pattern variation to select squares for breathing
- Adheres to symmetry; lean on visual content variety for interest

#### Rule-of-Thirds Grid
**Use for**: Photo composition, key-visual placement
**Operating rule**: Divide canvas into 9 equal rectangles (2 horizontal + 2 vertical lines)
- Place key subject on a grid intersection
- Break the rule occasionally for dramatic off-balance effect

---

### Logo Grids

#### Circular Grid
**Use for**: Round / organic logos, badges, seals
**Operating rule**: Concentric circles + radial lines for symmetry
- Balance is crucial; circles attract symmetry expectations
- Use spaces between elements as design opportunities
**Pairs with**: Curvy visual primitive (organic, friendly, inclusive)

#### Triangular Grid
**Use for**: Modern packaging, geometric brand systems
**Operating rule**: Triangular module layout creates dynamic geometric patterns
- Position logo + product info at key intersection points
- Combine with bright colors / metallic foil at intersections
**Pairs with**: Sharp-angle visual primitive (robust, technical, modern)

---

### Specialty Grids

#### Isometric Grid
**Use for**: 3D illustrations, infographics, building/data visualizations
**Operating rule**: 30°/30°/120° grid creates 3D depth feel
- Light colors on top + dark beneath = volume + realism
- Don't shy from shadows for shape definition
- Best for technical / architectural / data-heavy content

## Grid-Breakage Rules

Establishing a grid → adhering to most → breaking deliberately is the highest-tier grid use.

### When to break (not random — purposeful)
1. **For leverage** — one element off-grid commands attention (the disruption is the focal point)
2. **For tension** — small breakage adds energy without sacrificing readability
3. **For hierarchy emphasis** — top-tier content lives outside the system to signal "different"
4. **For brand identity** — consistent breakage style becomes part of the visual language

### When NOT to break
- When the grid is already complex (compound grids)
- When the content density is high (breakage compounds chaos)
- When the brief calls for trust / corporate feel (breakage feels chaotic)
- When you don't have a defensible reason for the break

### Breakage budget
**One major breakage per layout.** Multiple breakages compound into "no grid at all."

## Quick Selector by Common Briefs

| Brief | Recommended Grid | Breakage |
|---|---|---|
| LinkedIn carousel | Square or Modular | Optional — one slide off-grid for emphasis |
| Real estate listing reel frame | Asymmetric or Hierarchy | Hero image breaks; secondary info anchored to grid |
| Streetwear poster | Asymmetric or Hierarchy | Strong — one element rotated or oversized |
| Newsletter article | Manuscript + Baseline | None — readability first |
| Brand pitch deck | Hierarchy or Modular | Strategic — title slide breaks; content slides hold |
| Product e-commerce page | Modular + Compound | Featured product breaks via 2-cell span |
| Logo on round seal | Circular | None — symmetry serves brand |
| 3D infographic | Isometric | None — system serves the depth illusion |
| Magazine spread | Column + Baseline | Featured spread breaks via cross-column image |
| Mobile app onboarding | Hierarchy | None — clarity beats expression |
| Resume / CV | Manuscript or Hierarchy | None — readability rules |
| Wedding invitation | Manuscript or Asymmetric | One ornamental element off-grid |
