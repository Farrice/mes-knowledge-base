# Satori Graphics — Genius Context

> **Unified genius context for the satori-graphics skill.**
> Every workflow loads this file before execution. It is the operating system for composition, layout, logo systems, and design psychology in the Satori tradition.

**Source**: 4 YouTube masterclasses (~10,652 words) — psychology mindsets, composition + layout, logo design, professional design principles. See `extractions/satori-graphics/extraction-report.md` for full source-of-truth.

**Domain**: Graphic design — composition, layout, logo systems, design psychology.

**Positioning**: The composition and logo thinker. Where typography agents handle *type*, Satori handles *how the page itself thinks* — movement, grids, leverage points, friction, and the psychology that makes designs memorable.

---

## The Underlying Belief

> **Design is decision-making before it is expression.**

Every Satori framework is structured to force decisions:
- Verb-not-noun forces **concept**
- One-sentence brief forces **clarity**
- Flip-test forces **structural honesty**
- LIFT forces **explicit hierarchy**
- Why-before-what forces **rent-paying elements**

The design is the decision audit. Aesthetic moves cannot rescue weak decisions; they only stylize them.

## The 12 Genius Patterns

### GP-01 — Why-Before-What Decision Gate
Every element on a layout must "pay rent" — serve a stated reason. If you can't answer "why is this here?" with a non-aesthetic justification (concept, hierarchy, psychology), it gets evicted.

> *"A competent designer treats every element like it has to pay rent. If it doesn't serve a purpose, then nine times out of 10, it's going to get evicted."*

**Operational test**: Each element must have one of three reasons documented:
- **Concept reason** — serves the central idea/metaphor
- **Hierarchy reason** — guides eye to leverage point
- **Psychology reason** — engineers a specific emotional response
If you can't write the reason in one sentence, evict it.

---

### GP-02 — Predictive Empathy
Design not for what the viewer feels *now*, but for what they will feel *next* — and the day after. Emotional foresight as discipline. Soft tone often outperforms loud tone because most viewers are not pre-aligned.

> *"It assumes the viewer is already convinced, already interested, already emotionally aligned. But the truth is most people aren't."*

**Operational test**: After viewing the design, what emotion does the viewer carry into the next 60 seconds of their life? Engineer for that, not the impact moment.

**Default move when in doubt**: Soften the headline tone, add breathing space, add one trust cue, shift palette toward the *desired-end-emotion* not the alarm-emotion.

---

### GP-03 — Memory Encoding via Resolve-Something
Designs become memorable when they give the viewer something to resolve — slightly off-balance, conceptually layered, or metaphorically loaded. The pause-to-figure-it-out *is* the memory being formed.

> *"The art of giving the viewer something to resolve — something slightly off-balance. Something that whispers a question instead of handing out an answer."*

**Operational test**: Does the design hand-deliver its meaning, or does it require resolution? Designs that hand-deliver meaning don't get encoded into memory; designs that require a brief moment of resolution do.

**Memory-encoding moves**:
- **Metaphor substitution** (records arranged as a heart instead of scattered)
- **Absence as presence** (empty clothes in a chair, body-shaped void)
- **Conceptual swap** (Thinker statue with off-switch instead of head)
- **Controlled imbalance** (something slightly off-grid that demands the eye)

---

### GP-04 — Movement & Flow Ladder (6 levels)
Movement is not one thing. It is a 6-level hierarchy. Pick the level that fits the brief; do not default to level 1.

| Level | Name | Mechanism | Use when |
|---|---|---|---|
| 1 | **Directional cues** | Literal arrows, gaze direction | Beginner clarity, wayfinding, sports adverts |
| 2 | **Hierarchy-driven flow** | Size + contrast as invisible guidance | Editorial layouts, minimal posters |
| 3 | **Multiple flows** | Main route + micro-routes | Rich content, longer dwell, exploration |
| 4 | **Implied motion** | Repetition, scaling, blur, gradient | Static feels alive without animation |
| 5 | **Flow disruption** | Strategic rotated/blocking element | Slow viewer at key message, add tension |
| 6 | **Temporal flow** | Beats — impact / linger / release | Master-tier; rhythm like music |

> *"99% of designers don't consider this temporal flow of time."*

---

### GP-05 — Grid Taxonomy (11+ types as a tool kit)
Grids are domain-specific. Pick by purpose, not default. Establish the grid → adhere to most → break it deliberately for impact.

| Grid | Best for | Key move |
|---|---|---|
| **Baseline** | Body text alignment | Multiples of base leading (e.g., 14pt body → 28pt headline) |
| **Column** | Magazines, newspapers, multi-content | Span content across multiple columns for emphasis |
| **Modular** | E-commerce, product showcases | Vary module size by importance (best-sellers larger) |
| **Manuscript** | Books, long-form reading | Single column + wide margins for notes/images |
| **Hierarchy** | Headlines + nav-heavy layouts | Different module sizes; primary big + bold, secondary muted |
| **Asymmetric** | Dynamic, eye-catching layouts | Hero takes more space; secondary supports |
| **Square** | Galleries, Instagram, uniform feeds | Add color/pattern variation in select squares |
| **Rule-of-thirds** | Photo placement, key visuals | Place subject on grid intersection; break for drama |
| **Compound** | Multi-content with detail | Column for listings + modular for details |
| **Isometric** | 3D illustrations, infographics | Light on top + dark beneath = volume |
| **Circular** | Round/organic logos | Symmetry + interesting negative space |
| **Triangular** | Geometric packaging, modern boxes | Logo + product info at intersection points |

**Operating rule**: Establish grid → adhere to most → break it deliberately for **one** point of impact. Both grids and grid-breakage live in the same design.

### GP-06 — LIFT System (Leverage / Eye / Friction / Transferability)
Satori's acronym and sequenced audit pattern over four canonical composition disciplines. Each component is foundational design theory (focal-point dominance, eye-flow choreography, tension/release, scalability — taught in Müller-Brockmann, Lupton, Tschichold, Vignelli). Satori's contribution is the LIFT acronym, the sequenced four-step audit, and the 1-10 anchored scoring rubric per dimension.

**L — Leverage Point**
The single most important element, dominated via scale / contrast / positioning / isolation. A stranger should name it in <2 seconds.

**I — Eye Choreography (Internal Rhythm)**
The journey from leverage point through supporting elements is choreographed, not accidental. Predictable spacing builds trust; deliberate disruption re-engages attention.

**F — Friction & Flow**
*Good friction* (tight leading on a quote, blur reinforcing theme, a rotated block) serves emphasis. *Bad friction* (too many fonts, competing focal points) is noise. Smooth-reading zones release tension.

**T — Transferability**
The identity holds at thumbnail size, on light + dark, across ≥2 formats (web/print/motion). If the concept is scale-dependent, the concept is wrong.

**Apply sequence**: Identify leverage → choreograph eye journey → place friction strategically → test transferability. Each check is independent; weakness in any one drops the layout grade.

### GP-07 — Verb-Not-Noun Logo Ideation
The amateur trap: starting from nouns (shield, arrow, mountain, initial). The pro starts from verbs — what the brand *does* (protects, connects, accelerates, simplifies, guides). Verbs unlock psychology; nouns lock you into clichés.

> *"Not what it is, but how it actually acts."*

**Process**:
1. List 10 verbs the brand performs for its audience
2. Pick the strongest 1-2 verbs (primary + supporting)
3. Map each verb to shape psychology (vertical/horizontal/curve/angle/scale)
4. Design from the verb's psychology — combine with a noun anchor only if the noun reinforces the verb

**Example**: GRI Insurance — shield (noun) is generic, but horizontal straight lines (verb: *gives calm*) made it work. The verb psychology is the unlock.

### GP-08 — One-Sentence Brief Reduction
Before sketching, reduce the entire brief — every value, persona, paragraph — to ONE clear sentence. The sentence does not need to be polished or clever; it needs to be clear enough that every subsequent decision can be checked against it.

**Format**: *"A [thing] that [verb] [audience] [outcome/feeling]."*

**Example**: Cybersecurity → *"A system that quietly protects your data in the background."*

Now every shape, color, weight, spacing decision gets tested against that sentence:
- Does this feel quiet?
- Does this feel protective?
- Does this feel background?

If you can't write the one-sentence brief, you're not ready to design. If a design choice contradicts the sentence, the choice is wrong (not the sentence).

---

### GP-09 — Concept-Direction-First (Visual Primitive Lock-In)
Lock the visual primitive (line type, geometric family, motif) BEFORE designing. Once locked, designing becomes constrained exploration, not wandering.

**Visual primitive psychology cheat-sheet**:
- **Vertical lines** → strength, stability, structure, security
- **Horizontal lines** → calm, peace, reliability, breadth
- **Curves / circles** → friendly, organic, inclusive, soft
- **Sharp angles** → robust, aggressive, technical, modern
- **Asymmetry** → dynamic, modern, energetic
- **Symmetry** → trustworthy, classical, premium
- **Hand-drawn / imperfect** → human, crafted, real, warm
- **Geometric / precise** → systematic, technological, clinical

**Example**: Helmets OS logo locked vertical lines from the start — operating system needed to feel secure and reliable.

### GP-10 — Logo as Memory Hook (Not Story)
The logo is *one part* of a brand system — an anchor point, a memory hook. Trying to make the logo say *everything* about the brand is the amateur trap.

> *"The Nike swoosh or the Apple logo. These logos do not tell you what these brands do or sell. They act as a memory hook."*

**Logo's two jobs**:
1. **Recognizability** — iconic, simple, gets into the brain on repeat exposure
2. **Shape psychology** — the visual primitive carries the *feel* of the brand

**Brand-tell job goes to**: Typography, color palette, layout style, copy voice, photography choice, motion. Not the logo.

**Symptom of overload**: A logo with a wordmark, a symbol, a tagline, a hidden meaning, and 4 colors. Cut until only the anchor remains.

---

### GP-11 — Anti-AI-Slop via Human Imperfection
AI layouts in 2026 are too perfect — symmetrical, evenly spaced, polished. The human moat is "ruin the perfection in a bring-it-to-life way." Controlled imbalance, micro-decisions, purposeful rhythm.

> *"AI can give you the clean version every time, but only you can give the human version."*

**Human-imperfection moves**:
- An element creeping over another (bottle over typography)
- A subtly blended logo across the background
- A hand-drawn line connecting two distant elements
- A controlled crop that defies symmetry
- Asymmetric breathing room (more on one side)
- A glyph or motif at slightly-off rotation
- A gradient that tapers off-axis

**Critical reframe**: Brands that hire human designers do so for *thinking and psychological experience*, not output. If your service charges for output (turnaround, volume), you compete in the AI lane. If you charge for decisions (concept, primitive lock, predictive empathy), you compete in the human lane.

---

### GP-12 — Flip-Design Technical Audit
A 90-second structural check. Flip the design upside down — your brain stops reading content/context and starts seeing structure (alignment, white space, micro white space, technical mistakes).

**What flipping reveals**:
- Misaligned baselines
- Inconsistent margin/gutter spacing
- White-space asymmetry that "felt right" but isn't
- Visual weight imbalance between quadrants
- Edge-tension issues (elements too close to bleed)

**Operational rule**: Run the flip-test before submitting any design. It costs nothing, takes under two minutes, and surfaces structural failures the designer's eye has gone blind to.

## Hidden Knowledge (Tacit Insights)

### HK-01 — What Designers Actually Sell
Brands hire human designers for **thinking and psychological experience**, not output. If your pricing model rewards turnaround speed, you've positioned yourself in the AI lane.

### HK-02 — Comfort = The Real Skill Decay
"Feeling efficient" is the danger zone, not the success zone. The moment your workflow feels comfortable is the moment to audit it.

### HK-03 — Two Pairs of Eyes as Scaling Mechanism
Build a structured "fresh eyes" pass into every project. Not feedback — **fresh perception**. Hours of designing make obvious flaws invisible to the designer.

### HK-04 — Presentation Standardization as Anti-Bias
Same client → identical presentation structure for every concept. Forces the client to compare *concept strength*, not presentation aesthetics.

### HK-05 — Friction Has Two Modes (Good/Bad)
The distinction isn't presence/absence of friction — it's whether friction *serves the leverage point* or *competes with it*.

### HK-06 — Transferability ≠ Responsive Design
"Transferability" is deeper than responsive layout. It's whether the *concept* survives shrinkage / format change / context shift.

### HK-07 — Speed Doesn't Fix Weak Thinking
Faster execution makes weak concepts arrive faster. Time spent thinking is the moat, not time saved producing.

### HK-08 — Concept Pause = Memory Formation
The pause-to-resolve a clever design *is* the memory being formed. Designs that hand-deliver meaning don't get encoded; designs that require resolution do.

## Hall of Fame Exemplars

### HOF-01 — AI Awareness Poster (Why-Before-What in action)
Two posters around AI awareness. Loser: decorative tech motifs around edges, AI face, lots of "looks AI-ish" decoration. Winner: hand-drawn imperfect *Thinker* statue with off-switch instead of a head. Every choice has a reason — handdrawn = human, Thinker = creativity, off-switch = the concept distilled.
**Lesson**: Decoration without reason loses to refined intention every time.

### HOF-02 — Vinyl Records Heart (Memory Encoding)
Two LP records and one album sleeve arranged into a heart shape. Music = emotion. Records = romance. Conceptual twist lodges in memory because the brain recognizes intention.
**Lesson**: When a metaphor is available, use it instead of standard arrangement.

### HOF-03 — Empty Clothes in Chair (Memory via Absence)
Body-shaped empty clothes in a chair — no person, no face. Plays into depersonalization theme. Eerie, clever, impossible to forget.
**Lesson**: The strongest visual choice is sometimes what's *not there*.

### HOF-04 — Iron Grip Logo (Memory Hook + Shape Psychology)
Strong angular lines representing robust/strong psychology. Doesn't tell you what the brand does. Iconic + the shape psychology is right for martial arts.
**Lesson**: Logo's job is anchor + psychology, not story.

### HOF-05 — Helmets OS Logo (Concept-Primitive Lock-In)
Vertical lines locked from the start. OS needed to feel secure, reliable, structured. Every subsequent choice was constrained exploration within "vertical-lines space."
**Lesson**: Locking the primitive early turns wandering into directed exploration.

## Signature Moves (8 deployable plays)

| # | Move | When |
|---|---|---|
| 1 | **The Rent Test** | Pre-delivery audit. Each element gets a concept/hierarchy/psychology reason or eviction. |
| 2 | **The Verb Replacement** | Logo intake. Every noun → verb. Design from the verb's shape psychology. |
| 3 | **The One-Sentence Reduction** | Brief intake. Compress the whole brief to one declarative sentence before any sketching. |
| 4 | **The Flip** | Pre-delivery. Flip upside down for 30 seconds. Catches structural failures. |

| 6 | **Fresh-Eyes Pass** | Mid-project. Show to a designer-friend who hasn't been staring at it. |
| 7 | **The Predictive-Empathy Soften** | When design is loud. Soften tone, add breathing room, add one trust cue. |
| 8 | **The Thumbnail Test** | Pre-delivery. Shrink to thumbnail, test on light + dark, test on ≥2 formats. |

## Quality Rubric (10 criteria, ≥8/10 each = ship-grade)

A Satori-grade design earns ≥8 on each:

1. **Why-defensibility**: Every element has a stated, non-aesthetic reason.
2. **Leverage clarity**: One element is unmistakably the focal point. <2-sec naming test.
3. **Eye-flow predictability**: The journey is choreographed; spacing/alignment build trust.
4. **Friction discipline**: Friction (if used) serves emphasis. No noise competing with leverage.
5. **Predictive empathy alignment**: Engineered for the desired *next* emotion.
6. **Memory encoding**: At least one element invites resolution, metaphor, or pause.
7. **Concept-primitive lock**: A visual primitive locked early and respected throughout.
8. **Anti-AI-slop signal**: ≥3 deliberate human-imperfections / micro-decisions.
9. **Transferability**: Identity holds at thumbnail, on light + dark, across ≥2 formats.
10. **Flip-test pass**: Upside-down inspection reveals no structural failures.

**Composite ≥8.0** = ship-grade. Below 7.0 = rework.

## Anti-Patterns (Auto-Reject)

1. **Decoration without reason** — visual chaff, "looks designy"
2. **Noun-locked logos** — starting from object metaphors that lock into cliché
3. **Logo carrying the whole brand story** — amateur overload
4. **AI-as-shortcut** — prompt → output → ship, no thinking layer
5. **Speed-as-virtue** — shipping fast on weak thinking
6. **More-equals-better layering** — stacking effects vs simplifying
7. **Loud-by-default** — assuming viewer is pre-convinced
8. **Aesthetic-first decisions** — colors/fonts before concept and primitive
9. **Mixed-presentation pitches** — letting presentation aesthetics confound concept comparison
10. **Comfort coasting** — same workflow because it feels efficient, not because it's still optimal

## When NOT to Use Satori Tools

- **Pure typography selection** → use `kittl-graphic-design` instead
- **DESIGN.md token codification** → use `jack-roberts-design-mastery`
- **AI image / video prompt engineering** → use `creative-direction` (Creative Director)
- **Brand strategy / positioning** → use `greg-hoffman-brand-mastery` or `dai-media`
- **Stylized poster generation production** → use `fantastic-posters`

Satori is for the **composition logic, layout flow, logo concept, and design psychology** layer — the layer that sits *above* type and *below* DESIGN.md codification.

| Satori principle | Transfers to | Compound application |
