# Satori Graphics: Design-Thinking + Composition + Color Engine

> **Design is decision-making before it is expression.** Every Satori framework forces decisions before output — communication-problem forces purpose, hidden-truth forces concept, one-sentence brief forces clarity, 5-layer color forces strategy, LIFT forces hierarchy, flip-test forces structural honesty.
>
> Source: Satori Graphics YouTube masterclass series — v1 (~10,652 words, 4 videos: psychology mindsets, composition + layout, logo, professional principles) + v2 (2026-07-04, ~7,800 words, 5 videos: high-level design thinking, color full-guide, creative-concept techniques, high-vs-low-level mindsets, design business).

**Core Capabilities:**
- **Originate concepts** via the 7-technique creative engine — hidden-truth, one-big-idea, audience-language, literal, what-if, tiny-detail, emotion-over-info *(v2)*
- **Build strategic color systems** — 5-layer model (Functional→Strategic) × 4-role palette (Primary/Secondary/Accent/Neutral) → hex tokens *(v2)*
- **Run the full generative pipeline** — communication problem → concept → hierarchy → color → feeling → memory hook → production brief + tool handoff *(v2)*
- **Diagnose perception gaps** — intended-vs-perceived reading via the sequence-recall test *(v2)*
- **Calibrate feeling** — tune the same asset to premium/cheap/playful via type + color + layout *(v2)*
- Audit any layout against the LIFT system (Leverage / Eye / Friction / Transferability)
- Engineer movement at the right level (1-6 from directional cues to temporal flow)
- Select grids from an 11-type taxonomy with explicit breakage rules
- Develop logo concepts from verbs (not nouns) with locked visual primitives
- Engineer memory hooks; inject human imperfection to escape AI-default templates
- Run 90-second flip-test technical audits + multi-touchpoint brand audits

**Domain**: Graphic design — communication thinking, concept origination, color strategy, composition, layout, logo systems, design psychology.

**Positioning vs. roster**: Where Kittl handles **typography** and Jack Roberts handles **DESIGN.md codification**, Satori is the **design-thinking brain above the production tools**. v2 rule: **Satori decides; the generation tools (`fantastic-posters`, `creative-direction`, `product-design-build`) execute.** Never let a generation tool originate the concept.

## The 17 Genius Patterns

See [genius.md](genius.md) for full context. GP-13 to GP-17 are the v2 generative layer and run *first* in a real workflow. Quick reference:

| # | Pattern | Operating test |
|---|---|---|
| GP-13 | **Communication-Problem-First** *(v2)* | Write the communication problem in one line before any layout; cut what doesn't solve it |
| GP-14 | **Feeling-Before-Information** *(v2)* | Name the target feeling before choosing type/color; match the audience |
| GP-15 | **Strategic Color System** *(v2)* | 5 layers (Functional→Strategic) × 4 roles; every color has a job |
| GP-16 | **Creative Concept Engine** *(v2)* | 7 techniques; start from the hidden truth, commit to one idea |
| GP-17 | **Perception Gap** *(v2)* | Sequence-recall test; if it needs explaining, it failed |
| GP-01 | Why-Before-What (Rent Test) | Each element has a concept/hierarchy/psychology reason or eviction |
| GP-02 | Predictive Empathy | Engineer for the *next* emotion the viewer carries, not impact |
| GP-03 | Memory Encoding (Resolve-Something) | Whisper a question, don't deliver an answer |
| GP-04 | Movement Ladder (6 levels) | Pick the right level for the brief; default to L2-3 |
| GP-05 | Grid Taxonomy (11+ types) | Pick by purpose, not default; budget 1 break per layout |
| GP-06 | LIFT System | Leverage / Eye / Friction / Transferability — sequenced disciplines |
| GP-07 | Verb-Not-Noun (Logo) | Start from what the brand *does*, not what it *is* |
| GP-08 | One-Sentence Brief | Reduce the entire brief to one declarative sentence |
| GP-09 | Visual Primitive Lock-In | Lock the line type / geometry before designing |
| GP-10 | Logo as Memory Hook | Logo's job: anchor + psychology, not story |
| GP-11 | Anti-AI-Slop (Human Imperfection) | 3+ deliberate imperfections; brands hire designers for thinking, not output |
| GP-12 | Flip-Design Technical Audit | 90-second structural audit before delivery |

## Source Caveats

1. **Sponsorship sections filtered**: Promotional segments were excluded from extraction — v1: Dream Eater C Dream 5.0, Skywork AI / Nano Banana 2; v2: Pixai.io, Superhuman Mail, Octo/Dream C-dance 2.0.
   - **v2 caveat**: The color, concept, and design-thinking material (GP-13 to GP-17) comes from 5 additional 2026 Satori videos; the same practitioner-level positioning applies. The 4-role color system and 5-layer color model are Satori's framing of widely-taught color theory (Itten, Albers lineage) — Satori's contribution is the layered decision sequence and the "every color has a job" role system, not discovered theory.
2. **Visual context not captured**: Source videos exceeded the 10-min plugin cap; transcripts carry the visual reasoning (Satori narrates explicitly), but frame-level extraction is unavailable.
3. **Practitioner positioning**: Satori is a YouTube design educator at the practitioner level — not Vignelli/Rand-tier industry icon. Output reflects "synthesized practitioner knowledge for working designers," not master-designer voice impersonation.
4. **LIFT system attribution (honest version)**: LIFT is Satori's acronym and sequenced audit pattern. The underlying disciplines are canonical composition theory:
   - Leverage point = focal-point dominance (Müller-Brockmann, Lupton)
   - Eye choreography = visual hierarchy + reading-path (Tschichold)
   - Friction & flow = tension/release (standard editorial vocabulary)
   - Transferability = scalability / system design (Vignelli)
   Satori's contribution is the LIFT acronym, the sequenced four-step audit, the 1-10 anchored scoring rubric per dimension, and the veto rule (any dimension ≤4 caps composite at C). Workflows attribute LIFT as Satori's audit pattern over canonical disciplines — not as discovered theory.
