# Multiply Formats — Turn One Proven Book Into 7+ Streams

## Pre-Flight Gate

Run this ONLY for a **proven seller** — a book that has cleared reviews and is generating consistent sales in its primary format. Multiplication is a leverage play on a validated unit, not a hope for a struggling one.

Do NOT run this when:
- The book hasn't proven itself (thin reviews, flat sales). Multiplying a non-seller multiplies effort with no return — the exact opposite of the doctrine. Fix it in `05-book-doctor` or accept it as a learning unit.
- The book is inside its first ~30 days. Let the honeymoon prove velocity first (Pattern 13).
- Someone wants to audiobook a low/medium-content title. Low-content can't become an audiobook (Pattern 8); skip that rung.

Governing economics (Pattern 21): **research and writing are the expensive part — formats are near-free multipliers off the same content.** "Research once, multiply free." Every proven book should exist in **3+ formats within its first months; no winner sits ebook-only.** The endgame frame (Insight 5): every format deepens a *sellable* asset — the catalog is the real product (his first sold for **$820,000** on Empire Flippers).

## Execution

### Step 1 — Confirm proof, then commit the multiplication order
Verify the go criteria (Step 2 gate). Then sequence formats in **effort/return order** — cheapest-highest-leverage first, each rung a near-free multiplier off the already-paid research:

1. **Paperback** — trivial print-on-demand conversion of the ebook (reformat interior + cover for print; a ~$5 gig converts the cover). Zero inventory — Amazon prints and ships only after a sale. First rung because the content is done and POD carries no downside cost.
2. **Hardcover** — same POD conversion, a higher-ticket format on the identical content (Daniel Walter's catalog books earn ~$2.4k/mo on hardcover alongside paperback). Near-zero marginal effort.
3. **Audiobook (ACX)** — sign up to ACX (Amazon's sister company), post the book for **audition**, pick a narrator from samples for **~$200 one-time** on a 30k-word book, earn **~$3.40 royalty per sale**. Proof of the stream: Dollwet sold **100,000+ audiobooks by 2020**; a dashboard shows "$400,741 earned / $16K per month." Only high-content books reach this rung (low/medium content skips it).
4. **Translations (winners only)** — Amazon operates **19 marketplaces**; each translation is a whole new book for zero new research. Reserve for the clear winners — translate the earners, not the whole catalog.
5. **Bundles / box sets** — available **once 2+ related books exist** under the pen name. Higher ticket than singles, still cheaper for the buyer than buying each separately; pure packaging leverage on content already written.
6. **Wide distribution (last)** — after Amazon is saturated, go wide for the ~26% of the market off Amazon: **IngramSpark** (~40,000 stores), **Google Play**, **Draft2Digital**. Last because Amazon (74–78% share, buyer traffic) is where the return concentrates; wide is incremental.

### Step 2 — Apply per-format go/no-go criteria
Each rung has a gate; do not advance until it's met:
- **Paperback / hardcover:** GO the moment the ebook proves itself — trivial, no downside. No reason to delay.
- **Audiobook:** GO only if (a) the book is **high-content** and (b) it's a demonstrated seller worth a ~$200 narration bet with ~$3.40/sale payback. NO-GO for low/medium content (can't audiobook) or unproven titles.
- **Translations:** GO only for a clear winner in the home marketplace. NO-GO for median or unproven books — translation cost isn't free of time even if research is reused.
- **Bundles:** GO only once 2+ *related* books exist. NO-GO with a single book or unrelated titles.
- **Wide distribution:** GO only after Amazon is worked; NO-GO as a first move (adds customer-service and platform load for a small traffic share).

### Step 3 — State the research-once-multiply-free logic per rung
For each format on the roadmap, make the economics explicit: the expensive work (validation, writing, editing) is already sunk; this rung adds a new revenue stream at a marginal cost of near-zero (paperback/hardcover/bundles) or a small one-time bet (~$200 audiobook). This is *why* no proven book stays ebook-only — you'd be leaving free streams on the table off content you already paid for.

### Step 4 — Frame the catalog as the compounding asset
Every format deepens the sellable asset (Insight 5). Keep the pen-name branding clean, formats diversified, and review bases stable — a KDP catalog lists on Empire Flippers for six figures routinely (his first: $820,000; live proofs: $526,055.73 / 364 books, $495,736.13 / 183 books). Then tie multiplication to the flag-planting ladder (Pattern 22): a proven, multi-format unit is the thing you *duplicate* across 2–5 niches in 6 months — $1k→$10k→$100k is duplication of this exact unit, not new tactics.

### Step 5 — Set timeline expectations
- Paperback + hardcover: immediate — days, alongside the ebook launch (1–3 days KDP review per format).
- Audiobook: weeks — audition + narration production after the ebook proves itself.
- Translations / bundles / wide: months — reserved for confirmed winners once the catalog has depth.
Target: **3+ formats within a proven book's first months.** No winner ebook-only.

## Content Type Adaptations

| Type | Adaptation |
|------|------------|
| High-content (nonfiction/fiction) | Full ladder including audiobook (its defining advantage — Pattern 8). Translations and audiobook are the high-leverage rungs; this is where the ~$24k/mo Daniel Walter multi-format stack lives. |
| Low-content (journals/planners) | Paperback + hardcover only; **skip audiobook** (can't narrate a journal). Bundles once 2+ related titles exist. Wide distribution optional. |
| Medium-content (workbooks, prompt books) | Paperback + hardcover; audiobook usually NO-GO (little prose to narrate). Bundles and translations for proven winners. |
| Sprint vs standard | Sprint: paperback + hardcover only (the trivial rungs), roadmap the rest. Standard: full go/no-go pass across all six rungs + timeline + catalog framing. |

## Output Requirements

Deliver a multiplication roadmap:
1. **Proof confirmation** — the evidence this book qualifies (reviews + consistent sales); if unproven, a NO-GO with the reason.
2. **Ordered format sequence** — the six rungs in effort/return order, each with its go/no-go verdict for THIS book and content type.
3. **Per-rung economics** — the research-once-multiply-free logic + real numbers (audiobook ~$200 / ~$3.40 per sale; 19 marketplaces; IngramSpark ~40k stores).
4. **Timeline** — when each format lands (immediate / weeks / months).
5. **Catalog-as-asset note** — what to keep clean for the compounding-and-exit posture, tied to the flag-planting ladder.
