# Portfolio Command — One Validated Unit, Duplicated

## Pre-Flight Gate

Run this ONLY after the operator has driven at least one book to the learning milestone. The gating number is not a dollar target, it is a *proof*: **$1,000/mo from a single book is the only real learning milestone** — it proves the whole pipeline (validate → build → 15 reviews → market → multiply) works in the operator's hands. Everything above it is duplication, not new tactics.

> "If you can do $1,000, you can do $10,000. If you can do $10,000, you can do $100,000… all you have to do is rinse and repeat." (genius.md Pattern 22)

Run this when:
- One book clears ~$1,000/mo (or the operator has 2+ books live and wants a coherent scaling plan).
- The operator is deciding where next-quarter effort goes — a new niche, ads scale on a winner, format multiplication, or retiring a dud.
- Exit is on the horizon and the catalog needs to be packaged as a sellable asset.

Do NOT run this to rescue a pre-proof operator. If no book has cleared the pipeline yet, the honest move is to send them back to workflows 01→04 (or 05 if a book stalled). Planting flags across niches you can't yet convert just multiplies unproven work. Surface that in one line and redirect.

Anti-pattern this kills (genius.md kill list): **stopping at one book** — single-book thinking forfeits the portfolio compounding the window makes available. "One book is cool, but a portfolio of books is a real business."

## Execution

### Step 1 — Build the portfolio state board (honest per-book P&L)
Inventory every live book. For each, capture the real numbers, not hopes:
- **Title / pen name / niche / content tier** (low / medium / high — Pattern 8).
- **Formats live** (ebook / paperback / hardcover / audiobook / translations / bundle) — the multiplication surface from workflow 08.
- **Reviews** (count + trajectory) and **BSR band**.
- **Monthly revenue**, benchmarked against the honest median: **$300–$400 per published book per month** (Hidden Knowledge 13 / price-sheet). Flag over-performers and under-performers against that anchor, never against outlier income.
- **Status verdict** (see Step 3).

The median is the planning anchor and the honesty gate. A portfolio modeled on "$40/day per book" is fantasy; a portfolio modeled on $300–400/book/month is a business. Carry the no-guarantees caveat (Signature Move 1) into any projection.

### Step 2 — Read portfolio shape against the ladder
The duplication frame (Pattern 22): **$1k → $10k → $100k is the same validated unit republished, not a new strategy at each rung.** Assess:
- **How many rungs of the ladder is the operator on?** One proven book (~$1k) = ready to duplicate. 3–4 books = mid-climb. 8–12 books = the $3–5k/mo target range.
- **The target math (price-sheet):** at the $300–400/book/month median, a portfolio of **8–12 books ≈ $3,000–$4,000+/month.** State the honest book-count required for the operator's income goal instead of promising a per-book jackpot.
- **Niche spread.** Count distinct niches. The doctrine wants **2–5 niches within 6 months** (Pattern 22 / window-thesis) — enough to plant flags across the open window, not so many the operator can't out-execute each one.

### Step 3 — Assign a next-quarter status verdict per book
Every book gets exactly one lane. The review cadence is quarterly:
- **SCALE ADS** — book is converting and profitable. Push the $3–5/day diagnostic ad up from a profitable baseline (never scale a leaking listing — that's a workflow 05 problem, not a scale candidate).
- **MULTIPLY FORMATS** — book is proven ebook/paperback but hasn't harvested its near-free multipliers. Route to workflow 08: paperback → audiobook (ACX ~$200 one-time, ~$3.40/sale) → translations → bundles. No winner sits ebook-only.
- **HOLD (digital real estate)** — book pays steadily with no cheap lever left; leave it. "I have many books that I've published and completely forgot about… it still pays me every single month."
- **RETIRE / REPOSITION** — book failed proof-of-concept (ranks #1–2 for its keyword and still doesn't sell = dead demand, Pattern 2). Stop spending on it; either reposition to a proven adjacent keyword or let it sit. Do NOT pour marketing at dead demand.

### Step 4 — Plant the next flag (allocation of new capacity)
Whatever validated capacity remains after scale/multiply goes to a NEW niche, not a fifth book in a worked niche (diminishing return). Route the new-niche decision back through workflow 01 (hunt & validate) — the BSR gate and soft-underbelly scan are non-negotiable even for an experienced operator. Target the **2–5 niches / 6 months** flag-planting cadence while the 12–18-month window is open (window-thesis).

Frame each new flag as a claimed position: an entrenched book (quality + review moat, Pattern 12) later entrants can't dislodge — "the publishers who plant their flag in two, three, even five different niches in the next 6 months are the ones who are going to be compounding for years."

### Step 5 — Pen-name-per-niche architecture
Assign pen names deliberately (Hidden Knowledge 4). Pen names are sales-neutral, so the only questions are catalog hygiene and niche coherence:
- **One pen name per niche** (or per coherent cluster) so a browsing buyer sees an author who *only* writes their subject — reinforces topical authority and keeps cross-niche books from muddying an author page.
- Pen names decouple the catalog from the operator's identity and let one publisher run unrelated niches cleanly (a stoicism pen name and a coloring pen name never collide).
- Don't overthrow existing names to chase this — "don't overthink pen-name vs real name; pick and go." Apply the architecture going forward, migrate only if a name is actively confusing buyers.

### Step 6 — Exit-readiness pass (catalog as the real product)
Even if no sale is imminent, build toward it — the endgame is equity, not just royalties (Hidden Knowledge 5). Score the catalog on the four exit levers and flag gaps:
1. **Clean pen-name branding** — coherent author pages, consistent covers within a niche.
2. **Documented processes** — the validate→build→launch→multiply pipeline written down so a buyer can operate it.
3. **Diversified formats** — winners in 3+ formats (ebook / paperback / audiobook at minimum), which raises both revenue and multiple.
4. **Stable review bases** — books past the 50–100-review moat, not fragile new launches.

Comp for the target: Dollwet sold his first KDP account for **$820,000** on Empire Flippers (Aug 24 2021, Listing #32231); live proof includes accounts booking **$526,055.73 across 364 books** and **$495,736.13 across 183 books** (price-sheet). A KDP catalog lists there for six figures routinely.

## Content Type Adaptations

| Content tier | Portfolio role | Scale lever | Exit weighting |
|---|---|---|---|
| **High-content nonfiction** | Portfolio backbone — thin competition + audiobook stream compounds hardest | MULTIPLY (audiobook/translations) then SCALE ADS | Highest multiple; format-diverse and review-deep |
| **Low-content journals/planners** | Volume filler; least money per Pattern 8 — cap exposure | SCALE ADS only if a genuine underbelly exists; rarely MULTIPLY (no audiobook) | Lower multiple; keep as steady-cash HOLD, don't over-index |
| **Medium-content coloring/activity** | Trend-dependent cash; model page-one winners (Coco Wyo kawaii "Bold-Easy") | Organic engine (workflow 06) more than ads; MULTIPLY into bundles | Moderate; bundles/box sets raise per-title value |
| **Mixed portfolio** | The realistic 8–12-book state | Allocate by per-book P&L, not by tier sentiment | Diversified formats across tiers = cleanest sale |

## Output Requirements

Deliver a **portfolio command sheet** containing:
- **Portfolio state board:** one row per book — title | pen name | niche | tier | formats live | reviews | BSR band | monthly revenue vs. the $300–400 median | status verdict.
- **Ladder read:** which rung the operator is on, the honest book-count required for their stated income goal (at the median), and current niche spread vs. the 2–5/6-months cadence.
- **Next-quarter allocation plan:** each book assigned SCALE ADS / MULTIPLY FORMATS / HOLD / RETIRE-REPOSITION, plus the new-niche flag(s) to plant (routed to workflow 01) with capacity budget.
- **Pen-name architecture map:** current names → recommended per-niche assignment, migrations flagged (migrate only if actively confusing).
- **Exit-readiness scorecard:** the four levers graded with named gaps and the honest comp ($820k / $526k / $496k), framed as equity-building, not a promise.
- **Honesty anchor:** every projection carries the $300–400/mo/book median and a no-guarantees caveat; zero outlier-income leads, zero fabricated per-book revenue.

## Quality Gate (pass/fail — references genius.md Rubric + anti-patterns)

- [ ] Pre-flight honored: the operator has at least one book at/near the **$1,000/mo learning milestone**; pre-proof operators are redirected, not scaled.
- [ ] Per-book P&L is benchmarked against the **$300–400/mo median** (Rubric 6), never against outlier income; no fabricated revenue figures.
- [ ] The **8–12 books ≈ $3–4k/mo** math is used to state the honest book-count for the operator's income goal (price-sheet).
- [ ] Every book carries exactly one status verdict; RETIRE candidates are diagnosed via the ranking-without-sales / dead-demand check (Pattern 2), not abandoned arbitrarily.
- [ ] New capacity plants a flag in a NEW niche routed through workflow 01's BSR gate — toward the **2–5 niches / 6 months** cadence — rather than over-stacking a worked niche.
- [ ] Pen-name-per-niche architecture is stated; migrations proposed only when a name actively confuses buyers ("pick and go," don't over-optimize).
- [ ] Exit scorecard grades all four levers (clean branding / documented process / diversified formats / stable reviews) with the honest Empire Flippers comp — equity framing, no guaranteed sale price.
- [ ] Sequencing intact (Rubric 7): nothing scales ads on an unproven or leaking book; multiplication only follows ebook proof.
