# Portfolio Command — Scale Only What Book One Taught

## Pre-Flight Gate

Require `RUNTIME_OBSERVED` capability proof and a Book One `NET_COLLECTED` event with costs, refunds, and lessons. Do not infer repeatability from one draft, upload, live listing, gross royalty, or creator benchmark.

## Execution

1. Build a per-title board: niche, reader, formats, production state, discovery, units, refunds, gross royalty, direct costs, allocated tools/time, net collection, and evidence period.
2. Record what is actually causal, merely correlated, or unknown across demand, book quality, listing, organic distribution, and timing.
3. Assign one lane per title: `HOLD`, `REPAIR`, `REPOSITION`, `FORMAT TEST`, `NEXT BOOK TEST`, or `RETIRE`.
4. Run cross-title similarity, recycled-content, rights, metadata, account, and audience-overlap gates before any new title.
5. Choose one next-quarter hypothesis with budget, capacity, success metric, stop rule, and separate approval.
6. Keep catalog sale values and linear $1k→$10k claims `SOURCE_REPORTED/UNTESTED` until independent evidence exists.

## Output Requirements

- Evidence-period portfolio board.
- Gross-to-net economics per title.
- Causal/unknown learning ledger.
- One status lane per title.
- Similarity/account-risk receipt.
- One controlled next-quarter decision; client/factory packaging remains parked.

## Quality Gate

- [ ] Runtime and net-collection proof exist.
- [ ] Gross, costs, refunds, tax assumptions, and net are separated.
- [ ] Unknown causality stays unknown.
- [ ] Cross-title similarity and account risk pass.
- [ ] Exactly one next-quarter hypothesis is selected.
- [ ] No creator median, catalog multiple, or linear scaling claim is presented as forecast.
- [ ] External spend, publishing, and client use require approval.
