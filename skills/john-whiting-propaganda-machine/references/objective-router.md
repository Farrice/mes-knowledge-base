# Objective Router — deploy the propaganda genius on anything

The classification map `jw-engine` uses in Phase 1. Read the objective, match the archetype, run the recipe. This is what makes the OS general-purpose instead of a narrow pipeline: **any objective resolves to a propaganda sequence.**

## The propaganda jobs (an objective stacks 1–3)

| Job | Whiting outcome | Primary patterns |
|---|---|---|
| **EYEBALLS** | reach, attention, the scroll-stop | tone/awareness ladder (attention rung), self-selection (polarize for reach), cadence |
| **ATTRACTION** | belief-shift, desire, "I need this" | big domino, belief-shift assets, sell-what-they-want/give-what-they-need |
| **PIPELINE** | conversion, self-close, inbound | objection arsenal, pattern-interrupt, retargeting, assumptive close |
| **OFFER** | irresistibility, one-best-client fit | one-best-client, vehicle-engineer, big domino |
| **QUALITY** | right-fit buyers, low fulfillment drag | self-selection / polarization |

## Archetype → recipe

Each archetype lists: **jobs**, the **sequence** (which `jw-*` fire, in order), the **stack** (craft experts), **grounding** needed, and **output**.

### 1. Single content piece (post, short, email, thread)
- **Jobs:** EYEBALLS + ATTRACTION
- **Sequence:** `jw-big-domino` (the one belief this piece installs) → `jw-tone-awareness-ladder` (meet the rung) → produce → gate. Light objection-handling only if it's a conversion piece.
- **Stack:** Kallaway (share-trigger/hook) · Lara Acosta (LinkedIn 4-3-2-1) · Nicolas Cole (newsletter) · Luke Iha (vicious hook if paid)
- **Grounding:** your files + thought-bank; no market cold-start needed.
- **Output:** 1 finished piece + 2-3 hook variants.

### 2. Content campaign / series (a week, a season, a theme)
- **Jobs:** EYEBALLS + ATTRACTION + PIPELINE
- **Sequence:** `jw-big-domino` (the season's through-line belief) → `jw-objection-arsenal` (each objection = an episode) → `jw-self-selection-filter` → `jw-tone-awareness-ladder` (sequence rungs across the run) → `jw-content-cadence-engine` (production + schedule)
- **Stack:** Cole (series architecture) · Lara (LinkedIn) · Kallaway (per-piece virality) · Hawley `/hawley-content-season` (serialized arc) if narrative
- **Grounding:** ICP + thought-bank; cache the audience once, reuse across the series.
- **Output:** campaign calendar + the asset set, big-domino-anchored.

### 3. Offer / service design (build or sharpen the thing you sell)
- **Jobs:** OFFER + ATTRACTION
- **Sequence:** `jw-one-best-client` (the one person) → `jw-vehicle-engineer` (does the model fit the destination + how you want to live) → `jw-big-domino` (the belief that makes the offer inevitable) → `jw-data-bottleneck` (if pricing/economics in question)
- **Stack:** April Dunford (positioning) · Alen Sultanic (offer economics) · Dan Martell (scaling fit)
- **Grounding:** real client history if it exists (mine the Saunders); else ICP target + flag pending validation.
- **Output:** one-sentence offer + sales-page spine + the 3 objections that must die + the price/vehicle call.

### 4. Launch (time-boxed push for a product/offer/event)
- **Jobs:** ATTRACTION + PIPELINE + QUALITY
- **Sequence:** pre-launch `jw-big-domino` + belief-shift → `jw-self-selection-filter` → `jw-objection-arsenal` (pre-handle before cart opens) → launch assets → `jw-retargeting-architecture` (frequency ramp) → `jw-pattern-interrupt` (lean-back close)
- **Stack:** Jason Fladlien (launch/offer mechanics) · Luke Iha (VSL/ad) · Lara/Cole (organic) · supercomputer pattern for cross-phase coherence
- **Grounding:** market cache (copy-engine) + warm-audience map.
- **Output:** phased launch plan + all assets, anchored dependency graph.

### 5. Cold-start an audience (zero → warm)
- **Jobs:** EYEBALLS + ATTRACTION + QUALITY
- **Sequence:** ground the market (copy-engine) → `jw-big-domino` → lead with borrowed-authority + `jw-self-selection-filter` for reach → `jw-content-cadence-engine`
- **Stack:** Diandra (borrowed-attention formats) · Kallaway · Lara
- **Grounding:** market cold-start is justified here (it's the point). Cost-preview, then cache.
- **Output:** positioning + first 2-4 weeks of polarizing reach content; longer time-to-trust flagged.

### 6. Authority build (become the known name in a lane)
- **Jobs:** ATTRACTION + PIPELINE
- **Sequence:** `jw-big-domino` (your category belief) → `jw-tone-awareness-ladder` → `jw-content-cadence-engine` → objection arsenal woven in over time
- **Stack:** Cole (newsletter flywheel) · Lara (LinkedIn authority) · Sean Macintyre (post-hook depth)
- **Grounding:** your interest stack / positioning files (FARRICE.md).
- **Output:** authority content engine + the recurring big-domino through-line.

### 7. Sales asset (one VSL, landing page, ad, email sequence)
- **Jobs:** PIPELINE + ATTRACTION
- **Sequence:** route to `/copy-engine` for grounding+craft, then layer `jw-objection-arsenal` (pre-handle in-asset) + `jw-big-domino` + `jw-pattern-interrupt` (the CTA posture)
- **Stack:** Luke Iha (VSL/mechanism/proof) · Georgi (sentence-level) · Cimorelli (big idea) · Sabri (DR funnel)
- **Grounding:** copy-engine market cache (this is its home turf).
- **Output:** the finished asset, propaganda-gated.

### 8. Reposition (you're commoditized / mis-seen)
- **Jobs:** OFFER + ATTRACTION + QUALITY
- **Sequence:** `jw-vehicle-engineer` → `jw-one-best-client` → `jw-big-domino` (the new category belief) → `jw-self-selection-filter` (repel the old wrong-fits loudly)
- **Stack:** April Dunford · Alex M H Smith (only-is-better-than-best) · Erica Mallet (belief-based brand)
- **Grounding:** current positioning + market.
- **Output:** the reposition statement + the belief shift + the polarizing announcement set.

### 9. Filter / de-risk fulfillment (pure QUALITY)
- **Jobs:** QUALITY (primary) — the standalone home for "I'm drowning in bad-fit clients, fix my inbound."
- **Sequence:** `jw-self-selection-filter` (the whole job) → `jw-objection-arsenal` (pre-handle the wrong-fit's reasons for self-identifying) → light `jw-big-domino` (the belief that makes right-fits raise their hand)
- **Stack:** Dai Media (`dai-media`, consumer posture) · Erica Mallet (`erica-mallet`, enemy effect)
- **Grounding:** your current client base — who drains you vs. who you'd clone 50×. Pre-revenue → the ICP's anti-avatar.
- **Output:** the repel-lines + magnetize-lines + disqualification content that fixes inbound quality upstream of the sale.

## Fallback (no clean archetype match)
If the objective doesn't map cleanly: run the **minimum viable spine** — `jw-big-domino` → `jw-tone-awareness-ladder` → produce → gate. Name the assumed archetype + the single most load-bearing assumption, then proceed (never refuse, never hard-block) — but **stamp the whole run `[LOW-CONFIDENCE INFERENCE]` in the output header** so the user sees the OS guessed and can redirect before acting on it. This keeps the not-narrow contract (it still runs) while flagging the misfire risk. (Mirrors autopilot's freeform handling: name the best-fit, proceed, flag the guess.)

## Routing notes
- **Every archetype passes Phase 4 gate** (ethics + spine + prose) without exception.
- **Stack = craft, jw = strategy.** The jw-* sequence decides *what to say and to whom*; the stacked expert decides *how to make it land* in the format.
- **When the objective names a platform** (LinkedIn, Substack, YouTube, ads), the stack's platform expert leads the render; the jw-sequence stays the spine.
- **When in doubt between archetypes,** pick the one whose primary JOB matches the objective's verb: "get seen" → EYEBALLS (1/2/5); "make them want" → ATTRACTION (1/2/6); "get clients" → PIPELINE (4/7); "fix what I sell" → OFFER (3/8); "stop bad-fit clients" → QUALITY (9).
