# Propaganda Machine — The Hero System

> "I'm basically creating a whole bunch of setters and closers and I'm deploying them as a fucking army, and I have full control over what they say all the time." — John Whiting

The orchestrator. Builds the complete system that lets content close sales with no setters, no closers, no calls. This workflow sequences the sub-tools (`jw-objection-arsenal`, `jw-retargeting-architecture`, `jw-self-selection-filter`, `jw-pattern-interrupt`, `jw-content-cadence-engine`) into one deployable machine. When the requested outcome is a compact three-asset path, Model/Machine/Invite, or a no-pre-sale-call decision sequence, route the close layer through `jw-three-asset-close` instead of inventing a parallel funnel.

---

## Pre-Flight Gate

Before building, confirm with the genius.md decision framework:

1. **Do you have ANY sales reps under your belt?** The machine is built FROM real sales conversations. If the operator has never handled objections live, the content has no source material. → If zero reps: route to "do 20–50 real conversations first, record them" before building. Whiting: *"If you're smart, you record yourself on video while taking sales calls. As you're handling an objection, you clip that out."*
2. **Is there a real, true offer that takes a buyer from a clear Point A to Point B?** If the offer is vague or the result isn't real → route to `jw-one-best-client` + `jw-the-map` first.
3. **Run `jw-ethics-gate` intent check.** Are we installing beliefs we'd defend under oath, with real proof, in the buyer's genuine interest? If no → stop.

If all three pass, build.

## The Machine (5 stages)

### Stage 1 — Mine the Sales Psychology
Inventory everything a human currently does to close a buyer. Source from: recorded sales calls, DM threads, onboarding calls, "considerations" people raise, the reasons people DON'T buy, the reasons clients churn.
Output: a raw list of **every objection, every limiting belief, every "yeah but…", and the ONE big-domino belief** that, once installed, makes all objections irrelevant (`jw-big-domino`).

### Stage 2 — Build the Asset Army
For each item in Stage 1, produce a content asset that kills it (`jw-objection-arsenal`). Each asset:
- Headlines with the objection/belief itself ("Why I fired a client who asked for X").
- Handles it the way the operator handles it live — clipped from a real recording where possible.
- Carries the confrontational spine (see Voice Reference). The edge is the mechanism.
Layer in: belief-shift pieces, value pieces, testimonial/proof pieces, and assumptive-close onboarding clips.

### Stage 3 — Engineer Self-Selection
Build the polarization layer (`jw-self-selection-filter`): content that tells the wrong-fit buyer to leave and the right-fit buyer "you're my people." This is the qualification filter that pre-solves fulfillment cost. Disqualification flexes, drawn lines, "here's how I roll — if you want that, here's what happens; if not, here's the door."

### Stage 4 — Distribute at Frequency
Architect the 3-tier retargeting funnel (`jw-retargeting-architecture`):
- **TOF:** testimonial-led book/SLO funnel (borrowed authority, liquidate ~30%, feed the warm audience).
- **MOF (~1,000):** ~50 belief-shift assets, ~2×/7 days, optimize completed plays.
- **BOF (~600 warmest):** logistics + assumptive-close onboarding clips, ~5×/day.
Force-feed the 7 hours of content. You control every word.

### Stage 5 — Close Without Closing
Wire the pattern interrupt (`jw-pattern-interrupt`): don't chase, don't set, don't hard-close in the DMs. Let the content do the selling; the first real conversation happens *after* payment, when you set the rules of the game. For a considered-purchase three-asset route, run `jw-three-asset-close`: Model sells the shift, Machine sells the vehicle, Invite qualifies the right buyer, and the async path gates payment and delivery. Measure time-to-close, frequency hit rate, and self-close rate.

## Content Type Adaptations

| Deliverable | How the machine adapts |
|---|---|
| **Coaching / high-ticket service (Authority Flywheel)** | Full machine. Hero use case. Map objections → assets → retarget warm audience → self-close. |
| **LinkedIn-native (× Lara Acosta)** | Render assets in 4-3-2-1 format; "force-feed" = consistent posting cadence + DM funnel vs. paid retargeting. |
| **Newsletter / Substack (× Nicolas Cole)** | Belief-shift assets become editions; the big-domino belief is the through-line; CTA is the assumptive next step. |
| **Paid-ads-heavy (× Luke Iha / Sabri)** | Full paid retargeting; assets get vicious hooks + proof ladders; awareness-ladder targeting. |
| **Low/no ad budget** | Organic-only: cadence engine carries distribution; lengthen time-to-close expectation; lean harder on polarization for reach. |

## Output Requirements

Deliver a **Propaganda Machine Build Sheet**:
1. The mined objection/belief inventory + the ONE big domino.
2. The asset army list (every asset, mapped to the objection it kills, with headline).
3. The self-selection layer (the lines drawn, who's repelled, who's magnetized).
4. The 3-tier retargeting plan with frequency caps + audience sizes.
5. The pattern-interrupt rules (what you do NOT do).
6. Metrics to watch: frequency, completed-play rate, time-to-close, self-close rate.
7. **Ethics Gate sign-off** on the whole machine.

## Quality Gate

Score against genius.md rubric. Specifically:
- **Objections pre-handled in content, not saved live?** (Rubric #3) — if the plan still needs a human to save the sale, the machine isn't built.
- **Self-selecting?** (Rubric #4) — does the polarization layer actually repel wrong-fits and name the right-fits? Maps to Stage 3; if the content keeps everyone in, it qualifies no one.
- **Edge intact?** (Rubric #5) — run the spine test on the polarization + objection assets. Sanded-down = failed.
- **Leveraged?** (Rubric #6) — every asset keeps working without the operator.
- **Ethics Gate passed?** (Rubric #7) — all four gates, or kill it.
- **One big domino present?** (Rubric #8).

If any dimension <6, rebuild that stage once and re-score.
