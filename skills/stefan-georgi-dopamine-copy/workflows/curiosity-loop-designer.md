# Curiosity Loop Designer

> Design nested curiosity gap sequences with compounding tension.
> Engineers the neurological sequence: gap detection → discomfort →
> search activation → reward circuitry → dopamine flood.

## Expert
Stefan Georgi — Dopamine Copywriting Architecture

## Inputs Required
1. **Asset Type**: What's this loop structure being built for?
2. **Core Information to Reveal**: What is the answer the reader ultimately gets?
3. **Number of Loops**: How many nested loops? (2-5 recommended)
4. **Revelation Point**: Where in the asset should the final gap close?

## Phase 1: Information Gap Architecture

For the core information to be revealed, build the gap hierarchy:

### Level 1: The Master Gap
The biggest, broadest curiosity gap that won't close until near the end:
- **The Question**: [State the question the reader will carry throughout]
- **What They Know**: [Just enough to make the gap visible]
- **What They Don't Know**: [The specific information being withheld]
- **Emotional Charge**: [What emotion amplifies this gap? Jealousy? Fear? Outrage?]

### Level 2: Supporting Gaps (2-3)
Smaller gaps that keep dopamine flowing between the master gap's open and close:
- Each supporting gap should take 1-3 paragraphs to resolve
- Resolving a supporting gap should OPEN a new one or DEEPEN the master gap
- Supporting gaps are the "hit" between the big dopamine surges

### Level 3: Micro-Gaps (5-10)
Sentence-level tension that prevents dead zones:
- Incomplete sentences resolved 1-2 sentences later
- "But there's a catch..." followed by expansion
- "The surprising part isn't X — it's what happened NEXT"
- These are the punctuation of curiosity — they keep the dopamine meter above zero

## Phase 2: Loop Nesting Protocol

Design the nesting sequence:

```
OPEN Master Gap (never closes until Section 4)
  │
  ├── OPEN Supporting Gap 1
  │     ├── Micro-gap → resolve
  │     ├── Micro-gap → resolve
  │     └── CLOSE Supporting Gap 1 → immediately OPENS Supporting Gap 2
  │
  ├── OPEN Supporting Gap 2
  │     ├── Micro-gap → resolve
  │     ├── DEEPEN Master Gap (add new information that makes the master question more urgent)
  │     └── CLOSE Supporting Gap 2 → OPENS Supporting Gap 3
  │
  ├── OPEN Supporting Gap 3
  │     ├── Micro-gap → resolve
  │     ├── Tease Master Gap resolution ("We're almost there...")
  │     └── CLOSE Supporting Gap 3
  │
  └── CLOSE Master Gap (dopamine payoff — mechanism reveal or "aha" moment)
```

**Critical Rule**: At no point should ALL gaps be closed simultaneously (except the final resolution). The brain should always have at least ONE unresolved question.

## Phase 3: Epistemic-Empathetic Blending

For each gap, classify and blend:

| Gap | Epistemic Component (info I need) | Empathetic Component (experience I need to understand) | Blend Score |
|-----|----------------------------------|-------------------------------------------------------|-------------|
| Master | | | |
| Supporting 1 | | | |
| Supporting 2 | | | |

**Target**: Every gap should have BOTH epistemic and empathetic components. Pure epistemic = Wikipedia. Pure empathetic = gossip. Blended = irresistible.

## Phase 4: Tension Modulation Map

Chart the curiosity tension level across the asset:

```
Tension Level (1-10)
10 |  ★              ★★           ★★★
 8 | ★  ★          ★    ★       ★     ★
 6 |★    ★       ★       ★    ★        ★
 4 |      ★    ★           ★★            ★
 2 |       ★★★                              ★★
 0 |___________________________________________|
   Lead   Rapport   Build    Mechanism    Close
```

**Rules**:
- Tension should never drop below 3 (dead zone territory)
- Each resolution creates a brief dip followed by a higher peak
- Maximum tension immediately before mechanism reveal
- Close should maintain 5+ tension (purchase = continued dopamine)

## Phase 5: Loop Stress Test

Test each loop for failure modes:

- [ ] **Premature Resolution**: Does any gap close too early and kill momentum?
- [ ] **Gap Abandonment**: Does any gap open and never close? (frustration, not curiosity)
- [ ] **Tension Plateau**: Does tension flatline for more than 2 consecutive paragraphs?
- [ ] **Complexity Overload**: Are there so many open loops that the reader gets confused rather than curious?
- [ ] **Emotional Drain**: Do the loops create fatigue instead of anticipation?

## Output Contract
- Complete loop nesting diagram (Master + 2-3 Supporting + 5-10 Micro)
- Epistemic-empathetic blend scores for each gap
- Tension modulation map
- Stress test results with fixes for any failures
- Ready-to-deploy loop sequence integrated with the asset structure
