# Nostalgia Lead Builder

> Create hippocampus-mediated nostalgic opens that trigger episodic
> memory and fire 3+ simultaneous Ekman emotions before the first
> product mention. Georgi's highest-conversion lead architecture.

## Expert
Stefan Georgi — Dopamine Copywriting Architecture

## Inputs Required
1. **Product/Offer**: What's being sold
2. **Target Audience Age Range**: Critical for era-specific memory selection
3. **Product Domain**: Health | Finance | Relationships | Business | Personal development
4. **Desired Emotional Arc**: What emotion should the reader feel after the nostalgic open?

## Phase 1: Era Calibration

Calculate the audience's "Peak Dopamine Window" (ages 12-19):

| Audience Age Now | Peak Dopamine Era | Cultural Anchors |
|-----------------|-------------------|-----------------|
| 35-40 | 1998-2010 | Early internet, flip phones, MySpace, mixtapes |
| 40-50 | 1988-2000 | Walkman, VHS, Saturday morning cartoons, mall culture |
| 50-60 | 1978-1990 | Vinyl records, rotary phones, neighborhood play, muscle cars |
| 60-70 | 1968-1980 | Vietnam era, Woodstock, muscle cars, drive-ins |
| 70+ | 1958-1970 | Radio era, Korean War, soda fountains, Elvis |

**Select 3-5 cultural anchors from the target era.**

## Phase 2: Sensory Memory Mining

For each cultural anchor, identify specific SENSORY details:

- **Visual**: What did they see? (specific colors, shapes, light quality)
- **Auditory**: What did they hear? (specific songs, sounds, voices)
- **Olfactory**: What did they smell? (grass, sunscreen, a parent's cooking)
- **Tactile**: What did they touch? (dirt, baseball leather, book pages)
- **Gustatory**: What did they taste? (penny candy, well water, school lunch)

**Rule**: General nostalgia ("those were the days") fails. Specific sensory detail ("the smell of fresh-cut grass through a screen door on a July afternoon") succeeds. The detail must be specific enough to trigger one person's actual memory, not vague enough to describe everyone's.

## Phase 3: Nostalgic Lead Construction

### Template: The Question-Memory-Bridge

```
QUESTION: "Dear friend, do you ever [specific childhood activity]?"
     ↓ (3-5 seconds — dopamine fires via hippocampus)
MEMORY EXPANSION: "If you did, you probably remember [specific sensory detail]..."
     ↓ (emotions compound — enjoyment + sadness + surprise)
THE BRIDGE: "Well, what I want to tell you about today is being called
[metaphorical name] — because it [connects memory to product]..."
     ↓ (curiosity gap opens — HOW does this memory connect to the product?)
MECHANISM TEASE: "And it could help you [core benefit]..."
```

### Alternative: The "Time Capsule" Structure
1. Open with a universal childhood ritual (time capsule, lemonade stand, fort-building)
2. Describe what you'd find inside if you went back today
3. Use that inventory as metaphor for the product's promise
4. The product IS the time capsule — it contains what's been lost

### Alternative: The "Song That Changed Everything" Structure
1. Open with "There's a song that, every time you hear it..."
2. Describe the involuntary emotional response (chills, tears, smile)
3. Explain the neuroscience: ages 12-19, highest dopamine, permanent associations
4. Bridge: "What if there was something that could make your BODY feel that way again?"

## Phase 4: Emotion Verification

Before shipping, verify the lead fires 3+ simultaneous emotions:

| Emotion | Triggered? | Via What Stimulus? |
|---------|-----------|-------------------|
| Enjoyment | | Fond memory of the activity |
| Sadness | | Recognition that time has passed |
| Surprise | | Unexpected sentimental direction |
| Fear | | (Optional) Awareness of mortality/aging |
| Anger | | (Optional) Frustration at what's been lost |

**Minimum: 3 emotions verified. Target: 4+.**

## Phase 5: Bridge Quality Gate

The bridge from nostalgia to product must feel:
- [ ] **Organic** — not forced or jarring
- [ ] **Metaphorical** — the product connects to the memory through meaning, not features
- [ ] **Curiosity-Generating** — the connection itself raises a question
- [ ] **Emotion-Preserving** — the emotional state built by nostalgia carries into the product section

**If the bridge feels like a "bait and switch," rebuild the metaphorical connection.**

## Output Contract
- 2-3 complete nostalgic leads for the given product
- Era calibration table for the specific audience
- Sensory memory inventory (5+ specific details per lead)
- Emotion verification checklist for each lead
- Bridge quality assessment
