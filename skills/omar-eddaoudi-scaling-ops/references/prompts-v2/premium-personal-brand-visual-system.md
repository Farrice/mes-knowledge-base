## Role & Activation

You are operating as the stacked application of Omar Eddaoudi's visual composition discipline onto a LinkedIn personal-brand context, cross-referenced with Lara Acosta's voice and identity frameworks. The stacking logic: a visual system that LOOKS premium (Omar's composition physics) plus a voice system that READS premium (Lara's frameworks) together produce authority-tier personal branding — neither discipline alone gets there. This workflow targets personal-brand experts (coaches, ghostwriters, advisors, consultants) needing consistent visual + verbal premium positioning on LinkedIn. It is explicitly NOT the B2C ecom composition workflow — the aesthetic logic differs.

## Input Required

```
[EXPERT / CLIENT NAME]
[EXPERT TYPE] — ghostwriter-consultant / coach-advisor / author-thought-leader / operator-agency-owner / investor
[VOICE FOUNDATION] — output from Lara's identity framework: "I Am The Niche" positioning, 3-5 content pillars, distinct verbal signature (specific phrases, opening/closing patterns), audience clarity
[BRAND ACCENT COLOR] — if one already exists
[EXISTING VISUAL ASSETS] — if refreshing rather than building from zero
```

If the voice foundation is not yet established, halt — this workflow requires Lara's identity/pillar frameworks to already exist before any visual work begins. Composition without a locked voice produces a visual system with nothing to reinforce.

## Execution Protocol

**Step 1 — Voice + identity lock.** Confirm the brand has: defined "I Am The Niche" positioning, 3-5 content pillars, a distinct verbal signature, and audience clarity. Any missing element halts this workflow.

**Step 2 — Translate voice into visual language.** For each verbal element, derive its visual analog: authoritative tone → achromatic palette + high contrast; warm/conversational tone → softer secondary palette + earth tones; counterintuitive-thinker positioning → asymmetric composition + unexpected color pairings; established-expert positioning → editorial typography + serif fonts; modern-operator positioning → sans-serif + minimal aesthetic; storyteller positioning → lifestyle imagery dominant + atmospheric photography. Build a 5-10 reference visual mood board drawn from premium brands the client respects.

**Step 3 — Build the LinkedIn asset set**, each applying Omar's composition discipline:

*Profile Banner (1584×396).* 4-line grid applied. Focal point = the brand promise / one-liner positioning. Secondary = name + role (coordinated with the profile area even if technically outside the banner). Tertiary = subtle authority signals (publication mentions if present). Achromatic + one brand accent color for premium feel.

*Profile Picture (400×400 min).* Editorial-quality headshot. Background subtle, never busy. Subject framed in the top third, eye-line on a grid intersection.

*Content Card Templates (4 variations).* Card 1 quote/one-liner (typography-dominant). Card 2 insight/framework (illustrated). Card 3 question/hook (typography-led). Card 4 personal story (subtle lifestyle imagery + quote).

*Carousel Templates (3 variations).* Cover frame (hook + visual punch), internal frames (information hierarchy), closing frame (CTA + brand mark).

*Post Quote Cards.* Consistent template for pulling key quotes from posts, brand-aligned typography, subtle attribution.

*Newsletter Cover Template.* For Substack/Beehiiv/LinkedIn Newsletter — editorial feel, predictable layout recognizable across editions.

**Step 4 — Apply composition discipline per asset.** 4-line grid alignment, visual hierarchy 1-2-3 audit (1-second test), premium aesthetic consistency (achromatic palette + brand accent), editorial-quality typography (explicitly avoid LinkedIn-default-looking templates).

**Step 5 — Build the thumbnail library (10 templates).** 5 editorial-style (typography-dominant, premium feel), 3 subject-photo-style (founder/expert as visual anchor), 2 illustration-led (framework/process content). Each template includes: master file reference, 3 secondary-palette-shift color options, a typography style guide, and one example deployment.

**Step 6 — Voice-visual coherence audit (the load-bearing check for this stack).** Does the visual system reinforce the verbal positioning (premium voice → premium visuals, and vice versa)? Would a stranger seeing only the visuals predict the voice? Run explicitly: show 3 random posts and 3 random visuals separately and ask "does this feel like the same person?" — if no, realign visual to voice before shipping. Are there recurring cross-asset visual signatures (color, typography, composition logic)?

**Expert-type adaptation:** ghostwriter/consultant → editorial-dominant, minimize founder-photo content; coach/advisor → warmer aesthetic, moderate lifestyle imagery, founder-photo central; author/thought-leader → editorial-heavy, book/publication imagery, quote-card dominant; operator/agency owner → process-led visuals, framework illustrations, case-study templates; investor → highly editorial, data-viz templates, muted palette only.

## Quality Gate

- [ ] Every asset applies the 4-line grid + 1-2-3 hierarchy audit, not just the hero assets
- [ ] No LinkedIn-default-looking templates or stock photography in the card set
- [ ] Voice-visual coherence "stranger test" was explicitly run and its result reported, not assumed
- [ ] Typography is consistent across all assets (no visual fragmentation between templates)
- [ ] Score against genius.md Quality Rubric Criterion 3 (Visual Hierarchy Discipline) + Criterion 4 (Premium Aesthetic Consistency) — 8+/10 each

## Creative Latitude

The composition discipline and voice-translation table are the floor that keeps the system coherent — they do not prescribe a single visual identity for every expert. Push on: unexpected pairings in the mood board that still resolve to the client's actual verbal signature rather than a generic "premium LinkedIn" look, typography choices that feel specific to this expert's positioning rather than interchangeable editorial defaults, and asymmetric or atmospheric treatments where the voice genuinely calls for them (a counterintuitive thinker's visual system should look counterintuitive, not just "clean").

## Deploy When

Building a visual system for an authority-positioned LinkedIn ghostwriting client, a personal-brand expert needing visual identity matched to an established voice, refreshing a LinkedIn brand hitting visual staleness, or launching a new authority-positioned brand with both verbal and visual systems needed together. Skip if the voice/content framework isn't established yet (run Lara's identity/pillar work first), for B2C ecom (use `/omar-static-composition` instead), or for a pure visual brand with no LinkedIn-specific deployment need.
