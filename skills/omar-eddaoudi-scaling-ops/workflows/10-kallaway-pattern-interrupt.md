# 10 — Omar × Kallaway — Pattern Interrupt Visual Hooks

> **Stacking Pattern**: Omar's visual hierarchy + composition discipline + Kallaway's content psychology + curiosity gap engineering. The stack: visual system engineered to STOP the scroll + verbal system engineered to HOLD attention after the stop.

The cross-expert workflow for short-form content (Reels, TikTok, Shorts) where the thumbnail/hook frame must do both visual scroll-stop and curiosity-gap-opening simultaneously.

## Pre-Flight Gate

Run this workflow when:
- ✅ Producing short-form video content (Reels / TikTok / Shorts)
- ✅ Thumbnail design for YouTube short-form or long-form
- ✅ Static-as-hook content (carousel covers, single-image hooks)
- ✅ Refreshing low-CTR thumbnails on existing content

Skip when:
- ❌ Long-form ads where production quality dominates over hook engineering
- ❌ B2B service content (use Omar × Lara stack instead — different attention economics)
- ❌ Brand-awareness ads (this workflow optimizes for click/watch, not awareness)

## Execution

### Step 1: Hook Genome Identification

Before designing, identify the hook type from Kallaway's framework:
- **Curiosity Gap**: question that opens loop the viewer must close
- **Pattern Interrupt**: unexpected/contrarian frame
- **Stakes Reveal**: implication that this matters more than they thought
- **Identity Match**: "for people who [niche identity]"
- **Mechanism Reveal**: "the actual reason X happens"

Pick ONE hook type per content piece. Mixing dilutes both.

### Step 2: Verbal Hook Crafting (Kallaway Layer)

Per hook type, write the verbal hook:

**Curiosity Gap example**:
- "Why scaling your ad budget is the WORST way to grow"
- Tension: scaling = growth, so why worst?

**Pattern Interrupt example**:
- "Your funnel is the problem. It's also the solution."
- Tension: contradiction forces re-read

**Stakes Reveal example**:
- "Most brands die from one decision. They make it on day 1."
- Tension: implication that an early decision is fatal

**Identity Match example**:
- "If your ad spend just hit $1K/day, watch this."
- Tension: exclusion of non-niche, reward for in-niche

**Mechanism Reveal example**:
- "The actual reason your CAC keeps inflating (it's not what you think)"
- Tension: implies you're wrong + promises correct answer

Word count target: 6-12 words. Longer = lost in scroll.

### Step 3: Visual Hierarchy Design (Omar Layer)

Apply composition discipline:
- 4-line grid in vertical 9:16 format
- Focal point engineering: WHERE does the eye land first?
- For thumbnail: focal point typically face (high pull) OR object (medium pull) OR text (low pull but high info)
- Visual hierarchy 1-2-3: hook text / focal subject / context elements

### Step 4: Hook Type → Visual Strategy Mapping

| Hook Type | Visual Strategy |
|-----------|----------------|
| Curiosity Gap | Text-dominant thumbnail; subject reaction face supporting; question mark or visual gap encoded |
| Pattern Interrupt | Visual contradiction (smiling at "bad" thing, formal in chaotic setting, etc.); high contrast |
| Stakes Reveal | High-stakes visual (financial chart, broken X, dramatic moment) + text |
| Identity Match | Subject visually represents the niche identity (gear, environment, posture); text confirms |
| Mechanism Reveal | Diagram or visual mechanism implied; text as setup |

### Step 5: Build the 10-Template Library

Build 10 reusable hook templates, distributed across hook types:

| Template # | Hook Type | Visual Strategy | Aspect Ratio Variants |
|-----------|-----------|-----------------|----------------------|
| 1 | Curiosity Gap | Text-dominant + reaction face | 9:16 + 1:1 |
| 2 | Curiosity Gap | Question mark visual + setup | 9:16 only |
| 3 | Pattern Interrupt | Smile + dark imagery contrast | 9:16 + 1:1 |
| 4 | Pattern Interrupt | Formal in chaotic setting | 9:16 only |
| 5 | Stakes Reveal | Financial/data viz + text | 9:16 + 1:1 |
| 6 | Stakes Reveal | Broken/decline imagery + text | 9:16 only |
| 7 | Identity Match | Subject in niche gear/environment | 9:16 + 1:1 |
| 8 | Identity Match | Niche-specific object dominant | 9:16 only |
| 9 | Mechanism Reveal | Diagram/process visual + text | 9:16 + 1:1 |
| 10 | Mechanism Reveal | "Hidden" mechanism teased visually | 9:16 only |

Each template includes:
- Master Figma file at correct dimensions
- 3 color variation options
- Typography rules
- Example deployments (3 worked examples per template)

### Step 6: First-Frame / Static Hook Compatibility

For video content, the first frame IS the thumbnail (autoplay logic). Design templates so:
- First frame = thumbnail-quality (passes Self-Test Hierarchy Audit)
- Title text appears in first 0.5 seconds
- Subject is on-screen and visually anchored from frame 1

For static-only deployment (carousel covers, image hooks):
- Same templates work with text-as-primary or subject-as-primary
- Carousel covers benefit from "incomplete information" — text that promises slides 2-N

### Step 7: Run the Cross-Stack Quality Audit

For each template, run BOTH disciplines' quality checks:

**Omar layer**:
- Visual hierarchy 1-2-3 audit (1-second test)
- Focal point on grid intersection
- Premium aesthetic preserved (no cheap-looking elements)

**Kallaway layer**:
- Does the verbal hook open a curiosity gap, force a pattern interrupt, etc.?
- Word count 6-12?
- Niche specificity preserved (would your ICP recognize this is for them?)

If template fails either layer → rebuild.

## Content Type Adaptations

| Platform | Adaptation |
|----------|-----------|
| Instagram Reels | 9:16 dominant; first-frame critical (autoplay logic) |
| TikTok | 9:16; less text density (younger audience, quicker scroll) |
| YouTube Shorts | 9:16 + thumbnail also for in-feed display; higher text density acceptable |
| YouTube long-form | 16:9 thumbnail; subject face dominant; text concise |
| LinkedIn carousel covers | 4:5 or 1:1; text density medium; professional aesthetic |
| Twitter/X video covers | 1:1; high text density acceptable |

## Quality Gate

Score against `genius.md` Quality Rubric Criterion 3 (Visual Hierarchy Discipline). Pass condition: 8+/10.

Cross-stack: also score against Kallaway's content psychology rubric (curiosity gap depth, hook clarity, niche specificity).

**Veto**:
- Template fails 1-second self-test → rebuild
- Verbal hook >12 words → trim or fail
- Generic stock-photo-feeling thumbnail → rebuild with niche-specific imagery

**Anti-pattern check**:
- Templates that all look the same with text variation → variation failure, rebuild for visual diversity
- Curiosity gap without verbal payoff in content → bait-and-switch, drops trust
- Pattern interrupt without follow-through → dilutes hook power
- All templates target same hook type → diversity failure, rebuild distribution

**Iteration loop**: Track CTR per template across deployments. Quarterly: kill bottom 2 templates, build 2 new based on winner patterns.
