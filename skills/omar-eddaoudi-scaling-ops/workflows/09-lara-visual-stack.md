## Execution

### Step 1: Voice + Identity Lock

Before any visual work, confirm the brand has:
- Defined "I Am The Niche" positioning (Lara's identity framework)
- 3-5 content pillars identified
- Distinct verbal signature (specific phrases, opening patterns, closing patterns)
- Audience clarity (who they're writing FOR)

If any are missing → halt and complete Lara's content frameworks first.

### Step 2: Translate Voice into Visual Language

For each verbal element, identify visual analog:

| Verbal Element | Visual Translation |
|----------------|-------------------|
| Authoritative tone | Achromatic palette + high contrast |
| Warm/conversational tone | Softer secondary palette + earth tones |
| Counterintuitive thinker | Asymmetric composition + unexpected color pairings |
| Established expert | Editorial typography + serif fonts |
| Modern operator | Sans-serif + minimal aesthetic |
| Storyteller | Lifestyle imagery dominant + atmospheric photography |

Build a visual mood board reflecting voice (5-10 references from premium brands the client respects).

### Step 3: Build the LinkedIn Asset Set

Per LinkedIn deployment surface, design assets:

**1. Profile Banner** (1584 × 396)
- Apply 4-line grid
- Focal point = brand promise / one-liner positioning
- Secondary = name + role (often outside the banner, in profile area, but coordinated)
- Tertiary = subtle authority signals (publication mentions if any)
- Use achromatic + 1 brand accent color for premium

**2. Profile Picture** (400 × 400 minimum)
- Editorial-quality headshot
- Background = subtle, never busy
- Subject framing = top third (eye-line on grid intersection)

**3. Content Card Templates (4 variations)**
- Card 1: Quote / one-liner (typography-dominant)
- Card 2: Insight / framework (illustrated)
- Card 3: Question / hook (typography-led)
- Card 4: Personal story (subtle lifestyle imagery + quote)

**4. Carousel Templates (3 variations)**
- Cover frame: hook + visual punch
- Internal frames: hierarchy of information
- Closing frame: CTA + brand mark

**5. Post Quote Cards (consistent template)**
- For pulling key quotes from posts
- Brand-aligned typography
- Subtle attribution

**6. Newsletter Cover Template**
- For Substack / Beehiiv / LinkedIn Newsletter
- Editorial feel
- Predictable layout (recognizable across editions)

### Step 4: Apply Composition Discipline

Per asset, run the standard checks:
- 4-line grid alignment
- Visual hierarchy 1-2-3 audit (1-second test)
- Premium aesthetic consistency (achromatic palette + brand accent)
- Editorial-quality typography (avoid LinkedIn-default looking templates)

### Step 5: Build the Thumbnail Library

For ongoing content creation, build 10 thumbnail templates:
- 5 editorial-style (typography-dominant, premium feel)
- 3 subject-photo style (founder/expert as visual anchor)
- 2 illustration-led (for framework / process content)

Each thumbnail template comes with:
- Master Figma file
- Color palette options (3 secondary palette shifts)
- Typography style guide
- Example deployment

### Step 6: Voice-Visual Coherence Audit

Final check across all assets:
- Does the visual system reinforce the verbal positioning? (Premium voice → premium visuals)
- Would a stranger seeing only the visuals predict the voice? (Yes = coherent, No = misaligned)
- Are there cross-asset visual signatures? (Recurring color, typography, composition logic)

### Step 7: Deliverable

Produce:
- `linkedin-brand-system-[client]-[date].md` documentation
- Master Figma file with all templates
- Brand guidelines (colors, typography, composition principles)
- Thumbnail library (10 templates ready to deploy)
- Deployment guide (which template for which content type)

## Content Type Adaptations

| Expert Type | Adaptation |
|-------------|-----------|
| Ghostwriter / consultant | Editorial-dominant aesthetic; minimize founder-photo content |
| Coach / advisor | Warmer aesthetic; lifestyle imagery moderate; founder-photo central |
| Author / thought leader | Editorial-heavy; book/publication imagery; quote-card dominant |
| Operator / agency owner | Process-led visuals; framework illustrations; case-study templates |
| Investor | Highly editorial; data viz templates; muted palette only |

## Quality Gate

Score against `genius.md` Quality Rubric Criterion 3 (Visual Hierarchy Discipline) + Criterion 4 (Premium Aesthetic Consistency). Pass condition: 8+/10 each.

**Cross-stack quality check**: Does this deliverable READ as one brand across visual + verbal? Run a stranger test — show 3 random posts + 3 random visuals separately and ask "does this feel like the same person?" If no → realign visual to voice.

**Anti-pattern check**:
- LinkedIn-default templates that look like everyone else's profile → premium positioning failure
- Stock photography in cards → erodes editorial feel
- Inconsistent typography across assets → visual fragmentation
- Voice + visual misalignment (warm voice + cold visuals or vice versa) → audit and fix

**Iteration loop**: Refresh thumbnail library quarterly. Voice evolves; visual system should evolve with it.
