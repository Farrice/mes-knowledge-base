# 05 — Premium Ad Teardown

> Per Omar (analyzing Whoop's "Add More Life to Your Years"): "These unique ads follow hidden principles that guide your eye, evoke emotion, and trigger you to feel something before you even know why."

Systematic teardown methodology. Transforms looking at ads from "I like this one" to "this works because of patterns A, B, C — and here's how to replicate."

## Pre-Flight Gate

Run this workflow when:
- ✅ Studying competitor ads to extract patterns
- ✅ Analyzing your own winning ads to identify what made them win
- ✅ Auditing a portfolio for pattern repetition / staleness
- ✅ Building a swipe file of high-performing ads in your category

Skip when:
- ❌ You only have 1 ad to analyze (need minimum 3-5 for pattern extraction)
- ❌ Ads are pre-launch / no performance data on own ads

## Execution

### Step 1: Assemble Ad Set

Collect 3-7 ads to analyze. Sources:
- Competitor ads (Meta Ads Library, internal scraping tool)
- Own brand top-performers (last 90 days, sorted by ROAS)
- Industry benchmarks (Whoop, Aura, Seed, etc. for premium category)

Capture for each ad:
- Screenshot at full resolution
- Brand + product
- Format (1:1 / 4:5 / 9:16 / video / carousel)
- Performance data if known (ROAS, CTR, spend duration)

### Step 2: Run the 4-Layer Teardown Per Ad

For each ad, analyze in this order:

#### Layer 1: Composition
- Where's the focal point? (Mark on screenshot)
- Does it pass the 4-line grid test? (Place mental grid)
- Visual hierarchy: what reads 1st / 2nd / 3rd in 1-second test?
- Color contrast strategy: primary palette + secondary?
- Authority deployment: niche-relevant or generic?

#### Layer 2: Psychology
- Which neural trigger category dominates? (Fear / Desire / Social Proof / Cognitive Bias / Urgency / Trust)
- Specific trigger deployed?
- Trigger intensity (1-10)?
- Funnel stage targeted?

#### Layer 3: Positioning
- What category does this ad position the product in?
- Is this category-leading or category-following positioning?
- Is there a counter-positioning move (e.g., "we're not [category default]")?
- What white space is being claimed?

#### Layer 4: Replicable Lesson
- Single sentence: what's the transferable principle?
- Which of the 17 genius patterns is in play?
- How would I deploy this in a different category?

### Step 3: Pattern Cross-Reference

After all ads analyzed, look for patterns ACROSS ads:
- Which patterns appear in multiple ads?
- Which patterns appear ONLY in winners (if you have performance data)?
- Which patterns are present in losers but absent in winners (anti-patterns)?

### Step 4: Build the Pattern Library Output

Per ad, produce a one-page teardown:

```
## [Brand] — [Ad Description]

[Screenshot]

### Composition
- Focal point: [where + how engineered]
- Grid alignment: [pass/fail + observations]
- Hierarchy 1-2-3: [first / second / third element]
- Color strategy: [primary + secondary palette analysis]
- Authority: [if present, who + niche-relevant?]

### Psychology
- Dominant trigger: [category + specific]
- Trigger intensity: [1-10]
- Funnel stage: [which]

### Positioning
- Category positioning: [...]
- Counter-positioning move: [if any]
- White space claimed: [what nobody else says]

### Replicable Lesson
[Single sentence transferable principle]

### Patterns Deployed (from genius.md)
- [Pattern #X]: [how]
- [Pattern #Y]: [how]
```

### Step 5: Cross-Ad Synthesis

After per-ad teardowns, produce synthesis:
- "Top 3 patterns that appeared in winners"
- "Top 2 anti-patterns that appeared in losers"
- "1 pattern nobody in this set is using" (white-space opportunity)
- "3 ideas for our brand based on this teardown"

### Step 6: Deliverable

Produce `ad-teardown-[date].md`:
1. Methodology summary
2. Per-ad teardowns (one page each)
3. Cross-ad synthesis
4. Pattern library updates (any new patterns discovered)
5. Recommendations for our brand

## Content Type Adaptations

| Teardown Type | Adaptation |
|---------------|-----------|
| Competitor analysis | Focus heavily on positioning + white space — what are they NOT saying? |
| Own portfolio audit | Add performance data column; correlate patterns with ROAS |
| Industry benchmarks | Cross-category — note which patterns travel and which don't |
| Pre-launch swipe file | Tag each ad with which avatar's stage it would best target |
| Diagnostic on stuck brand | Compare current portfolio to swipe file; identify pattern gaps |

## Output Requirements

The deliverable must include:
- ✅ 3-7 per-ad teardowns at the 4-layer depth
- ✅ Cross-ad pattern synthesis
- ✅ Pattern library updates (any new patterns)
- ✅ Specific recommendations for own brand based on findings
- ✅ Identified white space opportunities

## Quality Gate

Score against `genius.md` Quality Rubric — applies analytically (you're scoring the analyzed ads, not your own deliverable). Aim for: every ad gets a clear pattern attribution.

**Anti-pattern check**:
- "I like this one" without specific pattern attribution → re-analyze with the 4-layer framework
- Vague patterns ("good design") → specify which of the 17 patterns is in play
- No replicable lesson → re-analyze; if you can't extract a transferable principle, the ad isn't worth tearing down
- Skipping psychology layer → composition without psychology is decoration analysis

**Synthesis check**: Does the teardown produce specific brand recommendations or just observations? Recommendations are the actionable output.
