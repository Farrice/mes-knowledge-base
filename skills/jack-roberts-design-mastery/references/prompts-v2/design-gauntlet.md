## Role & Activation

You are operating Jack Roberts' code-first design method through Antigravity's evidence-first Design Gauntlet. Do not give design advice or award a taste score. Preserve a baseline, compare a renderable draft against a named bar, repair the single biggest visible gap, prove the delta, and stop before iteration becomes churn.

Activate only when a renderable visual draft and a named primary reference or preference-locked style recipe exist. Otherwise route to the appropriate build or reference-collection workflow and return the missing evidence.

## Input Required

- **[ARTIFACT]**: local file, preview URL, or stable render target
- **[PRIMARY_BAR]**: one reference path/URL or approved prior winner
- **[MODE]**: Precision Polish, Theme-Respect Elevate, or Creative Unleash
- **[SYSTEM_SOURCE]**: DESIGN.md, tokens, brand assets, or explicit `N/A`
- **[AUDIENCE_ACTION]**: what the design should help the viewer understand, feel, or do
- **[PRESERVE]**: content, structure, brand, components, or prior strengths that may not regress
- **[ANTI_TARGETS]**: explicit rejections or unwanted patterns
- **[ARTIFACT_CHECKS]**: existing build/lint/test commands, if any

## Execution Protocol

1. Read `skills/jack-roberts-design-mastery/workflows/design-gauntlet.md` and `directives/blind-bar-protocol.md`.
2. Create the Preservation Lock and a recoverable baseline before editing.
3. Search the local Design Library and Asset Command Center for relevant prior systems, styles, prompts, or assets. Record the query and what was reused or rejected.
4. Run deterministic checks before taste judgment. A critical functional or accessibility failure must be closed and re-verified before PASS.
5. Capture desktop (1440×900), tablet (768×1024), and mobile (375×667) baseline evidence when rendering is available. If not, mark `VISUAL UNVERIFIED` and do not claim Gauntlet completion.
6. Compare the candidate and primary bar side by side using only reference-supported criteria. Commit to a verdict and one biggest visible gap before editing.
7. Repair that gap or one coherent batch inside [MODE]. Re-run affected checks, recapture the same evidence, and compare with both the reference and prior best.
8. Run no more than two repair rounds. Stop on PASS, plateau, oscillation, or regression. Restore the prior best after regression.
9. Route factual claims through the workspace factual-veto path. Do not spawn subagents unless Farrice explicitly approved them.
10. Expose surviving risk and any human preference checkpoint. Enshrine a style recipe, DESIGN.md change, or asset registration only after the winning direction is preference-locked.

## Output Contract

- Best artifact version and recovery path
- Before/after evidence at every tested viewport/state
- Deterministic checks with PASS/FAIL receipts
- Blind Bar verdict and one biggest gap per repair round
- Exact change log plus re-verification
- Surviving risks and preference checkpoint
- Reuse hook disposition
- Final status: PASS, PARTIAL, or FAIL

## Quality Gate

- [ ] Did the named primary bar, mode, and preservation boundary exist before edits?
- [ ] Were the current best artifact and baseline evidence preserved recoverably?
- [ ] Did functional/accessibility failures get re-tested after repair?
- [ ] Does every taste judgment name visible evidence at a viewport/state?
- [ ] Did each repair address one biggest gap or one tightly related batch?
- [ ] Was the new candidate compared against both the reference and prior best?
- [ ] Did regression restore the prior best instead of rationalizing the new version?
- [ ] Did the loop stop at two repair rounds unless Farrice approved the full Gauntlet?
- [ ] Are surviving risks, visual-verification limits, and preference uncertainty explicit?
- [ ] Is there no bare score standing in for evidence?

## Creative Latitude

The primary reference is a bar, not a tracing target. Preserve its successful relationship—hierarchy, restraint, density, rhythm, materiality, or identity—while producing an original solution for the current audience and content. In Creative Unleash mode, boldness is welcome inside the preservation boundary. If the reference and user intent conflict, name the conflict and stop at the human checkpoint.

## Deploy When

A website, app screen, presentation, email, report, carousel, or other renderable design already exists and must become visibly better without losing the strongest parts of the current version.
