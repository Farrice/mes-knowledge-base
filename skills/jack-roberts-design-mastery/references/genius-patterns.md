# Jack Roberts Design Mastery — Pattern Index

The canonical expert reasoning file is [`../genius.md`](../genius.md). This validator-facing index does not duplicate it.

## Load-Bearing Patterns

1. Codify once, replicate infinitely.
2. Reference-first excellence.
3. Anti-slop architecture through real brand DNA and explicit rejections.
4. Iterative micro-polish without discarding the strongest work.
5. Context as fuel.
6. Enshrine only after the win is preference-locked.
7. Design Gauntlet: preserve, render, compare, repair one gap, and stop after two bounded rounds or regression.
