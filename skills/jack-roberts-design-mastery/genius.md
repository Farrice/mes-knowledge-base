The unlock: once you know design components, you give the AI the assets, explain what "good" looks like, and drive it.

## The 5-Step Design System (Core Framework)

### Step 1: Pick Your Format
Choose the highest-leverage design asset. Start with what you create most often and what would have the highest impact if automated.

**Format options:**
- Landing pages and web apps
- HTML slide decks / presentations
- Branded graphics and social media
- Reports and proposals
- Data visualization
- Identity systems / brand books
- Infographics and documents

**Selection criteria:** "What is the thing you spend most of your personal time creating and what would have the highest impact if you were to automate it?"

### Step 2: Equip Integrations
Give the AI the tools and connections it needs:

| Tool | Purpose |
|------|---------|
| **Firecrawl** | Extract brand identity from any website — logos, accent colors, typography, HTML |
| **Kia API** | Cost-effective image generation via Nano Banana 2 (~$0.06/image) |
| **Granola** | Meeting transcripts for context-aware presentations |
| **Gmail/Calendar** | Client context, scheduling awareness |
| **YouTube** | Research and reference material |
| **NotebookLM** | Deep research integration |

**Philosophy:** Add every relevant data source. The AI needs context to produce contextual design.

### Step 3: Define Excellence (Design Philosophy)
This is the critical step. Find what excellent design looks like BEFORE building.

**Process:**
1. Start with the end outcome (what should happen after someone sees this?)
2. Collect reference materials: Midjourney for illustration styles, Godly.website for web inspiration, 25.dev for components, Google image search for format-specific references, Canva templates for structural starting points
3. Provide brand assets: fonts, typography, logos, color palettes
4. Define the design philosophy in natural language that the AI can interpret

**The key prompt pattern:**
> "I would like to build a skill for building [FORMAT]. The format is [SPECS]. I would like to define what excellence looks like. I'm going to give you some beautiful materials so we can agree and go back and forth on a desired style. Once we've done that, I'm going to make sure you're using the right skills, the right connections, and then we're going to codify this to be a skill that I can use whenever I want."

### Step 4: Generate & Refine (The 80/20 Loop)
Build the first draft to get 80% of the way there, then refine:

**Generation phase:**
- Provide all context in a single comprehensive prompt
- Let the AI build the full first draft
- Include specific instructions: "Lead with metaphors," "Do research on what makes great [format]"

**Refinement phase (micro-polishes):**
- Give specific, actionable feedback: "I don't like X. Let's never have that."
- Add structural rules: "Logo centered on first deck. Client logo on final deck."
- Request sub-agent research: "Spin up sub-agents and fact-check that research"
- Iterate until the output matches your standard of excellence

### Step 5: Enshrine as Skill
Convert the refined design process into a reusable, one-command skill:

> "I would like to turn this entire thing into a skill. I'm going to give you some information in the future, and you're going to produce this for me systematically."

**What gets enshrined:**
- The design philosophy (aesthetic rules)
- The integration requirements (tools needed)
- The structural conventions (layout rules, brand placement)
- The refinement criteria (what "done" looks like)
- The prompt patterns that produced the best results

## Genius Patterns

### 1. Codify-Once-Replicate-Infinitely
The master pattern. Every design decision, once perfected, becomes a permanent system instruction. You never solve the same design problem twice.

### 2. DESIGN.md as Source of Truth
A plain-text markdown file — no Figma, no JSON, no special tooling — that captures the complete design language of any brand or style. The AI reads markdown better than any other format.

**DESIGN.md anatomy:**
- Visual Theme & Atmosphere (mood, density, aesthetic philosophy)
- Color Palette & Roles (descriptive name + hex code + functional role)
- Typography Rules (font family, weight usage, letter-spacing)
- Component Stylings (buttons, cards, inputs)
- Layout Principles (whitespace strategy, grid alignment)

### 3. Anti-Slop Architecture
Deliberately combating AI's default aesthetic by:
- Extracting real brand DNA (not relying on AI defaults)
- Providing specific reference materials (not generic prompts)
- Defining what excellence looks like before generation
- Using real-world design systems as templates, not AI imagination

### 4. Brand DNA Extraction (Firecrawl Pattern)
Don't describe a brand — extract it. Use web scraping tools to pull:
- Exact logos and brand marks
- Precise accent colors and palettes
- Typography families in use
- HTML/CSS patterns and component styles
- Overall visual structure and hierarchy

This produces pixel-accurate brand consistency that manual description never achieves.

### 5. Reference-First Excellence
Never start from a blank canvas. Always start from:
1. World-class examples of the target format
2. Specific illustration/visual styles you admire
3. Competitive analysis of what exists
4. User/audience expectations for the format

### 6. Highest-Leverage-First Selection
Don't automate everything at once. Find the ONE format you create most often, perfect the system for it, then expand. Impact = frequency × time-saved × quality-improvement.

### 7. Context-as-Fuel
The more context the AI has, the better the design. Connect every relevant data source: meeting transcripts, brand guidelines, client history, project briefs. Design without context produces slop.

## Signature Moves

### The Design Philosophy Prompt
Instead of giving the AI layout instructions, give it an aesthetic worldview:
> "I would like to lead with metaphors. I want it to be beautiful to look at. Do research on what makes great presentations and implement that throughout."

### The Firecrawl Brand Inject
Use Firecrawl to extract a company's visual identity, then inject it directly into the design context. The AI pulls logos, colors, typography — everything needed for brand-consistent output.

### The Iterative Micro-Polish
Don't try to get perfection in one shot. Get 80% right, then give hyper-specific feedback:
- "I don't like the 'now live' and 'beta' labels. Let's never have that."
- "Logo in the center of the first deck. Client's logo on the final deck."
- "Simplify. Less text. More visual."

### The Skill Enshrinement
After perfecting a design workflow, explicitly ask the AI to codify it as a reusable skill — turning discovery into infrastructure.

| Dimension | Savant (9-10) | Professional (7-8) | Generic (4-6) | Slop (1-3) |
|-----------|---------------|---------------------|----------------|------------|

| **Reusability** | One-command reproduction at identical quality | Minor adjustments needed per use | Significant manual work each time | Essentially starting from scratch |
