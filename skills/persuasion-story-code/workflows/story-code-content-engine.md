# Story Code Content Engine

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/story-taxonomy.md`
- `skills/persuasion-story-code/references/stacking-guide.md`

Use when the user needs written content: LinkedIn posts, X threads, Instagram captions, emails, newsletters, blog sections, carousels, or founder notes.

## Input Required

- Topic, offer, insight, or raw story.
- Target audience.
- Platform or channel.
- Desired action.
- Tone constraints and proof available.

## Execution

1. **Pick the story job**: Choose what the content must move: attention, trust, desire, clarity, proof, objection, or action.
2. **Select story type**: Match the content to one Story Code type.
3. **Draft the core story**: Write a short conversational version.
4. **Package for channel**: Adapt structure for post, thread, email, newsletter, or caption.
5. **Add content mechanics**: Hook, story body, bridge, proof, CTA, and repurposing notes.
6. **Create variations**: Produce versions with different story jobs when useful.

## Output Schema

Produce a **Written Content Package**:

- **Primary Piece**: ready to publish.
- **Hook Variants**: 5 options.
- **Short Version**: for fast social posting.
- **Email Version**: subject line + body when relevant.
- **Thread/Carousel Outline**: when relevant.
- **Repurpose Notes**: how to turn it into video or sales copy.
- **Proof/Claim Notes**: anything needing evidence.

## Quality Gate

- The content leads with story or story tension, not generic advice.
- It stays platform-appropriate.
- It contains a clear next step without sounding forced.
