# Story Code Video Stack

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/stacking-guide.md`
- Relevant partner skill only when needed: PJ Accetturo, Tao Prompts, Remotion, or `/create-video`.

Use when the user wants persuasive video content, ads, product demos, founder videos, VSL sections, shorts, reels, or production prompts.

## Input Required

- Video goal and platform.
- Product, offer, or story.
- Audience and desired action.
- Visual assets, proof, product shots, testimonials, or B-roll if available.
- Length target.

## Execution

1. **Story Code layer**: Pick the story job and write the spoken story spine.
2. **Video concept layer**: Turn the story into visual beats and a retention path.
3. **Prompt layer**: Describe scenes, shots, transitions, and product moments for AI/video production.
4. **Production layer**: Package script, shot list, on-screen text, and edit notes for the next tool.
5. **Distribution layer**: Create cutdowns and hooks for short-form platforms.

## Output Schema

Produce a **Video Story Production Brief**:

- **Core Video Story**.
- **Script**: short-form and long-form versions when useful.
- **Shot List**.
- **On-Screen Text**.
- **B-Roll / Asset Needs**.
- **AI Video Prompt Notes**.
- **Cutdowns**: 15s, 30s, 60s.
- **Handoff**: exact next workflow to run.

## Quality Gate

- The story can be understood without reading captions.
- Visuals support the persuasion job.
- Production notes do not add unsupported claims.
