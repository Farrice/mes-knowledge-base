# Story Code Video Script

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/story-taxonomy.md`
- `skills/persuasion-story-code/references/stacking-guide.md`

Use when the user needs a video script for short-form content, VSL sections, founder video, product explainer, case-study video, or ad script.

## Input Required

- Topic, offer, product, or story.
- Audience.
- Platform and target length.
- Desired action.
- Proof and visual assets if available.

## Execution

1. **Choose the story job**: Attention, familiarity, desire, reassurance, explanation, proof, or objection handling.
2. **Build the story spine**: Hook -> short scene -> meaning -> business bridge -> CTA.
3. **Make it visual**: Turn abstract claims into visible moments, gestures, screenshots, demos, or B-roll prompts.
4. **Write the script**: Keep lines speakable and concise.
5. **Add shot notes**: Suggest visuals that support the story without distracting.
6. **Prepare stacking handoff**: If production is needed, hand the script to PJ, Tao, Remotion, or `/create-video`.

## Output Schema

Produce a **Video Script Package**:

- **Story Strategy**: story type, job, audience barrier.
- **60-Second Script**: spoken lines with beats.
- **15-Second Cutdown**: hook and core story.
- **Longer Version**: 2-5 minute structure when relevant.
- **Visual Direction**: shot list, B-roll, on-screen text, demo moments.
- **Hook Variants**: 5 options.
- **Production Handoff**: notes for PJ/Tao/Remotion.

## Quality Gate

- The script sounds spoken, not written.
- The story is visible on screen.
- The CTA follows naturally from the story.
