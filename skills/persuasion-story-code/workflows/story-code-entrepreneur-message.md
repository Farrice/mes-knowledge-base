# Story Code Entrepreneur Message

## Pre-Flight Gate

Load:
- `skills/persuasion-story-code/genius.md`
- `skills/persuasion-story-code/references/story-taxonomy.md`
- `skills/persuasion-story-code/references/stacking-guide.md`

Use when the user needs a founder message, offer message, pitch, launch angle, positioning section, or business explanation powered by persuasion stories.

## Input Required

- Business or offer.
- Audience and current belief.
- Main promise.
- Proof, founder context, customer results, mechanism, or differentiator.
- Target format: website, pitch, sales page, email, post, deck, webinar, or video.

## Execution

1. **Clarify the agreement target**: State exactly what the audience should now believe or do.
2. **Build a story stack**: Choose 3-5 story blocks that match the persuasion sequence.
3. **Assign roles**: Origin for credibility, experience for empathy, future for desire, explanation for clarity, trust for proof, reassurance for risk.
4. **Write the message spine**: Connect stories with minimal framing and clean transitions.
5. **Create channel version**: Shape for the requested asset.
6. **Add proof prompts**: Mark where metrics, screenshots, testimonials, or demos should be inserted.

## Output Schema

Produce a **Story-Led Message System**:

- **Core Message**: one concise statement.
- **Story Stack**: ordered story blocks with exact purpose.
- **Finished Draft**: complete asset for the requested format.
- **Alternate Openings**: 3 options with different story types.
- **Proof Insertions**: where to add evidence.
- **Stacking Recommendation**: which Antigravity expert to use next if more conversion, social, or video polish is needed.

## Quality Gate

- The message is not a list of claims.
- Each story block answers a buyer question.
- The final draft can be used without further creative work.
