# Story Taxonomy

## Origin Stories

Use when the prospect needs to know why the person, product, method, or company deserves belief.

| Story Type | Use When | Core Structure |
|---|---|---|
| Qualifications / Track Record | Expertise needs proof | Motivating moment -> touchstones -> outside recognition -> current authority |
| Discovery | The offer came from an important finding | Frustration -> discovery -> concrete change |
| Failure / Success | The market has struggled and wants proof of turnaround | Painful failure -> matched success -> meaning of the turn |
| Created It Myself | The product exists because nothing adequate was available | Search/frustration -> decision to create -> highlights -> unique result |

## Prospect Experience Stories

Use when the prospect needs to feel recognized before they are ready for the offer.

| Story Type | Use When | Core Structure |
|---|---|---|
| Prospect Pain | You solve a felt problem | Specific daily moment -> physical/emotional detail -> unresolved pain |
| World Today | Market context is changing | Current event/shift -> prospect fear or hope -> why it matters now |
| Pain You Know Personally | You have lived the same pain | "I have been there" -> concrete experience -> shared frustration |
| Pressure From Others | Social judgment blocks action | Important people apply pressure -> prospect feels isolated -> need for support |

## Future Stories

Use when the prospect needs to want the future enough to act.

| Story Type | Use When | Core Structure |
|---|---|---|
| Unexpected Benefit | There is a valuable benefit beyond the main promise | Main promise -> surprising related benefit -> spinoffs -> cost of missing it |
| Predicted Transformation | The offer can credibly create rare ability or identity change | Rare ability -> impressive results -> life/self change |
| Improved Status | Status gain matters but should not be blunt | New markers of regard -> implied doors opening -> prospect imagines recognition |
| Future Health / Process Improvement | A technical process drives future outcome | One key mechanism fact -> simple process -> desired outcome |

## Reassurance Stories

Use when desire exists but doubt stalls action.

| Story Type | Use When | Core Structure |
|---|---|---|
| New Or Unfamiliar | The offer feels different or strange | Familiar anchor -> new difference -> why the difference helps |
| Others Made It Work | Prospect doubts usability | Similar person -> use moment -> successful result |
| Endurance Claim | Prospect doubts strength, durability, or permanence | Reasonable test -> harder test -> product holds |
| Refund / Risk Reversal | Prospect fears regret | What happens if dissatisfied -> simple safe path -> seller assumes risk |

## Explanation Stories

Use when the prospect asks, "How does this work?"

| Story Type | Use When | Core Structure |
|---|---|---|
| Product Use | Prospect cannot picture using it | User like them -> key use actions -> success |
| Mechanism | Unique process matters | Mechanism name -> simple visual explanation -> benefits |
| Eliminate Alternatives | One choice is clearly superior | Available choices -> unique difference -> prospect concludes there is no equal |
| Problem / Solution | The offer solves a known problem | Problem -> solution tried -> result |

## Trust Stories

Use when the prospect needs belief carried by other people or institutions.

| Story Type | Use When | Core Structure |
|---|---|---|
| Case Study | You need witnessed proof | Initial condition -> intervention -> result -> meaning |
| Certification | Authority recognition matters | Certifying body -> award/approval -> why it matters |
| Expert Testimonial | Known expert can validate | Expert identity -> concise endorsement -> credential context |
| Results Testimonial | Specific outcome matters | Problem/need -> provider/product -> result |
| Experience Testimonial | Fear of the experience matters | Initial anxiety -> actual experience -> relief/confidence |

## Responsive Story Selection

- **Confusion**: use created-it-myself, new/unfamiliar, mechanism, or product-use stories.
- **Uncertainty**: use others-made-it-work, case study, experience testimonial, refund, or problem-solution stories.
- **Objection**: use endurance, unexpected benefit, results testimonial, eliminate-alternatives, or certification stories.
- **Low trust**: use origin, case study, expert testimonial, certification, or personal-pain stories.
- **Low desire**: use unexpected benefit, transformation, status, or world-today stories.
