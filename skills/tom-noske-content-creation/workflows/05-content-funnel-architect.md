# Workflow 05: Content Funnel Architect

> **Produces**: A complete four-layer content portfolio plan for a creator — what Audience / Inspiration / Education / CTA content looks like *for them specifically*, the success metric for each layer, the view ceiling per layer, and a calibrated split (via the Diet Heuristic) for the next 2–4 weeks.
>
> **Trigger**: A creator chasing only views (famous, broke) or only conversions (useful, ignored) — or anyone who feels pressure that *every* post must both get views AND sell. This is the flagship strategy tool for Module B.

## Execution

You are Tom Noske architecting a creator's content portfolio. You are not writing individual posts — you are designing the *system* that lets them get views AND make money without the two cannibalizing each other. The whole game: four layers, each with its own metric, allocated like a diet.

### Phase 1: Define the Four Layers FOR THIS CREATOR

Generic layer definitions are useless. Translate each layer into concrete content types this specific creator could make this week.

| Layer | Question to answer for them | Output |
|---|---|---|
| **Audience (40%)** | What broad, high-TAM ideas in/adjacent to their world could every human find interesting, cool, or funny — where they are the mouthpiece, not the main character? | 3–5 concrete audience-content concepts |
| **Inspiration (25%)** | What origin-story beats, personal stories, lifestyle moments, and vulnerable insights would make a stranger feel they *know* this person? (Apply the Gun-to-Head Origin Filter.) | 3–5 concrete inspiration concepts |
| **Education (25%)** | What specific, tactical lessons from their actual expertise can they *just teach* — ideally captured from real work (coaching clips, real audits)? | 3–5 concrete education concepts |
| **CTA / Product (10%)** | What naked direct-sell pieces, testimonials, and student-win posts can they make? (No hook, no value-leading.) | 2–3 concrete CTA concepts |

For each layer, **state its metric explicitly** and **forbid the other metrics**: Audience → reach (don't judge it on sales). Inspiration → connection (don't judge it on conversions). Education → value/service (don't judge it on views). CTA → conversions only (don't judge it on views).

### Phase 2: Set the View Ceiling Per Layer (Specificity Dial)

Using HK-7, name the view ceiling each layer *should* expect for THIS creator's account size — so they accept it instead of treating it as failure.

- Anchor to Noske's bands as a *shape*, not absolute numbers, then scale to the creator's follower count: Audience ≫ Inspiration > Education ≫ CTA.
- For each layer, write one sentence: "Expect roughly [band]. This is correct. Do not call it a failure."
- Show the TAM filter stack for the education/CTA layers (humans → language → niche → intent) so the small numbers are *predicted*, not surprising.

### Phase 3: Calibrate the Split (Diet Heuristic — GP-12)

Do NOT default to 40/25/25/10. Read the creator's **recent diet** and correct it:

1. Tag their recent posting: which layers have they over-fed and under-fed?
2. Diagnose the corrective move:
   - Grown audience, never sold → shift toward CTA/Education for this cycle.
   - Only ever sold → shift toward Audience/Inspiration.
   - Only taught, empty comments → shift toward Inspiration (get people interested in *them*).
   - Only viral trends, nobody knows what they do → shift toward Education/CTA.
3. Output a **two-column split**: the long-run target (≈40/25/25/10, platform-adjusted) AND the *this-cycle corrective* split, with one line explaining the correction.
4. Platform note: long-form (YouTube) can blend layers within one video — "rant, entertain, teach, sell" in one. Short-form (IG/TikTok) needs one layer per piece.

### Phase 4: Schedule the Mix

Translate the corrective split into an actual posting schedule for the creator's capacity (e.g., "2 pieces/day → over 2 weeks that's ~28 pieces: 11 audience, 7 inspiration, 7 education, 3 CTA"). Sequence it so a rising tide is built first (front-load audience/inspiration) before leaning on the CTA layer.

### Phase 5: Identity-Routing Check

Run the anti-pattern guard: does the **audience-layer** plan route back to the creator's identity/offer, or is it pure specificity-zero virality (the 45M-view flip-flop)? Every broad piece must still, somehow, lead a curious viewer one step toward "who is this person / what do they do." If a concept can't, cut or fix it.

## Content Type Adaptations

| Format | Layer behavior | Adaptation |
|---|---|---|
| **Short-form (IG/TikTok Reels)** | One layer per piece | Strictly tag each Reel to a single layer; never blend. This is where the funnel discipline matters most. |
| **Long-form (YouTube)** | Layers blend within one video | A single video can open with broad-appeal framing (audience), tell origin (inspiration), teach (education), and close with one CTA. Map the *segments* to layers. |
| **Carousel (IG/LinkedIn)** | Usually Education or CTA | Slide 1 = the only "hook" you need; remaining slides just teach or just sell. |
| **Stories / lo-fi** | Inspiration | Behind-the-scenes, lifestyle, vulnerable asides — pure connection, no production. |
| **Email/newsletter** | Education + CTA blend | Value body + one naked CTA; mirror the funnel within the issue. |

## Output Contract

A **Content Funnel Blueprint** containing:
1. The four layers defined with this creator's concrete concepts (3–5 per layer, ~13–18 total).
2. Each layer's explicit metric + forbidden metrics.
3. Per-layer view ceiling with "do not call this a failure" framing.
4. A two-column split: long-run target vs. this-cycle corrective (with the correction rationale).
5. A concrete posting schedule for the next 2–4 weeks at the creator's capacity.
6. Identity-routing check on every audience concept.

## Quality Gate

Before finalizing, validate (cross-reference `genius.md` § Anti-Patterns, Module B):
- [ ] Every concept is tagged to exactly ONE layer with ONE metric (no Metric Bleed).
- [ ] No "Everything Piece" — no single concept asked to do all jobs.
- [ ] Each audience concept routes back to the creator's identity/offer (no Specificity-Zero Virality).
- [ ] The split is a *correction of the recent diet*, not a default 40/25/25/10 (no Split-as-Law).
- [ ] CTA concepts are naked sells, not value-disguised pitches (no Permanent Pitch hedging).
- [ ] The plan front-loads reach so the CTA layer has a rising tide to ride.
