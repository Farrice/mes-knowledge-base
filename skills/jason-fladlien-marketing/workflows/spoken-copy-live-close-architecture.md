## Workflow

### Phase 1: The Live Close Architecture
Design the structural flow of the spoken close.

- **Task**: Create a **Live Close Blueprint**:
  1. **The Radical Candor Opening** (60 seconds): Establish the frame — "I got to determine whether you should give me money or not."
  2. **The Label-and-Disarm** (2 min): Name the biggest fear in the room. "This is going to be scary. This is going to be difficult."
  3. **The Constraint Naming** (2 min): Articulate WHY they haven't bought yet — inertia, comfort, fear of the unfamiliar.
  4. **The Key Ring Sequence** (10-15 min): 5-7 close attempts, each using a different psychological lever.
  5. **The 10% Self-Selection** (2 min): Indirect close targeting the elite buyers.
  6. **The Double Bind Finale** (3 min): Cost-of-inaction projection.
  7. **The Soft Exit** (1 min): "If this makes sense, I'll see you inside. If not, no hard feelings."

### Phase 2: The Hypnotic Language Toolkit
Equip the close with spoken-only hypnotic elements.

- **Task**: Design **Hypnotic Language Elements** for the close:
  1. **Embedded Commands**: Phrases with hidden instructions ("You don't have to immediately *accept it*")
  2. **Presuppositions**: Assumptions baked into statements ("When you start seeing results...")
  3. **Truisms That Can't Be Invalidated**: "Some of you will be successful with this" (can never be proven wrong)
  4. **Cadence Markers**: Words to emphasize vocally to mark embedded commands (italic/bold for script)
  5. **Agree-First Patterns**: "I want you to *continue* to be skeptical"

### Phase 3: The Real-Time Read Playbook
Create decision trees for reading the audience.

- **Task**: Build a **Room-Read Decision Tree**:
  - **Signal**: Chat is active, lots of questions → **Move**: Deploy the Key Ring faster, they're engaged
  - **Signal**: Silence, drop-off → **Move**: Label-and-Disarm: "I can feel the hesitation. Let me address that directly."
  - **Signal**: Objections in chat → **Move**: Agree-and-Redirect live: "Great question. I love that skepticism."
  - **Signal**: Buying energy → **Move**: Accelerate to CTA, don't over-close
  - **Signal**: Specific names engaging → **Move**: Name them in the 10% Self-Selection close

### Phase 4: The Spoken Close Scripts
Write the actual scripts, marked for vocal delivery.

- **Task**: Produce 5 **Spoken Close Scripts** (each 200-400 words):
  - Script 1: The Fear-of-Familiarity Close (from Exemplar 1)
  - Script 2: The Radical Candor Frame
  - Script 3: The 10% Self-Selection
  - Script 4: The "What Does Staying the Same Cost You?" Double Bind
  - Script 5: The "Give Me Enough of You" Reciprocity Close
  - **Format**: Mark embedded commands in *italics*, cadence pauses with [PAUSE], vocal emphasis with **bold**

## Quality Gate
1. **Speakability Check**: Read every script out loud. If it doesn't flow conversationally → rewrite.
2. **Embedded Command Subtlety**: Are the embedded commands hidden enough to bypass conscious resistance?
3. **Room-Read Present**: Does the playbook account for at least 4 different audience states?
4. **No Script Dependency**: Could a skilled practitioner use this as a framework, not a word-for-word script?
5. **Radical Candor Opener**: Does the opening establish the "I'm selling you" frame within 60 seconds?

> **🛡️ Anti-Pattern Check**: Reject written-copy-disguised-as-spoken, formal language, and closes that would sound robotic when spoken aloud.
