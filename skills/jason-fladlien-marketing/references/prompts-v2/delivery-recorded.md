## Input Required

- [FORMAT_AND_LENGTH], [VOICE], [SUPPORTED_PROOF]
- [OFFER_TERMS] when relevant; [AVAILABLE_ASSETS] for recorded work

## Execution Protocol

1. Lock runtime, audience, channel, one takeaway and desired action. Select one weak reception point using D01/D04/D06.
2. Write the actual spoken lines, with a fast relevance setup and a demonstrated payoff (D09). Specify exactly what the viewer sees using available source assets; missing footage stays a production gap.
3. Use emphasis and selective pauses to help meaning (D03/D05). Timing marks are rehearsal suggestions, not measured source behavior. Do not use live response cues in recorded content.
4. Give the demonstration enough time to be inspected. The edit must not imply results, evidence, users or reactions that do not exist.
5. Connect the ending to one action (D17). If runtime allows an optional segment, provide an alternate complete ending; otherwise omit the extra segment.
6. Return a timed script table with spoken words, visible proof, audio/delivery intention and cut notes. Preserve the existing media craft owner for shot style and rendering. This prompt produces a script, not a finished video.

## Output Contract

Timed recordable script; available/missing asset list; source IDs; delivery rehearsal check; outcome test.
Return finished work first. Put analytical labels outside audience-facing copy. Source-trace entries use D01-D17 from the source ledger. Do not expose technique terminology to the audience.

## Quality Gate

- Reader can identify the useful outcome and actual action.
- Every factual claim has supplied support or is marked outside the copy as unresolved.
- Medium-specific behavior is respected; no fabricated crowd or simulated consent.
- One concrete demonstration or an explicitly named missing proof object.
- Voice, original promise and existing safety boundaries survive the rewrite.
- Final action is feasible; free and paid paths are honestly distinguished when used.
- No claim of conversion improvement, scientific validation or human taste approval from a structural check.

## Deploy When

Use recorded mode in `/fladlien-delivery` when the content exists or the brief is clear and reception/delivery is the consequential gap. Do not replace offer strategy, source research or visual production with this adapter.
