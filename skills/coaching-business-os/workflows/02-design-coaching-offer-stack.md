# Design Coaching Offer Stack

## Role

You are the conductor composing this hub's lanes into ONE coherent offer architecture: a business side that sells the promise (Welch / Hiette / Novotny / Elkaim lanes) and a transformation side that keeps it (Kotler / Eyal / Manson lanes). The output is the blueprint a coach could build and sell from — not seven disconnected lane outputs stitched together.

## Input Required

1. Niche + ICP: who the offer serves and the one problem it solves (if vague, run workflow 01 first)
2. The coach's genuine expertise and track record (the Specialist Prerequisite evidence)
3. Revenue target and capacity (hours/week available for delivery and for acquisition)
4. Existing assets: audience size by platform, email list, testimonials/case studies, current programs
5. Acquisition preference or constraint: paid budget available, or organic-only
6. (Optional) Existing offer to rebuild rather than design from scratch

## Workflow

### Phase 1 — Promise and Mechanism (Transformation Side First)

1. Define the transformation promise: specific end state, timeframe, for whom — in the client's symptom language, one problem, one population.
2. Select the mechanism from the transformation lanes and load only what's needed:
   - Performance/flow outcomes → `steven-kotler-flow-performance` (trigger-based protocol as the named method)
   - Adherence/consistency outcomes → `nir-eyal-habit-design` (the follow-through system built into delivery)
   - Meaning/self-sabotage outcomes → `mark-manson-values-psychology` (values work as the foundation module)
3. Name the mechanism (the proprietary method label) — this is what distinguishes the offer from information and justifies premium pricing. Teach-to-Sell rule: the marketing will reveal WHAT the mechanism is and why it works; only the program delivers HOW.

### Phase 2 — Structure and Price (Business Side)

1. Design the delivery structure: duration, cadence, format (1:1 / group / hybrid), and where each transformation-lane component sits in the client journey (e.g., Manson values intake → Kotler protocol build → Eyal adherence system → review cycles).
2. Price from transformation value and acquisition math, not market rates: target $2K-$10K program pricing (High-Ticket Structural Requirement). Compute allowable client-acquisition cost at that price. If the coach flinches at the number, flag a `taylor-welch-wealthy-consultant` identity pass as a prerequisite.
3. Run the positioning check via `jay-hiette-coaching-positioning` framing: what does the ICP currently believe that keeps them stuck, and what belief shift does every marketing asset need to make ("People think X, which causes Y, but the truth is Z")?

### Phase 3 — Acquisition Path (One Pipeline Only)

1. Select exactly ONE primary acquisition system:
   - Experienced coach + ad budget + wants off the content treadmill → `yuri-elkaim-health-coaching-business` Perfect Client Pipeline (ads → evergreen masterclass → application → call)
   - Fitness coach, organic-first, no budget → `gabe-novotny-fitness-content-business` (reels → stories → DMs, CPR economics)
   - Already posting with some traction, needs message-led deal flow → `jay-hiette-coaching-positioning` deal-flow build
2. Insert the Buy-a-Drink-First layer: name the intermediate value asset (masterclass, critique/audit offer, DM-keyword resource) and the nurture sequence behind it, set to a 2-4 week conversion clock. Email capture at first value exchange is mandatory — the list is the backend business.
3. Apply Packaging Before Production to the system's first-contact moment: 10+ variants of the masterclass title / hook / DM opener, validated against a working comparable, with effort weighted to first contact.
4. Write the deferral list: every acquisition channel NOT chosen, each with a metric trigger for when it earns a build.

## Output Contract

One offer-stack document (≤ 2 pages) containing:
- **Promise**: one sentence, symptom language, specific population
- **Named mechanism**: which transformation lane(s) power it and how the what-vs-how line is drawn
- **Delivery structure**: journey map with each lane component placed
- **Price + math**: program price, rationale, allowable acquisition cost
- **Belief-shift statement**: the X → Z shift all marketing must make
- **Primary acquisition system**: the one pipeline, stage by stage, with the intermediate value asset and nurture clock
- **Deferral list**: with re-entry triggers
- **Build order**: what gets built first, second, third

## Quality Gate

- [ ] At least one business-side lane AND at least one transformation-side lane composed — never acquisition without mechanism
- [ ] All composed lanes are this hub's own seven; peers outside the hub appear nowhere in the architecture
- [ ] Exactly one primary acquisition system; everything else on the deferral list with triggers
- [ ] Price is $2K+ program pricing with acquisition math shown, or an explicit written justification for going lower
- [ ] An intermediate value asset and nurture sequence exist between cold attention and the offer
- [ ] The document reads as one architecture (promise → mechanism → delivery → price → acquisition), not stitched lane outputs; ≤ 2 pages
