# Set and Location Content Map

## Use When

You have a house, venue, event space, booth, store, office, launch site, or client location and need to turn it into content infrastructure.

## Inputs

- Venue or location description.
- Available rooms, zones, props, products, people, and schedule.
- Team size.
- Platforms.
- Sprint duration.

## Process

1. Inventory every physical zone.
2. For each zone, identify:
   - Natural action.
   - Strongest prop or visual detail.
   - Best person or character.
   - Camera position.
   - Audio or dialogue opportunity.
   - Funnel job: reach, immersion, proof, product, bridge, or ritual.
3. Score each zone:
   - Repeatability.
   - Visual specificity.
   - Guest friction.
   - Brand fit.
   - Editing speed.
4. Select 3 to 7 primary sets.
5. Assign each selected set a daily capture target.
6. Name concepts that can repeat without feeling copied.

## Output

```markdown
# Set and Location Content Map

## Location Inventory

| Zone | Natural Action | Prop/Detail | Person | Funnel Job | Score |
|---|---|---|---|---|---|

## Primary Sets

## Daily Capture Targets

## Concepts By Set

## Missing Assets Or Props
```

## Quality Gate

The map fails if it lists locations but does not assign content jobs, repeatable actions, or capture targets.
