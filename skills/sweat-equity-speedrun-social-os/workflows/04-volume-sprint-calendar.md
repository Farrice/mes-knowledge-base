# Volume Sprint Calendar

## Use When

A team needs daily output targets, capture windows, edit windows, and publishing sequence for a short-window growth push.

## Inputs

- Sprint length.
- Target platforms.
- Team size.
- Number of sets.
- Output target.
- Approval constraints.

## Process

1. Choose sprint length: 3, 4, 7, or 14 days.
2. Set output targets by day:
   - Capture target.
   - Edit target.
   - Publish target.
   - Remix target.
3. Split content into:
   - Reach.
   - Immersion.
   - Proof.
   - Product.
   - Bridge.
4. Build a daily sequence:
   - Open with high-attention reach or invitation content.
   - Use immersion content to make the event feel alive.
   - Insert product/proof content only after attention exists.
   - Remix winners quickly.
5. Add approval and publishing checkpoints.

## Quality Gate

The calendar fails if it schedules posts without explaining what must be captured, edited, approved, and remixed each day.
