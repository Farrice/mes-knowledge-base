# Execution Station Role Map

## Use When

The sprint needs a real team process for capture, editing, approvals, guest asks, and same-day output.

## Inputs

- Team members.
- Available equipment.
- Sprint schedule.
- Number of sets.
- Approval owner.
- Publishing owner.

## Process

1. Assign core roles:
   - Director: owns the show, shot decisions, and live upgrades.
   - Shooter 1: owns primary set capture.
   - Shooter 2: owns roaming or secondary capture.
   - Editor: owns fast cuts, captions, exports, and versioning.
   - Handler: gets guests, permissions, and 20-second asks.
   - Publisher: owns captions, posting, and platform checks.
2. Define footage drop process.
3. Define brief format for each concept.
4. Define turnaround targets.
5. Define escalation rules:
   - Who can kill an idea.
   - Who can approve a live pivot.
   - Who can ask a guest.
   - Who can publish.
6. Create a war-room checklist.

## Quality Gate

The role map fails if it only lists job titles. It must name decisions, handoffs, backups, and time targets.
