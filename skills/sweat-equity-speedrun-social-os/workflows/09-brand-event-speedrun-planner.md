# Brand Event Speedrun Planner

## Use When

You need the full OS in one pass: narrative, sets, hooks, calendar, roles, live capture, funnel mix, bridges, and review plan.

## Inputs

- Brand/client.
- Event or launch moment.
- Sprint dates.
- Location or venue.
- Team and equipment.
- Audience.
- Platforms.
- Output target.
- Constraints.

## Process

1. Run Social Narrative North Star.
2. Run Set and Location Content Map.
3. Select 3 to 7 primary sets.
4. Run Modular Hook Multiplier for the top 3 sets.
5. Build the Volume Sprint Calendar.
6. Build the Execution Station Role Map.
7. Build the Top and Middle Funnel Mix.
8. Identify bridge moments and 20-second asks.
9. Add the In-The-Moment Capture Loop to the operating rules.
10. Define measurement:
   - Published pieces.
   - Views.
   - Saves/shares/comments.
   - Follower movement.
   - Collab posts.
   - Inquiries or sales signals.
   - Case-study material.

## Quality Gate

The plan fails if a team could not show up at the event and know what to shoot, who owns each handoff, what gets published, and how to adapt when better moments appear.
