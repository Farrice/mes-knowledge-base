These twelve patterns are production instincts, not a checklist to march through in order. A plan that visibly labels "Pattern 1: Temporary North Star, Pattern 2: Sets Before Posts..." in sequence has already failed the source discipline: a production team internalizes the system and then makes fast calls on the ground, it does not narrate the framework to the client. - Polish-is-the-tell warning: an output with no risk list, no missing-asset gaps, and no live-pivot judgment call reads as theory, not as a plan that has been inside a real venue. If nothing in the plan could go wrong, it has not been stress-tested against a live event.

## Core Thesis

A social speedrun is a production system, not a posting challenge. The team wins by turning a live environment into a set network, matching each set to a content job, creating repeatable concepts, and using fast human judgment to improve ideas while the moment is still alive.

## Genius Patterns

1. **Temporary North Star**: Translate the brand's larger narrative into a temporary event narrative. For the illustrative example, the broader idea of making golf more inclusive became making the home feel like the common space.
2. **Sets Before Posts**: Map the physical environment before writing ideas. Each backyard, entrance, store, table, coffee area, kitchen, or hallway can become a set with a repeatable content role.
3. **Itinerary Reverse Engineering**: Use the event schedule as a content map. Dinner, arrival, shopping, bird watching, cold plunge, run club, and guests are all source material.
4. **Modular Hooking**: A single set can produce several hooks if the team changes the opening action, visual detail, character, prop, or emotional frame.
5. **Scalable Concept Filter**: Prefer concepts that can be repeated quickly. If a concept can only happen once and requires heavy setup, it may not belong in a speedrun.
6. **Character-Led Sets**: The best set is often not the prettiest area; it is the area with a person who creates energy and unscripted lines.
7. **Friction-Light Participation**: A short prompt and a small action work best. Low friction creates more episodes.
8. **Top vs. Middle Funnel Split**: Reach content casts the wide net. Immersion content makes people feel like they were there. Product and proof content sell without flattening the event into an ad.
9. **Live Upgrade Loop**: The plan is a base layer. When a guest, prop, visual setup, or cultural story appears, the team spends 2 minutes making the idea stronger.
10. **Execution Stations**: The speedrun needs a director, shooters, dedicated editor, briefs, footage drop process, and someone who can ask guests for short moments.
11. **Bridge Building**: Guests and partners are bridges into new audiences. The best bridge also makes the guest look good, so collaboration becomes easy to approve.
12. **Story Compression**: A few seconds can contain setup, conflict, resolution, and brand meaning when props, action, and context are chosen well.

## Signature Moves

- Turn brand narrative into a one-line event north star.
- Draw the venue as a set map before choosing content ideas.
- Assign every set a content job: reach, immersion, product, proof, character, bridge, or ritual.
- Build concepts with repeatability tests: can it produce five pieces, can it be shot fast, can it survive imperfect conditions?
- Add one odd or specific action that keeps the viewer watching.
- Use props that already belong to the story.
- Keep an editor in a war-room loop for hour-scale turnaround. Per `references/hidden-knowledge.md`: "Fast editing is not back-office work. It decides whether content arrives while people still care, whether the team can learn during the event, and whether volume stays possible."
- Let the director carry the shot checklist and the permission asks.

## Quality Rubric

Score each sprint from 1 to 5:

| Criterion | 5 Means |
|---|---|
| North star clarity | Every idea clearly amplifies the temporary event narrative |
| Set productivity | Each important location has a content job and repeatable concept |
| Volume design | The plan can create enough clips without exhausting the team |
| Specificity | Content could only come from this brand, this place, and this moment |
| Funnel balance | Reach, immersion, product, proof, and bridge content are all represented |
| Turnaround speed | Capture, edit, approval, and publish loops are mapped before the event |
| Live judgment | Team can improve or replace ideas when better moments appear |
| Guest utility | Collaborators look good and have a reason to say yes |
| Proof capture | Results and source claims are tracked without inflating certainty |

Score bands should reference the skill's own structure checkpoints — the 9 workflows, the 12 genius patterns above, and the "First 24 Hours" review window used in `workflows/09-brand-event-speedrun-planner.md` — rather than a generic 1-5 vibe check with no anchor.

## Anti-Patterns

- Recap-only content after an expensive activation — per `references/hidden-knowledge.md`: "Most brands spend money on the event and under-invest in turning it into media."
- One photographer, one recap video, and no production map — per `references/genius-patterns.md` Pattern 10: "Assign director, shooters, editor, handlers, and approval roles before the event. The system fails if footage sits unused."
- Treating a beautiful room as a backdrop instead of a set — per `references/hidden-knowledge.md`: "A good prompt in a dead space stays generic."
- Volume without a narrative filter — per `references/genius-patterns.md` Pattern 1: "Use a short-lived event narrative as the filter for all content."
- Viral-chasing that ignores the brand's tone or tradition — per `references/hidden-knowledge.md`: "That specificity is why the output does not feel like a generic activation recap."
- Overproduced concepts that cannot be repeated — per `references/genius-patterns.md` Pattern 5: "Choose ideas that can produce multiple clips with low friction."
- Waiting until the event is over to edit — per `references/hidden-knowledge.md`: "Fast editing is not back-office work."
- Making guests work too hard for a clip — per `references/genius-patterns.md` Pattern 7: "Make guest participation easy: one prompt, one short action, one clear reason to say yes."
