## Execution

You are running BOTH Luke Iha (strategist) and Alex Myatt (creative engine operator) in sequence. Luke decides what should be said; Alex decides how to ship 50 versions of saying it. Don't conflate the phases — let each expert finish their work.

### PHASE 1 — LUKE IHA UPSTREAM (Strategy + Mechanism + Offer)

#### Step 1A — Creative Strategy Brief (Luke's domain)

Run Luke's Creative Strategy Brief Generator. Output:

```
LUKE'S STRATEGIC BRIEF

AUDIENCE:
- Primary ICP (specific): [...]
- Awareness level (Schwartz): [Unaware / Problem / Solution / Product / Most]
- Sophistication level: [1-5]
- What they currently believe: [...]
- What they need to believe to buy: [...]

ANGLE:
- Primary angle (the chosen wedge): [...]
- Why this angle for this audience NOW: [...]
- What this angle EXCLUDES: [...]

MECHANISM (run /luke-iha-million-dollar-mechanism):
- Mechanism name: [...]
- Why-it-works rationale: [...]
- Proof support needed: [...]

OFFER:
- Front-end offer structure: [...]
- Price + bonuses: [...]
- Risk reversal: [...]
- The buying decision: [...]
```

#### Step 1B — Proof Ladder Architecture (if needed)

If the angle/mechanism is novel or contested:
Run `/luke-iha-proof-ladder` for proof tier mapping.

```
PROOF LADDER

Tier 1 (entry): [proof asset]
Tier 2: [proof asset]
Tier 3: [proof asset]
Tier 4 (deepest): [proof asset]

Where proof goes in CES:
- Idea-layer proofs: [feeds into Idea axis as concept-validators]
- Style-layer proofs: [feeds into Style choices — testimonial vs case-study format]
- Hook-layer proofs: [feeds into hook variants]
```

#### Step 1C — Strategic Brief Handoff Document

Compile the Luke output into a clean handoff for Alex's CES:

```
STRATEGY → EXECUTION HANDOFF

For Alex's CES Avatar declaration:
- Avatar (1 paragraph): [synthesized from Luke's ICP + awareness-level work]
- Their language about the problem: [from Luke's Belief work]
- Pain hierarchy: [primary / secondary / tertiary]

For Alex's CES Idea axis (X):
- Strategic angle constraints: [what angles are ON-strategy vs OFF-strategy]
- Mechanism that must appear: [Luke's mechanism]
- Proof tiers available: [from proof ladder]

For Alex's CES Style axis (Y):
- Style constraints (brand-fit): [if any]
- Style permissions (brand can stretch into): [if any]

For Alex's CES Hook variants:
- Belief-installation moves needed in hooks: [from Luke's belief work]

For Alex's CES Vacation Test:
- "Different" must mean different ANGLE or different PROOF — surface differences don't satisfy strategic brief either
```

### PHASE 2 — ALEX MYATT DOWNSTREAM (CES + Production)

#### Step 2A — Run /myatt-ces with Luke's brief loaded

Execute the CES workflow with Luke's strategic brief as the constraining input:

- Avatar declaration uses Luke's ICP work
- IVOC mining is constrained to Luke's strategic angle (don't pull IVOC for OFF-strategy angles)
- Idea axis (X) is generated WITHIN Luke's mechanism + offer + angle space
- Style axis (Y) respects brand-fit constraints from Luke
- Content Grid is built (8-12 Ideas × 4-6 Styles)
- Hooks integrate Luke's belief-installation moves
- Vacation Test enforces both Andromeda diversity AND strategic-angle integrity

#### Step 2B — Strategic Audit on the Grid

Before production, audit grid against Luke's brief:

```
STRATEGIC ALIGNMENT AUDIT

For each top-10 concept:
- ON-strategy? [yes / no — references Luke's angle]
- Mechanism present? [yes / no — references Luke's mechanism]
- Belief-installation hooks integrated? [yes / no]
- Proof tier appropriate for awareness level? [yes / no]

If any "no": rebuild that concept BEFORE production.
```

#### Step 2C — Production SOPs (from CES)

Standard CES production layer applies:
- Brief template
- Asset library
- Turnaround SLAs
- Batch cadence
- Feedback loop

## Quality Gate

Apply BOTH expert rubrics:
- [ ] Luke's quality bar: strategic clarity, mechanism specificity, proof-tier appropriateness
- [ ] Alex's quality bar: diversity at fundamental layer, Andromeda compliance, IVOC provenance, hook layering, system decomposability

If output passes Alex's bar but fails Luke's: the ads are diverse but off-strategy. Rebuild.
If output passes Luke's bar but fails Alex's: the strategy is clean but the execution will fail Andromeda. Rebuild.

**Anti-pattern check**:
- [ ] Don't blur the phases (Alex doing Luke's work or vice versa)
- [ ] Don't skip the Strategic Alignment Audit (most common failure mode of stacked workflows)
- [ ] Don't let CES generate concepts that are diverse but off-angle (Andromeda passes, strategy fails)
