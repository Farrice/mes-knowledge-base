### Step 4 — The 5 Hook Types (Alex's framework)

Every hook must classify as ONE of these 5 (Luke's craft applies WITHIN each type):

1. **CURIOSITY GAP** — opens an information loop the reader needs to close
2. **PATTERN INTERRUPT** — breaks the visual / format / expected pattern
3. **DIRECT RELEVANCE CALL-OUT** — names the audience explicitly
4. **SOCIAL PROOF / AUTHORITY** — credentialed voice or 3rd-party validation
5. **STAKES / CONSEQUENCE** — names what's lost / risked

### Step 5 — The 8 Vicious Hook Principles (Luke's craft)

Every hook must satisfy AT LEAST 4 of these 8 (load full from Luke's skill):

1. **Specificity over generality** — "47 leads in 30 days" not "more leads"
2. **Stakes high enough to flinch** — physical, financial, social
3. **Verbatim audience language** — straight from IVOC
4. **Pattern interrupt at sentence level** — broken expectation in syntax
5. **Concrete sensory detail** — engages a specific sense
6. **Compressed phrasing** — every word earns its place
7. **The "wait, what?" gap** — reader has to keep going to make sense
8. **Implicit promise** — what they'll get if they keep reading/watching

### Step 6 — Generate the Hook Matrix

For each Idea×Style cell, generate 5 hooks (one per hook TYPE), each individually vicious.

```
HOOK MATRIX

IDEA 1 (your pillow is destroying your spine while you sleep) × STYLE 1 (Founder-to-camera):

  Type 1 — CURIOSITY GAP (vicious):
  "I'm a chiropractor. Here's the one thing destroying your spine that you're paying for every month."
  [Vicious principles satisfied: 1, 4, 7, 8 = 4/8 ✓]

  Type 2 — PATTERN INTERRUPT (vicious):
  "Your $200 pillow. Your $20 chiropractor bill. Wait until you see the receipts."
  [Principles: 1, 2, 4, 6 = 4/8 ✓]

  Type 3 — DIRECT RELEVANCE CALL-OUT (vicious):
  "If you wake up with neck pain three or more days a week and you're under 40 — this is for you."
  [Principles: 1, 3, 6 = 3/8 — REWRITE to satisfy 4]

  Type 4 — SOCIAL PROOF (vicious):
  "47,000 patients. One pillow. Three of them have an entirely different spine shape now."
  [Principles: 1, 5, 6, 7 = 4/8 ✓]

  Type 5 — STAKES (vicious):
  "Your spine compresses 1mm every year you sleep on the wrong pillow. By 50, you'll have lost an inch. There's no surgery that gets it back."
  [Principles: 1, 2, 5, 8 = 4/8 ✓]

(Repeat for each Idea×Style cell — focus on top 6-10 cells if matrix is huge)
```

### Step 7 — Vicious-Quality Filter Pass

Re-read every hook. For each:
- Does it satisfy 4+ of Luke's 8 principles? If no, rewrite.
- Would Alex's "Show Me Your Research" audit pass on it? (Is it grounded in IVOC, not invented?)

Reject anything that's vicious but invented — Alex's standard is harder than Luke's here.

### Step 8 — Diversity Filter Pass (Vacation Test on the bank)

Pull the top 30 hooks. Run Vacation Test on every consecutive pair:
- Pair 1→2: pass / fail
- ...

If 3+ fails: rebuild failing hooks at the FUNDAMENTAL layer (different Idea, different hook type — not surface tweaks).

## Content Type Adaptations

| Surface | Adaptation |
|---|---|
| **Meta video ads (default)** | Full matrix; hook = first 2-3 sec spoken/shown |
| **Meta static** | Hook = dominant visual + headline; some hook types translate (Curiosity gap → headline; Pattern interrupt → visual) |
| **TikTok** | Same matrix; hook is even more critical (1-2 sec window); favor Pattern Interrupt + Curiosity types |
| **LinkedIn posts** | Hook = first 2 lines (mobile truncation); Style = post format (carousel / text / story / contrarian) |
| **Email subject lines** | Style is the email body; hook = subject line; matrix shrinks to Idea × Hook-Type (skip Style axis) |
| **YouTube thumbnails + titles** | Title = hook; thumbnail = Style. Generate matrix for both. |
| **Cold outreach subject lines** | Add "Recipient-Specific Hook" type as 6th option (Hyperlocal Specificity from Alex) |
