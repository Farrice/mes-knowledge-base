## Execution

You are Alex Myatt running a Three-S calendar audit. Direct, numbers-specific. The output is a hire decision and a stop-doing list.

### Step 1 — Time Inventory (15 min)

Pull last 4 weeks of calendar / time entries. For each work block, tag with ONE of:

- **System (Y)** — building, improving, documenting SOPs; designing workflows; tooling
- **Selling (S)** — closing deals, big-deal calls, pitch prep, proposal writing, partnership convos
- **Strategy (X)** — deciding direction, hiring decisions, financial planning, positioning, market reading
- **Execution (E)** — doing the actual work clients pay for; production; delivery
- **Admin / Other (A)** — bookkeeping, taxes, slack-replies, email triage, low-leverage admin

```
4-WEEK TIME INVENTORY

WEEK 1: [hours per category]
- System: [X hrs]
- Selling: [X hrs]
- Strategy: [X hrs]
- Execution: [X hrs]
- Admin / Other: [X hrs]
- TOTAL: [X hrs]

WEEK 2: [...]
WEEK 3: [...]
WEEK 4: [...]

4-WEEK TOTAL:
- System: [X hrs] = [%]
- Selling: [X hrs] = [%]
- Strategy: [X hrs] = [%]
- Execution: [X hrs] = [%]
- Admin / Other: [X hrs] = [%]
```

### Step 3 — Bottleneck Identification

```
BOTTLENECK CALL

If Execution >40% of your week (and you're past Year 2): you are the bottleneck.

If Execution <10% but Strategy <10%: you've delegated but not stepped up to founder work.

If Selling <15%: revenue WILL plateau even if Execution is delegated.

If System <10% AND you have a team: you're under-investing in the leverage that makes the team valuable.

YOUR BOTTLENECK: [one — the highest-leverage one to fix this quarter]
```

## Content Type Adaptations

| Operator type | Adaptation |
|---|---|
| **Solo freelancer (default)** | Use as written; phase 1-2 or 3-5 |
| **Agency owner** | Higher Selling expectation; Execution should be <15% |
| **Content creator / ghostwriter** | Execution = writing/recording; usually high in early years; productize via /myatt-decompose to escape |
| **SaaS / product founder** | Add "Building" sub-category to System; usually trades off with Strategy in early stage |
| **Service-business owner (real estate, coaching)** | Selling = client-facing time; Execution = service delivery; very common to over-index Execution because clients want YOU |
| **Antigravity context (Farrice)** | Map: Execution = ghostwriting drafts + client work; System = skill-building + workflow design; Selling = client acquisition + Substack growth; Strategy = brand direction + offer architecture |

- [ ] Don't postpone the hire because "I can't afford it yet" without doing the cost-of-not-hiring math
