# Reference — The Creative Pyramid (CES Core Mental Model)

> Visual cheat sheet of Alex Myatt's Creative Engine System mental model. Use as the briefing template for any creative project.

---

## The Pyramid (top-down)

```
                    ┌──────────────┐
                    │    AVATAR    │  ← who is this test set FOR?
                    └──────┬───────┘
                           │
              ┌────────────┴────────────┐
              │   3 VARIABLES OF AD     │  ← per individual ad
              │      SUCCESS            │
              │                         │
              │  IDEA ─ STYLE ─ HOOK    │
              └────────────┬────────────┘
                           │
        ┌──────────────────┴──────────────────┐
        │           3 PILLARS                 │  ← account-level
        │                                     │
        │  VOLUME ── DIVERSITY ── RELEVANCE   │
        └─────────────────────────────────────┘
```

---

## Layer 1 — AVATAR (top)

**What it is**: The ideal customer for this specific test set. Not "the brand's avatar" (one canonical persona) — the test-specific avatar, which can change per Content Grid.

**Why it's at the top**: Every decision below this layer is downstream of who you're talking to. Same product, two avatars = two completely different Content Grids.

**Deployment**: Before any creative work, declare the Avatar in 1-3 sentences: their primary pain, their current state, the language they use about the problem (not the language the brand uses about the solution).

**Common mistake**: Defaulting to the brand's marketing-deck Avatar. Real avatars are narrower and more specific.

---

## Layer 2 — 3 VARIABLES OF AD SUCCESS (per individual ad)

These are the only three variables that fundamentally change an ad. Vary at this level = real diversity. Vary outside this level = surface diversity that fails Andromeda.

### IDEA
**What's being said.** The message the ad is making.

Examples (sore-neck pillow):
- "Headaches?" 
- "Cervical disc compression"
- "You've been lied to about what's causing your neck pain"
- "Your pillow is breaking your spine while you sleep"

Each is a fundamentally different IDEA. Same product, different angle of attack.

### STYLE
**How it's communicated.** The format, genre, narrative shape.

Examples:
- Founder-to-camera (talking-head)
- UGC (user-generated content style)
- Versus-format ("Pillow A vs Pillow B")
- Expose ("here's what they're not telling you")
- Doctor interview / expert testimonial
- Narrated case study
- Static image (clean product shot)
- Animated diagram / explainer
- "Day-in-the-life" lifestyle

### HOOK
**The first 2-3 seconds.** The thing that decides whether anyone watches the rest.

For video: literal opening seconds.
For static: the dominant visual element / headline.

5 hook types (from Alex's CES — applied across formats):
1. **Curiosity gap** — "Here's what's really happening when you sleep on your cervical disc..."
2. **Pattern interrupt / disruption** — visual shock, unexpected motion, breaking the format
3. **Direct relevance call-out** — "If you're 35+ and waking up with a sore neck..."
4. **Social proof / authority** — "I'm a doctor and here's what I tell every patient..."
5. **Stakes / consequence** — "What happens to your spine if you don't fix this..."

## Layer 3 — 3 PILLARS (account-level)

These operate at the AD ACCOUNT level, not per ad. Audit these monthly. Most accounts (80%) fail on Diversity.

### VOLUME
**Are we taking enough shots?**

Alex's frame: creative strategists are professional guessers. Would you rather guess once or 10 times?

Operational target: enough independent shots to find winners within a reasonable spend window. Specifics depend on budget, but the question to ask is "how many independent shots can this fund?" — not "how can we make this ONE ad work?"

### DIVERSITY
**Are the shots different enough?**

Different at the IDEA / STYLE / HOOK layer (Layer 2 of the pyramid) — NOT at the surface. Surface variation (color, copy tweak, image angle) does NOT escape Andromeda's Entity ID grouping.

Diagnostic: Vacation Test on every batch.

### RELEVANCE
**Are we talking about what the audience actually cares about?**

Sourced from IVOC (Indirect Voice of Customer) — Reddit forums, YouTube comments, Amazon reviews. Verbatim customer language only. Brand language = secondary.

## How To Use The Pyramid as a Briefing Template

For any creative project, fill in:

```
AVATAR: [1-3 sentences — who, what state, what language]

3 PILLARS — account-level audit:
  Volume: [target shot count for this test cycle]
  Diversity: [how will this batch escape Entity ID grouping?]
  Relevance: [3-5 IVOC quotes informing this batch]

3 VARIABLES — per ad in batch:
  Ad 1:
    Idea: [1 sentence]
    Style: [genre]
    Hook: [first 2-3 seconds + hook type from the 5]
  Ad 2:
    Idea:
    Style:
    Hook:
  ...

VACATION TEST PRE-CHECK:
  Would a viewer who saw Ad N recognize Ad N+1 as different or same?
  [yes/no per pair]
```

If any pyramid layer is empty or generic, the brief is not complete.

---

## Compounding the Pyramid Into a Content Grid

The pyramid is the single-ad mental model. The **Content Grid** is the batch-production tool:

- **X-axis**: 5-10 Ideas (from IVOC clusters)
- **Y-axis**: 4-6 Styles (from Style menu above)
- Each intersection = 1 ad concept
- Layer 3-5 hook variants per intersection

One pyramid + one grid = 25-300 distinct ad concepts from a single planning session.

## Common Confusions

- **"Idea vs Hook — what's the difference?"** Idea is the WHOLE message of the ad ("we're talking about cervical disc compression"). Hook is the FIRST 2-3 SECONDS ("here's what's happening to your spine right now while you read this"). Same Idea can have multiple Hooks. Different Idea = different ad.
- **"Why isn't 'offer' a variable?"** Offer matters but it's the same offer across most of a brand's ads. Idea/Style/Hook vary per ad; Offer is usually a constant that anchors the brand. If you ARE testing offers, treat each offer as its own grid.
- **"Why isn't 'avatar' a variable per ad?"** Because changing Avatar changes the WHOLE pyramid. Multiple avatars = multiple grids, not multiple ads in one grid.
