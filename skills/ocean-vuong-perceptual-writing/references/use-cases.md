# Ocean Vuong — Use Cases & Workflow Routing

> Specific deployment scenarios mapped to the exact workflow that handles them. Use this to route a real task to the right Vuong workflow in one step. Workflow paths are relative to the skill root (`skills/ocean-vuong-perceptual-writing/`).
>
> **Before routing, confirm the expert fits** (genius.md § Decision Framework): is *haunting* more valuable than *hooking* here? Does the writing need to feel genuinely new? Is there time for perception (80/20)? If speed is the only constraint or the content is purely transactional (product specs, how-to steps), pick a faster system.

## Deployment Recipes (multi-workflow chains)

These are the proven sequences when a single workflow isn't enough.

**1. Premium content, zero-to-ship**
`perceptual-content-engine` (build on perception) → `species-test-protocol` (kill Google-returnable lines) → `haunting-residue-audit` (confirm two-week residue).
*Use for:* flagship newsletters, brand essays, premium Substack editions.

**2. Sales page that haunts**
`haunted-copy` (recursive loops, re-seen problem) → `estrangement-engine` (any obvious mechanism metaphor) → `species-test-protocol` (median-sentence purge).
*Use for:* VSLs, landing pages, email sequences. **Honesty spine non-negotiable** — estrange only true claims; route missing proof back to the copywriter/researcher.

**3. Ghostwriting a distinctive voice**
`recognition-workshop` (name the client's tendencies across passes) → `haunted-narrative` or `haunted-social` (amplify the strangeness in the right format) → `anti-homogenization-audit` (confirm it couldn't be anyone).
*Use for:* founder ghostwriting, executive thought leadership.

**4. Rescuing an overdone subject**
`cliche-rescue-protocol` (displace the context) → `poietic-threshold-writer` (if it's a transformation) → `haunting-residue-audit`.
*Use for:* "I have to write about X again and it's been done to death."

**5. Brand voice de-homogenization**
`anti-homogenization-audit` (diagnose the category-voice) → `cliche-rescue-protocol` (recover flattened category words) → `recognition-workshop` (lock the thumbprint so future writers stay on-voice).
*Use for:* positioning resets, brand voice guidelines.

## When NOT to Deploy (route elsewhere)

| Situation | Use instead |
|---|---|
| 30-minute deadline, speed is the only constraint | A faster production engine (Vuong's 80/20 perception split needs observation time) |
| Transactional content — product descriptions, how-to steps, spec sheets | Clarity-optimized writing; estrangement adds noise here |
| Pure attention-capture need (ad headline that must stop the scroll in 1 second) | Hook-specialist (Diandra hooks à la carte; Vuong is anti-hook by design) |
| Audience reads only synchronically (won't reward linguistic novelty) | A trend/algorithm-fit system |
| A claim is missing and a beautiful sentence is being asked to cover for it | Route to the copywriter/researcher — never let syntax manufacture a fact |

> **Routing default:** if the ask is "make it unforgettable / make it feel new / make it not sound like everyone else," start with the matching generation workflow above, then close with at least one audit (`species-test-protocol` for originality, `haunting-residue-audit` for persistence). If the ask is "judge / fix what exists," start with the audit. Either way, perception before syntax — name what you noticed before you reach for the lush line.
