# Anti-Homogenization Audit

Deploy Vuong's diagnosis of the invisible homogenization that makes contemporary writing "publishable but forgettable." This is the diachronic survival audit — testing whether writing would hold up against the full history of literature, not just this season's publications.

> **🔒 Pre-Flight Gate**: This workflow fires on any piece that feels "fine," "competent," "publishable," or "good" — but lacks the quality of *distinctiveness* that makes writing survive diachronically.

## Execution

### Phase 1: The Familiarity Test

Read the piece cold — as if encountering it for the first time. Answer honestly:

| Question | Y/N | Severity |
|----------|-----|----------|
| "I feel like I've read this before" | | 🔴 Critical |
| "This could have been written by any competent writer" | | 🔴 Critical |
| "The style reminds me of the last 5 things I read on this subject" | | 🟡 Warning |
| "I can predict the next sentence before reading it" | | 🟡 Warning |
| "The opening uses a pattern I've seen on LinkedIn/Medium this week" | | 🟡 Warning |
| "No single sentence made me stop and re-read" | | 🔴 Critical |
| "I could summarize this piece without quoting a single line" | | 🔴 Critical |

**Scoring**: 
- 0 Y answers: Piece may be distinctive. Proceed to Phase 2 for verification
- 1-2 Y answers: Partial homogenization. Targeted estrangement needed
- 3+ Y answers: Full homogenization. Major revision required
- Any Critical Y: Stop. Revision required before publication

### Phase 2: The Newspaper Sentence Scan

Identify every sentence operating as a "newspaper sentence" — the invisible, butler-style prose where the author's presence is completely erased:

Markers of the newspaper sentence:
- Subject-verb-object with no syntactic deviation
- Adjectives are expected ("beautiful sunset," "innovative solution," "passionate about")
- Verbs are generic ("is," "was," "has," "makes," "helps")
- No etymological depth — words used at dictionary-shallow definitions
- Could be produced by Grammarly or Microsoft Word's writing suggestions
- Passive construction that removes the writer's agency

**Mark each newspaper sentence with [NS]**. Calculate the ratio: newspaper sentences ÷ total sentences. If > 60%, the piece has been homogenized.

### Phase 3: The Diachronic Comparison

Select a canonical writer in a similar mode and read 500 words of their work. Then immediately re-read the piece under audit.

**Selection guide**:
| Writing Mode | Compare Against |
|-------------|----------------|
| Personal essay/reflection | Baldwin, Dillard, Didion |
| Narrative/storytelling | Morrison, McCarthy, Pynchon |
| Analytical/critical | Sontag, Berger, hooks |
| Lyric/poetic prose | Carson, Rankine, Maggie Nelson |
| Humor/voice-forward | Sedaris, Lebowitz, Nora Ephron |

After reading both:
- Does the audited piece feel like it has its own *territory*?
- Or does it feel like a diluted version of the canonical comparison?
- What does the canonical writer do with syntax that the audited piece doesn't?
- Where does the canonical writer's *consciousness* appear in the sentences?

### Phase 4: Estrangement Prescriptions

For each identified problem, prescribe specific fixes:

| Problem | Prescription |
|---------|-------------|
| Newspaper sentences > 60% | Run the Estrangement Engine on the 5 most important sentences. Push verbs toward behavioral specificity |
| No sentence stops the reader | Identify the piece's central perception and deploy the Species Test. If the core insight has 300K+ Google results, the perception itself is homogenized |
| Style indistinguishable | Deploy the Recognition Workshop on the writer's corpus. Find the thumbprint. Then rewrite toward the thumbprint, not away from it |
| Predictable structure | Apply strategic denial (satisfy/deny) at 2-3 key moments. Break the pattern the reader has predicted |
| Dictionary-shallow language | For the 5 most important words, access OED etymology. Let the etymological depth inform word choice |
| No poietic moments | Identify 2-3 moments of transformation or process in the piece. Apply the Poietic Threshold Writer to capture the unnamed states between |

### Phase 5: Verdict

| Verdict | Criteria | Next Step |
|---------|----------|-----------|
| **DISTINCTIVE** | < 2 Y in Familiarity Test, < 30% newspaper sentences, holds diachronic comparison | Ready for publication |
| **SALVAGEABLE** | 2-3 Y in Familiarity Test, 30-60% newspaper sentences | Apply 3-5 targeted prescriptions and re-audit |
| **HOMOGENIZED** | 4+ Y in Familiarity Test, 60%+ newspaper sentences, fails diachronic comparison | Major revision required — return to perception work. The issue isn't the writing, it's the seeing |
| **NEWSPAPER** | Every sentence could have been produced by AI/Grammarly — no writer consciousness detectable | Start over from the Medicinal Plant Method. Find what surprises you |

## Output Requirements

**Deliver**:
1. Familiarity Test results (table with scores)
2. Newspaper sentence ratio (with 3 worst examples quoted)
3. Diachronic comparison notes (which canonical writer, what was learned)
4. Estrangement prescriptions (specific to this piece's problems)
5. Final verdict with action items

---

## Quality Gate

> **🛡️ Anti-Pattern Check**: This audit must be ruthless but not nihilistic. Not every piece needs to be literature — some content is functional and that's acceptable. The audit detects homogenization, not ordinariness. The question isn't "Is this great literature?" but "Has the writer's consciousness been erased from the prose?"
