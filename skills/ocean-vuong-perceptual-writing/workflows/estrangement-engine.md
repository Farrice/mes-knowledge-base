# Estrangement Engine

Deploy Ocean Vuong's core technique: estrangement through behavioral displacement. Transform familiar descriptions into genuinely novel perceptions.

> **🔒 Pre-Flight Gate**: Before executing, run the **Decision Framework** in `genius.md` § Decision Framework. Confirm the piece needs perceptual novelty.

Load the following in order:

1. **Genius Context**: `skills/ocean-vuong-perceptual-writing/genius.md` — operating principles + voice DNA

## Execution

### Phase 1: Identify the Mimetic Sentences

Read through the draft (or brainstorm the subject). Flag every sentence operating in pure mimesis — naming what already has a name:
- Common metaphors ("heart of gold," "sharp as a knife")
- Expected descriptions ("the sun set beautifully," "she walked into the room")
- Image-correspondence similes ("the lake was like glass")
- Taxonomic language (words used at dictionary-shallow definitions)

Mark these with [M] in the margin.

### Phase 2: Select Displacement Targets

Not every mimetic sentence needs estrangement — some scaffolding is necessary ("he walked into the room and sat down" sometimes just needs to happen). Select the **3-5 most important perceptual moments** in the piece — the images, metaphors, or descriptions that carry the weight of meaning.

For each target, answer:
1. **What behavior does this subject exhibit?** (Not appearance — behavior. How does it move, grow, change, decay, arrive, depart?)
2. **What radically different domain exhibits the same behavior?** (Not visual resemblance — behavioral correspondence)
3. **Does the displacement retroactively change how both elements are perceived?** (If only the tenor shifts, push further)

### Phase 3: Build Behavioral Correspondences

For each target sentence:

| Original (Mimetic) | Behavior Identified | Displaced Domain | New Sentence (Estranged) |
|--------------------|--------------------|-----------------|-----------------------|
| "Moss grew on the tree" | Nebulous, quick-spreading, patchy | Applause | "Moss grew along the tree like applause" |
| "The sun set" | Rolling descent, severed finality, speed | Beheading | "The low red sun rolls across the hills as if beheaded" |
| "A rose in a bride's hair" | Familiar beauty in expected context | Boxing | "A rose in Mike Tyson's ear" |

**The behavioral correspondence test**: Does the displacement change the *rate*, *quality*, or *character* of the subject's behavior? If it only adds visual decoration, it's still image correspondence.

### Phase 4: Run the Species Test

For each estranged sentence:
1. Google the exact phrasing (or close variants)
2. If **300,000+ results** appear → the species already has it. Push further
3. If **<100 results** or nothing → you may have created something genuinely new
4. If in between → examine whether the novelty is real or just unusual word choice

### Phase 5: Reintegration

Replace the mimetic targets with their estranged versions. Read the full piece aloud. Verify:
- [ ] The estranged sentences don't feel forced or "trying to be literary"
- [ ] The behavioral correspondences genuinely alter perception of the subject
- [ ] Mimetic scaffolding sentences remain where needed for pacing and clarity
- [ ] At least one sentence passes the Species Test — genuinely new to human language
- [ ] The displacement retroactively changes how both tenor and vehicle are perceived

## Output Requirements

**Deliver**:
1. The mimetic/estranged comparison table (Phase 3)
2. Species Test results for top 3 sentences
3. The rewritten piece with estrangement integrated
4. One alternate displacement per key image (different behavioral domain)

**Quality Standard**: A reader encountering the estranged sentences should re-see the familiar subject as if for the first time. If recognition occurs instead of perception, the estrangement isn't deep enough.
