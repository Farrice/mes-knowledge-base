# Haunting Residue Audit

The final layer of quality control. The Species Test checks originality. The Anti-Homogenization Audit checks distinctiveness. This checks the third dimension: **persistence**. A piece can be original and distinctive but still not haunt — because it doesn't leave the specific kind of sensory/behavioral residue that creates permanent habitation in the reader's mind.

> **🔒 Pre-Flight Gate**: Run this AFTER the piece is "done." This is not a revision tool — it's a diagnostic. The piece should already be through content editing, Species Testing, and any other quality gates. This is the final pass: does it haunt?

## Execution

### Phase 1: The Cold Read

Read the piece ONCE, cold — as a reader, not an editor. After reading, without returning to the text:

1. **Close your eyes. What image from the piece appears?** Write it down. If no image appears — the piece has a residue problem.
2. **What sentence echoes?** Write down any exact phrasing you remember. If nothing comes back verbatim — the thumbprint is missing.
3. **What feeling persists?** Name the specific emotional/intellectual residue. If you can name it with a single common word ("inspired," "motivated") — the feeling is too generic to haunt.
4. **What did the piece make you re-see?** If you can't name one thing you now perceive differently — the piece didn't haunt.

### Phase 2: The Haunting Dimensions Scorecard

Score each dimension 1-10:

| Dimension | 1-3 (Forgettable) | 4-6 (Noticeable) | 7-9 (Memorable) | 10 (Haunting) | Score |
|-----------|-------------------|-------------------|-----------------|---------------|-------|
| **Image Residue** | No image persists after reading | A vague visual atmosphere lingers | A specific image sticks | The image appears involuntarily when encountering the subject | |
| **Sentence Residue** | No sentence recalled verbatim | General phrasing remembered | A specific sentence echoes | The sentence has become the reader's internal language for the subject | |
| **Perception Shift** | Reader sees subject exactly as before | Reader has a vague new feeling about subject | Reader has a specific new angle | Reader cannot UN-see the new perception — it has permanently altered how they encounter the subject | |
| **Thumbprint** | Could be any writer | Style is pleasant but interchangeable | Writer's voice is recognizable | Sentences could be identified in a blind test by syntax alone | |
| **Structural Surprise** | Every moment predicted | Most moments predicted, one surprise | Key moments denied expectation | The piece is ABOUT something different than the reader predicted — and the actual subject is more true | |
| **Diachronic Survival** | Feels like this season's content | Feels like a strong current writer | Feels like it belongs with the best on this subject | Feels like it adds something to the literature that wasn't there before | |

**Scoring**:
- **48-60: HAUNTING** — Ship it. This piece will persist.
- **36-47: MEMORABLE** — Strong but check which dimension drags. Targeted fix may push it to haunting.
- **24-35: NOTICEABLE** — Competent but forgettable. 2-3 dimensions need significant work.
- **6-23: FORGETTABLE** — Fundamental perception work needed. Return to the Haunting Engine or Perceptual Content Engine.

### Phase 3: Residue Diagnostics

For any dimension scoring ≤ 5, diagnose the specific failure:

| Low-Scoring Dimension | Likely Cause | Prescription |
|----------------------|-------------|-------------|
| **Image Residue ≤ 5** | Images are decorative (visual resemblance) rather than behavioral (behavioral correspondence) | Run the Estrangement Engine on the 3 key images. Push from image correspondence to behavioral displacement |
| **Sentence Residue ≤ 5** | Newspaper syntax — invisible prose with erased authorial presence | Deploy the thumbprint: identify the writer's unique syntactic patterns and rewrite the 3 most important sentences in that syntax |
| **Perception Shift ≤ 5** | The piece delivers information, not perception. The reader learns something but doesn't RE-SEE anything | Return to Phase 1 of the Perceptual Content Engine: "What have I perceived about this subject that I haven't seen anyone articulate?" |
| **Thumbprint ≤ 5** | Writer is imitating a style or following convention rather than writing from their own consciousness | Run the Recognition Workshop to identify and name the writer's actual tendencies, then rewrite toward those tendencies |
| **Structural Surprise ≤ 5** | Piece delivers exactly what it promises — no denial, no pivot, no discovery | Apply strategic denial at 1-2 key moments. Build expectation, then deny it with something more true |
| **Diachronic Survival ≤ 5** | Piece is well-crafted but lives entirely within current conventions | Read 500 words of a canonical writer in a similar mode. Identify what they do that this piece doesn't. Often the issue is DARING — the refusal to be "too much" |

### Phase 4: The Persistence Projection

Based on the scorecard, project the piece's persistence timeline:

| Score Range | Persistence Projection |
|-------------|----------------------|
| 48-60 | **Years** — reader thinks about this regularly, quotes it in conversation, returns to re-read |
| 36-47 | **Weeks** — reader remembers reading it, may recall the main idea, unlikely to quote specific lines |
| 24-35 | **Hours** — reader enjoyed it while reading, forgotten by the next day |
| 6-23 | **Minutes** — reader finishes, scrolls to next piece, no residue |

### Phase 5: Fix Priority

If the piece needs revision, prioritize fixes in this order:
1. **Perception Shift** — if the piece doesn't re-see, nothing else matters
2. **Image Residue** — the specific detail that embeds
3. **Sentence Residue** — the thumbprint line
4. **Structural Surprise** — the denied expectation
5. **Diachronic Survival** — the canonical company test
6. **Thumbprint** — syntactic identity

**Fix a maximum of 3 dimensions per revision pass.** Trying to fix everything simultaneously dilutes all fixes.

## Output Requirements

**Deliver**:
1. Cold Read results (Phase 1 — what persisted after one reading)
2. Haunting Dimensions Scorecard (Phase 2 — all 6 dimensions scored)
3. Residue Diagnostics (Phase 3 — specific diagnoses for low-scoring dimensions)
4. Persistence Projection (Phase 4 — how long the piece will persist)
5. Fix Priority list (Phase 5 — ordered prescriptions if revision needed)
6. Final Verdict: **HAUNTING** / **MEMORABLE** / **NOTICEABLE** / **FORGETTABLE**

## Quality Gate

> **🛡️ Anti-Pattern Check**: This audit must distinguish between three different things that feel similar:
> - **Haunting** (permanent perception shift) — the target
> - **Impressive** (readers admire the craft) — not the same. Impressive writing gets compliments; haunting writing gets remembered.
> - **Moving** (readers feel emotion in the moment) — not the same. Moving writing creates a feeling that dissipates; haunting writing creates a perception that persists.
> The question is never "did this make the reader feel something?" It's "will the reader still feel it — and see differently because of it — three weeks from now?"
