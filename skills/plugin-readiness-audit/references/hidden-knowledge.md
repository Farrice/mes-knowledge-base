# Plugin Readiness — Antigravity-Specific Knowledge

## Command bridge

A command is discoverable across the current workspace when its canonical workflow, Codex/Claude command shim, source-command compatibility skill, and menu/index surfaces agree.

## Plugin bridge

A repository plugin additionally needs a valid plugin manifest, bundled skill paths, installation or marketplace discovery, and fresh-thread path resolution.

## Proof boundary

Local scorecards measure packaging readiness. They do not prove adoption, portability on another machine, marketplace safety, or improved outcomes.

## Current operating fact

Google Antigravity is Farrice's primary harness. Internal workflows do not need plugin packaging merely to work here. Plugin packaging earns its cost when a stable bundle must travel, install cleanly, or work outside repository-local context.
