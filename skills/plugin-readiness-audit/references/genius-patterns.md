# Plugin Readiness Patterns

- **Package the stable loop:** trigger, source loading, tool use, checks, output, and stop condition must already repeat.
- **Skill before plugin:** stabilize the method before distributing it.
- **Distribution is not intelligence:** plugins install; skills and workflows think and execute.
- **Large library does not equal context bloat:** inspect what loads, not only what exists.
- **Cleanup before packaging:** prefer metadata and routing improvements when they solve the same problem.
