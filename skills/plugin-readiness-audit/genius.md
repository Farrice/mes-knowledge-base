# Plugin Readiness Audit — Operating Intelligence

## Core patterns

### Package the stable loop

Google Antigravity's Workflow Packaging Ladder says, "Package proven workflows, not vague intent." A candidate needs a trigger, source-loading policy, tool use, checks, output contract, and stop condition. [Source: `semantic_libraries/antigravity/primitives/workflow-packaging-ladder.md`, retrieved 2026-08-13]

### Skill before plugin

The archived Plugin Readiness Audit states, "If Codex cannot follow the method as a skill or workflow, a plugin will only distribute the confusion." [Source: `_active/harness/codex-harvest-2026-06-11/skills/plugin-readiness-audit/references/genius-patterns.md`, retrieved 2026-08-13]

### Distribution is not intelligence

The archived method is explicit: "The skill or workflow carries the method. The plugin makes it installable and easier to share." [Source: archived Plugin Readiness Audit, retrieved 2026-08-13]

### On-disk inventory is not prompt bloat

The 2026-08-13 System Efficiency Benchmark counted 2,761 workflows and recommended 2,702 remain cold. It also says, "Archive nothing from this report alone." Measure prompt-time exposure and routing evidence before pruning.

### One new failure mode at a time

The archived method sequences five proofs: workflow, plugin manifest, marketplace entry, fresh-thread trigger, then MCP/apps/hooks/assets. [Source: archived Plugin Readiness Audit, retrieved 2026-08-13]

## Quality rubric

1. Existing-route fit was checked before proposing a package.
2. The package solves reconstruction, portability, installation, or permission friction.
3. The smallest coherent bundle is named.
4. Hidden repo dependencies are explicit.
5. Direct and natural-language invocation tests are defined.
6. Structural readiness is not presented as adoption or market proof.
7. The audit can return **KEEP AS IS** without treating that as failure.

## Anti-patterns

- **Packaging because the asset is important.** The Workflow Packaging Ladder requires repetition and reconstruction evidence. [Source: Workflow Packaging Ladder, 2026-08-13]
- **Converting every slash command into a skill.** Commands can remain launchers for workflows and utilities. [Source: Skill System Contract, 2026-08-08]
- **Creating a mega-plugin for the whole repository.** The benchmark says, "Do not package the whole Antigravity system in this pass." [Source: System Efficiency Benchmark, 2026-08-13]
- **Using plugins to compensate for weak routing metadata.** Cleanup projects to 9.3/10 before plugin work. [Source: System Efficiency Benchmark, 2026-08-13]
- **Calling a plugin ready before fresh-thread and path-resolution tests.** Both are acceptance tests in the Workflow Packaging Ladder. [Source: Workflow Packaging Ladder, 2026-08-13]
- **Archiving cold workflows without usage evidence.** The benchmark explicitly blocks archive decisions from this report alone. [Source: System Efficiency Benchmark, 2026-08-13]
