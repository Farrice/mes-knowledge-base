# Plugin Readiness Audit

Decide whether packaging solves a proven reconstruction or portability problem. A plugin distributes stable behavior; it does not create the behavior.

## Decision Policy

- **80–100:** candidate for packaging, pending fresh-thread and path tests.
- **65–79:** improve the workflow/skill layer first.
- **45–64:** keep as workflow or skill.
- **0–44:** keep as prompt, reference, or archive candidate.
- Router/metadata cleanup wins when it produces the same result with less machinery.
- Broad packaging remains blocked without routing feedback and cold-start evidence.
