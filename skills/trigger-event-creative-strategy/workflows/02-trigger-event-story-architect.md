# Trigger-Event Story Architect

## Input

A provenance-backed event, brand/product truth, mechanism evidence, proof assets, format constraints, and claim boundaries.

## Workflow

1. Lock the verbatim event and its evidence boundary.
2. Map trigger → aggravation → discovery/recommendation → differentiated mechanism → payoff.
3. Remove any transition the evidence cannot support or label it as dramatization requiring approval.
4. Write the production-ready narrative, visual beats, proof placement, and CTA.
5. State the single learning question and the evidence still missing.

Execution prompt: `references/prompts-v2/trigger-event-narrative-brief.md` — honor its Output Contract.

## Quality Gate

- The event, not a generic benefit, opens the narrative.
- The mechanism and payoff are substantiated.
- A creator can execute the brief without inventing biography.
- The test question is singular.
