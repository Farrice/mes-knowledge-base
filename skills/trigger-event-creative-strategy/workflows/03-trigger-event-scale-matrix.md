# Trigger-Event Scale Matrix

## Input

A verified message or winning creative, available trigger-event bank, credible characters, formats, production capacity, and baseline performance.

## Workflow

1. Name the invariant message and proof state.
2. Generate trigger variants while holding character and format constant.
3. Generate character variants while holding trigger and format constant.
4. Translate the strongest message into formats while preserving its narrative hinge.
5. Prioritize cells by evidence strength, expected learning, and production effort.
6. Define control, baseline, window, and outcome capture for each live test.

Execution prompt: `references/prompts-v2/trigger-event-scale-matrix.md` — honor its Output Contract.

## Quality Gate

- Each comparison changes one variable.
- All triggers retain provenance.
- Format adaptation preserves the message.
- No cell is called a winner before a result exists.
