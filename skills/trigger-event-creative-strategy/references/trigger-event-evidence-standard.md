# Trigger-Event Evidence Standard

## Candidate Test

A usable candidate answers all four:

1. What concrete event occurred?
2. What existing problem did it make intolerable?
3. What changed immediately afterward: attention, search, conversation, purchase, or action?
4. Where is the exact evidence?

If #3 is inferred, label it `UNCONFIRMED`. If #4 is missing, the event cannot be presented as customer truth.

## Evidence Hierarchy

1. Direct customer quote with stable provenance
2. Interview or survey response with timestamp/respondent reference
3. Ad comment or review with URL/export row
4. Repeated category evidence, labeled category-level
5. Strategist inference, labeled `UNCONFIRMED`

## Claim Boundary

Never convert an observed event into an unsupported product outcome. “She refused the bowl” can support the moment. It does not prove why the product worked, that every dog behaves similarly, or that the ad will perform.
