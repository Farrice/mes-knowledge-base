# Trigger-Event Creative Strategy — Genius Context

## The Judgment

The strategist's hard job is not generating dramatic stories. It is distinguishing a true decision moment from language that merely sounds emotional, then preserving the physics of that moment as the message moves across formats.

## Genius Patterns

### 1. The Intolerance Transition

A trigger event contains before, disruption, and decision pressure. Ask: **what happened, when did it happen, and what could the person no longer continue tolerating?** “Wants healthier skin” is a benefit. “At 2:00 a.m. I woke to my dog chewing his paws raw” is an event.

### 2. Evidence Before Drama

Mine the longest and most emotional reviews, ad comments, post-purchase surveys, interviews, and relevant category conversations. Preserve exact words. The more cinematic the proposed event, the stronger its provenance must be. Never improve a quote by making it cleaner than the customer.

### 3. The Narrative Hinge

The event starts the story because it collapses indifference. The portable sequence is:

`trigger event -> lived aggravation -> discovery/recommendation -> differentiated mechanism -> payoff/social validation`

The sequence is elastic. Preserve the decision hinge; do not force five sections when the evidence only supports three.

### 4. Message Before Format

When a message works, translate it rather than restart ideation. Scale three controlled dimensions:

1. **Trigger:** a different intolerable moment;
2. **Character:** a different credible person experiencing or observing it;
3. **Format:** native video, creator delivery, AI animation, static, founder story, or interview.

Changing all three at once creates volume without learning.

### 5. The Proof Ladder

Ad-library presence, impressions, spend, CTR, CPA, and ROAS answer different questions. A high-spend ad is a prioritization signal, not proof of why it won. A single result remains descriptive unless a baseline or controlled comparison exists.

### 6. Governed Compounding

Creative memory compounds only when the record includes the hypothesis, artifact, actual result, scope, and review status. Human taste may become a project preference. Cross-project doctrine requires repeated independent evidence and explicit approval.

## Anti-Patterns

- Turning a pain point into a fabricated first-person anecdote.
- Treating any sentence containing “when” as a trigger event.
- Using the customer's quote without a traceable source.
- Calling impressions, spend, or an expert demonstration conversion proof.
- Swapping trigger, character, and format in the same test cell.
- Writing one campaign result directly into `SKILL.md`, `genius.md`, or an agent memory file.

## Recognition Test

The output should make the triggering moment visible enough to storyboard, the evidence visible enough to audit, and the test variable narrow enough to learn from. If it is simply a list of emotional hooks, the method was not applied.
