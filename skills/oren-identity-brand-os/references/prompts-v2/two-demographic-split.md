## Role & Activation

You are running Oren John's Two-Demographic Split. "Guys do things to impress guys, girls do things to impress girls" [05:33] — algorithms now drive engagement toward same-gender performance, so the two demographics occupy less-overlapping worlds than before. "You can't hit them with the same advertisement even if you sell to a wide base" [06:26]. This prompt forces a brand with meaningful volume in both demographics to build two real creative strategies, not one unisex compromise.

## Input Required

- [BASE SPLIT]: current gender/demographic breakdown of the real buyer base
- [EXISTING CREATIVE]: current assets, sorted by which demo they were built for, if known
- [PLATFORM MIX]: channels in use (algorithm behavior varies by platform)

## Execution Protocol

**Step 1 — Confirm the Base Split.** Use [BASE SPLIT] as ground truth, not assumption. Note whether roughly even or skewed — a skewed split still needs a secondary strategy if the secondary demo represents real revenue.

**Step 2 — Diagnose the Performative Pattern [05:33].** For each demo, name what "performing for the same gender" looks like in this category. Reference the calibration case: men over-lifting toward a body type that "isn't actually appealing to the opposite sex" [06:26] — a same-gender performance signal that doesn't map to real cross-gender desire. Find the category-specific equivalent for each demo.

**Step 3 — Select a Primary Identity Driver Per Demo.** Using the Five Identity Drivers, pick a primary driver for each demographic independently. Do not assume the same driver transfers across; state explicitly if they differ.

**Step 4 — Build Two Full Creative Strategies.** Produce two genuinely separate strategy briefs — different hooks, different visual language, potentially different platforms within [PLATFORM MIX]. Name explicitly what changes between them, not just that they're "tailored."

**Step 5 — Build the Per-Demo Checklist.** For each demo, produce a 3-5 item checklist any new creative asset must pass: driver alignment, performative-pattern accuracy, visual/tonal fit.

## Output Contract

- Confirmed base-split data stated plainly
- Per-demo performative-pattern diagnosis (specific to this category, not generic)
- Per-demo primary Identity Driver, independently selected
- Two distinct creative strategy briefs
- Per-demo checklist (3-5 items each)

## Quality Gate

- Were two genuinely distinct strategies produced, not one strategy with cosmetic swaps?
- Was the performative pattern diagnosed specifically for this category, not assumed generically?
- Did each demo get its own independently-selected primary driver?
- Is the secondary demo's strategy treated as real, not a footnote?

## Creative Latitude

Within each demo's strategy brief, push for the sharpest category-specific read of the performative pattern — the calibration example (over-lifting) is a template for the KIND of insight required, not something to reuse verbatim across categories.

## Deploy When

Any brand with meaningful volume in both gender demographics planning creative strategy, especially when a "wide base" brief is about to default to one unisex approach.
