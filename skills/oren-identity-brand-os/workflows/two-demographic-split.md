# Two-Demographic Split

"Guys do things to impress guys, girls do things to impress girls" [05:33]. Algorithms now drive engagement toward same-gender performance, which means the two demographics occupy less-overlapping worlds than they used to — and "you can't hit them with the same advertisement even if you sell to a wide base" [06:26]. This workflow forces a brand serving both demographics to build two real creative strategies instead of one unisex compromise.

## Pre-Flight Gate

> **🔒 Pre-Flight Gate**: cite genius.md **Pattern 12 — The Two-Demographic Split**. This workflow applies whenever a brand's base includes both genders in meaningful volume, even if one is currently dominant. Do not skip it because "our audience is 70% one gender" — a wide base with a secondary demographic still needs its own strategy, not a footnote inside the primary one.

## Input Required

- Current gender/demographic split of the actual buyer base (from `persona-reality-audit` if available)
- Existing creative assets, sorted by which demo they were built for (if any)
- Platform/channel mix (algorithm behavior varies by platform)

## Execution Steps

**Step 1 — Confirm the Base Split.** Pull the real demographic breakdown of the buyer base, not an assumption. Note whether the split is roughly even or skewed — skewed still requires a secondary strategy if the secondary demo represents real revenue.

**Step 2 — Diagnose the Performative Pattern [05:33].** For each demo, identify what "performing for the same gender" looks like in this category. Reference Oren's viral example: men over-lifting toward a body type that "isn't actually appealing to the opposite sex" [06:26] — a same-gender performance signal that doesn't map to real cross-gender desire. Name the equivalent pattern in this brand's category for each demo.

**Step 3 — Select a Driver Per Demo.** Using Pattern 6 (Five Identity Drivers), pick a primary driver for each demographic separately — they will often differ. A brand's belonging play for one demo may need to be a rebel or standout play for the other; do not assume the same driver transfers across.

**Step 4 — Build Two Full Creative Strategies.** Not two ad variants of the same concept — two genuinely separate strategies: different hooks, different visual language, potentially different platforms or placements. State explicitly what changes between the two, not just that they're "tailored."

**Step 5 — Build the Per-Demo Checklist.** For each demo, produce a short checklist the creative team can run any new asset against: driver alignment, performative-pattern accuracy (does this reflect what they actually want, not what they perform for their own gender), and visual/tonal fit.

## Content Type Adaptations

| Format | Adaptation |
|---|---|
| Paid social ads | Fully separate creative sets and possibly separate campaigns per demo |
| Organic content calendar | Alternate content pillars or interleave demo-specific series rather than blending into one feed |
| Email marketing | Segment lists by demo where data allows; separate subject-line and imagery strategy |
| Retail / packaging | If SKUs differ by demo, apply the driver selection to packaging language and imagery separately |

## Output Requirements

- Per-demo performative-pattern diagnosis
- Per-demo primary Identity Driver selection
- Two distinct creative strategy briefs (not one brief with a note "adjust for gender")
- Per-demo creative checklist (3-5 items each)
