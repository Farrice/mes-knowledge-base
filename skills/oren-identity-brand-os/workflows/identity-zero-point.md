# /identity-zero-point — Zero-Point Identity Excavation

Answer "who am I as a public identity" before any archetype, content format, or platform choice. This is the net-new gap the wider Oren arsenal doesn't cover — `oren-brand-archetypes` presupposes this question is already answered.

## Pre-Flight Gate (genius.md decision framework)

- Has an archetype or content system already been chosen? If yes, run this anyway as a retroactive audit and flag the sequencing violation explicitly — do not silently validate a downstream choice built on an unexcavated identity.
- Is there enough raw material to excavate (a real person with a real origin), or is this a faceless product brand with no visible founder? If the latter, the weak-point pass in Step 4 may not apply — route product-only brands toward `Signature-Design Recognizability Ladder` work instead (Tier 2, this skill) once published.

Pull directly rather than re-excavating — but the weak-point pass (Step 4) still requires checking §3's PRIVATE marker before anything ships public.

## Execution

1. **Origin excavation.** Birthplace, formative displacement, family trade or background, what shaped the founder before the business existed. Apply the mechanism at [09:30]: "you can make a unique brand off any of those angles" — a NW-vs-SW outdoors brand, an Americana-vs-British-vs-Chinese racing company. Ask for specifics, reject abstractions ("I'm passionate about health" is not an origin).

2. **Place excavation.** The geography and scene the founder physically inhabits now — not an aspirational city, the actual one. Place is a legitimate identity seed on its own per the same [09:30] mechanism.

3. **Subculture / obsession excavation.** What the founder can't stop consuming, doing, or talking about outside the work. This is the raw material for **Subculture-pride** later — the "if you know, you know" register [14:03]. List it verbatim, don't paraphrase it into something more palatable.

4. **Weak-point honesty pass.** Apply **Identity Beyond Affiliation** [14:31]: "if people have a weak point in their internal identity, how can you help resolve it?" Ask what internal weak point the founder's own journey resolves for their audience — then apply the **Reframe-The-Wound-As-A-Feeling** signature move: never name it as a deficiency ("you're aging out"), name it as a feeling still available ("I can still have that feeling of flight" [15:14]).

5. **Mirror Test gate.** Before any weak-point material is approved for public use, run **The Mirror Test** [17:32]: does surfacing this resolve something real (mirror), or manufacture/exploit a vulnerability (dirty)? Reject anything that fails — this is Oren's ethics veto, not a suggestion.

6. **Identity-vs-expression sequencing lock.** Assemble Steps 1–5 into a single Identity Seed Document. Explicitly state what is NOT yet decided: archetype, content format, platform, visual signature. The output of this workflow is raw material locked into identity, not a content plan — resist the pull to jump ahead.

Execution prompt: references/prompts-v2/identity-zero-point.md — honor its Output Contract.

## Content Type Adaptations

| Founder Type | Adaptation |
|---|---|
| Solo founder with visible face | Full five-step excavation, weak-point pass mandatory |
| Faceless / product-only brand | Steps 1–3 route to founder-origin-of-the-PRODUCT (not a person); Step 4 optional, apply only if a real weak-point mechanism exists |

| Co-founder / multi-person brand | Run the excavation per person, then a synthesis pass identifying shared vs. individual seed material |

## Output Requirements

Identity Seed Document: origin narrative (with specifics), place, subculture/obsession list (verbatim), weak-point statement (post-reframe, post-mirror-test), explicit "not yet decided" list.

## Quality Gate

- Weak-point dignity: reframed as a feeling, never a deficiency
- Mirror-test: passes cleanly — solves something real, nothing "dirty"; fails on this criterion are rejected outright regardless of the rest, per the expert rubric's minimum bar
- Receipt density: origin/place/subculture material is specific and owned by the founder, not generic or invented
- Sequencing intact: no archetype, platform, or content-format decision has leaked into this output
