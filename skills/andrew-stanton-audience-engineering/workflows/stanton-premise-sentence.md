# Premise-Sentence (Andrew Stanton)
*Nemo* spent three years before "fear denies a good father from being one" finally rang true — fear is the character, *denies* is the conflict, and that line never appeared on screen but governed every cut. The premise-sentence is not an outline you obey; it is a litmus you hold against the page to find out what you actually made, and what in the draft is lying to it.

## Input Required
- The project, raw — script, essay draft, post, deck, offer, or even just the pile of notes
- What you *think* it is about (one phrase is fine, "a wish" is fine — we will test it)
- The protagonist (person, brand, customer, founder, robot — whoever the piece happens to)
- Any element you are already in love with and would fight to keep

## Workflow

### Step 1: Write the bad premise sentences
Open a page and keep writing one-sentence premises, the form being **character + conflict + conclusion**. Do not stop on the first. Do not sweat the wrong word — "that's not the right word, that's not the right thing" is the sound of the dig working. Write ten ugly ones fast; the pressure is off because they are supposed to be bad. The true one is usually hiding behind the obvious three.

| # | Character (the force) | Conflict (the verb that does the damage) | Conclusion (where it lands) | One-line premise |
|---|---|---|---|---|
| 1 | (e.g. *fear*) | (e.g. *denies*) | (e.g. *a good father from being one*) | "Fear denies a good father from being one." |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

Aim for the abstract force, not the plot. "A clownfish loses his son" is plot. "Fear denies a good father from being one" is the premise underneath it.

### Step 2: Pressure-test each against what is on the page — litmus, not wish
This is the move most people skip. A premise sentence is *"a litmus test of an analysis of what I think I've done"* — not a goal you are reaching toward. So hold each candidate up to the actual draft and ask: does the work *currently prove this*, or do I just *want* it to? A wish describes the project you meant to make; a litmus describes the one sitting in front of you.

| Candidate premise | Where the draft *proves* it (cite a real line/beat/scene) | Where the draft *contradicts* it | Litmus or wish? |
|---|---|---|---|
| | | | |
| | | | |

If every candidate is a wish — the draft proves none of them — you do not yet understand the piece. That is fine. Let it "be lost for a while" and keep digging rather than forcing a premise to hit a deadline.

### Step 3: Pick the TRUE one, not the one you want
Two sentences will compete: the one you *hoped* the piece was about, and the one it is *actually* about. Choose the true one even when it is smaller, darker, or less flattering than the pitch. A forced premise is a false premise, and everything you build on it inherits the lie. If the true premise is genuinely better than the work you have, you have just found your rewrite — that is the dinosaur you dug up, not the one you promised.

State the winner and *why it is the litmus and not the wish*:
```
TRUE PREMISE: "________ [character] ________ [conflict] ________ [conclusion]."
It is the litmus because the draft already proves it at: ________
The wish I am setting down: "________" — because the page never earns it.
```

### Step 4: Audit the piece against the premise — flag everything that does not serve it
Now run the draft beat by beat (or section by section, paragraph by paragraph) and judge each element against the one true sentence. The premise organizes invisibly: it never gets said aloud, but everything either serves it or fights it. Anything that does not serve it is either cut, or bent until it does — and the audit usually surfaces the root note hiding under a pile of surface symptoms.

| Element (beat / section / line) | Serves the premise? | If not: cut, or bend it to serve? |
|---|---|---|
| | YES / NO | |
| | YES / NO | |
| | YES / NO | |

The element you were "in love with" gets the hardest look. If it does not serve the true premise, love is not a reason to keep it.

## Content Type Adaptations
| Format | Adaptation |
|--------|-----------|
| Screenplay / film / video | The premise is the spine the whole runtime hangs on; never spoken, present in every scene. Audit each reel against it — a scene that does not turn the premise's face is a slack beat to cut or re-purpose, the way the *Nemo* prologue made one upstream move fix a dozen downstream notes. |
| Long-form essay / Substack | The premise is what the essay is *actually* arguing, under its topic. Run every section against it; cut the paragraph that is interesting but proves a different sentence. The reader should finish having *felt* the premise without ever being told it. |
| Short-form social (LinkedIn / X / Reels) | One premise per post — if it needs two sentences, it is two posts. The hook proves the character + conflict; the last line lands the conclusion. Audit ruthlessly: at this length, one off-premise line is a third of the post. |
| Sales / marketing copy | The premise is the single transformation the offer promises, stated as character + conflict + conclusion ("comfort denies a capable founder from being seen"). Every proof point, bullet, and testimonial is audited against it; anything that sells a different premise dilutes the one that converts. |
| Brand / campaign | The premise is the brand's real internal conflict, not its tagline. Each asset is audited as serving-or-fighting it. The "clever" asset that wins applause while proving a different sentence is exactly the element to flag — it is off-premise no matter how good it is. |

```
PROJECT: __________
What I thought it was about (the wish): __________

CANDIDATE PREMISES (character + conflict + conclusion):
  1. __________
  2. __________

  (kept writing until one rang true)

TRUE PREMISE (the litmus): "________ [character] ________ [conflict] ________ [conclusion]."
  • Proven on the page at: __________
  • Chosen over the wish "______" because the draft never earns the wish.

PREMISE AUDIT (serves / does not serve):
  • SERVES:  [element] — [how it turns the premise's face]
  • SERVES:  [element] — __________
  • FLAGGED: [element] — does not serve → CUT / BEND TO: __________
  • FLAGGED: [the beloved element] — verdict: __________

ROOT NOTE (if the audit found one upstream cause under many symptoms): __________
RESULT: this premise is a litmus on what exists [yes] — not a wish for what I wanted [confirmed].
```

## Quality Gate
> **🛡️ Anti-Pattern Check**: review against `genius.md § Anti-Patterns` + § Expert-Specific Quality Rubric. Flag and fix before delivering.
- The chosen premise is a **litmus on the actual draft** (cite the line/beat that proves it), not a wish for the piece you meant to write. If you cannot cite proof, it is a wish — keep digging.
- The premise has all three parts — **character + conflict + conclusion** — and reads as a true single sentence, not a topic ("a clownfish loses his son" fails; "fear denies a good father from being one" passes).
- The premise is **nowhere stated on the page** in the work itself; it organizes invisibly. If a line says the premise aloud, the architecture is showing — rewrite.
- Every flagged element got a verdict (cut or bend), including the one you were in love with. A premise audit that spares everything did not audit anything.
- You picked the **true** premise over the flattering one. If the winner is the one you wanted rather than the one the page proves, you forced it — redo Step 3.

## Common Pitfalls
- **Treating the premise as an outline to obey.** It generates nothing; it diagnoses. Recovery: stop writing *toward* the sentence and start holding it *against* what you already made — litmus, not instruction.
- **Forcing a premise to beat a deadline.** A premise forced when patience runs out is false, and everything built on it inherits the lie. Recovery: let the piece be lost a while; keep writing bad candidates until a true one surfaces, rather than crowning a convenient one.
- **Picking the wish over the litmus.** The flattering pitch-sentence is rarely the true one. Recovery: re-run Step 2 — if the draft does not *prove* it, it is a wish; choose the smaller, truer sentence even if it costs you the pitch.
- **Sparing the beloved element.** Keeping a great line/scene/asset that proves a *different* premise quietly splits the piece in two. Recovery: bend it to serve the true premise or cut it; love is not a litmus.
