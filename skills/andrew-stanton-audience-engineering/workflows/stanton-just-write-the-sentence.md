# Just Write the Sentence (Andrew Stanton)
You keep saying "someday" about the line, the open, the paragraph — and the someday is the block. The cure is mechanical: finish the sentence now, accept that it is bad, and rewrite it toward true. The good sentence only exists on the far side of the bad one, and you can't rewrite a sentence you never wrote.

## Workflow

### Step 1: Name the half-built sentence you keep saying "someday" about
Blocks hide. They feel like "I don't have time" or "I need to think more," but underneath is a specific sentence you keep narrating instead of writing — the symphony you're describing on the steps of Carnegie Hall. Drag it into the open and name it exactly. Capture it in writing first; the fear of forgetting a good thought is what freezes you, and once it's on the page you're free to make it bad.

| What I keep deferring | The "someday" excuse I tell myself | What it's actually supposed to land |
|---|---|---|
| (the opening line) | (e.g. "I'll nail the hook when I'm fresh") | (the feeling / claim it carries) |
| (the turn in the middle) | | |
| (the close) | | |

Pick the one stalling the whole piece. You only need one. Whistling stops the second a real sentence exists.

### Step 2: Write it badly NOW — pressure off, it is supposed to be bad
Write the sentence this minute. Not the good version — any version. The point is that it will be bad, which is exactly why the pressure is off: "just freaking write the sentence, it's going to be bad, so pressure's off." A bad sentence on the page beats a perfect one in your head, every time, because you can rewrite the first and you can't touch the second.

```
BAD DRAFT v0 (write fast, do not fix, do not delete):
__________________________________________________
```

Rules for v0: no backspacing, no rereading, no "let me just rephrase." Ugly, on-the-nose, cliché — all allowed. If you wrote a full sentence that says the thing badly, you have already beaten the block.

### Step 3: Rewrite it 2–3 times toward true
Now the actual craft starts. Writing is rewriting — the seventh or eighth draft is where it gets good, so commit to looking bad on the first six. Run v0 through 2–3 rewrites, each one a real attempt to make it truer, not just prettier. Hunt the wrong word the way you'd hunt the wrong note: when a word is off, don't sweat it, swap it and keep going. Stop when the line rings true, not when it's "fine."

| Pass | Rewrite | What got truer (or: what's still forced) |
|---|---|---|
| v1 | (cut the throat-clearing, find the live verb) | |
| v2 | (test the real claim under it — does it dig or decorate?) | |
| v3 (if needed) | (read it aloud; would you actually say it?) | |

Two checks before you call it: does the line **uncover** something or did you **force** it to hit a deadline (HK-2 — a forced line is a false one)? And does the *telling* match — is the rhythm worth savoring, or did you just get the information out? If it's forced, the block is back; let it sit a beat and write the next bad sentence instead of nailing a fake one in place.

### Step 4: Repeat for the next sentence
Momentum is the whole prize. One unblocked sentence makes the next one cheaper. Move straight to the next deferred line on your Step 1 list and run the bad-draft-then-rewrite loop again, without stopping to admire the one you just fixed. You are not trying to finish the piece in this pass — you are trying to keep the cable car clamped to the chain so it pulls you forward. Stop the session while you still know what the next sentence is, so tomorrow you start writing instead of whistling.

## Content Type Adaptations
| Format | Adaptation |
|--------|-----------|
| Screenplay / film / video | The blocked unit is usually a line of dialogue or a description beat. Write the bad line, then read it aloud — the test is whether you'd fear a good actor saying it, not whether it scans on the page. Harvest the rewrite from how it sounds in the mouth. |
| Long-form essay / Substack | The block is almost always the opening sentence or the transition into the hard middle. Write the bad lede now, in plain on-the-nose words; the real lede is hiding two rewrites past it. Never polish paragraph one before paragraph two exists. |
| Short-form social (LinkedIn / X / Reels) | The whole post is one or two sentences, so the bad-draft loop runs fast and visible. Write the ugly hook, then do 2–3 passes on that single line — the gap between v0 and v2 is usually the difference between scroll-past and stop. |
| Sales / marketing copy | The deferred sentence is the promise or the lead. Write the clichéd version ("save time, make money") on purpose, then rewrite toward the specific, true claim underneath it. The cliché is the diagnostic — it shows you the slot the real line has to fill. |
| Brand / campaign | The block is the one-liner or manifesto line everyone keeps "workshopping" instead of writing. Force a bad version into the doc to break the committee paralysis; a concrete bad line gives the room something to push against, which a blank slide never does. |

## Output Format
```
THE BLOCK: __________ (the piece + where it stalled)

THE DEFERRED SENTENCE: "__________"
  • What it's supposed to land: __________

BAD DRAFT v0: __________

REWRITES:
  v1 → __________
  v2 → __________
  v3 → __________  (if needed)

CHOSEN LINE: "__________"
  • Uncovered or forced? [uncovered / forced — let it sit, write the next bad one]
  • Telling check (rhythm worth savoring?): [yes / fix]

NEXT SENTENCE TO ATTACK: "__________"  (left live, so the next session starts in motion)
```

## Quality Gate
> **🛡️ Anti-Pattern Check**: review against `genius.md § Anti-Patterns` + `§ Expert-Specific Quality Rubric`. Flag and fix before delivering.
- A real sentence exists on the page — not a description of the sentence you intend to write. If the output is still narration about the work, you're whistling on the steps; write v0 before delivering.
- v0 was allowed to be bad and at least one true rewrite happened. A first draft handed back untouched fails Pattern 15; "writing is rewriting" means the loop ran.
- The chosen line was **uncovered, not forced** to beat the clock (HK-2). A line nailed in place because patience ran out is false — flag it and write the next bad sentence instead.
- The telling matches the content: rhythm and word choice are worth savoring, not just informationally correct.
- A next sentence is left live so momentum carries to the next session, rather than stopping at a clean wall.

## Common Pitfalls
- **Polishing v0 into the ground before any other sentence exists.** You rewrite the first line eleven times and the piece still has one line. Recovery: cap it at 2–3 passes, accept "true enough," and move to the next deferred sentence — momentum beats a perfect opener.
- **Skipping v0 and trying to write the good sentence directly.** That's the block wearing a productive disguise; the good sentence only exists past the bad one. Recovery: force the ugly version with no backspacing, then rewrite from there.
- **Forcing the line to hit a deadline.** A sentence manufactured because the clock ran out is a false one, and everything you build on it inherits the lie. Recovery: let that line stay lost a while, write the next bad sentence, and circle back when the true word surfaces.
- **Stopping at a clean stopping point.** Ending the session at a finished section means tomorrow you start cold and whistle again. Recovery: stop mid-momentum with the next sentence named, so the next session opens in motion.
