# Composition Map — Intent → Altitude Stack Decision Tree

> The OS's routing table. Find the intent, run the named experts in the listed order (3–6, never all 10), then run the gates. Every stack opens on the **Runia story-vs-topic gate** (`/runia-story-test`) and closes on the **truth/clamp/prose gate** (Layer 7). One Layer-4 expert is always the **body-voice owner** — marked `[VOICE]`. Experts not listed for an intent are *deliberately omitted* (note them in the receipt). Lane disambiguation: see `genius.md § The Lane Map`.

The universal gate bookends (assume on every stack, not repeated below):
- **OPEN** — Runia `/runia-story-test` (story exists? if not, `/runia-tension-dig` or route to a non-narrative engine).
- **CLOSE** — `really-real-*` truth pass + Stanton `/stanton-clamp-audit` (no slack) + `prose_classifier.py check <file>` (no slop).

## 1. Literary / personal essay
Interiority-grade, Parallax-class. Emotion and perception are the point; no market to move.
- **Stack (4–5):** Runia `/runia-story-test` → Hawley `/hawley-theme-engine` (theme + ending) → Shukman `/shukman-one-thread` + `/shukman-distance-digestion` (is it ripe? the single true thread) → **[VOICE]** Shukman `/shukman-concrete-doorway` + `/shukman-presence-essay` (or Harding `/harding-perception-engine` if lyric-description-led) → Ward `/ward-saxon-punch` (only the closing line) → CLOSE with `/really-real-writing`.
- **Omit:** Browder, Lulu, Wang, Connelly-momentum. No market, no evidence-spine, no analysis.

## 2. Founder origin story
Brand/founder narrative that must read as jeopardy, not a résumé.
- **Stack (5):** Runia → Stanton `/stanton-brand-origin` (living founder character + premise) → Browder `/browder-founder-warstory` (real jeopardy, adversary-through-evidence, dry-origin excavated) → **[VOICE]** Albom `/albom-brand-story` (the one human truth so customers see their own life) → Ward `/ward-saxon-punch` (the close) → CLOSE with `/really-real-writing` + `verify` (evidence-spine claims).
- **Branch:** if the founder is being *positioned* publicly (go-direct, contrarian thesis), add Lulu `/founder-narrative-voice-architecture` at Layer 6.
- **Omit:** Wang, Orlean, Shukman unless the origin is contemplative.

## 3. High-stakes nonfiction / investigative
Finance/law/policy/technical, or a real adversary; must grip AND survive scrutiny.
- **Stack (5–6):** Runia → Stanton `/stanton-spine` → Browder `/browder-drama-excavation` + `/browder-stakes-architecture` + `/browder-villain-evidence` (the lane owner) → **[VOICE]** Connelly `/connelly-rewrite` (economy/momentum) OR Wright (immersive scene) → Ward `/browder-show-then-nail` close → CLOSE with `/really-real-writing` + **`verify` / `wright-truth-audit` mandatory** (every claim routed through receipts).
- **Deploy point:** `/browder-investigative-content` for Substack-length.
- **Omit:** Orlean (subject is dangerous, not overlooked), Lulu unless it's a cause campaign, Shukman.

## 4. Profile (person or brand)
A subject the reader doesn't yet care about, seduced into caring.
- **Stack (4–5):** Runia → Orlean `/orlean-telling-subject` + `/orlean-in-love-test` (the small door onto the large theme; the go/no-go) → Orlean `/orlean-card-structure` (structure before prose) → **[VOICE]** Orlean `/orlean-yarn-engine` + `/orlean-wait-what-lead` (the dinner-table telling) with Connelly/Roth rendering scenes inside it → Ward (the kicker, light) → CLOSE with `/orlean-be-brutal-edit` + `/really-real-writing`.
- **Brand variant:** `/orlean-brand-profile` (company as telling subject) stacked over `oren-brand` spine.
- **Omit:** Browder (unless adversarial), Lulu, Wang.

## 5. Substack / newsletter edition
Zeitgeist-first, voice-driven, re-readable.
- **Stack (5):** Runia → Hawley `/hawley-theme-engine` (or `/hawley-content-season` for a series) → Wang `/wang-friction-map` + `/wang-newsletter-essay` (the gap that is the story; literary analysis) OR Orlean `/orlean-newsletter-narrative` (if narrative not analytical) → **[VOICE]** Connelly `/connelly-content-slingshot` (the lede drop-into-drive) → Ward `/wang-anchor-sentence` + `/ward-aphorism-forge` (the line it's built to earn) → CLOSE with `/really-real-social` + slop gate.
- **Route note:** for actual Parallax editions use `/parallax` (it owns the edition pipeline); this OS supplies the craft layers *inside* it, never rebuilds it.
- **Omit:** Browder unless investigative, Lulu unless it's a launch edition.

## 6. Analytical thread / annual letter
Dense insight compressed; rewards a re-read.
- **Stack (4):** Runia (does an argument-as-story exist?) → Wang `/wang-big-questions` + `/wang-friction-map` (the live tensions + the gap) → Wang `/wang-annual-letter` OR `/wang-analytical-thread` + `/wang-texture-zoom` (claim-to-texture welding) → **[VOICE]** Wang `/wang-musical-pass` (Wang holds the pen — single coherent voice) → Ward `/wang-anchor-sentence` (the quotable center) → CLOSE with slop gate + `/really-real-writing`.
- **Omit:** Albom, Shukman, Orlean, Browder, Lulu. Wang owns this lane nearly end-to-end; keep the stack tight.

## 7. Manifesto / keynote
Lines must be remembered and repeated; a position must be staked.
- **Stack (5):** Runia → Hawley `/hawley-theme-engine` (the one idea) → Lulu `/lulu-reality-architect` + `/lulu-strategic-wrongness` (the new operating truth + the contrarian stake) → **[VOICE]** Lulu `/lulu-conviction-copy` (belief-installing body) → Ward `/ward-speech-memorable` (anaphora build → epistrophe switch → Saxon closes, deployed sparingly) → CLOSE with `/really-real-writing`.
- **Omit:** Browder, Orlean, Wang, Connelly. This is rhetoric + conviction, not analysis or scene-craft.

## 8. VSL / converting copy
High-stakes persuasion; jeopardy and proof must be real.
- **Stack (5–6):** Runia → Stanton `/stanton-sales-arc` (the arc) → Browder `/browder-high-stakes-vsl` (real jeopardy, proof-as-narrative, next-sentence grip) → Lulu `/lulu-conviction-copy` (belief sequence) → **[VOICE]** copy-engine as the body engine with Connelly `/connelly-copy-detail` (one true detail implies the feature set) → Ward `/ward-copy-rhetoric` + `/ward-saxon-punch` (device on each high-stakes line, Saxon close on the CTA) → CLOSE with **hard honesty-spine gate** + slop gate + `/really-real-marketing`.
- **Route note:** the body copy is written by `/copy-engine` (it owns converting copy); the OS supplies the narrative + rhetoric + conviction layers around it.
- **Omit:** Shukman, Wang, Orlean, Harding.

## 9. Brand voice / positioning
A voice that can't be confused with the category.
- **Stack (4–5):** Runia (the brand's story-of-itself) → Lulu `/lulu-line-in-sand` + `/lulu-reality-architect` (what it stands against; the new reality) → Ocean `/ocean-brand-estrangement` (defamiliarize the category; a syntactic thumbprint) OR Harding `/harding-brand-sensory` (a living sensory texture) OR Shukman `/shukman-contemplative-brand` (presence-first, for calm/wellness brands) → **[VOICE]** the chosen Layer-4 expert holds the voice → Ward `/ward-tagline` (the one line the frame compresses into) → CLOSE with `voice-audit` + `/anti-homogenization-audit` + slop gate.
- **Route note:** `oren-brand` / `build-bos` supply the positioning + visual spine; the OS supplies the perceptual/conviction voice inside it.
- **Omit:** Browder, Wang, Connelly-momentum.

## 10. Social post / hook
Short-form; must stop the scroll and (ideally) haunt.
- **Stack (3–4):** Runia (micro-story check) → Stanton `/stanton-30sec-arc` (the change in 5 seconds) → **[VOICE]** pick ONE by goal: Connelly `/connelly-content-slingshot` (momentum hook) · Ocean `/haunted-social` (residue-first, anti-hook) · Shukman `/shukman-stillness-social` (anti-hype pause) · Albom `/albom-content-emotion` (meaning) → Ward `/ward-headline-rhetoric` (end-weight + one device) → CLOSE with `/really-real-social` + slop gate.
- **Route note:** `linkedin-daily` / `diandra-content-engine` own the daily production cadence; the OS supplies the hook + voice layer. For LinkedIn from scratch route to Lara via `/ghostwrite`.
- **Omit:** everything heavier. Keep social to 3–4 experts; preserve hook + brevity (defer to `/depth-social` for deepening, which preserves scannability).

## 11. Contemplative / wonder piece
Presence, awe, aliveness; sincerity is non-negotiable.
- **Stack (4):** Runia → Shukman `/shukman-mythos-logos` (register decision: transmit an experience, not convey info) + `/shukman-let-it-through` (surrendered first draft) → **[VOICE]** Shukman `/shukman-concrete-doorway` + `/shukman-embodied-word` (vastness through the smallest true thing; the word that is a felt event) → Harding `/harding-precision-wonder` (luminous precision + calculus, optional) → CLOSE with `/shukman-dont-cut-live-flesh` + `/really-real-writing`.
- **Critical:** Shukman vetoes faked mystery and performed awe. Do NOT add Stanton `/stanton-invoke-wonder` on top — that engineers the *feeling*; Shukman supplies the *genuine article*. If both appear, Shukman's honesty spine wins.
- **Omit:** Browder, Lulu, Wang, Connelly-momentum, Ward (unless the closing line needs one quiet device).

## 12. Ghostwriting a client voice
One coherent author in the client's voice; never a multi-expert composite.
- **Stack (3–4):** Runia → Albom `/signature-voice-legacy-identity` (the voice-DNA, if soulful) OR Connelly `/connelly-ghostwrite-economy` (if the voice needs edge + economy) → **[VOICE]** the single chosen expert holds the entire body — this is the strictest single-author lane → Ward (the client's quotable lines, à la carte) → CLOSE with `voice-audit` + `/really-real-writing` + slop gate.
- **Critical lesson:** never stitch multi-expert bodies for voice. The Sandwich tested 4/10 disjointed; the single-author draft won (`feedback_diandra-hooks-only-separation.md`). One author writes the body; other experts are à la carte amplifiers only.
- **Route note:** `/ghostwrite` (Lara/Cole pipeline) owns the ghostwriting workflow; this OS supplies the voice-craft layer inside it.
- **Omit:** any second body-voice expert. Hard rule.

## Quick selection logic (when the intent is ambiguous)

1. **Is there a market to move?** Yes → Lulu enters at Layer 6. No → omit Lulu.
2. **Is the material dangerous/dry, overlooked, analytical, or invented?** → Browder / Orlean / Wang / (Pressfield·Wright). Pick exactly one (Lane Map).
3. **Is the target feeling meaning, wonder, momentum, or strangeness?** → Albom / Shukman / Connelly / Ocean. Pick exactly one as `[VOICE]`.
4. **Does a single line have to be remembered?** Yes → Ward, one device. No → skip Layer 5.
5. **Always** open on Runia, close on really-real + clamp + slop gate.

If the stack exceeds 6 experts, a lane was double-picked — cut to one per altitude band.
