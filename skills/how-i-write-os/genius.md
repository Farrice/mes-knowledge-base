# How-I-Write OS — Master Writing Conductor

> **Load instruction**: Read this file before composing any writing/content/marketing mission through `/how-i-write`. This OS owns NO craft. It is a conductor — the same posture as `skills/writing-depth-layer` and the `stanton-produce` workflow. It diagnoses the intent, picks the *smallest sufficient* stack of existing experts, sequences them by altitude, runs them in order, and ends on a truth/clamp/prose gate. It never rebuilds a writer. The ten "How I Write" experts and the existing story-stack already own the craft; this OS only decides *who plays, in what order, and how much.*

---

## How to Use This OS (Opus Calibration)

The OS is a router, not an author. Its only intelligence is composition: *what does this piece need, who owns that, in what sequence, and how lightly can I touch it.*

1. **Compose existing engines — never rebuild.** Every craft move below is owned by a forged expert with a front-door command. The OS's job is to call them in order, not to re-teach what they already do. If you find yourself writing a hook formula or a restraint rule from scratch, stop — an expert owns it. (Same law as `stanton-produce`: "orchestrates existing engines; never rebuilds production.")

2. **Pick the smallest sufficient stack — 3 to 6 experts, never all 10.** A literary essay does not need Browder's evidence-spine and Lulu's distribution matrix. A VSL does not need Shukman's contemplative surrender. Most missions resolve on a **gate → architecture → one mid-layer → one voice-layer → one line-layer → truth-pass** spine of 4–5 experts. If your stack has more than 6, you have double-picked an adjacent lane — consult the Lane Map and cut.

3. **Restraint is the whole discipline.** More experts ≠ better. The repo lesson is load-bearing: *"More experts ≠ better for voice"* (`feedback_diandra-hooks-only-separation.md`) and the multi-engine rebuild that degraded already-elevated work to 3/10 (`feedback_multi-engine-rebuild-degrades-elevated-content.md`). One author owns the body voice. The rest advise from the wings. A stack of six that homogenizes the prose is a worse output than a stack of three that keeps one heartbeat.

4. **Preserve the spine.** When a draft is already good, do not run the full stack on it — diagnose the one or two missing layers and touch only those (defer to `/depth-audit` → `/depth-inject` from the Writing Depth Layer). The felt verdict wins over any gate score.

## The Altitude Stack

The composition spine. Every mission runs top-down through the layers it needs. Skip the layers it doesn't. The order is non-negotiable: **architecture before scene before line before truth.** Inverting it yields gorgeous sentences with no spine (the Writing Depth Layer's Ordering Law).

| # | Layer | Expert(s) + front door | Fires when |
|---|-------|------------------------|------------|
| **0** | **Story-vs-topic gate** | **Tim Runia** — `/runia-story-test` | ALWAYS, first. Does a story even exist here (want → tension → change), or is this just a topic? If no story, either dig one (`/runia-tension-dig`) or route to a non-narrative engine. The gate that prevents writing a "story" that has none. |
| **1** | **Theme / ending-first** | **Noah Hawley** — `/hawley-theme-engine`, `/hawley-ending-first` | When the piece needs a reason to exist and a destination. Lock why this exists and where it lands before any prose. Multi-part work runs Hawley first. |
| **2** | **Premise / clamp / surprising-inevitable** | **Andrew Stanton** — `/stanton-premise-sentence` (front door), `/stanton-spine`, `/stanton-clamp-audit`, `/stanton-surprising-inevitable` | Almost always. Distill the one-line premise, build the spine, and keep the audience from looking away beat to beat. Stanton is the attention architecture under the whole piece. |
| **2.5** | **One human truth** (theme's emotional twin) | **Mitch Albom** — `/albom-theme-first-engine` | When the piece must *move* a reader, not impress one. Sits at Stanton's altitude but answers a different question: not "what is this about" but "what truth about being human will the reader carry into their own life." Pick Albom OR run alongside Stanton when emotion is the point. |
| **3** | **The right NONFICTION mid-layer** (pick ONE) | **Browder** `/browder-drama-excavation` · **Orlean** `/orlean-telling-subject` · **Wang** `/literary-cornerstone-sprint` · **Albom** `/albom-gravedigger-angle` | When the material is real-world. Pick exactly one by the Lane Map: dry/high-stakes/adversarial → Browder; overlooked subject seduced via curiosity → Orlean; dense analysis into voice → Wang; one human truth via a margin figure → Albom. |
| **3-alt** | **The right FICTION / narrative mid-layer** | **Pressfield** (narrative physics) · **Wright Thompson** (lyric long-form immersion) · **Hawley** (season arc) | When the work is invented narrative or immersive long-form rather than analytical/investigative. |
| **4** | **The right SCENE + VOICE layer** (pick ONE primary) | **Connelly** `/connelly-rewrite` (economy/momentum/telling detail) · **Harding** `/harding-perception-engine` (lyric perception, luminous description) · **Ocean** `/estrangement-engine` (defamiliarization / anti-slop voice) · **Shukman** `/shukman-concrete-doorway` (wonder/presence/sincerity) · **Roth** (scene + line craft) | The body-voice owner. This is the one author whose fingerprint the prose carries. Pick by the Lane Map — do NOT stack two perception experts on the same passage. |
| **5** | **Memorable line / rhetoric** | **Ward Farnsworth** — `/ward-rhetorical-engine` (front door, diagnoses then deploys ONE device), `/ward-saxon-punch`, `/ward-aphorism-forge` | When a line has to be remembered, repeated, or land like a punch — closer, hook, tagline, kicker, the quotable thesis. Diagnose, then deploy ONE device. Never stack devices. |
| **6** | **Distribution / positioning** | **Lulu Cheng Meservey** — `/lulu-m3-matrix`, `/lulu-reality-architect`, `/lulu-conviction-copy` | ONLY when the piece must move a market — launch, category creation, founder brand, contrarian thesis, crisis. Lulu is the strategy + conviction spine; the craft experts write the assets inside it. Skip for pure personal/literary work. |
| **7** | **Truth pass** (ALWAYS last) | **really-real-*** (`/really-real-writing`, `/really-real-social`, `/really-real-ending`) + **Stanton clamp-audit** (`/stanton-clamp-audit`) + **prose gate** (`prose_classifier.py check`) | Every run ends here. Truth/compassion/reader-trust (really-real), no slack moment (clamp), no AI slop (deterministic classifier). The gate that ships. |

**When each layer fires** is the whole game. A contemplative personal essay runs 0 → 1 → (2 light) → 4=Shukman → 5 light → 7. A high-stakes VSL runs 0 → 2 → 3=Browder → 6=Lulu → 5=Ward → 7. A Substack analytical edition runs 0 → 1 → 3=Wang → 4=Connelly → 5=Ward → 7. The `references/composition-map.md` gives the exact stack per intent.

## The Lane Map (no collisions)

The near-adjacent lanes that the OS must never double-pick. One crisp sentence per expert: exactly what they own, and when to choose them over the neighbor.

### Nonfiction mid-layer — Browder vs Orlean vs Wang vs Wright

| Expert | Owns | Choose over the neighbor when… |
|--------|------|-------------------------------|
| **Bill Browder** | Making *dry, complex, high-stakes* material grip + rendering a real adversary through unassailable evidence (jeopardy, next-sentence test, evidence-spine). | The subject resists narrative (finance, law, policy, technical) OR there is a real antagonist who must land hard AND survive a lawyer. Over Orlean when the subject is dangerous, not merely overlooked. |
| **Susan Orlean** | Finding the small *overlooked* subject that secretly carries a large theme + seducing a reader who thinks they don't need the piece (telling-subject, wait-what lead, card-structure-before-prose). | The subject is low-demand and must be made irresistible by curiosity and the dinner-table telling. Over Wright when you reach the universal through the seductive small *door*, not through deep immersion. |
| **Dan Wang** | The *literary treatment of analysis* — turning dense domain insight into voice-driven nonfiction that rewards re-reading (friction-map, anchor sentence, texture-zoom, annual letter). | The piece is an argument/analysis that must read as elevated prose. Over Browder when the material is smart-but-dry analysis (not dangerous); over Orlean when it's argument, not narrative profile. |
| **Wright Thompson** | Reaching the universal through *immersion and interiority* — the residue of a deeply-inhabited scene (lyric long-form). | You get to the universal by living inside the subject's world, not by the seductive small door (Orlean) or the evidence-spine (Browder). The deep-immersion scene layer inside an Orlean or Browder structure. |

### Perception / detail / scene-voice — Connelly vs Harding vs Ocean vs Shukman

| Expert | Owns | Choose over the neighbor when… |
|--------|------|-------------------------------|
| **Michael Connelly** | Economy + momentum + the ONE telling detail that does five paragraphs' work; the reader can't find a place to stop. | The prose needs to move fast and cut clean — momentum, restraint, detail-selection. Over Harding when you want speed and economy, not luminous slowness. The default scene-voice for most commercial and content work. |
| **Paul Harding** | Lyric perception — slowing attention to the pre-linguistic instant and re-translating raw seeing so the ordinary turns luminous (two-things, counterpoint, botanist's-precision-plus-calculus). | You want luminous, re-seen description that persuades by recognition. Over Connelly when slowness and luminosity are the point; over Ocean when the strangeness stays *purely literal* (no flaunted metaphor). |
| **Ocean Vuong** | Estrangement / defamiliarization — rescuing familiar subjects from automatized perception so the sentence passes the Species Test; the anti-slop voice layer. | The prose reads as the AI-median/homogenized sentence and needs rupture. Over Harding when you want the displaced metaphor and the snap of the never-before-seen; the explicit anti-slop weapon. |
| **Henry Shukman** | Contemplative interiority + genuine wonder — carrying the largest feeling on the smallest true concrete particular, in a fully sincere register with no performed awe. | The piece must make the reader feel *alive* and the wonder must be real, not engineered. Over Connelly/Harding when presence and sincerity are the subject; runs *before* the attention engineers, not after. |

### Emotion vs Wonder — Albom vs Shukman

| Expert | Owns | Choose over the neighbor when… |
|--------|------|-------------------------------|
| **Mitch Albom** | Theme-first emotional architecture — one human truth, the ending decided first, the feeling *earned by restraint* so it "cuts the flesh" (gravedigger angle, loss architecture). | The target feeling is meaning/grief/love/legacy — "it made me think about my own life." Over Shukman when the emotion is human relationship and mortality, carried by a margin figure. |
| **Henry Shukman** | Wonder/awe/presence — reopening the reader to the wonder of *ordinary reality* through one exact perceivable particle, in total sincerity. | The target feeling is awe/aliveness/the sublime, carried on a concrete sensory doorway, never on the cosmic. Over Albom when the subject is presence and perception, not human loss and meaning. |

## Composition Rules

1. **Pick the smallest sufficient stack.** Start from the intent's named stack in `references/composition-map.md`. Add a layer only when a deficit is *confirmed*, never speculatively.

2. **Never run all 10.** A stack of 7+ means an adjacent lane was double-picked. Consult the Lane Map and cut to one expert per altitude band.

3. **Always end on a truth/clamp/prose gate.** Layer 7 is mandatory: `really-real-*` (truth) + `/stanton-clamp-audit` (no slack) + `prose_classifier.py check` (no slop). A run without the gate is incomplete.

4. **Preserve a spine — one author owns the body voice.** Do NOT let six experts homogenize the prose into composite mush. Exactly one Layer-4 expert is the *body-voice owner*; every other expert *advises* (supplies a move, a line, a diagnosis) without taking the pen. This is the load-bearing repo lesson:
   - *"More experts ≠ better for voice."* The Diandra Sandwich test scored 4/10 disjointed; the single-author draft beat every multi-expert escalation (`feedback_diandra-hooks-only-separation.md`).
   - The multi-engine rebuild of already-elevated content degraded it to 3/10 while the system scored it 7.5–8.6 (`feedback_multi-engine-rebuild-degrades-elevated-content.md`). Never rebuild what's already good; preserve the spine; small surgical passes; one engine.

5. **Don't name-drop experts inside the prose.** Moves are integrated invisibly. Experts are named only in the Output Receipt.

6. **Diagnose before treating an existing draft.** If a draft already exists, route to `/depth-audit` (diagnosis) → `/depth-inject` (single surgical move) before a full multi-expert pass. Refining slop on a misdiagnosed draft wastes the stack.

## The Output Receipt

Every run returns the finished piece PLUS a receipt mapping each move to the expert that produced it — the Writing Depth Layer's receipt pattern. The receipt is how the OS stays honest: it proves the composition was deliberate and lets Farrice see exactly which expert touched what.

```
## How-I-Write Receipt

- Intent: <the writing/content/marketing intent>
- Stack selected (smallest sufficient): <ordered list of experts + front-door commands>
- Body-voice owner: <the ONE Layer-4 expert who held the pen>

- Moves applied (in altitude order):
  - <Layer 0 gate>  → Runia /runia-story-test → <story exists? want/tension/change named>
  - <Layer 1>       → Hawley /hawley-theme-engine → <theme + ending locked>
  - <Layer 2>       → Stanton /stanton-premise-sentence → <premise line + clamp>
  - <Layer 3>       → <one mid-layer expert> → <what it did to the material>
  - <Layer 4>       → <body-voice owner> → <the voice/scene fingerprint>
  - <Layer 5>       → Ward /ward-rhetorical-engine → <the one device on the one line>
  - <Layer 6>       → Lulu (if market) → <strategy/conviction frame>  [omit if not a market piece]
  - <Layer 7 gate>  → really-real-* + /stanton-clamp-audit + prose_classifier → <PASS/flags>

- Experts deliberately NOT used: <name them + one-line why — proves restraint>
- Remaining risk: <what still could fail>
- Finalize: run execution/chain_runner.py finalize per The Chain (Step 6)
```

The "Experts deliberately NOT used" line is not optional — it is the proof of restraint that keeps the OS from sliding back into running all ten.
