# Library Asset Multiplication

## Input Required

- A grounded library-unit card or existing source asset.
- Audience, goal, and voice mode.
- Requested channels or permission to choose formats.
- Proof/claim status and source paths.
- Publishing state: draft-only or approval-ready.

## Execution

1. Verify the unit's claim, proof, source rights, and permissions.
2. Choose one primary asset and no more than two derivatives unless the user explicitly requests a full pack.
3. Give each asset a different job: test, teach, visualize, anchor, convert, or package.
4. Draft the assets in practitioner mode. If shipping in Farrice's voice, load the Voice Card and chosen dial before drafting.
5. Route only the weak link to the fitting craft owner. Visual assets require visual review; factual claims require factual verification.
6. Run the publishable prose gate when the assets are intended for publication.
7. Update the library-unit card with new language, reusable blocks, proof gaps, and the next measurement.

Execution prompt: `../references/prompts-v2/library-asset-multiplication.md` — honor its Output Contract.

## Output Contract

Produce one Markdown pack containing:

- Source Library Unit.
- Format Selection and job for each asset.
- One to three complete draft assets.
- Craft/claim review notes.
- Updated Library Unit.
- Save-Back and measurement plan.
- Approval boundary and remaining risk.

## Quality Gate

- Each asset is complete and useful, not an outline unless the format itself is a production brief.
- The assets share source truth without reading like resized duplicates.
- No more than three assets appear by default.
- Voice, proof, permission, and taste boundaries are explicit.
- The updated unit is more reusable than the input.
