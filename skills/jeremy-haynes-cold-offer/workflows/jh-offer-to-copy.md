# /jh-offer-to-copy — Offer→Copy Articulation Brief

The handoff artifact between offer architecture and copywriting. Downstream experts (copy-engine, luke-iha hooks/mechanisms, dara statics, VSL builders) receive a brief that locks offer alignment BEFORE craft begins — hooks written to a misaligned offer are wasted craft.

## Pre-Flight Gate

- Requires completed stack + narrative. Missing → `/jh-offer-stack` first.
- This workflow produces the BRIEF, not finished copy. Finished copy routes onward (cold-start converting copy → `/copy-engine`; hooks → luke-iha; Farrice's own voice → VOICE-CARD layer applies downstream).

## Skill Acquisition

- `genius.md` — articulation order, cold-stranger legibility, messaging principles (specificity/proof/diagnosis)

## Execution

1. **Core message line**: who specifically + what specific outcome + unique mechanism — one sentence, instantly qualifying AND disqualifying.
2. **Two-cliffs sequence**: the articulation order the copy must honor — problems (verbatim market language) → circumstances (the consequence layer) → desired outcomes → THEN the bridge/offer. Copy that opens with the product violates the brief.
3. **Specificity ledger**: every vague claim pre-replaced ("great results" → the actual number/range/timeline available); what comes with it named concretely (counts, names, cadences — "35+ SOPs" not "resources").
4. **Proof block**: available proof mapped to format — before/after + strategy + measurable outcome per testimonial; pattern proof across N clients; profession-matched proof indexed by persona. Per claims-quarantine: only proof the CLIENT actually possesses.
5. **Urgency line**: quantified cost of inaction from the narrative's circumstances — or explicitly "no urgency claim available" (fake urgency banned at brief level).
6. **Awareness-stage note**: in-market vs. needs-convinced → tells the copywriter whether to lead with differentiation/proof or with problem-education/mechanism.
7. **Scanner-mode constraint**: pre-commitment assets carry recognition, not education; flag which assets sit pre- vs. post-commitment so depth lands in consumption mode.

Execution prompt: references/prompts-v2/offer-to-articulation-brief.md — honor its Output Contract.

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| Ad creative brief | Compress to: core line, top problem-in-market-language, proof unit, disqualifier |
| VSL/webinar | Full brief + stage-gated depth map (what's revealed pre- vs. post-commitment) |
| Landing page | Two-cliffs sequence becomes the page's section order |
| Email sequence | Narrative elements distributed across sends; conversion push carries the offer articulation |

## Output Requirements

Articulation Brief: core message line, two-cliffs sequence with verbatim language, specificity ledger, proof block, urgency line (or honest absence), awareness-stage directive, asset depth-staging map.

## Quality Gate

- Core line disqualifies as clearly as it qualifies
- Zero vague claims survive the ledger
- Proof limited to what actually exists
- Articulation order enforced (no product-first structure)
- Awareness-stage directive present
