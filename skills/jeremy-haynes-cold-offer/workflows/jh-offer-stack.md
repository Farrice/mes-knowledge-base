# /jh-offer-stack — Cold Traffic Offer Stack Builder (Front Door)

Compose an offer whose every component is derived from the ICP's umbrella narrative, built to convert strangers. The full 8-step spine, front-loaded on composition (steps 1–5); instrumentation/augmentation/migration hand off to `/jh-objection-mine` and `/jh-temp-migrate`.

## Pre-Flight Gate (genius.md decision framework)

- Field-grounded narrative available? If no research corpus exists → run GROUND (Step 1) in full; never compose from assumption. "You never want to pull the narrative out of your ass."
- Audience state declared? In-market vs. needs-convinced must be explicit before composition.
- Existing offer? If auditing/repairing rather than building → `/jh-offer-audit` instead. Plateaued at scale → `/jh-plateau-diagnostic` first.

## Skill Acquisition

- `skills/jeremy-haynes-cold-offer/genius.md` (mandatory)
- `references/source-receipts.md` (claims quarantine + calibration quotes)
- If avatar/ICP research already exists in-session or via `/avatar-machine`: ingest through `/jh-avatar-bridge` instead of re-grounding.

## Execution

1. **GROUND**: Assemble the field corpus — scrape/search where the ICP complains (Reddit, X, IG, TikTok, reviews, community threads); harvest verbatim problem/circumstance/outcome language; pull real-prospect conversation notes if available. Deploy research agents; cite what was actually gathered.
2. **NARRATE**: Write the umbrella narrative as a story paragraph — who they are, what they've tried, **what failed** (scar tissue), what they now know they don't know, the specific outcome they name. Decompose into three labeled lists: Problems / Circumstances / Desired Outcomes.
3. **CLASSIFY**: Declare in-market or needs-convinced, with evidence. Note the implied funnel family (audience state dictates funnel type) and the future migration trigger.
4. **COMPOSE**: For each narrative element, generate the component that neutralizes it. Enforce both traceability directions: no orphan components, no unanswered narrative elements. Include at least one **next-problem absorption** component (what must the buyer solve immediately post-purchase for this to make sense?). Never sell done-for-you to a buyer scarred by failed done-for-you — component TYPE must respect scar tissue.
5. **LAYER**: Split CORE (majority-buyer components — the steak) from EDITIONS (contextual reserve — deployed by closers on commitment signals). When no frequency data exists yet, default fragile/situational components to editions.
6. **ARTICULATE**: Draft the bridge articulation — problems and circumstances first, desired outcomes second, offer last ("only after you successfully articulate their problems, their circumstances, and their desired outcomes, do they care about the bridge"). Core message: who specifically + what specific outcome + unique mechanism. Urgency only as quantified cost of inaction.
7. **COLD-READ TEST**: Run the 30-second stranger test on the articulation. A cold prospect must recognize their situation, self-qualify or self-disqualify, and understand what comes with it. Fail → recompose, don't decorate.

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| High-ticket service/coaching | Full stack + editions kit; failure-history components lead |
| SaaS / software | Next-problem absorption = implementation/migration; trial mechanics are stack components |
| Local / real estate | Editions dominate (subcontractor networks, financing paths); narrative per property/farm area |
| Low-ticket front-end | Segment the flagship: extract components into sub-$300 front-end offers; break-even acquisition goal |
| Client work | Strip/label all Haynes-reported numbers per claims quarantine |

## Output Requirements

Offer Stack Blueprint: narrative map, audience-state declaration, component table with traceability column, core/edition split, bridge articulation draft, cold-read verdict, migration note.

## Quality Gate (genius.md anti-patterns)

- Zero brainstormed components — every one names its narrative element ("not random")
- Scar-tissue respected in component types
- No inflated value-stack anchoring, no fake urgency
- Cold-stranger legibility passes
- Depth staged: recognition assets pre-commitment, education assets post-commitment
