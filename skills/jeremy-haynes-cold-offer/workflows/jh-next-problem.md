# /jh-next-problem — Next-Problem Absorption

High-ticket deals die at the problem ADJACENT to the purchase, not the purchase itself (the $1.5M construction after the $3.8M house). "You can deal with the next set of problems before the current problem is done by adding it to the original offer where the current problem's being solved."

## Pre-Flight Gate

- Requires a concrete offer and a real buyer journey. If the post-purchase sequence is unknown, interview fulfillment/onboarding first — don't speculate the map.

## Skill Acquisition

- `genius.md` — pattern 8, Cat Piss Mansion exemplar

## Execution

1. **Sequence the aftermath**: T+0 through T+90 days after purchase — everything the buyer must do, spend, decide, or solve for the purchase to make sense (implementation, hiring, financing, integration, approvals, family/stakeholder buy-in).
2. **Find the kill-points**: which of these, if unresolved AT decision time, kills the deal? Test: "If I didn't have the $1.5 million afterwards, dude, I wouldn't have bought the home." Rank by deal-mortality.
3. **Design absorption components**: for each kill-point — financing paths, done-with-you implementation, partner/subcontractor networks, staff training seats, templates, warm intros. The component de-risks the NEXT step inside the CURRENT offer.
4. **Place**: majority kill-points → core stack + articulated in the offer presentation; situational ones → editions (hand to `/jh-offer-editions`).
5. **Articulate**: write the line that surfaces each absorption in the pitch — the buyer must KNOW the next problem is covered before they're asked to decide.

Execution prompt: references/prompts-v2/cold-offer-stack-blueprint.md (§ next-problem components) — honor its Output Contract.

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| Financing-heavy purchases | Capital partners as stack components ("effortless decision" framing), incl. post-purchase capital |
| Info/education | Kill-point is usually implementation capacity → staff logins, accountability structure |
| Agency services | Kill-point is internal adoption → stakeholder onboarding components |
| E-com | Post-purchase = setup/compatibility/consumables → bundles and guides as absorption |

## Output Requirements

Next-Problem Map: aftermath timeline, kill-point ranking with mortality rationale, absorption component per kill-point, core/edition placement, pitch lines.

## Quality Gate

- Kill-points evidenced (fulfillment/onboarding reality or buyer statements), not imagined
- Every high-mortality kill-point has an absorption component
- Pitch lines present the absorption inside the offer, not as fine print
