# /jh-plateau-diagnostic — Offer vs. Funnel Differential

The decision instrument for the most expensive misdiagnosis in scaling: churning campaigns/angles/funnels/teams when the actual disease is offer misalignment with a colder lead pool. His client "tried damn near every single thing... nothing was working until they made an offer change."

## Pre-Flight Gate

- Is there real performance data (funnel stats over time, sales-call evidence)? Without longitudinal data this is a hypothesis sketch — label it as such.
- Pre-scale business with no traction yet? Not a plateau — run `/jh-offer-stack`; you can't diagnose drift with no baseline.

## Skill Acquisition

- `genius.md` — patterns 3/4/9 (bifurcation, temperature drift, show-rate telemetry), hidden knowledge (offer upstream of funnel)

## Execution

1. **Stat shape analysis**: chart the decay. **Step-function decay across ALL stats at once** (show rate + close rate + enthusiasm together) = alignment signature. **Isolated single-stat decay** = funnel tuning target. "Every stat is going to be cooked" vs. one leak.
2. **Sales-floor interview**: are prospects arriving pre-sold and in-pursuit (in-market) or curious, information-seeking, "open to the idea of being sold" but needing convincing? Pull direct quotes from reps/recordings. This is the drift instrument.
3. **Pool math**: estimate the in-market pool vs. current spend/reach. Scaled past the pool = drift is structural, not a creative problem.
4. **Cheaper-fixes ledger**: list what's already been tried (campaign structures, angles, messaging, funnel types, sales teams, marketers). Haynes explicitly counsels exhausting other solutions before "a massive offer change" — an offer re-composition is a big move; the ledger proves whether it's earned.
5. **Verdict**: OFFER-ALIGNMENT / FUNNEL / MIXED, with the evidence line for each. If OFFER → prescribe `/jh-temp-migrate` (re-compose for needs-convinced). If FUNNEL → name the specific stage and stat. Never both at once blindly — sequence the fixes.
6. **Expectation set**: if migration is prescribed, pre-state the ROAS dip pattern ("10:1 to 3:1 and work your way back up") so the dip doesn't trigger a panic reversal.

## Output Requirements

Diagnostic Verdict: stat-shape finding, drift evidence (quotes), pool math, cheaper-fixes ledger, verdict with confidence, prescribed next move, dip expectation if migrating.

## Quality Gate

- Verdict traceable to stat shape + floor evidence, not intuition
- Cheaper fixes documented before prescribing offer change
- No "do everything" prescriptions — sequenced
- Confidence labeled honestly when data is thin
