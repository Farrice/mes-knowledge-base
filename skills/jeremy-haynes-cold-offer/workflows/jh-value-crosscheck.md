# /jh-value-crosscheck — Haynes × Hormozi Value Cross-Check

Two offer philosophies, sequenced: Haynes decides WHAT belongs in the stack (narrative traceability); Hormozi's value equation tests HOW STRONGLY each surviving component lands (dream outcome × perceived likelihood ÷ time delay × effort). Composition first, magnitude second — never the reverse (a high-value component with no narrative element is still decoration).

## Pre-Flight Gate

- Requires a composed stack (from `/jh-offer-stack` or `/jh-offer-audit` inventory). No stack → build first.
- The two frameworks conflict on value stacks: Haynes bans inflated "$14,997 value" anchoring. Hormozi's equation is used HERE as a per-component diagnostic, never as price-anchoring theater.

## Skill Acquisition

- `genius.md` (this skill) + `skills/alex-hormozi/SKILL.md` (Tier 1: value equation section; Tier 2 add genius.md)

## Execution

1. **Confirm traceability first**: run/verify the Haynes component challenge. Orphan components exit before any value scoring.
2. **Score each survivor** on the four value-equation axes (1–10): dream-outcome match, perceived likelihood (proof attached to THIS component), time-to-result, effort/sacrifice demanded.
3. **Fix the weak axes with the right expert**: low likelihood → proof-specificity work (pattern proof, profession-matched); slow time-to-result → quick-win component or milestone restructure; high effort → done-with-you absorption (feeds `/jh-next-problem`).
4. **Guarantee design** (Hormozi's strongest tool) applied Haynes-style: the guarantee must answer a named narrative fear (McLaren warranty logic — reputation problem → bulletproof warranty), not exist as generic risk-reversal.
5. **Re-articulate**: strongest-scoring components lead the offer presentation; weak-but-necessary ones get bolstered or demoted to editions.

## Output Requirements

Cross-Check Matrix: component × (narrative element, 4 value axes, verdict: LEAD / KEEP / BOLSTER / DEMOTE / CUT) + guarantee design + re-articulated presentation order.

## Quality Gate

- No component scored before traceability confirmed
- Guarantees answer named narrative fears
- No value-stack price anchoring reintroduced
- Verdicts drive a concrete re-articulation, not just scores
