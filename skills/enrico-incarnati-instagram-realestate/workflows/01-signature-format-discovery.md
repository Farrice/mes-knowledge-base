# /enrico-format — Signature Format Discovery Engine

Discover the ONE repeatable content format that makes a real estate agent instantly recognizable on Instagram. Uses Enrico Incarnati's Lifestyle Intersection Method to find the unique angle where personal identity meets buyer demographic.

## Usage

```
/enrico-format [agent name or "my wife"]
```

Works for any real estate agent. Can be deployed for individual agents or batch-run across an entire team.

## Steps

### Step 1: Agent Identity Interview

Gather the following data points. If working for a known agent (like @_jiing), fill from context. Otherwise, ask:

```
AGENT PROFILE
─────────────
Name: [Full name]
Instagram: [@handle]
Market/City: [Where they sell]
Brokerage/Team: [e.g., Equity Union / MyHouseSellers]
Experience Level: [New / 1-3 years / 5+ years / 10+ years]
Niche: [First-time buyers / Luxury / Families / Investors / Relocation / etc.]

IDENTITY QUESTIONS
─────────────────
1. What do you love OUTSIDE of real estate?
   → [List 3-5 passions/hobbies/interests]

2. What's the thing your friends always say about you?
   → [Personality trait they're known for]

3. What's your unfair advantage that has nothing to do with selling homes?
   → [Unique skill, background, or experience]

4. Who are your typical buyers? Be specific.
   → [Demographics: age, family status, income, lifestyle]

5. Do your buyers share any of your interests?
   → [Map overlaps between agent interests and buyer interests]
```

### Step 2: Lifestyle Intersection Matrix

Cross-reference agent interests with buyer demographics to find format candidates:

```
LIFESTYLE INTERSECTION MATRIX
─────────────────────────────
| Agent Interest | Buyer Interest | Overlap? | Format Idea |
|----------------|---------------|----------|-------------|
| [Interest 1]   | [Buyer trait] | YES/NO   | [If YES: format concept] |
| [Interest 2]   | [Buyer trait] | YES/NO   | [If YES: format concept] |
| [Interest 3]   | [Buyer trait] | YES/NO   | [If YES: format concept] |
```

Generate 3-5 format candidates. For each:
- **Name**: Give it a catchy, memorable name (like "The Disruptor" or "Gamified Home Tours")
- **One-Line Description**: What the viewer sees
- **Integration Method**: How the interest physically integrates into a home walkthrough
- **Repeatability Score (1-10)**: Can this be done for EVERY listing?
- **Entertainment Value (1-10)**: Would a non-buyer still watch this?
- **Lead Qualification Power (1-10)**: Does this attract the RIGHT type of buyer?

### Step 3: Three-Function Test

Every format MUST pass all three:

```
THREE-FUNCTION TEST
───────────────────
Format: [Name]

✅ or ❌ BRINGS IN NEW EYES
- Would someone who isn't looking to buy share this?
- Is this entertaining/interesting enough for the explore page?
- Reasoning: [Explain]

✅ or ❌ QUALIFIES LEADS
- Does this attract the specific type of buyer for this agent's market?
- Would it repel the wrong type of buyer?
- Reasoning: [Explain]

✅ or ❌ MAKES YOU AN ATTRACTIVE CHARACTER
- Does this showcase personality in a way nobody can copy?
- Would viewers recognize this agent without seeing their handle?
- Reasoning: [Explain]

VERDICT: [PASS / FAIL / NEEDS REFINEMENT]
```

Run the test on all 3-5 candidates. Recommend the one with the highest combined score that passes all three functions.

### Step 4: Format Blueprint

For the winning format, produce a complete blueprint:

```markdown
# SIGNATURE FORMAT BLUEPRINT

## Format Name: [Name]
## Tagline: "[What viewers call you]"

### The Concept
[2-3 sentences describing exactly what this format looks like]

### Episode Template
1. OPEN: [How every video starts — the recurring bit]
2. HOOK: [First 3 seconds — what hooks the viewer]
3. BODY: [What happens during the walkthrough]
4. PAYOFF: [How each video ends — the signature close]
5. CTA: [What you want them to do after watching]

### First 5 Episode Ideas
| # | Listing/Topic | Angle | Hook Line |
|---|--------------|-------|-----------|
| 1 | [Property] | [How the format applies] | "[Hook]" |
| 2 | [Property] | [How the format applies] | "[Hook]" |
| 3 | [Property] | [How the format applies] | "[Hook]" |
| 4 | [Property] | [How the format applies] | "[Hook]" |
| 5 | [Property] | [How the format applies] | "[Hook]" |

### Production Notes
- Equipment needed: [Phone? Gimbal? Props?]
- Ideal video length: [15s / 30s / 60s / 90s]
- Filming style: [Handheld, tripod, someone else filming]
- Audio: [Original audio, trending audio, voiceover]
- Posting frequency: [X times per week]
- Best posting times: [Based on Instagram data for real estate]

### What Makes This Uncopyable
[Explain why no other agent can replicate this exact format — it's rooted in WHO you are]
```

### Step 5: Competitive Differentiation Check

Search Instagram for the agent's city/market and verify:
- Is anyone else doing something similar in this market?
- How does this format position them differently from every other agent?
- What does their feed look like with this format vs. the "billboard" default?

### Step 6: Deliverable Summary

Produce the final output as a conversation artifact containing:
1. Agent Profile Summary
2. Lifestyle Intersection Matrix
3. All Format Candidates with Three-Function Test results
4. Winning Format Blueprint (complete)
5. First 5 Episode Scripts (ready to film)
6. Competitive differentiation analysis
