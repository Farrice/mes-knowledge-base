# /enrico-sprint — Weekly Content Sprint

Generate a complete, production-ready content week for a real estate agent. Combines signature format, expansion pack content, proximity play, listings, and stories into a single executable sprint. The agent gets a done-for-you calendar with scripts — just film and post.

**EVOLUTION ADDITION: Visual Narrative Sequencing Layer (Phase 0 — before calendar generation)**

Before assigning content to days, design the SEQUENCE — the psychological arc that makes each post compound toward a conversion action (DM inquiry, keyword comment, profile visit → link click).

## Usage

```
/enrico-sprint [agent name] [optional: week of / specific listing / topic focus]
```

Examples:
- `/enrico-sprint @_jiing`
- `/enrico-sprint @_jiing "week of April 7" "new listing at 123 Main St"`
- `/enrico-sprint "any agent" "focus on first-time buyers"`

## Steps

### Phase 0: Visual Narrative Sequencing (NEW — before calendar generation)

Before assigning content types to days, design the conversion arc for the week. This is the cognitive layer that transforms isolated posts into a compounding sequence.

#### Step 0a: Identify the Conversion Target

Name the ONE specific action this week's sequence builds toward:
```
CONVERSION TARGET THIS WEEK
────────────────────────────
Action: [e.g., "DM 'ready' for free buyer consultation" / "Comment 'checklist' for viewing guide"]
Who: [Specific segment — first-time buyers in [area] / sellers considering listing / investors]
Current viewer state: [What they believe/feel BEFORE seeing this week's content]
Target viewer state: [What they must believe/feel BEFORE they'll take the action]
Belief gap: [The specific shift required — e.g., "from 'I can't afford this market' to 'there's a strategy I don't know about'"]
```

#### Step 0b: Design the 5-Post Demand Chain

Each post must create DEMAND for the next post. Map the psychological sequence:

```
DEMAND CHAIN
────────────
Post 1 (PATTERN INTERRUPT): 
  Purpose: Break the scroll. Introduce a tension the viewer didn't know they had.
  Viewer state after: "Wait, is that true?"
  Demand created for Post 2: [What question or curiosity Post 1 leaves unresolved]

Post 2 (AUTHORITY PROOF):
  Purpose: Answer Post 1's open question with demonstrated expertise.
  Viewer state after: "This person actually knows what they're talking about."
  Demand created for Post 3: [What Post 2 proved that makes Post 3's topic urgent]

Post 3 (LOCAL EVIDENCE):
  Purpose: Ground the authority in THIS specific market/area. Make it undeniably local.
  Viewer state after: "They know MY neighborhood / MY situation."
  Demand created for Post 4: [What proximity proof makes the next reveal feel personal]

Post 4 (THE REVEAL):
  Purpose: Show the outcome — what it looks/feels like when you work with this person.
  Viewer state after: "I want that."
  Demand created for Post 5: [What desire Post 4 creates that Post 5 converts]

Post 5 (CONVERSION CATALYST):
  Purpose: Make the action feel obvious and low-risk. Not a hard sell — a natural next step.
  Viewer state after: "I should reach out." → [Takes the conversion action]
  CTA: [Specific keyword/DM prompt aligned to the conversion target]
```

#### Step 0c: Thread Design (Cross-Post Callbacks)

For each post, design ONE element that references a previous post in the sequence:

```
THREAD ELEMENTS
───────────────
Post 1 → Post 2: [How Post 2 references the tension Post 1 created — e.g., "Remember that number I showed you Monday?"]
Post 2 → Post 3: [How Post 3 grounds Post 2's claim locally — e.g., "Let me show you what that looks like on YOUR street"]
Post 3 → Post 4: [How Post 4 pays off Post 3's proximity — e.g., "This is the house two blocks from that coffee shop"]
Post 4 → Post 5: [How Post 5 makes the desire from Post 4 actionable — e.g., "If you saw Friday's tour and thought 'how do I find something like that'..."]
```

**NOTE**: These callbacks are SUBTLE — a sentence or visual reference, not "as I said in my last post." Viewers who saw the previous post get a recognition hit. Viewers who didn't still get a complete experience.

## Quality Gate

Before delivering, verify:
1. **The demand chain actually chains.** Each post's "demand created for next" must be a specific, answerable-only-by-the-next-post hook — not a generic "stay tuned." If Post 2 doesn't reference Post 1's open loop, the sequencing layer (this workflow's core differentiator) has failed.
2. **Thread elements are subtle, per the workflow's own rule**: "a sentence or visual reference, not 'as I said in my last post.'" An explicit callback like that phrase is a fail.
3. **Format assignment serves the sequence role, not vice versa.** Reel 3 (Local Evidence) should use a Proximity Play format because that's what proves local knowledge — assigning formats arbitrarily and retrofitting a sequence role is backwards per Step 2's stated design principle.
4. **Every format used still obeys its own source pattern** (Digital Clipboard is still the highest-save format, Green Screen still borrows real headline authority) — sequencing is additive, never a replacement for the underlying pattern discipline.
5. **Recognition check**: would Enrico Incarnati recognize the five reels as a single coherent week that BUILDS — or as five unrelated pieces of content that happen to share a posting calendar?
