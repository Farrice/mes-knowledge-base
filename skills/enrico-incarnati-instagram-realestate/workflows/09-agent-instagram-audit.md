# /enrico-audit — Agent Instagram Audit

Complete 360° Instagram audit for any real estate agent — scores their current presence across all 7 dimensions, identifies the exact gaps, and produces a prioritized transformation roadmap. This is the diagnostic tool that sells the service.

## Usage

```
/enrico-audit [@handle or agent name]
```

Examples:
- `/enrico-audit @_jiing`
- `/enrico-audit "new agent on team"`
- `/enrico-audit @competitor_agent` (competitive intelligence)
