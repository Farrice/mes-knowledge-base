# /enrico-expand — Content Expansion Engine

Take ANY boring real estate educational topic and produce 5 distinct, engagement-optimized content pieces using Incarnati's proven format library. One topic → 5 pieces of content ready to film.

## Usage

```
/enrico-expand [topic]
```

Examples:
- `/enrico-expand "Can I afford a home?"`
- `/enrico-expand "interest rates"`
- `/enrico-expand "renovations that add value"`
- `/enrico-expand "first-time buyer mistakes"`

## Steps

### Step 1: Topic Analysis

Identify the core topic and its audience value:

```
TOPIC ANALYSIS
──────────────
Topic: [The subject]
Why agents usually post about this: [Standard approach]
Why it's boring when done the standard way: [The problem]
Target awareness level: [Unaware / Problem-aware / Solution-aware / Product-aware]
Pain it addresses: [What buyers/sellers worry about]
```

### Step 2: Generate All 5 Formats

Produce complete, ready-to-film content for each format. Do NOT produce outlines — produce scripts.

#### Format 1: Visual Math

```
📊 VISUAL MATH
Title: [Title]
Hook (first 3 seconds): "[Exact opening line]"

SCRIPT:
[Person walks in / appears on screen]
Person: "[Question]"
You: "[Set up the math]"

[Walk through calculation step by step]
Step 1: [Calculation + what you say]
Step 2: [Calculation + what you say]
Step 3: [Calculation + what you say]

PAYOFF: "[The surprising answer or insight]"
CTA: "Comment [KEYWORD] and I'll send you [specific resource]"

PRODUCTION NOTES:
- Props needed: [Whiteboard / paper / screen overlay]
- Duration: [30-60 seconds]
- Filming: [Office setting, someone else as the "asker"]
```

#### Format 2: Green Screen Reaction

```
📰 GREEN SCREEN REACTION
Title: [Title]
Headline/Article: [Specific real headline to use — provide a real one or describe what to search for]
Hook (first 3 seconds): "[Exact opening line]"

SCRIPT:
[Green screen — article visible behind you]
"I just saw this headline and we need to talk about it..."
[Point to headline]

SURFACE LEVEL: "Here's what the headline says: [summary]"
REALITY: "But here's what this ACTUALLY means for you: [expert interpretation]"
ACTION: "So if you're looking to [buy/sell] right now, here's what I'd do: [specific advice]"

CTA: "Save this — you'll want to reference it when [specific situation]"

PRODUCTION NOTES:
- Use Instagram's built-in green screen effect
- Duration: [30-60 seconds]
- Energy: Conversational, not lecturing
```

#### Format 3: This vs. That Bracket

```
🏆 THIS VS. THAT BRACKET
Title: [Title — "Which [X] is ACTUALLY worth it?"]
Hook (first 3 seconds): "[Exact opening line]"

BRACKET:
Round 1: [Option A] vs. [Option B]
→ Winner: [X] because [reasoning in 1-2 sentences]

Round 2: [Option C] vs. [Option D]
→ Winner: [X] because [reasoning]

Round 3: [Winner R1] vs. [Winner R2]
→ Winner: [X] because [reasoning]

(Add more rounds if 6-8 options available)

FINAL: "[Champion] wins and here's why..."

CTA: "Do you agree? Drop your pick in the comments 👇"

PRODUCTION NOTES:
- Use on-screen graphics/text for bracket visual
- Duration: [45-90 seconds]
- Tone: Playful but informed
- Goal: Drive comment debate (algorithmic fuel)
```

#### Format 4: S-Tier Ranking

```
🎯 S-TIER RANKING
Title: [Title — "I'm ranking [X] from S tier to trash tier"]
Hook (first 3 seconds): "[Exact opening line — should be slightly controversial]"

RANKINGS:
S Tier: [Item] — "[Why — make it compelling]"
A Tier: [Item] — "[Why]"
B Tier: [Item] — "[Why]"
C Tier: [Item] — "[Why]"
D Tier: [Item] — "[Why — start getting spicy]"
F Tier: [Item] — "[Why — be bold/funny/controversial]"

PAYOFF: "The one everyone thinks is S tier but is actually [lower tier]? [Item]. Here's why..."

CTA: "What's YOUR S tier? I know we're about to fight about this 💬"

PRODUCTION NOTES:
- Use tier list visual template (create or use existing)
- Duration: [45-90 seconds]
- Hot take energy — ranked lists only work if you have opinions
```

#### Format 5: Digital Clipboard

```
📋 DIGITAL CLIPBOARD
Title: "[N] things you MUST [action] before [event]"
Hook (first 3 seconds): "[Exact opening line]"

VIDEO: [Describe the walkthrough footage]

OVERLAY CHECKLIST:
1. [Item — specific, actionable, non-obvious]
2. [Item]
3. [Item]
4. [Item]
5. [Item]
6. [Item]
7. [Item]
8. [Item]
9. [Item]
10. [Item]
11. [Item]
12. [Item]

CTA: "Comment '[KEYWORD]' and I'll DM you the full checklist PDF you can take with you"

PRODUCTION NOTES:
- This is the HIGHEST save-rate format
- Film a real property walkthrough as the base video
- Overlay text items one at a time as you walk through
- Duration: [60-90 seconds]
- Lead magnet: Create a PDF version of this checklist for ManyChat delivery
```

### Step 3: Cross-Format Synergy Map

Show how these 5 pieces connect into a content week:

```
CONTENT WEEK: "[Topic]"
─────────────────────
Monday:    Digital Clipboard (highest save rate — starts the week strong)
Tuesday:   Visual Math (educational, builds authority)
Wednesday: Green Screen Reaction (borrows authority, current/topical)
Thursday:  This vs. That Bracket (engagement driver — comments fuel algorithm)
Friday:    S-Tier Ranking (entertainment — shareable, controversial)

STORIES THROUGHOUT: Behind-scenes of filming these + polls asking
"Which tier would YOU put [X]?" to pre-engage before the ranking drops
```

### Step 4: Lead Magnet Design

For the Digital Clipboard format, design the PDF lead magnet:

```
LEAD MAGNET SPEC
────────────────
Title: "[Title of checklist/guide]"
Format: PDF, mobile-optimized (single column, large text)
Pages: 2-3 max
Content: The full checklist from Format 5, expanded with 1-2 sentences per item
Branding: Agent name, logo, contact info, Instagram handle
CTA at end: "Ready to [buy/sell]? Book a free consultation: [link]"

ManyChat Trigger Word: "[KEYWORD]"
Auto-DM Message: "Here's your [checklist name]! 📋 [PDF link]
P.S. — If you have any questions about [topic], just reply here and I'll help you out."
```

### Step 5: Deliverable

Produce a conversation artifact containing:
1. Topic Analysis
2. All 5 format scripts (ready to film)
3. Content Week scheduling map
4. Lead magnet spec
5. ManyChat trigger configuration
6. Thumbnail/cover suggestions for each piece
