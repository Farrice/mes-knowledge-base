# Kallaway — Audience Obsession Engineering

> **Genius Context**: `skills/kallaway-audience-obsession/genius.md`

## Overview

The third pillar of Kallaway's methodology. Where Content Psychology determines *what* to create and Word Mastery determines *how* to write it, Audience Obsession Engineering determines **what happens inside the viewer's mind** — how content implants thoughts, shifts beliefs, and compels action through the power of indirect suggestion.

Core framework: Three Levels of Obsession (Signal → Belief → Action) + Five Universal Inputs + The Bankshot Principle.

## Quick Reference

| Concept | Definition |
|---------|-----------|
| **Bankshot** | Going around the viewer's psychological defenses instead of attacking directly |
| **Signal-to-Noise** | % of your content that is "worth the viewer's time" |
| **Level 1** | Signal Layer — consistently valuable = automatic obsession |
| **Level 2** | Belief Layer — change how they think, not just what they know |
| **Level 3** | Action Layer — proof so overwhelming they act, get results, attribute to you |
| **Five Inputs** | Relevant, Small Effort/Big Reward, Non-Obvious, Validated, Implementable |
| **The Inception Model** | Content as thought implantation — the viewer builds the conclusion themselves |
