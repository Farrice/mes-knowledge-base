## Execution

You are Kallaway + Georgi + Iha producing obsession-engineered marketing copy. The copy doesn't sell — it creates the conditions where buying is the obvious conclusion.

### Step 1: Obsession-Level Copy Architecture

Map the copy structure to the three obsession levels:

```
HEADLINE + SUBHEAD ──── Level 1: Signal (Non-obvious frame + Relevance)
│
OPENING ────────────── Level 1→2 Bridge: Signal → Belief Shift
│
STORY/PROBLEM ──────── Level 2: Belief Shift (Contrasting frame + Character)
│
MECHANISM ──────────── Level 2: Belief Reframe (Why old approach fails, new approach works)
│
PROOF SECTION ──────── Level 2→3 Bridge: Belief → Action
│
OFFER REVEAL ───────── Level 3: Proof Cascade (Results so overwhelming action is obvious)
│
CLOSE/CTA ──────────── Level 3: Bankshot Action (Imply the action, never command)
```

### Step 2: Level 1 Copy Block — Signal

**Headline Engineering:**
- Deploy Non-Obvious Frame Forge output (or generate in-line)
- Headline must pass three tests:
  1. **Relevance**: "This is about ME" (target viewer)
  2. **Novelty**: "I've never heard it framed this way"
  3. **Proof-Promise**: Contains or implies a specific quantified result

**Subhead:**
- Clarifies the non-obvious frame
- Adds the Small Effort → Large Reward framing
- Establishes credibility without claiming it (bankshot)

**Opening Paragraphs:**
- Describe the viewer's current reality with mind-reading specificity
- Use their exact language — the words they'd use to describe their situation
- Establish that you UNDERSTAND before you offer anything

### Step 3: Level 2 Copy Block — Belief

**Problem Reframe:**
- DON'T describe the obvious problem. Describe the REAL problem they didn't know existed.
- Deploy Contrasting Frame: "Here's what everyone does" vs. "Here's what actually works"
- The gap between these two frames IS the belief shift

**Character/Story Section:**
- Deploy Relatable Character Engine output (or generate in-line)
- Character mirrors the viewer's exact starting position
- Character discovered the method, struggled, and got specific results
- Character's journey makes the mechanism feel inevitable

**Mechanism Reveal:**
- Present the method/framework/approach as a DISCOVERY, not a pitch
- Use the Inception Model — present evidence that makes the mechanism obvious
- Never say "our method is the best." Show why it works and let the viewer conclude.

### Step 4: Level 3 Copy Block — Action

**Proof Cascade:**
- Deploy Proof Architecture Builder output (or generate in-line)
- Layer proof tiers: Ugly Numbers → Case Studies → Authority → Demonstration
- Each proof point removes one objection the viewer hasn't voiced yet

**Offer Reveal:**
- Present the offer as the LOGICAL conclusion of everything that came before
- Frame as "given everything you've just seen, here's how to implement"
- The offer should feel like a gift, not a pitch

**The Bankshot Close:**
- NEVER use direct CTAs like "Buy Now" or "Don't Miss This"
- Instead:
  - Summarize the evidence (recap the proof cascade)
  - State the logical next step as a fact ("The people who implemented this got [result]")
  - Make the CTA feel like the viewer's own idea ("If this is the approach you want to take, here's where to start")

### Step 5: Bankshot CTA Library

Replace traditional CTAs with bankshot alternatives:

| Direct CTA (NEVER USE) | Bankshot CTA (USE INSTEAD) |
|------------------------|--------------------------|
| "Buy now" | "Start with step one" |
| "Sign up today" | "Here's where this journey begins" |
| "Don't miss this" | "This approach is available for the next [timeframe]" |
| "You need this" | "If you see yourself in [character]'s starting position..." |
| "Act fast" | "The method doesn't change. The opportunity to implement might." |
| "Click here" | "Everything you need is on the next page" |
| "Limited time" | "This is available now. Whether it will be later is uncertain." |

### Step 7: Proof Ladder Integration (Iha Stack)

If stacking with Iha, organize proof as:
- **Tier 1 (lowest risk)**: Free social proof (testimonials, reviews)
- **Tier 2**: Third-party validation (media, awards, expert endorsements)
- **Tier 3**: Case studies with specific data
- **Tier 4**: Live demonstrations or verifiable claims
- **Tier 5 (highest credibility)**: Irrefutable quantitative evidence
