# Kieran Flanagan - Content Ops

The optimization and orchestration layer of Kieran's AI content team architecture. These tools manage the full content production pipeline, analyze performance, and improve the system over time. This is what separates a "prompt collection" from a self-improving content machine.

## Available Workflows

| # | Workflow | Produces | Use When |
|---|---------|----------|----------|
| 01 | [Content Orchestrate](workflows/01-content-orchestrate.md) | Full content production session with all skills chained | You want to run a complete content sprint — from talking points through creation through enrichment — without manually chaining skills |
| 02 | [Content Feedback](workflows/02-content-feedback.md) | Performance analysis report + skill improvement recommendations | You have published content with engagement data and want to know what worked, what didn't, and how to update your profiles and style cards |
| 03 | [Content Review Cycle](workflows/03-content-review-cycle.md) | Monthly content system audit + proposed skill updates | You want to audit the entire content system — profiles, style cards, talking points — and propose targeted improvements based on last month's performance |
| 04 | [Content Queue](workflows/04-content-queue.md) | Human-selected queue delta, current state, and health report | You want to add selected idea cards, prune stale inventory, or promote one idea into a separate creation workflow |
