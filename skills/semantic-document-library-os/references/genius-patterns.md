# Genius Patterns - Semantic Document Library OS

1. **Access is not meaning**: tool access gets the agent into the workspace, but the work primitive tells it what the action means.
2. **The button is not the primitive**: document the action behind the interface, not the surface click.
3. **Permission is semantic**: replace read/write with draft/send, stage/deploy, sandbox/production, recommend/approve, reversible/irreversible.
4. **Tests are meaning artifacts**: validations teach the agent what correct work looks like.
5. **The work graph beats the prompt**: durable agent execution comes from objects, actions, permissions, failure modes, and feedback loops.
6. **Human simple, agent rich**: keep the human interface clear while exposing richer structure for agents.
7. **Semantic exposure is strategic**: decide what meaning to expose so agents can act without turning the product into someone else's invisible backend.
8. **Agent readiness is a service line**: businesses will pay to turn implicit work knowledge into agent-executable operating libraries.
