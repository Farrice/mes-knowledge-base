# LinkedIn Image and Caption Studio

## Pre-flight and skill acquisition
Load `../genius.md` calibration and `../references/linkedin-source-method.md`, then the reference guide produced by the lab. Inputs: seed idea, audience, objective, owned evidence and current author context. For Farrice, read `_active/farrice-brand/voice/VOICE-CARD.md`, BLEND unless specified. Apply anti-slop before drafting and before delivery. If no guide exists, use the source-method reference and label the output source-demo practice, not a personalized trained writer.

## Execute
1. Preserve the raw seed, actual author belief, supporting artifact and audience problem. Use provided context; ask only for missing private facts essential to the claim.
2. Propose three genuinely different angles (different stakes, application or interpretation). Recommend one with a reason; proceed when the brief makes the choice clear. Do not force Dan's exact three example labels into unrelated ideas.
3. Produce the image's one-thought text and a visual brief: readable hierarchy, attribution, source/rights, relevant dimensions to confirm at render time. Use owned plain cards or cleared source screenshots. Never invent engagement counts, verification badges or account UI.
4. Draft a caption that adds an example, mechanism, constraint, consequence or next action to the image. Include a clear opening, useful development and a natural ending; no compulsory question or engagement bait.
5. Edit in the author's voice. Remove stock AI assertions, claims beyond evidence, duplicate sentences, and any personal details the author has not cleared.
6. Run the removal test: if the caption disappears, what useful information is lost? If nothing, revise. Run the ownership test: can the author defend each factual sentence and own the opinion?
7. Return the final draft plus image brief and a compact proof note outside the post. Default status PASS FOR DRAFT REVIEW, not published. Render only when visual production is requested; use existing craft owner and tools, no paid tool by default.

Deliver selected angle, image text/brief, complete caption, evidence boundaries and distribution handoff. Claim/voice failures get one focused revision. No false performance promise. Execution prompt: `references/prompts-v2/linkedin-image-caption-package.md` — honor its Output Contract.
