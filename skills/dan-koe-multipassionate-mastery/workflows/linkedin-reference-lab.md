# LinkedIn Reference Lab

## Pre-flight and acquisition
Load `../genius.md` calibration and `../references/linkedin-source-method.md`. Inputs: audience, goal, four to six actual preferred posts (text/image/source), optional normal-performance comparisons. Search provided/local sources first. If missing, produce a source-request brief and a source-demo practice analysis, not invented current examples. Eden is optional; source captures and local files suffice.

## Execute
1. Preserve each post's author, URL/capture, date, platform, complete available text, image/caption distinction, selection reason and available performance. If only an excerpt is available, name the omitted context.
2. Inventory the observable construction: first reader-facing thought, tension, promise, sequence, example/proof, closing action, visual reading order. Separate analysis from reproduced source text.
3. Derive a reader-level explanation for each move. Mark psychological/causal explanations INFERRED; likes alone cannot verify them.
4. Compare examples to one another, including ordinary posts where supplied. If a breakout ratio is reported, identify metric, comparable age and baseline; missing denominator = unconfirmed breakout.
5. Distill three to seven actionable choices supported by the set. Avoid averaging conflicting voices. Preserve alternatives with use conditions.
6. Produce a compact guide (target one page) with source links and one worked transformation using an owned or explicitly fictional practice input. Keep detailed analysis cold.
7. Handoff guide path, selected structures, source limitations and needed personal input to the studio. No repeated background interview if context already exists.

## Adaptations
| Source | Adaptation |
|---|---|
| Owned successful posts | Retain real wording/metrics and diagnose repeatable construction |
| Other authors | Learn structure; attribute short excerpts and preserve rights boundaries |
| Book/article | Mark cross-platform transfer as a hypothesis; do not call it a LinkedIn winner |

## Output and quality gate
Deliver source table, compact guide, method distinctions and next-input handoff. Must distinguish evidence from inference and retain original authorship. Reject invented examples and inflated breakout claims. Execution prompt: `references/prompts-v2/linkedin-reference-guide.md` — honor its Output Contract.
