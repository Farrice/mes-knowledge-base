# Luke Iha: Copy Blocks & CASH Method (v2.0 — Director's Cut)

## What This Skill Does

This is the **WRITING LAYER** of Luke Iha's system — the building blocks from which every ad, VSL, lead, email, and landing page is constructed, plus the diagnostic loop and composition tools that bind his other 10 skills together. While other Luke skills go deep on strategy (creative-strategy), openings (vsl-leads), mechanisms (million-dollar-mechanisms), and proof depth (proof-mechanisms / proof-ladder), THIS skill owns the **grammar + composition layer**: how the blocks compose, how to diagnose any copy, and how to strengthen any block.

Core systems:
1. **The 6 Copy Blocks (P3C2 + 1)** — Pain, Promise, Proof, Constraints, Curiosity, Conditions — each at full depth, cycled at variable **velocity**.
2. **The Two-Move Diagnostic** — *Does it have all the blocks? Add the missing. Which is weakest? Strengthen via CRAVES.* (How Luke reviews $2,500/mo client copy.)
3. **CRAVES** — universal block strengthener (Clear, Relevant, Accurate, Visual, Expressive, Specific).
4. **The Copy Blocks Equation** — `(Promise × Proof × Curiosity) ÷ Constraints × Conditions` — find the limiting factor.
5. **CASH Method** — Concept × Angle × Style × Hook ideation engine (100+ variations from one product).

## When to Use

- Before writing ANY ad, VSL, email, or landing page → `copy-from-scratch` (build) or `copy-block-audit` (diagnose a draft)
- Copy "feels flat" → usually a curiosity or CRAVES problem → `craves-polish` / `curiosity-engine`
- Can't get past the blank page → `copy-from-scratch`
- Endless ad variations needed → `cash-method-generator`
- An offer underperforms but you can't say why → `copy-blocks-equation-score`
- A hardened belief blocks the sale → `constraint-dissolution`
- A solo draft has plateaued / high stakes / client wants the reasoning visible → `expert-panel-deliberation`
- Copy has all the blocks but doesn't *pull* the reader through → map the feeling arc with `emotional-journey-map`
- Training AI to write copy → the blocks give it structural scaffolding
