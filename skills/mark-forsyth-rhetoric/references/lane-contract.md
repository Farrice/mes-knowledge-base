# Lane Contract — Forsyth, Farnsworth, and the four front doors

**Binding source for how the Enchantment OS coexists with the writing surfaces already live in this
harness.** Written 2026-08-06 at Farrice's instruction: *"execute in a masterful way that enhances and
enriches the system and doesn't conflict."*

The risk this file exists to prevent is not that Forsyth is wrong. It is that a fifth writing surface
quietly starts competing with four working ones, and every future run has to guess which to use.

---

## Why there are two composition front doors, on purpose

`/how-i-write` and `/enchant` both take raw material and return a finished piece. That is deliberate, and it
is the experiment Farrice commissioned.

| | `/how-i-write` | `/enchant` |
|---|---|---|
| **Philosophy** | Orchestra — 3–6 experts at named altitudes, one body-voice owner | Single author — Forsyth's method, alone, end to end |
| **Runs** | architecture → scene → line → truth gate | occasion → prepare-aloud → fast draft → announcer map → run-up edit |
| **Optimises for** | structural soundness, correct expert per altitude | memorability, sound, enchantment |
| **Body voice** | whichever Layer-4 expert holds the pen | Forsyth, always |
| **Risk it carries** | composite mush if lanes double-pick | ornament without a spine |

**They are not redundant; they are a measurement.** The Phase-7 bake-off runs the same brief through both
and banks Farrice's felt verdict. Until that verdict exists, neither is the default — the operator picks,
and the ledger learns. If `/enchant` loses, that is the finding, and it ships.

**The one hard rule:** never run both on the same passage in the same pass. A piece composed by `/enchant`
does not then get Layer 5 of `/how-i-write` applied to it; a piece composed by `/how-i-write` does not get
`/enchant elevate` bolted on. That is a double-picked lane, and the 2026-06-22 bake-off already measured
what it costs — the system scored the multi-engine rebuild 7.25–8.6 while Farrice rated it 3/10.

## Surface ownership

| Surface | Owns | Never touches |
|---|---|---|
| **`/enchant compose`** | End-to-end composition in Forsyth's method: occasion diagnosis, voice establishing shot, announcer mapping, figure deployment, run-up editing, section units that offer the exit and pull on anyway | Multi-expert composition; distribution strategy; market positioning — those route to `/how-i-write` and `/lulu-*` |
| **`/enchant elevate`** | An existing draft's line, sound and voice-texture layer | The draft's structure, thesis or argument. If the spine is wrong, `/enchant` says so and stops — it does not rebuild |
| **`/how-i-write` Layer 5** | The memorable-line altitude inside a composed run. Picks **exactly one** of Farnsworth or Forsyth | Never both. See the split below |
| **`/writers-room`** | Loads `lens-card.md` at card tier; fires `genius.md` only on a diagnostic hit | Never grep-as-load — the 2026-07-27 laundered-half-pass scar |
| **`/high-taste-writing-os`** | Runs the enchantment check as one gate item among many | Does not become a Forsyth persona; high-taste stays an operating wrapper |

## The Layer-5 split — Farnsworth vs Forsyth

Both own "the memorable line." They answer different questions, and the OS must pick one per passage.

| | **Ward Farnsworth** | **Mark Forsyth** |
|---|---|---|
| **Core question** | *How should this sentence sound?* | *What shape does this idea want?* |
| **Owns** | Saxon/Latinate register contrast · the Saxon punch · end-weight engineering · the aphorism forge · device diagnosis · the apprenticeship loop | The memory-receptor catalog · false-memory mechanics · enchantment-vs-efficiency triage · voice as establishing shot · the practice regimen · adynaton/synesthesia/paradox |
| **Calibration** | "If they notice the technique, it's bad technique." Restraint is the master rule | "I've never seen somebody overusing the figures of rhetoric." The ceiling exists; nobody is near it |
| **Choose when** | The line must land as a *punch* — register, end-weight, and a hard final syllable are the problem | The line must be *repeated* — a stranger should misquote the flat version into yours |
| **Test it applies** | Would moving any other word to the end weaken it? | Would a listener "correct" a flat paraphrase into this? |

**Note the calibration conflict and do not average it.** Farnsworth's default is restraint; Forsyth's is
that under-ornamentation is the real risk. That disagreement is real, it is preserved on purpose
(dissent-preserved expert output), and it is exactly why the OS picks one owner per passage rather than
blending them. A passage treated by both will inherit two contradictory ceilings and read as neither.

## Where Forsyth outranks harness defaults (declare, never silently)

Three standing instruments in this repo are built to subtract. Forsyth's method adds. Inside `/enchant`
only, these resolve as follows:

| Instrument | Default behaviour | Inside `/enchant` |
|---|---|---|
| `prose_classifier.py` / AI-slop ban bank | Flag and fix | **Runs and prints as a report.** Never blocks. Its flags appear in the receipt so Farrice can see what was overridden and why |
| Density-over-completeness | Compress | **Suspended when the job is "meant to be kept."** Ecclesiastes compressed to "there is a time for everything" says the same thing and moves nobody |
| Low-cognitive-load message gate | Optimise every clause for instant comprehension | **Suspended for sound and mystery.** "You're not meant to know. The mystery is part of the fun" |

**These suspensions are scoped to `/enchant` and to workflows in this skill.** They do not travel. A
Forsyth-treated line dropped into a client deliverable is still subject to that deliverable's gates.

**What never suspends:** the factual veto, the cost gate, fair-housing and compliance language, and the
source-manifest's UNCONFIRMED list. Enchantment is a licence to shape words, never to invent facts.

## Handoffs (options, never pipeline steps)

- Structure is wrong, not the lines → `/how-i-write` (composed) or `/depth-audit` → `/depth-inject`
- Line needs a *punch*, not a *shape* → `ward-farnsworth-rhetorical-mastery`
- Whole draft needs multi-lens treatment → `/writers-room` (Forsyth fires there as a card)
- Voice profile needed across a body of work, not one opening → `/voice-os`
- Real-world claims present → `fact-verifier` before delivery, always
