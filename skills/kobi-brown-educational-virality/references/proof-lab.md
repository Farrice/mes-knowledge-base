# Behavior Proof Lab

> One weak educational input, transformed into a behavior-changing asset using Kobi Brown's documented mechanics (`../genius.md`), then validated against `anti-slop-aha-gate.md`. Non-space example on purpose: this proves the system is universal, not science-only.

## Input Tested
Weak draft from a leadership/management consultant:

> "Most managers need better 1-on-1s. In this post I explain the five steps to run a great one-on-one: set an agenda, ask about blockers, give feedback, set goals, and follow up."

## Diagnosis
- **Curriculum before curiosity** — opens with a syllabus ("five steps"), not an appetite. Violates Pattern 1 (Vegetable Smuggle): the door should be the hook, not the lesson plan.
- **Hook-on-a-hollow-idea risk** — the "idea" is a generic checklist anyone has seen. Pattern 6 (Core Idea Over Hook): a thin idea is thin no matter how it opens.
- **Borrowed/absent legitimacy** — no proof this consultant has run or fixed real 1-on-1s. Pattern 4: trust is asserted by the byline, not earned.
- **No visual / no mechanism** — "give feedback" is a label, not an observable model. Pattern 9: nothing the reader could redraw.
- **Replaceable author** — an AI could produce this verbatim. Pattern 5 (Commoditization Escape): zero expensive-to-fake layer.
- Anti-slop pre-read: this hits Slop Tells **#1 (replaceable author)** and **#2 (consumed, not changed)** → SLOP until rebuilt.

## Output Produced
Platform: LinkedIn post / short educational script.

Title: `Your worst employees aren't the ones who complain in 1-on-1s. They're the ones who've gone quiet.`

Draft:

Most managers run 1-on-1s like a status meeting. Agenda, blockers, updates, done.

So the meeting that's supposed to build trust ends up auditing output. And the manager walks away thinking it went fine, because nobody pushed back.

Here's the part nobody clocks: trust isn't a state, it's a charge. Picture a battery. Every week of silence, vague feedback, or "we'll circle back" drains it a little. The person doesn't quit the job — they quit the candor first. By the time they go quiet, the battery's been dead for a month.

The five-step checklist isn't wrong. It's just measuring the wrong thing. Agenda, blockers, feedback, goals, follow-up — all of it is plumbing. The actual job of the meeting is one question: **did the battery go up or down this week?**

You can feel it. They volunteered a problem before you asked → up. They agreed too fast → down. They saved the real thing for the hallway after → it's nearly empty.

So before you optimize the agenda, run the read. A perfectly-run 1-on-1 on a dead battery is just a well-documented exit interview you haven't scheduled yet.

## Validation — Anti-Slop / Aha Gate
- **Step 1 (Slop tells):** 0 of 5 now fire. Author is no longer replaceable (lived read), and the reader leaves changed.
- **Step 2 (Cognitive Change ladder):** lands at **Perspective shift (8)** — a manager re-sees a familiar weekly meeting and "quiet" employees differently. Crosses the mandatory aha bar (≥7).
- **Step 3 (Differentiation):** passes the Copy test — the diagnostic reads ("agreed too fast → down") are pattern-recognition from real management, not a promptable list.
- **Accuracy line defined:** stops at the honest mechanism; refuses the milkable hot-take sequence (Pattern 10).
- **Verdict: SIGNAL.** (Not yet BREAKTHROUGH — that needs an uncopyable proof asset + a named thing walked away from; see risk below.)

## Remaining Risk
- **Legitimacy is still implied.** To push toward BREAKTHROUGH, anchor it: one anonymized real case ("a director I coached found three dead batteries on her team she'd rated 'fine'"). Run `/legitimacy-ladder`.
- **The battery analogy must stay accurate.** If pushed to "measure trust 1-10," it becomes false precision — keep it a directional read, not a metric. Run `/accuracy-without-clickbait` before any quantified version.
- **Format fit:** as a short video, lead on the visible battery draining; don't narrate the checklist. Run `/shorts-to-longform-loop` if expanding into a flagship long-form on team trust.
