# Educational Virality Rubric

Score each dimension from 1 to 10.

| Dimension | Failure Signal | Strong Signal | 10/10 Signal |
|---|---|---|---|
| Curiosity Doorway | Starts with topic label | Starts with a question or tension | Audience needs the answer now |
| Learning Payoff | Generic tips | Clear mechanism | Audience can use or retell the idea |
| Accuracy | Overclaims or vague claims | Bounded and fair | Verified, precise, and still magnetic |
| Legitimacy | "Trust me" energy | Relevant proof or process | Trust earned through evidence, access, and restraint |
| Visualizability | Abstract explanation only | Example or analogy | Mechanism becomes observable |
| Stakes | Interesting but optional | Clear reason to care | Personal, professional, or worldview consequence |
| Compression | Dense or thin | Clean sequence | Feels simple without losing truth |
| Platform Fit | Same content everywhere | Adapted structure | Native pacing with intact substance |
| Authority Lift | Informational only | Shows expertise | Creates durable demand for deeper work |
| Share/Saves Logic | Nice to know | Useful or surprising | People save/share to think better or look smart |

## Pass Bar
- Minimum average: 7.
- Accuracy, legitimacy, and learning payoff must each be 7 or higher.
- If accuracy is below 7, run `/accuracy-without-clickbait`.
- If curiosity is below 7, run `/curiosity-clarity-script`.
- If authority lift is below 7, run `/legitimacy-ladder`.
