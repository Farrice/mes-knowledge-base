## Core Pattern

Novelty is a feeling to engineer, not a fact to possess. The reusable pattern is:

1. Reveal a new aspect of an old or boring thing.
2. Map the reveal to the audience's wanted outcome.
3. Contrast it against the audience's held belief.
4. Add urgency only when the time window is real.
5. Use the closest honest proof rung available.
6. Protect the illusion by removing hedges, mascot reveals, and salesy tone.

Use this as a navigation card, not as a replacement for `../genius.md`.
