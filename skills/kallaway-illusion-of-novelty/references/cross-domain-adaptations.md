# Cross-Domain Adaptations — The Master Key

The five components are universal; the *execution* is not (`../genius.md` Apex Move 2: "the framework fits one-size-fits-all, the execution will not"). This file is the translation layer. Pick the asset row-set, read down the five component cells, and you have a deployment spec for that format in any vertical.

Load `../genius.md` first if not hot — that file owns the *why*; this file owns the *where it lands and how it breaks*. Component definitions are not re-explained here; only their per-asset manifestation.

The five components (rows) in canonical order: **New Reveal + Outcome Mapping · Contrast Framing · Urgency (optional) · Bullseye Proof · Protect the Illusion.** The two halves of Protect (Don't-Show-the-Mascot, Gossip-Whisperer) are split where the format distinguishes them.

> Honesty spine, every asset: the illusion is of NOVELTY only. The reveal must be a real angle, the urgency window must be real, the proof must be real. Never fabricate to fill a cell.

---

## How to read this file

1. Run the `../genius.md` Decision Framework first (topic old/new, held belief, wanted outcome, honest urgency window, highest honest proof rung, hedge-risk points).
2. Find your asset's block below. Each block opens with a **profile line** (where the densest hook goes · length/structure norm · the most common way the illusion breaks in this format) then a 5-row table.
3. Build top-to-bottom. Hook zone carries components 1–3; body carries 4–5 (`../genius.md` Pattern 10).
4. All templates: **vary, never verbatim.** Kallaway's own warning — "don't 1,000 people copy those exact things."

## Per-asset deployment blocks

### 1 — Short-form video script (Reels / TikTok / Shorts)
**Densest hook:** spoken in the first 1–2 seconds, with an on-screen text twin. **Norms:** 20–45s, one idea, vertical, captions burned in. **Most common break:** the creator hedges on camera ("I mean this isn't groundbreaking but…") or shifts into ad-read voice — town-crier register the instant a CTA appears.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | First sentence out of the mouth = reveal + outcome, mirrored as on-screen text so a muted scroller reads it. Lead with the *aspect*, not the topic noun. |
| Contrast Framing | Seconds 2–6, said as a turn: "you've been told X… turns out Y." Visual cut on the word "turns out" reinforces the gap. |
| Urgency | A single spoken clause if real ("this only got approved last month"). No countdown graphics — that reads as a sale. |
| Bullseye Proof | One viewer-mimic mini-story shown, not listed. B-roll of "someone like you" getting the result beats a stat card. If you're the demo, show your own before/after. |
| Protect the Illusion | Even, low-key delivery; cut every "probably know this." Gossip-whisperer = conversational VO, never a hype shout. |

*Vertical swap example (gutter cleaning):* "Your gutters aren't clogged with leaves — they're clogged with shingle grit, and that's what's rotting your fascia. You've been told to clean them every fall; the grit builds year-round and you never see it. We just did a 2-year-no-clean house — pulled out a coffee can of asphalt sand, owner had no idea." Reveal (grit not leaves) → outcome (stop fascia rot) → contrast (fall-cleaning belief) → bullseye (a house like theirs).

### 2 — LinkedIn post
**Densest hook:** line 1 above the "see more" fold; outcome by line 2. **Norms:** 120–250 words, short lines, white space, one insight, no link in body. **Most common break:** logo-dropping and credential-flexing (town crier), or the "this is obvious to most of you, but…" false-modesty opener — both take the mascot's head off.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Line 1 is the reveal as a stated finding; line 2 names the outcome the feed-reader wants. The fold is your hook real-estate — both jobs done before "see more." |
| Contrast Framing | Lines 3–4: name the held industry belief, then flip it. "Everyone optimizes X. The teams that win quietly do Y." |
| Urgency | One dated clause mid-post if real ("the rule changed in Q1"). Evergreen posts skip it. |
| Bullseye Proof | One named, relatable mini-case ("a 30-person SaaS I worked with…"), reader-shaped — not a wall of client logos. |
| Protect the Illusion | Commit. No "I'm no expert," no "you've heard this." Whisper register = plainspoken, slightly conspiratorial, never announce-y. |

### 3 — X/Twitter thread
**Densest hook:** tweet 1 = reveal + outcome with zero link and zero thread-emoji bait. **Norms:** 5–12 tweets, one beat per tweet, the contrast gets its own tweet for the pause. **Most common break:** the self-deprecating quote-tweet, the "old news to some" reply, or a final "thanks for reading 🙏 follow me" beg that snaps the secret-sharing spell.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Tweet 1 carries both, standalone-readable (it'll be screenshotted). No "a thread 🧵" as the value. |
| Contrast Framing | Tweet 2 states the held belief flatly; tweet 3 flips it. Splitting them across two tweets *is* the gap — the scroll between them is the freeze. |
| Urgency | Optional tweet, only on a real window, with the source linked. |
| Bullseye Proof | Tweets 4–5: a "someone exactly like you" story or your own receipts (screenshot, number). Proximity over authority. |
| Protect the Illusion | No "obviously this is just X" tweet. The mascot-reveal in threads is usually the humble-brag disclaimer — cut it. |

### 4 — Email
**Densest hook:** subject line = the reveal; preview text = the outcome (two jobs, two fields). **Norms:** one idea, scannable, single primary CTA. **Most common break:** a P.S. or sign-off that hedges ("honestly nothing revolutionary, just a reminder"), or a subject in all-caps sale voice.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Subject is the reveal, preview text the outcome. The first body line restates the reveal so the open isn't wasted. |
| Contrast Framing | First body paragraph names the belief the subscriber holds, then opens the gap. The email *is* a contrast machine — old-you vs new-you. |
| Urgency | A real "why now" line (a genuine cohort close, a real price move, a dated regulation). Fabricated deadlines here are the fastest unsubscribe. |
| Bullseye Proof | One vivid story of a subscriber-twin in the body, in their language. Pair with one number if honest. |
| Protect the Illusion | No hedging P.S., no "you probably already know this." Whisper = write like a forwarded note to one person, not a broadcast. |

### 5 — Cold DM
**Densest hook:** line 1, personalized to *them* — the reveal framed as an observation about their specific situation. **Norms:** 2–4 sentences, no link in first message, reads human. **Most common break:** copy-paste "you've probably seen this go around" openers, or instant pitch register — both scream mass-send and trip sales-resistance immediately.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Line 1 ties the reveal to something true about *their* account/business. Reveal-as-observation, outcome implied to their goal. |
| Contrast Framing | Line 2 contrasts their likely current assumption ("most [their role] still do X; the ones pulling ahead do Y"). |
| Urgency | Usually skip — fake urgency in a DM is the single loudest sales tell. Use only if genuinely time-boxed *to them* (a deadline they actually have). |
| Bullseye Proof | "We did exactly this for [a named peer who looks like them]." The proof must resemble *them*, or it reads as spray-and-pray. |
| Protect the Illusion | No "you've probably seen this," no link-dump. Gossip-whisperer = one operator quietly telling another, not a vendor opening. |

### 6 — Ad / VSL
**Densest hook:** first 3–8 seconds (video) / first line (static) = reveal + outcome + contrast compressed. **Norms:** hook → contrast → mechanism → proof → CTA; VSLs run long but the first 15s decide watch-through. **Most common break:** the entire format pulls toward town-crier; the moment the VO hits hype cadence or stacks exclamation energy, trust collapses regardless of the offer. Plus platform-compliance: disclosed scarcity must be true (FTC).

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Opening frames: reveal + the outcome the avatar wants, on screen and in VO simultaneously. |
| Contrast Framing | A literal old-way / new-way visual split or "they told you X" voiceover. The mechanism reveal lives here. |
| Urgency | A disclosed-scarcity beat that is *real and provable* (genuine cohort cap, real expiring bonus). Compliance and honesty are the same constraint here. |
| Bullseye Proof | On-camera testimonial that mirrors the avatar (same age/look/problem). The in-demo customer is the bullseye; ladder down to aggregate only after. |
| Protect the Illusion | This is the hardest format to keep whispering. Coach the VO down from billboard to secret-sharing. No "BUT WAIT." The whisper out-converts the shout. |

### 7 — Sales / Landing page
**Densest hook:** H1 = reveal, sub-H1 = outcome, both above the fold. **Norms:** F-pattern scan, hero → contrast → proof stack → offer → CTA, repeated CTAs. **Most common break:** "as everyone knows / industry-leading / revolutionary" filler copy (mascot reveal by cliché), or a proof wall of generic logos that resembles no specific reader.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | H1 carries the reveal as a specific claim; sub-H1 the outcome. The above-fold is the hook — both jobs visible without scroll. |
| Contrast Framing | An explicit "the old way vs this" block near the top. Name the belief the visitor walked in with, then break it. |
| Urgency | Only real levers: genuine inventory, a real cohort close, a real dated price change. Fake countdown timers are the canonical trust-killer. |
| Bullseye Proof | Hero proof = an avatar-twin case (photo + story that looks like the visitor), *then* ladder down to aggregate stats. Order matters: closest-to-reader first. |
| Protect the Illusion | Strip "revolutionary," "as everyone knows," and hedge copy. Commit to the frame in the body voice; keep CTA confident, not shouty. |

### 8 — Long-form article / blog
**Densest hook:** title + dek (deck/standfirst); first 2 sentences re-land the reveal. **Norms:** 800–2,000 words, scannable subheads, the contrast becomes the first full section. **Most common break:** the throat-clearing intro and the "of course, this is really just [old concept] that's existed forever" aside that an academic-leaning writer adds to sound balanced — that's the mascot, head off.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Title = reveal, dek = outcome. Opening lines restate so the click pays off in two sentences, not three paragraphs. |
| Contrast Framing | The first section *is* the dismantled belief: state what the reader was told, show the gap, hold the gap open as the article's spine. |
| Urgency | A "what changed and when" context paragraph if there's a real shift; evergreen pieces skip it. |
| Bullseye Proof | A case vignette resembling the reader, woven mid-article; third-party studies support but never lead. |
| Protect the Illusion | Delete the "this is nothing new" balancing aside. Whisper in prose = confident, plainspoken, the buried-lede told like a confidence. |

### 9 — YouTube long-form
**Densest hook:** title + thumbnail promise; first 15 seconds spoken re-deliver reveal + outcome. **Norms:** 8–20 min, retention-shaped, open loops, the contrast sets up the through-line. **Most common break:** breaking the spell with a self-aware "honestly this is just basic X" mid-roll — *unless* you're doing the deliberate meta-reveal, which is the one format where breaking the mascot rule is the strongest proof (`../genius.md` Apex Move 1).

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | Title + thumbnail carry it for the click; first 15s of VO re-land both before any intro. |
| Contrast Framing | Seconds 15–45 establish the held belief the whole video will break; it becomes the spine the chapters hang on. |
| Urgency | Mentioned once, sourced, if real. Long-form tolerates a "here's what just changed" beat better than short-form. |
| Bullseye Proof | A built, on-screen case study or live demo — the format's superpower. The viewer can *watch* the result on someone like them. |
| Protect the Illusion | Commit throughout. The sanctioned exception: a closing fourth-wall reveal ("the name I made up") that turns the whole video into one lived bullseye proof. Use only as a deliberate finale, never as accidental mid-roll hedging. |

### 10 — Ghostwritten thought-leadership (exec byline)
**Densest hook:** opening anecdote or observation that *implies* the reveal — the byline persona never announces a "framework." **Norms:** essay register, narrative-led, authority through specificity, no marketing seams. **Most common break:** naming the mechanic ("I use a technique called…") or slipping into vendor voice — either exposes the ghostwriting and the manufactured frame at once.

| Component | Manifestation |
|---|---|
| New Reveal + Outcome | An opening scene or observation from the executive's world that *carries* the reveal implicitly; the outcome shows up as stakes, not a promise. |
| Contrast Framing | Threaded through the narrative as "what we believed / what we found," never labeled as a contrast move. The gap is dramatized, not announced. |
| Urgency | Tied to a real market or regulatory shift, stated with restraint — the senior register under-claims by default. |
| Bullseye Proof | A client, team, or peer figure the target reader self-identifies with, rendered specifically enough to feel like *their* world. |
| Protect the Illusion | Never name the mechanic; the author *embodies* it. The whisper here is gravitas — quiet authority, zero sales seams, no "as I always say" tell. |

## Cross-cutting deployment rules (true in every cell)

- **Hook density scales down, not away.** Even a 3-sentence DM packs reveal + outcome + contrast. The denser the format constraint, the more the opener multitasks (`../genius.md` Pattern 10 / Hidden Knowledge: "the hook is doing 2–4 jobs").
- **Proof always climbs toward the reader, never toward prestige.** Across all ten assets, an avatar-twin beats an authoritative aggregate. Bullseye first; ladder down only after (`../genius.md` Pattern 6).
- **Urgency is the universal skip.** If the window isn't real for *this* asset and *this* moment, omitting it is correct in every format. Bolted-on deadlines are the most format-portable way to burn trust.
- **The whisper is medium-specific in surface, identical in intent.** Lowercase energy in text, conversational VO in video, gravitas in exec bylines, restraint in DMs — all the same secret-sharing register, never the billboard.
- **The mascot reveal mutates by format but is always self-inflicted.** Hedge-in-VO (video), humble-brag disclaimer (thread/post), "nothing new really" P.S. (email), academic balancing aside (article), naming-the-mechanic (ghostwriting). Audiences rarely catch you; you hand them the head (`../genius.md` Pattern 8). The lone exception is the deliberate YouTube/long-form meta-finale.

## Quality Gate

This reference passes the `../genius.md` rubric when:
- **Domain Fit (#9):** every cell is asset-specific, not generic template-slop — names the hook zone, the contrast staging, the proof shape, the urgency norm, and the whisper move *for that medium*.
- **Hook Density (#2):** every asset block places the densest reveal+outcome in that format's true hook real-estate (first 1–2s, the fold, tweet 1, subject line, H1, etc.).
- **Trust-Ladder Height (#5):** every Bullseye row routes to avatar-proximity, never to prestige-by-default.
- **Urgency Honesty (#4) + Whisper Test (#7) + Illusion Intact (#6):** each block names the format-specific fake-urgency trap, the salesy register to avoid, and the self-inflicted mascot reveal that breaks it.
- **Honesty Spine (#8 — non-negotiable):** the illusion is of NOVELTY only. In no asset, no vertical, no cell may an agent fabricate a reveal, an urgency window, or a proof point to fill the slot. Manufactured *angle*, real *facts* — always.

**Self-check (one line):** Could a sub-agent open any single block, in a vertical they've never touched, and produce on-format output that earns Relevant + Novel + Interesting without inventing a fact? If not, the cell is too generic.
