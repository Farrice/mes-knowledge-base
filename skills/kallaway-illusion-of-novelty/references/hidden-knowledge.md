# Hidden Knowledge

The hidden knowledge for this skill is captured in `../genius.md`,
`illusion-of-novelty-doc.md`, `source-quotes.md`, and the component-specific
references. This file exists as the repository-standard compatibility surface so
validators and agents can find the expected path.

## Non-Obvious Operating Notes

- "New" is mostly contrast, naming, recency, and outcome mapping, not actual
  invention.
- Urgency is optional. Fake urgency is worse than no urgency.
- Proof should move closer to the viewer's life before it moves toward prestige.
- The most common failure is self-sabotage: explaining that the new frame is
  "really just" an old idea breaks the illusion.
- The strongest teaching move is recursive: run the framework on the audience,
  then reveal the mechanism as proof only when the piece is explicitly teaching
  the framework.

Load `../genius.md` for full examples and the complete operating model.
