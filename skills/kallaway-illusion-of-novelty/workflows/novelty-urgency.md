# /novelty-urgency — The Turbo Button + Fake-Urgency Detector

Produces either a set of honest urgency lines (when a genuine timeliness window exists) or an explicit, reasoned SKIP recommendation, plus a fake-urgency scrub of any draft you feed it. Fire this after the New Reveal + Contrast are set (Steps 1–2 of `../genius.md`) and before proof; or run it standalone to audit an existing piece for manufactured scarcity.

This is the **one component you are allowed to skip**. The skill here is restraint as much as application — four real components beat five with one fake.

## Pre-Flight Gate

Load `../genius.md` if it is not already hot. Then answer the Decision-Framework questions this workflow turns on:

- **Is there an HONEST urgency window?** (Decision Framework Q4.) Something that *just happened* or is *about to stop happening*, genuinely tied to this topic? If you can't point to a concrete event, the answer is no.
- **Is this piece evergreen or time-anchored?** Evergreen content usually skips urgency (recency bias has a half-life — see Hidden Knowledge in `../genius.md`).
- **Where am I tempted to fabricate a deadline?** (Decision Framework Q6, applied to time.) Pre-identify the bolted-on-deadline temptation so the detector below catches it.

If you do not yet have a sharp New Reveal and Contrast, stop and run `./novelty-reveal.md` and `./novelty-contrast.md` first — urgency layered on a weak reveal amplifies nothing.

## Execution

Urgency is a **timeliness red-alert**: *pay attention now, because something just changed or is about to change*. It works on **recency bias** — the brain prioritizes recent things in case they force it to update its model. That power is exactly why a fake window is so toxic: the audience's recency radar is sensitive, and a manufactured one reads as a sale and burns all trust at once.

### 1 — Honest-Window Audit

Look for a real lever in five places. The window must be **genuinely tied to this specific topic**, not the niche in general.

| Window type | What qualifies | What does NOT qualify (fabrication risk) |
|---|---|---|
| **Just happened** | A study, report, or finding published recently; a new tool/feature shipped; a product or model dropped | "Experts have always said…" reframed as breaking news |
| **About to stop** | A policy/rate/rule changing on a real, citable date; a benefit or program sunsetting; an enrollment or filing deadline set by an external body | An invented "this offer ends Friday" with no external cause |
| **Closing scarcity** | A real, finite quantity or capacity; a genuinely limited cohort; a supply constraint you can name | "Only a few spots left" with no actual cap |
| **Training rarity** | Almost no one is trained/certified on a method yet; the technique is genuinely early-adoption | "Nobody knows this" when it is common knowledge in the field |
| **Seasonal / cyclical reality** | A real recurring window (tax season, open enrollment, a weather/maintenance cycle) that is open *now* | Manufacturing seasonality where none exists |

Run each candidate through one test: **could a skeptical viewer verify the window is real if they looked?** If yes, it is a usable lever. If the only support is your assertion, it fails the audit.

Output of this step: a one-line statement of the window and its type, or the verdict "no honest window."

### 2 — If YES: Write the Urgency Lines

Compress the verified window into 1 line (occasionally 2). Stay in the Gossip Whisperer register — *let them in on the timing*, do not announce it from a billboard. Templates below are **starting shapes; vary, never verbatim** (mass-copying the exact phrasing is itself a tell):

- "This only became possible a couple of [days/weeks] ago."
- "For years this didn't work — until [the one change]."
- "This window won't stay open forever."
- "Barely anyone is trained on this yet, so you have to go looking."
- "[External thing] changes on [real date] — after that, the old way is back."

**Placement:** drop the urgency line right after the contrast, before or braided into the reveal of the outcome. Recency-bias lift comes from it sitting *near the top*, not buried in the body.

**Magnitude discipline:** under-claim the volume, let the substance carry weight. "Not that many people know this yet" beats "THIS IS HUGE — ACT NOW." The whisper outperforms the shout every time, and it is not close (rubric criterion 7).

### 3 — If NO: Recommend SKIP (and say so explicitly)

A missing window is **not a gap to fill — it is a correct answer.** Return an explicit SKIP with the one-line reason: *"No honest urgency window for this topic; the four other components carry it. Adding a fake deadline would cap the piece at ≤4 on Urgency Honesty (rubric 4) and risk a trust-burn."*

Do not soften the skip into a half-fake hint ("it's kind of timely…"). Restraint here is a skill, not a deficiency. A piece with four real components beats one with five where the fifth is invented.

### 4 — Fake-Urgency Detector (scan a provided draft)

When handed an existing draft, scan line-by-line and flag every urgency claim that reality does not support. For each flag, name the offense and recommend the fix.

| Tell | What it looks like | Verdict / fix |
|---|---|---|
| **Phantom deadline** | "Ends Friday" / "today only" with no external cause | Strip it, or replace with a real window from Step 1; if none, remove |
| **Manufactured scarcity** | "Only X spots/units left" with no actual cap | Cut unless the limit is real and nameable |
| **Stale recency** | "Just dropped" on something months/years old | Remove or re-anchor to a current real event (half-life expired) |
| **Borrowed urgency** | A real event used to imply a window it doesn't create | Sever the false link; keep the event only where it honestly applies |
| **Generic FOMO** | "Don't miss out" / "everyone's doing this" with no time basis | Delete — this is mood, not a window |
| **Town-Crier amplifier** | "ACT NOW," all-caps, exclamation stacks | Rewrite to whisper, or cut; salesy register caps the piece at 6 (rubric 7) |

Each flagged item is, by rubric criterion 4, an **automatic ≤4 on Urgency Honesty** — meaning even one un-fixed fake-urgency line drags the whole piece. Output: a flag list (line → tell → recommended action), then a clean re-write or an explicit "remove urgency entirely" call.

### 5 — Recency Half-Life Note

Urgency **decays.** "Just dropped yesterday" is false in three weeks. Two consequences:

- **Evergreen pieces usually skip urgency** by default. If the piece is meant to run for months, leaning on a fresh-window line bakes in a future lie.
- **Time-anchored pieces need a refresh or rotation plan.** If a window-based piece will keep circulating, either schedule a line swap to a still-open window or strip the urgency before it ages into a tell.

Return a one-line shelf-life verdict with any YES output: *"Window valid through [date/duration]; refresh or remove after."*

### Worked Mini-Example — Tax Prep (one WITH a window, one WITHOUT)

Boring topic: tax preparation. Same expert, two pieces, opposite urgency calls.

**Piece A — real window (USE urgency).**
A genuine rule change exists: a new filing requirement or credit takes effect for the current tax year, with a hard IRS deadline.
- Reveal + Contrast (Steps 1–2, already set): "You've been filing the same way for a decade. That approach now leaves a credit on the table that didn't exist last year."
- **Urgency (this workflow):** *"This only opened up for this filing year — and it closes the day the deadline passes. Most preparers haven't updated their checklists for it yet."*
  - Window type: *just happened* (rule change) + *training rarity* (preparers not yet updated). Both verifiable.
  - Half-life: valid through this tax season only — flag for removal next year.
- Verdict: USE. Honest, dated, whispered.

**Piece B — no window (correct SKIP).**
Topic: the perennial "which receipts to keep for deductions." Nothing changed; no deadline beyond the standard one that everyone already knows.
- Reveal + Contrast: "You think you need a shoebox of every receipt. For most filers, the category that actually moves your return is the one you're not tracking."
- **Urgency check:** is anything *just happening* or *about to stop*? No. The standard April deadline is common knowledge, not a fresh lever — leaning on it would be borrowed urgency.
- Verdict: **SKIP.** Return: *"No honest urgency window; the reveal + contrast + bullseye proof carry it. Adding 'file before it's too late' would be generic FOMO and read as a sale."* Then move to proof (`./novelty-proof.md`).

The discipline the example demonstrates: identical confidence in *using* the window and in *refusing* to fake one.

## Content-Type Adaptations

How this workflow's output changes per asset. Urgency lives at the **top of attention** everywhere; what shifts is its weight, durability, and how visibly the window is dated.

| Asset | How the urgency output adapts |
|---|---|
| **Short-form video script** | One spoken urgency beat in the first ~3 seconds, braided into the hook; whispered delivery. Highest half-life risk — if the clip is evergreen and re-circulates, prefer SKIP over a "just dropped" line that ages on-screen. |
| **LinkedIn post** | Urgency as a single early line, framed around a real industry shift or change date, not a sales clock. B2B audiences punish manufactured scarcity hardest — lean toward SKIP unless a genuine market/regulatory window exists. |
| **X/Twitter thread** | Urgency belongs in the hook tweet only; do not re-trigger it down the thread. Real-time platform — a true "this changed today" lever overperforms here, but stale recency is caught fast. Pin the window to a citable event. |
| **Email** | Urgency can extend to a real subject-line window ("rule changes [date]") and an honest send-time hook. The classic abuse zone — every phantom "ends tonight" trains the list to ignore you. Only date-anchor when the date is externally real. |
| **Ad / VSL** | Highest fabrication temptation and highest cost. Any countdown or scarcity claim must map to a real cap, cohort, or external deadline — a fake one is both a trust-burn and a compliance exposure. If no honest window, run the VSL on the other four components. |
| **Sales / landing page** | Scarcity widgets (seats, units, timers) must reflect real inventory or a real close date. A perpetually-resetting timer is the canonical fake-urgency tell; the detector should flag it for removal or replacement with true limits. |
| **Long-form article** | Usually evergreen → default SKIP. If the piece is pegged to a current event, date the window explicitly in-text ("as of [month/year]") so the recency claim ages honestly instead of becoming a silent lie. |
| **Ghostwritten thought-leadership** | Urgency drawn from a genuine shift the principal is early to ("for years this didn't work in our field, until [change]") — training-rarity framing fits authority voice. Never a deadline; the credibility cost of one fake window on a named expert is severe. |

## Output Requirements

Return one of two structured artifacts:

**If a window exists (YES):**
1. **Window statement** — one line: the verified event + its type (just-happened / about-to-stop / closing-scarcity / training-rarity / seasonal).
2. **Verification note** — how a skeptic could confirm it.
3. **Urgency line(s)** — 1–2 lines, varied from templates, in Gossip Whisperer register, with placement note.
4. **Half-life verdict** — valid-through date/duration + refresh-or-remove instruction.

**If no window exists (SKIP):**
1. **SKIP verdict** with the one-line reason.
2. **Confirmation** that the remaining four components carry the piece.

**If auditing a provided draft (detector run):**
1. **Flag list** — line → tell → recommended action, per the Step 4 table.
2. **Clean rewrite** of any salvageable line, or an explicit "remove urgency entirely" call.

## Quality Gate

Cite and pass these `../genius.md` rubric criteria and anti-patterns:

- **Criterion 4 (Urgency Honesty)** — any fake/bolted-on urgency = automatic ≤4. This workflow exists to make that score impossible to earn by accident.
- **Criterion 7 (Whisper Test)** — Town-Crier / exclamation-point urgency caps the piece at 6. Lines must whisper the timing.
- **Genius pattern 7 (honesty on three axes)** — urgency is one of the three things you must never fake (alongside the reveal and the proof).
- **Anti-patterns checked:** fake urgency / bolted-on deadlines; perpetual-reset timers; stale recency past its half-life; generic FOMO with no time basis.

**Honesty Spine (non-negotiable):** the illusion is of NOVELTY only. The *window itself must be real* — a genuine event, a true date, a real scarcity. Manufacture the *feeling* of timeliness around a real lever; never invent the lever. A fabricated window fails the Honesty Spine outright and is a trust-burn that no amount of craft offsets.

**One-line self-check:** *Could a skeptical viewer verify this window is real — and if there is no real window, did I recommend SKIP instead of inventing one?*
