# Workflow: Long-Form Explainer (monthly)

**Produces**: one long-form piece (video script, newsletter edition, or article) on the Proof → Principles → Process spine, closing ONE named awareness gap, ending in a lead-form CTA.

## Load Context

1. Read `../genius.md` (mandatory) — especially patterns 6, 7 and Hidden Knowledge 2, 4.
2. Read the SLL System Map: pick the proof story and the ONE gap this piece closes from the gap register.
3. **Voice layer (binding)** if Farrice-named: VOICE-CARD.md + dial. Platform arc rules: `_active/farrice-brand/voice/PLATFORM-NARRATIVE-CARD.md`.

## Steps

1. **Open on proof.** The proof story (or statistic/research) leads — "a story that proves you know what you're talking about." Specific and checkable ("20 kilos", "2M to 5M in under 2 years"), never fogged. Claims quarantine: verify or attribute.
2. **Extract the principles** — the 3-5 things that made the proof story possible. These are the teachable spine, not tips.
3. **Show the process** — how the result is actually delivered or adopted (service delivery, software onboarding, product use, store visit, program participation, donation journey, or internal rollout). This is where the reader sees what the next commitment really involves.
4. **Close the gap, step-by-step.** "Don't assume they're mind readers — explain step-by-step how something is done." The reader should finish ABLE to see the path, and wanting the guide.
5. **CTA to the lead form** — one form, one action, framed as the natural next step for whoever wants the result done with you.
6. **Pin it.** The piece becomes the stable converter short-form bridges point to for the month. Note the pin location in the deliverable.
7. Model check: the source video itself is the demonstration (proof: $1,500/hr + 7 startups → principles: era map → process: SLL → CTA: workshop). Compare structure before shipping.

Output step — Execution prompt: `references/prompts-v2/sll-long-form-explainer.md` — honor its Output Contract.

## Output Schema

```
# Long-Form Explainer — [Business] — [month]
Gap being closed: [one sentence — the awareness/understanding gap]
## Piece (full text/script)
   [PROOF story open → PRINCIPLES (3-5, named) → PROCESS → step-by-step gap close → lead-form CTA]
## Distribution note (pin location + which short-form bridges point here)
```

## Quality Gate

- [ ] Opens on proof, not on throat-clearing or "in this video"
- [ ] Exactly 3-5 named principles, each traceable to the proof story
- [ ] Process section shows real engagement mechanics, not "DM me"
- [ ] ONE gap named and actually closed step-by-step
- [ ] Single CTA to a live lead form; pin plan stated
- [ ] Proof claims verified or attributed (Factual Grounding gate)
