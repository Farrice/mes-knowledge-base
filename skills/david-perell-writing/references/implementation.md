## Safe Stop States

| State | Meaning | Next action |
|---|---|---|
| `HOLD` | Required evidence, fit, or decision is missing | Name the missing field or route |
| `EXPIRED CURRENT` | Signal window has passed | Restore evergreen fallback |
| `NO EVENT` | No public rep or market event occurred | Return protocol, never conclusions |
| `NO PERMISSION` | Publication or external action was not authorized | Prepare locally only |
| `UNTESTED EFFECT` | Artifact exists without outcome evidence | Do not claim reach, conversion, sales, or revenue |
| `INSUFFICIENT EVIDENCE` | Bottleneck cannot be diagnosed honestly | Request the smallest discriminating evidence |

## Preservation Rules

The timely shell may change the entrance but not the locked thesis, claim set, evidence, or conclusion. Placeful edits may use only supplied facts. Portfolio allocations remain qualitative unless the user supplies numbers. All response analysis separates execution, current, reach, audience fit, conversion, and revenue.
