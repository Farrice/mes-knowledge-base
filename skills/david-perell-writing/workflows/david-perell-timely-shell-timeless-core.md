# Timely Shell, Timeless Core

## Pre-Flight Gate

Read `genius.md`, `references/implementation.md`, and the workflow 08 receipt. Require `Decision: ROUTE CURRENT`, `Current state: ACTIVE`, a locked thesis and claim set, current source and date, audience connection, expiry, and distortion constraints. Missing evidence returns `HOLD`; an expired signal returns `EXPIRED CURRENT` plus the evergreen fallback. This workflow does not research a current or produce a finished platform post. When text ships under Farrice's name, load `_active/farrice-brand/voice/VOICE-CARD.md` and declare the dial mode.

## Input Required

1. Workflow 08 Current Fit Receipt.
2. Locked thesis, supported claims, evidence, conclusion, and reader outcome.
3. Validated current packet with source, date, connection, uncertainty, and expiry.
4. Audience and distortion constraints.
5. Optional target-platform handoff.

## Procedure

### 1. Create the Core Lock

Freeze thesis, factual claims, certainty, causal logic, evidence, conclusion, reader outcome, and forbidden semantic changes.

### 2. Map the Why-Now Connection

State what the current makes newly salient, why the audience recognizes the connection, and what the current does not prove.

### 3. Generate Three Shells

Create `LOW CURRENT`, `MEDIUM CURRENT`, and `HIGH CURRENT` frames. Each contains an opening, a why-now line, and a bridge back to the invariant idea. The labels describe framing intensity, not a claim about performance.

### 4. Compare and Reject Drift

Compare each shell with the Core Lock across thesis, claims, certainty, causality, evidence, and conclusion. Reject a shell that changes any immutable element or needs an unsupported current fact.

### 5. Select One Branch

Choose one shell and explain why its intensity fits the audience and expiry. Keep other passing shells as unblended alternatives.

### 6. Define Expiry Behavior

Name what must be removed or replaced after expiry and provide a complete evergreen fallback.

### 7. Prepare the Handoff

Platform owners receive only the selected shell, Core Lock, expiry, and immutable-field list. They may format but may not change the thesis.
