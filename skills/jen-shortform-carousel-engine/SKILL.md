# JEN SHORT-FORM CAROUSEL ENGINE
Research → Plan → Scripts → Branded Carousels. Content is never invented — it is the documented answer to what LA buyers, sellers, and relocators are searching RIGHT NOW. Design is the last step, not the first. Every output is for Jen (@realestatewithjing) or a named team member via their overlay brain, in her locked brand system, fair-housing screened. Practitioner mode: produce finished deliverables, never advice. Save each stage's output as a file — it is the next stage's input; never skip upstream stages.

## Trigger
Any short-form/Instagram content request for Jen or her team. Commands: /sf-research [market], /sf-plan, /sf-scripts [videos], /sf-carousels [batch], /sf-full-run [market] (whole pipeline, pausing only at the carousel approval gate).

## Steps

### Stage 1 — SHORT-FORM RESEARCH (/sf-research)
Load the agent's brain first (run AI Brain Builder if missing). Research live demand for the given LA sub-market across Google/YouTube search suggestions and People-also-ask, Reddit (r/LosAngeles, r/AskLosAngeles, neighborhood subs), Facebook/Nextdoor themes, LA Times/LAist housing coverage, Zillow/Redfin trends, and current-events triggers (rates, insurance, new construction). Output a Demand Report with four buckets — BUYER SEARCHES, SELLER SEARCHES, RELOCATION SEARCHES, and exactly 5 ranked QUESTIONS NOBODY IS ANSWERING — where every entry carries the three-field pattern: exact phrase (verbatim style), evidence (where/how often observed), the worry (the underlying fear, written in the person's voice), plus a LOW/MED/HIGH difficulty rating. Flag top 3 items PRODUCE FIRST. Zero invented demand: every phrase traces to an observed source.

### Stage 2 — VIDEO PLAN (/sf-plan)
Convert the Demand Report into a 4-week, 20-video Production Calendar (Mon–Fri). Theme each week; sequence inside weeks (Mon = strongest hook, Wed = highest-save educational, Fri = story/timely). Each entry: number + working title, source demand (phrase + worry carried forward), format, written-out hook line, 3–5 beat outline, one CTA (rotated across the week; comment-keyword CTAs get a named keyword), recording note (location/props/minutes), and a ★ VISUAL flag for carousel-worthy ideas (target ≥10 of 20; test: could this live as 5–7 slides, one idea per slide?). Include a FILM THESE THREE FIRST starter set with a same-day batch-recording micro-plan, and a batch-filming appendix grouping by location so the month shoots in 2–3 sessions. Time-expiring hooks break the theming and slot into the next open Monday.

### Stage 3 — SCRIPT PACK (/sf-scripts)
For each planned video produce: (A) 3 hook variants tagged [pattern-interrupt]/[stakes]/[specificity], built from the worry field, one marked RECOMMENDED; (B) full word-for-word script, 90–150 spoken words (30–60s), hook → one-breath context → 3 payoff beats → CTA, written for the mouth with [stage directions]; (C) bullet version — hook verbatim, 3 beat cues ≤6 words, CTA verbatim; (D) THREE separately optimized caption blocks — Instagram (hook-first line, 2–4 value lines, comment-keyword CTA, 3–5 niche local hashtags, no hashtag walls), TikTok (shorter, question-forward, 2–3 hashtags), YouTube Shorts (keyword-front-loaded searchable title, description with the search phrase verbatim, tags); (E) on-screen text plan (3–5 overlays with timing — most viewers watch muted). End with a recording run sheet. Every script must pass "would Jen say this out loud?"

### Stage 4 — CAROUSEL DESIGN ENGINE (/sf-carousels)
Load Jen's brand spec (run Brand Direction first if missing). From ★ VISUAL entries, select the 10 strongest visual ideas (strongest = clearest single visual concept). Spec each carousel at 5–7 slides, 1080×1350: Slide 1 HOOK — typographic star, ≤12 words, legible at 150px thumbnail; middle slides — ONE idea per slide, ≤25 words, every stat rendered as a visual element (oversized numeral, comparison bar) never a sentence, sourced and dated on-slide in small print; final slide — assigned CTA + @realestatewithjing lockup. ENFORce THE BANLIST verbatim on every graphic: no cheesy stock photos, no emojis as design elements, no gradients, no drop shadows, no clip art, no text touching edges, no more than one idea per graphic. APPROVAL GATE: build and present ONE complete sample carousel, get approval, then batch the rest as a locked visual system (siblings, not clones). Two modes: BUILD (create the designs here) or BRIEF (output the portable master prompt + per-carousel slide specs to attach-and-paste into Claude Design). For edits, regenerate the single slide, not the carousel. Deliver a caption-pairing list mapping Script Pack captions to carousels.

## Force multipliers
Stack with jen-real-estate-mastery: This Week in LA → weekly "what LA is asking" carousel series; YouTube SEO → ranking Shorts titles; Lead Follow-Up → comment-keyword DM sequences; Daily Planner → filming sessions from the batch appendix. Listing mode: point Stage 1 at one listing's neighborhood for a per-listing carousel pack.

## Verification
Every deliverable: traceable to observed demand; speakable by the named agent; on-brand within the locked system; zero banlist violations; fair-housing clean (housing stock, price data, amenities, commute — never demographics or steering); every stat sourced and dated; copy-paste or press-record ready. Final test: could a brand-new team member execute today's content from the files alone?
