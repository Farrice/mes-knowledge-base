# Use Cases — Scenario → Matching `ward-` Workflow

> A routing table for *when you have a real job in front of you* and need the one
> Farnsworth workflow that does it. Each row is a concrete deployment scenario, the
> workflow that owns it, and *why* — so you reach for the device the **occasion** calls
> for instead of admiring a favorite device in the abstract (Pattern 10, occasion-sensing).
>
> **The default move when you're unsure is `/ward-rhetorical-engine`** — it diagnoses
> the rhetorical soil, picks the single right device, and routes into the specific
> workflow below. Use the direct workflow when you *already know* the device the line
> wants. Every workflow obeys the same law: one device per line (AN-1), on a line that
> carries payload (AN-2), built backwards from its last word (Pattern 8), in the native
> voice (AN-5). **Load `genius.md` before executing any of them.**

---

## The front door (when you don't know which device)

| Scenario | Workflow | Why this one |
|---|---|---|
| "This line matters and I don't know what's wrong with it / what it needs." | `/ward-rhetorical-engine` | Reads the soil, names what the line is trying to say, deploys the **one** right device + a one-sentence reason. The anti-stacking gate is the headline behavior — it picks one, never four. |
| "Make this stronger" / "punch this up" (vague). | `/ward-rhetorical-engine` | The vague ask is exactly the trap that produces device-stacking. The engine diagnoses *before* it decorates. |
| "I have a flat paragraph and want it to ring but it has no obvious thesis line." | `/ward-rhetorical-engine` → (if truly inert) plain rewrite | The engine's Step 2 catches the no-payload case and hands the line back plain instead of wrapping rhetoric around filler (AN-2). |
| A line matches two devices at once (it's a reversal *and* a punch). | `/ward-rhetorical-engine` | If it matches two rows of the soil table, it's two lines — the engine splits it rather than stacking two devices in one (AN-1). |

## Saxon Punch — `/ward-saxon-punch`

**The job:** a line that must land like a physical hit and ring after — built
backwards from a chosen final word, Latinate setup dropping to a stony Saxon close.

| Scenario | Why this workflow |
|---|---|
| Closing the final line of a sales argument or pitch deck thesis slide. | The thesis is "the punch" soil — end on the one stony word the room carries out the door. |
| Writing the CTA / button text on a VSL, landing page, or email. | Run the value conceptually so the logical brain signs off, then land the *do-it* word in Saxon so it rings. The button itself wants to be the punch. |
| The last line of a social hook, so the eye stops scrolling. | Short Latinate-flavored setup (little runway), then the final word drops like a slammed door. |
| The last sentence of an essay paragraph or section — the line readers quote back. | Most Latinate runway lives here; build a real conceptual stretch, then drop to the stone. |
| A line that's all "corporate fog" — Latinate with no payoff, sounds smart, says nothing. | The workflow forces the chord change: keep the conceptual setup, *resolve* it into the short hard word (fixes AN-4). |
| You want defiance/dread/resolve to be the *last* feeling the reader holds. | The "felt verdict target" picks *which* Saxon word lands the emotion. |

**Don't use it when:** the point is a reversal (→ chiasmus) or a series/crescendo (→
parallelism). A Saxon close needs a *single* landing word, not a structure.

## Chiasmus — `/ward-chiasmus`

**The job:** an ABBA reversal that inverts the audience's backwards belief into the
truth — the wisdom-illusion loop. Reach for it the instant what you mean is *and vice versa*.

| Scenario | Why this workflow |
|---|---|
| Handling an objection in copy ("it costs too much," "I don't have time"). | The objection-handler's home — reverse the prospect's frame so arguing against it "feels like arguing against gravity." Drop the Knockout on the CTA-adjacent line. |
| A scroll-stop reframe for a LinkedIn/X hook that says "you have this backwards." | The reversal *is* the scroll-stopper — it feels wise enough to earn a second read. Ship the Knockout. |
| A tagline or brand line that must feel inevitable, quotable, closed-loop. | Taglines *want* the symmetry; the wisdom illusion makes the line feel discovered, not written. Cross two poles core to the brand promise. |
| The thesis sentence of an essay where the whole argument is a flipped relationship. | Place the Direct chiasmus on the turn of the argument so the reader feels it click shut — once per essay. |
| "Enemy" positioning in a VSL — inverting the market's assumed cause-and-effect. | The crossover loop frames the competitor's logic as the inverted one. |

**Don't use it when:** the contrast is between *two different things* (light vs. dark,
budget vs. return) rather than an *inversion of the same two terms* — that's antithesis
(→ `/ward-antithesis`). Chiasmus inverts; antithesis juxtaposes.

## Parallelism (Anaphora · Epistrophe · the Switch) — `/ward-parallelism`

**The job:** a parallel run that crescendos — front-repeat (anaphora), end-repeat
(epistrophe), or the switch between them — defaulting to three beats, the climax
landing on the broken pattern.

| Scenario | Mode | Why this workflow |
|---|---|---|
| Building momentum *into* a CTA or a payoff line. | Anaphora | The repeated front-phrase primes the ear; break the pattern *on* the CTA so the offer is the goal. |
| Hammering the one belief that must survive the close ("...it's your fault"). | Epistrophe | The workhorse of converting copy — the same Anchor word ends three clauses until the belief is inescapable. |
| A manifesto / keynote crescendo ("We shall fight..."). | Anaphora → break | The native habitat; land the climax on the line that snaps the drumbeat. |
| Closing an essay paragraph so the concept lingers into the white space. | Epistrophe (tricolon) | One run per section; let the prose breathe between. |
| A memorable insult, takedown, or the rhetorically perfect kicker. | The Switch | Relief-and-return is what makes a line quotable for decades — needs long-form room. |
| A three-beat social hook that *is* the whole post. | Anaphora | Front-repeat to prime, break on the last line, Saxon close. One run per post. |

**Don't use it when:** you only have a single line with no room to repeat (a headline,
a one-line tagline) — repetition needs at least two beats of runway. For a single
quotable line, use `/ward-aphorism-forge`; for a single punchy close, `/ward-saxon-punch`.

## Antithesis — `/ward-antithesis`

**The job:** set one idea hard against its opposite in matched parallel slots so the
contrast does the persuading. *Juxtaposes* opposites (not a chiasmus inversion).

| Scenario | Why this workflow |
|---|---|
| A pattern-interrupt social hook: the assumed world vs. the real one. | "Everyone optimized the funnel. No one fixed the offer." The gap between the halves is the scroll-stop. |
| Writing the before/after of a VSL or sales page. | The before/after *is* an antithesis — pain-state hard against outcome-state in matched slots, ending on the outcome pole. |
| Shutting an objection by setting the prospect's fear against the real stakes. | "Not the cost of buying. The cost of waiting." The contrast reframes the risk. |
| A headline where two poles do the curiosity work ("Big budgets, small returns."). | Symmetry makes it feel true before the reader has read the article; end on the concrete Saxon pole. |
| A manifesto closer in the "so much / so many / so few" family. | Build the contrast across a balanced clause, drop into Saxon on the pole that matters, let it ring. |

**Don't use it when:** you're inverting the *same two terms* ("ask not what your
country..." ) — that's chiasmus (→ `/ward-chiasmus`). Antithesis sets A against
not-A; chiasmus crosses A-B into B-A.

## Aphorism Forge — `/ward-aphorism-forge`

**The job:** compress a worthy claim drowning in qualifiers into the one quotable line
people repeat — built backwards from its last word — **plus an honest TRUE-or-just-said
shield note**.

| Scenario | Why this workflow |
|---|---|
| You have a paragraph-long insight and need the single line people will screenshot. | Compression isn't trimming — it decides the last word first and dismantles everything before it that doesn't earn its place. |
| Forging a maxim to close an essay or a section the piece is remembered for. | Rule-of-three earns its place; the maxim *must* be TRUE/LIKELY or a reader who finds it was merely well-said distrusts the whole essay. |
| Writing a tagline or brand promise and you want to know if it's defensible. | The shield note tells you it's a STANCE (a promise, not a proven fact) — correct for a tagline, but ship it knowingly. |
| A pull-quote or CTA line that's persuasive *and* might get quoted back at you. | A STANCE dressed as TRUTH in sales copy is exactly the converting line *and* the liability — the workflow flags it so you ship with eyes open. |
| You're worried a "punchy" line is beautiful but possibly false. | This is the one workflow whose deliverable includes the honesty verdict — the sword *and* the shield. |

**Don't use it when:** the line is already short and you just need the close to hit
harder (→ `/ward-saxon-punch`), or you need a *series* rather than a single maxim (→
`/ward-parallelism`).

## Headline Rhetoric — `/ward-headline-rhetoric`

**The job:** engineer scroll-stopping hooks and headlines on the rhetorical ear —
end-weight first, then exactly one device (Saxon close, chiasmus reframe, or
Two-Languages), ranked and ready to hand to a hook engine.

| Scenario | Why this workflow |
|---|---|
| Writing X / LinkedIn first lines that have to stop the thumb. | At hook length the machinery shows fastest; this workflow caps at the three devices that fit and engineers the *end* of the line first. |
| Headlines, H1s, email subject lines, ad headlines. | The click happens on the last word — it builds backwards from the one belief the open must plant, then hands a ranked set down. |
| A talk title or talk opener. | A title is still a hook → still one device; it earns its stop on a Saxon close or a chiasmus, saving anaphora for the body. |
| You need a batch of ranked hook candidates to feed a downstream hook/copy engine. | Ward supplies the *device*; the hook engine supplies the scroll-mechanics. This workflow is built to stack with them, not replace them. |

**Don't use it when:** you need a full parallel *run* (anaphora/epistrophe rarely fit a
single hook — use `/ward-parallelism` for the body), or you need the honest
true/just-said verdict on a maxim (→ `/ward-aphorism-forge`).

## Metaphor-as-Argument — `/ward-metaphor-argument`

**The job:** restate one abstract, emotionally-inert claim as a single concrete
picturable image (the Saxon/visceral half of a Two-Languages pair) that the reader
metabolizes instantly. Ranked by persuasive *load*, not prettiness.

| Scenario | Why this workflow |
|---|---|
| You have an intellectually clear claim that nobody *feels*. | The image does the arguing — the gut closes the case before the head reopens it. |
| Carrying the *problem* in a VSL so the offer can be the fix. | The metaphor holds the leak / the bleed / the rusted lock; the offer becomes the plug. One controlling picture per section. |
| A controlling image a whole speech or essay can return to. | Native habitat (Lincoln's "house divided," MLK's "promissory note") — land it early in concrete words, refer back without re-explaining. |
| A tagline that must carry the brand's *actual* claim, not generic uplift. | Hardened picture-only version — if it could sit on any brand, it carries nothing. |

**Don't use it when:** the claim just needs a hard Saxon *word* (not a whole image) at
the end (→ `/ward-saxon-punch`), or the move is a logical reversal rather than a
picture (→ `/ward-chiasmus`). *(This workflow supersedes the legacy
`visceral-persuasion-bridge`.)*

## Cadence Audit — `/ward-cadence-audit`

**The job:** a line-by-line rhythm scan of an *existing* draft — Saxon/Latinate ratio,
sentence-length map, end-weight, flat "all one color" stretches flagged — then a
re-tuned pass that installs chord changes and short Saxon finishes. **Diagnostic, not
generative.**

| Scenario | Why this workflow |
|---|---|
| A draft is clear and correct but *tires the ear* — every sentence the same weight. | "If everything is loud, nothing is loud." This finds where the music goes flat and *why*, then re-tunes only those places. |
| Converting copy where every claim is the same medium-length sentence (the `M M M M M` flatline). | Audits the rhythm of the *run*, breaks claim-runs with short punches, reserves the chord change for the CTA. |
| Final QA before shipping any piece — the "ear check" mandatory step. | Pass over finished prose to confirm at least one deliberate chord change and a short Saxon finish where it counts. |
| An essay where flatness clusters mid-paragraph and after the best line (the reader coasts). | Audits the last sentence of each paragraph for a chord change and section openings for length variety. |
| A speech that builds and builds but never *drops* to the stone. | Hunts the build-with-no-payoff — pomp that never lands the Saxon climax — and installs the break. |

**Don't use it when:** you're writing *new* lines from scratch — that's the generative
workflows above. The audit operates on prose that already exists.

## Reverse index — "I'm working on X, which workflow?"

| If you're producing... | Start with... | Then maybe... |
|---|---|---|
| A LinkedIn / X hook | `/ward-headline-rhetoric` | `/ward-chiasmus` or `/ward-saxon-punch` if you know the device |
| A headline / H1 / email subject | `/ward-headline-rhetoric` | `/ward-saxon-punch` for the close |
| A VSL / sales page | `/ward-chiasmus` (objections) + `/ward-antithesis` (before/after) + `/ward-parallelism` (build into CTA) + `/ward-saxon-punch` (CTA line) | `/ward-cadence-audit` on the finished draft |
| An email | `/ward-parallelism` (the belief) + `/ward-saxon-punch` (the ask) | — |
| A tagline / brand line | `/ward-chiasmus` or `/ward-aphorism-forge` | `/ward-saxon-punch`, `/ward-metaphor-argument` |
| A speech / manifesto | `/ward-parallelism` (the run + switch) + `/ward-antithesis` (closer) + `/ward-metaphor-argument` (controlling image) | `/ward-cadence-audit` read aloud |
| A ghostwritten piece (client voice) | `/ward-rhetorical-engine` (matches device to *their* cadence) | the specific device workflow it routes to |
| The one quotable maxim from an insight | `/ward-aphorism-forge` | — |
| An existing draft that feels flat | `/ward-cadence-audit` | the device workflow for any line it flags |
| **You don't know** | `/ward-rhetorical-engine` | it routes you |

**The meta-rule for all of the above:** the workflow is the *delivery mechanism*, never
the goal. The goal is the line reading as "that was well said," with the machinery
invisible. If the output announces its device, you've routed correctly and *executed*
wrong — go back to the genius.md anti-patterns, not to a different workflow.
