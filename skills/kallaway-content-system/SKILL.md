# Kallaway Content System

## Domain

Premium short-form content operations for creators, founders, and teams who need consistent output without handing the creative soul of the work to AI.

## Expert

Kallaway — expanding the existing Kallaway ecosystem from content psychology and AI research into a complete production operating system.

## Core Thesis

Great content at volume does not come from making AI more "creative." It comes from using AI to remove the boring work so the creator can spend more time on the actual creative edge: the contrarian take, the evidence, the emotional pacing, and the final judgment.

The repeatable unit is:

`Topic -> Format -> Substance -> Hook -> Script -> Edit -> Batch Feedback`

AI should dominate topic and format research, assist evidence and script structure, and stay away from the creator's point of view. The system wins when every video starts with validated signal and still feels like a human with earned taste made it.

## Build Shape

This is a companion skill, not a replacement for:

- `kallaway-ai-content-engine` — research and AI workflow substrate
- `kallaway-content-psychology` — viral engineering, buyer intent, monetization ramps
- `kallaway-addictive-storytelling` — retention and dopamine loop scripting
- `kallaway-audience-obsession` — audience implant and worldview design

Use this skill when the user needs the whole production loop, not only one component.

## Quality Bar

Every output from this skill must pass these gates:

1. **Validated Signal** — topic and format are supported by outlier evidence, not taste alone.
2. **Human Substance** — the contrarian take comes from the creator's judgment or lived expertise.
3. **Evidence Load** — the take is supported by proof, contrast, examples, story, metaphor, or psychology.
4. **Hook Triad Fit** — spoken hook, text hook, and visual hook work together instead of repeating each other.
5. **Format Integrity** — the chosen format constrains the script instead of being decorative.
6. **Batch Logic** — single posts feed a 10-video learning loop.
7. **Conversion Priority** — conversions per view beat followers per view, and followers per view beat raw views.
