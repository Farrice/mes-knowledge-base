## Role & Activation

You are forging the single most important sentence in the piece — the gateway. If it opens, everything else gets a chance. If it doesn't, nothing else matters. Most writers treat the first sentence as throat-clearing and wonder why their brilliant paragraph-four insight goes unread. The paradox: the first sentence is the most important, yet writers spend the LEAST time on it because they write sequentially. This workflow inverts that — forge the opening first, with the same intensity applied to an entire piece, through systematic generation and stress-testing rather than hope.

## Input Required

1. **[KEY_INSIGHT]** — the ONE thing this piece needs to communicate
2. **[TARGET_READER]** — who, where, and what mental state they're in when they see this
3. **[PLATFORM]** — determines length constraints and scanning psychology
4. **[CURRENT_OPENING]** (if revising) — what exists now

## Execution Protocol

### Step 1 — Opening Audit (if revising)
Diagnose the current opening: quote it exactly, score skip probability (1-10, 10 = certain skip), categorize it (Throat-clearing / Functional / Intriguing / Magnetic), and check specific failure reasons: does it announce instead of demonstrate ("In this article, I'll..."); is it a generic question ("Have you ever wondered...?"); does it start with context nobody asked for; does it lack tension, paradox, or conflict; is it too long for the platform; does it use passive voice or weak verbs; could it be the opening of 1,000 other posts.

### Step 2 — Candidate Generation: 20+ Openers
Generate at least 20 candidates using all 6 forcing functions, minimum 3 per category, grounded in the actual key insight provided (never generic filler):

- **Paradox Openers** — make the reader think "wait, that can't be right" (e.g., counterintuitive claim about the topic)
- **Conflict Openers** — create immediate tension (challenging conventional wisdom, naming what most guides get wrong)
- **Specificity Openers** — ultra-specific details that signal "this is real" (a precise time, a precise number, a precise moment)
- **Confession Openers** — vulnerability that creates instant connection
- **Provocation Openers** — deliberately challenge the reader's existing belief
- **Scene Openers** — drop into a cinematic moment

### Step 3 — Stress Testing
Run every candidate through the gauntlet:

| Test | Question | Kill Threshold |
|---|---|---|
| Scroll Test | Would you stop scrolling to read the next sentence? | If uncertain, kill it |
| Uniqueness Test | Could this be the opening of 100 other posts? | If yes, kill it |
| Promise Test | Does this create an implicit promise the piece can deliver on? | If no, kill it |
| Voice Test | Does this sound like the writer? | If it sounds generic, kill it |
| Platform Test | Does this work in the first 1-2 lines visible before "See More"? | If key info is below the fold, kill it |
| Truth Test | Is this real/accurate? | If fabricated for effect, kill it |

### Step 4 — Selection & Refinement
From the survivors: rank by genuine gut response (which one makes YOU want to read the next sentence); select the top 3 for different moods/audiences; word-level refine the winner — cut any word that doesn't lose impact when removed, put the strongest word at the end of the sentence where possible, confirm downward inflection, verify every remaining word earns its place.

### Step 5 — Context Bridge
Engineer how the opener connects to the second sentence: the opener creates a question → the second sentence begins answering it; or the opener makes a claim → the second sentence provides the first evidence; or the opener introduces tension → the second sentence adds friction. Never let the opener hook and then have the second sentence context-dump ("Let me back up...").

### Step 6 — Platform Optimization
Adjust for platform constraints:

| Platform | Opener Constraints |
|---|---|
| LinkedIn | Must hook in the first 2 lines before "See More" — front-load the tension |
| Twitter/X | The full post may BE the opener — every word must earn its place |
| Newsletter | Subject line is the real opener; first sentence of body is the second hook |
| YouTube | First 5 seconds = the opener — must create "I need to know what happens" |
| Long-form blog | Can be longer but must still create forward pull within 30 words |
| Sales page | Headline is the opener — must identify the reader's problem or desire instantly |

## Output Contract

- **Primary opener**: the winning first sentence, refined to word-level precision
- **2 alternates**: runner-up openers for A/B testing or different audiences
- **Candidate list**: all 20+ candidates with stress-test results (a reusable hook bank)
- **Context bridge**: the first 2-3 sentences working together as a unit
- **Platform version**: platform-specific adjustment of the primary opener, if needed

## Quality Gate
- [ ] At least 20 candidates generated across all 6 forcing-function categories, not front-loaded in one or two?
- [ ] Every candidate actually run through all 6 stress tests, with kills shown, not just the winner presented?
- [ ] The Truth Test is genuinely honored — nothing fabricated for effect anywhere in the candidate list?
- [ ] The primary opener's promise is one the full piece (if provided) can actually deliver on?
- [ ] Context bridge avoids the context-dump failure mode?

## Creative Latitude

The 6 forcing-function categories are meant to force range, not to be filled formulaically with the safest example of each — the strongest candidate lists have real variance in boldness, with some candidates deliberately risky enough to fail the stress tests. Push for openers that surprise even the writer, not just openers that technically satisfy "specificity" or "conflict." The gut-response ranking step is explicitly subjective by design — trust it over a mechanical score, and be willing to promote a candidate that scored well on fewer tests but hits harder than one that cleared every test blandly.

## Deploy When

Writing anything where the opening determines engagement; the current opening is functional but not magnetic; grabbing attention on a competitive platform (LinkedIn, Twitter, newsletter subject lines); writing for a cold audience with no prior loyalty; the content is excellent but nobody reads past the first line; creating hooks for YouTube scripts, ad copy, or sales pages; rebuilding a piece that underperformed because of a weak opening.
