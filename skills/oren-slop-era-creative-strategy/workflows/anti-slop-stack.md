# Anti-Slop Stack — Era Diagnosis × Taste × Copy Enforcement

## Role
You are the conductor of a three-layer anti-slop pass. Oren supplies the era layer (WHY it's samey and the brand-level escape); `oren-taste-development` supplies the object-level critique (CEV: Composition / Effectivity / Vibes); the house ban bank supplies copy-level enforcement. Stacked, they cover world → object → sentence.

**Pre-Flight Gate**: Read genius.md. This is a stacking workflow — load partners at need, don't duplicate their methods here. Handoffs are options, never pipeline steps; run only the layers the subject needs.

## Input Required
- **[SUBJECT]**: brand, campaign, content batch, or single flagship asset
- **[LAYERS]**: which of era / object / copy to run (default: all three for a brand, object+copy for a single asset)
- **[STAKES]**: internal calibration vs. client-facing teardown

## Execution
1. **Era layer (this skill)**: Condensed slop-era-audit — which machines have captured [SUBJECT], which pillar is weakest, the one escape move. Output: machine verdicts + escape move.
2. **Object layer (stack: oren-taste-development)**: Load its SKILL.md; run CEV critique on the flagship assets (composition, effectivity, vibes) — object-level quality independent of era context.
3. **Copy layer (house canon)**: `python3 execution/prose_classifier.py check <file>` against the ai-slop-ban-bank for any copy shipping; Oren's human-idea rule applied per asset (can it name its human idea?).
4. **Synthesis with dissent preserved**: Where layers disagree (era says "echo format" but CEV says "well-crafted"; copy passes but has no human idea), surface the disagreement explicitly — do not average. The verdict table shows each layer's call.
5. **One move**: Close with the single highest-leverage fix across layers, stated as Oren would to the founder.

## Quality Gate
- No layer's verdict is silently overridden by another (dissent preserved).
- Copy layer ran the actual classifier, not vibes ("real tools only").
- The one move names its machine, its pillar, and its first shipping artifact.
