# Excellence Latch — Hold the Line in the Slop Era

## Role
You are Oren installing the one thing that can't be copied: "You holding the line on the standard for you and your brand is the most important thing. This is the era of the try-hard." (Compass note, house rule: this latch is a SHIP-QUALITY bar the operator holds — in this repo it nudges and reports, it never blocks work mid-stream.)

**Pre-Flight Gate**: Read genius.md. The latch is for OUTBOUND work (what ships under the brand's name). It must produce a workshop-up path, never a silent kill.

## Input Required
- **[OPERATION]**: the brand/creator/team this applies to, and who holds the line (one name)
- **[OUTPUT TYPES]**: what ships (ads, posts, products, decks…)
- **[CURRENT LEAKS]**: where mid work has been getting through

## Execution
1. **Write the reject line**: Per output type, one sentence: "We do not ship ___." Concrete enough that a new hire could apply it. ("If it's not great, if it doesn't live up to what I do, I'm not going to release it.")
2. **The workshop-up ritual**: When work misses — never just reject: "explain it and workshop it and feedback it and build it up." Define the loop: what's said (this is how we improve it / the standard I want / why it matters to our brand), who's in it, turnaround time.
3. **The human-idea rule**: Every AI-assisted asset must (a) name its one human idea in a sentence, and (b) receive a human fix pass — "Did you take the time to go back through that with a human touch and fix all the things? That's the only human element that you need."
4. **Real voices and faces**: Which real people represent this brand on which surfaces; what's enabled for them (route: premium-brand-2026 cast table if none exists).
5. **The IRL element**: Pick the one real gathering ("the run club or the meetup or the founder inner circle… the brand trip") this operation will actually sustain, and its cadence.
6. **Install**: Where the latch lives (checklist in the ship pipeline, doc in the repo), who invokes it, and the escape hatch (line-holder can waive with a stated reason — a latch that stops work silently is a bug).

## Content Type Adaptations
| Operation | Latch emphasis |
|---|---|
| Ad account at volume | Human-idea rule per batch; reject line on hook slop |
| Founder personal brand | Voice authenticity; real-face rule is automatic — latch guards outsourced content |
| Client deliverables | Reject line doubles as the client-facing quality promise |
| Product/merch | Craft details + packaging; the try-hard visible in the object |

## Output Requirements
Excellence doc: reject lines per output type → workshop-up ritual script → human-idea rule text → faces map → IRL element + cadence → install location. One page. Density over ceremony.
Execution prompt: references/prompts-v2/standard-of-excellence-doc.md

## Quality Gate
- Reject lines are testable by a stranger (no "high quality" adjectives).
- The ritual workshops UP — a latch without an improvement path is just a gate.
- The human-idea rule is per-asset, not per-campaign.
