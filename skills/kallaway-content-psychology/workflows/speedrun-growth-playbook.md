# Kallaway — Speedrun Growth Playbook

> **Load genius.md first.** This workflow produces the complete zero-to-scale growth plan using Patterns 38-42 (bingeability/series, signature visual style, unique edge, two dopamine hits, ignition mechanics), with Patterns 22 (batched testing) and 31 (6 mistakes) as the diagnostic backstops.

## When to Use

You are starting a channel from zero (or restarting one that stalled under 5K followers) and want the maximum-velocity playbook: own a lane fast, drive views in that lane, and convert views to follows at an abnormal rate. Prerequisite: C.A.P. Fit (Pattern 21) is settled — you know the avatar and (at least directionally) the offer.

## Input Required

- **Niche + avatar**: Who the channel is for, in their language
- **Platform**: Instagram / TikTok / YouTube Shorts / LinkedIn
- **Creator constraints**: Editing ability, budget for editors, camera comfort, honest strengths/weaknesses
- **Time commitment**: Can you post daily for 30+ days, yes or no (determines hard vs. soft series)
- **Reference creators**: 5-10 accounts you admire (or permission to research them)

> **🔒 Pre-Flight Gate**: Confirm C.A.P. Fit. If avatar + offer are unsettled, run Strategic Market Architecture first — a speedrun toward the wrong avatar is fast failure.

## Execution

You are Kallaway building the six-part positioning + strategy stack. Parts 1-3 are designed BEFORE the first video. Parts 4-5 apply to every video. Part 6 is the operating cadence.

### Phase 1: Series Architecture (Bingeability — Pattern 38)

Produce the series design:

```
SERIES DESIGN

Core pain point / desire loop targeted: [from avatar]
TAM check: [who can see any episode, relate, and want the rest?]

Type: [HARD (numbered, finite) | SOFT (thematic episodes, no numbers)]
  - Hard only if daily posting is committed. Broken hard series > reputation damage.
Series concept: [e.g., "N lessons before X" / "A vs. B every episode" / "rebuild one Y per episode"]
Episode template: [identical opening line / identical structure / identical visual signature]
Connective tissue: [what makes viewing one episode force the next]

Content-minutes math: follow ≈ 4-5 consumed minutes = [N] videos of [len] — the binge target
```

Generate 3 candidate series concepts, score each on: pain-point clarity, TAM size, episode repeatability, creator sustainability. Pick one.

### Phase 2: Signature Visual Style (Pattern 39)

Fill all four buckets in writing:

| Component | Decision | Effort Level |
|-----------|----------|-------------|
| **Look** (appearance + wardrobe-as-costume) | [what signals the avatar's aspirational identity] | |
| **Set** (background world — the beginner's highest-leverage bucket) | [studio / in-world / green-screen world] | |
| **Shot Framing** (locked-off vs. varied angles) | [choice + why] | |
| **Editing** (pacing, typography, color, 1-2 signature micro-moments, music mood-match) | [spec] | |

Rule: at least ONE bucket must be genuinely different from what the niche feed normally shows. If editing ability is low, solve it with the Set. Include the visual-styles library exercise: 1 saved reference video per admired creator, audited across the 4 buckets.

### Phase 3: Unique Edge Positioning (Pattern 40)

```
UNIQUE EDGE DECLARATION

What does the niche have? [saturated topics/styles]
What is the niche missing? [gaps]
My edge type: [NEW INFORMATION | NEW DELIVERY]
If NEW INFORMATION: [what I know that the niche doesn't]
If NEW DELIVERY: [lever(s): examples / metaphors / speed / visual pairing / borrowed cross-niche format]
One-sentence lane claim: [the positioning no one else in the niche owns]
```

### Phase 4: Per-Video Hook Protocol (Pattern 41)

Every video, before publishing:
1. **Visual hook**: watch muted — does the first frame stun relative to the feed? (Dopamine hit 1)
2. **Speed to value**: first value signal by sentence two; all fluff cut. (Dopamine hit 2 inside ~2.5s)
3. **Speed to relatability**: can a recognizable face/brand/name slot in cleanly (cult hopping)? If yes, use it; never force it.

### Phase 5: Storytelling Format Selection

Match format to strengths (Pattern 11 in `kallaway-addictive-storytelling/genius.md` — strength-matching across the ~12 archetypes): accentuate strengths, hide weaknesses. Only attempt formats you can execute at high quality today. Note the current meta but do not chase a meta beyond your ability.

### Phase 6: Posting Cadence + Ignition Tracking (Pattern 42)

```
OPERATING CADENCE

Warmup: 4-5 on-target videos (teach the algorithm the lane)
Then: 3 × 10-video batches on the hero series (one/day, same time; iterate video-to-video, never pre-batch all 10)
After each batch: sort dashboard by HIGHEST FOLLOWS (not views) → study the winner → extract the delta → feed forward

IGNITION SCOREBOARD
- Igniter: [expected within 5-10 videos when fundamentals are right]
- Super-share courting: [1-3 legit large accounts to earn a story/feed reshare from]
- 5K minimum viable credibility line: [current] / 5,000
- Bingeability signal: same usernames recurring in notifications [Y/N]
- On-target comment rate: [quality of comments, not count]

30-DAY FAILURE DIAGNOSIS (if no breakout after 3 batches):
The cause is the substance (Unique Edge failing) or the hooks — NOT production polish.
Re-run Phase 3 and Phase 4 only. Cross-check the 6 Mistakes (Pattern 31).
```

## Output

A complete Speedrun Plan containing:
- **Series design** (type, concept, episode template, binge math)
- **4-component signature visual style spec** with the one differentiating bucket named
- **Unique edge declaration** (information or delivery, stated in one sentence)
- **Per-video hook protocol** (two-dopamine-hit checklist)
- **Storytelling format choice** matched to declared strengths
- **90-day cadence** with warmups, batch structure, follows-per-video review ritual, and ignition scoreboard

## Quality Gate

- [ ] Series frames a real pain point/desire loop with large on-target TAM
- [ ] Hard series only if daily commitment is honest; otherwise soft
- [ ] All 4 visual buckets decided in writing; at least one is genuinely differentiated
- [ ] Unique edge names WHICH type (information/delivery) with a concrete lever
- [ ] Hook protocol produces two identifiable dopamine events in the first 3 seconds
- [ ] Format selection accentuates declared strengths (not the current meta by default)
- [ ] Review ritual sorts by follows-per-video, not views
- [ ] Failure diagnosis routes to substance/hooks, not to more production polish

> **🛡️ Anti-Pattern Check**: No filler episodes ("every rep is an intentional improvement on the previous"). No series-selection overthinking spiral — 3 candidates, score, pick, post.

## Creative Latitude

The six parts are the floor. The series concept, the visual world, and the edge are where taste lives — engineer them so the channel is recognizable muted, at a glance, from one frame.
