# /segura-audit — Material Ownership Audit

Diagnoses a piece of material or topic angle on whether it's unrepeatably yours, then produces a scored verdict plus — when it fails — the autobiographical PIVOT. Deploys **Pattern 13: Story Ownership (No One Else Has This)** and **Hidden Knowledge 7: Emulation is the Larval Stage**.

## When to Use
- A draft, bit, or topic angle feels generic and you suspect it's the **derivative middle**.
- You're entering a **crowded topic** (the AI bit, the hot take everyone has) and need a go/no-go.
- A piece is competent but forgettable — the "comprehensive but dead" smell.
- Topic selection before development: decide *report vs. invent*.

## When NOT to Use
- The material is already confirmed yours and needs *development* → route to `/segura-develop` (Long-First, Edit-Second).
- You need *more angles* on a topic, not a verdict → route to `angle-swarm` or the Annoyance Dig.
- Pure mechanics (joke architecture, virality) → route to Robert Mack.

## Pre-Flight Gate
Load genius.md. This workflow is governed by **Pattern 13 (Story Ownership)** and **Hidden Knowledge 7 (Emulation is the Larval Stage)**, with **Anti-Exemplar: The 15th AI Bit** as the failure anchor. Disqualify the input if it's a confirmed-original draft needing only polish (route to develop/word-swap). If the material is a pure hot take with no autobiographical surface and the user wants it kept, flag that **Move: The Annoyance Dig** may rescue it — but ownership is still the binding test.

## Skill Acquisition
- Load: skills/tom-segura-comedy-storytelling/genius.md — Patterns **13** (Story Ownership), **2** (Complaining is the Engine), **3** (Universal-but-Unarticulated); Moves **The Annoyance Dig**, **The "Way In" Install**.

## Execution
1. **Strip** the material to its core claim and topic. Name the topic in one line. State plainly whether the topic is crowded (many people are doing this) or owned territory.
2. **Score Ownership** (1-10): could anyone else tell this? Cite **Pattern 13** — "no one else has that story or that perspective." Render a 1-line verdict: *Anyone's* / *Partly yours* / *Unrepeatably yours*.
3. **Score Superiority** (1-10, crowded topics only): is yours FAR superior — the only license to do a crowded topic? Per Pattern 13, you do the 15th AI bit only if it's "far superior"; otherwise the topic is forfeit. If not far superior, mark **NO LICENSE**.
4. **Score Report-vs-Invent** (1-10): is it true to the user's life or fabricated? Cite **Pattern 13** — "I report. I don't make up a single thing." Flag any invented detail that should be reported instead.
5. **Render the verdict.** Composite = lowest of the three scores (a single fail sinks the bit). If Ownership ≥7 OR (crowded AND Superiority ≥8) AND Report-vs-Invent ≥7 → **PASS, develop it**. Otherwise → **FAIL, pivot**.
6. **On FAIL, produce the PIVOT.** Cut the derivative angle. Dig into the user's actual life for the unrepeatable version of the same charge — their kids, mom, friends, specific lived moment. Generate **2-3 autobiographical replacements**, each reported (not invented), each carrying a **Universal-but-Unarticulated** charge (Pattern 3) the original was reaching for.
7. **Hand off.** For each pivot, name the next workflow: install a **"Way In"** before developing (Pattern 4) or run **Long-First, Edit-Second**.

## Content Type Adaptations
| Content Type | How this shifts |
|---|---|
| Stand-up / spoken | Hardest test of Superiority — the club has 15 versions. Default to autobiography; pivot to kids/mom/friends material. |
| Essay / newsletter (Parallax) | Ownership = memoir interiority no one else has lived. Pivot toward the specific suppression-wound moment, reported. |
| LinkedIn / social | "Lesson posts" fail Ownership constantly. Pivot to the literal scene from the user's career only they witnessed. |
| Sales / DR copy | Ownership = founder's actual origin/proof, not borrowed case studies. Pivot to the one event that proves the claim. |
| Video / sketch script | Superiority bar is highest (visual saturation). Pivot to a premise rooted in the user's real household/relationships. |

## Output Requirements
- **Format**: A scored verdict block — three labeled scores (Ownership / Superiority / Report-vs-Invent), composite, and a one-line PASS/FAIL ruling with the binding reason.
- **Must include**: The named genius pattern justifying each score; on FAIL, **2-3 autobiographical pivots**, each reported-not-invented, each with its recognition charge named.
- **Ends with**: The next-workflow handoff for the winning pivot (Way In install or Long-First develop). No generic question close.

## Quality Gate
Score against the genius.md rubric (name the anchor for any score ≥8 — e.g. **Ownership 9** must cite "only you could tell this," **Recognition 9** must cite the "why didn't I say it?" charge). Reject if any of these anti-patterns are present: **#7 The derivative middle** (the 15th AI bit / inventing instead of reporting), **#9 Comprehensive but dead** (a verdict with no ownership stake), **#1 The neutral take** (a pivot with no temperature). Retry the weakest pivot once before delivery.
