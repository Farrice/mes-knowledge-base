# /segura-hook — Antenna → Hook

Takes a ranked observation bank (from `/segura-antenna`) and produces scroll-stopping recognition hooks that open on the unarticulated-universal and swerve. Deploys **Pattern 1 (The "That's a Thing" Antenna)**, **Pattern 3 (The Universal-but-Unarticulated)**, and **Pattern 6 (Surprise is the Core Mechanism)**, stacked onto Lara Acosta's LinkedIn hook engine.

## When to Use
- You have a flagged observation bank and need first-line hooks for LinkedIn, X, or any feed.
- A post draft dies on the first line and needs a recognition swerve installed.
- Converting "that's a thing" fragments into scroll-stops without losing the raw charge.

## When NOT to Use
- No observation bank exists yet → run `/segura-antenna` first.
- The piece is a full story open needing stakes, not a one-line hook → use `/segura-way-in` (Pattern 4).
- Pure joke-mechanics or virality engineering with the bit already written → route to Robert Mack.

## Pre-Flight Gate
Load genius.md. This workflow is governed by Patterns 1, 3, 6 and the **"That's a Thing" Flag** + **Word Swap** moves. Disqualify any input observation that has no temperature (**Anti-Pattern 1: the neutral take**) or that is derivative rather than autobiographical (**Anti-Pattern 7: the derivative middle**). If an observation is genuinely universal but flat, it stays; if it's just generically relatable, cut it before hooking.

## Skill Acquisition
- Load: `skills/tom-segura-comedy-storytelling/genius.md` — Patterns **1, 3, 6**; Moves **The "That's a Thing" Flag**, **The Word Swap**.
- Stack: load Lara Acosta's LinkedIn hook engine via `.agent/workflows/ghostwrite.md` (or the Lara Acosta skill `SKILL.md`). Her hook formats supply the structural container; Segura supplies the recognition payload and the swerve.

## Execution
1. **Pull** the top-ranked observations from the bank (5-10 candidates). For each, isolate the precise unarticulated-universal underneath it — the thing noticed "60, 70 times" but never voiced (**Pattern 3**). State it in one plain sentence.
2. **Test** each for the "of course" charge: does it trigger "why didn't *I* say it?" If it only reads as "yeah, relatable," cut it (**Pattern 3 success metric**, **Anti-Pattern 9: comprehensive but dead**).
3. **Translate** each survivor into Lara Acosta's hook container — open on the recognition, then **swerve** before the line resolves (**Pattern 6**). Build anticipation in one direction, turn somewhere else. Where possible, engineer the against-judgment beat (the line they laugh at reluctantly).
4. **Swap** the pivotal word on every hook for the funniest-sounding specific (**Move: The Word Swap** / Pattern 11) — "yanked" over "pulled." Strip flat verbs and abstractions. Test the sound, not just the sense.
5. **Cut** any winking or "this is a joke" signaling — play the recognition straight so the swerve hits harder (**Pattern 8**).
6. **Rank** all hooks 1-N by scroll-stop potential, scoring each on Recognition + Surprise (the two rubric rows this workflow owns). Tag each with the source observation and the format used.
7. **Render** the ranked list and mark the single strongest hook as the recommended open.

## Content Type Adaptations
| Content Type | How this shifts |
|---|---|
| Stand-up / spoken | Hook becomes the spoken premise line; lean harder on the against-judgment swerve and word-sound. |
| Essay / newsletter (Parallax) | Hook expands into a recognition-essay opener; pair the swerve with one beat of memoir interiority. |
| LinkedIn / social | Native mode — full Lara Acosta container, line-break cadence, one-idea-per-line scroll rhythm. |
| Sales / DR copy | The unarticulated-universal becomes the prospect's unspoken frustration; swerve into the mechanism. |
| Video / sketch script | Hook is the cold-open line delivered straight (Pattern 8); the swerve is the first visual turn. |

## Output Requirements
- **Format**: numbered, ranked list of 5-10 hooks. Each entry: the hook line + source observation + Lara format used + Recognition/Surprise scores.
- **Must include**: at least one against-judgment (reluctant-laugh) hook; the word-swapped final phrasing on every line.
- **Ends with**: the single recommended open flagged, with one line on why it tops the ranking.

## Quality Gate
Score against the genius.md rubric (name the anchor for any score ≥8) — prioritize **Recognition (universality)**, **Surprise**, and **Word/Sound precision**. Reject if any present: **Anti-Pattern 1 (the neutral take)**, **Anti-Pattern 7 (the derivative middle)**, **Anti-Pattern 8 (callback as tic)**, **Anti-Pattern 9 (comprehensive but dead)**. Retry the weakest hook once before delivery.
