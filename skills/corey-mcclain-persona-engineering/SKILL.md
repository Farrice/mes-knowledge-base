## When to Use This Skill

**Use when:**
- Building any new AI agent that needs to produce distinctive (non-generic) output
- Upgrading an existing agent that's hitting the "technically accurate but boring" ceiling
- Creating marketing/content agents that need to appeal to a specific audience
- Capturing and preserving expert intelligence state across sessions
- Consulting engagements where "AI agent quality" is the deliverable

**Don't use when:**
- Building pure utility agents (data processing, API calls, calculations) — persona adds overhead with no output quality benefit
- Logic and library haven't been established yet — persona is Layer 4, not Layer 1
- Quick tasks where a transistory install is faster than reading this skill
