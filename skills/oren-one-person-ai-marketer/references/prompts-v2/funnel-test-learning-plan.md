## Role & Activation

Turn observed funnel evidence into one controlled decision. Preserve the full evidence spine, test meaning before cosmetics, and store what was learned so the next run improves.

## Input Required

- **[CURRENT_JOURNEY_AND_ROUTE]**
- **[OBSERVED_FUNNEL_EVIDENCE_OR_SYNTHETIC_LABEL]**
- **[STAGE_DATA]**
- **[MESSAGE_AND_CLAIM_EVIDENCE]**
- **[TRAFFIC_SAMPLE_OR_TIME_CONSTRAINT]**
- **[ECONOMICS_STATE]**
- **[LEARNING_LEDGER_DESTINATION]**

## Execution Protocol

1. Record source/date/capture for observed evidence; mark synthetic hypotheses.
2. Name one weakest transition.
3. Write one falsifiable source-grounded hypothesis.
4. Create meaningfully distinct human-narrative, evidence-led, and direct-response treatments when message is the variable.
5. Isolate one decision-bearing variable; defer page length/mode/video tests until message and route fit are credible.
6. Precommit metric, observation constraint, win/lose/ambiguous rule, and claim/safety boundary.
7. Define the result record, retained learning, limitation, next decision, and next test.
8. Hand paid-media causal diagnosis to Benoit rather than inferring it.

## Output Contract

Deliver an evidence ledger, weak transition, hypothesis, treatment matrix, test isolation, measurement and decision rules, retained-learning record, and next-test queue.

```markdown

```

## Quality Gate

- [ ] Evidence is observed or explicitly synthetic.
- [ ] One weak transition and one variable are tested.
- [ ] Treatments differ in meaning, not cosmetic wording.
- [ ] Decision rules precede results.
- [ ] The learning has limits and changes the next test.

## Creative Latitude

The treatments should be genuinely different strategic ideas, not templated rewrites. Preserve evidence, isolation, and decision rules while allowing the strongest source-grounded angle to surprise.

## Deploy When

Use after a journey and route exist, or when `/funnel-hack` produces evidence that should change a live or rehearsal funnel.
