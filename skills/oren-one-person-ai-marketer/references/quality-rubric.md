# Quality Rubric — The One-Person AI Marketing Machine

> Load on-demand for grading any deliverable produced by this skill. Score each criterion 0–2 (0 = absent, 1 = partial, 2 = fully met). A deliverable ships only if it scores ≥ 2 on every **GATE** criterion and ≥ 80% overall.

## The One-Line Test
**Does every deliverable carry both an explicit AI-leverage mechanic AND a taste gate, trace to a single better/faster/cheaper axis, and stay deployable this week by one operator?**

## GATE Criteria (a zero on any of these blocks delivery)

1. **Dual requirement.** Does the output carry BOTH an explicit AI-leverage mechanic AND a taste gate? (The skill's defining property. A workflow with leverage but no taste gate builds slop; with a gate but no leverage can't run solo.)
2. **The sameness diagnostic.** Was "Is sameness acceptable here?" answered, and was Class A (AI-assisted) vs Class B (human-voice-only) routed correctly? (Class B = founder POV, personal LinkedIn/IG, plain-text founder email → never AI final voice.)
3. **Substrate, not paste-and-pray.** Does every AI-touched asset trace to a real-customer-grounded persona + a NAMED copywriting framework loaded in a persistent Project — not "write me a version"?
4. **Deployable this week.** Is every recommendation a concrete action (trigger + tool + step) a solo operator could run this week, not a descriptive worldview observation?

## Core Criteria

5. **Macro placement explicit.** Is the deliverable anchored to a single better/faster/cheaper axis, with messaging derived from it (not drifting across all three)?
6. **Word-of-mouth before paid.** Does it engineer referral/virality FIRST (4-type audit + checkout affiliate + completion-moment ask) before any paid channel — not default to ads/content first?
7. **Deterministic referral.** Is the referral system triggered (project-completion gate + quarterly re-ask + gift) with the highest-conversion/lowest-CAC moment named — not a vague "ask for referrals"?
8. **Monthly MESSAGES cadence.** Are value-props refreshed monthly from the 4 friction channels (support / comments / competition / objections) + 1 trending hook, feeding UPSTREAM into all creative?
9. **Info-release / AEO.** Does each message fan out across the 6 surfaces, prioritizing the LLM-aggregated ones (Reddit / YouTube / articles) — engineering for answer-engine citation, not just human reach?
10. **Caps enforced, not just allocations.** Does it specify the weekly hour-budget AND the HARD CAPS (ads ≤4h, meetings ≤1h/day, "does it fit in logistics?" kill filter)?
11. **Performance in-housed + capped.** Is paid media treated as commoditized/in-house and time-boxed (two 2h blocks, Meta→Google→TikTok→YouTube), explicitly no agency?
12. **Organic = validation, not growth.** Is organic social treated as LAST and as cheap idea-validation, preserving the priority order (creative > performance > funnel > email > influencer >> organic)?
13. **Honest AI marking.** Is AI leverage marked HONESTLY — amplifier + research/clerical assist, with reaction-vs-structure and stated-vs-real JUDGMENT reserved as human strategic calls — never overclaiming AI makes the macro-timing or taste call?
14. **Org-chart-in-disguise preserved.** Does each block map to a future hire / double as the SOP and hiring sequence at scale?
15. **Voice fidelity.** Does it read like an in-the-arena operator (specific, named, time-boxed, anti-hype, allergic to sameness) per genius.md § Voice DNA — not guru-generic?
16. **Buyer/job/offer lock.** Is the funnel anchored to one buyer, purchased job, bounded offer, and honest commercial proof state?
17. **Journey states.** Are attention, lead, qualified, booked, held, sold, collected, fulfilled, retained, and referred kept distinct where relevant?
18. **One action per handoff.** Does every page, DM, email, call, or checkout earn one named next state with an owner and measurement?
19. **Route decision.** Is one primary route selected with rejected alternatives and prerequisites, rather than listing funnel types?
20. **Economics veto.** When CAC, conversion, fulfillment cost, repeat purchase, or LTV is missing, does the output say `ECONOMICS: UNPROVEN` and request the measurement?
21. **Permission veto.** Are all external assets visibly drafts/build specifications unless live action was explicitly authorized?
22. **Tool neutrality.** Can the plan run without Framer, Kit, HubSpot, or another named vendor?
23. **Learning retention.** Does the next test isolate one meaningful variable and write the learning into a destination that changes the next decision?

## The Irony Guard
This is an anti-slop skill. Its own output must not be slop. Scan for AI tells: "Here's what/why/how" openers, em-dash overuse, twin-sentence endings, triple anaphora, "It's not X. It's Y." If the deliverable about avoiding midbaseline content is itself midbaseline, it fails regardless of score.
