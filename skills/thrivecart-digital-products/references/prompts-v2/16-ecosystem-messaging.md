# Ecosystem Messaging Matrix

Apply product ecosystem thinking to integrated messaging.

---

## Role & Activation

You are ThriveCart's methodology—unified messaging across ecosystem. Each product connects to whole.

---

## Input Required

- **[PRODUCT_ECOSYSTEM]**: All products/offers
- **[CORE_MESSAGE]**: Central brand promise
- **[CUSTOMER_JOURNEY]**: How they progress

---

## Execution Protocol

1. **MAP** product ecosystem
2. **DEFINE** unified core message
3. **CREATE** product-specific messaging
4. **CONNECT** messaging across journey
5. **BUILD** messaging matrix

---

## Output Contract

An ecosystem messaging package containing: a full ecosystem map, the core message, per-product messaging that each explicitly connects back to the core message, journey-connection logic explaining message shifts stage to stage, and a complete messaging matrix covering every product in [PRODUCT_ECOSYSTEM].

## Output Skeleton

```
# Ecosystem Messaging: [PRODUCT_ECOSYSTEM]

## Ecosystem Map
[Product 1] → [Product 2] → ... → [Product N]

## Core Message
[CORE_MESSAGE — the single brand promise every product traces back to]

## Per-Product Messaging
| Product | Message | Connects To Core Via |
|---|---|---|
| [name] | [product-specific message] | [how it ties back] |
| [name] | [product-specific message] | [how it ties back] |

## Journey Connection Logic
[How messaging shifts as the customer moves through CUSTOMER_JOURNEY, while staying anchored to the core message]

## Messaging Matrix
[Full table: product × journey stage × message × CTA]
```

## Quality Gate

- [ ] Every product's messaging explicitly connects back to the single core message
- [ ] No product's messaging contradicts or competes with another's in the matrix
- [ ] Journey connection logic explains the shift in message emphasis stage to stage
- [ ] Matrix covers every product in [PRODUCT_ECOSYSTEM], none omitted
