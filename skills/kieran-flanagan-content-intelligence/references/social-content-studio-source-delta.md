## What Changes Kieran's Existing System

Kieran already owns the content firewall, portable context, single-capability skills, surplus generation, corpus building, and the compounding loop. This source adds six bounded mechanics:

1. **Prepare Brain before Focus.** Resolve identity, audience, voice, offer, visual grammar, corpus, and refusals as a named Context Lock.
2. **Person → Tension → Path.** Give the focus stage a compact commercial spine before format or production decisions.
3. **Refusal file.** Store rejected language, visuals, privacy breaches, proof inflation, and generic patterns as enforceable constraints.
4. **Surplus-selection distinction.** A month request creates inventory; it never means automatic publication or a promise to use every item.
5. **Five-stage run.** `Focus → Style → Plan → Create → Package` reduces ambiguity in dependency order.
6. **First-week adoption.** Start with one foundation, one seed, one test, and one repeated job. Expand only from observed use.
