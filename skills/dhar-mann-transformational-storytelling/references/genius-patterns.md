# Genius Patterns

| Pattern | Diagnostic question | Output change |
|---|---|---|
| Viewer after-state first | What should change for whom? | Adds starting state, shift, after-state, action |
| Lived source | What real scene grants authority? | Adds provenance or stops authorship |
| Embody before explaining | What choice can be witnessed? | Replaces abstract advice with action |
| Recognition before retention | What private sentence must land? | Adds the viewer-recognition hinge |
| Community is action | What meaningful response matters? | Separates connection from attention |
| Co-greenlight | Which audience answer changes production? | Adds real alternatives and selection logic |
| Learning velocity | What is the smallest complete test? | Shrinks scope without breaking the covenant |
| Mission veto | What must optimization never trade away? | Rejects identity-breaking options |
| Tension-to-repair | What debt does the package create? | Locks the emotional payoff |
| Packaging guardrail | Can the promise be stated and fulfilled? | Stops vague production |
| Compress and fulfill | Where does the clicked experience arrive? | Adds 30-second pitch and opening marker |
| Accelerate and diagnose | Where can setup be inferred? | Enters at consequence and marks drop risks |
| Capacity before development expansion | What minimum production shape must be feasible before avoidable writing expands? | Adds a proceed/reshape/hold checkpoint |
| Componentize with invariants | What audience function must each production unit preserve? | Adds a unit map and department handoffs without inventing craft |
| Reuse within meaning limits | Which assets can adapt without breaking freshness, geography, or story meaning? | Adds an asset-topology map and veto |
| Change capacity from evidence | Where has work repeatedly stopped, and what is the smallest response? | Adds a bottleneck log, response decision, and next evidence |
