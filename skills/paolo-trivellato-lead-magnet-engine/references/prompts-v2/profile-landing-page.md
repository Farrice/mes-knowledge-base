# Execution Prompt: LinkedIn Profile Rebuilt as Landing Page

## Role & Activation

You rewrite a LinkedIn profile as the funnel's landing page — the destination every post drives to. Source warning: "a broken landing page just burns the audience you are building." Four elements + two conversion paths, per the on-screen schema in `references/source-quotes.md`.

**Voice layer**: Farrice's profile → VOICE-CARD + dial first (binding).

## Input Required

`[OFFER]` — what's sold, to whom, at what outcome
`[AUTHORITY]` — rare credential/result material
`[ICP]` — who must convert (role, industry, dialect)
`[PROOF]` — client quotes + numbers (real only)
`[MAGNET]` — current lead magnet / newsletter for the featured section
`[CURRENT_PROFILE]` — existing copy (for the before/after and generic-phrase purge)

## Execution Protocol

1. **Headline** = outcome + timeframe + mechanism + authority statement, ONE niche only (multi-topic headlines confuse allocation). Kyle pattern: "Ex 8-figure agency COO — helping agencies fix their operations and scale to $10M/yr." Answers why-listen AND what-you-get.
2. **Purge check**: strip every flashy-generic phrase from `[CURRENT_PROFILE]` ("dad," "serial entrepreneur," multi-hyphenate titles).
3. **Custom button** (Premium): "Visit my website"/"Book an appointment" → calendar. The high-intent path books straight from the profile.
4. **Featured section** (the curious path): current `[MAGNET]` opt-in first, newsletter join, best case study pinned — "keep them moving down the funnel at their own pace."
5. **About = mini sales letter**, exact frame from source: call out the ICP → the pain point → the mechanism → 3–5 proof bullets (client quotes in quotation marks, real numbers from `[PROOF]`) → **one-word DM CTA** (About holds no clickable links; anything else is dead friction). Emotional target: stimulated to work with you, or feeling the fear of remaining the same.
6. **Two paths declared**: high intent → button; curious → featured → email. Note which post CTAs point where.

## Output Contract

**Deliverable: full profile rewrite**
1. Headline + 2 variants
2. Button config line
3. Featured lineup (ordered, with one-line rationale each)
4. Complete About text (ending in the one-word DM CTA)
5. Two-path note + before/after summary of what was purged

## Output Skeleton

```
# Profile Rebuild — [name]
## Headline
REC: [headline] · Alt: [v2] / [v3]
## Button
[label → destination]
## Featured (ordered)
1. [item — why]
## About
[full text → "...DM me '[WORD]'"]
## Paths + Purge
[high-intent/curious wiring · removed: [phrases]]
```

## Quality Gate

- [ ] Headline: outcome + timeframe + mechanism + authority, one niche?
- [ ] Zero generic-flashy phrases survive?
- [ ] About follows ICP→pain→mechanism→proof→one-word CTA exactly?
- [ ] Proof bullets are quoted/numbered real material?
- [ ] No links in About; button + featured carry the links?
- [ ] Both paths wired and named?

## Creative Latitude

Headline rhythm and About voice are open — the About should read like the operator talking, not a template. Where `[AUTHORITY]` is thin, the self-serving proposition ("my account is the case study") is the honest fallback — build the headline on specific experience counts or public results.

## Deploy When

Engine builds (step 2 of the spine); prospect audits that convert to rebuild work; quarterly profile refresh.
