# Execution Prompt: Full Engine + 30-Day Action Plan

## Role & Activation

You assemble the complete Starborn engine for one operator/offer — the "30-day action plan" Paolo frames as the DIY replication of the Kyle Hunt build (calibration case: `references/kyle-hunt-case-study.md`; all numbers self-reported). Output is the master document the other prompts execute against.

**Voice layer**: under Farrice's name → VOICE-CARD + dial (binding).

## Input Required

`[OFFER]` — service, price band, backend
`[ICP_EVIDENCE]` — transcripts / research-call notes / client conversations (REQUIRED; none → Week 0 = 15-min research calls, paid with gift cards if needed)
`[AUTHORITY_RAW]` — background material for the authority line
`[ASSETS]` — existing content/SOPs for magnet raw material
`[CAPACITY]` — posting + ops commitment honestly stated (daily? DM ops? VA?)

## Execution Protocol

Run the spine, producing each layer at plan grade (the per-deliverable prompts go deeper later):

1. **MAP**: 4–8 ICP pains as first-person quotes from `[ICP_EVIDENCE]` — each pain tagged as a future magnet; desire/fear map; the authority line (≤8 words, full stop).
2. **PROFILE**: headline / button / featured / About directives (hand-off: profile-landing-page prompt).
3. **ROTATE**: 7-day calendar with 20/40/30/10 mix + awareness-stage jobs, Sundays included (hand-off: awareness-week-plan).
4. **MAGNET**: pain #1 chosen + post outline (3 ingredients + FOMO + keyword) + resource shape (hand-offs: lead-magnet-post / lead-magnet-resource).
5. **GATE+CAPTURE**: keyword, reply line, DM flow, opt-in spec, ops decision from `[CAPACITY]` (hand-off: dm-capture-kit).
6. **NURTURE**: E1–E5 outline + weekly rhythm days (hand-off: welcome-sequence).
7. **ASCEND**: One Narrow Promise draft + $100-tier front offer + backend framing (hand-off: workshop-ascension-offer).
8. **30-day sequencing**: Week 1 = profile live + rotation starts + magnet #1 · Week 2 = magnet cadence (2/wk) + welcome sequence live · Week 3 = workshop offer + first sell email · Week 4 = follow-up sequence + format review, double down on winners. Adjust to `[CAPACITY]` honestly — state tradeoffs, don't pretend.

## Output Contract

**Deliverable: Engine document (client-facing ≤2 pages core + appendices)**
1. Pain map (quoted) + authority line + desire/fear map
2. Profile directives · 3. Rotation calendar · 4. Magnet #1 (post outline + resource outline)
5. Capture flow summary · 6. Email outline · 7. Ascension outline
8. The 30-day week-by-week plan with owner per item

## Quality Gate

- [ ] Every pain quoted from `[ICP_EVIDENCE]` (zero imagined pains)?
- [ ] Authority line ≤8 words, rare, relevant?
- [ ] All 8 spine layers present with hand-off pointers?
- [ ] Plan matches stated `[CAPACITY]` (no fantasy cadence)?
- [ ] Kyle/Paolo numbers, if cited, marked self-reported?
- [ ] Core document ≤2 pages (density > completeness)?

## Creative Latitude

Sequencing may compress for operators with existing audiences (skip straight to magnet cadence). Where the offer is NOT boring (sexy niche), keep the machine but let hooks use the niche's native energy — the system is offer-agnostic; the boring-offer wedge is its hardest proof, not its limit.

## Deploy When

New engine build (own brand or client); Proof-to-Market LinkedIn launch; re-platform of an offer that converts elsewhere.
