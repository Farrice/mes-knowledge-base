# Execution Prompt: Comment-Gated Lead Magnet Post

## Role & Activation

You execute Starborn AI's lead-magnet post method (Paolo Trivellato) — the format behind Kyle Hunt's 1,000–4,000-comment posts (self-reported). Three ingredients in order, then an honest FOMO stack, then a one-word comment gate. The post's job is comments and profile views; the funnel behind it does the selling.

**Voice layer**: if this ships under Farrice's own name, load `_active/farrice-brand/voice/VOICE-CARD.md` + dial mode first (binding `farrice_voice_alignment`).

## Input Required

`[PAIN]` — the ONE pain this magnet solves, ideally as an ICP first-person quote
`[AUTHORITY]` — the author's rare, relevant credential (raw form; you will compress it)
`[RESOURCE]` — what's behind the gate: name + the 3–5 concrete things inside
`[ICP]` — who reads this (role, industry, dialect notes)
`[KEYWORD]` — comment gate word (or propose one: short, relevant, brandable)
`[FOMO_FACTS]` — which exclusivity/urgency claims are actually true (paid-client-only? takedown date? capacity?)

## Execution Protocol

1. **Authority line** — compress `[AUTHORITY]` to ≤8 words, full stop, as sentence one. Bar: "I am an eight-figure agency COO." Must be rare (few could claim it) and exactly relevant to `[PAIN]`. Reader test: "what's next?"
2. **Outcome line** — the dream state + removal of pain: "You can scale to 500K a month and remove yourself from the business."
3. **Pain descent** — 2–4 present-tense lines in the ICP's dialect ("Right now you're probably..."). Target feeling: "this person is in my head." Use `[PAIN]`'s verbatim phrasing where given.
4. **Bridge + reveal** — the skeleton (verbatim on-screen template): "I spent X years as [role] at a [size] agency. The [stage] was [pain]. So I wrote a step by step [resource] that takes you from [bad state] to [desired state] without [annoying thing]." List the 3–5 spec'd deliverables from `[RESOURCE]` — named, concrete, no vague "guide."
5. **FOMO stack** — 1–2 lines drawn ONLY from `[FOMO_FACTS]` ("This is what we only give to paid clients" / "My team is not going to be happy about this" / "Taking this down in 24 hours"). Nothing manufactured.
6. **Comment CTA** — "Comment [KEYWORD] and I will send it." No link anywhere in the post. Add the publishing note: edit a direct link in only after engagement tapers.

## Output Contract

**Deliverable: publish-ready LinkedIn post + operational notes**
1. The post (line-broken for LinkedIn skim rhythm)
2. Keyword + first comment-reply line ("check your DMs" form)
3. Deliverables list handed to the resource build (if resource not yet built)
4. Post-viral link plan (one line)
Length: post 120–220 words. No hashtag walls; no links.

```

Keyword: [WORD] · Reply line: [text] · Link-after-taper: [when/where]

- [deliverable 1..5]
```

## Quality Gate

- [ ] Authority line ≤8 words, sentence one, full stop, rare + relevant?
- [ ] Pain in ICP dialect, present tense — would the ICP say "in my head"?
- [ ] One pain only (no ultimate-guide sprawl)?
- [ ] Every FOMO claim true per `[FOMO_FACTS]`?
- [ ] Zero links; single keyword gate?
- [ ] No AI tells / slop-bank phrases (run prose check on client-facing output)?

## Creative Latitude

The skeleton fixes the sequence, not the sentences. Push on: the outcome line's specificity, the pain descent's observed detail (real Tuesday-afternoon texture beats category language), an unexpected-but-true FOMO angle, keyword wordplay the ICP would enjoy. Trend-jack runs may restructure the hook to name the trending tool first — authority line then moves to line two, nothing else changes.

## Deploy When

Any comment-gated giveaway post; 1–3×/week per account; trend-jack variant via /pt-trend-jack.
