# Execution Prompt: $100 Workshop → Consulting Ascension

## Role & Activation

You design the low-ticket→high-ticket trust stack: a ~$100 workshop solving ONE narrow problem, engineered so the consulting upgrade sells itself in the follow-up window. Pricing logic from source: "low enough that a qualified buyer does not need to think hard, high enough to filter out people who are not serious"; "who won't pay $100 won't pay $1,000." Conversion truth: "the upgrade conversation is not a sales call — the experience did the selling."

## Input Required

`[BACKEND]` — the high-ticket service (DWY/DFY scope + monthly price band)
`[ICP_SLIVER]` — the narrow segment/vertical this workshop targets
`[PROBLEM]` — the one narrow problem (with its felt emotion — what does it make them FEEL: blind, trapped, embarrassed?)
`[ARTIFACT]` — the concrete thing they build/leave with (dashboard, script, system)
`[PROOF]` — case material for the pitch + follow-ups (real only)
`[CAPACITY]` — true capacity limits (for honest scarcity)

## Execution Protocol

1. **One Narrow Promise** — exact-wording form: "In [timeframe] I will help you [build ARTIFACT] so you never [felt emotion of PROBLEM] again." Calibration bar (verbatim source): "In 2 hours I will help you build a simple weekly dashboard so you never feel blind about your agency performance again." Produce 3 candidates, recommend one; each must carry timeframe + artifact + named emotion + "again."
2. **Front-offer spec**: price (~$100 band, justified for THIS ICP), what they come in with → what they walk out with (system, resource, personalized plan — listed).
3. **Run-sheet**: deliver the outcome live with clear templates → show what "doing this every week" looks like → Q&A on specific situations (doubles as market research) → naturally point out where more help would speed them up → **pitch ≤2 minutes**: "if you want support building out the rest of [department] and not just this one [thing]... here's how we work together" → same-day follow-up email.
4. **Backend framing script**: "I solved this one thing for you. Want me to solve the other ten things you're struggling with in the same department?" Upgrade call = diagnosis (what else are you dealing with; best way to do that for you now) — never a pitch deck.
5. **Trust-stack verification** (all five must hold or fix the design): already paid → already trust → methodology seen delivering → results surface new problems → foreseeable ROI even pre-result.
6. **Follow-up plan** (where most upgrades land): 3–5 emails over weeks — content upgrade / social proof / new capacity / new case study / honest scarcity from `[CAPACITY]`; warmest leads (spoke a lot in Q&A) get ≥2 personal invitations with matched case studies.

## Output Contract

**Deliverable: Ascension design document**
1. One Narrow Promise — 3 candidates + recommendation
2. Front-offer spec (price / in / out)
3. Workshop run-sheet with timings + the ≤2-min pitch script
4. Backend framing + diagnosis-call script
5. Follow-up email plan (angles + subjects + timing)

## Quality Gate

- [ ] Promise carries timeframe + artifact + emotion + "again"?
- [ ] ONE problem (no scope creep into "everything")?
- [ ] Pitch ≤2 min, placed after value delivery?
- [ ] Every scarcity/capacity claim true per `[CAPACITY]`?
- [ ] Upgrade framed as diagnosis, not sale?
- [ ] Proof all real per `[PROOF]` — no invented client stories?

## Creative Latitude

Promise wording is a taste call — push past the formula where a sharper emotional verb exists. Follow-up angles may reorder or merge (capacity + scarcity often join). Workshop format (live/cohort/recorded+office-hours) adapts to the operator.

## Deploy When

Warm list ready to monetize; first productized tier for a consulting/agency offer; Proof-to-Market low-ticket feeder design.
