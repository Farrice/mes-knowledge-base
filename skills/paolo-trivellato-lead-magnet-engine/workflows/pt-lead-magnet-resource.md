# /pt-lead-magnet-resource — The Resource That Converts

The post gets the comment; the resource earns the trust and starts the sale. "Number one: super valuable. Number two: actually needs to convert."

## Pre-Flight Gate

- **One pain = one resource.** Multi-pain brief → split.
- **Source the substance from real assets**: SOPs, call transcripts, delivered client work, existing blog/course material. "Every business has content they've already made" — repurpose; never generate generic filler. No real substance available → say so; a thin resource burns the audience.
- Format ceiling check: can this be a prompt/template they paste for instant output? If yes, that shape wins (silver-platter physics).

## Skill Acquisition

- `genius.md` — MAGNET step, Copy-Paste Solution Bias, Quality Rubric
- `references/source-quotes.md` — V2 3:28 (20/80 concision), V1 15:37 (Claude-magnet physics)

## Execution

1. **Promise restated** as before → after (mirrors the post's bridge sentence).
2. **Structure as steps**: numbered, each with a do-this action; screenshots/examples where they remove ambiguity. Nobody reads 50 pages of plain text — compress to the 20% that gets 80%.
3. **Make it copy-paste**: include the actual template/prompt/checklist artifact — not a description of one. Claude-prompt magnets: full prompt text, input slots marked, expected output described.
4. **Place CTAs by seller type**: agency/consultant → book-a-call CTA top or bottom; SaaS → product mentioned at the step where it naturally slots; personal brand → newsletter/next-resource pointer.
5. **Quick-win engineering**: the reader must get a visible result within 24h (the same principle as welcome E3).
6. **Package**: short Notion guide (his default) or equivalent low-friction format; preview screenshot exported for the opt-in page.

## Content Type Adaptations

| Resource type | Adaptation |
|---|---|
| Prompt/AI giveaway | Prompt is the artifact; add 3-line usage guide + example output |
| Blueprint/system | Steps + the template file; "what doing this every week looks like" section |
| Case-study breakdown | Numbers → decisions → replicable steps; CTA stronger (sales asset) |
| Checklist/audit | Scored items; "if you checked >N, [CTA]" bridge |

## Output Requirements

The complete resource (publishable), CTA(s) placed, preview screenshot description, one-line delivery summary for the DM ("I put the breakdown into a short Notion guide so it's easy to use").
Execution prompt: references/prompts-v2/lead-magnet-resource.md — honor its Output Contract.

## Quality Gate

Copy-paste test (usable today without questions?) · 24h-win test · one-pain test · CTA present but not spammy · zero ChatGPT-slop tells · substance traceable to real assets, not invention.
