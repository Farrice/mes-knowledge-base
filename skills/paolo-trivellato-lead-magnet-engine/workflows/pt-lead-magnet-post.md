# /pt-lead-magnet-post — The 3-Ingredient Lead Magnet Post

Produces the LinkedIn post that gives a resource away behind a one-word comment gate. The format behind Kyle's 1,000–4,000-comment posts (self-reported).

## Pre-Flight Gate

- **One pain, chosen.** If the brief says "our ultimate guide to X," stop — cut to ONE painful problem (plaster model). The rest are future posts.
- **The resource must exist or be in build** (`/pt-lead-magnet-resource`). Never post a gate with nothing behind it — FOMO must be honest.
- **Authority line derived?** If the client has no rare credential yet, the fallback is a specific result or specific experience count — never a generic title.

## Skill Acquisition

- `genius.md` — MAGNET + GATE steps, Decision Framework
- `references/source-quotes.md` — post skeleton, FOMO lines, hook exemplars
- Farrice's own voice → VOICE-CARD + dial (binding)

## Execution

1. **Authority line** (≤8 words, full stop): rare + exactly relevant to the pain. Test: does an ICP reader ask "what's next?"
2. **Hook line 2**: outcome + removal-of-pain ("You can scale to 500K a month and remove yourself from the business").
3. **Pain descent** (2–4 lines, ICP dialect, present tense — "Right now you're probably..."): pass the in-my-head test.
4. **Bridge + resource reveal** via the skeleton: "So I wrote a step by step [resource] that takes you from [bad state] to [desired state] without [annoying thing]." Name 3–5 concrete things inside (spec'd, not vague).
5. **Perceived-value / FOMO stack** (1–2 lines, all true): paid-client exclusivity / team-won't-be-happy / 24h takedown.
6. **Comment CTA**: one relevant keyword, no link. ("Comment [WORD] and I will send it.")
7. **Post-viral plan note**: when engagement tapers, edit in the direct link.

## Content Type Adaptations

| Context | Adaptation |
|---|---|
| Trend-jack magnet | Trending tool named IN the hook (see /pt-trend-jack) |
| Case-study magnet | Hook = transformation numbers; expect lower virality, highest intent |
| Compliance-bound niche (health/finance) | Specificity on outputs/time/process — never income claims |
| Client ghost-written | Their authority line, their dialect — pull from onboarding interview |

## Output Requirements

The finished post (ready to publish) + keyword + the 3–5 promised deliverables list (handed to `/pt-lead-magnet-resource` if not yet built) + first comment-reply line ("check your DMs").
Execution prompt: references/prompts-v2/lead-magnet-post.md — honor its Output Contract.

## Quality Gate

genius.md rubric rows: authority line ≥7, pain ≥7, FOMO honest, funnel (keyword + no link). Prose check: no AI tells (`prose_classifier.py` on client-facing runs). Would a skeptic still comment ("no harm in a quick comment")?
