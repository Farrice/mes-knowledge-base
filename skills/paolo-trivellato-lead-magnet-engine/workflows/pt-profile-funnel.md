# /pt-profile-funnel — Profile as Landing Page

Every post drives profile traffic; "a broken landing page just burns the audience you are building." Rebuilds all 4 elements plus the two conversion paths.

## Pre-Flight Gate

- Offer + ICP + authority credential known (else MAP first).
- If the current profile says "dad," "serial entrepreneur," or any flashy generic phrase — that's the before-state; strip it all.

## Skill Acquisition

- `genius.md` — PROFILE step
- `references/source-quotes.md` — profile schema (on-screen artifact)
- Farrice's own profile → VOICE-CARD layer

## Execution

1. **Headline** = outcome + timeframe + mechanism + authority statement. Kyle pattern: "Ex 8-figure agency COO — now helping agencies fix their operations and scale to $10M/yr." Why-listen + what-they-get in one line. One clear niche only (multi-topic headlines confuse allocation).
2. **Custom button** (Premium): "Visit my website" / "Book an appointment" → calendar. Highest-visibility element; high-intent path books directly from the profile.
3. **Featured section**: the curious path — opt-in page for the current lead magnet, newsletter join, best case study pinned. For the not-ready: "keep them moving down the funnel at their own pace."
4. **About = mini sales letter**, exact frame: call out the ICP → the pain point → the mechanism you use → 3–5 proof bullets (client quotes in quotation marks, real numbers) → **one super-clear one-word DM CTA** (About holds no clickable links — anything else is dead friction). After reading: stimulated to work with you, or feeling the cost of staying the same.
5. **Two paths declared**: high intent → button → call. Curious → featured → email list. Every post CTA points at one of them.

## Content Type Adaptations

| Profile | Adaptation |
|---|---|
| Consultant/agency (Kyle-shaped) | As documented |
| SaaS founder | Button → product demo; About mechanism = product-led story |
| No credentials yet | Authority = specific experience/results ("analyzed 2,000 viral posts"), self-serving proposition: your account is the case study |
| Client rebuild | All copy from onboarding interview; their dialect |

## Output Requirements

Full rewrite deliverable: headline (+2 variants), button config, featured lineup (ordered), complete About text, DM keyword, two-path diagram note.
Execution prompt: references/prompts-v2/profile-landing-page.md — honor its Output Contract.

## Quality Gate

Headline passes why-listen + what-you-get? · Zero generic-flashy phrases? · About ends in one-word DM CTA (no links)? · Proof bullets concrete (quotes/numbers)? · Both paths wired?
