# /pt-lead-engine — The Full Boring-Offer Engine (front door)

Builds the entire system Starborn delivered to Kyle Hunt as one coherent plan: pain map, profile rebuild, content rotation, lead-magnet calendar, capture flow, email engine, workshop ascension — sequenced as a 30-day action plan.

## Pre-Flight Gate

- **An actual offer must exist** (service, price band, deliverable). No offer → route to offer work (`/jh-offer-stack`, `/design-offer`) first; this engine distributes and converts, it doesn't invent the thing sold.
- **ICP evidence check**: call transcripts, client conversations, or research-call access. None available → the plan's Week 0 becomes 15-min market-research calls (genius.md MAP; pay gift cards if needed). Never fabricate the pain map from imagination.
- Boring offer? Good — that's the wedge. Do not manufacture flashy hooks or income claims.

## Skill Acquisition

- `genius.md` — full spine + Decision Framework + Anti-Patterns
- `references/kyle-hunt-case-study.md` — the calibration case
- `references/source-quotes.md` — verbatim templates (post skeleton, DM scripts, promise wording)
- If output ships in Farrice's own voice: `_active/farrice-brand/voice/VOICE-CARD.md` + dial mode (binding `farrice_voice_alignment`)

## Execution

1. **MAP** — Extract 4–8 ICP pains as first-person quotes (transcripts > research calls > competitor comments). Each pain = one future lead magnet. Add desire/fear map (who they want to be; what would break them). Derive the **authority line** (≤8 words, rare, relevant, full stop).
2. **PROFILE** — Rebuild all 4 elements as a landing page (headline outcome+timeframe+mechanism+authority; custom button → calendar; featured → opt-in; About = ICP call-out → pain → mechanism → proof bullets → one-word DM CTA). Define the two paths (high-intent/curious).
3. **ROTATE** — 7-day calendar, daily incl. Sunday: 20/40/30/10 personal/authority/educational/social-proof, each post tagged with its awareness-stage job. Objections-as-hooks fill solution-aware slots.
4. **MAGNET** — Pick pain #1 → build the first resource (one pain, copy-paste shape, CTAs inside) + its post (3 ingredients + FOMO stack + keyword comment CTA, no link).
5. **GATE + CAPTURE** — comment-reply script, DM scripts (verbatim from source-quotes), opt-in page spec (name+email+preview), refusal fallback, ops decision (time block / VA / automation-at-own-risk).
6. **NURTURE** — welcome E1–E5 (subjects from source-quotes) + weekly rhythm (3/week, same days, 2 value + 1 sell).
7. **ASCEND** — $100 workshop: One Narrow Promise in the exact-wording form; inside-the-workshop arc (deliver live → weekly view → where help speeds them up → 2-min pitch); follow-up sequence (3–5 emails: upgrade/social-proof/capacity/case-study/honest-scarcity); warmest-lead personal invitations.
8. **Assemble the 30-day plan**: Week 1 = profile + rotation live + magnet #1 · Week 2 = magnet cadence 2/week + welcome sequence live · Week 3 = workshop offer + first sell email · Week 4 = follow-up sequence + review winning formats, double down.

## Content Type Adaptations

| Client type | Adaptation |
|---|---|
| Agency/consultant (Kyle-shaped) | Run as documented; book-a-call CTA inside resources |
| B2B SaaS | Softer resource CTA — mention product at the natural step, founder-led voice |
| Spam-sensitive niche | 1–2 magnets/month, not weekly; authority content carries the load |
| Farrice/Proof-to-Market | VOICE-CARD layer mandatory; compliance: specificity on outputs/time, never income claims |

One engine document: pain map (quoted), authority line, profile rewrite (all 4 elements written out), 7-day rotation calendar, magnet #1 (post + resource outline), capture scripts, E1–E5 outlines, workshop promise, 30-day plan. Client-facing: ≤2 pages density rule; depth lives in appendices.
