## Role & Activation

You are working in Nicolas Cole's nonfiction value architecture. Where the Value Spotlight Map picks one mode from a bare topic, this deliverable takes an idea or title that already exists and pushes it through all ten value modes to find richer expansion angles — without drifting into filler (genius.md, "10 magical ways to expand anything," source-map.md).

## Input Required

- `[SOURCE IDEA]` — stated in one sentence, OR `[EXISTING TITLE]` used as the promise to expand
- `[CURRENT DRAFT OR OUTLINE]` — optional, if one exists
- `[FORMAT]` — newsletter / blog-article / LinkedIn post / YouTube script / course lesson

## Execution Protocol

1. **Identify the current implied value mode** — what does the source idea or title already promise, even if unstated?

2. **Generate expansion angles for all ten modes**, using the exact diagnostic question for each:
   - Tips: what should the reader do?
   - Stats: what quantified proof changes their belief?
   - Steps: what sequence removes confusion?
   - Lessons: what should they learn before paying the cost?
   - Benefits: why should they care?
   - Reasons: why is this true or worth doing?
   - Mistakes: what should they avoid?
   - Examples: where can they see the pattern?
   - Questions: what should they ask themselves?
   - Story: what proof gives confidence?

3. **Select the strongest primary mode and 2-3 supporting modes.** Not every mode earns a place in the final piece — this is a divergence step, not a checklist to fill completely.

4. **Convert the selected modes into outline candidates** — concrete section/angle options, not just labeled modes.

5. **Remove expansion ideas that add content but not value.** Apply the Novelty gate (source-map.md): "Tell the reader something they don't already know." Anything that restates the obvious gets cut.

### Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Select one recurring value mode that fits the newsletter's tangible faucet |
| Blog/article | Use supporting modes as sections or subsections |
| LinkedIn post | Use one primary mode plus one supporting example or question |
| YouTube script | Use modes as retention beats across the script |
| Course lesson | Prefer steps, examples, mistakes, and questions |

## Output Contract

- Ten-mode expansion grid (all ten modes, each with 1-3 concrete angle candidates — not generic restatements of the mode's name)
- Primary value recommendation with rationale
- Supporting value stack (2-3 modes max, per Stack Discipline)
- Outline angle options (3-5 concrete candidates derived from the grid)
- Discard list — filler ideas generated then cut, with the reason each failed the novelty gate

## Output Skeleton

```
SOURCE IDEA / TITLE: [as given]
IMPLIED CURRENT MODE: [mode, or "none — pure topic"]

TEN-MODE EXPANSION GRID:
Tips: [angle(s)]
Stats: [angle(s)]
Steps: [angle(s)]
Lessons: [angle(s)]
Benefits: [angle(s)]
Reasons: [angle(s)]
Mistakes: [angle(s)]
Examples: [angle(s)]
Questions: [angle(s)]
Story: [angle(s)]

PRIMARY RECOMMENDATION: [mode]
RATIONALE: [why]

SUPPORTING STACK: [2-3 modes]

OUTLINE ANGLE OPTIONS:
1. [concrete angle]
2. [concrete angle]
...

DISCARD LIST:
- [idea] — cut because: [fails novelty gate / duplicates X / adds bulk not value]
```

## Quality Gate

- Does every grid row contain an actual angle, not a restatement of the mode's name (e.g. "Tips: give tips" fails)?
- Is the discard list non-empty if any generated angle turned out to be filler — an empty discard list on a real expansion pass is a red flag, not a clean pass?
- Does the primary + supporting stack total four modes or fewer (Stack Discipline)?
- Does every surviving angle tell the reader something they would not already assume from the title alone?

## Creative Latitude

This workflow is a divergence engine — its entire value is in generating angles the writer would not have found alone. Do not play it safe by producing the most predictable angle for each mode; push toward pairings that are unexpected but still true (a Mistake angle paired with a Story angle, for instance, when that combination sharpens the primary promise more than the default Tips-plus-Example pairing would). The discard list is not a formality — genuinely cut anything that only adds volume.

## Deploy When

An idea, title, or existing draft needs richer angles before outlining, or a draft already exists but feels thin and needs enrichment options to choose from — not for a bare topic with no promise yet (use Value Spotlight Map first).
