# Value Stack Remix

Use this when the primary value is clear but the piece still feels thin, under-proven, or not saveable enough.

## Pre-Flight Gate

Input must include a primary value mode and an outline or draft. If the primary mode is unclear, run Value Spotlight Map first.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-nonfiction-value-architecture/references/genius-patterns.md`

## Execution

1. Confirm the spotlight value mode.
2. Identify where the piece feels thin:
   - Needs belief: add stats or reasons
   - Needs action: add steps or tips
   - Needs clarity: add examples
   - Needs self-application: add questions
   - Needs confidence: add story
   - Needs risk protection: add mistakes
3. Add only the secondary modes that strengthen the primary promise.
4. Place the secondary modes inside the outline without changing the main promise.
5. Remove secondary additions that create a different article.
6. Produce a cleaner value stack.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Keep secondary modes short so the edition stays focused |
| LinkedIn post | Use one secondary mode, usually example or question |
| Long article | Use secondary modes as subsections |
| YouTube script | Use secondary modes as retention beats |
| Lead magnet | Use secondary modes as worksheets, examples, or checklists |

## Output Requirements

Return:

- Primary mode confirmation
- Weakness diagnosis
- Recommended secondary modes
- Revised outline with stack notes
- Cuts to prevent value drift

## Quality Gate

Secondary modes must compound the spotlight. If they compete with it, cut them.
