# Nonfiction Outline Architect

Use this when the user needs a full outline for a newsletter, article, post, script, lesson, or lead magnet.

## Pre-Flight Gate

Input must include audience, topic, and desired format. If the audience is broad, define the reader's current problem before outlining.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-nonfiction-value-architecture/references/quality-rubric.md`

## Execution

1. Define the reader's current state and desired state.
2. Choose the spotlight value mode.
3. Build the list of primary deliverables.
4. Run the Specificity Ladder on each deliverable.
5. Add supporting modes where useful:
   - Stat to strengthen belief
   - Example to create pattern recognition
   - Question to create self-diagnosis
   - Story to create confidence
6. Create title options that clearly promise the value.
7. Create subheads that act as receipts for the title.
8. Add draft notes under each subhead: what to say, what not to say, and what proof/example/question to include.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Include intro promise, 3-5 value sections, and closing reader action |
| LinkedIn post | Compress to hook, 3-5 points, and final implication |
| Long article | Include sections, examples, and transitions |
| YouTube script | Include cold open, promise, beats, and retention questions |
| Lead magnet | Include checklist/tool/template shape |

## Output Requirements

Return:

- Reader state map
- Spotlight value mode
- Title options
- Value-first outline
- Specific subheads
- Support-mode notes
- Drafting brief

## Quality Gate

The outline must be useful before the body is written. If the subheads do not already give value, revise the outline.
