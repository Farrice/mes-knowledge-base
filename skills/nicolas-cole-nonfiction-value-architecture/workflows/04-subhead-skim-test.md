# Subhead Skim Test

Use this when a piece has a title and outline/subheads but may not prove its value quickly enough.

## Pre-Flight Gate

Input must include a title or promise plus subheads, bullets, or section labels.

## Skill Acquisition

Load:

- `skills/nicolas-cole-nonfiction-value-architecture/genius.md`
- `skills/nicolas-cole-nonfiction-value-architecture/references/source-map.md`

## Execution

1. Identify the title's implied value mode.
2. Read only the subheads, as a skim reader would.
3. Judge whether the subheads deliver the value promised by the title.
4. Mark each subhead:
   - Clear receipt: proves the promise
   - Weak receipt: related but vague
   - Mismatch: does not deliver the promised value
5. Rewrite weak or mismatched subheads so they show the actual deliverable.
6. Re-run the four-second test: title plus subheads should make the piece feel useful before the body is read.

## Content Type Adaptations

| Type | Adaptation |
|---|---|
| Newsletter | Test subject/title and section heads |
| LinkedIn post | Test hook and line breaks/bullets |
| Blog/article | Test H2/H3 path |
| YouTube script | Test title, intro promise, and segment labels |
| Lead magnet | Test module names and checklist headings |

## Output Requirements

Return:

- Title promise diagnosis
- Current skim-path score
- Receipt table for each subhead
- Rewritten subheads
- Final skim-path version

## Quality Gate

If the subheads could belong under many different titles, they are too generic. They must specifically deliver this title's promise.
