# Lamott → Pressfield Dual-Mode Unblocking

## Role
Two different approaches to the same enemy. Lamott dissolves Resistance through tenderness — befriending the critic, giving permission, removing pressure. Pressfield confronts Resistance through discipline — identifying it as the enemy, sitting down, doing the work. This stack deploys Lamott first (dissolution). If that doesn't break the block within 30 minutes, Pressfield enters (confrontation).

**Why this order**: Tenderness first because most blocks are fear-based, and fighting fear creates more fear. But some blocks are discipline-based — the writer knows what to do but won't do it. For those, Lamott's gentleness enables avoidance. Pressfield's warrior cuts through.

## When to Use
- You've been stuck for more than 48 hours
- Single-expert unblocking hasn't worked
- You don't know if your block is emotional or behavioral

## Input Required
1. **[Project]**: What you're stuck on
2. **[Duration]**: How long you've been stuck
3. **[Previous Attempts]**: What you've tried (including which Antigravity workflows)
4. **[Emotional State]**: Scared, ashamed, bored, angry, numb, or "I don't know"

> **🔒 Pre-Flight Gate**: If the writer reports they haven't tried ANY unblocking — including `/lamott-unblock` — start there first. This dual-mode stack is for blocks that have resisted single-expert intervention.

## Workflow

### Mode A: Lamott Dissolution (30-Minute Window)
Deploy the tender approach first.

1. **Diagnosis**: Run `/lamott-unblock` Phase 1 — identify block type (Emptiness, Pressure, Fear, Perfectionism, Structural).
2. **Matched Treatment**: Deploy the matching tool from `/lamott-unblock` Phases 2-5.
3. **Timer**: Set 30 minutes from start of Mode A. If the writer is writing by minute 30, Mode A succeeded. Stay in Lamott territory.
4. **Escalation Trigger**: If at minute 30 the writer is NOT writing and reports the block is still present, proceed to Mode B.

### Mode B: Pressfield Confrontation
Deploy the warrior approach.

1. **Name the Enemy**: Pressfield's Resistance is not your inner critic. It's not fear. It's a force — like gravity. Impersonal. Predictable. It shows up every day at the same time. It doesn't care about your feelings.
2. **The Professional Standard**: "The amateur waits for inspiration. The professional sits down at 9 AM." You don't have to feel like writing. You have to write.
3. **The Territory vs. Hierarchy Check**: Are you writing for the work itself (territory) or for approval (hierarchy)? If hierarchy — the block is Resistance using vanity as a weapon. Return to territory: what does the WORK need right now?
4. **Sit Down**: Set a timer for 60 minutes. Open the document. Start typing. It doesn't matter what comes out. Resistance loses the moment you sit down. Every word after that is a victory.
5. **Do Not Leave**: The urge to get up, check your phone, make coffee, "just quickly" do something else — that IS Resistance. Name it. Stay seated.

### Mode C: Integration (If Both Modes Produce Writing)
If the writer began writing during either mode:
1. **Assess Which Mode Worked**: Was it the tenderness or the discipline? This reveals the writer's primary block pattern.
2. **Build the Protocol**: For future blocks:
   - If Lamott worked → the writer's blocks are primarily emotional. Default to `/lamott-unblock` first.
   - If Pressfield worked → the writer's blocks are primarily behavioral. Default to `/resistance` first.
   - If BOTH were needed → the writer has compound blocks. Always run both modes in sequence.
3. **Document**: Add to the writer's creative profile — "Block Pattern: [emotional / behavioral / compound]."

### Mode D: Nuclear Option (If Neither Mode Works)
If after 90 minutes total (30 Lamott + 60 Pressfield) the writer has produced zero words:
1. **Emptiness Diagnosis**: This is likely not a block but genuine emptiness. Deploy Phase 0 of `/lamott-observe` — stop writing entirely for 24-48 hours.
2. **Burnout Check**: Has the writer been producing at high volume? The block may be the body's wisdom, not Resistance. Rest is not avoidance.
3. **Project Assessment**: Is the project itself the problem? Sometimes the block is your subconscious telling you this isn't the right project, angle, or voice. Ask: "If I could write anything right now — with no obligations — what would it be?"

## Output Contract
1. **Block Diagnosis**: Type identified (emotional, behavioral, compound, emptiness)
2. **Mode That Worked**: A or B (or neither → nuclear option)
3. **Writing Produced**: At least one paragraph from the session
4. **Writer Profile Update**: Block pattern documented for future reference
5. **Prevention Protocol**: Specific morning routine recommendation based on block pattern

## Quality Gate
1. Lamott mode deployed FIRST (not skipped in favor of "just push through")
2. Correct escalation — Pressfield only after Lamott had 30 minutes
3. Writing produced within 90 minutes total (or nuclear option correctly triggered)
4. Block pattern documented for future sessions
5. The tone matched the mode — tender in Mode A, disciplined in Mode B. Never harsh in either.

> **🛡️ Anti-Pattern Check**: If Mode B sounds cruel ("stop being lazy," "you're just making excuses"), Pressfield is being deployed wrong. Pressfield is NOT a drill sergeant — he's a professional describing the professional's relationship with work. Firm, impersonal, respectful. The enemy is Resistance, not the writer.
