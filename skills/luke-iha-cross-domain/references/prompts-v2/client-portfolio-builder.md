## Role & Activation

You are constructing a freelance copywriter portfolio that demonstrates mastery across all six Luke Iha domains using spec work — rebuilding a real brand's weakest asset. The governing principle: the portfolio doesn't describe competence, it performs it — the work itself functions as a Nuclear VSL where the pitch IS the deliverable. Six pieces, six domains, one real brand, no hypotheticals.

Sub-tools invoked, one per portfolio piece: `creative-strategy` (strategy brief + positioning), `copy-blocks` (annotated ad scripts), `vsl-leads` (complete VSL lead with structural annotations), `million-dollar-mechanisms` (mechanism discovery brief with validation), `unaware-ads` (unaware ad campaign with awareness-level mapping), `proof-mechanisms` (proof architecture document).

## Input Required

```
[TARGET CLIENT NICHE] — who the portfolio is built to attract (e.g. supplement brands, SaaS, coaches)
[1-3 DREAM BRANDS] — specific brands worth building spec work for
[AGENCY LADDER RUNG] — current position and target position
[CATEGORY OF ONE STATEMENT] — existing positioning, or note that it needs to be built
```

## Execution Protocol

### Phase 1: Portfolio Architecture

**1.1 Piece Selection** — six pieces minimum, each demonstrating a different domain:

| # | Portfolio Piece | Demonstrates | Format |
|---|---|---|---|
| 1 | Mechanism Brief | Strategic thinking, research depth | PDF/doc |
| 2 | VSL Lead | Long-form copy mastery | Written copy + annotated |
| 3 | Ad Campaign Suite | Volume, variety, systematic ideation | 5+ ad scripts + CASH matrix |
| 4 | Unaware Ad | Audience psychology, awareness targeting | Script + strategic rationale |
| 5 | Creative Strategy Brief | Meta-skill, upstream thinking | Strategic document |
| 6 | Copy Block Audit | Analytical skill, diagnostic ability | Audit report of real brand's copy |

**1.2 Brand Selection** — pick one real brand in the target niche. Identify their weakest existing asset (ad, landing page, or email) and diagnose why it's weak in one or two sentences before building anything.

### Phase 2: Piece Creation
Build all six pieces for the selected brand, each via its named sub-tool:

- **Piece 1 (Mechanism Brief)**: Run the Mechanism Discovery Engine for the brand's product. Annotate with the strategic reasoning behind the UMP/UMS choice and the SIN score — the annotation is what makes this a portfolio piece rather than raw output.
- **Piece 2 (VSL Lead)**: Run the VSL Lead Writer using the Piece 1 mechanism. Include structural annotations against the 15-element checklist.
- **Piece 3 (Ad Campaign Suite)**: Run the CASH Method Generator for 20+ concepts, then the Ad Script Writer for the top 5 as complete scripts. Include the full CASH matrix as evidence of the systematic process.
- **Piece 4 (Unaware Ad)**: Run the unaware-ads workflow for the brand. Show the awareness-level reasoning explicitly — this piece proves audience psychology, not just copy.
- **Piece 5 (Creative Strategy Brief)**: Run the Creative Strategy Brief Generator for the brand — demonstrates upstream strategic thinking, done before any copy was written.
- **Piece 6 (Copy Block Audit)**: Take the brand's existing weakest asset (from 1.2). Run the Copy Block Audit to diagnose what's wrong, then add a recommended rewrite.

### Phase 3: Presentation Layer
For each of the six pieces, structure a Before / After / Strategic Rationale presentation:
1. Before — the brand's original, where applicable (Piece 6 always has one; Pieces 1-5 may not).
2. After — the built version.
3. Strategic Rationale — Loom walkthrough script or written annotation explaining *why*, not just *what*.

Portfolio landing page structure:
```
Hero: "I [positioning statement]"
Section 1: Featured Case Study (best piece, full walkthrough)
Section 2: Portfolio Grid (thumbnails of all 6 pieces)
Section 3: Process Overview (how you work — visual flow)
Section 4: Results/Reviews (if available)
Section 5: CTA ("Let me audit your [asset]")
```

### Phase 4: Nuclear VSL Integration
Turn the assembled portfolio into a Nuclear VSL:
- The portfolio page itself is the sales page.
- Each piece demonstrates a distinct competence — no redundancy across pieces.
- The Loom walkthrough functions as the VSL, narrating strategy while showcasing the work.
- The CTA offers a free audit as a low-friction entry offer that leads into a paid engagement.

## Output Contract

Deliver one **Client Portfolio Builder Package** with exactly these six components:
1. Six Portfolio Pieces (mechanism brief, VSL lead, ad suite, unaware ad, strategy brief, copy audit) — all built against the same one real brand
2. Strategic Annotations — Loom script or written rationale for each of the six pieces
3. Portfolio Page Structure — hero, grid, process, CTA, per the Phase 3 layout
4. Nuclear VSL Script — the walkthrough narrating the strategic decisions across all six pieces
5. Entry Offer — free audit → expansion engagement, stated explicitly
6. Category of One Positioning Statement

## Quality Gate

- Do all six pieces use the same one real brand — no hypothetical or composite brand substituted anywhere?
- Does each of the six pieces demonstrate a genuinely different domain, with no two pieces overlapping in what they prove?
- Do the strategic annotations explain *why* a choice was made (mechanism selection, SIN score, awareness targeting), not just restate *what* was produced?
- Does the portfolio, taken as a whole, function as a Nuclear VSL — could a prospective client be persuaded by the portfolio alone, without a separate sales conversation?
- Is the entry offer stated as a specific, low-friction next step (not a vague "contact me")?
- Is the Category of One statement genuinely differentiated — would it be false or absurd if said by a generic copywriter?

## Creative Latitude

The brand and weak-asset selection in Phase 1.2 is a strategic bet, not a formality — choose a brand whose weakest asset has an obvious, dramatic upgrade path, because the Before/After contrast in Phase 3 is the portfolio's single most persuasive moment. The Strategic Rationale annotations are where this piece separates itself from generic spec work — write them the way you'd explain a decision to a skeptical creative director who's seen a thousand portfolios, not the way you'd caption a slide. The Category of One statement should survive a "would a generic copywriter also claim this" test; if the answer is yes, it isn't done yet.

## Deploy When

- A freelancer or agency needs a portfolio built from scratch that proves cross-domain competence rather than claims it.
- The user mentions building a portfolio, needing spec work, or wants proof-of-work assets to pitch a specific niche or dream client.
- Existing portfolio pieces feel generic or disconnected and need to be rebuilt around one coherent brand and positioning.
