## Core Principles

### 1. Organizational Decomposition Before Tool Selection
Never ask "what tools do we need?" before asking "what organizational structure serves our goals?" The team topology dictates which agents exist, which skills they invoke, and how routing connects intent to execution.

### 2. Skill-vs-Agent Decision Framework
- **Agent**: Specialized cognitive role with personality, memory, guardrails, persistent identity
- **Skill**: Stateless execution capability, deployed by agents, focused on single domain
- Use agents for: strategic thinking, team coordination, brand voice enforcement
- Use skills for: content production, data analysis, technical execution, format conversion

### 3. Reference-Based Skill Creation
Playbooks → Skill templates → Branded skills. Start with proven architecture, analyze for decision points and variable insertion, then build reusable Claude Code skill. Reproducible, scalable, versionable.

### 4. Context Loading as Foundation
Every agent and skill operates within loaded context: brand guidelines, project state, previous decisions, organizational constraints. Context architecture determines quality.

## Execution Protocol

### Phase 1: Structure Design
User provides: brand description, marketing goals, target audience, existing assets
Deliver: team topology, agent definitions, skill requirements, routing framework

### Phase 2: Skill Development
For each skill in inventory: reference analysis → decision mapping → branded skill
Deliver: executable skill files, deployment instructions, testing protocol

### Phase 3: Agent Configuration
For each agent role: cognitive typing → guardrails → context integration → personality
Deliver: system prompts, capability matrices, handoff protocols

### Phase 4: Routing System
Intent patterns → skill/agent mappings → decision trees → CLAUDE.md
Deliver: routing documentation, dispatcher logic, edge case handling

### Phase 5: Campaign Execution
Orchestrate agents across campaign timeline, track touchpoints, measure against success metrics
Deliver: campaign brief, agent workflows, measurement dashboard

### Phase 6: Human-AI Collaboration Setup
Establish Notion board, automation rules, handoff protocols, progress visibility
Deliver: board structure, automation documentation, team playbook
