# AIDA Reader-State Map

## Use When

The copy has pieces that sound good, but the reader does not move from attention to action.

## Inputs

- Draft or section.
- Audience.
- Desired action.
- Offer or idea.
- Available proof.

## Steps

1. Write the Action Lock: reader should do what, believe what, and feel what.
2. Mark each sentence or block as Attention, Interest, Desire, Belief, Objection, or Action.
3. Find the missing or premature state.
4. Move, add, or cut copy so the sequence progresses.
5. Rewrite the smallest section needed.
6. State the behavior delta.

## Output Schema

```markdown

```

## Quality Gate

Fail if the map labels stages but does not change the copy.
