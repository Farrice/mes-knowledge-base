# Headline Gravity Lab

## Use When

The first line is a label, topic, summary, or polite setup.

## Inputs

- Current opener.
- Audience.
- Desired action.
- Proof object or proof gap.
- Platform.
- Brand voice boundary.

## Steps

1. Name the current opener type: label, claim, summary, shock, story, proof, or gap.
2. Generate 12 candidates:
   - 3 proof-first,
   - 3 curiosity-gap,
   - 2 known-phrase twists,
   - 2 familiar-energy openers,
   - 2 plain tension openers.
3. Pick the top 3 and write the immediate payoff line for each.
4. Select the opener with the best mix of clarity, pull, proof support, and voice fit.
5. Show why the chosen opener beats the original.

## Output

```markdown
## Headline Gravity Lab
- **Original opener:**
- **Opener type:**
- **Proof object or proof gap:**
- **Top candidates:**
- **Selected opener:**
- **Payoff line:**
- **Behavior delta:**
- **Risk:**
```

## Quality Gate

Fail if the selected opener is more clever but less clear, or if the curiosity has no payoff.
