# Visual Proof Translation

## Use When

A fact is true but abstract, so the reader understands it without feeling it.

## Inputs

- Abstract fact or claim.
- Available evidence.
- Audience context.
- Platform and format.

## Steps

1. Name the abstract fact.
2. Identify what the reader could see, compare, count, hold, or inspect.
3. Create three visual translations:
   - object comparison,
   - before/after contrast,
   - visible consequence.
4. Choose the most accurate translation, not the most dramatic one.
5. Insert it near the claim.
6. State the evidence limit.

## Output

```markdown

- **Visual translations:**
- **Selected translation:**
- **Inserted line:**

```

## Quality Gate

Fail if the visual comparison exaggerates beyond the evidence.
