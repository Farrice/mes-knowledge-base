# Weak Ad Rescue

## Use When

An ad, post, email, landing section, or offer intro is generic, benefit-first, unsupported, or flat.

## Inputs

- Weak copy.
- Audience.
- Desired action.
- Offer.
- Available proof.
- Biggest likely objection.
- Platform.

## Steps

1. Write the Action Lock.
2. Diagnose the primary weak link: attention, interest, desire, proof, objection, rhythm, story, humor, or action.
3. Mark claims and proof gaps.
4. Select one to three Sam mechanics.
5. Rewrite the weakest section.
6. Show before/after delta.
7. State the proof object or proof gap.
8. Send public or revenue copy to `/publishable-copy-gate`.

## Quality Gate

Fail if the rescue does not produce a rewritten section and a behavior delta.
