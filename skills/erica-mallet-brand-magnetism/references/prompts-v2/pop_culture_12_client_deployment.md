## INPUT REQUIRED

- **Client Name/Brand**: Who this engagement is for
- **Engagement Scope**: Which phases are in scope (Foundation / Growth / Full transformation)
- **Client Background**: Career history, expertise, current positioning (feeds Phase 1)
- **Existing Assets**: Any prior brand work, content, or research already done
- **Timeline**: Available weeks/sessions for the engagement

---

## EXECUTION PROTOCOL

### Phase 1: Discovery & Excavation
1. Send the Pre-Session Client Questionnaire (Journey / Audience / Positioning / Vision sections) 3-5 days before the first session.
2. Run the 90-minute Discovery Session: Through-Line Excavation (30 min) → Expertise Mapping (30 min) → Enemy Identification (30 min).
3. Produce the Discovery Excavation Report.

### Phase 2: Belief Architecture
1. Run the 90-minute Belief Building Session: Theme Identification (30 min) → Belief Excavation (45 min) → Enemy Refinement (15 min).
2. Produce the Belief Architecture Document.

### Phase 3: Content Ecosystem Design
1. Run the 90-minute Content Strategy Session: Pillar Definition (30 min) → Bucket Creation (30 min) → Angle Generation (30 min).
2. Produce the Content Ecosystem document with 90-day angle bank.

### Phase 4: Voice & Style Crystallization
1. Extract voice DNA from client's real sample content and session recordings.
2. Produce the Voice & Style Guide.

### Phase 5: Cult Mechanics Implementation
1. Build tribal language, rituals, identity markers, initiation levels, and status architecture from the beliefs and enemy established in Phase 2.
2. Produce the Cult Mechanics Package.

### Phase 6: Deployment & Optimization
1. Run the Launch Checklist.
2. Establish the Optimization Metrics tracking table (baseline + check-in intervals).

## Quality Gate

- Every deliverable template is populated only from real answers gathered in that phase's session — no invented client quotes, backstory, or beliefs standing in for actual discovery input.
- The 90-Day Content Bank contains genuinely distinct angles per pillar (30+ each), not repeated or placeholder rows.
- The Optimization Metrics dashboard ships with blank cells for real tracked data — never pre-filled with fabricated baseline/week numbers.
- Engagement scope tiers describe deliverable scope only; no specific dollar pricing is presented as an industry-standard figure — pricing is explicitly left to the practitioner's own market judgment.
- Each phase's deliverable traces directly to the prior phase's output (Content Ecosystem pillars map to Belief Architecture themes; Cult Mechanics language maps to the same beliefs/enemy) — no phase invents new foundational elements.
- The Launch Checklist items are all genuinely verifiable as done/not-done.
