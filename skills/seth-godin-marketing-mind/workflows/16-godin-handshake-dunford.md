# `/godin-handshake-dunford` — Godin × Dunford Handshake

The compound output: Godin's trap detection + fuzzy-word splitting + who's-it-for reset runs FIRST on the raw positioning premise, then hands the SURVIVING premise to Dunford's 5-component methodology as its input. Godin = premise gate. Dunford = build engine. Sequential, not parallel: Dunford never builds on a premise Godin hasn't cleared.

## Genius Context (Load First)

Read both:
- `skills/seth-godin-marketing-mind/genius.md` — Pattern 1 (Name the Trap), Pattern 3 (Split the Word), Pattern 4 (Two-Question Solvent + Exclusion Clause), Pattern 6 (Compared to What?)
- `skills/april-dunford-positioning/genius.md` — the 5-Component System, "Reverse Insight Derivation," Anti-Category-Creation Default

Internalize:
- Godin interrogates the QUESTION before anyone answers it. Dunford builds the ANSWER once the question is trustworthy.
- Stack thesis: Dunford's 5-component system is precision engineering, brilliant construction on whatever premise it's handed, with no interrogation of the premise itself. Godin without Dunford names the trap and stops; no positioning artifact ships. Together: a premise that survived refusal, then built into a defensible position with competitive alternatives, differentiated value, target segment, and category.
- **What this replaces**: running `/godin-lens` and a Dunford positioning workflow separately re-derives the handoff from scratch every time. Godin's verdict evaporates before Dunford opens a blank 5-component template. This workflow makes the handoff itself the artifact.

## Stacking Partners

- **Seth Godin (Marketing Mind)**: supplies premise interrogation, trap naming (reach-marketing / hustle-through / outcome-judgment / founder-centrality), fuzzy-word splitting, the who's-it-for reset with exclusion clause and sufficiency number
- **April Dunford (Positioning)**: supplies the 5-component build, competitive alternatives, unique attributes, value themes, target segment, market category

## When to Use

- A positioning brief, offer doc, or ICP statement is about to get a full Dunford build, but the premise underneath it has never been interrogated
- Positioning "claims everyone" or stacks multiple buyer types under one label without splitting them
- A stated primary buyer and the buyer actually being pursued in execution have quietly diverged
- Before spending a full 5-component workshop on a premise that might be the wrong question

## The Handoff Contract

Godin's pass outputs exactly one artifact, the **Cleared Premise Card**:

```
TRAP NAMED: [which of the 4 trap families, or "none found"]
FUZZY WORD SPLIT: [word], Pole A [...] vs Pole B [...], assignment test: [one line]
WHO'S-IT-FOR (post-split): [specific buyer, one sentence]
EXCLUSION CLAUSE: [who does NOT come, and why]
SUFFICIENCY NUMBER: [how many would be enough]
SURVIVING PREMISE: [one sentence — this is what Dunford builds on]
```

Dunford's build consumes ONLY the `SURVIVING PREMISE` line plus the `WHO'S-IT-FOR` and `EXCLUSION CLAUSE` fields as its Target Customer input; it does not re-litigate them. If Godin found no trap, the Cleared Premise Card still runs (verdict: "none found," premise passes through unchanged) so the handoff format never varies.

## Fused Sequence

### Step 1: Name the Trap (Godin)
Read the raw positioning/offer premise. Ask: which trap family is this? Reach-marketing (mistakes distribution for positioning), hustle-through (mistakes volume for differentiation), outcome-judgment (mistakes a good result for a good decision), founder-centrality (mistakes the founder's story for the buyer's problem). Name it or declare none found; don't force one.

### Step 2: Split the Fuzzy Word (Godin)
Find the noun doing double duty in the premise, usually the buyer descriptor or the category noun. Split into two poles. Write the one-line assignment test that tells you which pole a given prospect is actually in.

### Step 3: Who's-It-For Reset (Godin)
Answer "who's it for and what's it for" specifically enough to write a don't-come list. Attach a sufficiency number: how many of this buyer would be enough to prove the model.

### Step 4: Issue the Cleared Premise Card (Godin to Dunford handoff point)
Fill the contract above. This is the only artifact that crosses the boundary.

### Step 5: Competitive Alternatives (Dunford)
Given the surviving premise's specific buyer, what do they actually do instead today? Not "no solution," but the real status-quo alternative(s) they're comparing this against.

### Step 6: Unique Attributes to Value (Dunford)
List what's genuinely different given THIS buyer (not the pre-split, fuzzier one), then chain each attribute through "so what?" until it lands on value this specific buyer would pay for.

### Step 7: Target Market Segment (Dunford)
Confirm or sharpen: does the segment from Godin's who's-it-for reset match who values the differentiated attributes most? If Godin's split buyer and Dunford's best-fit buyer diverge, that's a second-order trap. Surface it, don't paper over it.

### Step 8: Market Category (Dunford)
Name the category this premise should compete inside of, per Dunford's anti-category-creation default: enter and dominate a subsegment before inventing a category. Check whether the category framing matches the exclusion clause from Step 3, or quietly re-widens the buyer back to "everyone."

## Quality Gate

- Godin's card names an ACTUAL trap grounded in the specific document, never a generic "everyone claims too broad an audience" placeholder
- Dunford's build reads as plain-spoken conviction, not five labeled boxes; no "Competitive Alternatives: [X]" mad-libs language in the final positioning statement
- The Divergence Flag section is not optional. If Godin and Dunford's buyers match cleanly, say so explicitly; silence reads as an unchecked step

## What This Replaces

Running `/godin-lens` and a Dunford positioning workflow (e.g. `diagnostic` or `product`) back-to-back in separate sessions re-derives this same handoff from scratch each time. The premise verdict lives in one conversation's memory and evaporates before the next positioning workshop opens a blank template. This workflow makes the Cleared Premise Card a durable, reusable artifact between the two passes.
