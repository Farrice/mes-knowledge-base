# Godin Stack Router Architecture

> **Expert**: Seth Godin | **Skill**: seth-godin-marketing-mind | **Tier**: Stacking
> **Produces**: Stack Route
> **Slash Command**: `/gmind-stack`

---

## Purpose

Four Godin layers now exist in this system, each covering ground the others don't. This workflow is the map between them — options the executor offers when a live problem needs more than the marketing-mind lens, never a forced pipeline the lens has to run through. Godin's own instinct against a rigid single path applies here too: a router that hands work off in one fixed order is exactly the kind of defended-plan thinking `/gmind-three-plans` exists to break. Route by what the problem actually needs.

---

## Inputs Required

1. **The Live Problem** — what's actually being worked, stated plainly.
2. **What's Already Been Run** — which gmind workflow, if any, produced the need for a handoff.
3. **Whether a Route Is Even Needed** — some problems are fully served inside this layer; check that first (Step 2) before routing outward.

## Workflow

### Step 1: Routing Table — Options, Not Steps

Offer, don't force, based on what the problem needs next:

| Need | Route To | Workflows Available |
|------|----------|---------------------|
| Brand promise, trust engineering, AI-era marketing takes | `seth-godin-brand` (front door `/seth-godin-brand`) | `/godin-brand-promise`, `/godin-brand-trust-stack`, `/godin-consistency-protocol`, `/godin-remarkability-engine`, `/godin-market-driven-audit`, `/godin-culture-as-marketing`, `/godin-personal-brand-role`, `/godin-false-proxy-purge`, `/godin-better-not-louder`, `/godin-ai-permission` |
| Spread mechanics, viral engineering, idea propagation | `seth-godin-ideavirus` (front door `/seth-godin-ideavirus`) | Ideavirus Content & IP Creation, Ideavirus Strategic Positioning, Permission Monetization Roadmap, Remarkable Narrative Design, Side-Door Market Entry, Viral Engine Deployment — invoke by workflow name through the front door |
| Resistance, shipping, SVA depth, strategy compass, decision quality, audience truth | `seth-godin-philosophy` (front door `/seth-godin-philosophy`) | `/ship-it`, `/strategic-clarity`, `/remarkability-audit`, `/status-trap`, plus Resistance Breakthrough, Four Threads Strategy Compass, Decision Quality Audit, Audience Truth Audit — invoke by workflow name through the front door |

A problem naming "our promise is inconsistent" goes to brand. A problem naming "this isn't spreading" goes to ideavirus. A problem naming "I can't ship" or "who's this actually for" goes to philosophy — unless it's a live in-the-moment reasoning problem, which stays here (Step 2).

### Step 2: This Layer's Own Lane

Before routing out, check whether the problem belongs here instead. This skill's lane is the thinking itself, not a content or positioning deliverable: strategic reasoning under a live question (`/godin-lens`), premise audits on broken briefs (`/gmind-premise-audit`), freelancer/entrepreneur structure and the hire-yourself audit (`/gmind-hire-yourself-audit`), client portfolio design (`/gmind-client-portfolio`), quit-vs-persist decisions (`/gmind-quit-or-dip`), and fear experiments for stalled launches (`/gmind-fear-isolate`). If the problem is "how do I think about this," it stays in this layer. If the problem is "I've decided the direction, now build the deliverable," it routes out.

### Step 3: Cross-Expert Stacks

Beyond the Godin-internal routes, specific principle combinations compound with experts outside the Godin trio entirely — these are the stacks worth naming when they fit:

- **Godin premise-refusal × `/gw-challenger`** — both interrogate the frame before doing any work; running them together catches broken premises a single pass would miss.
- **Godin exclusion-clause positioning × `/april-dunford` × `/nicolas-cole-niche-positioning`** — don't-come lists sharpen Dunford's category work and Cole's niche mechanics rather than duplicating them.
- **Godin tension mechanics × `/kallaway`** — the story-tension-relief chain pairs with Kallaway's attention-psychology diagnosis for content that needs to convert, not just get seen.
- **Godin fear-isolation × `/drk-resistance`** — the $10-bill experiment design pairs with Dr. K's samskara/ego resistance diagnosis for stalled launches with a deeper root.
- **Godin better-clients × `/luke-iha-client-mastery`** — the Chip Kidd / Juilliard framing pairs with Luke Iha's client-relationship mechanics for freelancers scaling by client quality, not volume.

## Quality Gate

| Dimension | Minimum Standard |
|-----------|-----------------|
| Offered, Not Forced | Routes are presented as options; the executor never chains workflows as a mandatory pipeline |
| Correct Destination | The route matches what the problem actually needs — brand for promise/trust, ideavirus for spread, philosophy for shipping/SVA/decisions |
| Own-Lane Check First | Step 2 runs before any external route is offered — this layer's own workflows aren't skipped by default |
| No Invented AI Content | AI-era questions route to seth-godin-brand explicitly; this skill never fabricates an AI-era Godin take |
