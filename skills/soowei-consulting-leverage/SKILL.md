## Stacking Guide

- Start with **Buyer Mirror Content Intelligence** when buyer language is missing or blended with assumptions.
- Run **Trust Sequence Content Architecture** before drafting a portfolio or campaign.
- Use **Broad-to-Buyer** and **Triple-Hook Packaging** for individual asset briefs; last-mile platform experts may execute only after those briefs exist.
- Use **Organic Content Acquisition System** as the recommended front door for an end-to-end run.
- Use **Retention, Repurposing & Learning Loop** only with supplied performance or buyer-event evidence. Reach alone is not conversion proof.
- Never preload every workflow. Load `genius.md`, then one workflow and its matching execution prompt.
