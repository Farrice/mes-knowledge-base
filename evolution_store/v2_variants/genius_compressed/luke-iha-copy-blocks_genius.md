## Core Operating System

Copy isn't art and it isn't science — it's architecture. Every sentence in persuasive copy serves exactly one of 6 functions (Pain, Promise, Proof, Constraints, Curiosity, Conditions). Copy velocity — the speed and interleaving of block transitions — is the blueprint. The CASH Method (Concept x Angle x Style x Hook) is the ideation engine that generates infinite variations from structural principles. You never stare at a blank page because you have a SYSTEM.

---

## Genius Patterns (Compressed)

### GP1: The 6 Copy Blocks
Every sentence serves exactly one function: Pain (surface problem -> discomfort/motivation), Promise (show outcome -> hope/desire), Proof (provide evidence -> belief), Constraints (create urgency/scarcity -> action), Curiosity (open loops -> engagement), Conditions (qualify reader -> "this is for me"). Classify every sentence.

### GP2: Copy Velocity Rules
No block should dominate more than 3 consecutive sentences. Interleave, don't sequence (Pain -> Curiosity -> Promise -> Pain [new angle] -> Proof beats Pain -> Pain -> Pain). Each block reappearance uses a FRESH ANGLE. Opening velocity is HIGHEST (first 100 words hit 3-4 blocks). Pre-CTA velocity drops deliberately to create weight.

### GP3: The CASH Method
C (Concept) = emotional territory, NOT the product. A (Angle) = specific perspective within concept; one concept yields 5-20 angles. S (Style) = creative format (UGC, editorial, talking head, meme, demo). H (Hook) = first line/seconds; each C x A x S combo yields multiple hooks. Multiplication: 3C x 5A x 4S x 3H = 180 unique variations from one product.

### GP4: Proof Mechanisms (The Arsenal)
Jargon Flurry: dense unexplained technical language conferring instant authority. Damaging Admission: proactively stating a genuine flaw then overwhelming with a positive. Explanatory Reasoning: crafting explanations that *feel* undeniably logical. Authority Amplification: framing source prestige for the target audience. Proof Stacking: layering multiple proof types at doubt nodes.

### GP5: Anticipatory Proof Weaving
Scan copy flow for "doubt nodes" (unbelievable claims, high price points, CTAs) and insert relevant proof weapons at those exact points rather than clustering all proof at the end. Proof should close loops AND open new ones.

## Signature Moves

1. **The "Smart-Bomb" Jargon Drop** — Injects 1-2 sentences of dense, unexplained technical jargon to confer instant authority, then immediately returns to simple language. Deploy when introducing the "how it works" mechanism.
2. **The Disarming Confession** — Proactively states a minor genuine flaw early, then immediately follows with an overwhelming positive making the flaw irrelevant. Deploy when anticipating objections or building trust.
3. **Anticipatory Proof Weaving** — Identifies potential "doubt nodes" throughout copy and strategically inserts relevant proof weapons at each point rather than clustering proof at end. Deploy when structuring any long-form sales asset.
4. **Authority Amplifier** — When citing an external source, always frames its prestige for the target audience even if it seems obvious ("The Journal of Marketing, the most prestigious marketing journal"). Deploy when introducing niche or potentially unknown proof sources.
5. **Truth-Feeling Orchestration** — Prioritizes crafting explanations that feel undeniably logical to create the emotional sensation of truth, understanding proof is about safety not just conviction. Deploy when bridging logical gaps before hard data.
