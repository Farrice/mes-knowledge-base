## Core Operating System

Every failed vibe-coded project traces to the same root cause: unanswered questions in the brief that the LLM must improvise at generation time. Sean's methodology enforces a strict Research -> Design -> Build trinity where phases never collapse, each uses distinct tools, and each produces a reviewed deliverable before the next begins. Design quality is not aesthetic preference — it's a subconscious authority signal that directly drives conversion.

## Genius Patterns (Compressed)

### GP1: The Under-Specified Plan Diagnosis
Before any build prompt, audit the brief for gaps. Every undefined element (audience, tone, structure, positioning) is a coin flip the LLM makes for you. Fill every gap with research, not imagination. Zero tolerance for "I'll figure it out later."

### GP2: The Research -> Design -> Build Trinity
Three categorical steps, three different tools, three different outputs. Research produces intelligence (deep research tools). Design produces visuals (Stitch, Figma). Build produces code (Cursor, VS Code). Hard phase gates — each deliverable reviewed before next begins.

### GP3: Direct vs. Indirect Competitor Mapping
Map at least 2 direct competitors (same product category) AND 2 indirect competitors (different approach to same problem). The personal trainer's indirect competitor is Ozempic. Indirect competitors reveal the most powerful positioning insights.

### GP4: The Competing Hypotheses Technique
Generate exactly 3 distinct positioning approaches after research. Each gets mapped to concrete headline, subheadline, and CTA. Evaluate against target audience, select one, document why others were rejected. Prevents defaulting to first decent idea.

### GP5: Design Quality as Subconscious Authority
Visual quality is a conversion mechanism, not aesthetic preference. Beauty signals authority, authority builds trust. A first-time visitor should form an impression of authority BEFORE reading any copy.

### GP6: The Structure-Before-Copy Sequencing
Design visual scaffolding WITHOUT real copy first (placeholder text), get aesthetic locked, THEN swap in researched copy as a second pass. AI design tools produce "pretty mid" designs when given all copy upfront — separating them produces better results in both dimensions.

### GP7: The MCP Bridge Pattern
Use MCP servers as lossless bridge between design tools and development environments. Set up MCP server for design tool in IDE, install companion skill library, issue single build command. Built output matches approved design without manual CSS translation.

## Signature Moves

1. **The Pre-Flight Brief Audit** — Before any build prompt fires, reviews brief for every unanswered question. If a single blank exists, halt and research.
2. **The Tri-Phase Lock-Down** — Enforces strict sequential phase gates: Research (doc) -> Design (approved mockup) -> Build (working code), each reviewed independently.
3. **The Indirect Competitor Hunt** — Systematically identifies 2+ indirect competitors (different approach to same problem) for novel positioning insights.
4. **The Aesthetic Scaffolding Pass** — Generates visual layout with placeholder text first in AI design tools, locks aesthetic, then integrates actual copy in second pass.
5. **The Style Keyword Blitz** — Explores diverse aesthetics by applying single powerful design keywords or reference images to same foundational content.
