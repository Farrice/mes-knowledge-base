## Core Operating System

Kashef's council architecture eliminates AI sycophancy through structure, not prompting. You cannot prompt your way out of agreement bias — opposition must be architecturally required through conflicting behavioral mandates. The value isn't in the "right" perspective; it's in the tension between perspectives that surfaces assumptions you didn't know you had.

---

## Genius Patterns (Compressed)

### GP1: Subagent Council Architecture
Use Claude Code subagents as perspective agents with opposing mandates. Each agent has distinct behavioral requirements that generate genuinely divergent viewpoints on any decision.

### GP2: Behavioral Mandates Over Personality
Define what agents MUST DO, not personality traits. "Must assume failure has occurred" produces distinctive output; "be pessimistic" doesn't. Mandates create consistent, reliable behavior across contexts.

### GP3: Shared Reasoning File
Create file-based memory capturing HOW agents think, not just conclusions. Document reasoning evolution so wisdom accumulates across sessions and informs future decisions.

### GP4: Anti-Sycophancy Architecture
Make disagreement structurally guaranteed. Optimist agent CANNOT agree with pessimist's concerns — mandates conflict by design. If all agents agree, either the decision is trivial or council design has failed.

### GP5: Context Window Preservation
Use subagents for distinct reasoning threads. Main conversation stays focused while subagents do heavy reasoning in separate contexts, preventing quality degradation in long conversations.

### GP6: Single-Phrase Invocation
Design invocation where one phrase summons the correct council. "Strategy decision" → Business Council. Zero friction to activate appropriate expertise.

### GP7: Steelman Requirements
Before disagreeing, agents must articulate the strongest version of the opposing position. No strawmanning. This produces actual crux isolation, not surface disagreement.

### GP8: Domain-Specific Council Configuration
Different decisions need different expert combinations. Hiring Council ≠ Marketing Council. Council composition must match decision domain precisely.

## Signature Moves

1. **Mandate-First Configuration** — Defines explicit behavioral mandates for each agent ("must identify failure modes") rather than vague personality traits.
2. **Conflict Architect** — Designs council structures where mandates inherently conflict, guaranteeing productive disagreement and exposing hidden assumptions.
3. **Reasoning Trace Linker** — Establishes shared reasoning files so thought evolution, findings, and disagreements persist across sessions.
4. **Precision Invocation** — Ensures council activation via a single, unambiguous phrase, eliminating cognitive load and friction.
5. **Hybrid Grunt-to-Architect Pipeline** — Deploys cheaper sub-agents for initial data gathering before feeding distilled context to reasoning-heavy agent teams.

| Disagreement Fidelity | Distinct but complementary views; mild disagreement | Genuinely divergent views with some structural conflict | Mandates architected for inherent conflict; steelmanning forces deep assumption surfacing; zero sycophancy |
