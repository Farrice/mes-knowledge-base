# Mark Kashef (Visual Blueprint) — Genius Context

> Load before executing any workflow. Full extraction intelligence.

## Core Operating System

Kashef uses ASCII art wireframes as a visual contract between human intent and AI execution, eliminating the most expensive failure mode in AI design: the assumption gap. Humans provide taste and spatial judgment; AI handles execution beauty. All iteration happens at the wireframe layer (~50 tokens/change) instead of the code/design layer (~5,000 tokens/change), reducing token spend by 60-80%.

---

## Genius Patterns (Compressed)

### GP1: Visual Contract Protocol
Force every visual project through a blueprint phase where BOTH human and AI agree on spatial layout before production. The wireframe IS the specification — not a suggestion, not an inspiration board. It's the contract.

### GP2: Assumption Assassin
AI failure in visual work stems from unstated assumptions, not capability gaps. Every unspecified element is one the AI will assume. Three unstated assumptions across ten elements = 30 divergence points. The wireframe makes the invisible visible.

### GP3: Token Economist
All iteration at wireframe layer (~50 tokens) instead of code/design layer (~5,000 tokens). Slide decks are especially token-intensive. Wireframe-first reduces token spend by 60-80%. This is the ROI argument for the entire methodology.

### GP4: Taste Arbitrage
Separate thinking (layout, structure, hierarchy) from beauty (colors, typography, spacing). In wireframe: specify WHAT goes WHERE and WHY. In build prompt: focus on making it beautiful. Never mix these two cognitive tasks in one step.

### GP5: Progressive Refinement Engine
Multi-turn conversation at wireframe layer for surgical edits: "Two changes only. Make the line chart wider. Change active/green to inactive/gray. Redraw." Small, numbered, scoped changes. Each iteration <30 seconds.

### GP6: Complexity Equalizer
Visual diagrams make technical concepts accessible to non-technical stakeholders. If a diagram "looks like gibberish," request: "Make this as if you're in seventh grade." If you can't wireframe it, you don't understand it.

### GP7: Multi-Vertical Blueprint
Same protocol works identically across dashboards, landing pages, slide decks, databases, email templates, PDFs, infographics. Universal pattern: "Before writing any [output type], create an ASCII wireframe of [specifications]."

### GP8: Orchestrator Identity Shift
The human becomes creative director, not prompt engineer. You sketch, approve, greenlight. AI is your production team. Focus on vision, taste, and approval gates while AI handles execution.

## 6-Phase Execution Pattern

1. **Conceptualize** — Define components, relationships, hierarchy. No tools yet.
2. **Wireframe** — "Before writing any [X], create an ASCII wireframe of [Y]."
3. **Iterate** — Small, numbered, scoped changes until wireframe = mental model.
4. **Annotate** — Add style/aesthetic notes to locked wireframe.
5. **Execute** — "Build using wireframe as exact specification."
6. **Validate** — Compare output to wireframe. 1:1 element mapping.

## Signature Moves

1. **The Blueprint Mandate** — Always initiates visual tasks with "Before writing any [output], create an ASCII wireframe of [specifications]."
2. **Taste-Logic Arbitrage** — Defines structure in wireframe first, provides aesthetic instructions only after wireframe approval, in a separate prompt.
3. **Surgical Refinement Loop** — Precise, numbered, scoped modifications: "Two changes only. 1. [change]. 2. [change]. Redraw the full wireframe."
4. **The Orchestrator's Hand-off** — "Build using wireframe as exact specification. Focus on making it beautiful within these aesthetic guidelines: [notes]."
