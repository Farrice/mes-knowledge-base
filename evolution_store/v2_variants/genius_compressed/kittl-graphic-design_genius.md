## Core Operating System

Design is mood-first, not tool-first. Every typography and AI generation decision begins by naming the emotional territory, then selecting materials (fonts, spacing, prompts) that serve that feeling. Speed comes from systematic pattern matching, not talent.

## Genius Patterns (Compressed)

### GP1: Mood-First Font Selection
Look at any image for 5 seconds, write 3 mood words, type those exact words into font search, select from results. Drops font selection from 15+ minutes to under 90 seconds.

### GP2: Serif/Sans-Serif Mood Mapping
Ethereal/Elegant/Nostalgic/Romantic/Gothic = SERIF. Techy/Futuristic/Sporty/Brutalist/Modern = SANS-SERIF. Western/Vintage = DISPLAY/DECORATIVE. Correct font category on first attempt 90%+ of time.

### GP3: Height-Width Contrast Pairing
Identify headline font's dominant characteristic (tall/condensed OR wide/extended), then select subtitle font with the opposite characteristic. Creates immediate visual tension and hierarchy.

### GP4: Letter Spacing as Mood Amplifier
Modern/Tech/Editorial = tighten tracking (-20 to -60). Luxurious/Airy/Minimal = loosen tracking (+100 to +600). Single tracking adjustment transforms "close" into "perfect."

### GP5: Line Spacing Compression
For headline/display typography, reduce line spacing to -20 or tighter until lines nearly touch but remain legible. Text block feels intentional and designed rather than default.

### GP6: The Keyword Font Search
Type mood/style keywords directly into font panel and browse filtered results only. Eliminates endless scrolling through font libraries.

### GP7: Pinterest-to-Execution Training Loop
Daily practice: select 1 reference design, recreate it completely, note what made it work. After 30 days, can execute any typography style within 10 minutes.

### GP8: Optical vs. Mathematical Centering
After mathematical centering, ask "Does this LOOK centered?" Adjust by 5-10% if script tails or visual weight create imbalance. Compositions feel balanced without measuring.

### GP9: Same-Font-Family Pairing Shortcut
When pairing is difficult, check if headline font has alternate weights, widths, or companion fonts. Pair within family first for guaranteed visual harmony with minimal risk.

### GP10: The Text Shading Technique
For thin fonts: add same-color stroke (offset 0, width 1-2). For dimension: add contrasting shadow (offset 3-5). Fonts gain presence and dimension instantly.

### GP11: Gray Text for Visual Hierarchy
Primary text = full color. Secondary text = 40-60% opacity or gray value. Eye naturally flows to important information first.

### GP12: Border-as-Cutout Technique
Shape needs to "cut" into another? Add thick border matching background color instead of complex masking. Complex visual effects achieved in seconds.

### GP13: AI Model-to-Task Matching
Graphic design with text = Ideogram 2/3. Photorealistic = Google Image Gen 4. Artistic/stylized = Seedream 3/4. Fast concepting = Flux/Flash. Image editing = Nana Banana. First-generation accuracy increases 60%+.

### GP14: The "Big Six" Prompt Architecture
Before prompting AI, answer: What is it? Where is it? How does it feel? How is it lit? What style? What angle? Produces intended results on first/second generation.

### GP15: Technical-First Prompt Structure
Structure as: [Shot type] + [Lighting] + [Subject] + [Setting] + [Style] + [Mood]. Consistent visual style across generations.

### GP16: Line Break Prompt Separation
After each major element, hit Shift+Enter to create logical separation. AI respects distinct elements rather than blending them.

### GP17: Positive Instruction Framing
Reframe every negative as positive. "No clutter" becomes "minimal, clean composition." Fewer unwanted elements and clearer AI interpretation.

### GP18: The Emotional Design Vocabulary
Build personal mood vocabulary. When a design "feels right," name that feeling. Enables articulating "why" a design works in reproducible terms.

## Signature Moves

1. **Mood-First Font Dive** — Identifies core emotion, translates to 2-3 keywords, uses as primary font filter. Deploy when starting any design involving text or branding.
2. **Optical Balance Override** — After numerical centering, performs visual scan and nudges 5-10% to achieve perceived balance over mathematical precision. Deploy when finalizing layout.
3. **The Daily Re-Creation Gauntlet** — Dedicates time to meticulously recreating a reference design from Pinterest to internalize principles. Deploy for skill building or overcoming creative blocks.
4. **Structured Prompt Blueprint** — Outlines "Big Six" and applies technical-first structure with line breaks before typing any AI prompt. Deploy for any AI image generation task.
5. **Texture Blend Experimentation** — Introduces texture layer and cycles blending modes (especially Exclusion) when design feels flat. Deploy for unique color exploration or visual depth.
