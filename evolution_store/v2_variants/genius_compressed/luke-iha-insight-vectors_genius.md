## Core Operating System

The best copy doesn't persuade — it creates epiphanies. An Insight Vector is a precise intervention in the audience's mental model that exploits a structural weakness (reversed causation, hidden constraints, missing variables) to introduce new understanding. When that understanding takes hold, the audience's existing belief architecture DEMANDS your product. This skill sits upstream of all other Luke Iha skills — it's the idea generator feeding the entire pipeline.

## Genius Patterns (Compressed)

### GP1: Mental Models Are Maps With Errors
People navigate reality using internal maps with missing regions, wrong connections, outdated territories, and unmarked hazards. Insight Vectors exploit map errors — you're correcting their map so they navigate better, not changing the territory.

### GP2: Suspicion > Novelty
The most powerful vectors CONFIRM something the audience already half-suspects rather than introducing brand new information. This validates their intelligence, creates relief, builds trust, and bypasses skepticism. Always prioritize vectors tapping existing suspicions over completely new concepts.

### GP3: Naming = Power
An unnamed process doesn't survive in memory. Naming rules: 2-3 words max, must be visual (creates image), emotional (triggers feeling), enemy-coded (UMP) or hero-coded (UMS), and pass the dinner table test — a non-expert remembers it after one hearing. Examples: "The Fat Brake," "Cortisol Belly."

### GP4: Reverse Causation Is Highest-Leverage
Flipping a causal arrow uses the audience's existing variables — same pieces, different arrangement. Maximally simple, intuitive, and new simultaneously. High SIN scores almost guaranteed because it satisfies all three criteria using familiar elements.

### GP5: Types Create Compulsive Engagement
System Archetype vectors ("What's your ___ type?") trigger compulsive self-classification. Types must emerge from real observable behavioral variation — if you can't find genuine clusters, don't force it. Each type receives a tailored solution, making your product feel personalized.

### GP6: Vicious Cycles Make Traps Visible
Once someone sees a loop, they can't unsee it. Explains why past efforts failed without blaming the person, creates urgency (loops worsen), positions product as loop-breaker, and shifts self-narrative from "I failed" to "I was trapped."

### GP7: The 8-Fold Elaboration Is Not Linear
The 8 beats (paradox, UMP, trigger, proof, intensifiers, myths, cause, resolution) can be reordered by format: VSL = heavy beats 1-3; Social = beat 1 + 6; Email = one beat per email; Landing page = all 8; Ad = beat 1 + condensed 2 + beat 8.

### GP8: Vectors Stack For Religious Certainty
One vector = interest. Same-type vectors = skepticism. Different-type vectors pointing to the SAME conclusion = conviction. For 3+ vector campaigns: use 2+ categories, attack the old model from different angles, make convergent thesis clear.

### GP9: SIN Is The Quality Filter
Simple + Intuitive + New, scored 1-10 each (/30). <15 = kill; 15-20 = refine (usually "New" or "Intuitive" needs work); ≥21 = deploy (commercial power); ≥25 = rare million-dollar mechanism candidate. SIN measures likelihood of AHA in first 10 seconds.

### GP10: Product Must Be The Upstream Fix
In the 8-Fold Elaboration, Beat 8 (Resolution) must position product as addressing ROOT cause, not symptom. "Breaking the [Named Mechanism] requires addressing [root cause] FIRST. [Product] is built to [address root cause]."

### GP11: Ground Everything In Existing Truth
Vectors are REFRAMES of existing reality, not inventions. Allowed: naming real unnamed processes, reframing known relationships, highlighting under-discussed variables. NOT allowed: fabricating biology, inventing research, claiming mechanisms are "proven" when theoretical.

### GP12: The Meta-Insight — Vectors Are Source Code
Hierarchy: Insight Vectors → Mechanisms → Hooks → Copy Blocks → Content → Campaigns. If vectors are powerful, everything else follows. If weak, no copy skill saves the campaign.

| HK8 | Stack order: gut punch first → system view → proof vector → identity vector → hidden condition (product). Each layer changes HOW audience processes the next. | Multi-vector campaign sequencing |

## Signature Moves

1. **The Epiphany Stack** — Sequence of 3-5 insight vectors from DIFFERENT categories converging on one conclusion: Vector 1 disrupts old model (interest) → Vector 2 reveals hidden system (engagement) → Vector 3 provides self-verifiable proof (conviction) → Vector 4 reframes identity (commitment) → Vector 5 reveals hidden precondition (purchase).
