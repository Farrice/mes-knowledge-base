# Futurepedia Prompt Engineering — Genius Context

> Load before executing any workflow. Full extraction intelligence.

## Core Operating System

AI is a prediction engine that defaults to "average of the internet." The fix is a 3-phase architecture: (1) extract expert knowledge as anchor material, (2) extract user context through structured interview, (3) synthesize both into a master execution prompt in a clean session. Never mix phases — never let AI plan and execute simultaneously. The word "reconstruct" produces fundamentally different output than "summarize."

---

## Genius Patterns (Compressed)

### GP1: The Generic Output Diagnosis
Before accepting ANY AI output, apply the "execution test" — can you actually implement this, or is it generic advice that sounds good but provides no leverage? Zero "impressive-looking but useless" outputs accepted.

### GP2: Prediction Engine Mental Model
Never expect expert-level output by default. Always provide expert anchoring material to override the "average of the internet" tendency. AI outputs should demonstrate specific framework logic, not general best practices.

### GP3: Expert Anchor Architecture
Rather than asking AI for advice, upload proven frameworks and command reconstruction — shifting AI from advisor to analyst/executor. Output should reflect specific methodology from uploaded source.

### GP4: Expert Discovery Protocol
Use prompt: "Identify top experts in [topic], signature frameworks, most important resources, and where these experts disagree with each other." Receive actionable resource list AND nuanced domain debate understanding.

### GP5: Context Extraction Through Interview
Instead of providing context, have AI extract it: "Ask me questions one by one to gather all context for the best possible [deliverable]. Do not move on until I've answered each." Captures details you didn't think to mention.

### GP6: The Separate Chat Architecture
Never mix expert extraction, context gathering, and execution in the same chat. Each gets its own clean session to prevent direction contamination.

### GP7: Meta-Prompt Synthesis
After providing expert anchor + context file: "Synthesize these blocks into a single master execution prompt using the RICECO framework. Do not execute yet. Simply output the final prompt." Produces prompts you couldn't have written yourself.

## Signature Moves

1. **The Context Crucible** — Initiates structured multi-turn interview to extract all operational context BEFORE any task execution. Deploy when task requires situational details or nuanced understanding.
2. **Architectural Tagging** — Encloses distinct information blocks in XML-style tags for complex prompts. Deploy when prompts involve multiple distinct information sources.
3. **System Reconstruction Command** — Commands "reconstruct the system/framework" rather than "summarize" to preserve operational methodologies. Deploy when extracting actionable frameworks.
4. **Phased Execution Protocol** — Strictly separates into distinct sessions: Expert Discovery, Context Extraction, Meta-Prompt Synthesis, Final Execution. Deploy for any complex task risking generic output.
5. **The Predictive Override** — Front-loads expert-level anchoring material to override AI's "average of the internet" tendency. Deploy when output requires specific methodology.
