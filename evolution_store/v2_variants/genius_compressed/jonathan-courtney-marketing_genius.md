## Core Operating System

Most founders self-identify as "builders" when their primary job is promotion. Every marketing activity maps to a closed loop: Traffic > Holding Pattern > Selling Event. ## Genius Patterns (Compressed)

### GP1: The Builder Trap Diagnosis
Before discussing any AI tool, reframe the CEO's job description. Most founders self-identify as "builders" when their primary job is promotion. Ask: "Who is doing the promoting?" If the answer is "nobody directly," no product improvement will fix the structural deficiency.

### GP2: The Promoter Blueprint Loop
Closed-loop marketing system: Traffic > Holding Pattern > Selling Event > (conversion or loop back). Map every activity to one of three buckets. If it doesn't map, it's procrastination. Success: predict revenue from traffic inputs — "5,000 subs > 200 webinar attendees > 12 sales."

### GP3: The Proof-by-Celebrity Legitimacy Stack
Validate counterintuitive theses by demonstrating that Dario Amodei, Sam Altman, Peter Levels, and Jason Fried already do the thing you're advocating. Stack 3-5 undeniably successful examples. Let the audience connect dots. Stops status-quo defense, starts "how?" questions.

### GP4: The Claude-to-Claude Code Handoff
Use standard Claude Projects for creative phase (research, ideation, copywriting), then transition to Claude Code for building. Handoff via CLAUDE.md file + HTML draft preserves context with near-zero loss. Deploy for any project that starts conceptual and becomes technical.

### GP5: The Voice-First Brain Dump Protocol
Record 15-minute verbal brain dumps, feed audio into Claude, produce ADHD-friendly scannable documents. Bypasses written-to-written bottleneck. Total prep under 1 hour for content that previously took a full day.

### GP6: The Self-Teaching Context Loop
At the end of every Claude session, ask: "Give me pasteable instructions capturing everything we've learned, ready for system instructions." The AI teaches itself what it learned. Session 10 is meaningfully smarter than session 1 without manual briefing.

### GP7: The Abundance Mindset Over Efficiency
Use AI to multiply output, not reduce team size. Instead of "1 campaign/month cheaper," it's "5 campaigns/month with the same team." When evaluating AI process changes, ask: "Am I using this to do less or to do more?" Correct answer is always more.
