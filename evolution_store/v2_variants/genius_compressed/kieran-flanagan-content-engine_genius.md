## Core Operating System

Content is built FROM extracted positions, never invented from scratch. Before creating anything, run a talking points extraction that aggregates the creator's unique perspectives from existing work. ALWAYS separate enrichment (data, stories, quotes) from creation (argument structure) as distinct pipeline stages — asking AI to do both simultaneously produces hallucinated data. Find content that already went viral in adjacent domains, reverse-engineer the structural pattern (not topic), and apply that proven architecture to the creator's unique talking points.

## Genius Patterns (Compressed)

### GP1: Multi-Source Talking Point Extraction
Before creating ANY content, extract the creator's unique perspectives from existing work — podcast transcripts, articles, social posts, interviews, notes. Organize into 4 categories: Educational, Data Nuggets, Spicy Takes, Story Sparks. This prevents AI from inventing positions the creator doesn't hold. The talking point library is the source of truth.

### GP2: Enrichment-Before-Creation Sequencing
ALWAYS separate enrichment from creation as distinct stages. Stage 1: Draft the argument structure (no data, no quotes, just flow). Stage 2: Enrich — inject 2-3 statistics, 1 story/case study, 1 expert quote per section. Stage 3: Polish — voice alignment, formatting. Asking AI to "write with 3 statistics" produces hallucinated data. Separating them produces real, correctly integrated data.

### GP3: The Lookalike Content Engine
Find content that already went viral in adjacent domains. Reverse-engineer the structural pattern — hook type, argument flow, emotional arc — NOT the topic. A parenting influencer's viral post architecture can apply to B2B SaaS. Scan 50-100 posts, filter to top 30% by performance, identify 5-10 structural patterns, map onto creator's talking points.

### GP4: Content Bundling (One Idea -> Multi-Platform)
Create for highest-effort platform FIRST (usually LinkedIn or newsletter). Then ADAPT through style card swaps — don't rewrite. The first platform is "source of truth." Bundling builds from a single idea outward with platform-native approaches (writing forward); atomizing breaks existing long-form into derivatives (breaking backward). Target: 4x output with less than 25% additional effort per platform.

### GP5: The Four Talking Point Categories
Organize all talking points into exactly four categories: (1) Educational — how-to, frameworks, tutorials. (2) Data Nuggets — statistic-led, trend analysis. (3) Spicy Takes — contrarian opinions, myth-busting. (4) Story Sparks — personal anecdotes, case studies, origin stories. Every content piece maps to exactly one category.

### GP6: Model Routing for Content Tasks
Use the right AI model for the right job. Analytical tasks (extraction, pattern analysis, cluster mapping): use reasoning models — they follow complex multi-step instructions precisely. Creative tasks (writing, hooks, enrichment): use conversational models — more natural, human-sounding output. Never mix.

## Signature Moves

1. **Deconstructs for Structure, Not Topic** — When analyzing successful content, strips away subject matter to identify underlying hook type, argument flow, emotional arc, and closing mechanism.
2. **Initiates with the "Never Use" List** — Before any drafting, ensures anti-vocabulary is loaded and active; telling AI what not to say is more powerful than positive instruction.
3. **Separates Argument from Evidence** — Always demands a full coherent argument structure first, devoid of statistics, quotes, or anecdotes; enrichment is a distinct subsequent task.
4. **Bundles & Adapts, Never Rewrites** — Once core idea is developed for primary platform, adapts for others using style card swaps; core idea identical, voice/format/length change dramatically.
5. **Validates Beliefs Upstream** — Every core assertion is traceable to the creator's existing body of work; AI never invents a position the creator doesn't authentically hold.
