## Proposal 5: Ratchet Jen Reel Look Baseline into Render Guard
**Root Pattern**: `feedback_jen-reel-look-baseline.md` (touched 09-09) records Farrice's PASS on the photo-motion reel grammar: "stop redesigning it." The ENGINE-V2 §15 documents the spec, but no guard prevents a render that violates it (wrong font, wrong lockup position, type near face, etc.).

**File**: `_active/clients/jen-listings/04-deliverables/2026-09-01-september-carousels/build_reel.py` (or a shared Jen render validator)

**Proposed Edit**:

Add a pre-render validation function (can be a simple checklist, not a full linter):

```python
def validate_jen_reel_spec(spec: dict) -> list[str]:
    """
    Returns list of violations. Empty = pass.
    Per feedback_jen-reel-look-baseline 2026-09-09: the look is settled, stop redesigning.
    """
    violations = []
    # Font
    if spec.get("font_family") not in ("Playfair Display", "Caveat"):
        violations.append(f"Font '{spec.get('font_family')}' not in approved set (Playfair Display, Caveat)")
    # Font color
    if spec.get("font_color", "").lower() != "#ffffff":
        violations.append(f"Font color '{spec.get('font_color')}' is not white (#ffffff)")
    # Lockup position
    if spec.get("lockup_position") != "bottom":
        violations.append(f"Lockup position '{spec.get('lockup_position')}' should be 'bottom'")
    # Aspect
    if spec.get("dimensions") != (1080, 1920):
        violations.append(f"Dimensions {spec.get('dimensions')} should be (1080, 1920)")
    return violations
```

Call before `render()` and abort with the violations list if non-empty.

**Expected Effect**: Renders that violate the settled look fail before producing output. "Stop redesigning it" is enforced mechanically.
