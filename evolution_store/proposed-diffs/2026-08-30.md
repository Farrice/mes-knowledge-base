## Proposal 4 — Log same-day batch production for session-fatigue audit

**Root pattern:** 5 of 6 low-composite entries are from 2026-08-29. Same-day batch production without context reset between artifacts risks skill-bleed and cumulative degradation. The rubric doesn't penalize this directly, but the pattern correlates with lower scores.

**File:** `execution/chain_runner.py`

**Proposed edit (add session-tracking, after line ~130):**
```python
# Same-day batch tracking (2026-08-30 verdict-to-diff proposal)
# Log when multiple finalizes occur on the same day to detect session fatigue.
_SESSION_DAY_LOG = PROJECT_ROOT / ".agent" / "session-day-batch.jsonl"

def _log_day_batch_event(output_description: str, composite: float) -> int:
    """Log a finalize event and return today's count."""
    today = date.today().isoformat()
    _SESSION_DAY_LOG.parent.mkdir(parents=True, exist_ok=True)

    # Count today's entries
    today_count = 0
    if _SESSION_DAY_LOG.exists():
        with _SESSION_DAY_LOG.open() as f:
            for line in f:
                try:
                    entry = json.loads(line)
                    if entry.get("date") == today:
                        today_count += 1
                except json.JSONDecodeError:
                    pass

    # Log this entry
    with _SESSION_DAY_LOG.open("a") as f:
        f.write(json.dumps({
            "date": today,
            "output": output_description[:60],
            "composite": composite,
            "count": today_count + 1,
        }) + "\n")

    return today_count + 1

# In finalize(), after composite calculation:
day_count = _log_day_batch_event(output_description, composite)
if day_count >= 4:
    result["batch_warning"] = f"This is finalize #{day_count} today — session fatigue risk"
```

**Expected effect:** Batch production becomes visible. At 4+ finalizes/day, a warning surfaces. The weekly card can correlate batch size with composite degradation.
