# Andrew Dun — Offer Verdict

## Output Contract

Produces a zero-based offer assessment: given current constraints (cash runway, audience size, proof inventory, time available), should the operator pursue this offer, park it, or pivot to an alternative?

### 1. Constraint Inventory
- Cash position and collection urgency

## Proposal 4 — Wire prompt-menu hook to surface "no matching prompt" at finalize

**Root pattern:** 4 of 5 entries invoked an expert without a matching execution prompt, and finalize completed without surfacing the gap. The prompt_menu_hook already lists available prompts after a skill Read — but finalize has no equivalent check.

**File:** `execution/chain_runner.py`

**Proposed edit (add check after expert/skill/workflow parsing, near line ~950):**
```python
# Prompt coverage check (advisory, 2026-08-16 verdict-to-diff proposal)
# If a skill was specified, check whether any execution prompt exists for
# the output description. This is a heuristic match, not a block.
if skill:
    _prompt_dir = Path(f"skills/{skill}/references/prompts-v2")
    if _prompt_dir.is_dir():
        _prompts = list(_prompt_dir.glob("*.md"))
        if _prompts:
            # Simple keyword overlap check
            _output_lower = output_description.lower()
            _any_match = any(
                any(kw in _output_lower for kw in p.stem.replace("-", " ").split())
                for p in _prompts
            )
            if not _any_match:
                result["prompt_coverage_miss"] = True
                result["available_prompts"] = [p.stem for p in _prompts]
```

**Expected effect:** When an expert is loaded but no execution prompt matches the output, the finalize result includes `prompt_coverage_miss: true` and lists available prompts. This makes the gap visible without blocking — the next evolution wave can decide whether to nudge or enforce.
