## Proposal 3: Client ENGINE Authority Field

**Root Pattern**: Jen rows (ENGINE-V2.md §3 realism gate, §5 formats, §6 Valley Native look, §7 photo rules) log no reference to the authority engine. Expert Standard dimension cannot anchor to format spec and realism gates because they're not recorded anywhere in the finalize payload.

**File**: `execution/chain_runner.py`

**Proposed Edit** (add after finalize argument parser, before payload assembly):

```python
# Client ENGINE authority resolution (NEW SECTION)
CLIENT_ENGINE_PATTERNS = {
    "jen": "_active/clients/jen-listings/06-system/ENGINE-V2.md",
    "andrea": "_active/clients/andrea-dj/06-system/ENGINE.md",  # if exists
}

def resolve_client_authority(notes_field: str) -> str:
    """Extract client name from BRAND LOCK in notes, return engine path if exists."""
    if not notes_field:
        return ""
    # BRAND LOCK pattern: "BRAND LOCK: <client-name> ..."
    import re
    match = re.search(r"BRAND LOCK:\s*(\w+)", notes_field)
    if match:
        client = match.group(1).lower()
        engine_path = CLIENT_ENGINE_PATTERNS.get(client)
        if engine_path and os.path.exists(engine_path):
            return engine_path
    return ""

# In finalize() payload assembly, add:
skill_authority = resolve_client_authority(notes)
payload["skill_authority"] = skill_authority if skill_authority else None
```

Expert Standard can now anchor to §3 (realism gate: no condos/rail), §5 (formats: photo-motion reels primary), §6 (Valley Native look: full-bleed photo), §7 (photos: no warm-orange). ENGINE becomes the canonical authority for content format and constraint decisions.

## Proposal 4: Antipattern "general" Hygiene Rule

**Root Pattern**: `--skill general` appears in logs as a catch-all for work that doesn't match any expert directory. System work tagged this way scores 5–6 on Expert Standard by default (no expert to load). The antipattern should be blocked at log time, not after scoring.

**File**: `evolution_store/ground_truth/rubric_v1.md`

**Proposed Edit** (insert in Dimension 2 preamble):

```markdown
### Hygiene: Avoid "general" Skill String

`--skill general` or any nonexistent skill directory is an automatic **5 on this dimension**. If no expert applies:
- **System/harness work**: use `--skill system` and mark Expert Standard **N/A** (see "When this dimension doesn't apply" above)
- **Operator/orchestration work**: use `--skill operator` and mark Expert Standard **N/A**
- **Pure research/analysis**: use `--skill analyst` and mark Expert Standard **N/A**

The test: can you name a real skill directory in `skills/` or `agents/` that was loaded? If no, mark N/A instead of scoring low on an inapplicable dimension.
```

**Expected Effect**: "general" stops appearing in finalize logs. System and operator rows route to N/A instead of false 5–6 scores. Cleaner signal: a score of 6 no longer means "I couldn't find the expert"; it means "the expert files were loaded but the work doesn't embody their thinking."
