# Solution Card — Spec samples in a prospect's voice: the receipted-override protocol

**Date:** 2026-07-21 (Signal Pilot day-1 execution, Rosner + Broxterman flagships)
**Domain:** Cold outreach / voice-mimicry copy / QA-gate interaction
**Trigger:** Both flagship spec samples got FLAGGED by prose_classifier and drew "invented number / creepy mimicry" findings from adversarial reviewers — yet most flags were wrong, because the flagged lines were the PROSPECT'S own verbatim material.

## The problem shape
QA gates (prose classifier, adversarial panels) are calibrated against AI-tells and fabrication. Prospect-voice spec copy triggers them constantly: the prospect's own signature constructions look like negation-templates, their emoji sign-offs look like structural emoji, their own article titles look like invented stats ("90% of your runs" was Rosner's own headline; "VIP Nutrition & Mindset Reboot" was Broxterman's own program name). Naive response = rewrite to satisfy the gate, which DE-VOICES the sample and destroys the artifact's entire value.

## The protocol (4 moves)
1. **Corpus first, receipts mandatory.** Research agent captures 10-15 VERBATIM quotes with URLs before any copy is written. Every voice move in the sample must trace to a receipt.
2. **Resolve flags by receipt, not rewrite.** For each gate flag: if the flagged line traces to the prospect's verbatim corpus, KEEP it and log the receipt in internal notes ("this is HIS construction, source URL"). Only rewrite flags that are genuinely unowned (our em-dashes, our "Here's" openers, our guru tropes). Run the classifier per-piece on sendable prose, never on the whole multi-part file (headers/notes inflate the score).
3. **De-mimic the intimate markers.** Signature emoji, pet openers, private sign-offs: accuracy does not neutralize uncanny valley on a cold approach, and the forward-test reader lacks the receipts frame. Gesture instead of reproduce ("Jen / *(your ❤️🐻🌈 goes here)*") and NAME the mimicry aloud in the read ("I matched your opener on purpose; if that's a step too far, it's the first thing I'd cut"). Naming converts skin-wearing into craft-confidence.
4. **Preempt the selectivity objection.** For capacity-capped offers (selective 1-on-1, application-gated), the buyer's real objection is "why drive applications I'd have to reject?" Reframe the artifact's goal as warmer applications from people who already know them, never volume.

## Bonus finding
Absence claims must be scope-limited to the sample actually read ("in the issues I read", "from the outside") and never presume the prospect's private analytics. The strongest trust-builder in both artifacts was the stranger-with-a-credit-card move: narrate the actual failed attempt to buy, which proves homework no adjective can.

## Re-solve guard
Before rewriting ANY flagged line in prospect-voice copy: (1) is the line in the verbatim corpus? → keep + receipt. (2) Is it an intimate marker? → de-mimic + name aloud. (3) Is it ours? → rewrite. If the research agent captured no verbatim corpus, stop: the sample cannot be built yet.
