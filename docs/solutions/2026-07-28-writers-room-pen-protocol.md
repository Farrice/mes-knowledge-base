# Solution Card — Writers' Room Pen Protocol: committee editing is the template trap

**Date:** 2026-07-28 · **Domain:** content system / orchestration · **Session:** About v13 writers-room

## The problem

A fully-loaded room (15/15 lens cards read, load-truth PASS) still produced output
Farrice verdicted *"so bland and flat and generic... trying to be so safe."* Loading
was fixed on 2026-07-27; the output didn't improve. So the laundered half-pass wasn't
the only failure mode — **the treatment structure itself was the second one.**

## Root causes (three, distinct)

1. **Nobody holds the pen.** Layer-by-layer application (Structure pass → Emotion
   pass → Platform pass) means every lens applies its move to the same body. The
   seams between passes read as "disjointed, flows poorly." Every lens card's own
   calibration section warns against exactly this ("intuition primitives, not a
   checklist") — the cards were right and the workflow contradicted them.
2. **The PASS bank became a freeze list.** Lines logged PASS in VOICE-CARD §6 were
   treated as untouchable across twelve versions. Two of them ("waited for the work
   to speak / It never once spoke", "Years of that..." as payoff) were killed by
   Farrice the moment he read them fresh. A felt verdict is a floor reference at a
   moment in time, not immunity from the current diagnosis.
3. **Conditional lenses gated by format.** Dan Wang ("only for analytical
   long-form") was skipped on profile copy — and his AN-1 (*abstraction with no
   texture gateway*) was the exact failure class of every line Farrice flagged
   ("the only room where...", "a body instead of a bottle"). The gate excluded the
   one instinct the draft needed.

## The fix (live in `.agent/workflows/writers-room.md` Phase 3, binding)

**The Pen Protocol:** diagnostics compress into a one-screen WRITER'S BRIEF →
ONE lead voice takes the pen and writes the whole body with full creative latitude
(lenses as absorbed instincts, override allowed) → the room re-enters as pass/fail
CRITICS, never editors → findings return to the same pen. Conditional lenses are
invitations, never format gates. PASS bank is a floor, never a freeze list.

## The root rule (transferable)

**An expert ensemble edits; an author writes.** Any orchestration that has N
experts each apply their move to a shared body will converge on safe, seamed,
committee output regardless of how good the experts are — quality comes from one
sensibility with the others absorbed as instinct (matches standing memories:
one-author-per-body, multi-engine-rebuild-degrades). When output from a
well-loaded ensemble reads flat, check WHO holds the pen before adding experts.

## Applies to

All 17 multi-expert rooms (see `.agent/sessions/room-audit-2026-07-27.md`), any
future ensemble workflow, and any model in the seat (written specifically so the
correction survives the Fable → Opus 5 handoff).
