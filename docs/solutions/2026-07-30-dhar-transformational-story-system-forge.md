## Problem

A single Dhar Mann interview contained unusually strong creator doctrine about emotional connection, audience trust, packaging, accelerated YouTube structure, positive action, and community feedback. The request called for a new expert and full content factory, but the source did not teach complete screenplay, dialogue, directing, editing, survey-methodology, or studio-operating craft. The build had to capture the real capability without inflating the evidence or duplicating existing Bayer, Stanton, Kobi, Kallaway, and Kieran systems.

## Root Cause

The valuable capability was distributed across several layers that are easy to collapse: mission governance, viewer transformation, packaging, story change, body authorship, and operations. Treating every layer as Dhar-native would create a mega-skill and attribute unprovided methods to the source. Treating every adjacent expert as a default collaborator would create expert soup. Treating the user's “full nine” language as automatic permission to package a plugin would freeze an untested interface before any real production run.

## Approach That Worked

1. Preserve the primary VTT, metadata, normalized transcript, timestamped segments, sparse visual notes, uncertainty report, and a typed source ledger before synthesis.
2. Remove rolling-caption overlap before applying the deterministic corpus manifest. The normalized 7,530-word source earned seven workflows and eight born-v2 prompts, not an arbitrary forge maximum.
3. Compare the source against the existing arsenal. Give Dhar one distinct function: the viewer-transformation and community spine. Assign one bounded Bayer body mode and one Stanton or Kobi change route, with Kallaway and Kieran cold until their entry conditions exist.
4. Build one expert skill, one expert identity, and one thin conductor. Reference exact existing dependency paths rather than copying their methods.
5. Test the factory on a realistic creator thought with the required lived scene intentionally absent. A correct run produced a strategy packet, changed the baseline behavior, and stopped full authorship instead of inventing Farrice's experience.
6. Verify source shape, routing, workflow and prompt counts, relative links, dependency paths, menu reachability, claim boundaries, composition, prose risk, and plugin readiness with deterministic checks.

## Dead Ends

- A literal “full nine” build from one interview would have invented screenplay and studio-operating competence.
- A default stack containing Dhar, Bayer Mirror, Magnetic Authority, Stanton, Kobi, Kallaway, Kieran, Shaan, and Dai would have hidden ownership instead of integrating expertise.
- The first workflow description was discoverable by command name but not by the natural language “make viewers feel seen and change perspective.” Rewriting the description around the user's actual outcome fixed routing without changing the global router.
- The first skill heartbeat exposed unsourced anti-pattern bullets, missing recognition language, weak named-entity density, and six internal workflows without a menu path. Source anchors and a real workflow selector cleared those failures.
- The first behavior-proof prose scan treated uppercase run statuses and em-dash-heavy scaffolding as AI tells. Sentence-case verdicts and plainer syntax reduced the result to a single structural warning caused by the proof tables.

## Weaker-Model Trap

A weaker run will mistake extraction volume for source authority, call generic inspiration “transformation,” or add every plausible expert to look comprehensive. It may also write a convincing personal scene when provenance is missing, treat views as evidence of betterment, repeat the interview's therapy comparison as a capability claim, or package a plugin because the user used the word “plugin.” The guard is one function owner, exact dependency slots, typed claim boundaries, a missing-provenance behavior fixture, and a plugin promotion ladder tied to real runs.

Another trap is assuming `--help` makes a local script read-only. Inspect local CLIs before invoking them; some workspace generators ignore unknown flags and write.
