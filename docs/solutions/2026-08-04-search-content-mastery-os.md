## Problem

Eleven practitioner videos needed to become reusable SEO/AEO/GEO capability, but a new mega-skill would have duplicated Nathan Gotch, Ethan Smith, `/create`, media craft, and Health Performance authority. The system also needed to rate multiple content formats and learn from exports without converting readiness scores into invented market proof.

## Root Cause

The existing arsenal had strong specialist methods but no shared project record, strict import contract, cross-format evaluation receipt, independent outcome ledger, or single search-system front door. The Codex command palette also scored lexically and did not consult the mandatory routing bindings used by the workflow router.

## Approach That Worked

1. Forge one source-labeled portfolio, extend the existing Nathan skill with bounded component workflows, and put a non-persona conductor in front of the existing specialist arsenal.
2. Make the runtime import-first and receipt-driven: reject unknown schemas, preserve raw hashes, separate deterministic checks from judgment and taste, append independent outcome states, and require human promotion for learning.
3. Prove the system with exact source reuse, eleven evidence packages, three vertical cold starts, six evaluator formats, malformed/conflicting import fixtures, routing parity, JSON Schema validation, and a protected Health Performance pilot.

## Dead Ends

- A lexical-only command-menu score ranked `/create` above the unified conductor; consulting the existing binding source of truth fixed parity without adding another signal list.
- A generated short-name shim would have created a second `/search-content` front door; explicit `command_exempt: true` made registry generation converge on `/search-content-mastery` only.
- Sentence-level risk matching treated “does not guarantee” as a guarantee; the evaluator now distinguishes disclaimer-local negation from asserted promises.
- One reused evidence package had a stale provenance hash after its reuse receipt was finalized; the acceptance verifier now recalculates every on-disk source hash.

## Weaker-Model Trap

A weaker implementation will summarize the videos, generate one opaque “SEO score,” silently guess export fields, confuse citations with demand, create duplicate expert skills, or market the Health Performance prototype as proven. Require source receipts, versioned records, separate outcome stages, protected-file hashes, and a dated external event before any market claim.
