# Red-Team Verdict: Listing Launch Install (realtor-pack offer)

**Date:** 2026-08-24 · **Method:** /offer-redteam (3 blind agents: prosecutor KILL-UNLESS / defender DEFENSIBLE-AS-TEST / evidence THIN) · **Verdict: MODIFY**

## The offer tested
One-time done-with-you install of per-listing launch system. $950 founding / $1,800 after, cap 6, half/half payment, $390/yr refresh renewal. Cold outreach, solo operator, no niche proof.

## Convergence (all three blind agents, from opposite postures)
1. **Agency-first targeting is structurally wrong.** Agencies can't run the flagship (no property walkthrough, no agent face for reels, no seller text); the white-label license clause lets them strip the owner's name off the launches that were supposed to become his case studies — the proof mechanic cannot fire on the segment mailed first. Evidence: one-time white-label sales to agencies = ABSENT, zero receipts anywhere.
2. **Funnel math was hope.** Offer doc implied ~25-30% cold reply; benchmark B2B cold email = 3.43% reply, ~1 deal per 464 sends. 50 contacts ≈ 1-2 replies at benchmark, not 12-15.
3. **"Run it in about an hour" self-refutes** — the offer's own ledger says 2.5 hrs/client with the owner driving; the bracketed fields are writing assignments (walk-in narrative, market thesis), not merge fills.
4. **Price band exists, transaction proof doesn't.** Concierge for Realtors publishes $950/$1,100/$1,800 one-time setups to this exact buyer (near-identical $1,100 shape) — but zero sales evidence, and the counter-anchor is brutal: $35/listing marketing kits (Picture This Property), $150-400/listing coordinators. Copy must answer "why not $35?" explicitly: they launch a listing; this installs the system + judgment scaffolding forever.

## The modification (prosecutor's flip condition; defender's concessions agree)
1. Founding cohort = **listing-heavy agents/teams ONLY** — must personally control a listing going live ≤30 days. Agencies OUT of cohort one.
2. **Right-to-publish** each founding launch as a named case study = written term of engagement.
3. White-label agency license **deferred to month 4**, sold on the back of six published launches (build-once-sell-N restored).
4. Price argument goes **GCI-relative** (6-9% of one commission side), never agency-seat-relative.
5. Honest time promise: first launch is done WITH him on the install call (his engine writes the narrative live — that's where the 10-50x edge is real); subsequent launches ~1 hr.
6. Funnel recalibrated to benchmarks: 50 sends = wave one; iterate band pre-registered; list extends toward 150-200 listing-heavy names across ramp.
7. Send-blocker: 3 customer-facing artifacts (outreach scripts, sales page, PRODUCT.md) still pitch the dead $49/mo subscription — rewrite before any send.

## Strongest surviving numbers
- $390/yr renewal undercuts every annual incumbent (Social Broker $470, Agent Crate $590, Coffee & Contracts $740) — the strongest number in the offer.
- Half-at-signing/half-after-first-launch risk reversal is honorable and channel-appropriate.

## Cheapest real-world test ($0, ≤72h)
10 hand-picked listing-heavy agents from the existing CSV with visibly active listings; GCI-anchored DM offering the founding install with first-launch-on-your-live-listing; measure reply/application. Sends are Farrice's (SENDS STAY HUMAN).

## Reusable lesson
"Who has budget" ≠ "who has the pain." A method/system product sells to the operator missing the method — not to businesses that sell method for a living (they read it as a competitor's SOP). Proof mechanics must be structurally publishable: a license that lets buyers rebrand the work kills the case-study engine it was meant to feed.
