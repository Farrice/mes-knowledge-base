## Problem

The video supplied a connected personal-brand method, not one isolated tactic. Its value lived across spoken distinctions, recurring examples, and visible brand-world references. Antigravity already had separate Oren skills for repositioning, identity, content-team architecture, taste, and world-building, so a new expert or catch-all skill would split authority.

## Root Cause

The missing capability was a paved orchestration path. `oren-repositioning` owned personality-level creative direction, but it did not yet turn a founder brief into one direction spine, biweekly idea room, world kit, pilot set, and 90-day operating plan. Source capture also hit YouTube's PO-token retry loop, and repository-wide pointer tooling could refresh unrelated skills.

## Approach That Worked

1. Capture native captions with the `web_embedded` fallback, download the video, inspect 40 scene-aware frames, and preserve spoken, visual, source-reported, inferred, and untested evidence separately.
2. Search the existing Oren bench before building. Extend `oren-repositioning` as the function owner, then hand off content operations, identity, taste, and deep world-building to their existing owners.
3. Add one full-system workflow plus bounded idea-room and world-kit components, born-v2 prompts, thin command wrappers, and a Skill System Contract with explicit human and no-action boundaries.
4. Run a frozen cold-start fixture. Require the system to turn a generic expert brief into a specific direction while keeping founder history, taste, market performance, outreach, purchases, and publishing unclaimed.

## Dead Ends

- The default watcher entered a repeated PO-token loop. Stop retrying and use `yt-dlp --ignore-config --extractor-args "youtube:player_client=web_embedded"`.
- A new personal-brand mega-skill would duplicate several Oren owners. The durable shape is one conductor with bounded handoffs.
- `validate_skill.py` counts the legacy `references/prompts/` folder, so it reports seven prompts even though the live born-v2 prompt library correctly finds all ten. Use `renaissance_audit.py` and `prompt_library.py` for the actual v2 surface.
- `wire_prompt_pointers.py --write` refreshed six unrelated skill files. Revert those generated diffs and retain only the intended Oren pointer update.
- The prose classifier treats repeated proof-state labels and mandated extraction headings as stylistic repetition. Keep the evidence labels; use the classifier as a publishing-prose gate, not as authority over structured receipts.

## Verification

- Video source package: PASS with 822 caption segments, 5,638 clean words, and 40 reviewed frames.
- Personal-brand system verifier: 7/7 PASS, including the false-green negative control.
- Prompt contract audit: 3,952/3,952 PASS.
- Command menu and natural-language workflow router rank the intended full-system, idea-room, and world-kit commands first for their respective queries.
- Codex authority, live-surface, harness, Operator Core, and skill-system contract checks: PASS.
- Human blind taste review, production feasibility, live publishing, and market response remain untested.

## Weaker-Model Trap

A weaker model will summarize the transcript into a large prompt, copy every example into doctrine, or create a new Oren expert because the source covers several functions. The correct move is to preserve source boundaries, select one existing craft owner, pave the handoffs, and prove that the system becomes more specific without fabricating founder history or live results.
