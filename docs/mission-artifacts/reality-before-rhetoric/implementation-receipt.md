## Existing limitations outside this scope

- `codex_harness_check.py` reports the isolated worktree's untracked `.env` as missing. The build neither copied nor created secrets.
- `verify_system_control_plane.py` reaches its local-helper stage, then stops on the pre-existing harness state mismatch: `intent memory and cohesion state do not agree`. Operator Core status and routing probes still pass.
- The Farrice Content OS workflow still names an archived `verify_farrice_content_os.py`, and `validate_skill.py source-command-farrice-content-os` looks only for the old live wrapper path. The dedicated Reality verifier and current routers prove this integration; repairing the archived verifier/wrapper lookup would be a separate control-plane task.
- The chain finalizer's phrase binding saw “High-Taste Writing OS” inside the
  integration target and flagged `/source-to-skill-system` as a routing
  violation. The Skill System Contract deliberately assigns the reusable system
  build to Source-to-skill-system and High Taste as a consumer, so the owner was
  preserved rather than changed to satisfy the phrase matcher.
- The finalizer's optional Notion regression check could not run without
  `NOTION_API_KEY`; Notion was explicitly skipped and no external write was
  attempted.

None of these limitations was caused by the Reality Before Rhetoric diff, and none was expanded or silently repaired.
