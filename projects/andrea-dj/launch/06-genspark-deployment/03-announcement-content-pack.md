## Critical Day 0 Failure Modes (and how to recover)

1. **Veo 3.1 Quality hero video drifts golden hour**: regenerate with stronger negative tail emphasis. If still wrong after 2 retries, fall back to Seedance 2.0 with the same prompt — register might be tighter.

2. **Kling B-roll faces morph**: regenerate at 5s instead of 8s. If still morphs, use a SOLO subject shot (one person, not two) for the B-roll — Kling is more stable on single subjects.

3. **GPT Image 2 mis-renders typography** (rare but happens): try the exact same prompt 1-2 more times. If consistent failure, switch to Nano Banana Pro with typography rendering described in plain language.

4. **Application count under 8 by 6pm Story 17**: don't fake the number. Use the fallback line: *"The applications have started coming in. I'm reading them tonight."* Honesty preserves the brand.

5. **JR doesn't confirm by Day 0**: ship Frame 4 with `Anchor DJ to be announced` instead of his name. Same for Reel 4 voiceover and email. The brand absorbs uncertainty gracefully when the copy is honest.
