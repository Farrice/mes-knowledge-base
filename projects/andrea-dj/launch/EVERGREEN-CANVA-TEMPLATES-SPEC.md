# Evergreen Canva Templates Specification
## 5 Locked Templates for Resonance Event Promotion

**For**: Andrea's friend setting up Canva templates  
**Purpose**: Once these templates are created and locked, each future event requires only swapping the photo, headline, and date — layout, colors, typography, and structure stay protected.  
**Workflow**: Create design → Lock as template in Canva → "Create design from template" for each new event  
**Time to Build**: Approximately 2–3 hours (one-time setup)  
**Time to Reuse**: 15 minutes per template per new event (swapping photo + copy only)

---

## Template 1: IG Feed Post (1080×1350px, vertical)

### Purpose
Hook people on Instagram feed with a daytime photo + copy. Drives to application link.

### Layout & Structure
```
┌─────────────────────────────┐
│   [PHOTO FILLS 60% TOP]     │  ← Daytime room photo (full width)
│                             │
├─────────────────────────────┤
│                             │
│  HEADLINE (8 words max)     │  ← GT Sectra 48–56pt, Terracotta-600
│  in 1–2 lines              │
│                             │
│  Body copy below.           │  ← Inter 16–18pt, Ink-900
│  100–150 words of the       │
│  moment and the room.       │  ← "It's 2pm on a Saturday..."
│  Show what happens.         │
│                             │
│  If you've tried            │  ← Hell-yes filter, smaller type
│  everything, the room is    │  Inter 14pt, Slate-500
│  open. If not sure yet,     │
│  the next one might be.     │
│                             │
│  Application opens [DATE]   │  ← CTA link, Terracotta-600
│  resonance.com/apply        │  Inter 14pt, clickable
│                             │
└─────────────────────────────┘
```

### Locked Elements
- Background color: Cream-100 (#F5EFE3)
- Margins: 24px on all sides
- Text alignment: Left-aligned (not centered)
- Spacing between blocks: 20px
- Font sizes and colors (above)

### Swappable Elements
- Photo (must pass 11pm test)
- Headline (≤8 words, name one mechanic)
- Body copy (100–150 words, show the room)
- Event date (in headline or CTA)
- Application link (update if needed)

### Notes
- Photo should occupy top 50–60% of canvas (height varies by photo aspect)
- Typography should not overlap photo
- No hashtags (flyer aesthetic, not caption aesthetic)

### Purpose
Shareable standalone visual. Posts to IG feed, sent via email, shared in DMs. Drives to application.

```
│  Resonance                  │  ← Wordmark, GT Sectra 24pt, Cream-100
│  (top-left corner)          │
│                             │
│  [PHOTO FILLS CENTER]       │  ← Daytime room photo, 1080×880px
│  65–75% of canvas           │
│  Full width, bleed to edges │
│                             │
├─────────────────────────────┤
│                             │
│  JULY 18, 2026 · CHICAGO    │  ← Label-caps, Inter 12pt, Slate-500
│                             │
│  It's 2pm.                  │  ← GT Sectra 64pt, Midnight-900
│  The music does             │
│  the work.                  │
│                             │
│  Saturday afternoon in a    │  ← Inter 18pt, Ink-900
│  real room with real people │
│  who said yes to the same   │
│  thing.                     │
│                             │
│  Application opens July 1   │  ← Inter 14pt, Terracotta-600
│  resonance.com/apply        │
│                             │
└─────────────────────────────┘
```

### Locked Elements
- Wordmark (top-left, never centered)
- Photo region (top 75% of canvas)
- Date stamp position (directly below photo)
- Headline font/size/color (GT Sectra 64pt, Midnight-900)
- Body copy font/size/color (Inter 18pt, Ink-900)
- CTA link font/color (Inter 14pt, Terracotta-600)
- Background: Cream-100 (#F5EFE3) below photo
- Margins: 24px on left/right

### Swappable Elements
- Photo
- Event date (in date stamp and headline)
- Headline (≤8 words, one mechanic)
- Body copy (≤30 words)
- Application opening date (in CTA)
- Application URL (if it changes)

### Notes
- This template exports as JPG for IG and as 300dpi CMYK for print
- No drop shadows, no QR codes as focal elements
- Spacing between date stamp, headline, body, CTA is consistent (20–24px)

## Template 4: Print Flyer (8.5×11in, portrait, 300dpi)

### Purpose
Physical handout. Same design as digital flyer, scaled to letter size for print.

### Specs
- **Dimensions**: 8.5×11 inches
- **Resolution**: 300dpi
- **Color Profile**: CMYK (not RGB)
- **Bleed**: 0.25 inches
- **Safe Area**: 0.5 inches inset from edge
- **Paper Stock**: 100lb uncoated text or 80lb cover (never glossy)

### Layout (Same Structure as Digital)
```
Wordmark (top-left)
[PHOTO fills 60–70% of canvas]
Date stamp
Headline (GT Sectra, scaled to 72–96pt)
Body copy (Inter, scaled appropriately)
CTA link
```

### Locked Elements
- Same as digital template (colors, typography, structure)
- Margins account for bleed (0.25")
- All type sits within safe area (0.5" inset)

### Swappable Elements
- Same as digital template

### Notes
- Before printing: download as PDF and verify color profile is CMYK
- Ask printer to confirm paper stock (uncoated only)
- Request soft proof to check color accuracy (Terracotta may shift slightly on uncoated)
- Export from Canva as PDF 300dpi for best print results

## Template 5: Email Header (600×200px)

### Purpose
Email newsletter header. Sets up the announce, drives to application link in email body.

### Layout
```
┌───────────────────────────────────┐
│  Resonance                        │  ← Wordmark, GT Sectra 20pt, Cream-100
│                                   │
│  [PHOTO 50% LEFT]  It's 2pm.      │  ← Photo + headline split layout
│                    The music      │     Headline: GT Sectra 36pt,
│                    does the       │     Terracotta-600
│                    work.          │
│                                   │
│                    Saturday        │  ← Details: Inter 14pt, Ink-900
│                    July 18         │
│                    Chicago         │
│                                   │
└───────────────────────────────────┘
```

### Locked Elements
- Wordmark (top-left)
- Left 50% reserved for photo
- Right 50% reserved for copy (headline + details)
- Background: Cream-100 (#F5EFE3)
- Font families and sizes (above)
- Horizontal divider (1px, Border color #E1D6C2)

### Swappable Elements
- Photo
- Headline (≤6 words)
- Event date + city
- Can add small CTA button ("Apply now") below if space

### Notes
- This header sits ABOVE the email body (not inside it)
- Must be responsive — looks good on mobile (60% width)
- Click-through should link to application page or full event post

## Build Order & Time Estimate

**Phase 1: Layout & Locked Elements** (60 min)
1. Create digital flyer template (25 min) → lock in Canva
2. Create IG feed post template (15 min) → lock in Canva
3. Create email header template (10 min) → lock in Canva
4. Create IG story (5-slide) template (10 min) → lock in Canva

**Phase 2: Print Template** (30 min)
5. Duplicate digital flyer → resize to 8.5×11 → adjust resolution to 300dpi → set color profile to CMYK → lock

**Phase 3: QA & Folder Setup** (30 min)
- Test creating a design from each template (make sure locks work)
- Organize in Canva folders
- Share folder with Andrea
- Document template naming & location

**Total first-time setup**: ~120 minutes (2 hours)

## Reuse Workflow (Per New Event)

For each new event (e.g., August, September, etc.):

1. **Digital Flyer**: "Create design from template" → swap photo + headline + date + copy (8 min)
2. **IG Feed Post**: "Create design from template" → swap photo + headline + body copy (7 min)
3. **IG Story**: "Create design from template" → swap photos + update dates (10 min)
4. **Email Header**: "Create design from template" → swap photo + headline + date (5 min)
5. **Print Flyer**: "Create design from template" → verify CMYK + bleed (2 min)

**Total per event after setup**: ~30–35 minutes
