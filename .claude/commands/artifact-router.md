# /artifact-router

Global artifact organization router for files, documents, artifacts, project folders, deliverables, staged cleanup, canonical placement, and enforcement.

Read and execute `.agent/workflows/artifact-router.md`. The executable source is `execution/artifact_router.py`.

Default to inventory, classification, staged move plans, backlog maps, or enforcement checks. Do not apply moves, delete files, archive broadly, or reorganize the workspace without explicit approval.
