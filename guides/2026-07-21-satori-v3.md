## ⚡ If you only read 10 lines

- Any layout, before anything else: `/satori-three-flow` — commit **Hook → Secondary Detail → Finisher**, and the Finisher (CTA/date/price) gets committed FIRST.
- Doctrine line: **largest ≠ most important; largest = entry.** The essential info rides the *end* of the journey.
- Ship bar: **≥3 deliberate contrast forms**, zonal not global — `/satori-contrast-stack` to build, `/satori-contrast-audit` to check. <3 nameable forms = the AI-flat tell.
- Any web surface before build: `/satori-frontend-flow` — beat map **punch → linger → release**, always ending on release into the CTA.
- Verification habit: shrink to ~120px thumbnail; eye bounces → fix contrast → spacing → alignment, in that order.
- Memorability play: `/satori-expectation-flip` — ONE learned association inverted (teal skull), against a straight field.
- Arrow-free flow: `/satori-gaze-path` — faces/shapes/light point the eye; never let a face point off-canvas.
- Contrast on UI = choice architecture: CTA gets the page's only saturated accent; the larger option gets clicked; red reserved for urgency.
- Temporal flow is the 99% edge — almost nobody engineers when/how long the eye lingers.

## The mental model

1. **A layout is one journey, not a field of elements.** Three committed anchors carry it; everything else pays rent or gets evicted. LIFT audits hierarchy after the fact — three-flow *originates* it, so the v3 sequence runs spine (21) → gaze wiring (24) → contrast (22) → grid → the v1 audit machinery.
2. **Contrast is the anti-generic mechanism.** AI defaults distribute emphasis evenly; deliberate zonal contrast is exactly what it can't do unprompted. Nine nameable forms in three tiers — the advanced tier (psychology/emotion/concept) works by violating a learned association, which is memory-encoding by other means.
3. **Pages are temporal compositions.** Punch/linger/release beats (the Apple product-page pattern) turn a scroll into rhythm; the release into a calm CTA zone is the beat almost every generated page is missing.

## Per-capability notes

**Three-Flow Spine (GP-18).** Mechanism: commit Finisher first ("if they remember nothing else, they leave with ___"), then Hook (largest visual) and Secondary. Verify at thumbnail. When NOT to: logos (one beat — `/satori-logo-concept`), undefined message (`/satori-comms-brief` first). Worked exemplar in the reference: Buck Design "Universe '24" — frame archived. Honest edge: the ATTISM exception (type hooks, date finishes) requires judgment; the spec forces you to justify it.

**Contrast Stack + Audit (GP-20).** Mechanism: 9-form menu, each selection assigned to an anchor; double-whammy zones (element contrasts container AND its content contrasts internally); restraint logged as decisions. When NOT to: palette strategy is `/satori-color`; wrong *vibe* is `/satori-feeling-calibrate`. The audit twin reads existing designs Nike-poster-style and prescribes quiet-first (silence noise before adding signal). Honest edge: the audience gate ("cheap hectic" can be correct) means no score without knowing the buyer.

**Gaze Path (GP-19).** Mechanism: hierarchy decides first fixation, direction decides the rest — gaze lines, funneling angles, curves, light falloff. The Dazed move: quiet the element the path already delivers (black masthead), buying back contrast budget. Honest edge: needs directional assets in the composition; a flat type-only layout gets little from it.

**Expectation Flip.** Mechanism: evidence the norm → invert ONE association → three-question service gate (serves message / reads without narration / audience+cultural check) → straight field around the flip. When NOT to: trust surfaces (checkout, legal, medical). Cultural connotation check is mandatory on loaded symbols.

**Frontend Flow.** Mechanism: page spine + beat map + behavioral contrast + directional wiring, compiled into a brief a developer or generation tool executes and Jack Roberts can codify. The 10%-zoom test: rhythm should be visible as dense/empty banding. Honest edge: **unproven on a live build** — first deployment (Proof-to-Market landing or MyBPM shop) is the open thread.
