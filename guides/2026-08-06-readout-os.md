# Readout OS — What We Built 2026-08-06 and How to Use It

> One session took the research-brief engine from a single-purpose tool to the system's delivery layer: every surface re-skinned to the Farrice Cain Premium Minimal brand, the Briefing Room upgraded into a filtered/paginated library with agent context packs, the Pulse rebuilt as a click-to-complete live console, a Visual Delivery Doctrine ratified for both harnesses, and a deterministic librarian keeping the shelves current. Companions: `.agent/workflows/briefs.md` (authoring doctrine), `docs/solutions/2026-08-06-live-local-board-pattern.md` (the live-board pattern), `_active/farrice-brand/premium-minimal/REPORT-DIALECT.md` (design-system exceptions).

## ⚡ If you only read 10 lines

- `/briefing-room` — open the library (uses the live server when running, static file otherwise).
- `python3 execution/pulse_serve.py --open` — live boards: `/` = Pulse console, `/room` = Briefing Room; buttons WRITE (done/park/reopen, log outcome, archive); idle-exits after 2h.
- Any brief render = complete package automatically: HTML + `.md` mirror + `-context.json` pack + room index refresh. No route can miss it.
- Doctrine line: reusable deliverables (research · ICP · extraction · client · receipts) default to briefs; conversation stays conversation; markdown stays first-class.
- Card copy grammar: `path` = for file-access tools (Codex/Claude Code); `copy brief` = full inline paste for any chat AI.
- Outward-facing = `--share` render ONLY (strips paths/costs/pack). Skim authored prose before sending.
- Drive vault: `--gdoc` for briefs, `python3 execution/md_to_gdoc.py <file.md>` for any markdown (30TB — use it).
- Librarian: `python3 execution/brief_library.py archive|unarchive|audit`; periodicals auto-archive at 30d; archived is NEVER gone (filter-only).
- Side window: leave a served board open — it reloads itself when work changes it underneath.
- Design tokens live in ONE place: `templates/research-brief/template.html` `:root`; change once, re-render loop in `/briefs`.

## The mental model

1. **One engine, four artifacts, every time.** `render_brief.py` is the only door; walking through it always yields the human view (HTML), the agent view (md mirror), the grounding manifest (context pack), and a fresh room index. Nothing downstream depends on remembering a second step.
2. **Two copy grammars because two consumer types.** Tools with disk access want a path; chat models want content inline. Every card and every brief page carries both.
3. **Live is a mode, not a service.** The localhost server is on-demand and self-terminating. Served = buttons write and pages self-reload; `file://` = the same buttons copy the exact command. Nothing ever breaks, nothing runs overnight.
4. **The librarian is policy, not memory.** Currency is applied on every regen (which happens on every render), so shelves stay honest without cron jobs or anyone remembering.

## Capability: the Briefing Room (visual delivery layer)

**What it is:** `deliverables/research-briefs/index.html`, generated by `execution/brief_library.py` — every brief as a Premium Minimal card with sidebar filters (shelf/priority/category, counts), 10-per-page pagination, compiled-date sorting, quick-copy buttons, and a housekeeping strip.
**When to reach for it:** any reusable output — the five family recipes (research, ICP/avatar, extraction dossier, client deliverable, build receipt) live in `.agent/workflows/briefs.md` § What ships as a brief, with chip/category/priority conventions and a semantic-document mapping table.
**When NOT to:** quick answers, corrections, conversational output — markdown or chat is cheaper and correct. Standalone md deliverables remain fully legitimate.
**How to invoke:** author JSON per the schema in `execution/render_brief.py`'s docstring → `python3 execution/render_brief.py <json>`. Categories/priority are one JSON line each (`"category": "icp", "priority": 1`).
**Worked example:** `deliverables/research-briefs/icp-invisible-expert/` — ICP profile with verbatim buyer language, resistance matrix, ranked bridge moves, say/never-say card. `design-system-showcase/` renders every section kind once.
**Honest edges:** `--share` strips mechanical internals only — costs/paths written into authored prose are the author's to redact. A hand-dropped HTML (bypassing the renderer) lists in the room but lacks mirror/pack.

## Capability: the live Pulse (click-to-complete console)

**What it is:** cockpit (sprint band, tiles, needs-you top-3, fresh intel pulled from the room) + context-rich console (mission cards with goal-in-words, age, outcome, copy-packet), backed by `execution/pulse_actions.py` — the system's first mission-close writers — and `execution/pulse_serve.py`.
**When to reach for it:** morning read; closing/parking/reopening missions; logging outcome check-ins (inline revenue + one-line form); resuming/archiving handoff threads.
**When NOT to:** deep mission work — the board points into work (`copy packet`, `/resume <thread>`); it is not where work happens.
**How to invoke:** `/pulse-board` or `python3 execution/pulse_serve.py --open`. All actions also exist as CLI (`pulse_actions.py done|park|reopen|outcome|outcome-snooze|outcome-dismiss|thread-archive`).
**Worked example:** live POST round-trips verified on scratch data; tier strings like "T2 waiting" are prefix-matched (exact-match was why "needs you" always rendered empty pre-rebuild).
**Honest edges:** revenue numbers are never invented — empty form logs $0. The `open` links route through the server's ROOT-jailed OS opener because http pages cannot navigate `file://`.

## Capability: the librarian (lifecycle without a daemon)

**What it is:** shelf-keeping inside `brief_library.py`: `status`/`superseded_by` fields (additive), archive/unarchive (CLI + live card buttons), `audit`, auto-currency (periodical categories `zeitgeist`/`angles` archive at 30 days — constants at the top of the file, tunable), stale flags at 30d for the rest, broken-path detection via context packs.
**When NOT to:** never delete — archived keeps every file in place; the shelf filter is presentation only.
**Honest edges:** auto-currency keys off render mtime tiebreak + compiled dates; a brief re-rendered today resets its clock.
