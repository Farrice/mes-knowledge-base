# Creative OS — The User's Guide (copy-paste edition)

> How to actually USE everything built 2026-08-02→04: the `/generate` engine, the Asset Command Center, your locked avatar `frbpm`, the eight masters, and the styles library — for social media, client work, and anything visual. Every prompt below is copy-paste-ready; steer by swapping the [BRACKETS]. Costs shown are real (fal pay-as-you-go; caps $20/day).

## ⚡ If you only read 10 lines

- **See everything:** 🎨 Desktop icon, or `/assets-board`. Every asset has 📋 Copy path + 📝 Copy prompt.
- **Make anything:** just describe it — the intent mirror reflects it back, the craft gate loads the right master, then it generates. You never need to name a model.
- **Your avatar:** say *"use frbpm"* in any creative ask → your locked anime self appears, consistent every time.
- **Any style you loved once:** board → ✨ Style Cards → Copy prompt → paste into your next ask.
- **Money grammar:** add *"total budget $X"* to any batch — it's enforced in code, not vibes.
- **Paid video always shows you the shot + price first** and waits for your "go."
- **Compare before committing:** *"give me 3 takes in 3 different styles"* → pick → iterate the winner only.
- **Video feels dead?** `/dave-clark-flat-to-cinematic-audit` before you post it.
- **Everything works identically in Codex** (same files, same commands; the mirror runs constitutionally there).
- Rough cost anchors: image $0.04 · 5s video ~$0.65 · voiceover ~$0.10 · full avatar scene $0.04.

## The one workflow to remember

**Describe → confirm the mirror → pick from takes → say what to change → ship.** You bring intent and taste verdicts; the system carries the craft (that's the standing doctrine — never learn the tools, learn to steer me).
