## The mental model

1. **Teaching is the engine, not the marketing.** The four phases — Lead Gen → Conversion → Fulfillment → Retention/Ascension — are all the same skill deployed at different objectives. There is no sales team because the teaching IS the selling.
2. **Feeling over information.** An asset is judged by the impulse it creates ("I felt ready to book"), never by coverage ("I learned a lot"). One idea per asset — "it's one drink at a time." An overwhelmed person never takes action.
3. **Context determines value.** Free channels get the WHAT generously; the paid container gets the HOW — not because the info is withheld, but because "when somebody pays you, they'll be more receptive of the how-to." Disclosure is calibrated per platform via `/oe-objective-by-context`.
4. **Three layers in one skill.** Interior Game (mindset: "I am boring — I just run the play"), Exterior Game (the teach-to-sell craft), and the Sales & Offers layer added 2026-07-01 (8 Buyables, packaging law: "People don't buy what it is you sell. They buy what it is you say").

## 1. `/oe-teaching-business-os` — the router

**What it is.** A diagnostic orchestrator. It does not produce content or offers — it walks the ladder top-down, stops at the FIRST rung that isn't solidly built (most operators self-report a later rung than they've earned), and dispatches ONE sub-workflow with a "built when" success metric plus an explicit do-NOT-skip-to guardrail.

**When to reach for it.** Any "where do I start / what's next / why is this stuck" question on a teaching, coaching, or personal-brand business. The stuck symptom in the operator's own words is the primary rung-locator ("attention but no sales" → Conversion; "I'll run out of ideas" → Phase 0 Mine IP).

**When NOT to.** You already know the rung and just need the tool — invoke the sub-workflow directly. Operator wants a sales team and a build-to-sell exit — this OS optimizes the no-sales-team machine; say so plainly rather than routing politely.

**How to invoke.** `/oe-teaching-business-os` with: the expertise, owner's intent (cash-now vs build-to-sell), current state, and the stuck symptom. Pre-flight gate: the Four-Soils check runs on the OPERATOR first — a chronic non-implementer gets `/oe-receptive-soil-filter` pointed inward before any roadmap.

**Honest edges.** The roadmap is only as honest as the self-reported current state; revenue inputs stay labeled UNCONFIRMED.

## 2. `/oe-teach-to-sell-engine` — the converting asset builder

**What it is.** Seven steps that build one asset: set the ONE idea + target FEELING → name the belief shift (BEFORE → AFTER) → draft receiver-first → rewrite as WHAT-not-HOW with the HOW explicitly parked "→ paid container" → over-deliver via story/picture/specific (never added information) → install Possible·Easy·Trust with a self-selecting CTA → margin-note every beat with the feeling it creates. Beats with no feeling get cut.

**When to reach for it.** People watch, nod, and don't act. Also: web-class segments, launch emails, even sales calls (reframed as a teach).

**When NOT to.** Fulfillment/course modules — there the HOW is finally allowed (still one idea per module). Pure reach content with no next step — cheaper to use the content experts directly.

**Worked example.** None live yet — the format adaptations table in the workflow (IG/YouTube/email/webinar/sales call) is source-derived, not run-derived. First real run should be a Farrice conversion asset, which is blocked on the Step-0 decision below.

**Honest edges.** The 12-criterion rubric gate is a self-score; pair with `/two-axis-verify` on anything client-facing.
