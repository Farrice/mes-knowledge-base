## The Non-Negotiable Reading Discipline

**Before any major {{BRAND_NAME}} decision**, read these three docs in this order:
1. `05-ops/03-drift-signals.md` — am I drifting?
2. `00-foundation/05-non-negotiables.md` — does this proposal cross a line?
3. `05-ops/04-success-metrics.md` — does this serve the 25% couple-formation target?

If any signal fires or any line is crossed: **stop**. The brand stays unchanged until the proposal is reframed or rejected.

---

## What Gets Updated How

The Constitution principle is: **amend, don't rewrite.**

- **Foundation docs (Layer 0)**: amend only when {{FOUNDER_NAME}} names a change in writing. Cascade the amendment to all references.
- **Visual system (Layer 1)**: refine after each event based on what worked / didn't work in production.
- **Creative briefs (Layer 2)**: living — refine as production reveals what's missing.
- **Marketing system (Layer 3)**: living — update after each event with what the data taught us.
- **AI handoff (Layer 4)**: living — each prompt that fails goes back into the library improved.
- **Ops (Layer 5)**: living — drift signals + success metrics get re-tested per-event.

The change log (`05-ops/01-change-log.md`) tracks every amendment with date, reason, and who approved.
