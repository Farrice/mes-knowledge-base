## Format Reminder For Future Amendments

When logging a new amendment, copy this block and fill it in:

```
**[YYYY-MM-DD] — [doc filename]**
- What changed: [1-line description]
- Why: [1-2 sentence reason]
- {{FOUNDER_NAME}}-confirmed: [Yes / Pending / Date]
- Cascade impacts: [list of downstream docs that need review]
```

The cascade-impacts line is non-optional. Per the cascade rules in `05-ops/00-update-protocol.md` §4, every amendment names what downstream the change touches — even if the answer is "none." A blank cascade line is a flag that the amendment hasn't been thought through.
