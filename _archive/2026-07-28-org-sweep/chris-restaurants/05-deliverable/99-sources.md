## Sourcing Discipline (the rule the deliverable was built under)

Every dollar figure, every percentage, every competitor statistic in this folder is anchored to a source documented inline in the relevant artifact. If a claim is not anchored to a source, it is described as an inference, an estimate, or a defensible range. No POS data was used to produce any analysis in this folder. Every finding is reproducible from public data alone, plus the verified Parkzer.com receipt and the Apify-pulled review datasets.

If any reader wants to verify a specific dollar attribution and cannot trace it through the inline citation in the source artifact, that's a documentation gap and should be flagged. The expectation is that every number in this folder defends itself.
