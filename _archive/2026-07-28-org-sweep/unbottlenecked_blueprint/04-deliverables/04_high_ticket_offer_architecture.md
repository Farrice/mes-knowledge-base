## Phase 3: MVP Scope Guillotine (The Delivery Container)
We must relentlessly cut scope to ensure this deliverable does not take 3 months per client. 
- **Core Problem Statement**: Complex creators need their tacit knowledge codified into an active, 24/7 AI-accessible brain.
- **KEEP**: 
  - The Core Operating Ruleset (`GEMINI.md` / `CLAUDE.md` equivalent).
  - A standardized Notion memory backend (Projects, KIs, Assets).
  - 3 Core Custom Workflows (e.g., Output Generation, Strategy Lock, Fulfillment).

- **MVP Specification**: A 30-day "Done-With-You" sprint. Delivery consists of the core agent instructions, 3 tuned workflow files, and the connected Notion framework.
