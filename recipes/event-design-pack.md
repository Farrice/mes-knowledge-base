## The job
From an event idea to a matched set of invitation and party assets, built through visible co-creation beats, taste calls answered by him, nothing printed or sent without approval.

## Sub-jobs / lanes
- L1 Brief — event details (who, what, theme, date), taste references on file [parallel]
- L2 Concept — design-philosophy pass per `skills/canvas-design/SKILL.md` [after: L1]
- L3 Draft assets — invitation plus party assets via `skills/fantastic-posters` or `skills/kittl-graphic-design` typography [after: L2]
- L4 Jam loop — two-take co-creation, 10-second gut verdicts per `.agent/workflows/jam.md` [after: L3]
- L5 Gauntlet — `.agent/workflows/design-gauntlet.md` bounded repair against a named reference [after: L4]
- L6 Package — export set (print + digital), asset-board index [after: L5]

## Ask me first
- Q: His raw take on the theme and vibe (the jam spark) · look first: thought-bank inbox, `.agent/workflows/jam.md` new-spark mode
- Q: A named reference to gauntlet against, or Creative Unleash mode? · look first: `directives/blind-bar-protocol.md`

## Handles alone
Brief capture, concept draft, asset generation, jam takes, bounded gauntlet repair rounds, package export.

## Comes back when
- Each jam loop's gut verdict (that is the co-creation, not a formality)
- Two rejected renditions of one asset → stop, back to the brief
- A taste call only he can make (color, tone, "is this us")

## Needs approval
Printing or ordering physical items · publishing or sending the invitations.

## Needs
`skills/fantastic-posters` · `skills/canvas-design` · `.agent/workflows/jam.md` · `.agent/workflows/design-gauntlet.md` · `directives/fal-usage-policy.md` (Fal budget gate).

## When it breaks
| Failure | Keep-going move | Ask when |
|---|---|---|
| generation blocked by the cost gate | surface the cost, hold for his approve | never retry silently |
| gauntlet can't render the artifact | return VISUAL UNVERIFIED, ask for a renderable path | never guess a score |
| two rejected renditions | stop, back to the brief | second miss |

## Done means
Asset set exported (invitation plus at least one party asset) · gauntlet pass or explicit VISUAL UNVERIFIED noted · his gut verdict recorded per jam loop.
