# Video Script — How To Measure AI Search Visibility Honestly

Format: video script. Structure: visual hook -> unstable answer -> receipt method -> proof boundary.

## Scene 1 — Visual hook

**Shot:** Split screen. The same query appears twice. The cited sources are different.

**Voiceover:** “If the answer moves, one tracker screenshot is not ground truth.”

## Scene 2 — What is unstable?

**Visual:** Highlight the engine, exact query, time, answer excerpt, cited URL, and evidence file.

**Voiceover:** “The honest unit is a dated observation, not a permanent rank.”

## Scene 3 — The receipt method

A visual demonstration that unstable AI answers require dated query and evidence receipts.

1. Save the exact query.
2. Name the engine and surface.
3. Add the timestamp.
4. Preserve the answer and citation evidence.
5. Repeat the same observation set later.

Source: https://example.com/video-source-receipt [1]. For example, a citation can be observed without proving that it caused traffic.

## Scene 4 — Proof boundary

**Voiceover:** “Do not claim a tracker proves stable citations, causation, traffic, leads, or revenue.”
