# Reality Before Rhetoric Regression Fixtures

This directory contains two intentionally separate regression surfaces.

## Frozen V1 experiment

`regression-set.json` freezes the original activation and artifact-tier design
across two realistic behaviors in each of five domains:

- personal content;
- offer copy;
- strategy;
- research;
- system repair.

Each pair contrasts a blocked or narrowed claim with a source-ready path. It is
preserved as historical evidence and must keep the accepted-behavior hash
`20fd35a3dfb99c088d481649a71a73eecfef8afaec73cffb11e288d263ce6077`.
It is no longer the active behavior contract.

## Active restoration regression

`anti-shackle-regression-set.json` freezes six safe semantic controls, the four
hard claim/material veto families, and the Dhar capability surfaces that must
survive restoration.

The active verifier must prove:

- no front-door RBR import or packet field;
- no mandatory artifact tier or content-card schema;
- safe exploration continues;
- truth, proof, privacy, and permission remain protected;
- Dhar storytelling, packaging, community, production, capacity, and Bayer
  composition capabilities remain present.

## Freeze policy

Both hashes are explicit. Future behavior changes require a versioned fixture
or an intentional hash update with a written reason. Silent drift fails
verification. The verifier reports hashes; it does not rewrite them.
