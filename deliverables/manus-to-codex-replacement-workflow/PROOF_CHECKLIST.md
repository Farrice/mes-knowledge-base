# Proof Checklist

## Evidence

- [ ] Original external session, transcript, screenshots, or preview captured.
- [ ] Unavailable evidence named.
- [ ] User goal preserved.
- [ ] Final artifact identified.

## Local Artifact

- [ ] Local files exist.
- [ ] Source is editable.
- [ ] Assets are local or gaps are named.
- [ ] Claim boundaries are preserved.
- [ ] No accidental publishing or external writes.

## Browser Verification

- [ ] Desktop viewport checked.
- [ ] Mobile viewport checked.
- [ ] Wide viewport checked when floating UI exists.
- [ ] Broken images: 0.
- [ ] Horizontal overflow: false.
- [ ] Clean console/page reload.
- [ ] Screenshots saved for visual artifacts.

## Regression Scans

- [ ] Palette/style regression scan, if relevant.
- [ ] Banned or risky claim scan, if relevant.
- [ ] Source path and prompt reuse scan.
- [ ] Workflow packet includes a cold-start prompt.

## Closeout

- [ ] Run Map written.
- [ ] Preservation Lock written.
- [ ] Hardening audit written when patched.
- [ ] Reuse prompt included.
- [ ] Promotion boundary stated.
