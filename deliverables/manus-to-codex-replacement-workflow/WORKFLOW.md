# Workflow - External AI Run To Local Codex Artifact

## Phase 1 - Source Access

1. Open the external session or artifact.
2. If blocked, ask for login, export, screenshots, or pasted transcript.
3. Separate observed evidence from inferred behavior.
4. Save or cite the source surface used.

## Phase 2 - Run Map

Extract:

- original user goal
- prompt sequence
- agent decisions
- assets generated or changed
- files/components touched
- final artifact
- verification loop
- acceptance criteria
- hidden gaps or unavailable evidence

## Phase 3 - Preservation Lock

Write:

- **Keep**: what made the original work.
- **Change**: what Codex should improve.
- **Do not disturb**: claims, style, source boundaries, and approvals.
- **Risk**: what would make the reproduction worse.
- **Gate**: checks required before delivery.

## Phase 4 - Build Shape

Choose one:

- audit only
- local static reproduction
- patched existing project
- new app/site
- workflow packet
- command candidate
- no build

Default to local editable source. Do not hot-promote commands without approval.

## Phase 5 - Local Rebuild

1. Create or patch the local target folder.
2. Download or recreate assets only when allowed.
3. Rebuild with readable source, not opaque copied bundles.
4. Preserve the final artifact and the process.

## Phase 6 - Hardening

Audit against the original:

- first-viewport fidelity
- hierarchy and typography
- visual asset quality
- copy specificity
- persuasion speed
- claim boundaries
- mobile fit
- artifact editability

Patch the weakest one to three issues. Avoid endless polish.

## Phase 7 - Verification

Run browser checks:

- desktop viewport
- wide desktop, if floating UI exists
- mobile viewport
- broken image count
- horizontal overflow
- console/page errors
- source scan for known regressions

Capture screenshots when the work is visual.

## Phase 8 - Reuse Package

Produce:

- Run Map
- hardening audit
- reusable prompt
- proof checklist
- cold-start fixture
- optional promotion recommendation

## Finish Line

The run is complete when the local artifact opens, proof checks pass, and a future Codex session can repeat the workflow from files without relying on hidden chat context.
