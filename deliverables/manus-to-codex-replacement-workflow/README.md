# Manus-To-Codex Replacement Workflow

This is a cold, reusable workflow packet for turning an external AI session into local editable source, proof, and reusable prompts.

It is intentionally **not** hot-promoted as a slash command. Promotion to `.agent/workflows`, `.claude/commands`, or `.agents/skills` should happen only after explicit approval and router/index validation.

## Use When

- A Manus, Lovable, v0, Claude, ChatGPT, or other AI tool produced a good result.
- Farrice wants to know whether Codex can reproduce or beat it.
- The goal is not a comparison essay, but a local artifact that survives tool churn.

## Start Here

1. Read [SKILL_SYSTEM_CONTRACT.md](SKILL_SYSTEM_CONTRACT.md).
2. Run [WORKFLOW.md](WORKFLOW.md).
3. Use [PROMPTS.md](PROMPTS.md) for paste-ready invocations.
4. Verify with [PROOF_CHECKLIST.md](PROOF_CHECKLIST.md).
5. Use [COLD_START_FIXTURE.md](COLD_START_FIXTURE.md) as the first regression example.
