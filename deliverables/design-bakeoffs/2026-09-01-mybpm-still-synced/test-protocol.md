# MYBPM STILL SYNCED — Blind Composition Bake-off

## Test control

One existing campaign is rendered through two composition routes. The test is blind and the route assignment is randomized.

Locked for both candidates:

- Brand: `MYBPM`
- Campaign: `WEEK 1 / STILL SYNCED`
- Supporting line: `MET STRANGERS. FOUND FAMILY.`
- Data line: `03:17 / 128 BPM`
- Footer: `NIGHT SOCIETY`
- Palette: black, white/mineral white, concrete gray, frequency acid
- Typography: neutral grotesk/system sans
- Motif: one EKG trace with one acid signal
- Formats: desktop 16:9, square 1:1, vertical 9:16

Only the layout and composition system may differ.

## Fairness rule

The baseline must remain competent and brand-correct. It may not contain intentional errors, clutter, weak contrast, or broken hierarchy. The alternate route may not add imagery, copy, colors, effects, or typographic families unavailable to the baseline.

## Taste verdict

Farrice chooses `A`, `B`, or `neither`, then names the format where the difference is clearest. The route key stays hidden until that verdict is recorded.
