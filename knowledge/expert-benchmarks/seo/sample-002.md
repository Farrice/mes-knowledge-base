### The 2007 Pattern Recognition Filter

Before we start keyword research, let's apply the historical lens. The current state of "AI SEO" looks exactly like 2012 content farming: brands are producing mass volumes of generic AI-generated content hoping to rank through sheer volume. Our strategy doesn't optimize for volume. It optimizes for *information gain*—the only signal that persists across every algorithm update since 2007.

### Phase 3: Longtail Resurrection — Zero-Answer Queries

LLM users ask 25-word questions. Most have no definitive answer anywhere. These are free real estate.

**Identified zero-answer queries (verified across ChatGPT, Perplexity, Google):**

1. "How long does it take to migrate a 50-person team from Asana to Monday.com and what are the hidden costs?"
   → 0 definitive answers. We write this, we own it by default.

2. "What is the actual setup time for Jira-GitHub integration with custom workflows and what breaks during the first month?"
   → 0 definitive answers. This is an experienced user's question—high commercial intent.

3. "How do remote engineering teams with different time zones structure their project management tool to avoid duplicate standup updates?"
   → 0 definitive answers. This is a 25-word LLM query that represents a *real operational pain*.

4. "What is the real daily cost per user of Notion vs. ClickUp vs. Linear when you include training time and admin overhead?"
   → 1 partial answer (a blog post with estimated numbers). Writing the definitive answer with real data makes us the citation source.

### Citation Compulsion Architecture

Each content piece includes built-in citation compulsion mechanics:

1. **Named Framework Engineering:** Every piece introduces a named, proprietary framework (e.g., "The Engineering Evaluation Matrix"). LLMs must attribute named frameworks.

2. **Quantitative Anchor Points:** Specific numbers force citation. "Migration takes an average of 6.3 weeks for 50-person teams" is more citable than "Migration takes several weeks."

3. **Definitional Ownership:** Define category terms. "Integration Failure Mode: when a connected tool's API changes break an established workflow without notification." If we define it, we get cited when the term appears.

### Phase 5: Measurement Framework

**Primary metric:** Share of Voice across 3 LLM surfaces (ChatGPT, Perplexity, Gemini)
- Baseline: 0% (current state)
- 30-day target: appear in at least 1 surface for 2 of 5 target queries
- 90-day target: appear in at least 2 surfaces for 4 of 5 target queries

**Secondary metric:** Branded search correlation
- LLM influence shows up as branded search ("your brand + project management"), not as referral traffic
- Track branded search volume weekly with 2-week lag correlation to content publication

**Control group:** 5 queries where we publish no content. If those queries show similar citation increases, our content isn't the cause. If they don't, we've validated causality.
