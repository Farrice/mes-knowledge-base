## Naming Sprint: AI-Powered Financial Planning Tool

### Strategic Question Cascade

Before generating a single name, we need to answer the questions that determine what kind of name we're building:

1. **What category does this live in?** → Financial planning / wealth management software
2. **What's the emotional end-state?** → Feeling in control without anxiety
3. **What's the enemy?** → Complexity. Jargon. The feeling of being "behind."
4. **What would make someone say this name out loud?** → If it felt like an insider password rather than a product label

### Category Escape Analysis

The financial planning space is polluted with predictable naming patterns:
- **Trust signals:** Fidelity, Vanguard, Prudential (Latin/institutional gravity)
- **Compound smash:** Wealthfront, Betterment, MoneyLion (function + aspiration)
- **Made-up tech words:** Robinhood (borrowed fame), Acorns (metaphor)

The *Category Escape Heuristic* says: if your name could swap with a competitor's and nobody would notice, you've failed. Every name above could plausibly belong to any of the others' products.

**Escape vector:** Move from financial vocabulary entirely. Name it like it belongs to a different category—one that carries the emotional resonance without the category baggage.

### The Short List (with strategic rationale)

**1. Measure** — *"Financial planning that actually fits your life."*
Why: The word operates in three registers simultaneously. In music, a measure is a unit of rhythm—your money has a tempo. In science, it's precision. In daily life, it's proportion. The name suggests the tool adapts to *your* scale without making you feel small.

**2. Proof** — *"Your money, verified."*
Why: In printing, a proof is the version you check before final. In math, it's airtight certainty. In spirits, it's strength. The name carries quiet confidence. It doesn't shout trust—it assumes it.

**3. Notation** — *"The financial record that reads like yours."*
Why: Mathematical precision without the coldness. Musical notation is personal—it's how *you* played it. This name positions the tool as a personal record, not an institutional dashboard.

### Recommendation

**Lead with Proof.** One syllable. Phonetically explosive (the P hits hard). Complete category escape from finance naming conventions. And the double meaning—proof as evidence, proof as strength—does the positioning work the tagline would normally carry.

**Kill Steady and Compass.** Both live inside the category they should be escaping.
