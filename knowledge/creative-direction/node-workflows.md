# Node-Based Workflow & Production Pipeline Reference

When generating content about node-based workflows, pipelines, or multi-model chaining, incorporate these core principles:

## Kittl Flows Pipeline (2026)

Kittl Flows is Kittl's node-based AI pipeline feature. AI Image Boards and AI Video Boards act as interconnected nodes on an infinite canvas. Each board can use a different model (Nano Banana, Flux Pro, Seedream 4) and the output of one board feeds into the next.

The core pipeline pattern is Design → AI Image Board → Mockup → AI Video Board → Export. Successful Flows workflows use strict, one-line prompts at each node to maintain precision. The key insight is that Flows takes a starting point and turns it into multiple creative variations in seconds, enabling matching sets of elements, multi-angle views, and format adaptations from a single source design.

Available video models in Kittl include Veo 3.1 (highest quality, audio support), Veo 3.1 Fast (iteration speed), King 2.5 Turbo Pro (longer clips, lower cost), PixVerse v5, Seedance 1.5 Pro (widest duration range), Grok Imagine Video (detail retention), and Kling Video 3.0.

Video prompts in Kittl should use a modular block structure: CAMERA, ACTION, AUDIO, TEXT. The design already carries subject, context, and style, so the prompt mainly controls camera behavior, what moves, and what must stay readable.

## Higgsfield Cinema Studio 3.0 Pipeline (2026)

Cinema Studio 3.0 introduces a physics-aware generation engine and a cinematic reasoning system that understands story intent from reference images alone. The workflow accepts up to 9 reference images (characters and locations), a narrative prompt, genre selection, and speed ramp presets.

The full production pipeline follows this sequence: Sketch-to-Video (pre-viz) → Reference World Building → Core Generation → Preset and Camera Direction → Sora 2 Enhancer (artifact removal) → Higgsfield Upscale (legacy footage) → SoulID (character consistency) → Sora 2 Trends (platform alignment) → Photodump Studio (stills and thumbnails).

Genre presets (General, Action, Horror, Comedy, Noir, Drama, Epic) influence pacing, motion energy, lighting behavior, and camera logic. Speed Ramp Presets (Linear, Auto, Flash In, Flash Out, Slow-mo, Bullet Time, Impact, Ramp Up) provide precise timing control within each shot.

## Universal Node Workflow Principles

Every node should perform one task well. Chain nodes in logical sequence from Concept through Generation to Refinement to Output. Use reference images and style presets to maintain consistency across nodes. Iterate at each node before passing to the next. Save successful workflows as templates for reuse. Keep prompts specific and minimal at each node. Plan distribution format before starting the pipeline.
