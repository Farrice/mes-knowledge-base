# The Commons — per-session shared reasoning files

One file per live council session: `<date>-<slug>.md`. The append-only blackboard all seated
personas read and write during deliberation — evidence, intermediate findings, named
disagreements — each member under its own `### <Name>` heading.

Rules and lifecycle: `directives/agent-mailroom.md`. Created by the conductor in
`.agent/workflows/roundtable-live.md` Step 2; snapshotted into the session digest at close.
These are RECORDS (dated filenames) — never built on directly; the living outputs are the
session digests in `knowledge/council-sessions/` and the persona memories.
