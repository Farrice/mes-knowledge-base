# Standing Buyer Panels

A panel file here is a reusable simulated-customer roster for `/buyer-council` (`skills/geoff-woods-ai-thought-partner/workflows/17-buyer-council.md`) — not a one-off persona set. Each file holds 4-6 tight seats (identity, incentives, what they defend, what triggers yes, tell-tale objection voice), always including a mandatory NO-FIT seat and, when price is in scope, an economic-gatekeeper seat.

Runs check here FIRST before building fresh personas — reuse compounds; rebuilding from scratch every time throws away the calibration history the panel is earning.

**Calibration ledger**: `calibration.jsonl` — one line per council run (`ts`, `artifact`, `panel`, `headline_prediction`, `real_outcome`). Predictions start `"pending"` and get updated once a real outcome lands. This is how a panel earns trust over time instead of staying a one-shot guess.
