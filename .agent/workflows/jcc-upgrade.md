# /jcc-upgrade — JARVIS Command Center Scale Upgrade

Scale up a running mission — add more experts or escalate to a higher deployment level mid-mission.

## Execution

1. Assess the current mission state: what workstreams are complete, what's in progress, what's remaining
2. Propose scaling up by one of:
   - **Option A:** Adding more sub-agents to current workstreams (within Solo/Strike)
   - **Option B:** Completing current workstreams, then re-deploying at higher scale with prior outputs as context (Solo/Strike → Campaign/Deploy)
3. Show the expanded proposal
4. Deploy only after user approval
5. **Phase 1 limitation:** Escalating from sub-agents to Agent Teams requires completing current work first
