# /kallaway-x-priestley-sll

Read and execute the workflow at `skills/kallaway-illusion-of-novelty/workflows/kallaway-x-priestley-sll.md` — Priestley supplies the lane cadence and bridges, Kallaway runs a per-post New Reveal + Contrast pass plus a new lane-level staleness monitor that rotates the reveal frame (never the lane) when a lane's angle pool runs dry.

Load before execution:
- `skills/kallaway-illusion-of-novelty/genius.md` — 5-component novelty engine
- `skills/daniel-priestley-sll-engine/genius.md` — SLL physics, four-lane system, 11×90 recognition math

## Usage
```
/kallaway-x-priestley-sll [SLL lane bank + batch window + niche stock takes + current news]
```

## When to use
- A lane bank and SLL cadence already exist and the daily batch is starting to read like the same post in a different hat
- A cadence running 2-3+ weeks where one lane (usually Pain) is producing posts a competitor could lift unchanged
- Team is tempted to fix lane fatigue by drifting a post into the wrong lane instead of mining a fresh angle

## Not This
Single-post rescue with no cadence around it → `/novelty-forge` or `/novelty-audit`. Positioning-layer novelty (the claim under the content, not the daily posts) → `/kallaway-x-dunford`. No lane bank yet → Priestley's `01-sll-system-map` first.

## Stacking
- Upstream: `01-sll-system-map` / `02-sll-short-form-daily` (cadence + lane bank)
- Downstream: `03-sll-long-form-explainer` / `04-sll-lead-form` (unaffected, still fed by the same bridged posts)
- Adjacent: `/kallaway-x-dunford` (positioning layer, not cadence layer); `/novelty-audit` (this crossing specializes it with the lane-level staleness mechanic)
