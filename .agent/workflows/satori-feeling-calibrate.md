# /satori-feeling-calibrate

> Same content, different feeling. Retune an asset premium / cheap / playful / reassuring through typography, color, layout, and surface alone — the message, offer, price, and copy never change — then prove the target feeling fits who actually sees it.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/19-feeling-calibrate.md
```

## Usage

```
/satori-feeling-calibrate [asset] target: [premium | cheap | playful | reassuring]
```

## When to Use

- The content is locked and correct, but the *feel* is wrong (reads cheap when it should read premium)
- You need to move an asset up- or down-market without changing the offer, copy, or price
- A client says "make it feel more expensive / more approachable / more fun" and you need concrete lever moves
- You're producing two tiers of the same asset (value line vs. flagship) that must *feel* distinct

## Output

A feeling-calibration spec:
- The LOCKED content and the current feeling named (one word + one clause)
- The target feeling, cleared through the audience-fit veto and the locked walk-away emotion
- Concrete moves on each of the four levers (type psychology · color scheme · layout · surface)
- Before/after rationale tying every lever move back to the target
- A production-ready description of the retuned asset
