# `/suzuki-launch-debugger` - Launch Debugger

## When To Use
- A digital product post is not converting.
- A funnel gets clicks or comments but no sales.
- A draft post needs a before/after repair.

## Load
1. `skills/alex-suzuki-digital-product-revenue-os/SKILL.md`
2. `skills/alex-suzuki-digital-product-revenue-os/workflows/05-launch-debugger.md`
3. `skills/alex-suzuki-digital-product-revenue-os/references/hidden-knowledge.md`
4. `skills/alex-suzuki-digital-product-revenue-os/references/revenue-mechanics.md`

## Execute
Run the Launch Debugger. Treat question-map-only, caution-only, single-CTA, no link lane, and no first-use path as floor failures.

## Usage
```text
/suzuki-launch-debugger [post/funnel] [product] [buyer] [price] [results]
```

## Required Output
- Diagnosis
- Primary bottleneck
- Repaired asset
- Buyer routing repair
- First-use or replay repair
- Behavior delta
- Proof gaps
