# /oren-oracle-architect

Build the **Oracle Content Architecture** — the expert-driven content system.

## Instructions
1. Load `skills/oren-brand-archetypes/genius.md` — Patterns 3 (Oracle section), 4, 5, 7, 8
2. Prerequisite: Archetype diagnostic must have selected ORACLE

## Context
Oracle brands have deep expertise to share. The core expert (or expert team) creates content that educates the audience into wanting the product. Funnel mechanic: Education → trust → product credibility → purchase.

**Canonical exemplar**: Ken Sakata / Front Office — salvage denim history → development process → product releases.

## Process

### Step 1: Expert-Adjacency Funnel Design (Pattern 7)
Build the 3-layer content architecture:

| Layer | Content Type | Purpose | Examples |
|:---|:---|:---|:---|
| **Top of Funnel** | Wide-interest educational | Attract broadly via expertise | History, trends, "why things are the way they are," predictions |
| **Mid-Funnel** | Process and development | Build trust via transparency | What you're working on, how you think, behind-the-scenes |
| **Bottom Funnel** | Product releases + launches | Convert educated audience | Launches, carousels, product details |

For each layer, generate 5-7 specific content ideas tied to the brand's domain.

### Step 2: Two-Account Assessment (Pattern 4)
Evaluate whether the brand should deploy the Two-Account Method:
- **Does the brand have a charismatic, knowledgeable founder?** → Yes = Two-Account
- **Brand account** → curated, polished, product-focused
- **Founder account** → top-of-funnel expert content, trends, opinions
- "The founder account drives awareness; the brand account captures intent"

If Two-Account: map which content types go where.

### Step 3: Niche Audience Math (Pattern 8)
For B2B or niche brands, build the value calculation:
- Estimated audience size per video
- Average contract/purchase value per viewer
- ROI comparison: 2,000 qualified views vs. 100,000 unqualified views
- Use this to justify the Oracle strategy to leadership

### Step 4: "Boring Industry" Excavation (Pattern 5)
If the brand or industry triggers the "boring" objection, run the Interest Excavation Protocol:
1. What does an insider find fascinating that outsiders don't know?
2. What arguments happen between experts in this space?
3. What's the history behind something everyone takes for granted?
4. What process would blow someone's mind if they saw it?

Target: 10+ content ideas the client previously dismissed.

### Step 5: Content Calendar Skeleton
Map the 3-layer funnel to a weekly/monthly cadence:
- How many top-of-funnel education pieces per week?
- How many mid-funnel process pieces?
- What's the product release cadence?
- Which pieces are iPhone-only? Which need production?

## Produces
3-Layer Oracle Funnel Map + Content Calendar + Two-Account Decision + Niche Audience Math (if applicable)
