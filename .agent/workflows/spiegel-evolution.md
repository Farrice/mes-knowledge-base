# /spiegel-evolution — Founder Evolution

> Map your current mode, identify the transition you're resisting, and build the skill for the next chapter.

## When to Use
- Stuck in one operational mode
- Business needs a different version of you
- Considering delegation but unsure what to keep
- Frustrated with how the job has changed

## Inputs Required
1. Current role (what you actually do day-to-day)
2. What you wish you were doing
3. What you're avoiding
4. Team size and capabilities
5. Business stage and challenges

## Execution Steps

### Step 1: Evolution Arc Diagnosis
| Mode | Description | You're Here If... |
|---|---|---|
| **Builder** | Doing everything | Can't name 3 fully delegated tasks |
| **Coordinator** | Managing others | >50% time in meetings/reviews |
| **Communicator** | Explaining the why | External communication is primary output |
| **Strategist** | Deciding what's next | Focus on decisions nobody else can make |

### Step 2: Resistance Identification
- Builder → Coordinator: "Nobody can do it as well as me" → Skill: delegation with standards
- Coordinator → Communicator: "I'll just send an email" → Skill: public presence
- Communicator → Strategist: "I need to stay close to the work" → Skill: strategic abstraction

Spiegel's rule: Choose to love it before you naturally love it.

### Step 3: Skill Development Protocol
1. Name the specific skill needed
2. Schedule recurring practice (weekly all-hands, monthly content)
3. Commit before comfort — don't wait to feel ready
4. Target 10+ reps before evaluating
5. Find honest feedback source

### Step 4: Delegation Design
**The Spiegel Keep Rule**: Stay close to product and customer. Everything else can go.

Map activities: Keep (product/customer touch) vs. Release (operations, admin, process)

### Step 5: AI-Enabled Scaling
Use agents to maintain information density as role evolves:
- Dashboard monitoring → agent summarizes daily
- Conversation awareness → agent surfaces hotspots
- Decision prep → agent creates briefings

## Output Format
```
## FOUNDER EVOLUTION — [Name]
### Current Mode: [Builder/Coordinator/Communicator/Strategist]
### Target Mode: [Next]
### Resistance: [What you're avoiding]
### Transition Skill + Practice Schedule
### Delegation Map (Keep vs Release)
### AI Agent Briefing Design
### 30-Day Sprint
```

## Quality Gate
- Must identify mode being avoided, not just aspirational target
- Practice must be scheduled with dates, not aspirational
- Delegation must include the "keep close to product" rule
- Must include AI-enabled scaling component
