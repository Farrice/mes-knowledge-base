# /jenny-text-transfer

A text-first post (LinkedIn / Substack Note / X) built by transferring Jenny Hoyos' short-form mechanics onto the written feed.

## Trigger
`/jenny-text-transfer`

## Workflow
`skills/jenny-hoyos-shorts/workflows/12-text-platform-transfer.md`

## Quick Use
Provide:
1. The idea/topic (raw is fine)
2. Platform (LinkedIn / Substack Note / X)
3. Audience + avatar (who's scrolling, what they fear/want/recognize)
4. Voice constraints (VOICE-CARD if under Farrice's name) + goal

## Output
A transfer honesty note, the finished post, a mechanics map (first-line frame, but/so beats, progression device, loop close), a relatability call, and stacking hand-offs.
