# /gw-thought-partner

A full strategic thought-partner session run live in-conversation — Claude interviews you before it answers, then delivers non-obvious strategies and iterates until you like where it lands.

## Trigger
`/gw-thought-partner`

## Workflow
`skills/geoff-woods-ai-thought-partner/workflows/02-thought-partner.md`

## Quick Use
Bring a problem — or nothing but willingness to answer questions. The session opens with "what is the biggest problem you're facing right now that, if solved, would unlock huge value?", builds a CRIT with you out loud, then interviews you one question at a time (3-5) before producing anything.

## Output
A live session: target lock (biggest-problem + 20% test), a co-built CRIT, an interview Claude runs one question at a time, non-obvious strategies grounded in your answers, and like/don't-like/top-changes iteration until you're satisfied. Reference arc: the Japan debt-restructure case.

## Stacks With
→ `/gw-crit` (build the CRIT prompt as a reusable artifact)
→ `/gw-feedback-loop` (the triad iteration, run as a dedicated pass)
→ `/gw-persona-flip` (Challenger stress-test when the loop plateaus)
→ `/gw-20-percent` (run first if you're not sure which problem is the real 20%)
