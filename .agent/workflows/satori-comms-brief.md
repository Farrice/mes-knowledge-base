# /satori-comms-brief

> The generative front door. Before a single element is placed, lock three decisions — what is the communication problem, what feeling do we want, where/how is this actually seen — and compress them into one paragraph the whole pipeline is audited against.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/15-comms-brief.md
```

## Usage

```
/satori-comms-brief [design task, raw brief, or vibe to convert into decisions]
```

## When to Use

- Starting any design from scratch — poster, logo, UI, social tile, package, ad
- A brief arrived as a vibe ("make it pop", "modern but warm") and needs converting into decisions
- A previous design came back "looking fine but not working" — the communication problem was never stated
- You're feeding the `/satori-design-think` pipeline — this is the intake it composes first

## Output

A locked one-paragraph comms brief:
- The communication problem, stated as a gap (not a task)
- The target feeling — the engineered next emotion (arrival → walk-away)
- The viewing context and distance (recognition-at-distance ladder)
- The compressed paragraph every later type/color/grid/image move is checked against

## Related Workflows

- `/satori-concept` — turn the locked brief into 3 anchored concept directions
- `/satori-design-think` — the end-to-end pipeline that composes this as Stage 1
- `/satori-why-before-what` — reduce an existing design to its one-sentence brief instead
- `/satori-lift-audit` — if you're auditing a finished layout, not originating one
