# /jenny-hook

5-10 ranked hook options (visual + verbal pairs) for a short-form video, with curiosity-gap and you-before-me verification.

## Trigger
`/jenny-hook`

## Workflow
`skills/jenny-hoyos-shorts/workflows/02-engineer-hook.md`

## Quick Use
Provide:
1. The video's core idea or existing draft/script (or the current hook, if fixing)
2. Niche + avatar (who scrolls past this, what they fear/want)
3. The payoff — what the video ultimately reveals
4. Showable assets + viewed-vs-swiped % if fixing an underperformer

## Output
Ranked hook table (5-10 rows: first frame, first line, gap, pattern), first-frame vs. first-line QA on the top 2, production notes, and a hook-vs-downstream verdict if fixing.

## Stacks With
→ `/jenny-script-short` (feed the winning hook into the full script)
→ `/jenny-retention` (routes here when viewed-vs-swiped falls below 70%)
→ `/jenny-visual-analogy` (staged-analogy hook pattern)
