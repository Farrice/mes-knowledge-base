# /oren-resource-audit

Run the **Resource-Reality Audit** — pre-qualify which archetypes a brand can actually execute.

## Instructions
1. Load `skills/oren-brand-archetypes/genius.md` — Patterns 1, 11, 3
2. Execute this standalone audit

## Context
This is the LIGHTWEIGHT version of the diagnostic. Use when you need the resource inventory without the full archetype selection process. Produces the eligibility matrix only.

## Process

### Step 1: Inventory Collection
Gather intel on these 4 dimensions. Accept whatever format the client provides (brief answers, detailed docs, discovery call notes):

| Resource Dimension | Questions | Notes |
|:---|:---|:---|
| **Camera Talent** | Who can be on camera? Expert/founder? Hired talent? Multiple staff? Nobody? | Rate: Strong / Available / Weak / None |
| **Design/Production** | Internal designer? Agency? Budget for freelance? iPhone-only capacity? | Rate: Strong / Available / Weak / None |
| **Showcasable Assets** | Physical product? Unique process? Interesting space? Deep knowledge? | List all assets |
| **Acquirable Resources** | What can you GET within 30-60 days? Hire? Outsource? Develop? | List realistic acquisitions |

### Step 2: Eligibility Matrix
Cross-reference resources against each archetype's minimum requirements:

| Archetype | Minimum Requirements | Risk Level | Status |
|:---|:---|:---|:---|
| **Oracle** | Camera talent (expert-grade) + showcasable knowledge | 1 (Safest) | ✅ Eligible / ⚠️ Conditional / ❌ Eliminated |
| **Helper** | Camera talent (relatable, non-expert OK) + practical value to offer | 2 (Low) | ✅ / ⚠️ / ❌ |
| **Catalyst** | Educational capacity + aspirational framing ability | 3 (Medium) | ✅ / ⚠️ / ❌ |
| **Performer** | Creative talent + visual product + risk tolerance | 4 (Higher) | ✅ / ⚠️ / ❌ |
| **World Builder** | Budget + creative director/team + high risk tolerance | 5 (Highest) | ✅ / ⚠️ / ❌ |

### Step 3: Conditional Pathways
For any "⚠️ Conditional" archetypes, specify:
- What resource gap exists
- Whether it's acquirable within 30-60 days
- What the fallback archetype would be

## Produces
Resource Inventory + Archetype Eligibility Matrix + Conditional Pathway Recommendations

## Stacking
- Feed results into → `/oren-archetype-diagnostic` (for full selection)
- Pair with consumer understanding → `/consumer-posture-profile`
- Route eligible archetypes to architect workflows
