# `/suzuki-scale` - Portfolio Scale Engine

## When To Use
- "Scale this to multiple accounts / a portfolio."
- Add a new account in a new niche.
- Plan how a brand-new account gets its first views.

## Load
1. `skills/alex-suzuki-digital-product-revenue-os/SKILL.md`

4. `skills/alex-suzuki-digital-product-revenue-os/references/compliance-gate.md`

## Execute
Run the Portfolio Scale Engine. Each account needs a proof source (own/partner/affiliate — route to `/suzuki-product-source` if missing), an offer, and a first-distribution plan. Keep accounts genuinely distinct; flag multi-account ToS risk.

## Usage
```text
/suzuki-scale [current accounts/niches] [proof sources] [goal]
```

## Required Output
- Account map (account, niche, proof source, offer, first-distribution)
- Distribution plan (boost/retweet per new account)
- Per-account economics targets (qualified comments × price, kill/keep)
- Saturation + compliance note
- Next account to launch
