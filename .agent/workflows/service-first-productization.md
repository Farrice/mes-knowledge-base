# /service-first-productization — Service-First Productization

Use this route when the fastest revenue path is a manual service that can later become a repeatable system.

## Route

1. Start with one sellable service promise and one delivery constraint.
2. Define the repeatable sprint, audit, or service package.
3. Create a proof loop that can become a reusable asset after the first delivery.

## Guardrails

- Service first, product second.
- Keep the first version deliverable by the current operator and workspace.
- Hand off to `/first-10k` for fast acquisition or `/revenue-offer-agent` for offer repair.
