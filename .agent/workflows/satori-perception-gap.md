# /satori-perception-gap

> Measure the delta between what you INTEND and what the audience actually UNDERSTANDS. Amateurs argue taste; professionals measure the perception gap. A design you have to explain has already failed part of its job.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/18-perception-gap.md
```

## Usage

```
/satori-perception-gap [layout description, file path, screenshot, or URL]
```

## When to Use

- A layout "looks fine" but you suspect people aren't getting the message in the order you meant
- Stakeholders keep asking "wait, what am I looking at?" — the design needs explaining to work
- A live asset underperforms and the leading hypothesis is *comprehension*, not offer or channel
- The CTA / key element exists on the page but nobody seems to act on it

## Output

A measured perception-gap diagnostic:
- The intended reading, declared in writing FIRST (first / second / missed-completely)
- The perceived reading, extracted via the sequence-recall test with weight scoring
- An intended-vs-perceived map with the named gaps
- Prioritized, element-level fixes to close each gap
- A recommended next workflow
