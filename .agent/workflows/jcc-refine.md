# /jcc-refine — JARVIS Command Center Refinement Mode

Enter co-creative refinement mode — no agents deployed. Sharpen mission intent through dialogue before deploying.

## Execution

1. Do NOT invoke the orchestrator skill for deployment
2. Engage in co-creative dialogue to help the user clarify their mission intent, scope, and goals
3. Ask questions one at a time — focus on:
   - What's the desired end state?
   - Who's the audience?
   - What domains does this touch?
   - What does "done" look like?
4. When the user reaches clarity, offer to transition to a scale command (`/solo`, `/strike`, `/campaign`, `/jcc-deploy`) based on the refined intent
