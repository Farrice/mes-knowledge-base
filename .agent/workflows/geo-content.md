# /geo-content — The Content OS (single front door)

One command so you never chain workflows by hand. It loads the OS + the buyer truth + the voice law every run, points at the evergreen **Content OS**, and produces edu-first, value-first content that builds audience, authority, and pipeline from zero. **The spine is adjudication** — you settle the category's live fights out loud from inside 18 yrs credentialed physiology; edutainment is the delivery, never the topic. The offer is **earned by the work**, surfaced softly (`--cta`, ~1-in-5), never on every post.

> **Always-loaded source of truth (read these every run):**
> - `_active/linkedin-launch/04-content-os/CONTENT-OS.md` — the master doc (the 3 functions, the signature template, the 8 blends, the edutainment/aha/psychology stack, the playbook, the cadence)
> - `_active/linkedin-launch/01-research/CONTENT-DOMINATION-RESEARCH.md` — the thesis + build spec (what's working, the gap, the blend map, the formula, the jacking protocol)
> - `_active/linkedin-launch/01-research/MARKET-ICP-DOSSIER-2026-06.md` — the buyer (avatars, fears, VoC, labeled facts)
> - `_active/farrice-brand/CLAUDE.md` + `_active/linkedin-launch/04-content-os/voice-gate.md` — the voice law (banned MOVES, pass/fail)
> - `_active/linkedin-launch/06-automation/daily/performance-log.md` — rotation (never repeat a hook format/close/pillar inside 7 days)
>
> **SUPERSEDES** the old offer-coupled `content-engine/CONTENT-ENGINE.md` + the always-on `DM "AUDIT"` bridge. Value-first is the default; the offer is a toggle.

## Usage / Modes

```
/geo-content                 # CREATE (default): rotate to today's pillar → prime the raw take →
                             #   cook the Physiology Misconception Correction → checklist + prose gate → ship.
                             #   NO CTA unless --cta.
/geo-content --map           # show today's pillar + the format-grid cell + recommended angle. No cook.
/geo-content --research      # RESEARCH only: run the 48-hr-lag beat scan → ride-able moments + the grid cell
                             #   for today's pillar. Labeled facts only. No cook.
/geo-content --create "X"    # skip selection; cook this angle/raw take now (alias --topic).
/geo-content --distribute    # DISTRIBUTE: take the latest post → pick the format → write the first-comment
                             #   receipt + the 30-60 min reply plan + the repurpose map (X/newsletter/IG/short-form).
/geo-content --jack          # NEWSJACK: Entity-Assessment gate → if pass, body-first Misconception-Correction
                             #   on the live moment, entity in first 2 lines, So-What to Round 3, >60% analysis.
/geo-content --cta           # opt-in toggle on any create mode: add ONE soft discussion-CTA (first comment),
                             #   ~1-in-5 only, never a pitch, NEVER on a --jack. Default across the OS = no CTA.
/geo-content --full          # whole sequence for a new vertical/reposition: research → create → distribute.
/geo-content --rebuild       # regenerate the OS itself (positioning shift / quarterly). See below.
```

**Cost ceiling:** $0.10/run. tavily/WebSearch primary; one Perplexity call max if free search is thin.

## THE STANDING RULE (every mode)
Edu-led, direct, adjudicating. **Entertainment is tone, not topic** — for this audience, entertainment-LED hooks underperform ~20%; the adjudication framing IS the entertainment. Never growth-hacker/influencer energy (the buyer winces). The PRIMARY blend is **Due-Diligence Teardown** (Thesis/Bull/Bear/Verdict/Receipt — buyer-native AND GEO-citable); gaming/anime/parenting are ~1-in-4 seasoning, fluent-or-absent (the Expertise Constraint: never bend a format you can't fill with world-class substance). Every post hands a tangible GET and resolves one of the buyer's 5 fears, said better than they could say it.

## THE SIGNATURE POST (the default cook)
**"The Physiology Misconception Correction"** — the one shape that is the edutainment engine, the aha engine, AND the AI-citation engine at once. 5-layer stack: **Stakes opener** (a real person did everything right, the floor moved) → **Big Question** (curiosity gap: predict, can't guess) → **Head-Fake accommodation surprise** (the corrected mechanism; "Oh!" not "Huh?"; surprise + relevance + safety) → **Face-Saving belief shift** ("I used to think X. Then I realized Y. Now I understand Z") → **Restraint-Cut close** (the GET, recognition close, stop). Two modes: evergreen (correct a held myth) + newsjack (correct a viral study/AI answer/brand claim in the 48-hr window). Full skeleton + 2 walk-throughs: `04-content-os/content-creation-system.md` §1.

## MODE: CREATE (default)
1. **Load context** (the source-of-truth files above).
2. **Rotation check** (`performance-log.md` + the cadence): pick today's pillar — signature #2/#4/#5 ~60%, volume #1/#3/#6 ~40% (overlay always on); never repeat a hook format/close/pillar inside 7 days; honor **Teardown Tuesday** (the Due-Diligence flagship slot). Pull the format-grid cell (`CONTENT-OS.md` PART 3 / `social-playbook.md` §3).
3. **Surface the recommendation:** today's pillar + 1-2 candidate angles from its live fights (`CONTENT-DOMINATION-RESEARCH.md` §2 question map). Optionally layer a fresh 48-hr-lag moment.
4. **Prime the raw take:** present the angle + the raw-take questions, **HALT for Farrice's voice note** (the soul of the cook). `--create "X"` skips the halt.
5. **Cook:** the signature template (or a blend per the grid). Run the edutainment + aha + psychology checklist (`CONTENT-OS.md` PART 2). Hooks char-counted to the ceilings, 0 em dashes in hooks.
6. **Gate (pass/fail; fail = regenerate, never patch):** the 6-item pre-publish checklist → `python3 execution/prose_classifier.py check <file>` → fact-verify (labeled-only; **no UNCONFIRMED stat ships** — never the 60.7%/58%/Medician figures) → the edu-first wince test.
7. **Bridge:** default = NO CTA. With `--cta` only: ONE soft discussion-CTA in a first comment (the rotating soft phrasings; never a pitch).
8. **Ship + log:** append to `performance-log.md`; print the 3-line to-do (publish + be present 30-60 min in-thread; the strategic-commenting list; drop yesterday's numbers next run). Remind: **Teardown Tuesday is non-negotiable.**
9. **Finalize (Chain Step 6):** `chain_runner.py finalize ... --workflow geo-content --type Content`.

## MODE: --research / --map / --distribute / --jack
Run the matching OS part: `--research` = PART 1 (the 48-hr-lag beat scan + the grid cell; labeled facts only; no cook). `--map` = the pillar + grid cell + recommended angle, stop. `--distribute` = PART 3 (format pick + first-comment receipt + the 30-60 min reply plan + the repurpose map). `--jack` = the newsjack engine (Entity-Assessment go/no-go gate → body-first Misconception-Correction, entity in first 2 lines, So-What to Round 3, >60% your analysis, speed > polish; **never a CTA on a jack**). Full specs: `social-playbook.md` §2.

## Error handling
- **No raw take (not --create "X"):** present `--map` and HALT. The engine is a co-pilot; without the raw take the cook caps at competent-but-flat.
- **Shell strips PATH (python3/gws "not found"):** the prose gate / finalize may fail in a degraded Bash invocation — re-run the Bash step (a fresh invocation usually has a healthy shell), or dispatch a `prose-doctor` subagent (no shell). Never skip the gate silently.
- **Hook/post fails the gate twice:** drop the angle, cook a different live fight (Rewrite Before Relabel).
- **Newsjack with no real triggering moment:** do not ship a `[VERIFY LIVE]` scaffold as fact — swap in a real, screenshotted moment or run evergreen mode instead.
