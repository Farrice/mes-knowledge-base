# /novelty-campaign

Scale one strong New Reveal into a coordinated multi-asset, multi-platform campaign without it feeling repetitive.

## Trigger
`/novelty-campaign`

## Workflow
`skills/kallaway-illusion-of-novelty/workflows/novelty-campaign.md`

## Quick Use
Provide:
1. The core reveal + outcome (the campaign spine)
2. Target platforms / assets
3. Sequence intent (seed → amplify → convert), optional

## Output
A campaign map (which component leads on each platform so it never reads copy-pasted) + per-asset briefs (angle expression, native contrast, trust-ladder rung, honest urgency, whisper delivery) + the launch sequence.

## Stacks With
→ `/platform-adapt`, `/atomize`, `/content-series`
→ `/novelty-angles` (multiple angles for breadth)
