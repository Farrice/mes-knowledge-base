# /haunt-social — Haunting Social Content

Deploy residue-first social content architecture. Inverts the standard hook-first model — design the haunting line FIRST, then build the post around it.

| Platform | Key Adaptation |

2. Work backward: what does the reader need before this line lands?
3. Open with perception, not hook
