# /deploy-council — Maximum-Breadth Council

The widest convening: 16 diverse cross-domain voices diverge, the 6 most complementary are
seated for deliberation. A **preset of the Collective Genius Council** (`/convene`) — use when
the problem is big enough that you want maximum perspective spread before synthesis.

> Named `/deploy-council` (not `/deploy`) to avoid colliding with the installed
> `jarvis-command-center` plugin's `/deploy` (JCC Full Deploy). Same engine as `/convene`,
> just `mode: deploy`.

## Execution
Invoke the **Workflow tool** with:
- `scriptPath`: `.agent/workflows/collective-genius-council.workflow.js`
- `args`: `{ "task": "<the user's mission>", "mode": "deploy" }`

Returns: the deliberated synthesis (net-new principle + forks for you + next moves) and a
"How the Masters Thought" learning digest → `knowledge/council-sessions/`. Holds the grounding
floor; $0 incremental.

For focused/fast instead of wide, use `/strike`. For the default wide pass, use `/convene`.
