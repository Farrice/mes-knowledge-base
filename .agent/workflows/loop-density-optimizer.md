# /loop-density-optimizer

Final-pass optimizer that compresses time-per-hand and eliminates dead air in already-looped content.

## Trigger
`/loop-density-optimizer`

## Workflow
`skills/kallaway-addictive-storytelling/workflows/loop-density-optimizer.md`

## Quick Use
Provide:
1. Loop-architected content (must already have loop structure)
2. Content format
3. Current diagnostic (optional, from `/addiction-loop-diagnostic`)
4. Density target (Standard / High / Maximum)

## Output
Density-Optimized Content — before/after density audit, optimization log, full optimized content, comparison table, over-density notes.

## Stacks With
→ `/addiction-loop-diagnostic` (audit first to get baseline)
→ `/loop-chain-scripting` or `/flat-to-addictive-rewrite` (build loops first, then optimize)
