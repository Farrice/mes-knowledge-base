# /haynes-handshake-geoff-stakeholder

Read and execute the workflow at `skills/jeremy-haynes-cold-offer/workflows/haynes-handshake-geoff-stakeholder.md` — Haynes' composed offer stack + objection inventory becomes Woods' simulated stakeholder panel's input; the panel returns a per-element kill/revise/ship Verdict Sheet with the strongest simulated objections preserved verbatim.

Load before execution:
- `skills/jeremy-haynes-cold-offer/SKILL.md` + `skills/jeremy-haynes-cold-offer/genius.md`
- `skills/geoff-woods-ai-thought-partner/SKILL.md` + `skills/geoff-woods-ai-thought-partner/genius.md` + `skills/geoff-woods-ai-thought-partner/references/CO-CREATION-CARD.md`

## Usage
```
/haynes-handshake-geoff-stakeholder [composed offer stack + known/likely stakeholders]
```

## When to use
- A Haynes offer stack is composed and about to face a real prospect for the first time
- Money, reputation, or a limited-capacity pilot slot is riding on first contact going well
- An existing offer keeps landing flat and the objection inventory may be incomplete
- Before a cold-DM or outreach sequence goes wide on a new or revised offer

## Stacking
- Haynes supplies: the composed offer stack (core + editions, narrative tags) + objection inventory
- Woods supplies: interview-inversion-profiled stakeholder panel (mandatory self-selection stakeholder included) reading the actual offer under the cognitive-sovereignty guard
- Handoff artifact: the Verdict Sheet — per-element kill/revise/ship, verbatim objections, dissent log, self-selection finding
- Guardrail: dissent between stakeholders is never averaged into a blended verdict
