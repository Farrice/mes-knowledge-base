# `/suzuki-product-funnel` - Product Funnel Builder

## When To Use
- Build the funnel after a sales post.
- Turn an ebook/course/template into a checkout or conversation path.
- Write DM, checkout, and email copy for a digital product.

## Load
1. `skills/alex-suzuki-digital-product-revenue-os/SKILL.md`
2. `skills/alex-suzuki-digital-product-revenue-os/workflows/03-product-funnel-builder.md`
3. `skills/alex-suzuki-digital-product-revenue-os/references/funnel-map.md`
4. `skills/alex-suzuki-digital-product-revenue-os/references/revenue-mechanics.md`

## Execute
Run the Product Funnel Builder. The free asset must create decision motion and the paid path must match price, risk, and buyer readiness.

## Usage
```text
/suzuki-product-funnel [product] [buyer] [price] [proof] [traffic source]
```

## Required Output
- Path decision
- Offer spec
- Free asset bridge
- Buyer readiness and routing
- DM scripts
- Checkout/application copy
- First-use path
- Email follow-up
- Replay hooks
- Proof gate
