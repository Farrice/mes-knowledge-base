# /word-tone

Precision tone calibration for any content piece using Kallaway's 5-register system.

## Execution

1. **Read skill files:**
   - `skills/kallaway-word-mastery/genius.md` — Focus on Tone Calibration System
   - `skills/kallaway-word-mastery/workflows/tone-calibration-engine.md`

2. **Gather inputs:**
   - The content to rewrite
   - Target tone (casual / professional / entertaining / comedic / authoritative / blend)
   - Publishing context (platform, audience)

3. **Execute the Tone Calibration Engine** end-to-end

4. **Deliver:**
   - Fully rewritten content in the target tone
   - Tone scorecard (before/after register metrics)
   - Annotation layer with key word-level choices explained
   - Code-switch map showing register shifts

## Stacks With

- `/word-rhythm` → `/word-tone` (rhythm first, then tone)
- `/word-sprint` (includes tone calibration as Pass 2)
