# /jenny-ai-brain

A buildable AI ideation brain — a full-pipeline SOP loaded into a custom GPT/Claude Project that runs as a team member for hook generation, variant expansion, and beat-list critique.

## Trigger
`/jenny-ai-brain`

## Workflow
`skills/jenny-hoyos-shorts/workflows/13-ai-ideation-brain.md`

## Quick Use
Provide:
1. The creator/brand (voice, niche, lens)
2. Existing SOP material (or "none, build from scratch")
3. Avatar + mission (the single named viewer, the channel's throughline)
4. Reference channels + target platform (custom GPT / Claude Project)

## Output
Pipeline SOP outline (ideation/scripting/filming/editing), context-layer spec, output constraints (question-form-hook rule), operating modes (10-variants, hook-ranking, beat-critique, visual brainstorm), and the human gate.
