# /satori-why-before-what

> Audit every element on a layout against the rent test: each element must serve concept, hierarchy, or psychology. Otherwise, it gets evicted.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/04-why-before-what.md
```

## Usage

```
/satori-why-before-what [layout description, file path, screenshot, or URL]
```

## When to Use

- A layout feels cluttered but you can't articulate why
- A draft is ready and you want a pre-delivery decision audit
- You inherited / are reworking someone else's design
- A brief is unclear and you need to derive design intent from elements

## Output

Element-level audit:
- One-sentence brief documented + visual primitive identified
- Complete element inventory with rent test verdict per element
- Eviction list with specific elements and reasons
- Strengthening list (weak reasons rewritten as strong)
- Multi-job audit
- Executable action list
