# /satori-predictive-empathy

> Most designs are loud because the designer assumed the viewer was already convinced. They aren't. Rewrite the design for the *next* emotion the viewer will carry.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/07-predictive-empathy.md
```

## Usage

```
/satori-predictive-empathy [layout description / draft / live design]
```

## When to Use

- A draft design feels loud / aggressive / shouty
- The brief assumes audience is pre-aligned (it usually isn't)
- A live ad / campaign isn't converting and the diagnosis is "it's not landing emotionally"
- Working in a category that defaults to alarmist tone (insurance, security, health)

## Output

Empathy pass spec:
- Audience state map (pre-state / awareness / trust / time)
- Wrong-assumption diagnosis
- Desired next-emotion locked (one, not 2+)
- Empathy shifts applied (tone + visual + trust cue + palette + pacing)
- Three-state validation (cold / skeptical / considering)
- Executable directives at element level
