# /jenny-idea-ladder

A ranked shortlist of short-form ideas — outlier-sourced by growth stage, filtered through avatar + lens fit, stamped with the signature twist, each stated as a curiosity-gap question.

## Trigger
`/jenny-idea-ladder`

## Workflow
`skills/jenny-hoyos-shorts/workflows/04-viral-idea-ladder.md`

## Quick Use
Provide:
1. Channel stage (subscriber count / typical views per post)
2. Niche as a lens (not a topic) + avatar
3. Signature twist (the creator's unmistakable fingerprint)
4. Content type (entertainment/educational/branded/personal-brand)

## Output
Outlier sources by ladder rung, idea longlist (~100 candidates, real count reported), ranked shortlist with lens/avatar fit, and the single pick that won the 100→1 gate.

## Stacks With
→ `/jenny-script-short` (script the winning pick)
→ `/jenny-lens-niche` (locks the lens/avatar this ladder filters through)
→ `/jenny-anything-viral` (applies the same sourcing logic to a product/brand/offer)
