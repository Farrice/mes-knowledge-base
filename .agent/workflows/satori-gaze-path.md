# /satori-gaze-path

> "The goal isn't to create movement. It's actually to create a path of importance." Hierarchy decides what's seen first; direction decides where the eye goes next. Gaze lines, angled shapes, light/shadow — arrow-free flow, the Dazed-cover way.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Load: skills/satori-graphics/references/layout-flow-hierarchy.md
Execute: skills/satori-graphics/workflows/24-gaze-path.md
```

## Usage

```
/satori-gaze-path [layout + committed spine + available imagery]
```

## When to Use

- A spine is committed and the layout has faces, figures, product angles, or strong shapes that can point
- Viewers read the layout "out of order" despite correct anchors
- Selecting photography BY pointing direction (the shot that points where the journey goes)
- Premium/editorial surfaces where literal arrows look amateur

## Output

A Gaze-Path Spec: per-leg wiring (`LEG → CARRIER → SPECIFIC MOVE`), hijack list (cues quieted/evicted), refused salience defaults (the Dazed move: quiet the element the path already delivers), photography direction requirements, and a thumbnail-trace verdict.
