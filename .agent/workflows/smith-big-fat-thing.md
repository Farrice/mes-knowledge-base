# /smith-big-fat-thing

Run the Big Fat Obvious Thing Test — Smith's signature interrogation. Compresses differentiation into a single sentence that survives the Competitor-Mirror Test and the Sentence Test, OR produces an honest "no answer yet" diagnostic with a smallest 30-day commitment.

## Instructions

1. **Load** `skills/alex-m-smith-natural-strategy/genius.md` (full genius context)
2. **Execute** `skills/alex-m-smith-natural-strategy/workflows/04-big-fat-thing.md` (full workflow)

The skill carries:
- Principle 1 (Different Actions → Different Results)
- The Big Fat Obvious Thing Test (signature move)
- The Competitor-Mirror Test ("would competitors agree they offer this?")
- The Sentence Test (≤ 25 words, no qualifiers)
- The Trade Test (no sacrifice attached = no real positioning)
- Three outcomes: A (answer survives), B (latent differentiator surfaced), C (no answer yet, smallest commitment produced)

## When to Deploy

- Strategy review where positioning feels weak
- Hiring strategically-minded people (test their differentiation thinking)
- Board prep / investor pitch crafting
- Pre-launch positioning lock
- Founder self-audit ("do I actually have a differentiator?")

## What This Workflow Refuses to Produce

- Output sentences containing generic claims (culture, customer-obsession, execution, "better")
- Competitor-Mirror Test verdicts that hand-wave instead of evaluating each named competitor
- Trade Tests that are missing or vague (every real positioning has a trade)
- Outcome C without a 30-day smallest commitment
- Defense sections written in corporate-speak instead of the user's voice
- Output sentences > 25 words

## Stacks With

- If Outcome A (real answer) → `/smith-supply-side-audit` (confirm differentiation creates scarcity)
- If Outcome B (latent surfaced) → `/smith-natural-strategist-audit` (test across all 4 principles)
- If Outcome C (no answer yet) → `/smith-sacred-truth-inventory` (find the sacrifice that creates a future answer)
- After any outcome → Oren Klaff `/oren-pitch-architecture` (frame the sentence for sales/fundraising)
