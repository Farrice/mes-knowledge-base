# /big-question-calibrator

Calibrate the Big Question to the specificity sweet spot for maximum sustained dopamine drip.

## Trigger
`/big-question-calibrator`

## Workflow
`skills/kallaway-addictive-storytelling/workflows/big-question-calibrator.md`

## Quick Use
Provide:
1. Stakes setup (what precedes this question)
2. The answer (what will be revealed as the head fake)
3. Target audience (expertise level affects calibration)
4. Content format

## Output
Calibrated Big Question Set — question landscape, specificity scorecard with Goldilocks scoring, selected question in 3 phrasing variants, drip duration plan, pre-head-fake validation.

## Stacks With
→ `/stakes-engineer` (design the stakes that precede the question)
→ `/head-fake-forge` (design the reveal that follows the question)
