# /smith-value-creation-audit

Run the Value Creation Audit — Smith's anti-JTBD intervention. Diagnoses whether the business is stuck in hotel-manager-fixing-rough-edges mindset or operating with the Disney/Lego/Rafa "create something that didn't exist before" disposition.

## Instructions

1. **Load** `skills/alex-m-smith-natural-strategy/genius.md` (full genius context)
2. **Execute** `skills/alex-m-smith-natural-strategy/workflows/05-value-creation-audit.md` (full workflow)

The skill carries:
- Principle 2 (Businesses Create Value, Not Solve Problems)
- Anti-Retrofit Discipline (refuse to retrofit JTBD onto value-creating businesses)
- The Disney World Anti-JTBD Refusal (Hall of Fame Exemplar)
- 6-test mode diagnostic (Disappearance, Want vs. Need, Pre-Existence, How Big Allowed to Think, JTBD Retrofit, Walt Disney Pitch)
- Three diagnoses: A (genuine value creator), B (stuck value creator — produces reframe), C (genuine problem-solver — also valid)

## When to Deploy

- Product strategy where JTBD is being force-applied
- Category creation work
- Ambitious vision check ("are we thinking big enough?")
- Brand pivot consideration
- Founder feels "we're not telling our story right"

## What This Workflow Refuses to Produce

- Value-creation framing fabricated for genuine problem-solver businesses (most common failure mode)
- JTBD retrofits onto genuine value-creator businesses (opposite failure)
- Reframes that use any JTBD vocabulary
- Skipped Disney Test
- Recommendations of "do positioning work" without specifying which next workflow and why

## Stacks With

- If Diagnosis A (genuine value creator) → `/smith-natural-strategist-audit` (test across all 4 principles)
- If Diagnosis B (stuck value creator + reframe produced) → `/smith-big-fat-thing` (compress reframe into defensible sentence)
- If Diagnosis C (genuine problem-solver) → `/smith-supply-side-audit` (defend against commoditization)
- After any diagnosis → Grace `/grace-city-blueprint` (build brand identity around correct mode)
