# /satori-concept

> The generative flagship. Given a brief, generate 3 distinct concept directions using 7 named creative techniques — each direction built on a hidden truth (the "one big idea") and pressure-tested for the ONE specific audience it is for. Produces concepts, not critique.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/16-concept.md
```

## Usage

```
/satori-concept [comms brief or raw brief + named audience]
```

## When to Use

- A brief is in hand and you need concept *directions* before any layout, moodboard, or generation
- A design came back generic ("looks fine, says nothing") and needs a real idea underneath it
- You have facts and features but no angle — staring at the product, not the truth behind it
- A stakeholder needs to choose between distinct thinking directions, not aesthetic variations of one

## Output

Three anchored concept directions:
- The excavated hidden truth (real problem / consequence / emotional impact / the unspoken thing)
- 3 directions, each generated via a named technique from the 7-technique palette
- The one specific audience each is built for, with a fit justification
- A one-sentence central idea per direction (fails the test = not one idea)
- A recommended lead direction to carry into composition
