# /satori-contrast-stack

> Contrast is the strongest anti-generic mechanism in design. AI-default layouts distribute emphasis evenly — this stacks 3+ deliberate, ZONAL contrast forms (from 9 forms × 3 tiers) so the right things win. On interfaces, contrast is choice architecture.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Load: skills/satori-graphics/references/contrast-stack.md
Execute: skills/satori-graphics/workflows/22-contrast-stack.md
```

## Usage

```
/satori-contrast-stack [design/brief + committed anchors + audience]
```

## When to Use

- A three-flow spine exists and the anchors need to WIN their beats
- Briefing a generation tool and you want non-generic output with teeth
- A design is "clean but flat" — everything tidy in the same way (the AI-default tell)
- CTA/conversion surfaces where contrast steers behavior

## Output

A Contrast Stack Spec: 3–5 forms each mapped `FORM → ZONE → WHAT IT MAKES WIN`, one advanced-tier flip (or logged absence-by-decision), double-whammy zone(s), a restraint log (what you deliberately did NOT use), the audience-gate verdict, and executable per-zone directives.
