# /perception-lab — Language Laboratory

Deploy Pattern 7 from Ocean Vuong's extraction: Poetry as R&D Lab. This is a dedicated creative space for language experimentation — no assignment, no brief, no audience. The goal is to discover new syntactic moves, test behavioral displacements, and build a repertoire of perceptual tools that deploy in production work later.

## The Chain

1. **SCORE**: Intent Score 4 (R&D, not production)
2. **ROUTE**: Ocean Vuong (perceptual writing)
3. **LOAD**: Tier 2 — `skills/ocean-vuong-perceptual-writing/SKILL.md` + `genius.md` + Pattern 7
4. **PRODUCE**: Execute experiments below
5. **FINALIZE**: chain_runner.py (log the session for future reference)

## Execution

### Phase 1: Choose the Experiment

Select one (or design your own):

| Experiment | What You're Testing |
|-----------|-------------------|
| **Displacement Sprint** | Take one subject. Write 10 sentences about it, each using a different displacement domain. Test which domains create the deepest behavioral correspondence. |
| **Threshold Discovery** | Pick a transformation you've witnessed. Write 500 words ONLY about the threshold — the unnamed moment between the two named states. No context. No setup. Pure threshold. |
| **Syntax Surgery** | Take one sentence you've already written. Rewrite it 15 different ways — different clause structures, different rhythms, different word orders. Find the arrangement your consciousness naturally gravitates toward. That's your thumbprint. |
| **Etymology Dig** | Pick one word. Trace it through 4+ languages and 500+ years. Write one sentence that uses the word at EACH historical depth. |
| **First-Perception Writing** | Look at an everyday object for 5 minutes. Write about it without using any word that has been previously used to describe that class of object. No "warm" for fire, no "cold" for ice. Describe ONLY what you perceive, not what you know. |
| **Cliché Autopsy** | Take the most overdone sentence in your niche ("hustle harder," "be authentic," "provide value"). Perform a full autopsy: why is it dead? What was its original perception before it became a cliché? Can you recover the original perception? |

### Phase 2: Run the Experiment

Write freely. No word count requirement, no quality gate, no audience consideration. This is the lab.

**Lab rules**:
- No self-editing during the experiment
- No audience consideration — this is not for publication
- No "is this good?" — only "is this interesting?"
- Follow surprises — if the language goes somewhere unexpected, let it go there
- Record what works AND what fails — the failures are data

### Phase 3: Extract the Discovery

After the experiment, identify:
1. **What syntactic move did you discover?** (A clause structure, rhythm, or arrangement you haven't used before)
2. **What displacement domain surprised you?** (A cross-domain connection you didn't expect)
3. **What perception appeared?** (A way of seeing the subject that arrived through the writing, not before it)
4. **What would you deploy?** (Which discovery is ready for production content?)

### Phase 4: Lab Notes

Write brief lab notes for future reference:

```
EXPERIMENT: [type]
DATE: [date]
SUBJECT: [what you explored]
DISCOVERY: [1-2 sentences on what you found]
DEPLOY-READY: [yes/no — and if yes, which production workflow would use it]
FAILED ATTEMPTS: [what didn't work and why]
```

## Output

1. The experiment type and subject
2. The raw lab output (the actual writing)
3. Discoveries extracted (Phase 3)
4. Lab notes (Phase 4)
5. Deployment recommendation — which production workflow would benefit from this discovery?

## When to Use

- Writer's block → run a Perception Lab to un-stick
- Before a major creative project → warm up with 2-3 experiments
- When your writing feels stale → the lab reveals new moves
- Weekly R&D practice → build a discovery log that compounds over time
