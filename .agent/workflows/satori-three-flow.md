# /satori-three-flow

> Every layout is ONE primary journey with THREE committed anchors. Commit them in writing before the canvas opens; verify them at thumbnail size before anything ships. LIFT audits hierarchy after the fact — three-flow ORIGINATES it.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/21-three-flow.md
```

## Usage

```
/satori-three-flow [surface + communication problem + available elements]
```

## When to Use

- Starting any layout from scratch — poster, landing hero, carousel frame, listing frame, slide
- A draft "has everything on it" but no one can say where the eye should go
- Prepping a generation-tool brief that would otherwise produce evenly-weighted AI-default composition
- The essential info (CTA, date, price) keeps getting missed

## Output

A Three-Flow Spine Spec: the essential-info line (finisher committed FIRST), the spine `HOOK → SECONDARY → FINISHER` with element/position/size level, the traced flow line, rent-test verdicts on path hijackers, and the thumbnail-test verdict with ordered fixes (contrast → spacing → alignment).
