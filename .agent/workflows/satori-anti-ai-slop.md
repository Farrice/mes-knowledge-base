# /satori-anti-ai-slop

> AI layouts in 2026 are too perfect — symmetrical, evenly spaced, polished. Inject 3+ deliberate human-imperfections into any AI-generated or AI-assisted layout heading toward delivery.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/09-anti-ai-slop.md
```

## Usage

```
/satori-anti-ai-slop [AI-generated layout / template-feeling design]
```

## When to Use

- Layout was AI-generated (Midjourney, DALL-E, Nano Banana, Skywork, Canva AI)
- Layout was human-made but feels template / generic
- Final layout heading to delivery and needs the human-quality differentiator
- Brief explicitly demands a human, hand-crafted feel

## Output

Anti-slop spec:
- AI tell diagnosis (with severity counts)
- Imperfection quota locked (3+ minimum)
- Each imperfection with type / implementation / rent reason / location
- Distribution audit (leverage / secondary / texture)
- Stress test (legibility / LIFT / empathy / alive vs chaotic)
- Executable directives at element level
