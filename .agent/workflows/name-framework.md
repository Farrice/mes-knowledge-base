# `/name-framework` — Framework Naming Sprint

Apply David Placek's $75K-$200K naming methodology — condensed for solopreneurs, creators, and consultants — to name a proprietary framework, method, content series, newsletter, course, or coaching program. Uses sound symbolism scoring, the Surprisingly Familiar test, and proof-of-concept contextualization.

## When to Use
- You've built a method or framework and it needs a name
- You're launching a content series, newsletter, or course and need a title
- Your current method name is generic ("My 5-Step Process") and needs an upgrade
- You want a name that's ownable, memorable, and linguistically optimized
- Stack with Luke Iha mechanism naming for named mechanisms in copy

### 2. Gather Input
Ask the user:

- What transformation does it produce?
- Target audience
- Competitor methodology names
- Desired feeling (power, clarity, speed, trust, elegance)

### 3. Execute
Follow the `name-your-framework` prompt — all 6 steps:
1. Discovery
2. Category escape (competitive naming landscape)
3. Treasure hunting — 3 tracks (functional, metaphorical, sonic-first) — 21-30 candidates
4. Evaluation (7-criterion scorecard)
5. Proof-of-concept (LinkedIn post, sales page headline, casual recommendation)
6. Deliverable (top 3 with rationale, positioning line, variants)

### 4. Quality Gate
- [ ] 21+ raw candidates generated across 3 tracks
- [ ] Top 7 scored on all 7 criteria
- [ ] Top 3 presented in 3 real-world contexts (not on a list)
- [ ] Sound symbolism analysis included
- [ ] Positioning line crafted for each finalist
- [ ] Name works as a noun ("I used the [Name]")
