# Dr. K × McRaney — Belief Dissolution Engine

Combine Dr. K's samskara architecture with David McRaney's belief change science to dissolve hardened beliefs by first diagnosing whether they're trauma-encoded (samskara) or epistemically held.

## Why This Stack Works

McRaney knows HOW beliefs change. Dr. K knows WHY some beliefs won't change — because they're not beliefs at all, they're samskaras (trauma-encoded impressions). Different root = different treatment. This stack prevents wasting persuasion techniques on trauma-driven conviction.

## Steps

1. **Load Dr. K**: `skills/dr-k-consciousness/genius.md`
2. **Load McRaney**: `skills/david-mcraney-belief-change/genius.md`
3. **Phase 1 — BELIEF EXCAVATION (McRaney)**:
   - Identify the target belief
   - Classify by type: fact / attitude / value / identity-fused
   - Map trust landscape and emotional root
4. **Phase 2 — SAMSKARA SCAN (Dr. K)**:
   - Is this belief connected to a samskara (past impression)?
   - Run groove-detection: does the belief have physical/somatic markers?
   - Test: Can the person observe the belief from distance, or are they fused?
5. **Phase 3 — DIFFERENTIAL DIAGNOSIS**:
   - **If epistemically held** → McRaney track: Motivational Interviewing, anxiety dissolution, environment optimization
   - **If samskara-encoded** → Dr. K track: sitting-with protocol, groove dissolution, identity-process reframe
   - **If both** → Dual-track: Dr. K dissolves emotional charge FIRST, then McRaney provides rational pathway
6. **Phase 4 — DISSOLUTION EXECUTION**:
   - Design sequenced intervention matching the diagnosis
   - Set realistic timeline (samskara work takes longer)
   - Build safety nets for identity-threatening belief changes
7. Output: Belief Dissolution Blueprint with diagnosis, track assignment, and sequenced protocol
8. Run quality gate against both rubrics
