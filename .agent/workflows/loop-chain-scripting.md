# /loop-chain-scripting

Chain all Addiction Loop components into a complete, polished, production-ready script.

## Trigger
`/loop-chain-scripting`

## Workflow
`skills/kallaway-addictive-storytelling/workflows/loop-chain-scripting.md`

## Quick Use
Provide:
1. Topic or story
2. Target audience
3. Format + target length
4. Core insights (2-4 must-have takeaways)
5. Transformation goal
6. Prior workflow outputs (optional — from Tier 1/2 workflows)

## Output
Full Addiction-Looped Script — master blueprint, complete polished script, cycle annotations, narrative arc map, validation report, delivery notes.

## Stacks With
→ `/addiction-loop-architect` (build the blueprint first, feed to this workflow)
→ `/loop-density-optimizer` (compress the script after writing)
→ `/obsession-script-architect` (inject obsession payload into the looped script)
