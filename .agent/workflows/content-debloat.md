# /content-debloat — Content De-Bloat Pass

Take a content idea or draft that's trying to do every job at once (hook + value + origin + personality + CTA) and strip it to its single true funnel layer and single job — reassigning the extracted jobs to their own future pieces. The "shoulders drop" pass.

## Usage

```
/content-debloat [paste the content idea/draft, or describe what it's trying to do] [+ optional: the creator's offer]
```

## Steps

### 1. Load Skill Context
// turbo
Read these files in order:
1. `skills/tom-noske-content-creation/genius.md` (focus: **Module B**, GP-11)
2. `skills/tom-noske-content-creation/workflows/07-content-debloat-pass.md`

### 2. Execute the Workflow
Follow the workflow file exactly:
- Phase 1: Job inventory (count the jobs; 3+ = bloated)
- Phase 2: Identify the TRUE layer (one job, one metric)
- Phase 3: Strip and reassign (extracted jobs → their own pieces)
- Phase 4: Rebuild the de-bloated piece (just teach / just sell / just tell)
- Phase 5: Shoulder-drop confirmation (is it lighter to make?)

### 3. Run Quality Gate
Validate against the workflow's quality gate. Target anti-pattern: **The Everything Piece** — confirm fully resolved.

### 4. Offer Stacking
After delivery, recommend:
- `/content-funnel` if multiple pieces are chronically bloated (the funnel fixes the root cause)
- `/promise-payoff` to structure the de-bloated piece's single promise
