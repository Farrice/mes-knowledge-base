# /satori-memory-encoding

> Designs become memorable when they require resolution. Engineer a memory hook into any design — logo, key visual, hero, listing thumbnail, ad, social tile.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/08-memory-encoding.md
```

## Usage

```
/satori-memory-encoding [layout / brief description]
```

## When to Use

- A design feels "too clean / too safe / too unoriginal"
- Brief explicitly demands memorability (logo, key visual, brand identity)
- A draft is technically correct but emotionally forgettable
- Designing for an attention-saturated context (social feeds, busy ads)

## Output

Memory hook spec:
- Current memorability audit (resolve-something present? 24-hour recall test?)
- Chosen move (one of 4): Metaphor Substitution / Absence as Presence / Conceptual Swap / Controlled Imbalance
- Validation against foundation (brief + primitive + empathy)
- Pause-time calibration (1-3 sec target)
- Stickiness audit (24-hour recall + element specificity + metaphor portability)
- Executable directives
