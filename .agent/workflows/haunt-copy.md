# /haunt-copy — Haunted Copy Engine

Deploy Vuong's haunting principle to commercial writing — sales pages, VSLs, email sequences, brand manifestos, long-form ads. Copy that creates recursive thought loops instead of urgency pressure.

## The Chain

1. **SCORE**: Intent Score 5
2. **ROUTE**: Ocean Vuong (perceptual writing) + Luke Iha (proof) or Cardinal Mason (persuasion)
3. **LOAD**: Tier 2 — `skills/ocean-vuong-perceptual-writing/SKILL.md` + `genius.md` + `workflows/haunted-copy.md`. Load stacking skill at Tier 1.
4. **PRODUCE**: Execute `workflows/haunted-copy.md` — all 6 phases
5. **FINALIZE**: Quality gate per haunted-copy.md + chain_runner.py

## When to Use

- Sales pages where you want the prospect thinking about your copy at 3am
- Email sequences where each email leaves residue that compounds
- Brand manifestos that become the reader's internal language
- VSL scripts where ONE line does the work of twelve testimonials
- Any copy competing against commodity offers — haunting IS the differentiation

## Quick Deploy

1. Read the existing copy
2. Identify ONE line with haunting potential
3. Apply problem estrangement (Phase 2 of haunted-copy.md)
4. Run the 3AM Test
5. Ship
