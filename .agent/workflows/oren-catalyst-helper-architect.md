## The Critical Split (Pattern 8)
- **Catalyst** = ASPIRATIONAL — shared because it makes people feel like they're becoming better
- **Helper** = PRACTICAL — shared because it solves a specific problem

Ask: "Is our customer sharing this because it makes them FEEL better? Or because it SOLVES a problem?"

| Signal | Catalyst | Helper |
|:---|:---|:---|
| Sharing motivation | Identity signaling | Practical utility |
| Engagement type | Saves + shares | Comments + DMs |
| Creator requirement | Multiple staff OK | Relatable host |

## Catalyst Architecture
- Content: Training docs, inspirational content, challenges, community curation
- Funnel: Aspiration → community belonging → brand as enabler → purchase
- End state: Audience PRODUCES the brand's content (Artifaxing model)

## Helper Architecture
- Content: Visual tutorials, carousel tips, story vlogs, comparisons
- Funnel: Practical value → ambient recognition → paid ad lift → purchase
- Organic-to-Paid Bridge (Pattern 10): Measure ROI by paid ad CPA reduction, not organic metrics
