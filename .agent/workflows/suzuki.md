# `/suzuki` - Cold-Start Revenue Engine

## When To Use
- "I want to sell a digital product — build me the whole system."
- "I have no product / no proof / no following — start me from zero."
- Any end-to-end request for the full Suzuki revenue OS in one pass.

## Execute
Run the Cold-Start Revenue Engine. If there is no product or proof, route through `/suzuki-product-source` (Build/Partner/Affiliate) first, then sequence post engine → platform funnel → automation → distribution → launch → scale. Must work from a true cold start. Deliver finished assets, a compliance ledger, a 7-day plan, and one action today — not a framework.

## Usage
```text
/suzuki [product or "none"] [buyer] [price target] [proof or "none"] [platform(s)] [goal]
```

## Required Output
- Intent lock
- Offer (or sourcing path: build / partner / affiliate)
- Offer ladder + funnel choice
- Sales post (finished, anatomy-mapped)
- Platform funnel(s) (finished native assets)
- Automation plan (create / schedule / opt-in auto-DM)
- Distribution plan (first views)
- Launch mode (evergreen or flash)
- Scale plan (add accounts)
- Mirrorboard outline (if high-ticket)
- Compliance ledger (claims, disclosures, platform risk)
- 7-day plan + one action today
