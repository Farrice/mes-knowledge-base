# /jenny-anything-viral

A viral treatment for any product, brand, offer, or boring topic — hook, VIRAL skeleton, loop lever, and brand-fit note.

## Trigger
`/jenny-anything-viral`

## Workflow
`skills/jenny-hoyos-shorts/workflows/11-anything-viral-brief.md`

## Quick Use
Provide:
1. The thing (product/brand/offer/topic, however boring or narrow)
2. The brand's actual goal (awareness, trial, a specific action, subscribers)
3. Audience + signature lens available
4. Platform target + producible visuals

## Output
Universal angle, hook (question + statement-under stakes stack), visual, signature twist, VIRAL skeleton, loop lever, and a brand-fit note (audience+brand-over-creator verdict).

→ `/dara-static-engine` (adapt the treatment into a paid static ad for cold traffic)
→ `/hook-forge` (5-10 ranked hook variants of the frame-one + first-line, stress-tested)
