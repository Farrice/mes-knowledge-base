# Dr. K — Full Diagnostic

Run ALL three Tier 1 foundation workflows in sequence for a complete consciousness state assessment.

## Why This Exists

Individual diagnostics (identity, guna, samskara) each tell one part of the story. The Full Diagnostic runs all three and cross-references the findings to produce a unified consciousness map with prioritized intervention pathways.

## Steps

1. **Load Dr. K**: `skills/dr-k-consciousness/genius.md`
2. **Phase 1 — IDENTITY ARCHITECTURE AUDIT**:
   - Load: `skills/dr-k-consciousness/workflows/identity-architecture-audit.md`
   - Map all active identities with guna classification
   - Identify fused, vestigial, and aspirational identities
   - Note protective functions
3. **Phase 2 — THREE GUNAS DIAGNOSTIC**:
   - Load: `skills/dr-k-consciousness/workflows/three-gunas-diagnostic.md`
   - Assess current guna dominance (tamas/rajas/sattva)
   - Map state-shift triggers
   - Note how guna patterns connect to identity findings
4. **Phase 3 — SAMSKARA MAPPING**:
   - Load: `skills/dr-k-consciousness/workflows/samskara-mapping-protocol.md`
   - Surface automatic behavioral patterns
   - Trace roots to original impressions
   - Cross-reference with identity scars and guna patterns
5. **Phase 4 — UNIFIED MAP**:
   - How are the samskaras reinforcing the limiting identities?
   - What guna state perpetuates the pattern cycle?
   - Where is the highest-leverage intervention point?
   - Design the priority sequence: which to address first?
6. **Phase 5 — PATHWAY DESIGN**:
   - Recommend which Tier 2 workflow to run next
   - Build a 30-day consciousness cultivation plan
   - Set daily practice minimum
7. Output: Complete Consciousness Map with unified diagnosis + 30-day pathway
8. Run quality gate against genius.md rubric
