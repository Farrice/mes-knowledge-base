# /sam-parr-copywriting-mechanics - Sam Parr Copywriting Companion OS

## Purpose

Upgrade weak copy with the project-local Sam Parr Copywriting Companion OS extracted from the Sweat Equity source. This command is a direct-response mechanics front door. It does not replace `/copywriting-agent`, `/high-taste-writing-os`, or `/publishable-copy-gate`.

## Source Authority

Read only the files needed for the current pass:

1. `skills/sam-parr-copywriting-mechanics/SKILL.md`
2. `skills/sam-parr-copywriting-mechanics/genius.md`
3. `skills/sam-parr-copywriting-mechanics/references/genius-patterns.md` — for pattern-level mechanic reference
4. `skills/sam-parr-copywriting-mechanics/references/hidden-knowledge.md` — for evidence-limit notes

Note: the companion OS (`_active/sam-parr-copywriting-os/`) was not ported with this skill. All mechanic routing is self-contained in SKILL.md and the `skills/sam-parr-copywriting-mechanics/workflows/` directory. The `_active/` OS can be ported separately if deep ad-breakdown protocols or the copywork training system are needed.

Video source: `https://www.youtube.com/watch?v=uf4fR3qcDkU&t=151s`. Evidence boundary: transcript-backed spoken evidence only; visual/OCR evidence unavailable. The video extraction package (`extractions/video-context/uf4fR3qcDkU/`) exists only in the Codex fork — port it to canonical before citing evidence limits from file.

Do not load the full transcript unless source fidelity is in question. Preserve the transcript-only evidence boundary.

## Use When

- headline or hook is weak,
- proof is absent, generic, or abstract,
- curiosity gap is missing or untrustworthy,
- copy is too long because it is not interesting,
- story is missing before the product pitch,
- objections are unhandled,
- rhythm is flat,
- humor may help but needs a fit check,
- the writer needs copywork,
- or `/farrice-content-os` Hook Room needs a direct-response pass.

## Do Not Use When

- the user only needs grammar or formatting,
- the main issue is offer strategy rather than copy mechanics,
- the copy lacks basic source material or proof and the user wants final publishable copy,
- or the task is broader than headline, proof, curiosity, rhythm, story, objection, humor, or copywork.

## Operating Flow

1. **Action Lock**: name the desired reader behavior.
2. **Weak-Link Diagnosis**: choose the current failure: attention, interest, desire, proof, objection, rhythm, story, humor, or action.
3. **Mechanic Selection**: choose one to three mechanics from the Mechanic Triggers table in `skills/sam-parr-copywriting-mechanics/SKILL.md`.
4. **Workflow Selection**:
   - AIDA movement problem -> `aida-reader-state-map.md`
   - weak opener -> `headline-gravity-lab.md`
   - missing or bad curiosity -> `curiosity-gap-repair.md`
   - unsupported claim -> `proof-object-builder.md`
   - abstract proof -> `visual-proof-translation.md`
   - flat continuation -> `rhythm-slippery-slope-pass.md`
   - product too early -> `story-desire-pass.md`
   - private doubt -> `objection-by-detail-pass.md`
   - humor uncertainty -> `humor-fit-check.md`
   - training need -> `copywork-rule-extraction.md`
   - generic ad or offer section -> `weak-ad-rescue.md`
5. **Rewrite Or Drill**: produce the changed section or copywork output.
6. **Behavior Proof**: show the before/after delta and reader-behavior explanation.
7. **Evidence Note**: cite mechanic timestamps when useful and preserve the transcript-only limit.
8. **Quality Checklist**: score against the Required Output Shape in `skills/sam-parr-copywriting-mechanics/SKILL.md`. (The full copy-quality-checklist.md lives in the `_active/sam-parr-copywriting-os/` companion OS — port that directory for the detailed scoring rubric.)
9. **Handoff**: send public, client-facing, or revenue copy to `/publishable-copy-gate`.
