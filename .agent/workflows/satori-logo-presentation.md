# /satori-logo-presentation

> Produce the structured client presentation that removes aesthetic confound from concept comparison. Every concept gets the same 1900×10000-px vertical layout. Clients compare *idea strength*, not *presentation polish*.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/06-logo-presentation.md
```

## Usage

```
/satori-logo-presentation [client + concepts ready from /satori-logo-concept]
```

## When to Use

- Presenting 2-4 logo concepts to a client
- Building a logo project's deliverable structure for the first time
- Replacing ad-hoc concept slides with a defensible standardized format

## Output

Presentation spec:
- Standardized 1900×10000-px vertical frame applied to every concept
- Per-concept content: name + tagline + thinking ≤80 words + iterations + color + 3 mockup scales (intimate / presence / thumbnail)
- Final decision page (recap + comparison table + recommended direction + next steps)
- Designer implementation instructions
