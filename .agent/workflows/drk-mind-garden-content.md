# Dr. K × Eric Roth — Mind-Garden Content

Write long-form content and newsletters using Dr. K's emotional processing as creative fuel, channeled through Eric Roth's cinematic prose architecture.

## Why This Stack Works

Roth writes from emotional depth — but unprocessed emotion creates reactive content (rajas). Processed emotion creates resonant content (sattva). Dr. K ensures you process first, then Roth channels that clarity into cinematic prose that hits harder because it comes from truth, not performance.

## Steps

1. **Load Dr. K**: `skills/dr-k-consciousness/genius.md`
2. **Load Roth**: `skills/eric-roth-cinematic-prose/genius.md` (if available)
3. **Phase 1 — EMOTIONAL PROCESSING (Dr. K)**:
   - What emotion is driving this piece? Name it precisely.
   - Sit-with protocol: process the raw emotion before writing
   - Identify the samskara connected to this topic (what past impression lives here?)
   - Reach the processed clarity state: "I see this experience from distance"
4. **Phase 2 — CONSCIOUSNESS LENS**:
   - What is the universal truth this processed emotion reveals?
   - What identity-as-process insight belongs in this piece?
   - What garden metaphor maps to this experience?
5. **Phase 3 — CINEMATIC ARCHITECTURE (Roth)**:
   - Build structure using Third Rail principle (the dangerous truth)
   - Deploy visual prose: show the internal experience, don't explain it
   - Use displacement selling: let the story do the work
   - Apply erosion: revise by removing, not adding
6. **Phase 4 — DEPTH CHECK**:
   - Does this read like processed truth or performed emotion?
   - Would Dr. K say this serves the reader's consciousness?
   - Would Roth say this has cinematic gravity?
7. Output: Long-form content piece with consciousness depth + cinematic architecture
8. Run quality gate against both rubrics
