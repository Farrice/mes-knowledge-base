# /gw-custom-instructions

A once-and-done global AI operating profile in Woods' style — built by a short interview about how you want AI to talk to you, then emitted as paste-ready custom-instructions blocks for ChatGPT, Claude, and Copilot so every future session inherits you. The anti-sycophancy / red-team block is one component of the whole profile.

## Trigger
`/gw-custom-instructions`

## Workflow path
`skills/geoff-woods-ai-thought-partner/workflows/16-custom-instructions.md`

## Quick Use
Say whose profile (you or a client) and which tools. The session interviews you one question at a time across disposition, patience, the 20%-that-drives-80% delivery preference, adversarial default, verification needs, and banned tells (em-dash ban included), then composes a tool-agnostic master profile and formats a copy-paste block per tool.

## Output
A tool-agnostic master profile in your voice (Woods' "high-D, zero patience, give me the 20%, don't fluff me up, be the challenger, red-team everything, fact-check everything" + tell bans), paste-ready blocks per tool with install paths, and a workspace pointer: in THIS workspace the layer is already live via CO-CREATION-CARD + CLAUDE.md, so the deliverable is for your OTHER AI surfaces and for clients — plus the standing-guard reminder that best-prompt tell-leak still runs 10-20%.
