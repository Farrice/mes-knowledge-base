# /psychological-bottleneck-finder

> A thin discovery alias for Rory Sutherland's canonical reframe and detective engines.

## Quick Deploy

```text
Load: skills/rory-sutherland-marketing/genius.md
Prompt: skills/rory-sutherland-marketing/references/prompts-v2/the-psychological-reframe-engine.md
Validate with: skills/rory-sutherland-marketing/workflows/behavioral-detective-protocol.md
```

## When to Use

- A good offer, journey, or message stalls at one small step.
- The proposed fix is “more copy,” “more features,” or “more speed,” but the actual obstruction is unclear.
- You need to rank uncertainty, effort, rejection/status risk, trust deficit, response-channel mismatch, and technical defects before prescribing a change.

## Input

- Goal or offer
- Audience and context
- Exact behavior that is not happening
- Observed evidence and current explanation
- Fixed technical, legal, safety, brand, budget, and timing constraints
- Requested downstream artifact

## Alias Boundary

This command creates no new methodology. It routes to the psychological reframe prompt, then uses Behavioral Detective Protocol when the leading hypothesis needs observation or a causal test. Choose one primary bottleneck. Add at most one delivery expert after diagnosis.

## Required Canonical Outputs

Return the ranked bottleneck map, selected reframe, strongest rival explanation, fixed-constraint check, and one atomic or honestly labeled radical-alternative test.
