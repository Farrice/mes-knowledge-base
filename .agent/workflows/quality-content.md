# Quality Content — The Proven Stack (floor, not ceiling)

Reproduces the pipeline that produced **ship-ready-as-is** content on 2026-06-19 (Farrice: "I'd ship them without adding anything").
- **Benchmark (the bar to clear):** `_active/linkedin-launch/ai-boom-content-package.md`
- **Full mechanism breakdown:** `_active/linkedin-launch/CONTENT-QUALITY-BENCHMARK-AND-RECIPE.md`

## ⚠️ Philosophy — READ FIRST
This is a **strong default**, NOT a hard rule and NOT the only way. It reliably clears the PASS bar. The system is capable of more, so:
- **Scale UP freely** when the task warrants — more research angles, multiple expert lenses, a writers-room emotional pass, depth workflows. The point is to keep raising the floor *and* the bar.
- **Scale DOWN** for a quick post that doesn't need the full stack — but never silently drop Layer 4 (dual QA); it's cheap and catches ship-killers.
- If a better path exists for THIS request, take it and say why. Judgment overrides the recipe, always.

## Arguments
`TOPIC/SEED + AUDIENCE + ANGLE (what makes the author look smart) + FORMATS (LinkedIn / newsletter / audio / X / etc.)`
Infer missing pieces from context, MEMORY.md, and any client CLAUDE.md. Ask only if genuinely blocked — don't bottleneck.

## The Stack

**Layer 0 — Scope (Chain 1-3).** Score intent, route to expert(s), pull voice/audience context (MEMORY.md + client CLAUDE.md).

**Layer 1 — DEPTH (the spine).** Establish ONE converged thesis/wedge before writing:
- *Default:* dispatch **3+ parallel `deep-research` agents**, distinct lenses — macro signal · vertical intersection (this niche) · live community pain (Reddit/forums = shadow market). Word-ceiling each (~550–600w); demand sources + VERIFIED/LIKELY/UNCONFIRMED labels. (This is `/hunt-trends`, generalized.)
- *Alt seed:* an existing insight, client brief, or personal story — still ground it, still find the wedge.
- **If the angles don't converge, there is no spine — dig more before drafting.**

**Layer 2 — LENS.** Route to the right expert(s) and **READ their `genius.md`** (never work from vibes). Let their model reframe the work — e.g. Cole: "what tangible asset does the reader GET?" Multi-domain → load 2+ experts or `/convene`.

**Layer 3 — VOICE.** Draft each format under the banned-AI-tells rules (MEMORY.md): em dashes ≤1-2; no negation-correction ("not X / it's Y"); no triple anaphora; no cheap-question closes; Show > Tell; reader-as-protagonist. Format-native each time.

**Layer 4 — DUAL ADVERSARIAL QA (run in parallel, before delivery — do not skip).**
- `prose-doctor` → structural AI-tells, surgical fixes, voice preserved.
- `fact-verifier` → every real-world claim checked vs primary source; fabrications killed.
- Apply fixes.

**Layer 5 — FINALIZE (Chain 6).** `chain_runner.py finalize`, honest scores. Marginal (7.0–7.5) = push the weakest layer once or flag with eyes open. (System score runs conservative vs Farrice's felt verdict — trust the felt verdict.)
