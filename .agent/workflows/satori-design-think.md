# /satori-design-think

> The crown of the skill. One command that thinks a design task all the way from communication problem to a production brief a generation tool can execute — Satori is the brain, the generation tools are the hands. It never auto-fires a paid or cost-gated API; the human reviews the brief, then triggers generation.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/20-design-think.md
```

## Usage

```
/satori-design-think [fresh design task — poster, identity, UI, social, packaging, or ad]
```

## When to Use

- A fresh design task needs to go from problem → production-ready brief in one pass
- A generation tool (fantastic-posters, Creative Director, product-design, Kittl, Higgsfield) is about to be called and you want the thinking layer locked first
- A design came back generic and you want to rebuild it from the communication problem up, not patch the surface
- You want a single defensible artifact a teammate or client can review before spending a cent on generation

## Output

A single production brief assembled from nine composed stages:
- Stage 0 surface + one-sentence brief → Stage 1 comms brief → Stage 2 concept
- Stage 3 LIFT hierarchy → Stage 4 color system → Stage 5 feeling calibration
- Stage 6 memory hook → Stage 7 anti-AI-slop imperfection → Stage 8 perception-gap check
- A Handoff Block: the routed, human-triggered generation command for the correct tool
