# /jenny-visual-analogy

A physically-staged visual analogy for an abstract or educational concept — props, staging, and a play-it-out script that shows the idea instead of narrating it.

## Trigger
`/jenny-visual-analogy`

## Workflow
`skills/jenny-hoyos-shorts/workflows/05-visual-analogy-engineer.md`

## Quick Use
Provide:
1. The abstract concept (idea, lesson, or number with no obvious visual)
2. Niche + avatar (how much they already know)
3. What they should feel or understand after the beat lands
4. Available props/staging + content type

## Output
Chosen analogy staging (prop, element mapping, physical motion), first-frame spec, play-it-out beat script (VISUAL/AUDIO), and rejected stagings with reasoning.
