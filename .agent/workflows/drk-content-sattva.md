# Dr. K × Kallaway — Sattva Content Engine

Write content from a processed, clear mental state (sattva) using Kallaway's content psychology for maximum psychological depth and audience resonance.

## Why This Stack Works

Most creators write from rajas (anxious productivity) or tamas (forced output). Kallaway's content psychology + Dr. K's guna framework = content that resonates at a deeper level because the creator is operating from clarity, not reactivity.

## Steps

1. **Load Dr. K**: `skills/dr-k-consciousness/genius.md`
2. **Load Kallaway**: `skills/kallaway-content-psychology/genius.md`
3. **Phase 1 — STATE CHECK (Dr. K)**:
   - Run Three Gunas Diagnostic on the creator's current state
   - If tamas or rajas dominant → run Emotional Processing Protocol first
   - If sattva → proceed to Phase 2
   - Key question: "Are you writing to express or to escape?"
4. **Phase 2 — TOPIC THROUGH CONSCIOUSNESS LENS (Dr. K)**:
   - Map the content topic through identity/samskara/dharma framework
   - What universal consciousness pattern does this topic touch?
   - What observing-mind insight can be embedded?
5. **Phase 3 — CONTENT ARCHITECTURE (Kallaway)**:
   - Apply Lego Brick decomposition to the consciousness-aware topic
   - Design hook using Dr. K's "distance from thoughts" principle
   - Build retention through psychological tension (not manipulation)
   - Deploy C.A.P. Fit: Content × Audience × Product alignment
6. **Phase 4 — DEPTH INTEGRATION**:
   - Layer Vedantic metaphors naturally (garden, groove, water)
   - Ensure authority comes from processed experience, not performance
   - Apply Ugly Numbers (Dr. K's specific frameworks create credibility)
7. Output: Content piece with consciousness depth + viral architecture
8. Run quality gate: Kallaway's 11-brick check + Dr. K's anti-slop rubric
