# /spiegel-close-friends — Close-Friends Strategy

> Right people > most people. Design for high-density connections that create 10x more value than large networks.

## When to Use
- Building a community, audience, or network
- Deciding between broad reach and deep engagement
- Designing social features or community architecture
- Segmenting an email list or client base

## Inputs Required
1. Audience/network/community description
2. Current size and engagement quality
3. Product/service and how it's used socially
4. Who your "best" users are and why

## Execution Steps

### Step 1: Best Friend Equivalent Identification
Ask: "What's the 'best friend' relationship in my product?"
- For a newsletter → the reader who forwards every issue to the same 3 people
- For a service → the client who refers without being asked
- For a community → the member who answers questions before you do
- For a product → the user who can't imagine using the alternative

### Step 2: High-Density Connection Mapping
Identify your top 10 connections by relationship density:

| Person/Segment | Engagement Level | Referral Power | Value Created | Density Score |
|---|---|---|---|---|
| | | | | |

### Step 3: Design for Density
Redesign your product/service to maximize high-density connection value:
1. What experience do your top 10 get that the other 990 don't?
2. What tools help them share with THEIR best connections?
3. How do you make the product better when used with close connections?
4. What community signals identify potential high-density connections early?

### Step 4: Network Density Architecture
| Layer | Description | Size | Purpose |
|---|---|---|---|
| **Inner Circle** | Best friend equivalents | 5-15 | Value co-creation, product direction |
| **Active Community** | Regular engagers | 50-150 | Content, feedback, social proof |
| **Broader Network** | Passive audience | 1,000+ | Distribution, discovery |

### Step 5: Density Growth Protocol
Grow through density, not volume:
1. Identify what converted inner circle members (pattern recognition)
2. Find people with identical patterns in broader network
3. Create pathways from broader → active → inner
4. Measure: density (engagement per person) > reach (total people)

## Output Format
```
## CLOSE-FRIENDS STRATEGY — [Product/Community]
### Best Friend Equivalent: [definition]
### Top 10 High-Density Connections
### Design-for-Density Changes
### Network Layer Architecture
### Density Growth Protocol
### Key Metric: [engagement density, not reach]
```

## Quality Gate
- Must define the "best friend equivalent" specifically
- Top 10 must be real people/segments, not hypothetical
- Design changes must create differential experience for high-density users
- Growth metric must prioritize density over volume
