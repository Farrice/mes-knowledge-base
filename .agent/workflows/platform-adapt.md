# /platform-adapt — Deep Platform Adaptation

Unlike `/content-bundle` which produces multiple versions simultaneously, this workflow goes deep on ONE platform — studying its specific algorithms, format conventions, and audience expectations to produce content that is indistinguishable from native.

## Usage

```
/platform-adapt [path to content] --to [platform]
/platform-adapt .tmp/linkedin-post.md --to Newsletter
```

## Steps

### 1. Load Skills
Read these files:
1. `skills/kieran-flanagan-content-engine/SKILL.md`
2. `skills/kieran-flanagan-content-engine/genius.md`
3. `skills/kieran-flanagan-content-engine/workflows/05-platform-adapt.md`

### 2. Execute Workflow
Follow the workflow in `05-platform-adapt.md` using the loaded genius context.

### 3. Optional Really Real Depth Layer
If the user asks for "real," "soulful," "less AI," "less generic," "more human," "make people feel it," or similar depth language, load `skills/lamott-allen-really-real-writing/` after platform adaptation. Use it only to add one true observation, clearer reader trust, plain force, or restraint while preserving the target platform's native rhythm.

### 4. Save Output
Save adapted content to `.tmp/kieran-flanagan/adapted-[platform].md`.
