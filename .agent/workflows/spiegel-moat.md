# /spiegel-moat — Moat Architecture

> Build defensible moats that take years to replicate. Features are copyable in months — ecosystems are not.

## When to Use
- Competitors are copying your features
- You need structural defensibility beyond product quality
- After completing `/spiegel-distribution` (distribution is solved, now defend it)
- Strategic planning for long-term competitive positioning

## Inputs Required
1. Current product/service and its features
2. Competitive landscape (who's copying or could copy you?)
3. Existing assets (audience, content, partnerships, technology)
4. Current moat inventory (what you believe is defensible today)

## Execution Steps

### Step 1: Copyability Audit
List every competitive advantage. Classify each:

| Advantage | Category A: Copyable (<6 months) | Category B: Structural (>2 years) |
|---|---|---|
| | | |

**The Spiegel Rule**: If everything is in Category A, you're building on sand. Stop and redesign before competitors arrive.

### Step 2: Five-Layer Moat Assessment
Score your business 1-10 on each moat layer:

| Moat Layer | Current State | Score | Build Priority |
|---|---|---|---|
| **Ecosystem** — Third parties creating value on your platform | | | |
| **Platform** — Infrastructure others depend on (APIs, tools, marketplaces) | | | |
| **Network Density** — Right connections, not most connections (GP-3) | | | |
| **Hardware/Vertical** — Own the full stack (hardest to copy) | | | |
| **Brand** — Emotional moat (people choose you even when alternatives exist) | | | |

### Step 3: Ecosystem Design Sprint
For the highest-priority moat layer:
1. **Who creates value?** List every stakeholder who COULD create value on your platform
2. **What tools do they need?** APIs, templates, marketplaces, distribution
3. **What incentives work?** Revenue share, exposure, community, tools
4. **What's the chicken-and-egg?** How do you seed the ecosystem before it's self-sustaining?

### Step 4: Moat Construction Roadmap
Design a 90-day moat-building sprint:
- **Days 1-30**: Seed — build the first ecosystem element, attract first contributors
- **Days 31-60**: Grow — launch incentive programs, expand stakeholder categories
- **Days 61-90**: Harden — measure ecosystem health, identify and fix vulnerabilities

### Step 5: Competitor Moat Comparison
Map competitors against the same 5-layer framework:
- Where are they stronger? Where are they vulnerable?
- What moat layer would hurt them most if you built it first?

## Output Format
```
## MOAT ARCHITECTURE — [Product Name]

### Copyability Ratio: X% Category A (sand) / Y% Category B (stone)

### Five-Layer Moat Score: X/50

### Priority Moat Layer: [Ecosystem/Platform/Network/Vertical/Brand]
[Why this layer, what building it looks like]

### Ecosystem Design
- Value creators: [who]
- Tools needed: [what]
- Incentive structure: [how]
- Seeding strategy: [chicken-and-egg solution]

### 90-Day Moat Sprint
[Week-by-week plan]

### Competitor Vulnerability Map
[Where competitors are weakest on the 5-layer framework]
```

## Quality Gate
- Copyability audit must classify EVERY current advantage, not just cherry-pick
- At least one moat layer must have a concrete build plan, not just a score
- 90-day sprint must have measurable milestones at 30/60/90
- Competitor map must identify at least one exploitable vulnerability
