# /reference-led-creative-system — Reference-Led Creative System

Use this front door when the user wants the Performance Evidence Journal process repeated for a new brand, asset, product, page, campaign, presentation, or media surface.

## Required reads

1. `skills/reference-led-creative-system/SKILL.md`
2. `skills/reference-led-creative-system/references/skill-system-contract.md`
3. `skills/reference-led-creative-system/references/visible-choice-contract.md`
4. The matching v2 prompt under `skills/reference-led-creative-system/references/prompts-v2/`
5. The installed Refero Design skill
6. The active brand/product/design-system source of truth

## Invocation

```text
/reference-led-creative-system EXPLORE — [brief]
/reference-led-creative-system LOCK — [chosen direction or use the verdict]
/reference-led-creative-system APPLY — [locked direction + asset]
/reference-led-creative-system AUDIT — [good example + current artifact]
```

## Run

1. Compile the brief and name the identity owner.
2. Search Refero styles across 3–5 genuinely different angles; add screens/flows only when structure or journey requires them.
3. Retrieve full styles in batches of 3–4 and synthesize three directions without averaging.
4. Write a direction manifest and run the local capture helper.
5. Verify and display the local contact sheet plus individual images.
6. Recommend one direction and record strategic fit, system impact, and risk.
7. Stop for visual selection unless the user explicitly said to use the verdict.
8. Write the reference lock and build target before implementation.
9. Build one or two representative surfaces through the existing system.
10. Run rendered visual QA, correct P0/P1/P2 drift, and preserve the good example, receipt, and replay prompt.

## Hard boundaries

- Remote images never count as the decision surface.
- Do not replace an existing brand system without explicit approval.
- Do not generate bitmap media unless it changes the outcome; paid generation retains its cost gate.
- Do not publish, upload, purchase, contact, or perform external writes without approval.
- Do not treat local checks as human taste or market proof.
- Do not turn the golden example into a universal house style.

## Result

Return:

- contact sheet and individual local previews;
- compact three-direction comparison;
- one recommendation;
- selected reference lock;
- production surface links, when built;
- QA and proof state;
- one replay prompt.
