# /jenny-script-short

Shot-ready 30-60 second short-form video script built on the VIRAL framework with but/so story beats.

## Trigger
`/jenny-script-short`

## Workflow
`skills/jenny-hoyos-shorts/workflows/01-script-viral-short.md`

## Quick Use
Provide:
1. The idea or topic
2. Niche + avatar (who it's for, what they fear/dream)
3. Format context + available visuals (what can be shown on camera)
4. Target length (default 30-45s) + characters available (optional)

## Output
VIRAL table, full timestamped script (VISUAL/AUDIO columns), progression mechanism, pacing map, loop design, delivery note, and edit notes.

## Stacks With
→ `/jenny-hook` (generate ranked hook options before scripting)
→ `/jenny-idea-ladder` (source the idea) · `/jenny-visual-analogy` (stage the V-box) · `/jenny-cast` (cast characters)
→ `/jenny-retention` (diagnose after posting)
