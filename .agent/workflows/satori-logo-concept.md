# /satori-logo-concept

> End the "let's just sketch" wandering. Produce 3 concept directions with locked visual primitives, derived from verbs (not nouns), validated against a one-sentence brief.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/05-logo-concept.md
```

## Usage

```
/satori-logo-concept [brand name + brief / industry / context]
```

## When to Use

- Starting a logo project from scratch
- A logo direction is wandering and needs to be re-anchored
- A client gave a noun-heavy brief ("we want a shield / mountain / arrow")
- An existing logo direction feels generic

## Output

Logo concept brief:
- One-sentence brief locked
- Primary + supporting verbs extracted (from 10 candidates)
- Visual primitive locked with shape psychology rationale
- 3 concept directions (Literal / Metaphorical / Conceptual Inversion)
- Trap audit per concept (whole-story / noun-locked / decoration / generic)
- Sketchable + AI-promptable description per concept
