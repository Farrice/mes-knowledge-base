# /caleb-format-strategy — Content Format Strategy Engine

Design a platform allocation plan, content type matrix, and 30-day sprint matched to your audience growth phase using Caleb's methodology.

## Steps

### 1. Load Skills
Read these files:
1. `skills/caleb-ralston-personal-brand/genius.md`
2. `skills/caleb-ralston-personal-brand/workflows/content-format-strategy-engine.md`

### 2. Execute Workflow
Follow the workflow. Requires:
- Current platforms and posting cadence
- Audience size per platform
- Business goals (trust, discovery, conversion)
- Content creation capacity

### 3. Deliver
- Platform purpose map (YouTube=trust, short-form=discovery, Instagram=conversion)
- Format niche recommendation
- Accordion pipeline (test short-form → expand winners to long-form)
- 30-day format sprint with 75/20/5 content mix
- Wrapping paper suggestions for each platform

### 4. Quality Gate
Each platform assigned ONE primary purpose. Accordion pipeline defined. Format niche identified. Sustainable cadence set below aspiration.
