# /grace-quickstart

> **When to use**: Starting from zero or near-zero. Brand exists but lacks content strategy. Someone just decided "I'm going to build an audience." This is the onboarding command.

## Usage
```
/grace-quickstart
```
Or: "run grace-quickstart", "@grace-quickstart", "start my content strategy"

## What It Does

Compressed end-to-end onboarding using Workflow 18 (Zero-to-Scale Playbook), activating the right Grace Andrews workflows at each stage:

### Phase 1: 24-Hour Quickstart → Anchor Document
### Phase 2: 7-Day Sprint → First Content In-Market  
### Phase 3: 30-Day Integration → Operating System Installed

## Steps

1. **Load Context**
   - Read `skills/grace-andrews-media-company/genius.md`
   - Read `skills/grace-andrews-media-company/workflows/18-zero-to-scale-playbook.md`

2. **Stage Assessment**
   - Determine user's current stage: Zero / Foundation / Growth / Scale
   - If Growth or Scale → redirect to `/grace-city-blueprint` (more appropriate)
   - If Zero or Foundation → continue

3. **24-Hour Quickstart** (Workflow 18, Stage 1)
   - Grand Central Station definition (compressed Workflow 01)
   - Initial City Map (2 destinations, 2 lines, 1 named passenger)
   - Starter Trust Pathway (3 stages minimum)
   - Publishing commitment statement
   - **Output**: Anchor Document

4. **7-Day Sprint Plan** (Workflow 18, Stage 2)
   - Days 1-2: Discovery content (Workflow 17 — Audience Niche Laser)
   - Days 3-4: Depth content (Workflow 15 — Emotional Residue Engineer)
   - Day 5: Experiment content (Workflow 03 — C×E Engine)
   - Day 6: Outreach activation (compressed Workflow 05)
   - Day 7: Sprint review
   - **Output**: 7-piece content plan with trust tags

5. **30-Day Integration Plan** (Workflow 18, Stage 3)
   - Week 1: Cadence lock
   - Week 2: C×E ratio formalization (Workflow 03)
   - Week 3: Data Kill Switch (GP-5 anti-romanticism check)
   - Week 4: City Map revision with 30 days of data
   - **Output**: 30-day operating calendar

6. **Deliver Unified Playbook**
   ```
   # Quickstart Playbook: [Brand Name]

   ## Anchor Document (24-Hour Quickstart)
   ## 7-Day Sprint (content plan + trust tags)
   ## 30-Day Integration (operating calendar)
   ## Growth Phase Preview (what happens at 100+ followers)
   ## Key Metrics to Track
   ```

7. **Quality Gate**
   - Grand Central passes the "500 episodes" test
   - All 7 sprint pieces have trust pathway tags
   - Named person is specific (not demographic)
   - Data Kill Switch scheduled for Day 30

**Execution prompts**: before producing the deliverable, check `skills/grace-andrews-media-company/references/prompts-v2/` for the matching structure-pure prompt and honor its Output Contract (prompt-load sweep, 2026-07-21).
