# /addiction-loop-diagnostic

Audit any content for Addiction Loop presence, prediction coverage, and retention quality.

## Trigger
`/addiction-loop-diagnostic`

## Workflow
`skills/kallaway-addictive-storytelling/workflows/addiction-loop-diagnostic.md`

## Quick Use
Provide:
1. The full content to audit (script, email, sales page, post)
2. The content format
3. The target audience

## Output
Addiction Loop Audit Report — executive verdict (vending machine vs slot machine), loop map, time-per-hand score, dead air report, priority fix list.

## Stacks With
→ `/flat-to-addictive-rewrite` (fix what the diagnostic finds)
→ `/loop-density-optimizer` (compress after fixing)
