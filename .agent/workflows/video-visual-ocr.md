# /video-visual-ocr

Run the full ledger command and read `ocr-notes.md`.

```bash
python3 execution/video_context_ledger.py "<youtube-url>" --mode full
```

If OCR tooling is unavailable, the output must create limitation rows instead of guessed on-screen text.
