# /addiction-copy-engine

Adapt the Addiction Loop to written copy — sales pages, emails, LinkedIn posts, ads, and any text format.

## Trigger
`/addiction-copy-engine`

## Workflow
`skills/kallaway-addictive-storytelling/workflows/addiction-copy-engine.md`

## Quick Use
Provide:
1. Copy type (sales page, email, email sequence, LinkedIn post, landing page, ad, thread)
2. Offer or topic
3. Target audience
4. Desired action (buy, click, reply, share, save)
5. Proof assets (testimonials, data, case studies)
6. Voice reference (optional)

## Output
Loop-Driven Copy Package — loop architecture, full polished copy with CTA, annotated version, validation report, A/B variant (optional), email sequence map (if applicable).

## Stacks With
→ `/addiction-loop-diagnostic` (audit existing copy first)
→ `/loop-density-optimizer` (compress after writing)
→ `/obsession-copy-engine` (combine loop architecture with obsession mechanics)

**Execution prompts**: before producing the deliverable, check `skills/kallaway-addictive-storytelling/references/prompts-v2/` for the matching structure-pure prompt and honor its Output Contract (prompt-load sweep, 2026-07-21).
