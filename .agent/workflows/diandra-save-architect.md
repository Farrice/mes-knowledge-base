# `/diandra-save-architect` — Save-Worthy Content Architect

Transforms any content idea into a format that triggers SAVE behavior — the most valuable engagement signal in LinkedIn's 2026 algorithm. Based on Authored Up data: 1 save ≈ 5x the reach impact of 1 like.

## When to Use
- You have a content idea and want maximum algorithmic reach
- Building Authority or Growth bucket content
- Creating reference material (frameworks, checklists, data)
- After `/diandra-algorithm-audit` identifies low save rates

## Usage

```
/diandra-save-architect "[content idea]" --bucket [authority|growth|conversion|personal]
```

## What It Does

1. **Loads**: `skills/diandra-escobar-linkedin-growth/genius.md` (Pattern 16, 6, 12)
2. **Reads**: `skills/diandra-escobar-linkedin-growth/workflows/18-save-worthy-content-architect.md`
3. **Classifies**: Which save psychology trigger the idea serves
4. **Selects**: Optimal format architecture (Playbook, Framework, Data, Blueprint, or Template)
5. **Produces**: Full post with body-first writing, AI-audited first 50 words, visual brief
6. **Delivers**: Save-worthy post package with 5 hook candidates

- `/diandra-first-50` → Run AFTER this to fine-tune the opening
- `/diandra-content-engine` → Use this INSTEAD when you want save-optimization specifically
- `/diandra-semantic-lanes` → Ensure the save-worthy post is within your declared lanes
