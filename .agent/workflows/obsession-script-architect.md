# Obsession Script Architect

Produce obsession-architected video scripts with progressive level ascension.

1. Load and execute `skills/kallaway-audience-obsession/workflows/obsession-script-architect.md`

## Required Inputs
- **Topic**: What is this video about?

- **Desired action**: What should the viewer do after watching?
- **Available proof**: Results, data, case studies
