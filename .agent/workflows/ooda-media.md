# /ooda-media — OODA Loop Media Warfare

Design a communication system that cycles through Observe→Orient→Decide→Act faster than any competitor. Produces a stage-by-stage compression plan, competitor benchmarks, pre-built position templates, flood-the-zone crisis protocol, and proactive disruption calendar.

**When to use**: You're always reacting to competitors instead of leading the narrative. Decision-to-publish takes days. You need a permanent structural speed advantage, not just faster typing.

## Usage

```
/ooda-media [organization/brand]
/ooda-media "My Company" --current-speed "72 hours" --competitors "Competitor A"
/ooda-media --crisis "Active: competitor published hit piece 4 hours ago"
```

## Steps

### 1. Load Skills
Read these files:
1. `skills/andreessen-horowitz-new-media/SKILL.md`
2. `skills/andreessen-horowitz-new-media/genius.md`
3. `skills/andreessen-horowitz-new-media/workflows/02-ooda-media-warfare.md`

### 2. Assess Mode
- **Standard mode**: Build the full OODA loop system with all 5 steps
- **Crisis mode** (if `--crisis` flag or active threat described): Skip to crisis protocol, execute the flood-the-zone playbook with minute-by-minute timeline

### 3. Execute Workflow
Follow every step in `02-ooda-media-warfare.md`:
- Step 1: Measure existing OODA loop (stage by stage in hours)
- Step 2: Benchmark competitor loop speeds
- Step 3: Compress each stage with structural fixes
- Step 4: Build crisis protocol (flood variant)
- Step 5: Design proactive disruption calendar

### 4. Pre-Build Position Templates
For the top 10 most likely narrative scenarios (ask user for their industry), draft response templates:
- Each template: pre-written thesis + key talking points + evidence links
- Categories: competitor attack, industry trend shift, regulation change, viral moment, product comparison

### 5. Save Output
Save to `research_outputs/[date]-ooda-playbook-[org-slug].md`

## Output Structure

```
# OODA Loop Media Warfare Playbook: [Organization]

## Current Loop: [X hours]
## Competitor Benchmark Table

## Pre-Built Position Templates (top 10)
## Crisis Protocol (Flood Variant — minute-by-minute)
## Proactive Disruption Calendar (next 4 weeks)
## 7-Day Speed Drill (implementation sprint)
```
