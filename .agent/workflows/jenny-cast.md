# /jenny-cast

A cast design for a short — aspirational × relatable pairing, named trait-distinct characters, dual-audience seating, and reaction-beat placement.

## Trigger
`/jenny-cast`

## Workflow
`skills/jenny-hoyos-shorts/workflows/08-character-cast-director.md`

## Quick Use
Provide:
1. The video idea/draft and its payoff
2. Available people (solo, family, friends, strangers, animals, named object)
3. Target demographics (primary avatar + any second demographic)
4. Dense beats where a reaction pause would help + content type

## Output
The aspirational/relatable pair, full cast with named trait-distinct characters, dual-audience map, reaction-beat placements, and familiarity + laugh-ritual notes.

## Stacks With
→ `/jenny-script-short` (cast feeds directly into the script's character beats)
