# Art Direction

Full creative direction for any visual concept — campaigns, brands, products, content. Produces 3 concept directions with complete execution specs and production-ready AI prompts.

## Expert Loading

Load `skills/creative-direction/SKILL.md` at Tier 1. For high-stakes or complex briefs, escalate to Tier 2 (`genius.md`) for deep reference on art movements, visual language, and platform prompting.

## Workflow

### Step 1: Deconstruct the Brief

Ask clarifying questions if the concept is vague. Identify:
- **Message** — What is the core communication? (1 sentence max)
- **Audience** — Specific demographic + psychographic
- **Medium** — Where will this live? (social, print, video, web, apparel)
- **Emotional target** — What should the viewer feel? (primary + secondary)
- **Constraints** — Budget, timeline, platform, format

### Step 2: Develop 3 Concept Directions

Each direction must include:
- A concept name and one-sentence thesis
- **Visual Hook** + **Emotional Core** + **Cultural Anchor** (Three Anchors framework)
- Art movement/style reference (be specific — not "modern" but "Swiss International meets Neo-Tokyo")
- Color palette with emotional reasoning (specific hex codes)
- Typography pairing with hierarchy rationale
- Photography/image direction (shot types, lighting, composition from genius.md reference)
- 5-layer mood board description (Color, Texture, Typography, Image, Cultural References)

### Step 3: Recommend One Direction

Explain WHY it best serves the brief. Reference the audience, the emotional target, and the cultural context. Apply the Virgil Test:
- Does it have tension?
- Is there a specific cultural anchor?
- One-sentence concept test
- Would removing any element make it stronger?

### Step 4: Execution Specs

For the recommended direction:
- **Platform recommendation** (Higgsfield, Kittl, Midjourney, Flux — reference Platform Selection Matrix)
- **Production-ready prompts** for each asset needed (using platform-specific formulas from genius.md)
- **File specifications** (dimensions, resolution, color mode)
- **If multi-shot:** full storyboard using 4-act trailer structure
- **If apparel:** placement guide, print method, production specs

### Step 5: Generate 3 Prompt Variants per Key Asset

For the primary asset:
- **Variant A (Safe):** Proven approach, highest success probability
- **Variant B (Creative):** More artistic interpretation
- **Variant C (Wild Card):** Unexpected angle, high risk/high reward
- Include Pro Tip for each on what to adjust if output isn't right

## Quality Standard

Every recommendation must reference a specific technique, principle, or cultural reference. "Clean and modern" is not art direction — "Swiss International grid with Neo-Grotesque type at 48pt, muted earth palette (#2C2C2C, #D4C5A9, #8B7355) evoking Wabi-Sabi imperfection" is art direction.
