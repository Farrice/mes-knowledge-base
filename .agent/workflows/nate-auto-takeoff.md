# /nate-auto-takeoff — Local Hard Takeoff Deployment Plan

Client-ready consulting deliverable. "Each of these is a hard takeoff — steep, sudden, compounding, bounded."

## Workflow

### Step 1: Load Expert Context
Read `skills/nate-b-jones-auto-improvement-loops/SKILL.md` and `skills/nate-b-jones-auto-improvement-loops/genius.md`.

Read `skills/nate-b-jones-auto-improvement-loops/workflows/07-local-hard-takeoff-deployment.md` for the specific workflow.

### Step 2: Gather Input
1. All prerequisite workflow outputs (WF 01-06, gates passed)
2. Team composition (3-5 people per GP-11)
3. Compute budget ($500-$5000 first month)
4. Executive sponsor (for red-tape cutting)

### Step 3: Execute the 9-Phase Workflow
1. **System Selection** — Tier A (cheap failure) first
2. **Infrastructure Build Order** — 6-10 week Gantt
3. **First 3 Cycles (Supervised)** — validate mechanism, judgment, autonomy
4. **Supervised Volume Sprint** — cycles 4-10, reach 5+ KEPT with zero regressions
5. **Promotion Criteria** — 6-point gate for production deployment
6. **Scale-Out Protocol** — when to expand, how
7. **Program.md Authoring** — the direction document (required sections)
8. **Monitoring + Governance Rhythm** — per-cycle to quarterly cadences
9. **Deployment Document Production** — full 9-section deliverable

### Step 4: Produce Deliverable
- Full deployment plan (9-phase structure)
- First version of program.md for selected system
- Infrastructure build timeline
- Team composition + roles
- 90-day success metrics
- Failure response plan
- Document at `deliverables/takeoff-deployment-[system].md`

### Step 5: Quality Gate
All 7 rubric dimensions ≥7. Especially: Judgment Leverage, Revert Capability, Safety Monitoring.

### Step 6: Hand-off
- Approved by sponsor → begin infrastructure build
- Rejected → rescope (smaller system? more prereq work?)
- Stuck on prereq → return to specific prior workflow
