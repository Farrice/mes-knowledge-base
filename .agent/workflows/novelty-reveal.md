# /novelty-reveal

Step 1 — convert an old/boring topic into a new-feeling angle tied to a wanted outcome.

## Trigger
`/novelty-reveal`

## Workflow
`skills/kallaway-illusion-of-novelty/workflows/novelty-reveal.md`

## Quick Use
Provide:
1. The old/boring topic
2. What the viewer wants (the outcome to map to)
3. Anything genuinely new about it (optional — if none, the workflow mines a new angle)

## Output
Path A/B determination + chosen new aspect + outcome tie + 6–10 hook variants (new reveal × outcome).

## Stacks With
→ `/novelty-angles` (if you need angle breadth first)
→ `/novelty-contrast` (anchor the reveal against the held belief)
→ `/novelty-hook` (compress into the densest hook)
