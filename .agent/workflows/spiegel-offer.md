# /spiegel-offer — Distribution-First Offer

> Full pipeline: solve distribution → design moat → understand customer emotions → build the offer → launch with advantage.

## When to Use
- Building something from scratch (full pipeline)
- Want the complete Spiegel methodology in one workflow
- Need a comprehensive product/offer development process
- Testing a new market or product category

## Inputs Required
1. Raw idea or opportunity description
2. Target audience
3. Available resources and timeline
4. Competitive landscape

## Execution Steps

### Step 1: Distribution Audit (Compressed)
Run the core of `/spiegel-distribution`:
- Distribution channel scan (5 questions)
- Temporal window status
- Distribution advantage statement (ONE sentence)

**Gate**: If you cannot write the distribution advantage statement, STOP. Fix distribution before proceeding.

### Step 2: Moat Pre-Design (Compressed)
Run the core of `/spiegel-moat`:
- Copyability audit on planned features
- Identify which moat layer to build toward
- Design the first ecosystem element

### Step 3: Empathy Sprint (Compressed)
Run the core of `/spiegel-empathy`:
- 3+ deep listening sessions (1-2 hours each)
- Dual-track logging (requests vs. substrates)
- Synthesis of dominant emotional substrates
- Invention brief (address substrates, NOT requests)

### Step 4: Offer Architecture
Build the offer around distribution + empathy:
1. **Core value**: What emotional substrate does this address?
2. **Distribution integration**: How is distribution built INTO the product?
3. **Moat seed**: What ecosystem/platform element launches with the product?
4. **Viral coefficient**: What makes a user invite another user?
5. **Pricing**: What does the distribution channel support?

### Step 5: Launch Sequence
Run the core of `/spiegel-launch`:
- Close-friends seed strategy (10-50 people)
- Distribution-first sequencing (pre-launch → launch → moat transition)
- Post-launch moat building timeline

## Output Format
```
## DISTRIBUTION-FIRST OFFER — [Offer Name]

### Distribution Advantage: "___"
### Moat Layer: [Ecosystem/Platform/Network/Vertical/Brand]
### Emotional Substrates: [top 2-3]

### Offer Architecture
- Core value: [substrate addressed]
- Distribution integration: [how]
- Moat seed: [first ecosystem element]
- Viral coefficient: [share mechanic]
- Pricing: [amount + rationale]

### Launch Sequence (6-week plan)
### Post-Launch Moat Timeline (90-day)
```

## Quality Gate
- Distribution must be solved BEFORE product design begins
- Empathy results must show substrates, not feature requests
- Offer must integrate distribution INTO the product (not bolted on)
- Must include post-launch moat transition plan
