# /satori-lift-audit

> Score any layout on Satori's LIFT system (Leverage / Eye / Friction / Transferability). Produces a graded composition diagnostic with executable rewrite directives.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/01-lift-audit.md
```

## Usage

```
/satori-lift-audit [layout description, file path, screenshot, or URL]
```

## When to Use

- A layout is in draft and needs structural critique before delivery
- A live layout is underperforming and you need to diagnose why
- You're stress-testing a competitor's layout to learn from it
- You want defensible rationale for a redesign brief

## Output

A scored LIFT diagnostic:
- All four dimensions (L/I/F/T) scored 1-10 with anchor justifications
- Composite grade (A/B/C/D/F) with veto rule applied
- Per-dimension rewrite directives (executable element-level changes)
- Flip-test structural findings
- Recommended next workflow
