# /satori-movement-ladder

> Pick the right level of movement for the brief and produce executable directives. Most designers default to Level 1 when Levels 2-6 would serve better.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/02-movement-ladder.md
```

## Usage

```
/satori-movement-ladder [layout / brief description]
```

## When to Use

- Designing flow / journey for any layout from scratch
- A draft layout feels static or aimless
- A draft layout feels chaotic and you suspect competing flows
- Stuck between "do I add an arrow?" and "do I rely on hierarchy?"

## Output

Movement spec:
- Selected level (1-6) with explicit override reason if non-default
- Movement mechanics (origin → path → destination)
- Stacking strategy (if multi-level)
- Disruption budget enforced (≤1)
- Executable directives at element level
