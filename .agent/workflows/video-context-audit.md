# /video-context-audit

Audit an existing package under `extractions/video-context/<video-id>/`.

## Steps

1. Read `video-context-ledger.md`, `video-context-ledger.json`, `analysis.md`, and `uncertainty-report.md`.
2. List major spoken claims.
3. Check visual and OCR rows for support or contradiction.
4. Separate inference from observed evidence.
5. Produce a repair/reuse recommendation.
