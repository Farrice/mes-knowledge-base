# /content-bundle — Cross-Platform Content Bundler

Take one completed content piece and produce genuinely platform-native versions for multiple platforms. Not reformatting — real adaptation that sounds native to each platform.

## Usage

```
/content-bundle [path to finished content] --platforms LinkedIn,Newsletter,X
/content-bundle .tmp/atomize/linkedin-1-thesis.md --all
```

## Steps

### 1. Load Skills
Read these files:
1. `skills/kieran-flanagan-content-engine/SKILL.md`
2. `skills/kieran-flanagan-content-engine/genius.md`
3. `skills/kieran-flanagan-content-engine/workflows/04-content-bundle.md`

### 2. Execute Workflow
Follow the workflow in `04-content-bundle.md` using the loaded genius context.

### 3. Save Output
Save bundle to `.tmp/kieran-flanagan/bundle-[date]/` with one file per platform.
