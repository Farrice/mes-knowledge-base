# /adoption-unit

> A thin discovery alias for Rory Sutherland's canonical price-frame and metric-reframe engines.

## Quick Deploy

```text
Load: skills/rory-sutherland-marketing/genius.md
Execute: skills/rory-sutherland-marketing/workflows/price-frame-architect.md
Validate with: skills/rory-sutherland-marketing/workflows/perception-metric-reframe.md
```

## When to Use

- Buyers see technical specifications but cannot tell what operational behavior should change.
- An AI, software, service, or performance claim needs a “modern horsepower” translation.
- A price or capability is accurate but expressed in a unit the buyer does not use to decide.

## Input

- Offer or capability
- Audience and adoption behavior
- Original metric or specification
- Source values, formula, time window, and exclusions
- Current comparison set
- Desired decision

## Alias Boundary

This command creates no new methodology. It routes through Price Frame Architect and Perception Metric Reframe. The output must disclose its formula, source inputs, exclusions, confidence, and original total. If the evidence cannot support a unit, return a measurement plan rather than a fabricated number.

## Required Canonical Outputs

Return the Price Frame diagnosis plus:

1. a buyer-native unit receipt;
2. at least five honest re-expressions with calculations and evidence status;
3. a truth-preservation receipt that keeps the original total visible;
4. the adoption behavior the unit should change;
5. a one-variable validation test.
