# `/suzuki-platform-engine` - Platform Revenue Engine

## When To Use
- "Build a native Instagram (or other platform) funnel for this offer."
- Stand up a platform-native selling system, not a copy-paste of an X post.
- Adapt the funnel — not just the wording — to a new platform's behavior.

## Load
1. `skills/alex-suzuki-digital-product-revenue-os/SKILL.md`

## Execute
Run the Platform Revenue Engine for the chosen platform. Carry the mechanism (hook → proof → opt-in asset → DM → trust → checkout/application); rebuild the asset natively. Automation must be opt-in and within the platform's ToS.

## Usage
```text
/suzuki-platform-engine [platform] [product] [buyer] [price] [proof] [free asset]
```

## Required Output
- Native asset (finished)
- Opt-in + automation path (+ compliance note)
- Funnel map (to checkout or application)
- Intent routing (cold/warm/ready/wrong-fit)
- First-use + replay templates
- Proof/risk ledger
