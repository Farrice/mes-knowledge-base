# /andrew-lane-design-systems — Brand Direction Decision Spine

This restores the executable bridge for the already-registered Andrew Lane command. It is the specialist route for discovery-backed brand direction, not a replacement for `/build-bos` or a generic campaign moodboard.

## Steps

1. Read `skills/andrew-lane-design-systems/SKILL.md` and `skills/andrew-lane-design-systems/genius.md`.
2. Read `skills/andrew-lane-design-systems/references/brand-direction-decision-spine.md`.
3. If the business strategy is unsettled, run `skills/andrew-lane-design-systems/workflows/03-clarify-business-decisions.md` before visual exploration. Preserve settled decisions.
4. Run `skills/andrew-lane-design-systems/workflows/01-build-vibe-foundation.md` to produce evidence-backed design challenges, an internal exploration board, three client-ready direction boards, and the first proving-surface test.
   Compose `/mood-board` when actual visual-board construction, reference ledgers, or blind board comparison is needed; Andrew retains the parent decision and approval ledger.
5. Record the selected direction, rejected alternatives, borrowed qualities, proving-surface result, and unresolved taste calls in the Direction Decision Ledger.
6. Run the workflow quality gate. Label commercial impact and revision reduction `UNTESTED` until observed in a real approval cycle.

## Boundaries

- A complete six-layer Brand Operating System routes to `/build-bos`; Andrew Lane owns its direction-setting phase.
- Campaign, shoot, event, and non-brand reference boards route to `/mood-board`.
- `/mood-board` is a bounded visual-board component inside this spine, not a competing owner for discovery-backed brand direction.
- No public deployment, publishing, paid generation, or existing approval displacement without explicit permission.
