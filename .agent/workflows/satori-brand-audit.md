# /satori-brand-audit

> Comprehensive design audit across multiple touchpoints of a brand. Combines LIFT scoring, anti-AI-slop scanning, flip-testing, and memory-encoding evaluation into a single defensible report.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/14-brand-audit.md
```

## Usage

```
/satori-brand-audit [brand name + touchpoint inventory or URL list]
```

## When to Use

- Auditing your own brand (Farrice's brand, Parallax, my.bpm) for visual coherence
- Auditing a client's brand before pitching a redesign or refresh
- Auditing a competitor's brand to identify positioning opportunities
- Pre/post-launch design QA across a launch suite

## Output

Strategic Visual Brief:
- Executive summary (composite grades + top finding)
- Brand foundation documented (gaps flagged if present)
- Per-touchpoint scoring (≥4 touchpoints, all 5 layers each)
- Cross-touchpoint coherence audit (5 dimensions)
- Pattern analysis with root causes
- 3-7 strategic recommendations (impact-ordered, with sequencing + expected outcomes)
- Next-workflow routing per touchpoint
- Re-audit plan (30-60 days post-implementation)
