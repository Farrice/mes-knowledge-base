# Five-Input Content Gate

Run the Kallaway Five-Input quality gate on any content draft.

## Execution

1. Load and execute `skills/kallaway-audience-obsession/workflows/five-input-content-gate.md`
2. Score all 5 inputs, diagnose failures, execute rewrites
3. Deliver scorecard with composite verdict

## Required Inputs
- **Content draft**: The content to audit (paste or reference)
- **Target audience**: Who is this for?
- **Desired obsession level** (optional): Defaults to Level 2
