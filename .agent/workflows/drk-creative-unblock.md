# Dr. K × Pressfield × Cole — Creative Unblock Protocol

Three-expert creative emergency response: Dr. K diagnoses the root, Pressfield provides the war framework, Cole supplies the production architecture to ship.

## Why This Stack Works

Creative blocks have three possible roots: trauma (samskara), ego (Resistance), or systems (no production process). Most people try to fix one when it's actually the other. This stack diagnoses correctly, then deploys the right expert.

## Steps

1. **Load all three**:
   - `skills/dr-k-consciousness/genius.md`
   - `skills/steven-pressfield-narrative-physics/genius.md` (if available)
   - `skills/nicolas-cole-ghostwriting/genius.md`
2. **Phase 1 — TRIAGE (Dr. K)**:
   - Run samskara scan: Is this block connected to past trauma/failure?
   - Run guna check: Are you in tamas (paralysis) or rajas (busy-avoiding)?
   - Run identity audit: Is "I'm not a writer/creator" the operating identity?
3. **Phase 2 — RESISTANCE CHECK (Pressfield)**:
   - Is this The Resistance? Signs: fear of shipping, perfectionism, procrastination that targets ONLY creative work
   - Is this amateur vs. professional behavior? Which one are you choosing?
   - What would "turning pro" look like starting tomorrow morning?
4. **Phase 3 — DIAGNOSIS REPORT**:
   - **Root A: Samskara** → Dr. K dissolution protocol (process first, produce later)
   - **Root B: Resistance** → Pressfield's daily practice architecture (show up, sit down, work)
   - **Root C: No system** → Cole's production architecture (daily output frameworks)
   - **Root D: Multiple** → Sequenced deployment (process → practice → produce)
5. **Phase 4 — PRODUCTION PROTOCOL (Cole)**:
   - After clearing/overcoming → install daily production system
   - Define minimum viable creative session (time, word count, output type)
   - Build the "Ship It" habit using Cole's frameworks
6. Output: Creative Unblock Rx with root diagnosis, treatment sequence, and 7-day production plan
7. Run quality gate against all three expert rubrics
