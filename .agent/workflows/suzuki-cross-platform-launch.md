# `/suzuki-cross-platform-launch` - Platform Adapter

## When To Use
- Move an X post mechanism to another platform.
- Create Instagram, LinkedIn, Substack, email, Threads, or TikTok launch assets.
- Preserve the same funnel while changing the native format.

## Load
1. `skills/alex-suzuki-digital-product-revenue-os/SKILL.md`
2. `skills/alex-suzuki-digital-product-revenue-os/workflows/04-cross-platform-launch-adapter.md`

4. `skills/alex-suzuki-digital-product-revenue-os/references/revenue-mechanics.md`

## Execute
Run the Cross-Platform Launch Adapter. Preserve buyer readiness, value lane, purchase lane, first-use path, and replay plan while changing the native format.

## Usage
```text
/suzuki-cross-platform-launch [source post or product] [target platform] [buyer] [CTA path]
```

## Required Output
- Source mechanism
- Platform choice
- Adapted asset
- CTA and follow-up
- Intent routing
- First-use and replay
- Proof/risk notes
