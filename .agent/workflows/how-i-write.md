# How I Write — Master Writing Conductor

> **Invocation**: `/how-i-write` | `@how-i-write` | "run how-i-write"
> **Purpose**: Take an OBJECTIVE + FORMAT + RAW MATERIAL and produce a finished piece by composing the ten "How I Write" experts and the existing story-stack at the right altitudes, in the right order, with the lightest sufficient touch — then ship it through the truth/clamp/prose/fact gates.
> **Posture**: Same as `stanton-produce` and the Writing Depth Layer — this OS owns NO craft. It diagnoses, composes, sequences, and gates. It NEVER rebuilds a writer; every move is owned by a forged expert with a front-door command.

This is the **headline deliverable** of the How-I-Write OS: the executable front door. Inputs:

- **OBJECTIVE** — what the piece must do (move a reader, move a market, install a belief, make someone feel alive, convert).
- **FORMAT** — essay / founder-story / nonfiction / profile / Substack / thread / manifesto / VSL / brand-voice / social / contemplative / ghostwrite.
- **RAW MATERIAL** — the source: notes, a transcript, an existing draft, a research brief, a half-formed idea.

---

## Pre-Flight

1. **Load the OS spine**: read `skills/how-i-write-os/genius.md` — the **Altitude Stack** (Layers 0-7), the **Lane Map** (no collisions), and the **Composition Rules**. This is the conductor's only intelligence.
2. **Load the routing table**: read `skills/how-i-write-os/references/composition-map.md` — the intent → exact-stack decision tree (3-6 experts per intent + deliberate omissions).
3. **Hold the four laws** before composing anything:
   - **Compose existing engines — never rebuild.** If you start writing a hook formula or a restraint rule from scratch, stop — an expert owns it.
   - **Smallest sufficient stack — 3 to 6, never all 10.** A stack of 7+ means an adjacent lane was double-picked. Cut.
   - **One author owns the body voice.** Multi-author bodies homogenize the prose. The others advise from the wings; they do not co-write.
   - **Always end on the gate.** Layer 7 is mandatory: really-real (truth) + clamp-audit (no slack) + prose_classifier (no slop) + fact-verifier (if real claims).

---

## Step 1 — Diagnose (intent → smallest sufficient stack)

Classify the FORMAT into one of the twelve composition-map intents, then pick the named stack. State your reasoning out loud in three lines:

1. **Intent**: which composition-map row this is (essay / founder-story / high-stakes-nonfiction / profile / Substack / analytical-thread / manifesto / VSL / brand-voice / social / contemplative / ghostwrite).
2. **Stack (3-6, ordered by altitude)**: the experts the intent names — Layer 0 gate → architecture → ONE mid-layer → ONE voice-layer → (line) → (distribution) → Layer 7 gate. Pull this directly from `composition-map.md`; do not improvise a longer one.
3. **Body-voice owner — exactly ONE.** Name the single Layer-4 expert who will hold the pen for the entire body. This is the load-bearing decision. (Lesson: *"More experts ≠ better for voice"* — the Diandra Sandwich scored 4/10 disjointed; the single-author draft beat every multi-expert escalation. `feedback_diandra-hooks-only-separation.md`.)

Use the Lane Map to break any near-adjacent tie (Browder vs Orlean vs Wang vs Wright; Connelly vs Harding vs Ocean vs Shukman; Albom vs Shukman). Pick exactly one per altitude band. If your stack exceeds 6, you double-picked — cut.

**Existing-draft branch**: if the RAW MATERIAL is already a good draft, do NOT run the full stack. Route to `/depth-audit` (diagnose the 1-2 missing layers) → `/depth-inject` (one surgical move) and touch only those. Never rebuild what's already good (`feedback_multi-engine-rebuild-degrades-elevated-content.md`).

---

## Step 2 — Story gate (Runia, ALWAYS first if narrative)

If the piece is narrative (essay, founder-story, profile, most Substack/social), run the **Runia story-vs-topic gate**: `/runia-story-test`. Does a story actually exist here — **want → tension → change** — or is this just a topic dressed as one?

- **Pass** → proceed to Step 3.
- **Fail** → fix BEFORE drafting: dig a story with `/runia-tension-dig`, or, if no story is recoverable, re-route to a non-narrative engine (analytical → Wang; pure positioning → Lulu). Do not draft a "story" that has none.

For non-narrative intents (analytical thread, brand-voice, manifesto) run the gate as an **argument-as-story** check: is there a live tension worth resolving, or just a survey?

---

## Step 3 — Architecture (lock what the piece is about and why it grips)

Run the chosen high-altitude experts to lock the spine before any prose. Pick only the architecture layers the intent names — never all of them:

- **Theme / ending-first** — Hawley `/hawley-theme-engine`, `/hawley-ending-first`: why this exists and where it lands. (Multi-part work runs Hawley first.)
- **Premise / clamp / surprising-inevitable** — Stanton `/stanton-premise-sentence` (front door), `/stanton-spine`, `/stanton-surprising-inevitable`: distill the one-line premise (character + conflict + conclusion), build the spine, set the beat-to-beat pull. Stanton is the attention architecture under almost every piece.
- **Stakes / jeopardy** — Browder `/browder-stakes-architecture`, `/browder-drama-excavation`: when the material must grip AND survive scrutiny.
- **Structure-before-prose** — Orlean `/orlean-card-structure`: when the subject is overlooked and must be seduced into mattering.
- **Frame / friction** — Wang `/wang-friction-map`, `/wang-big-questions`: the gap between the stated story and the ground truth IS the analytical engine.
- **One human truth** (theme's emotional twin) — Albom `/albom-theme-first-engine`: when the piece must *move*, not impress.

Output of this step: the premise sentence + the destination + (if real-world) the stakes/structure/frame the body will be built on. Lock these before a word of body prose.

---

## Step 4 — Draft in ONE voice (the body-voice owner writes; others advise)

The single Layer-4 expert named in Step 1 writes the entire body. Choose by the Lane Map:

- **Connelly** `/connelly-rewrite` — economy + momentum + the one telling detail; the default for most commercial and content work.
- **Harding** `/harding-perception-engine` — lyric perception, luminous re-seen description.
- **Ocean** `/estrangement-engine` — defamiliarization; the explicit anti-slop voice layer.
- **Shukman** `/shukman-concrete-doorway` — contemplative presence + genuine wonder, total sincerity.
- **Albom** `/albom-theme-first-engine` — soulful emotional voice carrying one human truth.
- **Orlean** `/orlean-yarn-engine` — the seductive dinner-table telling.
- **Wang** `/wang-musical-pass` — literary analysis in a single coherent voice.

**The hard rule (cite it in the receipt):** multi-author bodies homogenize the prose into composite mush. The other experts in the stack **ADVISE** — they supply a move, a diagnosis, a single line — but they **do not take the pen.** One coherent author writes the body. (Sandwich test = 4/10 disjointed; single-author draft won — `feedback_diandra-hooks-only-separation.md`. Multi-engine rebuild degraded elevated content to 3/10 — `feedback_multi-engine-rebuild-degrades-elevated-content.md`.)

Never name an expert inside the prose. Moves are integrated invisibly; experts appear only in the receipt.

---

## Step 5 — Line + memorability (Ward, sparingly)

Fires only when a specific line has to be remembered, repeated, or land like a punch — the hook, the close, the kicker, the quotable thesis. Ward `/ward-rhetorical-engine` (front door: diagnoses, then deploys ONE device) — or the specific device front doors `/ward-saxon-punch`, `/ward-aphorism-forge`.

- Apply ONE classical device to ONE load-bearing line. **Never stack devices.** Rhetoric only on the line that carries the argument, never as ornament.
- Read it aloud. If it isn't a punch, it isn't done. Never break sense for sound.
- If no single line has to be remembered, **skip this step entirely.**

---

## Step 6 — Distribution (Lulu, optional)

Fires ONLY when the piece must move a market — launch, category creation, founder positioning, contrarian thesis, crisis. Lulu `/lulu-reality-architect` (the new operating truth), `/lulu-conviction-copy` (belief-installing frame), `/lulu-m3-matrix` (go-direct positioning), `/ward-tagline` or `/lulu-line-in-sand` (the headline / line in the sand).

- Lulu is the strategy + conviction spine; the craft experts write the assets *inside* it.
- **Skip for pure personal / literary / contemplative work** — there is no market to move.

---

## Step 7 — Gates (ALWAYS last, in order)

Every run ends here. A run without the gate is incomplete.

1. **Engagement** — Stanton clamp-audit `/stanton-clamp-audit`: walk the piece as a cold reader; mark every beat where attention would drop (the beach ball). "Polished but flat" is an unclamped draft, not a finished one. Re-clamp before continuing.
2. **Anti-slop (deterministic)** — run `python3 execution/prose_classifier.py check <file>` if the piece is on disk (the classifier exists at `execution/prose_classifier.py`). Fix every flagged AI tell. If the piece isn't yet on a file, run the banned-MOVES check by eye against `directives/ai-slop-ban-bank.md` and write to a temp file to classify.
3. **Truth pass** — `/really-real-writing` (or `/really-real-social` for short-form, `/really-real-marketing` for copy, `/really-real-ending` for the close): truth / compassion / reader-trust. Apply one concrete repair — a cut overproof line, a plainer hard sentence, a restraint beat, a reader-trust fix.
4. **Fact-verifier** — if the piece contains claims about real people / events / dates, statistics, technical facts, market claims, or source attributions, run `verify` (and `/wright-truth-audit` for high-stakes investigative). Label VERIFIED / LIKELY / UNCONFIRMED per the Verification protocol. Does NOT fire for pure creative/personal voice. For VSL/converting copy this is a HARD honesty-spine gate.

If any gate fails, fix the weakest layer and re-run that gate before output.

Return the **finished piece** plus a **RECEIPT** mapping each move to the expert that produced it. The receipt is how the OS stays honest — it proves the composition was deliberate and shows exactly which expert touched what.

  - Step 3 arch     → Hawley /hawley-theme-engine → <theme + ending locked>
  - Step 3 arch     → Stanton /stanton-premise-sentence → <the one-line premise + spine>

  - Step 4 voice    → <body-voice owner> → <the voice/scene fingerprint>   [advisors: <names + the single move each contributed>]
  - Step 5 line     → Ward /ward-rhetorical-engine → <the one device on the one line>   [or "skipped — no line had to be remembered"]

## When NOT to use

Route to the specific expert directly — do NOT spin up the whole conductor — when the ask is a **single tactic**:

- "Make this line land / give me a punchy close" → `/ward-saxon-punch` or `/ward-rhetorical-engine`.
- "Is there a story here?" / "this feels like a topic" → `/runia-story-test`.
- "Tighten / cut the slack from this" → `/stanton-clamp-audit` or `/connelly-rewrite`.
- "Refine this existing good draft" → `/depth-audit` → `/depth-inject` (diagnose-then-treat, not full stack).
- "Polish this drafted LinkedIn post" → `/writers-room` (it owns draft → publication-ready).
- "Run an actual Parallax edition" → `/parallax` (owns the edition pipeline; this OS supplies craft *inside* it).
- "Daily LinkedIn production" → `/linkedin-daily` or `/diandra-content-engine`; "LinkedIn from scratch" → `/ghostwrite` (Lara/Cole).
- "Write the converting body copy" → `/copy-engine` (owns converting copy; the OS supplies narrative + rhetoric + conviction around it).
- "Ghostwrite in a client's voice" → the single voice expert via `/ghostwrite`; never a multi-expert composite body.
- Pure system / non-deliverable asks → no chain, no conductor.

The conductor earns its overhead only when the piece needs **composition across altitudes** (architecture + voice + line/distribution + gates). For one move, call the one expert.

## Anti-Patterns

- **Don't run all ten.** A stack over 6 means a lane was double-picked — consult the Lane Map and cut to one expert per altitude band.
- **Don't let the stack homogenize the voice.** Exactly one author owns the body; the rest advise. A tight three with one heartbeat beats a six that turns to mush.
- **Don't rebuild what's already good.** If the RAW MATERIAL is an elevated draft, diagnose the missing 1-2 layers and touch only those (`/depth-audit` → `/depth-inject`). The felt verdict beats any gate score.
- **Don't invert the altitude order.** Architecture before scene before line before truth. Gorgeous sentences with no spine is the failure mode of skipping Step 3.
- **Don't skip the gate.** Layer 7 (clamp + prose + really-real + verify-if-claims) is mandatory on every run.
- **Don't name-drop experts in the prose.** Moves are invisible; experts live only in the receipt.
- **Don't rebuild a production engine.** copy-engine owns converting copy, parallax owns editions, linkedin-daily owns daily cadence, ghostwrite owns the Lara/Cole pipeline. The OS supplies craft layers *inside* them — never a from-scratch replacement.
