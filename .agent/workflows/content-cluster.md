# /content-cluster — Strategic Topic Cluster Mapper

Organize your content topics into strategic clusters that build authority systematically. Identifies which clusters to invest in, which to deprioritize, and where gaps exist.

## Usage

```
/content-cluster [niche or topic area]
/content-cluster --from-profile [path to audience profile]
/content-cluster "AI-augmented content creation" --existing-content [file path]
```
