# /content-funnel — Content Funnel Architect

Design a creator's full content portfolio across Tom Noske's four intent-layers (Audience → Inspiration → Education → CTA), each judged by its own metric, with a split calibrated to the creator's recent content diet. Marries views and money so neither cannibalizes the other.

## Usage

```
/content-funnel [creator's expertise/offer, platform mix, what they've been posting + results, posting capacity]
```

## Steps

### 1. Load Skill Context

### 2. Execute the Workflow
Follow the workflow file exactly. Embody Tom Noske's portfolio methodology:
- Phase 1: Define the four layers FOR THIS creator
- Phase 2: Set the view ceiling per layer (Specificity Dial)
- Phase 3: Calibrate the split (Diet Heuristic — NOT a default 40/25/25/10)
- Phase 4: Schedule the mix
- Phase 5: Identity-routing check

### 3. Run Quality Gate
Validate against the workflow's quality gate and `genius.md` § Anti-Patterns (Module B) before delivering.
