# /satori-color

> Turn "what color should this be?" into a defensible decision. Walk the 5 layers of color meaning, make an explicit fit-in-vs-stand-out call, and output 4 role-assigned colors with hex + one-sentence job + WCAG-checked pairs — a palette you can paste straight into a DESIGN.md tokens block.

## Quick Deploy

```
Load: skills/satori-graphics/genius.md
Execute: skills/satori-graphics/workflows/17-strategic-color.md
```

## Usage

```
/satori-color [brand one-sentence brief + industry + audience/markets + primary goal]
```

## When to Use

- Starting a brand, product, or campaign and the palette must come *from strategy*, not "what looks nice"
- A DESIGN.md, Brand OS, or UI build needs color tokens locked with rationale + accessibility
- An existing palette "feels off" and you need to diagnose *which of the 5 layers* it failed
- Deciding whether to blend into a category or break from it — a positioning-level color call

## Output

A strategic color system:
- The 4 locked inputs (brief · category · audience+markets · primary goal)
- A 5-layer decision log (Functional → Cultural → Emotional → …), one decision per layer
- An explicit fit-in-vs-stand-out positioning call
- 4 role-assigned colors: hex + one-sentence job + WCAG contrast note per pair
- A tokens block ready to paste into DESIGN.md
