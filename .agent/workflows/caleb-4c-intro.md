# /caleb-4c-intro — 4C Intro Content Architect

Build a 15-30 second video intro that compresses your full brand positioning into a cold-audience hook using Caleb Ralston's 4C's Framework.

## Steps

### 1. Load Skills
Read these files:
1. `skills/caleb-ralston-personal-brand/genius.md`
2. `skills/caleb-ralston-personal-brand/workflows/4c-intro-content-architect.md`

### 2. Execute Workflow
Follow the workflow. Requires:
- User's niche, credibility bank, and topic
- Target platform (YouTube, Instagram, etc.)
- Content concept (problem + solution pair)

### 3. Deliver
- Complete 4C intro script (Callout → Credibility → Compass → Core Learning)
- Gift/Wrapping Paper separation
- Content body structure with environmental suggestions
- 3 intro variants

### 4. Quality Gate
All 4 C's present. Credibility specific not generic. Core learning in first 30 seconds. Wrapping paper (personality, environment) clearly separated from gift (expertise).
