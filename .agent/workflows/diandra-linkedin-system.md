Use ledger timestamps when quoting or attributing source claims. Keep observed spoken evidence separate from inferred synthesis.

### 2. Profile And SEO Foundation

Run the profile as a landing-page audit:

- Banner: does it re-hook and pull attention down the page?
- Headline: does it say problem, ICP, and searchable category language?
- About: problem, solution, proof, CTA.
- Services: exact buyer-language terms.
- Featured: owned channel, lead magnet, booking path, or exceptional proof.
- CTA button: one action, not a generic homepage.
- Supporting details: alt text and upload file names for documents/carousels.

Related workflow: `/diandra-headline-engineer`. Use `/profile-conversion` only as a supporting profile-conversion reference, not the owner of this system.

### 3. 72-Hour Landscape Study

Use `skills/diandra-escobar-linkedin-growth/workflows/12-outlier-study-and-remix.md`.

Build an outlier study table:

| Account | ICP Fit | Topics | Hook Patterns | Formats | Endings | Outlier Notes | Rebuild Opportunity |
|---|---|---|---|---|---|---|---|

Rule: steal formats, hooks, design structures, and endings; do not copy ideas.

### 4. Content Architecture

Use `skills/diandra-escobar-linkedin-growth/workflows/06-content-strategy-architect.md`.

Default bucket mix:

| Bucket | Monthly Share | Job | Primary Signal |
|---|---:|---|---|
| Growth | 40% | Reach new people | Shares, comments, profile clicks |
| Authority | 30% | Prove expertise | Saves, smart comments |
| Conversion | 20% | Create pipeline | DMs, calls, link clicks |
| Personal | 10% | Make the expert memorable | Emotional comments, connection requests |

Use 35/35/20/10 only when the account already has reach but needs more trust-building.

### 5. Content Execution

Route by task:

- Growth entity post: `/diandra-growth-sprint`
- Daily topic-to-post: `/diandra-content-engine`
- Universal hook format, rehooking, brand/news/name/trend hook generation: `/attention-hijack-hooks`
- Save-worthy authority post: `/diandra-save-architect`
- First 50-word semantic audit: `/diandra-first-50`
- Semantic lanes: `/diandra-semantic-lanes`
- Full diagnostic: `/diandra-algorithm-audit`

The orchestrator should name the selected route and why it was selected.

### 6. Comment Flywheel

Use `skills/diandra-escobar-linkedin-growth/workflows/10-engagement-layer-builder.md`.

Create an engagement list with:

| Category | Name | ICP Overlap | Recent-Activity URL | Comment Angle | Cadence |
|---|---|---:|---|---|---|

Rules:

- Use recent-activity URLs, not profile URLs.
- Spend 30 minutes/day commenting before opening drafts in the first 90 days.
- Good comments add a new angle, respectfully challenge, or tell a quick story.
- Reply to every comment on owned posts in the first hour.

### 7. 90-Day Review

Use the content-market fit timeline:

- Posts 1-20: practice, hook tests, format reps.
- Posts 21-40: voice, community, repeatable audience signal.
- Posts 41+: momentum and content-market fit.

Review signals:

- Which bucket produced profile clicks?
- Which authority posts earned saves?
- Which conversion posts created DMs or calls?
- Which comments drove profile views or relationships?
- Which topic lanes are becoming obvious to the audience?

### 8. Rule-of-100 Operating Loop

For zero-to-scale or full-client-system requests, run workflow 23 after the profile and semantic foundation:

- Initialize and validate one account workspace with `execution/linkedin_growth_os.py`.
- Add and score 20 sourced ideas every two weeks.
- Preserve the body-first production line; use the Ben Meer hook families only when their claims are true.
- Keep peer draft feedback separate from public engagement and forbid coordinated engagement.
- Review after every 10 posts and retain the top 10 patterns after every 100 posts.
- Record leads and attributed revenue alongside reach so follower growth does not become the sole success test.

## Human Checkpoints

Pause for user approval before:

- Rewriting a real public LinkedIn profile.

- Contacting, commenting, posting, or scraping private account data.

Do not pause for a local operating plan, local audit, or internal command routing recommendation.

## Quality Gate

Reject or revise the output if it:

- Starts with posting before profile and SEO setup.
- Treats the video as visually observed when only transcript evidence exists.
- Skips `/attention-hijack-hooks` when the actual bottleneck is hook format, first-window fit, or rehooking.
- Routes a whole-system request to `/publishable-copy-gate` first.
- Collapses all four buckets into one generic content calendar.
- Uses profile URLs in the engagement list instead of recent-activity URLs.
- Lacks week-by-week validation.
