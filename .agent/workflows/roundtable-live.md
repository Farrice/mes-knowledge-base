# `/roundtable-live` — Live Council (The Mailroom)

Real agent-to-agent deliberation: seated personas are **named teammates** who DM each other via
SendMessage, share the Commons blackboard, and meet under the manager protocol. This is the live
counterpart to the frozen `/convene` engine — reply-to-reply instead of frozen-snapshot.

> **Protocol canon:** `directives/agent-mailroom.md` (binding). **Briefs:** generated by
> `execution/persona_team.py` — never hand-written. **Why a runbook, not a .workflow.js:**
> Workflow-engine `agent()` calls cannot message each other; only conductor-spawned named
> teammates can. The conductor (main loop) IS the meeting manager.
>
> **Cost posture:** deliberate invocation only — taste-bearing forks and real disagreements.
> 4 seats default, 6 max. Frozen mode (`/convene`, `/roundtable`) remains the cheap default.

## Steps

### 1. Cast

```bash
python3 execution/persona_team.py "<question>" --mode tight
```

Returns `{members[], commons_path}` — each member has `slug` (teammate name) and `brief`
(voice excerpt + private memory + Mailroom protocol + peer roster, fully assembled).
Present the panel to Farrice in one line each; swap seats on his word. Research-grounding gate
from `/roundtable` Step 2.5 applies when the question leans on external facts: run the grounding
queries FIRST and inject results into each brief under `## GROUNDING DATA`.

### 2. Open the Commons

Create `commons_path` with a header: question, date, seated members. Personas append under their
own `### <Name>` headings; append-only; conductor snapshots it at close.

### 3. Spawn the team

One message, parallel Agent calls — each seat spawned with `name: <slug>`, `prompt: <brief>`,
run_in_background. **Seating law:** explicit model per dispatch — `sonnet` for grunt seats,
`opus` for heavy/taste seats; never unseated. Diverge is built into each brief's FIRST MOVE:
independent opening take before reading the Commons (no anchoring).

### 4. Collect openings, then run the meeting

When opening takes land, the conductor becomes the **manager**:

1. Post the round to every seat via SendMessage: the takes digest (one line per member), the live
   disagreements you see, and the instruction — *contribute (BUILD / CHALLENGE / CROSS-POLLINATE,
   DM peers directly for point-to-point disputes) or reply exactly `PASS`.*
2. Members DM each other (`[NORMAL]`/`[PRIORITY]`/`[URGENT]` tiers) and answer challenges —
   this is the reply-to-reply layer the frozen engine cannot do. Let exchanges run; don't relay
   what they can say peer-to-peer.
3. Close the round when every member has contributed or passed. **Max 3 rounds; a full-pass round
   ends the meeting immediately.** Relay any input from Farrice as `[URGENT]`.

### 5. Converge

Conductor synthesizes with the frozen engine's schema — `{crux, net_new_principle, forks,
synthesis_direction}` — plus the Mailroom's `{next_steps, dissent_log}`. Preserve disagreement;
blending is failure. Echo-chamber check from `/roundtable` Step 6 applies.

### 6. Close the session (identity accumulates)

1. Digest → `knowledge/council-sessions/<date>-<slug>.md`: synthesis, dissent log, Commons
   snapshot, and **measured cost** (agents spawned, rounds run, token totals from the session).
2. Wake the memory:
   ```bash
   python3 execution/persona_team.py close-session --members "<slug,slug,...>" \
     --question "<q>" --verdict "<one line>" --session "<digest path>" \
     --positions '{"<slug>": "<position>"}'
   ```
3. Standing council? Append the verdict line to `councils/<name>/decisions.md`; close any
   `councils/buyers/calibration.jsonl` rows whose outcome is now known.
4. First live run ever: flip the Tier-2 activation tracker in `directives/parallelism-cheat-sheet.md`.
5. Report to Farrice: synthesis + forks + **measured tokens vs the ~150k frozen baseline**. After
   3 live runs, surface the cost comparison for his keep/widen/kill call.
