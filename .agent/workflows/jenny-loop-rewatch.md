# /jenny-loop-rewatch

An engineered back-half for a short — loop-ending design, rewatch-and-share levers, and an answer-as-last-word close with acknowledgment-driven CTA.

## Trigger
`/jenny-loop-rewatch`

## Workflow
`skills/jenny-hoyos-shorts/workflows/06-loop-rewatch-engineer.md`

## Quick Use
Provide:
1. The finished or drafted short (hook, beats, payoff/answer)
2. The opening question the video promised to answer
3. Format (challenge/recipe-or-hack/listicle/reaction/talking-head)
4. CTA goal (optional) + content type

## Output
Loop verdict (seamless-loop / second-question-plant / cold-open-fallback), rewatch and share levers, close script with acknowledgment CTA, and the retention target for the length.

## Stacks With
→ `/jenny-script-short` (installs into Phase 2's Lasting Payoff beat)
→ `/jenny-retention` (prescribed fix when retention is stuck flat at 100%)
