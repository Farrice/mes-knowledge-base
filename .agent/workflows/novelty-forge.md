# /novelty-forge

Take ANY topic — especially boring, old, or saturated — and run all five Illusion-of-Novelty components into a finished, fully-engineered asset.

## Trigger
`/novelty-forge`

## Workflow
`skills/kallaway-illusion-of-novelty/workflows/novelty-forge.md`

## Quick Use
Provide:
1. Topic (even the dullest one)
2. Asset type / platform (video, LinkedIn, email, ad, sales page, thread, long-form…)
3. Avatar (their held belief + the outcome they want) — if unknown, the workflow runs a 2-question mini-canvass

## Output
Finished asset for the requested format + a component map (which line does which job: new reveal, outcome, contrast, urgency-or-skip, bullseye proof, protected delivery).

## Stacks With
→ `/novelty-to-addictive` (engineer retention after attention is captured)
→ `/novelty-campaign` (scale the angle across platforms)
→ `/novelty-pattern` (calibrate against your own data)
