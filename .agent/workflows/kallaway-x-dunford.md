# /kallaway-x-dunford

Read and execute the workflow at `skills/kallaway-illusion-of-novelty/workflows/kallaway-x-dunford.md` — Dunford supplies the true claim per component, Kallaway passes only the expression, saturation-checked against the category's stock phrases.

Load before execution:
- `skills/kallaway-illusion-of-novelty/genius.md` — 5-component novelty engine
- `skills/april-dunford-positioning/genius.md` — the 5-Component positioning system, Anti-Category-Creation Default

## Usage
```
/kallaway-x-dunford [finished Dunford positioning + category stock phrases + avatar held belief]
```

## When to use
- Positioning is factually sound but reads like every other player's deck — "clean," "data-driven," "results-driven" doing the work
- Dunford's build is done; the deliverable stalls on delivery, not truth
- Team keeps reaching for the same category adjectives with no one sure if the underlying claim actually differs

## Not This
Novelty here never changes what is claimed, only how it lands. Truth-bending (a claim strengthened, a proof rung promoted, urgency invented) is an instant kill. Full positioning build from scratch → Dunford's Tier 1 front doors (`dunford-positioning-diagnostic`, `product-positioning-blueprint`). Premise validation (is this even the right category/differentiator) → `/godin-handshake-dunford`, run before this crossing.

## Stacking
- Upstream: `dunford-positioning-diagnostic` / `product-positioning-blueprint` (truth spine), `/godin-handshake-dunford` (premise gate)
- Downstream: `dunford-positioning-to-copy` (hands the novelty-passed frame to production copy)
- Adjacent: `/novelty-audit` — this crossing specializes it for positioning claims with a truth-bend gate
