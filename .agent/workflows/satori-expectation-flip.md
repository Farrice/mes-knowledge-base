# /satori-expectation-flip

> Psychology, emotion, and concept contrast: subvert ONE learned association on purpose. The teal skull in playful uplifting color lodges precisely because it violates the symbol. One flip, against a straight field, serving the message — never cleverness for its own sake.


## Usage

```
/satori-expectation-flip [design/brief + audience + the message the flip must carry]
```

## When to Use

- Memorability is the brief's explicit job (campaigns, brand moments, scroll-stoppers)
- A design is competent but forgettable — nothing lodges
- Category conventions are so uniform that obeying them guarantees invisibility
- Emotional briefs where information alone won't move anyone

## Output

An Expectation-Flip Spec: the evidenced norm, ONE inversion (psychology/emotion/concept axis), three service-gate verdicts (serves message / transmits without narration / audience+cultural gate), the straight-field inventory, and execution directives — or a logged no-flip decision (a valid pass).
