# AI Prompt Frameworks & Formulas

When generating prompts for specific AI tools, use these proven frameworks:

## The Nano Banana Pro Framework (Higgsfield/Video)
The "Logical Anchor" system for cinematic video generation:
1. **Subject:** The core focus (e.g., "A cyberpunk samurai").
2. **Action:** What the subject is doing (e.g., "unsheathing a glowing katana").
3. **Environment:** The setting (e.g., "in a neon-lit, rain-slicked alleyway").
4. **Camera/Lens:** The technical specs (e.g., "shot on 35mm anamorphic lens, f/1.8").
5. **Lighting:** The illumination (e.g., "low-key lighting, neon rim light").
6. **Motion/Pacing:** The camera movement (e.g., "slow tracking shot, cinematic pacing").

## The Kittl AI Framework (Graphic Design)
The "Building Block" system for vector and raster design:
1. **Style Keyword:** The overarching aesthetic (e.g., "Y2K acid graphic").
2. **Subject/Motif:** The central element (e.g., "a melting smiley face").
3. **Color Palette:** Specific hex codes or color names (e.g., "neon green and chrome").
4. **Texture/Finish:** The surface quality (e.g., "halftone dot pattern, distressed edges").
5. **Typography Hint:** (If applicable) The font style (e.g., "bold, distorted sans-serif").

## The Midjourney v6 Framework (Photography/Art)
The "Parameter-Heavy" system for high-fidelity images:
1. **Medium:** The format (e.g., "Editorial fashion photography").
2. **Subject Details:** Highly specific descriptions (e.g., "a model wearing an oversized, deconstructed trench coat").
3. **Lighting/Environment:** (e.g., "studio lighting, seamless white backdrop").
4. **Camera Specs:** (e.g., "shot on medium format, Kodak Portra 400").
5. **Parameters:** (e.g., "--ar 4:5 --style raw --v 6.0").
