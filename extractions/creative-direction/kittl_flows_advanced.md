# Kittl Flows & Advanced Features Research

## Kittl Flows — The AI Pipeline Feature
Kittl Flows is Kittl's node-based AI pipeline. You connect Smartboards (now called AI Image Boards) into a sequence so each step transforms your design.

### Core Concept:
- Start from a sketch, icon, or finished design
- Generate multiple variations with a single click
- Chain those into poster → T-shirt → menu → social graphic
- Keep iterating without redrawing from scratch

### Smartboard Chains:
- Each Smartboard is a "node" in the pipeline
- You attach Smartboards to artboards
- Each Smartboard can use a different model (Nano Banana, Flux Pro, etc.)
- Output of one Smartboard feeds into the next
- Simple one-line prompts transform the design at each stage

### Example Blueprint Pipeline:
1. Import product image → Artboard
2. Smartboard 1 (Nano Banana): "Convert this into hand-drawn outlines, no color"
3. Smartboard 2: "Make the color white chalk and the background blue"
4. Smartboard 3: "Change the angle to side view"
5. Smartboard 4: "Show front grille only" (close-up detail)
6. Arrange all outputs in template → Export

### Key Capabilities:
- Design → Mockup → Video (full pipeline on one canvas)
- Sketch → Full Design (Image Boards transform rough sketches)
- Single Design → Multiple Variations (color, style, angle)
- Design Sets at Scale (icon packs, illustration sets, mockups)
