## 4 Building Blocks of a Good Prompt (Official Kittl Guide)

### 1. Set the Scene (5 Ws)
- WHO: Define the subject clearly
- WHAT: What's happening (action)
- WHERE: Location with detail
- WHEN: Time of day, season
- WHY: Mood/purpose of the image

### 2. Add Details with Adjectives
- Colors, mood, background elements
- Lighting (bright sunny, dramatic evening)
- Quality, pose
- Balance: more detail = more unique, but don't overload

### 3. Define Output Style and Format
- Specify: "vector image", "digital artwork", "hand-drawn illustration"
- Add quality: "high resolution", "4K", "photo-realistic"
- Match preset style with written prompt (don't conflict)
- Can specify sub-styles: e.g., "kodomomuke" anime style

### 4. Incorporate "Don't" and Negatives
- "No people", "no birds" — exclude unwanted elements
- Powerful for complex scenes
- Saves time on re-prompts

## Key Tips from Kittl

- Include descriptive imagery in each of the 5 Ws
