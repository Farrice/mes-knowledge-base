# Jordan Crawford GTM Intelligence OS : Architecture

## Architectural verdict

Build one connected skill system, not a mega-skill and not a plugin yet. Jordan Crawford is the function owner. Ten workflows implement the causal loop; existing positioning, offer, copy, and RevOps experts enter only through explicit handoffs.

## Causal spine

```text
Evidence -> Dossier -> Problem-qualified segment -> Target universe
        -> Personally valuable proposition -> Message-market-fit test
        -> Outcome evidence -> Dossier update
```

## Component map

### Tier 1 : Foundation

1. `customer-truth-dossier` : creates the durable evidence base.
2. `zero-data-discovery` : creates a first evidence base without pretending proprietary data exists.
3. `problem-qualified-segment` : resolves worst-version problem and concentric fit.

### Tier 2 : Practitioner

4. `target-universe-high-dmi` : converts problem evidence into an enumerable market and disqualification logic.
5. `cost-per-right-answer` : routes research through deterministic, model, and human methods by error-adjusted cost.
6. `personally-valuable-proposition` : translates information asymmetry into independently useful recipient value.

### Tier 3 : Stacking and operation

7. `message-market-fit-test` : creates a bounded test with qualification, 10x, language, and proof counters.
8. `compounding-gtm-unit` : turns a validated step into a reusable input/output/evaluation/review unit.
9. `positioning-offer-copy-handoff` : transfers evidence without allowing downstream experts to rewrite source truth.
10. `gtm-learning-loop` : reconciles response and outcome evidence into the next dossier version.

## Orchestration rules

- The front door diagnoses the current truth state and starts at the earliest missing layer.
- It never preloads all workflows. Each step receives paths plus a compact handoff.
- The dossier is append/reconcile, not overwrite.
- Discovery and judgment remain separate operations.
- Missing data yields `UNKNOWN` or a discovery route, never synthetic confidence.
- Any external send, CRM write, paid API, enrichment purchase, or autonomous action remains approval-gated.
- Positioning, offer, and copy specialists can transform the interpretation layer; they cannot silently alter source evidence.

## Human checkpoints

The user approved uninterrupted local construction and testing. Runtime checkpoints remain at:

1. external or paid data acquisition;
2. public/client-facing claims with unresolved evidence;
3. outreach, publishing, or CRM writes;
4. promotion from tested local system to plugin or global mirror.

## Result surfaces

- Native readable strategy artifacts for dossiers, universes, PVPs, tests, and learning reviews.
- Machine-readable tables inside those artifacts for provenance and handoffs.
- Ten born-v2 execution prompts for deterministic cold starts.
- One expert front door plus generated command bridges.

## Proof design

- **Mature-company fixture:** conflicting customer sources must produce a reconciled dossier, not a blended summary.
- **Zero-data fixture:** a founder with no customers must receive a discovery plan and stop rule, not a fabricated ICP.
- **Cold-start proof:** a future agent must locate the source evidence, select the correct workflow, produce the required artifact, and name the next gate without chat history.
- **Blind embodiment proof:** generated outputs are compared against the corpus for recognizable mechanics; self-judged work cannot exceed B-tier.

## Parked

- Plugin packaging and global mirrors.
- Automatic enrichment purchases or paid-source ingestion.
- Autonomous outreach or CRM mutation.
- Claims that Jordan is objectively the world's highest-ranked GTM specialist.
