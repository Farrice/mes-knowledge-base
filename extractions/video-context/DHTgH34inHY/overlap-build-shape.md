# Overlap and Build-Shape Decision

## Verdict

**EXTEND `seth-godin-philosophy` WITH ONE WORKFLOW.** Do not create another expert, skill, agent, primitive, or global behavior layer.

## Existing Owners Preserved

| Existing owner | What it already owns | Boundary retained |
|---|---|---|
| `seth-godin-philosophy` | SVA, strategic clarity, resistance, reversible experiments, shipping, qualified feedback | Primary owner of the new practice |
| `seth-godin-brand` | Public brand promise, consistency, trust, AI permission | Consult only when the artifact changes a public promise or customer-facing AI boundary |
| `seth-godin-marketing-mind` | Premise interrogation and Godin-style live reasoning | Remains owner of broad strategic questions |
| `seth-godin-ideavirus` | Propagation, network effects, sneezer strategy | Loads only after a proven artifact needs spread architecture |
| Systems-thinking overlay | One-level system diagnosis, craft ownership, human accountability | Cold and on-demand only during System Gap Map diagnosis |
| Existing Ship It / Problem-to-Action workflows | Release discipline and reversible experiments | Reused instead of copied |

## Net-New Capability

The source uniquely composes six moves into one executable practice:

1. lock the desired change and consequential judgment to a human owner;
2. locate an underserved gap in a system;
3. specify a public artifact the human would be proud to own;
4. delegate bounded tasks, never the project objective;
5. run three capped, inexpensive experiments;
6. use observed traction to stop, iterate, scale, or kill.

No current Godin workflow makes that complete sequence the output. That composition—not generic AI advice—is the justified extension.

## Rejected Build Shapes

- **New Seth Godin skill:** rejected as duplicate ownership.
- **New agent:** rejected; the existing `seth-godin` agent already owns the domain.
- **Semantic primitive or Operator Core rule:** rejected; zero production receipts exist.
- **Global mirror:** rejected; local proof must precede promotion.
- **Commercial offer or external publication:** outside the approved boundary.

## Context Policy

- **Hot:** workflow contract, two execution prompts, compact source pointer.
- **On demand:** systems-thinking overlay during gap diagnosis; `seth-godin-brand` when a public promise changes; Ship It/Problem-to-Action for release and experiment support.
- **Cold:** full transcript, complete ledger, unrelated Godin skills, external anecdotes, and visual frames.
