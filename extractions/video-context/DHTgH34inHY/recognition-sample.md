# A project is not a task

AI can clear your desk.

It can sort the sources, compare the drafts and find the missing fields.

That does not make it the owner.

The project is the change you chose to make for someone specific. It includes the promise, the judgment and the risk of putting your name on the result.

Keep those.

Give the machine work you can inspect. Make one useful thing for the smallest group that needs it. Let them use it. Notice whether they return.

If the project is a claim-safe brief, the machine can inventory the sources and flag the missing citations. It cannot decide which promise your brand should make. It cannot sign the review.

If they do, make the next version.

If they don't, you bought an inexpensive lesson.

Either way, the project is still yours.
