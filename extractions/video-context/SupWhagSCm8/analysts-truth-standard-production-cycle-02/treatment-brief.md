# Activation Decision: Bounded Output-Surface Selection

Status: activate the clear cases and observe the mixed cases.

Native owner: System Audit and the existing Artifact Comprehension contract.
The Analyst's Truth Standard changes only the activation decision.

## Decision

Activate the one-primary-surface rule for clear consumption jobs.

| Consumption job | Primary surface |
|---|---|
| Finished reusable prose | Writing block |
| Durable substantial knowledge | Native Codex artifact |
| Calculation where real data carries the meaning | Spreadsheet |
| Presentation-shaped story | Slides |
| Changing operational state | Briefing Room |
| Visual form, mood, or space | Generated visual |

Mixed or ambiguous jobs default to the smallest surface that completes the
primary job. A second representation is allowed only when it performs a
different job. Tiny answers remain ordinary conversation. No new question is
added unless the surface choice would change what gets built.

## Evidence And Limits

The frozen source reports a behavior pass, 8/8 representation fixtures, 13/13
sabotage cases caught, 8/8 surface-selection fixtures, and 6/6 overuse cases
caught. The related shadow-pilot receipt records a completed human gate and
preserves ordinary replies, closeouts, and Clear Depth.

That evidence supports bounded activation of the clear cases. It does not prove
that every mixed artifact will be routed correctly. Fixture overfitting and
extra presentation overhead remain plausible failure modes.

## What Changes

The baseline says Codex should quietly choose a surface but leaves the whole
policy in SHADOW. This decision activates the unambiguous mappings, keeps mixed
cases under observation, and names the safe fallback. It converts a broad
design preference into a bounded operating rule with a rollback condition.

## Cold-Start Test

After merge, test an email, a numeric table, a one-fact explanation, and a mixed
research-and-action brief. Their expected primary surfaces are, respectively,
writing block, spreadsheet, conversation, and one durable artifact. The mixed
case may add a secondary surface only for a separate use.

Reverse the activation if any clear case chooses the wrong primary surface, a
tiny answer gains ceremony, or a mixed case produces duplicate deliverables.
