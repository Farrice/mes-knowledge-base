# Label-Blinded Comparison — Production Cycle 02

This is a label-blinded structural comparison using the declared production
rubric. It is not an independent human preference panel.

## Variant A

Codex should quietly choose one primary output surface based on how the work
will be consumed. A second representation should perform a different job. The
system remains in workspace SHADOW with structural and behavior passes.

## Variant B

Activate the six unambiguous surface mappings. Keep mixed cases under
observation, default them to the smallest surface that completes the primary
job, and preserve ordinary conversation for tiny answers. Reverse activation
if a clear case misroutes, a tiny answer gains ceremony, or a mixed case creates
duplicate deliverables.
