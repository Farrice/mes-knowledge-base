# Hardening Contract: Six-Domain Blind Story Deployment

## Objective

Build a source-traceable, held-out reference corpus from six real briefs; run artifact-only blind replays; and convert every observed failure into a permanent regression fixture without adding a route, expert, domain adapter, or narrative decision.

## Preservation Lock

- **Keep:** the decision-first order; `FULL STORY | STORY FRAGMENT | NO STORY`; one body-writing owner; cold `genius.md` until routing; Story Compass only after `FULL STORY`; evidence-first behavior in high-risk domains; explicit no-story success.
- **Change:** add held-out reference cases, blind replay evidence, and minimal regression language only when a replay exposes a concrete failure.
- **Do not disturb:** the six current production workflows, command name, truth invariant, adjacent-field handoff boundary, existing source ledger, global skill mirrors, external systems, or market claims.
- **Risk:** reference leakage, self-grading, stylistic overfitting, treating a polished output as factual proof, or solving a weak case by expanding router scope.
- **Gate:** references are written and sealed before replay; workers receive only shipped skill artifacts plus one normalized brief; every fail becomes a named fixture; one repair/replay maximum per case; Farrice retains final recognition authority.

## Evolution Council Verdict

- **Forager digest:** the approved router already has clean synthetic proof; the missing evidence is real-brief recognition across heterogeneous truth risk.
- **Build hypothesis:** a held-out six-case corpus and failure ratchet can harden repeatability without touching routing breadth.
- **Risk review:** the largest threat is leakage or a conductor declaring its own prose A-tier. Mitigation: use real source paths, seal references first, isolate workers, retain generated/reference paths, and leave final recognition to Farrice.
- **Change scope:** corpus folder first; existing skill files change only in response to a named failed fixture.
- **Evaluation plan:** hard factual gates plus dosage, usefulness, restraint, and reference-recognition criteria; one repair turn per failure.

### Verdict

- **Target:** Shaan story-deployment repeatability across six domains.
- **Goal packet complete:** yes.
- **Recommended path:** bounded local hardening; no new skill or route.
- **Permitted side effect:** corpus artifacts plus fixture-proven minimal edits.
- **Proof artifact:** final blind-pass report and six case receipts.
- **Stop condition:** six final case verdicts, every initial fail fixture-backed, unchanged router scope, relevant verifiers pass.
- **No-regression check:** original three synthetic fixtures plus the new six real cases remain valid.
- **Human checkpoint:** Farrice recognition before declaring human-certified A-tier or activating globally.
- **Open risk:** local model agreement is component evidence, not market or reader-response proof.
