## Uniqueness Audit

## Business and System Value

1. **Coherence at higher velocity.** This can prevent “Frankenstein” outputs across thousands of routes. More generation increases coordination debt faster than output value.
2. **Better expert composition.** It preserves specialist craft while broadening system awareness. This avoids both expert soup and shallow generalism.
3. **Safer autonomy.** Agents receive context, standards, and responsibility boundaries without forcing a choice between micromanagement and uncontrolled action.
4. **Reusable capability design.** Repeated local solutions can become common building blocks. Future work then carries less reinvention and context burden.
5. **Stronger operator learning.** Understanding, diagnosis, and recovery become part of AI fluency, reducing dependence on outputs nobody can explain or repair.
6. **Lower process debt.** Evidence is required before every scar becomes another gate. This protects speed and creative range while retaining hard truth and permission vetoes.

## Recommended Architecture Hypothesis

Create one cold, source-grounded semantic primitive tentatively titled **Systems Thinking and Expertise Intelligence Overlay**, then add narrow advisory pointers to the smallest set of existing owners. It should not create a new router, mandatory form, quality score, or blocking gate.

The overlay would carry five compact decisions:

1. **Zoom:** What is one level wider than the local task, and which assumption changes there?
2. **Craft:** Which judgment remains specialist-owned, even if execution is fluid?
3. **Pave:** What reusable default, source truth, or guardrail should solve this once?
4. **Own:** Which human/operator remains accountable for the outcome and recovery?
5. **Learn:** Did the failure require changed behavior, or is new process actually justified?

## Promotion and Kill Gates

The layer begins in `SHADOW`. Promotion requires all of the following:

1. Three independent production receipts across different task types.
2. A blind comparison where the overlay output is preferred or materially clearer.
3. Zero new blocks on frozen safe controls.
4. No increase in mandatory question burden for clear tasks.
5. Preserved specialist depth and creative range.
6. Explicit Farrice approval before any enforcement behavior.

Kill or keep cold if it produces generic “think bigger” language, duplicates existing contracts, adds ceremony without a changed decision, or makes agents less decisive.
