# Use Guide — Jun Pursuit and Angles Expansion

Use the existing `/jun-story-engine`; no new command was added.

## Recover a method

Ask: “Run `/jun-story-engine` on this lived material. Mine the Pursuit into a Method Card, preserve the proof ceiling, and stop at an offer hypothesis until market validation.”

Expected states: `NEEDS_SOURCE`, `NO_OFFER`, `METHOD_CANDIDATE`, or `OFFER_HYPOTHESIS`. Only a separate market-validation run may produce a validation verdict.

## Expand one moment

Ask: “Run `/jun-story-engine` on this one moment and create a source-traced Angle Map. Keep only meaning-distinct angles with their own 3P.”

The system may return fewer angles than requested. That is correct when the supplied material does not support semantic breadth.

## Boundaries

- The operator supplies lived facts, feelings, motives, and privacy permissions.
- A method candidate is not a validated offer.
- A payoff anecdote is not buyer proof.
- A wording variation is not a new angle.
