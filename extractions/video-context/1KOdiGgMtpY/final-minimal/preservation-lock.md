## Primary Failure Class

useful loss-detection idea became a visible presentation system and began to

## Preservation Lock

- **Keep:** source-grounded signal preservation; explicit machine-execution
  boundaries; natural human handoffs; unchanged public craft; human ownership;
  proof-state honesty; the broad prototype as negative-control evidence.
- **Change:** make the behavior silent by default; limit routine visible
  structure to AI-agent handoffs; reduce optional consequential strategy use to
  a three-line decision spine.
- **Do not disturb:** existing content, strategy, handoff, proof, routing,
  Launchpad, and agentic-engineering owners; public prose; approval boundaries;
  main checkout or global Codex behavior.
- **Risk:** renaming the same bureaucracy as a smaller framework, or mistaking
  deterministic field coverage for user value.
- **Gate:** four frozen recipient modes, zero visible Signal Fidelity surface
  for public readers and human collaborators, no command/router/hook/skill or
  automatic activation, and a clean diff against main.
