## Zero-shot trigger

Use the full account prompt with the account, offer, ICP, outcome, mechanism, proof, capacity, current assets, and constraints. If some data is missing, it creates a starter workspace with explicit assumptions and keeps all external copy in draft state.

Compared with the earlier Diandra system, it adds effort-adjusted idea selection and repeated 100-post learning cycles.
