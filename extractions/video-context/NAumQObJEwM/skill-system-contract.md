# Skill System Contract — Design Gauntlet

## Source evidence

The canonical source package is this directory. Video evidence is storyboard-grounded with transcript limitations preserved in `uncertainty-report.md`. External mechanics are source-inspected at pinned public commits and attributed in `video-context-ledger.md`.

## Objective

One invocation takes an existing renderable design from a preserved baseline through reference-anchored, responsive, evidence-backed repair and returns the best version without an open-ended loop or silent quality regression.

## Components

Jack Roberts Design Mastery owns craft; Design Library lookup supplies proven references; Asset Command Center supplies prior assets/styles; Blind Bar owns comparison; deterministic checks and screenshots own truth; Design Skill Enshrine preserves preference-locked winners.

## Step order

Context fingerprint → Preservation Lock → library/asset search → deterministic checks → responsive baseline → Blind Bar verdict → single-gap repair → re-verification → prior-best comparison → stop/recover → preference checkpoint → optional enshrinement.

## Inputs

Artifact, primary bar, mutation mode, system source, audience action, preservation items, anti-targets, and existing artifact checks.

## Outputs

Best artifact version, baseline and after evidence, check receipts, per-round verdicts and changes, surviving risks, preference checkpoint, and reuse disposition.

## Handoff summary

Every handoff names the current best artifact, recovery path, evidence directory, source system, unresolved gap, stop reason, and next authorized action.

## Human checkpoint

Farrice locks the winning aesthetic direction before it becomes permanent doctrine. More than two repair rounds or real critic/worker agents also require explicit approval.

## Validation

Prompt audit, pointer wiring, skill structure checks, routing discovery, repository diff review, source-boundary inspection, and a cold-start behavior proof.

## Behavior-changing proof

`behavior-proof.md` demonstrates that the new route requires a named bar, preserved screenshots, one visible gap, a re-render, regression comparison, and surviving-risk report.

## Result surface

The reusable surface is `skills/jack-roberts-design-mastery/workflows/design-gauntlet.md`, supported by a structure-pure v2 prompt and thin command bridge.

## Context policy

Keep artifact, primary reference, system source, screenshots, and repair log hot. Search libraries on demand. Keep video frames and external histories cold unless a fork requires them.

## Reuse hook

Preference-locked winners feed the existing enshrinement workflow, DESIGN.md library, or Asset Command Center. No parallel skill tree, gallery, or global command is created.
