# Source Analysis — Turn Claude into a Design Genius... Just Watch

## Verdict

The source is valuable as an integration pattern, not as a replacement system. Its strongest idea is the compounding sequence: start from a high-quality, machine-readable design reference; render and compare a real artifact against a named bar; then preserve winning assets and style recipes so the next build starts higher.

Antigravity already had stronger local implementations of each layer, but they were not joined by one paved, evidence-first design route. The Design Gauntlet closes that gap under the existing Jack Roberts owner.

## What Was Harvested

| Source mechanic | Local integration | Why it changes behavior |
|---|---|---|
| DESIGN.md library as the cold-start | `knowledge/design-libraries/INDEX.md` + `execution/design_md_brand_lookup.py` | Every Gauntlet checks proven systems before inventing a visual language. |
| Screenshot-first iteration against an admired example | `design-gauntlet.md` + `directives/blind-bar-protocol.md` | Taste claims now require visible comparative evidence. |
| Responsive/state-aware review | desktop, tablet, mobile plus semantic/state captures | A desktop-only beauty pass can no longer hide broken real use. |
| Separate mutation modes | Precision Polish, Theme-Respect Elevate, Creative Unleash | The system can elevate or reinvent without silently violating a preservation boundary. |
| Evidence before score | deterministic checks, critical failure caps, Blind Bar verdict | A self-awarded number cannot turn an unverified artifact green. |
| Bounded iteration with rollback | two repair rounds, plateau/oscillation/regression stop, preserve prior best | Iteration cannot become churn or make a good version worse. |
| Local design OS | existing Asset Command Center and style recipes | Winning decisions feed the next project without creating a parallel library. |

## What Was Deliberately Rejected

- A new global Gauntlet skill, new asset gallery, automatic critic/worker fleets, new browser dependency, universal taste bans, and open-ended five-plus-round loops.
- The external systems were harvested as bounded mechanics, not installed or copied wholesale.
