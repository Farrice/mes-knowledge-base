# Matt Haig Reader Bridge — Architecture Checkpoint 2

## Decision Requested

Approve, adjust, or reject the **cold** `matt-haig-reader-bridge` skill-system architecture below.

Approval authorizes implementation and validation in the isolated Codex lane. It does **not** authorize hot registration, global mirrors, external publication, A-tier promotion, or commercial claims.

Approval means these five choices are locked for the build: the `matt-haig-reader-bridge` slug; Haig as sole function owner; the ten-workflow ladder; seven non-duplicative born-v2 prompts; and cold B-tier status until Farrice judges a blind pass. Any requested change to those five belongs at this checkpoint, before files and command surfaces multiply.

## Architecture Verdict

**Build a new source-grounded expert system with one owner, nine production workflows, one proof workflow, and seven born-v2 deliverable prompts.**

Do not merge the material into a generic writing skill. The distinctive capability is not “write emotionally.” It is the connected decision system that protects a private signal, gives it an accessible story carrier, diagnoses revision causally, and stops before aliveness is polished away.

Do not position it as a bestseller formula. “Millions” belongs to the interview title and career context, not to a causal claim the source can prove.

## Seven Distinct Born-v2 Deliverable Prompts

The ten workflows collapse into seven distinct output shapes; forcing ten prompts would duplicate contracts.

| Prompt | Output contract |
|---|---|
| Reader Bridge Diagnostic | Signal/bridge diagnosis, causal issue, ranked intervention, stop condition |
| Feeling Carrier Scene | Target feeling, story vehicle, finished scene/passage, residue check |
| Oblique Truth Transformation | Emotional fact, three protective-distance options, selected premise, sample scene |
| Authentic Hope Revision | Darkness/cost inventory, false-hope removal, revised arc/passage, action affordance |
| Structural Pull Edit | Symptom ladder, root cause, structural patch, line patch, protected-original comparison |
| Simple-Word Residue Edit | Abstraction map, precise replacements, revised passage, ending options |
| Concept and Title Compression | Emotional proposition, child-simple story engine, title set, selection rationale |

Every prompt must include Role & Activation, bracketed inputs, source-derived execution protocol, exact output contract, shape-only skeleton, 3–6 yes/no gates, creative latitude, and deploy-when triggers.

## Runtime Decision Logic

```text
INPUT
  ├─ no actual premise/draft/evidence → HOLD and request the missing source
  ├─ asks to imitate Matt Haig's voice → REDIRECT to mechanics, not mimicry
  ├─ promises sales or mass readership → REJECT unsupported causal claim
  └─ usable material
       ├─ approval contamination? → taste-boundary
       ├─ idea has heat but no draft? → percolation-draft
       ├─ guarded autobiography? → oblique-truth
       ├─ theme stated, not felt? → feeling-carrier
       ├─ false bleakness/hope? → authentic-optimism
       ├─ local issue repeats? → structural-pull-edit
       ├─ abstraction/overwriting? → simple-word-residue
       └─ concept too complex? → child-story-reset

ALWAYS
  diagnose before treating
  preserve a protected original
  name reader consequence
  keep machinery invisible in shipped prose
  stop when charge falls
```

## Behavior-Changing Contract

The system must change decisions, not merely add Haig vocabulary.

| Weak default | Required behavior change | Observable proof |
|---|---|---|
| Polish the marked paragraph | Search upward for the causal story layer | One repair resolves multiple local failures |
| Copy what currently sells | Use market evidence as constraint, not origin | Premise has a non-comparables reason to exist |
| Make the material broadly relatable | Preserve a strange particular and simplify only the bridge | Readers can project without genericized content |
| Improve every sentence | Protect productive irregularity and compare against the earlier draft | Charge does not fall across revision |
| Add uplift | Make hope survive cost and create action | No denial of damage; a credible next possibility exists |
| Ask consensus what to think | Record the pre-feedback response first | Original judgment remains inspectable after feedback |

## Negative Controls

The proof workflow must fail or redirect each case:

1. **Trend-chasing premise:** “Rewrite this to resemble this month’s bestseller.” → Market-lag warning; recover private signal.
2. **No source material:** “Make my novel more Haig.” → HOLD; request premise or passage; reject voice imitation.
3. **Guaranteed reach:** “Use this to make a million-copy book.” → Reject causal promise; offer reader-access work only.
4. **Already-live draft:** A distinctive passage with no demonstrated reader friction. → Preserve; do not uniformly apply the method.
5. **Late-pass sterilization:** Revision improves grammar but lowers surprise/rhythm. → Revert or narrow the change.
6. **False hope:** Positive ending removes the story’s real cost. → Fail authentic-hope gate.
7. **Prestige performance:** Dense vocabulary exists mainly to signal seriousness. → Simplify only where accuracy and residue improve.
8. **Unsupported proper noun:** Caption-derived name lacks corroboration. → Mark UNCONFIRMED; do not encode.

## Architecture Risks

| Risk | Severity | Mitigation |
|---|---|---|
| “Reader bridge” collapses into generic emotional-writing advice | High | Require causal diagnostics, protected originals, finished artifacts, and source anchors |
| System imitates Haig’s prose voice | High | Mechanics-only activation; explicit voice-imitation redirect |
| Interview title creates a bestseller-formula claim | High | Evidence ceiling in every overview and prompt; negative control for reach guarantees |
| Too many micro-workflows fragment use | Medium | One conductor owns routing; nine specialist routes remain internal/explicit |
| Overlap produces expert soup | Medium | One owner + at most one bounded support layer |
| Single-interview embodiment is overclaimed | High | Cold B-tier; external corpus and Farrice blind pass required for A-tier |
| Revision system becomes another polish machine | High | Protected-original comparison and aliveness stop are mandatory |
