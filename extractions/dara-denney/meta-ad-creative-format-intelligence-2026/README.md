## What This Source Adds

The prior Dara system contained eight annual-review video archetypes and seven static archetypes. This source adds a broader, dated decision library spanning founder, partner, authority, creator, static, dynamic-product, educational, reaction, sale-period, AI, and proof formats.

The useful extraction is not the letter grade by itself. Dara repeatedly distinguishes:

- **scale drivers** from **supporting-cast formats**;
- top-of-funnel reach from mid/lower-funnel conversion work;
- creative potential from execution burden, rights risk, and creator fit;
- formats that can win briefly from formats that sustain spend;
- category-specific exceptions from universal recommendations.
