- **Forager Digest:** The new source adds big-idea compression, evidence ranking, cheapest validation, organic proxy research, persona-gap triangulation, and creative-ecosystem expansion. - **Build Hypothesis:** One new component workflow plus a small universal router changes behavior with the least duplication.
- **Risk Review:** A new mega-skill would duplicate the owner; an automatic evidence score would overstate a dated heuristic; a global mirror would exceed permission; new ledger fields would create premature schema coupling.
- **Change Scope:** Add source package, reference, workflow 00, workflow 30, prompt 30; update current skill, agent, source ledger, and existing command wrappers.
- **Evaluation Plan:** Verify source paths, prompt structure, skill completeness, command/router discoverability, five cold-start routes, applied Health Performance brief, and no unrelated diffs.
- **Target:** Existing Dara skill system and front door.
- **Goal packet complete:** yes.
- **Recommended path:** skill-evolution, bounded to the named component and router.
- **Permitted side effect:** workspace-local reversible edits.
- **Proof artifact:** `behavior-proof.md`.
- **Stop condition:** all declared checks pass or one repair pass is exhausted.
- **No-regression check:** prior workflows 01–29 remain addressable and existing Health Performance production artifacts stay unchanged.
- **Human checkpoint:** before global mirroring, spending, rendering, publishing, or external actions.
- **Open risk:** No live paid test from this new source exists; behavior proof can validate routing and brief quality, not performance.
