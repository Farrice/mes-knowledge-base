## Gap Fill Analysis

The roster had *how to make realtor content* covered from three angles (Enrico: format and profile; Sherrard: brand and conversion; Jen: production pipeline). It did not have *how to get an already-posting agent unstuck* — diagnosis from their own data, then a re-aim toward one person and one feeling. That is the capability this adds.

## Build Shape Decision (source-to-skill-system contract)

**Component skill + explicit stacking hooks into Enrico / Jen**, not a companion OS layer and not an expansion inside Enrico.

- Not an Enrico expansion: the source's center (diagnosis, audience specificity, comfort content) is a different author with a different thesis. Wiring it into Enrico's body would be voice-stacking (skill-craft anti-pattern 7).
- Not a companion OS layer: nothing here changes how *many* workflows operate; it adds a bounded set of moves.
- Not a mega-skill: seven workflows, one deliverable each, each fireable alone.
