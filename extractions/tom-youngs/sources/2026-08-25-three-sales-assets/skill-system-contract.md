| Field | Contract |
|---|---|
| Source evidence | This package: metadata, raw VTT, cleaned transcript, segments, source ledger, 12 reviewed frames and uncertainty report |
| Objective | Turn a truthful considered-purchase offer into a no-pre-sale-call Model -> Machine -> Invite -> async payment path |
| Function owner | John Whiting Propaganda Machine |
| Components | `jw-big-domino`, `jw-self-selection-filter`, `jw-ethics-gate`, new `jw-three-asset-close`, four born-v2 execution prompts, applied Control-Beater pack and local verifier |

| Inputs | Buyer, painful job, failed approach, new belief, vehicle, exact offer/terms, proof, objections, fit/disqualifiers, required inputs, claim constraints, delivery capacity, payment readiness, traffic source and awareness state |
| Outputs | Model video brief/script; Machine video brief/script; Invite decision document; Close Path with transitions, fit screen, objections, payment handoff and event ledger |

| Validation | Source package verifier, route searches, prompt-forging audit, skill validation, cold-start fixture and negative controls |
| Behavior proof | DM-only Control-Beater baseline transformed into a four-asset zero-call path with source mechanics, claim boundaries and readiness states |
| Result surface | Reusable workflow and prompts plus the private Control-Beater applied pack |
| Context policy | Keep the workflow and prompts hot on invocation; keep transcript, frames and raw metadata cold behind source pointers |
| Reuse hook | `/jw-three-asset-close`; routed from `/jw-propaganda-machine` for three-asset or zero-call-close intent |
