## Setup Details Riley Didn't Verbalize

1. **The Codex sidebar reveals real daily usage, not just the demo.** Under project "AgentNativePodcast," the persistent chat-thread list (visible across many frames) includes titles never mentioned on camera: *"Create morning episode automation," "Create Day 1 episode files," "Create long-form intro," "Find Blake Cole email thread," "Research Open[AI] announcements," "Research Codex interview questions," "Acknowledge greeting."* This is stronger evidence for "I run my entire startup inside Codex" than anything said aloud — it's an unstaged sidebar, not a demo artifact.
2. **The Foreplay "scrape ads" skill is a real 4+ file Python pipeline**, not a single prompt: `foreplay-competition/build_dataset.py`, `enrich_analysis.py`, `make_contact_sheets.py`, plus one more scrolled out of view. The skill writes CSV/JSON outputs (`selected_ads.csv`, `selected_ads_enriched.json`) that Codex then reads back into Notion and Paper.
3. **The scraped Notion "ads" schema is Ad (thumbnail) / CTA / Competitor** — a clean, reusable 3-column structure that could be replicated for any competitor-ad-spy skill, not described in words.
4. **Codex ships a first-class "New workflow" and "Memory (AGENTS.md)" command** (frame_0156's slash-command palette) — this is very likely the actual underlying mechanism for "turn this creator into a skill" and "call it Callaway top performing," rather than some bespoke file-write Riley improvised.
5. **The "Riley Brown" Chorus agent has an explicit, editable onboarding system prompt** ("GET STARTED GUIDE: DELETE AFTER THE FIRST CONVERSATION" with a numbered interview checklist) — the "hire agent" flow isn't a fixed persona, it's a templated interview that customizes itself to whoever hires it.
6. **The regenerated "Built a $100,000 agent for $50" ad kept the original competitor's real named person ("Dr. Fahim Hussain")** in the rebrand — Codex swapped the logo/brand copy but left the human byline untouched, an easy-to-miss but legally/ethically relevant detail (using someone else's real name/likeness-adjacent copy as a template) that's visible on screen but never flagged in the narration.
7. **Buffer's actual draft copy is longer/more polished than what Riley reads aloud** on camera — the full caption text ("Not a software engineer. Not a venture-backed startup. A domain expert with the right AI tools...") only appears in the screen share, confirming Codex is producing more finished copy than gets voiced in the summary.
8. **Cal.com's generated link correctly encodes constraint logic** (Tuesday/Thursday only, September–October only, 1pm–5pm slots, Google Meet auto-attached, America/New York timezone) — visible proof the skill can parse compound scheduling constraints from a single natural-language prompt, not just simple date ranges.
9. **Gmail's own AI-content safety banner fires on the Codex-drafted reply** before it can be sent ("Be cautious about sharing sensitive information — this AI-generated content... hasn't been checked for accuracy") — an actual platform-level guardrail Riley's workflow runs into, never mentioned in the audio.
10. **Two distinct Codex "new chat" landing templates exist**: a "What should we build?" marketing/general screen and a "What should we work on?" screen with coding-specific categories (Explore code / Build a feature / Review code / Fix issues) — visual proof that Codex's product surface still defaults to a software-engineering mental model even when Riley is exclusively using it for marketing ops.
