# Skill System Contract — Nicolas Cole Niche Discovery

## User Job

Help a creator, freelancer, consultant, agency, or client discover and deploy a niche using observed signal rather than identity theater or unsupported market certainty.

## Existing Owner and Build Shape

- Existing owner: `skills/nicolas-cole-niche-positioning/`
- Shape: extend the existing skill into a connected decision system.
- No new hot command, agent, dependency, router, or competing skill tree.

## Provenance Boundaries

- `VERIFIED`: directly supported by transcripts or observed frames.
- `SELF-REPORTED`: Cole's claims about his own experience/results.
- `DERIVED`: Antigravity operationalization of a source mechanic.
- `UNTESTED`: recommendation awaiting behavior.
- `NO EVENT`: no buyer reply, sale, deposit, or payment occurred.

## Architecture and Interfaces

The existing Nicolas Cole agent remains the entry surface. Niche outputs hand off to library-first writing for asset creation, client acquisition for prospecting, sentence craft for prose, and appropriate brand/offer owners for macro strategy. The niche system does not publish or contact anyone.
