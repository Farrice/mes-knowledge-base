# Andrew Sean Greer Story-Feels-Real System: Architecture Checkpoint

**Checkpoint status:** Architecture proposed · implementation not authorized · all live components remain cold

## Architecture Verdict

Build a **standalone Greer companion skill system** with one front-door conductor, eleven focused component workflows, a Greer expert configuration, an evidence bank, seven practitioner prompts, and a cross-domain adapter.

Do not build a universal writing replacement or a mandatory companion OS layer. The system should behave differently by context:

**Fiction and narrative long-form:** Greer may own the draft-discovery and revision route.

**Content, media, strategy, sales, research, and client work:** the host-domain specialist owns the artifact. Greer receives a bounded contribution slot for lived reality, latent coherence, narrator relation, surprise, or oddity preservation.

**Mechanical, factual, regulated, or format-only work:** Greer should abstain unless a genuine narrative deficit exists.


This preserves the source's scarce craft while making its mechanisms portable. It also keeps “works in any domain” as a testable ambition rather than an unearned deployment claim.

### Objective

Turn fragments, facts, scenes, observations, and feedback into stories or story-bearing artifacts that feel inhabited, coherent, surprising, and singular: without inventing evidence, flattening oddity, or overriding the host domain's function.

### Proposed components

1. **Expert skill:** `skills/andrew-sean-greer-novel-craft/`
2. **Expert configuration:** `agents/andrew-sean-greer/AGENT.md`
3. **Front door:** `/greer-story-feels-real`
4. **Eleven component workflows:** each owns one output family and loads only the references it needs.
5. **Evidence references:** source ledger, genius patterns, hidden knowledge, exemplars, quality rubric, and anti-patterns.
6. **Cross-domain adapter:** a host-contract and mechanism-allowlist layer, not a second general writing OS.
7. **Practitioner prompts:** seven self-contained prompts covering the distinct deliverable families.
8. **Proof lab:** frozen fixtures, baseline outputs, Greer outputs, negative controls, masked comparisons, and human verdicts.
9. **Existing owners:** Writing Depth as cross-cutting conductor; Stanton for premise and audience pull; Lamott for generative permission; Harding for perceptual rendering; domain specialists for factual, conversion, platform, and client constraints.

### Step order

#### Stage 0: Lock the host contract

Capture the artifact type, audience, objective, evidence boundary, locked voice, factual claims, conversion or client function, format, and the one thing that must not be lost.

#### Stage 1: Determine the work state

Classify the input as generation, assembly, revision, feedback diagnosis, or final reality pass. Do not load the entire Greer system when one component is sufficient.

#### Stage 2: Select the Greer move

Choose no more than three component workflows by default. A full novel reconstruction may use the entire ordered route.

#### Stage 3: Apply in altitude order

Run latent architecture before scene form, scene form before page pleasure, and page pleasure before grammatical timing. Feedback diagnosis runs after a draft exists.

#### Stage 4: Hand to the host-domain owner

The specialist for the destination format preserves truth, proof, conversion, platform, production, or client requirements. Greer cannot veto a hard host constraint.

#### Stage 5: Run the Greer reality pass

Check echo transformation, fair omission, surprise, human evidence, narrator relation, and distinctiveness. Apply only the checks relevant to the artifact.

#### Stage 6: Validate and return

Run factual, voice, prose, format, and destination gates. Return the finished artifact plus a compact Greer Receipt that names the mechanisms used, evidence anchors, behavior delta, and remaining risk.

### Composition rule

**One function owner:** Greer owns latent story reality and oddity-preserving revision. The destination expert owns the host artifact.

**Contribution slots:** at most one architecture owner, one Greer craft owner, and one destination owner are active by default.

**Integration rule:** every contributor must change a named decision or artifact section. A name in the stack is not evidence of contribution.

**Skip rule:** Stanton is skipped when premise, change, and audience pull are already sound. Greer is skipped when the task is mechanical or narrative treatment would impair truth or function. Line experts are skipped until architecture is stable.

**Conflict rule:** factual truth, permission, client selections, and host-domain hard constraints outrank literary elegance. Within those bounds, Greer owns whether the strange material is cut or more deeply integrated.

The implementation phase must prove five separate things:

2. **Structure:** files, metadata, workflow count, references, prompt contracts, and invocation bridges validate.
3. **Discoverability:** natural queries route to the conductor or correct component without displacing better owners.
4. **Cold-start use:** a fresh agent can select a route, apply it, return a deliverable, and name evidence without this conversation.
5. **Behavior change:** realistic inputs improve in masked comparisons, while negative controls prove the system knows when not to narrativize.

### Behavior-changing proof

## Workflow Architecture

### 1. `/greer-story-feels-real`: conductor

**Produces:** a finished story-bearing artifact or a complete reconstruction package, followed by a Greer Receipt.

**Use when:** the user wants the system to choose the smallest useful Greer route rather than selecting a mechanism.

**Core order:** host contract to work state to Greer components to destination owner to reality pass to validation.

**Source basis:** the full extraction loop.

**Does not own:** factual research, platform optimization, conversion proof, voice capture, or line-level lyric rendering.


### 2. `/greer-echo-map`: latent coherence

**Produces:** a recurrence map, dominant motif family, off-book material list, transformation opportunities, and a revision sequence.

**Use when:** the draft is episodic, overfull, or unable to name what it is about.

**Stacks with:** Lamott generation before; Stanton premise after the latent subject is visible; Writing Depth architecture route.

**Evidence:** Source Ledger §1.


### 3. `/greer-crossword-assemble`: nonlinear assembly

**Produces:** a scene lattice and the obligations carried by each completed scene, followed by missing-scene briefs and a sequence without filler.

**Use when:** scenes or story fragments exist out of order.

**Stacks with:** `/greer-echo-map`, then destination structure owner.

**Evidence:** Source Ledger §2.


### 4. `/greer-form-permission`: native form and reference mining

**Produces:** three form alternatives, a functional reference pile, device ledger, structural self-fit decision, and chosen scene or project container.

**Use when:** content is alive but the form is dutiful, generic, or friction-heavy.

**Embedded protocols:** Left-Hand diagnostic, project-specific consumption, detective reading, and literary permission mining.

**Evidence:** Source Ledger §§3, 7–8, 10–11, and 14.


### 5. `/greer-narrator-distance`: relation architecture

**Produces:** character-now knowledge, narrator-later knowledge, emotional distance, comic permission, compassion boundary, and revised sample.

**Use when:** narrator and character collapse, comedy trivializes pain, or serious material cannot breathe.

**Stacks with:** comedy workflow after the relation is fixed; voice owner for final language.

**Evidence:** Source Ledger §§5–6.


### 6. `/greer-reader-invention`: omission and difficulty

**Produces:** say/show/withhold decisions, inference clues, difficulty target, and a revised passage.

**Use when:** the work over-explains or withholds without fairness.

**Stacks with:** Martel for broader co-creation, destination owner for audience calibration.

**Evidence:** Source Ledger §4.


### 7. `/greer-surprise-movement`: page pleasure

**Produces:** beat-level movement and surprise audit, inert-unit diagnoses, repaired units, and a plot-versus-value balance check.

**Use when:** the work is coherent but flat, slow, or locally predictable.

**Stacks with:** Stanton when global pull is weak; Greer owns local perceptual renewal.

**Evidence:** Source Ledger §§9–10 and 13.


### 8. `/greer-human-evidence`: character and place reality

**Produces:** a human-trace inventory, cliché filter, character capture, and rewritten scene or description.

**Use when:** people or places read as dossiers, abstractions, tourism copy, or generic AI prose.

**Stacks with:** Harding after the evidence is selected; fact gate before delivery.

**Evidence:** Source Ledger §§12 and 19.


### 9. `/greer-comedy-through-fire`: honest comic treatment

**Produces:** pain statement, narrator safety contract, proportion map, grammatical timing pass, and finished comic treatment.

**Use when:** serious material is solemn, glib, emotionally evasive, or joke-stacked.

**Stacks with:** narrator distance first; host voice owner last.

**Evidence:** Source Ledger §§15–16.


### 10. `/greer-editor-patient`: feedback symptom ledger

**Produces:** pain locations, repeated effects, proposed-remedy quarantine, upstream diagnoses, and revision options.

**Use when:** feedback is abundant, contradictory, prescriptive, or flattening.

**Stacks with:** More Mermaid when the disputed element is singular or strange; Stanton root diagnosis only when the issue is audience architecture.

**Evidence:** Source Ledger §21.


### 11. `/greer-more-mermaid`: oddity-preserving reconstruction

**Produces:** cut/move/transform/prepare/intensify comparison, commitment decision, retrofit map, and a revised proof section.

**Use when:** a distinctive element does not fit and deletion is the easiest recommendation.

**Stacks with:** editor-patient first; echo map and crossword assembly for the retrofit.

**Evidence:** Source Ledger §22.


### 12. `/greer-lacquer-revision`: technical pass and perception reset

**Produces:** operation-classified revision plan, transformed draft, incubation interval, and cold-return checklist.

**Use when:** a draft is being polished into blindness or revision feels vague.

**Embedded protocol:** search for dormant setups and retrospective echoes before line polish.

**Evidence:** Source Ledger §§16–18.


## Seven Practitioner Prompt Families

The workflow count is twelve because the mechanisms produce distinct intermediate artifacts. The prompt count is seven because several components naturally compose into one user-facing deliverable.

1. **Story Feels Real:** front-door production from objective, evidence, raw material, and destination format.
2. **Echo + Crossword Reconstruction:** a latent motif map and scene lattice, followed by missing-scene briefs and revision order.
3. **Scene-Form Permission:** form alternatives and a finished scene in the chosen container.
4. **Narrator Comedy Distance:** relation map plus a rewritten passage that makes serious material breathable.
5. **Surprise + Human Evidence:** local reality audit plus repaired pages, beats, or scenes.
6. **Feedback + More Mermaid:** symptom ledger, diagnosis set, commitment decision, and oddity-preserving retrofit.
7. **Cross-Domain Story Adapter:** finished host artifact with bounded Greer mechanics and hard-domain validation.

Each prompt must operate in practitioner mode, state an exact output contract, preserve creative latitude, identify what it refuses to invent, and include a completed example in a distinct domain.

## Cross-Domain Adapter

### Fiction and narrative long-form

**Allowed by default:** all Greer mechanisms.

**Primary owner:** Greer for discovery and revision; other story experts stack by diagnosed need.

**Hard gate:** writer's intended experience and manuscript facts.


### Content and social media

**Allowed:** human evidence, narrator relation, echo, local surprise, omission, recovered setup.

**Dose:** one or two moves; preserve hook, brevity, scannability, and platform shape.

**Blocked:** turning a short post into a literary essay or obscuring the point for atmosphere.


### Video, audio, documentary, and scripted media

**Allowed:** scene form, narrator distance, surprise, human evidence, comic proportion, oddity preparation.

**Dose:** subordinate to visual grammar, runtime, production feasibility, and truth.

**Blocked:** importing prose-only devices that cannot be perceived in the medium.


### Strategy and advisory work

**Allowed:** crossword assembly, echo detection, human evidence, reader participation, and feedback diagnosis.

**Dose:** use narrative to make decisions legible, not to hide uncertainty.

**Blocked:** implied causality unsupported by evidence or an ambiguous recommendation.


### Sales, offers, and persuasion

**Allowed:** echo/payoff, narrator relation, character evidence, surprise, and story-bearing proof already present in the packet.

**Dose:** conversion clarity and proof remain primary.

**Blocked:** invented testimonials, urgency, outcomes, pain, buyer events, or market validation.


### Research, education, and health communication

**Allowed:** human evidence, calibrated omission, character capture, local surprise, and scene-based explanation.

**Dose:** evidence first; story illustrates rather than proves.

**Blocked:** fictionalizing claims, patients, outcomes, mechanisms, or consensus.


### Client and personal-brand work

**Allowed:** human evidence, source-pile voice calibration, narrator distance, comedy proportion, and oddity preservation.

**Dose:** client-approved facts and felt taste outrank the rubric.

**Blocked:** manufactured vulnerability, false memory, or rewriting a selected primary without permission.

## Anti-Duplication Boundaries

### Andrew Stanton boundary

Stanton finds premise, change, and the audience clamp. Greer finds latent rhyme, nonlinear fit, omission, local surprise, narrator relation, and the revision that protects strange material.

### Writing Depth boundary

Writing Depth diagnoses and composes owners across all depth deficits. Greer supplies one specialist craft system it can route into.

### Lamott boundary

Lamott permits the rough draft and protects the writer from premature judgment. Greer interprets the resulting evidence and reconstructs it.

### Paul Harding boundary

Harding renders perception and sentence music. Greer decides which human detail, scene relation, omission, or recurrence deserves rendering.

### Yann Martel boundary

Martel owns broad story mystery and reader co-creation. Greer owns the difficulty dial and device-level choices that operationalize participation.

### Generic authenticity boundary

Greer looks for inspectable human evidence and structural relation, not confessional tone or vulnerability theater.

### Gate D: cold-start behavior

A fresh context receives only a realistic input and user objective. It must:

1. state the host contract;
2. choose the smallest Greer route;
3. load only the needed references;
4. produce the finished deliverable;
5. preserve hard constraints;
6. return the receipt and open risk;
7. require no explanation from this task.

### Gate E: unlike-domain proof

Run masked baseline-versus-Greer comparisons on:

1. Unordered literary fragments.

2. A conventional relationship story with an unearned surreal ending.

3. A health-performance explainer with frozen claims.

4. A strategic recommendation memo with frozen evidence.

5. A founder narrative with frozen facts and voice.

6. A 60-second script with a fixed runtime.

7. A sales page with an explicit `UNTESTED / NO EVENT` proof state.


The Greer candidate must improve the relevant Greer criteria without losing the host-domain score. A win in fiction does not excuse a loss in truth, conversion clarity, or brevity elsewhere.

### Gate F: negative controls

The system must abstain or remain surgical on:

1. A citation correction.

2. A dosage or medical-claim question.

3. A legal or financial factual summary.

4. A formatting-only edit.

5. A one-sentence direct answer.

6. An offer with missing buyer proof.

7. A client-selected passage where the requested change is only punctuation.


Any invented story, added emotional arc, or unauthorized rewrite is a failure.

### Gate G: human acceptance

Farrice reviews masked pairs for:

felt reality;

singularity retained;

coherence without obvious machinery;

surprise without random cleverness;

human evidence rather than generic specificity;

host function preserved;

whether the Greer layer made the artifact more itself.


The final state remains `UNTESTED` until this verdict exists. Structural completion, automated scores, and assistant confidence do not substitute for it.
