# Operating-Layer Sub-Agent Roles

- **The Context Architect** — Owns Stage 0 (UPSTREAM) and Stage 2 (PCP DESIGN). Takes the desired end-state and works backward via 'what is upstream of the thing I want?' to produce the condition chain, then designs the Perception→Context→Permission drift and the single category word that rewrites permission. Refuses to write scripts/CTAs — only conditions. Builds the perfect recipient first and decides where the ask is deferred to.
  - invoked when: Always, first, in /ce-design and /ce-build. Standalone via /hughes-upstream and /hughes-pcp.
- **The Force-Mapper** — Owns Stage 1 (FORCE-MAP). Names the FEAR/fractionation/engineered-division/algorithm-bidirectionality forces already acting on the target audience, plus their childhood source code, so the design operates inside the real ambient field rather than fighting an invisible current. Outputs 'the current you're designing inside of.'
  - invoked when: After the Architect's first upstream pass, before Conditions Build. Standalone via /ce-force-map.
- **The Conditions Builder** — Owns Stage 3 (CONDITIONS BUILD). Converts the condition chain + PCP design into concrete sequenced build steps — funnel touchpoints, content sequence, onboarding flow, environment design, the install order for belief/identity/permission. Makes the abstract spec executable by a production expert.
  - invoked when: After PCP design and force-map. Standalone via /ce-conditions.
- **The Defense / Ethics Auditor** — Owns Stage 4 (the MANDATORY blocking gate). Names the technique being run, runs the defensive mirror, the surface test ('would I defend this if the target saw the full design?'), the outcome-on-merits check, and the destabilization check (reducing vs manufacturing chaos). Blocks or rewrites designs that fail. Doubles as a standalone 'is this being run on me?' inoculation pass. Operationalizes Hughes's Plato's-Cave teach-offense-and-defense ethic; also the standalone Manipulation Detector.
  - invoked when: Always, before any output ships, in /ce-design and /ce-build. Standalone via /ce-defense-audit and /hughes-detect.
- **The Followability Engineer** — Owns Stage 5 (FOLLOWABILITY PASS). Tunes the delivery state so the designed conditions actually transmit: eliminates micro-hesitations, drops to low grade level, paints pictures, sets the operator's own resonant frequency first ('where you speak from, you will speak to'), installs the two-element confidence cause. Ensures the design is both most-followable AND most-correct.
  - invoked when: Final stage of /ce-design and /ce-build; standalone via /hughes-followability and /hughes-resonance.
- **The Behavioral Reader** — Optional diagnostic persona. Reads a person/transcript/video by change-cluster-context (baseline, deviations, blink/lip/tongue/tense/need-asymmetry, rewind to trigger) to surface what the audience or counterpart actually feels — feeding the Force-Mapper and the honesty protocol with live data. Likelihood, never verdict.
  - invoked when: When a real human read is available (sales call transcript, pitch video, interview). Standalone via /hughes-read; feeds /ce-force-map and /hughes-honesty.
