## Review Loop

- **Target:** one connected command surface and its five versioned record types.
- **Evaluator:** `execution/verify_search_content_mastery.py` plus repository skill, prompt, routing, and harness checks.
- **Pass:** every locked fixture and all three cold starts pass; no unsupported source claim; route regression surfaces `/search-content-mastery` first.
- **Turn cap:** two repair passes per failing criterion.
- **No regression:** existing Nathan workflows remain present; Health automation prompt and existing ledgers are byte-identical; offer canon is unchanged.
- **Failure action:** mark the affected capability `PARTIAL`, retain the exact failing receipt, and do not promote to `RUNTIME_OBSERVED`.

## Dependency Gate

No new package is allowed. Runtime and validators use the Python standard library and existing repository tools. Video capture may use the already-installed watch plugin, `yt-dlp`, and `ffmpeg`; paid Whisper is forbidden without a separate cost-gate approval.

## Structure Pass

Check for duplicated Nathan/Ethan methods, oversized conductor files, implicit field guesses, mutable ledgers, hidden external actions, and any production method copied into the conductor instead of routed by reference.

## Use-Now Artifact

A local `/search-content-mastery foundation ...` run that creates and validates a portable project pack without hidden chat context.

- Cold starts: Health Performance, local service, ecommerce.
