# Fixture 02 — The Memory Bureau

## Request

The premise is overloaded: in a future city, a bereaved municipal archivist audits an AI memory market regulated by seven agencies while investigating whether simulated memories should count as legal inheritance. Use the child-story reset, then rebuild adult depth without copying *The Midnight Library*, *The Humans*, or *The Midnight Train*.

## Constraints

- Adult speculative fiction.
- Preserve the question of who owns a memory after someone dies.
- Produce a clear premise and opening movement.
