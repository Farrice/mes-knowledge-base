## Hidden Operating Mechanics

1. **Flow has levels, not a single tactic.** Literal cues solve clarity; hierarchy solves professional readability; micro-routes reward dwell; implied motion supplies energy; disruption creates re-engagement; temporal flow controls the experience over time.
2. **Hierarchy precedes decoration.** Size and contrast establish the first route before color, texture, and expressive surface treatment are allowed to compete.
3. **A grid is a commitment plus a break budget.** It generates order and whitespace. Selective breakage is effective because the underlying regularity makes the exception legible.
4. **Internal rhythm is trust architecture.** Predictable spacing and alignment lower cognitive friction. A deliberate interruption works only after that rhythm has been established.
5. **Friction is purposeful resistance.** It is not synonymous with visual noise. The useful question is what the pause makes the viewer notice or resolve.
6. **Transferability is a concept test.** A concept that survives only at one size or aspect ratio is not yet a system.
7. **Temporal flow makes time a design material.** `Punch → Slow → Pull → Release` converts a static hierarchy into a paced experience.

## Composition Sequence

1. Name one leverage point and the dominance mechanism.
2. Declare the primary eye path and at most two subordinate micro-routes.
3. Select a grid by the job it must perform; name the single intentional break or explicitly choose none.
4. Choose the movement level and, when relevant, map the four temporal beats.
5. Budget friction: where the viewer should pause, why, and where flow resumes.
6. Adapt the same hierarchy to the required formats before production.

## Anti-Patterns

- Choosing a grid because it looks sophisticated rather than because it organizes the content.
- Adding arrows after hierarchy failed instead of repairing scale and contrast.
- Making micro-routes as salient as the main route.
- Calling random rotation, texture, or blur “friction.”
- Breaking several grid relationships and losing the contrast between order and exception.
- Treating cross-format output as cropping rather than adapting hierarchy.
- Applying LIFT to logo-only or palette-only work.
