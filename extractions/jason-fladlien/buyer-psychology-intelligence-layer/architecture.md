## Architecture Checkpoint

### Verdict

Build one `Buyer Psychology Decision Intelligence Overlay` in SHADOW mode.

### Why this shape

The existing Jason package already has 27 workflows and substantial internal overlap. The missing capability is diagnosis and selection: which psychological decision is relevant, what source supports it, what countercondition prevents misuse, and which native owner should act.

A new mega-skill, eight new bias workflows, or broad router changes would increase duplication and context load without solving that problem.

### Components

1. **Source corpus index** — local video packages, source roles, novelty, overlap, scientific calibration, and evidence limits.
2. **Cold Jason reference** — compact selector, source anchors, supporting corpus moves, research links, and owner boundaries.
3. **SHADOW semantic primitive** — activation, abstention, eight decisions, ethics, ownership, context policy, and promotion/kill rules.
4. **Native owner pointers** — Copywriting, Content & Media, Marketing, Revenue & Offer, and bounded Writing.
5. **Behavior proof lab** — four simulated positive fixtures and two negative controls.
6. **Dedicated verifier** — structural, provenance, owner, fixture, mode, and forbidden-surface canary.

### Objective

Improve audience-facing decisions by selecting and applying one source-bounded psychological mechanism while preserving truth, evidence, voice, options, and native function ownership.

### Components

The system uses the six components named in the Architecture Checkpoint. No component is a standalone front door.

### Step order

1. Native owner determines whether a human comprehension, memory, evaluation, choice, adoption, or action outcome exists.
2. If no material decision can change, abstain.
3. Cold-load the primitive and select one primary decision.
4. Load the compact Jason reference or one source slice only when evidence detail is needed.
5. Make the smallest proposed change and state the preservation lock.
6. Native owner composes or revises the artifact.
7. Existing proof, claim-safety, quality, and publishability gates run as appropriate.

### Inputs

- artifact or brief;
- intended receiver and action, when already known;
- approved facts, proof, voice, offer terms, and constraints;
- relevant source evidence or uncertainty.

The layer does not require new user questions if the existing brief is sufficient.

### Outputs

- zero change when the layer abstains; or
- one selected decision, observed friction, source/evidence label, smallest proposed change, preservation lock, owner, and remaining proof gap.

### Handoff summary

The overlay hands diagnosis to the native owner. It never becomes the author merely because it found a mechanism. Existing specialist routes are loaded only for a named weak link.

### Human checkpoint

No checkpoint is needed for local reversible SHADOW files and owner pointers under the explicit build request. Farrice's approval is required before a workspace authority pointer, global pointer, hot route, mandatory gate, enforcement behavior, external write, or promotion.

### Validation

- `python3 execution/verify_jason_buyer_psychology_overlay.py`
- `python3 execution/verify_video_context_source_package.py extractions/video-context/<id>` for all six packages
- `python3 execution/validate_skill.py jason-fladlien-marketing`
- generic skill-system, behavior-changing, agentic-engineering, Codex-authority, live-surface, and harness checks
- artifact surface, export, and frontmatter guards for the written artifacts

### Behavior-changing proof

`behavior-proof.md` holds four baseline/treatment fixtures and two negative controls. They prove component behavior, not market performance. Production promotion remains untested.

### Result surface

Primary review surface: Rendered Conversation Document in the final response. Local Markdown Sources persist the primitive, reference, corpus, architecture, behavior proof, amplification report, and extraction analysis.

### Context policy

Hot context is limited to a pointer in each native owner and the activation rule. Cold context contains the primitive, compact reference, corpus index, and source packages. Load one selected mechanism and one relevant source slice rather than the full corpus.

### Reuse hook

Reuse the overlay for buyer-facing copy, content, campaigns, offers, and action-bearing knowledge documents. Reuse the negative controls when auditing future pointer or promotion proposals.
