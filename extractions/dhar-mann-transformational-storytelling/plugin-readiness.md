## Promotion Ladder

1. Run three independent Farrice or client inputs prospectively through workflows 08 and 09.
2. Capture at least one production-owner receipt showing what the packet prevented, clarified, or missed.
3. Record Farrice's felt verdict on whether the output has the intended nuance and depth.
4. Review one published result while keeping the four scoreboards separate.
5. Pass a cold-start test in a fresh task without hidden context.
6. Re-run the dedicated verifier and plugin-readiness audit.
7. Reach at least 65/100 and document the remaining acceptance gaps.
8. Package locally for inspection only after that evidence exists.
9. Ask for explicit approval before any global installation or mirror.

## Acceptance Tests for a Later Package

- Direct invocation loads the conductor and only the selected component.
- Natural language about preserving a viewer shift through production routes to the factory.
- Missing assets or craft ownership produces one bounded hold, not invented production decisions.
- All paths resolve outside the source repo.
- A fresh task can run after installation and restart.
- Dependencies are declared or degrade gracefully; the package does not bundle full Bayer, Stanton, Kobi, Kallaway, or Kieran systems.
- Uninstall leaves canonical Antigravity skills and receipt history untouched.

## Decision

Continue using the local workflow and collect field evidence. Packaging now would freeze an interface before production-owner and cold-start behavior have earned it.
