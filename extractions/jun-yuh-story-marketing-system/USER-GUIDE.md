# Jun Yuh Story Marketing System — Operator Guide

## Two Front Doors

Use `/jun-story-engine` when the job is focused: find, structure, expand, downgrade, or refuse one story.

Use `/junyuh-marketing` when the job is the full system: turn expertise and lived material into task-specific content, a campaign, conversion path, masterclass, Story Bank, and measurement plan.

## Exact Source Formula

Jun's formula is:

`Problem → Pursuit → Payoff`

- Problem creates relevance.
- Pursuit contains the method, decisions, and potential IP.
- Payoff shows the strongest supported change.

`Promise` is not a fourth Jun P. The system may derive a proof-bounded Promise after 3P, but it must be labeled `SYSTEM SYNTHESIS`.

## Task-Specific Invocations

### Turn Expertise Into Content

```text
Run `/junyuh-marketing` using Expertise-to-Story only. Take this supplied method or expertise and recover the real Problem, Pursuit, and Payoff. Select the correct service/product/coach/founder/education adapter. Produce one social asset or a bounded destination handoff. Do not invent a client result.
```

### Build A Four-Stage Campaign

```text
Run the Story Mission Campaign branch on this supported story packet. Produce ATTRACT, NURTURE, POSITION, and CONVERT assets with different evidence jobs and CTAs. Collapse paraphrases.
```

### Connect Story To An Offer

```text
Run the Story-Led Conversion branch. Map identification, trust, belief, and next action. Derive a proof-bounded Promise from 3P, label it SYSTEM SYNTHESIS, and preserve MARKET PROOF: NO EVENT until buyer behavior exists.
```

### Build A Story-Led Masterclass

```text
Run the Story-Selling Masterclass branch. Build a teaching-to-offer run-of-show from supplied speaker stories, method, proof, offer facts, objections, and CTA authority. Do not copy Jun's price, guarantee, bonuses, urgency, or results.
```

### Build The Story Bank

```text
Run the Story Bank branch on these notes and prior assets. Capture source, 3P, meanings, mission uses, proof state, results, and Payoff-to-Problem continuity. Keep hooks separate from angles and keep NO EVENT visible.
```

### Measure Story And ROI

```text
Run the Story Performance branch on this deployed asset. Evaluate it by its declared mission. Separate attention, recognition, intent, sale, and collected revenue. Calculate ROI only if attributable cost and revenue are supplied.
```

## Proof Boundary

The system is source-grounded and locally verified. It is not yet proof that Jun's formulas will improve Farrice's audience response, leads, sales, or revenue. That requires a real deployment with a baseline, measurement window, and buyer-event evidence.
